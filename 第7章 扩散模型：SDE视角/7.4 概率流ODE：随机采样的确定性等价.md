# 7.4 概率流ODE：随机采样的确定性等价

> **核心观点**：Song et al. (2020) 证明，每个逆向SDE都有一个确定性等价——概率流ODE（Probability Flow ODE）：$dx/dt = f(x,t) - \frac{1}{2}g(t)^2\nabla_x\log p_t(x)$。ODE与SDE在每个时刻有相同的边际分布 $p_t(x)$，但单条轨迹的演化方式完全不同——SDE描述"粒子的布朗运动"，ODE描述"气体的流线"。DDIM是PF-ODE的离散化特例，正如DDPM是逆向SDE的离散化特例。PF-ODE为扩散模型打开了确定性采样、似然计算和潜在空间操作的大门。

## 一个你可能没想到的痛点：每次生成都不一样，怎么复现？

上一节的逆向 SDE 牛是牛，但它有个"毛病"：因为最后那项布朗运动 $d\bar{w}$ 是随机的，**每次从同一个噪声起点出发，走出来的轨迹都不一样**。对创意生成这叫"多样性好"，但对科学计算、图像编辑、可复现实验来说，这就很头疼——你改个参数想对比，结果连输入噪声都没动，输出却变了。

**先猜后揭**：我们能不能把那个随机项"去掉"，得到一个完全确定的方程，让它和随机 SDE "殊途同归"——也就是说，虽然单条轨迹不同，但最后大量粒子的分布完全一样？直觉上好像去掉随机项会"改变分布"。**揭晓**：不会！而且只需把得分修正项的系数减半（从 $g^2$ 变 $g^2/2$）就恰好补偿了随机项的缺失。这就是概率流 ODE（Probability Flow ODE，概率流常微分方程——一种没有随机项的确定性演化方程，描述"速度场"而非"随机游走"）。

读完本节你会能：
1. 写出 PF-ODE 并说清"系数减半"为什么对；
2. 用 Fokker-Planck 方程证明 SDE 与 ODE 边际分布相同；
3. 知道 DDIM = PF-ODE 的离散化，和 DDPM = 逆向SDE 离散化是"一对"；
4. 列举 PF-ODE 的三大实践红利（确定性采样、似然计算、潜在空间插值）。

## 从SDE到ODE：去掉随机性，系数减半

逆向 SDE 含随机项 $g(t)\,d\bar{w}$。Song et al. (2020) 给出它的确定性等价——概率流 ODE：

$$\boxed{\frac{dx}{dt} = f(x,t) - \frac{1}{2}g(t)^2\,\nabla_x\log p_t(x)}$$

注意和逆向 SDE 的关系：

- 逆向 SDE 漂移：$f - g^2\nabla\log p_t$
- PF-ODE 漂移：$f - \frac{1}{2}g^2\nabla\log p_t$

**得分修正项系数减半**（从 $g^2$ 变 $g^2/2$）——看似微小，含义深刻：它正好补偿了"去掉随机项"后概率演化差的那一块。

## PF-ODE 的等价性证明：用 Fokker-Planck 看"殊途同归"

**定理**：PF-ODE 与正向 SDE 在每个时刻 $t$ 有相同的边际分布 $p_t(x)$。

证明靠 Fokker-Planck 方程（连接 SDE 与概率密度演化的核心工具，第5章附录5A）。

正向 SDE 的 Fokker-Planck 方程（描述密度如何随时间变）：

$$\frac{\partial p_t}{\partial t} = -\nabla\cdot[f\,p_t] + \frac{1}{2}\nabla\cdot[g^2\nabla p_t]$$

PF-ODE 的连续性方程（continuity equation，确定性过程的密度演化方程）：

$$\frac{\partial p_t}{\partial t} = -\nabla\cdot[\tilde{f}\,p_t], \quad \tilde{f} = f - \frac{1}{2}g^2\nabla\log p_t$$

展开验证两者给出相同密度演化。利用 $(\nabla\log p_t)\,p_t = \nabla p_t$：

$$-\nabla\cdot[\tilde{f}\,p_t] = -\nabla\cdot\left[f\,p_t - \frac{1}{2}g^2(\nabla\log p_t)\,p_t\right] = -\nabla\cdot[f\,p_t] + \frac{1}{2}\nabla\cdot[g^2\nabla p_t]$$

这和正向 SDE 的 Fokker-Planck 方程**完全相同** ✓

**物理解释**：正向 SDE 有两效应——漂移产生"确定性输运"，扩散产生"随机散布"。PF-ODE 通过调整漂移项（得分修正减半），把"随机散布"的效果吸收进"确定性输运"。宏观（分布）效果相同，微观（单条轨迹）机制完全不同。

## PF-ODE 的物理直觉：树叶 vs 流线

PF-ODE 与逆向 SDE 的关系，用一个优美的物理类比（Ref C 式画面）来理解：

- **SDE** 描述个体粒子的**布朗运动**——每个粒子被漂移力和随机力共同推着走，轨迹充满随机性；
- **PF-ODE** 描述气体的**流线**——一个"测试粒子"被速度场带着，沿确定性流线运动；
- 类比一条河——SDE 描述一片树叶的轨迹（随水流随机漂移），PF-ODE 描述水流的流线（确定性速度场）。

**边际分布等价**：大量树叶的分布 = 大量流线的分布——"殊途同归"。无论哪种方式，最终都收敛到相同分布。**单条轨迹不同**：同一片树叶的 SDE 轨迹和 ODE 轨迹可能完全不同，但宏观密度相同。

## VE-SDE 和 VP-SDE 的概率流ODE

**VE-SDE 的 PF-ODE**：代入 $f=0$、$g=\sqrt{d[\sigma(t)^2]/dt}$：

$$\frac{dx}{dt} = -\frac{1}{2}\frac{d[\sigma(t)^2]}{dt}\,\nabla_x\log p_t(x)$$

用 Tweedie 等式 $\nabla\log p_t(x)=(\mathbb{E}[x_0|x_t]-x_t)/\sigma(t)^2$：

$$\frac{dx}{dt} = -\frac{1}{2\sigma(t)^2}\frac{d[\sigma(t)^2]}{dt}\left[\mathbb{E}[x_0|x_t] - x_t\right]$$

**VP-SDE 的 PF-ODE**：代入 $f=-\frac{\beta(t)}{2}x$、$g=\sqrt{\beta(t)}$：

$$\frac{dx}{dt} = -\frac{\beta(t)}{2}x - \frac{\beta(t)}{2}\nabla_x\log p_t(x) = -\frac{\beta(t)}{2}\left[x + \nabla_x\log p_t(x)\right]$$

代入 Tweedie 等式后可写成条件期望形式。

## DDIM = PF-ODE 的离散化：两种"方言"的统一

PF-ODE 是连续方程，需离散化。最简单的离散化是 Euler 方法。以简单扩散（VE-SDE，$f=0$，$\sigma(t)=\sigma_q\sqrt{t}$）为例，PF-ODE 为：

$$\frac{dx}{dt} = -\frac{1}{2}\sigma_q^2\nabla\log p_t(x) = -\frac{1}{2t}\left[\mathbb{E}[x_0|x_t] - x_t\right]$$

逆向 Euler 离散化（从 $t$ 到 $t-\Delta t$）：

$$x_{t-\Delta t} = x_t + \frac{\Delta t}{2t}\left[\mathbb{E}[x_0|x_t] - x_t\right]$$

当 $\Delta t\to 0$，可证 $\lambda=\sigma_t/(\sigma_{t-\Delta t}+\sigma_t)\to 1/2$，恰好恢复 DDIM 更新：

$$x_{t-\Delta t} = x_t + \lambda\left[\mathbb{E}[x_{t-\Delta t}|x_t] - x_t\right]$$

**核心结论**（务必记住这一对）：

- **DDPM = 逆向 SDE 的 Euler-Maruyama 离散化**；
- **DDIM = PF-ODE 的 Euler 离散化**。

DDPM 和 DDIM 不是两种对立方法，而是同一连续框架的两种离散化——一个离散随机方程，一个离散确定性方程。

## PF-ODE 的实践意义：三扇大门

PF-ODE 不只是一个理论结果，它打开了三扇实践大门：

### 确定性采样

同一噪声起点 $x_1$，ODE 给出确定性输出——便于复现和调试。实验可复现是可靠性的基础。

### 精确似然计算

PF-ODE 定义了从噪声空间到数据空间的可逆变换 $\phi: x_1\mapsto x_0$。通过变量替换公式，可算数据精确对数似然：

$$\log p(x_0) = \log p_1(\phi^{-1}(x_0)) + \log\left|\det\frac{\partial\phi^{-1}}{\partial x_0}\right|$$

需算 Jacobian 行列式——用第6章6.4节的 Hutchinson 迹估计可高效估计对数行列式。似然计算让扩散模型能做密度估计和模型比较。

### 潜在空间操作

PF-ODE 把数据映射到噪声空间（编码），也能把噪声映射回数据（解码）。在噪声空间可：

- **插值**：两点 $x_0^{(a)},x_0^{(b)}$ 编码为 $x_1^{(a)},x_1^{(b)}$，噪声空间线性插值 $x_1^{(\lambda)}=(1-\lambda)x_1^{(a)}+\lambda x_1^{(b)}$，再解码得平滑过渡图像；
- **编辑**：噪声空间做语义操作再解码得编辑后图像。

## 实验 7.4-2：PF-ODE可控生成——噪声插值到语义插值

实验 `7.4-2.py` 演示**PF-ODE的确定性映射特性**及其在**噪声空间插值**中的应用，对比逆向SDE因随机性而无法实现可控插值的局限。

### 实验场景

实验在1D高斯混合分布 $p_0(x) = 0.3\,\mathcal{N}(-2,1) + 0.7\,\mathcal{N}(2,1)$ 上进行，使用VP-SDE（$\beta_{\min}=0.1$，$\beta_{\max}=20.0$）。实验分为三个步骤：

**步骤1（确定性映射验证）**：从相同的1000个初始噪声点出发，用PF-ODE采样两次，对比两次输出的最大差异；同样用逆向SDE采样两次（不同随机种子），对比输出差异。

**步骤2（噪声空间插值）**：选择两个极端初始噪声 $z_A = -3.0$（倾向生成 $\mu=-2$ 附近的样本）和 $z_B = 3.0$（倾向生成 $\mu=2$ 附近的样本），在噪声空间做线性插值 $z(\alpha) = \alpha z_A + (1-\alpha) z_B$（$\alpha \in [0,1]$，11个点），对每个插值噪声运行PF-ODE，观察生成样本 $x(\alpha)$ 是否平滑过渡。

**步骤3（逆向SDE对比）**：用逆向SDE重复步骤2的插值实验，使用两条独立的RNG流（种子42和142）贯穿全部 $\alpha$ 点，展示SDE因随机性导致插值路径不可复现。

**额外演示（2D语义插值）**：在2D高斯混合上用PF-ODE做噪声空间插值，可视化从 $z_A=(-3,-2)$ 到 $z_B=(3,2)$ 的语义过渡路径。

### 实验目的

1. **验证PF-ODE的确定性映射**：相同初始噪声产生完全相同的输出（最大差异 $\approx 0$）
2. **展示噪声空间插值的语义平滑性**：PF-ODE的确定性使得噪声空间的线性插值映射为数据空间的平滑语义过渡
3. **对比逆向SDE的不可控性**：逆向SDE因随机噪声注入，相同初始噪声产生不同输出，无法实现可复现的插值

### 实验输入

| 插值点数 | 11个（$\alpha$ 从0到1均匀分布） |

### 预期结果

- **步骤1**：PF-ODE两次采样最大差异 $\approx 0$（确定性）；逆向SDE两次采样最大差异 $\gg 0$（随机性）

## DDPM vs DDIM：随机性与确定性的对比

DDPM 和 DDIM 是扩散模型最常用的两种采样器，从同一连续框架出发选了不同离散化策略：

| 性质 | DDPM（随机采样） | DDIM（确定性采样） |
|---|---|---|
| 连续方程 | 逆向SDE | PF-ODE |
| 离散化 | Euler-Maruyama | Euler |
| 采样轨迹 | 每次不同 | 确定 |
| 同一起点的输出 | 可能不同 | 唯一确定 |
| 多样性 | 好（随机性提供多样性） | 受限（确定性限制多样性） |
| 典型步数 | 1000步 | 20-50步 |
| 鲁棒性 | 对得分误差较鲁棒 | 对得分误差较敏感 |
| 适用场景 | 无条件生成 | 图像编辑、逆问题 |

**核心权衡**：随机性 ↔ 确定性 ↔ 计算效率。更多随机性→更好多样性、更鲁棒但步数多；更少随机性→更快、更可控但对估计误差更敏感。实践中，生成任务常用 DDPM（或其变体），逆问题求解常用 DDIM/ODE——因为逆问题需要确定性、可控性且通常要快速采样。
