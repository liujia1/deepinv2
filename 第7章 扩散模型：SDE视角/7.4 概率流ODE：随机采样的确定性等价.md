# 7.4 概率流ODE：随机采样的确定性等价

> **核心观点**：Song et al. (2020) 证明，每个逆向SDE都有一个确定性等价——概率流ODE（Probability Flow ODE）：$dx/dt = f(x,t) - \frac{1}{2}g(t)^2\nabla_x\log p_t(x)$。ODE与SDE在每个时刻有相同的边际分布 $p_t(x)$，但单条轨迹的演化方式完全不同——SDE描述"粒子的布朗运动"，ODE描述"气体的流线"。DDIM是PF-ODE的离散化特例，正如DDPM是逆向SDE的离散化特例。PF-ODE为扩散模型打开了确定性采样、似然计算和潜在空间操作的大门。

## 从SDE到ODE：去除随机性

逆向SDE包含随机项 $g(t)\,d\bar{w}$——每次采样轨迹都不同。一个自然的问题：能否去除随机性，用确定性方程实现相同的采样？

答案是肯定的。Song et al. (2020) 证明，逆向SDE有一个确定性等价——概率流ODE（Probability Flow ODE，简称PF-ODE）：

$$\boxed{\frac{dx}{dt} = f(x,t) - \frac{1}{2}g(t)^2\,\nabla_x\log p_t(x)}$$

注意PF-ODE与逆向SDE的关系：

- 逆向SDE的漂移项：$f(x,t) - g(t)^2\nabla\log p_t(x)$
- PF-ODE的漂移项：$f(x,t) - \frac{1}{2}g(t)^2\nabla\log p_t(x)$

**得分修正项的系数减半**——从 $g^2$ 变为 $g^2/2$。这一"减半"看似微小，但含义深刻：它正好补偿了去除随机项后概率分布演化的差异。

## PF-ODE的等价性证明

**定理**：PF-ODE与正向SDE在每个时刻 $t$ 有相同的边际分布 $p_t(x)$。

证明通过Fokker-Planck方程完成——这是连接SDE与概率密度演化的核心工具（第5章附录5A）。

**正向SDE的Fokker-Planck方程**：

$$\frac{\partial p_t}{\partial t} = -\nabla\cdot[f\,p_t] + \frac{1}{2}\nabla\cdot[g^2\nabla p_t]$$

**PF-ODE的连续性方程**（确定性过程的密度演化方程）：

$$\frac{\partial p_t}{\partial t} = -\nabla\cdot[\tilde{f}\,p_t]$$

其中 $\tilde{f}(x,t) = f(x,t) - \frac{1}{2}g(t)^2\nabla\log p_t(x)$。

现在验证两者给出相同的密度演化。展开 $\tilde{f}\,p_t$：

$$-\nabla\cdot[\tilde{f}\,p_t] = -\nabla\cdot\left[f\,p_t - \frac{1}{2}g^2(\nabla\log p_t)\,p_t\right]$$

利用 $(\nabla\log p_t)\,p_t = \nabla p_t$：

$$= -\nabla\cdot[f\,p_t] + \frac{1}{2}\nabla\cdot[g^2\nabla p_t]$$

这与正向SDE的Fokker-Planck方程完全相同 ✓

**物理解释**：正向SDE有两个效应——漂移产生的"确定性输运"和扩散产生的"随机散布"。PF-ODE通过调整漂移项（得分修正减半），将"随机散布"的效果吸收到"确定性输运"中。两种描述的宏观效果（边际分布演化）相同，但微观机制（单条轨迹）完全不同。

## PF-ODE的物理直觉

PF-ODE与逆向SDE的关系可以用一个优美的物理类比来理解：

**气体类比**：

- **SDE**描述的是个体粒子的**布朗运动**——每个粒子在漂移力和随机力的共同下运动，轨迹充满随机性
- **PF-ODE**描述的是气体的**流线**——一个"测试粒子"被气体的速度场带动，沿确定性的流线运动
- 类比：想象一条河——SDE描述一片树叶的轨迹（随水流随机漂移），PF-ODE描述水流的流线（确定性的速度场）

**边际分布等价**：大量树叶的分布 = 大量流线的分布——"殊途同归"。无论用哪种方式，最终都收敛到相同的分布。

**单条轨迹不同**：同一片树叶的SDE轨迹和ODE轨迹可能完全不同。SDE轨迹蜿蜒曲折，ODE轨迹光滑确定。但在宏观（分布）层面，两者给出相同的密度。

## VE-SDE和VP-SDE的概率流ODE

### VE-SDE的PF-ODE

代入 $f=0$，$g(t) = \sqrt{d[\sigma(t)^2]/dt}$：

$$\frac{dx}{dt} = -\frac{1}{2}\frac{d[\sigma(t)^2]}{dt}\,\nabla_x\log p_t(x)$$

利用Tweedie等式 $\nabla\log p_t(x) = (\mathbb{E}[x_0|x_t] - x_t)/\sigma(t)^2$：

$$\frac{dx}{dt} = -\frac{1}{2\sigma(t)^2}\frac{d[\sigma(t)^2]}{dt}\left[\mathbb{E}[x_0|x_t] - x_t\right]$$

### VP-SDE的PF-ODE

代入 $f(x,t) = -\frac{\beta(t)}{2}x$，$g(t) = \sqrt{\beta(t)}$：

$$\frac{dx}{dt} = -\frac{\beta(t)}{2}x - \frac{\beta(t)}{2}\nabla_x\log p_t(x) = -\frac{\beta(t)}{2}\left[x + \nabla_x\log p_t(x)\right]$$

代入Tweedie等式后，可表示为条件期望的形式。

## DDIM = PF-ODE的离散化

PF-ODE是连续方程，需要离散化求解。最简单的离散化是Euler方法。

以简单扩散（VE-SDE，$f=0$，$\sigma(t) = \sigma_q\sqrt{t}$）为例。PF-ODE为：

$$\frac{dx}{dt} = -\frac{1}{2}\sigma_q^2\nabla\log p_t(x) = -\frac{1}{2t}\left[\mathbb{E}[x_0|x_t] - x_t\right]$$

逆向Euler离散化（从 $t$ 到 $t-\Delta t$）：

$$x_{t-\Delta t} = x_t + \frac{\Delta t}{2t}\left[\mathbb{E}[x_0|x_t] - x_t\right]$$

利用 $\mathbb{E}[x_{t-\Delta t}|x_t] = x_t + \frac{\Delta t}{t}[\mathbb{E}[x_0|x_t] - x_t]$（简单扩散的条件期望公式），可以证明当 $\Delta t \to 0$ 时：

$$\lambda := \frac{\sigma_t}{\sigma_{t-\Delta t} + \sigma_t} \to \frac{1}{2}$$

这恰好恢复DDIM更新规则：

$$x_{t-\Delta t} = x_t + \lambda\left[\mathbb{E}[x_{t-\Delta t}|x_t] - x_t\right]$$

**核心结论**：

- **DDPM = 逆向SDE的Euler-Maruyama离散化**（7.5节将严格推导）
- **DDIM = PF-ODE的Euler离散化**

DDPM和DDIM不是两种不同的方法，而是同一连续框架的两种离散化——一个离散化随机方程，一个离散化确定性方程。

## PF-ODE的实践意义

PF-ODE不仅是一个理论结果，它为扩散模型打开了多个实践大门：

### 确定性采样

同一噪声起点 $x_1$，ODE给出确定性输出——便于复现和调试。这对于科学计算和工程应用至关重要——实验可复现是可靠性的基础。

### 精确似然计算

PF-ODE定义了从噪声空间到数据空间的可逆变换 $\phi: x_1 \mapsto x_0$。通过变量替换公式，可以计算数据的精确对数似然：

$$\log p(x_0) = \log p_1(\phi^{-1}(x_0)) + \log\left|\det\frac{\partial\phi^{-1}}{\partial x_0}\right|$$

这需要计算Jacobian行列式——利用Hutchinson迹估计（第6章6.4节），可以高效地估计对数行列式。似然计算使得扩散模型可以用于密度估计和模型比较。

### 潜在空间操作

PF-ODE将数据映射到噪声空间（编码），也可以将噪声映射回数据（解码）。在噪声空间中，可以做：

- **插值**：两个数据点 $x_0^{(a)}$ 和 $x_0^{(b)}$ 编码为 $x_1^{(a)}$ 和 $x_1^{(b)}$，在噪声空间线性插值 $x_1^{(\lambda)} = (1-\lambda)x_1^{(a)} + \lambda x_1^{(b)}$，再解码得到平滑过渡的图像
- **编辑**：在噪声空间做语义操作（如方向调整），再解码得到编辑后的图像

### 灵活求解器

ODE可以用任意数值求解器——不仅限于Euler方法。RK4、DPM-Solver等高阶求解器可以用更少步数达到更高精度（7.5节详述）。

### 连续正规化流

PF-ODE定义了一个连续时间的正规化流——这将在第14章进一步展开，与Flow Matching建立联系。

## DDPM vs DDIM：随机性与确定性的对比

DDPM和DDIM是扩散模型最常用的两种采样器。它们从同一连续框架出发，选择了不同的离散化策略：

| 性质 | DDPM（随机采样） | DDIM（确定性采样） |
|---|---|---|
| 连续方程 | 逆向SDE | PF-ODE |
| 离散化 | Euler-Maruyama | Euler |
| 采样轨迹 | 每次不同 | 确定 |
| 同一起点的输出 | 可能不同 | 唯一确定 |
| 多样性 | 好（随机性提供多样性） | 受限（确定性限制多样性） |
| 典型步数 | 1000步 | 20-50步 |
| 鲁棒性 | 对得分误差较鲁棒 | 对得分误差较敏感 |
| 适用场景 | 无条件生成 | 图像编辑、逆问题 |

**核心权衡**：随机性 ↔ 确定性 ↔ 计算效率。

- 更多随机性 → 更好的多样性、对估计误差更鲁棒，但步数多
- 更少随机性 → 更快的速度、更好的可控性，但对估计误差更敏感

实践中，生成任务通常用DDPM（或其变体），逆问题求解通常用DDIM/ODE——因为逆问题需要确定性、可控性，且通常需要快速采样。
