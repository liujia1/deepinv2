# 7.1 从Langevin到扩散：连续时间推广

> **核心观点**：第5章的 Langevin SDE 以单一固定得分函数为驱动力，第6章的 NCSN 通过多噪声水平的退火 Langevin 实现了初步的图像生成，但本质上是"跳跃式"离散框架。本节回顾 Langevin SDE 的结构，分析其作为生成模型的局限（固定噪声水平、单尺度得分），展示 NCSN/退火 Langevin 向连续时间推广的路径——将离散噪声调度参数化为连续时间函数，将条件得分网络推广为时间条件得分网络。"离散→连续→重离散化"的认知螺旋是本章的方法论核心。

## 为什么第6章的方法还会"卡顿"——一个现场痛点

想象你在给一杯墨水均匀加热。第5章的做法是：火开到固定档位，一直搅（这就是 Langevin SDE，单一噪声水平）。它能把分布搅匀，但只能在一个"尺度"上工作——对于多尺度结构（比如一张图既有大色块又有细纹理），一个尺度的去噪器往往顾此失彼。

第6章聪明地提升了火候：先用大火（大噪声）粗搅，再逐步调小（NCSN 的退火 Langevin）。这招确实有效——但有个别扭的地方：你是在有限的几个档位之间**手动跳档**的。从噪声 $\sigma_1$ 一步跳到 $\sigma_2$，再跳到 $\sigma_3$……这种"阶梯式降温"既不光滑，也缺乏统一的理论底座。

**一个反直觉的事实**：你以为 DDPM（从一个变分角度发明）和 NCSN（从得分匹配角度发明）是两种本质不同的方法吗？其实它们只是同一个连续过程在离散世界里的两个"方言"。本节的任务，就是把这个连续过程找出来，把两种方言统一成一门"普通话"——SDE（随机微分方程，stochastic differential equation，就是带随机项的微积分方程）。

读完本节你会得到：
1. 看清 Langevin SDE 为什么只是"单尺度"采样器；
2. 说清 NCSN 退火 Langevin 的三个根本局限；
3. 理解"把离散噪声调度推成连续时间函数"是怎么一回事；
4. 记住本章的方法论核心——"离散→连续→重离散化"的认知螺旋。

## 回顾：Langevin SDE 与 ULA（为什么只有一个尺度）

第4章建立了 ULA 算法（一种用梯度做采样的迭代），第5章揭示了它的连续时间本质——Langevin SDE（朗之万随机微分方程，描述一个粒子在"概率地形"上被确定性推力 + 随机抖动共同推动的运动）：

$$dX_t = \nabla\log p(X_t)\,dt + \sqrt{2}\,dW_t$$

在动手改写这个方程之前，先想清楚它想说什么：采样就是从"概率地形"上扔下一个粒子，让它顺着山坡往上滚（朝高概率区走），同时又被随机抖动推开。式子右边第一项 $\nabla\log p(X_t)\,dt$ 是**确定性漂移**——$\nabla\log p(x)$ 是目标分布 $p(x)$ 的**得分函数**（score function，对数概率的梯度，它指向概率密度增长最快的方向，相当于"uphill"的指南针），它把粒子往上坡推；第二项 $\sqrt{2}\,dW_t$ 是**随机扩散**——布朗运动 $dW_t$ 让粒子不安分地抖动，防止它贪心地停在坡顶。

Langevin SDE 有两个关键特征，决定了它的天花板：

1. **固定得分函数**：整个采样过程中，$\nabla\log p(x)$ 不随时间变——没有时间参数。它像一把固定口径的筛子，只过滤一个尺度的信息。
2. **固定噪声系数**：扩散系数（diffusion coefficient，控制每步加多少随机抖动的量）$\sqrt{2}$ 是常数——每一步加入的噪声量相同。

在逆问题场景里，PnP-ULA 用去噪器通过 Tweedie 等式替换先验梯度（第5章5.5节），成功做了后验采样。但它受限于**单一噪声水平** $\varepsilon$——只能在一个尺度上估得分。对复杂多尺度分布，一个尺度的得分往往"把细节和全局一起抹平"。

## NCSN 退火 Langevin：多尺度的第一次尝试（也是第一次别扭）

第6章6.5节用 NCSN 突破了单一噪声水平的限制。NCSN 的核心想法很朴素：

- 训练一个**条件得分网络** $s_\theta(x, \sigma_i)$，同时学 $L$ 个噪声水平的得分函数；
- 用**退火 Langevin 动力学**（annealed Langevin dynamics，退火=逐步降低温度/噪声，让系统从高温混乱慢慢冷却到低温有序）从大噪声到小噪声逐步采样。

退火 Langevin 的算法流程：

1. 初始化 $x_0$（随机噪声）；
2. 对每个噪声水平 $i = 1, 2, \ldots, L$：
   - 跑 $T_i$ 步 Langevin 采样：$x_{t+1} = x_t + \frac{\alpha_i}{2}s_\theta(x_t, \sigma_i) + \sqrt{\alpha_i}\,z_t$；
3. 输出最终样本。

这里每个噪声水平 $\sigma_i$ 都配一个得分网络 $s_\theta(x,\sigma_i)$——**说穿了，就是在不同的"颗粒度"上各准备一把筛子**。$\alpha_i$ 是该水平下的步长，$z_t$ 是探索噪声。这个方案高明在"从粗到细"：先在大噪声下把握全局轮廓，再在小噪声下精修细节。

**成功之处**：多尺度得分覆盖了从"粗糙大结构"到"精细细节"的分布特征，让高质量图像生成成为可能。**但它有三个根本性的局限**，正是我们想甩掉的：

**局限1："跳跃式"切换**。噪声水平的切换是离散的——从 $\sigma_i$ 一步跳到 $\sigma_{i+1}$。这种"阶梯式"降温不是最优的：在切换点得分函数突变，采样轨迹可能不连续。

**局限2：步数分配不均**。每个噪声水平的步数 $T_i$ 要手动设定。太多浪费算力，太少采样不充分。目前没有系统化原则决定最优步数。

**局限3：框架不统一**。NCSN（SMLD）和 DDPM 看起来是两种不同方法——一个从得分匹配出发，一个从变分推断出发，加噪-去噪迭代长得不一样，缺一个统一数学框架。

## 连续时间推广：把"阶梯"变成"斜坡"

解决上述三局限的关键洞见只有一句话：**把离散噪声调度，推成连续时间函数。**

从更深层次看，这三个局限其实是同一个毛病的三种表现：**我们用了"离散"这个粗糙的工具，去刻画一个本质上是"连续"的过程**。加噪的颗粒度天然是连续的——从完全干净一路平滑地走到纯噪声，中间历经无穷多个噪声水平，而离散只刻出了其中的一小撮。既然底层的物理是连续的，数学工具也应该连续。于是：

- 把离散噪声水平 $\{\sigma_i\}_{i=1}^L$ 推广为连续时间函数 $\sigma(t)$，$t \in [0, 1]$
  - $t = 0$：干净数据（$\sigma(0) = 0$）
  - $t = 1$：纯噪声（$\sigma(1) = \sigma_{\max}$）
- 把条件得分 $s_\theta(x, \sigma_i)$ 推广为时间条件得分 $s_\theta(x, t)$
- 把退火 Langevin 的多步迭代，推广为连续时间的随机微分方程（SDE）

物理类比（来自 Ref C 的"降温"直觉）：从"阶梯式降温"变成"斜坡式降温"——连续的温度变化更光滑、更高效，也更容易用数学工具分析。

## "离散→连续→重离散化"的认知螺旋

这一推广遵循一条**认知螺旋**——先从离散走向连续，再从连续回到离散，但每转一圈理解都更深一层：

**第一步（离散→连续）**：把 NCSN/DDPM 的离散迭代推向连续极限，得到 SDE 框架。在这里，$L$ 个离散噪声水平变成连续时间参数 $t$，离散采样步骤变成连续随机过程。

**第二步（连续框架）**：在 SDE 框架里，逆向 SDE 和概率流 ODE 的推导是"免费"的——Anderson (1982) 的逆向时间 SDE 定理自动给出从噪声生成数据的方程，不用对每个方法单独推导。**这正是连续框架的威力：一旦有了正向 SDE，逆向方程自动获得。**

**第三步（连续→重离散化）**：从 SDE 出发，选最优离散化方案。我们不再被原始的 Euler-Maruyama 离散化绑死——可以用高阶数值求解器（RK4、DPM-Solver），也可以选确定性（ODE）而非随机性（SDE）的离散化。

```
离散迭代(NCSN/DDPM) ──极限──→ 连续SDE框架 ──离散化──→ 最优离散算法
     ↑                                                    │
     │                  "认知螺旋"                         │
     └──────────── 理解更深、选择更优 ◄──────────────────────┘
```

为什么这个螺旋值钱？

1. **统一**：SDE 框架统一了 NCSN 和 DDPM——它们是同一 SDE 的不同离散化（7.5节细看）；
2. **免费推导**：逆向 SDE 的数学结构由 Anderson 定理自动给出，不用单独推导；
3. **灵活选择**：从 SDE 出发可换不同数值求解器，不一定用 Euler-Maruyama；
4. **理论洞察**：连续框架揭示了概率流 ODE——这是离散框架里很难发现的"确定性等价"。

这条认知螺旋不仅是本章方法论核心，也是整条采样路径的认识论模式：第5章从 ULA 走向 Langevin SDE 是第一次"离散→连续"，本章从 NCSN/DDPM 走向扩散 SDE 是第二次，且更深刻。

## 实验 7.1-1：从Langevin到扩散——连续时间推广

实验 `7.1-1.py` 演示**单步Langevin与退火Langevin的采样对比**，直观揭示NCSN的三个根本局限，并验证"离散→连续→再离散"认知螺旋的数值正确性。

### 实验场景

实验在1D高斯混合分布 $p(x) = 0.3\,\mathcal{N}(-2,1) + 0.7\,\mathcal{N}(1,1)$ 上进行，对比两种采样方法：

**单步Langevin**：使用固定的噪声水平 $\sigma=1.0$ 的得分函数 $s_\theta(x,\sigma)$ 驱动整个采样过程。这模拟了第5章Langevin SDE的"单一噪声水平"局限——用一个粗粒度的得分函数做所有步骤。

**退火Langevin（NCSN）**：使用10个噪声水平 $\sigma_1=5.0 > \sigma_2 > \cdots > \sigma_{10}=0.05$（几何递减），每个水平运行200步Langevin采样。这代表了第6章NCSN的"多尺度退火"策略。

### 实验目的

1. **验证单步Langevin的多模态采样失败**：固定 $\sigma=1.0$ 的得分函数过度平滑，模态间信号消失，采样比例偏离真实分布
2. **验证退火Langevin的成功**：从粗到细的多尺度策略能正确恢复双模态比例
3. **可视化连续噪声调度**：展示VP-SDE的 $\beta(t)$ 调度和SNR曲线，验证离散DDPM与连续VP-SDE的一致性
4. **数值验证认知螺旋**：验证VP-SDE连续解 $\bar\alpha(t)$ 与DDPM离散 $\bar\alpha_i$ 高度一致

### 实验输入

| 参数 | 设置 |
|------|------|
| 目标分布 | $p(x) = 0.3\,\mathcal{N}(-2,1) + 0.7\,\mathcal{N}(1,1)$ |
| 样本数 | $N = 20000$ |
| 单步Langevin | $\sigma_{\text{score}}=1.0$，步长 $\delta=0.05$，迭代2000步 |
| 退火Langevin | 10个噪声水平 $\sigma \in [0.05, 5.0]$（几何递减），每水平200步，$\varepsilon=2\times10^{-3}$ |
| VP-SDE参数 | $T=1000$，$\beta_{\min}=0.0001$，$\beta_{\max}=0.02$ |

### 预期结果

- 单步Langevin的模态比例偏离真实分布（左模态比例显著偏差），因为 $\sigma=1.0$ 的平滑得分函数无法区分两个模态
- 退火Langevin的模态比例接近真实分布（$0.3:0.7$），多尺度策略成功
- VP-SDE连续SNR曲线与DDPM离散SNR曲线高度重合
- VP-SDE连续 $\bar\alpha(t)$ 与DDPM离散 $\bar\alpha_i$ 在各时间点上数值一致

#### 步骤2-3：连续噪声调度与认知螺旋验证

代码同时输出了VP-SDE连续解与DDPM离散 $\bar\alpha$ 的对比：

| 时间 $t$ | 连续 $\bar\alpha(t)$ | 离散 $\bar\alpha_i$ |
|----------|----------|----------|
| 0.1 | 高度一致 | 高度一致 |
| 0.5 | 高度一致 | 高度一致 |
| 0.9 | 高度一致 | 高度一致 |

两者数量级一致——离散的 $\bar\alpha_i$ 是连续 $\bar\alpha(t)$ 的Euler-Maruyama近似，$O(\Delta t)$ 误差来自累乘到积分的近似。

#### 核心知识点：NCSN的三个根本局限与连续化的收益

| 局限 | 表现 | 连续化的解决方式 |
|------|------|------------------|
| 跳跃式切换 | 离散 $\sigma_i$ 不连续 | 连续 $\sigma(t)$ 平滑过渡 |
| 步数无原则 | 每水平步数 $T_i$ 手动设定 | SDE求解器自适应步长 |
| 框架不统一 | NCSN和DDPM看起来不同 | 同一SDE的不同参数化 |

连续SDE框架的核心收益：统一NCSN/DDPM为同一框架，Anderson定理"免费"给出逆向方程，"离散→连续→再离散"的认知螺旋让我们在高一层理解离散算法。
