# 7.1 从Langevin到扩散：连续时间推广

> **核心观点**：第5章的Langevin SDE以单一固定得分函数为驱动力，第6章的NCSN通过多噪声水平的退火Langevin实现了初步的图像生成，但本质上是"跳跃式"离散框架。本节回顾Langevin SDE的结构，分析其作为生成模型的局限（固定噪声水平、单尺度得分），展示NCSN/退火Langevin向连续时间推广的路径——将离散噪声调度参数化为连续时间函数，将条件得分网络推广为时间条件得分网络。"离散→连续→重离散化"的认知螺旋是本章的方法论核心。

## 回顾：Langevin SDE与ULA

第4章建立了ULA算法，第5章揭示了其连续时间本质——Langevin SDE：

$$dX_t = \nabla\log p(X_t)\,dt + \sqrt{2}\,dW_t$$

其中 $\nabla\log p(x)$ 是目标分布的得分函数。Langevin SDE有两个关键特征：

1. **固定得分函数**：整个采样过程中，得分函数 $\nabla\log p(x)$ 不变——没有时间参数
2. **固定噪声系数**：扩散系数 $\sqrt{2}$ 是常数——每一步加入的噪声量相同

在逆问题场景中，PnP-ULA用去噪器通过Tweedie等式替换先验梯度（第5章5.5节），成功实现了后验采样。但PnP-ULA受限于**单一噪声水平** $\varepsilon$——它只能在一个尺度上估计得分函数。

## NCSN退火Langevin：离散多尺度尝试

第6章6.5节通过NCSN突破了单一噪声水平的限制。NCSN的核心思想是：

- 训练一个**条件得分网络** $s_\theta(x, \sigma_i)$，同时学习 $L$ 个噪声水平的得分函数
- 用**退火Langevin动力学**从大噪声到小噪声逐步采样

退火Langevin的算法流程是：

1. 初始化 $x_0$（随机噪声）
2. 对每个噪声水平 $i = 1, 2, \ldots, L$：
   - 运行 $T_i$ 步Langevin采样：$x_{t+1} = x_t + \frac{\alpha_i}{2}s_\theta(x_t, \sigma_i) + \sqrt{\alpha_i}\,z_t$
3. 输出最终样本

NCSN的成功之处在于：多尺度得分覆盖了从粗糙到精细的分布特征，使得高质量图像生成成为可能。但退火Langevin有三个根本性的局限：

**局限1："跳跃式"切换**。噪声水平的切换是离散的——从 $\sigma_i$ 一步跳到 $\sigma_{i+1}$。这种"阶梯式"降温不是最优的：在切换点，得分函数发生突变，采样轨迹可能出现不连续。

**局限2：步数分配不均**。每个噪声水平的步数 $T_i$ 需要手动设定。太多步浪费计算，太少步采样不充分。目前没有系统化的原则来决定最优步数分配。

**局限3：框架不统一**。NCSN（SMLD）和DDPM看起来是两种不同的方法——NCSN从得分匹配出发，DDPM从变分推断出发。它们的加噪-去噪迭代看起来不同，缺乏统一的数学框架。

## 连续时间推广的核心思想

解决上述三个局限的关键洞见是：**将离散噪声调度推广为连续时间函数**。

具体来说：

- 将离散噪声水平 $\{\sigma_i\}_{i=1}^L$ 推广为连续时间函数 $\sigma(t)$，$t \in [0, 1]$
  - $t = 0$：干净数据（$\sigma(0) = 0$）
  - $t = 1$：纯噪声（$\sigma(1) = \sigma_{\max}$）
- 将条件得分 $s_\theta(x, \sigma_i)$ 推广为时间条件得分 $s_\theta(x, t)$
- 将退火Langevin的多步迭代推广为连续时间的随机微分方程（SDE）

物理类比：从"阶梯式降温"到"斜坡式降温"——连续的温度变化更光滑、更高效，也更容易用数学工具分析。

## "离散→连续→重离散化"的认知螺旋

这一推广遵循一条"认知螺旋"——先从离散走向连续，再从连续回到离散，但每次循环都达到更高的理解层次：

**第一步（离散→连续）**：将NCSN/DDPM的离散迭代推向连续极限，获得SDE框架。在这个框架中，$L$ 个离散噪声水平变为连续的时间参数 $t$，离散的采样步骤变为连续的随机过程。

**第二步（连续框架）**：在SDE框架中，逆向SDE和概率流ODE的推导是"免费"的——Anderson (1982) 的逆向时间SDE定理自动给出了从噪声生成数据的方程，不需要对每个方法单独推导。这正是连续框架的威力：**一旦有了正向SDE，逆向方程自动获得**。

**第三步（连续→重离散化）**：从SDE出发，选择最优的离散化方案。我们不再受限于原始的Euler-Maruyama离散化——可以使用更高阶的数值求解器（RK4、DPM-Solver），也可以选择确定性（ODE）而非随机性（SDE）的离散化。

```
离散迭代(NCSN/DDPM) ──极限──→ 连续SDE框架 ──离散化──→ 最优离散算法
     ↑                                                    │
     │                  "认知螺旋"                         │
     └──────────── 理解更深、选择更优 ◄──────────────────────┘
```

为什么这个螺旋有价值？

1. **统一**：SDE框架统一了NCSN和DDPM——它们是同一SDE的不同离散化方案（7.5节将详细展示）
2. **免费推导**：逆向SDE的数学结构由Anderson定理自动给出，不需要对每个方法单独推导逆向过程
3. **灵活选择**：从SDE出发可以选择不同的数值求解器，不一定用Euler-Maruyama——高阶求解器可能用更少步数达到更好的质量
4. **理论洞察**：连续框架揭示了概率流ODE——随机采样的确定性等价，这是离散框架中难以发现的

这一"认知螺旋"不仅是本章的方法论核心，也是整条采样路径的认识论模式——第5章从ULA走向Langevin SDE是第一次"离散→连续"的跃迁，本章从NCSN/DDPM走向扩散SDE是第二次，且更为深刻。
