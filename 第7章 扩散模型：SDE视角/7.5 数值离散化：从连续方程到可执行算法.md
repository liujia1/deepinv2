# 7.5 数值离散化：从连续方程到可执行算法

> **核心观点**：连续时间的SDE和ODE需要数值离散化才能在计算机上执行。Euler-Maruyama方法是SDE的基本离散化方案，其在逆向VP-SDE上的应用恰好恢复DDPM迭代——这是Score-SDE框架的核心统一结论。类似地，逆向VE-SDE的离散化恢复SMLD采样，PF-ODE的离散化恢复DDIM。高阶数值求解器（RK4、DPM++）提供更少步数的加速采样。三种采样器（DDPM/DDIM/PF-ODE）的对比揭示了随机性与确定性的根本权衡。

## Euler-Maruyama方法：SDE的基本离散化

对一般SDE $dx = a(x,t)\,dt + b(x,t)\,dw$，Euler-Maruyama向前离散化：

$$x_{t+\Delta t} = x_t + a(x_t, t)\,\Delta t + b(x_t, t)\,\sqrt{\Delta t}\,z, \quad z \sim \mathcal{N}(0, I)$$

对逆向SDE $dx = a_{\text{rev}}(x,t)\,d\bar{t} + b(x,t)\,d\bar{w}$，逆向时间中的"向前"就是物理时间的"向后"。因此从 $t$ 到 $t-\Delta t$ 的离散化：

$$x_{t-\Delta t} = x_t + a_{\text{rev}}(x_t, t)\,\Delta t + b(x_t, t)\,\sqrt{\Delta t}\,z$$

注意这里 $d\bar{t}$ 是逆向时间增量（物理时间向后），$\Delta t > 0$ 表示逆向时间向前一步。这与第4章4.3节中ULA = Langevin SDE的Euler-Maruyama离散化一致。

Euler-Maruyama的收敛阶为 $O(\sqrt{\Delta t})$（强收敛）或 $O(\Delta t)$（弱收敛）——精度有限，但实现简单。更高阶方法（如Milstein方法）可以改善精度，但实现更复杂，且扩散模型中得分估计误差通常是主要瓶颈，高阶离散化的边际收益有限。

## DDPM = 逆向VP-SDE的Euler-Maruyama离散化

这是Score-SDE框架最核心的统一结论：**DDPM采样迭代是逆向VP-SDE的Euler-Maruyama离散化**。

### 推导

逆向VP-SDE：

$$dx = -\beta(t)\left[\frac{x}{2} + \nabla_x\log p_t(x)\right]\,d\bar{t} + \sqrt{\beta(t)}\,d\bar{w}$$

其中 $d\bar{t}$ 是逆向时间增量（物理时间向后），$d\bar{w}$ 是逆向布朗运动。对逆向SDE，从 $t$ 到 $t-\Delta t$ 的Euler-Maruyama离散化：

$$x_{t-\Delta t} = x_t + \beta(t)\Delta t\left[\frac{x_t}{2} + \nabla\log p_t(x_t)\right] + \sqrt{\beta(t)\Delta t}\,z$$

注意漂移项的符号：逆向SDE中的负号 $-\beta[\cdots]$ 乘以逆向时间增量 $d\bar{t} = -dt$（物理时间向后），得正号 $\beta\Delta t[\cdots]$。

令 $\beta_i = \beta(t)\Delta t$（即 $\Delta t = 1/N$ 时的离散方差增量），利用 $\sqrt{1-\beta_i} \approx 1 - \beta_i/2$（$\beta_i$ 小时），展开整理可得：

$$x_{i-1} \approx \frac{1}{\sqrt{1-\beta_i}}\left[x_i + \frac{\beta_i}{2}\nabla\log p_i(x_i)\right] + \sqrt{\beta_i}\,z_i$$

用得分网络替换 $\nabla\log p_i(x_i) = s_\theta(x_i, i)$，即得DDPM迭代式。

进一步，利用得分函数与噪声预测的关系 $s_\theta = -\epsilon_\theta/\sqrt{1-\bar\alpha_i}$（第6章6.6节），上述迭代等价于DDPM的标准形式：

$$x_{i-1} = \frac{1}{\sqrt{1-\beta_i}}\left[x_i - \frac{\beta_i}{2\sqrt{1-\bar\alpha_i}}\epsilon_\theta(x_i, i)\right] + \sqrt{\beta_i}\,z_i$$

**结论**：DDPM不是从零发明的孤立算法，而是逆向VP-SDE的Euler-Maruyama离散化——它只是SDE求解器的一个特例。这个认识意味着我们可以用更好的SDE求解器来替换DDPM迭代，而不需要重新推导逆向过程。

## SMLD采样 = 逆向VE-SDE的Euler-Maruyama离散化

类似地，SMLD/退火Langevin采样是逆向VE-SDE的Euler-Maruyama离散化。

### 推导

逆向VE-SDE：

$$dx = -\frac{d[\sigma(t)^2]}{dt}\nabla_x\log p_t(x)\,dt + \sqrt{\frac{d[\sigma(t)^2]}{dt}}\,d\bar{w}$$

令 $\alpha_i = \sigma_i^2 - \sigma_{i-1}^2$（对应 $\frac{d[\sigma(t)^2]}{dt}\Delta t$），Euler-Maruyama离散化：

$$x_{i-1} = x_i + \alpha_i\nabla\log p_i(x_i) + \sqrt{\alpha_i}\,z_i$$

$$= x_i + (\sigma_i^2 - \sigma_{i-1}^2)\nabla\log p_i(x_i) + \sqrt{\sigma_i^2 - \sigma_{i-1}^2}\,z_i$$

这恰好是SMLD/退火Langevin的采样迭代——**SMLD是逆向VE-SDE的Euler-Maruyama离散化**。

## DDIM = PF-ODE的Euler离散化

7.4节已推导：PF-ODE的Euler离散化恢复DDIM更新。这里给出更完整的推导。

VP-SDE的PF-ODE：

$$\frac{dx}{dt} = -\frac{\beta(t)}{2}\left[x + \nabla\log p_t(x)\right]$$

Euler离散化（从 $t$ 到 $t-\Delta t$）：

$$x_{t-\Delta t} = x_t + \frac{\beta(t)\Delta t}{2}\left[x_t + \nabla\log p_t(x_t)\right]$$

代入Tweedie等式 $\nabla\log p_t(x) = \frac{\mathbb{E}[\sqrt{\bar\alpha_t}x_0|x_t] - x_t}{1-\bar\alpha_t}$，整理后得到DDIM更新。

**三种采样的统一关系**：

| 采样器 | 连续方程 | 离散化方法 | 特性 |
|---|---|---|---|
| DDPM | 逆向VP-SDE | Euler-Maruyama | 随机 |
| SMLD | 逆向VE-SDE | Euler-Maruyama | 随机 |
| DDIM | PF-ODE | Euler | 确定性 |

这个表格是Score-SDE框架的核心总结：**NCSN（SMLD）和DDPM不再是两种不同的方法，而是同一连续框架的两种离散化方案**——一个离散化VE-SDE，一个离散化VP-SDE。DDIM则是第三种选择——离散化PF-ODE。

## 高阶求解器与加速采样

Euler-Maruyama和Euler方法仅有一阶精度——步数多、速度慢。实践中，扩散模型通常需要数百到上千步才能生成高质量图像。高阶求解器可以用更少步数达到相当甚至更好的质量。

### ODE求解器（用于PF-ODE）

**Runge-Kutta方法（RK4）**：

4阶精度，每步需要4次网络评估。迭代公式：

$$k_1 = \tilde{f}(x_t, t), \quad k_2 = \tilde{f}(x_t + \frac{\Delta t}{2}k_1, t + \frac{\Delta t}{2})$$
$$k_3 = \tilde{f}(x_t + \frac{\Delta t}{2}k_2, t + \frac{\Delta t}{2}), \quad k_4 = \tilde{f}(x_t + \Delta t\,k_3, t + \Delta t)$$
$$x_{t+\Delta t} = x_t + \frac{\Delta t}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$

每步4次网络前向传播的计算量限制了实际使用——但对于高精度场景（如似然计算），RK4仍然有价值。

**DPM-Solver / DPM++（Lu et al. 2022）**：

专为扩散模型ODE设计的高阶求解器，利用扩散ODE的特殊结构：

- 扩散ODE的漂移项可分解为数据相关项和数据无关项
- 数据无关项有闭式解，只需对数据相关项做数值积分
- 2阶DPM-Solver每步仅1次网络评估，精度相当于RK4
- DPM++进一步引入多步策略，20步即可达到DDPM 1000步的生成质量

DPM-Solver是当前实践中最常用的加速采样方法。

### SDE求解器

将Euler-Maruyama替换为高阶SDE求解器理论上可以改善精度，但实践中提升有限。原因在于：

- SDE求解的高阶方法（如Milstein方法）需要得分函数的Jacobian——计算代价高
- 扩散模型的主要误差来源是得分估计误差，而非离散化误差
- 因此，高阶SDE求解器的精度优势被得分估计误差"淹没"

## 采样器选择：DDPM vs DDIM vs PF-ODE

三种采样器各有优劣，选择取决于任务需求：

### DDPM（随机采样）

- **优势**：多样性好（随机性保证不同轨迹产生不同样本）、对得分估计误差鲁棒（随机性"平均掉"了估计偏差）
- **劣势**：步数多（通常1000步）、不可复现（同一噪声起点可能产生不同输出）
- **适用场景**：无条件生成、需要多样性的创意生成任务

### DDIM（确定性采样）

- **优势**：步数少（20-50步即可）、可复现（确定性映射）、支持潜在空间插值和编辑
- **劣势**：多样性受限（确定性限制了输出多样性）、对得分估计误差敏感
- **适用场景**：图像编辑、逆问题求解、需要可控性和可复现性的任务

### PF-ODE + 高阶求解器

- **优势**：步数最少（10-20步）、支持精确似然计算、可以用任意ODE求解器
- **劣势**：实现更复杂、需要适配求解器接口
- **适用场景**：需要精确似然、极少步数、或与正规化流集成的场景

### 温度参数与采样控制

回顾第5章5.4节的温度视角，我们可以引入温度参数 $\eta \in [0, 1]$ 来控制采样的随机性：

$$dx = \left[f(x,t) - \eta\,g(t)^2\nabla\log p_t(x)\right]\,dt + \sqrt{\eta}\,g(t)\,d\bar{w}$$

- $\eta = 1$：完整逆向SDE → DDPM采样
- $\eta = 0$：PF-ODE → DDIM采样
- $0 < \eta < 1$：部分随机——在多样性和确定性之间插值

这一温度视角统一了DDPM和DDIM——**它们不是两种不同的方法，而是同一连续框架的两种极端**。实践中，$\eta \approx 0.5$ 有时能给出最好的结果——既保留足够的随机性保证多样性，又足够确定性减少步数。

**来源**：Song et al. (2021); Tutorial_Diffusion_Imaging_Vision Sec 4.3-4.4; 2406.08929v2 Sec 2.4, 3.5; Kloeden & Platen (2011); Lu et al. (2022) DPM-Solver; Pock L2 P14; Habring et al. (2025)

## 实验 7.5：数值离散化采样方法对比——从DDPM到DDIM

实验 `7.5-1.py` 和 `7.5-2.py` 共同构成一组完整的数值离散化对比实验，覆盖**随机采样（DDPM/SMLD）**与**确定性采样（PF-ODE/DDIM）**两条路线，系统验证7.5节的核心理论结论。

### 实验场景

两个实验均在1D高斯混合分布 $p_0(x) = 0.3\,\mathcal{N}(-2,1) + 0.7\,\mathcal{N}(1,1)$ 上进行，使用VP-SDE（$\beta_{\min}=0.1$，$\beta_{\max}=20.0$）。`7.5-1.py` 额外使用VE-SDE（$\sigma_{\min}=0.01$，$\sigma_{\max}=10.0$）演示SMLD采样。

**`7.5-1.py` 的步骤**：

1. **Anderson定理验证**：从 $p_0$ 出发用正向VP-SDE（解析边际）走到 $t \in \{0.2, 0.5, 0.8, 1.0\}$，同时从 $\mathcal{N}(0,I)$ 出发用逆向VP-SDE（DDPM，500步）走回各时间步，对比正向与逆向的边际分布
2. **DDPM采样**：不同步数（50、200、500、1000）的逆向VP-SDE Euler-Maruyama离散化
3. **SMLD采样**：逆向VE-SDE的退火Langevin离散化，不同步数（50、200、500）
4. **步数-质量曲线**：多种子平均计算DDPM在10-1000步下的KS统计量

**`7.5-2.py` 的步骤**：

1. **PF-ODE采样**：确定性采样（无随机项，score系数为1/2），展示采样过程
2. **DDIM = Euler离散化PF-ODE**：验证DDIM($\eta=0$)与PF-ODE的等价性（相同初始噪声、500步，KS距离接近0）
3. **温度参数 $\eta$ 连续插值**：$\eta \in \{0.0, 0.25, 0.5, 0.75, 1.0\}$，从DDIM到DDPM的平滑过渡
4. **DDPM vs DDIM对比**：不同步数（10-500）下的KS统计量和运行时间

### 实验目的

1. **验证Anderson逆时SDE定理**：正向SDE与逆向SDE在各时间步的边际分布近似一致
2. **验证三种离散化对应关系**：DDPM = EM逆向VP-SDE，SMLD = EM逆向VE-SDE，DDIM = Euler PF-ODE
3. **展示PF-ODE的确定性采样**：与逆向SDE边际分布相同，但轨迹确定、可复现
4. **量化随机 vs 确定性的权衡**：DDIM在少步数时质量优于DDPM；温度参数 $\eta$ 控制随机性-确定性连续过渡

### 实验输入

| 参数 | 设置 |
|------|------|
| 目标分布 | $p_0(x) = 0.3\,\mathcal{N}(-2,1) + 0.7\,\mathcal{N}(1,1)$ |
| VP-SDE参数 | $\beta_{\min}=0.1$，$\beta_{\max}=20.0$ |
| VE-SDE参数（7.5-1） | $\sigma_{\min}=0.01$，$\sigma_{\max}=10.0$ |
| 粒子数 | 5000-20000（各步骤不同） |
| 温度参数 $\eta$（7.5-2） | $\{0.0, 0.25, 0.5, 0.75, 1.0\}$ |

### 预期结果

- Anderson定理验证：正向与逆向边际分布近似一致
- DDPM/SMLD步数越多，采样质量越高（KS统计量单调递减）
- DDIM($\eta=0$)与PF-ODE在相同初始噪声下走出几乎相同的轨迹
- DDIM在少步数（10-50步）时KS统计量显著低于DDPM
- $\eta$ 从0到1，采样从确定性逐渐过渡到完全随机

#### 统一框架总结

| 方法 | 连续方程 | 离散化 | 随机性 | 温度 $\eta$ | 步数需求 | 可控性 |
|------|---------|--------|--------|--------|---------|--------|
| 逆向SDE | $dx=[f-g^2\nabla\log p]dt+g\,d\bar{w}$ | Euler-Maruyama | 有 | — | 多(~1000) | 低 |
| PF-ODE | $dx=[f-\frac{1}{2}g^2\nabla\log p]dt$ | Euler | 无 | — | 少(~20-50) | 高 |
| DDPM | — | EM on rev VP | 有 | $\eta=1$ | 多(~1000) | 低 |
| DDIM | — | Euler on PF | 无 | $\eta=0$ | 少(~50) | 高 |
