# 7.5 数值离散化：从连续方程到可执行算法

> **核心观点**：连续时间的SDE和ODE需要数值离散化才能在计算机上执行。Euler-Maruyama方法是SDE的基本离散化方案，其在逆向VP-SDE上的应用恰好恢复DDPM迭代——这是Score-SDE框架的核心统一结论。类似地，逆向VE-SDE的离散化恢复SMLD采样，PF-ODE的离散化恢复DDIM。高阶数值求解器（RK4、DPM++）提供更少步数的加速采样。三种采样器（DDPM/DDIM/PF-ODE）的对比揭示了随机性与确定性的根本权衡。

## 一个让一切"落地"的问题：连续方程，电脑怎么跑？

前几节我们拿到了漂亮的连续方程——正向 SDE、逆向 SDE、概率流 ODE。但电脑不会解微分方程，它只会一步步迭代。**先猜后揭**：你可能以为 DDPM 是个从变分推断单独发明的、和第6章得分匹配毫无关系的黑科技。其实——**DDPM 就是逆向 VP-SDE 用最朴素的 Euler-Maruyama 方法离散化出来的**。这个"降维打击"式的统一结论，是 Song et al. (2021) Score-SDE 框架最爽的收获：你不必把 DDPM、SMLD、DDIM 当三个独立算法背，它们只是同一个连续 SDE "离散化"时的三种选择。

从更深的层面看，这一事实的意义在于：**离散算法不是数学的异乡，而是连续方程在精度预算下的必然投影**。一旦你认清了"离散化"这个统一视角，所有看似各立山头的采样器，都收敛为同一棵树上的不同枝条。

读完本节你会能：
1. 用 Euler-Maruyama 把逆向 VP-SDE 推回 DDPM 迭代；
2. 同理认出 SMLD = 逆向 VE-SDE 离散化、DDIM = PF-ODE 离散化；
3. 理解高阶求解器（RK4、DPM++）如何用更少步数加速；
4. 用温度参数 $\eta$ 把 DDPM 和 DDIM 统到一条连续谱上。

## Euler-Maruyama 方法：SDE 的"一阶近似"

对一般 SDE $dx = a(x,t)\,dt + b(x,t)\,dw$，Euler-Maruyama（欧拉-丸山，SDE 最基本的离散化，类似普通微分方程的欧拉法，但随机项要乘 $\sqrt{\Delta t}$）向前离散化：

$$x_{t+\Delta t} = x_t + a(x_t, t)\,\Delta t + b(x_t, t)\,\sqrt{\Delta t}\,z, \quad z\sim\mathcal{N}(0,I)$$

先看这个式子怎么读：左边 $x_{t+\Delta t}$ 是下一步的状态。右边第一项 $a(x_t,t)\Delta t$ 是确定性漂移部分——它把方程里的 $a\,dt$ 原样翻译成"乘个时间步长 $\Delta t$"；第二项 $b(x_t,t)\sqrt{\Delta t}\,z$ 是随机部分——注意它乘的是 $\sqrt{\Delta t}$ 而不是 $\Delta t$，这正是随机微积分和普通微积分最根本的分野：噪声项以"平方根的时间"累积，这是布朗运动方差与时间成正比的事实。

对逆向 SDE，逆向时间里的"向前"就是物理时间的"向后"。所以从 $t$ 到 $t-\Delta t$：

$$x_{t-\Delta t} = x_t + a_{\text{rev}}(x_t, t)\,\Delta t + b(x_t, t)\,\sqrt{\Delta t}\,z$$

这与第4章4.3节 ULA = Langevin SDE 的 Euler-Maruyama 离散化一致。

Euler-Maruyama 收敛阶有限（强收敛 $O(\sqrt{\Delta t})$），但实现简单。更高阶方法（如 Milstein）能改善精度却更复杂，且扩散模型里**得分估计误差**才是主要瓶颈，高阶离散化边际收益有限。

## DDPM = 逆向VP-SDE 的 Euler-Maruyama 离散化（核心统一结论）

> **与第11章的分工**：本节站在 **SDE 连续视角**，把 DDPM 采样迭代解释为逆向 VP-SDE 的离散化。DDPM 的**训练算法本身**（完整 VLB / 简化 $L_\text{simple}$ / 均值匹配）在第 11 章 11.4 系统推导——两条路在这里交汇，详见 12.4 的统一证明。

这是 Score-SDE 框架最核心的一句话：**DDPM 采样迭代 = 逆向 VP-SDE 的 Euler-Maruyama 离散化**。

在开始推导前，先明确"目标"：我们要把下面这个连续方程变成逐行可执行的小步骤。连续方程里一切都在一瞬间发生，离散化则把这一瞬间切成 $N$ 段，每段近似求解一次。

**推导**：逆向 VP-SDE

$$dx = -\beta(t)\left[\frac{x}{2} + \nabla_x\log p_t(x)\right]\,d\bar{t} + \sqrt{\beta(t)}\,d\bar{w}$$

对逆向 SDE，从 $t$ 到 $t-\Delta t$ 的 Euler-Maruyama 离散化（注意逆向时间增量 $d\bar{t}=-dt$，负号乘负号得正）：

$$x_{t-\Delta t} = x_t + \beta(t)\Delta t\left[\frac{x_t}{2} + \nabla\log p_t(x_t)\right] + \sqrt{\beta(t)\Delta t}\,z$$

令 $\beta_i=\beta(t)\Delta t$（即 $\Delta t=1/N$ 时的离散方差增量），用 $\sqrt{1-\beta_i}\approx 1-\beta_i/2$，展开整理：

$$x_{i-1} \approx \frac{1}{\sqrt{1-\beta_i}}\left[x_i + \frac{\beta_i}{2}\nabla\log p_i(x_i)\right] + \sqrt{\beta_i}\,z_i$$

把得分网络 $\nabla\log p_i(x_i)=s_\theta(x_i,i)$ 代进去，即得 DDPM 迭代。进一步用第6章6.6节得分与噪声预测关系 $s_\theta=-\epsilon_\theta/\sqrt{1-\bar\alpha_i}$，就等价于 DDPM 标准形式：

$$x_{i-1} = \frac{1}{\sqrt{1-\beta_i}}\left[x_i - \frac{\beta_i}{2\sqrt{1-\bar\alpha_i}}\epsilon_\theta(x_i, i)\right] + \sqrt{\beta_i}\,z_i$$

**结论**：DDPM 不是从零发明的孤立算法，而是逆向 VP-SDE 的 Euler-Maruyama 离散化——SDE 求解器的一个特例。这意味着我们可以用更好的求解器替换 DDPM 迭代，而不用重新推导逆向过程。

## SMLD = 逆向VE-SDE 的 Euler-Maruyama 离散化

类似地，SMLD/退火 Langevin 采样 = 逆向 VE-SDE 的离散化。

**推导**：逆向 VE-SDE

$$dx = -\frac{d[\sigma(t)^2]}{dt}\nabla_x\log p_t(x)\,dt + \sqrt{\frac{d[\sigma(t)^2]}{dt}}\,d\bar{w}$$

令 $\alpha_i=\sigma_i^2-\sigma_{i-1}^2$（对应 $\frac{d[\sigma(t)^2]}{dt}\Delta t$），Euler-Maruyama 离散化：

$$x_{i-1} = x_i + \alpha_i\nabla\log p_i(x_i) + \sqrt{\alpha_i}\,z_i = x_i + (\sigma_i^2-\sigma_{i-1}^2)\nabla\log p_i(x_i) + \sqrt{\sigma_i^2-\sigma_{i-1}^2}\,z_i$$

这恰好是 SMLD/退火 Langevin 的采样迭代——**SMLD = 逆向 VE-SDE 的 Euler-Maruyama 离散化**。

## DDIM = PF-ODE 的 Euler 离散化

7.4节已推导：PF-ODE 的 Euler 离散化恢复 DDIM。VP-SDE 的 PF-ODE：

$$\frac{dx}{dt} = -\frac{\beta(t)}{2}\left[x + \nabla\log p_t(x)\right]$$

Euler 离散化（从 $t$ 到 $t-\Delta t$）：

$$x_{t-\Delta t} = x_t + \frac{\beta(t)\Delta t}{2}\left[x_t + \nabla\log p_t(x_t)\right]$$

代入 Tweedie 等式 $\nabla\log p_t(x)=\frac{\mathbb{E}[\sqrt{\bar\alpha_t}x_0|x_t]-x_t}{1-\bar\alpha_t}$，整理后即得 DDIM 更新。

**三种采样的统一关系**（务必记牢这张表）：

| 采样器 | 连续方程 | 离散化方法 | 特性 |
|---|---|---|---|
| DDPM | 逆向VP-SDE | Euler-Maruyama | 随机 |
| SMLD | 逆向VE-SDE | Euler-Maruyama | 随机 |
| DDIM | PF-ODE | Euler | 确定性 |

**核心总结**：NCSN（SMLD）和 DDPM 不再是两种不同方法，而是同一连续框架的两种离散化——一个离散 VE-SDE，一个离散 VP-SDE；DDIM 是第三种选择——离散 PF-ODE。

## 高阶求解器与加速采样：用更少的步数

Euler-Maruyama 和 Euler 只有一阶精度——步数多、速度慢。扩散模型常需数百到上千步才能生成高质量图。高阶求解器能用更少步数达到相当甚至更好质量。

### ODE 求解器（用于 PF-ODE）

**Runge-Kutta（RK4）**：4阶精度，每步需4次网络评估。迭代：

$$k_1 = \tilde{f}(x_t, t), \quad k_2 = \tilde{f}(x_t + \frac{\Delta t}{2}k_1, t + \frac{\Delta t}{2})$$
$$k_3 = \tilde{f}(x_t + \frac{\Delta t}{2}k_2, t + \frac{\Delta t}{2}), \quad k_4 = \tilde{f}(x_t + \Delta t\,k_3, t + \Delta t)$$
$$x_{t+\Delta t} = x_t + \frac{\Delta t}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$

每步4次网络前向的计算量限制了实用——但高精度场景（如似然计算）仍有价值。

**DPM-Solver / DPM++（Lu et al. 2022）**：专为扩散 ODE 设计的高阶求解器，利用扩散 ODE 特殊结构（漂移项可拆成数据相关项 + 数据无关项，后者有闭式解）。2阶 DPM-Solver 每步仅1次网络评估，精度相当于 RK4；DPM++ 引入多步策略，**20步即可达 DDPM 1000步质量**。是当前实践最常用的加速方法。

### SDE 求解器

把 Euler-Maruyama 换成高阶 SDE 求解器理论上能改善精度，实践中提升有限。原因：SDE 高阶方法（如 Milstein）需得分函数的 Jacobian（雅可比矩阵，描述梯度如何随输入变化），计算代价高；且扩散模型主要误差来自**得分估计误差**而非离散化误差——高阶精度被估计误差"淹没"。

## 采样器选择：DDPM vs DDIM vs PF-ODE

三种采样器各有优劣，选哪个看任务：

### DDPM（随机采样）
- **优势**：多样性好（随机性保证不同轨迹出不同样本）、对得分估计误差鲁棒（随机性"平均掉"估计偏差）
- **劣势**：步数多（常1000步）、不可复现
- **适用**：无条件生成、创意生成

### DDIM（确定性采样）
- **优势**：步数少（20-50步）、可复现、支持潜在空间插值与编辑
- **劣势**：多样性受限、对得分估计误差敏感
- **适用**：图像编辑、逆问题求解、需可控可复现的任务

### PF-ODE + 高阶求解器
- **优势**：步数最少（10-20步）、支持精确似然计算、可用任意 ODE 求解器
- **劣势**：实现更复杂、需适配求解器接口
- **适用**：需精确似然、极少步数、或与正规化流集成

### 温度参数与采样控制：把 DDPM 和 DDIM 连成一条谱

回顾第5章5.4节的温度视角，引入温度参数 $\eta\in[0,1]$ 控制随机性：

$$dx = \left[f(x,t) - \eta\,g(t)^2\nabla\log p_t(x)\right]\,dt + \sqrt{\eta}\,g(t)\,d\bar{w}$$

- $\eta=1$：完整逆向 SDE → DDPM；
- $\eta=0$：PF-ODE → DDIM；
- $0<\eta<1$：部分随机——在多样性和确定性之间插值。

**这一温度视角统一了 DDPM 和 DDIM——它们不是两种方法，而是同一连续框架的两种极端**。实践里 $\eta\approx 0.5$ 有时最好：既保留足够随机性保证多样性，又足够确定减少步数。

**来源**：Song et al. (2021); Tutorial_Diffusion_Imaging_Vision Sec 4.3-4.4; 2406.08929v2 Sec 2.4, 3.5; Kloeden & Platen (2011); Lu et al. (2022) DPM-Solver; Pock L2 P14; Habring et al. (2025)

## 实验 7.5：数值离散化采样方法对比——从DDPM到DDIM

实验 `7.5-1.py` 和 `7.5-2.py` 共同构成一组完整的数值离散化对比实验，覆盖**随机采样（DDPM/SMLD）**与**确定性采样（PF-ODE/DDIM）**两条路线，系统验证7.5节的核心理论结论。

### 实验场景

两个实验均在1D高斯混合分布 $p_0(x) = 0.3\,\mathcal{N}(-2,1) + 0.7\,\mathcal{N}(1,1)$ 上进行，使用VP-SDE（$\beta_{\min}=0.1$，$\beta_{\max}=20.0$）。`7.5-1.py` 额外使用VE-SDE（$\sigma_{\min}=0.01$，$\sigma_{\max}=10.0$）演示SMLD采样。

**`7.5-1.py` 的步骤**：

1. **Anderson定理验证**：从 $p_0$ 出发用正向VP-SDE（解析边际）走到 $t \in \{0.2, 0.5, 0.8, 1.0\}$，同时从 $\mathcal{N}(0,I)$ 出发用逆向VP-SDE（DDPM，500步）走回各时间步，对比正向与逆向的边际分布
2. **DDPM采样**：不同步数（50、200、500、1000）的逆向VP-SDE Euler-Maruyama离散化
3. **SMLD采样**：逆向VE-SDE的退火Langevin离散化，不同步数（50、200、500）
4. **步数-质量曲线**：多种子平均计算DDPM在10-1000步下的KS统计量

**`7.5-2.py` 的步骤**：

1. **PF-ODE采样**：确定性采样（无随机项，score系数为1/2），展示采样过程
2. **DDIM = Euler离散化PF-ODE**：验证DDIM($\eta=0$)与PF-ODE的等价性（相同初始噪声、500步，KS距离接近0）
3. **温度参数 $\eta$ 连续插值**：$\eta \in \{0.0, 0.25, 0.5, 0.75, 1.0\}$，从DDIM到DDPM的平滑过渡
4. **DDPM vs DDIM对比**：不同步数（10-500）下的KS统计量和运行时间

### 实验目的

1. **验证Anderson逆时SDE定理**：正向SDE与逆向SDE在各时间步的边际分布近似一致
2. **验证三种离散化对应关系**：DDPM = EM逆向VP-SDE，SMLD = EM逆向VE-SDE，DDIM = Euler PF-ODE
3. **展示PF-ODE的确定性采样**：与逆向SDE边际分布相同，但轨迹确定、可复现
4. **量化随机 vs 确定性的权衡**：DDIM在少步数时质量优于DDPM；温度参数 $\eta$ 控制随机性-确定性连续过渡

### 实验输入

| 参数 | 设置 |
|------|------|
| 目标分布 | $p_0(x) = 0.3\,\mathcal{N}(-2,1) + 0.7\,\mathcal{N}(1,1)$ |
| VP-SDE参数 | $\beta_{\min}=0.1$，$\beta_{\max}=20.0$ |
| VE-SDE参数（7.5-1） | $\sigma_{\min}=0.01$，$\sigma_{\max}=10.0$ |
| 粒子数 | 5000-20000（各步骤不同） |
| 温度参数 $\eta$（7.5-2） | $\{0.0, 0.25, 0.5, 0.75, 1.0\}$ |

### 预期结果

- Anderson定理验证：正向与逆向边际分布近似一致
- DDPM/SMLD步数越多，采样质量越高（KS统计量单调递减）
- DDIM($\eta=0$)与PF-ODE在相同初始噪声下走出几乎相同的轨迹
- DDIM在少步数（10-50步）时KS统计量显著低于DDPM
- $\eta$ 从0到1，采样从确定性逐渐过渡到完全随机

| 方法 | 连续方程 | 离散化 | 随机性 | 温度 $\eta$ | 步数需求 | 可控性 |
|------|---------|--------|--------|--------|---------|--------|

| DDIM | — | Euler on PF | 无 | $\eta=0$ | 少(~50) | 高 |
