# 7.3 逆向SDE：从噪声到数据的采样过程

> **核心观点**：Anderson (1982) 的逆向时间SDE定理提供了从噪声生成数据的一般方程——$dx = [f(x,t) - g(t)^2\nabla_x\log p_t(x)]\,dt + g(t)\,d\bar{w}$，其中 $\bar{w}$ 是逆向时间的布朗运动。得分函数 $\nabla\log p_t(x)$ 在逆向SDE中扮演核心角色——它提供了"恢复"概率分布的驱动力。正向过程"抹平"概率分布（信息丢失），逆向过程用得分函数"重建"概率分布（信息恢复）。VE-SDE和VP-SDE的逆向方程分别恢复SMLD采样和DDPM采样。

## Anderson逆向时间SDE定理

正向SDE $dx = f(x,t)\,dt + g(t)\,dw$ 描述了从数据到噪声的演化。扩散模型的采样目标是**逆向**这个过程——从纯噪声 $x_1 \sim p_1(x)$ 出发，沿时间倒流回到数据分布 $p_0(x) = p_{\text{data}}(x)$。

Anderson (1982) 给出了一个深刻的结果：**正向SDE的逆向时间过程也是一个SDE**，且其形式由正向SDE的系数和得分函数完全确定。

**定理（Anderson 1982）**：对正向SDE $dx = f(x,t)\,dt + g(t)\,dw$，其逆向时间过程满足：

$$\boxed{dx = \left[f(x,t) - g(t)^2\,\nabla_x\log p_t(x)\right]\,dt + g(t)\,d\bar{w}}$$

其中 $\bar{w}$ 是逆向时间的布朗运动，$p_t(x)$ 是正向过程在时刻 $t$ 的边际分布。

这个定理的含义是深远的：

1. **逆向SDE自动获得**：一旦确定了正向SDE（选择 $f$ 和 $g$），逆向SDE的数学形式就自动确定了——不需要单独推导
2. **得分函数是唯一未知量**：逆向SDE中唯一需要学习的量是 $\nabla\log p_t(x)$——这正是第5-6章一直在讨论的得分函数
3. **逆向采样 = 求解逆向SDE**：从 $x_1 \sim p_1(x)$ 出发，求解逆向SDE到 $t=0$，即得数据分布的样本

与正向SDE的关键区别：
- **漂移项增加了得分修正** $-g(t)^2\nabla\log p_t(x)$——这是逆向SDE的"驱动力"
- **布朗运动方向反转**：$d\bar{w}$ 表示时间倒流的布朗运动

证明概要见附录7A。

## 逆向VE-SDE：SMLD采样的连续形式

将 $f(x,t) = 0$ 和 $g(t) = \sqrt{d[\sigma(t)^2]/dt}$ 代入Anderson定理：

$$dx = \left[0 - \frac{d[\sigma(t)^2]}{dt}\nabla_x\log p_t(x)\right]\,dt + \sqrt{\frac{d[\sigma(t)^2]}{dt}}\,d\bar{w}$$

即：

$$\boxed{dx = -\frac{d[\sigma(t)^2]}{dt}\,\nabla_x\log p_t(x)\,dt + \sqrt{\frac{d[\sigma(t)^2]}{dt}}\,d\bar{w}}$$

**直觉解读**：

- 漂移项 $-\frac{d[\sigma(t)^2]}{dt}\nabla\log p_t(x)\,dt$：得分函数指向概率增长的方向，乘以负号后指向概率减小的方向——但在逆向时间中，时间倒流使得粒子从低概率区域被"推"向高概率区域
- 扩散项 $\sqrt{d[\sigma(t)^2]/dt}\,d\bar{w}$：加入与正向过程相同强度的噪声——随机探索防止坍缩

由于VE-SDE没有漂移修正（$f=0$），逆向过程完全依赖得分函数来"引导"粒子回到数据分布。7.5节将展示，这个逆向VE-SDE的Euler-Maruyama离散化恰好恢复SMLD/退火Langevin的采样迭代。

## 逆向VP-SDE：DDPM采样的连续形式

将 $f(x,t) = -\frac{\beta(t)}{2}x$ 和 $g(t) = \sqrt{\beta(t)}$ 代入Anderson定理：

$$dx = \left[-\frac{\beta(t)}{2}x - \beta(t)\nabla_x\log p_t(x)\right]\,dt + \sqrt{\beta(t)}\,d\bar{w}$$

即：

$$\boxed{dx = -\beta(t)\left[\frac{x}{2} + \nabla_x\log p_t(x)\right]\,dt + \sqrt{\beta(t)}\,d\bar{w}}$$

**直觉解读**：

- 收缩力 $-\frac{\beta(t)}{2}x\,dt$：将信号拉向原点——这是正向收缩漂移的延续
- 得分力 $-\beta(t)\nabla\log p_t(x)\,dt$：将信号拉向数据分布的方向
- 两者组合：收缩力"收拢"信号幅度，得分力"指向"数据方向

与逆向VE-SDE的关键区别：逆向VP-SDE有额外的收缩力项 $-\beta x/2$，这使得逆向过程中的信号不会发散——即使在得分估计不准确时，收缩力也提供了一种"安全网"。

7.5节将展示，这个逆向VP-SDE的Euler-Maruyama离散化恰好恢复DDPM的采样迭代。

## 得分函数与条件期望的联系

逆向SDE中的得分函数 $\nabla\log p_t(x)$ 是"不可知的"——我们不知道真实数据分布的边际密度 $p_t(x)$。但第5章的Tweedie等式提供了一个关键的桥梁：得分函数可以从条件期望中提取。

**VE-SDE的Tweedie等式**：由于 $p_{0t}(x_t|x_0) = \mathcal{N}(x_t | x_0, \sigma(t)^2 I)$，由Tweedie等式（第5章5.3节）：

$$\nabla_{x_t}\log p_t(x_t) = \frac{\mathbb{E}[x_0|x_t] - x_t}{\sigma(t)^2}$$

将此代入逆向VE-SDE：

$$dx = -\frac{d[\sigma(t)^2]}{dt} \cdot \frac{\mathbb{E}[x_0|x_t] - x_t}{\sigma(t)^2}\,dt + \sqrt{\frac{d[\sigma(t)^2]}{dt}}\,d\bar{w}$$

漂移力指向 $\mathbb{E}[x_0|x_t]$（MMSE估计方向）——**逆向SDE的驱动力 = 指向最优估计的方向**。

**VP-SDE的Tweedie等式**：由于 $p_{0t}(x_t|x_0) = \mathcal{N}(x_t | \sqrt{\bar\alpha_t}x_0, (1-\bar\alpha_t)I)$，由Tweedie等式（将 $\sqrt{\bar\alpha_t}x_0$ 视为"干净信号"，$1-\bar\alpha_t$ 视为噪声方差）：

$$\nabla_{x_t}\log p_t(x_t) = \frac{\sqrt{\bar\alpha_t}\,\mathbb{E}[x_0|x_t] - x_t}{1-\bar\alpha_t}$$

代入逆向VP-SDE后同样可以表示为条件期望的形式。

这些联系揭示了一个深刻的统一性：**逆向SDE的漂移力 = 指向MMSE估计的方向 + 随机探索**。这与第5章PnP-ULA的洞见一脉相承——去噪器（MMSE估计器）提供了"方向"，噪声提供了"探索"。

## 逆向SDE的直觉理解

**物理类比**：想象墨水滴入清水的过程——

- **正向SDE** = "墨水滴入水中"：一滴墨水逐渐扩散，浓度分布越来越平坦——信息逐步丢失
- **逆向SDE** = "墨水从水中凝聚"：从均匀分散的墨水开始，逐步凝聚回一滴——信息逐步恢复

在这个类比中：

- 得分函数 $\nabla\log p_t(x)$ 是"指南针"——在每个含噪状态 $x_t$ 处，它指向"原始数据最可能在哪"
- 布朗运动 $d\bar{w}$ 是"随机搜索"——防止所有粒子坍缩到同一点（众数），保证收敛到分布而非众数
- 两者结合：得分力将粒子"聚集"到高概率区域，扩散力保证分布的"形状"——这与Langevin动力学的机制完全一致

**逆向SDE与Langevin动力学的对比**：

| 性质 | Langevin SDE | 逆向扩散SDE |
|---|---|---|
| 得分函数 | $\nabla\log p(x)$（固定） | $\nabla\log p_t(x)$（时间条件） |
| 噪声系数 | $\sqrt{2}$（固定） | $g(t)$（时间条件） |
| 漂移修正 | 无 | $f(x,t)\,dt$ |
| 平稳分布 | $p(x)$ | $p_0(x) = p_{\text{data}}(x)$ |

Langevin SDE是逆向扩散SDE的特例：当 $f = 0$, $g(t) = \sqrt{2}$, $p_t \equiv p$ 时，逆向扩散SDE退化为Langevin SDE。核心区别在于：扩散SDE的得分函数**随时间变化**——从"粗糙得分"（大噪声时，指向全局结构）到"精细得分"（小噪声时，指向局部细节），形成了自然的多尺度采样策略。

这正是扩散模型比单一Langevin采样更强大的根本原因：**扩散采样不是一个得分函数驱动的采样，而是无限个得分函数按时间调度驱动的采样**。

**来源**：Anderson (1982); Song et al. (2021) Score-SDE; Tutorial_Diffusion_Imaging_Vision Sec 4.3; 2406.08929v2 Sec 2.4

## 实验 7.3-1：Anderson定理解析验证与逆向Drift几何可视化

实验 `7.3-1.py` 通过**Fokker-Planck方程的数值验证**和**逆向Drift向量场的几何可视化**，直观展示Anderson逆时SDE定理的含义——正向SDE与逆向SDE产生相同的边际分布 $p_t(x)$。

### 实验场景

实验在1D和2D高斯混合分布上进行，使用VP-SDE（$\beta_{\min}=0.1$，$\beta_{\max}=20.0$）。实验分为三个步骤：

**步骤1（解析验证）**：对1D高斯混合 $p_0(x) = 0.4\,\mathcal{N}(-2,1) + 0.6\,\mathcal{N}(2,1)$，用解析解计算VP-SDE的边际分布 $p_t(x)$，然后用中心差分计算时间导数 $\partial p_t/\partial t$ 和空间导数，代入正向和逆向的Fokker-Planck方程，验证两边是否吻合。

**步骤2（向量场可视化）**：对2D三分量高斯混合，在不同时间点 $t \in \{0.1, 0.4, 0.7, 1.0\}$ 计算逆向VP-SDE的drift场 $\text{drift}_{\text{rev}} = \frac{\beta(t)}{2}x + \beta(t)\nabla\log p_t(x)$，用箭头图展示drift如何将粒子推向数据高密度区。

**步骤3（粒子演化轨迹）**：对1D高斯混合，从 $x_1 \sim \mathcal{N}(0,I)$ 出发，用Euler-Maruyama方法求解逆向VP-SDE，记录粒子在 $t \in \{1.0, 0.8, 0.6, 0.4, 0.2, 0.0\}$ 的分布快照，与理论边际分布对比。

### 实验目的

1. **验证Anderson定理的解析正确性**：通过Fokker-Planck方程验证 $p_t(x)$ 同时满足正向和逆向的密度演化方程，证明正向与逆向SDE产生相同的边际分布
2. **可视化逆向Drift的几何直觉**：展示得分函数 $\nabla\log p_t(x)$ 如何在每个含噪状态处"指向"数据高密度区，为逆向SDE提供"恢复"的驱动力
3. **展示逆向采样过程**：从纯噪声到数据分布的粒子演化轨迹，直观展示逆向SDE的工作方式

### 实验输入

| 参数 | 设置 |
|------|------|
| 1D目标分布（步骤1、3） | $p_0(x) = 0.4\,\mathcal{N}(-2,1) + 0.6\,\mathcal{N}(2,1)$ |
| 2D目标分布（步骤2） | 三分量高斯混合，权重 $[0.4, 0.3, 0.3]$ |
| VP-SDE参数 | $\beta_{\min}=0.1$，$\beta_{\max}=20.0$（线性插值） |
| 验证时间点（步骤1） | $t \in \{0.1, 0.3, 0.5, 0.7, 0.9\}$ |
| 粒子数（步骤3） | $N=500$，逆向采样500步 |

### 预期结果

- **步骤1**：在各时间点上，$p_t(x)$ 同时满足正向和逆向Fokker-Planck方程，最大绝对误差 $< 10^{-3}$，相对均方根误差 $< 0.01$
- **步骤2**：逆向drift箭头指向边际分布 $p_t(x)$ 的高密度区域；$t$ 接近1时drift方向混乱（接近纯噪声），$t$ 接近0时drift清晰指向各模态中心
- **步骤3**：粒子从 $t=1.0$ 的 $\mathcal{N}(0,I)$ 逐步演化到 $t=0.0$ 的目标高斯混合分布，中间快照与理论边际分布吻合

#### 步骤1：Anderson定理的Fokker-Planck方程验证

Fokker-Planck方程验证结果（1D高斯混合，VP-SDE）：

| $t$ | $\|\partial p_t/\partial t\|$ | 正向FP右端 | 逆向FP右端 | max|err| | rel_max_err | rms_rel_err |
|-----|-----|-----|-----|-----|-----|-----|
| 0.1 | $O(1)$ | $O(1)$ | $O(1)$ | $< 10^{-3}$ | $< 0.015$ | $< 0.01$ |
| 0.3 | $O(1)$ | $O(1)$ | $O(1)$ | $< 10^{-3}$ | $< 0.01$ | $< 0.005$ |
| 0.5 | $O(0.3)$ | $O(0.3)$ | $O(0.3)$ | $< 10^{-3}$ | $< 0.01$ | $< 0.005$ |
| 0.7 | $O(0.1)$ | $O(0.1)$ | $O(0.1)$ | $< 10^{-3}$ | $< 0.01$ | $< 0.005$ |
| 0.9 | $O(0.01)$ | $O(0.01)$ | $O(0.01)$ | $< 10^{-3}$ | $< 0.02$ | $< 0.01$ |

**结论**：在LHS/RHS量级 $O(0.01)$~$O(14)$ 的尺度下，max|err| $< 10^{-3}$，rms_rel_err $< 0.01$。$p_t(x)$ 在数值精度内同时满足正向与逆向Fokker-Planck方程，验证了Anderson定理——正向SDE与逆向SDE产生相同的边际分布。

> **数值方法学说明**：时间导数用中心差分 $O(\Delta t^2)$（$\Delta t=0.01$），空间导数用 `np.gradient`（二阶中心差分 $O(\Delta x^2)$）。误差来自差分截断，非验证失败。
