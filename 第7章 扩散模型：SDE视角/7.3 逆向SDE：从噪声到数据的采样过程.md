# 7.3 逆向SDE：从噪声到数据的采样过程

> **核心观点**：Anderson (1982) 的逆向时间SDE定理提供了从噪声生成数据的一般方程——$dx = [f(x,t) - g(t)^2\nabla_x\log p_t(x)]\,dt + g(t)\,d\bar{w}$，其中 $\bar{w}$ 是逆向时间的布朗运动。得分函数 $\nabla\log p_t(x)$ 在逆向SDE中扮演核心角色——它提供了"恢复"概率分布的驱动力。正向过程"抹平"概率，逆向过程用得分函数"恢复"概率。VE-SDE和VP-SDE的逆向方程分别恢复SMLD采样和DDPM采样。

## 一个反直觉的"aha"：倒着走，居然不用知道每一步的密度

先做个思想实验。正向过程（7.2节）把清晰图 $x_0$ 一步步加噪成纯噪声 $x_1$。现在你想反过来：从纯噪声 $x_1$ 出发，倒着走回 $x_0$。

**请你先猜一猜**：要倒着走，我们是不是得先算清楚"在时刻 $t$ 含噪数据 $x_t$ 的概率分布长啥样"（$p_t(x)$ 的完整形状）？直觉上好像必须——你要知道每步的密度，才能算"往哪走概率更大"。

**揭晓答案**：不需要！这就是 Anderson (1982) 的逆向时间 SDE 定理给出的反直觉结论——**你只需要第6章学过的那个得分函数 $\nabla\log p_t(x)$（对数密度的梯度，指向概率增长方向），就能倒着走，完全不用知道 $p_t(x)$ 本身长什么样**。得分函数就像一枚指南针，只告诉你"上坡往哪走"，不需要给你整张地形图。

这正是本章路标句的关键一环：**第5章**搞清了得分是什么、**第6章**学会了用去噪器估得分、**本章**我们终于**用**得分来生成——而 Anderson 定理告诉我们，会得分就够了。

读完本节你会能：
1. 背出 Anderson 逆向 SDE 定理，并说清"改符号 + 加得分"四个字；
2. 写出逆向 VE-SDE 和逆向 VP-SDE；
3. 用 Tweedie 等式把得分翻译成"指向干净数据最优估计的方向"。

## Anderson 逆向时间 SDE 定理：改符号，加得分

正向 SDE $dx = f(x,t)\,dt + g(t)\,dw$ 描述从数据到噪声。我们要的采样是**逆着时间**走——从纯噪声 $x_1\sim p_1(x)$ 出发，倒流回数据分布 $p_0(x)=p_{\text{data}}(x)$。

Anderson 的深刻结果：**正向 SDE 的逆向时间过程，依然是一个 SDE**，而且它的形式完全由正向 SDE 的系数 $f,g$ 和得分函数决定。

**定理（Anderson 1982）**：对正向 SDE $dx=f(x,t)\,dt+g(t)\,dw$，其逆向时间过程满足：

$$\boxed{dx = \left[f(x,t) - g(t)^2\,\nabla_x\log p_t(x)\right]\,dt + g(t)\,d\bar{w}}$$

其中 $\bar{w}$ 是逆向时间的布朗运动（时间倒流时的随机项），$p_t(x)$ 是正向过程时刻 $t$ 的边际分布。

这个定理为什么"免费"又强大？三点：

1. **逆向 SDE 自动获得**：一旦定了正向 SDE（选好 $f,g$），逆向方程自动定下来——不用对每个方法单独推导；
2. **得分函数是唯一未知量**：逆向 SDE 里唯一要学的就是 $\nabla\log p_t(x)$——这正是第5、6章一直在聊的得分函数；
3. **逆向采样 = 解逆向 SDE**：从 $x_1\sim p_1(x)$ 出发，把逆向 SDE 解到 $t=0$，就得到数据分布的样本。

和正向 SDE 比，关键改动只有两处：漂移项**多了得分修正** $-g(t)^2\nabla\log p_t(x)$（这是逆向的"驱动力"），布朗运动**方向反转**成 $d\bar{w}$（时间倒流）。证明概要见附录7A。

## 逆向VE-SDE：纯得分驱动（SMLD的连续形式）

把 $f=0$、$g(t)=\sqrt{d[\sigma(t)^2]/dt}$ 代入 Anderson 定理：

$$\boxed{dx = -\frac{d[\sigma(t)^2]}{dt}\,\nabla_x\log p_t(x)\,dt + \sqrt{\frac{d[\sigma(t)^2]}{dt}}\,d\bar{w}}$$

直觉解读：

- **漂移** $-\frac{d[\sigma(t)^2]}{dt}\nabla\log p_t(x)\,dt$：得分指向概率增长方向，乘负号后指向概率减小方向——但在逆向时间里时间倒流，粒子被"推"回高概率区域；
- **扩散** $\sqrt{d[\sigma(t)^2]/dt}\,d\bar{w}$：加和正向同强度的噪声，随机探索防止所有粒子坍缩到一点。

因为 VE-SDE 没有漂移修正（$f=0$），逆向过程**完全靠得分函数**把粒子引回数据分布。7.5节会看到，这个逆向 VE-SDE 的 Euler-Maruyama 离散化恰好恢复 SMLD/退火 Langevin 采样。

## 逆向VP-SDE：收缩力 + 得分力（DDPM的连续形式）

把 $f(x,t)=-\frac{\beta(t)}{2}x$、$g(t)=\sqrt{\beta(t)}$ 代入：

$$\boxed{dx = -\beta(t)\left[\frac{x}{2} + \nabla_x\log p_t(x)\right]\,dt + \sqrt{\beta(t)}\,d\bar{w}}$$

直觉解读：

- **收缩力** $-\frac{\beta(t)}{2}x\,dt$：把信号拉向原点（正向收缩漂移的延续）；
- **得分力** $-\beta(t)\nabla\log p_t(x)\,dt$：把信号拉向数据分布方向；
- 两者组合：收缩力"收拢"幅度，得分力"指向"数据。

相比逆向 VE-SDE，逆向 VP-SDE 多了收缩力项 $-\beta x/2$，让逆向信号不发散——即使得分估得不准，收缩力也提供一张"安全网"。7.5节会看到它离散化恰好恢复 DDPM。

## 得分函数 = 指向"最优估计"的方向（Tweedie桥梁）

逆向 SDE 里的得分 $\nabla\log p_t(x)$ 看似"不可知"——我们不知道真实边际密度 $p_t(x)$。但第5章的 Tweedie 等式（Tweedie's formula，去噪器与得分的桥梁）给了我们钥匙：得分可以从条件期望里直接提取。

**VE-SDE 的 Tweedie 等式**：因为 $p_{0t}(x_t|x_0)=\mathcal{N}(x_t|x_0,\sigma(t)^2 I)$，有

$$\nabla_{x_t}\log p_t(x_t) = \frac{\mathbb{E}[x_0|x_t] - x_t}{\sigma(t)^2}$$

代入逆向 VE-SDE：

$$dx = -\frac{d[\sigma(t)^2]}{dt} \cdot \frac{\mathbb{E}[x_0|x_t] - x_t}{\sigma(t)^2}\,dt + \sqrt{\frac{d[\sigma(t)^2]}{dt}}\,d\bar{w}$$

漂移指向 $\mathbb{E}[x_0|x_t]$（MMSE 估计，最小均方误差估计，即在给定含噪图时干净图的最优猜测）——**逆向 SDE 的驱动力 = 指向最优估计的方向**。

**VP-SDE 的 Tweedie 等式**：因 $p_{0t}(x_t|x_0)=\mathcal{N}(x_t|\sqrt{\bar\alpha_t}x_0,(1-\bar\alpha_t)I)$，

$$\nabla_{x_t}\log p_t(x_t) = \frac{\sqrt{\bar\alpha_t}\,\mathbb{E}[x_0|x_t] - x_t}{1-\bar\alpha_t}$$

代入后同样可写成条件期望形式。

**统一洞见**：逆向 SDE 的漂移 = 指向 MMSE 估计的方向 + 随机探索。这和第5章 PnP-ULA 一脉相承——去噪器（MMSE 估计器）提供"方向"，噪声提供"探索"。

## 逆向SDE的直觉：墨水凝聚

物理类比（Ref C 式的生活画面）：想象墨水滴入清水——

- **正向SDE** = "墨水滴入水中"：一滴墨逐渐扩散，浓度分布越来越平——信息逐步丢失；
- **逆向SDE** = "墨水从水中凝聚"：从均匀分散的墨开始，逐步凝聚回一滴——信息逐步恢复。

在这个画面里：

- 得分函数 $\nabla\log p_t(x)$ 是**指南针**——在每个含噪状态 $x_t$ 处，它指向"原始数据最可能在哪"；
- 布朗运动 $d\bar{w}$ 是**随机搜索**——防止所有粒子坍缩到同一个众数（mode，概率最高的点），保证收敛到整个分布而非一个点；
- 两者结合：得分力把粒子"聚集"到高概率区，扩散力保证分布的"形状"——和 Langevin 动力学机制完全一致。

**逆向SDE vs Langevin SDE**（对比表）：

| 性质 | Langevin SDE | 逆向扩散SDE |
|---|---|---|
| 得分函数 | $\nabla\log p(x)$（固定） | $\nabla\log p_t(x)$（时间条件） |
| 噪声系数 | $\sqrt{2}$（固定） | $g(t)$（时间条件） |
| 漂移修正 | 无 | $f(x,t)\,dt$ |
| 平稳分布 | $p(x)$ | $p_0(x)=p_{\text{data}}(x)$ |

Langevin SDE 是逆向扩散 SDE 的特例（$f=0,g=\sqrt{2},p_t\equiv p$）。核心区别：扩散 SDE 的得分**随时间变化**——从"粗糙得分"（大噪声时指向全局结构）到"精细得分"（小噪声时指向局部细节），形成天然的多尺度采样策略。

这正是扩散模型比单一 Langevin 更强的原因：**扩散采样不是"一个得分函数"驱动的采样，而是"无限个得分函数按时间调度"驱动的采样**。

**来源**：Anderson (1982); Song et al. (2021) Score-SDE; Tutorial_Diffusion_Imaging_Vision Sec 4.3; 2406.08929v2 Sec 2.4

## 实验 7.3-1：Anderson定理解析验证与逆向Drift几何可视化

实验 `7.3-1.py` 通过**Fokker-Planck方程的数值验证**和**逆向Drift向量场的几何可视化**，直观展示Anderson逆时SDE定理的含义——正向SDE与逆向SDE产生相同的边际分布 $p_t(x)$。

### 实验场景

实验在1D和2D高斯混合分布上进行，使用VP-SDE（$\beta_{\min}=0.1$，$\beta_{\max}=20.0$）。实验分为三个步骤：

**步骤1（解析验证）**：对1D高斯混合 $p_0(x) = 0.4\,\mathcal{N}(-2,1) + 0.6\,\mathcal{N}(2,1)$，用解析解计算VP-SDE的边际分布 $p_t(x)$，然后用中心差分计算时间导数 $\partial p_t/\partial t$ 和空间导数，代入正向和逆向的Fokker-Planck方程，验证两边是否吻合。

**步骤2（向量场可视化）**：对2D三分量高斯混合，在不同时间点 $t \in \{0.1, 0.4, 0.7, 1.0\}$ 计算逆向VP-SDE的drift场 $\text{drift}_{\text{rev}} = \frac{\beta(t)}{2}x + \beta(t)\nabla\log p_t(x)$，用箭头图展示drift如何将粒子推向数据高密度区。

**步骤3（粒子演化轨迹）**：对1D高斯混合，从 $x_1 \sim \mathcal{N}(0,I)$ 出发，用Euler-Maruyama方法求解逆向VP-SDE，记录粒子在 $t \in \{1.0, 0.8, 0.6, 0.4, 0.2, 0.0\}$ 的分布快照，与理论边际分布对比。

### 实验目的

1. **验证Anderson定理的解析正确性**：通过Fokker-Planck方程验证 $p_t(x)$ 同时满足正向和逆向的密度演化方程，证明正向与逆向SDE产生相同的边际分布
2. **可视化逆向Drift的几何直觉**：展示得分函数 $\nabla\log p_t(x)$ 如何在每个含噪状态处"指向"数据高密度区，为逆向SDE提供"恢复"的驱动力
3. **展示逆向采样过程**：从纯噪声到数据分布的粒子演化轨迹，直观展示逆向SDE的工作方式

### 实验输入

| 参数 | 设置 |
|------|------|
| 1D目标分布（步骤1、3） | $p_0(x) = 0.4\,\mathcal{N}(-2,1) + 0.6\,\mathcal{N}(2,1)$ |
| 2D目标分布（步骤2） | 三分量高斯混合，权重 $[0.4, 0.3, 0.3]$ |
| VP-SDE参数 | $\beta_{\min}=0.1$，$\beta_{\max}=20.0$（线性插值） |
| 验证时间点（步骤1） | $t \in \{0.1, 0.3, 0.5, 0.7, 0.9\}$ |
| 粒子数（步骤3） | $N=500$，逆向采样500步 |

### 预期结果

- **步骤1**：在各时间点上，$p_t(x)$ 同时满足正向和逆向Fokker-Planck方程，最大绝对误差 $< 10^{-3}$，相对均方根误差 $< 0.01$
- **步骤2**：逆向drift箭头指向边际分布 $p_t(x)$ 的高密度区域；$t$ 接近1时drift方向混乱（接近纯噪声），$t$ 接近0时drift清晰指向各模态中心
- **步骤3**：粒子从 $t=1.0$ 的 $\mathcal{N}(0,I)$ 逐步演化到 $t=0.0$ 的目标高斯混合分布，中间快照与理论边际分布吻合
