# 7.0 本章导读：从离散迭代到连续扩散——SDE统一框架

> "你有没有想过：我们第6章学会了让神经网络去'听'噪声里的信号，可那套方法还是一跳一跳的——在几个固定的噪声水平上反复横跳。能不能让噪声平滑地、连续地'流'起来？"

这正是本章要回答的问题。

**先给你一张地图（路标句）**：上一章（第6章）我们把"去噪器"训练成了一份**得分函数**——它能在任意噪声水平下告诉你"干净数据最可能在哪"。从这一章开始，我们要真正**用**这份得分函数来生成图像了。路标是：**第5章**搞清楚了得分函数是什么并学会了用Langevin去采样 → **第6章**把得分匹配从单一噪声水平推广到多噪声水平（NCSN）→ **本章（第7章）**把这些离散的"跳步"推成一条连续的扩散SDE，于是只要会得分，就能从纯噪声一步步"倒着走"回到数据。**第8章**我们会发现：走另一条"变分"的路，居然也能推到同一个扩散模型——殊途同归的伏笔先埋下。

从更深层次看，这个"离散跳步 → 连续流动"的转变，并不是一次技术微调，而是一次视角的升级。离散的加噪序列像一张张定格照片，而连续的SDE则是一部完整的电影——一旦进入连续时间，逆向方程、确定性等价、似然计算这些原本要逐一定死的东西，会像多米诺骨牌一样自动倒下来。这正是本章想让你体会的：**连续化的最大红利，不是"更精细"，而是"更容易推导"。**

读完本章，你将能够：

- 说清**为什么**要把NCSN/DDPM的离散加噪-去噪推广成连续时间的SDE；
- 写出正向SDE $dx=f(x,t)\,dt+g(t)\,dw$，并认出 VE-SDE（方差爆炸）和 VP-SDE（方差保留）这两个特例；
- 理解 Anderson 逆向时间定理的那个**反直觉结论**——只要第6章学的得分函数，就能倒着走，不用知道每一步的密度；
- 区分"随机"的逆向SDE和"确定性"的概率流ODE，并知道 DDPM/DDIM 其实只是它们的离散化；
- 跑通一段 numpy 代码，亲眼看到"一直对一张图加高斯噪声，最后会变成一团纯高斯噪声"。

## 本章的认知螺旋

我们走一条"推广 → 建立 → 等价 → 计算 → 实践"的路：

- **从Langevin到扩散（7.1）**：回顾单噪声水平的 Langevin SDE，看清 NCSN 退火 Langevin "跳跃式"降温的局限，提出连续时间推广。
- **正向SDE（7.2）**：建立一般加噪方程 $dx=f(x,t)\,dt+g(t)\,dw$，认识 VE-SDE 和 VP-SDE。
- **逆向SDE（7.3）**：Anderson 定理——改个符号、加个得分，就能倒着走回数据。
- **概率流ODE（7.4）**：每个逆向SDE都有一个确定性等价，DDPM 和 DDIM 不再是"对立的方法"。
- **数值离散化（7.5）**：连续方程怎么变成可执行算法——DDPM = 逆向SDE 的 Euler-Maruyama。
- **实践（7.6）**：噪声调度、时间条件得分网络、完整采样流程。
- **采样加速（7.7）**：采样快不快、准不准，取决于求解器。两条路——训练无关的高阶指数积分器（DPM-Solver 一族）与训练相关的一致性模型（把整条轨迹压成一步）。

```
Langevin局限(7.1) → 正向SDE(7.2) → 逆向SDE(7.3) → 概率流ODE(7.4) → 离散化(7.5) → 实践(7.6) → 采样加速(7.7)
```

在这一串路标里，隐藏着贯穿全书的信念叙事：**正向加噪声，是信念的一步步稀释**——清晰的数据被噪声一点点淹没，直到彻底分辨不清；**逆向去噪，则是信念的一步步重建**——借助得分函数这份"概率地形的指南针"，从混沌噪声里一步步把结构捞回来。你会在7.2节看到"稀释"，在7.3节看到"重建"，二者恰好构成了一个完整的过程。

**一句话大思想（先剧透，读完会懂）**：扩散模型 = 正向SDE（定义怎么加噪）+ 学习得分函数（驱动怎么去噪）+ 数值离散化（实现采样）——三位一体，完成了采样路径从"多步Langevin"到"连续扩散"的关键跃迁。而这一切的核心驱动力，正是你已经在第5、6章认识的那个老朋友：**得分函数**。

更微妙的是，这条SDE之路并非孤立。第8章起我们会从变分推断重新步行一遍，去推导同一个扩散模型——**因为扩散模型本就是变分路线在"无穷层隐变量"假设下的自然极限**。先记住这句伏笔，到了第8章和第12章，你会亲眼看到两条路的汇合。
