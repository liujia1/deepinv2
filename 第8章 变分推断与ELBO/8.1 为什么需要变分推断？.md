# 8.1 为什么需要变分推断？

> **核心观点**：第4-7章的采样路径提供了后验采样的理论保证和实用算法，但其核心操作——MCMC/Langevin迭代——本质上是"慢"的：每幅图像需要成百上千步迭代。变分推断提供了另一种策略：不追求从后验中精确采样，而是用一个参数化的简单分布 $q_\phi(z)$ 去逼近后验 $p(z|x)$，通过最大化ELBO来优化近似质量。这种"用近似换效率"的思路，是变分路径的起点。

## 采样路径的成就与局限

第4-7章建立了一条完整的采样路径，从MCMC到扩散SDE，层层递进：

- **第4章**：MCMC（Metropolis-Hastings、ULA）提供了后验采样的理论保证——渐近地从真实后验采样
- **第5章**：Langevin动力学利用后验梯度（得分函数）加速采样，PnP框架用去噪器替换先验梯度
- **第6章**：得分匹配从数据中学习得分函数，NCSN实现多尺度得分估计
- **第7章**：扩散SDE将离散框架统一到连续时间，逆向SDE提供从噪声生成数据的方程

这条路径的理论价值毋庸置疑：MCMC渐近无偏，Langevin高效利用梯度，扩散SDE统一框架。然而，采样路径有一个根本性的局限——**计算代价**。

考虑一个典型的逆问题场景：给定模糊观测 $y = Ax + \epsilon$，从后验 $p(x|y)$ 中采样。用ULA算法（第4章4.3节），每次采样需要运行数万步迭代：

$$x_{m+1} = x_m + \delta \nabla\log p(x_m|y) + \sqrt{2\delta}\,z_{m+1}$$

对于一幅 $256 \times 256$ 的图像（$d = 65536$ 维），ULA的混合时间与维度相关——维度越高，需要的步数越多。实际中，每幅图像的采样可能需要数万到数十万步。如果我们需要1000个后验样本来量化不确定性（第4章4.7节），计算代价更是成千倍增长。

更深层的问题在于：**采样路径优化的是采样质量，而不是对数似然 $\log p(x)$**。在第7章的SDE框架中，我们通过学习得分函数来驱动逆向SDE，但训练目标（DSM损失）并不直接优化 $\log p(x)$。这意味着我们无法直接评估模型对数据的拟合程度——模型可能生成了高质量的图像，但对数据的似然可能并不高。

## 真实后验不可解的普遍性

回顾第1章的核心困难：后验分布

$$p(x|y) = \frac{p(y|x)p(x)}{\int p(y|x)p(x)dx}$$

的计算需要归一化常数 $Z = \int p(y|x)p(x)dx$——一个高维积分。对于任意复杂的先验 $p(x)$（如数据驱动的深度学习先验），这个积分不可解析计算。

这并非逆问题的特殊困难——**后验不可解是概率推断的普遍现象**。在更一般的潜变量模型中：

$$p(x) = \int p(x, z)dz$$

观测 $x$ 的边际似然同样需要对潜变量 $z$ 积分。无论是逆问题的后验 $p(x|y)$，还是生成模型的后验 $p(z|x)$，高维积分都是绕不开的障碍。

我们已经见过几种应对策略：

1. **MCMC**（第4章）：绕过 $Z$ 的计算，直接从后验采样。精确但缓慢。
2. **Laplace近似**：用高斯分布近似后验。快速但仅适用于单峰后验。
3. **MAP估计**（第3章）：只求后验众数，完全忽略分布形状。最快但丢弃不确定性。

问题依然存在：**能否找到一种方法，既绕过 $Z$ 的计算，又不需要迭代采样，还能保留分布信息？**

## 变分推断的核心思想：从采样到优化

变分推断的回答是肯定的。其核心洞见可以一句话概括：

> **与其从 $p(z|x)$ 中采样（慢），不如找一个 $q(z)$ 逼近 $p(z|x)$（快）。**

这里发生了一个关键的范式转换：

- **采样范式**：目标是产生来自 $p(z|x)$ 的样本——需要迭代随机过程
- **优化范式**：目标是找到最接近 $p(z|x)$ 的 $q \in \mathcal{Q}$——需要求解优化问题

具体来说，变分推断将推断问题转化为优化问题：

|  | 推断问题 | 优化问题 |
|---|---|---|
| 目标 | 计算后验 $p(z\|x)$ | 找 $q^* = \arg\min_{q \in \mathcal{Q}} \text{KL}(q\|p(z\|x))$ |
| 操作 | 高维积分 | 最大化目标函数 |
| 结果 | 后验分布 | 近似后验分布 |
| 可解性 | 通常不可解 | 可解（取决于 $\mathcal{Q}$） |

"变分"（Variational）一词源于变分法——在函数空间中优化，而非参数空间。我们要优化的是整个分布 $q(z)$，而非单个参数。变分族 $\mathcal{Q}$ 定义了搜索空间——$\mathcal{Q}$ 中的每个元素都是一个概率分布。

这种转换带来了根本性的效率提升：

- **MCMC**：每幅图像需要迭代采样 → 慢
- **变分推断**：每幅图像只需求解一次优化 → 快（尤其是优化有闭式解或可以用梯度下降时）

当然，效率的提升不是免费的——变分推断的近似质量受限于变分族 $\mathcal{Q}$ 的表达能力。$\mathcal{Q}$ 太小，近似质量差；$\mathcal{Q}$ 太大，优化困难。这种**近似-效率的权衡**是变分推断的核心张力，也驱动了从平均场到VAE再到层级VAE的方法演进。

## 两条路径的分野与互补

现在，我们可以清晰地看到两条路径的分野：

```
           ┌── 采样路径（Part II）：追求精确 —— 渐近地从真实后验采样，但计算慢
贝叶斯框架 ─┤
           └── 变分路径（Part III）：追求高效 —— 用近似分布逼近后验，计算快但可能有偏
```

两条路径并非对立，而是互补：

- **采样路径**提供理论基准——MCMC的渐近精确性使我们能够验证变分近似的质量
- **变分路径**提供计算效率——优化问题的可扩展性使我们能够处理大规模模型

更深层的互补性在于：**两条路径最终汇合于扩散模型**。采样路径通过得分匹配和SDE推导出扩散模型，变分路径通过ELBO和层级VAE推导出扩散模型。第12章将证明，两条路径给出完全相同的训练目标——DSM损失 ≡ 变分下界。这种"殊途同归"不是巧合，而是数学结构的必然：扩散模型同时继承了采样路径的精确性和变分路径的高效性。
