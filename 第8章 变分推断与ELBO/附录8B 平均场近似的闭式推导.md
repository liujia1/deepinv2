# 附录8B 平均场近似的闭式推导（CAVI算法推导）

> 定位：为8.3节CAVI算法提供完整推导。

## 问题设定

在平均场假设下，近似后验因子化为：

$$q(z) = \prod_{j=1}^{M} q_j(z_j)$$

目标是在此约束下最大化ELBO：

$$\text{ELBO}(q) = \mathbb{E}_{q(z)}[\log p(x,z)] - \mathbb{E}_{q(z)}[\log q(z)]$$

CAVI的策略是坐标上升：固定 $q_{-j} = \prod_{i \neq j} q_i(z_i)$，对 $q_j$ 最大化ELBO。

## CAVI更新公式的推导

### 步骤1：分离ELBO中与 $q_j$ 相关的项

将ELBO写为：

$$\text{ELBO} = \int q(z) \log p(x,z)\,dz - \int q(z) \log q(z)\,dz$$

在平均场假设下，$q(z) = q_j(z_j) \cdot q_{-j}(z_{-j})$，其中 $q_{-j}(z_{-j}) = \prod_{i \neq j} q_i(z_i)$。

第一项（联合对数似然的期望）：

$$\int q_j(z_j) q_{-j}(z_{-j}) \log p(x, z_j, z_{-j})\,dz_j\,dz_{-j} = \int q_j(z_j) \left[\int q_{-j}(z_{-j}) \log p(x, z_j, z_{-j})\,dz_{-j}\right]dz_j$$

定义：

$$\tilde{p}(x, z_j) = \exp\left(\mathbb{E}_{q_{-j}}[\log p(x, z_j, z_{-j})]\right) = \exp\left(\int q_{-j}(z_{-j}) \log p(x, z_j, z_{-j})\,dz_{-j}\right)$$

则第一项为 $\int q_j(z_j) \log \tilde{p}(x, z_j)\,dz_j$（注意这里 $\tilde{p}$ 未必是归一化的概率分布，但 $\log \tilde{p} = \mathbb{E}_{q_{-j}}[\log p]$）。

第二项（负熵）：

$$-\int q(z) \log q(z)\,dz = -\int q_j(z_j) \log q_j(z_j)\,dz_j - \sum_{i \neq j} \int q_i(z_i) \log q_i(z_i)\,dz_i$$

其中与 $q_j$ 相关的部分只有 $-\int q_j(z_j) \log q_j(z_j)\,dz_j$。

### 步骤2：构造拉格朗日函数

因此，ELBO中与 $q_j$ 相关的部分为：

$$\mathcal{L}_j[q_j] = \int q_j(z_j) \mathbb{E}_{q_{-j}}[\log p(x, z)]\,dz_j - \int q_j(z_j) \log q_j(z_j)\,dz_j$$

加入归一化约束 $\int q_j(z_j)dz_j = 1$（拉格朗日乘子 $\lambda$）：

$$\mathcal{L} = \int q_j(z_j) \mathbb{E}_{q_{-j}}[\log p(x, z)]\,dz_j - \int q_j(z_j) \log q_j(z_j)\,dz_j + \lambda\left(\int q_j(z_j)dz_j - 1\right)$$

### 步骤3：求变分导数并令其为零

对 $q_j$ 在每个点 $z_j$ 处求变分导数（即将 $q_j$ 看作无限维向量，对每个分量求导）：

$$\frac{\delta \mathcal{L}}{\delta q_j(z_j)} = \mathbb{E}_{q_{-j}}[\log p(x, z)] - \log q_j(z_j) - 1 + \lambda = 0$$

解出 $q_j$：

$$\log q_j(z_j) = \mathbb{E}_{q_{-j}}[\log p(x, z)] + \lambda - 1$$

$$q_j(z_j) \propto \exp\left(\mathbb{E}_{q_{-j}}[\log p(x, z)]\right)$$

即：

$$\boxed{q_j^*(z_j) = \frac{\exp\left(\mathbb{E}_{q_{-j}}[\log p(x, z)]\right)}{\int \exp\left(\mathbb{E}_{q_{-j}}[\log p(x, z')]\right)dz_j'}}$$

这就是CAVI的更新公式——$q_j$ 的最优分布是联合对数似然在其他因子下的期望的指数族分布。

## 共轭模型下的闭式解

当先验和似然是共轭对时，CAVI更新有闭式解。以**高斯混合模型**为例：

### 模型

- 混合权重：$\pi \sim \text{Dir}(\alpha_0)$
- 混合均值：$\mu_k \sim \mathcal{N}(0, \sigma_0^2)$，$k = 1, \ldots, K$
- 分配变量：$c_i \sim \text{Cat}(\pi)$，$i = 1, \ldots, N$
- 观测：$x_i | c_i = k \sim \mathcal{N}(\mu_k, \sigma^2)$

### 平均场假设

$$q(\pi, \mu, c) = q(\pi) \prod_{k=1}^K q(\mu_k) \prod_{i=1}^N q(c_i)$$

### CAVI更新

对 $q(\mu_k)$：

$$\log q^*(\mu_k) = \mathbb{E}_{q_{-\mu_k}}[\log p(x, \pi, \mu, c)] + \text{const}$$

由于 $\mu_k$ 只出现在先验 $p(\mu_k)$ 和似然 $p(x_i | c_i = k, \mu_k)$ 中：

$$\log q^*(\mu_k) = -\frac{\mu_k^2}{2\sigma_0^2} - \frac{1}{2\sigma^2}\sum_{i=1}^N q(c_i = k)(x_i - \mu_k)^2 + \text{const}$$

这是关于 $\mu_k$ 的二次函数，因此 $q^*(\mu_k) = \mathcal{N}(\hat{\mu}_k, \hat{\sigma}_k^2)$，其中：

$$\hat{\mu}_k = \frac{\sigma_0^2}{\sigma_0^2 + \sigma^2 \sum_i q(c_i = k)} \cdot \sum_i q(c_i = k) x_i$$

$$\hat{\sigma}_k^2 = \frac{\sigma_0^2 \sigma^2}{\sigma_0^2 + \sigma^2 \sum_i q(c_i = k)}$$

类似地可以推导 $q(\pi)$ 和 $q(c_i)$ 的更新。每次更新都有闭式解——这正是共轭模型的便利之处。

## CAVI的收敛性

### 单调性

每步CAVI更新保证ELBO不减。这是因为每步更新都是条件最优——固定 $q_{-j}$，$q_j^*$ 是ELBO关于 $q_j$ 的全局最优。因此：

$$\text{ELBO}(q_j^*, q_{-j}) \geq \text{ELBO}(q_j, q_{-j})$$

### 收敛性

因为ELBO单调递增且有上界（$\text{ELBO} \leq \log p(x)$），所以CAVI必然收敛。

### 局部最优

CAVI收敛到ELBO的**驻点**（stationary point），不保证全局最优。在非凸的ELBO景观中，不同的初始化可能收敛到不同的局部最优。

### 初始化的影响

实践中，CAVI的初始化对结果有显著影响。常见的初始化策略包括：

1. **随机初始化**：多次随机初始化，取ELBO最高的结果
2. **启发式初始化**：用数据驱动的启发式方法（如K-means）初始化
3. **热启动**：用前一个数据点的结果初始化当前数据点
