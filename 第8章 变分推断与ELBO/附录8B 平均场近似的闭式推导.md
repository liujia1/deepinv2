# 附录8B 平均场近似的闭式推导（CAVI算法推导）

> 定位：为 8.3 节 CAVI 算法提供完整推导。8.3 节里我们"宣称"：在平均场假设下，固定其他因子、只优化第 $j$ 个，得到那个漂亮的交替更新公式 $q_j^* \propto \exp(\mathbb{E}_{q_{-j}}[\log p])$。如果你想知道它到底从哪来，这一节把它从第一性原理推出来；并接着给出 Jamil 手册里那个让人安心的高斯混合（GMM）闭式更新，让你亲眼看到"近似后验恰好吻合"不是吹的。

## 问题设定

平均场假设下，近似后验因子化：

$$q(z) = \prod_{j=1}^{M} q_j(z_j)$$

目标：在此约束下最大化 ELBO：

$$\text{ELBO}(q) = \mathbb{E}_{q(z)}[\log p(x,z)] - \mathbb{E}_{q(z)}[\log q(z)]$$

CAVI 的策略是坐标上升：固定 $q_{-j} = \prod_{i\neq j} q_i(z_i)$，只对 $q_j$ 最大化 ELBO。

先想清楚这个策略为什么合理：整个优化问题难在 $M$ 个因子纠缠在一起，谁动都会牵连别人。坐标上升的妙处是"先把其他人按住，专心收拾其中一个"——虽然每次只解一个局部子问题，反复循坏后却能让 ELBO 单调攀升，这正是它既简单又稳定的原因。

## CAVI更新公式的推导

### 步骤1：分离 ELBO 中与 $q_j$ 相关的项

把 ELBO 写成积分：

$$\text{ELBO} = \int q(z) \log p(x,z)\,dz - \int q(z) \log q(z)\,dz$$

平均场下 $q(z) = q_j(z_j)\cdot q_{-j}(z_{-j})$。第一项（联合对数似然期望）拆出对 $q_j$ 的依赖：

$$\int q_j(z_j) q_{-j}(z_{-j}) \log p(x, z_j, z_{-j})\,dz_j\,dz_{-j} = \int q_j(z_j) \Big[\int q_{-j}(z_{-j}) \log p(x, z_j, z_{-j})\,dz_{-j}\Big]dz_j$$

定义：

$$\tilde{p}(x, z_j) = \exp\left(\mathbb{E}_{q_{-j}}[\log p(x, z_j, z_{-j})]\right)$$

则第一项变成 $\int q_j(z_j)\log \tilde{p}(x,z_j)\,dz_j$（注意 $\tilde{p}$ 未必归一化，但 $\log \tilde{p} = \mathbb{E}_{q_{-j}}[\log p]$）。

第二项（负熵）：

$$-\int q(z)\log q(z)\,dz = -\int q_j(z_j)\log q_j(z_j)\,dz_j - \sum_{i\neq j}\int q_i(z_i)\log q_i(z_i)\,dz_i$$

与 $q_j$ 相关的只有 $-\int q_j\log q_j$。

### 步骤2：构造拉格朗日函数

与 $q_j$ 相关的部分为：

$$\mathcal{L}_j[q_j] = \int q_j(z_j)\,\mathbb{E}_{q_{-j}}[\log p(x,z)]\,dz_j - \int q_j(z_j)\log q_j(z_j)\,dz_j$$

加归一化约束 $\int q_j(z_j)dz_j=1$（拉格朗日乘子 $\lambda$）：

$$\mathcal{L} = \int q_j\,\mathbb{E}_{q_{-j}}[\log p]\,dz_j - \int q_j\log q_j\,dz_j + \lambda\left(\int q_j\,dz_j - 1\right)$$

### 步骤3：求变分导数并令为零

把 $q_j$ 看成"无限维向量"，对每个点求变分导数：

$$\frac{\delta \mathcal{L}}{\delta q_j(z_j)} = \mathbb{E}_{q_{-j}}[\log p(x,z)] - \log q_j(z_j) - 1 + \lambda = 0$$

解出：

$$\log q_j(z_j) = \mathbb{E}_{q_{-j}}[\log p(x,z)] + \lambda - 1 \quad\Rightarrow\quad q_j(z_j) \propto \exp\left(\mathbb{E}_{q_{-j}}[\log p(x,z)]\right)$$

即：

$$\boxed{q_j^*(z_j) = \frac{\exp\left(\mathbb{E}_{q_{-j}}[\log p(x, z)]\right)}{\int \exp\left(\mathbb{E}_{q_{-j}}[\log p(x, z')]\right)dz_j'}}$$

这就是 CAVI 更新公式——$q_j$ 的最优分布是"联合对数似然在其他因子下的期望"的指数族分布。这个式子的含义很直接：**$z_j$ 的信念，被塑成"在其余变量当前认知下，它最能解释数据的样子"**——其余变量都在替它搭台，它只需站到自己的最优位置。这一转变意味着，整个多变量推断被简化成一串"别人定好前提、我再补自己的答案"的循环默契。

## 共轭模型下的闭式解

当先验和似然是共轭对时，CAVI 有闭式解。以**高斯混合模型**为例：

### 模型

- 混合权重：$\pi \sim \text{Dir}(\alpha_0)$
- 混合均值：$\mu_k \sim \mathcal{N}(0, \sigma_0^2)$
- 分配变量：$c_i \sim \text{Cat}(\pi)$
- 观测：$x_i | c_i = k \sim \mathcal{N}(\mu_k, \sigma^2)$

### 平均场假设

$$q(\pi, \mu, c) = q(\pi) \prod_{k=1}^K q(\mu_k) \prod_{i=1}^N q(c_i)$$

### CAVI更新

对 $q(\mu_k)$：

$$\log q^*(\mu_k) = \mathbb{E}_{q_{-\mu_k}}[\log p(x, \pi, \mu, c)] + \text{const}$$

$\mu_k$ 只出现在先验 $p(\mu_k)$ 和似然 $p(x_i|c_i=k,\mu_k)$ 中：

$$\log q^*(\mu_k) = -\frac{\mu_k^2}{2\sigma_0^2} - \frac{1}{2\sigma^2}\sum_i q(c_i=k)(x_i-\mu_k)^2 + \text{const}$$

这是关于 $\mu_k$ 的二次函数，故 $q^*(\mu_k)=\mathcal{N}(\hat{\mu}_k, \hat{\sigma}_k^2)$：

$$\hat{\mu}_k = \frac{\sigma_0^2}{\sigma_0^2 + \sigma^2\sum_i q(c_i=k)}\cdot\sum_i q(c_i=k)x_i$$

$$\hat{\sigma}_k^2 = \frac{\sigma_0^2\sigma^2}{\sigma_0^2 + \sigma^2\sum_i q(c_i=k)}$$

注意这两行更新长得和第 8.3 节"完美匹配"玩具里的后验闭式几乎一样——不是巧合，而是共轭结构的反复显现：只要"某变量与其数据、先验"配对合理，最优信念就总是同一族高斯，只是把"被观测的 $x$"换成"被加权的汇总 $\sum_i q(c_i=k)x_i$"。$q(\pi)$、$q(c_i)$ 同理有闭式——这正是共轭模型的便利。

## CAVI的收敛性

- **单调性**：每步更新都是条件最优，故 $\text{ELBO}(q_j^*, q_{-j}) \geq \text{ELBO}(q_j, q_{-j})$，ELBO 不减。
- **收敛性**：ELBO 单调不减且有上界（$\leq \log p(x)$），必收敛。
- **局部最优**：收敛到驻点，不保证全局最优；非凸景观下不同初始化可能到不同局部最优。
- **初始化影响**：常用随机初始化取最优、K-means 启发式、或热启动（用上个点结果初始化）。

这也提醒我们：CAVI 的收敛保证是"一定到某个局部最优"，而不是"一定到全局最优"。这说明在变分路径里，选用哪个初始点、如何组织坐标轮替，常常和理论本身同等重要。
