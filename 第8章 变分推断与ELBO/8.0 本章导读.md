# 8.0 本章导读：从采样到优化——变分路径的起点

> 路标一句：**前面第 4–7 章我们学会了"从后验里慢慢抽样"，这一章我们换一种活法——不抽样了，直接找一个简单分布去"贴"住后验，把推断问题变成一个优化问题。这就是变分路径的起点，也是全书第二条主线的大门。**

先讲个场景，帮你对上节奏。第 7 章我们走到了采样路径的终点：扩散模型用一条 SDE（随机微分方程，一种用噪声驱动演化的方程）把噪声一步步变成图像。这套东西理论上很漂亮——它告诉我们"怎么从后验里采出样本"。但你只要亲手跑过一次 MCMC（第 4 章），就会很快体会到它的一个致命短板：**慢**。要给一幅 $256\times256$ 的图像出 1000 个后验样本，可能要迭代几十万步。这在研究里还凑合，真要上线到临床 CT 重建，根本等不起。

而且采样路径还有一层更深的局限，值得我们在这里停下来想一想。第 4–7 章给我们的整条叙事，都是"先算不出、再慢慢采"：我们相信只要采得足够久，样本就逼近真实后验。可"足够久"到底有多久？在医学成像这种对延迟极敏感的场合，"渐近正确"并不能替代"当下可用"。变分推断要回答的正是这个问题。

于是问题来了：有没有一种办法，**不追求"精确抽样"，只追求"快速贴住后验"**？这就是本章要回答的事。我们给它一个名字——变分推断（Variational Inference，简称 VI）。

从更深层次看，本章标志着信念刻画方式的一次转换：第 4–7 章的采样路径，是把"不确定的信念"用**一张样本清单**来表达；而本章的变分路径，是把"不确定的信念"用**一个参数化的分布 $q$**来表达，然后靠调整参数让这个 $q$ 去逼近后验。前者是"抽样"，后者是"优化"——同一枚贝叶斯硬币的两面。这一转换意味着，我们得到的不再是一堆离散的点，而是一个可以随时求值、求导、采样的**完整分布函数**，这为后面把它接进神经网络铺平了道路。

本章走一条"动机 → 推导 → 优化 → 统一 → 展望"的路线，最后用一个可运行的 numpy 小程序让你亲眼看到：一个简单的钟形曲线 $q_\phi$ 怎么一步步"长"成后验的形状。

**读完本章你能做这四件事：**
- 说清楚为什么后验算不出来 / 抽样太慢，非得走变分这条路（8.1）；
- 亲手推导出 ELBO（证据下界，Evidence Lower Bound），并理解"最大化 ELBO = 最小化与后验的 KL 散度"（8.2）；
- 把变分推断写成一个优化问题，看到平均场近似、CAVI 算法，用一个"完美匹配"的单变量高斯玩具建立信任，并在全章最亮的反直觉 aha 里看懂**零强迫（zero-forcing）vs 零避免（zero-avoiding）**两种 KL 近似的本质差异，再用高斯混合的手算实例见识 CAVI 的真功夫（8.3）；
- 理解 ELBO 的"重建 + 正则"结构如何和第 2 章的"先验 = 正则化"呼应，并用**摊推断（amortized VI）**这条加速器把 VI 接上 VAE，俯瞰整条变分路径通向扩散模型（8.4–8.5）。

## 本章要解决的核心困惑（先剧透，后面逐个拆解）

在正式开讲前，先把四个你大概率会卡住的点摊开，这样读起来心里有数：

1. **为什么需要 VI？** 后验算不出闭式（归一化常数 $Z$ 是个高维积分，算不了），MCMC 能绕开 $Z$ 但太慢。能不能既不算 $Z$、又不迭代抽样？
2. **"鸡生蛋"困境**：VI 想最小化 $\text{KL}(q\|p)$，可 $p = p(z|x)$ 本身含那个算不出的归一化常数 $Z$。我们拿不到 $p$ 的精确值，怎么还能去逼近它？
3. **ELBO 是怎么冒出来的？** 它明明是 $\log p(x)$ 的一个"下界"，为什么最大化这个下界，就等价于把 $q$ 贴到了后验上？
4. **重参数化（埋个伏笔）**：ELBO 里有个期望 $\mathbb{E}_q[\cdots]$，而 $q$ 是从里"采样"出来的——**采样操作不可导**，梯度流不过去。这坑怎么填？先卖个关子，8.3 节揭晓答案 $z = \mu + \sigma\cdot\epsilon$。

其中第 4 点看着像第 9 章 VAE 的内容，但它其实是我们这一章"变分路径"能跑起来的工程命门，所以本章就要把它讲透。

## 本章在全书的定位

```
采样路径(第4–7章)             变分路径(本章起)
MCMC → Langevin → 得分匹配 → 扩散SDE    ELBO → VAE(第9章) → 层级VAE(第10章) → 变分扩散(第11章)
   ↓                                                            ↓
   └──────────── 汇合于 Score ≡ ELBO(第12章) ──────────────┘
```

采样路径追求**精确**（渐近无偏，采样足够久就无限接近真后验），变分路径追求**高效**（用近似换速度）。两条路看似各走一边，最后在第 12 章汇成一句话：**DSM 损失 ≡ 变分下界**。本章就是这条变分路径的"地基"——后面每一章都踩在 ELBO 上。

需要强调的是，这两条路径的分野并不是"对错"之分，而是"目标"之别。采样路径要把信念画得**尽可能细**，变分路径要把信念表达得**尽可能省力**。对读者而言，理解其中任何一条，都能帮助你更深刻地理解另一条——因为它们的共同对手，都是那个算不出的归一化常数。

**本章一句话大思想（先记住，读完会更深）**：变分推断 = 把"推断"这件算不出的事，重写成"优化"这件能算的事；而 ELBO，就是连接这两件事的桥。

这一转变意味着什么？意味着我们不需要再在"精确但昂贵"与"便宜但极简"之间二选一——MAP 太快却丢掉不确定性，MCMC 保住不确定性却太慢。变分推断提供的是第三条路：保留后验的不确定性，只是对它的形状做了一次可控的简化。这正是"变分推断 = 信念刻画从采样转向优化"的第一个提示。

> **和本书库的关系**：本书主线是"分布打底，高斯成噪；似然保真，贝叶合成"。本章承接第 3 章 MAP 之后的分叉——MAP 只要一个点，我们这里要整个分布，但又不肯像 MCMC 那样慢慢采，于是走"变分"这条路，用优化去逼近后验。它和采样路径（第 4–7 章）殊途同归，为第 12 章的 Score ≡ ELBO 埋下最大伏笔。
