# 8.0 本章导读：从采样到优化——变分路径的起点

第4-7章建立了采样路径的完整体系：MCMC提供后验采样的理论保证，Langevin动力学利用梯度加速采样，得分匹配从数据中学习得分函数，扩散SDE统一了连续时间框架。然而，采样路径的核心操作——从后验分布中抽取样本——本质上是一种"慢"方法：每幅图像都需要迭代成百上千步。

本章换一种思路：**不追求从后验中采样，而是用一个简单分布去逼近后验**。这就是变分推断（Variational Inference）的核心思想——将推断问题转化为优化问题。ELBO（Evidence Lower Bound，证据下界）是这个转化的数学工具：它是对数似然 $\log p(x)$ 的一个下界，最大化ELBO等价于最小化近似分布与真实后验之间的KL散度。

本章走一条"动机→推导→优化→统一→展望"的路径：

**为什么需要变分推断**（8.1）：回顾采样路径的成就与局限，阐明变分推断的核心思想——从采样到优化的范式转换。两条路径（采样与变分）并非对立，而是互补：采样追求精确，变分追求高效。

**ELBO推导**（8.2）：从对数似然 $\log p(x)$ 出发，通过Jensen不等式和KL散度分解两种方法推导ELBO。ELBO有两个等价形式：一是"联合-熵"分解 $\mathbb{E}_q[\log p(x,z)] - \mathbb{E}_q[\log q(z)]$，二是"重建+正则"分解 $\mathbb{E}_q[\log p(x|z)] - \text{KL}(q\|p)$。后者揭示了ELBO的结构——最大化ELBO = 最大化重建质量 + 最小化与先验的偏离。

**变分推断作为优化问题**（8.3）：将变分推断形式化为优化问题——在变分族 $\mathcal{Q}$ 的约束下最大化ELBO。平均场近似是最经典的变分族选择——假设潜变量之间相互独立。坐标上升变分推断（CAVI）是平均场下的迭代优化算法。变分间隙 $\text{KL}(q\|p(z|x))$ 衡量近似质量，间隙为零当且仅当 $q = p(z|x)$。

**变分推断与正则化的统一视角**（8.4）：ELBO的"重建+KL正则"分解与第2章的"$-\ln$后验 = 数据项 + 正则项"遥相呼应——变分推断为正则化提供了概率解释，正则化为变分推断提供了优化直觉。Fenchel共轭为这种统一提供了更深层的优化理论基础（详见附录8A）。变分正则化框架将两种视角统一在同一个数学框架中。

**从变分推断到生成模型**（8.5）：变分推断的最终目标不是仅仅近似后验，而是构建生成模型。摊推断（Amortized Inference）用参数化网络替代逐样本优化，将变分推断从"推断工具"升级为"生成模型训练框架"——这正是VAE的核心思想。变分路径的路线图：ELBO → VAE → 层级VAE → 变分扩散，每一步都是对ELBO框架的扩展和深化。

```
采样局限(8.1) → ELBO推导(8.2) → 优化形式化(8.3) → 与正则化统一(8.4) → 生成模型路线图(8.5)
```

本章结束时，读者将理解：变分推断提供了一种与采样根本不同的后验近似策略——用优化替代采样，用近似替代精确。ELBO是这种策略的数学核心，它既是对数似然的下界，也是重建质量与先验约束的权衡。变分推断与正则化的统一视角揭示了一个深层联系：概率推断与优化正则化是一枚硬币的两面。本章的核心洞见是：**变分推断 = 将推断问题转化为优化问题，ELBO是连接两者的桥梁**——这一洞见将在后续章节中不断深化，最终导向扩散模型的变分推导。
