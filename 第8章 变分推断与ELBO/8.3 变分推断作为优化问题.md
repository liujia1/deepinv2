# 8.3 变分推断作为优化问题

> **核心观点**：变分推断的核心操作是在变分族 $\mathcal{Q}$ 的约束下最大化ELBO。变分族的选择决定了近似的表达能力和优化的难度——平均场近似假设潜变量之间相互独立，是最经典的选择。坐标上升变分推断（CAVI）是平均场下的迭代优化算法，交替更新每个因子的最优分布。变分间隙 $\text{KL}(q\|p(z|x))$ 衡量近似质量，为零当且仅当 $q = p(z|x)$。

## 变分推断 = 在 $\mathcal{Q}$ 的约束下最大化ELBO

8.2节推导了ELBO，并证明了最大化ELBO等价于最小化 $\text{KL}(q\|p(z|x))$。现在的问题是：如何最大化ELBO？

变分推断将这个问题形式化为一个约束优化问题：

$$q^* = \arg\max_{q \in \mathcal{Q}} \text{ELBO}(q)$$

其中 $\mathcal{Q}$ 是**变分族**（variational family）——一组候选分布的集合。变分族的选择至关重要：

- $\mathcal{Q}$ **太小**：近似质量差（变分间隙大），但优化容易
- $\mathcal{Q}$ **太大**：近似质量好，但优化困难
- **理想**：$\mathcal{Q}$ 足够表达真实后验的主要特征，且优化可行

两个极端：

- 如果 $\mathcal{Q} = \{p(z|x)\}$（只包含真实后验），则变分间隙为零，但找到它等价于计算后验——回到不可解问题
- 如果 $\mathcal{Q}$ 是所有可能分布的集合，则最优 $q^* = p(z|x)$，但搜索空间无限大——优化不可行

因此，变分族的设计是一种**近似-可解性的权衡**。平均场近似是最经典的选择。

## 平均场近似（Mean-Field Approximation）

平均场近似的核心假设是：**潜变量之间相互独立**。即，近似后验可以因子化为：

$$q(z) = \prod_{i=1}^{M} q_i(z_i)$$

其中 $z = (z_1, z_2, \ldots, z_M)$ 是 $M$ 个潜变量，每个 $q_i(z_i)$ 是一个独立的因子。

这个假设的来源是物理学中的**平均场理论**（Parisi 1988）。在统计力学中，平均场近似将多体相互作用简化为每个粒子在"平均场"中的独立运动——忽略了粒子之间的关联，但大幅简化了计算。

**平均场近似的优点**：

1. **大幅简化优化**——从联合优化 $q(z)$（$M$ 维联合分布）降为逐因子优化 $q_i(z_i)$（$M$ 个一维边际分布）
2. **减少参数量**——因子化假设将参数从指数级降为线性级
3. **CAVI有闭式更新**——许多模型下，每个因子的最优解有解析表达式

**平均场近似的缺点**：

1. **忽略变量间的相关性**——如果 $z_1$ 和 $z_2$ 在真实后验中强相关，平均场无法捕获
2. **无法表示多模态结构**——因子化的 $q$ 只能近似单峰后验
3. **欠估计后验方差**——独立性假设通常导致 $q$ 比真实后验更"窄"

一个典型的例子是**高斯混合模型**（GMM）的后验：真实的 $p(z|x)$ 是多模态的（每个高斯分量对应一个模态），但平均场近似 $q(z) = q(\mu)q(\pi)$ 只能近似其中一个模态。

尽管有这些局限，平均场近似在实践中非常成功——特别是在模型本身有较强先验结构（如共轭先验）的情况下。

## 坐标上升变分推断（CAVI）

在平均场假设下，ELBO的优化可以通过**坐标上升变分推断**（Coordinate Ascent Variational Inference, CAVI）实现。CAVI的思想简单而有效：固定其他所有因子，优化一个因子；交替进行直到收敛。

### CAVI更新公式

固定 $q_{-j} = \prod_{i \neq j} q_i(z_i)$，对 $q_j(z_j)$ 最大化ELBO，最优解为：

$$\boxed{q_j^*(z_j) \propto \exp\left(\mathbb{E}_{q_{-j}}[\log p(x, z)]\right)}$$

其中 $\mathbb{E}_{q_{-j}}$ 表示对除 $z_j$ 外的所有潜变量求期望。

**推导概要**（详细推导见附录8B）：

ELBO关于 $q_j$ 的最优条件可以通过拉格朗日乘子法得到。加入归一化约束 $\int q_j(z_j)dz_j = 1$，构造拉格朗日函数：

$$\mathcal{L} = \text{ELBO} + \lambda\left(\int q_j(z_j)dz_j - 1\right)$$

对 $q_j$ 求变分导数并令其为零，可以得到 $q_j^*$ 的闭式解。关键观察是：在平均场假设下，ELBO中与 $q_j$ 有关的项只有 $\mathbb{E}_{q_j}[\mathbb{E}_{q_{-j}}[\log p(x,z)]]$ 和 $-\mathbb{E}_{q_j}[\log q_j]$，最优化这两项给出了上述更新公式。

### CAVI算法

1. **初始化**：设定所有因子 $q_1, q_2, \ldots, q_M$ 的初始分布
2. **重复**：
   - 对 $j = 1, 2, \ldots, M$：
     - 计算 $\mathbb{E}_{q_{-j}}[\log p(x, z)]$
     - 更新 $q_j^*(z_j) \propto \exp(\mathbb{E}_{q_{-j}}[\log p(x, z)])$
   - 计算ELBO
3. **终止**：ELBO变化小于阈值或达到最大迭代次数

**CAVI的性质**：

- **单调性**：每步更新保证ELBO不减（因为每步都是条件最优）
- **收敛性**：因为ELBO有上界（$\leq \log p(x)$），单调递增且有上界的序列必然收敛
- **局部最优**：CAVI收敛到ELBO的局部最优，不保证全局最优
- **初始依赖**：不同的初始化可能收敛到不同的局部最优

### 一个具体例子：高斯-高斯模型

考虑最简单的共轭模型：

- 先验：$p(z) = \mathcal{N}(0, \sigma_0^2)$
- 似然：$p(x|z) = \mathcal{N}(z, \sigma^2)$（单个观测）

后验有闭式解：$p(z|x) = \mathcal{N}(\mu_{\text{post}}, \sigma_{\text{post}}^2)$，其中：

$$\mu_{\text{post}} = \frac{\sigma^2}{\sigma_0^2 + \sigma^2} \cdot 0 + \frac{\sigma_0^2}{\sigma_0^2 + \sigma^2} \cdot x = \frac{\sigma_0^2}{\sigma_0^2 + \sigma^2} x$$

$$\sigma_{\text{post}}^2 = \frac{\sigma_0^2 \sigma^2}{\sigma_0^2 + \sigma^2}$$

在这个简单模型中，$z$ 是一维的（平均场假设自动满足，无需因子化），变分推断的最优 $q^*$ 恰好等于真实后验——变分间隙为零。

当模型变得更复杂时（多个潜变量、非共轭结构），平均场近似开始产生非零的变分间隙，CAVI收敛到的 $q^*$ 不再等于真实后验。

## 实验 8.3-1：CAVI算法与平均场近似的局限

实验 `8.3-1.py` 通过一个对称双峰后验模型，实现 CAVI 算法并直观展示平均场近似的核心局限：单高斯变分族无法拟合多模态后验。

### 实验场景

考虑一个对称双峰后验分布：

- **先验**：$p(z) = 0.5 \cdot \mathcal{N}(-2, 1) + 0.5 \cdot \mathcal{N}(2, 1)$（对称双峰）
- **似然**：$p(x|z) = \mathcal{N}(x; z, 1^2)$
- **观测值**：$x = 0$（恰好位于两峰中间）

解析计算可得真实后验：
$$p(z|x=0) = 0.5 \cdot \mathcal{N}(-1.0, 0.71^2) + 0.5 \cdot \mathcal{N}(1.0, 0.71^2)$$

**关键设计**：观测值 $x=0$ 位于两峰中间，使得真实后验仍为对称双峰（两峰权重均为 0.5），而非像 8.2 节那样偏向某一峰。这**最大化**了平均场近似的困难——单高斯必须"同时覆盖两个等权峰"，无法选择锁定其中一个。

### 实验目的

1. **实现 CAVI 算法**：在单变量情形下，CAVI 退化为交替优化 $\mu_q$ 和 $\sigma_q$
2. **验证 CAVI 的单调性**：ELBO 在每步迭代后单调递增
3. **展示平均场的局限**：单高斯 $q^*$ 无法拟合对称双峰后验——变分间隙必然大于零
4. **理解间隙来源**：变分间隙来自变分族的表达能力限制，而非优化失败

### 实验输入

| 参数 | 设置 |
|------|------|
| 先验分布 | 对称双峰：$0.5 \cdot \mathcal{N}(-2, 1) + 0.5 \cdot \mathcal{N}(2, 1)$ |
| 观测噪声 | $\sigma_{\text{obs}} = 1.0$ |
| 观测值 | $x = 0$（两峰中间） |
| 变分族 | 单高斯 $q(z) = \mathcal{N}(\mu_q, \sigma_q^2)$ |
| CAVI 迭代 | 20 轮，每轮交替优化 $\mu_q$ 和 $\sigma_q$ |
| 初始值 | $\mu_q = 0$（先验均值），$\sigma_q = 1$ |

### 预期结果

- **CAVI 收敛**：ELBO 单调递增，最终收敛到局部最优
- **变分间隙 > 0**：最优 ELBO < $\log p(x)$，间隙必然存在
- **单高斯锁定中间**：$q^*$ 的均值 $\mu^*$ 位于两峰中间（约 $\mu^* \approx 0$），而非锁定某一峰
- **双峰被"抹平"**：真实后验的双峰结构被单高斯近似为一个宽峰

---

#### 核心洞见

实验揭示了平均场近似的本质局限：

1. **CAVI 确实收敛**：ELBO 单调递增，参数稳定——优化没有失败
2. **间隙来自表达能力限制**：变分族 $\mathcal{Q} = \{\mathcal{N}(\mu, \sigma^2)\}$ 只包含单峰分布，无法表达双峰结构
3. **间隙 ≠ 优化失败**：即使优化到最优 $q^*$，间隙仍存在——这是变分族的"先天"限制

**缩小间隙的方法**（8.3节已列出）：
- 扩大变分族：使用混合高斯 $q(z) = \sum_k w_k \mathcal{N}(\mu_k, \sigma_k^2)$ 可拟合双峰
- 结构化变分：部分因子化，保留部分变量间的相关性
- 归一化流：通过可逆变换将简单分布变为复杂多模态分布

## 变分间隙

8.2节的KL散度分解给出了变分间隙的精确定义：

$$\text{Gap} = \log p(x) - \text{ELBO}(q) = \text{KL}(q(z) \| p(z|x))$$

**变分间隙的性质**：

- **非负性**：$\text{Gap} \geq 0$（因为KL散度非负）
- **零间隙** ⟺ $q = p(z|x)$（a.e.）
- **正间隙** ⟺ $q$ 对后验的近似有偏差
- 间隙越大，近似质量越差

**实践中无法直接计算间隙**：因为 $\log p(x)$ 本身不可计算（这正是变分推断要绕开的困难）。但可以监控ELBO的变化来判断收敛——如果ELBO不再增长，说明CAVI已经收敛到（局部）最优。

**平均场近似的间隙通常不为零**：因为独立性假设限制了表达能力。缩小间隙的方法包括：

1. **扩大变分族**：从完全因子化到部分因子化（结构化变分），或使用混合分布（更丰富）
2. **增加潜变量维度**：更多的潜变量意味着更灵活的表示
3. **放松独立性假设**：允许部分变量相关
4. **使用归一化流**：通过可逆变换将简单分布变为复杂分布（第9章将涉及）

## 变分推断 vs MCMC：方法对比

| 特性 | 变分推断 | MCMC |
|---|---|---|
| 目标 | 逼近后验（有偏） | 从后验采样（渐近无偏） |
| 优化 | 最大化ELBO | 无需显式目标函数 |
| 收敛判断 | ELBO不再增长 | 自相关、ESS、Gelman-Rubin |
| 计算速度 | 快（优化问题） | 慢（采样问题） |
| 近似质量 | 受变分族限制 | 渐近精确 |
| 扩展性 | 容易扩展到大模型 | 难以扩展到大模型 |
| 多模态 | 平均场只能近似单模态 | 可以覆盖多模态 |
| 不确定性 | 可能欠估计不确定性 | 渐近精确的不确定性 |

**变分推断牺牲了精确性换取了效率**。在深度学习时代，变分推断的可扩展性使其更受欢迎——MCMC难以扩展到具有数百万参数的神经网络，而变分推断可以通过梯度下降高效优化。

**MCMC牺牲了效率换取了精确性**。在需要精确不确定性量化的场景（如医学影像），MCMC仍然是金标准。

两者的互补性在扩散模型中得到了统一：扩散模型的训练目标来自变分路径（ELBO/VLB），但采样过程来自采样路径（逆向SDE/Langevin）——**训练用变分，采样用MCMC**。

**来源**：Blei et al. (2017); Bishop PRML Ch10; Zhang et al. (2019) Advances in Variational Inference

变分推断将后验近似转化为优化问题，ELBO是其目标函数。而ELBO的"重建+正则"分解与第2章的"先验=正则化"框架遥相呼应，这种呼应并非巧合，而是概率推断与优化正则化之间的深层统一。
