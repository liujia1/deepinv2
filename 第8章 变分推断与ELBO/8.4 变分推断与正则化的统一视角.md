# 8.4 变分推断与正则化的统一视角

> 场景开场：你大概有过这种体验——第 2 章我们刚说"先验 = 正则化"，MAP 就是"数据项 + 正则项"的最小化。这节一冒出 ELBO 的"重建 + KL 正则"，你心里可能"咯噔"一下：这俩长得也太像了吧？不是巧合。这一节我们把这层关系坐实：正则化不是工程师随意添加的技巧，它是概率模型"积分掉潜变量"后自然掉出来的东西。同时，上一节那道最亮的 aha——零强迫 vs 零避免——会在实验里变成你可以亲眼看见的两条曲线。

## 1. ELBO = 重建项 + KL 正则项（再贴一次脸）

先把 8.2 的"重建+正则"形式搬过来：

$$\text{ELBO} = \underbrace{\mathbb{E}_{q(z)}[\log p(x|z)]}_{\text{重建项}} - \underbrace{\text{KL}(q(z) \| p(z))}_{\text{KL正则项}}$$

两项各有大白话：

- **重建项** $\mathbb{E}_q[\log p(x|z)]$：从 $q$ 采 $z$，用 $p(x|z)$ 重建 $x$ 的对数似然。越大，$z$ 带的信息越足。若 $p(x|z)=\mathcal{N}(x; f_\theta(z), \sigma^2 I)$，重建项就是 $-\frac{1}{2\sigma^2}\mathbb{E}_q[\|x-f_\theta(z)\|^2]$（负的均方误差，MSE）；
- **KL 正则项** $-\text{KL}(q\|p)$：$q$ 偏离先验 $p(z)$ 的惩罚项，越小说明 $q$ 越贴先验。

张力依旧：重建太猛 → 过拟合（过分解偏离先验）；正则太猛 → 欠拟合（$q$ 退化成先验，啥也没学到）。这和第 3 章 MAP 的"数据项 vs 正则项"是同一出戏——因为它们有共同的数学根。从更深层次看，这条对应正是"先验 = 结构化知识"的又一次现身：第 2 章说先验是正则项的分身，这一节则说明把先验"摊进"变分框架之后，它仍然以 KL 项的形式掌管着近似后验别跑偏。

## 实验 8.4-2：ELBO = 重建项 + KL 正则项的权衡

实验 `8.4-2.py` 通过扫描不同变分分布参数，定量验证 ELBO 的"重建+正则"分解，展示重建项与 KL 正则项之间的权衡关系。

### 实验场景

使用与 8.2 节相同的模型：

- **先验**：$p(z) = 0.3 \cdot \mathcal{N}(-2, 1) + 0.7 \cdot \mathcal{N}(1, 1)$
- **似然**：$p(x|z) = \mathcal{N}(x; z, 0.5^2)$
- **观测值**：$x = 0.5$
- **证据**：$\log p(x) \approx -1.45$

### 实验目的

1. **验证 ELBO 分解**：$\text{ELBO} = \mathbb{E}_q[\log p(x|z)] - \text{KL}(q \| p(z))$，两项之和等于直接计算的 ELBO
2. **扫描变分参数**：观察重建项和 KL 正则项随 $\mu_q$ 和 $\sigma_q$ 的变化规律
3. **定量验证变分间隙**：优化得到最优 $q^*$，验证 $\text{ELBO}^* < \log p(x)$（变分下界性质）
4. **理解重建-正则权衡**：当 $\mu_q$ 接近观测值 $x$ 时重建项最大，但 KL 正则项随之增加——两者存在张力

### 实验输入

| 参数 | 设置 |
|------|------|
| 先验分布 | 双峰高斯混合：$0.3 \cdot \mathcal{N}(-2, 1) + 0.7 \cdot \mathcal{N}(1, 1)$ |
| 观测噪声 | $\sigma_{\text{obs}} = 0.5$ |
| 观测值 | $x = 0.5$ |
| 变分族 | 单高斯 $q(z) = \mathcal{N}(\mu_q, \sigma_q^2)$ |
| 扫描范围 | $\mu_q \in [-3, 3]$，$\sigma_q \in [0.3, 2.0]$ |
| 公共随机数样本 | $N = 200000$（用于消除 MC 噪声，保证 $\text{recon} - \text{KL} \equiv \text{ELBO}$） |

### 预期结果

- **重建项随 $\mu_q$ 变化**：当 $\mu_q \approx x = 0.5$ 时重建项最大（$z$ 接近观测值）
- **KL 正则项随 $q$ 变化**：当 $q$ 偏离先验 $p(z)$ 时 KL 项增大
- **最优 $q^*$**：通过优化找到 ELBO 最大点，验证 $\text{ELBO}^* \leq \log p(x)$
- **变分间隙 > 0**：单高斯无法拟合双峰后验，间隙必然存在

#### 核心洞见

实验验证了 ELBO 与 MAP 估计的结构对应：

| 变分推断（ELBO） | MAP 估计 |
|----------------|---------|
| $\mathbb{E}_q[\log p(x|z)]$（重建项） | $-\ln p(y|x)$（数据项） |
| $-\text{KL}(q \| p(z))$（KL 正则项） | $-\ln p(x) = \lambda R(x)$（正则项） |
| $\max_q \text{ELBO}$（分布估计） | $\min_x [-\ln p(x|y)]$（点估计） |

**关键区别**：
- 变分推断优化整个分布 $q$（保留不确定性信息）
- MAP 估计只优化点 $x^*$（丢弃分布信息）
- 当 $q$ 退化为 $\delta$ 函数时，ELBO 退化为 MAP 目标——**确定性正则化是变分推断的退化形式**

## 2. 回顾第 2 章：先验 = 正则化

第 2 章建立了后验负对数的分解：

$$-\ln p(x|y) = -\underbrace{\ln p(y|x)}_{\text{似然项}} - \underbrace{\ln p(x)}_{\text{先验项}} + \text{const}$$

MAP 最大化后验等价于最小化：

$$\hat{x}_{\text{MAP}} = \arg\min_x \left[-\ln p(y|x) - \ln p(x)\right] = \arg\min_x \left[\underbrace{\frac{1}{2\sigma^2}\|y - Ax\|^2}_{\text{数据项}} + \underbrace{\lambda R(x)}_{\text{正则项}}\right]$$

对应表（第 2 章已建）：

| 概率框架 | 优化框架 |
|---|---|
| $-\ln p(y\|x)$（负对数似然） | $\frac{1}{2\sigma^2}\|y-Ax\|^2$（数据保真项） |
| $-\ln p(x)$（负对数先验） | $\lambda R(x)$（正则项） |
| 似然 → 数据项 | 先验 → 正则项 |

把 MAP 的"数据+正则"和 ELBO 的"重建+正则"摆一起：

$$\text{MAP}:\quad \min_x \left[\underbrace{-\ln p(y|x)}_{\text{数据项}} + \underbrace{\lambda R(x)}_{\text{正则项}}\right]$$

$$\text{ELBO}:\quad \max_q \left[\underbrace{\mathbb{E}_q[\log p(x|z)]}_{\text{重建项}} - \underbrace{\text{KL}(q\|p)}_{\text{正则项}}\right]$$

**结构一模一样**：一项驱动数据拟合，一项约束解的空间。符号约定不同（$x,y$ 互换成 $x,z$）而已，数学骨架完全对偶。

## 3. 两层对应关系：从点估计到分布估计

概率推断和优化正则化之间有两层对应：

**第一层：点估计 vs 分布估计**
- MAP（第 3 章）：$\min_x[-\ln p(x|y)]$ → 给你**一个点**；
- 变分推断：$\max_q \text{ELBO}(q)$ → 给你**一整个分布**。

MAP 是变分推断的**退化特例**：当变分族只允许 $\delta$ 函数（只在一点有质量的点分布），$q(z)=\delta(z-z_0)$，ELBO 退化成：

$$\text{ELBO}(\delta_{z_0}) = \log p(x,z_0) = \log p(x|z_0) + \log p(z_0)$$

对 $z_0$ 最大化它就是 MAP。（这里熵项是一个与 $z_0$ 无关的常数，不影响极大化位置。）所以**当 $q$ 不允许有不确定性时，变分推断 = MAP**。这也解释了 MAP 的根本局限（第 3 章）：它把后验的不确定性整个丢掉了；变分推断保留 $q$，也就保留了（近似的）不确定性。

从更深层次看，这就是"后验不确定性的保留相对 MAP"这一主题的精确表述：MAP 是变分族退化成"一条没有宽度的直线"时的特例，而变分推断坚持给 $q$ 留出宽度的余地——正是这条宽度，承载了本书反复强调的不确定性价值。

**第二层：确定性正则 vs 概率正则**
- 确定性正则（第 3 章）：$\lambda R(x)$——手工设计，$\lambda$ 要调参；
- 概率正则（变分推断）：$\text{KL}(q\|p)$——从模型 $p(x,z)$ 自动推出，不用手选。

概率框架的好处：正则项不是随意设定的，是模型的自然结果；正则强度由先验集中度自动定；还附赠不确定性量化。确定性正则的好处：不用指定概率模型，直接优化，解释直观（如 TV 正则="图像应分段光滑"）。

## 4. 前向 KL vs 逆向 KL：零避免与零强迫（实验见证）

上一节 8.3 我们用直觉拆过这道最亮的 aha。这里用实验把它变成你可以亲眼看见的两条曲线。KL 散度**不对称**，这导致两种截然不同的近似模式：

**前向 KL（KL($p\|q$）— 零避免）**：
$$\text{KL}(p \| q) = \mathbb{E}_{p(x)}\left[\log \frac{p(x)}{q(x)}\right]$$
$q$ 在 $p>0$ 处不能为零（否则 $\log(p/q)\to\infty$）。倾向让 $q$ **覆盖** $p$ 所有模态（均值寻求，mean-seeking）——像"广播"，别漏了任何听众。

**逆向 KL（KL($q\|p$）— 零强迫）**：
$$\text{KL}(q \| p) = \mathbb{E}_{q(x)}\left[\log \frac{q(x)}{p(x)}\right]$$
$q$ 在 $p=0$ 处不能有质量。倾向让 $q$ **锁住** $p$ 的一个模态（模态寻求，mode-seeking）——像"狙击"，瞄准一个目标，忽略其余。

变分推断选**逆向 KL**，原因有二：
1. **计算可行性**：最小化逆向 KL 只需从 $q$ 采样（ELBO 里的 $\mathbb{E}_q[\cdot]$），不用从真后验 $p(z|x)$ 采样——后者正是我们算不出的目标！
2. **模型正确性**：逆向 KL 保证 $q$ 不在真后验为零处乱放质量，不会给出"后验认为不可能"的解。

代价：多模态后验下，变分近似只抓一个峰（遗漏其他合理解）。

```
前向KL最小化 (KL(p||q)):           逆向KL最小化 (KL(q||p)):
                                     
  p(x) (真实分布,双峰)               p(x) (真实分布,双峰)
   ╱╲      ╱╲                        ╱╲      ╱╲
  ╱  ╲    ╱  ╲                      ╱  ╲    ╱  ╲
 ╱    ╲  ╱    ╲                    ╱    ╲  ╱    ╲
╱      ╲╱      ╲                  ╱      ╲╱      ╲
────────────────────               ────────────────────
      ╱──────╲                      ╱╲
     ╱  q(x)  ╲                    ╱  ╲  q(x)
    ╱ (覆盖两峰) ╲                 ╱    ╲ (锁定一峰)
```

## 实验 8.4-1：前向 KL vs 逆向 KL——零避免与零强迫

实验 `8.4-1.py` 通过一个不对称双峰后验模型，数值对比前向 KL 和逆向 KL 的优化行为，揭示两种 KL 方向的截然不同的近似模式。

### 实验场景

构造一个不对称双峰后验分布：

$$p(z) = 0.35 \cdot \mathcal{N}(-2.5, 0.6^2) + 0.65 \cdot \mathcal{N}(2.0, 0.6^2)$$

**关键设计**：
- 左峰权重 35%，右峰权重 65%（不对称）
- 两峰相距 4.5（约 7.5$\sigma$），明显分离
- 逆向 KL 会倾向于锁定较重的峰（右峰），而前向 KL 会尝试覆盖两峰

### 实验目的

1. **对比前向 KL 与逆向 KL 的优化结果**：用单高斯 $q$ 近似双峰 $p$，观察两者的不同行为
2. **验证零避免/零强迫行为**：
   - 前向 KL(p||q)：零避免（zero-avoiding）——$q$ 必须覆盖 $p$ 的所有模态
   - 逆向 KL(q||p)：零强迫（zero-forcing）——$q$ 在 $p \approx 0$ 处必须也 $\approx 0$
3. **理解变分推断为何选择逆向 KL**：计算可行性——逆向 KL 只需要对 $q$ 求期望，前向 KL 需要对真实后验 $p$ 求期望（后者不可解）

### 实验输入

| 参数 | 设置 |
|------|------|
| 真实后验 | 不对称双峰：$0.35 \cdot \mathcal{N}(-2.5, 0.6^2) + 0.65 \cdot \mathcal{N}(2.0, 0.6^2)$ |
| 变分族 | 单高斯 $q(z) = \mathcal{N}(\mu, \sigma^2)$ |
| 优化方法 | Nelder-Mead，网格搜索 + 精修 |
| 初始点 | 前向 KL：从中心 $\mu=0$ 初始化；逆向 KL：从两峰附近分别初始化 |

### 预期结果

- **前向 KL(p||q) 的最优 $q$**：$\mu \approx 0$（两峰中间），$\sigma$ 较大（覆盖两峰）
- **逆向 KL(q||p) 的最优 $q$**：锁定单个峰（较重的右峰，$\mu \approx 2$），$\sigma$ 较小
- **KL 值对比**：前向 KL 的最优 KL 值通常小于逆向 KL（因为覆盖型近似更"全面"）

#### 核心对比

| 特性 | 前向 KL(p||q) | 逆向 KL(q||p) |
|------|--------------|--------------|
| 名称 | 零避免（zero-avoiding） | 零强迫（zero-forcing） |
| 行为 | 均值寻求（mean-seeking） | 模态寻求（mode-seeking） |
| 最优 $q$ | 覆盖所有模态（$\sigma$ 大） | 锁定单个模态（$\sigma$ 小） |
| 缺点 | 可能过度分散（每个峰都不精确） | 遗漏其他模态（只给出一个解） |
| 计算可行性 | **不可行**：需要对 $p$ 求期望 | **可行**：只需要对 $q$ 求期望 |

#### 为何变分推断选择逆向 KL

**根本原因：计算可行性**

- **前向 KL**：$\text{KL}(p || q) = \mathbb{E}_{p(z)}[\log \frac{p(z)}{q(z)}]$
  - 需要从真实后验 $p(z|x)$ 采样或求期望
  - 但 $p(z|x)$ 正是我们要近似的目标——无法直接采样或计算
- **逆向 KL**：$\text{KL}(q || p) = \mathbb{E}_{q(z)}[\log \frac{q(z)}{p(z|x)}]$
  - 只需要从变分分布 $q$ 采样或求期望
  - $q$ 是可控的（如 $\mathcal{N}(\mu, \sigma^2)$），可以直接采样
  - ELBO 的计算只涉及 $\mathbb{E}_q[\cdot]$，可以用蒙特卡洛估计

**附带效果**：逆向 KL 的模态寻求行为意味着变分近似只能捕获一个模态——对于多模态后验，这是一个局限（但也带来计算效率）。

从更深层次看，这个实验给"变分路径求快"下了清晰的注脚：它宁可锚定一个可信模态，也不铺开去覆盖所有可能——因为在逆问题里，一个"后验认为不可能的假解"比"少覆盖一个次要模态"危险得多。这正是零强迫选型背后的工程哲学。

## 5. Fenchel 共轭：统一背后的优化理论

ELBO 与正则化的统一不是比喻，它有坚实的优化根基——**Fenchel 共轭**（凸共轭，convex conjugate）。对函数 $f$，其凸共轭：

$$f^*(y) = \sup_x [\langle y, x \rangle - f(x)]$$

Fenchel-Young 不等式：对任意 $x,y$，$f(x)+f^*(y) \geq \langle x,y\rangle$。

把这套搬到 ELBO：$\log p(x)$ 可看作关于 $q$ 的凸泛函，ELBO 正是它的 Fenchel 对偶：

$$\log p(x) = \sup_q \text{ELBO}(q)$$

Fenchel-Young 不等式直接给出 $\log p(x)\geq \text{ELBO}(q)$——下界来自凸共轭；变分间隙对应 Fenchel-Young 间隙。正则化框架里 Tikhonov 的原始-对偶关系也由同一套 Fenchel 共轭给出。详见附录 8A。

从更深层次看，Fenchel 共轭这把尺子一量到底：它把"ELBO 是 $\log p(x)$ 下界"这件事，从"Jensen 不等式的一次巧合"提升为"凸对偶的普遍法则"——这正是 8A 附录要建立的根基，也是"统一不是比喻"的硬证据。

## 6. 变分正则化框架：同一个数学骨架

变分正则化统一框架（Benning）：

$$\min_u \mathcal{D}(Au, f^\delta) + \alpha \mathcal{R}(u)$$

| 优化框架 | 概率框架 |
|---|---|
| $\mathcal{D}(Au, f^\delta)$（数据保真） | $-\ln p(y\|x)$（负对数似然） |
| $\mathcal{R}(u)$（正则项） | $-\ln p(x)$（负对数先验） |
| $\alpha$（正则参数） | 噪声/先验方差比 |
| 原始问题 | MAP 估计 |
| 对偶问题 | 变分下界 |

ELBO 给出了它的"分布版本"——不优化点 $x^*$，优化整个分布 $q$。当 $q$ 退化成 $\delta$，ELBO 退化为 MAP——**确定性正则化是变分推断的退化形式**。

## 7. 统一视角的意义

1. **正则化不是 trick**：选正则项 = 选先验，选 $\lambda$ = 选先验强度（第 2 章已建）；
2. **变分推断是正则化的升级版**：点→分布，确定性正则→概率正则，单解→不确定性量化；
3. **两条路径汇合是必然**：采样路径从概率走向优化（MAP→PnP），变分路径从优化走向概率（ELBO→VAE）。第 12 章 Score ≡ ELBO 的统一，是数学对称性的必然，不是巧合。

这一转变意味着，第 2 章学过的"数据 + 正则"不再只是工程师的训练配方，而是一张能同时装下 MAP 与 VI 两套方案的家族脸谱：同一条"保真 + 约束"的骨架，只是把"解"从点换成分布、把"约束"从手调的函数换成从先验里长出的 KL。
