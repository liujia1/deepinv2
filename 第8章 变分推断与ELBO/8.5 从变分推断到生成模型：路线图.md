# 8.5 从变分推断到生成模型：路线图

> 场景开场：前面四节，变分推断一直是个"推断工具"——拿到数据 $x$，用 $q$ 去近似后验 $p(z|x)$。可你想过没：如果每来一张新图，都要从头优化一遍 $q$，那有 100 万张图怎么办？这节我们请出"摊推断"这个加速器，让变分推断脱胎换骨，变成能训练生成模型的框架——这正是 VAE 的胚胎，也是整条变分路径通向扩散模型的入口。

## 1. 逐样本推断 vs 摊推断：把优化"摊销"掉

8.3 节的 CAVI 有个致命的可扩展性短板：**对每个数据点 $x_i$，要独立优化一个 $q_i(z)$**。

数据集有 $N$ 个样本，CAVI 就要维护 $N$ 个独立分布，每个都迭代好多轮。ImageNet 百万级数据？不可想象。

**摊推断**（Amortized Inference）的招数很巧：与其存 $N$ 个 $q_i$，不如训练**一个参数化网络** $q_\phi(z|x)$，输入 $x$，直接吐出近似后验的参数（如均值、方差）。网络的参数 $\phi$ 在全部数据上共享——等于把 $N$ 次优化的代价"摊销"到一次网络训练里。

>"摊"（amortized）就是"分摊"的意思。训练完，对没见过的新图，一次前向传播（forward pass，数据从输入走到输出算一遍）就出近似后验。

| 特性 | 逐样本推断（CAVI） | 摊推断 |
|---|---|---|
| 变分分布 | $N$ 个独立 $q_i(z)$ | 一个共享网络 $q_\phi(z\|x)$ |
| 推断方式 | 对每个 $x_i$ 迭代优化 | 一次前向传播 |
| 参数量 | $N\times$ 每分布参数 | $\|\phi\|$（网络参数） |
| 泛化能力 | 无（只对训练数据有效） | 有（对新数据有效） |
| 近似质量 | 每点独立优化，可能更精 | 受网络容量限制 |
| 计算代价 | $O(N\times\text{迭代})$ | $O(\|\phi\|\times\text{训练步})$ |

摊推断的关键红利是**泛化**：训好的网络对新数据也能推断，而逐样本推断每来一个新点都得重头优化。

## 2. 用神经网络当变分族：Tran 的 FFVB 视角

（这一段接通 Tran《VB 实用教程》的分类法。）注意一个微妙但重要的事：摊推断里那个网络 $q_\phi(z|x)$，本质上就是把**整个变分分布 $q$ 直接参数化为一个神经网络**。这正是 Tran 把变分贝叶斯（VB）分成两类的分野：

- **MFVB（Mean-Field VB，平均场 VB）**：把 $q$ 写成因子乘积 $q(z)=\prod_j q_j(z_j)$，每个因子仍由少量标量参数描述，靠坐标上升（CAVI）一轮轮更新——也就是我们 8.3 节的主角；
- **FFVB（Fixed-Form VB，固定形式 VB）**：不再手动设计因子结构，而是**直接把一个固定形式（通常是高斯）的变分分布 $q_\lambda$ 的所有参数 $\lambda$（均值、协方差…）交给一个神经网络去输出**，再用随机优化去训练 $\lambda$。

换句话说，**摊推断 ≈ 用 FFVB 的思路，把"推断"也用神经网络学会**。Tran 强调：FFVB 用随机优化（配合 score-function 梯度或重参数化梯度）来训练 $\lambda$，的好处是——它不再要求每个模型都手推 CAVI 闭式更新，于是能扩展到贝叶斯深度学习这种"模型复杂到根本写不出闭式"的庞然大物。

这就和我们的主线严丝合缝了：第 9 章的 VAE 编码器，干的就是 FFVB 的活——它就是一个把 $x$ 映成近似后验参数 $(\mu_\phi(x),\sigma_\phi(x))$ 的神经网络。而让这个网络能端到端训练的钥匙，正是 8.3 节揭晓的**重参数化技巧**：$z=\mu_\phi(x)+\sigma_\phi(x)\cdot\epsilon$。

## 3. 生成模型的变分框架：三个零件

摊推断让 VI 从"工具"升级为"生成模型训练框架"。完整框架三件套：

### (1) 生成模型 $p_\theta(x, z) = p_\theta(x|z)p(z)$
- 先验 $p(z)$：通常标准高斯 $\mathcal{N}(0,I)$；
- 解码器 $p_\theta(x|z)$：给定潜变量生成数据，例 $p_\theta(x|z)=\mathcal{N}(x; f_\theta(z), \sigma^2 I)$，$f_\theta$ 是神经网络。

### (2) 推断模型 $q_\phi(z|x)$
- 编码器：给定数据推潜变量近似后验，例 $q_\phi(z|x)=\mathcal{N}(z; \mu_\phi(x), \text{diag}(\sigma_\phi^2(x)))$——**这就是一个 FFVB 网络**。

### (3) 目标函数 $\text{ELBO}(\theta,\phi)$
$$\max_{\theta, \phi}\; \mathbb{E}_{x \sim p_{\text{data}}}\big[\text{ELBO}(\theta,\phi;x)\big] = \max_{\theta, \phi}\; \mathbb{E}_{x}\Big[\mathbb{E}_{q_\phi(z|x)}[\log p_\theta(x|z)] - \text{KL}(q_\phi(z|x)\|p(z))\Big]$$

- 优化 $\theta$：解码器更会生成；
- 优化 $\phi$：编码器近似更好；
- 两者联合：生成与推断互相促进。

这正是 **VAE（变分自编码器）** 的训练框架——第 9 章细讲。还记得 8.3 节的重参数化吗？那里揭晓的 $z=\mu+\sigma\epsilon$ 就是让这个联合优化能用梯度下降跑起来的钥匙。

## 4. 逆问题 = 条件生成：视角的统一

到这里，一个深刻统一浮现了：

- **逆问题视角**（第 1–7 章）：给定观测 $y$，推断未知 $x$ —— 后验 $p(x|y)$；
- **生成模型视角**（本章起）：给定数据 $x$，推断潜变量 $z$ —— 后验 $p(z|x)$。

两者都是后验推断，只是"观测"和"未知"角色互换：

| | 逆问题 | 生成模型 |
|---|---|---|
| 观测 | $y$（测量） | $x$（图像） |
| 未知 | $x$（原图） | $z$（潜变量） |
| 正向模型 | $y=Ax+\epsilon$（物理已知） | $x=f_\theta(z)+\epsilon$（学习得到） |
| 后验 | $p(x\|y)\propto p(y\|x)p(x)$ | $p(z\|x)\propto p(x\|z)p(z)$ |

**洞见：生成模型 = 学习正向模型 + 变分推断。** 逆问题里 $A$ 已知，只推断 $x$；生成模型里 $f_\theta$ 未知，要同时学正向模型并推断 $z$。VAE 联合优化 $\theta$（学模型）和 $\phi$（推潜变量）。这正应了全书那句：**逆问题求解 = 条件图像生成**（第 13 章推到极致）。

## 5. 变分路径路线图：从 ELBO 走到扩散

```
ELBO(本章) → VAE(第9章) → 层级VAE(第10章) → 变分扩散(第11章) → Score≡ELBO(第12章)
     │            │              │                  │                 │
 基础框架    摊推断+重参数化  多层潜变量      连续极限(加噪/去噪)  与采样路径汇合
```

- **第 8 章（本章）**：ELBO——数学基石，后续全踩在它上；
- **第 9 章**：VAE——摊推断 + 重参数化（即 FFVB 网络 + 重参数化梯度），第一个实用深度变分生成模型；
- **第 10 章**：层级 VAE——多层潜变量，高斯编码器恰好是加噪过程；
- **第 11 章**：变分扩散——层级 VAE 取连续极限，训练目标 = 最大化 VLB；
- **第 12 章**：Score ≡ ELBO——DSM 损失 ≡ VLB，两条路径汇合。

两条路径并行图：

```
时间轴    采样路径                    变分路径
────────  ──────────                 ──────────
起点      贝叶斯后验(第1章)           贝叶斯后验(第1章)
方法      MCMC采样(第4章)            变分近似(本章)
加速      Langevin梯度(第5章)        摊推断网络(第9章)
学习      得分匹配(第6章)            VAE训练(第9章)
推广      扩散SDE(第7章)             层级VAE(第10章)
终点      扩散SDE视角(第7章)         变分扩散视角(第11章)
汇合      ──────── Score ≡ ELBO(第12章) ────────
```

**殊途同归不是巧合**：扩散模型既从采样路径继承了得分驱动采样的理论（SDE 视角），又从变分路径继承了优化对数似然的目标（VLB 视角）。两路互补，构成对扩散模型的完整理解——也为第 12 章的最大伏笔埋好。

**来源**：Kingma & Welling (2014); Rezende et al. (2014); Kingma et al. (2021) Variational Diffusion Models; Tran et al. (2021) A Tutorial on Variational Bayes; 第1-7章叙事

## 6. 动手感受一下：用 numpy 跑最小变分推断

下面这段代码**不依赖任何深度学习框架**，只用 numpy/scipy/matplotlib。它复现本章核心现象：**用一个高斯 $q_\phi=\mathcal{N}(\mu,\sigma^2)$ 去近似一个已知的一维后验**，通过梯度上升最大化 ELBO，画出 $q_\phi$ 一步步"长"成后验形状的过程。

模型设定（和正文玩具一致）：先验 $p(z)=\mathcal{N}(0,1)$，似然 $p(x|z)=\mathcal{N}(z,\sigma_{\text{obs}}^2)$，观测 $x$ 给定。后验是已知高斯（共轭），我们故意让 $q$ 从一个离谱的起点出发，看它如何被 ELBO 吸到真后验——呼应 8.3 节"完美匹配"的直觉。

```python
# ============================================================
# 最小变分推断 (Minimal VI)
# 目标：用高斯 q_φ = N(μ, σ²) 近似已知一维后验 p(z|x)
# 方法：梯度上升最大化 ELBO，画出 q_φ 贴合真后验的过程
# 依赖：numpy, scipy, matplotlib
# ============================================================
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

# ---------- 1. 设定模型（共轭高斯，后验有闭式）----------
sigma0 = 1.0          # 先验标准差  p(z) = N(0, sigma0^2)
sigma_obs = 0.7       # 观测噪声标准差  p(x|z) = N(z, sigma_obs^2)
x_obs = 0.8           # 一个观测值

# 后验闭式解（共轭高斯）：p(z|x) = N(mu_post, sigma_post^2)
sigma_post = 1.0 / np.sqrt(1.0/sigma0**2 + 1.0/sigma_obs**2)
mu_post = sigma_post**2 * (0.0/sigma0**2 + x_obs/sigma_obs**2)
print(f"真后验: μ={mu_post:.3f}, σ={sigma_post:.3f}")

# ---------- 2. ELBO 的解析形式（高斯族闭式）----------
# 对 q=N(μ,σ²)、先验=N(0,σ0²)、似然=N(z,σ_obs²)，ELBO 可解析写出：
#   ELBO = -0.5*log(2π σ_obs²) - 0.5*( (μ-x_obs)² + σ² )/σ_obs²   (重建项)
#          - 0.5*log(σ0²/σ²) - 0.5*( μ² + σ² )/σ0² + 0.5           ( -KL(q||p) )
def elbo(mu, sigma):
    sigma = max(sigma, 1e-6)  # 防止 log(0)
    recon = -0.5*np.log(2*np.pi*sigma_obs**2) - 0.5*((mu - x_obs)**2 + sigma**2)/sigma_obs**2
    kl    = 0.5*np.log(sigma0**2/sigma**2) - 0.5*(mu**2 + sigma**2)/sigma0**2 + 0.5
    return recon - kl

# ELBO 对 (μ, σ) 的梯度（解析，便于教学；深度学习中由自动微分完成）
def elbo_grad(mu, sigma):
    sigma = max(sigma, 1e-6)
    d_mu = -(mu - x_obs)/sigma_obs**2 - mu/sigma0**2          # 重建梯度 - KL梯度
    # 对 σ 的梯度（注意 σ 是标准差，不是方差；这里直接对 σ 求导）
    d_sigma = -sigma/sigma_obs**2 + (0.5/sigma) - sigma/sigma0**2
    return np.array([d_mu, d_sigma])

# ---------- 3. 梯度上升优化 q_φ ----------
# 故意从一个离谱的起点出发：μ=3, σ=2（和真后验风马牛不相及）
mu, sigma = 3.0, 2.0
lr = 0.05                       # 学习率
n_iter = 200
history = []                    # 记录每步的 (μ, σ, ELBO)
# 用重参数化技巧的思想：采样 z = μ + σ*ε（这里仅用于"蒙特卡洛感"演示，闭式已足够）
rng = np.random.default_rng(0)

for it in range(n_iter):
    g = elbo_grad(mu, sigma)
    # 梯度上升：参数沿梯度方向走
    mu += lr * g[0]
    sigma = max(sigma + lr * g[1], 1e-3)   # σ 必须为正
    history.append((mu, sigma, elbo(mu, sigma)))

# 打印起点与终点的 KL(q||真后验)，看"完美匹配"有多接近
def kl_gauss(m1, s1, m2, s2):
    # KL( N(m1,s1²) || N(m2,s2²) )
    return np.log(s2/s1) + (s1**2 + (m1-m2)**2)/(2*s2**2) - 0.5

kl_start = kl_gauss(3.0, 2.0, mu_post, sigma_post)
kl_end   = kl_gauss(mu, sigma, mu_post, sigma_post)
print(f"起点 KL(q||后验) ≈ {kl_start:.3f}")
print(f"终点 KL(q||后验) ≈ {kl_end:.4f}   (μ={mu:.3f}, σ={sigma:.3f})")
print(f"ELBO 终点 = {elbo(mu, sigma):.4f}, log p(x) ≈ {elbo(mu_post, sigma_post):.4f}")

# ---------- 4. 可视化：q_φ 如何一步步贴合真后验 ----------
z_grid = np.linspace(-3, 4, 400)
true_post = norm.pdf(z_grid, mu_post, sigma_post)

plt.figure(figsize=(9, 4.5))
# 子图1：选几个时刻的密度对比
plt.subplot(1, 2, 1)
plt.plot(z_grid, true_post, 'k-', lw=2, label='真后验 p(z|x)')
for idx in [0, 20, 60, 199]:
    mu_i, sig_i, _ = history[idx]
    q_i = norm.pdf(z_grid, mu_i, sig_i)
    plt.plot(z_grid, q_i, '--', label=f'q (iter={idx}, μ={mu_i:.2f})')
plt.title('q_φ 贴合真后验的过程')
plt.xlabel('z'); plt.ylabel('密度'); plt.legend(fontsize=8)

# 子图2：ELBO 随迭代上升
plt.subplot(1, 2, 2)
elbos = [h[2] for h in history]
plt.plot(elbos, 'b-')
plt.axhline(elbo(mu_post, sigma_post), color='r', ls=':', label='log p(x) (天花板)')
plt.title('ELBO 随梯度上升单调上升')
plt.xlabel('迭代'); plt.ylabel('ELBO'); plt.legend(fontsize=8)

plt.tight_layout()
plt.show()

# ---------- 5. 一句话收尾 ----------
# 你看到：从一个乱来的 q 出发，只要顺着 ELBO 的梯度走，
# q_φ 就被吸到真后验上（本例真后验恰在 q 族内，KL 从约 0.80 降到约 0.002）。
# 当变分族"够大"，变分推断是精确的——这正是 8.3 节"完美匹配"玩具的 numpy 版。
```

跑完你会看到两张图：左边 $q$ 的钟形曲线从歪掉的位置一路滑到真后验上；右边 ELBO 单调爬升，逼近红色虚线的天花板 $\log p(x)$。这正是本章全部思想的一张快照——**用优化替代采样，用 ELBO 当桥，把 $q$ 贴到后验上**。

## 7. 收尾：为什么这件事重要（zoom-out）

把整章塌缩成一句话：**变分推断把"算不出的后验推断"重写成"算得出的优化问题"，而 ELBO 是这座桥——它让我们既绕开归一化常数 $Z$，又不必慢慢抽样，还能保住整个分布。**

它和采样路径（第 4–7 章）不是对手，而是两条早晚汇合的路。本章是变分路径的起点：下一章 VAE 接上摊推断（FFVB 网络）与重参数化，把这条路一路修到扩散模型，最终在第 12 章与得分匹配殊途同归——**Score ≡ ELBO**。记住这个伏笔，后面每一章它都会回来找你。

**本章核心叙事一句话回顾**：分布打底（后验收不到）→ 贝叶合成（用 $q$ 近似后验）→ 变分直解（ELBO 把推断变优化）→ 难则变分或扩散（为第 9–12 章铺路）。
