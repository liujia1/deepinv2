# 8.5 从变分推断到生成模型：路线图

> **核心观点**：变分推断从"推断工具"升级为"生成模型训练框架"的关键一步是摊推断（Amortized Inference）——用参数化网络替代逐样本优化，使得一次前向传播即可完成推断。VAE = 摊推断 + 重参数化技巧，是变分路径的第一个里程碑。变分路径的完整路线图是：ELBO → VAE → 层级VAE → 变分扩散，每一步都是对ELBO框架的扩展和深化。

## 逐样本推断 vs 摊推断

8.3节介绍的CAVI算法有一个根本性的可扩展性问题：**对每个数据点 $x_i$，需要独立优化 $q_i(z)$**。

具体来说，如果数据集有 $N$ 个样本 $\{x_1, x_2, \ldots, x_N\}$，CAVI需要维护 $N$ 个独立的变分分布 $q_1(z), q_2(z), \ldots, q_N(z)$，每个都需要多轮迭代才能收敛。当 $N$ 很大时（如ImageNet的百万级数据），这是不可接受的。

**摊推断**（Amortized Inference）提供了一种优雅的解决方案：**用一个参数化网络 $q_\phi(z|x)$ 替代 $N$ 个独立优化**。

"摊"（amortized）的含义是"分摊"——网络的参数 $\phi$ 在所有数据点上共享，将 $N$ 次独立优化的代价"摊销"到网络训练中。一旦网络训练完毕，对任意新的数据点 $x$，只需一次前向传播即可得到近似后验 $q_\phi(z|x)$ 的参数（如均值和方差）。

### 逐样本推断 vs 摊推断的对比

| 特性 | 逐样本推断（CAVI） | 摊推断 |
|---|---|---|
| 变分分布 | $N$ 个独立的 $q_i(z)$ | 一个共享的网络 $q_\phi(z\|x)$ |
| 推断方式 | 对每个 $x_i$ 迭代优化 | 一次前向传播 |
| 参数量 | $N \times$ 每个分布的参数 | $\|\phi\|$（网络参数） |
| 泛化能力 | 无（只对训练数据有效） | 有（对新数据有效） |
| 近似质量 | 每个点独立优化，可能更精确 | 受网络容量限制 |
| 计算代价 | $O(N \times \text{迭代次数})$ | $O(\|\phi\| \times \text{训练步数})$ |

摊推断的关键优势是**泛化**：训练后的网络可以对训练集中未见过的数据推断后验，而逐样本推断对每个新数据点都需要重新优化。

## 生成模型的变分框架

摊推断使变分推断从"推断工具"升级为"生成模型训练框架"。完整的框架包含三个组件：

### 1. 生成模型 $p_\theta(x, z) = p_\theta(x|z)p(z)$

- 先验 $p(z)$：潜变量的先验分布，通常选为标准高斯 $\mathcal{N}(0, I)$
- 解码器 $p_\theta(x|z)$：给定潜变量生成数据的条件分布，由参数 $\theta$ 控制
- 例如：$p_\theta(x|z) = \mathcal{N}(x; f_\theta(z), \sigma^2 I)$，其中 $f_\theta$ 是神经网络

### 2. 推断模型 $q_\phi(z|x)$

- 编码器：给定数据推断潜变量的近似后验，由参数 $\phi$ 控制
- 例如：$q_\phi(z|x) = \mathcal{N}(z; \mu_\phi(x), \text{diag}(\sigma_\phi^2(x)))$，其中 $\mu_\phi$ 和 $\sigma_\phi$ 是神经网络

### 3. 目标函数 $\text{ELBO}(\theta, \phi)$

$$\max_{\theta, \phi} \mathbb{E}_{x \sim p_{\text{data}}}\left[\text{ELBO}(\theta, \phi; x)\right] = \max_{\theta, \phi} \mathbb{E}_{x \sim p_{\text{data}}}\left[\mathbb{E}_{q_\phi(z|x)}[\log p_\theta(x|z)] - \text{KL}(q_\phi(z|x) \| p(z))\right]$$

- 优化 $\theta$：提升生成模型的数据拟合能力（更好的解码器）
- 优化 $\phi$：提升推断模型的近似质量（更好的编码器）
- 两者联合优化：生成和推断相互促进

这正是**VAE**（Variational Autoencoder）的训练框架——第9章将详细展开。

## 从逆问题到生成模型：视角的统一

至此，我们可以看到一个深刻的统一：

- **逆问题视角**（第1-7章）：给定观测 $y$，推断未知 $x$——后验 $p(x|y)$
- **生成模型视角**（第8章起）：给定数据 $x$，推断潜变量 $z$——后验 $p(z|x)$

两者都是**后验推断问题**，只是"观测"和"未知"的角色不同：

| | 逆问题 | 生成模型 |
|---|---|---|
| 观测 | $y$（测量数据） | $x$（图像数据） |
| 未知 | $x$（原始图像） | $z$（潜变量） |
| 正向模型 | $y = Ax + \epsilon$（物理模型） | $x = f_\theta(z) + \epsilon$（学习模型） |
| 后验 | $p(x\|y) \propto p(y\|x)p(x)$ | $p(z\|x) \propto p(x\|z)p(z)$ |

关键差异：逆问题中的正向模型 $A$ 是已知的物理模型，生成模型中的正向模型 $f_\theta$ 是需要学习的。

**洞见：生成模型 = 学习正向模型 + 变分推断**。

- 第1-7章的逆问题框架中，正向模型 $A$ 已知，任务是推断 $x$
- 生成模型中，正向模型 $f_\theta$ 未知，需要同时学习正向模型和推断潜变量
- VAE同时优化 $\theta$（学习正向模型）和 $\phi$（推断潜变量）——联合学习

这种统一是全书核心论点的一个体现：**逆问题求解 = 条件图像生成**。第13章将把这个等式推到极致——条件扩散采样直接求解逆问题。

## 变分路径路线图

变分路径从ELBO出发，经过四步递进，最终到达扩散模型：

```
ELBO(本章) → VAE(第9章) → 层级VAE(第10章) → 变分扩散(第11章) → Score≡ELBO(第12章)
     │            │              │                  │                 │
 基础框架    摊推断+重参数化  多层潜变量      连续极限(加噪/去噪)  与采样路径汇合
```

### 第8章：ELBO——变分路径的数学基石

- 建立ELBO的推导和性质
- 变分推断 = 优化ELBO
- 变分推断与正则化的统一
- 本章完成了"地基"——后续所有内容都建立在ELBO之上

### 第9章：VAE——摊推断 + 重参数化

- 用参数化编码器 $q_\phi(z|x)$ 实现摊推断
- 用重参数化技巧 $z = \mu_\phi(x) + \sigma_\phi(x) \odot \epsilon$ 使梯度可以穿过随机节点
- 联合优化编码器 $\phi$ 和解码器 $\theta$
- VAE是第一个实用的深度变分生成模型

### 第10章：层级VAE——多层潜变量

- 从单层 $z$ 扩展到多层 $z_1, z_2, \ldots, z_L$
- 马尔可夫推断链：$q(z_L, \ldots, z_1|x) = q(z_L|z_{L-1}) \cdots q(z_1|x)$
- 层级ELBO推导：每一层引入自己的KL正则项
- **关键观察**：高斯编码器 $q(z_l|z_{l-1}) = \mathcal{N}(\sqrt{1-\beta_l}z_{l-1}, \beta_l I)$ 恰好是**加噪过程**

### 第11章：变分扩散——从VLB视角推导扩散模型

- 层级VAE的ELBO → 变分下界（VLB）
- VLB分解：$L_T + \sum L_{t-1} + L_0$
- 当 $L \to \infty$ 时，层级VAE → 连续扩散过程
- **核心结论**：扩散模型的训练目标 = 最大化VLB = 最大化ELBO

### 第12章：Score ≡ ELBO——殊途同归

- 采样路径的终点：DSM损失（第6章）
- 变分路径的终点：VLB（第11章）
- **核心定理**：DSM损失 ≡ VLB
- 两条路径推导出的扩散模型训练目标是相同的——殊途同归

## 采样路径与变分路径的并行发展

将两条路径放在一起，可以清晰地看到它们的并行和汇合：

```
时间轴    采样路径                    变分路径
────────  ──────────                 ──────────
起点      贝叶斯后验(第1章)           贝叶斯后验(第1章)
方法      MCMC采样(第4章)            变分近似(本章)
加速      Langevin梯度(第5章)        摊推断网络(第9章)
学习      得分匹配(第6章)            VAE训练(第9章)
推广      扩散SDE(第7章)             层级VAE(第10章)
终点      扩散SDE视角(第7章)         变分扩散视角(第11章)
汇合      ──────── Score ≡ ELBO(第12章) ────────
```

两条路径从同一个贝叶斯框架出发，独立发展，最终汇合。采样路径从逆问题的后验采样需求驱动，变分路径从生成建模的需求驱动。汇合点是扩散模型——两种推导给出相同的训练算法。

这种"殊途同归"不是巧合——它反映了一个深层事实：**扩散模型同时继承了两种路径的优势**。从采样路径，它继承了得分函数驱动采样的理论框架（SDE视角）；从变分路径，它继承了优化对数似然的训练目标（VLB视角）。两种视角互补，共同构成了对扩散模型的完整理解。

**来源**：Kingma & Welling (2014); Rezende et al. (2014); Kingma et al. (2021) Variational Diffusion Models; 第1-7章叙事

> **过渡**：本章建立了变分路径的数学基石——ELBO。第9章将在ELBO之上构建VAE，通过摊推断和重参数化技巧，将变分推断从理论工具转化为实用的生成模型。
