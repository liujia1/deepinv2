## Imaging inverse problems

We are interested in an unknown image $x ^ { \star } \in \mathbb { R } ^ { d }$ 

We measure $y \in \mathrm { Y }$ , related to $x ^ { \star }$ by some mathematical model. 

For example, in many imaging problems 

$$
y = A x ^ {\star} + w,
$$

for some operator A that is poorly conditioned or rank deficient, and an unknown perturbation or “noise” w. 

The recovery of $x ^ { \star }$ from y is usually not well posed. Additional information is required in order to deliver meaningful solutions. 

## Mathematical imaging frameworks

There are three main mathematical and computational frameworks for inference in imaging inverse problems: 

1 Applied analysis 

2 Bayesian statistics. 

3 Machine learning. 

These frameworks have complementary strengths and weaknesses. 

Our aim is a unifying framework of theory, methods, and algorithms that inherits the benefits of each approach. 

## The Bayesian statistical approach

Model $x ^ { \star }$ as a realisation of a r.v. x on $\mathbb { R } ^ { d }$ . Use the distribution of x to regularise the problem and promote expected properties. 

The observation y is a realisation of a r.v. $\left( \mathbb { y } | \mathbb { x } = x ^ { \star } \right)$ 

Inferences about $x ^ { \star }$ from y are derived from the joint distribution of (x, y) - specified via the decomposition $p ( x , y ) = p ( y | x ) p ( x )$ 

This determines the posterior distribution, with density 

$$
p (x | y) = \frac {p (y | x) p (x)}{\int_ {\mathbb {R} ^ {d}} p (y | \tilde {x}) p (\tilde {x}) \mathrm{d} \tilde {x}},
$$

which models our beliefs about x after observing y = y. 

## Bayesian computation

A simple algorithm to compute probabilities and expectations w.r.t. $p ( x | y )$ is the Unadjusted Langevin Algorithm (ULA), given by 

$$
X _ {k + 1} = X _ {k} + \delta_ {k} \nabla \log p (y | X _ {k}) + \delta_ {k} \nabla \log p (X _ {k}) + \sqrt {2 \delta_ {k}} Z _ {k + 1},
$$

where $Z _ { k + 1 } \sim { \mathcal { N } } ( 0 , \mathrm { I } _ { d } )$ and $( \delta _ { k } ) _ { k \in \mathbb { N } }$ is a sequence of step-sizes. 

The samples generated by ULA can be used to compute Monte Carlo estimates of $\hat { x } _ { M M S E }$ and perform advanced inferences. 

Recall that, given a set of samples $X _ { 1 } , \ldots , X _ { M }$ distributed according to $p ( x | y )$ , we approximate posterior expectations and probabilities 

$$
\bar {h} = \frac {1}{M} \sum_ {m = 1} ^ {M} h (X _ {m}) \rightarrow \operatorname{E} \{h (x) | y \}, \quad \mathrm{as} M \rightarrow \infty
$$

## Bayesian computation

A stochastic gradient descent (SGD) to compute $\hat { x } _ { M A P }$ is given by 

$$
X _ {k + 1} = X _ {k} + \delta_ {k} \nabla \log p (y | X _ {k}) + \delta_ {k} \nabla \log p (X _ {k}) + \delta_ {k} Z _ {k + 1},
$$

again, $Z _ { k + 1 } \sim { \mathcal { N } } ( 0 , \mathrm { I } _ { d } )$ and $( \delta _ { k } ) _ { k \in \mathbb { N } }$ is a sequence of step-sizes. 

Given a sequence of non-increasing weights $( \omega _ { k } ) _ { k \in \mathbb { N } }$ , we iteratively approximate $\hat { x } _ { M A P }$ by 

$$
\bar {x} _ {M A P} = \frac {\sum_ {k = 1} ^ {M} \omega_ {k} X _ {k}}{\sum_ {k = 1} ^ {M} \omega_ {k}}.
$$

ULA and SGD are remarkably well understood and provably convergent under easily verifiable conditions on $p ( x | y )$ 

## The SDE underpinning ULA and SGD

Recall that ULA and SGD arise from discrete-time approximations of the Langevin difusion process 

$$
\boldsymbol {X}: \quad \mathrm{d} \boldsymbol {X} _ {t} = \frac {1}{2} \nabla \log p (\boldsymbol {X} _ {t} | y) \mathrm{d} t + \mathrm{d} W _ {t}, \quad 0 \leq t \leq T, \quad \boldsymbol {X} (0) = x _ {0}.
$$

where W is the Brownian motion on $\mathbb { R } ^ { d }$ . 

When $x \mapsto p ( x | y ) \in { \mathcal { C } } ^ { 1 }$ with $x \mapsto \nabla$ log $p ( x | y )$ Lipschitz continuous, $X _ { t }$ converges exponentially fast to $p ( x | y )$ as $t  \infty$ 

ULA and SGD stem from a basic Euler approximations of X . 

We recommend to use an accelerated approximation of X for significantly faster convergence (see 10.1137/19M1283719). 

## Proximal ULA and SGD computation

When $U : x \mapsto - \log p ( x )$ is convex but not Lipschitz diferentiable (or has a poor Lipschitz constant), we use the proximal ULA and SGD: 

$$
X _ {k + 1} = X _ {k} + \delta_ {k} \nabla \log p (y | X _ {k}) + \frac {\delta_ {k}}{\lambda} \left(\operatorname{prox} _ {U} ^ {\lambda} (X _ {k}) - X _ {k}\right) + \sqrt {2 \delta_ {k}} Z _ {k + 1},
$$

$$
X _ {k + 1} = X _ {k} + \delta_ {k} \nabla \log p (y | X _ {k}) + \frac {\delta_ {k}}{\lambda} \left(\operatorname{prox} _ {U} ^ {\lambda} (X _ {k}) - X _ {k}\right) + \delta_ {k} Z _ {k + 1}.
$$

where instead of ∇ log $p ( x )$ we evaluate the proximal operator 

$$
\operatorname{prox} _ {U} ^ {\lambda}: x \mapsto \underset {z \in \mathbb {R} ^ {d}} {\operatorname{argmin}}   U (z) + \frac {1}{2 \lambda} \| z - x \| _ {2} ^ {2}.
$$

Proximal ULA and SGD target a regularised approximation of $p ( x | y )$ 

● $\lambda > 0$ controls an (asymptotic) bias vs. convergence speed trade-of. 

## The Plug & Play (PnP) approach

PnP methods stem from the observation that 

$$
\operatorname{prox} _ {U} ^ {\lambda}: x \mapsto \underset {x \in \mathbb {R} ^ {d}} {\operatorname{argmin}}   U (z) + \frac {1}{2 \lambda} \| z - x \| _ {2} ^ {2}
$$

can be viewed as a MAP denoiser to recover z from a noisy observation $x \sim \mathcal { N } ( z , \lambda I )$ , when z has marginal $p ( z ) \propto \exp \{ - U ( z ) \}$

## The Plug & Play (PnP) approach

Instead of specifying U explicitly, PnP strategies “plug” a state-of-the-art denoiser $D _ { \epsilon } : \mathbb { R } \mapsto \mathbb { R }$ in lieu of ∇ log $p ( x )$ or $\mathrm { p r o x } _ { U } ^ { \lambda } ( x )$ in an iterative sampling or optimisation. 

For example, in the context of ULA and SGD, one would consider 

$$
\mathrm{PnP-ULA}: X _ {k + 1} = X _ {k} + \delta_ {k} \nabla \log p (y | X _ {k}) + \frac {\delta_ {k}}{\epsilon} (D _ {\epsilon} (X _ {k}) - X _ {k}) + \sqrt {2 \delta_ {k}} Z _ {k + 1},
$$

and 

$$
\mathrm{PnP-SGD}: X _ {k + 1} = X _ {k} + \delta_ {k} \nabla \log p (y | X _ {k}) + \frac {\delta_ {k}}{\epsilon} (D _ {\epsilon} (X _ {k}) - X _ {k}) + \delta_ {k} Z _ {k + 1}.
$$

Given some training data $\{ x _ { i } ^ { \prime } \} _ { i = 1 } ^ { M }$ , training a network to approximate an optimal MSE denoiser can deliver remarkable results. Why?! 

## Neural networks for denoising

Consider a neural network $f _ { w } : \mathbb { R } \mapsto \mathbb { R }$ , parametrised by its weights and biases gathered in $w \in W$ , where W is some measurable space. 

Let $\{ x _ { i } ^ { \prime } \} _ { i = 1 } ^ { M }$ be a training sample from a distribution with density $p ( x )$ 

We generate $\{ y _ { i } ^ { \prime } \} _ { i = 1 } ^ { M }$ by contaminating $\{ x _ { i } ^ { \prime } \} _ { i = 1 } ^ { M }$ with Gaussian noise with mean zero and covariance ϵ<sup>I</sup>, i.e., $y _ { i } ^ { \prime } \sim \mathcal { N } ( x _ { i } ^ { \prime } , \epsilon \mathbb { I } )$ 

The optimal MSE denoiser to recover $\{ x _ { i } ^ { \prime } \} _ { i = 1 } ^ { M }$ from $\{ y _ { i } ^ { \prime } \} _ { i = 1 } ^ { M }$ is the Bayesian estimator $\operatorname { E } ( x | y )$ associated the prior $p ( x )$ 

During training, when w is set such that 

$$
w ^ {*} = \underset {w \in W} {\operatorname{argmin}} \sum_ {i = 1} ^ {M} \left\| f _ {w} (y _ {i} ^ {\prime}) - x _ {i} ^ {\prime} \right\| _ {2} ^ {2}
$$

the resulting network $f _ { w ^ { \ast } }$ approximates the operator $y \mapsto \operatorname { E } ( x | y )$ 

Our aim here is to formalise the Bayesian perspective on inference with PnP priors and explore foundational questions, e.g.: 

1 Under what conditions on $D _ { \epsilon }$ are Bayesian PnP models well-posed and amenable to eficient computation? When do the key quantities of interest exist and inherit the well-posed nature of the model? 

2 Can we guarantee the convergence of PnP-ULA and PnP-SGD under easily verifiable conditions, with non-asymptotic accuracy bounds? 

3 Are these Bayesian PnP methods and algorithms delivering solutions that are meaningful from a non-subjective point of view? 

We also present an alternative Bayesian strategy for inference with data-driven priors derived from generative models (e.g., VAEs, GANs, etc.).

## The oracle Bayesian model

We analyse Bayesian models with data-driven priors in an M-complete modelling framework: 

There exists a true - albeit unknown - marginal distribution for x and posterior distribution for $\big ( \mathbb { x } | \mathbb { y } = y \big )$ 

Basing inferences on these oracle models is theoretically optimal. 

We henceforth denote this optimal prior distribution by $\mu .$ . When $\mu$ admits a density w.r.t. the Leb. measure on $\mathbb { R } ^ { d }$ , we denote it by $p ^ { \star }$ 

In that case, the posterior for $x | y$ has density 

$$
p ^ {\star} (x | y) = \frac {p (y | x) p ^ {\star} (x)}{\int_ {\mathbb {R} ^ {d}} p (y | \tilde {x}) p ^ {\star} (\tilde {x}) \mathrm{d} \tilde {x}}.
$$

## The oracle Bayesian model

We analyse Bayesian models with data-driven priors in an M-complete modelling framework: 

In this conceptual construction, $\mu$ naturally depends on the application. 

In problems where there is training data $\{ x _ { i } ^ { \prime } \} _ { i = 1 } ^ { M }$ available, we regard $\{ x _ { i } ^ { \prime } \} _ { i = 1 } ^ { M }$ as a sample from $\mu$ 

For presentation simplicity, we henceforth assume that $p ^ { \star }$ exists. However, our results hold even this is not the case. 

This is important to provide robustness to situations where $p ^ { \star }$ is nearly degenerate or improper (e.g., manifold hypothesis). 

## The oracle Bayesian model

We cannot verify that $p ^ { \star }$ is proper and diferentiable, with $x \mapsto \nabla \log p ^ { \star } ( x | y )$ Lipschitz. Problematic for ULA and SGD 

Let $\epsilon > 0$ . To guarantee that gradient algorithms are sensible, we introduce the regularised approximation $\mu _ { \epsilon }$ of $\mu$ with density 

$$
p _ {\epsilon} ^ {\star} (x) = (2 \pi \epsilon) ^ {- d / 2} \int_ {\mathbb {R} ^ {d}} \exp \left[ - \| x - \tilde {x} \| _ {2} ^ {2} / (2 \epsilon) \right] p ^ {\star} (\tilde {x}) \mathrm{d} \tilde {x}.
$$

By involving the likelihood $p ( y | x )$ , we derive the regularised posterior 

$$
p _ {\epsilon} ^ {\star} (x | y) = \frac {p (y | x) p _ {\epsilon} ^ {\star} (x)}{\int_ {\mathbb {R} ^ {d}} p (y | \tilde {x}) p _ {\epsilon} ^ {\star} (\tilde {x}) \mathrm{d} \tilde {x}}.
$$

Laumont et al. (2021a) establishes that, under mild and easily verifiable conditions on $p ( y | x )$ , the following holds: 

1 The regularised densities $p _ { \epsilon } ^ { \star } ( x )$ and $p _ { \epsilon } ^ { \star } ( x | y )$ are proper and smooth, but not necessarily Lipschitz diferentiable. 

2 The approximation error w.r.t. the oracle models $p ^ { \star } ( x )$ and posterior $p ^ { \star } ( x | y )$ is controlled by ϵ and vanishes as $\epsilon \to 0$ 

Guaranteeing that $x \mapsto \nabla$ log $p _ { \epsilon } ^ { \star } ( x | y )$ is Lipschitz continuous requires an additional assumption. 

## The oracle MMSE denoiser

To study $\nabla$ log $p _ { \epsilon } ^ { \star } ( x | y )$ and rigorously derive PnP Bayesian methods, we introduce the oracle MMSE denoiser: 

$$
D _ {\epsilon} ^ {\star} (x) = (2 \pi \epsilon) ^ {- d / 2} \int_ {\mathbb {R} ^ {d}} \tilde {x} \exp [ - \| x - \tilde {x} \| ^ {2} / (2 \epsilon) ] p ^ {\star} (\tilde {x}) \mathrm{d} \tilde {x},
$$

to recover an image $x \sim \mu$ from a noisy observation $\boldsymbol { x } _ { \epsilon } \sim \mathcal { N } ( \boldsymbol { x } , \epsilon \mathbb { I } _ { d } )$ 

From Tweedie’s identity, the gradient 

$$
\epsilon \nabla \log p _ {\epsilon} ^ {\star} (x) = D _ {\epsilon} ^ {\star} (x) - x.
$$

Laumont et al. (2021a) establishes that ∇ log $p _ { \epsilon } ^ { \star } ( x )$ is Lipschitz when the denoiser $D _ { \epsilon } ^ { \star }$ is guaranteed to achieve a finite MSE. This is a natural assumption given that $D _ { \epsilon } ^ { \star }$ is the MMSE Bayesian estimator. 

## The oracle Bayesian model

Moreover, under mild assumptions on the likelihood $p ( y | x )$ , the posterior $p _ { \epsilon } ^ { \star } ( x | y )$ is well posed in the sense of Hadamard. 

This implies that key quantities computed from $p _ { \epsilon } ^ { \star } ( x | y )$ are stable w.r.t perturbations of y . 

We can then easily establish the convergence of gradient-based computation algorithms for $p _ { \epsilon } ^ { \star } ( x | y )$ based on oracle denoiser $D _ { \epsilon } ^ { \star }$

## PnP Bayesian computation algorithms

Generic denoisers $D _ { \epsilon }$ , such as neural networks, are not usually gradient mappings. 

As a result, PnP-ULA and PnP-SGD algorithms implemented with $D _ { \epsilon }$ are not related to gradient flows. This makes their analysis dificult. 

We focus on deep neural network denoisers that are, by construction, Lipschitz continuous, and which seek to approximate $D _ { \epsilon } ^ { \star }$ 

$D _ { \epsilon }$ ’s Lipschitz constant is controlled during training by spectral normalisation. 

We establish convergence results and characterise accuracy w.r.t. the oracle models - the key factor is how well $D _ { \epsilon }$ approximates $D _ { \epsilon } ^ { \star }$ 

## PnP Unadjusted Langevin Algorithm

First, Laumont et al. (2021a) establishes that $\mathsf { P n P \mathrm { - } U L A }$ below convergences geometrically fast to a neighbourhood of $p _ { \epsilon } ^ { \star } ( x | y )$ 

$$
\begin{array}{c} \text {PnP - ULA:} X _ {k + 1} = X _ {k} + \delta_ {k} \nabla \log p (y | X _ {k}) + \frac {\delta_ {k}}{\epsilon} (D _ {\epsilon} (X _ {k}) - X _ {k}) \\ + \frac {\delta_ {k}}{\lambda} (\Pi_ {\mathrm{C}} (X _ {k}) - X _ {k}) + \sqrt {2 \delta_ {k}} Z _ {k + 1}. \end{array}
$$

Π(⋅) is the projection operator, $\mathrm { ~ C ~ c ~ } \mathbb { R } ^ { d }$ is any large compact set, and λ controls the target’s far-tail behaviour. 

The accuracy depends on the magnitude of the error between $D _ { \epsilon } ^ { \star }$ and $D _ { \epsilon }$ within an $0 , R \mathrm { - } \ell _ { 2 }$ ball, as well as on the algorithm parameters. 

Under additional assumptions, we can establish convergence to a neighbourhood of $p ^ { \star } ( x | y )$ 

## PnP Stochastic Gradient Descent

Laumont et al. (2021b) establishes that any stable sequence 

$$
\mathrm{PnP-SGD}: X _ {k + 1} = X _ {k} + \delta_ {k} \nabla \log p (y | X _ {k}) + \frac {\delta_ {k}}{\epsilon} (D _ {\epsilon} (X _ {k}) - X _ {k}) + \delta_ {k} Z _ {k + 1},
$$

converges to a neighbourhood of the set of critical points 

$$
S = \left\{x: \nabla \log p _ {\epsilon} ^ {\star} (x | y) = 0\right) \}.
$$

Again, the accuracy depends on the magnitude of the error between $D _ { \epsilon } ^ { \star }$ and $D _ { \epsilon }$ , as well as on the algorithm parameters.

## Generative modelling

We now focus on an alternative to $\mathsf { P n P }$ Bayesian inference based on deep generative models (e.g., VAEs, GANs). Again, our aim is to explore foundational questions and demonstrate the approach: 

1 Again, let $\{ x _ { i } ^ { \prime } \} _ { i = 1 } ^ { M }$ be a training sample from the true prior $\mu .$ 

2 We adopt a manifold hypothesis and suppose that x takes values close to an unknown p-dimensional submanifold of $\mathbb { R } ^ { d }$ 

3 To estimate the manifold, we introduce a latent r.v. z on $\mathbb { R } ^ { p }$ , with $p \ll d$ , and a mapping $\nu _ { \theta } : \mathbb { R } ^ { p } \mapsto \mathbb { R } ^ { d }$ , such that the push-forward measure of $\mathbb { Z } \sim \mathcal { N } ( 0 , \mathrm { I } _ { p } )$ under $\nu _ { \theta }$ is close to $\{ x _ { i } ^ { \prime } \} _ { i = 1 } ^ { M }$ (in dist.). 

4 We implement $\nu _ { \theta }$ as a neural network. We can learn $\nu _ { \theta }$ from $\{ x _ { i } ^ { \prime } \} _ { i = 1 } ^ { M }$ by using, e.g., a VAE, a GAN, or a flow approach. We use VAEs.

## Posterior distributions for generative priors

With z and $\nu _ { \theta }$ , we have the likelihood $p ( y | z ) = p ( y | x = \nu _ { \theta } ( z ) )$ 

We use Bayes’ theorem to derive the posterior for $\mathbb { Z } | \mathbb { y } = y$ 

$$
p (z | y) = \frac {p (y | x = \nu_ {\theta} (z)) p (z)}{\int_ {\mathbb {R} ^ {p}} p (y | \tilde {z}) p (\tilde {z}) \mathrm{d} \tilde {z}},
$$

Pushing ${ \bigl ( } \mathbb { z } | \mathbb { y } = y { \bigr ) }$ under $\nu _ { \theta } ( z )$ leads to the posterior for $\big ( \mathbb { x } | \mathbb { y } = y \big )$ which supported on a manifold and does not have a density. 

This provides a diferent approximation to the oracle $p ^ { \star } ( x | y )$ 

Holden et al. (2022) establishes that ${ \bigl ( } \mathbb { z } | \mathbb { y } = y { \bigr ) }$ and $\big ( \mathbb { x } | \mathbb { y } = y \big )$ are well-posed in the sense of Hadamard and have finite moments.

## Conditional generative priors

Despite their success in computer vision, scaling generative models to large inference problems reliably is dificult because of mode collapse, spurious modes, or other sources of bias. 

To reduce the dificulty of the machine learning problem, we consider a conditional generative model $\mathbb { x } = \nu _ { \theta } ^ { u } ( \mathbb { z } ) , \mathbb { z } \sim \mathcal { N } ( 0 , \mathrm { I } _ { p } )$ , that models the distribution of x given some additional r.v. u. 

For this construction to be useful, u should have low uncertainty given y. 

## Conditional generative priors

For example, we let u denote a low resolution version of $\mathbb { X } ,$ , and implement $\nu _ { \theta } ^ { u }$ by using a normalising flow for image super-resolution. 

This leads to the model 

$$
p (z | y, u) = \frac {p (y | z , u) p (z)}{p (y | u)},
$$

with $p ( y | z , u ) = p ( y | x = \nu _ { \theta } ^ { u } ( z ) )$ and $\begin{array} { r } { p ( y | u ) = \int _ { \mathbb { R } ^ { p } } p ( y | \tilde { z } , u ) p ( \tilde { z } ) \mathrm { d } \tilde { z } . } \end{array}$ 

## Empirical Bayesian imaging with conditional generative priors

We accurately estimate $\boldsymbol { u } ^ { \star }$ from y by maximum marginal likelihood estimation: 

$$
\hat {u} = \underset {\mu} {\operatorname{argmax}} p _ {\theta} (y | u).
$$

Adopting an empirical Bayesian strategy, we perform inference on $\big ( \mathbb { x } \big | \mathbb { y } = y , \mathbb { u } = \hat { u } \big )$ by using 

$$
p (z | y, \hat {u}) = \frac {p (y | z , \hat {u}) p (z)}{p (y | \hat {u})},
$$

and pushing $\big ( \mathbb { z } \big | \mathbb { y } = y , \mathbb { u } = \hat { u } \big )$ to $\big ( \mathbb { x } \big | \mathbb { y } = y , \mathbb { u } = \hat { u } \big )$ ) by using $\nu _ { \theta } ^ { u }$ 

A simple algorithm to compute $\hat { \boldsymbol { u } }$ probabilities and expectations w.r.t. $p ( z | y , \hat { u } )$ is the Stochastic Approximation Proximal Gradient scheme 

$$
Z _ {k + 1} = Z _ {k} + \delta_ {k} \nabla_ {z} \log p (y | Z _ {k}, u _ {k}) + \delta_ {k} \nabla_ {z} \log p (Z _ {k}) + \sqrt {2 \delta_ {k}} Z _ {k + 1},
$$

and 

$$
u _ {k + 1} = \Pi_ {U} \left[ u _ {k} + \gamma_ {k} \nabla_ {u} \log p (Z _ {k + 1} | y, u _ {k}) \right],
$$

where $Z _ { k + 1 } \sim \mathcal { N } ( 0 , \mathrm { I } _ { d } ) , ( \delta _ { k } ) _ { k \in \mathbb { N } }$ and $( \gamma _ { k } ) _ { k \in \mathbb { N } }$ are sequences of step-sizes, and $\Pi _ { U }$ denotes the Euclidean projection onto the set of admissible values for u. 

This SAPG is reasonably well understood and provably convergent under easily verifiable conditions on $p ( z | y )$ . See, e.g., 

https://doi.org/10.1007/s11222-020-09986-y and 

https://doi.org/10.1137/20M1339829 for details.

## Conclusion

We have studied theory, methods, and algorithms for performing Bayesian inference with data-driven priors encoded by neural networks. 

We rooted our discussion in the Bayesian M-complete paradigm that views PnP models as approximations of a regularised oracle model. 

We have considered PnP and generative strategies and established that the Bayesian models involved are well-posed under mild assumptions on the likelihood. 

These conditions are satisfied by Gaussian linear observation models, for example. 

## Conclusion

We studied the PnP ULA and SGD algorithms and provided detailed convergence guarantees under easily verifiable and realistic conditions. 

The provided theory does not require the denoiser to be a maximally monotone operator, e.g., to be a gradient or proximal operator. 

We also studied the estimation error involved in using implementable PnP algorithms instead of the oracle model. 

Bayesian model with generative priors rely on MCMC computation on the latent space, and on automatic diferentiation to compute gradients. Standard ULA results apply.
