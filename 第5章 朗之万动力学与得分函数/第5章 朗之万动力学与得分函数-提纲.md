# 第5章 朗之万动力学与得分函数 — 提纲

> **章节定位**：承接第4章的ULA离散算法，走向连续时间视角——揭示Langevin SDE的数学结构，并引入全书的核心数学对象：**得分函数** $\nabla_x \log p(x)$。第4章告诉我们ULA = 梯度下降 + 噪声，但梯度 $\nabla\log p(x|y)$ 究竟是什么？它有什么几何含义？如何从数据中获取它？本章回答这三个问题：得分函数是概率分布的"方向场"，Tweedie等式将去噪器与得分函数桥接，MAP与MMSE的对偶性揭示近端算子与去噪器的深层联系，PnP框架将理论落地为工程实践，近似理论则为这一切提供收敛保证。本章是采样路径的关键枢纽——从"利用已知梯度采样"到"从数据中学习梯度"的转折点，为第6章的得分匹配和第7章的扩散模型铺平道路。

> **逆问题动机**：ULA要求后验梯度$\nabla\log p(x|y)$已知，但逆问题中的先验梯度$\nabla\log p(x)$通常不可计算（归一化常数$Z$未知）→ 需要从数据中学习得分函数 → 需要建立去噪器与得分函数的桥梁（Tweedie等式）→ 需要理论保证学习到的得分驱动的采样收敛。本章每一步的驱动力都是"得分函数不可直接计算"这一根本困难。

> **叙事主线**：ULA的连续极限：Langevin SDE(5.1) → 得分函数：Langevin的驱动力(5.2) → Tweedie等式：从去噪器提取得分(5.3) → MAP与MMSE的结构对偶：近端算子vs去噪器(5.4) → PnP框架：用去噪器替换先验梯度(5.5) → 近似理论与收敛保证(5.6)

## 5.0 本章导读：从离散迭代到连续动力学——得分函数的登场

第4章建立了后验采样的完整工具箱——从MH到ULA/MYULA，从Gibbs到ILA。ULA的核心递推式是

$$X_{m+1} = X_m + \delta\,\nabla\log p(X_m|y) + \sqrt{2\delta}\,Z_{m+1}$$

其中 $\nabla\log p(x|y)$ 是后验概率密度的对数梯度——**得分函数**。第4章将ULA视为Langevin扩散的Euler离散化，但回避了两个核心问题：Langevin SDE作为连续随机过程的数学结构是什么？得分函数如何获取？

本章从这两个问题出发，走一条"理解→获取→应用→保证"的路径：

**Langevin SDE的连续时间理论**（5.1）：ULA是Langevin扩散的离散近似——但Langevin扩散本身是什么？它为什么以后验分布为平稳分布？Fokker-Planck方程提供了精确的数学回答。从离散迭代到连续SDE，是从"算法"到"过程"的认知升级，也是理解后续扩散模型（第7章）的必要准备。

**得分函数：Langevin的驱动力**（5.2）：得分函数 $s(x) = \nabla_x \log p(x)$ 是概率分布的"方向场"——在每一点指向密度增长最快的方向。Langevin动力学用得分函数作漂移力，布朗运动作随机探索，两者平衡恰好收敛到目标分布。对于后验分布，得分函数分解为似然得分 + 先验得分——先验得分通常是瓶颈。

**Tweedie等式：从去噪器到得分函数**（5.3）：先验得分 $\nabla\log p(x)$ 无法直接计算，但Tweedie等式揭示了一个惊人的事实：噪声扰动分布的得分函数可以从未知分布的MMSE去噪器中提取——$\nabla\log p_\varepsilon(x) = (D_\varepsilon(x) - x)/\varepsilon$。这意味着：**有了一个好的去噪器，就有了得分函数**。这是连接去噪与采样的核心桥梁，也是全书从逆问题走向扩散模型的关键一步。

**MAP与MMSE的结构对偶性**（5.4）：近端算子是MAP估计的一步近似（Moreau包络的梯度），去噪器是MMSE估计的精确表达（软下卷积的梯度）。两者都是"从含噪观测中恢复信号"的策略，但一个走向众数，一个走向均值——这一对偶性深刻揭示了优化与采样的内在统一。

**PnP框架**（5.5）：将Tweedie等式和MAP/MMSE对偶性的洞见付诸实践——用学习到的去噪器 $D_\varepsilon$ 替换ULA中的先验梯度 $\nabla\log p(x)$，得到PnP-ULA算法。去噪器成为"隐式先验"——不需要显式指定先验分布的形式，只需要一个能去噪的函数。这是从显式先验到隐式先验的跨越，也是后续扩散模型的雏形。

**近似理论与收敛保证**（5.6）：PnP-ULA的收敛性依赖于去噪器对得分函数的近似质量。Moreau-Yoshida包络理论提供了近似密度的性质保证（真密度、对数凹、光滑），PnP收敛定理则将去噪器的Lipschitz性质与采样收敛联系起来——理论为实践保驾护航。

```
Langevin SDE(5.1) → 得分函数(5.2) → Tweedie等式(5.3) → MAP/MMSE对偶(5.4) → PnP框架(5.5) → 收敛保证(5.6)
```

本章结束时，读者将理解：Langevin动力学以得分函数为驱动力实现后验采样，而得分函数可以从去噪器中提取（Tweedie等式）。这一洞见将采样路径推到关键转折点——从"利用已知梯度采样"到"从数据中学习梯度"，这正是第6章得分匹配的出发点。而PnP框架中"去噪器即先验"的思想，将在第7章扩散模型中演化为"去噪网络即得分估计器"——**采样路径继续向扩散模型演化**。

## 5.1 从MCMC到Langevin SDE

**核心观点**：第4章的ULA是Langevin随机微分方程（SDE）的Euler-Maruyama离散化。本节从离散迭代走向连续极限，建立Langevin SDE的数学框架——它是后续扩散模型（第7章）的直接前身。Langevin SDE以得分函数为漂移力、布朗运动为随机探索，其平稳分布恰好是目标后验分布——Fokker-Planck方程给出严格证明。

- **从ULA递推到连续SDE**
  - ULA递推式回顾：$X_{m+1} = X_m + \delta\,\nabla\log p(X_m|y) + \sqrt{2\delta}\,Z_{m+1}$
  - 时间参数化：令 $\Delta t = \delta$，$t_m = m\delta$，$X(t_m) = X_m$
  - 当 $\delta \to 0$，Euler离散化的极限是Langevin SDE：
    $$dX_t = \nabla\log p(X_t|y)\,dt + \sqrt{2}\,dW_t$$
  - 漂移项 $\nabla\log p(x|y)\,dt$：确定性力，推向高概率区域
  - 扩散项 $\sqrt{2}\,dW_t$：随机探索，保证遍历性
  - **两种等价写法**
    - 势能形式：$dX_t = -\nabla U(X_t)\,dt + \sqrt{2}\,dW_t$，其中 $U(x) = -\log p(x|y)$
    - 得分形式：$dX_t = s(X_t|y)\,dt + \sqrt{2}\,dW_t$，其中 $s(x|y) = \nabla\log p(x|y)$
    - 两种写法等价，但视角不同：势能视角连接优化，得分视角连接生成模型

- **Langevin SDE的平稳分布：Fokker-Planck方程**
  - 问题：如何证明 $p(x|y)$ 确实是Langevin SDE的平稳分布？
  - Fokker-Planck方程：描述SDE驱动的概率密度的时间演化
    $$\frac{\partial \rho_t}{\partial t} = -\nabla\cdot[\nabla\log p(x|y)\,\rho_t] + \Delta\rho_t$$
  - 平稳条件：$\partial\rho_t/\partial t = 0$ → 验证 $\rho^* = p(x|y)$ 满足
  - 证明思路（详细推导见附录5A）：代入 $\rho^* = p(x|y)$，利用 $\nabla\cdot[p\nabla\log p] = \Delta p$，两项恰好抵消
  - 物理直觉：漂移力将粒子推向高密度区域，扩散力将粒子从高密度区域推开——两者在平稳态恰好平衡

- **Langevin扩散的指数收敛**
  - 强对数凹条件：若 $U(x) = -\log p(x|y)$ 是 $m$-强凸且 $L$-光滑
  - 收敛结果：$W_2(\rho_t, p) \leq C\,e^{-mt}\,W_2(\rho_0, p)$
  - 收敛速率由势能的强凸性决定——凸性越强，收敛越快
  - 几何解释：强凸性意味着势能面"碗状"，梯度指向底部（众数），粒子被强力拉回

- **从Langevin到ULA：离散化的代价**
  - Euler-Maruyama离散化引入的误差：离散步长 $\delta$ 越大，近似越差
  - 两种离散化策略：
    - ULA（无校正）：$O(\delta)$ 偏差，但每步计算简单
    - MALA（有校正）：ULA + MH接受/拒绝步，偏差消除但计算量翻倍
  - 步长选择的权衡：$\delta$ 小→偏差小但收敛慢；$\delta$ 大→偏差大但收敛快
  - 与第7章的预告：扩散模型通过多时间步噪声调度，巧妙解决了单步Langevin的步长困境

- **Langevin SDE与梯度流的联系**
  - 梯度流（Wasserstein空间）：$\partial_t \rho_t = \nabla\cdot(\rho_t\nabla U)$——纯漂移，收敛到众数
  - Langevin SDE：$\partial_t \rho_t = \nabla\cdot(\rho_t\nabla U) + \Delta\rho_t$——漂移+扩散，收敛到分布
  - 扩散项 $\Delta\rho_t$ 是Langevin对梯度流的关键补充——它使收敛目标从众数变为分布
  - 这一对比呼应第4章的核心洞见：优化算法 + 噪声 = 采样算法

**来源**：Pereyra L1 P40-50; Pock L2 P14; LectureNotes2020_v2 Sec 8.2; Risken (1996)

Langevin SDE以得分函数 $\nabla\log p(x|y)$ 为驱动力，但得分函数究竟是什么？它有什么几何含义？

## 5.2 得分函数：对数概率的梯度

**核心观点**：得分函数 $s(x) = \nabla_x \log p(x)$ 是概率分布的"方向场"——在每一点指向密度增长最快的方向，其模长表示增长的剧烈程度。Langevin动力学以得分函数为漂移力，使得粒子系统收敛到目标分布。对于逆问题的后验分布，得分函数可分解为似然得分与先验得分——先验得分是获取的瓶颈。

- **得分函数的定义**
  - 定义：$s(x) = \nabla_x \log p(x) = \frac{\nabla_x p(x)}{p(x)}$
  - 与概率梯度的关系：$\nabla p(x) = p(x)\,s(x)$
  - 得分函数不需要归一化常数：$\nabla\log p(x) = \nabla\log \tilde{p}(x)$（其中 $\tilde{p}(x) = Z\,p(x)$）——这是得分函数的核心优势

- **得分函数的几何含义**
  - 方向：$s(x)$ 指向 $p(x)$ 增长最快的方向
  - 模长：$\|s(x)\|$ 表示密度变化的剧烈程度——边界处模长大（陡峭），平坦区域模长小
  - 零点：$s(x) = 0$ 在 $p(x)$ 的驻点（包括众数/MAP）
  - 向量场可视化：得分函数在空间中形成一个向量场，Langevin动力学沿此向量场流动

- **得分函数与Langevin动力学的直觉**
  - Langevin SDE：$dX_t = s(X_t)\,dt + \sqrt{2}\,dW_t$
  - 漂移项 $s(X_t)\,dt$：沿得分方向"爬坡"——推向高概率区域
  - 扩散项 $\sqrt{2}\,dW_t$：随机"游走"——探索分布的形状
  - 平衡：得分力将粒子聚集在高密度区域，扩散力防止所有粒子坍缩到众数——两者的平衡产生目标分布
  - **得分函数与梯度下降的对比**
    - 梯度下降：沿 $-\nabla U(x)$ 方向走，$U(x) = -\log p(x)$→ 收敛到众数
    - Langevin：沿 $-\nabla U(x)$ 方向走 + 噪声 → 收敛到分布
    - 得分函数 $s(x) = -\nabla U(x)$：两者的驱动力相同，区别在于是否有噪声

- **后验得分函数的分解**
  - 贝叶斯公式：$p(x|y) = p(y|x)\,p(x)/p(y)$
  - 对数求导：
    $$s(x|y) = \nabla\log p(x|y) = \underbrace{\nabla\log p(y|x)}_{\text{似然得分}} + \underbrace{\nabla\log p(x)}_{\text{先验得分}}$$
  - 似然得分：由正向模型和噪声模型决定，通常可计算
    - 高斯似然：$\nabla\log p(y|x) = -\frac{1}{\sigma^2}A^T(Ax - y)$
  - 先验得分：$\nabla\log p(x)$——**问题的瓶颈**
    - 显式先验（高斯、TV）：可计算，但表达能力有限
    - 复杂先验（自然图像的分布）：$\nabla\log p(x)$ 无法直接计算，因为归一化常数 $Z = \int \exp(-R(x))\,dx$ 不可解
  - **归一化常数的困境**
    - 先验通常写成 $p(x) = \frac{1}{Z}\exp(-R(x))$，其中 $Z = \int \exp(-R(x))\,dx$
    - $\nabla\log p(x) = -\nabla R(x) - \nabla\log Z = -\nabla R(x)$——看似$Z$被消去
    - 但$\nabla R(x)$对复杂先验（如"看起来像自然图像"）仍不可计算——$R(x)$本身没有解析形式
    - 这正是需要从数据中学习得分函数的根本原因（→第6章）

- **噪声扰动分布的得分函数**
  - 关键观察：与其直接估计 $s(x) = \nabla\log p(x)$，不如估计噪声扰动后的得分 $s_\varepsilon(x) = \nabla\log p_\varepsilon(x)$
  - 定义：$p_\varepsilon(x) = \int p(x')\,\mathcal{N}(x|x', \varepsilon I)\,dx' = p * \mathcal{N}(0, \varepsilon I)$
  - 噪声扰动的好处：
    1. 光滑化：$p_\varepsilon \in C^\infty$，即使 $p$ 不光滑
    2. 覆盖低密度区域：$p_\varepsilon(x) > 0$ 处处成立，得分处处有定义
    3. 与去噪器天然联系：$p_\varepsilon$ 恰好是去噪问题的边际分布（→5.3节Tweedie等式）
  - 这一观察是得分匹配（第6章）和扩散模型（第7章）的出发点

**来源**：Pereyra L1 P58-60; Hyvärinen (2005); Song & Ermon (2019)

先验得分 $\nabla\log p(x)$ 通常不可直接计算，但噪声扰动后的得分 $\nabla\log p_\varepsilon(x)$ 却可以从去噪器中提取——Tweedie等式建立了这一惊人的桥梁。

## 5.3 Tweedie等式：从去噪器到得分函数

**核心观点**：Tweedie等式（Robbins 1956, Miyasawa 1961）揭示了一个深刻的数学事实：噪声扰动分布的得分函数等于MMSE去噪器的残差除以噪声方差——$\nabla\log p_\varepsilon(x) = (D_\varepsilon(x) - x)/\varepsilon$。这意味着：**有了一个好的去噪器，就有了得分函数**。这是连接去噪与采样的核心桥梁，也是全书从逆问题走向扩散模型的关键一步。

- **高斯去噪问题的回顾**
  - 观测模型：$y = x + \sqrt{\varepsilon}\,z$，其中 $z \sim \mathcal{N}(0, I)$，$x \sim p(x)$
  - 目标：从含噪观测 $y$ 恢复原始信号 $x$
  - MMSE估计器（贝叶斯最优去噪器）：
    $$D_\varepsilon^*(y) = \mathbb{E}[x|y] = \int x\,p(x|y)\,dx = \int x\,\frac{p(y|x)\,p(x)}{p_\varepsilon(y)}\,dx$$
  - 边际分布：$p_\varepsilon(y) = \int p(x)\,\mathcal{N}(y|x, \varepsilon I)\,dx$
  - 第2章已讨论：MMSE去噪器是后验均值，最小化MSE风险

- **Tweedie等式的陈述**
  - **定理（Tweedie等式）**：对噪声扰动分布 $p_\varepsilon(y) = (p * \mathcal{N}(0, \varepsilon I))(y)$，
    $$\boxed{\nabla_y \log p_\varepsilon(y) = \frac{D_\varepsilon^*(y) - y}{\varepsilon}}$$
  - 文字表述：**得分函数 = 去噪器残差 / 噪声方差**
  - 等价形式：$\varepsilon\,\nabla_y \log p_\varepsilon(y) = D_\varepsilon^*(y) - y$
    - 左边：得分函数乘以噪声方差
    - 右边：去噪器的修正方向（从含噪观测指向原始信号的"残差"）
  - 直觉：得分函数告诉我们在 $y$ 处密度如何变化，而去噪器告诉我们 $y$ 离真实信号有多远——两者描述的是同一件事

- **Tweedie等式的证明思路**（详细证明见附录5B）
  - 核心步骤：对 $p_\varepsilon(y) = \int p(x)\,(2\pi\varepsilon)^{-d/2}\exp(-\|y-x\|^2/(2\varepsilon))\,dx$ 求梯度
  - 利用 $\nabla_y \exp(-\|y-x\|^2/(2\varepsilon)) = -\frac{y-x}{\varepsilon}\exp(-\|y-x\|^2/(2\varepsilon))$
  - 代入整理：
    $$\nabla_y p_\varepsilon(y) = \int p(x)\,\frac{x-y}{\varepsilon}\,\mathcal{N}(y|x, \varepsilon I)\,dx = \frac{1}{\varepsilon}\left[\int x\,p(x|y)\,dx - y\right]p_\varepsilon(y)$$
  - 因此 $\frac{\nabla_y p_\varepsilon(y)}{p_\varepsilon(y)} = \frac{D_\varepsilon^*(y) - y}{\varepsilon}$，即 $\nabla_y\log p_\varepsilon(y) = \frac{D_\varepsilon^*(y) - y}{\varepsilon}$

- **Tweedie等式的深层含义**
  - **去噪 = 得分估计**：训练一个去噪器，等价于学习噪声扰动分布的得分函数
  - **绕过归一化常数**：直接估计 $\nabla\log p(x)$ 需要 $Z$，但通过去噪器间接估计 $\nabla\log p_\varepsilon(x)$ 完全不需要 $Z$
  - **数据驱动的先验梯度**：去噪器从数据中学习"干净图像长什么样"，Tweedie等式将这一知识转化为先验的得分函数——**去噪器即隐式先验**
  - **第6章的铺垫**：Tweedie等式说明去噪目标函数与得分匹配目标函数是等价的——训练去噪器 = 训练得分估计器

- **从Tweedie到PnP-ULA：一个计算链**
  - 步骤1：训练去噪器 $D_\varepsilon$（监督学习，数据充足时可行）
  - 步骤2：Tweedie等式给出 $s_\varepsilon(x) = (D_\varepsilon(x) - x)/\varepsilon$
  - 步骤3：将 $s_\varepsilon(x)$ 代入ULA替换先验梯度 → PnP-ULA
  - 这条链将在5.5节完整展开

- **Tweedie等式的历史与命名**
  - Robbins (1956) 在经验贝叶斯框架下首次推导此公式
  - Miyasawa (1961) 独立给出更一般的形式
  - Efron (2011) 将其系统化并命名为"Tweedie公式"
  - 在扩散模型社区中重新发现后，成为连接去噪与采样的核心工具
  - 注意：统计学中的"Tweedie分布"（指数散布模型）与此Tweedie等式无关

**来源**：Pock L2 P7-13; Pereyra L3 P12-21; Ratti P9-13; Robbins (1956); Efron (2011)

Tweedie等式将去噪器与得分函数桥接。去噪器是MMSE估计的产物，而近端算子是MAP估计的一步近似——两者都是"从含噪观测中恢复信号"的策略，却走向不同的目标。MAP与MMSE之间的结构对偶性，揭示了优化与采样更深层的统一。

## 5.4 MAP与MMSE的结构对偶性

**核心观点**：近端算子是MAP估计的一步近似（Moreau包络的梯度步），去噪器是MMSE估计的精确表达（软下卷积的梯度步）。两者都从含噪观测出发恢复信号，但近端算子走向众数（MAP），去噪器走向均值（MMSE）。这一对偶性深刻揭示了优化与采样的内在统一——MAP是"0温度"的MMSE，MMSE是"满温度"的MAP。

- **MAP与MMSE：两种贝叶斯估计回顾**
  - MAP估计：$\hat{x}_{\text{MAP}} = \arg\max_x p(x|y) = \arg\min_x \{-\log p(y|x) - \log p(x)\}$
    - 后验众数——"最可能的值"
    - 通常通过优化算法求解（第3章）
  - MMSE估计：$\hat{x}_{\text{MMSE}} = \mathbb{E}[x|y] = \int x\,p(x|y)\,dx$
    - 后验均值——"平均意义下最好的值"
    - 通常通过采样算法估计（第4章）
  - 关系：当后验对称单峰时，MAP = MMSE；多峰时两者可能差异巨大

- **高斯去噪场景下的MAP与MMSE**
  - 统一框架：先验 $p(x) \propto \exp(-R(x))$，高斯噪声 $y = x + \sqrt{\varepsilon}\,z$
  - MAP去噪器：
    $$\hat{x}_{\text{MAP}} = \arg\min_x \left\{R(x) + \frac{1}{2\varepsilon}\|x - y\|^2\right\} = \text{prox}_{\varepsilon R}(y)$$
    - 即：**MAP去噪器 = 近端算子**（第3章3.4节）
  - MMSE去噪器：
    $$\hat{x}_{\text{MMSE}} = \mathbb{E}[x|y] = D_\varepsilon^*(y)$$
    - 由Tweedie等式：$D_\varepsilon^*(y) = y + \varepsilon\,\nabla\log p_\varepsilon(y)$

- **近端算子 = Moreau包络的一步梯度**
  - Moreau包络定义：$R_\varepsilon(y) = \inf_x \left\{R(x) + \frac{1}{2\varepsilon}\|x - y\|^2\right\}$
  - 关键性质：$\nabla R_\varepsilon(y) = \frac{y - \text{prox}_{\varepsilon R}(y)}{\varepsilon}$
  - 因此：$\text{prox}_{\varepsilon R}(y) = y - \varepsilon\,\nabla R_\varepsilon(y)$
  - 解读：**近端算子 = 沿Moreau包络梯度走一步**——这是MAP方向的"一步梯度下降"

- **去噪器 = 软下卷积的一步梯度**
  - 软下卷积（Moreau-Yoshida包络的概率对偶）定义：
    $$\bar{R}_\varepsilon(y) = -\log\int \exp\left(-R(x) - \frac{\|x-y\|^2}{2\varepsilon}\right)dx$$
  - 关键性质：$\nabla\bar{R}_\varepsilon(y) = \frac{y - D_\varepsilon^*(y)}{\varepsilon}$
  - 因此：$D_\varepsilon^*(y) = y - \varepsilon\,\nabla\bar{R}_\varepsilon(y)$
  - 解读：**去噪器 = 沿软下卷积梯度走一步**——这是MMSE方向的"一步梯度下降"

- **结构对偶：Moreau包络 vs 软下卷积**

  | 性质 | Moreau包络 $R_\varepsilon$（MAP方向） | 软下卷积 $\bar{R}_\varepsilon$（MMSE方向） |
  |---|---|---|
  | 定义 | $\inf_x\{R(x) + \frac{\|x-y\|^2}{2\varepsilon}\}$ | $-\log\int\exp(-R(x) - \frac{\|x-y\|^2}{2\varepsilon})dx$ |
  | 算子 | $\min$（硬选择） | $\text{softmin}$（软选择/指数加权平均） |
  | 梯度 | $\nabla R_\varepsilon = \frac{y - \text{prox}_{\varepsilon R}(y)}{\varepsilon}$ | $\nabla\bar{R}_\varepsilon = \frac{y - D_\varepsilon^*(y)}{\varepsilon}$ |
  | 一步 | $\text{prox}_{\varepsilon R}(y) = y - \varepsilon\nabla R_\varepsilon(y)$ | $D_\varepsilon^*(y) = y - \varepsilon\nabla\bar{R}_\varepsilon(y)$ |
  | 目标 | 众数（MAP） | 均值（MMSE） |
  | 温度 | $T = 0$ | $T = 1$ |

  - 统一视角：引入温度参数 $T > 0$：
    $$R_\varepsilon^T(y) = -T\log\int\exp\left(-\frac{R(x) + \|x-y\|^2/(2\varepsilon)}{T}\right)dx$$
    - $T \to 0^+$：软下卷积 → Moreau包络（$\text{softmin} \to \min$），MMSE → MAP
    - $T = 1$：软下卷积，MMSE去噪器
    - **MAP是"零温度"的MMSE，MMSE是"满温度"的MAP**——温度控制从众数到均值的过渡

- **"绝对零度扩散"：温度对偶的极限**
  - Habring, Falk, Zach & Pock (2025) 提出温度参数的视角
  - 当 $T \to 0^+$，得分函数退化为近端算子方向的梯度——Langevin采样退化为近端梯度下降
  - 当 $T > 0$，得分函数对应去噪器方向的梯度——Langevin采样收敛到分布
  - 这一视角统一了PnP优化（$T=0$）和PnP采样（$T>0$）

**来源**：Pock L2 P7-13, P18-20; Habring, Falk, Zach & Pock (2025); Moreau (1965)

MAP方向的近端算子和MMSE方向的去噪器具有完全相同的数学结构：$y - \varepsilon\nabla(\cdot)(y)$。这自然引出一个大胆的想法——能否用学习到的去噪器替换近端算子，在采样算法中使用数据驱动的隐式先验？这就是PnP（Plug-and-Play）框架的核心思想。

## 5.5 PnP框架：用去噪器替换先验梯度

**核心观点**：PnP（Plug-and-Play）框架将ULA中的先验梯度 $\nabla\log p(x)$ 替换为由去噪器通过Tweedie等式计算的得分函数 $(D_\varepsilon(x)-x)/\varepsilon$，从而实现数据驱动的后验采样。去噪器成为"隐式先验"——不需要显式指定先验分布的形式，只需要一个能去噪的函数。PnP-ULA是逆问题中条件生成的实用方法，也是后续扩散模型的雏形。

- **从MYULA到PnP-ULA：替换的逻辑**
  - MYULA回顾（第4章4.4节）：用Moreau-Yoshida包络光滑化不可微先验，在近似后验上运行ULA
    $$X_{m+1} = X_m - \delta\nabla f(X_m) + \frac{\delta}{\lambda}[\text{prox}_{\lambda g}(X_m) - X_m] + \sqrt{2\delta}\,Z_{m+1}$$
  - 关键观察：近端算子 $\text{prox}_{\lambda g}(x)$ 就是MAP去噪器（5.4节），而Tweedie等式给出了MMSE去噪器
  - 替换：$\text{prox}_{\lambda g}(x) \to D_\varepsilon(x)$
  - PnP-ULA：
    $$\boxed{X_{m+1} = X_m - \delta\nabla f(X_m) + \frac{\delta}{\varepsilon}[D_\varepsilon(X_m) - X_m] + \sqrt{2\delta}\,Z_{m+1}}$$
  - 三步解读：
    1. 似然梯度步：$-\delta\nabla f(X_m)$——数据一致性
    2. 先验得分步（Tweedie）：$\frac{\delta}{\varepsilon}[D_\varepsilon(X_m) - X_m]$——先验知识（去噪器 = 隐式先验）
    3. 探索噪声：$\sqrt{2\delta}\,Z_{m+1}$——保证收敛到分布而非点

- **PnP-ULA的后验得分分解验证**
  - 后验得分：$s(x|y) = \nabla\log p(y|x) + \nabla\log p(x)$
  - 似然得分：$\nabla\log p(y|x) = -\nabla f(x)$（已知）
  - 先验得分（Tweedie替换）：$\nabla\log p_\varepsilon(x) \approx (D_\varepsilon(x) - x)/\varepsilon$
  - 代入ULA：$X_{m+1} = X_m + \delta[-\nabla f(X_m) + (D_\varepsilon(X_m) - X_m)/\varepsilon] + \sqrt{2\delta}\,Z_{m+1}$
  - 与MYULA的对比：近端算子 → 去噪器，显式先验 → 隐式先验

- **PnP-ADMM：优化视角的PnP**
  - ADMM回顾（第3章）：交替更新原始变量和对偶变量，近端算子是关键子步骤
  - PnP-ADMM：将近端算子 $\text{prox}_{\lambda R}$ 替换为去噪器 $D_\varepsilon$
    1. $x^{k+1} = (A^TA + \rho I)^{-1}(A^Ty + \rho(v^k - u^k))$
    2. $v^{k+1} = D_\varepsilon(x^{k+1} + u^k)$ ← 去噪器替换近端
    3. $u^{k+1} = u^k + x^{k+1} - v^{k+1}$
  - PnP-ADMM vs PnP-ULA：
    - PnP-ADMM：优化框架，收敛到点（MAP估计的PnP版本）
    - PnP-ULA：采样框架，收敛到分布（后验采样的PnP版本）
    - 两者体现了MAP vs MMSE的对偶（5.4节）

- **去噪器的选择与训练**
  - 理想去噪器：贝叶斯MMSE去噪器 $D_\varepsilon^*$——最优但需要知道先验
  - 实际去噪器：从数据中学习
    - 经典去噪器：BM3D、NLM——非学习型，但效果良好
    - 深度学习去噪器：DnCNN、DRUNet——学习型，支持条件噪声水平
    - DRUNet的关键优势：$\varepsilon$-条件输入 → 同一网络处理不同噪声水平 → 对应不同尺度的得分函数（→第7章多时间步扩散）
  - 去噪器的质量决定PnP的效果：更好的去噪器 = 更准确的得分估计 = 更好的采样

- **PnP-ULA的后验采样与不确定性量化**
  - 实验流程：给定逆问题 $y = Ax + \text{noise}$
    1. 设定步长 $\delta$ 和噪声水平 $\varepsilon$
    2. 运行PnP-ULA生成样本链 $\{X_m\}$
    3. Burn-in后收集样本
    4. 用样本估计后验均值（MMSE重建）、方差（不确定性）、可信区域
  - 去卷积实验示例：模糊核 + 高斯噪声
    - PnP-ULA用DRUNet去噪器生成后验样本
    - 样本均值 → MMSE重建（优于MAP的视觉效果）
    - 样本方差 → 像素级不确定性图（高方差区域对应难以恢复的细节）
  - **PnP-ULA实践中的参数选择**
    - $\varepsilon$ 的选择：去噪器的训练噪声水平 → 控制得分估计的尺度
    - $\delta$ 的选择：步长 → 控制离散化精度（$\delta \leq 1/L$）
    - $\varepsilon$ 和 $\delta$ 的协同：$\varepsilon$ 小 → 得分模长大 → 需要 $\delta$ 小 → 收敛慢
    - 经验法则：$\delta \approx \varepsilon / 2$ 或通过实验调节

- **PnP的思想源流**
  - Venkatakrishnan, Bouman & Wohlberg (2013)：首次在ADMM中用去噪器替换近端算子
  - 最初是优化方法（PnP-ADMM → MAP），后被扩展到采样（PnP-ULA → MMSE）
  - Laumont et al. (2021)：给出了PnP-ULA的收敛性理论
  - PnP是"隐式先验"的工程实现：不需要 $p(x)$ 的解析式，只需要 $D_\varepsilon$ 的函数值

**来源**：Pereyra L3 P9-11, P22-35; Calatroni P41-44; lab2_PnP_sol; Venkatakrishnan et al. (2013); Laumont et al. (2021)

PnP-ULA将去噪器嵌入采样算法，但去噪器对得分函数的近似有多好？采样是否收敛到正确的分布？这需要近似理论的支撑——Moreau-Yoshida包络理论给出了近似密度的性质保证，PnP收敛定理将去噪器的Lipschitz性质与采样收敛联系起来。

## 5.6 近似理论与收敛保证

**核心观点**：PnP-ULA的收敛性依赖于去噪器对得分函数的近似质量。本节给出两层保证：第一层，Moreau-Yoshida包络理论证明光滑化后的近似密度是真密度、对数凹且光滑，近似误差可控；第二层，PnP收敛定理将去噪器的Lipschitz性质与采样收敛联系起来——当去噪器充分Lipschitz时，PnP-ULA的样本分布收敛到真实后验的邻域。

- **Moreau-Yoshida包络回顾**
  - 定义：对不可微函数 $g(x)$，Moreau-Yoshida包络
    $$g_\lambda(x) = \inf_u \left\{g(u) + \frac{1}{2\lambda}\|u - x\|^2\right\}$$
  - 第3章3.4节和第4章4.4节已从优化和算法角度介绍，本节从概率密度角度深化

- **近似密度的性质**
  - 定义近似后验：$p_\lambda(x|y) \propto \exp\{-f(x) - g_\lambda(x)\}$
  - 性质1（真密度）：$p_\lambda(x|y)$ 是良定义的概率密度
    - 证明：$g_\lambda(x) \leq g(x)$（下界），且 $g_\lambda(x) \to g(x)$（$\lambda \to 0$）
    - 积分 $\int\exp\{-f(x) - g_\lambda(x)\}dx < \infty$（因为 $g_\lambda(x) \geq 0$ 对真函数 $g$）
  - 性质2（对数凹性）：若 $f + g$ 是对数凹的，则 $f + g_\lambda$ 也是对数凹的
    - Moreau包络保持对数凹性——这是ULA收敛性的关键条件
  - 性质3（光滑性）：$g_\lambda \in C^1$（即使 $g$ 不可微）
    - 梯度表达式：$\nabla g_\lambda(x) = \frac{x - \text{prox}_{\lambda g}(x)}{\lambda}$
    - Lipschitz常数：$\nabla g_\lambda$ 是 $(1/\lambda)$-Lipschitz的
  - 性质4（梯度Lipschitz）：$\nabla\log p_\lambda$ 是 $L$-Lipschitz的，$L \leq L_f + 1/\lambda$
    - 这是ULA步长条件 $\delta \leq 1/L$ 的理论依据

- **近似误差界**
  - 总变差距离：$\|p_\lambda - p\|_{\text{TV}} \leq \lambda\,L_g^2$（$g$ 是 $L_g$-Lipschitz时）
  - 直觉：$\lambda$ 越小，近似越好，但Lipschitz常数 $1/\lambda$ 越大→步长越小→收敛越慢
  - 权衡曲线：$\lambda$ 控制近似精度与计算效率的trade-off
  - **$\lambda$ 的选择策略**
    - 理论最优：$\lambda \sim \sqrt{\delta}$（平衡近似误差和离散误差）
    - 实践经验：$\lambda = \varepsilon$（与去噪器的噪声水平一致）
    - 自适应策略：初期用大 $\lambda$（快速收敛），后期减小 $\lambda$（提高精度）

- **PnP-ULA的收敛性**
  - 问题：PnP-ULA用学习去噪器 $D_\varepsilon$ 替换 $\text{prox}_{\lambda g}$，是否还有收敛保证？
  - 关键假设：去噪器的Lipschitz常数 $\text{Lip}(D_\varepsilon) \leq \eta < 1$
    - 这是PnP收敛的核心条件——去噪器必须是"压缩映射"
    - 物理含义：去噪器不能"过度修正"——输出的变化不能大于输入的变化
  - 收敛定理（Laumont et al., 2021）：在Lipschitz条件下，PnP-ULA生成的样本分布收敛到某个目标分布 $\tilde{p}$，且
    $$\|\tilde{p} - p\|_{\text{TV}} \leq C(\varepsilon, \delta, \eta)$$
    - 误差依赖于噪声水平 $\varepsilon$、步长 $\delta$ 和去噪器的Lipschitz常数 $\eta$
    - 当 $\varepsilon \to 0$ 且 $\delta \to 0$ 且 $\eta \to 0$：$\tilde{p} \to p$

- **从PnP到扩散模型的理论桥梁**
  - PnP-ULA的局限：单一噪声水平 $\varepsilon$ → 单一尺度得分 → 对复杂多尺度分布采样不足
  - 扩散模型的解决方案：多时间步噪声调度 $\varepsilon_1 > \varepsilon_2 > \cdots > \varepsilon_T$ → 多尺度得分 → 逐步去噪
  - 理论预告：第7章将展示，扩散模型是PnP-ULA的多时间步推广
    - PnP-ULA：$X_{m+1} = X_m + \delta\,s(X_m) + \sqrt{2\delta}\,Z_{m+1}$（单步，固定 $\varepsilon$）
    - 扩散模型：$dX_t = s_\theta(X_t, t)\,dt + \sqrt{2}\,dW_t$（连续时间，$t$ 对应 $\varepsilon(t)$ 递减）
  - 核心洞见：**PnP是"单温度"扩散，扩散是"多温度"PnP**

- **Lipschitz去噪器的正则化**
  - 约束 $\text{Lip}(D_\varepsilon) \leq \eta$ 可以通过训练正则化实现
  - 方法1：权重裁剪（weight clipping）——简单但可能损害性能
  - 方法2：谱归一化（spectral normalization）——对每层卷积的谱范数约束
  - 方法3：梯度惩罚（gradient penalty）——$\lambda_{\text{gp}}\,\mathbb{E}[\|\nabla D_\varepsilon(x)\|^2]$
  - 实践中，谱归一化是最常用的方法

**来源**：Pereyra L1 P43-44; Pereyra L3 P9-11; Durmus et al. (2018); Laumont et al. (2021); Ryu et al. (2019)

## 附录5A Fokker-Planck方程与Langevin扩散的平稳分布

> 定位：为5.1节提供Langevin SDE平稳分布的严格证明。Fokker-Planck方程是连接SDE与概率密度演化的核心工具，其推导涉及随机分析的基础知识，放在附录以保持主线叙事的流畅。

- **Fokker-Planck方程的推导**
  - 从Itô公式到Fokker-Planck：对测试函数 $\phi \in C_c^\infty$，
    $$\frac{d}{dt}\mathbb{E}[\phi(X_t)] = \mathbb{E}[\nabla\phi(X_t)\cdot s(X_t)] + \mathbb{E}[\Delta\phi(X_t)]$$
  - 分部积分转化为密度方程：
    $$\frac{\partial \rho_t}{\partial t} = -\nabla\cdot(s(x)\,\rho_t) + \Delta\rho_t$$
  - 这是Fokker-Planck方程的一般形式

- **验证 $p(x)$ 是平稳分布**
  - 代入 $\rho^*(x) = p(x)$，验证 $\partial\rho^*/\partial t = 0$
  - 关键等式：$\nabla\cdot[p(x)\,s(x)] = \nabla\cdot[\nabla p(x)] = \Delta p(x)$
  - 因此：$-\nabla\cdot(s\,p) + \Delta p = -\Delta p + \Delta p = 0$ ✓
  - 物理解释：漂移产生的"流量"与扩散产生的"流量"恰好抵消

- **指数收敛的证明（强对数凹情形）**
  - 利用Bakry-Émery曲率条件：$\text{Hess}(-\log p) \succeq m\,I$
  - 得到 $W_2$ 距离的指数衰减：$W_2(\rho_t, p) \leq e^{-mt}\,W_2(\rho_0, p)$

**来源**：Risken (1996); Bakry, Gentil & Ledoux (2014)

## 附录5B Tweedie等式的严格证明

> 定位：为5.3节提供Tweedie等式的完整数学推导。证明虽不复杂，但需要仔细的积分交换和分部积分操作，放在附录以避免打断主线的概念流。

- **一般形式的Tweedie等式**
  - 设 $X \sim p(x)$，$Y = X + \sqrt{\varepsilon}\,Z$，$Z \sim \mathcal{N}(0, I)$
  - 则 $Y$ 的边际密度 $p_\varepsilon(y) = \int p(x)\,\mathcal{N}(y|x, \varepsilon I)\,dx$

- **完整证明**
  - 步骤1：写出 $p_\varepsilon(y)$ 的积分表达式
  - 步骤2：对 $y$ 求梯度 $\nabla_y p_\varepsilon(y)$
  - 步骤3：利用高斯密度的梯度 $\nabla_y\mathcal{N}(y|x, \varepsilon I) = -\frac{y-x}{\varepsilon}\mathcal{N}(y|x, \varepsilon I)$
  - 步骤4：提取因子 $(x-y)/\varepsilon$，识别条件期望
  - 步骤5：除以 $p_\varepsilon(y)$ 得到 $\nabla_y\log p_\varepsilon(y) = (D_\varepsilon^*(y) - y)/\varepsilon$

- **推广：标量Tweedie等式（Efron, 2011）**
  - 对一维指数族 $p(y|\theta) = e^{\theta y - \psi(\theta)}\,h(y)$：
    $$\mathbb{E}[\theta|y] = \frac{d}{dy}\log h(y) + \frac{d}{dy}\log p(y)$$
  - 高斯情形的特殊化
  - 与经验贝叶斯的联系

**来源**：Robbins (1956); Efron (2011); Miyasawa (1961)

```
      │

      ▼
5.6 近似理论与收敛保证（理论保障）
      │
      ├──→ 如何从数据中学习得分？→ 第6章（得分匹配）
      └──→ PnP→扩散的多时间步推广 → 第7章（扩散模型）
```

**核心叙事**：第4章建立了ULA算法，其驱动力是得分函数 $\nabla\log p(x|y)$。本章首先从离散ULA走向连续Langevin SDE，揭示得分函数的几何含义——它是概率分布的"方向场"。然后，Tweedie等式架起从去噪器到得分函数的桥梁——有了去噪器就有了得分函数。MAP与MMSE的对偶性进一步揭示：近端算子（MAP方向）和去噪器（MMSE方向）具有相同的数学结构，区别仅在"温度"。PnP框架将Tweedie等式的洞见落地为实用算法——用学习到的去噪器替换ULA中的先验梯度。最后，Moreau-Yoshida理论和PnP收敛定理提供理论保证。本章的核心洞见是：**去噪器 = 隐式先验 = 得分估计器**——这一三位一体的认识是理解后续章节的钥匙：第6章将展示如何系统地训练得分估计器（得分匹配），第7章将展示多时间步得分驱动采样如何成为扩散模型——**从逆问题的后验采样需求出发，采样路径继续向扩散模型演化**。
