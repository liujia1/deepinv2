# 5.4 MAP 与 MMSE 的结构对偶性

> **先抛一个尴尬**：上一节我们拿到了去噪器（MMSE，奔均值），第3章我们又拿到了近端算子（MAP，奔众数）。这俩都是从"带噪观测"恢复信号，听着像亲兄弟，可一个走均值、一个走众数，仿佛分属两个阵营。这一节我们要揭晓：它们其实是**同一个骨架的两个极端**——只差一个叫"温度"的旋钮。把温度拧到零，去噪器退化成近端算子；拧回自然温度，近端算子又变回去噪器。

**本节目标**：

- 在高斯去噪场景下，看清 MAP 去噪器 = 近端算子、MMSE 去噪器 = 后验均值；
- 用 Moreau 包络（MAP）和软下卷积（MMSE）统一两者的一步梯度结构；
- 引入温度参数，把"优化 vs 采样"统一进同一框架；
- 为下一节的 PnP（去噪器替换近端算子）提供理论自洽性。

---

## 1. MAP 与 MMSE：两种贝叶斯估计回顾

第2章介绍过贝叶斯点估计的两种基本策略。这里我们在高斯去噪场景下把对比加深，揭示它们惊人的结构对偶。

### 一般框架

贝叶斯点估计由损失函数定义：

$$\hat{x}(y) \in \arg\min_z \int \ell(x, z)\,p(x|y)\,dx$$

不同损失给出不同估计器：

- **0-1 损失** $\ell(x,z)=\mathbf{1}_{x\neq z}$ → **MAP 估计**：$\hat{x}_{\text{MAP}}=\arg\max_x p(x|y)$（后验众数，"最可能的值"）；
- **平方损失** $\ell(x,z)=\|x-z\|^2$ → **MMSE 估计**：$\hat{x}_{\text{MMSE}}=\mathbb{E}[x|y]$（后验均值，"平均意义下最好的值"）。

**点 vs 分布**：MAP 只给你"最尖的那个值"，像传统优化给你一个单点；MMSE 给你"平均意义上的最好值"，已经触碰到了后验的整个分布形状。当后验对称单峰时两者相等；多峰时可能差很远。

## 2. 高斯去噪场景下的 MAP 与 MMSE

### 统一框架

设先验 $p(x)\propto\exp(-R(x))$（吉布斯分布），高斯噪声 $y=x+\sqrt{\varepsilon}\,z$。去噪问题的负对数后验为：

$$-\log p(x|y) = R(x) + \frac{1}{2\varepsilon}\|x - y\|^2 + \text{const}$$

$R(x)$ 是正则项，$\frac{1}{2\varepsilon}\|x-y\|^2$ 是数据项。

### MAP 去噪器 = 近端算子

MAP 估计最小化负对数后验：

$$\hat{x}_{\text{MAP}} = \arg\min_x \left\{R(x) + \frac{1}{2\varepsilon}\|x - y\|^2\right\}$$

这正是**近端算子**的定义（第3章 3.4 节）：

$$\hat{x}_{\text{MAP}} = \text{prox}_{\varepsilon R}(y) = \arg\min_x \left\{R(x) + \frac{1}{2\varepsilon}\|x - y\|^2\right\}$$

**MAP 去噪器 = 近端算子**——第3章已建立，这里从得分角度再看一遍。

### MMSE 去噪器 = 后验均值

MMSE 估计是后验均值：

$$\hat{x}_{\text{MMSE}} = \mathbb{E}[x|y] = D_\varepsilon^*(y)$$

由 Tweedie 等式（5.3 节），$D_\varepsilon^*(y) = y + \varepsilon\,\nabla\log p_\varepsilon(y) = y - \varepsilon\,\nabla\bar{R}_\varepsilon(y)$，其中 $\bar{R}_\varepsilon$ 是下面要讲的软下卷积。

---

## 3. 近端算子 = Moreau 包络的一步梯度

### Moreau 包络回顾

对函数 $R(x)$，其**Moreau 包络**（也叫下卷积 / infimal convolution）定义为：

$$\hat{R}_\varepsilon(y) = \inf_x \left\{R(x) + \frac{1}{2\varepsilon}\|x - y\|^2\right\}$$

它是 $R$ 和二次函数 $\frac{\|\cdot\|^2}{2\varepsilon}$ 的 infimal 卷积，是 $R$ 的光滑近似。

### 关键性质

Moreau 包络的梯度有闭式：

$$\nabla\hat{R}_\varepsilon(y) = \frac{y - \text{prox}_{\varepsilon R}(y)}{\varepsilon}$$

证明基于近端算子的最优性条件和包络定理：设 $\hat{x}=\text{prox}_{\varepsilon R}(y)$，最优性条件 $0\in\partial R(\hat{x})+\frac{1}{\varepsilon}(\hat{x}-y)$；包络定理让 $R(\hat{x})$ 对 $y$ 的间接贡献被抵消，于是 $\nabla_y\hat{R}_\varepsilon(y) = \frac{y-\hat{x}}{\varepsilon}$。结论：$\hat{x} = y - \varepsilon\,\nabla\hat{R}_\varepsilon(y)$。

### 近端算子的梯度步解读

把关系重排：

$$\text{prox}_{\varepsilon R}(y) = y - \varepsilon\,\nabla\hat{R}_\varepsilon(y)$$

含义是：**近端算子 = 从 $y$ 出发，沿 Moreau 包络梯度走一步**，步长 $\varepsilon$。

这是 MAP 方向的"一步梯度下降"——沿 $\hat{R}_\varepsilon$ 的下降方向走一步，从含噪观测 $y$ 积向 MAP 估计。

> **配套实验 5.4-1：近端算子 = Moreau 包络的一步梯度**
>
> 在一维去噪场景 $y=x+\varepsilon$（$A=I$）里，用 TV 正则项 $R(x)=\text{TV}(x)$，通过 Chambolle 算法算 TV 近端算子。实验两步：① TV 近端算子演示（不同 $\lambda$ 看正则化强度影响）；② 用有限差分独立估 Moreau 包络梯度，与理论公式 $\nabla\hat{R}_\lambda(y)=(y-\text{prox})/\lambda$ 对比。

> 结果：有限差分与理论梯度整体趋势一致（TV 非光滑导致边缘处有误差）；$\lambda$ 小时近端算子接近输入（弱先验），$\lambda$ 大时趋近常数（强先验）。这验证了"近端算子是从 $y$ 沿 Moreau 包络梯度走一步"。

### 软下卷积定义

对函数 $R(x)$，其**软下卷积**定义为：

$$\bar{R}_\varepsilon(y) = -\log\int \exp\left(-R(x) - \frac{\|x - y\|^2}{2\varepsilon}\right)dx$$

软下卷积是 $R$ 与二次函数的"软"版本卷积——用 $\text{softmin}$（指数加权平均）代替 $\min$（硬选择）。在统一框架里，若先验 $p(x)\propto\exp(-R(x))$，则 $\exp(-\bar{R}_\varepsilon(y))$ 正是噪声扰动分布 $p_\varepsilon(y)$ 乘归一化常数，所以软下卷积就是噪声扰动分布的负对数。

### 关键性质

软下卷积的梯度同样有闭式：

$$\nabla\bar{R}_\varepsilon(y) = \frac{y - D_\varepsilon^*(y)}{\varepsilon}$$

这直接对应 Tweedie：$D_\varepsilon^*(y) = y + \varepsilon\,\nabla\log p_\varepsilon(y) = y - \varepsilon\,\nabla\bar{R}_\varepsilon(y)$。

### 去噪器的梯度步解读

重排：

$$D_\varepsilon^*(y) = y - \varepsilon\,\nabla\bar{R}_\varepsilon(y)$$

**去噪器 = 从 $y$ 出发，沿软下卷积梯度走一步**，步长 $\varepsilon$。

这是 MMSE 方向的"一步梯度下降"——沿 $\bar{R}_\varepsilon$ 的下降方向走一步，从含噪观测 $y$ 移向 MMSE 估计。

## 4. 结构对偶：Moreau 包络 vs 软下卷积

把 MAP 和 MMSE 的对偶性摆到最清楚：

| 性质 | Moreau 包络 $\hat{R}_\varepsilon$（MAP 方向） | 软下卷积 $\bar{R}_\varepsilon$（MMSE 方向） |
|---|---|---|
| 定义 | $\inf_x\{R(x) + \frac{\|x-y\|^2}{2\varepsilon}\}$ | $-\log\int\exp(-R(x) - \frac{\|x-y\|^2}{2\varepsilon})dx$ |
| 算子 | $\min$（硬选择） | $\text{softmin}$（软选择 / 指数加权平均） |
| 梯度 | $\nabla\hat{R}_\varepsilon = \frac{y - \text{prox}_{\varepsilon R}(y)}{\varepsilon}$ | $\nabla\bar{R}_\varepsilon = \frac{y - D_\varepsilon^*(y)}{\varepsilon}$ |
| 一步结果 | $\text{prox}_{\varepsilon R}(y) = y - \varepsilon\nabla\hat{R}_\varepsilon(y)$ | $D_\varepsilon^*(y) = y - \varepsilon\nabla\bar{R}_\varepsilon(y)$ |
| 目标 | 众数（MAP） | 均值（MMSE） |
| 温度 | $T = 0$ | $T = 1$ |

> 注：$T=1$ 对应物理里"自然温度单位"——此时指数加权分布恰好是贝叶斯后验 $p(x|y)$，不引入额外缩放。

### 统一解读

两者有**完全相同的数学结构**——"从含噪观测 $y$ 出发，沿某个光滑函数的梯度走一步，步长 $\varepsilon$"：

$$\text{一步结果} = y - \varepsilon\,\nabla(\cdot)(y)$$

区别只在于"沿哪个函数的梯度走"：

- Moreau 包络 $\hat{R}_\varepsilon$：硬选择（$\min$）→ 走向众数；
- 软下卷积 $\bar{R}_\varepsilon$：软选择（$\text{softmin}$）→ 走向均值。

$\min$ 和 $\text{softmin}$ 的关系，可以用温度参数统一。

## 5. 温度参数：从 MMSE 到 MAP 的连续过渡（when/why/how）

- **什么时候用**：当你想在同一套公式里同时描述"优化（要一个众数）"和"采样（要整个分布）"时，温度参数是统一语言。
- **为什么难**：MAP 和 MMSE 表面上是两个不同估计器，好像没法放进一个框架。
- **怎么做**：引入温度 $T$，让 $\min$ 在 $T\to 0$ 时退化、在 $T=1$ 时变成 $\text{softmin}$。

### 统一定义

引入温度参数 $T>0$，定义温度化的软下卷积：

$$\bar{R}_\varepsilon^T(y) = -T\log\int\exp\left(-\frac{R(x) + \|x-y\|^2/(2\varepsilon)}{T}\right)dx$$

- **$T=1$**：$\bar{R}_\varepsilon^1=\bar{R}_\varepsilon$（标准软下卷积）→ MMSE 去噪器；
- **$T\to 0^+$**：$\bar{R}_\varepsilon^T\to\hat{R}_\varepsilon$（Moreau 包络）→ MAP 近端算子。

> 注：此极限在子问题有唯一最小值点时成立；严格凸 $R$ 自动满足。非凸 $R$ 时收敛行为更复杂。

### 物理直觉

温度控制"软选择"的程度：

- **高温**（$T=1$）：所有候选 $x$ 都按 $\exp(-E/T)$ 加权平均——典型 Gibbs 分布行为，结果是后验均值（MMSE）；
- **零温**（$T\to 0^+$）：只有最优候选有贡献（指数加权退化为硬选择）——典型优化行为，结果是后验众数（MAP）。

**MAP 是"零温度"的 MMSE，MMSE 是"满温度"的 MAP**——温度参数把优化（MAP）和采样（MMSE）统一进同一个框架。

### 对应的"一步"随温度变化

温度化的一步结果为：

$$\text{一步}_T(y) = y - \varepsilon\,\nabla\bar{R}_\varepsilon^T(y)$$

- $T=1$：$\text{一步}_1(y)=D_\varepsilon^*(y)$（MMSE 去噪器）；
- $T\to 0^+$：$\text{一步}_0(y)=\text{prox}_{\varepsilon R}(y)$（MAP 近端算子）。

温度从 1 降到 0，一步结果从均值连续过渡到众数——**优化和采样之间没有鸿沟，只有温度的差别**。

### 在 Langevin 采样中的体现

这个温度视角在 Langevin 采样里直接可见：

- **ULA**（$T>0$）：$X_{m+1}=X_m+\delta\,s(X_m)+\sqrt{2\delta}\,Z$——噪声驱动的随机过程，收敛到分布；
- **梯度下降**（$T=0$）：$x_{k+1}=x_k-\tau\nabla U(x_k)$——确定性优化，收敛到众数。

ULA 里的噪声项 $\sqrt{2\delta}\,Z$ 就是"温度"的体现——有噪声（$T>0$）就是采样，无噪声（$T=0$）就是优化。这再次呼应第4章：**优化算法 + 噪声 = 采样算法**。

### "绝对零度扩散"：温度对偶的极限（提示：涉及第7章，初读可跳过）

Habring, Falk, Zach & Pock (2025) 基于温度视角提出"绝对零度扩散"（Diffusion at Absolute Zero）：

- 标准扩散模型里，去噪器（得分估计器）对应 $T>0$——每步是 MMSE 方向的一步梯度；
- 绝对零度扩散里，用近端算子（$T=0$）替换去噪器——每步是 MAP 方向的一步梯度；
- 近端算子可用高效优化算法算（第3章），无需训练神经网络；
- 这给出一种"免训练扩散模型"——代价是采样质量受限于近端算子的先验表达能力。

这深刻揭示：扩散模型与近端方法是一对"温度对偶"。

> **配套实验 5.4-2：近端算子 vs 学习去噪器——结构对偶性验证**
>
> 在图像去模糊+去噪逆问题下，对比两种先验的 ULA：显式先验（TV-ULA，用 TV 近端算子+Moreau 梯度）和隐式先验（PnP-ULA，用预训练 RealSN-DnCNN 去噪器+Tweedie 得分）。观测模型 $y=Ax+\sigma z$，ULA 更新 $X_{k+1}=X_k-\delta(\nabla f(X_k)-s(X_k))+\sqrt{2\delta}Z_k$。

## 6. 从对偶性到 PnP：替换的合理性

MAP/MMSE 对偶性为 PnP 框架（5.5 节）提供了理论基础：

- 近端算子 $\text{prox}_{\varepsilon R}(y)=y-\varepsilon\nabla\hat{R}_\varepsilon(y)$：MAP 方向的一步，沿 Moreau 包络；
- 去噪器 $D_\varepsilon(y)=y-\varepsilon\nabla\bar{R}_\varepsilon(y)$：MMSE 方向的一步，沿软下卷积。

两者结构完全相同：**含噪观测 $y$ 减去步长 $\varepsilon$ 乘以某个梯度**。所以，用去噪器替换近端算子——从 MAP 方向切到 MMSE 方向——在数学结构上是自洽的。

更重要的是，去噪器不需要 $R(x)$ 的解析式——它从数据里学，隐式定义了先验。这让 PnP 能超越显式先验的表达能力限制，用更强大的隐式先验。

**来源**：Pock L2 P7-13, P18-20; Habring, Falk, Zach & Pock (2025); Moreau (1965); Robbins (1956)

## 7. 收尾：为什么这件事重要

把整节塌缩成一句话：**MAP 与 MMSE 不是两个隔阂的阵营，而是同一操作（"沿某个梯度走一步"）在温度 $T=0$ 与 $T=1$ 两端的样子**。这个对偶性之所以关键，是因为它给了一个底气：既然近端算子（MAP 方向）和去噪器（MMSE 方向）结构一模一样，那么"用学习到的去噪器替换近端算子"就不是偷换概念，而是同一骨架内的合法切换——下一节我们正式落地成 PnP 框架。
