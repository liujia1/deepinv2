# 5.3 Tweedie 等式：从去噪器到得分函数

> **先抛一个谜题**：给你一个"去噪器"——你喂它一张带噪点的图，它吐出一张干净的图。再给你一个"得分函数"——在空间每点告诉你概率密度往哪边涨。这俩东西，听起来八竿子打不着吧？一个在修图，一个在算梯度。可是数学里有一条等式，硬要说：**这俩是同一个东西**。这一节我们就要把这个反直觉的等式——Tweedie 等式——彻底讲清楚，并让你亲手"先猜再揭晓"。

**本节目标**：

- 看懂 Tweedie 等式 $\nabla\log p_\varepsilon(x) = (D_\varepsilon(x) - x)/\varepsilon$ 在说什么；
- 用一个 1D 高斯小例子"先猜再揭晓"，感受去噪器残差和得分函数完全重合的 aha；
- 理解它的三层深意：去噪=得分估计、绕过归一化常数、数据驱动先验梯度；
- 看清它如何串起一条"去噪器 → 后验采样"的完整计算链。

---

## 1. 先从一个反直觉的"aha"开场

你大概会觉得：去噪和贝叶斯得分，这是两码事吧？去噪是"把图弄干净"，得分函数是"概率密度的梯度"，听着风马牛不相及。

可 Tweedie 等式偏要说：它们**就是同一个东西**。先别急，我们等下用一个具体数字小例子让你"先猜再揭晓"。这个等式是全书最重要的桥之一——它呼应绪论的五座桥之第 1 座，也和第2章的贝叶斯去噪器一脉相承。

---

## 2. 高斯去噪问题回顾：最简单的逆问题

先从最简单的逆问题——高斯去噪——说起：

$$y = x + \sqrt{\varepsilon}\,z, \quad z \sim \mathcal{N}(0, I_n)$$

$x\sim p(x)$ 是未知信号（服从某个先验分布），$\varepsilon>0$ 是噪声方差。观测 $y$ 是信号加高斯噪声，目标是从 $y$ 恢复 $x$。

这个去噪问题是逆问题的"零算子"情形（$A=I$，正向模型是恒等），是理解更复杂逆问题的基础。更重要的是，去噪和得分函数之间有个惊人的联系——就是 Tweedie 等式。

### MMSE 去噪器：均方误差意义下的最优

第2章讲过，给定含噪观测 $y$，在均方误差（MSE）意义下最优的估计器是**后验均值**（MMSE 估计器）：

$$D_\varepsilon^*(y) = \mathbb{E}[x|y] = \int x\,p(x|y)\,dx$$

由贝叶斯公式 $p(x|y)=p(y|x)p(x)/p_\varepsilon(y)$，可写成：

$$D_\varepsilon^*(y) = \frac{1}{p_\varepsilon(y)}\int x\,p(y|x)\,p(x)\,dx = \frac{\int x\,\mathcal{N}(y|x, \varepsilon I)\,p(x)\,dx}{p_\varepsilon(y)}$$

其中 $p_\varepsilon(y) = \int p(x)\,\mathcal{N}(y|x, \varepsilon I)\,dx$ 正是 5.2 节定义的噪声扰动分布。

MMSE 去噪器的关键性质：它最小化 MSE 风险 $\mathbb{E}[\|x-D(y)\|^2]$，是后验均值（携带后验的一阶信息），而且不要求先验 $p(x)$ 有解析形式。

---

## 3. Tweedie 等式的陈述：先猜，再揭晓

### 定理（Tweedie 等式）

对噪声扰动分布 $p_\varepsilon(y) = (p * \mathcal{N}(0, \varepsilon I))(y)$，有：

$$\boxed{\nabla_y \log p_\varepsilon(y) = \frac{D_\varepsilon^*(y) - y}{\varepsilon}}$$

等价写法：$\varepsilon\,\nabla_y \log p_\varepsilon(y) = D_\varepsilon^*(y) - y$。

### 文字表述

**得分函数 = 去噪器残差 / 噪声方差**。

- 左边 $\nabla_y\log p_\varepsilon(y)$：噪声扰动分布的得分函数——在 $y$ 处密度增长最快的方向；
- 右边 $(D_\varepsilon^*(y)-y)/\varepsilon$：MMSE 去噪器的修正方向（从含噪观测指向真实信号的"残差"），除以噪声方差。

### 直觉理解

Tweedie 等式的深意是：**得分函数和去噪器残差在讲同一件事**——都在回答"含噪观测 $y$ 离真实信号有多远、该往哪修正"。

- 得分函数 $\nabla\log p_\varepsilon(y)$ 说：在 $y$ 处，$p_\varepsilon$ 的密度怎么变——该往密度增大的方向挪；
- 去噪器残差 $D_\varepsilon^*(y)-y$ 说：去噪器认为 $y$ 离真实信号多远——该从 $y$ 向 $D_\varepsilon^*(y)$ 挪。

两者方向一致，量级由噪声方差 $\varepsilon$ 标定：$\varepsilon$ 越大（噪声越强），残差越大，但得分模长也越大（因为模糊后的分布梯度更平缓，需要更大的梯度来驱动同样的位移）。

---

### 先猜再揭晓：一个 1D 高斯小例子

来，动手猜一下。设先验是标准高斯 $x\sim\mathcal{N}(0,1)$，观测 $y = x + \sqrt{\varepsilon}\,z$。我们知道（第2章）：

- 贝叶斯最优去噪器（MMSE）是 $D_\varepsilon^*(y) = \mathbb{E}[x|y] = \dfrac{y}{1+\varepsilon}$（把观测向 0 收缩）；
- 噪声扰动分布 $p_\varepsilon(y)=\mathcal{N}(0, 1+\varepsilon)$，它的得分是 $\nabla_y\log p_\varepsilon(y) = -\dfrac{y}{1+\varepsilon}$。

**猜一猜**：用 Tweedie 等式，从去噪器残差算出的得分会是多少？是不是觉得"去噪器这东西怎么可能跟概率梯度挂上钩"？直觉上，你大概会猜两边差得远。

揭晓：

$$s_\varepsilon(y) = \frac{D_\varepsilon^*(y) - y}{\varepsilon} = \frac{y/(1+\varepsilon) - y}{\varepsilon} = -\frac{y}{1+\varepsilon}$$

和精确得分**完全一样**！去噪器的残差一除噪声方差，恰好就是得分。这就是那个"aha"——你以为风马牛不相及的两样东西，其实是同一个量。

> 实验 5.3-1 在一维解析情形和图像去噪场景里都验证了这个等式，数值梯度与 Tweedie 公式给出的得分误差在浮点精度内（$10^{-14}\sim 10^{-16}$）。去噪器的收缩效应 $D_\varepsilon^*(y)=y/(1+\varepsilon)$ 把观测向原点（先验均值）拉，残差 $- \varepsilon\cdot y/(1+\varepsilon)$ 指向原点方向，正好等于 $\varepsilon\times$ 得分。

> **核心洞察**：等式"得分 = 去噪器残差 / 噪声方差"不仅是数学定理，更是连接去噪与采样的桥：有去噪器就有得分，有得分就能驱动 Langevin 采样。这正是"隐式先验"工作流的数学基础。

## 4. Tweedie 等式的证明：高斯梯度的魔法（可跳过）

证明不复杂，核心就是利用高斯密度的梯度性质。

**第一步：写出边际密度**

$$p_\varepsilon(y) = \int p(x)\,(2\pi\varepsilon)^{-n/2}\exp\left(-\frac{\|y - x\|^2}{2\varepsilon}\right)dx$$

**第二步：对 $y$ 求梯度**。利用 $\nabla_y \exp\left(-\frac{\|y-x\|^2}{2\varepsilon}\right) = -\frac{y-x}{\varepsilon}\exp\left(-\frac{\|y-x\|^2}{2\varepsilon}\right)$：

$$\nabla_y p_\varepsilon(y) = \int p(x)\,\frac{x - y}{\varepsilon}\,\mathcal{N}(y|x, \varepsilon I)\,dx$$

**第三步：拆开、识别条件期望**

$$\nabla_y p_\varepsilon(y) = \frac{1}{\varepsilon}\left[\int x\,p(x)\,\mathcal{N}(y|x, \varepsilon I)\,dx - y\int p(x)\,\mathcal{N}(y|x, \varepsilon I)\,dx\right]$$

第二个积分里 $y$ 与积分变量无关，提出来就是 $y\,p_\varepsilon(y)$。第一个积分注意到 $\frac{p(x)\mathcal{N}(y|x,\varepsilon I)}{p_\varepsilon(y)}=p(x|y)$，所以：

$$= \frac{1}{\varepsilon}\left[\int x\,p(x|y)\,p_\varepsilon(y)\,dx - y\,p_\varepsilon(y)\right] = \frac{p_\varepsilon(y)}{\varepsilon}\left[D_\varepsilon^*(y) - y\right]$$

**第四步：除以 $p_\varepsilon(y)$**

$$\frac{\nabla_y p_\varepsilon(y)}{p_\varepsilon(y)} = \nabla_y\log p_\varepsilon(y) = \frac{D_\varepsilon^*(y) - y}{\varepsilon} \quad \blacksquare$$

最妙的一步是第三步：把 $\int x\,p(x)\mathcal{N}(y|x,\varepsilon I)\,dx$ 认成 $D_\varepsilon^*(y)\cdot p_\varepsilon(y)$——正是 MMSE 去噪器的定义。（完整严格推导见附录 5B。）

## 5. Tweedie 等式的深层含义：三层

Tweedie 等式不只是一个等式，它藏着三个层次的深意。

### 第一层：去噪 = 得分估计

训练一个去噪器 $D_\varepsilon$（让它逼近 $D_\varepsilon^*$），等价于在学习噪声扰动分布的得分函数 $s_\varepsilon(x)=\nabla\log p_\varepsilon(x)$。由 Tweedie：

$$s_\varepsilon(x) = \nabla\log p_\varepsilon(x) = \frac{D_\varepsilon(x) - x}{\varepsilon}$$

这意味着：**去噪器的训练目标 = 得分函数的估计目标**。第6章就靠这个等价性建立得分匹配理论——训练去噪器的损失，等价于得分匹配的损失。

### 第二层：绕过归一化常数

直接估 $s(x)=\nabla\log p(x)$ 需要归一化常数 $Z=\int\exp(-R(x))\,dx$——这个高维积分通常算不出（5.2 节讲过）。但用 Tweedie 间接估 $s_\varepsilon(x)=(D_\varepsilon(x)-x)/\varepsilon$ **完全不需要 $Z$**——只要有个训练好的去噪器 $D_\varepsilon$。

去噪器的训练是监督学习：给数据对 $(x, y=x+\sqrt{\varepsilon}\,z)$，最小化 $\mathbb{E}[\|D_\varepsilon(y)-x\|^2]$。这个过程不用知道 $p(x)$ 的解析形式，只要有能从 $p(x)$ 采样的训练数据。

### 第三层：数据驱动的先验梯度

去噪器从数据里学"干净信号长啥样"——这是对先验知识 $p(x)$ 的一种隐式表达。Tweedie 把这隐式先验知识翻译成显式的先验梯度（得分函数）：

$$\underbrace{D_\varepsilon(x)}_{\text{去噪器（隐式先验）}} \xrightarrow{\text{Tweedie}} \underbrace{s_\varepsilon(x) = \frac{D_\varepsilon(x) - x}{\varepsilon}}_{\text{得分函数（先验梯度）}}$$

这是从**显式先验**（写出 $p(x)$ 解析式）到**隐式先验**（通过去噪器隐式定义）的跨越——去噪器不用知道 $p(x)$ 长啥样，只要能去噪，Tweedie 就自动把去噪能力变成得分信息。

## 6. 从 Tweedie 到 PnP-ULA：一条计算链

Tweedie 给了一条"从去噪器到后验采样"的完整链路：

**步骤1：训练去噪器 $D_\varepsilon$**

- 从训练集 $\{x_i\}$ 采样干净信号；加噪声 $y=x+\sqrt{\varepsilon}\,z$；最小化 $\frac{1}{N}\sum_i\|D_\varepsilon(y_i)-x_i\|^2$；得到 $D_\varepsilon\approx D_\varepsilon^*$。

**步骤2：Tweedie 给出得分函数**

$$s_\varepsilon(x) = \nabla\log p_\varepsilon(x) = \frac{D_\varepsilon(x) - x}{\varepsilon}$$

**步骤3：把 $s_\varepsilon(x)$ 代入 ULA**

ULA 的后验得分分解为 $s(x|y)=\nabla\log p(y|x)+\nabla\log p(x)$。用 Tweedie 替换先验得分（这里粒子位置 $X_m$ 被当成"含噪样本"去噪）：

$$X_{m+1} = X_m + \delta\left[\nabla\log p(y|X_m) + \frac{D_\varepsilon(X_m) - X_m}{\varepsilon}\right] + \sqrt{2\delta}\,Z_{m+1}$$

这就是 **PnP-ULA**（Plug-and-Play ULA，即插即用朗之万算法）——5.5 节细讲。

> 这条链的核心洞见：**我们不用知道先验 $p(x)$ 的解析形式，只要有个好去噪器**。去噪器从数据学先验，Tweedie 把它变得分，ULA 用得分做后验采样。这是"隐式先验"完整的工作流。

## 7. 一维示例：高斯混合的 Tweedie（数值精确成立）

设先验为高斯混合 $p(x)=0.5\,\mathcal{N}(-3,1)+0.5\,\mathcal{N}(3,1)$，噪声 $\varepsilon=0.5$。噪声扰动分布 $p_\varepsilon(y)=0.5\,\mathcal{N}(-3,1+\varepsilon)+0.5\,\mathcal{N}(3,1+\varepsilon)$，得分可解析算。由于高斯先验配高斯似然是共轭的，各分量的后验条件均值由精度加权平均给出：

$$\mathbb{E}[x|y,k] = \frac{\varepsilon\mu_k + y}{1+\varepsilon}$$

MMSE 去噪器是各分量条件均值的加权平均：

$$D_\varepsilon^*(y) = \frac{0.5\,\mathcal{N}(y|-3,1+\varepsilon)\cdot\frac{\varepsilon(-3)+y}{1+\varepsilon} + 0.5\,\mathcal{N}(y|3,1+\varepsilon)\cdot\frac{\varepsilon\cdot 3+y}{1+\varepsilon}}{0.5\,\mathcal{N}(y|-3,1+\varepsilon)+0.5\,\mathcal{N}(y|3,1+\varepsilon)}$$

可以验证 $(D_\varepsilon^*(y)-y)/\varepsilon$ 恰好等于 $\nabla\log p_\varepsilon(y)$——Tweedie 数值上精确成立。特别地，当 $y=0$ 时由对称性 $D_\varepsilon^*(0)=0$（均值），且 $p_\varepsilon$ 在 0 处取极值故 $\nabla\log p_\varepsilon(0)=0$，两边独立为零，与等式吻合。

## 8. Tweedie 等式的历史与命名

- **Robbins (1956)** 在经验贝叶斯框架下首次推导此公式，用于不指定先验就估计后验均值；
- **Miyasawa (1961)** 独立给出更一般的形式；
- **Efron (2011)** 把它系统化并命名为"Tweedie 公式"（致谢与 Maurice Tweedie 的私下交流）；
- 在扩散模型社区被重新发现后，成了连接去噪与采样的核心工具；
- 注意：统计学里的"Tweedie 分布"（指数散布模型）和本等式无关，只是同名。

**来源**：Pock L2 P10-13; Pereyra L3 P12-21; Ratti P9-13; Robbins (1956); Efron (2011)

## 9. 收尾：为什么这件事重要

把整节塌缩成一句话：**一个好去噪器，就是一把现成的得分函数钥匙**——Tweedie 等式 $(D_\varepsilon(x)-x)/\varepsilon=\nabla\log p_\varepsilon(x)$ 把"修图"和"算梯度"这两件看似无关的事焊在了一起。这不仅是技巧，更是一次世界观升级：我们不必再为"先验得分算不出"发愁，只要能训练去噪器，得分就自动到手。下一节我们会发现，这个去噪器（MMSE 方向）和上一章的近端算子（MAP 方向）其实长着同一个骨架。
