# 5.0 本章导读：从离散迭代到连续动力学——得分函数的登场

> "我们已经造出了能用的采样机器（ULA），但这台机器内部究竟在运转着什么？"

上一章（第4章）我们一路从 Metropolis–Hastings 走到 ULA（无调整朗之万算法）与 MYULA，后验采样（从后验分布中抽取样本）的工具箱已基本配齐。回看 ULA 的核心递推式：

$$X_{m+1} = X_m + \delta\,\nabla\log p(X_m|y) + \sqrt{2\delta}\,Z_{m+1}$$

其中那一项 $\nabla\log p(x|y)$，是"后验概率密度的对数梯度"，我们给它起了一个名字——**得分函数**。上一章把 ULA 视为朗之万扩散（Langevin diffusion，一种带噪声的随机过程）的欧拉离散化（用固定步长近似连续过程的数值技巧），但始终绕开了两个核心问题：

- **连续视角**：Langevin SDE（随机微分方程）作为连续随机过程，其数学结构究竟是什么？
- **获取难题**：得分函数 $\nabla\log p(x|y)$，究竟如何得到？

本章沿"**理解它 → 获取它 → 用它 → 保证它可用**"这条线索，把这两个问题彻底讲透。从更深层次看，这两个问题分别对应信念形成的两个环节：先要弄清风从何处来（连续动力学的平稳分布），再要弄清风从数据中学得（得分函数的获取）——这正是本章要回答的整套认知路径。

**本章目标**（读完你应该能）：

- 说清 ULA 如何从离散迭代"连续化"为 Langevin SDE，以及为什么它的平稳分布（长时间演化后不再变化的概率分布）恰好是目标后验；
- 理解得分函数 $s(x)=\nabla_x\log p(x)$ 的几何含义——它是概率分布的"方向场"，在每一点指向密度增长最快的方向，也就是信念的梯度式更新方向；
- 用 Tweedie 等式把"去噪器"与"得分函数"桥接起来，明白"有一个好去噪器 = 有了得分函数"；
- 看清 MAP（后验众数）与 MMSE（后验均值）背后的结构对偶——信念的两种刻画方式只差一个"温度"；
- 把 PnP（即插即用）框架的思路跑通，并了解理论给它的收敛保证。

---

下面先给出一张"本章地图"，标明每一节在整条逻辑链中的位置：

- **Langevin SDE 的连续时间理论（5.1）**：ULA 不过是被离散化了的朗之万扩散。朗之万扩散本身是什么？它为什么以后验分布为平稳分布？Fokker-Planck 方程（描述概率密度随时间演化的偏微分方程）给出严格答案。从离散算法走到连续过程，是理解后续扩散模型（第7章）的必要一步。

- **得分函数：朗之万的动力（5.2）**：得分函数 $s(x)=\nabla_x\log p(x)$ 是概率分布的"方向场"——在空间每一点，它都指向密度增长最快的方向。朗之万动力学用它作漂移力（确定性的推力），用布朗运动（随机游走）作探索力，两者平衡即收敛到目标分布。对后验而言，得分函数可分解为"似然得分 + 先验得分"，而先验得分往往是瓶颈所在。

- **Tweedie 等式：从去噪器到得分函数（5.3）**：先验得分 $\nabla\log p(x)$ 通常无法直接写出，但 Tweedie 等式陈述了一个反直觉的事实——噪声扰动分布的得分 $\nabla\log p_\varepsilon(x)$，可以从一个不必知道分布解析形式的 MMSE 去噪器中提取出来：$\nabla\log p_\varepsilon(x)=(D_\varepsilon(x)-x)/\varepsilon$。换言之：**有了一个好的去噪器，你就有了得分函数**。这是连接"去噪"与"采样"的桥，也是全书从逆问题走向扩散模型的关键一跃——去噪器即隐式先验，先验作为结构化知识，可以被学习获得。

- **MAP 与 MMSE 的结构对偶性（5.4）**：近端算子（proximal operator，MAP 的一步近似）与去噪器（MMSE 的精确表达）具有同一个数学骨架，只是一个奔着众数、一个奔着均值。这一对偶表明，"优化"与"采样"是信念的两种刻画方式，处在同一条温度轴的两端。

- **PnP 框架（5.5）**：把上面两个洞见落地——用训练好的去噪器 $D_\varepsilon$ 直接替换 ULA 中的先验梯度 $\nabla\log p(x)$，得到 PnP-ULA。去噪器成为"隐式先验"：不必写出先验的解析形式，只要有一个能去噪的函数就够了。这是从显式先验到隐式先验的跨越，也是后续扩散模型的雏形。

- **近似理论与收敛保证（5.6）**：PnP-ULA 到底收不收敛、收得多准？Moreau-Yoshida 包络（光滑化不可微函数的工具）保证近似密度是真密度、对数凹且光滑；PnP 收敛定理把去噪器的 Lipschitz 性质（不"过度修正"的数学约束）与采样收敛绑定在一起——理论为实践兜底。

```
Langevin SDE(5.1) → 得分函数(5.2) → Tweedie等式(5.3) → MAP/MMSE对偶(5.4) → PnP框架(5.5) → 收敛保证(5.6)
```

读完本章你会明白一件事：朗之万动力学以得分函数为动力做后验采样，而得分函数又能从去噪器中提取（Tweedie 等式）。这一认识把采样路径推到关键转折点——从"用已知梯度采样"转向"从数据中学习梯度"，这正是第6章得分匹配的出发点。而 PnP 中"去噪器即先验"的思想，将在第7章扩散模型中演化为"去噪网络即得分估计器"。这一转变意味着，采样这条线背后，蕴含着一个更深的原理：**先验不必被精确书写，只需被一个可学习的去噪器隐式承载**——**采样这条线，正继续向扩散模型演化。** 而纵观第 5 章的六节，贯穿着同一条主线的三次亮相：Tweedie 等式说"去噪器给出得分"，MAP/MMSE 对偶说"去噪器与近端算子同一骨架"，PnP 说"去噪器即可采样先验"——三句话合起来，正是"去噪器即隐式先验即得分估计器"这个三位一体的全貌。
