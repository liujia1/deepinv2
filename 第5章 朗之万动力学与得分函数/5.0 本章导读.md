# 5.0 本章导读：从离散迭代到连续动力学——得分函数的登场

> "我们造出了能用的采样机器（ULA），可那台机器肚子里到底装着什么？"

上一章（第4章）我们一路从 Metropolis–Hastings 走到了 ULA（无调整朗之万算法）、MYULA，把后验采样（从后验分布里抽样的意思）的工具箱基本上配齐了。回看 ULA 那个核心递推式——它长这样：

$$X_{m+1} = X_m + \delta\,\nabla\log p(X_m|y) + \sqrt{2\delta}\,Z_{m+1}$$

括号里那一项 $\nabla\log p(x|y)$，就是"后验概率密度的对数梯度"，我们给它起了个名字，叫**得分函数**。上一章把 ULA 当作"朗之万扩散（Langevin diffusion，一种带噪声的随机过程）"的欧拉离散化（用数学步长近似连续过程的数值技巧），但一直绕着两个核心问题没正面回答：

- **连续视角**：Langevin SDE（随机微分方程）作为连续随机过程，它的数学结构到底是什么？
- **获取难题**：得分函数 $\nabla\log p(x|y)$ 这东西，到底怎么拿到手？

本章就沿着"**理解它 → 获取它 → 用它 → 保证它能用**"这条线，把这两个问题彻底讲透。

**本章目标**（读完你应该能）：

- 说清楚 ULA 是怎么从离散迭代"连续化"成 Langevin SDE 的，以及为什么它恰好把目标后验当平稳分布（长时间跑下去概率分布不变）；
- 理解得分函数 $s(x)=\nabla_x\log p(x)$ 的几何含义——它是概率分布的"方向场"，指向密度增长最快的方向；
- 用 Tweedie 等式把"去噪器"和"得分函数"桥接起来，明白"有个好去噪器 = 有了得分函数"；
- 看清 MAP（后验众数，最可能的那个值）与 MMSE（后验均值，平均意义上的最好值）背后的结构对偶；
- 把 PnP（即插即用）框架跑通思路，并知道理论给它的收敛保证。

---

下面先给你一张"本章地图"，让你知道每一节在链条里的位置：

- **Langevin SDE 的连续时间理论（5.1）**：ULA 不过是被离散化了的朗之万扩散。那朗之万扩散本身是个啥？它为什么把后验分布当平稳分布？Fokker-Planck 方程（描述概率密度随时间怎么变的偏微分方程）给了严格答案。从离散算法走到连续过程，是我们理解后续扩散模型（第7章）的必要一步。

- **得分函数：朗之万的动力（5.2）**：得分函数 $s(x)=\nabla_x\log p(x)$ 是概率分布的"方向场"——在空间每一点，它都指向密度增长最快的方向。朗之万动力学用它当漂移力（deterministic drift，确定的推力），用布朗运动（随机游走）当探索力，两者一平衡，就收敛到目标分布。对于后验，得分函数能拆成"似然得分 + 先验得分"，而先验得分往往是卡脖子那块。

- **Tweedie 等式：从去噪器到得分函数（5.3）**：先验得分 $\nabla\log p(x)$ 通常直接算不出来，但 Tweedie 等式说了个反直觉的事实——噪声扰动后的得分，居然能从不知道具体分布的 MMSE 去噪器里提取出来：$\nabla\log p_\varepsilon(x)=(D_\varepsilon(x)-x)/\varepsilon$。换句话说：**有了一个好的去噪器，你就有了得分函数**。这是连接"去噪"与"采样"的桥，也是全书从逆问题走向扩散模型的关键一跃。

- **MAP 与 MMSE 的结构对偶性（5.4）**：近端算子（proximal operator，MAP 的一步近似）和去噪器（MMSE 的精确表达）长着同一个数学骨架，只是一个奔着众数、一个奔着均值。这一对偶把"优化"和"采样"的内在统一撕开了给你看。

- **PnP 框架（5.5）**：把上面两个洞见落地——用训练好的去噪器 $D_\varepsilon$ 直接替换 ULA 里的先验梯度 $\nabla\log p(x)$，得到 PnP-ULA。去噪器成了"隐式先验"：不需要写出先验长啥样，只要有个能去噪的函数就够了。这是从显式先验到隐式先验的跨越，也是后续扩散模型的雏形。

- **近似理论与收敛保证（5.6）**：PnP-ULA 到底收不收敛、收得多准？Moreau-Yoshida 包络（光滑化不可微函数的工具）保证近似密度是真密度、对数凹（log-concave，形状像单峰碗）且光滑；PnP 收敛定理把去噪器的 Lipschitz 性质（不"过度修正"的数学约束）和采样收敛绑在一起——理论为实践兜底。

```
Langevin SDE(5.1) → 得分函数(5.2) → Tweedie等式(5.3) → MAP/MMSE对偶(5.4) → PnP框架(5.5) → 收敛保证(5.6)
```

读完本章你会明白一件事：朗之万动力学靠得分函数当动力做后验采样，而得分函数又能从去噪器里提出来（Tweedie 等式）。这个认识把采样路径推到了关键转折点——从"用已知的梯度采样"转向"从数据里学习梯度"，这正是第6章得分匹配的出发点。而 PnP 里"去噪器即先验"的思想，会在第7章扩散模型里演成"去噪网络即得分估计器"。**采样这条线，正继续向扩散模型演化。**
