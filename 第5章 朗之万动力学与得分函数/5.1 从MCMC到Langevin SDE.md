# 5.1 从 MCMC 到 Langevin SDE

> **从一个场景出发**：第 4 章我们得到了一台实用的采样机器——ULA，它一步步向高概率区域移动，迭代足够多次后便抽出了后验样本。但值得追问的是：如果让这台机器每步走得越来越小，小到趋于连续，它会变成什么数学对象？本节找出这个"连续化的极限"——**Langevin 随机微分方程**（Langevin SDE）。正是它，成为第 7 章扩散模型的直接前身。

**本节目标**：

- 看清 ULA 如何从离散迭代连续化为 Langevin SDE；
- 理解 SDE 的两种等价表述（势能视角 vs 得分视角），以及本书主用得分视角的原因；
- 用 Fokker-Planck 方程（描述概率密度随时间演化的偏微分方程）严格证明：这个 SDE 的平稳分布（长时间演化后不再变化的概率分布）恰好是目标后验；
- 理解离散化的代价，以及步长 $\delta$ 上"偏差 vs 效率"的权衡。

---

## 1. 从 ULA 递推到连续 SDE：把"跳步"变成"流动"

先回顾第 4 章的 ULA（无调整朗之万算法）。它是一个高效的后验采样方法，核心递推式为：

$$X_{m+1} = X_m + \delta\,\nabla\log p(X_m|y) + \sqrt{2\delta}\,Z_{m+1}, \quad Z_{m+1} \sim \mathcal{N}(0, I_n)$$

这个式子可以拆成两股力量的叠加：一股是**确定性漂移** $\delta\,\nabla\log p(X_m|y)$——顺着后验密度上升的方向走；一股是**随机扩散** $\sqrt{2\delta}\,Z_{m+1}$——随机扰动。既然迭代是离散的，一个自然的问题随之浮现：当步长 $\delta$ 趋于零时，这个迭代逼近什么连续过程？

### 时间参数化与连续极限

回答这个问题，只需把迭代序号重新解读为时间：令 $\Delta t = \delta$ 为时间步长，$t_m = m\delta$ 为第 $m$ 步对应的时刻，$X(t_m) = X_m$ 为该时刻的状态。于是 ULA 可写成：

$$X(t_{m+1}) = X(t_m) + \nabla\log p(X(t_m)|y)\,\Delta t + \sqrt{2\Delta t}\,Z_{m+1}$$

移项，看"单位时间内的变化率"：

$$\frac{X(t_{m+1}) - X(t_m)}{\Delta t} = \nabla\log p(X(t_m)|y) + \frac{\sqrt{2\Delta t}}{\Delta t}\,Z_{m+1}$$

关键在于随机项的分布身份：$\sqrt{2\Delta t}\,Z_{m+1}$ 的方差恰好是 $2\Delta t\,I_n$，而标准布朗运动（Brownian motion，永不停歇的随机抖动轨迹）在 $\Delta t$ 时间内的增量 $\Delta W_m = W_{t_{m+1}} - W_{t_m}$ 的方差是 $\Delta t\cdot I_n$，乘以 $\sqrt{2}$ 正是 $2\Delta t$。因此 $\sqrt{2\Delta t}\,Z_{m+1}$ 在分布意义下就是 $\sqrt{2}\,\Delta W_m$。于是：

$$X(t_{m+1}) - X(t_m) = \nabla\log p(X(t_m)|y)\,\Delta t + \sqrt{2}\,\Delta W_m$$

当 $\Delta t \to 0$，只要漂移系数 $\nabla\log p(\cdot|y)$ 满足全局 Lipschitz 条件（变化速率不过快的正则性假设），这个欧拉格式就以路径意义收敛到下面的连续时间方程：

$$\boxed{dX_t = \nabla\log p(X_t|y)\,dt + \sqrt{2}\,dW_t, \quad X_0 = x_0}$$

这就是 **Langevin 随机微分方程**（以物理学家 Paul Langevin 命名，他最初用这类方程描述布朗粒子受到的力）。$W_t$ 是 $\mathbb{R}^n$ 上的标准布朗运动。至此，"离散的一跳一跳"变成了"连续的漂移 + 随机游走"。从更深层次看，这一转变意味着后验采样不再只是一个数值算法，而是一个概率分布的时间演化过程——从此可以调用随机分析的全部工具来研究它。

### 两个等价视角：势能 vs 得分

同一个方程，换一种记号就是另一个故事，这一区分值得记牢：

**势能视角**：令 $U(x) = -\log p(x|y)$ 为后验的"势能函数"（负对数后验，形状像碗）。则：

$$dX_t = -\nabla U(X_t)\,dt + \sqrt{2}\,dW_t$$

这把 Langevin SDE 看成"在碗状势能面上、带噪声的梯度下降"——漂移项 $-\nabla U$ 把粒子推向碗底（后验众数 / MAP），噪声项 $\sqrt{2}\,dW_t$ 又不让它停在碗底，逼它探索整个碗。这个视角直接连接第 3 章的优化方法。

**得分视角**：令 $s(x|y) = \nabla\log p(x|y)$ 为后验的得分函数。则：

$$dX_t = s(X_t|y)\,dt + \sqrt{2}\,dW_t$$

这把 Langevin SDE 看成"由得分函数驱动的随机过程"——漂移项沿得分方向"爬坡"（推向高概率区域），噪声项负责随机探索。这个视角是理解第 7 章扩散模型的关键，因为扩散模型的核心正是"学出得分函数"。

两种写法完全等价（$s = -\nabla U$），只是叙述角度不同：势能视角连接优化，得分视角连接生成模型。历史上势能视角先出现（统计物理），得分视角后出现（机器学习），但数学上是同一个方程。本书后面主要使用得分视角，因为它直通第 6 章的得分匹配和第 7 章的扩散模型。

## 2. Langevin SDE 的平稳分布：Fokker-Planck 方程

### 一个根本性问题

Langevin SDE 定义了一个随机过程 $\{X_t\}$——但凭什么说，这个过程的"长时间行为"恰好是目标后验 $p(x|y)$？换句话说，如何证明 $p(x|y)$ 是 Langevin SDE 的**平稳分布**（stationary distribution，跑得足够久后不再变化的概率分布）？

要回答这个问题，得先搞清 SDE 如何"驱动"概率密度随时间演化。**Fokker-Planck 方程**（也叫前向 Kolmogorov 方程）正是连接 SDE 与概率密度演化的那座桥。

### Fokker-Planck 方程的直觉

设 $\rho_t(x)$ 是 $X_t$ 的概率密度（即 $P(X_t \in A) = \int_A \rho_t(x)\,dx$）。对 Langevin SDE $dX_t = s(X_t)\,dt + \sqrt{2}\,dW_t$（简写 $s(x)=\nabla\log p(x|y)$），$\rho_t$ 满足：

$$\frac{\partial \rho_t}{\partial t} = -\nabla\cdot[s(x)\,\rho_t] + \Delta\rho_t$$

右边第一项叫**漂移项**（advection，平流），描述得分力如何搬运密度；第二项叫**扩散项**（diffusion），描述布朗运动如何摊开密度。其背后的思想其实很朴素：对任意光滑测试函数 $\phi$，用 Itô 公式（随机版本的链式法则）得到 Kolmogorov 后向方程的弱形式，再分部积分，即得上面这个偏微分方程。（严格推导见附录 5A。）

### 验证后验分布是平稳分布

平稳分布的定义就是"不随时间变"：$\partial\rho_t/\partial t = 0$。直接验证 $\rho^*(x) = p(x|y)$ 满足它。把 $\rho^* = p(x|y)$ 代入方程右边：

$$-\nabla\cdot[s(x)\,p(x|y)] + \Delta p(x|y)$$

关键的一步观察：$s(x)\,p(x|y) = \nabla\log p(x|y) \cdot p(x|y) = \nabla p(x|y)$。于是：

$$-\nabla\cdot[\nabla p(x|y)] + \Delta p(x|y) = -\Delta p(x|y) + \Delta p(x|y) = 0 \quad \checkmark$$

**后验分布 $p(x|y)$ 确实是 Langevin SDE 的平稳分布。** 这一验证也说明，"以得分为漂移"的选择并非随意——它恰好是让漂移力与扩散力在平衡态相互抵消的那个漂移项。

### 物理直觉：聚拢 vs 分散的平衡

Fokker-Planck 方程描述的是两股"力"的拉锯：

- **漂移力** $-\nabla\cdot[s(x)\,\rho_t]$：得分函数把粒子推向高密度区——这是"聚拢"；
- **扩散力** $\Delta\rho_t$：布朗运动把粒子从高密度区往外赶——这是"分散"。

到了平稳态，聚拢与分散恰好抵消——粒子既不会全部坍缩到众数（因为有扩散力），也不会均匀散开（因为有漂移力）。这正是 $p(x|y)$ 描述的概率分布。

这个画面完美呼应了第 4 章的核心洞见：**优化算法 + 噪声 = 采样算法**。漂移力对应优化（推向众数），扩散力对应噪声（防止坍缩），两者的平衡产出"分布"。从更深层次看，信念的刻画在这里完成了从"一个最优点"到"一个完整分布"的升级——"后验即学习"在随机动力学层面的体现，正是这条平衡关系。

## 3. Langevin 扩散的指数收敛：为什么它真的会"到"目标分布

证明了 $p(x|y)$ 是平稳分布，下一个问题自然浮现：从任意初始分布 $\rho_0$ 出发，$\rho_t$ 会不会收敛到 $p(x|y)$？多快？

### 强对数凹条件下的指数收敛

**什么条件下收敛得快**：如果势能 $U(x) = -\log p(x|y)$ 满足两个正则性条件——碗够陡（强凸）且梯度变化受控（光滑）——收敛就快。具体说：

- **$m$-强凸**（strongly convex）：$\nabla^2 U(x) \succeq m\,I$（碗够"陡"）；
- **$L$-光滑**（smooth）：$\nabla^2 U(x) \preceq L\,I$（梯度变化不过快）。

那么 Langevin 扩散在 Wasserstein-2 距离（衡量两个分布"差距"的一种度量）下**指数收敛**：

$$W_2(\rho_t, p) \leq C\,e^{-mt}\,W_2(\rho_0, p)$$

收敛速率 $m$ 由势能的强凸性决定——**碗越陡（$m$ 越大），收得越快**。

> 补充说明 $L$-光滑的作用：速率 $e^{-mt}$ 本身只依赖 $m$，但 $L$-光滑在证明中不可或缺——它保证漂移系数 $\nabla\log p$ 全局 Lipschitz，从而确保 SDE 解存在且唯一。而且 $L$ 与 $m$ 一起定义条件数 $\kappa = L/m$，它决定了离散后 ULA 的步长上界 $\delta \le 1/L$，以及达到 $\varepsilon$ 精度所需的迭代次数（量级 $O(\kappa/\varepsilon)$）。

### 几何解释：碗里的粒子

强凸性意味着势能面是一个"碗"——梯度永远指向碗底（众数），且离碗底越远，拉力线性地越强。在这个碗里：

- 漂移力把粒子强力拉向碗底；
- 布朗运动让粒子在碗底附近游走；
- 平衡后，粒子的空间分布恰好是 $\exp(-U(x))$（吉布斯分布，Gibbs distribution）。

### 一般条件下呢？

当后验不满足全局强对数凹（比如图像逆问题中常见的多峰后验）时，Langevin 扩散照样收敛，只是速率可能不再是指数级。常用的分析手段有：

- **局部强凸 + 远端耗散**：势能在某个球外强凸、球内可以非凸——Durmus & Moulines (2019) 在此类耗散条件下给出多项式速率；
- **噪声扰动保覆盖**：第 4 章 4.4 节的 Moreau-Yoshida 光滑化能保证 $\nabla\log p_\lambda$ 的 Lipschitz 性，从而保证 ULA 收敛。

## 4. 从 Langevin 到 ULA：离散化的代价

Langevin SDE 是连续时间的"理想模型"，实际计算必须回到离散迭代——ULA 正是它的欧拉离散化。离散化会引入偏差，这是理论与实践之间的裂痕。

### 两种离散化策略

**ULA（无校正）**：

$$X_{m+1} = X_m + \delta\,\nabla\log p(X_m|y) + \sqrt{2\delta}\,Z_{m+1}$$

- 偏差：$O(\delta)$——步长越大偏差越大；
- 优点：每步计算简单，不需要接受/拒绝判断；
- 非渐近误差界（强对数凹情形）：$\|p_m - p\|_{\text{TV}} \le C_1 e^{-cm\delta} + C_2\delta$（Durmus & Moulines, 2019），第一项是收敛项（随迭代步数指数衰减），第二项是偏差项（只跟步长 $\delta$ 有关）。迭代足够多后，ULA 的渐近偏差上界约为 $\|\rho_m - p\|_{\text{TV}} \lesssim C_2\delta$。

**MALA（Metropolis 调整后的朗之万算法）**：在 ULA 之上再加一个 MH 接受/拒绝步：

1. 提议：$X^* = X_m + \delta\,\nabla\log p(X_m|y) + \sqrt{2\delta}\,Z_{m+1}$
2. 以概率 $\alpha = \min\{1, p(X^*|y)/p(X_m|y) \cdot q(X_m|X^*)/q(X^*|X_m)\}$ 接受

- 偏差：0（满足细致平衡，收敛到精确的 $p(x|y)$）；
- 代价：每步多算一次接受概率，且可能被拒绝（浪费计算）；在高维图像逆问题中接受率可能很低。

### 步长选择的权衡

- **什么时候用**：ULA 是日常默认采样器；MALA 适合对精度要求极高、且接受率尚可维持的场合。
- **为什么难**：步长 $\delta$ 是 ULA 的核心实践难题，本质上是"偏差 vs 效率"的取舍。
- **怎么做**：在偏差与效率之间取一个折中。

| 步长 | 偏差 | 收敛速度 | 总效果 |
|---|---|---|---|
| $\delta$ 很小 | 小 | 慢（每步挪得少） | 精确但低效 |
| $\delta$ 很大 | 大 | 快（每步挪得多） | 高效但不精确 |
| $\delta = 1/L$ | 中等 | 适中 | 实践推荐 |

其中 $L$ 是 $\nabla\log p(x|y)$ 的 Lipschitz 常数。$\delta \le 1/L$ 是保证 ULA 不发散的必要条件（与第 3 章 3.2 节梯度下降的步长条件完全一致）。

### 与第 7 章的预告

单步 Langevin 受困于步长两难：大步长偏差大，小步长收敛慢。扩散模型用**多时间步噪声调度**破解这一困境——早期用大噪声水平（允许大步长），后期用小噪声水平（保证精度）。第 7 章细讲。

### Langevin SDE 与梯度流的联系（补充阅读，主线非必需）

Langevin SDE 与概率测度空间上的"梯度流"有深刻联系，它揭示了"优化 → 采样"转化的数学本质。

**势能的 Wasserstein 梯度流**是最小化期望势能 $\int U\,d\rho$ 的梯度流。粒子沿 $-\nabla U$ 运动（梯度下降），质量流 $J = -\rho\nabla U$，由连续性方程得：

$$\frac{\partial \rho_t}{\partial t} = \nabla\cdot(\rho_t\,\nabla U) = \nabla\cdot(\rho_t\,\nabla(-\log p))$$

注意这只有漂移、没有扩散项——这是一个**纯漂移**过程，质量在势能极小值处汇聚，最终所有质量坍缩到众数（MAP）。

**KL 散度的 Wasserstein 梯度流**则同时包含漂移与扩散：

$$\frac{\partial \rho_t}{\partial t} = \underbrace{\nabla\cdot(\rho_t\,\nabla U)}_{\text{漂移（聚拢）}} + \underbrace{\Delta\rho_t}_{\text{扩散（分散）}}$$

这恰好就是 Langevin SDE 的 Fokker-Planck 方程。扩散项来自 KL 散度中熵项的梯度，是 Langevin 相对纯梯度流的关键补充——它把收敛目标从"众数"变成"分布"。这再次呼应第 4 章：**优化算法 + 噪声 = 采样算法**。

**来源**：Pereyra L1 P40-50; Pock L2 P14; LectureNotes2020_v2 Sec 8.2; Risken (1996); Durmus & Moulines (2019)

## 5. 收尾：为什么这件事重要

至此，Langevin SDE 的框架立起来了：它以得分函数 $\nabla\log p(x|y)$ 为漂移力，以布朗运动为随机探索，平稳分布恰好是目标后验。把整节压缩成一句话：离散的 ULA 只是连续朗之万动力学的一帧快照，而驱动这一切的"力"，就是下一节要彻底看清的得分函数。但这个框架把"得分函数"当成了已知量——它究竟是什么、从何而来？下一节我们打开这个黑箱。
