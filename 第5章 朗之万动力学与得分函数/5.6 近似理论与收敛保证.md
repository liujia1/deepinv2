## 1. Moreau-Yoshida 包络回顾：从算法到理论

第4章 4.4 节从算法角度讲了 Moreau-Yoshida 包络——用来光滑化不可微函数，让 ULA 能用。第3章 3.4 节从优化角度讲了近端算子及其与 Moreau 包络的关系。本节从概率密度角度深化，为 PnP 收敛分析打地基。

### 定义

对下半连续真函数 $g:\mathbb{R}^n\to\mathbb{R}\cup\{+\infty\}$，其 **Moreau-Yoshida 包络**定义为：

$$g_\lambda(x) = \inf_{u\in\mathbb{R}^n}\left\{g(u) + \frac{1}{2\lambda}\|u - x\|^2\right\}$$

$\lambda>0$ 是光滑化参数。$g_\lambda$ 是 $g$ 的光滑近似，$\lambda$ 越小越精确。

### 近端算子与梯度的关系

Moreau-Yoshida 包络的梯度有闭式：

$$\nabla g_\lambda(x) = \frac{x - \text{prox}_{\lambda g}(x)}{\lambda}$$

其中 $\text{prox}_{\lambda g}(x)=\arg\min_u\{g(u)+\frac{1}{2\lambda}\|u-x\|^2\}$ 是近端算子。这个关系在 5.4 节已通过 MAP/MMSE 对偶讨论过——近端算子是 Moreau 包络梯度的一步实现。

## 2. 近似密度的性质：为什么光滑化不破坏采样

### 近似后验的定义

设原始后验 $p(x|y)\propto\exp\{-f(x)-g(x)\}$，其中 $f$ 光滑、$g$ 不可微。定义近似后验：

$$p_\lambda(x|y) = \frac{\exp\{-f(x) - g_\lambda(x)\}}{\int\exp\{-f(x) - g_\lambda(x)\}\,dx}$$

### 性质1：真密度

**命题**：对所有 $\lambda>0$，$p_\lambda(x|y)$ 是良定义的概率密度。

**证明思路**：$g_\lambda(x)\le g(x)$（从下方逼近）→ $\exp(-g_\lambda)\ge\exp(-g)$；$g_\lambda(x)\ge\inf g>-\infty$ → $\exp(-g_\lambda)$ 有上界；$\int\exp\{-f-g_\lambda\}\,dx<\infty$（远处增长够快）。所以归一化常数有限，是良定义密度。

### 性质2：对数凹性

**命题**：若 $f+g$ 是对数凹（$-\log p(x|y)$ 凸），则 $f+g_\lambda$ 也是对数凹。

**证明思路**：infimal 卷积保持凸性；$f$ 凸 + $g_\lambda$ 凸 → $f+g_\lambda$ 凸 → $p_\lambda$ 对数凹。

对数凹是 ULA 收敛的关键条件——第4章 4.3 节提到，ULA 在强对数凹下有非渐近收敛保证。Moreau-Yoshida 包络保持对数凹性，意味着光滑化不破坏 ULA 的收敛条件。

### 性质3：光滑性

**命题**：$g_\lambda\in C^1$（即使 $g$ 不可微），且 $\nabla g_\lambda$ 是 $\frac{1}{\lambda}$-Lipschitz。

**证明**：$g_\lambda$ 是 $g$ 与二次函数的 infimal 卷积，二次强凸性保证光滑；$\nabla g_\lambda=(x-\text{prox}_{\lambda g}(x))/\lambda$；近端算子是 1-Lipschitz（非扩张），故 $\nabla g_\lambda$ 是 $1/\lambda$-Lipschitz。光滑性是 ULA 的前提——ULA 要 $\nabla\log p$ 存在且 Lipschitz。

### 性质4：梯度 Lipschitz

**命题**：$\nabla\log p_\lambda(x|y)$ 是 $L$-Lipschitz，$L\le L_f+1/\lambda$。

**证明**：$\nabla\log p_\lambda=-\nabla f-\nabla g_\lambda$；$\nabla f$ 是 $L_f$-Lipschitz；$\nabla g_\lambda$ 是 $1/\lambda$-Lipschitz；故 $\nabla\log p_\lambda$ 的 Lipschitz 常数 $\le L_f+1/\lambda$。

这个 Lipschitz 常数直接决定 ULA 步长条件：$\delta\le 1/L=1/(L_f+1/\lambda)$。

## 3. 近似误差界：精度与效率的权衡

### 总变差距离上界

在 $f+g$ 强对数凹（即强凸）条件下：

**定理**（Durmus et al., 2018）：若 $g$ 是 $L_g$-Lipschitz，则：

$$\|p_\lambda - p\|_{\text{TV}} \le \lambda\,L_g^2$$

$\|\cdot\|_{\text{TV}}$ 是总变差距离（衡量两个分布差异的一种指标）。

### 误差的直觉

- $\lambda$ 小 → 近似误差小（$p_\lambda$ 接近 $p$），但 $L=L_f+1/\lambda$ 大 → 步长 $\delta$ 必须小 → 收敛慢；
- $\lambda$ 大 → $L$ 小 → 步长可以大 → 收敛快，但近似误差大。

这是**近似精度与计算效率的权衡**——$\lambda$ 同时控制两头。

```
近似误差 ‖p_λ - p‖_TV
    ↑
    │ ╲
    │   ╲
    │     ╲ ─ ─ ─ ─ ─ 上界 λL_g²
    └──────────────────→ λ
    0

收敛速度（步长上界 δ_max = 1/L）
    ↑
    │         ╱
    │       ╱ ─ ─ ─ ─ ─ ─ ─ δ_max = 1/(L_f + 1/λ)
    │     ╱
    │   ╱
    └──────────────────→ λ
    0
```

### $\lambda$ 的选择策略

- **理论最优**：$\lambda\sim\sqrt{\delta}$（平衡近似误差 $O(\lambda)$ 和离散误差 $O(\delta)$）；
- **实践经验**：$\lambda=\varepsilon$（与去噪器噪声水平一致——Tweedie 里的噪声方差）；
- **自适应**：初期大 $\lambda$（快收敛到正确区），后期减小（提精度）；
- **与 PnP 的联系**：PnP-ULA 里 $\varepsilon$ 同时扮演 $\lambda$ 的角色——去噪器噪声水平就是光滑化参数。

## 4. PnP-ULA 的收敛性：去噪器当"黑箱"行不行

### 问题的本质

PnP-ULA 用学习去噪器 $D_\varepsilon$ 替换了 MYULA 里的近端算子 $\text{prox}_{\lambda g}$。近端算子有完整数学理论（第3章），但去噪器是个"黑箱"——它的数学性质是什么？PnP-ULA 还收敛吗？

### 关键假设：去噪器的 Lipschitz 性

PnP 收敛的核心是去噪器 Lipschitz 常数有上界：

$$\|D_\varepsilon(x) - D_\varepsilon(x')\| \le \eta\,\|x - x'\|, \quad \forall x, x'$$

且 $\eta<1$——去噪器必须是**压缩映射**（contraction）。

物理含义：**去噪器不能"过度修正"**——输入变 1 单位，输出变化不超过 $\eta<1$ 单位。如果去噪器太激进（$\eta>1$），可能放大误差，导致 PnP-ULA 发散。

### 收敛定理

**定理**（Laumont et al., 2021）：设去噪器 $D_\varepsilon$ 是 $\eta$-Lipschitz（$\eta<1$），似然梯度 $\nabla f$ 是 $L_f$-Lipschitz。则 PnP-ULA 生成的样本分布收敛到某目标分布 $\tilde{p}$，且：

$$\|\tilde{p} - p\|_{\text{TV}} \le C(\varepsilon, \delta, \eta)$$

误差 $C$ 依赖：

- $\varepsilon$：去噪器噪声水平（控制 Tweedie 近似精度）；
- $\delta$：ULA 步长（控制离散化误差）；
- $\eta$：去噪器 Lipschitz 常数（控制先验近似精度）。

当 $\varepsilon\to 0$（得分近似精确）、$\delta\to 0$（离散化精确）时：$\tilde{p}\to p$——PnP-ULA 收敛到真实后验。$\eta<1$ 是收敛存在的前提；$\eta$ 越小误差界常数 $C$ 越小（量的差异，非是否收敛）。

### 误差的分解

PnP-ULA 总误差可拆三类：

1. **Tweedie 近似误差**：$\nabla\log p_\varepsilon(x)\approx\nabla\log p(x)$——噪声扰动引入的偏差，由 $\varepsilon$ 控制；
2. **离散化误差**：ULA 是 Langevin SDE 的欧拉离散——由 $\delta$ 控制；
3. **去噪器近似误差**：$D_\varepsilon\neq D_\varepsilon^*$——学到的去噪器与理想 MMSE 去噪器的差距，由训练质量和 $\eta$ 控制。

三类误差独立可控，给 PnP-ULA 的实践改进指明方向。

## 5. 后验采样 vs 点估计：不确定性量化

### MAP vs MMSE：两种哲学的答案

逆问题里我们面对两种答案哲学：

**MAP 估计（第3–5章优化路径）**：

$$\hat{x}_{\text{MAP}} = \arg\max_x \log p(x|y) = \arg\min_x \{f(x) + g(x)\}$$

- 给"最可能的"重建——后验众数；
- 是**点估计**：只返回一个值，不给置信信息；
- PnP-ADMM、近端梯度下降都属此路径。

**MMSE 估计（第5章采样路径）**：

$$\hat{x}_{\text{MMSE}} = \mathbb{E}[x|y] = \int x\,p(x|y)\,dx$$

- 给"平均意义下最好"的重建——后验均值；
- 是**估计+不确定性**：均值是点估计，方差是置信度；
- PnP-ULA、MALA 等采样算法都属此路径。

### PnP-ULA 如何同时给 MAP 和 MMSE

PnP-ULA 的样本链 $\{X_0,X_1,\dots,X_M\}$ 同时编码两种估计：

| 估计 | 计算方式 | 物理意义 |
|---|---|---|
| MAP | 最后几个样本（或 ADMM 变体） | 最可能的重建，保留更多细节 |
| MMSE | $\frac{1}{M-B}\sum_{m=B+1}^{M} X_m$ | 平均意义下的重建，更平滑 |

> **关键洞察**：后验均值天然平滑多峰不确定性。后验多峰时（同一观测对应多个可能重建），MAP 只取最高峰，MMSE 平均所有峰——所以 MMSE 视觉上通常更平滑。

### 像素级不确定性：后验方差

PnP-ULA 采样后可估每个像素的后验方差：

$$\widehat{\text{Var}}(x_i) = \frac{1}{M-B}\sum_{m=B+1}^{M} (X_m^{(i)} - \hat{x}_{\text{MMSE}}^{(i)})^2$$

**后验方差图的意义**：高方差区 = 高不确定区 = 正向算子 $A$ 导致信息丢失区；低方差区 = 数据约束强、先验影响小。实验中常见：模糊核导致的频率缺失区对应高方差。

> **配套实验：实验 5.6-1 不确定性可视化**（素材 `配套实验/实验5.6-1/5.6-1.py`）：从实验 5.5-1 的 `sampling_results.npz` 算像素级后验标准差，生成不确定性热图。结果：后验标准差均值 0.0151，高不确定像素占比 10.1%，不确定性-误差 Pearson 相关系数 **0.422**（落在预期 0.4–0.7），验证了"后验方差是可靠误差代理"。注意样本仅 37 个（建议 ≥100），统计波动较大。

### 置信区间：从方差到区间估计

由中心极限定理，后验均值近似正态。95% 置信区间：

$$\hat{x}_{\text{MMSE}}^{(i)} \pm 1.96\,\sqrt{\widehat{\text{Var}}(x_i)}$$

区间宽度 $w_i = 3.92\,\sqrt{\widehat{\text{Var}}(x_i)}$ 直观反映局部不确定性，高风险场景（医疗）可把高不确定区交专家复核。

> **配套实验：实验 5.6-2 置信区间与后验样本多样性**（`配套实验/实验5.6-2/5.6-2.py`）：对比正态近似（±1.96σ）与样本分位数两种 95% 置信区间。结果：平均宽度正态近似 0.0591 vs 分位数 0.0510（正态略宽，因假设正态）；后验标准差与样本标准差相关系数 **1.000**，强验证"样本差异大的像素 = 高后验方差像素"。

### 后验样本多样性与多峰性

PnP-ULA 的多个后验样本直观展示后验结构：

```
后验样本 {X_{B+1}, ..., X_M} 的特征：
  ├── 共享相似的全局结构：先验约束把所有样本拉向相似大尺度模式
  ├── 细节存在差异：数据不足以唯一确定信号时，后验多峰
  └── 差异区域 = 高不确定区域：样本差异大的像素 = 高后验方差像素
```

在图像去卷积实验中，PnP-ULA 样本显示：后验均值（MMSE）比含噪观测清晰但边缘比 MAP 略平滑；后验标准差在边缘/纹理区高、平坦区低；不确定性-误差相关约 0.55；样本边缘位置有 1–2 像素偏移——正是模糊逆问题常见的多峰后验。

### 不确定性量化的实践指导意义

| 应用场景 | 利用不确定性 |
|---|---|
| 医学影像重建 | 高不确定区标"需医生复核" |
| 遥感图像解译 | 不确定图指导采样——高不确定区增采样 |
| 科学计算 | 不确定性量化是结果可信度核心指标 |
| 主动学习 | 选高不确定样本主动标注或重测 |

> **配套实验：实验 5.6-3 MAP vs MMSE 综合对比**（`配套实验/实验5.6-3/5.6-3.py`）：从 `sampling_results.npz` 算 MMSE（后验均值），用含噪观测作 MAP 替代基准。结果：MMSE PSNR **26.57 dB** vs 含噪观测 21.61 dB（高 4.96 dB），NRMSE 0.1745 vs 0.3091。清晰展示贝叶斯推断（正则化）的价值。注：含噪观测作基准是教学选择（ULA 样本难直接得 MAP）；步骤6 参数敏感性曲线是理论示意（已标注），非真实跑数。

## 6. 从 PnP 到多尺度得分：展望

PnP-ULA 用单一噪声水平 $\varepsilon$ 的去噪器，对应单一尺度得分 $s_\varepsilon(x)=\nabla\log p_\varepsilon(x)$。对复杂分布有局限：

- **单一尺度**：大 $\varepsilon$ 抓全局丢细节，小 $\varepsilon$ 保细节但全局探索不足；
- **步长困境**：$\varepsilon$ 小→$1/\varepsilon$ 大→步长必须小→收敛慢；
- **混合质量**：不同区域"最优噪声水平"不同——平坦区要大 $\varepsilon$，边缘区要小 $\varepsilon$。

这些局限指向自然的发展方向：用**多个噪声水平**的得分函数，逐步从全局到局部采样。下一章展示如何系统训练多尺度得分估计器（得分匹配），第7章展示这多尺度策略如何演成扩散模型的连续时间框架。

### Lipschitz 去噪器的正则化：怎么让去噪器"别过度修正"

约束 $\text{Lip}(D_\varepsilon)\le\eta<1$ 是 PnP 收敛核心条件。实践里几种办法：

- **方法1 权重裁剪（Weight Clipping）**：训练后把权重裁到 $[-c,c]$；简单但可能损性能；
- **方法2 谱归一化（Spectral Normalization）**：对每层卷积/线性层谱范数约束 $\bar{W}=W/\max(\sigma_{\max}(W),1)$；最常用，效果好且对性能影响小；
- **方法3 梯度惩罚（Gradient Penalty）**：训练损失加 $\mathcal{L}_{\text{total}}=\mathcal{L}_{\text{denoise}}+\lambda_{\text{gp}}\,\mathbb{E}[\|\nabla_x D_\varepsilon(x)\|^2]$；灵活但需调 $\lambda_{\text{gp}}$。

实践中谱归一化是 PnP 去噪器最常用的 Lipschitz 约束方法。

**来源**：Pereyra L1 P43-44; Pereyra L3 P9-11; Durmus et al. (2018); Laumont et al. (2021); Ryu et al. (2019)

## 8. 动手感受一下：用 Langevin 动力学从已知分布采样

下面这段代码复现本章核心现象之一：**Langevin 动力学靠"得分函数"当动力，就能从一个已知分布里抽出样本，样本直方图会渐渐趋近真实密度**。我们用最简单的目标——1D 标准高斯 $N(0,1)$，它的得分函数有解析形式 $s(x)=-x$（指向均值 0）。代码只用 numpy，可选运行。

```python
# -*- coding: utf-8 -*-
# 用 Langevin 动力学从标准高斯 N(0,1) 采样，验证"得分函数驱动采样"这一章核心思想。
# 依赖：仅 numpy 和 matplotlib（可选绘图）。

import numpy as np
import matplotlib.pyplot as plt

# ---- 1. 目标分布的"得分函数" ----
# 标准高斯的负对数概率是 0.5*x^2，其梯度（势能梯度）是 x；
# 得分函数 s(x) = - 势能梯度 = -x，恰好指向均值 0（5.2 节的"指南针"）。
def score(x):
    return -x

# ---- 2. Langevin 采样的离散递推（就是 ULA，5.1 节） ----
# X_{m+1} = X_m + delta * s(X_m) + sqrt(2*delta) * Z
# 第一项顺得分"爬坡"，第二项布朗运动随机探索，两项平衡 => 收敛到目标分布。
def langevin_sample(n_steps=20000, delta=0.05, x0=3.0, seed=0):
    rng = np.random.default_rng(seed)
    x = x0                      # 从任意初始点出发（这里故意离均值很远）
    samples = np.empty(n_steps)
    for m in range(n_steps):
        z = rng.standard_normal()                 # 标准正态随机增量
        x = x + delta * score(x) + np.sqrt(2 * delta) * z
        samples[m] = x
    return samples

# 跑一条采样链；丢弃前 20% 当作 burn-in（链还没进入平稳）
samples = langevin_sample(n_steps=30000, delta=0.05, x0=3.0)
burn = int(0.2 * len(samples))
chain = samples[burn:]

# ---- 3. 和真实密度对比 ----
# 标准高斯真实密度 phi(x) = exp(-x^2/2)/sqrt(2*pi)
xx = np.linspace(-4, 4, 400)
true_density = np.exp(-xx**2 / 2) / np.sqrt(2 * np.pi)

print(f"采样均值 ≈ {chain.mean():.3f}  (目标 0)")
print(f"采样标准差 ≈ {chain.std():.3f}  (目标 1)")

plt.figure(figsize=(7, 4))
plt.hist(chain, bins=60, density=True, alpha=0.6, label="Langevin 样本直方图")
plt.plot(xx, true_density, 'r-', lw=2, label="真实密度 N(0,1)")
plt.xlabel("x"); plt.ylabel("密度")
plt.title("Langevin 采样：样本直方图趋近真实密度 (得分 s(x)=-x)")
plt.legend(); plt.tight_layout(); plt.show()

# ---- 4. 拓展：Tweedie 关系的小验证（5.3 节） ----
# 对先验 N(0,1)、噪声 eps，MMSE 去噪器 D(y)=y/(1+eps)；
# Tweedie 说 (D(y)-y)/eps 应当等于得分 s_eps(y) = -y/(1+eps)。
eps = 0.5
y = np.array([-2.0, 0.0, 1.5])
D = y / (1 + eps)                       # 去噪器输出
s_from_denoiser = (D - y) / eps         # Tweedie 算出的得分
s_exact = -y / (1 + eps)                # 解析得分
print("Tweedie 残差/eps =", np.round(s_from_denoiser, 4))
print("精确得分       =", np.round(s_exact, 4))
# 两者应完全相等——去噪器的输出与输入之差（除以噪声方差）就是得分方向。
```

跑完你会看到：尽管初始点设在 $x_0=3$（离均值很远），采样直方图仍稳稳贴合标准高斯钟形曲线，采样均值≈0、标准差≈1。这就把全章那句话落了地——**得分函数当动力，Langevin 动力学就能从任意起点收敛到目标分布**。代码末尾还顺手验证了 Tweedie 关系：去噪器残差除以噪声方差，恰好等于解析得分。

## 9. 收尾：为什么这件事重要

把整节塌缩成一句话：**理论上，光滑化（Moreau-Yoshida）保证 ULA 还能跑、PnP 收敛定理保证"黑箱去噪器"也能收敛——只要去噪器别过度修正（Lipschitz 收缩）**。这意味着 PnP 不是拍脑袋的工程技巧，而是有理论兜底的概率推断方法；而它顺手给出的后验方差、置信区间与样本多样性，正是点估计（MAP）永远给不了的不确定性量化。但全章仍留一个根问题：去噪器到底怎么从数据里来？下一章的得分匹配，正是这条路的系统化答案。
