# 5.6 近似理论与收敛保证

> **核心观点**：PnP-ULA的收敛性依赖于去噪器对得分函数的近似质量。本节给出两层保证：第一层，Moreau-Yoshida包络理论证明光滑化后的近似密度是真密度、对数凹且光滑，近似误差可控；第二层，PnP收敛定理将去噪器的Lipschitz性质与采样收敛联系起来——当去噪器充分Lipschitz时，PnP-ULA的样本分布收敛到真实后验的邻域。

## Moreau-Yoshida包络回顾

### 从算法到理论

第4章4.4节从算法角度介绍了Moreau-Yoshida包络——用于光滑化不可微函数以使ULA可用。第3章3.4节从优化角度介绍了近端算子及其与Moreau包络的关系。本节从概率密度角度深化这一理论，为PnP的收敛性分析提供基础。

### 定义

对下半连续真函数 $g: \mathbb{R}^n \to \mathbb{R} \cup \{+\infty\}$，其**Moreau-Yoshida包络**定义为：

$$g_\lambda(x) = \inf_{u \in \mathbb{R}^n}\left\{g(u) + \frac{1}{2\lambda}\|u - x\|^2\right\}$$

其中 $\lambda > 0$ 是光滑化参数。$g_\lambda$ 是 $g$ 的光滑近似，$\lambda$ 越小近似越精确。

### 近端算子与梯度的关系

Moreau-Yoshida包络的梯度有闭式表达：

$$\nabla g_\lambda(x) = \frac{x - \text{prox}_{\lambda g}(x)}{\lambda}$$

其中 $\text{prox}_{\lambda g}(x) = \arg\min_u\{g(u) + \frac{1}{2\lambda}\|u - x\|^2\}$ 是近端算子。

这个关系在5.4节已经通过MAP/MMSE对偶性讨论过——近端算子是Moreau包络梯度的一步实现。

## 近似密度的性质

### 近似后验的定义

设原始后验 $p(x|y) \propto \exp\{-f(x) - g(x)\}$，其中 $f$ 光滑、$g$ 不可微。定义近似后验：

$$p_\lambda(x|y) = \frac{\exp\{-f(x) - g_\lambda(x)\}}{\int\exp\{-f(x) - g_\lambda(x)\}\,dx}$$

### 性质1：真密度

**命题**：对所有 $\lambda > 0$，$p_\lambda(x|y)$ 是良定义的概率密度。

**证明思路**：
- $g_\lambda(x) \leq g(x)$（下界：Moreau包络不超过原函数）→ $\exp(-g_\lambda) \geq \exp(-g)$
- $g_\lambda(x) \geq \inf g > -\infty$（真函数有下界）→ $\exp(-g_\lambda)$ 有上界
- $\int\exp\{-f(x) - g_\lambda(x)\}\,dx < \infty$（因为 $f + g_\lambda$ 在远处增长足够快）

因此 $p_\lambda$ 的归一化常数有限，是良定义的概率密度。

### 性质2：对数凹性

**命题**：若 $f + g$ 是对数凹的（$-\log p(x|y)$ 是凸函数），则 $f + g_\lambda$ 也是对数凹的。

**证明思路**：
- $g_\lambda$ 是 $g$ 与二次函数的infimal卷积——infimal卷积保持凸性
- $f$ 凸 + $g_\lambda$ 凸 → $f + g_\lambda$ 凸 → $p_\lambda$ 对数凹

对数凹性是ULA收敛性的关键条件——第4章4.3节提到，ULA在强对数凹条件下有非渐近收敛保证。Moreau-Yoshida包络保持对数凹性，意味着光滑化不破坏ULA的收敛条件。

### 性质3：光滑性

**命题**：$g_\lambda \in C^1$（即使 $g$ 不可微），且 $\nabla g_\lambda$ 是 $\frac{1}{\lambda}$-Lipschitz的。

**证明**：
- $g_\lambda$ 是 $g$ 与二次函数的infimal卷积，二次函数的强凸性保证了光滑性
- $\nabla g_\lambda(x) = (x - \text{prox}_{\lambda g}(x))/\lambda$
- 近端算子是 $1$-Lipschitz的（非扩张映射），因此 $\nabla g_\lambda$ 是 $1/\lambda$-Lipschitz的

光滑性是ULA的前提条件——ULA需要 $\nabla\log p$ 存在且Lipschitz连续。Moreau-Yoshida包络保证了这一条件。

### 性质4：梯度Lipschitz

**命题**：$\nabla\log p_\lambda(x|y)$ 是 $L$-Lipschitz的，其中 $L \leq L_f + 1/\lambda$。

**证明**：
- $\nabla\log p_\lambda = -\nabla f - \nabla g_\lambda$
- $\nabla f$ 是 $L_f$-Lipschitz的（假设）
- $\nabla g_\lambda$ 是 $1/\lambda$-Lipschitz的（性质3）
- 因此 $\nabla\log p_\lambda$ 的Lipschitz常数 $\leq L_f + 1/\lambda$

这个Lipschitz常数直接决定了ULA的步长条件：$\delta \leq 1/L = 1/(L_f + 1/\lambda)$。

## 近似误差界

### 总变差距离上界

**定理**（Durmus et al., 2018）：若 $g$ 是 $L_g$-Lipschitz的，则：

$$\|p_\lambda - p\|_{\text{TV}} \leq \lambda\,L_g^2$$

其中 $\|\cdot\|_{\text{TV}}$ 是总变差距离。

### 误差的直觉

- $\lambda$ 小 → 近似误差小（$p_\lambda$ 接近 $p$），但 $L = L_f + 1/\lambda$ 大 → 步长 $\delta$ 必须小 → 收敛慢
- $\lambda$ 大 → $L$ 小 → 步长 $\delta$ 可以大 → 收敛快，但近似误差大

这是**近似精度与计算效率的权衡**——$\lambda$ 控制这一trade-off。

### 权衡的可视化

```
近似误差 ‖p_λ - p‖_TV
    ↑
    │ ╲
    │   ╲
    │     ╲
    │       ╲ ─ ─ ─ ─ ─ 上界 λL_g²
    │
    └──────────────────→ λ
    0

收敛速度（步长上界 δ_max = 1/L）
    ↑
    │         ╱
    │       ╱
    │     ╱
    │   ╱
    │ ╱ ─ ─ ─ ─ ─ ─ ─ δ_max = 1/(L_f + 1/λ)
    │
    └──────────────────→ λ
    0
```

$\lambda$ 增大：误差增大，但步长可以增大（收敛加快）。最优 $\lambda$ 在两者之间。

### $\lambda$ 的选择策略

- **理论最优**：$\lambda \sim \sqrt{\delta}$（平衡近似误差 $O(\lambda)$ 和离散误差 $O(\delta)$）
- **实践经验**：$\lambda = \varepsilon$（与去噪器的噪声水平一致——Tweedie等式中的噪声方差）
- **自适应策略**：初期用大 $\lambda$（快速收敛到正确区域），后期减小 $\lambda$（提高近似精度）
- **与PnP的联系**：PnP-ULA中，$\varepsilon$ 同时扮演 $\lambda$ 的角色——去噪器的噪声水平就是光滑化参数

## PnP-ULA的收敛性

### 问题的本质

PnP-ULA用学习去噪器 $D_\varepsilon$ 替换了MYULA中的近端算子 $\text{prox}_{\lambda g}$。近端算子有完整的数学理论（第3章），但去噪器是一个"黑箱"——它的数学性质是什么？PnP-ULA是否还收敛？

### 关键假设：去噪器的Lipschitz性

PnP收敛的核心条件是去噪器的Lipschitz常数有上界：

$$\|D_\varepsilon(x) - D_\varepsilon(x')\| \leq \eta\,\|x - x'\|, \quad \forall x, x'$$

其中 $\eta < 1$——去噪器必须是**压缩映射**（contraction）。

这个条件的物理含义是：**去噪器不能"过度修正"**——输入变化1个单位，输出的变化不超过 $\eta < 1$ 个单位。如果去噪器过于激进（$\eta > 1$），它可能放大误差，导致PnP-ULA发散。

### 收敛定理

**定理**（Laumont et al., 2021）：设去噪器 $D_\varepsilon$ 是 $\eta$-Lipschitz的（$\eta < 1$），似然梯度 $\nabla f$ 是 $L_f$-Lipschitz的。则PnP-ULA生成的样本分布收敛到某个目标分布 $\tilde{p}$，且：

$$\|\tilde{p} - p\|_{\text{TV}} \leq C(\varepsilon, \delta, \eta)$$

其中误差 $C$ 依赖于：
- $\varepsilon$：去噪器的噪声水平（控制Tweedie近似的精度）
- $\delta$：ULA步长（控制离散化误差）
- $\eta$：去噪器的Lipschitz常数（控制先验近似的精度）

当 $\varepsilon \to 0$（得分近似精确）、$\delta \to 0$（离散化精确）、$\eta \to 0$（去噪器完全非扩张）时：$\tilde{p} \to p$——PnP-ULA收敛到真实后验。

### 误差的分解

PnP-ULA的总误差可以分解为三个来源：

1. **Tweedie近似误差**：$\nabla\log p_\varepsilon(x) \approx \nabla\log p(x)$——噪声扰动引入的偏差，由 $\varepsilon$ 控制
2. **离散化误差**：ULA是Langevin SDE的Euler离散——由 $\delta$ 控制
3. **去噪器近似误差**：$D_\varepsilon \neq D_\varepsilon^*$——学习到的去噪器与理想MMSE去噪器的差距，由训练质量和 $\eta$ 控制

这三类误差的独立控制为PnP-ULA的实践提供了清晰的改进方向。

## 从PnP到多尺度得分：展望

PnP-ULA使用单一噪声水平 $\varepsilon$ 的去噪器，对应单一尺度的得分函数 $s_\varepsilon(x) = \nabla\log p_\varepsilon(x)$。这对复杂分布的采样有以下限制：

- **单一尺度**：大 $\varepsilon$ 捕捉全局结构但丢失细节，小 $\varepsilon$ 保留细节但全局探索不足
- **步长困境**：$\varepsilon$ 小 → $1/\varepsilon$ 大 → 步长必须小 → 收敛慢
- **混合质量**：不同区域的"最优噪声水平"不同——平坦区域需要大 $\varepsilon$，边缘区域需要小 $\varepsilon$

这些局限指向一个自然的发展方向：使用**多个噪声水平**的得分函数，逐步从全局到局部进行采样。下一章将展示如何系统地训练多尺度得分估计器（得分匹配），第7章将展示这种多尺度策略如何演化为扩散模型的连续时间框架。

### Lipschitz去噪器的正则化

约束 $\text{Lip}(D_\varepsilon) \leq \eta < 1$ 是PnP收敛的核心条件。在实践中，可以通过以下方法实现：

**方法1：权重裁剪（Weight Clipping）**
- 训练后将网络权重裁剪到 $[-c, c]$
- 简单但可能损害去噪性能

**方法2：谱归一化（Spectral Normalization）**
- 对每层卷积/线性层的谱范数进行约束
- $\bar{W} = W / \max(\sigma_{\max}(W), 1)$，其中 $\sigma_{\max}$ 是最大奇异值
- 最常用的方法，效果好且对性能影响小

**方法3：梯度惩罚（Gradient Penalty）**
- 在训练损失中加入正则项：$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{denoise}} + \lambda_{\text{gp}}\,\mathbb{E}[\|\nabla_x D_\varepsilon(x)\|^2]$
- 鼓励去噪器的梯度范数较小，间接约束Lipschitz常数
- 灵活但需要调节超参数 $\lambda_{\text{gp}}$

实践中，谱归一化是PnP去噪器最常用的Lipschitz约束方法。
