# 18.1 从理论到实践：把全书的推理链，翻译成一张"操作清单"

> 你可能会想：前面 17 章的公式我都能背了，为什么还要单独开一节"整合框架"？因为**会背公式 ≠ 会干活**。这一节要干的事很具体：把"逆问题→贝叶斯→采样→得分→扩散→条件生成=逆问题求解"这条推理链，逐条翻译成你动手时真正要点的按钮。每一句理论，都对应流水线上的一个动作。如果把全书比作一座工厂，前面 17 章是各条生产线，这一节就是**总装车间**——把散件装配成一台能开动的机器。

读完这节，你应该能：
- 把"逆问题为什么需要扩散"这条因果链，**给一个完全没听过这词的朋友讲明白**；
- 说出优化、PnP、扩散三代方法各自的能力上限和"软肋"；
- 把全书知识对应到一根五段管线的每一步，知道下一步（18.2）该动手做什么。

## 先给你一个反直觉的冲击：你其实早就握着所有工具了

很多同学学到这里会焦虑："扩散模型那么复杂，我真的能拿来解一个自己的逆问题吗？"先做个思想实验——

> 假设你面前有一个黑箱，塞进一张清晰图 $x$，吐出一堆带噪声的测量 $y$。现在反过来：给你 $y$，要你猜 $x$。你手上其实已经备齐了四样东西：
> 1. 一个描述"黑箱怎么把 $x$ 变 $y$"的公式（这是第 1 章的**似然**）；
> 2. 一个描述"什么样的图才是合理照片"的直觉（这是第 2 章的**先验**）；
> 3. 一个能从噪声图里"擦干净"的去噪器（第 5–6 章的**去噪器=得分**）；
> 4. 一套"一边擦噪、一边往测量上靠"的迭代玩法（第 13 章的**条件扩散**）。

把这四样按顺序串起来，就是本章的端到端管线。你不是缺工具，你是没把它们**按顺序排好**。这一节就是帮你排。

## 18.1.1 全书推理链回顾：每一步理论 → 一个工程动作

我们重画第 1 章到第 17 章的链，但这次右边写的是"你动手时该干嘛"：

```
理论推理链                                   你对应的工程动作
─────────────────────────────────────────   ──────────────────────────────
逆问题需要求解(Ch1)                ──→  步骤1：写下 y = Ax + ε 里的 A 和 ε
贝叶斯框架：似然×先验(Ch1-2)       ──→  步骤1：确定 p(y|x)（似然）和 p(x)（先验）
MAP 的局限：只给一个点(Ch3)        ──→  步骤2：决定"我是否要分布，而不只是点"
需要后验采样(Ch3)                  ──→  步骤2：选采样类方法（扩散）
ULA/Langevin 采样(Ch4-5)           ──→  步骤4：跑 Langevin / 扩散采样
得分函数算不出(Ch5)                ──→  步骤3：得有个能算得分的东西（去噪器）
得分匹配训练(Ch6)                  ──→  步骤3：训 / 加载一个去噪器
扩散模型 = 多步得分采样(Ch7)       ──→  步骤4：跑扩散采样
条件化 = 逆问题求解(Ch13)          ──→  步骤2-4：选"怎么把测量塞进扩散里"
```

这条链的灵魂还是那句：**逆问题的需求，逼出了方法；每一步演化，都给你留了一件趁手的工具。**
- 从贝叶斯：你继承了"似然 + 先验"的建模语言；
- 从 MAP：你继承了梯度下降、近端算子这些快但只给点的工具；
- 从 PnP：你继承了"去噪器就是先验"这个灵活至极的范式；
- 从扩散：你继承了"能从后验里采样"的终极能力。

> **和本书库的关系**：这一节就是第 1–17 章的"使用说明书"。后面 18.2–18.5 的每个动作，都能在这张表里找到它的理论娘家。

### 核心论点的三重验证

全书的核心论点一直是："扩散模型是逆问题自然发展的终点。"这句话靠三关来验证：
1. **理论验证**（第 13 章已完成）：条件扩散采样在连续时间 SDE 下，当得分函数精确、条件化理想时，收敛到真实后验 $p(x|y)$。
2. **实践验证**（18.4 节）：扩散在去模糊、超分、修复三类问题上，质量系统性压过优化和 PnP。
3. **能力验证**（18.5 节）：只有扩散能天然给你不确定性——而"量化不知道的东西"恰恰是逆问题最原始的需求（第 1 章就说了：逆问题不适定）。

这一转变意味着：方法的"好坏"不再只由 PSNR 一个数字衡量，而是由"能不能诚实地报告自己有多确定"共同衡量——这正是全书把贝叶斯推断理解为"智能信念形成"的落点。

## 18.1.2 三类求解方法谱系：从"一个点"到"一整片云"

面对一个自定义逆问题，你第一反应可能是"选哪个方法？"先看清三代方法的血缘关系——它们不是并列选项，而是**一代比一代更强、一代比一代更慢**的进化：

### 第一代：优化类方法（第 3 章）

思想一句话概括：**把逆问题变成"在保住测量的前提下，挑最像真图的那个解"的最优化问题。**

为什么需要这个公式？因为逆问题本身不适定（一个 $y$ 对应无穷多个 $x$），直接硬解 $Ax=y$ 要么无解要么解满天飞。所以我们得给"解"加两道约束：一是**别和测量差太远**，二是**别太不像一张真图**。把这两道约束压成一个数，求它最小化的那个 $x$，就是 MAP（最大后验）估计：

$$\hat{x}_{\text{MAP}} = \arg\min_x \underbrace{\frac{1}{2\sigma^2}\|Ax - y\|^2}_{\text{数据项：别和测量差太远}} + \underbrace{\lambda R(x)}_{\text{正则项：别太不像图}}$$

逐项看现实含义：$Ax-y$ 是"当前猜测图正演一遍"与"你手里观测"的差距，除以 $2\sigma^2$ 是按噪声水平给这个差距定权重——噪声越大，越不必苛求逐像素吻合；$R(x)$ 是先验对"合理图"的打分，$\lambda$ 决定先验话语权的大小。这个公式就是把"似然 × 先验"取对数后的优化化身。

- **像什么**：你有一张糊照片，规则是"离观测别太远 + 整体平滑"，然后让电脑找最平衡的那张。
- **优势**：快（通常 10–100 次迭代）、理论成熟、不用训网络。
- **局限（关键）**：它只吐**一个点** $\hat x$。第 3 章就说过，MAP 把"不确定性"整个丢掉了。还有，显式先验 $R(x)$ 的表达力有限——高斯先验糊、TV 先验出阶梯。
- **代表**：Tikhonov、TV、ISTA/FISTA、ADMM、Chambolle-Pock。

### 第二代：PnP 类方法（第 5 章）

优化类的痛点是"显式先验不够好"。PnP 的解法很妙：**别写 $R(x)$ 了，直接拿一个训好的去噪器 $D_\sigma$ 当先验用。**

为什么需要这个替换？因为手写正则 $R(x)$ 写不出真实图像的复杂统计，而去噪器在海量图上练过"什么是干净图"。第 5 章用 Tweedie 等式证明：去噪器"擦一步"本质上就是"沿得分方向走一步"。所以近端算子（白话：把解往先验方向拉一步）可以直接被去噪器取代：

$$\text{prox}_{\lambda R}(\cdot) \approx D_\sigma(\cdot)$$

- **优势**：不用手写先验；去噪器学到的图像统计比 $R(x)$ 丰富得多；同一个 DRUNet 换个逆问题还能复用。
- **局限**：它**还是点估计**（要量化不确定性得另接 PnP-ULA）；收敛性依赖去噪器性质；需要预训练去噪器。
- **代表**：PnP-ADMM、PnP-HQS、DPIR。

### 第三代：扩散采样类方法（第 7、13 章）

前两代都只给点。扩散类直接奔着"后验"去：**从后验分布 $p(x|y)$ 里采样**，而不是只找一个 $\hat x$。

为什么这一步是质变的关键？因为逆问题不适定，真正诚实的回答不是"一张图"，而是"一整片都可能成立的图"。贝叶斯定理告诉我们，后验正比于"似然 × 先验"，所以只要能从这两个东西里抽到信息，就能得到分布而不只是点：

$$x \sim p(x|y) \propto \underbrace{p(y|x)}_{\text{似然：和测量一致}} \underbrace{p(x)}_{\text{先验：像真图}}$$

- **优势（也是它独占的能力）**：
  - **后验采样**→ 天然能量化不确定性（第 5 章想做还得接 ULA，它自带）；
  - **生成式先验**→ 它学的是整张图的分布 $p(x)$，不是局部梯度；
  - **零样本迁移**→ 训好的扩散模型直接套到新逆问题，不用重训；
  - **退化越狠它越占优**→ 测量信息快没了时，只有"会编图"的先验能补上空缺。
- **局限**：慢（100–1000 次去噪器前向）；要预训练扩散模型；条件化是近似，样本多样性偶尔"过度发挥"。
- **代表**：DPS、DDRM、DiffPIR。

### 三代怎么连起来（因果链）

```
优化类           PnP类            扩散采样类
(显式先验)       (隐式先验)        (生成式先验)

点估计    →     点估计      →     分布估计
手工先验  →     学习型先验  →     生成式先验
快但弱    →     中速中强    →     慢但最强
```

每一代都是对上一代"不够好"的回应：
- 优化 → PnP：手写先验不够好 → 用学习型去噪器替掉它；
- PnP → 扩散：点估计丢掉了不确定性 → 直接去采样整个后验。

从更深层次看，这条"点 → 云"的演化线，正是绪论那个公式里"信念刻画"的升级史：信念从"一个最优点"（MAP），到"一个带学习先验的最优点"（PnP），最终成为"一个完整分布"（后验采样）。第 17 章我们还补上了最后一块——即便没有干净数据，先验也能从观测的内在结构里长出来。

> 实操建议先记一句：**退化轻、要快 → 优化；退化中，要质量又要快 → PnP；退化重、还要知道靠不靠谱 → 扩散。** 18.3 会把这个变成一棵决策树。

## 18.1.3 端到端管线设计：把上面所有东西拧成一根管子

基于上面的谱系，我们把全书整合成一根五段管子。输入是"测量 $y$ + 你怎么测的"，输出是"重建 + 它靠不靠谱"：

```
┌─────────────────────────────────────────────┐
│ 步骤1：定义前向算子                           │
│   · 写下 A（或 A）                            │
│   · 实现并验证伴随 Aᵀ                         │
│   · 设定噪声模型 p(ε)                         │
│   → 输出：physics 对象                        │
└─────────────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────┐
│ 步骤2：选择求解策略                           │
│   · 问题有多不适定？要不要不确定性？          │
│   · 选 优化 / PnP / 扩散                      │
│   → 输出：求解器配置                          │
└─────────────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────┐
│ 步骤3：准备先验 / 去噪器                       │
│   · 加载 DRUNet / DiffUNet                    │
│   · 或自监督训一个（第17章）                   │
│   → 输出：denoiser                            │
└─────────────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────┐
│ 步骤4：运行求解                               │
│   · 优化：迭代梯度/近端                       │
│   · PnP：迭代去噪 + 数据一致                  │
│   · 扩散：条件扩散采样                         │
│   → 输出：x̂（单次或多次）                     │
└─────────────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────┐
│ 步骤5：评估与不确定性量化                      │
│   · PSNR / SSIM                              │
│   · 多次采样 → 置信区间 / 不确定性图           │
│   → 输出：重建 + 不确定性报告                  │
└─────────────────────────────────────────────┘
```

### deepinv 在管子里的位置（不用 deepinv 也能对照）

deepinv 只是把上面每步包成了统一接口：

| 管线步骤 | deepinv 模块 | 关键类/函数 |
|---------|------------|-----------|
| 步骤1 | `deepinv.physics` | `LinearPhysics`、`Blur`、`Downsampling`、`Inpainting` |
| 步骤2 | `deepinv.optim` | `DPIR`、`ADMM`、`HQS` |
| 步骤3 | `deepinv.models` | `DRUNet`、`DiffUNet`、`NCSNpp` |
| 步骤4 | `deepinv.sampling` | 扩散采样接口（`DiffPIR`、`DPS`、`DDRM`） |
| 步骤5 | `deepinv.utils` | `cal_psnr`、`cal_ssim`、`plot` |

这套统一 API 的好处是：换方法只换求解器，其余不动。但强调一遍——**步骤1 到步骤5 的逻辑完全不依赖 deepinv**。本章末的 numpy 代码会用最朴素的方式把同一根管子跑给你看。

> **因果串联收尾**：管线的第一步"定义前向算子"是所有后续的地基。没有正确的正向模型，再花哨的求解器也只是在错误的数字上打转。所以下一节（18.2），我们专门聊怎么定义并验证你自己的前向算子。

## 收尾：为什么这一节重要

这一节没教任何新数学，它做的唯一一件事是**把"为什么"钉到"怎么做"上**：逆问题的不适定逼你贝叶斯，贝叶斯的积分逼你采样，采样的得分逼你训练去噪器，去噪器的多步迭代干脆叫扩散。这也是全书知识整合的最后一块拼图——当你能对着一个新问题报出"步骤几"时，17 章的理论就真正成了你自己的能力。既然你已经握齐了四样工具，下一节我们就动手造第一样——你自己的前向算子。
