# 18.4 端到端实战：把管子接起来，真跑三个逆问题

> 前面三节你造了引擎（18.2 的 $A$）、选了策略（18.3 的方法谱）。现在到了"毕业设计答辩"环节——把它们接成一根完整的管子，真跑一遍。先问你一个反直觉的问题：**同样一张被糊掉、又加了噪的图，TV 正则化几秒出结果，扩散模型要慢上几十倍，那扩散到底贵得有没有道理？** 这一节用三个递进项目（去模糊、超分、修复）把"贵得值不值"用数字摊开。结论先剧透：**"退化越重、扩散越强"这个流行说法在本实验里并没有成立**——决定排序的不是退化有多重，而是退化属于哪一类（缺纹理还是缺像素），以及你给自己的方法调了什么参数。本实验里，修复场景的排名甚至被一次参数修复整体改写：同一张 DRUNet 去噪器，换个噪声调度就从 12 dB 量级跳到 33 dB。

读完这节，你应该能：
- 把 18.2–18.3 的管线和代码真正跑通"模糊→清晰"；
- 看懂"方法强弱"不是口号，而是 PSNR/耗时表上的硬数字，且随时可能被参数改写；
- 亲手验证：方法强 ≠ 永远强，**退化类型 + 参数配置**共同决定一切。

## 18.4.1 项目 1：图像去模糊

### 问题定义（这就是第 1 章的 $y=Ax$）

去模糊是最经典的线性逆问题，前向模型：

$$y = Kx + \varepsilon, \quad \varepsilon \sim \mathcal{N}(0,\sigma^2 I)$$

为什么从去模糊开刀？因为它最"朴素"——模糊核 $K$ 一卷积、噪声一加，就是你的观测 $\mathbf{x}$ 变 $y$ 的全过程，最能看清管线的每一步。我们看两档难度：
- **轻度**：小模糊（$\sigma_K=1.5$）+ 低噪（$\sigma=0.01$）
- **重度**：大模糊（$\sigma_K=3.0$）+ 高噪（$\sigma=0.05$）

### 步骤 1：定义前向算子（回到 18.2）

```python
import torch, deepinv as dinv
device = dinv.utils.get_freer_gpu() if torch.cuda.is_available() else "cpu"
x_true = dinv.utils.load_example("celeba_example.jpg", img_size=(256, 256))

# 自定义模糊核（也可直接用 dinv.physics.blur.gaussian_blur）
kernel = dinv.physics.blur.gaussian_blur(sigma=(3.0, 3.0))   # 重度档
# 用 BlurFFT（FFT 实现、可 SVD 分解）：PnP/DiffPIR 的数据保真步 prox_l2 有闭式解，性能稳定
physics = dinv.physics.BlurFFT(img_size=(3, 256, 256), filter=kernel)
physics.set_noise_model(dinv.physics.GaussianNoise(sigma=0.05))
y = physics(x_true)   # 制造一次观测
```

### 步骤 2–3：选策略 + 加载去噪器（回到 18.1 的方法谱系）

```python
denoiser_drunet = dinv.models.DRUNet().to(device)    # PnP 用
denoiser_diffunet = dinv.models.DiffUNet().to(device)  # 扩散用
```

### 步骤 4：三种方法同台打擂（对应第 3 / 5 / 13 章）

**优化——TV 正则化**（第 3 章 3.5 节，Chambolle-Pock 解）：

$$\hat{x} = \arg\min_x \frac{1}{2\sigma^2}\|Kx - y\|^2 + \lambda\|Dx\|_1$$

```python
from deepinv.optim import ADMM
model_tv = ADMM(...)   # TV 正则化配置
x_tv = model_tv(y, physics)
```

**PnP——DPIR**（第 5 章的去噪器即先验）：
```python
from deepinv.optim import DPIR
model_dpir = DPIR(denoiser=denoiser_drunet,
                  params={"stepsize":1.0, "sigma":[0.1,0.05,0.025,0.01]})
x_dpir = model_dpir(y, physics)
```

**扩散——DiffPIR**（第 13 章条件扩散采样）：
```python
from deepinv.sampling import DiffPIR
model_diffpir = DiffPIR(denoiser=denoiser_diffunet, data_fidelity="L2",
                        params={"step_size":1.0})
x_diffpir = model_diffpir(y, physics)
```

> 说明：以上三段代码的参数写法是教学示意，突出"每类方法只换求解器、管线其余不动"；`DPIR` 与 `DiffPIR` 在 deepinv 中的实际构造参数，以 18.3.2 和 18.3.3 的接口说明为准。

### 步骤 5：结果对比（先猜后揭）

**先猜一下**：重度模糊+高噪下，TV、DPIR、DiffPIR 三者 PSNR 谁高？差距会有多大？
> 揭晓（来自 18.4-1 实验实测，见本节末尾）：重度模糊下 **DPIR≈29.2 dB 最高**，TV≈27.3 dB 与 DiffPIR≈26.9 dB（后验均值图 28.6 dB）紧随其后；轻度模糊下 **DPIR≈34.7 dB 领先**，DiffPIR≈31.6 dB（均值图 33.6 dB）、TV≈31.6 dB 次之，Tikhonov≈31.2 dB。DPIR 单次约 19.4 s，DiffPIR 单样本约 354 s——慢约 18 倍，却没有更准。

| 方法 | 轻度 PSNR/SSIM | 重度 PSNR/SSIM | 速度（CPU 实测） |
|------|----------------|----------------|------|
| Tikhonov | 31.22/0.85 | 25.30/0.56 | 快（<1 s） |
| TV 正则化 | 31.57/0.86 | 27.32/0.74 | 较快（≈6 s） |
| DPIR | **34.66**/0.92 | **29.21**/0.80 | 中等（≈19.4 s） |
| DiffPIR | 31.63±0.22/0.90 | 26.93±0.06/0.77 | 慢（≈354 s/样本） |

（数值取自 18.4-1 实验实测的 `results_summary.json`；耗时为 CPU 环境实测，GPU 上整体约快一个数量级。DiffPIR 一栏为 3 次独立采样 PSNR 的均值±标准差，其 3 样本平均图即后验均值（MMSE）估计，PSNR 分别为 33.60 / 28.62 dB，反而更接近 DPIR——同一方法、两种口径，正是 18.5 要讲的"点估计 vs 后验分布"的实物预演。）这里有两点值得注意：其一，**同一条管子下参数决定成败**——早期版本的 TV 因参数被静默忽略、退化到默认值，在轻度模糊上只有 21.5 dB；修正为适配良态模糊算子的 $(\lambda,\text{stepsize})=(0.01,1.0)$ 后升到 31.6 dB。其二，本实验中 DiffPIR 使用 $\sigma$ 随场景设定（重度模糊 0.05、其余 0.01）、$\zeta=0.1$、$\lambda=7.0$ 加 100 步的**教学简化配置**（代码注释自陈未按场景调优），因此它的成绩应读作"该配置下的成绩"，不能当作扩散方法的性能上限。这说明**方法强 ≠ 永远强**，参数和退化程度共同决定结果。

**视觉差异一句话**：TV 太滑（丢纹理）、DPIR 恢复细节最好、DiffPIR 纹理自然但受上述配置拖累，细节之外仍留残噪。

## 18.4.2 项目 2：超分辨率重建

### 问题定义

前向模型是"模糊 + 下采样"：

$$y = DSx + \varepsilon$$

$S$ 抗混叠模糊，$D$ 下采样。$s$ 倍下采样把 $n\times n$ 图压成 $(n/s)\times(n/s)$。为什么超分是"扩散的秀场"？因为每测 1 个像素对应 $s^2$ 个未知像素，测量信息被成倍吃掉，越高的倍率，这种"信息真空"越夸张。

### 步骤 1：定义前向算子

```python
physics_sr = dinv.physics.Downsampling(factor=4, img_size=(3,256,256), filter="gaussian")
physics_sr.set_noise_model(dinv.physics.GaussianNoise(sigma=0.02))
y_sr = physics_sr(x_true)
```

（实验 18.4-1 中超分场景的噪声水平取 $\sigma=0.01$。）

### 求解与对比（先猜后揭）

**先猜**：4 倍超分下，Tikhonov（纯优化）能到多少 dB？DPIR/DiffPIR 呢？
> 揭晓（18.4-1 实测）：4 倍超分时 DPIR≈30.2 dB 为样本口径最高，但 DiffPIR 的后验均值图 30.58 dB 实际反超——同一方法两种口径给出不同排名；Tikhonov 29.15 dB、TV 27.81 dB、插值基线（无先验）26.85 dB 随后，**学习型先验比无先验基线高约 3 dB**。注意 Tikhonov 已不是早期提纲预期的 12.5 dB：v7 版把正则权重改成按算子范数自适应（$\lambda=0.01\|A\|_2^2$）后，它在欠定下采样场景里也能给出合理的平滑解，甚至略超无先验插值基线。

| 方法 | 2× PSNR/SSIM | 4× PSNR/SSIM | 8× PSNR/SSIM |
|------|-------------|-------------|-------------|
| 插值基线（无先验） | 33.07/0.91 | 26.85/0.77 | — |
| Tikhonov | 33.18/0.89 | 29.15/0.81 | — |
| TV 正则化 | 34.12/0.92 | 27.81/0.79 | — |
| DPIR | **35.67**/0.94 | **30.19**/0.85 | — |
| DiffPIR | 33.04±0.16/0.92 | 29.16±0.04/0.84 | — |

"—" 表示 8× 倍率未实测。"插值基线"是超分场景下无先验重建的别名：本实验里它是**双线性插值上采样**的输出（不是 $A^\top y$——下采样算子的伴随是零填充上采样，4× 时仅 8.9 dB、极暗不可用），其余场景仍叫伴随重建。DiffPIR 一栏为 3 次独立采样 PSNR 均值±标准差；其后验均值图（MMSE）在 2×/4× 分别为 34.77/30.58 dB，4× 档反超 DPIR。

**为什么高倍率更需要强先验**：倍率越大，零空间维度越大。4 倍时每测 1 个像素对应 16 个未知像素，测量信息被大幅吃掉，无先验插值基线停在 26.85 dB，而学习型先验（DPIR 30.19 dB）与适配过的显式先验（Tikhonov 29.15 dB）都能把它往上拉——先验的价值不分"手写"与"学习"，区别在于拉动的幅度与适用的退化类型。

## 18.4.3 项目 3：图像修复

### 问题定义

$$y = Mx + \varepsilon$$

$M$ 是对角掩码（保留部分像素、其余置零），比如"只留 20% 像素"。为什么修复最考验"敢不敢编"？因为缺失的像素彻底没信息，求解器要么保守留洞，要么靠先验"脑补"——而脑补的质量，正是三代方法的分水岭。

### 步骤 1：定义前向算子

```python
physics_inpaint = dinv.physics.Inpainting(img_size=(3,256,256), mask=0.20, device=device)
physics_inpaint.set_noise_model(dinv.physics.GaussianNoise(sigma=0.01))
y_inpaint = physics_inpaint(x_true)
```

### 求解与对比（一个被参数改写的结论）

**先猜**：一半像素缺失时，TV 和 DPIR 谁强？换成 80% 缺失呢？
> 揭晓（18.4-1 实测，50%/80% 两档缺失）：**DPIR 两档都是第一**——50% 档 DPIR 33.01 dB、DiffPIR 31.32 dB、TV 29.01 dB、Tikhonov 11.34 dB；80% 档 DPIR 28.14 dB、TV 21.08 dB、DiffPIR 21.05 dB、Tikhonov 9.32 dB。但这个故事有个重要前提：**DPIR 的领先是"任务匹配的噪声调度"换来的**。早期版本直接套用为去模糊/超分设计的默认调度（8 步、σ 从 0.19 降到测量噪声），同一张 DRUNet 在 50%/80% 缺失上只有 12.34/9.79 dB，几乎退回无先验基线——当时"TV 断层领先学习型先验 11–17 dB"的结论就是那么来的；换成修复专用调度（20 步、σ 从 0.5 到 0.05 对数递减、数据锁定随 σ² 缩放）后，DPIR 反超 TV 4–7 dB。所以本节真正的教训不是"修复场景 TV 最强"，而是：**修复场景的排名由"先验 × 调度参数"共同决定**——同一方法，换个参数就从垫底到第一。

| 方法 | 50% PSNR/SSIM | 80% PSNR/SSIM |
|------|---------------|---------------|
| 无先验基线（伴随） | 11.34/0.22 | 9.32/0.10 |
| Tikhonov | 11.34/0.22 | 9.32/0.10 |
| TV 正则化 | 29.01/0.79 | 21.08/0.54 |
| DiffPIR | 31.32±0.16/0.91 | 21.05±0.58/0.64 |
| DPIR | **33.01**/0.88 | **28.14**/0.76 |

（DiffPIR 一栏为 3 次独立采样 PSNR 均值±标准差；其后验均值图在 50%/80% 分别为 33.30/22.39 dB。Tikhonov 与无先验基线完全相等不是巧合：缺失像素处数据项不提供任何梯度，零均值 L2 先验的解析最优值就是 0——这是先验的固有特性，不是 bug。）

**退化严重性与方法选择的关系**（一句话地图）：

```
退化严重性（信息缺失）  低 ──────────────────────── 高
候选方法：              优化 / TV      PnP         扩散采样
实测结论：            快、轻度够用  六场景全胜    样本口径未超 PnP
缺的是什么：            高频纹理      高频纹理      缺失像素（靠先验"编"内容）
```

（本实验最有意思的一课：**"缺纹理"和"缺像素"是两类不同的退化**，但决定排序的不是退化类别本身，而是"退化类型 × 参数配置"的组合——缺像素时 DPIR 换个调度就能从 9.79 dB 跳到 28.14 dB，TV 则是不需要任何调参的最强显式先验，DiffPIR 在 80% 大洞上抖动明显（±0.58 dB）。）

## 18.4.4 多方法综合对比

### 定量总表（来自 18.4-1 实验实测，最可信的一版）

| 场景 | 无先验基线 | Tikhonov | TV 正则化 | DPIR (PnP) | DiffPIR (扩散) |
|------|---------|----------|-----------|-----------|---------------|
| 轻度模糊 | 27.73（伴随） | 31.22 | 31.57 | **34.66** | 31.63±0.22（均值图 33.60） |
| 重度模糊 | 23.91（伴随） | 25.30 | 27.32 | **29.21** | 26.93±0.06（均值图 28.62） |
| 2 倍超分 | 33.07（插值） | 33.18 | 34.12 | **35.67** | 33.04±0.16（均值图 34.77） |
| 4 倍超分 | 26.85（插值） | 29.15 | 27.81 | **30.19** | 29.16±0.04（均值图 30.58） |
| 50% 修复 | 11.34（伴随） | 11.34 | 29.01 | **33.01** | 31.32±0.16（均值图 33.30） |
| 80% 修复 | 9.32（伴随） | 9.32 | 21.08 | **28.14** | 21.05±0.58（均值图 22.39） |

（DiffPIR 一栏为 3 次独立采样 PSNR 的均值±标准差；"均值图"为 3 样本平均图（后验均值/MMSE 估计）的 PSNR。耗时为 CPU 实测：Tikhonov 与基线 <1 s，TV 6–8 s，DPIR 19.4–48.4 s，DiffPIR 约 354 s/样本。）

**读表四句话**：
1. **修复场景的无先验基线最差、先验的价值最明显**（80% 缺失时伴随重建 9.32 dB，DPIR 拉到 28.14 dB、TV 拉到 21.08 dB）；但在超分场景，无先验的插值基线本身就有 26.9–33.1 dB，先验的增益只有约 3 dB。
2. **DPIR 在全部六个场景都是第一**（模糊 34.66/29.21、超分 35.67/30.19、修复 33.01/28.14）——但修复场景的领先是任务匹配的噪声调度换来的（见 18.4.3），默认调度下它只有 12.34/9.79 dB。
3. **TV 是最强调式先验、且零调参**：修复场景仅次于 DPIR（29.01/21.08），去模糊与 DiffPIR 相当；但 4× 超分时被分段常数化拖累（27.81 dB，反而低于 Tikhonov 的 29.15 dB）——显式先验的强项是"缺失像素的稀疏梯度填充"，不是"恢复高频纹理"。
4. **DiffPIR 样本 PSNR 在全部场景低于 DPIR**，CPU 实测约 354 s/样本（比 DPIR 的 19.4 s 慢约 18 倍；GPU 上约 10 s，慢 30–50 倍）。这不构成"扩散不如 PnP"的结论：其 $\sigma/\zeta/\lambda$ 为未调优的教学配置、步数仅 100；且若改用后验均值（MMSE）口径，4× 超分（30.58 vs 30.19）与 50% 修复（33.30 vs 33.01）反超 DPIR——**同一方法两种口径给出不同排名，这正是"点估计 vs 后验分布"的实物教材**（18.5 展开）。

需要说明的是，本实验中 DiffPIR 采用 100 步采样（库默认/论文标准配置，低于典型的 1000 步），CPU 实测单样本约 354 s，低于 18.3 表中"分钟级"的一般情形——18.3.5 的加速手段正在于此。

从更深层次看，这张表的意义不在给方法排名，而在把 18.3 的"阶梯"从论断变成了实测事实：三类方法的差距随信息缺失程度拉开，且没有一个方法在所有场景称王。这一转变意味着，工程上真正的功夫在"先诊断退化、再选方法"，而不是背一个最优解。

### 定性对比（人眼看啥区别）

- **优化**：Tikhonov 太滑（丢高频）；TV 还可能出阶梯，但绝不"编"不存在的东西。**在修复场景，这份"保守"很能打**——TV 把已知像素间的缺失区填成稀疏梯度，是不需要任何调参的最强显式先验（29.01/21.08 dB）。
- **PnP**：细节最多，实测分数也最高（六个场景全胜）。关键在修复场景必须换任务匹配的噪声调度：默认去模糊调度下会假性失败（12.34/9.79 dB，几乎退回无先验基线），换成 20 步修复专用调度后 33.01/28.14 dB 反超 TV——**参数是 PnP 的"隐藏开关"**。
- **扩散**：纹理自然，理论上能"编"出合理的缺失内容，多次采样还能给出一族合理解（→ 不确定性，接 18.5）。但本实验里 DiffPIR 的教学配置与 100 步采样让它没能兑现质量优势（样本口径全部低于 DPIR），这一条**要靠调好采样超参才成立**。

### 计算效率 vs 质量权衡（决策者视角）

```
重建质量
  ▲
  │  ● PnP（≈19 s，六场景全胜；修复场景须任务匹配调度）
  │
  │        ● 扩散采样（≈354 s/样本，样本口径未超 PnP；后验均值口径在 4× 超分反超）
  │     ● TV（≈6 s；修复场景第二，去模糊/2× 超分中游，4× 超分被阶梯化拖累）
  │  ● Tikhonov（<1 s，轻度退化性价比高）
  │ ● 无先验基线（伴随/插值，0 s）
  └──────────────────────────▶ 计算时间
```
- 时间敏感（实时成像）→ PnP（本实验里既快又准）
- 质量敏感（医学诊断）→ 本实验实测 PnP 第一；扩散要先调好采样超参
- 修复场景（缺像素）→ 有去噪器可用时 DPIR（须配修复专用调度）；只能用显式先验时 → TV
- 要不确定性 → **只有扩散**

（耗时为 CPU 实测；GPU 上 PnP 约 0.2–0.35 s、扩散约 10 s。）

## 18.4.5 deepinv 端到端代码模板（通用管子）

把三个项目压成一根可复用管子：

```python
import torch, deepinv as dinv

# ===== 步骤1：定义前向算子（换这里就能换逆问题）=====
physics = dinv.physics.Blur(...)           # 去模糊
# physics = dinv.physics.Downsampling(...)  # 超分
# physics = dinv.physics.Inpainting(...)    # 修复
# physics = CustomPhysics(...)              # 自定义（见18.2）
physics.set_noise_model(dinv.physics.GaussianNoise(sigma=0.05))
y = physics(x_true)

# ===== 步骤2：选求解策略 =====
# 选项A 优化：model = dinv.optim.ADMM(...)
# 选项B PnP：
model = dinv.optim.DPIR(denoiser=dinv.models.DRUNet(),
                        params={"sigma":[0.1,0.05,0.025,0.01]})
# 选项C 扩散：
# model = dinv.sampling.DiffPIR(denoiser=dinv.models.DiffUNet(), data_fidelity="L2")

# ===== 步骤3：先验/去噪器（已并入步骤2）=====
# 若要自监督训，见第17章，训完把 denoiser 传给求解器

# ===== 步骤4：求解 =====
x_hat = model(y, physics)

# ===== 步骤5：评估 + 不确定性（扩散需多次采样，见18.5）=====
print(f"PSNR: {dinv.utils.cal_psnr(x_hat, x_true):.2f} dB, "
      f"SSIM: {dinv.utils.cal_ssim(x_hat, x_true):.4f}")
dinv.utils.plot([x_true, y, x_hat], titles=["GT","Meas","Recon"])
```

**设计原则**：前向算子与求解器解耦（换求解器不动 $A$）、统一接口（`model(y, physics)`）、噪声模型独立、可扩展（自定义算子/求解器遵循同接口）。

## 实验 18.4-1：端到端求解策略对比

实验 `18.4-1.py` 在统一框架下对比**优化方法（Tikhonov、TV 正则化）、PnP 方法（DPIR）和扩散方法（DiffPIR）**在六种退化场景中的重建质量与计算效率，验证 18.3 节的方法选择决策指南。

### 实验场景

实验构造六类逆问题场景，覆盖退化程度从轻到重的完整谱系：

**去模糊**：轻度模糊（高斯核 $\sigma_K=1.5$，噪声 $\sigma=0.01$）与重度模糊（高斯核 $\sigma_K=3.0$，噪声 $\sigma=0.05$）。

**超分辨率**：2 倍下采样（噪声 $\sigma=0.01$）与 4 倍下采样（噪声 $\sigma=0.01$），使用双三次抗混叠滤波。

**图像修复**：50% 像素缺失（噪声 $\sigma=0.01$）与 80% 像素缺失（噪声 $\sigma=0.01$）。

每类场景均使用相同的测试图像（celeba_example.jpg，$256 \times 256$），并在相同观测下对比五种重建结果：无先验基线（伴随重建 $A^\top y$，超分场景为双线性插值，记作"插值基线"）、Tikhonov 正则化（100 次梯度下降，$\lambda=0.01\|A\|_2^2$ 按算子范数自适应，步长 $1/(\|A\|_2^2+\lambda)$）、TV 正则化（PGD，150 次迭代，$(\lambda,\text{stepsize})$ 按算子类型分场景设置）、DPIR（PnP-HQS，DRUNet 去噪器；去模糊/超分用 `get_DPIR_params` 默认调度，修复场景用 20 步修复专用调度）和 DiffPIR（扩散去噪器 DiffUNet，100 步采样，$\zeta=0.1$、$\lambda=7.0$，$\sigma$ 随场景设定）。

DiffPIR 在全部六个场景上运行（Inpainting 的 L2 prox 有闭式解，无需 SVD；GPU 上每场景仅约 10 s），每场景独立采样 3 次（种子 42/123/2024）：PSNR/SSIM 报告 3 次采样的均值±标准差，重建配图取 3 样本平均（后验均值/MMSE 估计）。

### 实验目的

1. **验证退化严重性与方法选择的关系**：同样是"退化"，缺高频纹理（模糊/超分）与缺像素（修复）对方法的要求并不相同——前者学习型先验（DPIR）领先且极快；后者的排名由"先验 × 调度参数"共同决定（DPIR 换修复专用调度后第一，TV 是不调参的最强显式先验）
2. **对比三类方法的计算效率-重建质量权衡**：优化方法秒级完成、质量居中；PnP 方法质量最高（六场景全胜）；扩散方法慢一个数量级以上，样本口径未取得质量优势，但后验均值口径在部分场景反超
3. **观察不同方法的重建视觉特征**：Tikhonov 过度平滑（修复场景输出黑洞，系零均值 L2 先验的固有特性）、TV 保边但可能阶梯效应、DPIR 恢复细节最好、DiffPIR 生成纹理自然
4. **量化无先验基线的水平**：伴随重建 $A^\top y$（超分场景为双线性插值）作为无先验基线，展示先验信息的价值——在修复场景差距最大，在超分场景差距最小

### 实验输入

| 参数 | 设置 |
|------|------|
| 测试图像 | celeba_example.jpg，$256 \times 256$ 像素 |
| 去模糊场景 | 轻度：$\sigma_K=1.5, \sigma=0.01$；重度：$\sigma_K=3.0, \sigma=0.05$ |
| 超分场景 | 2 倍/4 倍下采样，bicubic 抗混叠，$\sigma=0.01$ |
| 修复场景 | 50%/80% 像素缺失，$\sigma=0.01$ |
| Tikhonov | $\lambda=0.01\|A\|_2^2$（相对算子范数自适应），100 次梯度下降，步长 $1/(\|A\|_2^2+\lambda)$ |
| TV 正则化 | PGD，150 次迭代；$(\lambda,\text{stepsize})$ 分场景：去模糊 $(0.01,1.0)$、超分 $(0.001,0.5)$、50% 修复 $(0.05,1.0)$、80% 修复 $(0.2,1.0)$ |
| DPIR | DRUNet 去噪器；去模糊/超分用 `get_DPIR_params` 按场景噪声水平（重度模糊 0.05，其余 0.01）生成 step-size 与降噪调度；修复场景用 20 步专用调度（$\sigma:0.5\to0.05$ 对数递减，数据锁定随 $\sigma^2$ 缩放） |
| DiffPIR | DiffUNet 扩散去噪器，100 步采样，$\zeta=0.1,\lambda=7.0$；$\sigma$ 随场景设定（重度模糊 0.05，其余 0.01）；每场景 3 次独立采样 |
| 无先验基线 | 伴随重建 $A^\top y$（超分场景为双线性插值，记作"插值基线"） |

### 预期结果（已按实测更新）

原提纲预期与实测差异很大（详见下文各场景表），这里先给出结论：

- **去模糊**（轻度/重度）：DPIR 最高（34.66 / 29.21 dB），TV（31.57 / 27.32 dB）与 DiffPIR（31.63 / 26.93 dB）接近，Tikhonov 31.22 / 25.30 dB
- **超分**（2×/4×）：DPIR 最高（35.67 / 30.19 dB），TV（34.12 / 27.81 dB）与 DiffPIR（33.04 / 29.16 dB）次之；Tikhonov（33.18 / 29.15 dB）已不低于无先验插值基线（33.07 / 26.85 dB）——**优化方法并未像提纲预期那样崩到 10–12 dB**，自适应 $\lambda$ 与分场景 TV 参数起了作用
- **修复**（50%/80% 缺失）：DPIR 第一（33.01 / 28.14 dB），但领先是修复专用调度换来的（默认调度下仅 12.34 / 9.79 dB）；TV 是不调参的最强显式先验（29.01 / 21.08 dB）；DiffPIR（31.32 / 21.05 dB）居中，80% 档采样抖动 ±0.58 dB
- **计算时间**（CPU 实测）：Tikhonov 与基线 <1 s，TV 6–8 s，DPIR 19.4–48.4 s，DiffPIR ≈354 s/样本（GPU 上约快一个数量级）
- **无先验基线**：在修复场景最差（9.3–11.3 dB），在超分场景却不差（26.9–33.1 dB）——说明"先验值不值"取决于算子零空间有多大、以及基线本身能走多远

| 点估计 vs 后验分布 | DiffPIR 样本口径全部低于 DPIR，但 3 样本后验均值（MMSE）在 4× 超分（30.58 vs 30.19）与 50% 修复（33.30 vs 33.01）反超——同一种扩散先验，两种评价口径 |
| 扩散方法的条件性 | DiffPIR 样本口径均低于 DPIR——其 $\sigma/\zeta/\lambda$ 为教学配置、步数仅 100，属未调优的简化配置；80% 大洞上采样抖动 ±0.58 dB |

> **实践启示**：实测结果修正了 18.3 节决策树的一处想当然——"退化越重，扩散越强"并不自动成立。真正决定排序的是**退化类型与参数配置的组合**：缺高频纹理时 DPIR 又快又准；缺像素时，方法排名会被调度参数整体改写（12 dB → 33 dB），TV 则是无需调参的保底选择。此外，本实验中 DiffPIR 的教学超参与 100 步采样使其未能发挥扩散的生成能力——评价扩散方法时须先把采样超参调好，否则得到的只是"配置的成绩"而非"方法的成绩"；而它"多样本 + 后验均值"的输出形态，正是 18.5 不确定性量化的入口。
