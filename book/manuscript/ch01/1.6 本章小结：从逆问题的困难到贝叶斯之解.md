# 1.6 本章小结：从逆问题的困难到贝叶斯之解

> 核心观点：逆问题天生困难——不适定性（算子本身的问题）与噪声（观测的不精确）叠加，使"直接求逆"在多数情况下不可行。贝叶斯框架用一句话统一应对：后验 = 似然 × 先验。本章把这两个困难、一个解、一张接口图完整交代清楚，为全书后续所有章节埋下种子。

## 一、本章走过了什么

一条"困难逐层叠加、贝叶斯统一应对"的主线：

```
1.1 定义逆问题：从果到因，y → x
  │
1.2 正向模型 y=Ax：卷积、下采样、Radon 变换
  │
1.3 第一层困难：不适定性（Hadamard 三条件 / 病态性 / SVD 视角）
  │
1.4 第二层困难：噪声（高斯→L²、Poisson→KL、Laplace→L¹）
  │
1.5 贝叶斯框架：后验 = 似然 × 先验，同时回应两个困难
```

- **1.1–1.2**：先回答"逆问题是什么"——从观测反推原因；再回答"观测如何生成"——正向算子 $A$ 把"因"变成"果"。卷积模糊、下采样、Radon 变换是贯穿全书（尤其是第 16 章 CT/MRI）的三个代表性正向模型。
- **1.3**：即使没有噪声，$x=A^{-1}y$ 也可能不可行——这是算子 $A$ 本身的性质。Hadamard 三条件（存在、唯一、稳定）与 SVD 视角（奇异值衰减放大噪声）给出了直觉。
- **1.4**：观测从不精确。关键洞察：**噪声模型决定似然，似然决定数据项**——高斯→L² 最小二乘、Poisson→KL 散度、Laplace→L¹，三者共享同一条推导链。
- **1.5**：贝叶斯定理把数据信息（似然）与先验知识（先验）融合为后验分布。取负对数后"后验能量 = 数据项 + 正则项"，天然解释了为什么正则化能够挽救不适定性。

从更深层次看，本章的两次"困难揭示"与一次"框架收束"，实际上完成了一次问题形态的转换：逆问题从一个"求出唯一解"的计算任务，变成一个"形成合理信念"的统计任务。先验由此不再是可有可无的装饰，而是结构化知识的正式成员；后验也不再是一个终点数字，而是一个随证据修正的分布。

## 二、核心对照表

| 层面 | 困难/工具 | 对应内容 |
|---|---|---|
| 问题 | 逆问题 | $y \approx Ax$，从果到因 |
| 第一层困难 | 不适定性 | Hadamard 三条件、SVD 病态性 |
| 第二层困难 | 噪声 | 高斯 / Poisson / Laplace |
| 解 | 贝叶斯框架 | $p(x|y) \propto p(y|x)\,p(x)$ |
| 视角跃迁 | 点估计 → 分布 | MAP（第3章）vs 采样（第4章） |

表中最后一行的"视角跃迁"值得再强调一句：从点估计到分布，不只是输出形式的变化，而是对"什么才算好答案"的重新定义——一个坦率标注自身宽度的后验，比一个假装确定的点更接近智能的本质。

## 三、与前后章的呼应

本章是全书唯一的问题定义章，打开了全部接口：

- **先验怎么选？** → 第 2 章（显式先验 → 隐式先验的演化谱系）
- **如何从后验求点估计？** → 第 3 章（MAP → 优化工具箱）
- **如何从后验采样分布？** → 第 4 章（MCMC/ULA → 采样路径主线）
- **先验表达力不够怎么办？** → 第 5–7 章（去噪器 → 得分 → 扩散），以及第 9 章（VAE）

一个值得记住的伏笔：本章列举的先验（高斯、Laplace、TV）都是**显式先验**，而"看起来像自然图像"这一先验无法用解析式表达——从显式到隐式先验的跨越，正是全书走向扩散模型的第一步。
