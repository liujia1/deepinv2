# 1.1 什么是逆问题？从观察到因果的推理

## 一、我们每天都在"由果推因"

先抛开数学。想想你日常生活里的这些瞬间：

- 你看到地上有个影子，脑子里立刻浮现出投射这个影子的物体大概长什么样；
- 你听到走廊里一串脚步声，马上判断"这大概是谁来了"；
- 你面对一幅缺了角的拼图，会盯着那几块碎片，推断缺失的部分该是什么图案。

这些动作看似平常，其实共享着同一种思维模式——**从感受到的"效果"，去推断看不见的"原因"**。

科学和工程里也处处是这种场景：

- **医学影像**：医生无法直接进入人体内部观察器官，但能利用 X 射线穿过身体后的投影，重建出器官的横截面（图1.1）；
- **天文学**：天文学家到不了黑洞跟前，却能利用一排射电望远镜的稀疏数据，合成人类第一张黑洞照片（图1.2）；
- **地球物理**：地质学家钻不到地壳深处，却能通过分析地震波的记录，推断地下结构（图1.3）。

这些任务的共同特征可以概括为一句话：我们手里只有间接的、不完整的观测，却要据此还原藏在背后的"真相"。

**这，就是逆问题（inverse problem）的核心——从效果反推原因。**

## 二、正问题 vs 逆问题：方向一反，难度判然有别

要真正理解"逆"字的含义，得先看清它的反面——**正问题（forward problem）**。

正问题是从原因出发预测结果：已知物理系统的参数和物理定律，推算系统会产生什么样的观测。而逆问题反过来：已知观测结果，推断产生它的未知参数。

用数学语言说，设未知量 $x$ 是你想知道的（比如人体组织的密度分布），$A$ 是描述物理过程的数学模型（比如 X 射线穿过人体的衰减过程），$y$ 是你能拿到的观测数据（比如探测器收到的投影值）。那么正问题和逆问题可以一句话写清楚：

$$y = Ax$$

- **正问题**：已知 $x$ 和 $A$，求 $y$——"给定原因，预测效果"
- **逆问题**：已知 $y$ 和 $A$，求 $x$——"看到效果，反推原因"

两者的对比如下：

| | 正问题 | 逆问题 |
|---|---|---|
| 方向 | 原因 → 效果 | 效果 → 原因 |
| 数学表述 | 已知 $x$，计算 $y = Ax$ | 已知 $y$，求解 $x$ 使得 $y = Ax$ |
| 性质 | 通常适定（well-posed）：解存在、唯一、稳定 | 通常不适定（ill-posed）：可能无解、不唯一、对噪声极度敏感 |
| 典型例子 | 已知器官密度，计算X射线投影 | 已知X射线投影，重建器官密度图像 |
| 难度 | 一般可直接计算 | 需要正则化等额外手段 |

在图像与视觉领域，逆问题几乎无处不在：**去模糊**（从模糊图恢复清晰图）、**超分辨率**（从低分辨率重建高分辨率细节）、**CT重建**（从投影数据恢复截面）、**图像修复**（填补缺失区域）……本质上全都是"从退化或残缺的观测里，把原始场景的信息恢复出来"。而文生图则是这一逻辑的极端推演：它试图仅凭高度抽象的语义描述，从近乎空白的观测中"无中生有"地恢复出视觉实体，将逆问题的欠定性推向了极致。

**因为**逆问题和正问题互为镜像，所以理解逆问题最快的捷径，是先吃透正向模型。以 CT 重建为例（图1.4）：正问题把物体截面沿各个角度做线积分（这叫 Radon 变换，1.2 节会细讲），得到一张叫"正弦图"（sinogram）的投影数据；逆问题则是从这张正弦图出发，重建出原始截面。你可以清楚地看到——正弦图本身无法被"直接读解"，必须求解逆问题才能得到可理解的图像。

> **逆问题的分类。** 按正向模型是否线性，逆问题分**线性逆问题**（$y = Ax$）和**非线性逆问题**（$y = \mathcal{A}(x)$）。按是否满足 Hadamard 三准则，又分**适定**和**不适定**两类。本书聚焦**线性不适定逆问题**——这是最基础也最普遍的情形，贝叶斯框架的数学推导在这里最干净。非线性情形（如相位恢复、盲去卷积）思路相同但推导更复杂。

## 三、为什么"除以 A"没那么简单？计算视角的三个鸿沟

如果正问题只是"乘一下 $A$"，那逆问题看起来只要"除以 $A$"——也就是求逆运算 $x = A^{-1}y$——不就够了吗？为什么实际上这么难？

答案藏在下面这句话里：**正问题和逆问题之间的不对称，不只是方向反了，更是信息量的坍缩。**

### 信息损失与误差放大

**因为**正问题 $y = Ax$ 在多数情况下是一个"压缩"过程——算子 $A$ 把高维的未知量 $x$ 映射到低维观测 $y$，这个过程中 $x$ 的某些信息被 $A$ 抹掉了。等我们想反推时，那些被抹掉的信息不可能凭空补回，这正是逆问题困难的根本来源。

即便 $A$ 是可逆的（信息没有完全丢失），逆过程仍然可能严重放大误差——正问题里"好算"的 $A$，在逆问题里可能"难算"到不可用。1.3 节我们会引入**条件数** $\kappa(A)$ 来定量刻画这种放大效应。

### 从连续到计算：三道鸿沟

**既然**直接求逆在数学上已经靠不住，那么从计算角度再拆一层，逆问题的困难还可以归结为三道鸿沟：

1. **从连续到离散**：真实物理过程发生在连续空间，但计算机只能在有限维度上运算。离散化是必经之路，而离散化的方式和精度直接影响重建质量。
2. **从精确到含噪**：理想模型假设 $y = Ax$，但实际观测总是 $y = Ax + \text{噪声}\varepsilon$。噪声看似微小，却被逆运算放大成灾难性的误差——我们在 1.4 节会系统建模噪声，在 1.5 节展示如何同时应对噪声和不适定性。
3. **从无限到有限**：我们只有有限个观测值，却可能要重建无穷维的未知量。信息不足是本质性的，任何计算方法都必须借助额外的先验知识来"补全"缺失的信息。

**于是**我们面对的是一个既缺信息、又带噪声、还被离散化约束的难题。图1.5 是地震成像的重建结果：从地表接收到的反射波（有限、含噪的离散数据）出发，推算地下不同深度的地层结构。这一结果无法从原始观测直接读出，必须借助正则化和优化算法才能得到稳定、有意义的重建。

计算逆问题的核心任务，是把逆问题的严格数学理论扩展成能实际运行的算法——在有限、含噪的离散观测下，稳定地重建未知量。这不仅需要数学分析（刻画适定性和收敛性），还需要数值线性代数、优化算法和统计推断的共同支撑。从更深层次看，"必须借助额外知识补全信息"这一事实，已经预告了本书的核心立场：任何逆问题求解都离不开先验，问题只在于先验从何而来、如何表达。
