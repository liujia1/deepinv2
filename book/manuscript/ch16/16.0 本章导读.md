# 16.0 本章导读：从物理到先验——医学成像中的逆问题实践

> "医生想看清楚你体内发生了什么，但病人不能一直躺在机器里被扫。"——这句话，就是 CT 和 MRI 重建全部难题的尾巴。

你有没有想过一个反直觉的事实：**CT 扫描时，X 光穿过你的身体，机器真正"看到"的并不是一张图像，而是一堆沿着不同角度的"射线积分值"**。先猜一下：如果让你只给你这些"积分值"，要你反推出身体内部的三维结构，你觉得这是"算一算就能还原"的容易事，还是"信息可能不够、答案可能不唯一"的难事？——答案是后者，而且难得出乎意料。同样，MRI 看似能直接"拍照"，但它采集到的其实是图像的"傅里叶变换"——一个叫作 k-space 的频域数据。我们人类想看的是一张清晰的图片 $x$，但物理仪器给我们的却是被前向算子"扭曲"过的测量 $y = Ax$。

怎么从 $y$ 反推出 $x$？这正是全书一直在说的**逆问题**（inverse problem，就是"从结果倒推原因"的反向问题）。

前 13 章我们完成了一个宏大的理论闭环：逆问题需要后验采样 → 采样需要得分函数 → 得分可以从去噪器里提取 → 去噪器能通过得分匹配训练 → 多步得分驱动的采样就是扩散模型 → 条件扩散采样就等于在解逆问题。第 14 章拓展了 Flow Matching 这个前沿，第 15 章解决了"用什么网络架构实现去噪器"这个工程问题。

但是——**所有这些漂亮的理论，真的在临床上管用吗？** 本章就要把它按在真实世界的两种医学成像上：CT 和 MRI。它们是教科书级的逆问题：正向模型有精确的物理基础，不适定性有深刻的数学刻画，而扩散先验重建，则是全书核心论点"扩散模型是逆问题自然发展的终点"在真实场景里的一次硬核验证。

**本章目标**（读完你应该能）：
- 说清 CT/MRI 的正向模型分别长什么样，为什么它们都逃不出"逆问题"这个框（呼应第 1 章的 $y=Ax$）
- 看懂"欠采样/有限角度"为什么让重建变得"不适定"（ill-posed，即解不唯一或极不稳定），以及正则化如何像第 2 章说的那样"当先验用"
- 理解学习型方法（UNet、算法展开）怎么替代手工先验，又卡在哪里
- 跑通章末的 numpy/skimage 代码，用肉眼看到"投影越少 → 重建越糊"这个不适定现象
- 把"物理建模 → 显式先验 → 学习型先验 → 扩散先验"这条演化线，和全书的叙事弧对接起来

## 一个核心论点：从物理到先验的统一

CT 和 MRI 看起来是两种物理原理大相径庭的设备。但用逆问题的眼光看，它们其实共享同一副骨架：

$$y = Ax + \epsilon \quad \xrightarrow{\text{逆问题}} \quad p(x|y) \propto p(y|x) \cdot p(x)$$

不同的 $A$（CT 是 Radon 变换，MRI 是欠采样傅里叶变换），相同的贝叶斯框架；不同的不适定来源（CT 是有限角度/稀疏投影，MRI 是欠采样），相同的"需要加先验"的诉求；不同的经典方法（CT 用滤波反投影 FBP，MRI 用逆 FFT），相同的"升级到学习型/扩散"的演化路径。

从更深层次看，本章反复使用的"先验"一词，正是全书核心命题"**先验即结构化知识、知识来源不断更替**"的应用体现。CT/MRI 的重建历史上，先验的来源大致经历过三次更替：先是以物理推导和成像几何为来源（如 FBP 依靠的斜坡滤波器 $|\omega|$、Radon 算子本身），再是以统计稀疏假设为来源（TV、小波、剪切波），最后是以学习到的数据分布为来源（UNet、扩散模型）。物理约束、统计稀疏、学习分布——三种先验来源截然不同，任务却一以贯之：**补全正向算子丢失的信息**。所谓"从物理到先验的统一"，正是这段知识来源更替的浓缩；这一认识，我们留到 16.6 一并收束。

**一句话路标**：我们从"X 光穿过人体、机器只记录了积分值"这个物理事实出发，一路走到"用扩散模型当先验、从极少的测量里采样出可信的图像"——这条从物理到先验的路，正是全书第 1 章到第 13 章推理链的缩影。

## 各节导航（本章的因果主线）

本章严格按"物理建模 → 数学分析 → 经典方法 → 深度学习 → 扩散先验"推进，每一节都是上一节局限性的自然回应：

- **16.1 CT 成像：从 X 射线到 sinogram**——先搞懂 CT 的正向模型：Beer-Lambert 定律说"射线测的是线积分"，Radon 变换把所有射线打包成 sinogram，Fourier 切片定理把这一切和傅里叶变换连起来，FBP 用"先滤波再反投影"做经典重建。
- **16.2 CT 的不适定性与正则化重建**——但 FBP 需要完整角度、低噪声。一旦投影不全（稀疏/有限角度），CT 就变成不适定问题。我们会看到全角是"温和不适定"（奇异值 $1/n$ 衰减），有限角是"严重不适定"（指数衰减），波前集理论解释了为什么有些边缘永远救不回来。正则化（Tikhonov/TV/剪切波）就是第 2 章说的"先验当正则化"。
- **16.3 MRI 成像：从自旋到 k-space**——换一种模态。MRI 的正向模型是傅里叶采样：k-space 就是图像的傅里叶变换。它的麻烦不是算子本身（傅里叶变换很良态），而是"想扫快一点"——欠采样导致混叠，于是有了并行成像和压缩感知。
- **16.4 学习型重建方法**——用数据驱动的网络（UNet、算法展开）替代手工先验，代表"从设计先验到学习先验"的范式转移，但卡在两点：要配对数据、给不了不确定性。
- **16.5 扩散先验重建**——用预训练的扩散模型当隐式先验，通过条件采样解 CT/MRI 逆问题（第 13 章"条件扩散=逆问题求解"的落地），三重优势：无需配对数据、能量化不确定性、零样本迁移。
- **16.6 小结**——把 CT/MRI 的演化归结成一句话：从物理模型出发，经正则化、学习型，最终自然走向扩散先验。

```
CT物理(16.1) → CT不适定性(16.2) → MRI物理(16.3) → 学习型方法(16.4) → 扩散先验(16.5) → 小结(16.6)
```

读完本章，你会明白：CT 和 MRI 重建方法的演化不是偶然的——从 FBP 到扩散先验，每一步都是对前一步局限性的回应，这个规律和全书的理论发展完全同构。更深层地，**医学成像是全书核心论点"扩散模型是逆问题自然发展的终点"最直接的证据**。

让我们从 CT 的物理基础开始——X 光是如何穿过人体，而机器又是如何把"积分值"变成一张图的。
