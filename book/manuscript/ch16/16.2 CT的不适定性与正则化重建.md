# 16.2 CT的不适定性与正则化重建

> 想象你在给一位乳腺癌高危病人做断层成像。为了少给她辐射，技师只让 X 光机在一个小角度（约 $30^\circ$–$60^\circ$）里转，而不是完整的一圈。图像出来后——边缘糊了，有些结构干脆消失了。你可能会想："不就少转一点点吗？"但数学会告诉你：这点"少转"，让问题从"温和"变成了"爆炸"。

**本节目标**（读完你应该能）：
- 用奇异值衰减速度区分"温和不适定"和"严重不适定"
- 看懂一个反直觉定理：极小的角度区间竟能"唯一确定"图像，却极度不稳定
- 用波前集理解"为什么有些边缘永远救不回来"
- 知道正则化方法该怎么跟着不适定的程度选

## 16.2.1 全角 CT：温和的不适定

**先回想第 1 章的一句话**。Hadamard 适定性（well-posedness，解存在、唯一、还连续依赖数据）有三条。CT 逆问题踩破了第 (3) 条：数据里哪怕一丁点扰动，重建结果都可能翻天覆地。这就是"不适定"。

**怎么衡量"不适定到什么程度"？** 用奇异值（singular value，SVD 分解出来的、代表"这个方向被放大多少"的系数）。Radon 变换是个紧算子（compact operator，一种"把有界集压成几乎紧"的线性算子），它的奇异值衰减速度，就是不适定程度的刻度尺。

当投影角度铺满整个 $[0,\pi)$（全角），奇异值按**多项式**衰减：

$$\sigma_n \sim \frac{1}{n}, \quad n \to \infty$$

这叫**温和不适定**（mildly ill-posed）。直觉：$\sigma_n \sim 1/n$ 意味着高频分量被放大的倍数"只"随 $n$ 线性增长——比起某些超严重问题（逆热方程，奇异值超指数衰减），这已经是相当友好的情况了。

> **点 vs 分布（呼应第 1、2 章）**：传统方法（FBP、Tikhonov）给你的是**一个**重建结果 $\mathbf{x}$——一个"点估计"（point estimate，单一答案）。但数据有噪声时，这个唯一答案其实极不可靠。贝叶斯视角下，真正该给的是**一整个后验分布** $p(\mathbf{x}|\mathbf{y})$，告诉我们"哪些区域可信、哪些区域纯属猜测"。本节我们先走经典路线（点估计 + 正则化），到 16.5 再看怎么拿到分布。

**全角 CT 怎么重建？** 回忆第 3 章的框架，把重建写成带正则化的优化（这就是第 2 章"先验 = 正则化"的落地）：

$$\min_x \|Ax - \mathbf{y}\|^2 + \lambda R(\mathbf{x})$$

$A$ 是离散 Radon 矩阵，$R$ 是正则化项。常见三选一：
- **Tikhonov**（$R=\|\mathbf{x}\|^2$）：有闭式解 $\mathbf{x}=(A^TA+\lambda I)^{-1}A^Ty$，但**过度平滑**、边缘糊
- **TV**（Total Variation，全变差，$R=\|Dx\|_1$）：保边缘，但会产生"阶梯效应"（分段常数感，回顾第 2 章 2.2）
- **截断 SVD**：扔掉小奇异值对应分量，等价于频域低通滤波

因为不适定性温和，适度正则化就够恢复高质量图像了。

## 16.2.2 有限角 CT：从温和到爆炸

**真实场景 hook**：乳腺断层成像（tomosynthesis，一种乳腺 3D 成像）为了少给病人辐射，X 光只在一个很小的角度范围（约 $30^\circ$–$60^\circ$）里转。工业上焊点检测也常因空间受限，拿不到全角度。这时候，重建质量断崖式下跌。

先猜一个数字：**如果一台全角 CT 缺了 5° 的角度（从 $180^\circ$ 变成 $175^\circ$），重建难度会变化多少？** 凭直觉说"差一点点而已，影响应该不大"——这一次直觉是对的；但如果缺的是 $60^\circ$，直觉就该失灵了。

为什么？看奇异值。有限角 CT（角度只在 $[\theta_{\min},\theta_{\max}]$、$<\pi$）的衰减是：

$$\boxed{\text{全角：}\sigma_n \sim \frac{1}{n} \quad \text{vs.} \quad \text{有限角：}\sigma_n \sim e^{-cn}}$$

关键在指数里的常数 $c$：它随缺角增大而增大。缺角很小时 $c\to 0$，$\sigma_n\sim e^{-cn}$ 就退化回全角的 $\sigma_n\sim 1/n$——缺 5° 对应 $c$ 约 $10^{-2}$ 量级，在常见离散尺寸（$n\lesssim 256$）下 $e^{-cn}\approx 1$，工程上几乎无法与全角区分（这正是很多"少扫几度"的采集仍能重建的原因）。只有当缺角大到几十度、$c$ 升到 $10^{-1}$ 量级，指数衰减才真正发作，此时才称为**严重不适定**（severely ill-posed）——"严重"是大缺角的属性，不是"只要缺一点就严重"。

**频域视角**：由 Fourier 切片定理（16.1.3），每个角度 $\theta$ 的投影确定了频域沿 $(\cos\theta,\sin\theta)$ 的一条径向切片。有限角度意味着频域里只有一块"蝴蝶结"形区域有数据，缺角度对应的频域区域**完全空白**。于是，有限角的不适定本质上是"频域有区域从未被测量"——而不适定的严重程度，恰恰由这段空白的形状与大小决定。

**一个反直觉的定理**——"Practically Dubious Theorem（实践上可疑定理）"：设 $f$ 光滑且有紧支撑（compactly supported，只在有限区域非零），那 $f$ 竟然被任意小角度区间里的投影数据**唯一确定**！

证明思路：Fourier 切片定理说有限角度投影确定了频域一个扇形区域的值；而紧支撑函数的傅里叶变换是解析函数（analytic function，可无限次求导、局部决定整体），在开集上相等就处处相等，于是 $f$ 整个频域被唯一确定。$\blacksquare$

> **为什么"可疑"？** 唯一性虽然成立，但恢复过程**极度不稳定**——要从扇形区域"外推"到整个频域，这是个严重不适定的解析延拓（analytic continuation，从已知区域往外推函数值）。指数衰减的奇异值，正是这种不稳定性的定量账单。理论说"能唯一确定"，实践说"你确定得让人头秃"。

## 16.2.3 波前集：为什么有些边缘永远救不回来

奇异值指数衰减告诉我们有限角"很糟"，但没说**糟在哪儿、丢了什么**。波前集理论（wavefront set，记录"奇异性在哪、朝哪个方向"的几何工具）来回答。

**波前集是什么？** 一个函数 $u$ 在位置 $\mathbf{x}_0$ 局部长什么样，看它的局部傅里叶变换（local Fourier transform，只在 $\mathbf{x}_0$ 附近开窗再做傅里叶变换）。如果 $u$ 在 $\mathbf{x}_0$ 沿方向 $\xi$ 是"光滑的"，局部傅里叶变换在 $\xi$ 方向就快速衰减。**波前集** $WF(u) \subset \mathbb{R}^n \times S^{n-1}$ 就是所有"奇异性位置 + 方向"的集合。

直觉：波前集记下"边缘在哪、边缘朝哪"。对一张图，一个边缘的波前集元素是（边缘位置，边缘法线方向）。（严格定义见附录 16C）

**有限角的可见性**：关键结论——**只有一部分波前集能被稳定恢复**。

设测量角度范围是 $[\theta_{\min},\theta_{\max}]$：
- **可见边缘**：法线方向在 $(\cos\theta,\sin\theta)$、$\theta$ 落在测量范围内的边缘 → 稳定可恢复
- **不可见边缘**：法线方向在测量范围之外的边缘 → **任何线性方法都救不回来**

> **直觉**：X 光沿 $\theta$ 方向穿过物体，只能"看见"法线和射线方向垂直的边缘——就像你拿手电筒从侧面照一个物体，只有和光线垂直的轮廓才会投下清晰阴影。法线方向没被照到的边缘，信息根本没进测量。

| 方法 | 恢复的波前集 |
|------|------------|
| FBP | 仅可见波前集 |
| Tikhonov 正则化 | 仅可见波前集 |
| TV 正则化 | 仅可见波前集（边界连接可能更好） |
| 剪切波学习 | 可恢复**部分**不可见波前集 |

关键观察：FBP、Tikhonov、TV——不管正则化参数怎么调，都**只能恢复可见波前集**。这是数学给的硬天花板。

> "能恢复什么"由测量与先验共同决定：测量决定了哪些波前集方向**被触碰过**，先验决定了这些触碰如何被解读。只要先验仍只约束"可见"方向，不可见方向的缺憾就无从弥补——除非先验本身携带了数据之外的信息。这正是下一段剪切波"学习"不可见边缘的真正含义，也提前预告了 16.4、16.5 更大规模的"用数据补全先验"。

**剪切波学习不可见边缘**：剪切波（shearlet，一种方向敏感的多尺度表示）能把系数拆成"可见"和"不可见"两组。Bubba et al. (2019) 发现：可见部分能从数据稳定恢复，不可见部分可以**从训练数据里学出来**（数据驱动的统计模型去"猜"）。把猜到的不可见边缘和 FBP 的可见边缘合并，结果比任何纯重建方法都好。这就是"从显式先验到学习型先验"在 CT 里的具体演出——和第 2 章 2.4 完全同构。

## 16.2.4 正则化谱系：选什么得看不适定有多重

因为不适定程度不同，正则化策略也得跟着变：

**Tikhonov**（闭式解、快，但过度平滑）：
$$\min_{x\ge 0} \|Ax - \mathbf{y}\|^2 + \alpha\|\mathbf{x}\|^2$$
适用：全角 + 高 SNR（信噪比，signal-to-noise ratio）。

**TV**（保边缘，但有阶梯效应）：
$$\min_{x\ge 0} \|Ax - \mathbf{y}\|^2 + \alpha\|Dx\|_1$$
适用：全角中噪声、稀疏投影 CT。

**小波稀疏**（Besov $B_{11}^1$，多尺度但缺方向性）：
$$\min_{x\ge 0} \|Ax - \mathbf{y}\|^2 + \alpha\|Wx\|_1$$
适用：稀疏投影 CT。

**剪切波稀疏**（方向敏感、最适合有限角）：
$$\min_{x\ge 0} \|Ax - \mathbf{y}\|^2 + \alpha\|Sx\|_1$$
适用：有限角 CT。

**TGV**（Total Generalized Variation，广义全变差，同时惩罚一阶和二阶变分，避免阶梯效应）：
$$\min_{x\ge 0} \|Ax - \mathbf{y}\|^2 + \alpha_1\|Dx\|_1 + \alpha_2\|D^2\mathbf{x}\|_1$$
适用：分片光滑图像。

**选择指南**（不适定程度 → 方法）：

| 不适定程度 | 场景 | 推荐方法 |
|-----------|------|---------|
| 良态 | 全角 + 高 SNR | FBP |
| 温和不适定 | 全角 + 低 SNR | Tikhonov / TV |
| 中度不适定 | 稀疏投影 | TV / 小波 |
| 严重不适定 | 有限角 | 剪切波 / 学习型方法 |

> **两把尺子不要混用**：上表的“中度”是**工程难度分级**（同时含采样完备性与噪声），与 16.2.1 按**奇异值衰减速度**定义的“温和”（$1/n$）不是同一个坐标轴。稀疏投影的 Radon 算子本身仍是 $1/n$ 温和衰减，但它欠采样、离散问题欠定，所以在工程上落到“中度”。

**Helsinki Tomography Challenge 2022**：一个有限角 CT 公开赛。用塑料 phantom（带各种孔洞）的全角度数据，逐步砍角度 $90^\circ \to 80^\circ \to \cdots \to 30^\circ$，评分用 MCC（Matthews 相关系数，取值 $[-1,1]$，$+1$ 完美）。结果：即使在最难的 $30^\circ$，最佳算法仍能给出有意义重建——但必须靠超越传统正则化的方法（学习型、扩散先验）。

## 本节小结

CT 不适定性的核心结构：

$$\text{全角CT: } \sigma_n \sim 1/n \xrightarrow{\text{温和不适定}} \text{正则化有效}$$
$$\text{有限角CT: } \sigma_n \sim e^{-cn} \xrightarrow{\text{严重不适定}} \text{需要学习型/扩散先验}$$

关键洞察：
1. 有限角 CT 病态性远比全角严重——SVD 衰减从多项式变指数
2. 波前集理论给几何解释——不可见边缘任何线性/凸方法都救不回
3. 正则化方法必须匹配不适定程度——"一刀切"行不通
4. 有限角 CT 是学习型/扩散先验的"天然战场"——传统方法局限最明显处

**贝叶斯含"信念更新"的旁注**：你可以把正则化项 $R(\mathbf{x})$ 想成我们**事先**对图像的"信念"（prior belief，先验信念，比如"图像应该平滑/分段常数"）。当数据很全（全角、低噪），数据说话算数，先验被"洗掉"；当数据稀少（有限角），先验的信念就被推到前台，成了重建的主角。这和第 3 章 MAP（最大后验，Maximum A Posteriori，在给定数据下找最可能的图）完全对应——$\min\|Ax-\mathbf{y}\|^2+\lambda R(\mathbf{x})$ 就是"似然保真 + 先验加权"的平衡点。但 MAP 只给一个点估计；到了 16.5，我们要用扩散先验拿到**整个后验分布**，那才是真正的"信念随证据更新"。

**承上启下**：CT 的正则化展示了"先验选择决定重建质量"。现在换一种模态——MRI。它的正向模型和 CT 完全不同（傅里叶采样而非线积分），但不适定性的挑战一样存在，只是换了副面孔。

## 收尾：为什么这件事重要

把整节的内容归结成一句话：**CT 的"难"不是均匀的——全角时只是温和不适定（奇异值按 $1/n$ 衰减），缺一点点角度就坠入严重不适定（指数衰减），而有些边缘在数学上永远救不回来。** 这个区分决定了你该用什么武器：温和时正则化就够，严重时得靠学习型甚至扩散先验。它也揭示了一个贯穿全书的真相——**当数据稀少，先验（你对图像"应该长什么样"的信念）就从配角变成主角**。下一节我们看到，MRI 的不适定性换了副面孔，但本质同源。

## 实验 16.2-1：CT不适定性与正则化重建

实验 `16.2-1.py` 演示**CT逆问题的两种不适定性（稀疏角度 vs 有限角度）及其正则化重建方法**，验证不同正则化方法的效果差异。

### 实验场景

实验考虑 CT 逆问题在两种欠采样情况下的表现：稀疏角度（角度少但覆盖全）和有限角度（缺失角度范围）。实验验证 16.2 节的核心论点：**正则化方法的选择必须匹配不适定性的程度**。

**两种不适定性的核心差异**（16.2.1/16.2.2节）：
- **稀疏角度 CT**：Radon 算子本身仍是 $1/n$ 的温和衰减，但角度欠采样让离散问题变为**欠定**，产生混叠伪影
- **有限角度 CT**：$\sigma_n \sim e^{-cn}$（严重不适定），产生条纹 + 不可见边缘丢失

**正则化方法对比**（16.2.4节）：
- **Tikhonov 正则化**：$R(\mathbf{x}) = \|\mathbf{x}\|_2^2$——过度平滑，边缘模糊
- **TV 正则化**：$R(\mathbf{x}) = \|Dx\|_1$——保持边缘，但可能阶梯效应

### 实验目的

1. **理解两种不同的不适定性**：对比稀疏角度和有限角度 CT 的伪影模式差异
2. **验证正则化方法的效果**：对比 FBP、Tikhonov、TV 正则化在欠采样 CT 上的重建质量
3. **量化不适定程度**：绘制 PSNR 随角度数/覆盖范围的变化曲线
4. **理解 TV 的保边优势**：验证 TV 正则化在稀疏角度 CT 上的优势

### 实验输入

| 参数 | 设置 |
|------|------|
| 测试图像 | Shepp-Logan 幻影，重建分辨率 $128 \times 128$，数据生成分辨率 $256 \times 256$ |
| 全角参考 | 180 角度，$\theta \in [0, 180^\circ)$ |
| 稀疏角度 | 30 角度，$\theta \in [0, 180^\circ)$ |
| 有限角度 | 120 角度，$\theta \in [0, 120^\circ)$ |
| 噪声水平 | 相对噪声 5%（高斯，占 sinogram 峰值的比例；用于正则化实验与含噪曲线） |
| TV 参数 | $\lambda = 0.1$，迭代次数 = 100 |
| Tikhonov 参数 | $\lambda = 0.1$，迭代次数 = 100 |
| 避免 inverse crime | 数据生成用 $256 \times 256$ 高分辨率 Radon 变换，resize 到 $128$ 探测器尺寸并做尺度归一化（$\times n/n_{data}$）供反演（`forward_radon`/`backward_radon` 用低分辨率模型） |

> **关于 inverse crime（反演罪行）**：迭代正则化重建中，如果数据生成和反演用的是同一个离散 Radon 算子（`forward_radon`），重建质量会被严重高估——因为"造数据用的 $A$"和"反演用的 $A$"完全一致，模型失配为零，这在真实 CT 中永远不会发生。本实验采用双分辨率方案：在 $256 \times 256$ 高分辨率下生成 sinogram，resize 到 $128$ 探测器尺寸后供 `forward_radon`/`backward_radon`（低分辨率）迭代重建。**注意必须做探测器尺度归一化**（resize 后乘 $n/n_{data}=1/2$）：radon 返回的线积分以像素为单位，同一物体在 $256$ 网格上跨越的像素数是 $128$ 网格的 $2$ 倍，若不归一化，sinogram 与重建值都会整体偏大 $2$ 倍，PSNR 会被强度误差主导（实测全角 FBP 仅 $12.6$ dB，修复后 $23.8$ dB）。归一化后 IC-free 的真实代价约为 $5.5$ dB：同模型基线全角 FBP 实测 $29.3$ dB $\to$ IC-free $23.8$ dB——这才是模型失配下的**诚实表现**。

### 预期结果

- 稀疏角度产生混叠摩尔纹覆盖全图；有限角度产生条纹 + 亮环伪影 + 边缘模糊丢失
- 含 5% 相对噪声下 TV > Tikhonov > FBP（实测约 20.7 / 18.8 / 14.2 dB），TV 恢复到无噪 FBP 水平
- PSNR 随角度数单调递增（无噪 13.1→23.8 dB）；有限角度覆盖范围越小 PSNR 越低（30° 覆盖时仅约 8.0 dB）

| 稀疏 30 角度 | $\theta \in [0, 180^\circ)$ | 20.6 dB | 0.577 | 混叠摩尔纹覆盖全图 | 算子温和（$\sigma_n \sim 1/n$），但欠采样→欠定 |
| 有限角 0°-120° | $\theta \in [0, 120^\circ)$ | 17.7 dB | 0.506 | 条纹 + 亮环伪影 + 边缘模糊丢失 | 严重（$\sigma_n \sim e^{-cn}$） |

步骤1验证了 16.2.1/16.2.2 节的核心观点：**稀疏角度和有限角度是两种不同的不适定性**。稀疏 30 角度：混叠摩尔纹覆盖全图（角度欠采样产生）。有限角 0°-120°：条纹 + 亮环伪影，误差高度集中在边缘——脚本在步骤 1 之后内置的**边缘诊断**（数值同步写入 `results_summary.json` 的“步骤1b_边缘诊断”）实测：边缘区平均绝对误差是平坦内部的 4.6 倍（相对全图平均也有 3.3 倍）；边缘处的梯度幅度只剩真值的 54%，即相对全角重建仍有约 29% 的幅度损失。更关键的是**方向选择性非常明显**：水平边缘保留度 0.86，垂直边缘仅 0.39——缺失的 120°–180° 投影对应的正是垂直方向的高频，这部分信息在有限角下被系统性抹掉，这就是 16.2.2 节所说的“不可见边缘”。有限角 CT 的不适定性更严重——16.2.2 节指出其奇异值按 $e^{-cn}$ 衰减（vs 稀疏角度的 $1/n$），缺失的角度范围导致对应方向的频域信息缺失。注意本实验采用 IC-free 双分辨率方案（$256 \to 128$，含尺度归一化），PSNR 绝对数值受模型失配限制（全角 23.8 dB，同模型基线实测 29.3 dB），但两种不适定性的**相对差异**仍然清晰可见。

---

#### 步骤2：正则化重建对比——FBP vs Tikhonov vs TV

![实验16.2-1 步骤2：正则化对比](<./第十六章 配套实验/实验16.2-1/步骤2_正则化对比.png>)

**正则化方法性能对比**（在稀疏 30 角度含噪 sinogram 上）：

| 方法 | PSNR | SSIM | 特点 |
|------|------|------|------|
| FBP | 14.2 dB | 0.279 | 噪声放大，条纹明显 |
| Tikhonov | 18.8 dB | 0.475 | 过度平滑，边缘模糊 |
| TV 正则化 | 20.7 dB | 0.577 | 保持边缘锐利 |

步骤2验证了 16.2.4 节的核心结论：**TV 的 $\ell^1$ 梯度惩罚天然匹配分段常数结构**（如 Shepp-Logan 幻影），而 Tikhonov 的 $\ell^2$ 惩罚偏好平滑解，导致边缘模糊。TV(20.7) > Tikhonov(18.8) > FBP(14.2) 的 PSNR 排序验证了 16.2.4 节的方法选择指南；且 TV 恢复到无噪 FBP 的水平（20.6 dB）——即 TV 正则化几乎完全抵消了 5% 相对噪声造成的损失。注意噪声采用**相对水平**（占 sinogram 峰值的 5%）：sinogram 峰值约 30，若按绝对 $\sigma=0.05$ 加噪，相当于约 62 dB 信噪比，噪声完全不可见（实测含噪与无噪 FBP 的 PSNR 完全相同），正则化对比将失去意义。

> **实现口径（读上面的表之前请先看这句）**：本实验的 TV 与 Tikhonov 共用同一套一阶梯度下降、同一 $\lambda=0.1$、同一步长，且 TV 走的是显式梯度步（$-\lambda\,\mathrm{div}(\nabla x/|\nabla x|)$），**不是**近端算子 prox。这是一次"同预算下的对比"，但两者都**不是各自调参到最优的结果**：TV 若换成 prox/ADMM 并单独调 $\lambda$，通常还能再高；Tikhonov 同理。所以上表应读作"同等参配下，TV 的归纳偏置更适合分段常数图像"，而不是"两种方法的最优性能差 1.9 dB"。

#### 步骤3：角度数量 vs 重建质量——不适定性的量化

![实验16.2-1 步骤3：角度vs质量](<./第十六章 配套实验/实验16.2-1/步骤3_角度vs质量.png>)

**PSNR 曲线对比**：

| 配置 | 曲线特征 | 关键观察 |
|------|---------|---------|
| 角度数量扫描 | PSNR 随角度数单调递增，约 30 角后趋于饱和 | 无噪 13.1→23.8 dB；含噪（5%）曲线整体更低，少角度时差距最大（10 角：13.1 vs 8.2 dB） |

步骤3量化了 16.2.1/16.2.2 节的不适定性程度差异。左图：PSNR 随投影角度数单调递增（10 角度 13.1 dB → 180 角度 23.8 dB），约 30 角后趋于饱和；含 5% 相对噪声的曲线整体低于无噪曲线，且少角度时差距最大（10 角度时 13.1 vs 8.2 dB）——欠采样与噪声的联合作用使问题更病态。右图：有限角度 PSNR 随覆盖范围非线性增长，接近全角（150°–180°）时提升加速（频域缺口缩小），30° 覆盖时 PSNR 仅 8.0 dB。两条曲线直观量化了 16.2.1/16.2.2 节的不适定性程度差异。注意 IC-free 方案下 PSNR 绝对数值受模型失配限制（上限 23.8 dB，同模型基线实测 29.3 dB——两组数见 `results_summary.json` 的 `同模型基线` 字段），但曲线的**单调递增趋势**和**有限角度的急剧下降**仍然清晰。

#### 核心知识点总结

| 概念 | 数学表达 | 实验验证 |
|------|---------|---------|
| 稀疏角度不适定性 | $\sigma_n \sim 1/n$（算子温和）+ 欠采样 | 步骤1：混叠摩尔纹覆盖全图（PSNR 20.6 dB） |
| 有限角度不适定性 | $\sigma_n \sim e^{-cn}$（严重） | 步骤1：条纹 + 亮环 + 边缘丢失（PSNR 17.7 dB，垂直边保留度仅 0.39） |
| Tikhonov 局限 | $\ell^2$ 惩罚偏好平滑解 | 步骤2：过度平滑，边缘模糊（18.8 dB） |
| TV 优势 | $\ell^1$ 梯度惩罚保边 | 步骤2：保边最优（20.7 dB，恢复无噪 FBP 水平） |
| 不适定性量化 | PSNR vs 角度数/范围 | 步骤3：无噪 13→24 dB、含噪 8→21 dB 单调递增；有限角 30° 覆盖仅 8.0 dB |
| inverse crime | 数据生成与反演用不同离散化模型 | 双分辨率 + 探测器尺度归一化（$256 \to 128$）；失配代价实测约 5.5 dB（29.3→23.8 dB） |

**关键洞察**：实验完整验证了 16.2 节的核心论点——**正则化方法的选择必须匹配不适定性的程度**。TV 正则化在含噪稀疏角度 CT 上将 PSNR 从 FBP 的 14.2 dB 提升至 20.7 dB（恢复到无噪 FBP 水平），但对于更严重的有限角度 CT，需要更强的先验（学习型方法、扩散先验）。实验同时验证了 16.2.4 节的方法选择指南：温和不适定 → Tikhonov/TV；严重不适定 → 剪切波/学习型方法。IC-free 双分辨率方案（含探测器尺度归一化）的失配代价实测约 5.5 dB（同模型基线 29.3 dB → IC-free 23.8 dB），揭示了模型失配是真实重建中不可忽略的误差源。

## 实验 16.2-2：ASTRA工具箱——CT不适定性演示

实验 `16.2-2.py` 使用**ASTRA/skimage 对比全角、稀疏角度和有限角度 CT 的重建效果**，直观验证两种不适定性的差异。

### 实验场景

实验使用 ASTRA 工具箱（或 skimage 回退版本）对比三种 CT 配置：全角（360 角度）、稀疏角度（30 角度）、有限角度（0°–90°）。实验重点展示 16.2.1/16.2.2 节的核心差异：**稀疏角度产生混叠，有限角度丢失不可见边缘**。

### 实验目的

1. **使用工业级工具箱演示 CT 不适定性**：在 ASTRA 或 skimage 上验证实验 16.2-1 的结论
2. **直观对比三种 CT 配置**：全角/稀疏角度/有限角度的重建差异
3. **验证伪影模式差异**：混叠伪影 vs 不可见边缘丢失
4. **量化不适定性程度**：绘制角度扫描的 PSNR 曲线

### 实验输入

| 参数 | 设置 |
|------|------|
| 测试图像 | 随机椭圆幻影或 Shepp-Logan 幻影，重建分辨率 $256 \times 256$，数据生成分辨率 $512 \times 512$ |
| 全角配置 | 360 角度（ASTRA 与 skimage 回退一致），ASTRA 覆盖 $[0,360^\circ)$ 扇形束 / skimage 覆盖 $[0,180^\circ)$ 平行束 |
| 稀疏配置 | 30 角度，$\theta \in [0, 180^\circ)$（skimage 回退） |
| 有限配置 | 180 角度（ASTRA 与 skimage 回退一致），$\theta \in [0, 90^\circ]$ |
| 运行环境 | ASTRA（需 CUDA：扇形束 FBP 仅有 FBP_CUDA 实现，CPU 版 ASTRA 会报错）或 skimage（无 CUDA 时自动回退） |
| 避免 inverse crime | skimage 回退路径采用 $512 \times 512$ 高分辨率生成 sinogram，resize 到 $256 \times 256$ 供重建（ASTRA 路径因工具箱本身模型差异，未额外处理） |

> **关于 inverse crime**：与实验 16.2-1 相同，skimage 回退路径采用双分辨率方案（$512 \to 256$）避免"用同一矩阵既造数据又反演"。实测同模型基线（$256$ 生成 $\to 256$ 反演）全角 FBP 约 27.8 dB，IC-free 后降为 23.5 dB（约 $-4.3$ dB）——方向正确但力度温和：由于高分辨率幻影是由低分辨率幻影上采样而来（信息同源），512 生成再 resize 回 256 的 sinogram 与直接 256 生成的数据高度相关（归一化尺度后逐点比值约 $1.00$），实质失配主要来自 resize 的探测器域抗混叠模糊；在稀疏角度下混叠误差主导，IC-free 的影响被淹没（实测 19.95 → 20.28 dB，仅 +0.33 dB）。ASTRA 路径由于工具箱自身的投影几何实现与 skimage 不同，模型失配天然存在，故未额外处理。

### 预期结果

- 全角 FBP 重建质量最高（skimage 回退实测 23.5 dB）
- 稀疏角度产生条纹伪影覆盖全图（skimage 回退实测 20.3 dB）
- 有限角度产生条纹集中在缺失方向 + 边缘丢失（skimage 回退实测 16.2 dB）
