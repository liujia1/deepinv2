# 16.6 本章小结：从物理到先验的统一

本章用两种最典型的医学成像模态——CT 和 MRI——把全书的理论框架按在了真实世界上。两种模态物理原理完全不同，但用逆问题的眼光看，它们共享同一副骨架：

$$y = Ax + \epsilon \quad \xrightarrow{\text{逆问题}} \quad p(x|y) \propto p(y|x) \cdot p(x)$$

| | CT | MRI |
|---|---|---|
| 物理基础 | X 射线衰减（Beer-Lambert） | 核磁共振（Bloch 方程） |
| 正向算子 $A$ | Radon 变换（线积分） | 欠采样傅里叶变换 |
| 测量空间 | sinogram $(\theta,s)$ | k-space $\mathbf{k}$ |
| 不适定性来源 | 有限角度/稀疏投影 | 加速采集（欠采样） |
| 经典方法 | FBP | 逆 FFT |
| 正则化 | TV/小波/剪切波 | CS（小波 + TV） |
| 加速技术 | — | 并行成像 + CS |
| 扩散方法 | DPS/DiffPIR | DDRM/DPS/DiffPIR |

## 先验演化的统一

从 FBP 到扩散先验，CT/MRI 重建方法的演化不是偶然的——每一步都是前一步局限性的自然回应：

```
物理先验（FBP/FFT）
    │ 局限：需要完整数据 + 低噪声
    ▼
正则化先验（TV/小波/CS）
    │ 局限：表达能力有限（第 2 章"显式先验天花板"）
    ▼
学习型先验（UNet/展开）
    │ 局限：需要配对数据、无不确定性量化
    ▼
扩散先验（DPS/DDRM/DiffPIR）
    │ 三重优势：无需配对数据、不确定性量化、零样本迁移
    ▼
```

这条演化线和全书第 1 章到第 13 章的叙事弧完全同构：

```
第1-2章：逆问题 → 贝叶斯 → 先验的必要性
第3章：MAP → 正则化 → 显式先验的天花板
第4-6章：后验采样 → 得分函数 → 学习先验
第7章：扩散模型 → 多步得分驱动采样
第13章：条件扩散 = 逆问题求解 → 扩散先验重建
```

**医学成像验证了全书核心论点**：扩散模型是逆问题自然发展的终点。从 CT/MRI 的具体场景看，这个"终点"不是理论推演，而是有真实临床价值的解决方案。

从更深层次看，这条演化线的本质，正是全书核心命题"**先验即结构化知识、知识来源不断更替**"在医学成像里的具体化。FBP 阶段，先验来自物理推导与成像几何——斜坡滤波器 $|\omega|$、Radon 算子本身，都是对"世界如何被成像"的物理约束；正则化阶段，先验来自统计稀疏假设——TV 的梯度稀疏、小波 / 剪切波的稀疏表示；学习型与扩散阶段，先验来自数据分布——UNet 学到的映射、扩散模型学到的生成分布。这三次更替并非改变了先验的意义，它们始终在回答同一个问题：**补全测量缺失的信息**。真正在变的是"知识从哪里来"：从物理世界、到统计规律、再到大规模数据。这一转变意味着，"从物理到先验的统一"最凝练的表述，其实就是"先验的知识来源在不同时期被系统地更替"。这也解释了为何本章的叙事从 FBP 出发、以扩散收束——每一步都在回答前一步先验"不够"的问题。

## 扩散先验的三重优势

回顾第 13 章 13.6，扩散模型超越传统方法的三重优势在医学成像里格外亮眼：

1. **无需配对训练数据**：预训练无条件扩散模型，条件采样无需针对特定逆问题的配对数据——医学里配对数据难获取，这优势尤其宝贵
2. **不确定性量化**：多次后验采样 → 像素级置信区间——临床决策里极重要
3. **零样本迁移**：同一个预训练模型可直接用于不同 CT/MRI 任务，无需重训

## 展望

本章的扩散先验方法还有两个未解的问题：

1. **训练扩散模型本身要大量图像数据**：虽然条件采样无需配对数据，但训扩散模型本身需要数据。医学数据稀缺怎么解？——第 17 章自监督学习给答案。
2. **计算效率**：扩散采样要数百步前向传播，重建分钟级——远慢于 UNet 毫秒级。怎么加速？——第 14 章 Flow Matching 和 DDIM 等加速采样器是可能的解法。
3. **等变性与物理约束**：CT/MRI 算子有特定对称性（平移、旋转等变），怎么把物理先验融进网络？——第 17 章等变架构回答。

下一章介绍自监督学习和等变架构——前者解训练数据稀缺，后者把物理对称性融进网络设计，进一步提升重建质量和泛化。

**全章收束**：用一句话概括整章——**CT 和 MRI 看似两种设备，但在逆问题眼里，它们都是从"扭曲的测量"反推"清晰的图像"；而从 FBP 一路走到扩散先验，本质就是从"靠物理公式"走向"靠数据分布当先验"，这恰好是全书一直在讲的同一件事：先验即知识，而知识的来源，在随着数据的丰富不断更替。**
