# 14.5 前沿组合：SD3 / Flux = Rectified Flow + DiT

> **核心观点**：Stable Diffusion 3（Esser et al., 2024）和 Flux 是工业级 Flow Matching 的成功验证——把 Rectified Flow 的训练目标与 Diffusion Transformer（DiT）架构结合，在文生图上达到 SOTA（state-of-the-art，当前最好水平）。关键创新：Logit-Normal 时间采样（给中间时间步更多权重）、多模态 DiT（MMDiT，图文双模态交互）、大规模可预测缩放规律。

> **本节定位**：本节只聚焦"Rectified Flow + DiT"这一组合**为何有效**，是一个"路线 + 架构"的缝合点；DiT 架构本身的设计细节（patch embedding、注意力结构、可预测缩放规律等）在第15章专门展开，本节不重复。请把它理解为向第15章的刻意过渡，而非第14章原创了 DiT。

## 反直觉开场：算法"更直"了，为什么还不够？

14.4 节我们让路径变直、采样变快。但工业级文生图的残酷现实是：**算法只占一半，架构是另一半**。你有最直的路径，但若网络看不清全局（CNN 局部感受野），少步采样时一步跨太大就会出错。SD3/Flux 的回答是：把最直的路径（Rectified Flow）配上最擅长"全局看问题"的架构（Transformer/DiT）。

下面我们沿着"为何有效"拆开看。

> **这一转变意味着**：从此前几节纯"算法/数学"的层面，我们过渡到了"算法 × 架构"的工业层面。算法决定了"轨迹该多直、目标该 regress 什么"，架构决定了"这样一个向量场网络能否在巨大规模上稳定地学到"。两者缺一，工业级 SOTA 都无从谈起。

## 14.5.1 SD3 的核心设计

### Rectified Flow 作为训练框架

SD3 选 Rectified Flow 作训练框架——直线插值 $x_t=(1-t)z+t\,x_0$，回归速度 $x_0-z$。这并非主观选择：SD3 论文在 **60 种不同扩散轨迹**上做了大规模对比（LDM、EDM、ADM、Rectified Flow 等），结论是 **Rectified Flow 在少步（4步、8步）采样下显著优于其他轨迹**，多步（50步）也有竞争力，且模型越大优势越明显。（具体 FID 对比见 Esser et al. 2024 Figure 4/18，本书不再转引。）

### Logit-Normal 时间采样：把力气花在"最难"的时刻

**痛点（when/why/how）。**
- **when**：标准 RF 均匀采样 $t\sim U[0,1]$，所有时间步同等对待。
- **why（先猜后揭）**：猜——所有时间步难度一样？**错**。靠近噪声端（$t\approx0$）信号微弱、接近纯噪声，好猜；靠近数据端（$t\approx1$）信号清晰，也好猜；**中间 $t\approx0.5$ 信号和噪声量级相当，最难**。少步采样时中间步误差会累积放大。
- **how**：用 Logit-Normal 分布替代均匀，让中间时间步概率更高：

$$\pi_{\text{ln}}(t; m, s) = \frac{1}{s\sqrt{2\pi}} \cdot \frac{1}{t(1-t)} \exp\left(-\frac{(\text{logit}(t) - m)^2}{2s^2}\right), \quad \text{logit}(t) = \log\frac{t}{1-t}$$

逐项看这个密度的含义：$\text{logit}(t)=\log\frac{t}{1-t}$ 把 $(0,1)$ 区间映射到整个实轴；外面那个 $1/[t(1-t)]$ 是 logit 变换的 Jacobian，保证"先对 $\logit(t)\sim\mathcal{N}(m,s)$ 采样、再经 $\sigma$ 变换回 $t$"得到的密度恰好是这个形式。两个参数各有直观意义：
- $m$：重心位置（$m=0$ 居中，$m>0$ 偏数据端）；
- $s$：集中程度（$s\to0$ 趋点质量，$s\to\infty$ 趋均匀）。

SD3 发现 $m=0,s=1$ 是较好默认。效果：少步（4/8步）下 FID 显著优于均匀采样——因为中间步预测质量对少步影响最大。

**和其他时间采样策略对比：**

| 策略 | 概率密度 | 优势 | 劣势 |
|---|---|---|---|
| 均匀采样 | 恒定 | 简单 | 中间步预测不充分 |
| 离散化采样 | 离散点 | 匹配推理步数 | 灵活性差 |
| Logit-Normal | 钟形（logit空间） | 中间步权重高 | 需调参 $m,s$ |
| Cosine调度 | 缓变 | 边界平滑 | 非最优权重 |

SD3 结论：**Rectified Flow + Logit-Normal 采样**是少步场景的最优组合。

### 实验 14.5-1：Logit-Normal时间采样

实验 `14.5-1.py` 演示**均匀时间采样与Logit-Normal时间采样在Rectified Flow训练中的效果对比**，验证SD3的核心改进之一。

### 实验场景

实验在MNIST数据集上训练两个Rectified Flow模型，使用相同的SmallUNet架构，但时间采样策略不同：

**均匀时间采样**：$t \sim U[0, 1]$，所有时间步等概率采样。这是标准Rectified Flow的默认设置。

**Logit-Normal时间采样**：$t \sim \pi_{\text{ln}}(t; m, s)$，中间时间步采样概率更高。参数$m=0$（重心在$t=0.5$），$s=1$（适度集中）。

两种采样策略的核心差异：
- **均匀采样**：端点区域（$t < 0.1$或$t > 0.9$）采样概率为10%+10%=20%
- **Logit-Normal采样**：端点区域采样概率很低（$m=0,s=1$ 时两侧各约1.4%，合计约2.8%，仅为均匀采样的约14%），中间区域采样概率更高

### 实验目的

1. **验证Logit-Normal采样的优势**：对比两种采样策略的少步采样质量
2. **理解端点采样概率的影响**：Logit-Normal在端点区域采样较少，对1步采样有影响
3. **验证SD3的结论**：Logit-Normal在少步采样（4-8步）下优势明显
4. **理解参数影响**：参数$m$控制重心位置，$s$控制集中程度

### 实验输入

| 参数 | 设置 |
|------|------|
| 数据集 | MNIST（60000训练，10000测试） |
| 网络架构 | SmallUNet（与实验14.3-3相同） |
| 均匀采样参数 | $t \sim U[0, 1]$ |
| Logit-Normal参数 | $m = 0, s = 1$（SD3推荐） |
| 训练轮数 | 30 epochs |
| 批大小 | 128 |
| 学习率 | $2 \times 10^{-4}$（Adam优化器） |
| 采样步数对比 | 1步 / 5步 / 10步 / 50步 |
| 量化指标 | 平均最近邻距离（生成样本与最近真实样本的像素距离） |
| 量化样本数 | 64（减少统计噪声） |

> **参数说明**：Logit-Normal的采样方法是：先从$\mathcal{N}(m, s^2)$采样$u$，然后$t = \sigma(u) = 1/(1+\exp(-u))$。

### 预期结果

- （SD3 理论预测）Logit-Normal 在少步采样（5-10 步）下优于或持平均匀采样；但本实验规模小、指标为代理量，能否复现需看实测
- Logit-Normal 在1步采样下可能不如均匀采样（端点采样不足）
- 训练收敛的原始 loss 因两者对 $t$ 的加权测度不同而**不可直接比较**（详见步骤2提醒）

#### 核心知识点：Logit-Normal采样的实践意义

**为什么Logit-Normal在少步采样下更优？**
- 少步采样时，中间时间步的预测误差会累积
- Logit-Normal给中间时间步更多权重，提高了关键区域的预测质量
- 这直接解释了SD3在60种轨迹对比中"Rectified Flow + Logit-Normal"最优的结论

**1步采样的特殊性**：
- 1步采样是极端外推场景：从$t=0$（纯噪声）直接跳到$t=1$（数据）
- 这要求模型在端点区域有充分训练经验
- Logit-Normal在端点采样不足，导致1步采样改善有限甚至略差
- 实践中，SD3论文的结论是"少步采样（4-8步）时优势明显"，而非1步

**参数选择建议**：
- $m = 0$：重心在中间，适合少步采样
- $s = 1$：适度集中，平衡端点和中间步
- 如需改善1步采样，可增大$m$（偏向数据端）或增大$s$（更接近均匀）

## 14.5.2 MMDiT 架构：双模态 Diffusion Transformer

### 从 UNet 到 DiT

**架构演进回顾（因果）：**
- **UNet**（Ronneberger et al., 2015；被 Ho et al., 2020 引入扩散模型）：编码器-解码器+跳跃连接，CNN 架构，局部感受野（只看附近像素）。
- **DiT**（Peebles & Xie, 2023）：用 Transformer 替代 UNet，全局感受野（自注意力能看到整张图），缩放性好。

DiT 核心设计：
- **Patchify**：图像切块（如16×16），每块成一个 token（token，白话：输入序列里的一个"词"）；
- **adaLN-Zero**：自适应 LayerNorm，用时间步 $t$ 和条件 $c$ 调制每个 Transformer 块的缩放/偏移；
- **缩放规律**：加参数量遵循可预测的性能提升曲线。

### MMDiT：多模态 DiT

SD3 提出 **MMDiT（Multi-Modal DiT）**，在 DiT 上扩展以同时处理图像和文本两种模态：
- **双权重设计**：图像 token 和文本 token 用独立权重集（因两者统计特性差异大）；
- **双向信息流**：每个 Transformer 块里图像/文本 token 做联合注意力，双向交互（图像→文本识别图中文字，文本→图像引导生成）；
- **序列构建**：图像 patch token + 文本 token 拼接后送入 MMDiT；
- **时间与条件调制**：adaLN-Zero 注入 $t$ 和文本条件。

**文本从哪来：编码器三件套的分工。** MMDiT 的文本 token 并非原始文字，而是由多个文本编码器联合提供。SD3 的配置体现了"分工"思想：**CLIP-L/14 与 OpenCLIP-bigG**（对比学习训练）输出池化的全局语义向量，负责"图文对齐"——prompt 的整体语义与图像风格基调；**T5-XXL** 输出 token 级细粒度语义序列，负责长 prompt 的逐词修饰关系与文字渲染所需的精确拼写信息。全局对齐与局部细节由不同编码器分担，再交给 MMDiT 的联合注意力与图像 token 交互。SD3 论文还在消融中探讨了字节级编码（ByT5）对拼写能力的进一步改进——文本表征的选择本身就是一条与架构并列的设计轴。

**与 UNet 对比：**

| 特性 | UNet | DiT | MMDiT |
|---|---|---|---|
| 架构 | CNN | Transformer | 多模态Transformer |
| 感受野 | 局部 | 全局 | 全局 |
| 条件注入 | 交叉注意力/嵌入 | adaLN-Zero | adaLN-Zero |
| 多模态 | 不原生支持 | 不原生支持 | 双权重+双向注意力 |
| 缩放性 | 受CNN归纳偏置限 | 可预测缩放 | 可预测缩放 |

> **从更深层次看**，DiT 的"全局感受野"与 Rectified Flow 的"直线路径"是一种几何上的共振：路径越直，意味着一次大步长采样就要跨越大片空间；若网络只能看见局部，这一步就容易"踩空"。全局注意力让网络在少步时也能看清整条传输方向——这是"更直路径"能被工业级落地的前提。

### CFG 的向量场形式：推理闭环的最后一块拼图

SD3/Flux 的推理还依赖最后一块拼图：**引导（guidance）**。13.4.2 节讲过得分版的 Classifier-Free Guidance——把条件得分与无条件得分的差值放大。向量场世界里配方原样照搬，只是放大的对象从得分换成了向量场：

$$\boxed{\tilde{v}_t(x \mid y) = (1-w)\, v_t(x \mid \varnothing) + w \cdot v_t(x \mid y) = v_t(x \mid \varnothing) + w\bigl[v_t(x \mid y) - v_t(x \mid \varnothing)\bigr]}$$

$\varnothing$ 是**空标记**（表示"无条件"），$w \geq 1$ 是引导权重。为什么这个线性组合式成立？回想 14.3.4 节的三角转换：高斯路径下向量场与得分线性相关，$v_t = a_t \nabla \log p_t + b_t x$。条件场与无条件场用的是**同一条概率路径**（同样的 $a_t, b_t$），差别只在得分项。于是由贝叶斯分解 $\nabla\log p_t(x \mid y) = \nabla\log p_t(x) + \nabla\log p_t(y \mid x)$：

$$\tilde{v}_t(x \mid y) = v_t(x \mid \varnothing) + w \, a_t \nabla \log p_t(y \mid x)$$

即 CFG 等价于把"隐式分类器" $\nabla \log p_t(y \mid x)$（条件带来的额外得分）的贡献放大 $w$ 倍——这正是 13.4.2 节"差值放大"结构的向量场版。对上式做代数整理即得线性组合形式；且这个组合式**对任意概率路径都成立**（不限于高斯路径），$w = 1$ 时恰好还原真条件场 $v_t(x \mid y)$。

**训练：一个网络，两种能力。** 与 13.4.2 的得分版完全平行：训练单一网络 $v_\theta(x, t, y)$，以概率 $\eta$（丢标签率）把条件 $y$ 替换为空标记 $\varnothing$：

$$\mathcal{L}_{\text{CFG-CFM}}(\theta) = \mathbb{E}_{(x_0, y) \sim p_{\text{data}},\ t \sim U[0,1],\ x_t \sim p_t(\cdot \mid x_0)} \bigl\| v_\theta(x_t, t, \tilde{y}) - v_t(x_t \mid x_0) \bigr\|^2, \quad \tilde{y} = \begin{cases} \varnothing & \text{以概率 } \eta \\ y & \text{以概率 } 1-\eta \end{cases}$$

注意一个容易忽略的细节：丢标签时**回归目标不变**（仍是条件向量场，RF 下就是 $x_0 - z$），被丢弃的只是网络的输入条件。对随机丢弃取平均后，$\varnothing$ 分支学的正是无条件（边际）场 $v_t(x \mid \varnothing) \approx \mathbb{E}[x_0 - z \mid x_t]$。于是一个网络同时具备条件与无条件两种前向能力——这就是"classifier-free"名字的由来：连 13.4.1 节 Classifier Guidance 需要的噪声分类器都省了。

**推理：每次前向变两次。** 采样每步要跑两次网络（条件、无条件各一次），按 $w$ 线性组合后再积分 ODE。这也是工业级文生图推理成本里"CFG 让开销翻倍"的来源。

> **一个必须诚实交代的警示**：$w = 1$ 时采样分布严格是 $p_{\text{data}}(\cdot \mid y)$；**$w > 1$ 之后不再如此**——组合场对应的其实是"似然放大 $w$ 次幂"的温度化后验 $\tilde{p}(x \mid y) \propto p_{\text{data}}(x)\, p(y \mid x)^w$（重新归一化后），而非真后验。所以 $w > 1$ 是纯启发式，理论保障为零。它的实际效果与 13.4.3 节的 $\zeta$ 完全同款：条件一致性增强、多样性下降。工业级文生图系统几乎无一例外重度依赖 CFG，引导权重常取 4 上下或更高——工程效果极好，理论身份始终是"启发式"。

至此 SD3/Flux 的完整配方闭环：**训练** = RF 直线路径 + Logit-Normal 时间采样 + CFG 丢标签（14.5.1 + 本小节）；**推理** = RF ODE 积分 + CFG 组合采样。理论（14.3/14.4）与工程（14.5）就此接通。

> **配套实验**（第 13 章）：CFG 的完整训练—推理闭环已在第 13 章配套实验中实现——13.4-1（Diffusers 的 CFG 采样）与 13.6-4（显式 CFG 的权重拼接）；上式的向量场形式与 13.4.2 的"差值放大"是同一机制在两种参数化下的写法，本章不再重复展开。

### SD3 的缩放规律

SD3 验证了一个重要结论：**验证损失与生成质量（FID、CLIP分数、人类偏好）正相关**——监控验证损失就能预测生成质量，无需每次都做昂贵的图像评估。从 0.4B 到 8B 参数，参数量每增10倍验证损失约降 $\Delta$，且跨数据集/指标一致。这对工业实践意义重大：可用小规模实验预测大模型性能，降低试错成本。

## 14.5.3 Flux 与后续发展

### Flux

Flux（Black Forest Labs, 2024）是 SD3 之后 Flow Matching 在工业界的进一步验证。核心设计一脉相承（Rectified Flow + DiT），改进了训练策略（更精细时间采样）、更大模型规模、更高效推理管线，在高分辨率（1024×1024+）图像质量上进一步提升。

### Flow Matching 生态的快速发展

**理论发展**：Riemannian Flow Matching（推广到黎曼流形，支持分子生成）、Stochastic Interpolants（FM 的随机化，融合 SDE/ODE）、Multisample FM（minibatch OT 耦合）、Shortcut Models（在 velocity 场里学步长，统一单/多步生成）。

**实践应用**：SD3/SD3.5（文生图）、Flux（高分辨率）、Cosmos（NVIDIA 视频生成）、Matcha-TTS / FlowMDM（语音、分子、运动等非图像领域）。

**趋势判断**：Flow Matching 正快速替代扩散模型成为新一代生成框架的标准——"从 SDE 到 ODE"的范式转变已在工业界发生。

## 14.5.4 回顾与展望

### 本章叙事线回顾

```
最优传输基础(14.1) → CNF困境(14.2) → Flow Matching突破(14.3) → Rectified Flow优化(14.4) → SD3/Flux落地(14.5) → 离散扩散/MDLM(14.6)
```

核心转变贯穿始终：
- **驱动力**：得分函数 $\nabla\log p_t$ → 向量场 $v_t$ → 速率矩阵 $Q_t$（14.6）
- **采样方式**：SDE → ODE（14.3.7：同一向量场可配任意噪声强度——二分实为连续谱）
- **路径形态**：弯曲 → 直线
- **训练方式**：间接（先学得分）→ 直接（回归向量场）
- **优化目标**：匹配噪声调度 → 最优传输

### Flow Matching 与扩散模型的统一视角

Flow Matching 不是否定扩散模型，而是**包容和超越**：
- 扩散模型 = FM 在**扩散耦合 + 弯曲条件路径**下的特例；
- DDIM = FM 在**扩散耦合 + 高斯条件路径**下的特例；
- OT-CFM = FM 在**OT耦合 + 直线条件路径**下的实例化；
- Rectified Flow = 通过**直线插值 + Reflow 迭代**逐步逼近 OT 映射。

从全书看，三条路径——得分路径（第5-7章）、变分路径（第8-12章）、向量场路径（本章）——在 ODE 层面汇合：无论哪个出发点，最终都是解一个从噪声到数据的 ODE。FM 提供了最直接的路径——直接学 ODE 的向量场，无需绕 SDE 或 ELBO。

### 全书核心论点的深化

第1章提出逆问题的贝叶斯解 $p(x|y)\propto p(y|x)p(x)$，全书围绕"如何从 $p(x)$ 采样"展开。FM 提供第三种采样策略：
1. 第4-5章 Langevin 动力学——用得分 $s(x)=\nabla\log p(x)$ 驱动 SDE；
2. 第7章 扩散 SDE——用多尺度得分 $\nabla\log p_t(x_t)$ 驱动逆向 SDE/PF-ODE；
3. **第14章 Flow Matching——用向量场 $v_t(x_t)$ 驱动流 ODE**。

三者关系：Langevin 是单尺度 SDE，扩散是多尺度 SDE+ODE，FM 是纯 ODE——逐步消除随机性与间接性，追求确定性、直接性、高效性。

> **从更深层次看**，这条"Langevin → 扩散 → FM"的演进，正是本书"从学得分到学向量场"叙事线的一次完整收官：驱动力越来越直接（得分→多尺度得分→向量场），随机性越来越低（SDE→SDE+ODE→纯 ODE）。它告诉我们，生成建模的效率追求天然地把我们推向"直接、确定、最短"的方向——而这一切，都收束在向量场学习这一层。

### 与第15章的衔接

14.5 涉及的 DiT/MMDiT 架构，将在第15章详细剖析其设计原理、缩放规律和工程实现。第15章回答：**为什么 Transformer 比 UNet 更适合 Flow Matching？**——答案在于 Transformer 的全局感受野与 FM 的直线路径天然契合：全局注意力让网络一步"看全"整条传输路径，而 CNN 的局部感受野更适合逐步扩散的弯曲路径。
