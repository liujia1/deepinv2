# 5.7 本章小结：去噪器 = 隐式先验 = 得分估计器

> 核心观点：第 4 章的 ULA 以得分函数 $\nabla\log p(x|y)$ 为驱动力，但得分函数从哪来？本章回答三个问题：Langevin SDE 作为连续随机过程的数学结构是什么？得分函数是什么、有什么几何含义？如何获取它？答案是：得分函数是概率分布的"方向场"，而 **Tweedie 等式**把去噪器与得分函数桥接起来——有了好的去噪器，就有了得分函数。再经由 MAP/MMSE 结构对偶与 PnP 框架，"去噪器 = 隐式先验 = 得分估计器"这一三位一体的认识正式确立。

## 一、本章走过了什么

```
5.1 从 MCMC 到 Langevin SDE（离散 → 连续，Fokker-Planck 保证平稳分布）
  │
5.2 得分函数：对数概率的梯度（方向场、无需归一化常数）
  │
5.3 Tweedie 等式：∇log p_ε = (D_ε - x)/ε（去噪器 → 得分）
  │
5.4 MAP 与 MMSE 的结构对偶：近端算子 vs 去噪器（温度视角）
  │
5.5 PnP 框架：用去噪器替换先验梯度（PnP-ULA / PnP-ADMM）
  │
5.6 近似理论与收敛保证（Moreau-Yoshida 包络 + PnP 收敛定理）
```

- **5.1**：ULA 是 Langevin SDE 的 Euler 离散化。Fokker-Planck 方程证明漂移力与扩散力在平稳态恰好平衡，$p(x|y)$ 是平稳分布；强对数凹条件下指数收敛。
- **5.2**：得分函数 $s(x)=\nabla\log p(x)$ 在每一点指向密度增长最快的方向，且**无需归一化常数**——这是它不可替代的核心优势。后验得分可分解为似然得分 + 先验得分，后者是获取的瓶颈。
- **5.3**：Tweedie 等式（核心定理）：$\nabla_y\log p_\varepsilon(y)=\frac{D_\varepsilon^*(y)-y}{\varepsilon}$——得分 = 去噪器残差 / 噪声方差。它绕过了 $Z$，把"训练去噪器"与"学习得分"等价起来，是全书从逆问题走向扩散模型的关键一步。
- **5.4**：近端算子（MAP 方向）与去噪器（MMSE 方向）具有相同结构 $y-\varepsilon\nabla(\cdot)(y)$，区别只在"温度"——MAP 是零温度的 MMSE，MMSE 是满温度的 MAP。
- **5.5**：PnP 把 Tweedie 的洞见落地——用学习到的去噪器替换 ULA 中的先验梯度得到 PnP-ULA，去噪器成为"隐式先验"，无需显式指定先验形式。
- **5.6**：Moreau-Yoshida 包络给出近似密度的性质保证（真密度、对数凹、光滑）；PnP 收敛定理要求去噪器是压缩映射（$\text{Lip}(D_\varepsilon)\le\eta<1$）。

从更深层次看，"去噪器 = 隐式先验 = 得分估计器"不是三个偶然相等的角色，而是同一对象的三张面孔，分别对望着同一个认知链条的三个环节：去噪器回答"干净信号长什么样"（先验），Tweedie 等式回答"这份知识如何换算成梯度"（得分），PnP 回答"这份梯度如何驱动后验采样"（推断）。三者缺一，都无法把隐式先验真正用起来。

## 二、从去噪器到采样的一条计算链

```
训练去噪器 D_ε（监督学习，数据充足时可行）
  → Tweedie 等式：s_ε(x) = (D_ε(x) - x)/ε（得分估计）
  → 代入 ULA 替换先验梯度 → PnP-ULA（数据驱动的后验采样）
  → 多时间步噪声调度 → 扩散模型（第7章）
```

这条链把"去噪"与"采样"打通，也把"显式先验"升级为"隐式先验"——是第 5 章作为采样路径关键枢纽的意义所在。

这一转变意味着：先验从"需要被书写出来的公式"变成了"可以被训练出来的能力"。我们不再试图穷尽"自然图像长什么样"的所有规则，而是让一个去噪网络在大量图像上习得这份统计知识，再由 Tweedie 等式把它翻译成计算可用的梯度。这是全书"先验即知识、知识可学习"主线的一次直接兑现。

## 三、与前后章的呼应

- **承接第 4 章**：ULA 是本章 Langevin SDE 的离散起点；MYULA 的近端算子被 PnP 的去噪器替换。
- **承接第 2 章**：2.3 的"去噪器 = 先验下的 MMSE 估计器"在此升级为 Tweedie 等式——去噪器直接给出得分。
- **向前开放（第 6 章）**：去噪器从哪来？得分匹配给出系统训练方法——训练去噪器等价于学习得分函数（DSM）。
- **向前开放（第 7 章）**：PnP 是"单温度"扩散，扩散是"多温度"PnP——多时间步噪声调度把单尺度得分推广为多尺度。

## 四、展望

下一章回答"去噪器从哪来"：如何从数据中系统地学习得分函数？第 6 章将走过 ESM → ISM → DSM → SSM 的方法演进，最终以去噪得分匹配（DSM）为实用突破——**得分匹配 = 从数据中学习得分 = 训练去噪器**，三位一体为第 7 章的扩散模型铺平道路。

**一句话总结全章**：把整章压缩成一句话——**你不需要知道"自然图像长什么样"的公式，只要有一个会去噪的网络，Tweedie 等式就能把它翻译成得分函数，进而驱动采样——这就是"隐式先验"思想的核心所在。**
