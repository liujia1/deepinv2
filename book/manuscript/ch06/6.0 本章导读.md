# 6.0 本章导读：从"得分不可得"到"得分可学习"

> "我们本来想学会一个密度函数长什么样——结果发现，光学会它的梯度指向哪，就够了。"

先讲一个你大概也遇到过的尴尬：你想认识一个人，却被告知"你不需要记住他长什么样，只要记住他在人群里总是往哪儿走就行"。听起来荒诞？这一章要讲的，正是这样一件反直觉的事——**我们想学的是概率分布本身，但真正够用的，只是它在每一点的"梯度指向"。**

从全书视角看，这一章完成的是一次知识来源的更替。第2章我们承认：先验是结构化知识，但由人手写的先验存在表达能力的天花板。本章将回答一个更根本的问题——**先验能否不从人写、而从数据中习得？** 答案是肯定的，而习得的载体，正是得分函数 $\nabla\log p(x)$。

先给你一个路标，看清我们在全书的方位：

- **上一章（第5章）讲了什么**：我们证明了 Langevin 动力学（一种采样算法）的核心驱动力是**得分函数** $s(x)=\nabla_x\log p(x)$——也就是"对数密度的梯度"；并且通过 Tweedie 等式搭起了一座桥：有一个好的**去噪器**，就能提取出得分函数。
- **本章（第6章）解决什么**：但去噪器从哪来？更根本地——**得分函数怎么从一堆数据里学出来？** 这就是得分匹配（Score Matching）要回答的问题。
- **下一章（第7章）去哪**：学会了得分，下一步就是怎样一步步用它从纯噪声里"长"出图像——那就是扩散模型（连续时间的 SDE 视角）。

---

## 本章目标（你能带走什么）

读完后你应该能：

- 说清楚**为什么直接估密度几乎不可能**（归一化常数算不出），但估它的梯度（得分）却可以绕开它；
- 讲明白**显式得分匹配（ESM）为什么行不通、隐式得分匹配（ISM）为何在高维卡死**；
- 亲自"先猜后验证"地理解**去噪得分匹配（DSM）**：给数据加点噪、训练网络猜"加了什么噪"，这个猜测恰好就是得分；
- 看懂四种方法的谱系（ESM / ISM / DSM / SSM），以及**多尺度**得分匹配为何是扩散模型的前身；
- 跑通一段带重度注释的代码，亲眼看到"去噪器学到的方向 ≈ 真实得分"。

## 一条反直觉的暗线

我们的故事从一个反直觉的观察开场：你本来想学的是"密度 $p(x)$ 到底长什么样"。这件事极难——因为任何合法的密度都要除以一个归一化常数 $Z=\int \tilde p(x)\,dx$，而这个积分在高维里根本算不出来（想想一张 $256\times256$ 的图，维度是六万多，$Z$ 需要在一个六万维空间上积分）。

**先别急着往下看，猜个数**：假设每个维度只需 100 个网格点做数值积分来凑 $Z$。维度 $d=2$ 时要 $10^4$ 个点；那 $d=20$ 呢？……答案是 $10^{40}$ 个。没错，$d=20$ 时就超过了任何计算机的存储极限。而一张图像 $d\approx 6.5\times 10^4$。**所以"把 $Z$ 算出来"这条路，从一开始就不具备可行性。**

但值得注意的是：我们其实**不需要**知道 $p(x)$ 长什么样，只需要知道它的梯度指向哪——也就是得分函数 $\nabla\log p(x)$。因为对数把归一化常数变成了一个加性常数，求导时直接消失：

$$\nabla\log p(x) = \nabla\log\big(Z\cdot \tilde p(x)\big) = \nabla\log \tilde p(x).$$

**$Z$ 被消掉了。** 这一转变意味着，学习分布的障碍从"归一化"转移到了"梯度"——而后者是可以用数据逼近的。只要某种训练方法只依赖得分、不依赖密度本身，归一化常数的障碍就被彻底绕开。这一句话，是本章所有方法的出发点。

## 本章的剧情线：尝试 → 失败 → 突破 → 扩展 → 实践 → 应用

围绕"怎么学得分"，我们走一条真实的探索路径：

- **6.1 为什么需要学习得分？** 先确认痛点：先验得分 $\nabla\log p(x)$ 是 Langevin 的引擎，但对复杂先验既写不出也求不了——好在"得分无需 $Z$"给了我们学它的希望。
- **6.2 显式得分匹配（ESM）与隐式得分匹配（ISM）**：ESM 最直白——让网络直接逼近 $\nabla\log p(x)$——可它需要的"正确答案"恰好是我们要学的，陷入循环依赖。ISM 用分部积分把 $\nabla\log p(x)$ 消去，却换来一个更昂贵的对象：Jacobian 矩阵的迹 $\mathrm{Tr}(\nabla_x s_\theta)$，图像维度下计算上不可承受。
- **6.3 去噪得分匹配（DSM）**：实用突破。给数据加一点噪，条件得分 $\nabla_{\tilde x}\log q_\sigma(\tilde x|x)$ 有闭式解；更妙的是 Vincent (2011) 证明 DSM 与建立在加噪分布上的 ESM 只差一个与参数无关的常数。**训练"去噪器"就是在学得分**——和第5章 Tweedie 遥相呼应。
- **6.4 切片得分匹配（SSM）与 Hutchinson 迹估计**：ISM 的 Jacobian 迹太贵？用随机投影（Hutchinson 估计）把 $O(d^2)$ 降到 $O(M)$。SSM 估的是"原始分布"的得分，和 DSM 互补。
- **6.5 多尺度得分匹配（NCSN）**：单一噪声水平有"低密度区域"的根本缺陷（数据像贴在低维流形上）。用一串噪声水平 $\sigma_1>\cdots>\sigma_L$ 由粗到精，大噪声填满空白、小噪声保留细节。NCSN 是扩散模型的直接前身。
- **6.6 去噪器作为得分估计器：架构实践**：理论要落地——网络用什么结构（DRUNet "一网多噪"），三种参数化（$\varepsilon$/ $s$/ $x_0$ 预测）怎么选，Tweedie 等式怎样现场转换。
- **6.7 用学习到的得分驱动采样**：终章落地。退火 Langevin 用学来的得分生成图像；PnP-ULA 用学来的得分解逆问题。学习先验显著胜过手工先验。

```
得分不可得(6.1) → ESM失败(6.2) → DSM突破(6.3) → SSM替代(6.4) → 多尺度扩展(6.5) → 架构实践(6.6) → 采样应用(6.7)
```

## 收尾一句话

这一章，我们把"得分函数不可得"变成了"得分函数可学习"——而且学到得分就等于训练了一个去噪器（DSM = Tweedie）。从更深层次看，这一步完成的是先验知识来源的更替：不再由人写下正则项 $R(x)$，而是让数据自己交出 $\nabla\log p(x)$。"去噪即学先验梯度"因此成为通向扩散模型的关键一步——这一步跨越，正是第7章扩散模型得以成立的地基：**采样路径，正在向扩散模型演化。**
