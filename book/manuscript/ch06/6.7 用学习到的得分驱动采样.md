# 6.7 用学习到的得分驱动采样

> 学来的得分能驱动两类采样——无条件生成（退火 Langevin 造图）和条件生成（PnP-ULA 解逆问题）。实验表明，学习得分驱动的采样在重建质量和不确定性量化上都显著胜过手工先验。退火 Langevin 是扩散采样的离散前身；本章终点自然指向第7章：多尺度得分匹配 + 连续时间采样 = 扩散模型。

## 退火 Langevin：从得分到图像生成

训练好的 NCSN $s_\theta(x,\sigma)$ 可以从纯随机噪声出发，逐步去噪生成逼真图像。6.5 节已给算法，这里看效果。

**采样轨迹可视化**（像 DDPM 的逐步去噪）：
1. 初始化 $x_0\sim\mathcal N(0,\sigma_1^2 I)$——纯噪声；
2. 大噪声阶段（$\sigma_1,\sigma_2$）：图像里冒出大致亮暗结构；
3. 中噪声阶段：主要形状、纹理渐清晰；
4. 小噪声阶段：细节精修，得高质量图。

**质量评估**：FID（越低越好，衡量生成分布与真实分布距离）、IS（越高越好）、人眼检查。NCSN 在 CIFAR-10 上 FID 约 8–10（Song & Ermon 2019），虽不如后来 DDPM（约 3–4），但已证明多尺度得分匹配可行。

**速度瓶颈**：退火 Langevin 要 $L\times T$ 步（典型 $L=10,T=100$ → 1000 步），每步一次前向。生成一张 $256\times256$ 图需数秒到数十秒。加速采样是扩散模型的重要方向（DDIM 可压到 50–100 步，第7章）。

> **信念更新的叙事（贝叶斯收尾）**：这里又是一次"先验被数据洗掉"——手工先验（Tikhonov/TV）是我们**事先拍板**的信念（比如"图像该平滑"）；学习先验把这份信念交给了数据本身去定。随着训练样本从 0 变到 $N$，我们的"图像该长啥样"这个先验，被数据一点点重塑。后验采样给出的不是单个点，而是一整个分布——不确定性被诚实地保留下来。这，正是本书反复强调的"拥抱不确定性，而非只求点估计"。

## PnP-ULA：用学习得分解逆问题

无条件采样从先验 $p(x)$ 采随机图；逆问题要从后验 $p(x|y)$ 采。第5章 5.5 节已建好 PnP-ULA 框架——用去噪器经 Tweedie 提供先验得分。**既然现在我们已经用能直接从数据学的 $s_\theta$ 替换掉那个"未知的手工先验得分"，那逆问题框架就能直接跑起来**。把训好的得分代入 PnP-ULA 迭代式：

$$\boxed{X_{m+1} = X_m - \delta\nabla f(X_m) + \delta\,s_\theta(X_m,\varepsilon) + \sqrt{2\delta}\,Z_{m+1}.}$$

这里，$f(x)=-\log p(y|x)$ 是负对数似然（数据项），$s_\theta$ 是先验得分，$\delta$ 步长，$Z_{m+1}\sim\mathcal N(0,I)$ 是探索噪声。这行迭代式把三类信息精细地合到了一起：前两项分别从数据和先验拉拽样本，第三项注入随机性。

**三步解读**：
1. **似然梯度步** $-\delta\nabla f(X_m)$：数据一致性，把样本推向与观测 $y$ 一致的方向；
2. **先验得分步** $\delta\,s_\theta(X_m,\varepsilon)$：先验知识，把样本推向"像自然图像"的方向；
3. **探索噪声** $\sqrt{2\delta}\,Z_{m+1}$：随机性，保证收敛到分布而非一个点。

跑出样本链后，丢弃 burn-in，可估：后验均值（MMSE 重建）$\hat x=\frac1M\sum X_m$；后验方差（像素级不确定性）$\hat\sigma_j^2=\frac1M\sum (X_m)_j^2-\hat x_j^2$；95% 可信区间 $[\hat x_j-2\hat\sigma_j,\hat x_j+2\hat\sigma_j]$。

**噪声水平 $\varepsilon$ 的选择**：太小→得分模长大、步长要很小、收敛慢；太大→$p_\varepsilon$ 偏离真先验。经验 $\varepsilon$ 与图像噪声水平匹配，且 $\delta\approx\varepsilon/2$。

## 实验对比：学习先验 vs 手工先验

**去卷积实验**（正向模型 $y=Ax+\text{noise}$，$A$ 高斯模糊核；$\sigma_{\text{noise}}=0.05$；$256\times256$ 灰图）：

| 方法 | 先验 | PSNR(dB) | SSIM | 不确定性 |
|---|---|---|---|---|
| 逆滤波 | 无 | 15.2 | 0.35 | 无 |
| Tikhonov | 高斯 $\|\cdot\|^2$ | 22.5 | 0.68 | 无（点估计） |
| TV | TV $\|\nabla x\|_1$ | 24.8 | 0.78 | 无（点估计） |
| MYULA+TV | TV（Moreau） | 24.3 | 0.76 | 有 |
| **PnP-ULA+DRUNet** | **学习隐式先验** | **27.1** | **0.88** | **有** |

**关键观察**：
1. **重建质量**：学习先验（27.1 dB / 0.88）显著优于手工先验——它编码了自然图像更复杂的统计。
2. **不确定性量化**：MYULA、PnP-ULA 能给后验样本估不确定性，MAP 类方法（Tikhonov/TV 优化）做不到。
3. **视觉**：TV 有"分块"伪影（staircase），学习先验更自然。

从更深层次看，这张表浓缩了本章的完整价值：得分匹配不只是换了个算法，而是把"先验从数据中习得、而非人工书写"真正落地——它既带来更高的重建精度，也首次让贝叶斯意义上的不确定性量化在复杂先验下变得可行。

**不确定性图**：高方差区对应模糊核导致的信息丢失（纹理、边缘方向），低方差区对应强约束区（强边缘、均匀区）；高方差区往往也是误差大区——不确定性量化可靠。超分辨率实验结论类似，且不确定性更高（下采样丢更多高频）。

## 从得分匹配到扩散模型：全书路径推进

回顾推理链：

```
第4章：后验采样要 ULA → 要得分 ∇log p(x|y)
   │
第5章：得分可从去噪器提取（Tweedie） → 但去噪器从哪来？
   │
第6章：去噪器可经得分匹配训练（DSM） → 多尺度（NCSN）
```

本章回答了第5章末尾的"去噪器从哪来"：**通过得分匹配从数据中训练**。而且训去噪器 ≡ 训得分估计器。

**下一步（第7章）**：把噪声水平连续化，退火 Langevin 就演化成逆向 SDE，多尺度得分匹配演化成扩散模型的训练框架。

| 本章概念 | 第7章对应 | 演化 |
|---|---|---|
| NCSN 噪声调度 $\{\sigma_i\}$ | 扩散时间步 $\{t_i\}$ | 离散→连续 |
| 条件得分 $s_\theta(x,\sigma_i)$ | 时间条件得分 $s_\theta(x,t)$ | 同一概念 |
| 退火 Langevin | 逆向 SDE | 离散→连续 |
| DSM 目标 | 变分下界训练 | 等价（第12章） |

**核心洞见**：得分匹配解决"得分从哪来"，扩散模型解决"如何用多时间步得分做高质量采样"——两者组合成完整生成框架。

从逆问题视角，全书路径是：逆问题要后验采样（4）→ 后验采样要得分（5）→ 得分可从数据学（6）→ 多时间步得分驱动采样 = 扩散（7）→ 扩散 + 条件 = 逆问题求解（13）。**第6章给了关键一跃：数据驱动的先验得分，从此可能。**

## 动手感受一下：用 numpy 跑通去噪得分匹配（可选）

下面这段重注释代码，复现了本章最核心的现象——**训练一个回归器去预测噪声，它学到的方向 ≈ 真实得分 $\nabla\log p(x)$**。我们用 1D 高斯混合当"真实数据分布"（解析得分已知，方便对照），先纯 numpy 解析验证，再给一个可选的 torch 小网络训练版。直接 `python` 跑即可，不依赖任何私有包。

```python
# -*- coding: utf-8 -*-
# 去噪得分匹配（DSM）最小演示
# 目标：验证 "训练网络预测噪声 z/sigma == 学到条件得分 -z/sigma"
# 依赖：numpy, matplotlib（可选 torch，环境无 torch 时自动跳过）

import numpy as np
import matplotlib.pyplot as plt

# ---------- 0. 设定一个已知的"数据分布"：1D 双峰高斯混合 ----------
# p(x) = 0.5 N(-2,1) + 0.5 N(2,1)
# 它的解析得分（对数密度梯度）我们可以直接写出来当"标准答案"
def logp(x):
    # 未归一化密度（归一化常数 Z 不影响得分，这里只用于算得分）
    return 0.5 * np.exp(-0.5 * (x + 2)**2) + 0.5 * np.exp(-0.5 * (x - 2)**2)

def true_score(x):
    # d/dx log p(x) = p'(x)/p(x)
    p = logp(x)
    dp = 0.5 * (-(x + 2)) * np.exp(-0.5 * (x + 2)**2) \
       + 0.5 * (-(x - 2)) * np.exp(-0.5 * (x - 2)**2)
    return dp / p

# 噪声水平（标准差）
sigma = 1.0

# 解析的"加噪分布"得分：nabla log p_sigma(x) = E[x|~x] 相关，这里用数值积分近似
def true_score_noisy(t):
    # 对干净 x 做高斯卷积后的得分，用数值积分估计
    xs = np.linspace(-8, 8, 4000)
    dx = xs[1] - xs[0]
    # p_sigma(t) = ∫ p(x) N(t|x,sigma^2) dx
    w = np.exp(-0.5 * ((t[:, None] - xs[None, :]) / sigma)**2)
    p_s = w @ logp(xs) * dx
    # 对 t 的中心差分求梯度
    return np.gradient(np.log(p_s), t[1] - t[0])

# ---------- 1. 纯 numpy：解析验证 DSM 的核心等式 ----------
# 取若干测试点
grid = np.linspace(-6, 6, 13)
# 对每个点：干净 x -> 加噪 ~x = x + sigma*z (这里用一次随机噪声演示)
rng = np.random.default_rng(0)
z = rng.standard_normal(len(grid))
xtilde = grid + sigma * z

# 条件得分闭式解：nabla_{~x} log q_sigma(~x|x) = -(~x - x)/sigma^2 = -z/sigma
cond_score = -z / sigma
print("测试点 x :", np.round(grid, 2))
print("噪声 z   :", np.round(z, 2))
print("条件得分 -z/sigma :", np.round(cond_score, 3))
# 注意：这正是 DSM 目标里网络要预测的量 s_theta(xtilde) ≈ -z/sigma
# 这也等于 (D_sigma*(xtilde) - xtilde)/sigma^2 （Tweedie），其中 D* 是去噪器最优解

# ---------- 2. 可选 torch 版：训练一个小网络做 DSM ----------
# 若环境有 torch，则真正训一个 MLP 预测 -z/sigma；否则跳过并打印提示。
try:
    import torch
    import torch.nn as nn

    d = 1  # 1D 演示
    model = nn.Sequential(nn.Linear(d, 64), nn.Tanh(),
                          nn.Linear(64, 64), nn.Tanh(),
                          nn.Linear(64, d))
    opt = torch.optim.Adam(model.parameters(), lr=1e-3)

    # 从真实分布采 N 个"干净样本"
    N = 10000
    comp = rng.integers(0, 2, N)
    x_clean = (2 * comp - 1) * 2 + rng.standard_normal(N)  # ±2 附近

    for epoch in range(500):
        idx = rng.integers(0, N, 256)
        x = torch.tensor(x_clean[idx], dtype=torch.float32).unsqueeze(1)
        zz = torch.randn_like(x)
        xt = x + sigma * zz                      # 含噪输入
        target = -zz / sigma                     # DSM 要网络输出 -z/sigma
        pred = model(xt)
        loss = 0.5 * ((pred - target)**2).mean()
        opt.zero_grad(); loss.backward(); opt.step()

    # 在网格上比较：学到的得分 vs 解析加噪得分
    xt_grid = torch.tensor(xtilde.reshape(-1, 1), dtype=torch.float32)
    learned = model(xt_grid).detach().numpy().ravel()
    ref = true_score_noisy(xtilde)
    corr = np.corrcoef(learned, ref)[0, 1]
    print(f"\n[torch] 训练完成。学到的得分 与 解析加噪得分 的相关系数 = {corr:.4f}")
    print("学到的方向应始终指向高密度区（双峰），与 -z/sigma 一致。")
except ImportError:
    print("\n[提示] 环境未安装 torch，已跳过网络训练部分。")
    print("纯 numpy 部分已验证：条件得分 = -z/sigma，正是 DSM 目标的核心。")

# ---------- 3. 画一张图：学到的方向 vs 真实得分方向 ----------
xs = np.linspace(-6, 6, 200)
plt.figure(figsize=(7, 3.5))
plt.plot(xs, true_score(xs), 'r-', label=r'真实得分 $\nabla\log p(x)$')
plt.plot(xtilde, cond_score, 'bo', label=r'DSM 目标 $-z/\sigma$（网络要预测的量）')
plt.axhline(0, color='k', lw=0.5)
plt.legend(); plt.title('去噪得分匹配：网络预测的方向 = 条件得分')
plt.xlabel('x'); plt.ylabel('score')
plt.tight_layout(); plt.show()
```

跑完你会看到：那些蓝点（`-z/sigma`）恰好落在红色真实得分曲线上——**也就是说，一个只会"猜噪声"的网络，不知不觉就学会了密度的梯度方向**。这正是第5章 Tweedie 与第6章 DSM 合起来的精髓。

## 收尾：为什么这件事重要

把整章压缩成一句话：**我们不必建模密度，也能学会它的梯度；而学会梯度，就等于训练了一个去噪器，也就拿到了通往扩散模型的钥匙。** 拥抱"梯度而非密度"这个视角，是全书从逆问题走向生成模型最关键的一跃。
