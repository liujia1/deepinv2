# 术语索引

符号总表管"记号长什么样"，这份索引管"概念在哪儿"。全书十八章共用一套词汇——"先验"在第 2 章是正则化，在第 5 章是去噪器，在第 7 章是得分函数，在第 13 章是引导项；同一个词沿主线换了四次外衣，正是本书要读者看见的那条等价链。索引的作用，就是在这条链上标出每个概念第一次被**定义**、以及后来被**重新解释**的位置。

用法有三：**查找**（想起一个词、忘了在哪节，按章序或英文速查定位）、**回溯**（读到后文某个术语，回到主条目看它的原始定义与假设）、**串联**（同一概念的"相关"列把散落在各章的解释串起来，读的时候可以按列跳读）。表中"主条目"列给出该概念被系统定义或推导的那一节；"相关"列给出必要的后续深化或不同语境下的再解释，不追求穷举。表中每一个节号都已逐条校对：该节存在，且该节确实讲到这个词。

收录范围是**概念与方法**：度量、先验族、算法、模型、数学工具。人名、实验编号、单一公式名不单独立条（如"Wang 等（2004）"、"实验 1.a-1"）；软件包只在承载书中自有方法的场合立条（如 deepinv 的 Physics 类）。

## 三、容易混淆的几对术语

| 对比 | 区别要点 | 辨析处 |
|---|---|---|
| MAP vs MMSE | 前者是后验众数（"最可能"），后者是后验均值（"平均意义上最省"）；高维下众数不在典型集合内，这正是第 3 章末尾分叉的由来 | 2.3 节、5.4 节 |
| 显式先验 vs 隐式先验 | 前者能写出 $p(\mathbf{x})$ 或能量函数，后者只以算子（去噪器、生成器）的形式存在，无法求值密度 | 2.4 节 |
| ESM vs ISM vs DSM | 三者只差"目标函数里出现的是哪个密度"：ESM 用真实得分、ISM 用分布积分、DSM 用加噪条件得分——DSM 能用是因为 Tweedie 等式 | 6.2 节、6.3 节 |
| 得分函数 vs 去噪器 | 同一对象的两种表述：去噪器给的是条件均值，得分是它的线性变换；Tweedie 等式是两者之间的桥 | 5.3 节、6.6 节 |
| VE-SDE vs VP-SDE | 前者只放大噪声、信号不衰减；后者在加噪同时压缩信号，故训练目标与数值尺度不同；两者经系数变换可互相翻译 | 7.2 节、附录7B |
| 零强迫 vs 零避免 | 逆向 KL 会"抢占"一个众数（zero-forcing），前向 KL 会"铺满"整个支撑（zero-avoiding）；这解释了 VAE 生成偏模糊 | 8.3 节、附录8C |
| 摊推断 vs 逐例优化 | 前者训练一个网络一次摊销所有样本，后者对每个观测单独优化隐变量；精度与成本互换 | 8.5 节、13.3 节 |
| 测量一致性 vs 数据一致性 | 本书统一写"测量一致性"，指重建结果经前向算子后与观测吻合；文献中的 data consistency 常与之混用 | 16.4 节、17.6 节 |
