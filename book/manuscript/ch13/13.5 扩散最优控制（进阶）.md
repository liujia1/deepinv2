# 13.5 扩散最优控制（进阶）

> 你有没有这种感觉：DPS 每步都"凭当下信息仓促决策"——拿当前这一步的 Tweedie 估计算个似然梯度，往轨迹里一塞就完事。它从不考虑"这一步的修正会不会把后面带沟里"。这种只看眼前的策略，控制论里叫"贪心"。这一节我们把条件扩散采样当成最优控制问题，看看"全局最优"长什么样，以及它为什么在真实图像问题的少步采样时能明显改善DPS（注：这一优势在玩具场景中未必复现，见本节实验的诚实检验）。

> **定位说明**：本节为进阶内容，对理解全书主叙事线非必需。读者可跳过本节而不影响对13.6节闭环叙事的理解。如需深研条件扩散采样最优控制理论，可在此处或附录找到完整讨论。

## 控制论视角：逆向扩散 = 受控动力学系统

### 逆向扩散过程的控制论表述

第7章建立的逆向 SDE 可视为一个动力学系统：

$$dx = \left[f(\mathbf{x},t) - g(t)^2\,\nabla_\mathbf{x}\log p_t(\mathbf{x})\right]dt + g(t)\,d\bar{w}$$

无条件逆向 SDE 从纯噪声 $x_T$ 出发，在得分函数驱动下回到数据分布。现在把这系统看作**受控动力学系统**——每步注入控制向量 $u_t$：

$$\boxed{\mathbf{x}_{t-\Delta t} = \mathbf{x}_t - \left[f(\mathbf{x}_t, t) - \frac{1}{2}g(t)^2\,\nabla_\mathbf{x}\log p_t(\mathbf{x}_t)\right]\Delta t + u_t + g(t)\sqrt{\Delta t}\,\varepsilon}$$

$\varepsilon \sim \mathcal{N}(0, I)$ 是随机噪声项，$u_t$ 是待设计控制输入。当 $u_t = 0$，退化为无条件采样；当 $u_t$ 编码观测约束，采样轨迹被引向与观测 $\mathbf{y}$ 一致方向。把这个式子逐项看：括号里是原有的无条件采样动力学——由正向过程 $f$ 和得分 $\nabla \log p_t(\mathbf{x})$ 决定；$u_t$ 是我们在每一步额外允许注入的"操纵杆"。这一转变意味着，条件采样从"改公式里的得分"变成了"在每一步叠加一个控制信号"，前者受结构约束，后者更自由。

### 控制目标的设定

最优控制核心问题：**怎么选控制序列 $\lbrace u_t\rbrace_{t=T}^{0}$，使生成的样本 $\mathbf{x}_0$ 既符合先验又与观测 $\mathbf{y}$ 一致？**

形式化为优化问题——最小化代价函数：

$$J(\{u_t\}) = \sum_{t=1}^{T} l_t(\mathbf{x}_t, u_t) + l_0(\mathbf{x}_0)$$

其中：
- $l_0(\mathbf{x}_0) = -\log p(\mathbf{y}\mid \mathbf{x}_0)$ 是**终端代价**（terminal cost），衡量生成结果与观测一致性——$\mathbf{x}_0$ 与 $\mathbf{y}$ 越不一致代价越高
- $l_t(\mathbf{x}_t, u_t)$ 是**运行代价**（running cost），衡量控制输入代价——$u_t$ 越大偏离先验越远

对条件扩散采样，我们希望控制信号仅在必要时修正轨迹，不额外惩罚控制量本身。因此设**运行代价为零**：

$$l_t(\mathbf{x}_t, u_t) = 0, \quad t = 1, \ldots, T$$

代价函数简化：

$$\boxed{J(\{u_t\}) = l_0(\mathbf{x}_0) = -\log p(\mathbf{y}|\mathbf{x}_0)}$$

讲清楚这个简化在说什么：代价函数里唯一剩下的 $-\log p(\mathbf{y}\mid \mathbf{x}_0)$ 就是"最终结果离观测有多远"——$\mathbf{x}_0$ 与 $\mathbf{y}$ 越一致，这一项越小。没有运行代价意味着我们允许控制信号"免费"使用，不对控制量本身加以惩罚。

**最优控制问题**：选控制序列 $\lbrace u_t\rbrace$，使终端代价 $-\log p(\mathbf{y}\mid \mathbf{x}_0)$ 最小，即生成结果 $\mathbf{x}_0$ 与观测 $\mathbf{y}$ 对数似然最大。

物理直觉清晰：我们允许逆向采样每步自由注入控制信号（不惩控制量），唯一约束是最终生成结果须与观测一致。运行代价为零设定使控制信号可"免费"用——只要最终结果好，过程怎么修正都行。

## DOC 的形式化与求解

### iLQR 算法与简化的 Riccati 方程

上述最优控制问题可用迭代线性二次调节器（iLQR）求解。iLQR 是经典最优控制在非线性动力学系统上的推广——在当前轨迹附近线性化动力学，迭代解二次近似子问题。

标准 iLQR 求解涉及 Riccati 方程——需递归算代价函数关于状态二阶导数（Hessian）和关于控制一阶导数（梯度）。但 DOC 特殊设定下，**运行代价 $l_t = 0$ 带来显著简化**：
1. **二阶项消失**：因 $l_t(x_t, u_t) = 0$，代价 Hessian 仅来自终端代价 $l_0(\mathbf{x}_0)$ 反向传播。中间步二阶项全零，Riccati 递推大幅简化
2. **计算量降**：标准 iLQR 需维护 $\mathcal{O}(n^{2})$ 的 Riccati 矩阵（$n$ 状态维度），DOC 只需维护从终端代价反传的梯度向量——复杂度从 $\mathcal{O}(Tn^{2})$ 降至 $\mathcal{O}(Tn)$

### 最优控制的结构

经 iLQR 求解，最优控制具如下结构：

**定理**（DOC最优控制，Li & Pereira 2024）：在确定性采样器（PF-ODE）下，最优控制为：

$$\boxed{u_t^* = \alpha \cdot \nabla_{\mathbf{x}_t}\log p(\mathbf{y}|\mathbf{x}_0)}$$

$\alpha$ 是与采样器步长相关的缩放因子，$\nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_0)$ 是终端似然关于当前状态 $\mathbf{x}_t$ 的梯度，通过**沿整个采样轨迹的反向传播**计算。

把这个定理拆开读：最优控制方向不是"当前时刻的似然得分 $\nabla \log p(\mathbf{y}\mid \mathbf{x}_t)$"，而是"终端条件 $p(\mathbf{y}\mid \mathbf{x}_0)$ 对当前状态 $\mathbf{x}_t$ 的梯度"。换句话说，它问的不是"这一步离观测多近"，而是"这一步的微小变动会如何影响最终结果与观测的一致性"。这正是全局优化的精髓——每一步的修正都指向最终目标，而不是眼前一步。

这结果揭示 DOC 核心特征：**最优控制方向是终端似然梯度 $\nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_0)$，而非当前时刻似然梯度 $\nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_t)$**。

### 与精确后验采样的联系

一个重要理论结果：**在确定性采样器（PF-ODE）下，$\alpha = 1$ 的最优控制精确恢复后验采样方程。**

**引理**：设PF-ODE为 $dx = [f(\mathbf{x},t) - g(t)^{2}\nabla \log p_t(\mathbf{x})]dt$，注入最优控制 $u_t^{*} = \nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_0)$ 后，受控PF-ODE等价于从条件分布 $p(\mathbf{x}\mid \mathbf{y})$ 采样的概率流ODE。

引理含义：若能精确算 $\nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_0)$（终端似然关于当前状态梯度），DOC 受控轨迹与从真实后验 $p(\mathbf{x}\mid \mathbf{y})$ 采样轨迹完全一致——无近似误差。

当然，$\nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_0)$ 实践无法精确算（依赖整条轨迹未来状态），需反向传播近似。但理论结果给 DOC **渐近精确性保证**：随近似精度提升，DOC 采样结果收敛于真实后验。

> **读法提醒（这条最容易被误读）**：定理说的是“把控制律取成 $u_t^{*} = \alpha \nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_0)$”时轨迹等于后验采样轨迹——它描述的是**最优控制律**本身。而工程上“用 Adam 直接最小化终端代价 $J = -\log p(\mathbf{y}\mid \mathbf{x}_0) + \lambda \sum u_t^{2}$”求出来的是**使残差最小的一组控制**，它不是 $u_t^{*}$，而是 $u_t^{*}$ 的一个极端取值：残差为零的极大似然点。两者不是同一件事：前者把先验的回传作用保留在 PF-ODE 漂移里，后者把“让 $\mathbf{y}$ 被拟合”当成了唯一目标。本实验步骤 4b 的 T=200 对照就是这个区别的直接证据——优化收敛后 DOC 落到 $y/A$，而不是“漂浮在 $y/A$ 两侧的后验样本”。所以下文说“DOC 渐近精确”必须配上限定：“精确”指控制律形式，不指“任意数值优化的解”。

## DOC 与 DPS 的关系

### DPS 是 DOC 的贪心近似

DPS 与 DOC 核心差异在**优化范围**：

| 维度 | DPS | DOC |
|---|---|---|
| 优化范围 | 局部（每步贪心） | 全局（整条轨迹） |
| 似然梯度计算 | $\nabla \log p(\mathbf{y}\mid \mathbf{x}_t) \approx \nabla \log p(\mathbf{y}\mid \hat{x}_{0\mid t})$ | $\nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_0)$ 通过反传 |
| Tweedie近似 | 需要 | 不需要 |
| 计算代价 | 低（单步前向+反传） | 高（全轨迹反传） |
| 理论保证 | 贪心最优 | 全局最优（渐近精确） |

**DPS 贪心策略**：第 $t$ 步仅据当前状态 $\mathbf{x}_t$ 决策——用 Tweedie 估计 $\hat{x}_{0\mid t}$ 近似 $\mathbf{x}_0$，算 $\nabla \log p(\mathbf{y}\mid \hat{x}_{0\mid t})$ 作似然梯度近似，注入当前步采样。它不考虑这步决策如何影响后续步采样质量。

**DOC 全局策略**：DOC 优化整个控制序列 $\lbrace u_t\rbrace_{t=T}^{0}$，通过沿完整轨迹反向传播算每 $u_t$ 对终端代价 $l_0(\mathbf{x}_0) = -\log p(\mathbf{y}\mid \mathbf{x}_0)$ 影响。每步控制信号都考虑"这步修正如何影响最终重建质量"——这是全局优化核心优势。

### Tweedie 近似 vs 精确反传

DPS 与 DOC 技术差异集中在似然梯度计算：

**DPS**：$\nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_t) \approx \nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \hat{x}_{0\mid t})$

这近似把不可解 $p(\mathbf{y}\mid \mathbf{x}_t) = \int p(\mathbf{y}\mid \mathbf{x}_0)p(\mathbf{x}_0\mid \mathbf{x}_t)dx_0$ 替成 $p(\mathbf{y}\mid \hat{x}_{0\mid t})$——用单点估计替代整个积分。这是 Tweedie 近似本质，也是 DPS 误差主要来源。高噪声阶段 $\hat{x}_{0\mid t}$ 与真 $\mathbf{x}_0$ 偏差大，近似误差显著。

**DOC**：$u_t^{*} = \alpha \cdot \nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_0)$

DOC 直接算终端似然 $p(\mathbf{y}\mid \mathbf{x}_0)$ 关于当前状态 $\mathbf{x}_t$ 的梯度——**不需 Tweedie 近似**。这梯度经沿整条采样轨迹反向传播获得：从终端代价 $-\log p(\mathbf{y}\mid \mathbf{x}_0)$ 起，沿时间轴反传每步 $\mathbf{x}_t$，得精确梯度方向。反向传播自然考虑"从 $\mathbf{x}_t$ 到 $\mathbf{x}_0$ 完整映射"——比 Tweedie 单点估计更准。

### DOC 的鲁棒性优势

DOC 全局优化策略带来显著鲁棒性优势：

**少步采样下优势**：DPS 在少步采样（如 $T=50$）表现退化——每步 Tweedie 近似误差累积，贪心策略无法协调相邻步修正方向。DOC 通过全局优化，即使步数很少也能找合理控制序列——因每步控制信号都考虑对最终结果影响。

**弱得分网络下优势**：当预训练得分网络质量差，DPS 先验得分不准，贪心策略易把轨迹推错方向。DOC 全局优化可通过调控制序列补偿先验得分误差——终端代价 $-\log p(\mathbf{y}\mid \mathbf{x}_0)$ 提供独立、不依赖先验得分质量的目标信号。

### 实验对比

@li2024doc 在 FFHQ 256×256 数据集实验验证 DOC 优势：
- **DOC with $T=50$ 在多项逆问题（超分辨、修复、去模糊）重建质量优于 DPS with $T=1000$**——少20倍采样步数却更好结果
- DOC 在低噪声场景优势更显——因终端代价 $-\log p(\mathbf{y}\mid \mathbf{x}_0)$ 梯度信号在高信噪比时更清晰
- DPS 在高噪声场景仍有竞争力——因先验得分权重较高，DPS 贪心策略偏差较小

### 实践考虑：随机低秩近似

DOC 主要计算瓶颈在反向传播中 Jacobian 矩阵计算——$\nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_0)$ 需算终端似然关于每步状态梯度，涉及得分网络 $\varepsilon_\theta(\mathbf{x}_t, t)$ 的 Jacobian 矩阵，维度 $n\times n$（$n$ 图像像素数），直接计算不可行。

@li2024doc 提出用**随机低秩近似**（randomized low-rank approximation）替精确 Jacobian：
1. 用随机投影矩阵 $P \in \mathbb{R}^{k\times n}$（$k \ll n$）把 Jacobian 投到低维空间
2. 低维空间算 Jacobian-向量乘积
3. 实验表明，**秩 $k=1$ 即可获良好近似**——因最优控制 $u_t^{*}$ 通常集中在少数方向

这近似使 DOC 计算代价降到与 DPS 可比，同时保留全局优化核心优势。

## 本节小结

从控制论视角审视条件扩散采样，DPS 与 DOC 对比揭示一般原则：

$$\text{贪心策略（DPS）} \xrightarrow{\text{全局优化}} \text{最优控制（DOC）}$$

DPS 每步做局部最优决策——快、简单，但少步采样或弱先验下可能失效。DOC 通过全局优化控制序列获更严格理论保证——渐近精确、鲁棒，但计算代价更高。两者非替代，而是精度-效率权衡两端。

控制论视角更深层意义：它把条件扩散采样从"采样算法"提升为"优化问题"——可借控制论丰富工具（iLQR、模型预测控制、鲁棒控制等）设计分析条件采样策略。这视角潜力远未被充分挖掘。

一个优雅理论副产品：**所需条件得分函数直接作为价值函数（value function）的雅可比出现**——最优控制价值函数 $V(\mathbf{x}_t,t)$ 对其状态 $\mathbf{x}_t$ 梯度 $\nabla_{\mathbf{x}_t}V$ 恰给出引导采样所需得分。从更深层次看，这从控制论视角重释第5~6章得分函数：它既是数据分布得分 $\nabla_{\mathbf{x}_t}\log p_t(\mathbf{x}_t)$，也是最优控制问题"价值梯度"。DOC 因此把"得分"与"最优性条件"统一。

从后验得分分解到引导采样再到最优控制，第13章逐步建立"条件扩散采样 = 逆问题求解"完整理论。现在回到全书起点——第1章逆问题 $\mathbf{y} = Ax + \varepsilon$，审视这段从贝叶斯到扩散的理论旅程，验证全书核心论点最终闭环。

> **本节主要参考**：Li & Pereira, *Solving Inverse Problems via Diffusion Optimal Control*, NeurIPS 2024；Chung et al. (2023) 第 3.2 节（DPS）。

## 实验13.5-1 扩散最优控制（DOC）

> **对应知识点**：13.5节扩散最优控制（进阶）——控制论视角、DOC全局最优 vs DPS贪心对比、计算代价分析
>
> **实验目的**：从控制论视角理解条件扩散采样，在1D简化基准上**检验**DOC全局最优控制相对DPS贪心策略的理论优势主张，分析两种方法计算代价差异
>
> **实验设计**：1D高斯混合先验 + VP-SDE框架（简化版，T=20步），DOC实现梯度优化控制序列，DPS实现标准得分修正的贪心策略
>
> **运行前提**：CPU/GPU 均可运行（50 次配对试验 + 300 步 Adam，CPU 约 30 分钟，GPU 约 3–5 分钟）。步数可用环境变量 `DEEPINV_DOC_T` 切换（默认 20；T=200 补充对照见步骤 4b），设备可用 `DEEPINV_DEVICE` 指定（`cpu`/`cuda`），试验次数可用 `DEEPINV_DOC_NTRIALS` 覆盖；补充对照写独立断点文件与独立图，不覆盖主实验结果

### 场景描述

本实验在简化1D高斯混合场景下，对比DOC全局最优控制与DPS贪心策略在条件采样中表现，检验13.5节的理论主张：

$$\text{贪心策略（DPS）} \xrightarrow{\text{全局优化}} \text{最优控制（DOC）}$$

**实验设置**：
- **先验分布**：1D高斯混合 $p(\mathbf{x}) = 0.5\mathcal{N}(-2, 0.5^{2}) + 0.5\mathcal{N}(2, 0.5^{2})$，得分函数用VP-SDE边际的解析式 $p(\mathbf{x}_t) = \sum_{i} w_{i} \mathcal{N}(\mathbf{x}_t; \sqrt{\bar\alpha_t} \mu_{i}, \bar\alpha_t \sigma_{i}^{2} + 1-\bar\alpha_t)$（与采样离散化、Tweedie公式同一约定）
- **观测模型**：$\mathbf{y} = Ax + \varepsilon$，$A = 2$，$\varepsilon \sim \mathcal{N}(0, 0.1^{2})$；每次试验从先验抽 $x^{*}$ 再生成对应观测 $y = 2x^{*} + \varepsilon$
- **扩散框架**：VP-SDE，时间步数 $T = 20$（简化版，便于可视化）；初始点 $x_T \sim \mathcal{N}(0, 1)$（与 \\bar\\alpha_T≈0.01 的末端边际匹配）
- **目标**：采样满足观测约束的后验样本 $\mathbf{x}_0 \sim p(\mathbf{x}\mid \mathbf{y})$，以终端误差 $| x_0 - x^{*}|$ 衡量

**DOC实现要点**：
- 终端代价 $J = -\log p(\mathbf{y}\mid \mathbf{x}_0) = (\mathbf{y}-Ax_0)^{2}/2\sigma^{2}$，叠加控制幅度正则 $\lambda \sum u_t^{2}$（$\lambda =0.1$）
- 在**确定性 PF-ODE 轨迹**上反向传播（BPTT），Adam 优化控制序列 $\lbrace u_t\rbrace$（300步，lr=0.01）；优化与评估使用同一动力学
- **单步控制饱和**：$u_t = U_{\mathrm{MAX}}\cdot \tanh(raw_u_t)$，$U_{\mathrm{MAX}}=0.5$。原因：本实验的离散 DDPM 调度在末步有 $\beta_0=0, \alpha_0=1$，无约束控制可一步把 $x_0$ 设成 $y/A$，使“全局轨迹优化”退化为“末步数据一致点投影”（修复前实测 DOC 误差与 y/A 误差在 1e-6 内相等）。饱和后控制必须在前面的步中分配

**DPS实现要点**：
- 贪心策略：每步用Tweedie估计 $\hat{x}_{0\mid t}$ 近似似然梯度
- 标准得分修正形式：$u_t = \beta_t \cdot \zeta \cdot \nabla_{\mathbf{x}_t} \log p(\mathbf{y}\mid \hat{x}_{0\mid t})$，$\zeta = 0.02$（与逆向SDE的 $g^{2}=\beta_t$ 同尺度；$\sigma_{\mathrm{obs}}=0.1$ 时梯度量级大，实测 $\zeta \ge 0.03$ 即出现发散试验，属少步大步长下的离散化脆性）

### 实验步骤

#### 步骤1：先验、得分函数与观测设置

**场景**：建立1D高斯混合先验与解析VP边际得分，设置线性观测。本步骤为设置与自检，代码不单独出图；先验的双峰结构体现在步骤4图(a)的轨迹收敛目标上。

**输入**：高斯混合参数 $[\mu_1, \mu_2] = [-2, 2]$，$[\sigma_1, \sigma_2] = [0.5, 0.5]$，观测算子 $A = 2$，噪声 $\sigma = 0.1$

**预期结果**：后验集中在与 $y/A$ 相符的左/右模态附近；终端误差的理论下限由后验不确定度决定（解析MMSE基线：平均误差 0.0364，后验std均值 0.0498）。

**实际效果**：

50次试验中样本均收敛至与 $y/A$ 同侧模态附近，与解析后验位置一致。DOC 平均误差 0.0373（MMSE 基线 0.0364，仅高 0.0009）；DPS 0.0426（高 0.0062）。两者都接近但未严格达到 MMSE 下界——DOC 的目标是终端代价而非 MMSE，DPS 则受后验采样噪声影响。

#### 步骤2：DOC全局最优控制——轨迹优化

**场景**：实现DOC全局优化控制序列，把采样当作可微分优化问题求解。

**核心公式**（13.5节）：

$$u_t^* = \alpha \cdot \nabla_{\mathbf{x}_t}\log p(\mathbf{y}|\mathbf{x}_0)$$

**实现要点**：
1. 从 $x_T \sim \mathcal{N}(0,1)$ 出发，沿无引导 PF-ODE 确定性 rollout 生成初始轨迹 $\lbrace x_T, \dots, x_0\rbrace$
2. 从终端代价 $-\log p(\mathbf{y}\mid \mathbf{x}_0)$ 反向传播（BPTT 穿过整条轨迹），算每步控制 $u_t$ 的梯度
3. Adam 优化控制序列，目标 = 终端代价 + 0.1·控制正则；每步控制经 $U_{\mathrm{MAX}}\cdot \tanh(\cdot)$ 饱和

**预期结果**：终端代价 $-\log p(\mathbf{y}\mid \mathbf{x}_0)$ 随优化迭代下降，最终收敛低值。

**实际效果**：

末次试验终端代价从约 233 降到 $6.5\times 10^{-5}$（见步骤4图(d)；299 个迭代间隔里有 92 个出现 $\le 5\times 10^{-4}$ 的细微回升，由 Adam 动量引起，宏观上单调），控制序列把轨迹从 $x_T\approx -0.155$ 引到 $x_0\approx -2.507$（$y/A=-2.508$，真实信号 $x^{*}=-2.531$）。控制输入呈“**末端最大、向高噪声端单调衰减**”的形态：末端两步 raw 约 $-0.370$（经 $U_{\mathrm{MAX}}\cdot\tanh$ 实际施加 $-0.177$，上限 0.5，**并未饱和**）、第 3 步 $-0.363$、第 4 步 $-0.279$、第 5 步 $-0.194$，此后稳定在 $-0.16\sim-0.14$，高噪声端 $-0.138$（施加 $-0.068$）。**幅度朝末端递增**这一点与一阶条件 $u_t^{*}\propto \partial x_0/\partial u_t$ 方向一致：实测终端增益 $G_0=0.44$、$G_{10}=0.099$、$G_{19}=0.046$（单调递减，末端是高噪声端的 9.5 倍），所以同样大的控制放在末端对 $x_0$ 的作用最强；但实测的振幅比 $\lvert u_0\rvert/\lvert u_{19}\rvert=2.7$ 远小于增益比 9.5——$\lambda=0.1$ 的控制正则把幅度差异压平了，两者只保证**方向**一致，不能把 2.7 读成增益的直接测量。从轨迹看，倒数第 2 步的 $-2.057$ 到终点的 $-2.507$ 共走 0.45，其中约 $-0.35$ 直接来自末端两步的控制，其余来自得分驱动漂移；高噪声段那串近常数控制提供的是稳定的整体位移。由于优化与评估同为确定性 PF-ODE，终端代价整体单调下降（早期版本“随机前向重采样导致抖动”的描述已不适用）。

#### 步骤3：DPS贪心策略——单步优化对比

**场景**：实现标准形式的DPS贪心策略，每步独立决策，与全局最优控制对比。

**核心公式**（13.5节）：

$$\nabla_{\mathbf{x}_t}\log p(\mathbf{y}|\mathbf{x}_t) \approx \nabla_{\mathbf{x}_t}\log p(\mathbf{y}|\hat{x}_{0|t})$$

**实现要点**：
1. 每步用Tweedie估计 $\hat{x}_{0\mid t}$ 近似最终结果
2. 得分修正 $u_t = \beta_t \cdot \zeta \cdot \nabla_{\mathbf{x}_t} \log p(\mathbf{y}\mid \hat{x}_{0\mid t})$，$\zeta =0.02$
3. 不考虑该步决策对后续步影响

**预期结果**（来自13.5节理论叙事）：DPS贪心策略在少步采样（$T = 20$）下性能退化——Tweedie近似误差累积。

**实际效果**：

本设定下 DOC 平均误差 0.0373±0.0258（n=50），DPS 0.0426±0.0295；DOC 相对改进 12.54%，胜出 31/50。注意：修复前（无控制饱和）DOC 会退化为 y/A 投影，误差与 y/A 的 0.0363 在 1e-6 内相等，看似“DOC 更优”，实为末步无约束控制的一步投影，不能作为全局优化的证据。修复后 DOC 仍优于 DPS（12.5%），但逐 trial 配对只有边缘显著（$p=0.065$）；本场景得分解析精确、观测线性，Tweedie 近似误差本就很小，DOC 的增益主要来自“终端代价直接优化”而非“全局协调”。

**输入参数**：

**核心洞察**（对13.5节理论的诚实检验）：
1. **末步控制退化是本实验最大的坑**：离散 DDPM 调度在末步有 $\beta_0=0, \alpha_0=1$，无约束控制可一步把 $x_0$ 设成 $y/A$；修复前 DOC 误差 0.0363 与 $y/A$ 的 0.0363 在 $10^{-6}$ 内相等，“全局优化”名存实亡。修复（$u_t=U_{\mathrm{MAX}}\cdot \tanh(raw)$）后 DOC 0.0373、$y/A$ 0.0363（比值 1.025），二者不再重合，实验才真正比较了“全局轨迹控制 vs 贪心引导”。
2. **本基准下 DOC 与 DPS 的终端误差只能算“边缘可分”**：均值上 DOC 低 12.54%，逐试验配对求差 $+0.0053 \pm 0.0028$（SE，$t=1.89$、$p=0.065$，双侧配对 t 检验），DOC 在 31/50 次胜出。得分解析精确、观测线性，Tweedie 近似误差很小，DPS 本身已接近最优；而 DPS 的标准差（0.0295）明显大于 DOC（0.0258），说明它的损失主要由少数过冲试验承担。$p=0.065$ 只是边缘显著，不能据此断言 DOC 在一般场景优于 DPS。
3. **DOC 的真实价值在框架而非本基准胜出**：把采样转为优化问题后，终端代价可任意定制、可借 iLQR/随机低秩等控制论工具（Li & Pereira 2024 在真实图像、弱得分网络、少步采样条件下报告 DOC 显著优于 DPS）；本实验复现不了那些前提，故应把结果读作“工具演示”而非“优势验证”。
4. **12.5% 这个数只能当点估计用**：配对差 $0.0053$ 的标准误是 $0.0028$，$p=0.065$ 属边缘显著，31/50 胜出也不是压倒性。这个百分比对优化收敛程度和随机流都不稳定：本实验定稿前那一版（checkpoint 由中间状态续跑、控制序列停在未完全收敛处）报出的相对改进是 4.5%。讲义若要把“DOC 更准”写进结论，必须同时给配对差、SE、胜出比例与 $p$ 值，并限定它只在“观测信息充分”的设定下成立。

#### ★ 步骤4b：把步数加密到 T=200——两种方法各自变在哪里

**为什么要补这一档**：本实验主参 $T=20$ 是离散化最脆的设置（每步 $\beta \approx 0.215$）。原文曾据此写下一句“T=200 对照中 DPS 误差（$\zeta =0.3\to 0.075$、$\zeta =0.5\to 0.063$）仍优于 DOC（0.425，固定 300 迭代对 200 维控制序列欠收敛）”，并由此断言“DOC 自身反而随 T 增大而退化”。复核发现那两个数字属旧版脚本（控制未加 $\tanh$ 饱和、末步可一步投影到 $y/A$）的残留，与当前版本记录不一致，故按当前代码补跑。结论要改，而且改得比原文更有意思。

**参数对照**：

| 项目 | T=20（主实验） | T=200（补充对照） |
|------|---------------|------------------|
| 试验次数 | 50 | 20 |
| 每步 $\beta_t$ | $\approx 0.215$（少步大步长） | $\approx 0.0215$（细步长） |
| DPS 主报 $\zeta$ | 0.02 | 0.3（按“$\zeta \propto T$ 等强度”外推选值，实测已越界） |
| $\zeta$ 扫描 | 0.01 / 0.02 / 0.025 / 0.03 | 0.1 / 0.15 / 0.2 / 0.3 / 0.5 |
| 断点文件 | `experiment_checkpoint_v3.pkl` | `experiment_checkpoint_T200.pkl` |
| 计算设备 | cpu | cpu |
| 图 | `DOC vs DPS对比.png` | `DOC vs DPS对比_T200.png` |

**第一条：两个 $T$ 的试验样本不能混着比，只能比“相对 $y/A$ 的倍数”**。每个 trial 消耗的噪声个数随 $T$ 变（$x_T$ 与 DPS 每步的噪声都要抽），所以两个 $T$ 的随机流在 trial 中途就分叉——重跑后两个 checkpoint 之间**没有可配对的 $x^{*}$**。更麻烦的是“平凡基线”自己也在动：$y/A$ 数据一致点在 T=20 全样本上是 0.0363、在 T=200 上是 0.0429（同一个解析量，差异只来自抽到的 $x^{*}$ 与噪声）。**所以跨 $T$ 直接比绝对误差是错的**，下表一律按“相对 $y/A$ 的倍数”读：

| 量 | T=20（n=50） | T=200（n=20） |
|----|------|-------|
| 数据一致点 $y/A$ | 0.036345 | 0.042860 |
| 精确后验均值（MMSE） | 0.036423 | 0.042200 |
| DOC | 0.037271（$1.025\times$） | **0.042859（$1.000\times$）** |
| DPS 最优 $\zeta$ | 0.042615（$\zeta=0.02$，$1.173\times$） | 0.048927（$\zeta=0.15$，$1.142\times$） |
| DOC 与 $y/A$ 的偏离（中位 / 最大） | $3.1\times 10^{-4}$ / $1.75\times 10^{-2}$ | $8.5\times 10^{-5}$ / $2.2\times 10^{-4}$ |
| DOC 落在 $y/A$ 的 $10^{-3}$ 内 | 41/50 | **20/20** |

读法：DOC 在 T=200 的落点与 $y/A$ 差不到 $3\times 10^{-4}$（20/20 落进 $10^{-3}$），在 T=20 只是“靠近”（41/50；中位偏离 $3\times 10^{-4}$ 但最大到 $1.8\times 10^{-2}$，个别 trial 的控制预算不够把它拉到底）；DPS 即使取最有利的 $\zeta$，也比数据一致点差 14%~17%。**注意这里没有跨 $T$ 的配对检验可做**——两个 $T$ 用的是不同的 $x^{*}$ 样本，跨 $T$ 的差异里混着抽样波动，不能报到显著性上；“谁更准”的显著性只能在单个 $T$ 内部逐 trial 配对做（见步骤 4 核心洞察 2）。下面几条机制结论都以这张“倍数表”为口径。

**第二条：DOC 在 T=200 收敛到 $y/A$，这是确定性控制该做的事，不是“退化”**。逐 trial 看，DOC 的终端值落在 $y/A$ 的 $10^{-3}$ 内，20/20，最大偏离 $2.2\times 10^{-4}$；图 (d) 里终端代价被压到 $10^{-6}$ 量级，$x_0$ 从 1.89 收敛到 1.565 ≈ $y/A$（途中先冲到 2.16、再摆到 $-1.82$，那是 Adam 对 200 维控制的初期过冲，不是采样噪声）。原因是结构性的：DOC 的终端代价只含测量残差 $\lVert \mathbf{y} - A\mathbf{x}_0\rVert^{2}$（外加控制正则 $\lambda \sum u_t^{2}$），它是确定性 PF-ODE 上的**单点估计**，目标函数里根本没有“多样性”这一项。$T$ 越细，控制自由度越多、总控制预算 $T\cdot U_{\mathrm{MAX}}$ 越大，它把这一个标量残差压得越干净，落点就越贴近 $y/A$。

机制上看清一点很重要：图 (b) 显示 T=200 时每步控制 $\lvert raw_u\rvert \le 0.064$（经 $\tanh$ 后施加量 $\le 0.032$），全程离 $U_{\mathrm{MAX}}=0.5$ 的饱和线很远——**T=20 那次“末步一步投影”的坑不会在 T=200 重现**，因为同样的每步上限在 200 步上累积出的总权限放大了约 10 倍。换句话说，$U_{\mathrm{MAX}}$ 是“每步”的帽子，真正决定 DOC 能不能一步投影到 $y/A$ 的是**总预算**；原文把 T=200 的偏离解释成“300 次迭代对 200 维欠收敛”，机制归因反了。

> **重跑说明（为什么这一版的控制形状和早期版本不同）**：本文的图与数字是**清空 checkpoint、从零跑满 300 次迭代**之后定稿的。定稿前那一版的 checkpoint 由更早的中间状态续跑得到，它在图 (b) 上呈“中段凸起”：峰值落在 $t\approx113$ 处 $-0.042$、末端 $t=0$ 处只有 $-0.008$，总目标值 0.0230；在同一 trial 上再加跑 600 次迭代，目标值降到 0.0048（控制能量降 4.8 倍），形状翻成“末端最大”（$t=0$ 处 $-0.041$、高噪声端 $-0.005$），这才与一阶条件 $u_t^{*}\propto G_t$ 相符（实测 $G_0=0.50$、$G_{50}=0.094$、$G_{100}=0.048$、$G_{199}=0.018$，单调递减）；换 4 个不同 $x_T$ 重跑，那一版的峰值都在 $t\approx112\sim129$，说明那是 300 次迭代对 200 维序列的欠收敛状态，而非某个 trial 的偶然。定稿版从零跑满 300 次后峰值已在末端（图 (b) 末端 $\lvert u\rvert=0.064$ vs 高噪声端 $0.028$），与一阶条件方向一致。**结论：图 (b) 能稳定读出的是“控制量级、离饱和线的距离、以及末端幅度 ≥ 高噪声端幅度”这个顺序；具体形状依赖优化路径（初始化与迭代次数），不能当解析结论引用**。

这里还有一层更根本的原因，值得单独说：本例的观测极其信息充分（$\sigma_\mathbf{y}/A = 0.05$，远小于先验标准差约 1.4），所以 $y/A$ 这个“只信测量”的点几乎就是 MMSE 点估计（T=200 时 0.042860 vs 0.042200，相差 1.6%）。在这个 regime 里，**谁把测量拟合得更死，谁的点误差就更小**——DOC 在 T=200 的落点就等于 $y/A$，所以相对 DPS 最优 $\zeta$ 那 12.4% 的改进，与其说是“全局协调优于贪心”，不如说是“确定性最优化把单点测量残差压到了零”。

**第三条：DPS 的稳定窗随 $T$ 整体右移，而“好误差”仍然靠收缩换**。

| $\zeta$ | 平均终端误差 | 标准差 | 方差比（中位数，理想=1） | 判定 |
|------|------------|--------|------------------------|------|
| 0.1 | 0.0494 | 0.0324 | 0.105 | 欠扩散（方差约 1/10） |
| 0.15 | **0.0489** | 0.0323 | 0.267 | 欠扩散（方差约 1/4） |
| 0.2 | 0.1204 | 0.1787 | 2.255 | 接近校准 |
| 0.3 | 0.5028 | 1.1676 | 40.46 | 失控 |
| 0.5 | 54.93 | 129.45 | $2.06\times 10^{5}$ | 发散 |

- $\beta_t \propto 1/T$，同一个 $\zeta$ 在每步上的引导量因此差一个数量级，稳定窗整体右移约一个数量级（0.02 → 0.1~0.15）。**$\zeta$ 不能跨 $T$ 搬用**，这是 13.4.3 那条“$\zeta$ 只在同一套参数化内部有意义”的第二个实例。
- 误差最好（0.0489）的 $\zeta=0.15$ 恰恰是方差比 0.267 的重收缩档：终端样本的标准差只有真实后验的一半左右；$\zeta=0.1$（0.0494）与它实质上是同一档（差 0.0004，小于标准误）。误差第三的 $\zeta=0.2$ 方差比 2.26 已接近校准，代价是误差翻倍到 0.120。**点误差与多样性在这里反着走**，与 T=20 主实验（$\zeta=0.02$ 方差比 0.154）同向，也和 13.6-2 那条图像任务上的“质量-多样性权衡”曲线同向。
- 校准诊断本身要小心读：方差比是重尾量，个别批次能冲到数十。T=20 的 $\zeta=0.025$ 就是个例子——5 批的均值 6.67、中位数 0.67，差一个数量级；只看均值会把“接近校准”误判成“过扩散”。所以 JSON 里均值与中位数都存了一份，按中位数下判断。

**第四条：修正后的说法**。

| 原文说法 | 复核结论 |
|---------|---------|
| “DPS 随 $T$ 增大接近 DOC” | 仍不成立，但理由不同：DPS 最优误差（0.0489@$\zeta=0.15$）比 DOC（0.0429）差 14.2%，加密步长并没有把这个差距抹平 |

#### ★ 步骤5：计算代价分析——精度与效率权衡

**场景**：分析DOC与DPS计算代价差异。本步骤为解析性讨论，代码不单独出图、不测墙钟时间。

**计算代价对比**：

| 维度 | DPS | DOC |
|------|-----|-----|
| 正向采样 | $\mathcal{O}(T)$ | $\mathcal{O}(T)$ |
| 反向传播 | $\mathcal{O}(T)$（单步） | $\mathcal{O}(T^{2})$（全轨迹） |
| 存储需求 | $\mathcal{O}(1)$ | $\mathcal{O}(T)$（存储轨迹） |
| 单样本计算量 | 1次采样轨迹 | 迭代次数×全轨迹（本实验300×） |
| 理论保证 | 贪心最优 | 全局最优（渐近精确） |

**核心权衡**（呼应13.5节小结）：

$$\text{贪心策略（DPS）} \xrightarrow{\text{全局优化}} \text{最优控制（DOC）}$$

DPS快速简单，在得分精确、观测线性的玩具场景中单步误差已足够小；DOC通过全局优化获得更严格的理论保证与目标函数灵活性，但需为每条样本付出数十到数百次全轨迹反传的代价（本实验中DOC单样本计算量约为DPS的300倍，而终端精度并未超过解析MMSE参考：0.0373 vs 0.0364）。两者非替代，而是精度-效率-灵活性权衡的不同端点。

**实践建议**：
- **高精度场景**（医疗重建、科学计算）且终端代价复杂/得分网络弱：考虑DOC或其随机低秩近似版
- **实时应用**（图像编辑、交互式生成）：DPS更实用
- **少步采样**（$T < 100$）：DPS需仔细调 $\zeta$（本场景 $\zeta=0.02$ 附近；$\zeta\ge 0.03$ 即出现发散试验，见参数表）；DOC优势在真实图像数据上才被文献验证（Li & Pereira 2024），本玩具场景未复现
- **多步采样**：本实验 T=200 对照（步骤 4b）显示，把 $T$ 从 20 加密到 200 后 DPS 的稳定窗整体右移（最优 $\zeta$ 从 0.02 变成 0.1~0.15，$\zeta$ 不能跨 $T$ 搬用），且 DOC 相对 DPS 最优 $\zeta$ 的优势稳定在 12% 左右（T=20 是 12.5%、T=200 是 12.4%，但两个 $T$ 的配对检验都不显著）——但它的性质变了：DOC 在 T=200 下落点等于数据一致点 $y/A$（$1.000\times$，20/20 落在 $10^{-3}$ 内），是“把单次测量精确反演”，不是“更好的后验采样”。本基准中观测极其信息充分（$\sigma_\mathbf{y}/A=0.05$），所以“拟合测量最死”几乎等于“点误差最小”，这正是 DOC 得分的地方，也是这个玩具场景不能用来验证 DOC 优势的原因

### 核心知识点总结

本实验对13.5节理论的检验结论：
1. **控制论视角统一性**：条件扩散采样 = 最优控制问题，控制序列 $\lbrace u_t\rbrace$ 编码观测约束。这视角把采样问题转优化问题，可借控制论丰富工具（iLQR、模型预测控制等）——这一价值不依赖本实验中DOC是否赢。
2. **DOC vs DPS本质差异**：
   - **DOC**：全局优化控制序列，考虑"这步如何影响最终结果"，渐近精确（需优化收敛为前提）。它是确定性 PF-ODE 上的**单点估计**，不产生后验样本——T=200 时落到 $y/A$ 正是这一点的直接体现，不是“退化”
   - **DPS**：贪心策略，每步仅据当前状态决策，Tweedie近似引入误差（误差大小依赖场景），但它是**采样器**，能给出多样性与不确定度（前提是 $\zeta$ 落在校准区，而本基准的稳定窗里没有这样的 $\zeta$）
3. **精度-效率权衡**：DOC需存整条轨迹并全轨迹反向传播，本实验中单样本计算量约为DPS的300倍。@li2024doc 随机低秩近似可将计算代价降至与DPS可比。
4. **Tweedie近似的误差是场景依赖的**：$\nabla \log p(\mathbf{y}\mid \mathbf{x}_t) \approx \nabla \log p(\mathbf{y}\mid \hat{x}_{0\mid t})$ 的误差在高噪声阶段变大，但在得分解析精确、观测线性的1D玩具场景中，它仍然大于 DOC 优化器自身的误差——DPS 与 MMSE 相差约 0.006，DOC 与 MMSE 只差 0.0009，两者差了一个量级。比较两种方法必须同时校准双方超参，否则结论由配置而非算法决定（本实验的"稻草人DPS"教训）。
5. **实践启示**：DOC的优势前提（弱得分网络、非线性观测、少步采样下的全局协调）在真实图像问题中才成立（见Li & Pereira 2024）；玩具场景只能演示控制论框架，不能验证优势主张。

## 收尾：为什么这一节重要

这一节把"每步加修正"这个朴素的 DPS 动作，提升成了一个严谨的**最优控制问题**。你会看到，DPS 之所以在少步采样或弱模型下失效，根子在于它"贪心"——只看眼前这一步；而 DOC 通过把整条轨迹一起优化，得到了理论上的全局最优，代价是计算翻了几倍。这再一次印证了全章反复出现的主题：**所有条件扩散方法，都是在"精度"和"效率"之间做权衡**。理解了贪心 vs 全局这根轴，你也就握住了下一节——全书收口——的钥匙。
