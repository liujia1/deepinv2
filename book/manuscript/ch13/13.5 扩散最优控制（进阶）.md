# 13.5 扩散最优控制（进阶）

> 你有没有这种感觉：DPS 每步都"凭当下信息仓促决策"——拿当前这一步的 Tweedie 估计算个似然梯度，往轨迹里一塞就完事。它从不考虑"这一步的修正会不会把后面带沟里"。这种只看眼前的策略，控制论里叫"贪心"。这一节我们把条件扩散采样当成最优控制问题，看看"全局最优"长什么样，以及它为什么在真实图像问题的少步采样时能明显改善DPS（注：这一优势在玩具场景中未必复现，见本节实验的诚实检验）。

## 控制论视角：逆向扩散 = 受控动力学系统

### 逆向扩散过程的控制论表述

第7章建立的逆向 SDE 可视为一个动力学系统：

$$dx = \left[f(\mathbf{x},t) - g(t)^2\,\nabla_x\log p_t(\mathbf{x})\right]dt + g(t)\,d\bar{w}$$

无条件逆向 SDE 从纯噪声 `x_T` 出发，在得分函数驱动下回到数据分布。现在把这系统看作**受控动力学系统**——每步注入控制向量 `u_t`：

$$\boxed{\mathbf{x}_{t-\Delta t} = \mathbf{x}_t - \left[f(\mathbf{x}_t, t) - \frac{1}{2}g(t)^2\,\nabla_x\log p_t(\mathbf{x}_t)\right]\Delta t + u_t + g(t)\sqrt{\Delta t}\,\varepsilon}$$

`ε ~ N(0, I)` 是随机噪声项，`u_t` 是待设计控制输入。当 `u_t = 0`，退化为无条件采样；当 `u_t` 编码观测约束，采样轨迹被引向与观测 `y` 一致方向。把这个式子逐项看：括号里是原有的无条件采样动力学——由正向过程 `f` 和得分 `∇log p_t(x)` 决定；`u_t` 是我们在每一步额外允许注入的"操纵杆"。这一转变意味着，条件采样从"改公式里的得分"变成了"在每一步叠加一个控制信号"，前者受结构约束，后者更自由。

### 控制目标的设定

最优控制核心问题：**怎么选控制序列 `{u_t}_{t=T}^0`，使生成的样本 `x_0` 既符合先验又与观测 `y` 一致？**

形式化为优化问题——最小化代价函数：

$$J(\{u_t\}) = \sum_{t=1}^{T} l_t(\mathbf{x}_t, u_t) + l_0(\mathbf{x}_0)$$

其中：
- `l_0(x_0) = -log p(y|x_0)` 是**终端代价**（terminal cost），衡量生成结果与观测一致性——`x_0` 与 `y` 越不一致代价越高
- `l_t(x_t, u_t)` 是**运行代价**（running cost），衡量控制输入代价——`u_t` 越大偏离先验越远

对条件扩散采样，我们希望控制信号仅在必要时修正轨迹，不额外惩罚控制量本身。因此设**运行代价为零**：

$$l_t(\mathbf{x}_t, u_t) = 0, \quad t = 1, \ldots, T$$

代价函数简化：

$$\boxed{J(\{u_t\}) = l_0(\mathbf{x}_0) = -\log p(\mathbf{y}|\mathbf{x}_0)}$$

讲清楚这个简化在说什么：代价函数里唯一剩下的 `-log p(y|x_0)` 就是"最终结果离观测有多远"——`x_0` 与 `y` 越一致，这一项越小。没有运行代价意味着我们允许控制信号"免费"使用，不对控制量本身加以惩罚。

**最优控制问题**：选控制序列 `{u_t}`，使终端代价 `-log p(y|x_0)` 最小，即生成结果 `x_0` 与观测 `y` 对数似然最大。

物理直觉清晰：我们允许逆向采样每步自由注入控制信号（不惩控制量），唯一约束是最终生成结果须与观测一致。运行代价为零设定使控制信号可"免费"用——只要最终结果好，过程怎么修正都行。

## DOC 的形式化与求解

### iLQR 算法与简化的 Riccati 方程

上述最优控制问题可用迭代线性二次调节器（iLQR）求解。iLQR 是经典最优控制在非线性动力学系统上的推广——在当前轨迹附近线性化动力学，迭代解二次近似子问题。

标准 iLQR 求解涉及 Riccati 方程——需递归算代价函数关于状态二阶导数（Hessian）和关于控制一阶导数（梯度）。但 DOC 特殊设定下，**运行代价 `l_t = 0` 带来显著简化**：
1. **二阶项消失**：因 `l_t(x_t, u_t) = 0`，代价 Hessian 仅来自终端代价 `l_0(x_0)` 反向传播。中间步二阶项全零，Riccati 递推大幅简化
2. **计算量降**：标准 iLQR 需维护 `O(n²)` 的 Riccati 矩阵（`n` 状态维度），DOC 只需维护从终端代价反传的梯度向量——复杂度从 `O(Tn²)` 降至 `O(Tn)`

### 最优控制的结构

经 iLQR 求解，最优控制具如下结构：

**定理**（DOC最优控制，Li & Pereira 2024）：在确定性采样器（PF-ODE）下，最优控制为：

$$\boxed{u_t^* = \alpha \cdot \nabla_{\mathbf{x}_t}\log p(\mathbf{y}|\mathbf{x}_0)}$$

`α` 是与采样器步长相关的缩放因子，`∇_{x_t}log p(y|x_0)` 是终端似然关于当前状态 `x_t` 的梯度，通过**沿整个采样轨迹的反向传播**计算。

把这个定理拆开读：最优控制方向不是"当前时刻的似然得分 `∇log p(y|x_t)`"，而是"终端条件 `p(y|x_0)` 对当前状态 `x_t` 的梯度"。换句话说，它问的不是"这一步离观测多近"，而是"这一步的微小变动会如何影响最终结果与观测的一致性"。这正是全局优化的精髓——每一步的修正都指向最终目标，而不是眼前一步。

这结果揭示 DOC 核心特征：**最优控制方向是终端似然梯度 `∇_{x_t}log p(y|x_0)`，而非当前时刻似然梯度 `∇_{x_t}log p(y|x_t)`**。

### 与精确后验采样的联系

一个重要理论结果：**在确定性采样器（PF-ODE）下，`α = 1` 的最优控制精确恢复后验采样方程。**

**引理**：设PF-ODE为 `dx = [f(x,t) - g(t)^2∇log p_t(x)]dt`，注入最优控制 `u_t^* = ∇_{x_t}log p(y|x_0)` 后，受控PF-ODE等价于从条件分布 `p(x|y)` 采样的概率流ODE。

引理含义：若能精确算 `∇_{x_t}log p(y|x_0)`（终端似然关于当前状态梯度），DOC 受控轨迹与从真实后验 `p(x|y)` 采样轨迹完全一致——无近似误差。

当然，`∇_{x_t}log p(y|x_0)` 实践无法精确算（依赖整条轨迹未来状态），需反向传播近似。但理论结果给 DOC **渐近精确性保证**：随近似精度提升，DOC 采样结果收敛于真实后验。

## DOC 与 DPS 的关系

### DPS 是 DOC 的贪心近似

DPS 与 DOC 核心差异在**优化范围**：

| 维度 | DPS | DOC |
|---|---|---|
| 优化范围 | 局部（每步贪心） | 全局（整条轨迹） |
| 似然梯度计算 | `∇log p(y\|x_t) ≈ ∇log p(y\|\hat{x}_{0\|t})` | `∇_{x_t}log p(y\|x_0)` 通过反传 |
| Tweedie近似 | 需要 | 不需要 |
| 计算代价 | 低（单步前向+反传） | 高（全轨迹反传） |
| 理论保证 | 贪心最优 | 全局最优（渐近精确） |

**DPS 贪心策略**：第 `t` 步仅据当前状态 `x_t` 决策——用 Tweedie 估计 `x̂_{0|t}` 近似 `x_0`，算 `∇log p(y|x̂_{0|t})` 作似然梯度近似，注入当前步采样。它不考虑这步决策如何影响后续步采样质量。

**DOC 全局策略**：DOC 优化整个控制序列 `{u_t}_{t=T}^0`，通过沿完整轨迹反向传播算每 `u_t` 对终端代价 `l_0(x_0) = -log p(y|x_0)` 影响。每步控制信号都考虑"这步修正如何影响最终重建质量"——这是全局优化核心优势。

### Tweedie 近似 vs 精确反传

DPS 与 DOC 技术差异集中在似然梯度计算：

**DPS**：`∇_{x_t}log p(y|x_t) ≈ ∇_{x_t}log p(y|\hat{x}_{0|t})`

这近似把不可解 `p(y|x_t) = ∫ p(y|x_0)p(x_0|x_t)dx_0` 替成 `p(y|\hat{x}_{0|t})`——用单点估计替代整个积分。这是 Tweedie 近似本质，也是 DPS 误差主要来源。高噪声阶段 `x̂_{0|t}` 与真 `x_0` 偏差大，近似误差显著。

**DOC**：`u_t^* = α · ∇_{x_t}log p(y|x_0)`

DOC 直接算终端似然 `p(y|x_0)` 关于当前状态 `x_t` 的梯度——**不需 Tweedie 近似**。这梯度经沿整条采样轨迹反向传播获得：从终端代价 `-log p(y|x_0)` 起，沿时间轴反传每步 `x_t`，得精确梯度方向。反向传播自然考虑"从 `x_t` 到 `x_0` 完整映射"——比 Tweedie 单点估计更准。

### DOC 的鲁棒性优势

DOC 全局优化策略带来显著鲁棒性优势：

**少步采样下优势**：DPS 在少步采样（如 `T=50`）表现退化——每步 Tweedie 近似误差累积，贪心策略无法协调相邻步修正方向。DOC 通过全局优化，即使步数很少也能找合理控制序列——因每步控制信号都考虑对最终结果影响。

**弱得分网络下优势**：当预训练得分网络质量差，DPS 先验得分不准，贪心策略易把轨迹推错方向。DOC 全局优化可通过调控制序列补偿先验得分误差——终端代价 `-log p(y|x_0)` 提供独立、不依赖先验得分质量的目标信号。

### 实验对比

Li & Pereira (2024) 在 FFHQ 256×256 数据集实验验证 DOC 优势：
- **DOC with `T=50` 在多项逆问题（超分辨、修复、去模糊）重建质量优于 DPS with `T=1000`**——少20倍采样步数却更好结果
- DOC 在低噪声场景优势更显——因终端代价 `-log p(y|x_0)` 梯度信号在高信噪比时更清晰
- DPS 在高噪声场景仍有竞争力——因先验得分权重较高，DPS 贪心策略偏差较小

### 实践考虑：随机低秩近似

DOC 主要计算瓶颈在反向传播中 Jacobian 矩阵计算——`∇_{x_t}log p(y|x_0)` 需算终端似然关于每步状态梯度，涉及得分网络 `ε_θ(x_t, t)` 的 Jacobian 矩阵，维度 `n×n`（`n` 图像像素数），直接计算不可行。

Li & Pereira (2024) 提出用**随机低秩近似**（randomized low-rank approximation）替精确 Jacobian：
1. 用随机投影矩阵 `P ∈ R^{k×n}`（`k ≪ n`）把 Jacobian 投到低维空间
2. 低维空间算 Jacobian-向量乘积
3. 实验表明，**秩 `k=1` 即可获良好近似**——因最优控制 `u_t^*` 通常集中在少数方向

这近似使 DOC 计算代价降到与 DPS 可比，同时保留全局优化核心优势。

## 本节小结

从控制论视角审视条件扩散采样，DPS 与 DOC 对比揭示一般原则：

$$\text{贪心策略（DPS）} \xrightarrow{\text{全局优化}} \text{最优控制（DOC）}$$

DPS 每步做局部最优决策——快、简单，但少步采样或弱先验下可能失效。DOC 通过全局优化控制序列获更严格理论保证——渐近精确、鲁棒，但计算代价更高。两者非替代，而是精度-效率权衡两端。

控制论视角更深层意义：它把条件扩散采样从"采样算法"提升为"优化问题"——可借控制论丰富工具（iLQR、模型预测控制、鲁棒控制等）设计分析条件采样策略。这视角潜力远未被充分挖掘。

一个优雅理论副产品：**所需条件得分函数直接作为价值函数（value function）的雅可比出现**——最优控制价值函数 `V(x_t,t)` 对其状态 `x_t` 梯度 `∇_{x_t}V` 恰给出引导采样所需得分。从更深层次看，这从控制论视角重释第5~6章得分函数：它既是数据分布得分 `∇_{x_t}log p_t(x_t)`，也是最优控制问题"价值梯度"。DOC 因此把"得分"与"最优性条件"统一。

从后验得分分解到引导采样再到最优控制，第13章逐步建立"条件扩散采样 = 逆问题求解"完整理论。现在回到全书起点——第1章逆问题 `y = Ax + ε`，审视这段从贝叶斯到扩散的理论旅程，验证全书核心论点最终闭环。

**来源**：Li & Pereira, "Solving Inverse Problems via Diffusion Optimal Control", NeurIPS 2024; Chung et al. (2209.14687) §3.2 DPS

## 实验13.5-1 扩散最优控制（DOC）

> **对应知识点**：13.5节扩散最优控制（进阶）——控制论视角、DOC全局最优 vs DPS贪心对比、计算代价分析
>
> **实验目的**：从控制论视角理解条件扩散采样，在1D简化基准上**检验**DOC全局最优控制相对DPS贪心策略的理论优势主张，分析两种方法计算代价差异
>
> **实验设计**：1D高斯混合先验 + VP-SDE框架（简化版，T=20步），DOC实现梯度优化控制序列，DPS实现标准得分修正的贪心策略
>
> **运行前提**：CPU可运行（约10分钟）

### 场景描述

本实验在简化1D高斯混合场景下，对比DOC全局最优控制与DPS贪心策略在条件采样中表现，检验13.5节的理论主张：

$$\text{贪心策略（DPS）} \xrightarrow{\text{全局优化}} \text{最优控制（DOC）}$$

**实验设置**：
- **先验分布**：1D高斯混合 `p(x) = 0.5N(-2, 0.5²) + 0.5N(2, 0.5²)`，得分函数用VP-SDE边际的解析式 `p(x_t) = Σᵢ wᵢ N(x_t; √ᾱ_t μᵢ, ᾱ_t σᵢ² + 1-ᾱ_t)`（与采样离散化、Tweedie公式同一约定）
- **观测模型**：`y = Ax + ε`，`A = 2`，`ε ~ N(0, 0.1²)`；每次试验从先验抽 `x*` 再生成对应观测 `y = 2x* + ε`
- **扩散框架**：VP-SDE，时间步数 `T = 20`（简化版，便于可视化）；初始点 `x_T ~ N(0, 3²)` 为过离散点（控制论视角下从任意初态驾回可行域，非严格扩散初值）
- **目标**：采样满足观测约束的后验样本 `x_0 ~ p(x|y)`，以终端误差 `|x_0 - x*|` 衡量

**DOC实现要点**：
- 终端代价 `J = -log p(y|x_0) = (y-Ax_0)²/2σ²`，叠加控制幅度正则 `λΣu_t²`（`λ=0.1`）
- 沿整条随机前向轨迹反向传播，Adam优化控制序列 `{u_t}`（300步，lr=0.01），最终确定性重放

**DPS实现要点**：
- 贪心策略：每步用Tweedie估计 `x̂_{0|t}` 近似似然梯度
- 标准得分修正形式：`u_t = β_t · ζ · A(y - A\hat{x}_{0|t})/σ²`，`ζ = 0.3`（与逆向SDE的 `g²=β_t` 同尺度；`σ_obs=0.1` 时梯度量级大，实测 `ζ≥0.7` 发散，属步长调参问题而非方法缺陷）

### 实验步骤

#### 步骤1：先验、得分函数与观测设置

**场景**：建立1D高斯混合先验与解析VP边际得分，设置线性观测。本步骤为设置与自检，代码不单独出图；先验的双峰结构体现在步骤4图(a)的轨迹收敛目标上。

**输入**：高斯混合参数 `[μ_1, μ_2] = [-2, 2]`，`[σ_1, σ_2] = [0.5, 0.5]`，观测算子 `A = 2`，噪声 `σ = 0.1`

**预期结果**：后验集中在与 `y/A` 相符的左/右模态附近；终端误差的理论下限由后验不确定度决定（解析MMSE基线：平均误差0.0364，后验std均值0.0498）。

**实际效果**：

50次试验中样本均收敛至与 `y/A` 同侧模态附近，与解析后验位置一致；两种方法的终端误差均高于MMSE基线约一个后验std，处于合理量级。

#### 步骤2：DOC全局最优控制——轨迹优化

**场景**：实现DOC全局优化控制序列，把采样当作可微分优化问题求解。

**核心公式**（13.5节）：

$$u_t^* = \alpha \cdot \nabla_{\mathbf{x}_t}\log p(\mathbf{y}|\mathbf{x}_0)$$

**实现要点**：
1. 前向采样生成随机轨迹 `{x_T, x_{T-1}, …, x_0}`（控制序列叠加在逆向SDE之上）
2. 从终端代价 `-log p(y|x_0)` 反向传播，算每步控制 `u_t` 的梯度
3. Adam优化控制序列，目标 = 终端代价 + 0.1·控制正则

**预期结果**：终端代价 `-log p(y|x_0)` 随优化迭代下降，最终收敛低值。

**实际效果**：

末次试验终端代价从初始约 4000 降至接近 0（见步骤4图(d)），控制序列成功将采样轨迹引至满足观测约束区域（`x_0 ≈ -2.61`，真实信号 `x* = -2.53`）。需注意：由于每轮前向重采样噪声，逐迭代终端代价有抖动；控制正则 `λ=0.1` 使解偏向小控制而非纯终端最优，这是DOC终端误差的固有来源之一。

#### 步骤3：DPS贪心策略——单步优化对比

**场景**：实现标准形式的DPS贪心策略，每步独立决策，与全局最优控制对比。

**核心公式**（13.5节）：

$$\nabla_{\mathbf{x}_t}\log p(\mathbf{y}|\mathbf{x}_t) \approx \nabla_{\mathbf{x}_t}\log p(\mathbf{y}|\hat{x}_{0|t})$$

**实现要点**：
1. 每步用Tweedie估计 `x̂_{0|t}` 近似最终结果
2. 得分修正 `u_t = β_t · ζ · A(y - A\hat{x}_{0|t})/σ²`，`ζ=0.3`
3. 不考虑该步决策对后续步影响

**预期结果**（来自13.5节理论叙事）：DPS贪心策略在少步采样（`T = 20`）下性能退化——Tweedie近似误差累积。

**实际效果**：

预期不成立。DPS终端误差 0.0743±0.0546（n=50），反而优于DOC的 0.1250±0.0875。原因：本场景得分函数解析精确、观测线性，Tweedie估计 `x̂_{0|t}` 在噪声阶段仍是有理估计，近似误差很小；而DOC简化实现（300步Adam、随机目标、控制正则偏差）未收敛到理论全局最优。贪心与全局的差距需要在得分网络弱、非线性观测的真实场景中才可能显现（见Li & Pereira 2024图像实验）。

#### ★ 步骤4：DOC vs DPS——全局最优与贪心对比

**场景**：相同实验设置下，定量对比DOC与DPS终端误差和轨迹质量。

**输入参数**：

| 参数 | 值 | 说明 |
|------|-----|------|
| 时间步数 `T` | 20 | 简化版，便于可视化 |
| 真实信号 `x*` | 每次试验从先验随机抽样 | 末次试验（作图用）`x* = -2.531` |
| 观测值 `y` | `y = 2x* + ε` 逐试验生成 | 末次试验 `y ≈ -5.01` |
| 测量噪声 `σ` | 0.1 | 高斯噪声标准差 |
| DOC学习率 | 0.01 | 控制序列优化步长 |
| DOC优化步数 | 300 | Adam迭代次数 |
| DOC控制正则 `λ` | 0.1 | 控制幅度惩罚 `λΣu_t²` |
| DPS控制形式 | `u_t = β_t·ζ·A(y-A\hat{x}_{0|t})/σ²` | 标准得分修正 |
| DPS缩放因子 `ζ` | 0.3 | 稳定区间内（`ζ≥0.7`发散） |
| 试验次数 | 50 | 独立蒙特卡洛试验（每试验新抽样`x*`） |

**实验结果**（n=50次试验统计）：

| 方法 | 终端误差 `‖x_0 - x*‖` | 计算代价 |
|------|------------------------|---------|
| DPS（贪心，标准形式） | **0.0743 ± 0.0546** | 低（单步前向+反传） |
| DOC（全局优化，简化版） | 0.1250 ± 0.0875 | 高（全轨迹反传×300迭代） |
| 解析MMSE基线（理论下限参考） | 0.0364 | — |

生成图`DOC vs DPS对比.png`（末次试验，`x* = -2.531`），包含：
- (a) **轨迹对比**（左上）：DOC轨迹平滑收敛到 `x* = -2.531`（终端 `x_0 ≈ -2.61`）；DPS轨迹前几步因大残差大幅过冲（一度探至 -8.7），约5步内即锁定 `x*` 附近，之后在采样噪声下围绕 `x*` 小幅波动（终端 `x_0 ≈ -2.46`）
- (b) **DOC控制输入**（右上）：前期约 -0.16 稳态控制，于 `t ≈ 10` 出现一次向 -0.40 的深谷（控制输入短暂增强），之后回升至约 -0.15 稳态——呈现"全局协调非单调控制序列"。这"先浅后深再回弹"形态是DOC全局优化的特征：反向传播发现中段（轨迹已接近目标、终端梯度最大）集中投放控制最划算；而DPS贪心控制强度逐步衰减（残差越小推得越轻），形态单调
- (c) **终端状态对比**（左下）：末次试验 DOC `x_0 ≈ -2.61`、DPS `x_0 ≈ -2.46`，均靠近真实信号 `x* = -2.531`（绿色虚线）；标题标注 n=50 平均误差 DOC=0.1250±0.0875、DPS=0.0743±0.0546
- (d) **DOC优化过程**（右下）：左轴终端代价 `J(x_0)` 从约 4000 收敛近 0；右轴终端状态 `x_0`（随机前向重采样，故抖动较大）整体收敛到 `x* = -2.531` 附近

**核心洞察**（对13.5节理论的诚实检验）：
1. **"DOC优于DPS"不是固有属性，而是对手配置产物**：本实验早期版本曾报告DPS误差0.4863、DOC"相对改进70.78%"，但当时DPS被额外乘了0.01阻尼因子并叠加±100裁剪（既非标准DPS也非表中声称的`ζ=1.0`），产生±1幅度的限幅锯齿振荡（旧图(a)的剧烈震荡即此伪影）。改用标准得分修正形式后结论反转：贪心DPS（0.0743）优于简化DOC（0.1250）。"全局 vs 贪心"的优势叙事在得分解析精确、观测线性的玩具场景中不成立——因为该场景下DPS的Tweedie近似误差本就很小。
2. **DOC简化实现的误差源**：控制正则 `λΣu²` 把解拉离纯终端最优；随机前向目标（每迭代重采样噪声）使300步Adam仅收敛到近似驻点；确定性重放轨迹继承得分边际近似偏差。三者叠加使DOC落在MMSE基线（0.0364）之上约一个后验std。
3. **DOC的真实价值在框架而非本基准胜出**：把采样转为优化问题后，终端代价可任意定制、可借iLQR/随机低秩等控制论工具（Li & Pereira 2024 在真实图像、弱得分网络、少步采样条件下报告DOC显著优于DPS）；本实验复现不了那些前提，故应把结果读作"工具演示"而非"优势验证"。

#### ★ 步骤5：计算代价分析——精度与效率权衡

**场景**：分析DOC与DPS计算代价差异。本步骤为解析性讨论，代码不单独出图、不测墙钟时间。

**计算代价对比**：

| 维度 | DPS | DOC |
|------|-----|-----|
| 前向采样 | `O(T)` | `O(T)` |
| 反向传播 | `O(T)`（单步） | `O(T²)`（全轨迹） |
| 存储需求 | `O(1)` | `O(T)`（存储轨迹） |
| 单样本计算量 | 1次采样轨迹 | 迭代次数×全轨迹（本实验300×） |
| 理论保证 | 贪心最优 | 全局最优（渐近精确） |

**核心权衡**（呼应13.5节小结）：

$$\text{贪心策略（DPS）} \xrightarrow{\text{全局优化}} \text{最优控制（DOC）}$$

DPS快速简单，在得分精确、观测线性的玩具场景中单步误差已足够小；DOC通过全局优化获得更严格的理论保证与目标函数灵活性，但需为每条样本付出数十到数百次全轨迹反传的代价（本实验中DOC单样本计算量约为DPS的300倍，精度反而略逊）。两者非替代，而是精度-效率-灵活性权衡的不同端点。

**实践建议**：
- **高精度场景**（医疗重建、科学计算）且终端代价复杂/得分网络弱：考虑DOC或其随机低秩近似版
- **实时应用**（图像编辑、交互式生成）：DPS更实用
- **少步采样**（`T < 100`）：DPS需仔细调 `ζ`（本场景稳定区间 `ζ≤0.5`）；DOC优势在真实图像数据上才被文献验证（Li & Pereira 2024），本玩具场景未复现
- **多步采样**：本实验T=200对照中，合理步长DPS误差（ζ=0.3→0.075、ζ=0.5→0.063）仍优于DOC（0.425，固定300迭代对200维控制序列欠收敛）——"DPS随T增大接近DOC"的说法在本基准下无从谈起，DOC自身反而随T增大而退化

### 核心知识点总结

本实验对13.5节理论的检验结论：
1. **控制论视角统一性**：条件扩散采样 = 最优控制问题，控制序列 `{u_t}` 编码观测约束。这视角把采样问题转优化问题，可借控制论丰富工具（iLQR、模型预测控制等）——这一价值不依赖本实验中DOC是否赢。
2. **DOC vs DPS本质差异**：
   - **DOC**：全局优化控制序列，考虑"这步如何影响最终结果"，渐近精确（需优化收敛为前提）
   - **DPS**：贪心策略，每步仅据当前状态决策，Tweedie近似引入误差（误差大小依赖场景）
3. **精度-效率权衡**：DOC需存整条轨迹并全轨迹反向传播，本实验中单样本计算量约为DPS的300倍。Li & Pereira (2024) 随机低秩近似可将计算代价降至与DPS可比。
4. **Tweedie近似的误差是场景依赖的**：`∇log p(y|x_t) ≈ ∇log p(y|\hat{x}_{0|t})` 的误差在高噪声阶段变大，但在得分解析精确、观测线性的1D玩具场景中，该误差小于DOC优化器的自身误差——比较两种方法必须同时校准双方超参，否则结论由配置而非算法决定（本实验的"稻草人DPS"教训）。
5. **实践启示**：DOC的优势前提（弱得分网络、非线性观测、少步采样下的全局协调）在真实图像问题中才成立（见Li & Pereira 2024）；玩具场景只能演示控制论框架，不能验证优势主张。

## 收尾：为什么这一节重要

这一节把"每步加修正"这个朴素的 DPS 动作，提升成了一个严谨的**最优控制问题**。你会看到，DPS 之所以在少步采样或弱模型下失效，根子在于它"贪心"——只看眼前这一步；而 DOC 通过把整条轨迹一起优化，得到了理论上的全局最优，代价是计算翻了几倍。这再一次印证了全章反复出现的主题：**所有条件扩散方法，都是在"精度"和"效率"之间做权衡**。理解了贪心 vs 全局这根轴，你也就握住了下一节——全书收口——的钥匙。
