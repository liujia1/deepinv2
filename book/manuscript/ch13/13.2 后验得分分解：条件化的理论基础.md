# 13.2 后验得分分解：条件化的理论基础

> 上一节我们把等式立起来了：**条件扩散采样 = 逆问题求解**。但"等式成立"和"怎么算"是两回事。这一节我们干两件事：第一，证明条件采样其实就是把无条件采样的得分函数换一项；第二，直面那个尴尬的事实——换进来的那一项（似然得分）恰恰算不出来。然后你会看到，第5章的 Tweedie 等式又一次来救场。

---

## 本节 roadmap

- 看清"条件逆向 SDE"和无条件版本长得一模一样，差别只在那一个得分替换；
- 跟着三行推导拿下**后验得分分解定理**，并理解它把逆问题拆成"先验"+"似然"两个子问题；
- 弄明白**似然得分为什么算不出**（一个对 $\mathbf{x}_{0}$ 的不可解积分）；
- 看 Tweedie 等式如何当"桥梁"，把"得分 → 去噪估计 → 一致性梯度 → 修正得分"串成一条闭环。

## 13.2.1 条件逆向 SDE 的推导

### 回顾：无条件正向 SDE 与逆向 SDE

第7章搭了扩散模型的 SDE 框架。正向 SDE 描述从数据到噪声的连续过程：

$$dx = f(\mathbf{x},t)\,dt + g(t)\,dw$$

$f(\mathbf{x},t)$ 是漂移函数，$g(t)$ 是扩散系数，$w$ 是标准布朗运动。选不同的 $f$、$g$，就覆盖 VE-SDE（$f=0$，$g(t)=\sqrt{d[\sigma(t)^{2}]/dt}$）和 VP-SDE（$f(\mathbf{x},t)=-\beta(t)/2\cdot \mathbf{x}$，$g(t)=\sqrt{\beta(t)}$）两种经典设定。

@anderson1982reverse 的逆向时间 SDE 定理（第7章 7.3）给出从噪声回数据的方程——**无条件逆向 SDE**：

$$\boxed{dx = \left[f(\mathbf{x},t) - g(t)^2\,\nabla_\mathbf{x}\log p_t(\mathbf{x})\right]\,dt + g(t)\,d\bar{w}}$$

$\bar{p}w$ 是逆向时间的布朗运动，$p_t(\mathbf{x})$ 是正向过程在时刻 $t$ 的边际分布。这个方程里，**得分函数 $\nabla \log p_t(\mathbf{x})$ 是唯一需要从数据里学的量**——第6章 DSM 和第11~12章 VLB 训的都是它。

无条件逆向 SDE 的采样：从纯噪声 $\mathbf{x}_T \sim p_T(\mathbf{x})$ 出发，逐步解回 $t=0$，拿到数据分布 $p_0(\mathbf{x})=p_{\mathrm{data}}(\mathbf{x})$ 的样本。这样生成的图"像训练数据"，但没法保证满足特定条件约束。

### 引入条件：条件逆向 SDE

现在的核心问题：给定观测 $\mathbf{y}$（比如 $\mathbf{y} = A(\mathbf{x}) + n$），怎么从**条件分布** $p(\mathbf{x}\mid \mathbf{y})$ 而不是无条件分布 $p(\mathbf{x})$ 里采样？

答案出人意料地简洁：**条件逆向 SDE 的形式和无条件的一模一样，只需把无条件得分换成条件得分**。

$$\boxed{dx = \left[f(\mathbf{x},t) - g(t)^2\,\nabla_\mathbf{x}\log p_t(\mathbf{x}|\mathbf{y})\right]\,dt + g(t)\,d\bar{w}_y}$$

$d\bar{w}_y$ 表示以观测 $\mathbf{y}$ 为条件的逆向时间布朗运动。

这个替换的推导是直接的。Anderson 的逆向 SDE 定理本身不要求正向 SDE 的边际分布是 $p_t(\mathbf{x})$——它对任意由正向 SDE 产生的边际分布都成立。当我们把采样目标从 $p(\mathbf{x})$ 换成 $p(\mathbf{x}\mid \mathbf{y})$，只需把边际分布的得分从 $\nabla \log p_t(\mathbf{x})$ 换成 $\nabla \log p_t(\mathbf{x}\mid \mathbf{y})$，SDE 的数学结构完全不变。

**关键洞察**：SDE 的形式不变——漂移项 $f(\mathbf{x},t)$ 和扩散系数 $g(t)$ 完全由正向过程决定，跟条件化无关。条件化的全部效果都浓缩在那一次得分函数的替换里。换言之，**条件得分 $\nabla \log p_t(\mathbf{x}\mid \mathbf{y})$ 是我们唯一需要新算的量**。

从更深的层次看，这一"只换一项"的结论是贝叶斯公式在采样骨架上的重演：正向过程（决定了 SDE 骨架）与"观测怎么进来"是解耦的，观测只通过得分这一入口施加影响。这保证了无条件扩散的整套训练与采样基础设施可以原封不动地复用。

### 物理直觉

无条件采样 vs 条件采样，区别可以这样感受：

- **无条件采样**：画"像训练数据的图"——轨迹被得分 $\nabla \log p_t(\mathbf{x})$ 拉向数据分布的高密度区；
- **条件采样**：画"像训练数据**且**和 $\mathbf{y}$ 一致的图"——轨迹被条件得分 $\nabla \log p_t(\mathbf{x}\mid \mathbf{y})$ 同时拉向两个方向：数据分布高密度区（先验知识）+ 与观测一致的区域（测量约束）。

这个直觉正好坐实了"从 $p(\mathbf{x}\mid \mathbf{y})$ 采样 = 解逆问题"：第1章说逆问题的贝叶斯解是 $p(\mathbf{x}\mid \mathbf{y}) \propto p(\mathbf{y}\mid \mathbf{x})p(\mathbf{x})$，而条件逆向 SDE 恰好给出了从 $p(\mathbf{x}\mid \mathbf{y})$ 采样的算法——把逆问题求解变成扩散采样里的一次得分替换。

但关键问题来了：条件得分 $\nabla \log p_t(\mathbf{x}\mid \mathbf{y})$ 怎么算？无条件得分 $\nabla \log p_t(\mathbf{x})$ 已经从预训练扩散模型拿到，条件得分还没有。后验得分分解定理给出答案。

## 13.2.2 后验得分分解定理

### 定理陈述

**后验得分分解定理**：条件得分 $\nabla_{\mathbf{x}_t}\log p(\mathbf{x}_t\mid \mathbf{y})$ 可拆成先验得分 + 似然得分：

$$\boxed{\nabla_{\mathbf{x}_t}\log p(\mathbf{x}_t|\mathbf{y}) = \nabla_{\mathbf{x}_t}\log p(\mathbf{x}_t) + \nabla_{\mathbf{x}_t}\log p(\mathbf{y}|\mathbf{x}_t)}$$

这正是 @chung2023dps 原文式 (3) 的核心，也是条件扩散采样解逆问题的**理论基石**。

在逐项解释之前，先看这个定理的整体含义：它把"给定观测的后验得分"拆成一个**已经掌握的量**和一个**有待逼近的量**的加法。这正是"贝叶斯 = 先验 + 似然"这一全书主线在得分空间里的显影——与其说这是一个待证明的公式，不如说它是贝叶斯定理换了一种"语言"在说话：把概率表达式换成梯度表达式，复制不变的是"两股信息相加"的结构。

### 第一项：先验得分 $\nabla_{\mathbf{x}_t}\log p(\mathbf{x}_t)$

先验得分编码"数据长什么样"——它指向数据分布 $p(\mathbf{x})$ 的高密度区。在扩散模型里，先验得分正是第6~7章训的目标：

$$s_\theta(\mathbf{x}_t, t) \approx \nabla_{\mathbf{x}_t}\log p_t(\mathbf{x}_t)$$

这个近似来自去噪得分匹配（DSM）或等价的变分下界（VLB）训练。**预训练扩散模型已经给了先验得分——不用任何额外训练。**

它的物理角色是"先验知识的驱动力"：把采样轨迹拉向"像真图"的区域，防止漂移到数据分布的低密度区。这和第5章 PnP-ULA 里先验梯度 $\nabla \log p(\mathbf{x})$ 的角色完全一致——区别只是扩散模型用多尺度得分给了更精确的先验。

### 第二项：似然得分 $\nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_t)$

似然得分编码"和观测 $\mathbf{y}$ 的一致性"——它指向让观测 $\mathbf{y}$ 更可能出现的方向。在逆问题 $\mathbf{y} = A(\mathbf{x}) + n$ 语境下，它把轨迹拉回"和测量数据一致"的区域。

**似然得分算不出来**——这是本节后面要细扒的核心困难，也是 13.3 节所有近似方法要解决的终极问题。所有方法的差异，本质上都在于怎么近似 $\nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_t)$。

它的物理角色是"数据一致性的驱动力"：每步采样都加一个修正力，让生成的图不仅"像真图"，而且"和观测一致"。这个力的大小和方向决定条件信息的强度和精度。

### 证明（可跳过）

证明是贝叶斯定理在得分函数层面的直接应用，三行就完事：

**第一步**：由贝叶斯定理写条件分布

$$p(\mathbf{x}_t|\mathbf{y}) = \frac{p(\mathbf{y}|\mathbf{x}_t)\,p(\mathbf{x}_t)}{p(\mathbf{y})}$$

**第二步**：两边取对数

$$\log p(\mathbf{x}_t|\mathbf{y}) = \log p(\mathbf{y}|\mathbf{x}_t) + \log p(\mathbf{x}_t) - \log p(\mathbf{y})$$

**第三步**：对 $\mathbf{x}_t$ 求梯度。由于 $p(\mathbf{y})$ 不依赖 $\mathbf{x}_t$，$\nabla_{\mathbf{x}_t}\log p(\mathbf{y}) = 0$：

$$\nabla_{\mathbf{x}_t}\log p(\mathbf{x}_t|\mathbf{y}) = \nabla_{\mathbf{x}_t}\log p(\mathbf{y}|\mathbf{x}_t) + \nabla_{\mathbf{x}_t}\log p(\mathbf{x}_t)$$

证明的简洁令人惊叹——三行推导就把条件得分拆成两个独立项。但这简洁背后有深意：$\nabla \log p(\mathbf{y})=0$ 能成立，是因为边际似然 $p(\mathbf{y})$ 相对 $\mathbf{x}_t$ 是常数。正是这个"常数无关性"，让得分函数天然绕过了贝叶斯公式里归一化常数的计算困难——和第5~6章得分匹配绕过配分函数的逻辑一模一样。这一转变意味着：**我们几乎免费地继承了一整套绕过归一化常数的机制**，上次它帮我们解决了"算不出配分函数"的难题，这次它帮我们扫清了"条件化"的障碍。

### 核心洞察：逆问题被拆成两个子问题

后验得分分解把逆问题求解拆成两个能分开处理的子问题：

| 子问题 | 对应项 | 状态 | 来源 |
|---|---|---|---|
| "数据长什么样？" | $\nabla \log p(\mathbf{x}_t)$ | **已解决** | 预训练扩散模型（第6~7章） |
| "和观测 $\mathbf{y}$ 是否一致？" | $\nabla \log p(\mathbf{y}\mid \mathbf{x}_t)$ | **未解决** | 需要近似（13.3节） |

这个拆解的意义：**我们不用为每个逆问题重训一个扩散模型**。预训练模型给的先验得分是通用的——同一个先验得分能配不同的似然得分，解不同的逆问题。这正是扩散解逆问题"零样本"优势（13.1节）的数学基础。

同时它也点明了本章核心技术挑战：**怎么近似算似然得分 $\nabla \log p(\mathbf{y}\mid \mathbf{x}_t)$**。所有条件扩散采样方法（DPS、ΠGDM、DDRM、DiffPIR…）的差异，本质上都来自对这个不可解量的不同近似策略。要理解似然得分为啥算不出，是看懂所有近似方法的前提。

## 实验 13.2-1：后验得分分解定理验证

实验 `13.2-1.py` 演示**1D高斯混合先验下，后验得分分解定理的数值验证**，通过三个独立计算的量验证 $\nabla \log p(\mathbf{x}_t\mid \mathbf{y}) = \nabla \log p(\mathbf{x}_t) + \nabla \log p(\mathbf{y}\mid \mathbf{x}_t)$ 的精确性。

### 实验场景

实验考虑1D去噪问题：$y = x + n$，$\sigma_\mathbf{y} = 0.5$，观测值 $y = 0.5$。先验分布为1D高斯混合 $p(\mathbf{x}) = 0.3\cdot \mathcal{N}(-2, 1) + 0.7\cdot \mathcal{N}(1, 1)$，使用VP-SDE框架。

验证方法采用**三个独立计算的量**进行双边验证：

1. **先验得分** $\nabla \log p(\mathbf{x}_t)$：由VP-SDE边际分布的解析解直接计算
2. **似然得分** $\nabla \log p(\mathbf{y}\mid \mathbf{x}_t)$：对归一化的 $p(\mathbf{y}\mid \mathbf{x}_t)$ 做中心有限差分，其中 $p(\mathbf{y}\mid \mathbf{x}_t) = \int p(\mathbf{y}\mid \mathbf{x}_0)p(\mathbf{x}_0\mid \mathbf{x}_t)dx_0$ 通过数值积分计算
3. **后验得分** $\nabla \log p(\mathbf{x}_t\mid \mathbf{y})$：独立对联合概率 $p(\mathbf{x}_t, \mathbf{y}) = p(\mathbf{x}_t)\cdot p(\mathbf{y}\mid \mathbf{x}_t)$ 做有限差分（$\nabla \log p(\mathbf{y})$ 不依赖 $\mathbf{x}_t$，故 $\nabla \log p(\mathbf{x}_t\mid \mathbf{y}) = \nabla \log p(\mathbf{x}_t, \mathbf{y})$）

验证在中心区域 $| x_t| < 3$ 内进行，排除尾部 $p(\mathbf{x}_t) \to 0$ 处的数值噪声。

### 实验目的

1. **数值验证后验得分分解定理**：确认 $\nabla \log p(\mathbf{x}_t\mid \mathbf{y}) = \nabla \log p(\mathbf{x}_t) + \nabla \log p(\mathbf{y}\mid \mathbf{x}_t)$ 在多个噪声水平 $t$ 下精确成立
2. **揭示归一化常数 $p(\mathbf{y})$ 的梯度为零**：这是得分函数天然绕过配分函数的核心机制
3. **验证三个独立计算路径的一致性**：先验得分（解析解）、似然得分（有限差分）、后验得分（独立有限差分）三路独立计算，确保验证的可靠性

### 实验输入

| 参数 | 设置 |
|------|------|
| 先验分布 | 1D高斯混合：$0.3\cdot \mathcal{N}(-2, 1) + 0.7\cdot \mathcal{N}(1, 1)$ |
| 噪声调度 | VP-SDE，$\beta_{\min}=0.1$，$\beta_{\max}=20.0$ |
| 逆问题 | 去噪：$y = x + n$，$\sigma_\mathbf{y} = 0.5$，$y_{\mathrm{obs}} = 0.5$ |
| 验证时刻 | $t \in \lbrace 0.1, 0.3, 0.5, 0.8\rbrace$ |
| 有限差分步长 | $\varepsilon = 10^{-4}$ |
| 验证区域 | $\lvert x_t\rvert < 3$（中心区域掩码） |

### 预期结果

- 分解公式在所有测试时刻 $t$ 下精确成立：$\max | \text{后验} - (\text{先验} + \text{似然})| < 10^{-3}$
- 误差主要来源于中心差分截断 $\mathcal{O}(\varepsilon^{2})$：步长 $\varepsilon =1e-4$ 时量级估计约 $10^{-8}$，但 $t$ 较小时得分函数三阶导较大，实测最大误差为 $5.15\times 10^{-7}$（比 $\varepsilon^{2}$ 粗估高一个量级多），仍远小于阈值 $10^{-3}$

## 13.2.3 似然得分 $\nabla \log p(\mathbf{y}\mid \mathbf{x}_t)$ 的计算挑战

### 不可直接计算的原因

似然得分看起来只是个梯度——为啥算不出？因为 $p(\mathbf{y}\mid \mathbf{x}_t)$ 本身就是个不可解的积分。

由全概率公式，$p(\mathbf{y}\mid \mathbf{x}_t)$ 可以展开：

$$p(\mathbf{y}|\mathbf{x}_t) = \int p(\mathbf{y}|\mathbf{x}_0)\,p(\mathbf{x}_0|\mathbf{x}_t)\,dx_0 = \mathbb{E}_{\mathbf{x}_0 \sim p(\mathbf{x}_0|\mathbf{x}_t)}[p(\mathbf{y}|\mathbf{x}_0)]$$

这个展开暴露了不可解性的两个来源：

**来源一**：$p(\mathbf{x}_0\mid \mathbf{x}_t)$ 没有闭式表达。后验 $p(\mathbf{x}_0\mid \mathbf{x}_t)$ 是"给定含噪状态 $\mathbf{x}_t$ 时干净数据 $\mathbf{x}_0$ 的条件分布"。虽然正向转移核 $p(\mathbf{x}_t\mid \mathbf{x}_0)$ 是简单高斯（SDE 结构保证），但逆向核 $p(\mathbf{x}_0\mid \mathbf{x}_t)$ 依赖数据分布 $p(\mathbf{x}_0)$ 的结构，一般没有闭式。

**来源二**：即便 $p(\mathbf{y}\mid \mathbf{x}_0)$ 很简单，积分仍不可解。最常见的线性高斯测量 $\mathbf{y} = Ax + n$，$n \sim \mathcal{N}(0, \sigma_\mathbf{y}^{2}I)$ 下，似然 $p(\mathbf{y}\mid \mathbf{x}_0) = \mathcal{N}(\mathbf{y}; Ax_0, \sigma_\mathbf{y}^{2}I)$ 是个简单高斯。但被复杂的后验 $p(\mathbf{x}_0\mid \mathbf{x}_t)$ 加权积分后，结果还是不可解——因为 $p(\mathbf{x}_0\mid \mathbf{x}_t)$ 的复杂性让积分化不开。

**根本原因**：$\mathbf{x}_t$ 到 $\mathbf{y}$ 的关系不是直接的——$\mathbf{x}_t$ 得先"去噪"到 $\mathbf{x}_0$，再经正向模型 $A$ 映射到测量空间。这条"去噪→映射"的两步链让 $p(\mathbf{y}\mid \mathbf{x}_t)$ 没法直接算，必须通过对 $\mathbf{x}_0$ 的积分 $p(\mathbf{x}_0\mid \mathbf{x}_t)$ 来搭桥。

> **类比**：你只知道"某个被严重打码的人"和"这个人是公安局档案里的人"。想知道"打码图 $\mathbf{x}_t$ 和证据 $\mathbf{y}$ 有多一致"，你得先脑补出"打码图对应哪个清晰人脸 $\mathbf{x}_0$"，再把清晰脸拿去比对证据。可"脑补"本身是个概率分布（同一个打码图可能对应好几个清晰脸），所以你得对**所有可能的清晰脸**求平均——这就是那个化不开的积分 $\int p(\mathbf{y}\mid \mathbf{x}_0)p(\mathbf{x}_0\mid \mathbf{x}_t)dx_0$。

### Tweedie 等式的关键角色

虽然 $p(\mathbf{x}_0\mid \mathbf{x}_t)$ 没闭式，但第5章的 **Tweedie 等式**给了它后验均值的闭式表达。这个后验均值是所有近似方法的共同起点。

**Tweedie 等式**（第5章 5.3，Chung et al. Theorem 1）：在高斯扰动核 $p(\mathbf{x}_t\mid \mathbf{x}_0) = \mathcal{N}(\mathbf{x}_t; s_t \mathbf{x}_0, \sigma_t^{2}I)$ 下，后验均值为：

$$\mathbb{E}[\mathbf{x}_0|\mathbf{x}_t] = \frac{1}{s_t}\left(\mathbf{x}_t + \sigma_t^2\,\nabla_{\mathbf{x}_t}\log p_t(\mathbf{x}_t)\right)$$

VP-SDE 下 $s_t = \sqrt{\bar\alpha_t}$，$\sigma_t^{2} = 1 - \bar\alpha_t$，所以：

$$\mathbb{E}[\mathbf{x}_0|\mathbf{x}_t] = \frac{\mathbf{x}_t + (1-\bar\alpha_t)\,\nabla_{\mathbf{x}_t}\log p_t(\mathbf{x}_t)}{\sqrt{\bar\alpha_t}}$$

用 ε 预测参数化 $\nabla_{\mathbf{x}_t}\log p_t(\mathbf{x}_t) = -\varepsilon_\theta(\mathbf{x}_t, t)/\sqrt{1-\bar\alpha_t}$（第11章 11.3），后验均值等价写成：

$$\hat{x}_{0|t} = \mathbb{E}[\mathbf{x}_0|\mathbf{x}_t] = \frac{\mathbf{x}_t - \sqrt{1-\bar\alpha_t}\,\varepsilon_\theta(\mathbf{x}_t, t)}{\sqrt{\bar\alpha_t}}$$

这个估计 $\hat{x}_{0\mid t}$ 是从含噪状态 $\mathbf{x}_t$ 出发，对干净数据 $\mathbf{x}_0$ 的 MMSE（最小均方误差）估计——是扩散模型在时刻 $t$ 对"原图长啥样"的最佳猜测。

### Tweedie 闭环：从得分到去噪再到修正得分

Tweedie 等式在似然得分近似里扮演枢纽角色，它搭起一条闭环计算链：

$$\underbrace{\nabla\log p_t(\mathbf{x}_t)}_{\text{得分函数}} \xrightarrow{\text{Tweedie}} \underbrace{\hat{x}_{0|t} = \mathbb{E}[\mathbf{x}_0|\mathbf{x}_t]}_{\text{去噪估计}} \xrightarrow{\text{正向模型}} \underbrace{\nabla_{\hat{x}_{0|t}}\ell(\hat{x}_{0|t})}_{\text{一致性梯度}} \xrightarrow{\text{链式法则}} \underbrace{\nabla_{\mathbf{x}_t}\log p(\mathbf{y}|\mathbf{x}_t)}_{\text{似然得分近似}}$$

闭环怎么转：

**第一步：得分函数 → 去噪估计。** 由 Tweedie 等式，预训练得分 $s_\theta(\mathbf{x}_t, t) \approx \nabla \log p_t(\mathbf{x}_t)$ 直接变成去噪估计 $\hat{x}_{0\mid t}$。这是先验得分的"副产品"——本来就有得分，Tweedie 免费给出去噪估计。

**第二步：去噪估计 → 一致性梯度。** 有了 $\hat{x}_{0\mid t}$，经正向模型算测量预测 $A(\hat{x}_{0\mid t})$，再算数据一致性损失 $\ell(\hat{x}_{0\mid t}) = \| \mathbf{y} - A(\hat{x}_{0\mid t})\|^{2}/(2\sigma_\mathbf{y}^{2})$ 及其梯度 $\nabla_{\hat{x}_{0\mid t}}\ell(\hat{x}_{0\mid t})$。

**第三步：一致性梯度 → 似然得分近似。** 链式法则把关于 $\hat{x}_{0\mid t}$ 的梯度回传到 $\mathbf{x}_t$，得到似然得分 $\nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_t)$ 的近似。

**第四步：似然得分近似 → 修正得分。** 近似后的似然得分加回先验得分，得到修正后的条件得分 $\nabla \log p(\mathbf{x}_t\mid \mathbf{y}) \approx \nabla \log p(\mathbf{x}_t) + \nabla \log p(\mathbf{y}\mid \mathbf{x}_t)$，驱动条件逆向 SDE 的下一步。

**第五步：回到第一步。** 新采样步产生新 $\mathbf{x}_t$，重算得分和去噪估计，循环。

这条闭环和第5章遥相呼应——第5章 Tweedie 连接去噪器和得分函数，实现"去噪→得分→采样"；条件扩散里 Tweedie 进一步连接去噪估计和似然得分，实现"得分→去噪→一致性→修正得分"。这正是 DPS 及其衍生算法的核心机制——13.3 节细展开。

### 去噪估计 $\hat{x}_{0\mid t}$ 的双重角色

$\hat{x}_{0\mid t}$ 在这条闭环里身兼两职：

1. **先验信息的载体**：它编码了扩散模型对"原图长啥样"的最佳估计，是先验知识的集中体现；
2. **似然得分的计算桥梁**：它把不可解积分 $p(\mathbf{y}\mid \mathbf{x}_t) = \int p(\mathbf{y}\mid \mathbf{x}_0)p(\mathbf{x}_0\mid \mathbf{x}_t)dx_0$ 变成可算的近似 $p(\mathbf{y}\mid \hat{x}_{0\mid t})$——用单点估计代替了整个积分。

所有近似方法——DPS 的 delta 函数近似 $p(\mathbf{x}_0\mid \mathbf{x}_t) \approx \delta(\mathbf{x}_0 - \hat{x}_{0\mid t})$、ΠGDM 的各向同性高斯近似 $p(\mathbf{x}_0\mid \mathbf{x}_t) \approx \mathcal{N}(\hat{x}_{0\mid t}, r_t^{2}I)$、Moment Matching 的完整协方差近似 $p(\mathbf{x}_0\mid \mathbf{x}_t) \approx \mathcal{N}(\hat{x}_{0\mid t}, \operatorname{Var}[\mathbf{x}_0\mid \mathbf{x}_t])$——都以 $\hat{x}_{0\mid t}$ 为起点。差别只在对 $p(\mathbf{x}_0\mid \mathbf{x}_t)$ 分布形状的近似精度。

从 delta 函数到各向同性高斯再到完整协方差，近似精度逐步提升，计算代价也逐步增加。这种精度-效率权衡，构成了 13.3 节方法分类的核心维度。

后验得分分解把条件扩散采样的核心挑战定位为似然得分 $\nabla \log p(\mathbf{y}\mid \mathbf{x}_t)$ 的近似计算，而 Tweedie 等式把这一挑战转化为对 $p(\mathbf{x}_0\mid \mathbf{x}_t)$ 的近似问题——所有方法都以去噪估计 $\hat{x}_{0\mid t}$ 为共同起点。系统梳理四类近似方法，从最简单的 DPS 到渐近精确的 MCMC 方法，能揭示它们在近似策略和精度-效率权衡上的差异。

## 实验 13.2-2：DPS的Tweedie闭环验证

实验 `13.2-2.py` 演示**DPS近似似然得分与精确似然得分的对比**，验证Tweedie闭环中delta函数近似的精度，以及含/忽略Jacobian项两种DPS变体的误差特征。

### 实验场景

实验考虑1D去噪问题：$y = x + n$，$\sigma_\mathbf{y} = 0.5$，$y = 0.5$。先验为1D高斯混合，使用VP-SDE框架。

DPS的核心近似是将不可解的积分 $p(\mathbf{y}\mid \mathbf{x}_t) = \int p(\mathbf{y}\mid \mathbf{x}_0)p(\mathbf{x}_0\mid \mathbf{x}_t)dx_0$ 用delta函数近似 $p(\mathbf{x}_0\mid \mathbf{x}_t) \approx \delta(\mathbf{x}_0 - \hat{x}_{0\mid t})$ 坍缩为单点求值：

$$p(\mathbf{y}|\mathbf{x}_t) \approx p(\mathbf{y}|\hat{x}_{0|t})$$

其中 $\hat{x}_{0\mid t}$ 由Tweedie等式给出。由此得到两种DPS似然得分近似：

- **含Jacobian项**：$\nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_t) \approx (\partial \hat{x}_{0\mid t}/\partial \mathbf{x}_t) \cdot \nabla_{\hat{x}_{0\mid t}}\log p(\mathbf{y}\mid \hat{x}_{0\mid t})$
- **忽略Jacobian项（保留一阶缩放）**：$\nabla_{\mathbf{x}_t}\log p(\mathbf{y}\mid \mathbf{x}_t) \approx \operatorname{mean}_t \cdot \nabla_{\hat{x}_{0\mid t}}\log p(\mathbf{y}\mid \hat{x}_{0\mid t})$；单位方差高斯先验下 $\partial \hat{x}_{0\mid t}/\partial \mathbf{x}_t = \operatorname{mean}_t$，所以这是“只丢 Jacobian 形状”的公平简化；若连 $\operatorname{mean}_t$ 也丢掉（旧版做法），就不是“仅忽略 Jacobian”了

### 实验目的

1. **验证Tweedie闭环的精度**：对比DPS近似似然得分与精确似然得分，揭示delta函数近似的误差特征
2. **比较含/忽略Jacobian形状的误差**：量化Jacobian形状对近似精度的贡献（两者都保留 $\operatorname{mean}_t$ 一阶缩放）
3. **揭示误差随噪声水平 $t$ 的变化规律**：高噪声时Tweedie估计不可靠，DPS近似误差增大

### 实验输入

| 参数 | 设置 |
|------|------|
| 先验分布 | 1D高斯混合：$0.3\cdot \mathcal{N}(-2, 1) + 0.7\cdot \mathcal{N}(1, 1)$ |
| 噪声调度 | VP-SDE，$\beta_{\min}=0.1$，$\beta_{\max}=20.0$ |
| 逆问题 | 去噪：$y = x + n$，$\sigma_\mathbf{y} = 0.5$，$y_{\mathrm{obs}} = 0.5$ |
| 验证时刻 | $t = 0.3$（似然得分对比），$t \in [0.05, 0.95]$（误差扫描） |
| 精确似然得分 | 对 $p(\mathbf{y}\mid \mathbf{x}_t)$ 数值积分 + 有限差分 |

### 预期结果

- DPS近似的似然得分方向基本正确（正负号绝大多数一致），但幅度系统性偏大
- 含Jacobian项的误差未必更小：真实Jacobian会把本已偏大的残差再放大；在主误差源（delta 近似忽略后验展宽）未被修正时，保留 $\operatorname{mean}_t$ 的简化反而可能更接近精确值
- 高噪声时（$t$ 大），Tweedie估计 $\hat{x}_{0\mid t}$ 不可靠，DPS近似误差增大——这解释了DPS在高噪声步需要更小引导权重 $\zeta$ 的实践策略

结果分析：

- **方向正确**：在精确得分幅度明显（$| \nabla \log p| > 10^{-3}$）的采样点中，仅 $x_t\approx 0.26$（精确得分过零附近的窄带）一个点变号，其余正负号均与精确值一致（符号一致率 99.5%，已写入 JSON），确保似然修正将采样推向正确方向
- **幅度系统性偏大**：含J 的 200 点中 99.5% 满足 $| \mathrm{DPS}| >| \text{精确}|$，表中相对误差 2.4–5.4 倍；忽略J（保留 $\operatorname{mean}_t$）也有 1.3–2.5 倍偏差。根源是 delta 近似忽略了 $p(\mathbf{x}_0\mid \mathbf{x}_t)$ 的展宽——真实得分相对“残差×Jacobian”多一个收缩因子 $\lambda = \sigma_\mathbf{y}^{2}/(\sigma_\mathbf{y}^{2}+A^{2}\operatorname{Var}[\mathbf{x}_0\mid \mathbf{x}_t]) < 1$
- **Jacobian 项：加回去反而更差**：截面上含J 的相对误差（2.45–5.41）普遍高于保留 $\operatorname{mean}_t$ 的变体（1.29–2.52）；t 扫描中 $t=0.95$ 时含J 误差 8.55、忽略J 仅 2.32。原因不是 Jacobian 算错，而是它把本已偏大的残差进一步放大，而主导误差（缺少后验方差收缩）未被消除。**旧版把 $\operatorname{mean}_t$ 也一并丢掉**，$t=0.95$ 时误差达 309——那是“两种缩放同时缺失”的叠加，不能拿来证明“Jacobian 项极其重要”
- **误差随 $t$ 增大**：忽略J（保留 $\operatorname{mean}_t$）从 0.12 平滑升至 2.32；含J 从 0.13 升至 8.55，但非单调——$t\approx 0.43$ 处因精确得分过零（≈−0.016）出现 26.4 的相对误差尖峰，属度量假象而非近似失效。趋势本身支持“高噪声时 Tweedie 估计不确定性增大、DPS 近似质量下降”——这是 13.4.3 节“时变引导权重”方案的直接动机

#### 核心知识点

本实验验证了13.2.3节Tweedie闭环的近似精度，揭示了DPS的核心局限：

1. **delta函数近似的精度-效率权衡**：DPS用单点 $\hat{x}_{0\mid t}$ 替代整个积分 $p(\mathbf{x}_0\mid \mathbf{x}_t)$，计算高效但引入幅度偏差。关键一点：**补上 Jacobian 形状并不能修正这一偏差**（本实验中反而更大）——主导误差是缺失的后验方差（收缩因子 $\lambda <1$）。更精确的近似（ΠGDM 的各向同性高斯、Moment Matching 的完整协方差）以更高计算代价换取更高精度
2. **Tweedie估计的双重角色**：$\hat{x}_{0\mid t}$ 既是先验信息的载体（"图像长什么样"），也是似然得分的计算桥梁（"与观测是否一致"）。当Tweedie估计不可靠时（高噪声），两个角色的精度同时下降
