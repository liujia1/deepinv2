# 12.3 结构对比：殊途为何同归？

> 核心观点：把 12.1 和 12.2 的终点并排，你会看到一个令人惊叹的事实——DSM 损失和 ε 预测 VLB 的核心结构**完全一致**，都是"预测加进去的噪声 ε"的 MSE，差异只在含噪输入的形式和时间权重。这种一致不是巧合，它说明两种推导正在趋同。权重选得当时，两者精确等价。
>
> **本节定位（直觉层）**：这里是等价性的**直觉与结构对照**，不做完整代数证明。两边的确切逐项等价由下一节 12.4 严格给出（离散时间），连续时间版本在附录 12A。读本节时牢牢记住一句话即可：**两边的差异只剩"时间权重"，而权重可以互相匹配。**

先玩一个**"猜猜看"**的小游戏。

假如我告诉你：学界有两组人，一组从"逆问题后验采样"出发，另一组从"生成模型最大似然"出发，用了完全不同的数学工具，翻了不同的山头。现在我问你——

> **他们各自训练出来的扩散模型，训练目标（损失函数）会是什么样子？**

你很可能会猜：既然出发点、工具、哲学全都不一样，**训练目标应该长得迥然不同吧**？一组在优化"概率梯度"，另一组在优化"概率值"，怎么可能相同？

但答案会让你一愣：**两者的核心结构一模一样，都是"预测加进去的噪声 ε"的均方误差，只差一个时间权重。** 这不是近似，是在结构上逐字对应。下面我们把两张"答案纸"摊开看。

---

## 一、两个损失函数的并排对比

把 DSM 损失（采样路径终点）和 ε 预测 VLB（变分路径终点）放进同一张表：

| 维度 | DSM 损失（采样路径） | ε 预测 VLB（变分路径） |
|---|---|---|
| **噪声变量** | $\sigma$（噪声水平） | $t$（时间步，对应 $\sqrt{1-\bar{\alpha}_t}$） |
| **含噪输入** | $\mathbf{x}_0 + \sigma\varepsilon$ | $\sqrt{\bar{\alpha}_t}\mathbf{x}_0 + \sqrt{1-\bar{\alpha}_t}\varepsilon$ |
| **预测目标** | $\varepsilon$（添加的噪声） | $\varepsilon$（添加的噪声） |
| **核心结构** | $\|\varepsilon - \varepsilon_\theta(\cdot)\|^2$ | $\|\varepsilon - \varepsilon_\theta(\cdot)\|^2$ |
| **时间权重** | $\lambda(\sigma)/\sigma^2$ | $w_t = \frac{\beta_t^2}{2\tilde{\beta}_t\alpha_t(1-\bar{\alpha}_t)}$ |
| **噪声/时间采样** | $\sigma \sim p(\sigma)$（噪声调度） | $t \sim \mathcal{U}\{1,T\}$（均匀） |
| **推导起点** | 得分函数 $\nabla\log p$ | 对数似然 $\log p$ |
| **理论框架** | Tweedie 等式 + 得分匹配 | ELBO + 变分推断 |

### 观察 1：预测目标完全相同

两张"答案纸"的核心都是 $\|\varepsilon - \varepsilon_\theta(\text{含噪输入}, \text{条件})\|^2$——都在猜加进去的那份噪声 $\varepsilon$。

为什么是同一个目标？因为 Tweedie 等式告诉我们：得分函数、去噪器残差、噪声预测，是同一信息的三种编码：

$$\underbrace{\nabla\log p_\sigma(\mathbf{x})}_{\text{边际得分函数}} = \underbrace{\frac{D_\sigma(\mathbf{x}) - \mathbf{x}}{\sigma^2}}_{\text{去噪器残差（Tweedie）}} \quad\longleftrightarrow\quad \underbrace{-\frac{\varepsilon}{\sigma}}_{\text{条件得分（DSM 目标）}}$$

左边两项是边际分布 $p_\sigma$ 的得分（由 Tweedie 等式成立），右边是 DSM 训练用的条件得分目标。三者靠 Tweedie 等式和 @vincent2011stacked 的 DSM 等价性串在一起。

**所以你看到的现象是**：采样路径从得分函数出发，变分路径从 ELBO 出发，兜了一大圈，却都发现了"预测噪声"这个共同语言。

### 观察 2：含噪输入的形式可以统一

DSM 用 $\mathbf{x}_0 + \sigma\varepsilon$（加性噪声，VE-SDE），VLB 用 $\sqrt{\bar{\alpha}_t}\mathbf{x}_0 + \sqrt{1-\bar{\alpha}_t}\varepsilon$（缩放加性噪声，VP-SDE）。两种写法可以塞进 @karras2022edm 的统一参数化：

$$\mathbf{x}_t = s(t)\,\mathbf{x}_0 + s(t)\,\sigma(t)\,\varepsilon$$

- VE-SDE：$s(t) = 1$，$\sigma(t) = \sigma_t$
- VP-SDE：$s(t) = \sqrt{\bar{\alpha}_t}$，$\sigma(t) = \sqrt{(1-\bar{\alpha}_t)/\bar{\alpha}_t}$

统一之后，含噪输入的差异只是参数化的选择，不影响等价性本身。

### 观察 3：差异仅在于时间权重

两个损失唯一的实质差别，就是时间权重：

- DSM：$\lambda(\sigma)/\sigma^2$（由权重函数 $\lambda$ 决定）
- VLB：$w_t = \frac{\beta_t^2}{2\tilde{\beta}_t\alpha_t(1-\bar{\alpha}_t)}$（由噪声调度决定）

**当权重匹配时，两个目标精确等价。** 这引出下面的等价性条件。

---

## 二、权重匹配与等价性条件

### 情况 1：简化 VLB ≡ 简化 DSM

当 $\lambda(\sigma) = \sigma^2$（NCSN 的默认选择），DSM 权重退化：

$$\frac{\lambda(\sigma)}{\sigma^2} = \frac{\sigma^2}{\sigma^2} = 1$$

此时 DSM 目标就是均匀加权的"猜噪声"MSE，和简化 VLB $L_\text{simple} = \mathbb{E}[\|\varepsilon - \varepsilon_\theta\|^2]$ **完全一致**。

**注意**：这正是 @ho2020ddpm 在 DDPM 论文里点破的——"某个参数化揭示，扩散模型的训练等价于多噪声水平的去噪得分匹配"。DDPM 的简化训练目标，就是 NCSN 的去噪得分匹配目标。这不再只是"结构相似"，而是**同一个目标**。

### 情况 2：加权 DSM ≡ 完整 VLB

选 $\lambda(t)$ 让 DSM 权重去匹配 VLB 权重：

$$\frac{\lambda(t)}{2(1-\bar{\alpha}_t)} = w_t = \frac{\beta_t^2}{2\tilde{\beta}_t\alpha_t(1-\bar{\alpha}_t)}$$

解得 $\lambda(t) = \frac{\beta_t^2}{\tilde{\beta}_t\alpha_t} = \frac{\beta_t(1-\bar{\alpha}_t)}{(1-\bar{\alpha}_{t-1})\alpha_t}$，此时

$$\mathcal{J}_\text{DSM}(\theta) = L_\text{VLB}(\theta) + \text{const}$$

两个目标的最优解完全相同——**DSM ≡ VLB**。

### 等价性的本质

权重匹配暴露了真相：DSM 和 VLB 优化的是**同一个目标函数**——预测噪声的 MSE——只是从不同的理论路径推出来，所以对时间步的加权方式不同。加权方式一旦对齐，两个目标在数学上就不可区分了。

> **从更深层次看**，这两个损失在写出来的那一刻是"不同的式子"，但在最优解的意义上却是"同一道题"。权重只是给"猜噪声"这个共同任务在哪些时间步上加多少重视，解得开它，前进的方向就是同一个。这一转变意味着，我们无需在"得分匹配"与"变分推断"两套哲学之间做选择——它们只是同一目标的两副外表。

## 实验 12.3-1：DSM 与 VLB 结构对比——殊途为何同归（数值验证）

实验 `12.3-1.py` 演示**采样路径（DSM）与变分路径（VLB）损失结构的并排对比**，通过 VP-SDE 噪声调度表、Karras 统一参数化数值对照、以及权重匹配曲线的可视化，数值验证本节三个关键观察；并把"噪声调度如何造出 $w_t$ 的形状"画成一条因果链。

### 实验场景

实验使用 DDPM 线性噪声调度（$T=1000$，$\beta_{\min}=10^{-4}$，$\beta_{\max}=0.02$），在 VP-SDE 设定下对比两条路径的损失结构：

**DSM 损失**（采样路径）：$\mathcal{J}_\text{DSM}(\theta) = \sum_i \frac{\lambda(\sigma_i)}{\sigma_i^2} \cdot \mathbb{E}[\|\varepsilon - \varepsilon_\theta(\mathbf{x}_0+\sigma_i\varepsilon, \sigma_i)\|^2]$

**VLB 损失**（变分路径）：$L_\text{VLB}(\theta) = \sum_t w_t \cdot \mathbb{E}[\|\varepsilon - \varepsilon_\theta(\mathbf{x}_t, t)\|^2]$，其中 $w_t = \frac{\beta_t^2}{2\tilde{\beta}_t\alpha_t(1-\bar{\alpha}_t)}$

两条路径的核心结构均为 $\|\varepsilon - \varepsilon_\theta(\text{含噪输入}, \text{条件})\|^2$，差异仅在于含噪输入的形式和时间权重。

> **记法说明**：本实验在 VP-SDE 下把 "$\sigma_t^2$" 用作扰动噪声方差 $1-\bar{\alpha}_t$（即有效噪声幅度 $\sigma_t = \sqrt{1-\bar{\alpha}_t}$），而非 SNR 意义下的 $(1-\bar{\alpha}_t)/\bar{\alpha}_t$（后者在 12.4 与附录 12B 中用到）。正是在这一约定下，匹配后的 DSM 权重 $\lambda(t)/\sigma_t^2 = \lambda(t)/(1-\bar{\alpha}_t)$ 才与 VLB 权重 $w_t$ 成精确的 2.0 常数比。

### 实验目的

1. **验证本节三个关键观察**：预测目标相同、含噪输入可统一、差异仅在权重
2. **展示 Karras 统一参数化消除含噪输入的形式差异**：VE-SDE 和 VP-SDE 只是 $(s, \sigma)$ 的不同取值
3. **数值验证权重匹配条件**：当 $\lambda(t) = \frac{\beta_t(1-\bar{\alpha}_t)}{(1-\bar{\alpha}_{t-1})\alpha_t}$ 时，DSM 权重与 VLB 权重重合
4. **展示 VLB 权重的量级与形状特征**：跨越约 2 个数量级，与简化目标的均匀权重形成对比；并把 $\beta_i\to\bar{\alpha}_i\to\mathrm{SNR}_i\to w_i$ 的因果链拆开画

### 实验输入

| 参数 | 设置 |
|------|------|
| 噪声调度 | DDPM 线性，$T=1000$，$\beta_{\min}=10^{-4}$，$\beta_{\max}=0.02$ |
| 展示时间步 | $t \in \{1, 10, 50, 100, 250, 500, 750, 999\}$ |
| 权重匹配条件 | $\lambda(t) = \beta_t(1-\bar{\alpha}_t) / [(1-\bar{\alpha}_{t-1})\alpha_t]$ |
| 对比目标 | DSM 权重 $\lambda(t)/(1-\bar{\alpha}_t)$（此处 $\sigma_t^2 = 1-\bar{\alpha}_t$） vs VLB 权重 $w_t$ vs 简化目标权重 $=1$ |
| 图表 | `DSM与VLB结构对比.png`（两者重合）；`调度与权重演化.png`（$\beta_i\to\bar{\alpha}_i\to\mathrm{SNR}_i\to w_i$） |

### 预期结果

- VP-SDE 噪声调度表展示 $\bar{\alpha}_t$、$\sigma_t = \sqrt{1-\bar{\alpha}_t}$、$\text{SNR}_t$ 随时间步的演化
- 因果链图展示 $\beta_i$ 线性增长 $\to$ $\bar{\alpha}_i$ 累乘衰减 $\to$ $\mathrm{SNR}_i$ 单调跨越 8.4 个数量级（$\mathrm{SNR}=1$ 在下标 $i=258$）$\to$ $w_i$ 呈 L 形并在末端回升
- Karras 参数化数值对照表展示 VP-SDE 在相同时间步下的 $s(t)$、Karras 噪声水平 $\sigma(t)$ 与实际边际噪声 $s(t)\sigma(t)$ 取值（VE-SDE 下 $s=1$，后两者相同）
- 权重匹配验证：DSM 权重与 VLB 权重在缩放后完全重合（比值恒为 2.0，偏差在浮点误差范围内）
- VLB 权重跨越约 2 个数量级，简化目标为均匀权重 1

## 三、直觉解释：等价性为何必然？

结构对比让我们"看见"了等价。但**为什么**两条完全不同的路会给出同一个目标？答案藏在得分函数和对数似然的根本关系里。

### 梯度与函数值的信息等价性

$$\nabla\log p(\mathbf{x}) = \text{概率分布的"梯度信息"}$$
$$\log p(\mathbf{x}) = \text{概率分布的"函数值信息"}$$

对一个光滑函数，**梯度信息和函数值信息是等价的**：

- 知道梯度 $\nabla\log p(\mathbf{x})$（处处），积分就能得函数值 $\log p(\mathbf{x})$（差一个常数）；
- 知道函数值 $\log p(\mathbf{x})$（处处），微分就能得梯度 $\nabla\log p(\mathbf{x})$。

DSM 优化的是梯度信息——逼模型准确估计 $\nabla\log p_t(\mathbf{x})$；VLB 优化的是函数值信息——逼模型给数据高 $\log p(\mathbf{x}_0)$。既然两者是同一分布的两种表示，优化一个就等于优化另一个。

### 一个一维小类比（先猜后揭）

考虑一维函数 $f(\mathbf{x})$。两个目标：

1. **目标 A**：找 $g(\mathbf{x})$ 使 $g(\mathbf{x}) \approx f'(\mathbf{x})$（逼近导数）
2. **目标 B**：找 $h(\mathbf{x})$ 使 $h(\mathbf{x}) \approx f(\mathbf{x})$（逼近函数值）

如果 $g(\mathbf{x}) = h'(\mathbf{x})$，那么：

- 逼近导数好 → 积分得函数值也接近（差常数）
- 逼近函数值好 → 微分得导数也接近

**这就是 DSM ≡ VLB 的本质**：得分函数是概率分布的"导数"，ELBO 是概率分布的"函数值"。你之前猜"梯度目标和值目标应该迥然不同"——现在揭晓：它们是同一座山的两种地图。

### 从 Tweedie 等式看等价性的根源

Tweedie 等式是等价性的核心枢纽：

$$\nabla\log p_\sigma(\mathbf{x}) = \frac{D_\sigma(\mathbf{x}) - \mathbf{x}}{\sigma^2}$$

- **采样路径**：Tweedie 把去噪器 $D_\sigma$ 转成得分函数 $\nabla\log p_\sigma$，用来驱动 Langevin / 扩散采样；
- **变分路径**：同一个去噪器 $D_\sigma$（经 ε 预测参数化）用来构造逆向过程 $p_\theta(\mathbf{x}_{t-1}|\mathbf{x}_t)$，最大化 ELBO。

两条路径**交汇于去噪器**——它同时扛着得分信息（采样路径）和似然信息（变分路径）。Tweedie 等式保证这两种信息其实是同一数学对象的不同表示。

### 信息论视角：两个"得分"必须分清

从信息论看：

- $\log p(\mathbf{x})$ 衡量"模型给数据 $\mathbf{x}$ 赋予了多少信息量"（负自信息）；
- $\nabla_{\mathbf{x}}\log p(\mathbf{x})$（数据得分）衡量"信息量在**数据空间**里随位置变化的速率和方向"。

但接下来必须把两个长得很像的"得分"分开，否则公式会写错：

| | 定义 | 对谁求导 | 出现在哪里 |
|---|---|---|---|
| **数据得分** | $\mathbf{s}_\theta(\mathbf{x}) = \nabla_{\mathbf{x}}\log p_\theta(\mathbf{x})$ | 数据 $\mathbf{x}$ | DSM、Tweedie、逆向 SDE |
| **参数得分** | $\nabla_\theta \log p_\theta(\mathbf{x})$ | 参数 $\theta$ | 费舍信息 |

费舍信息矩阵（费舍信息：衡量"数据能多大程度区分模型参数"的量）是**参数得分**的外积期望：

$$\mathcal{I}(\theta) = \mathbb{E}_{p_\theta}\left[\nabla_\theta\log p_\theta(\mathbf{x})\,\nabla_\theta\log p_\theta(\mathbf{x})^\top\right] = -\mathbb{E}_{p_\theta}\left[\nabla_\theta^2\log p_\theta(\mathbf{x})\right]$$

（第二个等号在正则条件下成立）它刻画对数似然曲面在最优点附近的**曲率**，因此一个参数扰动 $\delta\theta$ 造成的 KL 散度可以二阶近似为

$$D_{\text{KL}}(p_\theta\|p_{\theta+\delta\theta}) \approx \frac{1}{2}\delta\theta^\top \mathcal{I}(\theta)\,\delta\theta$$

两个得分什么时候会重合？当 $\theta$ 是**位置参数**时：若 $p_\theta(\mathbf{x}) = q(\mathbf{x}-\theta)$，则 $\nabla_\theta\log p_\theta = -\nabla_{\mathbf{x}}\log p_\theta$，两者只差一个符号，此时 $\mathcal{I}(\theta) = \mathbb{E}[\mathbf{s}\mathbf{s}^\top]$。所以"费舍信息是得分的外积期望"这句话只有在位置族这个特例下，才对**数据得分**成立；一般模型里不成立（尺度族就是反例：$p_\theta=\mathcal{N}(0,\theta^2)$ 时 $\mathcal{I}(\theta)=2/\theta^2$，而 $\mathbb{E}[(\nabla_x\log p)^2]=1/\theta^2$）。

**这条线索能说清什么、不能证明什么**：它解释了为什么"得分估得准"与"似然曲面的形状对"是同一件事的两面——得分是似然的梯度，费舍信息是参数梯度的二阶矩。但它**不能**用来证明 DSM ≡ VLB：那里比较的是两个**损失函数**（同一个 $\|\varepsilon-\varepsilon_\theta\|^2$ 配两种时间权重），是逐项的代数恒等，而不是参数空间里的局部近似。严格证明在下一节：把 VLB 每一步的 KL 展开成 $\|\varepsilon-\varepsilon_\theta\|^2$，再与 DSM 的权重对齐。

直觉已经站得住脚了。下一节，我们把这份直觉升级成严格的数学证明——DSM 损失 ≡ 变分下界。
