# 12.5 连续时间视角的统一

> 核心观点：离散时间的等价性，在连续时间极限下获得更深刻的形式。SDE 框架（采样路径）与 VDM 框架（变分路径）在连续时间下完全统一：连续时间 VLB 的权重与连续时间 DSM 的权重天然一致，概率流 ODE 提供了两条路径的第三种交汇方式。DDPM、Score-SDE、VDM 三者，是同一数学框架在不同约束下的特例。

上一节我们在离散时间下把 DSM ≡ VLB 坐实了。但你可能会想：**离散时间毕竟是近似——时间步切得粗，会不会掩盖了什么？** 好问题。这一节我们把时间步数 $T\to\infty$，看等价性在连续极限下是不是更干净、更本质。

**路标句**：第12章是全书必经之地，只有到这，统一才完整显现——而连续时间视角，让这个"统一"从"巧合"升级为"必然"。

---

## 一、SDE 形式：采样路径的连续极限

第7章 7.2–7.3 节建起了扩散模型的 SDE 框架。正向 SDE（正向 SDE：描述含噪图随时间被噪声逐步侵蚀的随机微分方程）：

$$dx = f(x,t)\,dt + g(t)\,dw$$

$f(x,t)$ 是漂移系数，$g(t)$ 是扩散系数。由 Anderson (1982) 定理，逆向 SDE 为：

$$dx = [f(x,t) - g(t)^2\nabla_x\log p_t(x)]\,dt + g(t)\,d\bar{w}$$

其中 $\bar{w}$ 是逆向时间的维纳过程，$\nabla_x\log p_t(x)$ 是时间 $t$ 处的得分函数。

### 连续时间得分匹配训练

逆向 SDE 的核心是得分函数 $\nabla\log p_t(x)$——通过连续时间得分匹配训练。连续时间 DSM 目标：

$$\mathcal{J}_\text{DSM}^\text{cont}(\theta) = \frac{1}{2}\int_0^T \lambda(t)\,\mathbb{E}_{x_0}\mathbb{E}_{\epsilon}\left[\left\|s_\theta(x_t, t) + \frac{\epsilon}{\sigma(t)}\right\|^2\right]dt$$

$\lambda(t)$ 是连续时间权重函数，$\sigma(t)$ 是时间 $t$ 处的有效噪声水平。变量含义上，$\sigma(t)$ 承担"此刻噪声有多强"的度量，而 $\lambda(t)$ 承担"此刻的学习该被多重视"的度量——两者共同决定连续时刻的训练信号强度。

换成 ε 预测参数化：

$$\mathcal{J}_\text{DSM}^\text{cont}(\theta) = \frac{1}{2}\int_0^T \frac{\lambda(t)}{\sigma^2(t)}\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]dt$$

> **记法说明**：这里的 $\sigma(t)$ 指含噪样本 $x_t$ 相对 $x_0$ 的扰动噪声标准差（在 VP-SDE 下即 $\sqrt{1-\bar\alpha(t)}$，故 $\sigma^2(t) = 1-\bar\alpha(t)$），这样才与条件得分目标 $-\epsilon/\sigma(t)$ 的分母一致。这与 12.4 中"VE-SDE 下分母 $\sigma^2$、VP-SDE 下分母 $1-\bar\alpha$"的分工相同。正因常数倍不影响最优解，后续的匹配在哪种记号下展开都不改变结论。

## 二、VDM 形式：变分路径的连续极限

Kingma (2021) 在变分扩散模型（VDM）框架下推导了连续时间 ELBO。把离散时间步数 $T\to\infty$，求和变积分：

$$\log p(x_0) \geq \text{ELBO}^\text{cont}$$

连续时间 ELBO 的结构和离散版类似，分三项：

1. **先验匹配项**：$\mathbb{E}_q[\log p(x_T)/q(x_T|x_0)]$，无训练参数；
2. **一致性积分**：$\int_0^T \mathbb{E}_q\left[\frac{1}{2}\left\|\frac{\mu_\theta(x_t,t) - \tilde\mu_t(x_t,x_0)}{\sigma_t}\right\|^2\right]dt$；
3. **重建项**：$\mathbb{E}_q[\log p_\theta(x_0|x_\epsilon)]$。

### 连续时间一致性项的 ε 预测展开

在 ε 预测参数化下，连续时间一致性项变为：

$$\int_0^T w(t)\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]dt$$

$w(t)$ 是连续时间权重，由正向 SDE 的参数（漂移 $f$、扩散 $g$）确定。

## 三、等价性的连续时间表述

### 权重函数的连续化

离散时间的等价性条件 $\lambda(\sigma_t)/\sigma_t^2 = w_t$，在连续时间下变成：

$$\frac{\lambda(t)}{\sigma^2(t)} = w(t)$$

Kingma (2021) 证明：在连续时间下，**三种参数化（ε 预测、$x_0$ 预测、得分预测）的 VLB 权重自动一致**——不像离散时间里因为数值近似产生微小差异。

> **从更深层次看**，离散版本里三种参数化权重只是"近似一致"，而连续版本里是"严格一致"——离散化是引入微小差异的唯一来源。这一转变意味着，连续时间是天然的理论基准：所有因离散化产生的"权重差异"在这里都自然消失，只剩下本质结构。

### 连续时间等价性定理

**定理（连续时间 DSM ≡ 连续时间 VLB）**：在连续时间下，选 $\lambda(t) = \sigma^2(t)\cdot w(t)$，则

$$\mathcal{J}_\text{DSM}^\text{cont}(\theta) = L_\text{VLB}^\text{cont}(\theta) + \text{const}$$

与离散时间相比，连续时间的等价性更"干净"——不存在因离散化带来的近似误差。

### 证明概要

思路和离散版一样，只是在积分框架下走一遍：

1. 从连续时间 ELBO 出发，把一致性积分展开成 ε 预测形式；
2. 从连续时间 DSM 出发，同样展开成 ε 预测形式；
3. 比较两个积分的权重函数 $w(t)$ 和 $\lambda(t)/\sigma^2(t)$；
4. 权重匹配时，两个积分逐点相等。

详细证明见附录 12A。

## 四、概率流 ODE：两条路径的第三种交汇

### 从 Fokker-Planck 到 PF-ODE

第7章 7.4 节从 Fokker-Planck 方程推导了概率流 ODE（PF-ODE，概率流常微分方程：把随机的逆向 SDE 换成一条确定的轨迹，但保持相同的边际分布）：

$$dx = \left[f(x,t) - \frac{1}{2}g(t)^2\nabla_x\log p_t(x)\right]dt$$

PF-ODE 把随机的逆向 SDE 变成确定性 ODE，却保持相同的边际分布 $p_t(x)$。

### PF-ODE 的变分视角

PF-ODE 也能从变分框架推导。连续归一化流（CNF）定义为：

$$\frac{\partial p_t(x)}{\partial t} = -\nabla\cdot(v_t(x)\,p_t(x))$$

$v_t(x)$ 是向量场。当 $v_t(x) = f(x,t) - \frac{1}{2}g^2(t)\nabla\log p_t(x)$ 时，CNF 的边际分布与逆向 SDE 一致。

从变分角度看，PF-ODE 定义了一个从噪声到数据的确定性映射，其似然可通过瞬时变量变换精确计算：

$$\log p(x_0) = \log p(x_T) + \int_0^T \nabla\cdot v_t(x_t)\,dt$$

这给出了 $\log p(x_0)$ 的**精确值**（而非下界），前提是向量场 $v_t$ 和真实得分一致。

### 三种采样方式的统一

PF-ODE 提供了 SDE 框架与变分框架的交汇点：

| 采样方式 | 来源 | 随机性 | 似然计算 |
|---|---|---|---|
| 逆向 SDE | 采样路径（Anderson 定理） | 随机 | 不可直接计算 |
| DDPM 采样 | 变分路径（离散逆向） | 半随机 | VLB 下界 |
| PF-ODE/DDIM | 两条路径的交汇 | 确定性 | 精确（瞬时变换） |

**DDIM = PF-ODE 的离散化**——第7章 7.5 节已建立这层对应。从变分角度看，DDIM 是一个确定性解码器，每步是 ODE 的 Euler 步，而非随机 SDE 步。

> **这一转变意味着**：当随机逆向 SDE 被换成确定性轨迹后，"似然"从"只能给下界"变成了"可以算精确值"。也就是说，采样路径与变分路径不仅共享训练目标，连"如何评估模型的似然"也通过 PF-ODE 走到了一起——这是除 DSM≡VLB 之外的另一条统一纽带。

## 五、三方统一：DDPM、Score-SDE、VDM

通过 12.4 的等价性证明和本节的连续时间统一，三种主要框架可统一为同一理论在不同约束下的特例：

**VDM 框架**（Kingma 2021）最一般，包含：

- **可优化的噪声调度**：$\beta_t$ 或等价的 $(s(t), \sigma(t))$ 可作为可训练参数；
- **连续时间 ELBO**：训练目标是严格的最大似然下界；
- **三种参数化统一**：ε 预测、$x_0$ 预测、得分预测在连续时间下等价。

**DDPM** 是 VDM 在以下约束下的特例：

- **固定噪声调度**：$\beta_t$ 预先设定（线性或余弦）；
- **离散时间 VLB**：训练目标通常用简化 VLB；
- **VP-SDE 参数化**。

**Score-SDE** 是 VDM 在以下约束下的特例：

- **固定 SDE**：$f(x,t)$、$g(t)$ 预先设定；
- **得分匹配训练**：训练目标是 DSM 损失；
- **VE-SDE 或 VP-SDE 参数化**。

### 统一框架的意义

1. **选哪个框架只是工程偏好**：DDPM、Score-SDE、VDM 在数学上等价；
2. **训练目标的选择才是本质**：简化 VLB vs 完整 VLB vs 自定义权重，才是影响模型性能的关键决策；
3. **连续时间是理解的理论基准**：离散时间的近似误差，可由连续时间分析来理解。

> **从更深层次看**，三方统一揭示了一个更一般的事实：形形色色的扩散模型不是"好几套理论"，而是同一套理论在不同约束（固定调度多少、是否可训练、离散还是连续）下的切片。这一转变意味着，"殊途同归"的最后一块拼图来自框架层——连框架间的差异，也只是约束选择造成的。

等价性在理论和连续时间层面都已立住。但它对实践到底意味着什么？下一节谈训练目标怎么选、权重怎么影响模型表现。

## 六、动手感受一下：连续时间权重确实自动匹配（可运行代码）

下面这段重度注释的 numpy 代码，用一个最简的 VP-SDE 连续时间噪声调度，验证本节核心事实：**只要选 $\lambda(t) = \sigma^2(t)\cdot w(t)$，连续时间 DSM 与 VLB 的权重逐点相等（仅差常数倍）**。纯 numpy 就能跑。

```python
# -*- coding: utf-8 -*-
# 第12.5章 复现：连续时间下 DSM 权重 ≡ VLB 权重
# 目标：在连续时间 VP-SDE 下，验证"选 λ(t) = σ²(t)·w(t) 时，两框架权重逐点相等"
# 需要：numpy（可选 matplotlib 画图）

import numpy as np

# ---------- 0. 设定：连续时间 VP-SDE 的 (s(t), σ(t)) ----------
# 离散时间 VP-SDE：x_t = √ᾱ_t·x0 + √(1-ᾱ_t)·ε
# 连续时间版：把 ᾱ_t 推广成 ᾱ(t)，令 t ∈ [0, 1]（0=数据，1=纯噪声）
# 为简单起见，我们用离散的 T 步来近似连续函数，并直接数值微分。

T = 1000
t = np.linspace(0.0, 1.0, T)                       # 时间网格
betas = np.linspace(1e-4, 0.02, T)                 # 线性噪声调度 β(t)
alphas = 1.0 - betas
bar_alpha = np.cumprod(alphas)                     # ᾱ(t)
one_minus_bar = 1.0 - bar_alpha

# 连续时间 VP-SDE 的有效噪声水平 σ²(t) = (1-ᾱ(t))/ᾱ(t)
sigma2 = one_minus_bar / bar_alpha

# ---------- 1. 连续时间 VLB 权重 w(t) ----------
# 离散权重 w_t = β_t² / [2 β̃_t α_t (1-ᾱ_t)]，β̃_t = (1-ᾱ_{t-1})β_t/(1-ᾱ_t)
# 连续化：用数值微分 dᾱ/dt 近似，Kingma (2021) 给出
#   w(t) ≈ 0.5 · (dᾱ/dt) / [(1-ᾱ)·α]
d_bar_alpha = np.gradient(bar_alpha, t)            # dᾱ/dt，数值微分
w_cont = 0.5 * d_bar_alpha / (one_minus_bar * alphas)

# ---------- 2. 连续时间 DSM 权重 ----------
# 连续 DSM 权重 = λ(t) / [2 σ²(t)]；我们按定理选 λ(t) = σ²(t)·w(t)
lambda_t = sigma2 * w_cont                         # 定理要求的 λ(t)
dsm_weight_cont = lambda_t / (2.0 * sigma2)        # = w(t)/2，理论上

# ---------- 3. 检查：两者是否逐点相等（差一个常数 1/2） ----------
print("连续时间权重匹配检查（前 5 步）：")
for i in [0, 1, 10, 100, 500]:
    print(f"  t={t[i]:.3f}  w(t)={w_cont[i]:.4f}  dsm_weight={dsm_weight_cont[i]:.4f}  "
          f"比值={dsm_weight_cont[i]/w_cont[i]:.6f}")

# 你会发现 dsm_weight_cont / w_cont 处处 ≈ 0.5 —— 即两框架权重仅差常数倍 1/2，
# 这正是 "连续时间 DSM ≡ 连续时间 VLB（仅差常数）" 的数值化身。

# ---------- 4. 把比值画出来（可选） ----------
try:
    import matplotlib.pyplot as plt
    plt.figure(figsize=(6, 3))
    plt.plot(t, w_cont, label="VLB 权重 w(t)")
    plt.plot(t, dsm_weight_cont * 2.0, '--', label="DSM 权重 λ/(2σ²) × 2")
    plt.xlabel("t"); plt.ylabel("权重")
    plt.legend(); plt.title("连续时间：DSM 权重与 VLB 权重逐点重合（×2 后）")
    plt.tight_layout(); plt.show()
except Exception as e:
    print("（未安装 matplotlib，跳过画图；数值检查已足够说明问题）")
```

**怎么读这段代码**：第 1 段把离散 VP-SDE 的 $\bar\alpha(t)$ 推广成时间上的连续函数，再用数值微分算 $d\bar\alpha/dt$。第 2 段按本节的定理取 $\lambda(t)=\sigma^2(t)\cdot w(t)$，算出连续 DSM 权重。第 3 段打印比值——你会看到 DSM 权重与 VLB 权重处处只差常数倍 1/2。也就是说，在连续时间下，两个框架"说同一种语言"是逐点成立的，没有任何离散化误差来捣乱。
