# 12.5 连续时间视角的统一

> 核心观点：离散时间的等价性，在连续时间极限下获得更深刻的形式。SDE 框架（采样路径）与 VDM 框架（变分路径）在连续时间下完全统一：连续时间 VLB 的权重与连续时间 DSM 的权重天然一致，概率流 ODE 提供了两条路径的第三种交汇方式。DDPM、Score-SDE、VDM 三者，是同一数学框架在不同约束下的特例。

上一节我们在离散时间下把 DSM ≡ VLB 坐实了。但你可能会想：**离散时间毕竟是近似——时间步切得粗，会不会掩盖了什么？** 好问题。这一节我们把时间步数 $T\to\infty$，看等价性在连续极限下是不是更干净、更本质。

**路标句**：第12章是全书必经之地，只有到这，统一才完整显现——而连续时间视角，让这个"统一"从"巧合"升级为"必然"。

---

## 一、SDE 形式：采样路径的连续极限

第7章 7.2–7.3 节建起了扩散模型的 SDE 框架。正向 SDE（正向 SDE：描述含噪图随时间被噪声逐步侵蚀的随机微分方程）：

$$dx = f(\mathbf{x},t)\,dt + g(t)\,dw$$

$f(\mathbf{x},t)$ 是漂移系数，$g(t)$ 是扩散系数。由 @anderson1982reverse 定理，逆向 SDE 为：

$$dx = [f(\mathbf{x},t) - g(t)^2\nabla_x\log p_t(\mathbf{x})]\,dt + g(t)\,d\bar{w}$$

其中 $\bar{w}$ 是逆向时间的维纳过程，$\nabla_x\log p_t(\mathbf{x})$ 是时间 $t$ 处的得分函数。

### 连续时间得分匹配训练

逆向 SDE 的核心是得分函数 $\nabla\log p_t(\mathbf{x})$——通过连续时间得分匹配训练。连续时间 DSM 目标：

$$\mathcal{J}_\text{DSM}^\text{cont}(\theta) = \frac{1}{2}\int_0^T \lambda(t)\,\mathbb{E}_{\mathbf{x}_0}\mathbb{E}_{\varepsilon}\left[\left\|s_\theta(\mathbf{x}_t, t) + \frac{\varepsilon}{\sigma(t)}\right\|^2\right]dt$$

$\lambda(t)$ 是连续时间权重函数，$\sigma(t)$ 是时间 $t$ 处的有效噪声水平。变量含义上，$\sigma(t)$ 承担"此刻噪声有多强"的度量，而 $\lambda(t)$ 承担"此刻的学习该被多重视"的度量——两者共同决定连续时刻的训练信号强度。

换成 ε 预测参数化：

$$\mathcal{J}_\text{DSM}^\text{cont}(\theta) = \frac{1}{2}\int_0^T \frac{\lambda(t)}{\sigma^2(t)}\,\mathbb{E}_{\mathbf{x}_0,\varepsilon}\left[\|\varepsilon - \varepsilon_\theta(\mathbf{x}_t, t)\|^2\right]dt$$

> **记法说明**：这里的 $\sigma(t)$ 指含噪样本 $\mathbf{x}_t$ 相对 $\mathbf{x}_0$ 的扰动噪声标准差（在 VP-SDE 下即 $\sqrt{1-\bar{\alpha}(t)}$，故 $\sigma^2(t) = 1-\bar{\alpha}(t)$），这样才与条件得分目标 $-\varepsilon/\sigma(t)$ 的分母一致。这与 12.4 中"VE-SDE 下分母 $\sigma^2$、VP-SDE 下分母 $1-\bar{\alpha}$"的分工相同。正因常数倍不影响最优解，后续的匹配在哪种记号下展开都不改变结论。

## 二、VDM 形式：变分路径的连续极限

@kingma2021vdm 在变分扩散模型（VDM）框架下推导了连续时间 ELBO。把离散时间步数 $T\to\infty$，求和变积分：

$$\log p(\mathbf{x}_0) \geq \text{ELBO}^\text{cont}$$

连续时间 ELBO 的结构和离散版类似，分三项：

1. **先验匹配项**：$\mathbb{E}_q[\log p(\mathbf{x}_T)/q(\mathbf{x}_T|\mathbf{x}_0)]$，无训练参数；
2. **一致性积分**：$\int_0^T \mathbb{E}_q\left[\frac{1}{2}\left\|\frac{\mu_\theta(\mathbf{x}_t,t) - \tilde{\mu}_t(\mathbf{x}_t,\mathbf{x}_0)}{\sigma_t}\right\|^2\right]dt$；
3. **重建项**：$\mathbb{E}_q[\log p_\theta(\mathbf{x}_0|x_\varepsilon)]$。

### 连续时间一致性项的 ε 预测展开

在 ε 预测参数化下，连续时间一致性项变为：

$$\int_0^T w(t)\,\mathbb{E}_{\mathbf{x}_0,\varepsilon}\left[\|\varepsilon - \varepsilon_\theta(\mathbf{x}_t, t)\|^2\right]dt$$

$w(t)$ 是连续时间权重，由正向 SDE 的参数（漂移 $f$、扩散 $g$）确定。

## 三、等价性的连续时间表述

### 权重函数的连续化

离散时间的等价性条件是 $\dfrac{\lambda(\sigma_t)}{2\sigma_t^2} = w_t$（因子 $2$ 来自 $\mathcal J_\text{DSM}$ 前的 $1/2$），在连续时间下变成：

$$\frac{\lambda(t)}{2\sigma^2(t)} = w(t)$$

@kingma2021vdm 证明：在连续时间下，**三种参数化（ε 预测、$\mathbf{x}_0$ 预测、得分预测）的 VLB 权重自动一致**。这里的“一致”指三种写法导出同一个权重函数 $w(t)$；离散时间下这一点其实也精确成立（见实验 12.4-1 步骤 3 的逐位相等），连续时间的价值在于把逐步权重统一成一个连续函数，消去网格带来的记号差异。

> **从更深层次看**，把权重写成连续函数后，三种参数化共享同一个 $w(t)$，不再需要分别推导——这不是离散版本“有误差”而连续版本“没误差”，而是连续语言把同一个代数恒等式表示得更紧凑。连续时间因此是天然的理论基准：它让结构显形，把网格带来的记号差异全部消掉。

### 连续时间等价性定理

**定理（连续时间 DSM ≡ 连续时间 VLB）**：在连续时间下，选 $\lambda(t) = \sigma^2(t)\cdot w(t)$，则

$$\mathcal{J}_\text{DSM}^\text{cont}(\theta) = L_\text{VLB}^\text{cont}(\theta) + \text{const}$$

与离散时间相比，连续时间的等价性更"干净"——不存在因离散化带来的近似误差。

### 证明概要

思路和离散版一样，只是在积分框架下走一遍：

1. 从连续时间 ELBO 出发，把一致性积分展开成 ε 预测形式；
2. 从连续时间 DSM 出发，同样展开成 ε 预测形式；
3. 比较两个积分的权重函数 $w(t)$ 和 $\lambda(t)/\sigma^2(t)$；
4. 权重匹配时，两个积分逐点相等。

详细证明见附录 12A。

## 四、概率流 ODE：两条路径的第三种交汇

### 从 Fokker-Planck 到 PF-ODE

第7章 7.4 节从 Fokker-Planck 方程推导了概率流 ODE（PF-ODE，概率流常微分方程：把随机的逆向 SDE 换成一条确定的轨迹，但保持相同的边际分布）：

$$dx = \left[f(\mathbf{x},t) - \frac{1}{2}g(t)^2\nabla_x\log p_t(\mathbf{x})\right]dt$$

PF-ODE 把随机的逆向 SDE 变成确定性 ODE，却保持相同的边际分布 $p_t(\mathbf{x})$。

### PF-ODE 的变分视角

PF-ODE 也能从变分框架推导。连续归一化流（CNF）定义为：

$$\frac{\partial p_t(\mathbf{x})}{\partial t} = -\nabla\cdot(v_t(\mathbf{x})\,p_t(\mathbf{x}))$$

$v_t(\mathbf{x})$ 是向量场。当 $v_t(\mathbf{x}) = f(\mathbf{x},t) - \frac{1}{2}g^2(t)\nabla\log p_t(\mathbf{x})$ 时，CNF 的边际分布与逆向 SDE 一致。

从变分角度看，PF-ODE 定义了一个从噪声到数据的确定性映射，其似然可通过瞬时变量变换精确计算：

$$\log p(\mathbf{x}_0) = \log p(\mathbf{x}_T) + \int_0^T \nabla\cdot v_t(\mathbf{x}_t)\,dt$$

这给出了 $\log p(\mathbf{x}_0)$ 的**精确值**（而非下界），前提是向量场 $v_t$ 和真实得分一致。

### 三种采样方式的统一

PF-ODE 提供了 SDE 框架与变分框架的交汇点：

| 采样方式 | 来源 | 随机性 | 似然计算 |
|---|---|---|---|
| 逆向 SDE | 采样路径（Anderson 定理） | 随机 | 不可直接计算 |
| DDPM 采样 | 变分路径（离散逆向） | 半随机 | VLB 下界 |
| PF-ODE/DDIM | 两条路径的交汇 | 确定性 | 精确（瞬时变换） |

**DDIM = PF-ODE 的离散化**——第7章 7.5 节已建立这层对应。从变分角度看，DDIM 是一个确定性解码器，每步是 ODE 的 Euler 步，而非随机 SDE 步。

> **这一转变意味着**：当随机逆向 SDE 被换成确定性轨迹后，"似然"从"只能给下界"变成了"可以算精确值"。也就是说，采样路径与变分路径不仅共享训练目标，连"如何评估模型的似然"也通过 PF-ODE 走到了一起——这是除 DSM≡VLB 之外的另一条统一纽带。

## 五、三方统一：DDPM、Score-SDE、VDM

通过 12.4 的等价性证明和本节的连续时间统一，三种主要框架可统一为同一理论在不同约束下的特例：

**VDM 框架**（Kingma 2021）最一般，包含：

- **可优化的噪声调度**：$\beta_t$ 或等价的 $(s(t), \sigma(t))$ 可作为可训练参数；
- **连续时间 ELBO**：训练目标是严格的最大似然下界；
- **三种参数化统一**：ε 预测、$\mathbf{x}_0$ 预测、得分预测在连续时间下等价。

**DDPM** 是 VDM 在以下约束下的特例：

- **固定噪声调度**：$\beta_t$ 预先设定（线性或余弦）；
- **离散时间 VLB**：训练目标通常用简化 VLB；
- **VP-SDE 参数化**。

**Score-SDE** 是 VDM 在以下约束下的特例：

- **固定 SDE**：$f(\mathbf{x},t)$、$g(t)$ 预先设定；
- **得分匹配训练**：训练目标是 DSM 损失；
- **VE-SDE 或 VP-SDE 参数化**。

### 统一框架的意义

1. **选哪个框架只是工程偏好**：DDPM、Score-SDE、VDM 在数学上等价；
2. **训练目标的选择才是本质**：简化 VLB vs 完整 VLB vs 自定义权重，才是影响模型性能的关键决策；
3. **连续时间是理解的理论基准**：离散时间的近似误差，可由连续时间分析来理解。

> **从更深层次看**，三方统一揭示了一个更一般的事实：形形色色的扩散模型不是"好几套理论"，而是同一套理论在不同约束（固定调度多少、是否可训练、离散还是连续）下的切片。这一转变意味着，"殊途同归"的最后一块拼图来自框架层——连框架间的差异，也只是约束选择造成的。

等价性在理论和连续时间层面都已立住。但它对实践到底意味着什么？下一节谈训练目标怎么选、权重怎么影响模型表现。

## 六、动手感受一下：连续时间权重确实自动匹配（可运行代码）

下面这段重度注释的 numpy 代码，用一个最简的 VP-SDE 连续时间噪声调度做两件事：一是把离散权重 $w_t$ 连续化成 $w(t)$，并用逐点对照与数值积分核对两者一致；二是说明 $\lambda(t)=2\sigma^2(t)w(t)$ 只是匹配条件的**定义式**——按它取 $\lambda$ 后 DSM 权重自然等于 $w(t)$，这一步不构成验证。纯 numpy 就能跑。

```python
# -*- coding: utf-8 -*-
# 第12.5章 复现：连续时间下 DSM 权重 ≡ VLB 权重
# 目标：把离散权重连续化成 w(t) 并用数值积分核对；同时说明 λ=2σ²w 是定义式
# 需要：numpy（可选 matplotlib 画图）

import numpy as np

# ---------- 0. 设定：连续时间 VP-SDE 的 (s(t), σ(t)) ----------
# 离散时间 VP-SDE：x_t = √ᾱ_t·x0 + √(1-ᾱ_t)·ε
# 连续时间版：把 ᾱ_t 推广成 ᾱ(t)，令 t ∈ [0, 1]（0=数据，1=纯噪声）
# 为简单起见，我们用离散的 T 步来近似连续函数，并直接数值微分。

T = 1000
t = np.linspace(0.0, 1.0, T)                       # 时间网格
betas = np.linspace(1e-4, 0.02, T)                 # 线性噪声调度 β(t)
alphas = 1.0 - betas
bar_alpha = np.cumprod(alphas)                     # ᾱ(t)
one_minus_bar = 1.0 - bar_alpha

# 连续时间 VP-SDE 的噪声标准差：按本节的记法 σ²(t) = 1-ᾱ(t)
# （注意不是 (1-ᾱ)/ᾱ，那是 Karras/EDM 的 relative sigma）
sigma2 = one_minus_bar

# ---------- 1. 连续时间 VLB 权重 w(t) ----------
# 把 12.4 的离散权重化简：w_t = β_t²/[2β̃_t α_t (1-ᾱ_t)] = β_t/[2(1-ᾱ_{t-1})α_t]。
# 连续化时 β(t) = -(dᾱ/dt)/ᾱ(t)，得到“每单位时间”的权重密度
#   w(t) = -(dᾱ/dt) / [2 ᾱ(t) (1-ᾱ(t)) α(t)]
# 负号不能省：dᾱ/dt < 0，w(t) 必须为正。与离散每步权重的换算是 w_t ≈ w(t)·Δt。
dt = t[1] - t[0]
d_bar_alpha = np.gradient(bar_alpha, t)            # dᾱ/dt（负值），数值微分
w_cont = -0.5 * d_bar_alpha / (bar_alpha * one_minus_bar * alphas)

# ---------- 2. 用离散公式独立算一遍每步权重，做交叉核对 ----------
# w_t = β_t / [2 (1-ᾱ_{t-1}) α_t]，t 从 1 开始（t=0 处 β̃_1=0，对应离散解码器 L_0）
bar_alpha_prev = np.concatenate([[1.0], bar_alpha[:-1]])
w_disc = np.full_like(bar_alpha, np.nan)           # t=0 处 0/0，置 nan 不参与
w_disc[1:] = betas[1:] / (2.0 * (1.0 - bar_alpha_prev[1:]) * alphas[1:])

# ---------- 3. 检查：连续密度 × Δt 是否重现离散权重 ----------
print("连续密度 w(t) 与离散权重 w_t 的对照：")
print("   t        w(t)      w(t)·Δt     w_t      相对误差")
for i in [10, 100, 500, 900, 998]:
    rel = abs(w_cont[i] * dt - w_disc[i]) / abs(w_disc[i])
    print(f"  {t[i]:.3f}  {w_cont[i]:9.4f}  {w_cont[i]*dt:.6f}  {w_disc[i]:.6f}   {rel:.2e}")

# 全局标定：Σ_t w_t 应等于 ∫w(t)dt。跳过 t→0 的最初几步（那里 1-ᾱ 太小，
# 一阶离散化误差最大），其余部分应吻合到百分之几。
lo = 10
integral = np.sum(0.5 * (w_cont[lo:-1] + w_cont[lo+1:]) * np.diff(t[lo:]))
print(f"\nΣ w_t = {w_disc[lo:].sum():.4f},  ∫w(t)dt = {integral:.4f},  "
      f"相对差 = {abs(w_disc[lo:].sum()/integral - 1):.2%}")

# ---------- 4. 匹配条件只是定义式，不是“验证” ----------
# 若按定理取 λ(t) = 2σ²(t)w(t)，则 DSM 权重 λ/(2σ²) 恒等于 w(t)：
# 这是构造使然，任何 w(t) 都成立，不能作为等价性的证据。
# 真正有内容的检查是上面的第 3 步：连续化公式能否重现离散权重。
lambda_t = 2.0 * sigma2 * w_cont
dsm_weight_cont = lambda_t / (2.0 * sigma2)
print("由 λ=2σ²w 构造的 DSM 权重 / VLB 权重（恒为 1）:",
      np.unique(np.round(dsm_weight_cont[1:] / w_cont[1:], 12)))

# ---------- 5. 把两条曲线画出来（可选） ----------
try:
    import matplotlib.pyplot as plt
    plt.figure(figsize=(6, 3))
    plt.plot(t, w_cont, label="continuous density w(t)")
    plt.plot(t, w_disc / dt, '--', label="discrete w_t / dt")
    plt.xlabel("t"); plt.ylabel("weight density")
    plt.legend(); plt.title("Continuous formula vs. discrete weights")
    plt.tight_layout(); plt.show()
except Exception as e:
    print("（未安装 matplotlib，跳过画图；数值检查已足够说明问题）")
```

**怎么读这段代码**：第 1 段把离散 VP-SDE 的 $\bar{\alpha}(t)$ 推广成时间上的连续函数，用数值微分算 $d\bar{\alpha}/dt$，再按 $w(t)=-(d\bar{\alpha}/dt)/[2\bar{\alpha}(1-\bar{\alpha})\alpha]$ 得到连续权重密度。第 2、3 段用离散公式 $w_t=\beta_t/[2(1-\bar{\alpha}_{t-1})\alpha_t]$ 独立算一遍，检查 $w(t)\Delta t$ 能否重现 $w_t$：逐点相对误差在 $10^{-3}\sim10^{-2}$ 量级，积分标定差约 1%——都是网格造成的一阶误差，随 $T$ 增大而减小。第 4 段把 $\lambda(t)=2\sigma^2(t)w(t)$ 单独列出，是为了提醒读者：**由它得到的 DSM 权重恒等于 $w(t)$，这是定义式，不是验证**。真正被验证的是第 3 步——连续化公式与离散公式彼此独立，却给出同一批权重。
