## 一、总原则

1. **多数派优先**：除非学术惯例强烈反对，选当前全书主流记法，改动面最小。
2. **公式环境 ASCII 化**：`$...$` / `$$...$$` 内只允许 ASCII 字符与 LaTeX 命令，
   Unicode 数学符号（`ᾱ`、`‖` 等）在排版管线（Pandoc/Quarto→LaTeX）中不可靠，全部清除。
3. **语义性分歧不动**：`σ` vs `σ_y` 是语义选择（泛指 vs 观测噪声）而非记法分裂，
   保留双语并用规则（见 §三）。

## 三、语义性记号的使用条件（写入成书"符号总表"）

- `σ`：泛指加性高斯噪声水平（AE/扩散的正向过程）。
- `σ_y`：仅当同一段落同时出现多种噪声、需要特指观测方程 `y = Ax + σ_y·n` 时使用。
- **状态下标写粗体**：`\mathbf{x}_0`（干净图）、`\mathbf{x}_t`（含噪状态）、`\mathbf{x}_{t\pm1}`、`\mathbf{x}_T`、`\mathbf{x}_L`、`\mathbf{z}_t`/`\mathbf{z}_0`（隐变量/初始噪声）。
  旧记录「`x_0`（裸斜体）：初始/干净图像」已作废——2026-10-17 拍板 #3/#11 后全书为粗体。

四条派生规则（同为「合法混用」，同行出现不构成不一致）：

1. **`\mathrm{Var}` / `\mathbb{E}` 的自变量按其取值形态写**：取值为**标量**（逐坐标方差、一维分布的方差）时自变量写分量裸斜体 `\mathrm{Var}(x_0)`；取值为**协方差矩阵**（进入 `\operatorname{tr}(A\,\cdot\,A^\top)` 等矩阵运算）时自变量写粗体 `\operatorname{Var}[\mathbf{x}_0\mid \mathbf{x}_t]`。据此 附录13A:104/106/108/112 已补粗（与同段 L110 的矩阵形态统一），而 10.2:183/189/210/212/214、7.5:174/290/298 保持裸。
2. **一维数值实验的状态就是标量，写裸体是正确的**：`7.5`（N=5000 粒子、`x_T=1.0`）、`13.5` DOC（`x_0\approx -2.524`、`x_T\sim\mathcal{N}(0,1)`）、`13.2:140/325`（验证网格 `| x_t|<3`，表格行 157 保留 `\lvert x_t\rvert`）、`13.1:210/228`（`$| x - y|$ 均值和 $| x - x_0^{*}|$`、`x_0^{*}=-0.112`）、`13.6:292/296`（`d\hat{x}_0/dx_t`）、`附录13A:186`（各向同性先验 `\mathcal{N}(\mu,v)` 下的逐坐标边缘方差）、`14.2`（2 维 cINN 的 `x_1/x_2`）。同一行引用的**通用公式**仍按 A 组写粗体——「实验标量裸 + 通用式粗」并存是本节的正确形态，不是漂移。
3. **z 只有作为隐变量/噪声样本时才粗体**；作为**检验统计量或一维随机变量**时保持裸斜体：`10.2:202/210`（`$z$(mean)`、`|z|<2` 的 z 检验）、`11.3:209`（`$z=0.26$`＝误差/标准误比值）、`4.5:150`（Gamma 变量 `\mathbb{E}[z]`）、`9.2:316`（`f(z)=z^2` 重参数化标量示例）。判据：该符号是否被当作「一张图/一个向量样本」来采样与求范数。
4. **一维观测方程与观测的具体取值保持裸**：`y = x + n` 型玩具前向式（`13.1:180/201`、`13.2:132/154/272/295`、`13.4:211/225/346/362`、`13.6:122/215/216/217`）、具体观测数值（`13.1:228/233`、`13.2:132/272`、`13.4:331/346` 的 `y=0.5`、`14.2:255` 的 `$y=0$ 处 $x_2$ 边缘`）、标量随机变量的一致性讨论（`13.4:395` 的 `\mathbb{E}| X-y|` 与 `|\mathbb{E}[X]-y|`，2026-10-25 由命令形态转裸竖线）、一维算子比（`13.5` 全节约 40 处 `y/A`）、一维指数族密度推导（附录5B 的 `h(y)/p(y)/Z(y)`）。它们描述的是**实数取值**而非观测向量，与同文件 `\mathbf{y}`（指整个观测向量）并存属合法。

### 成书层证据（决定性：先测后改）

同一算式的四种写法走真实管线（`pypandoc.get_pandoc_path()`，`-f markdown+tex_math_dollars+raw_tex+pipe_tables+link_attributes-yaml_metadata_block`）转 docx，解 `word/document.xml` 比对 OMML 编码：

- `$\|x\|^{2}$` → `<m:t>` 直接给出 U+2225 `∥`：双竖线，纯 run，不随内容伸展
- `$\Vert x\Vert^{2}$` → `<m:t>` 直接给出 U+2016 `‖`：双竖线，同样不随内容伸展
- `$\lVert x\rVert^{2}$` → `<m:d>` + `begChr/endChr="‖"`：双竖线且**会**随内容伸展
- 表格单元格内三种形态（`\|`／`\Vert`／裸竖线）均被正确解析：列数不分裂、数学原样透传

三条结论：① `\|` **不会**退化成单竖线，与 `\Vert` 只是 Unicode 码位不同（U+2225 vs U+2016），Cambria Math 下同为双竖线；② 两者的伸展行为一致（都非定界符对），需要竖线随分式长高时另用 `\left\|…\right\|`/`\big\|…\big\|`——全书现成 58 处（29 对，集中在 6.2/6.3/6.5/附录6A/11.3/11.5/12.1/12.4/12.5/附录11B/附录12A/13.3/14.5/16.3/17.6/2.3/7.6/7.7），本项归一不触碰；③ 「作者为表格防御性使用命令形态」的假设不成立，保留只是源树可读性取舍。
