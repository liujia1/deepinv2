# 11.5 两条路径的交汇预告

> **核心观点**：ε预测VLB与第6章的DSM损失在结构上高度相似——差异仅在于时间权重。具体而言，ε预测的完整VLB $= \sum_t w_t\,\|\epsilon - \epsilon_\theta(x_t, t)\|^2$ 是加权DSM，简化VLB（丢弃 $w_t$）≈ 简化DSM（均匀权重）。这一结构相似性不是巧合——它反映了两种推导路径（从得分匹配出发 vs 从变分推断出发）正在趋同。第12章将证明：在适当的权重选择下，DSM损失 ≡ VLB，两条路径的等价性是精确的。本节为这一等价性提供直觉铺垫。

## 回顾：第6章的DSM损失

第6章6.3节推导了去噪得分匹配（DSM）的目标函数。回顾核心结论：

DSM目标函数：

$$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2}\mathbb{E}_{\sigma}\mathbb{E}_{x_0}\mathbb{E}_\epsilon\left[\lambda(\sigma)\,\left\|s_\theta(x_0 + \sigma\epsilon, \sigma) + \frac{\epsilon}{\sigma}\right\|^2\right]$$

用ε预测参数化 $s_\theta = -\epsilon_\theta/\sigma$（第6章6.6节）：

$$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2}\mathbb{E}_{\sigma}\mathbb{E}_{x_0}\mathbb{E}_\epsilon\left[\frac{\lambda(\sigma)}{\sigma^2}\,\|\epsilon - \epsilon_\theta(x_0 + \sigma\epsilon, \sigma)\|^2\right]$$

其中：
- $\sigma$ 是噪声水平，对应NCSN的噪声调度 $\sigma_1 > \sigma_2 > \cdots > \sigma_L$
- $\lambda(\sigma)$ 是权重函数，NCSN默认取 $\lambda(\sigma) = \sigma^2$
- $s_\theta$ 是得分网络，$\epsilon_\theta$ 是噪声预测网络

## ε预测VLB的结构

11.3节推导的ε预测VLB：

$$L_\text{VLB} = \sum_{t=1}^T w_t\,\mathbb{E}_{x_0, \epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

其中 $x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$，权重 $w_t = \frac{\beta_t^2}{2\sigma_t^2\alpha_t(1-\bar\alpha_t)}$。

## 并排对比

将两个损失放在一起对比：

| 维度 | DSM损失（第6章） | ε预测VLB（本章） |
|---|---|---|
| 噪声变量 | $\sigma$（噪声水平） | $t$（时间步，对应 $\sqrt{1-\bar\alpha_t}$） |
| 含噪输入 | $x_0 + \sigma\epsilon$ | $\sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon$ |
| 预测目标 | $\epsilon$（噪声） | $\epsilon$（噪声） |
| 权重 | $\lambda(\sigma)/\sigma^2$ | $w_t = \frac{\beta_t^2}{2\sigma_t^2\alpha_t(1-\bar\alpha_t)}$ |
| 噪声采样 | $\sigma \sim p(\sigma)$（噪声调度分布） | $t \sim \mathcal{U}\{1,T\}$（均匀） |
| 网络输入 | 含噪图像 + 噪声水平 | 含噪图像 + 时间步 |

### 核心相似性

两个损失的核心都是 $\|\epsilon - \epsilon_\theta(\text{含噪输入}, \text{条件})\|^2$——**预测噪声**！

差异仅在于：
1. **含噪输入的形式**：VE-SDE（$x_0 + \sigma\epsilon$，无信号缩放）vs VP-SDE（$\sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon$，有信号缩放）
2. **权重**：DSM用 $\lambda(\sigma)/\sigma^2$，VLB用 $w_t$

### 关键等价性观察

当选择 $\lambda(\sigma) = \sigma^2$（NCSN的默认选择），DSM的权重退化为1：

$$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2}\mathbb{E}_{\sigma}\mathbb{E}_{x_0}\mathbb{E}_\epsilon\left[\|\epsilon - \epsilon_\theta(x_0 + \sigma\epsilon, \sigma)\|^2\right]$$

这与简化VLB的形式完全一致——**简化VLB ≈ 简化DSM**！

当选择特定的 $\lambda(\sigma)$ 使得 $\lambda(\sigma)/\sigma^2 = w_t$ 时，DSM与完整VLB的权重一致——**加权DSM ≡ 完整VLB**！

## 从直觉到形式化

### 得分匹配路径的回顾

采样路径（第4-7章）从逆问题的后验采样需求出发：

1. **第4-5章**：后验采样需要得分函数 $\nabla\log p(x|y)$
2. **第6章**：得分函数无法直接计算，需要从数据学习 → 得分匹配（DSM）
3. **第7章**：多时间步得分驱动采样 = 扩散模型（SDE视角）

这条路径的出发点是：**学习得分函数以驱动采样**。

### 变分推断路径的回顾

变分路径（第8-11章）从优化角度出发：

1. **第8章**：后验不可解，需要近似 → 变分推断（ELBO）
2. **第9章**：VAE用神经网络参数化变分分布
3. **第10章**：层级VAE的极限 → 扩散过程
4. **第11章**：VLB分解 → 均值匹配 → 三种参数化 → DDPM训练

这条路径的出发点是：**最大化数据似然以训练生成模型**。

### 两条路径的汇聚

两条路径的训练目标几乎相同——仅差权重选择：

- **得分匹配**：训练噪声预测网络 $\epsilon_\theta$，目标 $\sum \lambda(\sigma_i)/\sigma_i^2 \cdot \|\epsilon - \epsilon_\theta\|^2$
- **变分推断**：训练噪声预测网络 $\epsilon_\theta$，目标 $\sum w_t \cdot \|\epsilon - \epsilon_\theta\|^2$

**同一个网络，同一个训练信号（$\epsilon$），不同的权重**。

当选择 $\lambda(\sigma)$ 使得两种权重一致时，两条路径的训练目标完全相同。这意味着：

**无论从"学习得分函数"出发，还是从"最大化似然"出发，最终训练的是同一个模型。**

## 等价性的直觉解释

为什么两条看似完全不同的路径会殊途同归？

### 从得分匹配的角度

得分匹配优化的是"得分估计的准确性"——让模型知道"数据分布的梯度指向往哪"。得分函数 $\nabla\log p(x)$ 描述了概率密度增长最快的方向——学好得分函数，就知道如何从噪声"爬"回数据分布。

### 从变分推断的角度

VLB优化的是"数据的对数似然下界"——让模型对数据赋予高概率。最大化ELBO等价于最小化KL散度 $D_\text{KL}(q \| p_\theta)$——让变分分布接近真实后验。

### 两者的等价意味着

**准确估计得分函数 = 对数据赋予高概率**

这不是巧合——得分函数 $\nabla\log p(x)$ 正是"概率增长最快方向"。学好得分函数，就知道概率密度在哪里高、在哪里低——这自然等价于学好概率分布本身。

更具体地说：
- 得分匹配通过 $\nabla\log p(x)$ 学习 $p(x)$ 的"梯度信息"
- VLB通过 $\log p(x)$ 学习 $p(x)$ 的"概率值"
- 梯度信息 $\nabla\log p(x)$ 和概率值 $\log p(x)$ 是同一个函数的不同表示——知道梯度，积分就得概率；知道概率，求导就得梯度

### 用物理学类比

想象一个地形（概率分布）：
- **得分匹配**：学习地形在每个点的坡度和方向（梯度/得分函数）——知道坡度就知道如何"下山"到谷底（高概率区域）
- **VLB**：学习地形在每个点的高度（概率密度）——知道高度就知道哪里是谷底

两种信息是等价的——知道所有点的坡度，可以重建整个地形；知道所有点的高度，也可以计算坡度。

## 预告：第12章的等价性证明

第12章将给出精确的形式化证明：

$$\boxed{\text{DSM损失} \equiv \text{变分下界}}$$

具体地，在适当的权重选择下，第6章的多尺度DSM损失与本章的VLB是同一个目标函数——两条路径的训练目标完全一致。

这一等价性是全书的核心理论结论：

- 它证明了两条独立发展的路径（得分匹配 vs 变分推断）殊途同归
- 它意味着实践中选择哪种训练目标（DSM或VLB）不影响最终的模型——差异仅在于工程选择（权重、噪声调度等）
- 它为理解扩散模型提供了统一的理论框架——不再需要区分"得分模型"和"变分模型"，它们是同一个东西
