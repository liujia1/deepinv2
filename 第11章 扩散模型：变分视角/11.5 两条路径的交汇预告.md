# 11.5 两条路径的交汇预告：Score ≡ VLB 的先兆

> 你还记得第6章吗？那时我们从"学得分函数"出发，得到了一个训练目标：给图加噪，让网络预测噪声，最小化 $\|\epsilon-\epsilon_\theta\|^2$。本章我们从"变分下界"出发，绕了一大圈——VLB 分解、均值匹配、ε 预测——最后得到的训练目标，居然也是：给图加噪，让网络预测噪声，最小化 $\|\epsilon-\epsilon_\theta\|^2$。
>
> 两条从完全不同的山头出发的路，走到了同一个路口。这绝不是巧合。这一节我们把两个目标并排摆在一起，告诉你：它们差的那一点点，只是"权重"。第12章会把这点缝隙也焊死，证明它们精确相等。

## 回顾：第6章的 DSM 损失长啥样

第6章 6.3 节推导的**去噪得分匹配（DSM）**目标：

$$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2}\mathbb{E}_{\sigma}\mathbb{E}_{x_0}\mathbb{E}_\epsilon\left[\lambda(\sigma)\,\left\|s_\theta(x_0 + \sigma\epsilon, \sigma) + \frac{\epsilon}{\sigma}\right\|^2\right]$$

用 ε 预测参数化 $s_\theta = -\epsilon_\theta/\sigma$（第6章 6.6 节）把它翻成噪声预测的语言：

$$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2}\mathbb{E}_{\sigma}\mathbb{E}_{x_0}\mathbb{E}_\epsilon\left[\frac{\lambda(\sigma)}{\sigma^2}\,\|\epsilon - \epsilon_\theta(x_0 + \sigma\epsilon, \sigma)\|^2\right]$$

其中 $\sigma$ 是噪声水平（NCSN 的噪声调度），$\lambda(\sigma)$ 是权重函数（NCSN 默认取 $\lambda(\sigma)=\sigma^2$）。这里的核心动作和本章一模一样：**加噪 → 让网络认噪声**。不过它用的是无信号缩放的 VE 形式。

## 本章的 ε 预测 VLB 长啥样

11.3 节推导的 ε 预测 VLB：

$$L_\text{VLB} = \sum_{t=1}^T w_t\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

其中 $x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$，权重 $w_t = \frac{\beta_t^2}{2\sigma_t^2\alpha_t(1-\bar\alpha_t)}$。

## 并排对比：核心居然是同一个

| 维度 | DSM损失（第6章） | ε预测VLB（本章） |
|---|---|---|
| 噪声变量 | $\sigma$（噪声水平） | $t$（时间步，对应 $\sqrt{1-\bar\alpha_t}$） |
| 含噪输入 | $x_0 + \sigma\epsilon$ | $\sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon$ |
| 预测目标 | $\epsilon$（噪声） | $\epsilon$（噪声） |
| 权重 | $\lambda(\sigma)/\sigma^2$ | $w_t = \frac{\beta_t^2}{2\sigma_t^2\alpha_t(1-\bar\alpha_t)}$ |
| 噪声采样 | $\sigma \sim p(\sigma)$（噪声调度分布） | $t \sim \mathcal{U}\{1,T\}$（均匀） |
| 网络输入 | 含噪图 + 噪声水平 | 含噪图 + 时间步 |

**核心相似性**：两者的核心都是 $\|\epsilon - \epsilon_\theta(\text{含噪输入}, \text{条件})\|^2$——**预测噪声！**

差异仅两点：
1. **含噪输入形式**：VE-SDE 用 $x_0+\sigma\epsilon$（无信号缩放），VP-SDE 用 $\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$（有信号缩放）；
2. **权重**：DSM 用 $\lambda(\sigma)/\sigma^2$，VLB 用 $w_t$。

## 关键观察：选对权重，两者就合体

当取 $\lambda(\sigma)=\sigma^2$（NCSN 默认），DSM 权重退化成 1：

$$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2}\mathbb{E}_{\sigma}\mathbb{E}_{x_0}\mathbb{E}_\epsilon\left[\|\epsilon - \epsilon_\theta(x_0 + \sigma\epsilon, \sigma)\|^2\right]$$

这和**简化 VLB（11.4 节的 $L_\text{simple}$，丢权重）**形式完全一致！→ **简化 VLB ≈ 简化 DSM**。

更进一步，只要选特定的 $\lambda(\sigma)$ 让 $\lambda(\sigma)/\sigma^2 = w_t$，加权 DSM 就和完整 VLB 权重一致 → **加权 DSM ≡ 完整 VLB**。

## 从直觉到形式化：两条路径的身世

- **得分匹配路径（第4–7章）**：从"后验采样需要得分函数"出发 → 第6章用 DSM 学得分 → 第7章多尺度得分驱动采样 = 扩散（SDE 视角）。起点是"学梯度以驱动采样"。
- **变分推断路径（第8–11章）**：从"后验不可解，需近似"出发 → 第9章 VAE → 第10章 层级 VAE 极限 = 扩散 → 本章 VLB 分解→均值匹配→参数化→DDPM。起点是"最大化似然以训生成模型"。

两条路的训练目标几乎相同——**同一个网络 $\epsilon_\theta$、同一个信号（预测噪声 $\epsilon$）、只差权重选择**。当权重对齐，目标完全相同。从更深层次看，这意味着：无论我们是用"采样需要得分"这个动机，还是用"最大似然的下界"这个动机进入扩散模型，最终教会网络的都是同一件事——**猜每一团噪声**。动机不同，落点相同。

## 等价性的直觉：梯度与高度是同一座山

为什么两条路殊途同归？回到贝叶斯叙事的四个角色：

- **得分匹配**优化的是"得分估计的准确性"——让模型知道"数据分布的梯度指向哪"。得分函数 $\nabla\log p(x)$ 是概率密度增长最快的方向；学好它，就知道怎么从噪声"爬"回高密度区。
- **VLB**优化的是"数据对数似然下界"——让模型对数据赋高概率。最大化 ELBO 等价于最小化 KL 散度 $D_\text{KL}(q\|p_\theta)$，让变分分布贴近真后验。

两者等价意味着：**准确估计得分 = 对数据赋高概率。** 这不是巧合——得分 $\nabla\log p(x)$ 正是"概率增长最快的方向"，知道梯度就能重建整个地形。

**物理学类比**：把概率分布想成一片地形。
- 得分匹配 = 学每个点的坡度与朝向（梯度），知道怎么下山到谷底；
- VLB = 学每个点的高度（概率密度），知道谷底在哪。

坡度信息和高度信息等价：知道所有坡度能重建地形，知道所有高度能算坡度。所以"学得分"和"学似然"是同一件事的两种说法。

## 预告：第12章焊死这条缝

第12章将给出精确证明：

$$\boxed{\text{DSM损失} \equiv \text{变分下界}}$$

在合适的权重下，第6章的多尺度 DSM 与本章的 VLB 是**同一个目标函数**。这一等价性是全书的理论高光：
- 它证明两条独立发展的路径（得分匹配 vs 变分推断）殊途同归；
- 它意味着实践中选哪种训练目标（DSM 或 VLB）不影响最终模型，差异只在工程选择（权重、噪声调度）；
- 它给扩散模型一个统一框架——不必再区分"得分模型"和"变分模型"，它们本是一体。

从更深层次看，这也是对本章主线的收束：我们一路把"最大化似然的下界"化简到"让网络猜噪声"，而那边从"学得分"出发的路径也化简到同一件事——**两条路的本质都是"训练 = 让网络去猜每一步加的噪声"**，只是各自从不同的贝叶斯切面进入。

**来源**：Ho et al. (2020) DDPM; Song & Ermon (2019) NCSN; 2209.14687v1 Sec 3; 2406.08929v2 Appendix B.10

> 两条路径的训练目标结构几乎一致，只差权重。第12章将证明，在适当权重下 DSM ≡ VLB——这是全书核心结论，两条独立路径的殊途同归。
