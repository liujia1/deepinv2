# 11.0 本章导读：从"应该优化什么"到"怎么在计算机里跑起来"

> "我们费了九牛二虎之力，证明了扩散模型其实就是一个层级高斯 VAE（第10章）。可问题是——证明了'该优化什么'之后，模型到底怎么训练？"
>
> 预告一句结论：**答案是——训练 = 让网络去猜每一步加进去的噪声**。整章所有化简工作，最终都落到这一句话上。

上一章（第10章）我们做了一件很根本的事：把"一步步加噪、再一步步去噪"的过程，从数学上严丝合缝地装进了**变分下界（VLB，Variational Lower Bound，就是对数似然 log p(x) 的一个可计算的下界）**的框架里。我们说：要训练扩散模型，就去最大化这个下界。

可你真要打开电脑想写代码，会发现卡住了——VLB 是一长串 KL 散度（KL 散度，衡量两个概率分布差多少的一个数）的和，看起来无从下手。我们**知道该优化什么**，但还**不知道怎么把它变成神经网络能跑、一次梯度下降就能更新的目标函数**。

本章做的正是这个"落地"的工作。我们把那个抽象的 VLB，像剥洋葱一样一层层化简，最后得到一个简单到不可思议的训练目标：**给一张图加噪，让网络猜出加进去的噪声是多少，然后最小化"猜的噪声"和"真实噪声"之间的误差**。这就是 DDPM（Denoising Diffusion Probabilistic Models，去噪扩散概率模型，2020 年那篇开创性论文）的核心。

**本章目标**（读完你应该能）：
- 说清楚 VLB 拆成的三项里，为什么只有一项真正需要训练、另两项可以忽略；
- 理解"训练逆向去噪过程"在数学上等价于"让网络学会已知原图时的最优去噪步长"（均值匹配）；
- 区分三种等价的参数化方式（预测噪声 ε、预测原图 x₀、预测得分 s），并知道为什么 DDPM 选了预测噪声；
- 解释一个反直觉现象：丢掉 VLB 里精心设计的"时间权重"，生成质量反而更好；
- 感受到变分路径（本章）和得分匹配路径（第6章）正在悄悄汇合——为第12章的"殊途同归"铺垫直觉。

## 本章的化简链：一条因果主线

我们沿着下面这条"化简链"往下走，每一步都为下一步铺路：

**VLB 分解（11.1）**：先把 VLB 拆成三项——先验匹配项（常数，可忽略）、一致性项（核心训练项）、重建项（处理离散像素）。关键工具是推导"正向过程后验" $q(x_{t-1}|x_t,x_0)$ 的闭式解（闭式解 = 一个能直接算出来的公式，不用迭代）。有了它，一致性项才从抽象变得可算。

**一致性项化简（11.2）**：因为两头的分布都是高斯、方差又固定，KL 散度压缩成"均值之间的距离平方"——也就是说，**训练 = 让网络预测的均值去逼近那个最优均值**。从"分布匹配"变成了一个普通的"回归问题"，神经网络最擅长这个。

**三种参数化（11.3）**：均值可以用三种等价方式表达——让网络预测"加进去的噪声 ε"、"原始图像 x₀"、或"得分函数 s"。三者数学上完全等价，但训练稳定性差异显著。DDPM 选了 ε 预测。

**简化 VLB 与 DDPM 训练（11.4）**：Ho 等人发现，把完整 VLB 里复杂的时间权重一丢，用均匀权重去训练，生成的图像反而更好看（虽然严格意义上的似然变差了）。这是本章最反直觉的一幕。

**两条路径的交汇预告（11.5）**：你会发现，ε 预测的 VLB 和第6章的得分匹配损失（DSM）长得几乎一模一样——差别只在权重。这不是巧合，第12章会证明它们精确相等。

```
VLB分解(11.1) → 均值匹配化简(11.2) → 参数化选择(11.3) → 简化训练(11.4) → 交汇预告(11.5)
```

## 一个贯穿全章的直觉：把"生成"拆成一千个小去噪

在读具体推导前，先建立本章最重要的一个心理图像。

想象你要画一幅画，但手抖得厉害。直接画一幅完整的好画太难了。于是你换个办法：**先随手泼一团噪声（纯随机点），然后每次只做一点点"微调"——把画面擦干净一丁点，再擦干净一丁点……做一千次之后，噪声变成了清晰的画。**

正向过程（加噪）就是"泼噪声"——每一步往图像里掺一点点随机噪声，掺一千步后图像彻底变成纯噪声。逆向过程（去噪）就是"一千次微调"——每一步网络只学会"把当前这团含噪图像，往清晰的方向推一小步"。

从更深层次看，关键洞察在于：**因为每一步只动一点点，所以"从含噪图推回上一步"这个任务变得极其简单、好学**。这就好比让你从"几乎完成的画"倒推"差一点的画"很容易，但从"纯噪声"一步跳到"成品画"几乎不可能。把难问题拆成一千个极易的小问题——这就是扩散模型能从变分原理里长出来的根本原因。

## 本章核心洞见（先放在这里，读完后你会明白每一句）

**扩散模型的训练 = 最大化数据的对数似然下界 = 学会逆向过程的每一步均值 → 三种参数化只是同一件事的不同说法 → 实践中丢掉权重反而最好。**

变分原理不只是"理论优雅"——它直接告诉你 DDPM 算法该怎么写。而更妙的是，从另一条路（得分匹配）出发，居然会走到同一个终点。这正是我们下一章要收网的地方。

## 动手感受一下：用 numpy 复现"加噪 + 预测噪声"的核心一步

下面这段代码不依赖任何深度学习框架，只用 numpy，复现了 DDPM 训练最核心的一步：**对一张图加噪 → 让一个小网络（这里用一个最简单的线性层示意）去猜加进去的噪声 → 算均方误差损失**。运行它，你能直观看到"训练目标"到底是什么。配套实验（`.py` 文件）里有完整可跑的版本，这里只示意最核心的逻辑。

```python
# ============================================================
# 用 numpy 示意 DDPM 训练的核心一步：加噪 -> 预测噪声 -> 算损失
# 目的：让你"看见"本章最终落到的一个极简目标函数
# ============================================================
import numpy as np

# ---------- 1. 设定噪声调度（线性调度，T=1000 步）----------
T = 1000
# beta_t：每一步掺入的噪声比例，从很小线性涨到 0.02
betas = np.linspace(1e-4, 0.02, T)
# alpha_t = 1 - beta_t；bar_alpha_t = 累乘 alpha，表示"信号保留比例"
alphas = 1.0 - betas
bar_alphas = np.cumprod(alphas)          # \bar\alpha_t

def q_sample(x0, t, eps):
    """正向过程：在第 t 步给原图 x0 加噪。
    x_t = sqrt(bar_alpha_t) * x0 + sqrt(1 - bar_alpha_t) * eps
    eps 是标准高斯噪声 N(0, I)。"""
    a_bar = bar_alphas[t]
    return np.sqrt(a_bar) * x0 + np.sqrt(1 - a_bar) * eps

# ---------- 2. 一个"玩具网络"：线性预测噪声 ----------
# 真实 DDPM 用 UNet；这里用最简单的线性映射示意"网络输出"
rng = np.random.default_rng(0)
D = 784                                   # 比如 28x28=784 的图像拉平
W = rng.standard_normal((D, D)) * 0.01    # 网络权重（未训练，随机初始化）

def eps_theta(xt, t):
    """网络：输入含噪图 xt，输出它预测的噪声。
    这里用 W @ xt 示意；真实实现是 UNet(xt, t)。"""
    return W @ xt

# ---------- 3. 复现训练的一步 ----------
# 假装我们有一张"原图" x0（这里随机生成，示意用）
x0 = rng.standard_normal(D) * 0.5
t = rng.integers(1, T)                     # 随机均匀采样一个时间步
eps = rng.standard_normal(D)               # 真实的加噪噪声

xt = q_sample(x0, t, eps)                  # 构造含噪图 x_t
eps_pred = eps_theta(xt, t)                # 网络猜的噪声

# 训练目标：最小化 ||eps - eps_pred||^2 —— 这就是 L_simple！
loss = np.mean((eps - eps_pred) ** 2)
print(f"时间步 t={t:4d}，当前（未训练）损失 = {loss:.4f}")
print("含义：网络还没学，猜的噪声和真实噪声差很远；")
print("训练 = 不断减小这个差距，直到网络能'看出'加进去的噪声。")

# ---------- 4. 前向加噪可视化（打印不同 t 下的信噪比）----------
print("\n前向加噪：信号比例 sqrt(bar_alpha_t) 随 t 衰减——")
for tt in [0, 100, 300, 600, 999]:
    snr = bar_alphas[tt] / (1 - bar_alphas[tt])   # 信噪比
    print(f"  t={tt:4d}: 信号保留 {np.sqrt(bar_alphas[tt]):.3f}, "
          f"信噪比 SNR={snr:.4f}"
          + ("  <- 几乎纯噪声" if snr < 0.01 else ""))
```

运行后你会看到：未训练时损失很大；而随着训练推进，网络的任务始终只是"把加进去的那团噪声认出来"。这正是 11.3、11.4 节要反复说的——**不管数学包装得多复杂，DDPM 的本质就是一个"找噪声"的游戏**。

## 收尾：为什么这件事重要

本章看起来在"化简公式"，其实在做一件更根本的事：**把"生成一张图"这个看似魔法般的问题，翻译成了一个你我都能写进 `for` 循环里的监督学习任务**。你不用懂复杂的采样理论，只要会"加噪声"和"猜噪声"，就能训练出一个生成模型。

而当我们走到 11.5 节会发现，这条从变分原理出发的路，和之前第6章"学得分函数"的路，正在指向同一个训练目标。全书的两条大动脉，即将在下一章汇合。这正是全书核心论点——变分路径与采样路径殊途同归——在本章的第一次正式铺垫。
