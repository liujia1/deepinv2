# 11.0 本章导读：从层级VAE的训练目标到扩散实践

第10章建立了"扩散过程 = 层级高斯VAE"的等价关系：正向加噪过程是VAE的编码器，逆向去噪过程是VAE的解码器，层级ELBO是训练目标。然而，第10章的推导停留在"ELBO的存在性"——我们知道了应该优化什么，但还没有将ELBO化为可以在计算机上执行的训练算法。本章完成这一"落地"过程。

第10章末尾留下了一个核心问题：**层级ELBO如何化为具体的训练目标？** 这个问题看似简单，实则涉及多个层次：ELBO的三项各有不同的性质（常数项、核心训练项、边界项），一致性项需要从抽象的KL散度化为可计算的回归目标，回归目标又有不同的参数化选择，参数化选择影响训练动态和最终效果。每一步化简都涉及权衡——数学严谨性与训练稳定性的权衡、理论最优性与实践效果的权衡。

本章沿着一条"化简链"展开，逐层将抽象的变分下界转化为具体的训练算法：

**VLB分解与正向过程后验**（11.1）：将层级ELBO分解为三项——先验匹配项 $L_T$（常数，不含可训练参数，训练时忽略）、一致性项 $\sum_{t>1}L_{t-1}$（核心训练项，衡量正向后验与逆向先验的匹配程度）、重建项 $L_0$（从 $x_1$ 重建 $x_0$ 的对数似然）。关键步骤是推导正向过程后验 $q(x_{t-1}|x_t, x_0)$ 的闭式解——由于正向过程是高斯马尔可夫链，后验可以通过贝叶斯规则解析求得。这个闭式后验使得一致性项从抽象的KL散度变为可计算的表达式。

**一致性项化简**（11.2）：$L_{t-1}$ 是两个高斯分布的KL散度，由于方差固定，KL散度简化为均值匹配目标 $\|\tilde\mu_t(x_t, x_0) - \mu_\theta(x_t, t)\|^2$。训练的含义是：让逆向过程的均值 $\mu_\theta$ 尽可能接近正向后验的均值 $\tilde\mu_t$——**学习逆向过程 = 学习已知 $x_0$ 时的最优去噪步骤**。

**三种参数化**（11.3）：均值匹配目标中的 $\mu_\theta$ 可以用三种等价方式参数化——噪声预测 $\epsilon_\theta$（预测加入的噪声，DDPM使用）、x₀预测 $\hat{x}_\theta$（预测原始图像，去噪参数化）、得分预测 $s_\theta$（预测得分函数，SMLD/NCSN使用）。三种参数化在数学上等价（可以互推），但在训练动态上有显著差异：ε预测训练最稳定（监督信号尺度一致），x₀预测直观但训练不稳定，得分预测与第6章的得分匹配视角一致。

**简化VLB与DDPM训练**（11.4）：完整VLB包含时间依赖的权重因子，Ho et al. (2020) 发现丢弃权重使用简化目标 $L_\text{simple}$ 训练，虽不严格但生成质量更好。Improved DDPM (Nichol & Dhariwal 2021) 引入学习方差，兼顾似然与生成质量。

**两条路径的交汇预告**（11.5）：ε预测VLB与第6章的DSM损失在结构上高度相似——差异仅在于权重。简化VLB ≈ 简化DSM。这一观察预示着第12章的核心结论：Score Matching损失 ≡ 变分下界。

```
VLB分解(11.1) → 均值匹配化简(11.2) → 参数化选择(11.3) → 简化训练(11.4) → 交汇预告(11.5)
```

本章结束时，读者将理解：扩散模型的训练可以从变分原理出发，通过VLB分解→均值匹配→参数化→简化，得到DDPM训练算法。变分路径与得分匹配路径虽然起点不同，但最终收敛到几乎相同的训练目标。本章的核心洞见是：**扩散模型训练 = 最大化数据的对数似然下界 = 学习逆向过程的均值 → 三种参数化统一 → 简化目标在实践中最优**——变分原理不仅提供了理论优雅性，更直接指导了实践中的算法设计。
