# 11.2 一致性项化简：从 KL 散度到"均值匹配"

> 你面前有两个高斯分布（高斯分布 = 钟形曲线那样的正态分布），都带同样的方差。现在要算它们的 KL 散度（KL 散度 = 两个分布差多少的一个数）。你脑子里蹦出的公式大概是积分、对数、trace（矩阵的迹）……一团乱。
>
> 先猜一下：如果方差完全一样，这两个高斯的 KL 散度能简化成多简单的形式？——答案是：$\frac{1}{2\sigma^2}\|\mu_1-\mu_2\|^2$。**就只是"两个均值之差的平方除以方差"**。整个分布之间的距离，竟然只由两个"中心点"的位置决定。这一节我们就用这个朴素结论，把上一节那个吓人的一致性项，变成人人会写的回归题。

## 问题：一致性项长得太吓人

上一节我们把 VLB 拆开，确认了**只有一致性项 $L_{t-1}$ 真正需要训练**：

$$L_{t-1} = \mathbb{E}_q\left[D_\text{KL}(q(x_{t-1}|x_t, x_0) \| p_\theta(x_{t-1}|x_t))\right]$$

其中：
- 正向后验 $q(x_{t-1}|x_t,x_0) = \mathcal{N}(x_{t-1}; \tilde\mu_t(x_t,x_0), \tilde\beta_t I)$（上节已推导）；
- 逆向先验 $p_\theta(x_{t-1}|x_t) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t,t), \sigma_t^2 I)$（待学）。

直接对着这个 KL 散度优化，看起来要同时管均值和方差，无从下手。但别忘了上节结尾：我们**把方差固定了**（取 $\beta_t$ 或 $\tilde\beta_t$）。固定方差这个"小动作"，正是化简的命门。

## 直觉：方差锁死，分布就只剩"中心点"可变

高斯分布完全由"均值 + 方差"决定。现在方差已经钉死成常数——那两个分布到底差多少，**只取决于它们的均值差多远**。方差管的是"散布范围"，均值管的是"中心朝向"；范围不变时，你只要把中心点对齐，两个分布就重合了。

所以直觉上：既然方差固定，KL 散度应该塌缩成"均值之间的距离"。下面把它坐实。

## 数学：两个等方差高斯的 KL 闭式解

两个各向同性高斯（各向同性 = 每个方向方差相同，即 $\sigma^2 I$）的 KL 散度有标准闭式解：

$$D_\text{KL}(\mathcal{N}(\mu_1, \sigma^2 I) \| \mathcal{N}(\mu_2, \sigma^2 I)) = \frac{1}{2\sigma^2}\|\mu_1 - \mu_2\|^2$$

有个微妙处：正向后验方差是 $\tilde\beta_t$，逆向先验方差是 $\sigma_t^2$，二者不一定相等。分两种情况：

**情况 A：方差相同（$\sigma_t^2 = \tilde\beta_t$）**——直接是纯均值匹配：

$$L_{t-1} = \mathbb{E}_q\left[\frac{1}{2\tilde\beta_t}\|\tilde\mu_t(x_t,x_0) - \mu_\theta(x_t,t)\|^2\right]$$

**情况 B：方差不同**——一般高斯的 KL 还会多一项方差匹配：

$$L_{t-1} = \mathbb{E}_q\left[\frac{1}{2\sigma_t^2}\|\tilde\mu_t - \mu_\theta\|^2 + \frac{d}{2}\left(\frac{\tilde\beta_t}{\sigma_t^2}-1-\log\frac{\tilde\beta_t}{\sigma_t^2}\right)\right]$$

但第二项与 $\theta$ 无关（因为 $\sigma_t^2$ 是固定超参），训练时直接扔掉。**所以无论方差怎么取，训练目标都等价于均值匹配。**

忽略与 $\theta$ 无关的常数 $C$，得到本章第二个核心公式：

$$\boxed{L_{t-1} = \mathbb{E}_q\left[\frac{1}{2\sigma_t^2}\|\tilde\mu_t(x_t, x_0) - \mu_\theta(x_t, t)\|^2\right] + C}$$

## 先猜后揭：训练到底在干啥

请先猜：训练逆向网络 $p_\theta$，是在匹配"整个分布"还是"只是均值"？

揭晓：**只是均值。** 具体说——

- **$\tilde\mu_t(x_t,x_0)$ 是"目标均值"**：如果上帝告诉你原图 $x_0$，从 $x_t$ 往回走一步的最优落点。
- **$\mu_\theta(x_t,t)$ 是"预测均值"**：网络在只看到 $x_t$ 时，猜的往回走一步的落点。

训练数据怎么来？从正向过程采样一对 $(x_0,x_t)$，因为训练时我们**确实知道** $x_0$（它就来自训练集），所以能算出 $\tilde\mu_t$ 当监督信号：

1. 从训练集采 $x_0$；
2. 采噪声 $\epsilon\sim\mathcal{N}(0,I)$；
3. 算 $x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$；
4. 算目标 $\tilde\mu_t = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\epsilon\right)$；
5. 算损失 $\|\tilde\mu_t - \mu_\theta(x_t,t)\|^2$。

> 注意第 4 步已经用上了上节末尾的重参数化——把 $\tilde\mu_t$ 写成了 $x_t$ 和噪声 $\epsilon$ 的函数。这条线马上接到 11.3。

## 为什么是"均值匹配"而不是"分布匹配"

一致性项本质是"分布匹配"（KL 散度），化简后却只需匹配均值。原因三点：

1. **方差已固定**：$\sigma_t^2$ 是预设超参，不是可学参数；
2. **高斯由均值+方差完全确定**：方差锁死时，对齐均值 = 对齐整个分布；
3. **均值才是"方向"信息**：$\tilde\mu_t$ 告诉你"往哪去噪"，方差只说"有多不确定"——方向比不确定更重要。

这一步的意义：**把抽象的"分布匹配"翻译成具体的"回归"**——给定输入 $x_t$，预测目标 $\tilde\mu_t$。而"输入→预测"正是神经网络天生最会做的事。

## 贝叶斯视角：一次"模仿式"信念更新

把这里放回贝叶斯叙事：正向后验 $q(x_{t-1}|x_t,x_0)$ 是"知道原图时的理想后验信念"；逆向网络 $p_\theta(x_{t-1}|x_t)$ 是"只看含噪图时的近似后验信念"。训练 = 让近似后验不断贴近理想后验，即**用已知真相时的信念，去校准只看局部证据时的信念**。

这和第1章的贝叶斯框架一脉相承：先验/后验/似然/证据四个角色在这里化身成——
- **似然**（保真）：$q(x_t|x_{t-1})$ 告诉我们"加噪这一步长啥样"；
- **后验**：$q(x_{t-1}|x_t,x_0)$ 是已知原图时的"正确答案"；
- **变分近似（我们学的）**：$p_\theta(x_{t-1}|x_t)$ 是网络给出的近似；
- **证据**：整条链的边际，被 VLB 这个下界绕开了。

随着训练数据（不同的 $x_0,\epsilon,t$）不断喂进来，网络的近似后验被一步步"洗"向理想后验——典型的信念随证据更新的过程。

## 从均值匹配到"可训练目标"：还差一层包装

均值匹配目标 $\|\tilde\mu_t-\mu_\theta\|^2$ 数学上清楚了，但直接让网络输出 $\mu_\theta$ 有三个别扭：

1. **不直观**：$\tilde\mu_t$ 是 $x_0$ 和 $x_t$ 的加权组合，不是个有物理意义的量；
2. **尺度随时间飘**：不同时刻 $t$ 的 $\tilde\mu_t$ 数值范围差很多，训练不稳；
3. **得知道 $x_0$ 才能算目标**：虽训练时可用，但更自然的监督信号应是某种"预测"。

更好的办法是：把 $\mu_\theta$ **参数化成某种"预测"的函数**，让训练目标有直观含义。下节（11.3）给出三种等价的包装——预测噪声 ε、预测原图 x₀、预测得分 s。

## 数值行为预告：权重藏着"U 形"陷阱

一致性项外面还挂着权重 $1/(2\sigma_t^2)$。在 ε 预测参数化下，综合权重会变成

$$w_t = \frac{\beta_t^2}{2\sigma_t^2\alpha_t(1-\bar\alpha_t)}$$

它在小 $t$（低噪声）时极大（因为 $1-\bar\alpha_t\approx 0$），呈 **U 形**。意味着完整 VLB 过度偏爱低噪声时刻——这恰好是 11.4 节"为什么丢掉权重反而更好"的伏笔。
