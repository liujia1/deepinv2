## 实验 4.1 Monte Carlo 积分：收敛速率与维数无关性

**对应章节**：4.1 Monte Carlo 方法：从积分到采样
**知识点**：Monte Carlo 估计；大数定律；收敛速率 $O(1/\sqrt{M})$；与维数 $d$ 无关

### 实验目的

4.1 节指出 Monte Carlo 方法的核心优势：收敛速率 $O(1/\sqrt{M})$ 与维数 $d$ 无关——这是 Monte Carlo 能在高维问题中生效的根本原因。本实验的目标是：

1. **定量验证** Monte Carlo 估计的 $O(1/\sqrt{M})$ 收敛速率
2. **直观观察**收敛速率不随维数 $d$ 变化——与确定性数值积分（收敛速率随 $d$ 指数恶化）形成对比
3. **理解**为什么"从后验中采样"在高维逆问题中是可行的

### 场景描述

估计 $d$ 维标准高斯分布 $\mathcal{N}(0, I_d)$ 下函数 $h(x) = x_1^2$ 的期望 $\mathbb{E}[X_1^2]$（真实值为 1）。分别用 $d = 1, 5, 20, 100$ 维，每个维数下用不同样本量 $M$ 进行 Monte Carlo 估计，绘制估计误差随 $M$ 的变化曲线。

### 预期结果

- 所有维数下，估计误差 $\propto 1/\sqrt{M}$（对数坐标下斜率为 -1/2）
- 不同维数 $d$ 的曲线几乎重合——收敛速率与 $d$ 无关
- 与确定性数值积分（如网格法）对比：$d=20$ 时网格法已不可行，Monte Carlo 仍正常工作

### 源代码

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# ========== Monte Carlo 积分：收敛速率与维数无关性 ==========

def monte_carlo_estimate(d, M_list):
    """
    对 d 维标准高斯 N(0, I_d)，估计 E[X_1^2]。
    真实值 = 1（标准高斯的方差）。
    
    参数:
        d: 维数
        M_list: 样本量列表
    返回:
        estimates: 各 M 下的估计值
        errors: 各 M 下的绝对误差
    """
    # 一次性生成最大样本量，然后切片
    M_max = max(M_list)
    X = np.random.randn(M_max, d)  # M_max 个 d 维样本
    h = X[:, 0] ** 2               # h(x) = x_1^2
    
    estimates = []
    errors = []
    for M in M_list:
        est = np.mean(h[:M])
        estimates.append(est)
        errors.append(abs(est - 1.0))
    return estimates, errors

# --- 实验 ---
dimensions = [1, 5, 20, 100]
M_list = [50, 100, 200, 500, 1000, 2000, 5000, 10000, 20000, 50000]

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# 左图：估计值随 M 的变化
ax = axes[0]
for d in dimensions:
    estimates, errors = monte_carlo_estimate(d, M_list)
    ax.plot(M_list, estimates, 'o-', markersize=3, label=f'd={d}')
ax.axhline(y=1.0, color='k', linestyle='--', label='真实值 E[$X_1^2$]=1')
ax.set_xlabel('样本量 M')
ax.set_ylabel('估计值')
ax.set_title('Monte Carlo 估计值随样本量的变化')
ax.set_xscale('log')
ax.legend()

# 右图：误差随 M 的变化（对数坐标）
ax = axes[1]
for d in dimensions:
    estimates, errors = monte_carlo_estimate(d, M_list)
    ax.plot(M_list, errors, 'o-', markersize=3, label=f'd={d}')
# 参考线：O(1/sqrt(M))
M_ref = np.array(M_list)
ax.plot(M_ref, 1.0 / np.sqrt(M_ref), 'k--', label='$O(1/\\sqrt{M})$ 参考线')
ax.set_xlabel('样本量 M')
ax.set_ylabel('绝对误差 |$\\hat{I}_M$ - 真实值|')
ax.set_title('收敛速率与维数无关')
ax.set_xscale('log')
ax.set_yscale('log')
ax.legend()

plt.tight_layout()
plt.savefig('实验4_1_Monte_Carlo积分.png', dpi=150)
plt.show()

print("结论：所有维数下收敛速率均为 O(1/√M)，与维数 d 无关。")
print("这正是 Monte Carlo 方法在高维逆问题中可行的根本原因。")
```

## 实验 4.2 Metropolis-Hastings 采样（1D 高斯混合）

**对应章节**：4.2 Metropolis-Hastings 算法
**知识点**：MCMC 基本思想；提议-接受/拒绝机制；细致平衡条件；随机游走 MH；trace plot；burn-in

### 实验目的

4.2 节是全章 MCMC 方法的起点——MH 通过"提议-接受/拒绝"构造以目标分布为平稳分布的马尔可夫链。本实验的目标是：

1. **直观理解** MH 算法的运行机制：每一步都是"试探→评估→接受/拒绝"
2. **观察**链从初始值逐步收敛到目标分布的过程（trace plot）
3. **对比**不同提议方差对接受率和混合速度的影响
4. **验证** MH 采样结果的直方图与真实目标密度吻合

### 场景描述

从双峰高斯混合分布 $p(x) = 0.3 \cdot \mathcal{N}(x; -3, 1) + 0.7 \cdot \mathcal{N}(x; 3, 1)$ 中用随机游走 MH 采样。初始值 $x_0 = 0$（位于两峰之间的低概率区域）。测试三种提议标准差 $\sigma_q = 0.5, 2.0, 10.0$，观察接受率、trace plot 和采样分布的差异。

### 预期结果

- $\sigma_q = 0.5$：接受率接近 1，但链移动极慢（步长太小），难以在两峰间跳跃
- $\sigma_q = 2.0$：接受率适中（~0.3-0.5），链混合良好，直方图与真实密度吻合
- $\sigma_q = 10.0$：接受率很低（大部分提议被拒绝），链长期停滞不动
- 三种情况的 trace plot 清楚展示"步长太小→混合慢"与"步长太大→拒绝多"的权衡

### 源代码

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# ========== Metropolis-Hastings 采样（1D 高斯混合）==========

def gaussian_mixture_pdf(x, weights=[0.3, 0.7], means=[-3, 3], stds=[1, 1]):
    """双峰高斯混合的密度函数"""
    p = np.zeros_like(x, dtype=float)
    for w, mu, sigma in zip(weights, means, stds):
        p += w / (sigma * np.sqrt(2 * np.pi)) * np.exp(-(x - mu)**2 / (2 * sigma**2))
    return p

def log_target(x):
    """目标分布的 log 密度（MH 只需要到归一化常数，但这里密度本身已知）"""
    weights, means, stds = [0.3, 0.7], [-3, 3], [1, 1]
    log_p = np.zeros_like(x, dtype=float)
    for w, mu, sigma in zip(weights, means, stds):
        log_p = np.logaddexp(log_p, np.log(w) - np.log(sigma) - 0.5 * ((x - mu) / sigma)**2)
    return log_p

def mh_random_walk(n_iter, sigma_q, x0=0.0):
    """
    随机游走 Metropolis-Hastings 采样
    
    参数:
        n_iter: 迭代次数
        sigma_q: 提议分布的标准差（对称随机游走）
        x0: 初始值
    返回:
        chain: 采样链
        acceptance_rate: 接受率
    """
    chain = np.zeros(n_iter)
    x = x0
    accepted = 0
    log_p_x = log_target(x)
    
    for i in range(n_iter):
        # 提议：x* ~ N(x, sigma_q^2)
        x_prop = x + sigma_q * np.random.randn()
        log_p_prop = log_target(x_prop)
        
        # 接受概率（对称提议，MH 比值简化）
        log_alpha = log_p_prop - log_p_x
        if np.log(np.random.rand()) < log_alpha:
            x = x_prop
            log_p_x = log_p_prop
            accepted += 1
        
        chain[i] = x
    
    acceptance_rate = accepted / n_iter
    return chain, acceptance_rate

# --- 实验 ---
n_iter = 10000
sigma_q_list = [0.5, 2.0, 10.0]
colors = ['#2196F3', '#4CAF50', '#F44336']

fig, axes = plt.subplots(3, 3, figsize=(16, 12))

for col, (sigma_q, color) in enumerate(zip(sigma_q_list, colors)):
    chain, acc_rate = mh_random_walk(n_iter, sigma_q, x0=0.0)
    
    # 第一行：trace plot（前 2000 步）
    ax = axes[0, col]
    ax.plot(chain[:2000], linewidth=0.3, color=color, alpha=0.7)
    ax.set_title(f'$\\sigma_q$={sigma_q}, 接受率={acc_rate:.3f}')
    ax.set_xlabel('迭代步')
    ax.set_ylabel('$x$')
    if col == 0:
        ax.set_ylabel('Trace plot\n$x$')
    
    # 第二行：完整 trace plot
    ax = axes[1, col]
    ax.plot(chain, linewidth=0.1, color=color, alpha=0.5)
    ax.set_xlabel('迭代步')
    ax.set_ylabel('$x$')
    if col == 0:
        ax.set_ylabel('完整链\n$x$')
    
    # 第三行：直方图 vs 真实密度
    ax = axes[2, col]
    x_grid = np.linspace(-8, 8, 500)
    ax.plot(x_grid, gaussian_mixture_pdf(x_grid), 'k-', linewidth=2, label='真实密度')
    ax.hist(chain, bins=80, range=(-8, 8), density=True, alpha=0.6, color=color, label='MH 采样')
    ax.set_xlabel('$x$')
    ax.set_ylabel('密度')
    ax.legend(fontsize=8)
    if col == 0:
        ax.set_ylabel('采样分布\n密度')

fig.suptitle('实验4.2 Metropolis-Hastings 采样（1D高斯混合）', fontsize=14, y=1.01)
plt.tight_layout()
plt.savefig('实验4_2_MH采样.png', dpi=150, bbox_inches='tight')
plt.show()

print(f"结论：")
print(f"  sigma_q=0.5 时接受率高但链混合慢，难以跨越两峰；")
print(f"  sigma_q=2.0 时接受率适中，链混合良好；")
print(f"  sigma_q=10.0 时接受率极低，链长期停滞。")
print(f"  MH 的核心权衡：步长太小→混合慢，步长太大→拒绝多。")
```

## 实验 4.3 MH 接受率随维数衰减

**对应章节**：4.2 Metropolis-Hastings 算法
**知识点**：高维灾难；随机游走 MH 的接受率随维数指数衰减；最优接受率 ≈ 0.234

### 实验目的

4.2 节指出随机游走 MH 在高维空间效率极低——接受率随维数 $d$ 指数衰减。本实验的目标是：

1. **定量验证**随机游走 MH 的接受率随维数 $d$ 快速下降
2. **观察**最优缩放 $\sigma_q = 2.38 / \sqrt{d}$ 下接受率趋于理论值 ≈ 0.234
3. **理解**为什么高维问题需要利用梯度信息（ULA）而非随机游走

### 场景描述

从 $d$ 维标准高斯 $\mathcal{N}(0, I_d)$ 中用随机游走 MH 采样。提议方差取两种策略：（1）固定 $\sigma_q = 1$；（2）最优缩放 $\sigma_q = 2.38 / \sqrt{d}$。维数 $d \in \{1, 2, 5, 10, 20, 50, 100\}$。

### 预期结果

- 固定 $\sigma_q = 1$：接受率随 $d$ 快速下降（高维时几乎为 0）
- 最优缩放 $\sigma_q = 2.38/\sqrt{d}$：接受率随 $d$ 增大趋于 ≈ 0.234（Roberts et al., 1997 的理论预测）
- 高维空间中随机游走 MH 的"高维灾难"：需要越来越多的迭代才能产生有效样本

### 源代码

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# ========== MH 接受率随维数衰减 ==========

def mh_acceptance_rate(d, sigma_q, n_iter=5000, n_warmup=1000):
    """
    从 d 维标准高斯 N(0, I_d) 中随机游走 MH 采样，
    返回 warmup 之后的接受率。
    """
    x = np.zeros(d)
    accepted = 0
    total = 0
    
    for i in range(n_iter + n_warmup):
        # 提议
        x_prop = x + sigma_q * np.random.randn(d)
        # 对数密度差（N(0,I) 的 log 密度）
        log_alpha = -0.5 * (np.sum(x_prop**2) - np.sum(x**2))
        if np.log(np.random.rand()) < log_alpha:
            x = x_prop
            if i >= n_warmup:
                accepted += 1
        if i >= n_warmup:
            total += 1
    
    return accepted / total

# --- 实验 ---
dimensions = [1, 2, 5, 10, 20, 50, 100]
n_repeats = 5  # 多次重复取平均

acc_fixed = []
acc_optimal = []

for d in dimensions:
    # 固定提议方差
    rates = [mh_acceptance_rate(d, 1.0) for _ in range(n_repeats)]
    acc_fixed.append(np.mean(rates))
    
    # 最优缩放
    sigma_opt = 2.38 / np.sqrt(d)
    rates = [mh_acceptance_rate(d, sigma_opt) for _ in range(n_repeats)]
    acc_optimal.append(np.mean(rates))
    
    print(f'd={d:3d}: 固定σ_q=1 接受率={acc_fixed[-1]:.4f}, '
          f'最优σ_q={sigma_opt:.3f} 接受率={acc_optimal[-1]:.4f}')

# --- 可视化 ---
fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(dimensions, acc_fixed, 'ro-', markersize=6, label='固定 $\\sigma_q = 1$')
ax.plot(dimensions, acc_optimal, 'bs-', markersize=6, label='最优缩放 $\\sigma_q = 2.38/\\sqrt{d}$')
ax.axhline(y=0.234, color='k', linestyle='--', alpha=0.7, label='理论最优接受率 ≈ 0.234')
ax.set_xlabel('维数 $d$')
ax.set_ylabel('接受率')
ax.set_title('随机游走 MH 的接受率随维数衰减')
ax.set_xscale('log')
ax.legend()
ax.set_ylim(-0.05, 1.05)
plt.tight_layout()
plt.savefig('实验4_3_MH接受率与维数.png', dpi=150)
plt.show()

print("结论：固定提议方差下，MH 接受率随维数指数衰减（高维灾难）。")
print("最优缩放 σ_q = 2.38/√d 可维持接受率≈0.234，但每步移动量随√d减小。")
print("这说明高维空间需要利用梯度信息（ULA），而非随机游走。")
```

## 实验 4.4 1D 高斯 ULA 采样与渐近方差验证

**对应章节**：4.3 ULA：Langevin 采样的 Euler 离散
**知识点**：ULA 递推式 $X_{m+1} = X_m + \delta \nabla \log p(X_m|y) + \sqrt{2\delta} Z_{m+1}$；Euler 离散化 Langevin SDE；渐近方差公式 $\text{Var} = 2/(2-\delta)$

### 实验目的

4.3 节从 Langevin 扩散 $dX_t = \nabla \log p(X_t|y) dt + \sqrt{2} dW_t$ 出发，通过 Euler 离散化得到 ULA。本实验的目标是：

1. **实现** ULA 采样算法，理解"梯度下降 + 噪声"的两步解读
2. **验证** ULA 的渐近方差公式 $\text{Var}_{\text{ULA}} = 2/(2-\delta)$（1D 高斯情形）
3. **观察** ULA 有偏但高效的特性：$\delta$ 越小偏差越小，但收敛越慢

### 场景描述

从 1D 标准高斯 $\mathcal{N}(0, 1)$ 中用 ULA 采样。势能 $U(x) = x^2/2$，梯度 $\nabla \log p(x) = -\nabla U(x) = -x$。ULA 递推式：$X_{m+1} = X_m - \delta X_m + \sqrt{2\delta} Z_{m+1} = (1-\delta) X_m + \sqrt{2\delta} Z_{m+1}$。比较 $\delta = 0.1$ 和 $\delta = 1.0$ 两种步长。

### 预期结果

- $\delta = 0.1$：ULA 直方图与真实密度几乎完全吻合（偏差小），渐近方差 ≈ 2/(2-0.1) ≈ 1.053
- $\delta = 1.0$：ULA 直方图与真实密度有一定偏差（方差偏大），渐近方差 ≈ 2/(2-1) = 2.0
- 验证：ULA 的经验方差与理论值 $2/(2-\delta)$ 一致

### 源代码

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# ========== 1D 高斯 ULA 采样与渐近方差验证 ==========

def ula_gauss(n_iter, delta, x0=0.0):
    """
    1D 标准高斯 N(0,1) 的 ULA 采样。
    势能 U(x) = x^2/2, ∇log p(x) = -x。
    ULA: X_{m+1} = X_m - δ*X_m + sqrt(2δ)*Z_{m+1}
                 = (1-δ)*X_m + sqrt(2δ)*Z_{m+1}
    
    返回:
        chain: 采样链
        var_empirical: 经验方差
        var_theory: 理论渐近方差 2/(2-δ)
    """
    chain = np.zeros(n_iter)
    x = x0
    for i in range(n_iter):
        z = np.random.randn()
        x = (1 - delta) * x + np.sqrt(2 * delta) * z
        chain[i] = x
    
    var_empirical = np.var(chain)
    var_theory = 2.0 / (2.0 - delta)
    return chain, var_empirical, var_theory

# --- 实验 ---
n_iter = 100000
delta_list = [0.1, 0.5, 1.0]

fig, axes = plt.subplots(2, 3, figsize=(16, 8))

x_grid = np.linspace(-4, 4, 500)
true_pdf = np.exp(-x_grid**2 / 2) / np.sqrt(2 * np.pi)

for col, delta in enumerate(delta_list):
    chain, var_emp, var_theory = ula_gauss(n_iter, delta)
    
    # 第一行：trace plot（前 2000 步）
    ax = axes[0, col]
    ax.plot(chain[:2000], linewidth=0.3, alpha=0.7)
    ax.set_title(f'δ = {delta}')
    ax.set_xlabel('迭代步')
    if col == 0:
        ax.set_ylabel('Trace plot\n$x$')
    
    # 第二行：直方图 vs 真实密度
    ax = axes[1, col]
    ax.plot(x_grid, true_pdf, 'k-', linewidth=2, label='真实密度 $\\mathcal{N}(0,1)$')
    ax.hist(chain, bins=100, range=(-4, 4), density=True, alpha=0.6, 
            label=f'ULA 采样')
    ax.set_xlabel('$x$')
    if col == 0:
        ax.set_ylabel('密度')
    ax.legend(fontsize=8)
    ax.set_title(f'δ={delta}: 经验方差={var_emp:.3f}, 理论方差={var_theory:.3f}')

fig.suptitle('实验4.4 1D高斯ULA采样与渐近方差验证', fontsize=14, y=1.01)
plt.tight_layout()
plt.savefig('实验4_4_ULA采样.png', dpi=150, bbox_inches='tight')
plt.show()

# --- 渐近方差公式验证 ---
print("\n渐近方差公式验证：Var_ULA = 2/(2-δ)")
print("-" * 50)
for delta in [0.01, 0.05, 0.1, 0.2, 0.5, 0.8, 1.0]:
    _, var_emp, var_theory = ula_gauss(n_iter, delta)
    print(f"δ={delta:.2f}: 经验方差={var_emp:.4f}, 理论={var_theory:.4f}, "
          f"相对误差={abs(var_emp-var_theory)/var_theory*100:.2f}%")

print("\n结论：ULA 的经验方差与理论值 2/(2-δ) 高度吻合。")
print("δ 越大，渐近方差越大（ULA 偏差越大）；δ→0 时方差→1（无偏）。")
```

## 实验 4.5 ULA 步长 δ 对收敛的影响

**对应章节**：4.3 ULA：Langevin 采样的 Euler 离散
**知识点**：步长条件 $\delta \leq 1/L$；偏差与收敛速度的权衡；ULA 不满足细致平衡

### 实验目的

4.3 节强调 ULA 的步长选择是偏差与收敛速度的权衡：$\delta$ 小偏差小但收敛慢，$\delta$ 大收敛快但偏差大。当 $\delta > 1/L$ 时链发散。本实验的目标是：

1. **观察**不同步长 $\delta$ 下 ULA 的收敛行为和偏差
2. **验证**步长条件 $\delta \leq 1/L$（$L=1$ 时，$\delta > 1$ 导致发散）
3. **量化**偏差随 $\delta$ 的变化趋势

### 场景描述

1D 标准高斯 $\mathcal{N}(0,1)$ 的 ULA 采样。$L=1$（$\nabla \log p(x) = -x$ 的 Lipschitz 常数），步长条件 $\delta \leq 1$。测试 $\delta = 0.01, 0.1, 0.5, 1.0, 1.5, 2.0$。

### 预期结果

- $\delta = 0.01$：直方图与真实密度精确吻合（偏差极小），但链需要很多步才收敛
- $\delta = 0.1, 0.5$：直方图与真实密度近似，偏差可接受
- $\delta = 1.0$：处于步长边界，方差偏大（理论值 2.0 vs 真实 1.0）
- $\delta > 1.0$：链发散——$|X_m|$ 趋向无穷大

### 源代码

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# ========== ULA 步长 δ 对收敛的影响 ==========

def ula_gauss_brief(n_iter, delta, x0=0.0):
    """1D 标准高斯 ULA，返回链和关键统计量"""
    chain = np.zeros(n_iter)
    x = x0
    for i in range(n_iter):
        z = np.random.randn()
        x_new = (1 - delta) * x + np.sqrt(2 * delta) * z
        # 检测发散
        if abs(x_new) > 1e6:
            chain[i:] = np.nan
            break
        x = x_new
        chain[i] = x
    return chain

n_iter = 50000
delta_list = [0.01, 0.1, 0.5, 1.0, 1.5, 2.0]
L = 1.0  # Lipschitz 常数

fig, axes = plt.subplots(2, 3, figsize=(16, 8))

x_grid = np.linspace(-5, 5, 500)
true_pdf = np.exp(-x_grid**2 / 2) / np.sqrt(2 * np.pi)

for idx, delta in enumerate(delta_list):
    row, col = idx // 3, idx % 3
    ax = axes[row, col]
    
    chain = ula_gauss_brief(n_iter, delta)
    valid = chain[~np.isnan(chain)]
    diverged = np.any(np.isnan(chain))
    
    if not diverged and len(valid) > 1000:
        ax.plot(x_grid, true_pdf, 'k-', linewidth=2, label='真实密度')
        ax.hist(valid[len(valid)//2:], bins=80, range=(-5, 5), 
                density=True, alpha=0.6, label='ULA 采样（后半段）')
        var_ula = np.var(valid[len(valid)//2:])
        var_theory = 2.0 / (2.0 - delta) if delta < 2 else float('inf')
        ax.set_title(f'δ={delta} (δ≤1/L={1/L:.1f}): Var={var_ula:.2f} '
                     f'(理论={var_theory:.2f})')
    else:
        ax.text(0.5, 0.5, f'δ={delta} > 1/L\n链发散！', 
                transform=ax.transAxes, ha='center', va='center',
                fontsize=14, color='red', fontweight='bold')
        ax.set_title(f'δ={delta} (δ>1/L={1/L:.1f}): 发散')
    
    ax.set_xlabel('$x$')
    if col == 0:
        ax.set_ylabel('密度')
    ax.legend(fontsize=7)

fig.suptitle('实验4.5 ULA步长δ对收敛的影响（L=1, δ≤1/L=1）', fontsize=14, y=1.01)
plt.tight_layout()
plt.savefig('实验4_5_ULA步长影响.png', dpi=150, bbox_inches='tight')
plt.show()

print("结论：")
print("  δ ≤ 1/L 时 ULA 收敛，偏差随 δ 增大而增大；")
print("  δ > 1/L 时 ULA 发散，样本绝对值趋向无穷。")
print("  步长选择的权衡：小δ→偏差小但收敛慢；大δ→收敛快但偏差大。")
print("  与梯度下降的步长条件 δ ≤ 1/L 完全一致——优化与采样的统一结构。")
```

## 实验 4.6 MH vs ULA vs MALA：收敛速度对比

**对应章节**：4.3 ULA：Langevin 采样的 Euler 离散
**知识点**：MH 无偏但慢；ULA 有偏但快；MALA（ULA 提议 + MH 校正）折中

### 实验目的

4.3 节的核心对比：MH 利用随机游走（无偏但高维慢），ULA 利用梯度（有偏但快），MALA 结合两者（无偏且较快）。本实验的目标是：

1. **实现** MALA（ULA 提议 + MH 接受/拒绝步）
2. **对比**三种方法在相同目标分布上的收敛速度和采样质量
3. **直观理解** ULA 的"偏差"和 MH 的"效率低"如何被 MALA 折中

### 场景描述

2D 高斯分布 $\mathcal{N}(0, I_2)$ 上三种方法对比。用 KL 散度（或 TV 距离的近似）衡量采样质量随迭代步数的改善。

### 预期结果

- MH（随机游走）：需要很多步才能从初始值到达高概率区域，但最终样本无偏
- ULA：利用梯度快速到达高概率区域，但样本分布略有偏差（方差偏大）
- MALA：兼具梯度方向性和 MH 的无偏性，收敛速度与 ULA 相当但无偏

### 源代码

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import multivariate_normal

np.random.seed(42)

# ========== MH vs ULA vs MALA ==========

def log_prob_2d(x, mu=np.zeros(2), Sigma=np.eye(2)):
    """2D 高斯的 log 密度"""
    diff = x - mu
    Sigma_inv = np.linalg.inv(Sigma)
    return -0.5 * diff @ Sigma_inv @ diff

def grad_log_prob_2d(x, mu=np.zeros(2), Sigma=np.eye(2)):
    """2D 高斯的 ∇log p(x)"""
    Sigma_inv = np.linalg.inv(Sigma)
    return -Sigma_inv @ (x - mu)

def mh_random_walk_2d(n_iter, sigma_q, x0=None):
    """2D 随机游走 MH"""
    if x0 is None:
        x0 = np.array([5.0, 5.0])
    chain = np.zeros((n_iter, 2))
    x = x0.copy()
    accepted = 0
    for i in range(n_iter):
        x_prop = x + sigma_q * np.random.randn(2)
        log_alpha = log_prob_2d(x_prop) - log_prob_2d(x)
        if np.log(np.random.rand()) < log_alpha:
            x = x_prop
            accepted += 1
        chain[i] = x
    return chain, accepted / n_iter

def ula_2d(n_iter, delta, x0=None):
    """2D ULA"""
    if x0 is None:
        x0 = np.array([5.0, 5.0])
    chain = np.zeros((n_iter, 2))
    x = x0.copy()
    for i in range(n_iter):
        z = np.random.randn(2)
        x = x + delta * grad_log_prob_2d(x) + np.sqrt(2 * delta) * z
        chain[i] = x
    return chain

def mala_2d(n_iter, delta, x0=None):
    """2D MALA = ULA 提议 + MH 校正"""
    if x0 is None:
        x0 = np.array([5.0, 5.0])
    chain = np.zeros((n_iter, 2))
    x = x0.copy()
    accepted = 0
    for i in range(n_iter):
        # ULA 提议
        z = np.random.randn(2)
        x_prop = x + delta * grad_log_prob_2d(x) + np.sqrt(2 * delta) * z
        
        # MH 校正：计算接受概率
        # q(x'|x) = N(x'; x + δ∇log p(x), 2δI)
        # q(x|x') = N(x; x' + δ∇log p(x'), 2δI)
        log_q_forward = -np.sum((x_prop - x - delta * grad_log_prob_2d(x))**2) / (4 * delta)
        log_q_backward = -np.sum((x - x_prop - delta * grad_log_prob_2d(x_prop))**2) / (4 * delta)
        log_alpha = (log_prob_2d(x_prop) + log_q_backward 
                     - log_prob_2d(x) - log_q_forward)
        
        if np.log(np.random.rand()) < log_alpha:
            x = x_prop
            accepted += 1
        chain[i] = x
    return chain, accepted / n_iter

# --- 实验 ---
n_iter = 5000
x0 = np.array([5.0, 5.0])  # 从远离目标的位置出发

chain_mh, acc_mh = mh_random_walk_2d(n_iter, sigma_q=1.0, x0=x0)
chain_ula = ula_2d(n_iter, delta=0.5, x0=x0)
chain_mala, acc_mala = mala_2d(n_iter, delta=0.5, x0=x0)

# --- 可视化 ---
fig, axes = plt.subplots(2, 3, figsize=(16, 9))
methods = [('MH (随机游走)', chain_mh), 
           ('ULA (梯度采样)', chain_ula), 
           ('MALA (ULA+MH校正)', chain_mala)]

# 第一行：2D 轨迹
for col, (name, chain) in enumerate(methods):
    ax = axes[0, col]
    # 绘制目标分布等高线
    xx, yy = np.meshgrid(np.linspace(-4, 6, 100), np.linspace(-4, 6, 100))
    pos = np.dstack((xx, yy))
    rv = multivariate_normal(mean=np.zeros(2), cov=np.eye(2))
    ax.contour(xx, yy, rv.pdf(pos), levels=5, alpha=0.3, colors='blue')
    # 绘制轨迹
    burn = min(200, len(chain))
    ax.plot(chain[:burn, 0], chain[:burn, 1], 'r-', linewidth=0.3, alpha=0.5, label='前200步')
    ax.plot(chain[burn:, 0], chain[burn:, 1], 'g.', markersize=0.5, alpha=0.3, label='后续')
    ax.plot(x0[0], x0[1], 'k*', markersize=10, label='初始值')
    ax.set_title(name)
    ax.set_xlim(-4, 6)
    ax.set_ylim(-4, 6)
    ax.set_aspect('equal')
    ax.legend(fontsize=7)

# 第二行：x₁ 分量的直方图 vs 真实密度
x_grid = np.linspace(-4, 4, 200)
true_pdf = np.exp(-x_grid**2 / 2) / np.sqrt(2 * np.pi)

for col, (name, chain) in enumerate(methods):
    ax = axes[1, col]
    ax.plot(x_grid, true_pdf, 'k-', linewidth=2, label='真实密度')
    ax.hist(chain[len(chain)//2:, 0], bins=60, range=(-4, 4), 
            density=True, alpha=0.6, label='采样（后半段）')
    ax.set_xlabel('$x_1$')
    ax.set_ylabel('密度')
    ax.legend(fontsize=8)
    
    # 添加接受率信息
    if 'MH' in name:
        ax.set_title(f'{name}: 接受率={acc_mh:.3f}')
    elif 'MALA' in name:
        ax.set_title(f'{name}: 接受率={acc_mala:.3f}')
    else:
        ax.set_title(f'{name}: 有偏（无接受/拒绝）')

fig.suptitle('实验4.6 MH vs ULA vs MALA收敛速度对比', fontsize=14, y=1.01)
plt.tight_layout()
plt.savefig('实验4_6_MH_vs_ULA_vs_MALA.png', dpi=150, bbox_inches='tight')
plt.show()

print("结论：")
print("  MH：从远处出发时需要很多步才能到达目标区域，但最终无偏。")
print("  ULA：利用梯度快速到达目标区域，但直方图略有偏差（方差偏大）。")
print("  MALA：兼具梯度方向性和MH无偏性，是最优折中方案。")
print("  在高维图像逆问题中，ULA偏差通常可接受，计算效率优于MALA。")
```

## 实验 4.7 Moreau-Yoshida 包络可视化

**对应章节**：4.4 MYULA：近端 ULA
**知识点**：Moreau-Yoshida 包络 $g_\lambda(x) = \inf_u \{g(u) + \frac{1}{2\lambda}\|u-x\|^2\}$；光滑化效果；参数 $\lambda$ 的影响；近端算子 $\text{prox}_{\lambda g}(x)$

### 实验目的

4.4 节用 Moreau-Yoshida 包络光滑化不可微势能 $g(x)$，使 ULA 可以在近似分布上运行。本实验的目标是：

1. **直观理解** Moreau-Yoshida 包络的光滑化机制：$g_\lambda$ 是 $g$ 的光滑近似
2. **观察**参数 $\lambda$ 的权衡：$\lambda$ 小→逼近好但梯度 Lipschitz 常数大；$\lambda$ 大→更光滑但偏离 $g$
3. **验证**近端算子的几何含义：$\text{prox}_{\lambda g}(x)$ 是 $g$ 的"最近点"

### 场景描述

以 $g(x) = |x|$（L1 范数，1D 情况）为例。Moreau-Yoshida 包络：
$$g_\lambda(x) = \inf_u \left\{|u| + \frac{1}{2\lambda}(u-x)^2\right\}$$
其近端算子即软阈值函数：$\text{prox}_{\lambda g}(x) = \text{sign}(x) \max(|x|-\lambda, 0)$
梯度：$\nabla g_\lambda(x) = (x - \text{prox}_{\lambda g}(x)) / \lambda$

对不同 $\lambda = 0.01, 0.1, 0.5, 1.0$，绘制 $g(x)$、$g_\lambda(x)$、$\nabla g_\lambda(x)$ 和 $\text{prox}_{\lambda g}(x)$。

### 预期结果

- $\lambda$ 小（如 0.01）：$g_\lambda \approx g$（尖角处仅略微圆滑），梯度在 $x=0$ 附近陡峭
- $\lambda$ 大（如 1.0）：$g_\lambda$ 明显偏离 $g$（尖角被大幅平滑），梯度更温和
- $\text{prox}_{\lambda g}(x)$ 的软阈值行为清晰可见：$|x| > \lambda$ 时 $\text{prox} = x - \lambda \text{sign}(x)$；$|x| \leq \lambda$ 时 $\text{prox} = 0$
- $\nabla g_\lambda(x)$ 在 $x=0$ 处取值 $= 1/\lambda$——$\lambda$ 越小，梯度越大，Lipschitz 常数 $L \leq L_f + 1/\lambda$ 越大

### 源代码

```python
import numpy as np
import matplotlib.pyplot as plt

# ========== Moreau-Yoshida 包络可视化 ==========

def soft_thresholding(x, lam):
    """g(x)=|x| 的近端算子：软阈值函数"""
    return np.sign(x) * np.maximum(np.abs(x) - lam, 0)

def g_l1(x):
    """g(x) = |x|"""
    return np.abs(x)

def g_moreau(x, lam):
    """g(x)=|x| 的 Moreau-Yoshida 包络 g_λ(x)"""
    prox = soft_thresholding(x, lam)
    return g_l1(prox) + (x - prox)**2 / (2 * lam)

def grad_g_moreau(x, lam):
    """∇g_λ(x) = (x - prox_{λg}(x)) / λ"""
    return (x - soft_thresholding(x, lam)) / lam

# --- 可视化 ---
x = np.linspace(-3, 3, 1000)
lambdas = [0.01, 0.1, 0.5, 1.0]
colors = ['#E53935', '#FB8C00', '#43A047', '#1E88E5']

fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# 左上：g 和 g_λ
ax = axes[0, 0]
ax.plot(x, g_l1(x), 'k-', linewidth=2, label='$g(x)=|x|$')
for lam, c in zip(lambdas, colors):
    ax.plot(x, g_moreau(x, lam), '--', color=c, linewidth=1.5, label=f'$g_\\lambda(x), \\lambda={lam}$')
ax.set_xlabel('$x$')
ax.set_ylabel('函数值')
ax.set_title('Moreau-Yoshida 包络 $g_\\lambda(x)$ vs 原始 $g(x)$')
ax.legend()
ax.set_ylim(-0.1, 3.5)

# 右上：∇g_λ
ax = axes[0, 1]
# 次梯度 ∂g(x) = sign(x) for x≠0, [-1,1] for x=0
ax.plot(x[x<0], -np.ones_like(x[x<0]), 'k-', linewidth=2, label='$\\partial g(x)$（次梯度）')
ax.plot(x[x>0], np.ones_like(x[x>0]), 'k-', linewidth=2)
ax.plot([0], [0], 'ko', markersize=4)
ax.plot([-3, 0], [-1, -1], 'k--', linewidth=0.5, alpha=0.3)
ax.plot([0, 3], [1, 1], 'k--', linewidth=0.5, alpha=0.3)
for lam, c in zip(lambdas, colors):
    ax.plot(x, grad_g_moreau(x, lam), '--', color=c, linewidth=1.5, 
            label=f'$\\nabla g_\\lambda(x), \\lambda={lam}$')
ax.set_xlabel('$x$')
ax.set_ylabel('梯度值')
ax.set_title('$\\nabla g_\\lambda(x)$：光滑化后的梯度')
ax.legend(fontsize=8)
ax.set_ylim(-3, 3)

# 左下：prox_{λg}(x)
ax = axes[1, 0]
ax.plot(x, x, 'k-', linewidth=1, alpha=0.3, label='$y=x$（参考）')
for lam, c in zip(lambdas, colors):
    ax.plot(x, soft_thresholding(x, lam), '--', color=c, linewidth=1.5, 
            label=f'$\\mathrm{{prox}}_{{\\lambda g}}(x), \\lambda={lam}$')
ax.set_xlabel('$x$')
ax.set_ylabel('$\\mathrm{prox}_{\\lambda g}(x)$')
ax.set_title('近端算子 $\\mathrm{prox}_{\\lambda g}(x)$（软阈值函数）')
ax.legend()

# 右下：逼近误差 g_λ - g
ax = axes[1, 1]
for lam, c in zip(lambdas, colors):
    error = g_moreau(x, lam) - g_l1(x)
    ax.plot(x, error, '-', color=c, linewidth=1.5, label=f'$\\lambda={lam}$')
ax.set_xlabel('$x$')
ax.set_ylabel('$g_\\lambda(x) - g(x)$')
ax.set_title('逼近误差 $g_\\lambda(x) - g(x)$（始终 ≤ 0）')
ax.legend()

fig.suptitle('实验4.7 Moreau-Yoshida包络可视化（$g(x)=|x|$）', fontsize=14, y=1.01)
plt.tight_layout()
plt.savefig('实验4_7_Moreau_Yoshida包络.png', dpi=150, bbox_inches='tight')
plt.show()

print("结论：")
print("  λ 小：g_λ 接近 g（逼近好），但 ∇g_λ 在 x=0 附近陡峭（Lipschitz 常数大=1/λ）。")
print("  λ 大：g_λ 明显偏离 g（逼近差），但 ∇g_λ 温和（Lipschitz 常数小）。")
print("  MYULA 的权衡：λ 小→近似误差小但步长δ小→收敛慢；λ 大→步长大但偏差大。")
print("  这与 4.3 节 ULA 的步长权衡完全类似——偏差与效率的权衡贯穿采样方法。")
```

## 实验 4.8 MYULA 采样：不可微后验的处理

**对应章节**：4.4 MYULA：近端 ULA
**知识点**：MYULA 算法；近端算子替代不可微梯度；L1 先验 + 高斯似然

### 实验目的

4.4 节将 ULA 扩展到不可微后验：用 Moreau-Yoshida 包络光滑化不可微项 $g(x)$，在近似分布 $p_\lambda$ 上运行 ULA。本实验的目标是：

1. **实现** MYULA 算法，理解"光滑梯度步 + 近端校正步 + 噪声步"的三步解读
2. **对比** MYULA 与 Huber 近似 ULA 在不可微后验上的采样结果
3. **验证** MYULA 采样结果的直方图与真实后验密度吻合

### 场景描述

1D 后验分布：$p(x|y) \propto \exp\{-\frac{1}{2\sigma^2}(y-x)^2 - \lambda|x|\}$，即 Laplace 先验 + 高斯似然。此分布为非对称 Laplace 分布，有解析解，便于验证。

参数：$y = 1.0$, $\sigma = 0.5$, $\lambda = 2.0$。Moreau-Yoshida 参数 $\lambda_{MY} = 0.1$。

MYULA 递推式：
$$X_{m+1} = (1 - \frac{\delta}{\lambda_{MY}})X_m - \delta \nabla f(X_m) + \frac{\delta}{\lambda_{MY}} \text{prox}_{\lambda_{MY} g}(X_m) + \sqrt{2\delta} Z_{m+1}$$

其中 $f(x) = \frac{1}{2\sigma^2}(y-x)^2$，$\nabla f(x) = (x-y)/\sigma^2$，$\text{prox}_{\lambda_{MY} g}(x) = \text{soft\_thresholding}(x, \lambda_{MY} \cdot \lambda)$。

### 预期结果

- MYULA 直方图与真实非对称 Laplace 后验密度吻合
- 与直接用次梯度（非光滑）的 ULA 对比，MYULA 更稳定
- 近端算子的"软阈值校正"使链在 $x=0$ 附近的行为正确

### 源代码

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import laplace_asymmetric

np.random.seed(42)

# ========== MYULA 采样：不可微后验 ==========

def soft_thresholding(x, tau):
    """软阈值函数 = prox_{tau*|·|}(x)"""
    return np.sign(x) * np.maximum(np.abs(x) - tau, 0)

def asymmetric_laplace_pdf(x, y, sigma, lam):
    """
    p(x|y) ∝ exp(-(y-x)²/(2σ²) - λ|x|)
    这是不对称 Laplace 分布，解析解可用。
    """
    kappa = sigma**2 * lam
    # 使用数值归一化
    log_unnorm = -(y - x)**2 / (2 * sigma**2) - lam * np.abs(x)
    log_unnorm -= np.max(log_unnorm)  # 数值稳定性
    pdf = np.exp(log_unnorm)
    pdf /= np.trapz(pdf, x)
    return pdf

def myula_1d(n_iter, delta, lam_my, y, sigma, lam_prior, x0=0.0):
    """
    MYULA 采样 1D 不可微后验 p(x|y) ∝ exp(-f(x) - g(x))
    f(x) = (y-x)²/(2σ²)  （光滑）
    g(x) = λ|x|           （不可微）
    
    MYULA: X_{m+1} = (1-δ/λ_MY)X_m - δ∇f(X_m) 
                     + (δ/λ_MY)prox_{λ_MY·g}(X_m) + √(2δ)Z_{m+1}
    """
    chain = np.zeros(n_iter)
    x = x0
    for i in range(n_iter):
        z = np.random.randn()
        # 光滑梯度步
        grad_f = (x - y) / sigma**2
        # 近端校正步
        prox = soft_thresholding(x, lam_my * lam_prior)
        # MYULA 更新
        x = (1 - delta / lam_my) * x - delta * grad_f \
            + (delta / lam_my) * prox + np.sqrt(2 * delta) * z
        chain[i] = x
    return chain

def ula_subgrad_1d(n_iter, delta, y, sigma, lam_prior, x0=0.0):
    """
    用次梯度替代梯度的 ULA（不推荐，仅作对比）。
    g(x)=λ|x| 的次梯度：∂g(0) ∈ [-λ, λ]，取 0。
    """
    chain = np.zeros(n_iter)
    x = x0
    for i in range(n_iter):
        z = np.random.randn()
        grad_f = (x - y) / sigma**2
        # 次梯度（在 x=0 处取 0）
        subgrad_g = lam_prior * np.sign(x) if abs(x) > 1e-10 else 0.0
        x = x - delta * (grad_f + subgrad_g) + np.sqrt(2 * delta) * z
        chain[i] = x
    return chain

# --- 参数 ---
y = 1.0

# Lipschitz 常数
```

## 实验 4.9 2D 图像 ULA 后验采样（去卷积）

**对应章节**：4.3/4.4 ULA 与 MYULA
**知识点**：高维 ULA；后验分布采样；势能函数 $U(x) = -\log p(x|y)$；Huber-TV 近似；Lipschitz 常数计算；后验均值（MMSE 估计）

### 实验目的

4.3-4.4 节将 ULA 应用于图像逆问题。本实验的目标是：

1. **实现**完整的 2D 图像 ULA 后验采样流程：构建正向模型→计算势能梯度→运行 ULA→后验均值与方差
2. **理解** Huber-TV 近似如何使 TV 正则化可微
3. **观察**后验均值（MMSE 估计）与单样本的差异——采样提供的不止一个重建

### 场景描述

观测模型 $y = Ax + n$，其中 $A$ 是均匀模糊卷积算子，$n \sim \mathcal{N}(0, \sigma^2 I)$。后验 $p(x|y) \propto \exp\{-\frac{1}{2\sigma^2}\|Ax-y\|^2 - \lambda \text{TV}(x)\}$。用 Huber-TV 近似使 TV 可微，运行 ULA 采样。

### 预期结果

- 后验均值（MMSE 估计）比模糊观测清晰，PSNR 明显提升
- 后验标准差在边缘和纹理区域较大（不确定性高），在平坦区域较小
- 单个样本仍含噪声，但后验均值已平滑——"采样平均"等价于"去噪"
- MMSE 误差随迭代收敛

### 源代码

```python
import numpy as np
import matplotlib.pyplot as plt
import math
from skimage.data import camera
from skimage.transform import resize

np.random.seed(42)

# ========== 2D 图像 ULA 后验采样（去卷积）==========

# --- 辅助函数 ---

def kernel_uniform(n_row, n_col, s):
    """创建 (2s+1, 2s+1) 均匀模糊核"""
    h = np.zeros((n_row, n_col))
    h[0:s+1, 0:s+1] = np.ones((s+1, s+1)) / (2*s+1)**2
    h[0:s+1, -s:] = np.ones((s+1, s)) / (2*s+1)**2
    h[-s:, 0:s+1] = np.ones((s, s+1)) / (2*s+1)**2
    h[-s:, -s:] = np.ones((s, s)) / (2*s+1)**2
    return h

def convol_periodic(a, b):
    """周期卷积（FFT 实现）"""
    return np.real(np.fft.ifft2(np.fft.fft2(a) * np.fft.fft2(b)))

def grad_image(im):
    """图像梯度（前向差分）"""
    nr, nc = im.shape
    gx = im[:, 1:] - im[:, :-1]
    gx = np.block([gx, np.zeros((nr, 1))])
    gy = im[1:, :] - im[:-1, :]
    gy = np.block([[gy], [np.zeros((1, nc))]])
    return gx, gy

def div_image(cx, cy):
    """图像散度（梯度的伴随算子）"""
    nr, nc = cx.shape
    div_x = cx[:, :-1] - cx[:, 1:]
    div_x = np.block([cx[:, 0:1], div_x])  # 前向差分的伴随
    div_y = cy[:-1, :] - cy[1:, :]
    div_y = np.block([[cy[0:1, :]], div_y])
    return div_x + div_y

def grad_htv(im, eps):
    """Huber-TV 的梯度"""
    gx, gy = grad_image(im)
    norme = np.sqrt(gx**2 + gy**2)
    # ||g|| < eps 时：梯度 = -(1/eps)*div(g)
    temp1 = -(1.0 / eps) * div_image(gx, gy)
    # ||g|| >= eps 时：梯度 = -div(g/||g||)
    temp2 = -div_image(gx / (norme + 1e-15), gy / (norme + 1e-15))
    return temp1 * (norme < eps) + temp2 * (norme >= eps)

def psnr(im_0, im_rest):
    """计算 PSNR"""
    mse = np.mean((im_0 - im_rest)**2)
    if mse == 0:
        return float('inf')
    return -10 * math.log10(mse)

def ula_deblurring(im_blurred, im_orig, sigma, delta, lambd, epsilon, h,
                   inter=10, n_iter=10000, n_burn_in=1000):
    """
    ULA 去卷积后验采样
    
    参数:
        im_blurred: 模糊含噪图像
        im_orig: 原始图像（计算误差用）
        sigma: 噪声标准差
        delta: ULA 步长
        lambd: TV 正则化参数
        epsilon: Huber-TV 参数
        h: 模糊核
        inter: 保存间隔
        n_iter: 总迭代数
        n_burn_in: burn-in 迭代数
    
    返回:
        X_mean: 后验均值（MMSE 估计）
        Xf: 最后一个样本
        std: 后验标准差
        MMSE_error: MMSE 误差收敛曲线
    """
    nr, nc = im_blurred.shape
    X_mean = np.copy(im_blurred)
    X_2 = np.zeros((nr, nc))
    MMSE_error = []
    X = np.zeros((nr, nc))  # 初始化
    
    # 共轭核
    h_fft = np.fft.fft2(h)
    hc_fft = np.conj(h_fft)
    
    for i in range(n_iter):
        Z = np.random.randn(nr, nc)
        # 计算 ∇U(x) = (A^T Ax - A^T y)/σ² + λ∇HTV(x)
        Ax = np.real(np.fft.ifft2(h_fft * np.fft.fft2(X)))
        ATAx = np.real(np.fft.ifft2(hc_fft * h_fft * np.fft.fft2(X)))
        ATy = np.real(np.fft.ifft2(hc_fft * np.fft.fft2(im_blurred)))
        grad_U = (ATAx - ATy) / sigma**2 + lambd * grad_htv(X, epsilon)
        
        # ULA 步：X_{m+1} = X_m - δ∇U(X_m) + √(2δ)Z
        X = X - delta * grad_U + np.sqrt(2 * delta) * Z
        
        # Burn-in 后在线计算均值和方差
        if i >= n_burn_in:
            k = i - n_burn_in
            X_mean = k / (k + 1) * X_mean + 1.0 / (k + 1) * X
            X_2 = k / (k + 1) * X_2 + 1.0 / (k + 1) * (X**2)
            MMSE_error.append(np.sqrt(np.mean((X_mean - im_orig)**2)))
    
    var = X_2 - X_mean**2
    std = np.sqrt(np.maximum(var, 0))
    
    return X_mean, X, std, MMSE_error

# --- 准备图像 ---
im = camera().astype(float) / 255.0
# 裁剪为 128×128 以加速计算
im = resize(im, (128, 128), anti_aliasing=True)

# 模糊 + 噪声
sigma = 0.02
h = kernel_uniform(im.shape[0], im.shape[1], 3)
im_blurred = convol_periodic(im, h) + sigma * np.random.randn(*im.shape)

# --- ULA 参数 ---
lambd = 20.0
epsilon = 0.01
L = 1.0 / sigma**2 + 8 * lambd / epsilon  # Lipschitz 常数
delta = 1.0 / L  # 步长 δ = 1/L
n_iter = 15000
n_burn_in = int(0.1 * n_iter)

print(f"ULA 参数：")
print(f"  Lipschitz 常数 L = 1/σ² + 8λ/ε = {L:.1f}")
print(f"  步长 δ = 1/L = {delta:.6f}")
print(f"  总迭代 = {n_iter}, burn-in = {n_burn_in}")

# --- 运行 ULA ---
X_mean, Xf, std, MMSE_error = ula_deblurring(
    im_blurred, im, sigma, delta, lambd, epsilon, h,
    inter=10, n_iter=n_iter, n_burn_in=n_burn_in
)

# --- 可视化 ---
fig, axes = plt.subplots(2, 3, figsize=(15, 10))

axes[0, 0].imshow(im, cmap='gray', vmin=0, vmax=1)
axes[0, 0].set_title(f'原始图像')
axes[0, 0].axis('off')

axes[0, 1].imshow(im_blurred, cmap='gray', vmin=0, vmax=1)
axes[0, 1].set_title(f'模糊+噪声 (PSNR={psnr(im, im_blurred):.2f} dB)')
axes[0, 1].axis('off')

axes[0, 2].imshow(X_mean, cmap='gray', vmin=0, vmax=1)
axes[0, 2].set_title(f'后验均值/MMSE (PSNR={psnr(im, X_mean):.2f} dB)')
axes[0, 2].axis('off')

axes[1, 0].imshow(Xf, cmap='gray', vmin=0, vmax=1)
axes[1, 0].set_title(f'单个样本 (PSNR={psnr(im, Xf):.2f} dB)')
axes[1, 0].axis('off')

axes[1, 1].imshow(std, cmap='hot')
axes[1, 1].set_title('后验标准差（不确定性）')
axes[1, 1].axis('off')

axes[1, 2].plot(MMSE_error)
axes[1, 2].set_title('MMSE 误差收敛')
axes[1, 2].set_xlabel('迭代步（burn-in 后）')
axes[1, 2].set_ylabel('RMSE')

fig.suptitle('实验4.9 2D图像ULA后验采样（去卷积）', fontsize=14, y=1.01)
plt.tight_layout()
plt.savefig('实验4_9_2D图像ULA采样.png', dpi=150, bbox_inches='tight')
plt.show()

print(f"\n结果：")
print(f"  模糊观测 PSNR = {psnr(im, im_blurred):.2f} dB")
print(f"  后验均值 PSNR = {psnr(im, X_mean):.2f} dB")
print(f"  单个样本 PSNR = {psnr(im, Xf):.2f} dB")
print(f"  后验均值显著优于单个样本——'采样平均'等价于'去噪'。")
print(f"  后验标准差反映不确定性：边缘区域不确定性高，平坦区域低。")
```

## 实验 4.10 Gibbs 采样：2D 高斯条件采样

**对应章节**：4.5 Gibbs 采样：利用条件结构的采样
**知识点**：Gibbs 交替条件采样；条件分布 $p_{X_1|X_2}$ 和 $p_{X_2|X_1}$；Gibbs 采样轨迹；Gibbs = 带噪声的 Gauss-Seidel

### 实验目的

4.5 节指出 Gibbs 采样不利用梯度信息，而是利用后验的条件分布结构。本实验的目标是：

1. **实现** 2D 高斯分布的 Gibbs 采样，理解"交替条件采样"的机制
2. **观察** Gibbs 采样轨迹——交替沿坐标轴方向移动（"阶梯形"路径）
3. **对比** Gibbs 与 ULA 的采样轨迹差异
4. **验证** Gibbs = 带噪声的 Gauss-Seidel 迭代

### 场景描述

从 2D 高斯 $\mathcal{N}(\mu, \Sigma)$ 中 Gibbs 采样，其中 $\mu = (0, 0)$，$\Sigma = \begin{pmatrix} 1 & 0.8 \\ 0.8 & 1 \end{pmatrix}$。条件分布为：
- $X_1 | X_2 = x_2 \sim \mathcal{N}(\rho x_2, 1-\rho^2)$
- $X_2 | X_1 = x_1 \sim \mathcal{N}(\rho x_1, 1-\rho^2)$

其中 $\rho = 0.8$。

### 预期结果

- Gibbs 采样轨迹呈"阶梯形"——每次只沿一个坐标轴移动
- 相关性 $\rho=0.8$ 时链混合较慢（沿主轴方向移动缓慢）
- 与 ULA 的"自由移动"轨迹形成对比
- Gibbs 的条件方差 $1-\rho^2 = 0.36$ 比边缘方差 1 小——条件采样利用了相关性

### 源代码

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import multivariate_normal

np.random.seed(42)

# ========== Gibbs 采样：2D 高斯条件采样 ==========

def gibbs_2d_gaussian(n_iter, rho, x0=None):
    """
    2D 高斯 N(0, Σ) 的 Gibbs 采样
    Σ = [[1, ρ], [ρ, 1]]
    
    条件分布:
      X1|X2=x2 ~ N(ρx2, 1-ρ²)
      X2|X1=x1 ~ N(ρx1, 1-ρ²)
    """
    if x0 is None:
        x0 = np.array([3.0, -3.0])
    chain = np.zeros((n_iter, 2))
    x1, x2 = x0
    cond_var = 1 - rho**2  # 条件方差
    
    for i in range(n_iter):
        # 采样 X1 | X2
        x1 = rho * x2 + np.sqrt(cond_var) * np.random.randn()
        # 采样 X2 | X1
        x2 = rho * x1 + np.sqrt(cond_var) * np.random.randn()
        chain[i] = [x1, x2]
    
    return chain

def ula_2d_gaussian(n_iter, delta, rho, x0=None):
    """
    2D 高斯 N(0, Σ) 的 ULA 采样，用于对比。
    Σ = [[1, ρ], [ρ, 1]], Σ_inv = 1/(1-ρ²)*[[1, -ρ], [-ρ, 1]]
    ∇log p(x) = -Σ_inv @ x
    """
    if x0 is None:
        x0 = np.array([3.0, -3.0])
    Sigma_inv = np.array([[1, -rho], [-rho, 1]]) / (1 - rho**2)
    chain = np.zeros((n_iter, 2))
    x = x0.copy()
    
    for i in range(n_iter):
        z = np.random.randn(2)
        x = x - delta * (Sigma_inv @ x) + np.sqrt(2 * delta) * z
        chain[i] = x
    
    return chain

# --- 实验 ---
rho = 0.8
n_iter = 5000
x0 = np.array([3.0, -3.0])

chain_gibbs = gibbs_2d_gaussian(n_iter, rho, x0)
chain_ula = ula_2d_gaussian(n_iter, delta=0.3, rho=rho, x0=x0)

# --- 可视化 ---
fig, axes = plt.subplots(2, 2, figsize=(14, 12))

# 目标分布等高线
xx, yy = np.meshgrid(np.linspace(-4, 4, 200), np.linspace(-4, 4, 200))
pos = np.dstack((xx, yy))
Sigma = np.array([[1, rho], [rho, 1]])
rv = multivariate_normal(mean=np.zeros(2), cov=Sigma)

# 第一行：轨迹
burn = 50
for col, (name, chain) in enumerate([('Gibbs 采样', chain_gibbs), ('ULA 采样', chain_ula)]):
    ax = axes[0, col]
    ax.contour(xx, yy, rv.pdf(pos), levels=8, alpha=0.3, colors='blue')
    ax.plot(chain[:burn, 0], chain[:burn, 1], 'r-', linewidth=0.5, alpha=0.7, label=f'前{burn}步')
    ax.plot(chain[burn:300, 0], chain[burn:300, 1], 'g-', linewidth=0.3, alpha=0.5, label='后续')
    ax.plot(x0[0], x0[1], 'k*', markersize=10, label='初始值')
    ax.set_title(name)
    ax.set_xlim(-4, 4)
    ax.set_ylim(-4, 4)
    ax.set_aspect('equal')
    ax.legend(fontsize=8)

# 第二行：直方图
x_grid = np.linspace(-4, 4, 200)
marginal_pdf = np.exp(-x_grid**2 / 2) / np.sqrt(2 * np.pi)  # 边缘分布 N(0,1)

for col, (name, chain) in enumerate([('Gibbs 采样', chain_gibbs), ('ULA 采样', chain_ula)]):
    ax = axes[1, col]
    ax.plot(x_grid, marginal_pdf, 'k-', linewidth=2, label='真实边缘密度')
    ax.hist(chain[n_iter//2:, 0], bins=60, range=(-4, 4), density=True, alpha=0.6, label='采样')
    ax.set_xlabel('$x_1$')
    ax.set_ylabel('密度')
    ax.legend(fontsize=8)
    ax.set_title(f'{name}: $x_1$ 的边缘分布')

fig.suptitle(f'实验4.10 Gibbs采样 vs ULA（ρ={rho}）', fontsize=14, y=1.01)
plt.tight_layout()
plt.savefig('实验4_10_Gibbs采样.png', dpi=150, bbox_inches='tight')
plt.show()

print("结论：")
print("  Gibbs 采样轨迹呈'阶梯形'——每次只沿一个坐标轴移动。")
print("  ULA 采样轨迹更'自由'——可以沿任意方向移动（利用梯度信息）。")
print("  高相关性(ρ=0.8)时 Gibbs 混合较慢，ULA 更高效。")
print("  Gibbs = 带噪声的 Gauss-Seidel 迭代：条件均值 = Gauss-Seidel 步，条件方差 = 噪声。")
```

## 实验 4.11 ILA 惯性 Langevin 算法

**对应章节**：4.6 加速采样方法：过松弛与惯性 Langevin 算法
**知识点**：ILA 递推式 $X_{m+1} = X_m - \gamma \nabla E(X_m) + \beta(X_m - X_{m-1}) + \sqrt{2\gamma(1-\beta)} N_m$；动量加速；欠阻尼 Langevin SDE 的离散化

### 实验目的

4.6 节将优化中的动量加速迁移到采样：ILA = 重球法 + 噪声。本实验的目标是：

1. **实现** ILA 算法，理解"动量项"如何帮助加速采样
2. **对比** ILA 与 ULA 的自相关函数——ILA 的负自相关加速探索
3. **观察**动量参数 $\beta$ 的影响

### 场景描述

1D 标准高斯 $\mathcal{N}(0,1)$ 上 ULA vs ILA 对比。ILA 取 $\omega = 1.5$（过松弛参数），$\gamma = \omega^2 \tau$，$\beta = (1-\omega)^2 = 0.25$。

### 预期结果

- ULA 样本自相关为正且缓慢衰减
- ILA 样本出现负自相关——样本在均值两侧交替跳跃，加速探索
- ILA 的有效样本量（ESS）高于 ULA

### 源代码

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# ========== ILA 惯性 Langevin 算法 ==========

def ula_1d(n_iter, delta, x0=0.0):
    """1D 标准高斯 ULA"""
    chain = np.zeros(n_iter)
    x = x0
    for i in range(n_iter):
        z = np.random.randn()
        x = (1 - delta) * x + np.sqrt(2 * delta) * z
        chain[i] = x
    return chain

def ila_1d(n_iter, tau, omega, x0=0.0):
    """
    1D 标准高斯 ILA（惯性 Langevin 算法）
    
    ILA: X_{m+1} = X_m - γ∇E(X_m) + β(X_m - X_{m-1}) + √(2γ(1-β))N_m
    其中 γ = ω²τ, β = (1-ω)²
    
    对于 N(0,1)：∇E(x) = x
    """
    gamma = omega**2 * tau
    beta = (1 - omega)**2
    
    chain = np.zeros(n_iter)
    x = x0
    x_prev = x0
    
    for i in range(n_iter):
        z = np.random.randn()
        x_new = x - gamma * x + beta * (x - x_prev) + np.sqrt(2 * gamma * (1 - beta)) * z
        x_prev = x
        x = x_new
        chain[i] = x
    
    return chain

def autocorrelation(chain, max_lag=200):
    """计算自相关函数"""
    n = len(chain)
    chain_centered = chain - np.mean(chain)
    acf = np.zeros(max_lag)
    for k in range(max_lag):
        if k < n:
            acf[k] = np.sum(chain_centered[:n-k] * chain_centered[k:]) / (n - k)
    acf /= acf[0]
    return acf

def ess(chain, max_lag=200):
    """计算有效样本量 ESS = M / (1 + 2∑ρ_k)"""
    acf = autocorrelation(chain, max_lag)
    # 截断：当自相关首次变为负时停止求和
    cutoff = max_lag
    for k in range(1, max_lag):
        if acf[k] < 0:
            cutoff = k
            break
    ess_val = len(chain) / (1 + 2 * np.sum(acf[1:cutoff]))
    return ess_val

# --- 实验 ---
n_iter = 50000
tau = 0.1  # 基础步长

chain_ula = ula_1d(n_iter, delta=tau)
chain_ila_15 = ila_1d(n_iter, tau=tau, omega=1.5)  # ω=1.5, β=0.25
chain_ila_17 = ila_1d(n_iter, tau=tau, omega=1.7)  # ω=1.7, β=0.49

# --- 可视化 ---
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# 左上：trace plot（前 500 步）
ax = axes[0, 0]
ax.plot(chain_ula[:500], linewidth=0.5, alpha=0.7, label='ULA')
ax.plot(chain_ila_15[:500], linewidth=0.5, alpha=0.7, label='ILA (ω=1.5)')
ax.set_xlabel('迭代步')
ax.set_ylabel('$x$')
ax.set_title('Trace plot（前 500 步）')
ax.legend()

# 右上：自相关函数
ax = axes[0, 1]
max_lag = 100
acf_ula = autocorrelation(chain_ula[n_iter//2:], max_lag)
acf_ila_15 = autocorrelation(chain_ila_15[n_iter//2:], max_lag)
acf_ila_17 = autocorrelation(chain_ila_17[n_iter//2:], max_lag)
lags = np.arange(max_lag)
ax.plot(lags, acf_ula, 'b-', label='ULA')
ax.plot(lags, acf_ila_15, 'r-', label='ILA (ω=1.5)')
ax.plot(lags, acf_ila_17, 'g-', label='ILA (ω=1.7)')
ax.axhline(y=0, color='k', linestyle='--', alpha=0.3)
ax.set_xlabel('滞后 $k$')
ax.set_ylabel('自相关 $\\rho_k$')
ax.set_title('自相关函数对比')
ax.legend()

# 左下：直方图
ax = axes[1, 0]
x_grid = np.linspace(-4, 4, 200)
true_pdf = np.exp(-x_grid**2 / 2) / np.sqrt(2 * np.pi)
ax.plot(x_grid, true_pdf, 'k-', linewidth=2, label='真实密度')
ax.hist(chain_ula[n_iter//2:], bins=80, range=(-4, 4), density=True, alpha=0.4, label='ULA')
ax.hist(chain_ila_15[n_iter//2:], bins=80, range=(-4, 4), density=True, alpha=0.4, label='ILA (ω=1.5)')
ax.set_xlabel('$x$')
ax.set_ylabel('密度')
ax.set_title('采样分布对比')
ax.legend()

# 右下：ESS 对比
ax = axes[1, 1]
methods = ['ULA', 'ILA\n(ω=1.5)', 'ILA\n(ω=1.7)']
ess_values = [
    ess(chain_ula[n_iter//2:]),
    ess(chain_ila_15[n_iter//2:]),
    ess(chain_ila_17[n_iter//2:])
]
bars = ax.bar(methods, ess_values, color=['#2196F3', '#F44336', '#4CAF50'])
ax.set_ylabel('有效样本量 ESS')
ax.set_title(f'ESS 对比（总样本量 = {n_iter//2}）')
for bar, val in zip(bars, ess_values):
    ax.text(bar.get_x() + bar.get_width()/2, bar.get_height() + 50, 
            f'{val:.0f}', ha='center', fontsize=10)

fig.suptitle('实验4.11 ILA惯性Langevin算法 vs ULA', fontsize=14, y=1.01)
plt.tight_layout()
plt.savefig('实验4_11_ILA惯性Langevin.png', dpi=150, bbox_inches='tight')
plt.show()

print("结论：")
print("  ILA 引入动量项 β(X_m - X_{m-1})，样本出现负自相关——加速探索。")
print("  ULA 自相关缓慢衰减到 0；ILA 自相关先降为负，然后振荡衰减。")
print("  ILA 的 ESS 高于 ULA——相同迭代次数下获得更多'有效'信息。")
print("  ILA = 重球法 + 噪声：动量帮助'冲过'平坦区域，噪声缩放保证正确的平稳分布。")
```

## 实验 4.12 MCMC 收敛诊断：自相关函数与有效样本量

**对应章节**：4.7 收敛诊断与不确定性量化
**知识点**：burn-in；自相关函数 $\rho_k$；有效样本量 $\text{ESS} = M / (1 + 2\sum_k \rho_k)$；R-hat（Gelman-Rubin 统计量）

### 实验目的

4.7 节强调 MCMC 的输出是马尔可夫链而非独立样本，必须进行收敛诊断。本实验的目标是：

1. **实现**自相关函数（ACF）和有效样本量（ESS）的计算
2. **实现** R-hat（Gelman-Rubin 统计量）判断多链是否收敛到同一分布
3. **对比**不同算法（MH vs ULA vs ILA）和不同参数下的采样效率

### 场景描述

对 1D 高斯混合 $p(x) = 0.3 \cdot \mathcal{N}(-3, 1) + 0.7 \cdot \mathcal{N}(3, 1)$ 运行多条 MH 链和 ULA 链，计算 ACF、ESS 和 R-hat。

### 预期结果

- MH（小步长）：自相关衰减慢，ESS 低
- MH（适中步长）：自相关衰减较快，ESS 较高
- ULA：利用梯度信息，自相关衰减更快，ESS 更高
- R-hat 接近 1.0 表示多链已收敛到同一分布

### 源代码

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# ========== MCMC 收敛诊断 ==========

def log_target_mixture(x):
    """1D 高斯混合的 log 密度"""
    p1 = -0.5 * (x + 3)**2
    p2 = -0.5 * (x - 3)**2
    return np.logaddexp(np.log(0.3) + p1, np.log(0.7) + p2)

def grad_log_target_mixture(x):
    """1D 高斯混合的 ∇log p(x)"""
    w1, w2 = 0.3, 0.7
    p1 = np.exp(-0.5 * (x + 3)**2)
    p2 = np.exp(-0.5 * (x - 3)**2)
    # 后验分类概率
    r1 = w1 * p1 / (w1 * p1 + w2 * p2 + 1e-300)
    r2 = 1 - r1
    return r1 * (-(x + 3)) + r2 * (-(x - 3))

def mh_chain(n_iter, sigma_q, x0):
    """随机游走 MH"""
    chain = np.zeros(n_iter)
    x = x0
    for i in range(n_iter):
        x_prop = x + sigma_q * np.random.randn()
        log_alpha = log_target_mixture(x_prop) - log_target_mixture(x)
        if np.log(np.random.rand()) < log_alpha:
            x = x_prop
        chain[i] = x
    return chain

def ula_chain(n_iter, delta, x0):
    """ULA"""
    chain = np.zeros(n_iter)
    x = x0
    for i in range(n_iter):
        z = np.random.randn()
        x = x + delta * grad_log_target_mixture(x) + np.sqrt(2 * delta) * z
        chain[i] = x
    return chain

def autocorrelation(chain, max_lag=300):
    """计算自相关函数"""
    n = len(chain)
    chain_c = chain - np.mean(chain)
    var = np.var(chain)
    if var < 1e-10:
        return np.zeros(max_lag)
    acf = np.zeros(max_lag)
    for k in range(max_lag):
        acf[k] = np.mean(chain_c[:n-k] * chain_c[k:]) / var
    return acf

def compute_ess(chain, max_lag=300):
    """计算有效样本量 ESS"""
    acf = autocorrelation(chain, max_lag)
    # Geyer 初始正序列估计器：截断于首次负自相关
    sum_rho = 0
    for k in range(1, max_lag):
        if acf[k] < 0:
            break
        sum_rho += acf[k]
    return len(chain) / (1 + 2 * sum_rho)

def compute_rhat(chains):
    """
    计算 Gelman-Rubin R-hat 统计量
    chains: list of 1D arrays (多条链)
    R-hat ≈ 1 表示收敛
    """
    m = len(chains)
    n = min(len(c) for c in chains)
    chains = [c[:n] for c in chains]
    
    chain_means = [np.mean(c) for c in chains]
    chain_vars = [np.var(c, ddof=1) for c in chains]
    
    W = np.mean(chain_vars)  # 组内方差
    B = n * np.var(chain_means, ddof=1)  # 组间方差
    
    var_hat = (1 - 1/n) * W + (1/n) * B
    rhat = np.sqrt(var_hat / W) if W > 0 else float('inf')
    return rhat

# --- 实验：多链收敛诊断 ---
n_chains = 4
n_iter = 10000
# 不同初始值（故意从不同位置出发）
x0_list = [-5.0, 0.0, 5.0, 8.0]

# MH (σ_q=1.0) 的多条链
mh_chains = [mh_chain(n_iter, sigma_q=1.0, x0=x0) for x0 in x0_list]

# ULA (δ=0.1) 的多条链
ula_chains = [ula_chain(n_iter, delta=0.1, x0=x0) for x0 in x0_list]

# --- 可视化 ---
fig, axes = plt.subplots(3, 2, figsize=(16, 14))

# 第一行：trace plots
for col, (name, chains) in enumerate([('MH (σ_q=1.0)', mh_chains), 
                                        ('ULA (δ=0.1)', ula_chains)]):
    ax = axes[0, col]
    colors = ['#E53935', '#43A047', '#1E88E5', '#FB8C00']
    for i, (chain, c) in enumerate(zip(chains, colors)):
        ax.plot(chain[:3000], linewidth=0.3, alpha=0.7, color=c, label=f'链{i+1} (x₀={x0_list[i]})')
    ax.set_xlabel('迭代步')
    ax.set_ylabel('$x$')
    ax.set_title(f'{name}: Trace plot')
    ax.legend(fontsize=7)

# 第二行：自相关函数
for col, (name, chains) in enumerate([('MH (σ_q=1.0)', mh_chains), 
                                        ('ULA (δ=0.1)', ula_chains)]):
    ax = axes[1, col]
    for i, (chain, c) in enumerate(zip(chains, colors)):
        acf = autocorrelation(chain[n_iter//2:], max_lag=100)
        ax.plot(acf, linewidth=1, color=c, alpha=0.7, label=f'链{i+1}')
    ax.axhline(y=0, color='k', linestyle='--', alpha=0.3)
    ax.set_xlabel('滞后 $k$')
    ax.set_ylabel('自相关 $\\rho_k$')
    ax.set_title(f'{name}: 自相关函数')
    ax.legend(fontsize=7)

# 第三行：ESS 和 R-hat
ax = axes[2, 0]
methods = ['MH\n(σ_q=0.5)', 'MH\n(σ_q=1.0)', 'MH\n(σ_q=2.0)', 'ULA\n(δ=0.05)', 'ULA\n(δ=0.1)']
ess_means = []
for sigma_q in [0.5, 1.0, 2.0]:
    chains = [mh_chain(n_iter, sigma_q, x0) for x0 in x0_list]
    ess_means.append(np.mean([compute_ess(c[n_iter//2:]) for c in chains]))
for delta in [0.05, 0.1]:
    chains = [ula_chain(n_iter, delta, x0) for x0 in x0_list]
    ess_means.append(np.mean([compute_ess(c[n_iter//2:]) for c in chains]))

bars = ax.bar(methods, ess_means, color=['#E53935', '#E53935', '#E53935', '#1E88E5', '#1E88E5'])
ax.set_ylabel('平均 ESS')
ax.set_title('有效样本量对比（后半段）')
for bar, val in zip(bars, ess_means):
    ax.text(bar.get_x() + bar.get_width()/2, bar.get_height() + 20, 
            f'{val:.0f}', ha='center', fontsize=9)

ax = axes[2, 1]
rhat_mh = compute_rhat([c[n_iter//2:] for c in mh_chains])
rhat_ula = compute_rhat([c[n_iter//2:] for c in ula_chains])
methods_rhat = ['MH\n(σ_q=1.0)', 'ULA\n(δ=0.1)']
rhats = [rhat_mh, rhat_ula]
bars = ax.bar(methods_rhat, rhats, color=['#E53935', '#1E88E5'])
ax.axhline(y=1.0, color='k', linestyle='--', alpha=0.5, label='R-hat = 1.0（完全收敛）')
ax.axhline(y=1.1, color='orange', linestyle='--', alpha=0.5, label='R-hat = 1.1（经验阈值）')
ax.set_ylabel('R-hat')
ax.set_title('Gelman-Rubin R-hat 统计量')
ax.legend()
for bar, val in zip(bars, rhats):
    ax.text(bar.get_x() + bar.get_width()/2, bar.get_height() + 0.005, 
            f'{val:.4f}', ha='center', fontsize=10)

fig.suptitle('实验4.12 MCMC收敛诊断', fontsize=14, y=1.01)
plt.tight_layout()
plt.savefig('实验4_12_收敛诊断.png', dpi=150, bbox_inches='tight')
plt.show()

print("结论：")
print("  MH 的自相关衰减较慢（随机游走无方向性），ESS 较低。")
print("  ULA 的自相关衰减更快（利用梯度），ESS 更高。")
print("  R-hat ≈ 1.0 表示多链从不同初始值出发后收敛到同一分布。")
print("  R-hat > 1.1 提示链可能未充分混合或 burn-in 不够。")
print("  ESS 和 R-hat 是 MCMC 实践中不可或缺的诊断工具。")
```

## 实验 4.13 不确定性量化：后验均值、方差与像素级置信区间

**对应章节**：4.7 收敛诊断与不确定性量化
**知识点**：后验均值（MMSE 估计）；后验方差；像素级置信区间；后验可信区域；UQ 可视化

### 实验目的

4.7 节强调 MCMC 采样的最终目的是**从后验中提取完整信息**——不只是点估计，而是不确定性量化。本实验的目标是：

1. **实现**基于 MCMC 采样的不确定性量化流程
2. **计算**像素级置信区间和后验可信区域
3. **可视化**不确定性：后验标准差图、置信区间图、后验样本的变异系数

### 场景描述

基于 1D 去卷积问题（与实验 4.8 类似但更完整）。观测 $y = x * h + n$，用 ULA 从后验中采样，然后计算：
- 后验均值 $\bar{x} = \frac{1}{M}\sum_m X_m$（MMSE 估计）
- 后验标准差 $\sigma_x = \sqrt{\frac{1}{M}\sum_m (X_m - \bar{x})^2}$
- 95% 像素级置信区间 $[q_{0.025}(x_i), q_{0.975}(x_i)]$

### 预期结果

- 后验均值给出 MMSE 估计（优于任何单样本）
- 后验标准差在模糊边缘区域较高（不确定性大）
- 95% 置信区间覆盖真实值
- 不确定性量化比单纯点估计（如 MAP）提供更多信息

### 源代码

```python
import numpy as np
import matplotlib.pyplot as plt
import math

np.random.seed(42)

# ========== 不确定性量化 ==========

# --- 1D 去卷积 ULA 采样 ---

def kernel_1d(n, s):
    """1D 均匀模糊核"""
    h = np.zeros(n)
    h[:s+1] = 1.0 / (2*s+1)
    h[-s:] = 1.0 / (2*s+1)
    return h

def convol_1d(a, b):
    """1D 周期卷积"""
    return np.real(np.fft.ifft(np.fft.fft(a) * np.fft.fft(b)))

# 创建 1D 信号（分段常数 + 跳变）
n = 128
x_true = np.zeros(n)
x_true[20:50] = 1.0
x_true[60:80] = 0.5
x_true[90:110] = 0.8

# 模糊 + 噪声
h = kernel_1d(n, 3)
sigma = 0.05
y = convol_1d(x_true, h) + sigma * np.random.randn(n)

# ULA 参数
lambd = 5.0
L = 1.0 / sigma**2 + 4 * lambd  # 简化 Lipschitz 常数
delta = 1.0 / L
n_iter = 30000
burn_in = n_iter // 5

# ULA 采样
h_fft = np.fft.fft(h)
hc_fft = np.conj(h_fft)

# 保存所有 burn-in 后的样本（每隔 inter 步保存一次）
inter = 5
n_samples = (n_iter - burn_in) // inter
samples = np.zeros((n_samples, n))
X = np.copy(y)
sample_idx = 0

for i in range(n_iter):
    Z = np.random.randn(n)
    # ∇f(x) = (A^TAx - A^Ty)/σ²
    Ax = np.real(np.fft.ifft(h_fft * np.fft.fft(X)))
    ATAx = np.real(np.fft.ifft(hc_fft * h_fft * np.fft.fft(X)))
    ATy = np.real(np.fft.ifft(hc_fft * np.fft.fft(y)))
    grad_f = (ATAx - ATy) / sigma**2
    
    # 简单 L2 先验梯度（代替 TV 使代码简洁）
    grad_prior = lambd * X
    
    grad_U = grad_f + grad_prior
    X = X - delta * grad_U + np.sqrt(2 * delta) * Z
    
    if i >= burn_in and (i - burn_in) % inter == 0:
        samples[sample_idx] = X.copy()
        sample_idx += 1

# --- UQ 计算 ---
x_mean = np.mean(samples, axis=0)      # 后验均值（MMSE）
x_std = np.std(samples, axis=0)         # 后验标准差
x_ci_low = np.percentile(samples, 2.5, axis=0)   # 95% CI 下界
x_ci_high = np.percentile(samples, 97.5, axis=0)  # 95% CI 上界

# 覆盖率：真实值在 95% CI 内的像素比例
coverage = np.mean((x_true >= x_ci_low) & (x_true <= x_ci_high))

# --- 可视化 ---
fig, axes = plt.subplots(3, 2, figsize=(16, 14))

# 原始信号和观测
ax = axes[0, 0]
t = np.arange(n)
ax.plot(t, x_true, 'k-', linewidth=2, label='真实信号 $x$')
ax.plot(t, y, 'r-', linewidth=0.5, alpha=0.5, label='观测 $y$（模糊+噪声）')
ax.set_xlabel('像素位置')
ax.set_ylabel('值')
ax.set_title('真实信号与观测')
ax.legend()

# 后验均值 vs 真实
ax = axes[0, 1]
ax.plot(t, x_true, 'k-', linewidth=2, label='真实信号')
ax.plot(t, x_mean, 'b-', linewidth=1.5, label='后验均值（MMSE）')
ax.set_xlabel('像素位置')
ax.set_ylabel('值')
```

### 缺4-1 补充说明：Gibbs 采样 + TV 先验 GLM 框架

4.5 节的 GLM 框架是 Gibbs 采样在图像逆问题中的核心应用。实现需要：

1. **GIG 采样器**：TV 先验的辅助变量 $z_j \sim \text{GIG}(\lambda^2, (Kx)_j^2, 1/2)$。当 $p=1/2$ 时，GIG 退化为逆高斯分布（Inverse Gaussian），可用 Michael-Schucany-Haas 算法采样。
2. **条件分布 $p_{X|Z}$**：多元高斯 $\mathcal{N}(x | \mu(z), \Sigma(z))$，其中 $\Sigma(z) = (K^T \text{diag}(z)^{-1} K)^{-1}$。
3. **交替采样循环**：$x^{k+1} \sim p_{X|Z=z^k}$，$z_j^{k+1} \sim \text{GIG}(\lambda^2, (Kx^{k+1})_j^2, 1/2)$。

建议参考文献：
- Kuric, Zach, Habring, Unser & Pock (2025) — GLM 框架的原始论文
- Pock L2 P29-33 — 教学推导
- Geman & Reynolds (1992) — 半二次分裂
