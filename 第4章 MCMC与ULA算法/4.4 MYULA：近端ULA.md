# 4.4 MYULA：近端ULA

> "ULA 很美，可它怕尖角——一旦后验里出现 TV 范数那种'带尖儿'的不可微项，梯度就不存在了。怎么办？把尖角磨圆。"

4.3 节我们知道 ULA 高效，但有个硬前提：$\nabla\log p(\mathbf{x}|y)$ 得存在、还得 Lipschitz 连续。可图像逆问题的后验常常长这样：$p(\mathbf{x}|y)\propto\exp\{-f(\mathbf{x})-g(\mathbf{x})\}$，其中 $g(\mathbf{x})$ 是 TV 范数、$\ell_1$、指示函数这类**不可微**项（带着尖角）。梯度在尖角处不存在，ULA 无法直接使用。本节讲 MYULA（Moreau-Yoshida ULA，亦称近端朗之万算法）：用 Moreau-Yoshida 包络（一种光滑化技巧）把尖角磨平，在磨平后的近似分布上运行 ULA——误差可控、还有非渐近收敛保证。

**本节目标**（读完后你应该能）：
- 说清"不可微后验"为什么让 ULA 失效
- 用直白的语言理解 Moreau-Yoshida 包络如何把尖角磨圆，并写出它的梯度（用近端算子表示）
- 写出 MYULA 迭代式，并把它拆成"梯度步 + 近端校正 + 噪声"三步
- 看懂 $\lambda$ 的权衡：磨得越细越准、但收敛越慢

---

## 一、不可微后验的挑战

图像逆问题的后验常见结构：

$$p(\mathbf{x}|y) \propto \exp\{-f(\mathbf{x}) - g(\mathbf{x})\}$$

- $f(\mathbf{x})=\frac{1}{2\sigma^2}\|y-Ax\|^2$：光滑数据项，梯度 $\nabla f$ 是 $L_f$-Lipschitz 的（处处顺滑、变化有界）
- $g(\mathbf{x})=\beta\|Bx\|_1+\iota_S(\mathbf{x})$：不可微正则项（TV 范数、约束指示函数），$\beta$ 是正则权重

第3章 3.4 节就遇到过这种"光滑 + 不可微"的复合结构对优化的挑战——当时用近端方法替代梯度下降。现在采样遇到一模一样的麻烦：$\nabla g(\mathbf{x})$ 不存在 → $\nabla\log p(\mathbf{x}|y)$ 不存在 → ULA 无法直接使用。

**解决思路**：把 $g$ 光滑化，得到一个可微的近似分布 $p_\lambda$，然后在 $p_\lambda$ 上跑 ULA。这个光滑化得满足三件事：(1) $p_\lambda$ 是良定义的概率密度；(2) $\nabla\log p_\lambda$ 要 Lipschitz 连续（ULA 的收敛条件）；(3) 近似误差 $\|p_\lambda-p\|$ 要可控。Moreau-Yoshida 包络恰好三件都办到。

---

## 二、Moreau-Yoshida 包络：把尖角磨圆

在给出定义之前，先建立思想：与其在 $\mathbf{x}$ 处直接问"$g$ 的梯度是什么"（尖角处问不出答案），不如问"在 $\mathbf{x}$ 附近，$g$ 的最小能量代价是多少"——把"局部斜率"换成"邻域最优值"，尖角就被邻域平均自然磨平了。函数 $g$ 的 **Moreau-Yoshida 包络**（Moreau 包络）正是这一思想的严格化：

$$g_\lambda(\mathbf{x}) = \inf_{u} \left\{g(u) + \frac{1}{2\lambda}\|u - \mathbf{x}\|^2\right\}$$

其中 $\lambda>0$ 控制"邻域"的松紧：$\lambda$ 越小，二次项惩罚越重，$u$ 被拴在 $\mathbf{x}$ 附近，$g_\lambda$ 越贴近 $g$；$\lambda$ 越大，允许 $u$ 走得更远，磨得越平滑。它和第3章的**近端算子**（proximal operator，离 $\mathbf{x}$ 最近、又让 $g$ 小的那个点）是一对孪生兄弟：

$$\text{prox}_{\lambda g}(\mathbf{x}) = \arg\min_{u} \left\{g(u) + \frac{1}{2\lambda}\|u - \mathbf{x}\|^2\right\}$$

也就是说——使 $g_\lambda(\mathbf{x})$ 取到下确界的那个 $u$，就是 $\text{prox}_{\lambda g}(\mathbf{x})$。包络给出"最小值"，近端算子给出"取到最小值的点"。**用直白的话讲**：Moreau 包络就是"在 $\mathbf{x}$ 附近、给 $g$ 加了一个软枕头（二次 proximal 项）之后，把 $g$ 磨平滑得到的版本"。

它的关键性质（Pereyra, 2015）：
1. **良定义密度**：对所有 $\lambda>0$，$p_\lambda(\mathbf{x}|y)=\exp\{-f(\mathbf{x})-g_\lambda(\mathbf{x})\}/Z_\lambda$ 是真密度。
2. **对数凹且可微**：若 $f,g$ 凸（TV、$\ell_1$ 都凸），则 $p_\lambda$ 对数凹；一般情况下至少 $C^1$（即便原 $p$ 不可微）——包络自动磨平了尖角。
3. **梯度有闭式**：
   $$\nabla g_\lambda(\mathbf{x}) = \frac{x - \text{prox}_{\lambda g}(\mathbf{x})}{\lambda}$$
   梯度等于"位移残差除以 $\lambda$"——不可微的 $g$ 没有梯度，但它的包络有，而且只用近端算子就能算。于是 $\nabla\log p_\lambda(\mathbf{x}|y) = -\nabla f(\mathbf{x}) - \frac{x-\text{prox}_{\lambda g}(\mathbf{x})}{\lambda}$。
4. **Lipschitz 常数**：$\nabla\log p_\lambda$ 是 $L$-Lipschitz 的，且 $L\le L_f+1/\lambda$。
5. **近似误差可控**：$\lim_{\lambda\to0}\|p_\lambda-p\|_{\text{TV}}=0$；若 $g$ 是 $L_g$-Lipschitz，则 $\|p_\lambda-p\|_{\text{TV}}\le \lambda L_g^2$。

**直觉例子**（三个经典尖角如何被磨圆）：
- **Laplace 先验** $\exp(-|\mathbf{x}|)$：$|\mathbf{x}|$ 在 0 处有个尖角，$g_\lambda$ 把尖角磨圆，$\lambda$ 越大磨得越明显。
- **四次先验** $\exp(-\mathbf{x}^4)$：$\mathbf{x}^4$ 的梯度远处增长太快（非 Lipschitz），$g_\lambda$ 把远处梯度"截断"成 Lipschitz。
- **均匀先验** $\mathbf{1}_{[-0.5,0.5]}(\mathbf{x})$：阶梯状不连续，$g_\lambda$ 把台阶边缘变成光滑的 S 形。

> **权衡先说结论**：$\lambda$ 越小，$p_\lambda$ 越贴近 $p$，但 $L=L_f+1/\lambda$ 越大 → ULA 步长 $\delta$ 必须越小 → 收敛越慢。**精度与速度，此消彼长。**

## 三、MYULA 算法：梯度步 + 近端校正 + 噪声

在磨平后的 $p_\lambda$ 上跑 ULA：

$$X_{m+1} = X_m + \delta\,\nabla\log p_\lambda(X_m|y) + \sqrt{2\delta}\,Z_{m+1}$$

代入梯度表达式展开：

$$X_m + \delta\nabla\log p_\lambda(X_m) = X_m - \delta\nabla f(X_m) - \frac{\delta}{\lambda}\bigl(X_m - \text{prox}_{\lambda g}(X_m)\bigr)$$

$$= \left(1 - \frac{\delta}{\lambda}\right)X_m - \delta\nabla f(X_m) + \frac{\delta}{\lambda}\text{prox}_{\lambda g}(X_m)$$

得到 MYULA 的迭代式：

$$\boxed{X_{m+1} = \left(1 - \frac{\delta}{\lambda}\right)X_m - \delta\nabla f(X_m) + \frac{\delta}{\lambda}\text{prox}_{\lambda g}(X_m) + \sqrt{2\delta} \, Z_{m+1}}$$

**三步读懂它**：
1. **沿光滑梯度走一步**：$-\delta\nabla f(X_m)$——用数据项的梯度，朝"数据拟合好"的方向挪；
2. **近端校正**（替代不可微梯度）：$\frac{\delta}{\lambda}[\text{prox}_{\lambda g}(X_m)-X_m]$——用近端算子的"残差" $(\mathbf{x}-\text{prox}_{\lambda g}(\mathbf{x}))/\lambda$ 顶替不存在的 $\nabla g(\mathbf{x})$，实现正则化效果；
3. **加高斯噪声**：$\sqrt{2\delta}Z_{m+1}$——保住探索能力。

第二步是灵魂：当 $g$ 不可微时 $\nabla g$ 不存在，但近端算子 $\text{prox}_{\lambda g}$ 依然有定义（3.4 节）。MYULA 巧妙用近端算子的残差替代 $\nabla g$——这正是 Moreau-Yoshida 梯度的核心洞见。

> **步长约束**：迭代式第一项系数 $(1-\delta/\lambda)$ 必须为正，即 $\delta<\lambda$；再结合上限 $\delta_\lambda^{\max}=\lambda/(1+\lambda L_f)$，实际步长要满足 $\delta<\min\{\lambda,\delta_\lambda^{\max}\}$。$\lambda$ 小时这约束很紧。

## 实验 4.4-1：2D图像MYULA后验采样（去卷积）

实验 `4.4-1.py` 在图像去模糊问题上演示MYULA处理不可微TV先验的完整流程。实验使用Moreau-Yoshida包络光滑化TV范数，用Chambolle近端算子替代不可微梯度，验证MYULA迭代公式和Lipschitz常数计算。

### 实验场景

**正向模型**：$y = Ax + \varepsilon$，其中 $A$ 为均匀模糊核（9×9），$\varepsilon \sim \mathcal{N}(0, \sigma^2 I)$，BSNR=20dB。

**后验分布**：$p(\mathbf{x}|y) \propto \exp\{-f(\mathbf{x}) - g(\mathbf{x})\}$，其中：
- $f(\mathbf{x}) = \|y - Ax\|^2 / (2\sigma^2)$：光滑数据项
- $g(\mathbf{x}) = \beta \cdot \text{TV}(\mathbf{x})$：不可微TV正则项，$\beta = 0.3$

**MYULA光滑化**：用Moreau-Yoshida包络 $g_\lambda(\mathbf{x})$ 近似 $g(\mathbf{x})$，其中 $\lambda_{prox} = 1.0$。

### 实验目的

1. **验证MYULA处理不可微先验的能力**：TV范数 $g(\mathbf{x}) = \beta\|Bx\|_1$ 不可微，ULA无法直接使用；MYULA通过Moreau-Yoshida包络光滑化，使采样成为可能

2. **验证近端算子替代不可微梯度**：MYULA梯度 $\nabla g_\lambda(\mathbf{x}) = (\mathbf{x} - \text{prox}_{\lambda g}(\mathbf{x}))/\lambda$ 用近端算子的"残差"替代不存在的 $\nabla g(\mathbf{x})$

3. **验证Lipschitz常数计算**：$L = L_f + 1/\lambda$，其中 $L_f = \|A^TA\|/\sigma^2$，验证步长 $\delta < 1/L$ 的约束

4. **理解λ的权衡**：$\lambda$ 越小近似越精确，但 $L$ 越大（收敛越慢）；$\lambda$ 越大近似越粗糙，但 $L$ 越小（收敛越快）

## MYULA的收敛性

### 非渐近误差界

**定理**（Durmus et al., 2018, Theorem 3.1）：设 $\delta_\lambda^{\max} = (L_f + 1/\lambda)^{-1}$，$g$ 是Lipschitz连续的。则存在 $\delta_\varepsilon \in (0, \delta_\lambda^{\max}]$ 和 $M_\varepsilon \in \mathbb{N}$ 使得对 $\delta < \delta_\varepsilon$ 和 $M \geq M_\varepsilon$：

$$\|\delta_{\mathbf{x}_0} Q_\delta^M - p\|_{\text{TV}} < \varepsilon + \lambda L_g^2$$

其中 $Q_\delta^M$ 是MYULA迭代 $M$ 步后的核。

这个定理有两个部分：

- **$\varepsilon$ 项**：ULA的离散化误差，固定 $\delta$ 时仅增大 $M$ 无法消除（链收敛到的是离散化后的平稳核，仍偏真分布 $O(\delta)$）；需在减小步长 $\delta$ 的同时相应增大 $M$——定理中 $\delta<\delta_\varepsilon$ 与 $M\geq M_\varepsilon$ 是成对条件，$\delta$ 越小所需混合步数越多
- **$\lambda L_g^2$ 项**：Moreau-Yoshida近似误差，与 $\lambda$ 成正比——**无法通过增加迭代次数消除**

> **重要说明**：$\lambda L_g^2$ 项是MYULA无法消除的系统偏差——要使总误差小于 $\varepsilon_{\text{total}}$，需要选择 $\lambda < \varepsilon_{\text{total}}/(2L_g^2)$，再选择 $\delta$ 和 $M$ 使 $\varepsilon < \varepsilon_{\text{total}}/2$。这意味着MYULA的总误差不能任意趋近于零，而是受限于光滑化参数 $\lambda$ 的选择。

### 维数依赖

MYULA的迭代次数对维数的依赖是多项式级的，这是高维问题中效率的理论保证。具体的维数依赖参数可参考Durmus et al. (2018) 的原始论文。

### $\lambda$ 的权衡

$\lambda$ 的选择决定了近似精度与收敛速度的权衡：

| $\lambda$ | 近似误差 | Lipschitz常数 | 步长上限 | 收敛速度 |
|---|---|---|---|---|
| 小 | $\lambda L_g^2$ 小（精度高） | $L_f + 1/\lambda$ 大 | $\delta_\lambda^{\max}$ 小 | 慢 |
| 大 | $\lambda L_g^2$ 大（精度低） | $L_f + 1/\lambda$ 小 | $\delta_\lambda^{\max}$ 大 | 快 |

实践中，$\lambda$ 的选择需要在偏差和效率之间权衡。典型的做法是从较大的 $\lambda$ 开始，逐步减小——类似退火策略。

## 实验 4.4-2：MYULA经验贝叶斯（SAPG参数自适应估计）

**对应章节**：4.4 MYULA（近端ULA）、3.6（经验贝叶斯、边际似然）
**知识点**：不可微后验的挑战；Moreau-Yoshida包络光滑化；近端算子替代不可微梯度；MYULA迭代公式；Lipschitz常数 $L = L_f + 1/\lambda_{prox}$；Fisher恒等式；SAPG随机近似投影梯度；经验贝叶斯自适应参数估计

### 实验目的

实验4.4-1验证了MYULA在固定超参数（$\theta$和$\sigma^2$）下的采样能力。本实验进一步引入**经验贝叶斯**框架，从观测数据$y$中自动估计超参数，验证：

1. **经验贝叶斯的有效性**：通过最大化边际似然$p(y|\theta, \sigma^2)$自动估计超参数（$\theta$和$\sigma^2$），避免手动调参

2. **Fisher恒等式的应用**：边际似然梯度通过后验期望计算，$\nabla_\theta \log p(y|\theta) = -\mathbb{E}[\text{TV}(X)] + d/(\alpha\theta)$，其中期望用MYULA样本近似

3. **SAPG算法的收敛性**：随机近似投影梯度（SAPG）算法在MYULA采样过程中同步更新参数，验证参数估计的收敛性

4. **对数尺度参数化**：$\eta = \log(\theta)$自动保证$\theta > 0$，验证参数约束的处理方法

5. **burn-in截断**：只使用平稳分布区域的样本计算参数均值，验证burn-in策略的有效性

### 实验场景

**正向模型**：$y = Ax + \varepsilon$，其中$A$为均匀模糊核（9×9），$\varepsilon \sim \mathcal{N}(0, \sigma^2 I)$，BSNR=30dB。

**后验分布**：$p(\mathbf{x}|y, \theta, \sigma^2) \propto \exp\{-f(\mathbf{x}, \sigma^2) - g(\mathbf{x}, \theta)\}$，其中：
- $f(\mathbf{x}, \sigma^2) = \|y - Ax\|^2 / (2\sigma^2)$：光滑数据项，$\sigma^2$为待估计的噪声方差
- $g(\mathbf{x}, \theta) = \theta \cdot \text{TV}(\mathbf{x})$：不可微TV正则项，$\theta$为待估计的正则化权重

**MYULA先验梯度（关键实现细节）**：$\nabla g_{\lambda_{prox}}(\mathbf{x}) = (\mathbf{x} - \text{prox}_{\lambda_{prox}\theta\text{TV}}(\mathbf{x})) / \lambda_{prox}$。该式已通过近端参数 $\lambda_{prox}\theta$ 隐含了 $\theta$，外层**不可再乘** $\theta$（否则有效先验权重退化为 $\theta^2$，采样目标偏离 $\exp\{-f-\theta\text{TV}\}$）。其Lipschitz常数 $L_g = 1/\lambda_{prox}$（Moreau包络梯度对任意凸函数恒为 $1/\lambda$-Lipschitz，与 $\theta$ 无关），故总步长 $\gamma = 0.98/(L_f + 1/\lambda_{prox})$。

**经验贝叶斯框架**：
- 边际似然：$p(y|\theta, \sigma^2) = \int p(y|\mathbf{x}, \sigma^2) p(\mathbf{x}|\theta) \, dx$
- Fisher恒等式：$\nabla_\theta \log p(y|\theta) = \mathbb{E}_{x|y,\theta}[\nabla_\theta \log p(\mathbf{x}|\theta)]$
- TV先验的梯度：$\nabla_\theta \log p(\mathbf{x}|\theta) = -\text{TV}(\mathbf{x}) + d/(\alpha\theta)$，其中$d$为图像维数，$\alpha=1$（TV的1-齐次性）

    （实现注：$\text{TV}(\mathbf{x})$ 由共享库 `Grad_Image.TVnorm` 计算。2026-10复核发现旧实现在竖直差分后多做了一次 `.T` 转置，使各向同性TV在开方内把水平差与竖直差按转置下标错配——该转置不改变各分量平方和，但改变 sqrt 内配对，在代表图像上TV偏差实测达 2.5%～14%（后验平滑样本上更大），并经均衡关系 $\theta^*=d/\mathbb{E}[\text{TV}]$ 同比例污染 $\theta$（旧代码 θ=0.0231，修复后 θ=0.0242）。该差异**不可忽略**，现已删除 `.T` 并与近端算子 `GradientIm` 的零填充前向差分约定统一。早期版本讲义中"差异小于随机种子间抖动、可忽略"的免责说法不成立。修复效应经两套独立实现交叉确认：本地 4.4-2.py θ 0.0231→0.0242（+4.7%），Colab 重实现 0.0220→0.0231（+5.0%）；但两种口径下 SNR(MAP) 仅差 0.02 dB——θ 定义偏差约5%是实质的，只是重建恰处 SNR(θ) 平台而对其不敏感）

**SAPG算法**：
- 参数更新：$\theta_{k+1} = \mathcal{P}_{[\theta_{min}, \theta_{max}]}(\theta_k + c_\eta \delta_k \nabla_\eta \log p(y|\theta_k))$
- 对数尺度：$\eta = \log(\theta)$，$\nabla_\eta \log p = \nabla_\theta \log p \cdot \theta$
- 投影：$\mathcal{P}$为投影到容许集$[\theta_{min}, \theta_{max}]$的操作
- 步长：$\delta_k = (k+1)^{-d_{exp}} / d$，$d_{exp}=0.8$为衰减指数

**结果分析**：

1. **经验贝叶斯成功估计超参数**：SAPG算法自动估计的$\sigma^2 = 4.826$与真实值$4.975$的相对误差约3.0%，且能从极端初值（1或20）被拉回真值附近（4.51或5.06），验证了经验贝叶斯框架的有效性——从观测数据$y$中确实能够推断出噪声水平。**对旧版免责声明的最终裁决（2026-10，先本地核查、后Colab补证）**：旧版讲义称"3–4%残差在5个随机种子下稳定复现（3.1–3.6%）、估计一致略偏低、是包络平滑目标上的固有系统偏置，而非MC噪声"。补做的5种子实验（初值取真值）实测 rel 为 **3.1–3.7%、5/5 全部略偏低、种子间抖动仅0.3%**——**数值区间事后几乎被证实，"近平稳时系统性成分主导MC噪声"也成立**；但该免责在写下时**没有任何运行记录支撑（属先验断言），且其定性结论有两处错误，不能因数字碰巧吻合而平反**：① "一致略偏低"不是估计量的不变性质——初值取20时估计为5.06（**+1.7%偏高**），−9.4%～+1.7% 的跨度说明初值记忆在短链中可压倒并反转偏置方向；② "固有/包络平滑所致"无机制证据，更可能来自ULA大步长（$\gamma\approx0.82$）离散化、$\lambda_{prox}=1$粗包络与prox仅10步的近似，且全部可通过加大预算减小。正确表述应为：**当前离散化设置、近真值初值、1000步预算下，σ² 有约−3.5%、跨种子稳定（±0.3%）的小幅负偏置；链短时叠加显著初值记忆（符号随初值）。该精度对下游重建无害（见第4条）**

### 补充说明

本实验展示了MYULA与经验贝叶斯的结合——在采样过程中同步估计超参数，实现了完全数据驱动的推断：

1. **经验贝叶斯的优势**：避免了手动调参的繁琐，超参数从数据中自动学习。这在实际应用中尤为重要——噪声水平$\sigma^2$和正则化权重$\theta$往往难以预先确定

2. **Fisher恒等式的关键作用**：将边际似然梯度转化为后验期望，使梯度计算可以通过采样实现。这是连接"优化边际似然"与"采样后验"的桥梁

3. **SAPG的随机近似性质**：使用单步样本近似期望（无需多样本平均），在MYULA迭代过程中同步更新参数，实现了采样与参数估计的耦合。步长衰减保证了收敛性

4. **对数尺度参数化的必要性**：$\theta$必须为正，对数尺度$\eta = \log(\theta)$自动满足约束，避免了投影操作的复杂性。这是处理参数约束的标准技巧

5. **burn-in的重要性**：MYULA需要一定迭代次数才能收敛到平稳分布，burn-in期间的样本不应用于参数估计。本实验使用70% burn-in，保证了估计的可靠性

6. **与第3章的联系**：本实验的经验贝叶斯框架与3.6节的理论基础一致——边际似然最大化、Fisher恒等式、随机近似算法。MYULA提供了处理不可微先验的采样工具，SAPG提供了参数估计的优化工具，两者结合实现了完全贝叶斯推断

## MYULA与近端梯度下降的对偶

3.4节建立了近端梯度下降处理"光滑+不可微"优化问题的框架。MYULA是近端梯度下降在采样中的对应：

- **近端梯度下降**（第3章）：$x_{k+1} = \text{prox}_{\tau g}(x_k - \tau\nabla f(x_k))$
- **MYULA**（本章）：$X_{m+1} = (1 - \delta/\lambda)X_m - \delta\nabla f(X_m) + (\delta/\lambda)\text{prox}_{\lambda g}(X_m) + \sqrt{2\delta}Z_{m+1}$

需要说明：二者是**同一组算子（近端步、梯度步）的相反复合顺序**，而非严格相等。取 $\delta = \lambda$ 时，MYULA确定性部分化简为 $\text{prox}_{\lambda g}(X_m) - \lambda\nabla f(X_m)$（先近端、后梯度），而近端梯度下降是 $\text{prox}_{\tau g}(x_k - \tau\nabla f(x_k))$（先梯度、后近端）。仅当 $\nabla f$ 近似为常数时两者才重合，故这里是"结构对偶"而非"实用等价"——$\lambda$ 与 $\tau$ 在各自算法中也有不同的最优选择。优化与采样的结构对偶再次出现：

| 优化 | 采样 | 区别 |
|---|---|---|
| 梯度下降 | ULA | 加噪声 |
| 近端梯度下降 | MYULA | 加噪声 |

统一的转化律：**近端梯度下降 + 噪声 = MYULA**，正如梯度下降 + 噪声 = ULA。优化算法中的核心操作（梯度步、近端步）在采样算法中被完整保留，唯一的区别是添加了高斯噪声项——噪声将"收敛到点"变为"收敛到分布"。

从更深层次看，MYULA 的意义不只在于处理一个技术障碍（不可微性），更在于它示范了"优化算法 + 噪声 = 采样算法"这条转化律的普适性：第3章为优化发明的每一个算子（梯度、近端），都能在采样一侧找到对应位置，噪声项是唯一的增量。

ULA/MYULA利用后验的梯度信息构造采样步骤。另一种利用后验结构的方式是Gibbs采样——不利用梯度，而是利用条件分布的结构。通过引入辅助变量，将复杂后验分解为简单的条件分布，Gibbs采样在特定结构下极为高效。
