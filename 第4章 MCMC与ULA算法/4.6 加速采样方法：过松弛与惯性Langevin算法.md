# 4.6 加速采样方法：过松弛与惯性Langevin算法

> "优化有 Nesterov 加速、有动量法；采样难道只能慢慢挪？不——优化的加速技巧，在采样里都有精确对应的双胞胎。"

4.3–4.5 节建立了三类采样方法：ULA（梯度驱动）、MYULA（梯度+近端）、Gibbs（条件结构驱动）。但它们面临同一个效率瓶颈：**样本间自相关太强**——相邻样本高度相关，看似抽了许多点，实际带来的新信息有限。优化里，梯度下降的收敛能被 Nesterov 加速或重球法显著提速；采样的加速有没有类似机制？有，而且优化加速与采样加速之间存在**精确的结构对偶**。本节属于扩展内容（核心规律"优化 + 噪声 = 采样"已在 4.3–4.5 建立），但它为第7章"扩散模型是终极加速采样"埋下技术伏笔。

**本节目标**（读完后你应该能）：
- 理解过松弛 Gibbs 如何用"协方差缩放"制造负自相关、从而加速
- 写出 ILA（惯性 Langevin）迭代式，认出它 = 重球法 + 噪声
- 知道 ILA 的连续极限是欠阻尼 Langevin SDE（第7章扩散模型的近亲）

---

## 一、加速的动机

4.1 节说过，Monte Carlo 估计的误差按 $O(1/\sqrt{M})$ 衰减，前提是样本近似独立。马尔可夫链样本不独立，真正起作用的是**有效样本量**：自相关越强，$M$ 个样本折算出的独立信息越少（严格定义见 4.7 节的 ESS）。因此加速采样的本质目标只有一个——**削弱相邻样本的自相关**，让每一步都带来尽可能多的新信息。

优化里，梯度下降的收敛能被 Nesterov/重球法大幅提速。采样的加速有类似机制吗？有——而且和优化的加速**一一对偶**。

## 二、过松弛 Gibbs：让样本在均值两侧跳

### SOR 加速（优化视角）

4.5 节建立了 Gauss-Seidel 与 Gibbs 的对偶。Gauss-Seidel 本身能被**逐次超松弛**（SOR, Successive Overrelaxation）加速（Frankel, 1950）：
$$x_1^{k+1} = (1-\omega)x_1^k + \omega\,Q_{11}^{-1}(b_1 - Q_{12}x_2^k), \quad \omega\in(0,2)$$
其中 $\omega$ 是松弛参数：$\omega=1$ 就是标准 Gauss-Seidel；$\omega>1$ 是超松弛——不满足于走到目标值，而是"越过它一步"，用过度校正换取更快收敛；$\omega<1$ 是欠松弛。

### 过松弛 Gibbs（采样视角）

Adler（1981）发现 Gibbs 也能过松弛。回忆 4.5 节高斯上的 Gibbs：
$$X_1^{k+1}\sim\mathcal{N}(\mu_1-Q_{11}^{-1}Q_{12}(X_2^k-\mu_2),\ Q_{11}^{-1})$$
过松弛版改为：
$$\boxed{X_1^{k+1}\sim\mathcal{N}\left((1-\omega)X_1^k + \omega(\mu_1 - Q_{11}^{-1}Q_{12}(X_2^k-\mu_2)),\ \omega(2-\omega)Q_{11}^{-1}\right)}$$
与 SOR 对照，有两处改动：
1. **均值移动**：当前值保留权重 $(1-\omega)$，条件均值（"目标值"）追加权重 $\omega$——与 SOR 的确定性更新逐项同构；
2. **协方差缩放**：方差从 $Q_{11}^{-1}$ 变成 $\omega(2-\omega)Q_{11}^{-1}$——**这个缩放至关重要**。

**为什么必须缩放协方差？** 目标分布是 $\mathcal{N}(\mu,Q^{-1})$，过松弛后的平稳分布必须仍是它。若只动均值而不缩放方差，平稳分布的方差会偏离目标。因子 $\omega(2-\omega)$ 恰好补偿了均值移动给对方差带来的额外贡献，从而保住正确的平稳分布。注意它在 $\omega\in(0,2)$ 上恒正，协方差始终正定。

**负自相关的加速**。当 $\omega\to2$ 时，方差因子 $\omega(2-\omega)\to0$，均值移动趋近 $2[\text{条件均值}-X_1^k]$——样本在均值两侧**交替跳跃**。这产生**负自相关**：相邻样本倾向于从相反方向偏离均值。从蒙特卡洛渐近方差的角度看，负自相关甚至比零自相关更有利——相邻样本的偏差相互抵消，同样样本量下估计误差可以低于独立样本。Fox & Parker（2017）严格证明了过松弛 Gibbs 的收敛因子与 SOR 的收敛率完全一致：优化里的加速，在采样里有精确对应。

## 三、惯性 Langevin（ILA）：给 ULA 加动量

### 先把 ULA "拆成两块 Gibbs"

Falk, Habring & Pock（2025）发现 ULA 能用 Gibbs 的语言重写——这为加速 ULA 提供了切入点。把 ULA 的噪声 $\sqrt{2\tau}N$ 拆成两份：
$$X_{m+1} = X_m - \tau\nabla E(X_m) + \underbrace{\sqrt{\tau_1}N_1 + \sqrt{\tau_2}N_2}_{\sqrt{2\tau}N}, \quad \tau_1+\tau_2=2\tau$$
（这里 $E(x)=-\log p(x|y)$ 是势能，$-\nabla E=\nabla\log p$；$\tau$ 对应 4.3 节的步长 $\delta$。）定义中间变量：
$$Y_{m+1}\sim\mathcal{N}(X_m-\tau\nabla E(X_m),\ \tau_1 I),\qquad X_{m+1}\sim\mathcal{N}(Y_{m+1},\ \tau_2 I)$$
$X$ 的边缘更新恰是 ULA（两个高斯噪声之和仍是高斯）。严格说，这两个"条件核"一般并不来自同一个联合密度，因此这是**广义 Gibbs**（两块交替更新）而非标准 Gibbs 采样；但这一等价视角足以让我们把上一节的过松弛技巧移植过来。ILA 的最终正确性不依赖这个分解，而由欠阻尼 Langevin SDE 的平稳分布保证（第四节）。

### 对 ULA 施加过松弛 → ILA

把过松弛思想用到"ULA 的两块 Gibbs"上，消去中间变量 $Y$（利用 $Y_m\approx X_m-X_{m-1}$ 的递推关系合并高斯变量），得到单变量格式：
$$\boxed{X_{m+1} = X_m - \gamma\nabla E(X_m) + \beta(X_m - X_{m-1}) + \sqrt{2\gamma(1-\beta)}\,N_m}$$
其中重新参数化 $\gamma=\omega^2\tau,\ \beta=(1-\omega)^2$。

**三项读懂它**：
1. **梯度步** $-\gamma\nabla E(X_m)$：沿势能负梯度走（和 ULA 相同）；
2. **动量项** $\beta(X_m-X_{m-1})$：记住上一刻的运动方向，加速穿越平坦区；
3. **噪声项** $\sqrt{2\gamma(1-\beta)}N_m$：保住探索能力——**噪声缩放至关重要**。

**ILA = 重球法 + 噪声。** 它和 Polyak（1964）重球法精确对应：
- 重球法：$x_{k+1}=x_k-\gamma\nabla f(x_k)+\beta(x_k-x_{k-1})$——确定性，收敛到众数
- ILA：$X_{m+1}=X_m-\gamma\nabla E(X_m)+\beta(X_m-X_{m-1})+\sqrt{2\gamma(1-\beta)}N_m$——随机，收敛到分布

**转化律再次生效**：重球法 + 噪声 = ILA。

### 噪声缩放的重要性

ILA 噪声项里的 $(1-\beta)$ 因子来自过松弛的协方差缩放 $\omega(2-\omega)=1-(1-\omega)^2=1-\beta$。这个缩放不是随意选的——它是保证正确平稳分布的必要条件。
- $\beta=0$（$\omega=1$）：ILA 退化为标准 ULA，噪声为 $\sqrt{2\gamma}$
- $\beta\to1$（$\omega\to2$）：噪声趋零，动量主导——显著加速，但偏差增大

实践中 $\beta\to1$ 能大幅提速，引入的偏差可用 MH 校正步弥补——和 MALA 校正 ULA 偏差是同一思路。

## 实验 4.6-1：优化 vs 采样——MAP vs MMSE（重球法 vs ILA）

实验 `4.6-1.py` 演示**重球法与 ILA 的结构对应关系**，通过 TV 正则化图像去噪问题，直观验证"优化 + 噪声 = 采样"的统一规律。

### 实验场景

实验构造一个合成图像去噪问题：原始图像 $u$ 包含平坦区域、线性梯度区域和圆形边缘，观测模型为加性高斯噪声：

$$f = u + \varepsilon, \quad \varepsilon \sim \mathcal{N}(0, \sigma^2 I), \quad \sigma = 0.1$$

后验分布采用TV正则化先验（ROF模型）：

$$p(u|f) \propto \exp\left(-\lambda\|\nabla u\|_1 - \frac{1}{2\sigma^2}\|u - f\|_2^2\right)$$

在同一参数设置下（$\lambda = 10.0$，动量参数 $\theta = 0.99$），比较两种方法：

**MAP估计（重球法）**：使用加速梯度下降求解后验众数：

$$u_{m+1} = u_m + \theta(u_m - u_{m-1}) - \tau\nabla E(u_m)$$

其中 $E(u) = \lambda\|\nabla u\|_1 + \frac{1}{2\sigma^2}\|u - f\|_2^2$，步长 $\tau = 2/L$，$L$ 为Lipschitz常数估计。

**MMSE估计（ILA）**：使用惯性Langevin算法采样后验分布，取后验均值：

$$u_{m+1} = u_m + \theta(u_m - u_{m-1}) - \tau\nabla E(u_m) + \sqrt{2\tau(1-\theta)}N_m$$

与MAP的唯一区别是噪声项 $\sqrt{2\tau(1-\theta)}N_m$。迭代10000次，跳过前1000次作为burn-in，用剩余样本计算后验均值和后验方差。

### 实验目的

1. **验证"优化+噪声=采样"的统一规律**：MAP（重球法）和ILA使用完全相同的参数（$\lambda$、$\tau$、$\theta$），ILA仅多一个噪声项——直观展示两者结构上的精确对应
2. **对比后验众数与后验均值**：MAP给出后验最可能的解，MMSE给出后验分布的"重心"，两者在TV正则化问题下的差异反映了后验分布的偏斜性
3. **展示后验标准差的意义**：ILA采样不仅给出均值估计，还提供后验方差——量化不同区域的不确定性（边缘处不确定性高，平坦区域不确定性低）
4. **验证动量参数的稳定性**：$\theta = 0.99$ 是强动量参数，实验验证其与 $\tau = 2/L$ 组合在实际问题中的收敛稳定性

### 实验输入

| 参数 | 设置 |
|------|------|
| 图像尺寸 | $100 \times 100$ |
| 噪声模型 | 加性高斯白噪声，$\sigma = 0.1$ |
| TV正则化参数 | $\lambda = 10.0$ |
| 动量参数 | $\theta = 0.99$（$\beta$ 参数） |
| 步长 | $\tau = 2/L$，$L = \lambda \cdot 8/\epsilon + 1/\sigma^2$，$\epsilon = 10^{-3}$ |
| MAP迭代次数 | 10000 |
| ILA迭代次数 | 10000（burn-in: 1000） |
| 随机种子 | 42（numpy + torch） |

### 预期结果

- MAP和ILA使用相同参数，ILA仅多噪声项——验证"重球法 + 噪声 = ILA"的结构对应
- MAP（后验众数）PSNR高于MMSE（后验均值）——TV正则化后验偏斜，众数偏向更稀疏的解
- 后验标准差在图像边缘处较高（不确定性大），平坦区域较低（不确定性小）——量化重建置信度
- 收敛曲线稳定无发散——$\tau = 2/L$ 与 $\theta = 0.99$ 组合在数据项提供的强凸性下稳定

### 实验结果

运行 `4.6-1.py` 后，生成对比图。实验结果如下：

**PSNR对比**：

|----------|------|
| 含噪图像 | 19.97 dB |
| MAP（重球法） | 32.16 dB |

**结果分析**：

- **MAP vs MMSE**：MAP（32.16 dB）高于MMSE（29.71 dB）约2.5 dB。这是TV正则化后验偏斜的体现——后验众数偏向更稀疏的解（边缘更锐利），而后验均值被尾部概率质量"拉向"更平滑的方向。这与2.3节讨论的MMSE与MAP分歧一致：偏斜分布下众数与均值不重合。
- **后验标准差的空间分布**：右下角热图显示后验标准差的空间分布——边缘区域（圆形边界、方块边界）标准差较高（黄色），平坦区域标准差较低（深色）。这量化了不同区域的重建不确定性：边缘处TV正则化的梯度方向存在多种可能的解释，不确定性高；平坦区域梯度接近零，TV约束强，不确定性低。
- **ILA收敛稳定性**：ILA的TV+Data能量曲线在10000次迭代内稳定波动，无发散或持续振荡——验证 $\tau = 2/L$ 与 $\theta = 0.99$ 组合在数据项提供的强凸性下（$m \approx 1/\sigma^2 = 100$）收敛稳定。

**核心结论**：

| 结论 | 说明 |
|------|------|
| 结构对应验证 | MAP和ILA使用相同参数（$\lambda$、$\tau$、$\theta$），ILA仅多噪声项 $\sqrt{2\tau(1-\theta)}N_m$——直观验证"重球法 + 噪声 = ILA" |
| 后验众数 vs 后验均值 | MAP（众数）PSNR高于MMSE（均值）——TV后验偏斜，众数偏向更稀疏解 |
| 不确定性量化 | 后验标准差在边缘处高、平坦区域低——量化不同区域的重建置信度 |
| 动量稳定性 | $\theta = 0.99$ 强动量参数与 $\tau = 2/L$ 组合稳定收敛——数据项强凸性提供保障 |

> **核心洞察**：本实验直观验证了4.6节的核心命题——**优化加速与采样加速存在精确的结构对偶**。重球法（优化）与ILA（采样）的迭代格式几乎完全相同，唯一的区别是噪声项。这个噪声项不是随意添加的——其缩放因子 $\sqrt{2\tau(1-\theta)}$ 来自过松弛Gibbs的协方差缩放 $\omega(2-\omega) = 1-\beta$，是保证正确平稳分布的必要条件。

## 四、欠阻尼 Langevin SDE：ILA 的连续极限

与 ULA 之于过阻尼 Langevin 一样，ILA 的离散格式是某个连续 SDE 的离散化——**欠阻尼 Langevin 方程**（underdamped Langevin）：
$$\begin{cases} \mathrm{d}V_t = (-\eta V_t - \nabla E(X_t))\,\mathrm{d}t + \sqrt{2\eta}\,\mathrm{d}W_t \\ \mathrm{d}X_t = V_t\,\mathrm{d}t \end{cases}$$
其中 $\eta>0$ 是摩擦系数，$V_t$ 是速度、$X_t$ 是位置。这正是物理中的 Langevin 方程：位置由速度驱动，速度同时受势能力 $-\nabla E$、摩擦力 $-\eta V$ 和随机力 $\sqrt{2\eta}\,\mathrm{d}W_t$ 的共同作用。

**平稳分布**：
$$\pi(x,v)\propto\exp\left(-E(x)-\frac{\|v\|^2}{2}\right)$$
边缘化速度 $v$ 后，$x$ 的边缘恰为目标分布 $\int\pi\,\mathrm{d}v\propto e^{-E(x)}=p(x|y)$。这说明速度只是辅助变量，不影响 $x$ 的目标分布——它的全部作用在于让粒子"带着惯性"穿过空间。

**收敛定理**（Falk, Habring & Pock, 2025）：若 $E$ 强凸且梯度 Lipschitz，ILA 样本分布在 $W_2$ 距离下收敛到欠阻尼 Langevin SDE 的平稳分布。两点提醒：(1) ILA 同样**有偏**，偏差量级 $O(\gamma)$（与 4.3 节 ULA 的 $O(\delta)$ 离散化偏差同源）；(2) 欠阻尼的谱间隙大于过阻尼 Langevin——带惯性的粒子比纯扩散粒子更快地遍历整个空间。定性地，过阻尼 Langevin 的混合时间随条件数 $\kappa$ 按 $O(\kappa)$ 增长，欠阻尼在最优摩擦下可降至 $O(\sqrt{\kappa})$——与重球法加速梯度下降的提速幅度一致。

**与第7章的联系**：欠阻尼 Langevin SDE 是扩散模型里二阶 SDE 的特例。第7章会从扩散模型视角重看它——那时步长变为阻尼系数，$E(x)$ 换成数据分布的得分函数。ILA 是连接 Langevin 采样与扩散模型的重要桥梁。

## 五、优化加速 → 采样加速的完整对偶表

本章逐步建立的"优化→采样"对偶，在加速方法里达到高潮：

| 优化方法 | 采样方法 | 加速机制 | 转化律 |
|---|---|---|---|
| 梯度下降 | ULA | 加噪声 | GD + 噪声 = ULA |
| 近端梯度下降 | MYULA | 加噪声 | ProxGD + 噪声 = MYULA |
| 交替最小化 | Gibbs采样 | 加噪声 | AltMin + 噪声 = Gibbs |
| SOR/Gauss-Seidel加速 | 过松弛Gibbs | 协方差缩放 | SOR + 噪声缩放 = OR-Gibbs |
| 动量法/重球法 | ILA | 动量+噪声缩放 | HeavyBall + 噪声 = ILA |
| Nesterov加速 | ? | ? | 第7章：扩散模型 |

最后一行的问号并非虚设——Nesterov 加速在采样里的对应需要更深的数学（分数阶 SDE、随机插值），会在第7章扩散模型里自然出现。扩散模型可视为"终极加速采样"——靠多步噪声调度超越了 ILA。统一规律依然是：**优化里的加速技巧 → 采样里的对应方法**。两者共享同一套线性代数结构（条件高斯的均值 = 最优化步），优化的加速操作（均值移动）在采样里有精确对应（带协方差缩放的均值移动）。

至此我们建立了 MCMC 采样的完整方法工具箱——从通用框架（MH）到高效特例（ULA/MYULA），从梯度驱动到结构驱动（Gibbs），从基本方法到加速方法。但 MCMC 的输出是一条马尔可夫链——如何判断它是否已经收敛？收敛之后，又该如何用采样结果进行不确定性量化？这是下一节的主题。
