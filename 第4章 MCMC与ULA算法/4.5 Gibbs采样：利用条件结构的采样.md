# 4.5 Gibbs采样：利用条件结构的采样

> **核心观点**：Gibbs采样不利用梯度信息，而是利用后验的条件分布结构——通过引入辅助变量，将复杂分布分解为简单的条件分布，然后交替采样。GLM（Gaussian Latent Machine）框架展示了Gibbs采样在TV先验下的优雅实现，也揭示了采样与优化之间深层对偶：Gibbs = 带噪声的交替最小化。

## Gibbs采样的基本思想

### 从联合分布到条件分布

ULA/MYULA利用后验的梯度信息构造采样步骤。Gibbs采样提供了另一种策略：不利用梯度，而是利用后验的**条件分布结构**。

考虑联合分布 $p(x, z)$，目标是边缘分布 $p(x) = \int p(x, z)\,\mathrm{d}z$。Gibbs采样交替从条件分布中采样：

$$x^{k+1} \sim p_{X|Z=z^k}, \quad z^{k+1} \sim p_{Z|X=x^{k+1}}$$

### Gibbs采样是MH的特例

Gibbs采样实际上是MH算法的一个特例——当提议核恰好是条件分布时，接受概率恒为1：

**命题**：若提议核 $Q(x'|x) = p_{X|Z=z}(x')$（条件分布），则MH的接受概率 $\alpha = 1$。

*验证*：将条件分布代入MH接受概率：

$$\alpha = \min\left\{1, \frac{p(x', z)}{p(x, z)} \cdot \frac{p_{X|Z=z}(x)}{p_{X|Z=z}(x')}\right\} = \min\left\{1, \frac{p(x', z) \cdot p(x|z)}{p(x, z) \cdot p(x'|z)}\right\}$$

由 $p(x, z) = p(x|z)p(z)$ 和 $p(x', z) = p(x'|z)p(z)$，比值恰为1。 $\square$

Gibbs采样的优势在于：**不需要调节步长或提议分布**——条件分布就是最优提议，每一步都被自动接受。

## 从半二次最小化到GLM

### 半二次最小化回顾（优化视角）

3.4节处理不可微正则项时采用了近端方法。与近端方法不同，另一种优化策略是**半二次最小化**（half-quadratic minimization）（Geman & Reynolds, 1992）：

将函数 $f(x)$ 表达为辅助变量 $z$ 上的最小化：

$$f(x) = \min_z \, q(x, z)$$

其中 $q$ 关于 $x$ 是二次的。然后交替最小化：

$$x^{k+1} = \arg\min_x \, q(x, z^k), \quad z^{k+1} = \arg\min_z \, q(x^{k+1}, z)$$

**TV的例子**：绝对值函数可以表示为：

$$|t| = \min_{z > 0} \left\{\frac{t^2}{2z} + \frac{z}{2}\right\}$$

验证：对固定 $t$，在 $z > 0$ 上求 $\frac{t^2}{2z} + \frac{z}{2}$ 的最小值。对 $z$ 求导：$-\frac{t^2}{2z^2} + \frac{1}{2} = 0$，解得 $z^* = |t|$。代入得 $\frac{t^2}{2|t|} + \frac{|t|}{2} = |t|$。

### 从优化到采样的转化

半二次最小化的核心操作是 $\min$。在概率论中，$\min$ 的自然对应是**soft-min**（指数加权平均）。回顾TV的半二次表示 $|t| = \min_{z>0}\{t^2/(2z) + z/2\}$，将 $\min$ 替换为 $-\log\int\exp(\cdot)\,\mathrm{d}z$，就得到概率论中的对应关系：

$\lambda|t| \longleftrightarrow -\log\int_{\mathbb{R}^+} \exp(-q(t, z)) \, \mathrm{d}z$

其中 $q(t, z) = t^2/(2z) + z/2$ 关于 $t$ 是二次的。这种对应不是严格等式（右端实际上给出与Bessel函数相关的表达式），但它揭示了从优化到采样的关键转化：$\min$ 选择最优（众数），$-\log\int\exp$ 按指数权重平均（分布）。

从优化到采样的转化律：

$$\min \to \text{softmin}, \quad \text{交替最小化} \to \text{Gibbs采样}$$

## Gaussian Latent Machine（GLM）

### PoE先验模型

考虑**专家乘积**（Product of Experts, PoE）先验：

$$p_X(x) \propto \prod_{j=1}^m \phi_j((Kx)_j)$$

其中 $K$ 是线性算子（如有限差分算子），$\phi_j$ 是一维因子函数。当 $K$ 是卷积算子时，这等价于**专家场**（Fields of Experts, FoE）先验（Roth & Black, 2005）。

### GLM提升表示

GLM（Kuric, Zach, Habring, Unser & Pock, 2025）将PoE先验提升到联合空间：

$p_{X,Z}(x, z) = \underbrace{\mathcal{N}(Kx \mid \tilde{\mu}(z), \, \tilde{\Sigma}(z))}_{p_{KX|Z=z}(Kx)} \cdot \prod_{j=1}^m p_j(z_j)$

其中 $z = (z_1, \ldots, z_m)$ 是辅助变量。第一个因子是 $Kx$ 在给定 $z$ 下的条件密度（而非 $x$ 本身的条件密度）。

**条件分布的结构**：

- **$p_{X|Z}$**：由 $p_{KX|Z}$ 诱导的多元高斯 $\mathcal{N}(x \mid \mu(z), \Sigma(z))$，其中
  $$\mu(z) = (K^\top \tilde{\Sigma}(z)^{-1} K)^{-1} K^\top \tilde{\Sigma}(z)^{-1} \tilde{\mu}(z), \quad \Sigma(z) = (K^\top \tilde{\Sigma}(z)^{-1} K)^{-1}$$
  可以直接采样（多元高斯采样有成熟算法）

- **$p_{Z|X}$**：$m$ 个独立的一元分布——可以逐个采样

Gibbs采样在GLM上交替采样 $x$ 和 $z$，每一步都有闭式解——这就是GLM的优雅之处。

## TV先验的GLM实现

### Laplace因子的高斯尺度混合表示

TV先验的Laplace因子 $\exp(-\lambda|t|)$ 可以表示为**高斯尺度混合**（Gaussian scale mixture）：

$$\frac{\lambda}{2}\exp(-\lambda|t|) = \int_{\mathbb{R}^+} \frac{1}{\sqrt{2\pi z}} \exp\left(-\frac{t^2}{2z}\right) \cdot \frac{\lambda^2}{2}\exp\left(-\frac{\lambda^2 z}{2}\right) \mathrm{d}z$$

这个等式的含义是：Laplace分布是高斯分布（方差为 $z$）与Gamma分布（参数 $\lambda^2/2$）的混合。从高斯分量得到 $\tilde{\mu}(z_j) = 0$，$\tilde{\sigma}^2(z_j) = z_j$。

### 条件分布

- **$p_{Z_j|X=t}$**：给定 $(Kx)_j = t$，$z_j$ 的条件分布是**广义逆高斯分布** $\text{GIG}(\lambda^2, t^2, 1/2)$——一维分布，可以高效采样

- **$p_{X|Z}$**：多元高斯
  $$x^{k+1} \sim \mathcal{N}\left(x \mid 0, \, (K^\top \text{diag}(z^k)^{-1} K)^{-1}\right)$$

### Gibbs采样算法（TV先验）

**算法**（Gibbs采样，GLM框架，TV先验）：

1. 初始化 $z^0 = (z_1^0, \ldots, z_m^0)$
2. 对 $k = 0, 1, 2, \ldots$：
   - **采样 $x$**：$x^{k+1} \sim \mathcal{N}\left(x \mid 0, \, (K^\top \text{diag}(z^k)^{-1} K)^{-1}\right)$（多元高斯）
   - **采样 $z$**：$z_j^{k+1} \sim \text{GIG}(\lambda^2, (Kx^{k+1})_j^2, 1/2)$，$j = 1, \ldots, m$（独立一元分布）

### 扩展到后验采样

加入高斯似然项后，只需修改第一步的高斯分布：

$$x^{k+1} \sim \mathcal{N}\left(x \mid \mu(z^k, y), \, \Sigma(z^k, y)\right)$$

其中协方差和均值同时包含似然项和先验项的信息。第二步的GIG采样不变。

## Gibbs = 带噪声的交替最小化

### 高斯分布的Gibbs采样 vs Gauss-Seidel迭代

考虑二元高斯分布 $p(x_1, x_2) = \mathcal{N}(\mu, Q^{-1})$，其中精度矩阵 $Q = \begin{pmatrix} Q_{11} & Q_{12} \\ Q_{21} & Q_{22} \end{pmatrix}$。

**Gibbs采样**：

$$X_1^{k+1} \sim \mathcal{N}(\mu_1 - Q_{11}^{-1}Q_{12}(X_2^k - \mu_2), \, Q_{11}^{-1})$$
$$X_2^{k+1} \sim \mathcal{N}(\mu_2 - Q_{22}^{-1}Q_{21}(X_1^{k+1} - \mu_1), \, Q_{22}^{-1})$$

**Gauss-Seidel迭代**（交替最小化）：

$$x_1^{k+1} = \mu_1 - Q_{11}^{-1}Q_{12}(x_2^k - \mu_2)$$
$$x_2^{k+1} = \mu_2 - Q_{22}^{-1}Q_{21}(x_1^{k+1} - \mu_1)$$

**对比**：Gibbs采样的均值就是Gauss-Seidel的迭代值，唯一的区别是Gibbs在均值周围加了方差为 $Q_{ii}^{-1}$ 的高斯噪声——**Gibbs就是带噪声的Gauss-Seidel！**

### 结构对偶总结

| 优化 | 采样 | 区别 |
|---|---|---|
| 交替最小化 | Gibbs采样 | 加噪声 |
| Gauss-Seidel | 带噪声的Gauss-Seidel | 加噪声 |
| 半二次最小化 | GLM | 加噪声 |
| 收敛到众数 | 收敛到分布 | 目标不同 |

### 优化→采样的转化律

到目前为止，我们已经看到三种"优化→采样"的转化：

1. **梯度下降 $\to$ ULA**：加噪声
2. **近端梯度下降 $\to$ MYULA**：加噪声
3. **交替最小化 $\to$ Gibbs**：加噪声

统一规律：**优化算法 + 噪声 = 采样算法**——噪声将"收敛到点"变为"收敛到分布"。

更深层地，$\min \to \text{softmin}$ 是这个规律的数学基础：
- $\min$ 选择最优（众数），$\text{softmin}$ 按指数权重平均（分布）
- $\min$ 对应优化，$\text{softmin}$ 对应采样
- 从 $\min$ 到 $\text{softmin}$，确定性变为随机性，点估计变为分布估计

这一转化律将在4.6节的加速方法中继续适用——优化中的加速技巧也有采样中的对应方法。

Gibbs采样利用条件分布结构，ULA利用梯度信息——两种策略各有优势。能否进一步加速采样？正如优化中的Nesterov加速之于梯度下降，采样中也有对应的加速机制——过松弛与惯性Langevin算法。
