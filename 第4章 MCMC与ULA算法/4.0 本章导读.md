# 4.0 本章导读：从优化到采样——后验分布的探索

> "我们以为找到了答案，其实只是看清了问题的一个角。"——第3章的 MAP 估计就是这样一个"角"。

**路标句**：上一章（第3章）我们学会了怎么从后验里抠出"最可能那个点"——MAP。但第3章 3.7 节自己点破了：一个众数（mode，就是概率密度最高的那个点）不等于"典型样本"，更不等于整片分布的形状。本章要回答一个很实在的问题：**怎么从后验里"采"出一堆样本**，用这些样本把整片后验分布画出来。下一章（第5章）会把本章的 ULA 算法连续化，引出贯穿全书的"得分函数"。

想象你在一片浓雾里找一座山的山顶。第3章教你怎么最快爬到山顶（MAP）——这不错，但你其实还想知道：山有多宽？有没有别的山头？哪些地方其实也挺高、值得一去的？这些"形状信息"才是真正的不确定性。高维空间里，众数可能离均值（mean，所有样本的平均位置）非常远：比如 $n$ 维标准高斯，众数在原点，但一个典型样本的范数 $\|x\|$ 大约是 $\sqrt{n}$，离原点老远了。多峰后验（有多个山头）里，众数只代表一个峰，你把其他峰、以及整片宽度全丢了。

所以贝叶斯推断真正想要的，常常不是"一个点"，而是**一整片分布**——我们想算期望、方差、可信区域（credible region，简单说就是"真值有 95% 概率落在这里"的区域）。而要从分布里提取这些，最通用的办法就是**采样**：先生成一组样本 $X_1,\ldots,X_M \sim p(x|y)$，再用样本均值去近似后验期望：

$$\mathbb{E}[h(x)|y] \approx \frac{1}{M}\sum_{m=1}^M h(X_m)$$

这个朴素到家的想法叫 **Monte Carlo 积分**（蒙特卡洛积分，用随机样本近似积分），它是整条采样路径的基石。可麻烦在于：后验通常没法直接采样。这正是本章要解决的核心难题。

**本章目标**（读完你应该能）：
- 说清楚"为什么需要采样"——为什么后验期望算不出来、非得用样本凑（4.1）
- 用 Metropolis-Hastings（MH，提议-接受式采样）构造一条"稳态就是目标后验"的马尔可夫链（4.2）
- 看懂 ULA 为什么是"梯度下降 + 噪声"，并认出它里面的得分函数（4.3）
- 理解 MYULA 怎么用"光滑化"处理不可微先验、Gibbs 怎么利用条件结构（4.4–4.5）
- 用加速技巧（过松弛、惯性）提速，并学会判断"链收敛了吗、样本怎么用"（4.6–4.7）

## 本章地图：从"优化"拐进"采样"

这条路线是因果串联的，每一步都在解决上一步的不足：

```
Monte Carlo(4.1) → MH算法(4.2) → ULA/梯度采样(4.3) → MYULA/不可微(4.4)
                → Gibbs/条件结构(4.5) → 加速方法(4.6) → 诊断与UQ(4.7)
```

- **Monte Carlo 积分（4.1）**：后验期望需要样本，但后验通常没法直接采样——归一化常数（分母那个难算的积分）解不出来，高维直接采样又慢得离谱。出路是：不要求样本独立，改构造一条马尔可夫链（Markov chain，下一步只依赖当前步的随机序列），让它跑久了分布收敛到目标后验。这就引出 MCMC（Markov Chain Monte Carlo，马尔可夫链蒙特卡洛）。
- **Metropolis-Hastings 算法（4.2）**：MCMC 的通用框架。核心是一招"提议–接受/拒绝"：先随便试探着走一步，再决定留不留。妙处在于只需知道后验密度"到归一化常数"（也就是 $p(x|y) \propto p(y|x)p(x)$），不用算那个讨厌的分母。细致平衡（detailed balance，进出的"流量"相等）保证稳态正确。
- **ULA（4.3）**：MH 的随机游走提议在高维慢得像蜗牛。ULA 利用后验的梯度（最陡上升方向）走"有方向的步"——它是 Langevin 扩散（朗之万扩散，一种带漂流的随机过程）的 Euler 离散化（用折线近似连续过程）。ULA 有偏（不满足细致平衡），但快得多——这是"梯度信息"第一次登场，也给第5章埋下伏笔。**关键洞见：ULA = 梯度下降 + 噪声**。
- **MYULA（4.4）**：图像逆问题的后验常带不可微项（TV 范数、$\ell_1$、指示函数），ULA 的梯度要求直接翻车。MYULA 用 Moreau-Yoshida 包络（一种光滑化技巧）把尖角磨平，在磨平后的分布上跑 ULA——误差可控、有理论保证。
- **Gibbs 采样（4.5）**：不走梯度，改走"条件结构"。通过引入辅助变量，把复杂联合分布拆成简单的条件分布交替采样。GLM（Gaussian Latent Machine，高斯隐变量机）框架在 TV 先验下极其优雅：**Gibbs = 带噪声的交替最小化**。
- **加速采样（4.6）**：过松弛让 Gibbs 负自相关（样本在均值两侧来回跳，反而更高效）；惯性 Langevin（ILA）给 ULA 加动量项，连续极限是欠阻尼 Langevin SDE——优化与采样对偶的巅峰。
- **收敛诊断与不确定性量化（4.7）**：MCMC 吐出的是一条链，不是独立样本。怎么知道它收敛了？怎么用样本估不确定？Burn-in、自相关、有效样本量（ESS）是三件工具。

读完本章，你会拥有从任意后验里采样的完整工具箱。但更重要的是，你会记住一句贯穿全书的话：**优化算法 + 噪声 = 采样算法**——噪声把"收敛到一个点"变成了"收敛到一片分布"。下一章我们就把 ULA 的离散迭代变成连续的 Langevin SDE，正式请出"得分函数"这个贯穿全书的角色。
