# 4.0 本章导读：从优化到采样——后验分布的探索

> "我们以为找到了答案，其实只是看清了问题的一个角。"——第3章的 MAP 估计就是这样一个"角"。

**路标句**：上一章（第3章）我们学会了如何从后验中提取"最可能的那个点"——MAP。但 3.7 节已经点破：一个众数（mode，概率密度最高的点）不等于"典型样本"，更不等于整片分布的形状。从更深层次看，这正是信念刻画的演进节点：从"一个点"走向"一个分布"。本章要回答的是贝叶斯框架中一个基本的计算问题：**如何从后验中"采"出一组样本**，用这些样本描绘出整片后验分布。下一章（第5章）会把本章的 ULA 算法推向连续极限，引出贯穿全书的"得分函数"。

想象你在一片浓雾里寻找一座山的山顶。第3章教我们如何最快爬到山顶（MAP）——这固然有用，但雾中还藏着一层信息：山有多宽？有没有其他山头？哪些高地同样值得关注？这些"形状信息"合起来，才是真正需要刻画的不确定性。高维空间中，众数与均值（mean，所有样本的平均位置）的偏离往往超出直觉：以 $n$ 维标准高斯为例，众数在原点，但一个典型样本的范数 $\|x\|$ 约为 $\sqrt{n}$——"最可能的点"恰恰远离"样本通常出现的位置"。而在多峰后验中，众数只代表其中一个峰，其余的峰与整片分布的宽度全部丢失。

因此，贝叶斯推断真正想要的，常常不是"一个点"，而是**一整片分布**——我们需要计算期望、方差、可信区域（credible region，即"真值以 95% 概率落在此区域"）。而从分布中提取这些量的最通用办法，不是解析积分，而是**采样**：先生成一组样本 $X_1,\ldots,X_M \sim p(x|y)$，再用样本均值近似后验期望：

$$\mathbb{E}[h(x)|y] \approx \frac{1}{M}\sum_{m=1}^M h(X_m)$$

其中 $h(x)$ 是我们关心的任意量——取 $h(x)=x$ 得后验均值，取 $h(x)=x^2$ 得二阶矩；$M$ 是样本数。这条公式背后的思想极其朴素：积分算不动，就让随机出现的样本替我们"投票"。它就是 **Monte Carlo 积分**（蒙特卡洛积分，用随机样本近似积分），是整条采样路径的基石。困难在于：后验通常无法直接采样。这正是本章要解决的核心难题。

**本章目标**（读完你应该能）：
- 说清楚"为什么需要采样"——后验期望为何解析不可解、必须用样本逼近（4.1）
- 用 Metropolis-Hastings（MH，提议-接受式采样）构造一条"平稳分布即目标后验"的马尔可夫链（4.2）
- 理解 ULA 为什么是"梯度下降 + 噪声"，并认出其中的得分函数（4.3）
- 理解 MYULA 如何用"光滑化"处理不可微先验、Gibbs 如何利用条件结构（4.4–4.5）
- 用加速技巧（过松弛、惯性）提升采样效率，并学会诊断"链是否收敛、样本如何使用"（4.6–4.7）

## 本章地图：从"优化"走向"采样"

这条路线是因果串联的，每一步都在解决上一步的不足：

```
Monte Carlo(4.1) → MH算法(4.2) → ULA/梯度采样(4.3) → MYULA/不可微(4.4)
                → Gibbs/条件结构(4.5) → 加速方法(4.6) → 诊断与UQ(4.7)
```

- **Monte Carlo 积分（4.1）**：后验期望需要样本，但后验通常无法直接采样——归一化常数（分母那个难算的积分）解析不可解，高维直接采样又效率极低。出路是：放宽"样本独立"的要求，改构造一条马尔可夫链（Markov chain，下一步只依赖当前状态的随机过程），让它跑久了分布收敛到目标后验。这就引出 MCMC（Markov Chain Monte Carlo，马尔可夫链蒙特卡洛）。
- **Metropolis-Hastings 算法（4.2）**：MCMC 的通用框架。核心机制是"提议–接受/拒绝"：先按某个提议分布试探性地走一步，再按一定概率决定是否接受。其优势在于只需知道后验密度"到归一化常数"（即 $p(x|y) \propto p(y|x)p(x)$），无需计算那个不可解的分母。细致平衡（detailed balance，进出各区域的"流量"相等）保证稳态的正确性。
- **ULA（4.3）**：MH 的随机游走提议在高维空间效率低下。ULA 利用后验的梯度（概率上升最快的方向）走"有方向的步"——它是 Langevin 扩散（朗之万扩散，一种带漂流的随机过程）的 Euler 离散化（用折线近似连续过程）。ULA 有偏（不满足细致平衡），但效率远高于随机游走——这是"梯度信息"在采样路径中的首次登场，也给第5章埋下伏笔。**关键洞见：ULA = 梯度下降 + 噪声**。
- **MYULA（4.4）**：图像逆问题的后验常含不可微项（TV 范数、$\ell_1$、指示函数），ULA 的梯度假设不再成立。MYULA 用 Moreau-Yoshida 包络（一种光滑化技巧）把不可微项磨平，在光滑化后的分布上运行 ULA——近似误差可控、收敛有非渐近理论保证。
- **Gibbs 采样（4.5）**：不依赖梯度，转而利用"条件结构"。通过引入辅助变量，把复杂的联合分布拆成简单的条件分布交替采样。GLM（Gaussian Latent Machine，高斯隐变量机）框架在 TV 先验下尤为优雅：**Gibbs = 带噪声的交替最小化**。
- **加速采样（4.6）**：过松弛让 Gibbs 产生负自相关（样本在均值两侧来回跳，单个样本的信息量反而更高）；惯性 Langevin 算法（ILA）给 ULA 加上动量项，连续极限是欠阻尼 Langevin SDE——优化与采样对偶在此体现得最充分。
- **收敛诊断与不确定性量化（4.7）**：MCMC 输出的是一条链，不是独立样本。如何判断它已收敛？如何用样本量化不确定性？Burn-in、自相关函数、有效样本量（ESS）是三件核心工具。

读完本章，你将拥有从任意后验采样的完整工具箱。但更重要的是，你会记住一句贯穿全书的话：**优化算法 + 噪声 = 采样算法**——噪声把"收敛到一个点"变成了"收敛到一片分布"。这一转变意味着：随机性不再是需要消除的障碍，而是探索整个解空间的资源——优化轨迹只沿梯度下降，采样轨迹却因噪声得以造访每一处值得关注的区域。下一章我们就把 ULA 的离散迭代推向连续的 Langevin SDE，正式请出"得分函数"这个贯穿全书的角色。
