# 4.8 本章小结：优化算法 + 噪声 = 采样算法

> 核心观点：第 3 章告诉我们 MAP 只是后验众数，丢失了不确定性——本章沿采样路径（主线·逆问题驱动）前进，从后验分布中提取完整信息。Monte Carlo 积分是理论基础，MH 是通用框架，ULA 利用梯度信息实现高效采样，MYULA 扩展到不可微先验，Gibbs 利用条件结构，加速方法把优化中的加速技巧迁移到采样。贯穿全章的统一洞见：**优化算法 + 噪声 = 采样算法**——噪声把"收敛到点"变成"收敛到分布"。

## 一、本章走过了什么

```
4.1 Monte Carlo 积分：为什么需要采样（收敛率与维数无关）
  │
4.2 Metropolis-Hastings：通用 MCMC 框架（细致平衡，无需归一化常数）
  │
4.3 ULA：利用梯度的高效采样（Langevin 扩散的 Euler 离散）
  │
4.4 MYULA：Moreau 包络光滑化不可微项
  │
4.5 Gibbs 采样：利用条件分布结构（GLM 框架）
  │
4.6 加速：过松弛 Gibbs 与惯性 Langevin（ILA）
  │
4.7 收敛诊断与不确定性量化
```

- **4.1**：后验推断的核心计算任务是求期望 $\mathbb{E}[h(x)|y]$——高维积分不可解，Monte Carlo 用样本近似，收敛率 $O(1/\sqrt{M})$ 与维数无关。困难在于"如何从后验采样"——MCMC 用马尔可夫链绕开归一化常数。
- **4.2**：MH 通过"提议–接受/拒绝"构造以 $p(x|y)$ 为平稳分布的链。细致平衡是正确性保证；随机游走提议在高维效率极低，pCN-MCMC 对高维/无穷维问题尤其重要。
- **4.3**：ULA = 梯度下降 + 噪声——利用后验梯度构造"有方向"的提议，收敛远快于随机游走 MH。关键洞见：没有噪声只有"开发"（众数），有噪声才有"探索"（分布）。步长条件 $\delta\le 1/L$ 与梯度下降完全一致。
- **4.4**：图像后验常含不可微项，MYULA 用 Moreau-Yoshida 包络光滑化，在近似分布上运行 ULA——近似误差可控，收敛有非渐近保证。
- **4.5**：Gibbs 利用条件分布结构而非梯度。GLM 框架在 TV 先验下给出优雅实现——Gibbs = 带噪声的交替最小化，对应 Gauss-Seidel 的采样版。
- **4.6**：过松弛 Gibbs 对应 SOR，ILA 对应动量法/重球法，其连续极限是欠阻尼 Langevin SDE。优化加速技巧逐一迁移到采样。
- **4.7**：Burn-in、自相关函数、有效样本量（ESS）判断链是否收敛；HPD 可信区域、像素级可信区间把采样结果转化为决策依据。

从更深层次看，这条路径同时是**信念刻画的演进史**：第3章的 MAP 把解信念压缩为一个点，本章则让信念沿"采样路径"逐步展开——4.1 证明"点估计的积分可以用样本重建"，4.2–4.6 提供"如何高效生成这些样本"的梯度、近端、条件结构与加速四层工具，4.7 最后回答"这片分布可信到什么程度"。至此，对同一个后验，我们不仅能给出一个答案，还能给出整个答案的分布及其可信度。

## 二、优化 → 采样的结构对偶表

| 优化方法 | 采样方法 | 加速机制 |
|---|---|---|
| 梯度下降 | ULA | 加噪声 |
| 近端梯度下降 | MYULA | 加噪声 |
| 交替最小化 | Gibbs 采样 | 加噪声 |
| SOR/Gauss-Seidel | 过松弛 Gibbs | 协方差缩放 |
| 动量法/重球法 | ILA | 动量 + 噪声缩放 |

这张表是本章最重要的遗产。它的含义不止于"形似"：每一行里，优化算法的确定性更新被原封不动地保留，唯一的增量是一个缩放恰当的高斯噪声项——而正是这个噪声，把"收敛到后验众数的一个点"变成"遍历整个后验分布"。随机性在这里不是缺陷，而是能力：没有噪声的梯度下降只会反复攀登同一个峰，加入噪声的 ULA 却能把所有峰、谷与山脊的形状一并描出。**"优化算法 + 噪声 = 采样算法"**，这条转化律将在第5–7章以连续时间 SDE 的形式再次出现。

## 三、与前后章的呼应

- **承接第 3 章**：3.7 的分叉点在此兑现——走采样路径提取后验分布信息；误差分解五层次中的"采样误差"由本章处理。
- **关键伏笔（梯度信息）**：ULA 中"利用梯度 $\nabla\log p$"是采样路径中梯度信息的首次登场——第 5 章将追问：这个梯度（得分函数）从哪来、如何获取？这是通往扩散模型的关键转折。
- **向后开放**：ULA 的连续极限 → 第 5 章（Langevin SDE）；多尺度得分 → 第 6 章（得分匹配）；连续化 → 第 7 章（扩散模型）。

## 四、展望

下一章把 ULA 从离散迭代推向连续极限——Langevin SDE。第 5 章将揭示核心数学对象**得分函数** $\nabla_x\log p(x)$：它是概率分布的"方向场"，Tweedie 等式告诉我们"有了好的去噪器，就有了得分函数"——这是从逆问题走向扩散模型的关键一步。

**一句话总结全章**：沿着梯度走是优化，沿着梯度走并注入噪声是采样；而"噪声"这个看似多余的东西，正是让推断从"只给出一个答案"升级为"给出整个答案分布及其置信度"的关键。
