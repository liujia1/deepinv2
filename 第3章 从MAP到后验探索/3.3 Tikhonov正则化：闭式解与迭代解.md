# 3.3 Tikhonov正则化：闭式解与迭代解

> *"有没有一种正则化，能让我直接写出答案的公式？"* —— 在你掌握了优化基础之后，这一节先递给你一份最甜美的果实——高斯先验下的 Tikhonov。

**路标句**：上一节（3.2）搭好了优化地基：凸性、光滑性、梯度下降。现在我们从最简单的 MAP 实例入手——高斯先验下的 Tikhonov。它光滑、凸、有闭式解，是整个工具箱里最舒服的起点。这里还会呼应第2章：正则化参数 $\lambda$ 在贝叶斯眼里是信噪比的倒数，也正是先验信念强度的量化标尺。

---

**本节目标**（读完你应该能）：

- 从 MAP 推出 Tikhonov，并说明它"满足三好条件"；
- 在 SVD 域把 Tikhonov 看成"低通滤波器"，看懂 $\lambda$ 是截止频率；
- 理解 Landweber 迭代的"半收敛"——迭代次数本身就是正则化；
- 说清 $\lambda=\sigma^2/\sigma_x^2$ 的概率含义：噪声大→更信先验。

## 一、最简单的 MAP：光滑 + 凸

3.1 的导航图里，高斯先验那条线是最好走的：→ $\ell_2^2$ 正则项 → 光滑凸 → 有闭式解。这是所有 MAP 问题里最轻巧的情形，也是理解复杂方法的锚点。

在进入公式之前，先想清楚一个问题：为什么高斯先验是"最简单的"？因为它让目标函数同时具备了可微性与强凸性——梯度随处可用，最优点唯一且有限。换句话说，一个 MAP 问题最难伺候的三个地方（解存在、不会陷入局部、梯度能用），在高斯先验下全都自动满足。这正是我们想先从它身上学习"闭式解长什么样"的原因。

设观测 $\mathbf{y}=Ax+\varepsilon$，$\varepsilon\sim\mathcal{N}(0,\sigma^2 I)$；先验 $p(\mathbf{x})=\mathcal{N}(0,\sigma_x^2 I)$。

似然与先验：

$$p(\mathbf{y}|\mathbf{x}) \propto \exp\!\Big(-\frac{1}{2\sigma^2}\|Ax - \mathbf{y}\|_2^2\Big),\qquad p(\mathbf{x}) \propto \exp\!\Big(-\frac{1}{2\sigma_x^2}\|\mathbf{x}\|_2^2\Big)$$

MAP 目标：

$$\hat{x}_{\text{MAP}} = \arg\min_{x} \left\{\frac{1}{2\sigma^2}\|Ax - \mathbf{y}\|_2^2 + \frac{1}{2\sigma_x^2}\|\mathbf{x}\|_2^2\right\}$$

令 $\lambda = \sigma^2 / \sigma_x^2$，乘 $2\sigma^2$，得到标准 **Tikhonov 正则化（岭回归）**：

$$\boxed{\hat{x}_\lambda = \arg\min_{x} \left\{\|Ax - \mathbf{y}\|_2^2 + \lambda\|\mathbf{x}\|_2^2\right\}}$$

它完美满足 3.2 的三好条件：凸（二次和严格凸）、光滑（处处可微）、强制（$\lambda\|\mathbf{x}\|^2$ 兜底）。而且因为高斯共轭，后验仍高斯，MAP=MMSE——这是**唯一**有闭式解的情形。

这一步看似只是代数整理，但值得停下来看一眼其中的思想：$\lambda = \sigma^2/\sigma_x^2$ 不是凭空冒出的系数，而是"噪声不确定性"与"先验信念强度"之比。$\sigma=0$（无噪声）时 $\lambda=0$，我们完全信数据、退化为最小二乘；$\sigma_x$ 越小（先验越觉得 $\mathbf{x}$ 不可能偏离零太远）时 $\lambda$ 越大，我们越信先验。正则化在这里，正是先验信念在优化世界里的直接投影。

## 二、闭式解：在 SVD 域里它其实是个低通滤波器

### 正规方程：为什么这一步"值得庆祝"

在动手求导之前，先想清楚我们凭什么能"求导置零"。3.2 节说过：凸函数的任何驻点都是全局最小点。Tikhonov 目标是两个二次函数之和——处处可微、处处凸——所以"找最小解"这件原本困难的事，可以安全地化为"找梯度为零的点"。这正是闭式解得以存在的前提，也是高斯先验送给我们的第一份礼物。

回顾目标函数（把常数因子 $2\sigma^2$ 吸收进 $\lambda$ 之后）：

$$J(\mathbf{x}) = \|Ax - \mathbf{y}\|_2^2 + \lambda\|\mathbf{x}\|_2^2$$

两项各有现实含义：数据项 $\|Ax-\mathbf{y}\|_2^2$ 衡量"解对观测的解释程度"，正则项 $\lambda\|\mathbf{x}\|_2^2$ 衡量"解偏离先验信念（零均值）的程度"。对 $\mathbf{x}$ 求梯度（矩阵求导链式法则：$\|Ax-\mathbf{y}\|_2^2 = (Ax-\mathbf{y})^\top(Ax-\mathbf{y})$ 对 $\mathbf{x}$ 求导得 $2A^\top(Ax-\mathbf{y})$；$\mathbf{x}^\top \mathbf{x}$ 求导得 $2\mathbf{x}$）：

$$\nabla J(\mathbf{x}) = 2A^\top(Ax - \mathbf{y}) + 2\lambda \mathbf{x}$$

令梯度为零，约去公因子 2，再把含 $\mathbf{x}$ 的项归拢到一边：

$$A^\top(Ax - \mathbf{y}) + \lambda \mathbf{x} = 0 \quad\Longrightarrow\quad (A^\top A + \lambda I)\,\hat{x}_\lambda = A^\top \mathbf{y}$$

这就是**正规方程**——一个系数矩阵加 $\lambda I$ 的线性方程组。

看似只是代数整理，但真正值得停下来看一眼的是：$\lambda I$ 的加入改变了可解性的游戏规则。对比没有正则项的最小二乘：那里要解 $A^\top A\,\mathbf{x} = A^\top \mathbf{y}$，前提是 $A^\top A$ 可逆——而逆问题的不适定性恰恰体现在 $A^\top A$ 奇异或病态（某些奇异值为零或接近零），此时最小二乘解要么不存在、要么不唯一、要么被噪声放大到爆炸。而只要 $\lambda > 0$，对任意非零向量 $v$：

$$v^\top(A^\top A + \lambda I)\,v = \|Av\|_2^2 + \lambda\|v\|_2^2 > 0$$

即 $A^\top A + \lambda I$ 严格对称正定，必然可逆。从更深层次看，$\lambda I$ 做的事是把 $A^\top A$ 的谱整体抬高 $\lambda$——原本"平坦"的方向（数据不提供信息的方向）被赋予了正的曲率，解在这些方向上不再任意漂移，而是被先验拉回原点附近。这正是"正则化治愈不适定"在代数层面的体现：先验信念补上了数据缺失的方向。

于是解存在、唯一，且可以显式写出：

$$\hat{x}_\lambda = (A^\top A + \lambda I)^{-1} A^\top \mathbf{y}$$

### SVD 表示与滤波直觉

设 $A$ 的奇异值分解 $A=\sum_i \sigma_i u_i v_i^\top$。代入闭式解：

$$\hat{x}_\lambda = \sum_i \frac{\sigma_i}{\sigma_i^2 + \lambda} \langle \mathbf{y}, u_i \rangle v_i$$

和最小二乘解 $\hat{x}_{\text{LS}}=\sum_i \frac{1}{\sigma_i}\langle \mathbf{y},u_i\rangle v_i$ 对比，Tikhonov 把系数 $1/\sigma_i$ 换成了：

$$\underbrace{\frac{\sigma_i}{\sigma_i^2 + \lambda}}_{\text{Tikhonov滤波}} \quad \text{vs} \quad \underbrace{\frac{1}{\sigma_i}}_{\text{伪逆滤波}}$$

在解释这个公式之前，先建立一个直觉：逆问题里最危险的就是最小二乘。它在奇异值方向上的增益是 $1/\sigma_i$——当 $\sigma_i$ 很小时，噪声会被放大到爆炸。Tikhonov 想做的，无非是"给小奇异值方向踩刹车"。于是它把纯伪逆的 $1/\sigma_i$ 换成 $\frac{\sigma_i}{\sigma_i^2+\lambda}$：大奇异值方向几乎不受影响（保留有用信息），小奇异值方向被强烈衰减（压制噪声）。**一句话直觉**：Tikhonov 本质上是个**低通滤波器**。看它怎么随奇异值变化：

| 奇异值范围 | 滤波值 | 行为 |
|---|---|---|
| $\sigma_i^2 \gg \lambda$（大/低频） | $\approx 1/\sigma_i$ | 接近伪逆，保留信息 |
| $\sigma_i^2 \approx \lambda$（截止附近） | $=1/(2\sigma_i)$ | 衰减一半 |
| $\sigma_i^2 \ll \lambda$（小/高频） | $\approx \sigma_i/\lambda$ | 强烈衰减，压噪声 |

$\lambda$ 是**截止参数**：越大，越早截止（多压高频）；越小，越晚截止（多留高频，但也留噪声）。从更深层次看，这里面藏着一个极自然的哲学：数据在信息充足的频段才值得信任，而在信息被噪声淹没的频段，我们要用先验信念去"补位"。$\lambda$ 正是决定"哪个频段开始补位"的那条分界线。

两个极端：

- $\lambda\to 0$：趋近最小二乘——拟合完美，但小奇异值放大噪声→**过拟合**；
- $\lambda\to\infty$：解趋零——噪声压没了，信号也没了→**过正则化**。

Tikhonov 是"软截止"（平滑衰减）；与之对偶的截断 SVD（附录3A）则是"硬截断"。两者都是在 SVD 滤波视角下设计滤波函数——文献中把这一族方法统称为**谱滤波**（spectral filtering，作用于奇异值谱上的滤波）方法——一个对每个奇异值方向平滑压一把，一个直接丢弃小奇异值方向，只是"软压"与"硬扔"的极端程度不同。

### DFT 域加速：卷积情形的捷径

上面的闭式解 $(A^\top A + \lambda I)^{-1}A^\top \mathbf{y}$ 虽然漂亮，但要真正使用它，得显式构造并求逆一个 $n\times n$ 矩阵——一张 $1000\times 1000$ 的图像对应 $n=10^6$，$O(n^3)$ 的求逆代价完全不可行。求逆为什么这么贵？因为对一个"没有结构"的一般矩阵，求逆没有捷径可走。迭代解（下一节）是一条出路；但也可以反过来想：**如果算子本身结构极强，能不能让求逆直接变便宜？**

成像逆问题里最重要的一种强结构就是**卷积**：图像去模糊（第1章的相机抖动实验）、大多数光学系统的退化，都可以建模为图像与一个模糊核 $a$ 的卷积。

卷积的结构性体现在：**它能被离散傅里叶变换（DFT）一步对角化**。这不是巧合，而可以从卷积在做什么直接看出来。卷积的本质是"平移、加权、再叠加"。那么，有没有哪组波形在平移下保持不变？答案是复指数 $e^{\mathrm{i}\omega k}$：平移一个像素，它只是乘上一个相位因子 $e^{\mathrm{i}\omega}$，波形本身纹丝不动。既然卷积只是若干次平移的加权和，它作用在 $e^{\mathrm{i}\omega k}$ 上，结果必然还是 $e^{\mathrm{i}\omega k}$ 自己，只是乘上一个总增益 $\hat{a}(\omega)$（各次平移的系数 $a_j$ 乘各自相位后求和）。用线性代数的语言说：**复指数是卷积算子的特征向量，特征值 $\hat{a}(\omega)$ 恰是核 $a$ 的 DFT**——即模糊核的频率响应（核作为"冲激响应"的傅里叶变换，也称传递函数）。

这带来一个决定性的简化：把 DFT 的全部频率分量当作一组基，卷积矩阵在这组基下是对角矩阵，对角元就是 $\hat{a}(\omega)$。而闭式解里的 $A^\top A + \lambda I$ 是 $A$ 的多项式，它在这组基下同样是对角的（对角元为 $|\hat{a}(\omega)|^2 + \lambda$）——对角矩阵求逆，无非是把每个对角元取倒数。于是，庞大的矩阵求逆瓦解成一叠逐元素的除法：

$$\hat{x}_\lambda = \mathcal{F}^{-1}\left[\frac{\overline{\hat{a}} \odot \hat{y}}{|\hat{a}|^2 + \lambda}\right]$$

其中 $\mathcal{F}$ 表示 DFT 算子（$\mathcal{F}^{-1}$ 为逆变换），$\hat{a}=\mathcal{F}[a]$ 与 $\hat{y}=\mathcal{F}[\mathbf{y}]$ 则分别是模糊核 $a$ 与观测 $\mathbf{y}$ 的 DFT，$\overline{(\cdot)}$ 表示复共轭，$\odot$ 表示逐元素相乘。这正是上一小节 SVD 滤波视角在卷积情形的显式实现：特征值 $\hat{a}(\omega)$ 扮演奇异值 $\sigma_i$ 的角色，逐频率的滤波因子 $\overline{\hat{a}}/(|\hat{a}|^2+\lambda)$ 与 Tikhonov 滤波 $\sigma/(\sigma^2+\lambda)$ 同形——$|\hat{a}|$ 大的频率（信息充足）近乎无阻挡地通过，$|\hat{a}|$ 小的频率（多被噪声占据的高频）被 $\lambda$ 兜底压制，低通滤波的频域版本，一览无余。

代价核算：一次 FFT 正变换 + 逐元素运算 + 一次逆变换，总复杂度 $O(n\log n)$——对 $n=10^6$ 的图像，与 $O(n^3)$ 是天壤之别。这是 Tikhonov 在图像处理中广受宠爱的原因：当算子结构与傅里叶基对上时，贝叶斯最优解可以快到"随手可算"。

> **实践提示**：DFT 对角化隐含"循环卷积"假设（信号在边界外周期延拓）。若真实模糊不满足此假设，边界处会产生伪影，实践中常用镜像 padding 来缓解。

## 三、迭代解：当闭式太贵时

算子太大、矩阵求逆不划算时，用迭代。Tikhonov 目标的梯度：

$$\nabla f(\mathbf{x}) = A^\top(Ax - \mathbf{y}) + \lambda \mathbf{x}$$

梯度下降迭代：

$$x_{k+1} = x_k - \tau\big(A^\top(Ax_k - \mathbf{y}) + \lambda x_k\big)$$

3.2 节已分析：此目标 $L$-光滑（$\mu$-强凸），梯度下降线性收敛。换句话说，闭式解给出了"终点在哪"，而迭代给出了"不建大矩阵也能走到终点"的可行路线。

### Landweber 迭代：无正则项的梯度下降

$\lambda=0$ 时退化为最小二乘，梯度下降变成 **Landweber 迭代**：

$$x_{k+1} = x_k - \omega A^\top(Ax_k - \mathbf{y}),\qquad 0<\omega<2/\|A\|^2$$

它对含噪数据有个特殊行为——**半收敛性**：

- **前期**：迭代逼近真解，误差降；
- **后期**：噪声被逐步放大，误差回升。

**关键洞察：迭代次数 $k$ 本身就是正则化参数**。迭代太少欠拟合，太多过拟合——早停（early stopping）就是正则化。这和 $\lambda$ 控制强度完全是一回事，只是机制不同。这一转变意味着：正则化并不必然来自"显式的惩罚项"，它也可以来自"限制迭代步数"这条隐式通道——同一个平衡思想，两种外观。

Morozov 偏差原理给早停准则：当残差 $\|Ax_k-\mathbf{y}^\delta\|\approx\delta$ 时停（残差不该低于噪声水平，否则你在拟合噪声）。

> **统一观点**：正则化可以来自显式惩罚（Tikhonov 的 $\lambda\|\mathbf{x}\|^2$），也可以来自隐式早停（Landweber 的 $k$）。都是在数据拟合与稳定性间找平衡。3.6 节再深挖。

## 四、偏差-方差分解：λ 在走钢丝

Tikhonov 总误差可拆成两块：

$$\hat{x}_\lambda^\delta - \mathbf{x}^\dagger = \underbrace{(\hat{x}_\lambda^\delta - x_\lambda)}_{\text{方差（数据误差）}} + \underbrace{(x_\lambda - \mathbf{x}^\dagger)}_{\text{偏差（近似误差）}}$$

先解读这两项的物理含义。**方差项** $\hat{x}_\lambda^\delta - x_\lambda$ 刻画"噪声 $\delta$ 通过算子传播进解"的程度；**偏差项** $x_\lambda - \mathbf{x}^\dagger$ 刻画"正则化本身把解拉离真解"的程度。

- **方差**：噪声传播引起。$\lambda$ 越大，滤波越强，噪声放得越小→方差小；
- **偏差**：正则化本身引入。$\lambda$ 越大，偏离理想伪逆越远→偏差大。

| $\lambda$ | 偏差 | 方差 | 总误差 | 现象 |
|---|---|---|---|---|
| $\to 0$（欠正则） | 小 | 大 | 噪声主导 | 过拟合 |
| 最优 | 中 | 中 | **最小** | 最佳平衡 |
| $\to\infty$（过正则） | 大 | 小 | 偏差主导 | 过平滑 |

如果让你画"PSNR 随 $\lambda$ 变化的曲线"，你会画成单调的吗？其实它是**单峰**的——$\lambda$ 太小或太大都掉，中间有个尖。最优 $\lambda$ 在偏差与方差的钢丝上取得平衡。这正是统计学习与逆问题反复出现的主题。

SVD 视角下更清楚：滤波函数与理想伪逆的偏差 $-\frac{\lambda}{\sigma_i(\sigma_i^2+\lambda)}$——大奇异值方向偏差小，小奇异值方向偏差大（但这些方向本就被噪声污染，用偏差换抑噪是正经取舍）。

## 五、λ 的概率含义：它不是旋钮，是信噪比的倒数

这是本节最该记住的一句话：在整个推导里，$\lambda$ 始终连着概率模型：

$$\lambda = \frac{\sigma^2}{\sigma_x^2} = \frac{\text{噪声方差}}{\text{先验方差}}$$

直觉极深：

- **$\lambda$ 小**（噪声低/先验弱）→ 数据可信 → 弱正则；
- **$\lambda$ 大**（噪声高/先验强）→ 数据被污染 → 更信先验 → 强正则。

$\lambda$ 本质上是**信噪比的倒数**：信噪比高，$\lambda$ 小，正则弱；信噪比低，$\lambda$ 大，正则强。它根本不是"要调的旋钮"，而是噪声模型 + 先验模型的自然推论。这也是第2章那句"正则化参数有概率含义"在最优实例上的完全兑现——$\lambda$ 越大，代表我们越相信"真解本身不会偏离先验均值太远"，即先验信念越强。

实践中 $\sigma^2$（常可估）、$\sigma_x^2$（需领域知识）未必全知，所以选 $\lambda$ 仍是难题。两种策略：

| 策略 | 原理 | 代表方法 |
|---|---|---|
| 频率学派 | 数据统计性质 | 交叉验证、L-curve、GCV |
| 贝叶斯学派 | 概率模型推断 | 边际似然最大化（经验贝叶斯，3.6） |

## 📌 实验3.3-1：Tikhonov 闭式解与 λ 的贝叶斯诠释

### 实验场景

纯去噪（$A=I$）下验证 Tikhonov 闭式解与 $\lambda$ 的贝叶斯含义。对 128×128 Cameraman 加噪（$\sigma=0.1$），用以先验均值 $\mu$ 为中心的闭式解 $\hat{x}=\mu+(\mathbf{y}-\mu)/(1+\lambda)$ 去噪，扫描 $\lambda$ 画 PSNR-λ 曲线，对比三种选 $\lambda$ 策略。

选 $A=I$ 的原因：闭式解退化为逐元素收缩 $\hat{x}_i=\mu+(y_i-\mu)/(1+\lambda)$，去掉模糊算子干扰，纯粹观察 $\lambda$。

### 实验目的

1. 验证 $A=I$ 时 $\hat{x}=\mu+(\mathbf{y}-\mu)/(1+\lambda)$：每个像素被统一"收缩"向先验均值 $\mu$；
2. 通过 PSNR-λ 曲线看 $\lambda$ 的权衡；
3. 验证贝叶斯选 $\lambda=\sigma^2/\sigma_x^2$ 的合理性；
4. 对比 oracle 与含噪估计两种 $\sigma_x$ 获取方式；
5. 看三种 regime 下的误差分布。

### 实验输入

- 图像 128×128 Cameraman；退化 $A=I$，加噪 $\sigma=0.1$
- 图像标准差 $\sigma_x=0.2815$，先验均值 $\mu\approx\text{mean}(\mathbf{y})=0.5063$（均值对噪声稳健，可直接从观测估计）
- $\lambda\in[0.0001,10]$ 对数均匀扫描
- 三种 $\lambda$：Oracle 贝叶斯 $\lambda_{\text{bayes}}=\sigma^2/\sigma_x^2=0.1262$；含噪估计；PSNR 最优（网格搜索）

### 预期结果

- 闭式解去噪优于含噪观测；PSNR-λ 单峰；Oracle λ 与 PSNR 最优 λ 高度吻合。

### 实验结果

运行 `3.3-1.py` 后生成一张含 6 子图的图。

![实验3.3-1 Tikhonov闭式解与λ的贝叶斯诠释](<./第三章 配套实验/实验3.3-1/步骤1_Tikhonov闭式解与lambda.png>)

**参数**：图像 128×128，噪声 $\sigma=0.1$，图像标准差 $\sigma_x=0.2815$，先验均值 $\mu=0.5063$。

**闭式解验证**（$A=I$）：Oracle 贝叶斯 $\lambda=0.1262$，PSNR=20.22 dB（含噪观测 20.12 dB）——去噪确实优于含噪观测。

**λ 扫描**：

| 策略 | λ 值 | PSNR | 说明 |
|:---|:---|:---|:---|
| PSNR 最优（网格） | 0.1151 | **20.22 dB** | 理论界，需真解 |
| Oracle 贝叶斯 | 0.1262 | 20.22 dB | 用真实 $\sigma_x$，不可得 |
| 含噪估计贝叶斯 | 0.1327 | 20.22 dB | 从含噪观测估 $\sigma_x$ |

**核心验证**：

- 闭式解 $\hat{x}=\mu+(\mathbf{y}-\mu)/(1+\lambda)$ 把每个像素向先验均值 $\mu$ 收缩；$\lambda$ 越大收缩越强；
- PSNR-λ 单峰，峰值附近极平坦，$\lambda_{\text{best}}=0.1151$ 最高；
- Oracle 贝叶斯 λ（0.1262）与 PSNR 最优 λ（0.1151）高度吻合，验证了 $\lambda=\sigma^2/\sigma_x^2$ 的贝叶斯最优性。

> **为何收缩中心必须是 $\mu$ 而非 0**：高斯先验下 MAP=MMSE，$\lambda=\sigma^2/\sigma_x^2$ 本就**同时**最小化后验能量与 $\ell_2$ 重建误差，二者不存在"张力"。真正的关键是**先验均值**——自然图像并非零均值（Cameraman 均值约 0.5）。若错误地以 $\mu=0$ 为收缩中心，$\hat{x}=\mathbf{y}/(1+\lambda)$ 会把亮图整体压暗、引入系统偏差，使经验最优 λ 落到 $\sigma^2/\mathbb{E}[\mathbf{x}^2]\approx0.03$（这里 $\mathbb{E}[\mathbf{x}^2]=\sigma_x^2+\mu^2$ 是关于原点 0 的二阶矩），从而与 $\sigma^2/\sigma_x^2=0.1262$ 差近 4 倍（即 $\lambda_{\text{bayes}}$ 对 $\mu=0$ 而言偏大约 4 倍）；若仍套用 $\lambda=0.1262$ 去收缩，会把亮图压得过低，PSNR 跌到约 18.90 dB、反低于含噪观测的 20.12 dB（而若改用 $\mu=0$ 自己那约 0.03 的最优 $\lambda$，PSNR 仍可回到 20.21 dB，但重建仍带整体偏暗的系统偏差）。以正确均值 $\mu$ 为中心后，这一"反直觉"彻底消失，贝叶斯 λ 即 PSNR 最优 λ。

### 补充说明

1. **闭式解物理含义**：$A=I$ 时 $\hat{x}=\mu+(\mathbf{y}-\mu)/(1+\lambda)$ 是逐元素向先验均值 $\mu$ 收缩（$\mu=0$ 退化为 $\mathbf{y}/(1+\lambda)$，即一、二节的标准形式）；一般 $A\neq I$ 时收缩在 SVD 域按奇异值差异化进行。
2. **PSNR-λ 单峰性**：偏差-方差权衡的直接体现。
3. **贝叶斯 λ = 频率 λ**：高斯先验下 MAP=MMSE，$\lambda=\sigma^2/\sigma_x^2$ 同时是最小化后验能量与 $\ell_2$ 误差的解，两者一致（前提是收缩中心取对先验均值 $\mu$）。
4. **含噪估计 $\sigma_x$**：$\hat{\sigma}_x^2=\text{Var}(\mathbf{y})-\sigma^2$；低信噪比时变负，框架退化到"最大正则化"。
5. **三种 regime 误差**：欠正则误差≈噪声（均匀、幅度小）；过正则误差 $\approx|\mathbf{x}-\mu|$（显出图像结构、幅度大）；适中误差最小。
6. **$A=I$ 教学价值**：先在此理解 $\lambda$，再推广到 $A\neq I$（如 3.1-1 的模糊算子）。

> 本实验为 3.6 经验贝叶斯提供基础：当 $\sigma_x$ 未知，如何从数据自动推 $\lambda$？

## 本节小结

**闭式解与滤波**：$\hat{x}_\lambda=\sum_i \frac{\sigma_i}{\sigma_i^2+\lambda}\langle \mathbf{y},u_i\rangle v_i$ 在 SVD 域是低通滤波器——大奇异值留信号，小奇异值压噪声。$\lambda$ 控截止；对卷积问题 DFT 加速到 $O(n\log n)$。

**迭代与半收敛**：梯度下降是闭式解的迭代替代；$\lambda=0$ 退化为 Landweber，展现半收敛——迭代次数即正则化，早停=正则化。

**偏差-方差与 λ 含义**：总误差=偏差+方差，最优 $\lambda$ 取其平衡。$\lambda=\sigma^2/\sigma_x^2$ 是信噪比倒数，也是先验信念强度，有概率含义，但自动选取仍是难题（3.6 解决）。

**承上启下**：Tikhonov 闭式解依赖高斯先验的可微性。换 Laplace 先验（$\|\mathbf{x}\|_1$），目标在零点不可微，梯度下降失效——下一节（3.4）上近端方法。
