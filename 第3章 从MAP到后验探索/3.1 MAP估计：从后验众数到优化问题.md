# 3.1 MAP估计：从后验众数到优化问题

> *"后验都写出来了，然后呢？"* —— 这是第2章结尾时，你心里最自然的那句嘀咕。

上一章（第2章）把"先验 = 正则项"讲透了，后验的形式已经完整。但后验是高维空间里一团算不出的密度。本章我们退一步：先不要整片云，只要那一个点最合理的答案。这一节负责把"要那个点"翻译成"做一道优化题"。

---

**本节目标**：

- 说清 MAP 为什么就是"后验众数"，以及它和 MMSE（后验均值）是同一后验下的两种"问法"；
- 写出 MAP = 最小化"数据项 + 正则项"这个核心等式；
- 看懂一张导航表：先验 → 正则项 → 优化困难 → 求解算法；
- 用 Bregman 散度理解 MAP 的"最优性"到底优在哪。

---

## 一、我们为什么要"提取"一个点？

回想画面：第1章我们拼出 $p(x|y) \propto p(y|x)\cdot p(x)$；第2章我们给 $p(x)$ 找了各种具体长相。现在后验 $p(x|y)$ 在 $\mathbb{R}^n$（$n$ 可达百万）里是一团浓度分布。

可你不能直接"读"它。必须**提取**信息。第2章末尾预告了两种提取策略：

- **后验均值**（MMSE）：$\hat{x}_{\text{MMSE}} = \mathbb{E}[x|y] = \int x\,p(x|y)\,dx$——要用到后验的全部信息，但得算高维积分。
- **后验众数**（MAP）：$\hat{x}_{\text{MAP}} = \arg\max_x p(x|y)$——只用局部信息，只需优化。

**为什么本章先走 MAP？** 一句话：优化比积分便宜太多了。MMSE 要在百万维空间里算积分，工程上基本是天方夜谭；MAP 只需要在"云"里找最高的那个点。这个取舍非常现实——先要一个能用的单点答案，把工具箱搭起来。

> **直觉先行**：MAP 就像在一片山的模型里问"最高的山峰在哪"；MMSE 则问"所有点的平均海拔是多少"。前者只要爬山，后者要把整片地都量一遍。

---

## 二、MAP 是什么：后验众数

MAP（Maximum A Posteriori，最大后验）就是让后验密度最大的那个点：

$$\hat{x}_{\text{MAP}} = \arg\max_{x} \, p(x|y)$$

直观说，它就是"给定观测 $y$ 后，最可能的 $x$"——后验分布的**众数**（mode，密度最高的点）。

但"直接对密度求最大值"不好算。取个负对数（$-\ln$ 是严格单调递减函数，所以"最大化密度"等价于"最小化负对数密度"）：

$$\hat{x}_{\text{MAP}} = \arg\max_{x} p(x|y) = \arg\min_{x} \big[-\ln p(x|y)\big]$$

把贝叶斯定理 $p(x|y) \propto p(y|x)\,p(x)$ 代进去，并丢掉与 $x$ 无关的常数 $\ln p(y)$，得到：

$$-\ln p(x|y) = \underbrace{-\ln p(y|x)}_{\text{数据项 } D(x)} + \underbrace{(-\ln p(x))}_{\text{正则项 } R(x)} + \text{const}$$

于是最关键的等式出现了：

$$\boxed{\hat{x}_{\text{MAP}} = \arg\min_{x} \big\{D(x) + R(x)\big\} = \arg\min_{x} \big\{-\ln p(y|x) - \ln p(x)\big\}}$$

**一句话标点**：左边是概率语言（"最可能的 $x$"），右边是优化语言（"最小化后验能量"）——同一件事。

---

## 三、MAP 和 MMSE：同一后验下的两种"问法"

你可能会问：都是"最优估计"，凭什么 MAP 只给众数、MMSE 给均值，它俩差在哪？

答案是：它们回答的是**不同损失函数下的最优问题**。这需要请出 **Bregman 散度**（一种"凸函数剩余量"的距离度量）。

设后验是对数凹的（即 $p(x|y) \propto \exp\{-\phi_y(x)\}$，$\phi_y$ 凸）。定义 Bregman 散度：

$$D_{\phi}(u, x) = \phi(u) - \phi(x) - \langle \nabla\phi(x),\, u - x \rangle$$

它衡量 $\phi$ 在 $u$ 处的值，和它用 $x$ 点的一阶近似去估的差——非负（凸性保证），但一般**不对称**。

有个非常漂亮的结论（Pereyra, 2019）：

- **MAP** 是在 Bregman 散度损失下的贝叶斯最优估计器：
  $$\hat{x}_{\text{MAP}} = \arg\min_{u} \, \mathbb{E}\big[D_{\phi}(u, x) \,\big|\, y\big]$$
- 而把两个参数互换，**MMSE**（后验均值）恰好是：
  $$\hat{x}_{\text{MMSE}} = \arg\min_{u} \, \mathbb{E}\big[D_{\phi}(x, u) \,\big|\, y\big]$$

对偶结构如下：

| 损失函数 | 最优估计器 | 利用后验的方式 |
|---|---|---|
| 平方损失 $\|u-x\|_2^2$ | MMSE（后验均值） | 对后验全空间积分 |
| Bregman散度 $D_\phi(u,x)$ | MAP（后验众数） | 找后验密度最高点 |
| 反Bregman散度 $D_\phi(x,u)$ | MMSE（后验均值） | 对后验全空间积分 |

> 注意第一行和第三行都是 MMSE，只是来自不同损失。平方损失其实是 Bregman 散度的特例（取 $\phi=\frac12\|\cdot\|^2$ 即得 $\frac12\|u-x\|^2$）。所以：**MAP 和 MMSE 不是谁对谁错，而是对后验的两种不同"问法"**。高斯后验下众数=均值，两者重合；非高斯下就分道扬镳——这正是第2章讨论过的分歧。

## 四、从概率到优化：因果链导航图

现在我们把 MAP 的具体形式摊开。设观测模型 $y = Ax + \varepsilon$，$\varepsilon \sim \mathcal{N}(0,\sigma^2 I)$，先验 $p(x) \propto \exp(-\theta_g\,g(x))$（指数族）。取负对数、乘以 $2\sigma^2$，令 $\lambda = 2\sigma^2\theta_g$，得到：

$$\hat{x}_{\text{MAP}} = \arg\min_{x} \big\{\|y - Ax\|_2^2 + \lambda \, g(x)\big\}$$

这就是变分正则化的标准样貌：**数据拟合项 $\|y-Ax\|^2$ + 正则项 $\lambda g(x)$**。

注意 $\lambda = 2\sigma^2\theta_g$ —— 它由噪声参数 $\sigma^2$ 和先验参数 $\theta_g$ 共同决定。不是拍脑袋的旋钮（呼应第2章"正则化参数有概率含义"）。

**因为** MAP 把推断变成了优化，**所以**"好不好解"取决于目标函数的性质；**而**目标函数的性质完全由先验决定。这就形成因果链：

**先验的选择 → 正则项的形式 → 目标函数的优化困难 → 需要的求解算法**

不同先验在这一条链上的走向：

| 先验 | 先验密度 | 正则项 $R(x)$ | 目标函数性质 | 优化困难 | 求解算法 |
|---|---|---|---|---|---|
| 高斯 | $\propto e^{-\frac{1}{2\sigma_x^2}\|x\|^2}$ | $\|x\|_2^2$ | 光滑凸 | 无（有闭式解） | 直接解 / 梯度下降（3.3） |
| Laplace | $\propto e^{-\alpha\|x\|_1}$ | $\|x\|_1$ | 凸但不可微 | 梯度不存在 | 近端方法（3.4） |
| TV | $\propto e^{-\alpha\|\nabla x\|_1}$ | $\|\nabla x\|_1$ | 复合不可微 | 近端无闭式 | 原始-对偶（3.5） |

这张表是本章的导航图：每一步都是前一步遇到新困难后的发展。

### 一个完整的小例子：高斯先验 + 高斯似然 = Tikhonov

设似然 $p(y|x)=\mathcal{N}(Ax,\sigma^2 I)$，先验 $p(x)=\mathcal{N}(0,\sigma_x^2 I)$。MAP 目标是：

$$\hat{x}_{\text{MAP}} = \arg\min_{x} \left\{\frac{1}{2\sigma^2}\|y - Ax\|_2^2 + \frac{1}{2\sigma_x^2}\|x\|_2^2\right\}$$

令 $\lambda = \sigma^2/\sigma_x^2$，这正是 **Tikhonov 正则化（岭回归）**。由于高斯共轭，后验仍高斯，MAP=MMSE，有闭式解：

$$\hat{x}_\lambda = (A^\top A + \lambda I)^{-1} A^\top y$$

这个例子是理解更复杂方法的锚点：①闭式解依赖高斯先验的可微性（先验一不可微，闭式就消失）；②MAP=MMSE 依赖后验对称（一偏斜就分家）；③ $\lambda$ 的含义清晰，但怎么自动选仍是难题（3.6 节再谈）。

## 五、信念更新叙事：MAP 把"先验"洗成了"答案"

贝叶斯的核心戏码是"数据来了，信念被更新"。这里我们用最朴素的方式感受一下，为什么 MAP 少不了先验：

- **朴素基线（只用数据）**：如果你丢掉先验，只做最小二乘 $\min_x \|Ax-y\|^2$，在模糊算子 $A$ 有零空间时，答案根本不存在或不唯一——数据本身不足以定解。
- **加进先验（MAP）**：一旦加 $-\ln p(x)$ 这一项，目标函数被"强行兜底"，最优点出现了。先验在这里扮演的角色，正是第2章说的"把我们对 $x$ 的信念，作为正则项压进优化里"。

也就是说，**MAP = 数据信念 + 先验信念，两者在能量函数里被加权和**。权重 $\lambda$ 越大，越偏信先验；$\lambda$ 越小，越偏信数据。这个"信念被数据逐步修正"的故事，会在后续各章越讲越深（第4章用采样把整个后验画出来，就是它的完全体）。

## 📌 实验3.1-1：MAP 估计——后验能量分解

### 实验场景

在模糊逆问题下，对 32×32 Shepp-Logan 图像加高斯模糊（$\sigma_{\text{blur}}=2.0$）与噪声（$\sigma=0.05$），在高斯先验（$\sigma_x=0.5$）下算 MAP 闭式解。

### 实验目的

1. 验证 $-\ln p(x|y)$ 可拆成「数据项 + 正则项」；
2. 对比不同初始点的后验能量，确认 MAP 解确实最小；
3. 验证 $\lambda=\sigma^2/\sigma_x^2$ 来自概率模型而非拍脑袋；
4. 展示后验方差（不确定性），为 3.7 节"MAP 只是后验一个点"埋伏笔。

### 实验输入

- 图像：32×32 Shepp-Logan phantom，归一化 $[0,1]$
- 模糊：高斯核 $\sigma_{\text{blur}}=2.0$
- 噪声：加性高斯 $\sigma=0.05$
- 先验标准差：$\sigma_x=0.5$
- 正则化参数：$\lambda=\sigma^2/\sigma_x^2=0.01$

### 预期结果

- MAP 解的后验能量最小；PSNR 优于朴素基线；后验能量分解表清晰；后验方差图展示不确定性的空间分布。

### 实验结果

运行 `3.1-1.py` 后生成一张图。

![实验3.1-1 步骤1：MAP后验能量分解](<./第三章 配套实验/实验3.1-1/步骤1_MAP后验能量分解.png>)

**参数设定**：噪声 $\sigma=0.050$，先验 $\sigma_x=0.500$，$\lambda=\sigma^2/\sigma_x^2=0.0100$。

**后验能量分解**（$-\ln p(x|y)=\text{数据项}+\text{正则项}$）：

| 方案 | 数据项 | 正则项 | 后验能量 | PSNR |
|------|--------|--------|----------|------|
| 观测初始 | 545.93 | 53.04 | 598.97 | 14.64 dB |
| 转置初始 | 679.18 | 43.59 | 722.78 | 14.60 dB |
| MAP估计 | 441.16 | 67.84 | **509.00** | **15.02 dB** |
| 真解 | 490.25 | 123.04 | 613.28 | N/A |

**核心验证**：

- MAP 解能量 509.00 < 观测初始 598.97 < 转置初始 722.78，优化有效；
- MAP 的 PSNR=15.02 dB，优于两个初始点；
- $\lambda=0.01$ 是噪声方差与先验方差之比，有清晰概率来源。

> 观测初始 = "啥也不修"，是工程里最常见的朴素基线。

### 补充说明

1. **MAP = 最大化后验 = 最小化能量**：MAP 解能量（509.00）显著低于两个初始点，数值验证了目标有效。
2. **能量分解的直觉**：数据项衡量"与观测一致"，正则项衡量"与先验一致"。注意**真解能量（613.28）反而高于 MAP（509.00）**——说明 MAP 不是"真解"，而是在数据一致性与先验一致性之间的权衡点。
3. **$\lambda$ 的概率意义**：$\lambda=\sigma^2/\sigma_x^2$ 不是调参结果，是噪声/先验方差比。
4. **后验方差 = 不确定性**：闭式解还给出后验协方差 $\Sigma_{\text{post}}$，方差图显示模糊核中心与边缘处不确定更高——这也是 3.7 节"MAP 只给一个点"的呼应。
5. **闭式解的存在性**：共轭高斯 → 后验高斯 → MAP=MMSE → 有闭式解，是最简单的情形。

> 注：本实验展示的是边缘方差（对角元），忽略了像素间相关性；完整不确定性需要第4章的 MCMC/ULA 采样。

## 六、MAP 的适用范围与局限

**优势：计算友好。** MAP 把积分换成优化——MMSE 要算 $\int x\,p(x|y)dx$，MAP 只要解 $\arg\min\{D+R\}$。凸目标函数下有成熟的凸优化算法（梯度下降、近端、原始-对偶）。

**局限：只给众数，丢了形状。** 因为"优化替代积分"，MAP 把后验的其他信息全丢了：

- **不确定性**：后验方差能告诉你"答案多可靠"——MAP 给不出；
- **多峰性**：多解逆问题（如有限角 CT）里后验有好几个峰，MAP 只给最高的那个；
- **偏斜/重尾**：这些统计特征在优化里被完全抹掉。

> 一句话收束：MAP 是个强大的**点估计**工具，但点终究只是后验的一个切面。

## 本节小结

**一个等式**：MAP = 后验众数 = 后验能量最小化。取负对数后，"最大化后验"与"最小化能量"是同一枚硬币两面。MAP 在 Bregman 散度损失下最优，MMSE 在平方损失下最优——两者是同一后验的两种"问法"。

**一条因果链**：先验 → 正则项 → 优化困难 → 求解算法。MAP 把推断变成优化，优化的难度由先验决定：高斯→光滑凸（3.3），Laplace→不可微（3.4），TV→复合结构（3.5）。

**承上启下**：MAP 数学上是个优化问题。但"好不好解"取决于目标函数性质——凸性保唯一、光滑性保梯度可用、强制性保存在。这正是下一节（3.2）要搭的优化地基。
