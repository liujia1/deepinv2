# 3.0 本章导读：MAP——从后验众数到优化工具箱

第2章的结尾，后验分布 $p(x|y)$ 的形式已经完全确定——似然（第1章）乘以先验（第2章），并给出了两条路径：点估计（第3章）与分布采样（第4章）。但确定形式不等于解决问题：高维空间中的后验分布无法直接计算，我们必须从中**提取**有用的信息。本章走第一条路——最自然的提取方式：找后验最"高"的那个点，即后验众数，也就是MAP估计。取负对数后，MAP估计等价于一个优化问题：

$$\hat{x}_{\text{MAP}} = \arg\min_x \underbrace{-\ln p(y|x)}_{\text{数据项 } D(x)} + \underbrace{-\ln p(x)}_{\text{正则项 } R(x)}$$

这个等式是贝叶斯推断与正则化优化之间最直接的桥梁：左边是概率论语言——"最可能的 $x$ 是什么"，右边是优化语言——"最小化后验能量"。第2章已经建立了"先验→正则项"的对应关系，现在进入求解阶段。

不同的先验带来不同的正则项，不同的正则项带来不同的优化困难，不同的优化困难需要不同的求解算法——本章的主线就在这条因果链上展开：

**MAP=优化问题**（3.1）：MAP估计将"从后验中找最可能的 $x$"转化为最小化后验能量。概率论中的最大化后验与优化中的最小化能量是同一枚硬币的两面，MAP估计器在Bregman散度损失下具有最优性，这是它作为点估计的概率论根基。

**优化需要什么条件**（3.2）：目标函数的凸性保证解的唯一性，光滑性决定梯度信息是否可用，强制性保证解的存在性。梯度下降是最基本的迭代框架，步长选择和Lipschitz条件决定了它是稳步收敛还是震荡发散。

**最简实例：光滑+凸**（3.3）：高斯先验+高斯似然是唯一的共轭情形——后验为高斯，MAP=MMSE，有闭式解。Tikhonov正则化是最基本的正则化方法：闭式解给出理论直觉（SVD滤波器），迭代解提供数值框架（梯度下降），偏差-方差分解揭示正则化参数的深刻含义——$\lambda = \sigma^2/\sigma_x^2$ 不是任意常数，而是信噪比的倒数。

**不可微怎么办**（3.4）：Laplace先验（$\ell_1$ 正则化）的目标函数含不可微项，梯度下降失效。近端算子是处理不可微凸函数的基本工具——软阈值将小于阈值的分量归零、大于阈值的分量收缩，这正是稀疏化的操作。ISTA将梯度下降推广到"光滑+不可微"的复合结构，FISTA用Nesterov加速将收敛速率从 $O(1/k)$ 提升到 $O(1/k^2)$——一阶方法的最优速率。

**TV的复合结构怎么办**（3.5）：TV正则化 $\|\nabla x\|_1$ 中梯度算子 $\nabla$ 使近端算子没有闭式解，近端方法也遇到了障碍。通过Fenchel对偶将原始问题转化为鞍点问题，Chambolle-Pock算法在原始与对偶空间之间交替推进，高效求解——这是处理"复合不可微"问题的标准工具。PnP框架则暗示了另一条路：用学习到的去噪器替换近端算子，这为后续的Tweedie等式和得分函数埋下了伏笔。

**收敛有保障吗？参数怎么选**（3.6）：Bregman距离衡量收敛质量，源条件连接收敛速率与问题的正则性——源条件不是技术假设，而是问题可解性的度量。经验贝叶斯将"人为调参"转化为"数据驱动"：边际似然最大化让正则化参数的选择有了概率论根基，正则化参数不再是黑箱中的旋钮。

**MAP够了吗**（3.7）：MAP只给出后验众数，但众数≠典型。高维空间中众数可能远离均值——$n$ 维标准高斯的众数在原点，而典型样本的范数 $\|x\| \approx \sqrt{n}$ 远离原点。多峰后验中众数只代表一个峰，不确定性、多解识别、条件生成——这些任务都需要后验分布的完整信息，而非单点估计。两条路径从分叉点出发：采样探索后验（第4章），变分近似后验（第8章）。

```
MAP=优化(3.1) → 优化基础(3.2) → Tikhonov光滑实例(3.3) → 近端方法/不可微(3.4) → 原始-对偶/TV(3.5) → 收敛与参数(3.6) → 分叉：MAP→后验(3.7)
```

本章结束时，读者将拥有MAP求解的完整工具箱——从梯度下降到近端方法再到原始-对偶算法，按"光滑→不可微→复合"的困难递进逐步建立。同时也将理解它的局限——点估计只是后验的一个点，后验的完整信息需要采样或近似。接下来的两条路径各有侧重：第4章走采样路线（MCMC→ULA），第8章走变分路线（ELBO→VAE）——两条路终将在扩散模型处汇合。
