# 16.5 扩散先验重建

> 前面几节，所有方法——FBP、TV、UNet、算法展开——最终都只给你"一张图"。但临床里真正值钱的，往往是另一句话：**"这张图里，哪块我拿不准？"** 扩散先验重建要做的，不是只给一张图，而是给一整片"可能的图"——从这片分布里，你既能取平均得到最佳估计，也能取方差得到"我有多不确定"。这正是全书第 13 章"条件扩散 = 逆问题求解"在真实医院里的落地。

**本节目标**（读完你应该能）：
- 看懂扩散先验如何把"第 5–13 章的采样/得分/扩散"拼成 CT/MRI 的重建器
- 用 when/why/how 理解 DiffPIR / DDRM / DPS 三种方法的取舍
- 理解"点 vs 分布"：扩散先验给的是后验分布，不是单点
- 明白它能量化不确定性、无需配对数据——这三重优势为何在临床格外值钱

## 16.5.1 从传统先验到扩散先验：回到第 13 章

**先验演化回顾**。从第 2 章到本章，CT/MRI 重建的先验走了一条清晰的路：

$$\text{显式先验} \xrightarrow{\text{第2章}} \text{PnP 去噪先验} \xrightarrow{\text{第5-6章}} \text{扩散先验}$$

| 先验类型 | 代表方法 | 优势 | 局限 |
|---------|---------|------|------|
| 显式先验 | TV、小波、剪切波 | 可解释、无需训练 | 表达能力有限（第 2 章 2.4） |
| PnP 去噪先验 | PnP-ADMM、PnP-ULA | 学习型先验、可采样 | 单一噪声水平、需条件去噪器 |
| 学习型先验 | UNet、展开网络 | 强表达力 | 需配对数据、无不确定性量化 |
| **扩散先验** | DiffPIR、DDRM、DPS | 三重优势 | 计算代价高 |

**条件扩散采样的统一框架**。回顾第 13 章 13.2 的后验得分分解定理，CT/MRI 逆问题的条件逆向 SDE（随机微分方程，stochastic differential equation，带随机项的微分方程）为：

$$dx = [f(x,t) - g(t)^2 \nabla\log p_t(x_t|y)]\,dt + g(t)\,d\bar{w}$$

其中后验得分（score，对数概率密度的梯度，指向"概率更大的方向"）分解为两项：

$$\boxed{\nabla_{x_t}\log p(x_t|y) = \underbrace{\nabla_{x_t}\log p(x_t)}_{\text{扩散先验（已学到）}} + \underbrace{\nabla_{x_t}\log p(y|x_t)}_{\text{似然得分（需近似）}}}$$

- **第一项** $\nabla_{x_t}\log p(x_t)$：由预训练的无条件扩散模型提供——这是全书第 5–7 章"采样路径"的终点
- **第二项** $\nabla_{x_t}\log p(y|x_t)$：似然得分（likelihood score，把测量 $y$ 的信息灌进采样），不同方法的差别就在怎么近似这一项

> **点 vs 分布（呼应 16.4）**：前面 UNet、展开网络给你一个 $x$——单点。扩散先验给你的是**整个后验分布** $p(x|y)$。多次采样取平均得后验均值，取方差得不确定性的度量。这正是医学成像梦寐以求的：不只给"图"，还告诉医生"哪里我拿不准"。

**CT 和 MRI 的正向算子**。不同 $A$ 决定似然得分的具体形式：

- **CT**：$A = \mathcal{R}$（离散 Radon），$A^T$ 是反投影

$$\nabla_{x_t}\log p(y|x_t) \approx \zeta A^T(y - A\hat{x}_{0|t})$$

- **MRI**：$A = M_\Omega F$（欠采样傅里叶），$A^T = F^H M_\Omega^T$

$$\nabla_{x_t}\log p(y|x_t) \approx \zeta F^H M_\Omega^T(y - M_\Omega F\hat{x}_{0|t})$$

MRI 的 $A$ 有特殊优势：$F$ 是酉矩阵，$A^TA = M_\Omega^T M_\Omega$ 是对角阵——数据一致性步算得极快。

## 16.5.2 DiffPIR for CT/MRI

**when / why / how**：
- **什么时候用**：你想用扩散先验，但希望实现简单、稳定，能直接套现成的扩散去噪器。
- **为什么难**：既要利用扩散模型的强先验，又要保证和测量 $y$ 一致。
- **怎么做**：DiffPIR（Diffusion Plugin for Image Restoration，Zhu et al. 2023）把扩散去噪和数据一致性步**交替**执行（回顾第 13 章 13.3.4）。对 $t = T,T-1,\dots,1$：

1. **预测干净图像**：用 Tweedie 等式（第 5 章 5.3）从带噪 $x_t$ 预测 $\hat{x}_{0|t}$：

$$\hat{x}_{0|t} = \frac{x_t - \sqrt{1-\bar{\alpha}_t}\,\epsilon_\theta(x_t,t)}{\sqrt{\bar{\alpha}_t}}$$

（也可等价地从噪声预测 $\epsilon_\theta$ 反推。）

2. **数据一致性步**：把预测往"符合测量"方向拉：

$$\hat{x}_{0|t}' = \hat{x}_{0|t} - \zeta A^T(A\hat{x}_{0|t} - y)$$

3. **去噪步**：从修正后的 $\hat{x}_{0|t}'$ 出发，执行一步反向扩散

$$x_{t-1} = \text{ReverseStep}(x_t, t, \hat{x}_{0|t}')$$

**CT 上的 DiffPIR**：$A$ 是 Radon（常由 ASTRA 实现），数据一致性步就是上面的公式，$A^T$ 是反投影。实践要点：缩放因子 $\zeta$ 要随噪声水平调（CT 噪声常是 Poisson 型，需近似成高斯）；有限角时 $A^T$ 只给部分信息，数据一致性受限（正是 16.2.3 的不可见边缘问题）。

**MRI 上的 DiffPIR**：$A = M_\Omega F$，数据一致性步能进一步简化：

$$\hat{x}_{0|t}' = \hat{x}_{0|t} - \zeta F^H M_\Omega^T(M_\Omega F\hat{x}_{0|t} - y)$$

因 $M_\Omega^T M_\Omega$ 对角、$F^H F = I$，上式退化为：

$$\hat{x}_{0|t}' = \begin{cases}
\text{未采样位置：} \hat{x}_{0|t} \\
\text{已采样位置：} \hat{x}_{0|t} + \zeta(y - F\hat{x}_{0|t})
\end{cases}$$

> **直觉**：MRI 的数据一致性步像"填空题"——已知的 k-space 位置直接用测量值替换，未知位置保持扩散预测。CT 则像"校准题"——每条射线穿过多像素，无法简单替换，得靠 $A^T$ 做梯度修正。

## 16.5.3 DDRM 与 DPS for CT/MRI

**DDRM：基于 SVD 的线性方法**（Kawar et al. 2022，回顾第 13 章 13.3.1）。核心是用 $A$ 的 SVD 把逆问题拆成一串一维去噪。
- **CT 上的 DDRM**：需算 $A = U\Sigma V^T$ 的 SVD。大规模 CT（如 $512\times512$）的 $A$ 维度可达 $10^5\times10^5$，SVD 代价极高 → **不太实用**，除非低秩近似或迭代 SVD。
- **MRI 上的 DDRM**：$A = M_\Omega F$ 特殊结构（$F$ 酉、$M_\Omega$ 掩码），SVD 退化为对角化，代价极低 → **特别高效**。

**DPS：Laplace 近似的通用方法**（Chung et al.，回顾第 13 章 13.3.2）。用 Laplace 近似 $p(y|x_t)\approx p(y|\hat{x}_{0|t})$，是最通用的扩散逆问题方法。对 $t=T,\dots,1$：
1. 预测 $\hat{x}_{0|t} = \text{predict\_x0}(x_t,t)$
2. 数据一致性梯度 $\nabla_l = A^T(y - A\hat{x}_{0|t})$
3. 修正得分 $s_{\text{corrected}} = s_\theta(x_t,t) + \zeta\nabla_l$
4. Euler-Maruyama 步进 $x_{t-1} = x_t + f\cdot dt - g^2\cdot s_{\text{corrected}}\cdot dt + g\sqrt{dt}\cdot z$

- **CT 上的 DPS**：通用——不用算 SVD，只要 $A$ 和 $A^T$（ASTRA 给）。有限角、稀疏投影等任何线性 CT 问题都能直接上。
- **MRI 上的 DPS**：同样适用，且算子特殊结构让数据一致性梯度更高效。

**缩放因子 $\zeta$ 的选择**（影响重建质量的关键超参）：
- 太小：数据一致性不足，重建可能和测量不符
- 太大：过度约束，压住扩散先验表达力
- 经验范围 $\zeta\in[0.1,1.0]$；有限角 CT 要更大的 $\zeta$（数据约束更强），MRI 欠采样可适当减小

## 16.5.4 方法对比与选择指南

**全谱系对比**：

| 方法 | 是否需要训练 | 不确定性量化 | 非线性问题 | 计算代价 | 测量一致性 |
|------|------------|------------|-----------|---------|-----------|
| FBP/零填充 | 否 | 否 | 否 | 低 | 完美（线性） |
| 正则化(TV/CS) | 否 | 否 | 否 | 中 | 完美（优化解） |
| UNet 端到端 | 是（监督） | 否 | 是 | 低 | 弱 |
| 展开网络 | 是（监督） | 否 | 是 | 中 | 强 |
| DiffPIR | 否（预训练扩散） | 是 | 是 | 高 | 中 |
| DDRM | 否（预训练扩散） | 是 | 仅线性 | 高 | 强（SVD 精确） |
| DPS | 否（预训练扩散） | 是 | 是 | 高 | 中（Laplace 近似） |

**选择指南**（按场景）：
- **高 SNR 全角 CT** → FBP（数据充分、算子良态）
- **稀疏投影 CT** → 正则化（TV/小波）或展开网络
- **有限角 CT** → 扩散先验（DPS/DiffPIR，严重不适定 + 不可见边缘，只有强先验能救）
- **快速 MRI（轻度欠采样）** → 并行成像 + CS（临床成熟）
- **极端欠采样 MRI**（因子 >8）→ 扩散先验（DDRM/DPS/DiffPIR）
- **需不确定性量化** → 扩散先验（多次采样 → 像素级置信区间），唯一能给药不确定性的方法族
- **非线性逆问题**（PET、相位恢复）→ DPS（DDRM 只管线性）

**不确定性量化的实践**。扩散先验的核心优势之一：多次独立条件采样得 $\{x^{(1)},\dots,x^{(M)}\}$：
- **像素级均值** $\bar{x} = \frac{1}{M}\sum_m x^{(m)}$（后验均值估计）
- **像素级方差** $\sigma^2 = \frac{1}{M}\sum_m (x^{(m)}-\bar{x})^2$（不确定性度量）
- **置信区间** $\bar{x} \pm 2\sigma$（约 95%）

在 CT/MRI 里，不确定性图能揭示：
- 有限角 CT：不可见边缘区域不确定性高（和波前集理论预测一致）
- MRI 欠采样：k-space 缺失对应的空间频率不确定性高

> **临床价值**：高不确定性区域提示放射科医生"此处谨慎解读"。传统方法（FBP、CS、学习型）统统给不了这个信息。

## 本节小结

扩散先验重建在 CT/MRI 上的落地，验证全书核心论点：

$$\text{逆问题} \xrightarrow{\text{贝叶斯}} \text{后验采样} \xrightarrow{\text{条件扩散}} \text{逆问题求解}$$

关键成果：
1. **无需配对训练数据**——预训练无条件扩散模型，零样本迁移到任何 CT/MRI 任务
2. **可量化不确定性**——多次后验采样 → 像素级置信区间
3. **零样本迁移 + 通用性**——DPS 支持任何正向算子（线性/非线性），无需 SVD；MRI 傅里叶算子让数据一致性步极快

> **信念更新叙事（呼应第 3 章贝叶斯）**：把扩散先验想成我们**最强的事先信念**——它从海量图像里学到了"真实医学图像长什么样"。当测量数据 $y$ 进来时，这个信念被"拉"向符合测量的方向：数据强的方向（采样密集的 k-space、可见角度的射线），先验被洗掉、数据说了算；数据弱的方向（缺失的 k-space、不可见边缘），先验的信念被推到前台，成了重建的主角。多次采样，你就把这条"信念被证据更新"的过程变成了一张**不确定性地图**——这正是贝叶斯思想的终极兑现：不是给一个孤零零的答案，而是给答案 + 对答案的把握。

从 FBP 到扩散先验，CT/MRI 重建方法的演化完美映射全书叙事弧——从显式先验到隐式先验、从点估计到后验采样、从手工设计到数据驱动。

## 实验 16.5-1：扩散先验重建

实验 `16.5-1.py` 实现**DiffPIR 和 DPS 两种扩散先验方法求解 MRI 逆问题**，验证扩散先验的三重优势，实现不确定性量化。

### 实验场景

实验在 MNIST 数据集上训练 DDPM，再用 DiffPIR 和 DPS 求解 MRI 欠采样重建问题。实验验证 16.5 节的核心论点：**扩散先验方法无需配对训练数据、可量化不确定性、零样本迁移**。

**扩散先验核心公式**（16.5.1节）：
$$\nabla_{x_t}\log p(x_t|y) = \nabla_{x_t}\log p(x_t) + \nabla_{x_t}\log p(y|x_t)$$

**两种方法对比**（16.5.2/16.5.3节）：
- **DiffPIR**：Tweedie 预测 + 数据一致性步 + 反向扩散
- **DPS**：Laplace 近似，似然得分直接加入反向 SDE

### 实验目的

1. **实现 DiffPIR for MRI**：验证 MRI 算子结构的特殊性（数据一致性步极高效）
2. **实现 DPS for MRI**：验证缩放因子 $\zeta$ 的敏感性
3. **对比方法性能**：零填充、DiffPIR、DPS 的 PSNR 对比
4. **实现不确定性量化**：多次采样 → 像素级方差 → 95% 置信区间

### 实验输入

| 参数 | 设置 |
|------|------|
| 数据集 | MNIST，$28 \times 28$ 像素 |
| DDPM 训练 | T=200，线性 $\beta$ 调度，50 epoch |
| MRI 欠采样 | R=4，可变密度掩码 |
| DiffPIR 参数 | Tweedie 预测，数据一致性步 |
| DPS 参数 | $\zeta \in [0.1, 1.0]$，Laplace 近似 |
| 不确定性量化 | 15 次独立采样 |

### 预期结果

- DiffPIR 和 DPS 的 PSNR 高于零填充重建
- $\zeta$ 最优值约 0.5；$\zeta$ 太小 → 重建与测量不符；$\zeta$ 太大 → 过度约束
- 多次采样的后验均值比单次采样更平滑
- 高不确定性区域对应 k-space 缺失信息的位置

#### 核心知识点总结

| 概念 | 实验验证 |
|------|---------|
| 扩散先验三重优势 | 步骤4：无需配对数据、不确定性量化、零样本迁移 |

**关键洞察**：实验验证了 16.5 节的核心论点——**扩散先验方法是医学成像重建的终极解决方案**。三重优势（无需配对数据、不确定性量化、零样本迁移）完美契合医学成像需求。虽然 MNIST 小型 DDPM（28×28）上 PSNR 未显著优于零填充，但临床级 MRI（256×256+ 大模型）优势更显著。实验同时展示了不确定性量化的实用价值——为临床决策提供置信度信息，这是传统方法（FBP、CS、学习型）无法提供的。
