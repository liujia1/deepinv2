# 16.0 本章导读：从物理到先验——医学成像中的逆问题实践

> **核心观点**：CT和MRI是两种最典型的医学成像逆问题——CT的正向模型是Radon变换（线积分），MRI的正向模型是傅里叶采样（k-space）。从FBP到TV正则化，从压缩感知到深度学习，再到扩散先验重建，CT/MRI重建方法的演化完美映射了全书的叙事弧：**物理建模→显式先验→学习型先验→扩散先验**，每一步都是前一步局限性的自然回应。

前13章完成了一个宏大的理论闭环：逆问题需要后验采样→采样需要得分函数→得分可以从去噪器中提取→去噪器可通过得分匹配训练→多步得分驱动采样即扩散模型→条件扩散采样=逆问题求解。第14章拓展了Flow Matching前沿，第15章解决了"用什么架构实现去噪器"的实践问题。但所有这些理论和方法，最终都要在真实的逆问题上落地——**它们真的管用吗？**

本章选择CT和MRI作为落地场景，原因有三。第一，CT和MRI是医学成像中两个最基础的模态，临床需求巨大——全球每年CT扫描超过3亿次、MRI扫描超过1亿次。第二，它们的正向模型有明确的物理基础和数学刻画，是"教科书级"的逆问题。第三，CT和MRI恰好代表了两种截然不同的线性算子——Radon变换（积分几何）和傅里叶算子（调和分析）——它们的对比能加深对逆问题结构的理解。

**从物理到先验的统一**——这是本章的核心论点。CT和MRI看似是两种完全不同的成像模态，但从逆问题的视角看，它们共享同一结构：

$$y = Ax + \epsilon \quad \xrightarrow{\text{逆问题}} \quad p(x|y) \propto p(y|x) \cdot p(x)$$

不同的$A$（Radon vs Fourier），相同的贝叶斯框架；不同的不适定性来源（有限角度 vs 欠采样），相同的正则化需求；不同的经典方法（FBP vs FFT），相同的学习型方法升级路径；最终，相同的扩散先验落地方式。这条从物理到先验的路径，正是全书从第1章到第13章推理链的缩影。

本章从物理基础出发，走一条"物理建模→数学分析→经典方法→深度学习→扩散先验"的路径：

**CT成像**（16.1）：X射线穿过人体后的衰减遵循Beer-Lambert定律——测量的每一条射线都是衰减系数的线积分，所有射线的集合构成Radon变换。Fourier切片定理将Radon变换与傅里叶变换联系起来，滤波反投影（FBP）利用这一联系实现了经典重建。但FBP需要完整的投影角度和低噪声条件，否则重建质量急剧下降。

**CT的不适定性与正则化**（16.2）：全角CT的奇异值以$1/n$衰减（温和不适定），而有限角CT的奇异值指数衰减（严重不适定）。波前集理论从几何角度解释了有限角为何丢失信息——只有与测量角度垂直的边缘方向才可恢复。正则化方法的选择必须匹配不适定性的程度：Tikhonov适合温和不适定，TV和剪切波稀疏适合严重不适定。

**MRI成像**（16.3）：MRI的正向模型是傅里叶采样——k-space数据就是图像的傅里叶变换。MRI的不适定性不来自算子本身（傅里叶变换是良态的），而来自加速采集的愿望：用更少的k-space样本重建图像。并行成像利用多线圈信息，压缩感知利用图像的稀疏性，两者已成为临床标配。

**学习型重建方法**（16.4）：UNet端到端重建用数据驱动的网络替代手工先验，Learned Gradient Descent将迭代算法展开为可学习的网络，学习MRI采样模式则优化k-space采样策略本身。三种方法代表了"从设计到学习"的范式转移，但仍需配对训练数据且无法量化不确定性。

**扩散先验重建**（16.5）：用预训练的扩散模型作为隐式先验，通过条件采样求解CT/MRI逆问题——这正是第13章"条件扩散=逆问题求解"在医学成像中的落地。DiffPIR、DDRM、DPS等方法在CT和MRI上展现出三重优势：无需配对训练数据、可量化不确定性、零样本迁移到新任务。

```
CT物理(16.1) → CT不适定性(16.2) → MRI物理(16.3) → 学习型方法(16.4) → 扩散先验(16.5) → 小结(16.6)
```

本章结束时，读者将理解：CT和MRI重建方法的演化不是偶然的——从FBP到扩散先验，每一步都是前一步局限性的回应，这个演化规律与全书的理论发展完全一致。更深层地，读者将看到：**医学成像是全书核心论点"扩散模型是逆问题自然发展的终点"最直接的验证——从物理模型出发，经过正则化、学习型方法，最终自然走向扩散先验**。

> **过渡**：让我们从CT的物理基础开始——X射线如何穿过人体，我们又如何从测量中重建图像。
