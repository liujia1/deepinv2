# 16.2 CT的不适定性与正则化重建

> **核心观点**：CT逆问题的不适定性有两种截然不同的表现：全角CT是温和不适定的（奇异值$\sim 1/n$衰减），而有限角CT是严重不适定的（奇异值指数衰减）。波前集理论从几何角度解释了有限角为何丢失信息——只有法线方向与测量角度匹配的边缘才可恢复。正则化方法的选择必须匹配不适定性的程度。

## 16.2.1 全角CT的奇异性分析

回顾第1章1.3节，Hadamard适定性要求：(1)解存在，(2)解唯一，(3)解连续依赖数据。CT逆问题违反了条件(3)——即使数据中的微小扰动也可能导致重建的巨大变化。

**Radon变换作为紧算子**：$\mathcal{R}: L^2(\Omega) \to L^2(S^1 \times \mathbb{R})$是一个紧算子。紧算子的SVD分析是不适定性程度的标准工具。

**全角CT的奇异值衰减**：当测量角度覆盖完整的$[0, \pi)$范围时，Radon变换的奇异值按多项式衰减：

$$\sigma_n \sim \frac{1}{n}, \quad n \to \infty$$

这是一个**温和不适定**（mildly ill-posed）问题——奇异值衰减不算太快，正则化方法可以有效地恢复解。

直觉：$\sigma_n \sim 1/n$意味着高频分量的放大因子"仅"线性增长。这与某些严重不适定问题（如逆热方程，奇异值超指数衰减）相比，已经是相对友好的情况。

**全角CT正则化重建**：回顾第3章的正则化方法框架，CT重建的优化问题为：

$$\min_x \|Ax - y\|^2 + \lambda R(x)$$

其中$A$是离散Radon变换矩阵，$R$是正则化项。常见选择：

- **Tikhonov正则化**（$R(x) = \|x\|^2$）：闭式解$x = (A^TA + \lambda I)^{-1}A^Ty$，结果过度平滑
- **TV正则化**（$R(x) = \|Dx\|_1$）：保持边缘，但产生阶梯效应（回顾第2章2.2节）
- **截断SVD**：丢弃小奇异值对应的分量，等价于频域低通滤波

这些方法在全角CT上效果不错——因为不适定性温和，适度的正则化即可恢复高质量的重建。

## 16.2.2 有限角CT：奇异值的指数衰减

**有限角问题定义**：当投影角度仅在$[\theta_{\min}, \theta_{\max}]$范围内可用（而非完整的$[0, \pi)$），即$\theta_{\max} - \theta_{\min} < \pi$，这构成有限角CT问题。

**应用场景**：
- 乳腺断层成像（tomosynthesis）：角度范围仅约$30°$-$60°$，为减少辐射剂量
- 工业焊接检测：物理空间限制导致无法获取全角度投影

**SVD揭示的病态性**：有限角CT的奇异值衰减行为与全角CT截然不同：

$$\boxed{\text{全角CT：}\sigma_n \sim \frac{1}{n} \quad \text{vs.} \quad \text{有限角CT：}\sigma_n \sim e^{-cn}}$$

即使缺失的角度区间很小（例如只缺$5°$），奇异值也呈指数衰减。这是一个**严重不适定**（severely ill-posed）问题。

**频域视角**：由Fourier切片定理（16.1.3节），每个角度$\theta$的投影数据确定了频域沿方向$(\cos\theta, \sin\theta)$的径向切片。有限角度意味着频域信息仅存在于一个"蝴蝶结"（bowtie）形区域内——缺失角度对应的频域区域完全没有数据。

**一个令人惊讶的定理**——"Practically Dubious Theorem"：设$f$是光滑且紧支撑的函数，则$f$被任意小的角度区间内的投影数据唯一确定。

证明思路：由Fourier切片定理，有限角度的投影数据确定了频域在一个扇形区域内的值。由于紧支撑函数的傅里叶变换是解析函数，而在开集上相等的解析函数必然处处相等，因此$f$在整个频域被唯一确定。

这个定理的"Dubious"之处在于：唯一性虽然成立，但恢复过程极度不稳定——需要从扇形区域的频域数据外推到整个频域，这是一个严重不适定的解析延拓问题。指数衰减的奇异值正是这种不稳定性的定量表现。

## 16.2.3 波前集理论：为什么有限角丢失信息

奇异值的指数衰减告诉我们有限角CT是严重不适定的，但没有解释**为什么**会丢失信息以及丢失了**什么**信息。波前集理论从几何角度回答了这两个问题。

### 波前集的定义

函数$u$在点$x_0$的局部行为由其局部傅里叶变换刻画。如果$u$在$x_0$处沿方向$\xi$是"光滑的"，那么局部傅里叶变换在$\xi$方向快速衰减。**波前集**$WF(u)$是$u$的所有"奇异性位置+方向"的集合：

$$WF(u) \subset \mathbb{R}^n \times S^{n-1}$$

直觉：波前集记录了函数的"边缘在哪里"以及"边缘朝哪个方向"。对于图像而言，一个边缘的波前集元素是（边缘位置，边缘法线方向）。

### 有限角CT的可见性

有限角CT的关键结论是：**只有部分波前集可以被稳定恢复**。

具体地，设测量角度范围为$[\theta_{\min}, \theta_{\max}]$，则：

- **可见边缘**：法线方向在$(\cos\theta, \sin\theta)$，$\theta \in [\theta_{\min}, \theta_{\max}]$范围内的边缘可被稳定恢复
- **不可见边缘**：法线方向在测量角度范围之外的边缘**无法**被任何线性方法稳定恢复

**直觉理解**：X射线沿着$\theta$方向穿过物体时，只能"看到"法线与射线方向垂直的边缘——就像用手电筒从侧面照一个物体，只有与光线垂直的轮廓才能产生清晰的阴影。

**各方法的恢复能力**：

| 方法 | 恢复的波前集 |
|------|------------|
| FBP | 仅可见波前集 |
| Tikhonov正则化 | 仅可见波前集 |
| TV正则化 | 仅可见波前集（但可能有更好的边界连接） |
| 剪切波学习 | 可恢复部分不可见波前集 |

关键观察：FBP、Tikhonov、TV——这些方法都**只能恢复可见波前集**。无论正则化参数如何调节，线性方法和基于凸正则化的方法都无法恢复不可见边缘。

### 剪切波学习不可见边缘

剪切波（shearlet）是一种方向敏感的多尺度表示，特别适合表示波前集。Bubba, Kutyniok, Lassas, Maerz, Samek, Siltanen & Srinivasan (2019) 的研究表明：

- 剪切波系数可以分解为对应可见波前集和不可见波前集的两部分
- 通过学习（数据驱动）可以估计不可见波前集对应的剪切波系数
- 将学到的不可见边缘与FBP恢复的可见边缘合并，得到比任何纯重建方法更好的结果

这是**从显式先验到学习型先验**在CT领域的具体体现——与第2章2.4节"从显式先验到隐式先验"的论点完全一致。（波前集的严格定义和有限角CT的微局部性质详见附录16C。）

## 16.2.4 正则化重建：从Tikhonov到TV到剪切波

### 正则化方法谱系

根据不适定性的程度，选择不同的正则化策略：

**Tikhonov正则化**：

$$\min_{x \geq 0} \|Ax - y\|^2 + \alpha\|x\|^2$$

- 优势：闭式解、计算高效
- 劣势：过度平滑，边缘模糊
- 适用：全角CT、高SNR

**TV正则化**：

$$\min_{x \geq 0} \|Ax - y\|^2 + \alpha\|Dx\|_1$$

- 优势：保持边缘
- 劣势：阶梯效应（回顾第2章2.2节）；有限角下仍只能恢复可见波前集
- 适用：全角CT中等噪声、稀疏投影CT

**小波稀疏正则化**（Besov $B_{11}^1$）：

$$\min_{x \geq 0} \|Ax - y\|^2 + \alpha\|Wx\|_1$$

- 优势：多尺度稀疏表示
- 劣势：标准小波缺乏方向敏感性
- 适用：稀疏投影CT

**剪切波稀疏正则化**：

$$\min_{x \geq 0} \|Ax - y\|^2 + \alpha\|Sx\|_1$$

- 优势：方向敏感的最优稀疏表示，特别适合有限角CT
- 劣势：计算代价较高
- 适用：有限角CT

**TGV正则化**（广义全变差）：避免TV的阶梯效应

$$\min_{x \geq 0} \|Ax - y\|^2 + \alpha_1\|Dx\|_1 + \alpha_2\|D^2x\|_1$$

- 优势：同时惩罚一阶和二阶变分，避免阶梯效应同时保持边缘
- 适用：分片光滑图像的CT重建

### 方法选择与不适定程度的对应

| 不适定程度 | 场景 | 推荐方法 |
|-----------|------|---------|
| 良态 | 全角+高SNR | FBP |
| 温和不适定 | 全角+低SNR | Tikhonov/TV |
| 中度不适定 | 稀疏投影 | TV/小波 |
| 严重不适定 | 有限角 | 剪切波/学习型方法 |

### Helsinki Tomography Challenge 2022

Helsinki Tomography Challenge是有限角CT重建的公开竞赛，提供了实践对比不同方法的平台。

**竞赛设计**：
- 使用塑料phantom（含不同形状的孔洞），全角度X射线数据
- 逐步限制角度范围：$90° \to 80° \to \cdots \to 30°$
- 评分指标：Matthews Correlation Coefficient (MCC)，取值$[-1, 1]$，$+1$为完美重建

$$\text{MCC} = \frac{TP \times TN - FP \times FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}$$

**竞赛结果**：
- 9支参赛队伍来自7个国家，共提交22种算法
- 冠军：Technical University of Dortmund（德国）
- 所有数据和算法公开可用

**竞赛启示**：即使在最困难的角度范围（30°）下，最佳算法仍可获得有意义的重建——但需要超越传统正则化的方法（学习型方法、扩散先验等）。

## 本节小结

CT不适定性的核心结构：

$$\text{全角CT: } \sigma_n \sim 1/n \xrightarrow{\text{温和不适定}} \text{正则化有效}$$
$$\text{有限角CT: } \sigma_n \sim e^{-cn} \xrightarrow{\text{严重不适定}} \text{需要学习型/扩散先验}$$

关键洞察：
1. 有限角CT的病态性远比全角CT严重——SVD衰减从多项式变为指数
2. 波前集理论提供了几何解释——不可见边缘无法被任何线性/凸方法恢复
3. 正则化方法的选择必须匹配不适定性的程度——"一刀切"不可行
4. 有限角CT是学习型方法和扩散先验方法的"天然战场"——传统方法的局限性在此最为明显

**PET与发射断层成像**：PET是CT的重要变体（发射而非透射成像），其正模型包含衰减项导致的非线性，重建方法也有所不同。详见附录16D。

CT的正则化重建展示了"先验选择决定重建质量"这一核心原则。现在转向另一种医学成像模态——MRI，它的正向模型与CT完全不同（傅里叶采样而非线积分），但不适定性的挑战同样存在，只是形式不同。
