# 16.6 本章小结：从物理到先验的统一

## CT与MRI的统一逆问题视角

本章用两种最典型的医学成像模态——CT和MRI——展示了全书理论框架的实践落地。两种模态的物理原理完全不同，但从逆问题的视角看，它们共享同一结构：

$$y = Ax + \epsilon \quad \xrightarrow{\text{逆问题}} \quad p(x|y) \propto p(y|x) \cdot p(x)$$

| | CT | MRI |
|---|---|---|
| 物理基础 | X射线衰减（Beer-Lambert） | 核磁共振（Bloch方程） |
| 正向算子$A$ | Radon变换（线积分） | 欠采样傅里叶变换 |
| 测量空间 | sinogram $(\theta, s)$ | k-space $\mathbf{k}$ |
| 不适定性来源 | 有限角度/稀疏投影 | 加速采集（欠采样） |
| 经典方法 | FBP | 逆FFT |
| 正则化 | TV/小波/剪切波 | CS（小波+TV） |
| 加速技术 | — | 并行成像+CS |
| 扩散方法 | DPS/DiffPIR | DDRM/DPS/DiffPIR |

## 先验演化的统一

从FBP到扩散先验，CT/MRI重建方法的演化不是偶然的——每一步都是前一步局限性的自然回应：

```
物理先验（FBP/FFT）
    │ 局限：需要完整数据+低噪声
    ▼
正则化先验（TV/小波/CS）
    │ 局限：表达能力有限（第2章"显式先验天花板"）
    ▼
学习型先验（UNet/展开）
    │ 局限：需要配对数据、无不确定性量化
    ▼
扩散先验（DPS/DDRM/DiffPIR）
    │ 三重优势：无需配对数据、不确定性量化、零样本迁移
    ▼
```

这条演化路径与全书从第1章到第13章的叙事弧完全一致：

```
第1-2章：逆问题→贝叶斯→先验的必要性
第3章：MAP→正则化→显式先验的天花板
第4-6章：后验采样→得分函数→学习先验
第7章：扩散模型→多步得分驱动采样
第13章：条件扩散=逆问题求解→扩散先验重建
```

**医学成像验证了全书核心论点**：扩散模型是逆问题自然发展的终点。从CT/MRI的具体场景看，这个"终点"不是理论上的推演，而是有实际临床价值的解决方案。

## 扩散先验的三重优势

回顾第13章13.6节，扩散模型超越传统方法的三重优势在医学成像中体现得尤为明确：

1. **无需配对训练数据**：使用预训练的无条件扩散模型，条件采样无需针对特定逆问题的配对数据——在医学成像中配对数据获取困难，这一优势尤为宝贵
2. **不确定性量化**：多次后验采样→像素级置信区间——在临床决策中极为重要
3. **零样本迁移**：同一个预训练模型可直接用于不同的CT/MRI任务，无需重新训练

## 展望

本章的扩散先验方法仍有两个未解决的问题：

1. **配对数据用于训练扩散模型**：虽然条件采样无需配对数据，但训练扩散模型本身需要大量图像数据。医学成像中的数据稀缺如何解决？——第17章的自监督学习将提供答案。

2. **计算效率**：扩散采样需要数百步前向传播，重建时间在分钟级——远慢于UNet的毫秒级。如何加速？——第14章的Flow Matching和DDIM等加速采样器是可能的解决方案。

3. **等变性与物理约束**：CT和MRI的算子具有特定的对称性（平移等变性、旋转等变性），如何将这些物理先验融入网络设计？——第17章的等变架构将回答这一问题。

下一章将介绍自监督学习和等变架构——前者解决训练数据稀缺问题，后者将物理对称性融入网络设计，进一步提升重建质量和泛化能力。
