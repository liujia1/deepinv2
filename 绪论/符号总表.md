# 符号总表

一本以"统一思想"为骨架的书，符号不是装饰，而是论证本身的承重结构。本书刻意让同一批记号贯穿全部十八章反复出现——$\mathbf{x}$ 是第 1 章里等待恢复的图像，是第 5 章里被去噪器清理的对象，也是第 13 章里由扩散模型采样的隐变量；$\lambda$ 是第 2 章先验的强度，是第 3 章近端算子的尺度，也是第 13 章引导项的权重。这种复用不是省略，而是一种论证策略：当同一个符号在不同章节承担同一角色时，读者才真正看见"正则化 = 先验 = 得分 = 引导"这条等价链。

因此这份总表有三个用途：**查阅**（遇到记号不知其义时按表定位）、**消歧**（少数一符多义处按第六节的规则判断）、**核对约定**（第一节说明本书的排版与记法选择及其理由）。表中"首见"列给出该记号第一次被**定义或系统使用**的位置，格式为"章.节"；同一记号在不同义项下首见位置不同的，本列给主线的首次定义处，其余义项见第六节。

## 一、排版与记法约定

| 约定 | 写法 | 理由 |
|---|---|---|
| 向量与图像 | 粗体小写 $\mathbf{x},\ \mathbf{y},\ \mathbf{z}$ | Springer 向量粗体惯例；本书全书统一 |
| 标量分量 | 裸斜体带下标 $x_i,\ y_i,\ (\mathbf{x})_i$ | 分量是标量，不粗体 |
| 希腊字母 | **一律裸斜体**：$\varepsilon,\ \theta,\ \sigma,\ \lambda,\ \beta$ | 即使取向量值（如噪声 $\varepsilon$）也不粗体——DDPM/EDM/Score-SDE 原文均如此，粗体希腊字母反而偏离文献惯例 |
| 算子与矩阵 | 大写 $A,\ K,\ D$ | $A$ 为正向算子，是全书第一主角 |
| 积分测度 | $\mathrm{d}x$（裸斜体） | 测度记号不是向量 |
| 高斯分布 | $\mathcal{N}$ | 花体；正文散文里的"高斯"不强制 |
| 期望 | $\mathbb{E}$ | 黑板粗体 |
| 指示函数 | $\mathbf{1}_{C}$ | 粗体，与向量约定一致 |
| KL 散度 | $D_{\text{KL}}(q\|p)$ | 带花括号下标形态（全书主流） |
| 范数 | $\|\cdot\|$，下标写 $\|\cdot\|_2^2$ | ASCII 双竖线；不用 Unicode `‖`（排版管线不可靠） |
| 转置 | $(\cdot)^\top$ | 区别于集合补集与"大于"符号 |
| 累积量 | $\bar\alpha_t$ | 取 `\bar\alpha` 短形式，不写 `\bar{\alpha}` |
| 噪声扰动 | $\varepsilon$ | 用 `\varepsilon` 而非 `\epsilon`，避免与 $\in$ 混淆 |
| 估计与预测 | $\hat{\cdot}$ | **例外**：噪声预测网络写作 $\varepsilon_\theta$，不加 hat（与 DDPM/EDM 原文一致） |
| 行内 / 独立公式 | `$\dots$` / `$$\dots$$` | 全书唯一形态，不用 `\(\)` |
| 代码与伪代码 | 允许 Unicode 速记 | 脚本里的 `ᾱ_t`、`‖` 属实现语言层，不计入正文记法体系 |

## 七、两套记号体系的对照

第 8.4 节与第 3 章部分段落沿用**经典正则化文献**的记号传统（$u$ 作未知量、$f^\delta$ 作带噪数据）。这不是疏漏，而是为了与该文献的原始表述对齐——本书在此给出显式对照，读者可按主线记号自由换算：

$$\min_u\ \mathcal{D}(Au, f^\delta) + \alpha\,\mathcal{R}(u)$$

| 经典正则化记号 | 本书主线记号 | 角色 |
|---|---|---|
| $u$ | $\mathbf{x}$ | 待求量 |
| $f^\delta$ | $\mathbf{y}$ | 带噪观测（上标 $\delta$ 表噪声水平） |
| $\mathcal{D}(Au,f^\delta)$ | $-\ln p(\mathbf{y}\|\mathbf{x})$ | 数据保真项 |
| $\mathcal{R}(u)$ | $R(\mathbf{x})=-\ln p(\mathbf{x})$ | 正则项 = 负对数先验 |
| $\alpha$ | $\lambda$ | 正则参数（= 噪声 / 先验方差比） |
| 原始问题 | MAP 估计 | 点估计 |
| 对偶问题 | 变分下界 | 分布估计 |

> 注意此处 $\mathcal{R}$（花体正则项）与 $\mathcal{R}$（Radon 变换）**同形**：区分靠位置——作正则项时它作用在待求量上（$\mathcal{R}(u)$），作 Radon 时它作用在图像并输出正弦图（$\mathcal{R}u(\theta,t)$）。这是本书唯一需要额外提醒的同形风险。

## 八、刻意保留的例外

好的约定必须有明确的例外清单，否则规则会被误用为机械替换。本书有意保留以下五处：

1. **TDV 的多尺度 CNN 算子 $N(K\mathbf{x})$**（2.4）：此处 $N$ 是神经网络算子，不是高斯分布，**不得**写成 $\mathcal{N}$。判据：$N(\cdot)$ 的自变量是 $\cdot$ 而非概率密度。
2. **分量下标 $x_i,\ y_i,\ z_i$**：标量分量保持裸斜体，这是设计而非漏改。
3. **维度与物理量记号 $d_x,\ d_z,\ m_z,\ G_z$**（第 9、16 章）：这里的下标 `z` 表"维度 / 磁场分量"，是字母标签而非向量，故不粗体。
4. **$\sigma$ 与 $\sigma_{\mathbf{y}}$ 并用**：语义性区分（泛指噪声 vs 特指观测噪声），不是记法分裂。当同一段落出现多种噪声时用 $\sigma_{\mathbf{y}}$，否则一律用 $\sigma$。
5. **代码块与行内反引号内的速记**：`ᾱ_t`、`‖`、`x_t = √ᾱ_t x_0 + ...` 属实现层记法，随代码可读性优先，不受正文 LaTeX 约定约束。
