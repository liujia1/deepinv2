## 0.1 先讲个真事：你看到的黑洞照片，其实是"算"出来的

2019 年，人类历史上第一张黑洞照片（M87*）广受关注。但有一个反直觉的事实你可能从未意识到——**那张照片并不是"拍"出来的**。

黑洞距离我们约 5500 万光年，望远镜的分辨率再高，直接记录到的也只是一圈残缺、模糊的光斑。真正的工作是：全世界的射电望远镜把极稀疏的干涉信号（一种"残缺的测量"）汇总起来，再用强大的算法去**反推**黑洞本来的样子。换句话说，那张照片是计算机从一堆不完整的数字里"算"出来的。从更深层次看，它是在回答一个普遍性的问题：

> 给定我手头这些残缺的观测 $\mathbf{y}$，宇宙里最可能长成什么样的图 $\mathbf{x}$？

而这种"从结果反推原因"的困境，你每天都会遇到。医生手里一张带噪、模糊的低剂量 CT（计算机断层扫描），想知道肿瘤到底在哪、多大——这是同一类问题。手机里一张因手抖而模糊的夜景照片，想让它恢复清晰——还是同一类问题。

**因为这些场景都在做同一件事**：已知"退化（模糊、加噪声、采样不足）后的结果 $\mathbf{y}$"，要还原"原本干净的成因 $\mathbf{x}$"。书里把这类困境叫做**图像逆问题（inverse problem，从结果倒推原因的一类难题）**。

那另一边呢？你用 AI 输入"一只在火星上漫步的猫"，它给你画了一幅**从未存在过**的画。这叫**图像生成（image generation，从"图像长什么样"的分布里抽出一张新图）**：从图像的分布中采样出一张新图。

一个在"恢复已经存在的图"，一个在"创造不存在的图"——表面上看，这两件事几乎毫无关联，对吧？但本书的核心主张，恰恰是要把这两件事**统一为一件事**。先不必急着追问为什么，请记住这个反直觉的引子：

> **看似毫不相干的两件事，在数学家的眼里共享同一个根源。**

下面我们就把这个"根"揭示出来。

---

## 0.2 核心主张：为什么"复原"和"创造"是同一件事

让我们把上一节的引子落到实处。

先想"复原"。一张模糊的 CT 图 $\mathbf{y}$，背后对应某张真实清晰图 $\mathbf{x}$。我们关心的不是某个凭主观猜测给出的单一答案，而是——**在所有可能的 $\mathbf{x}$ 里，哪些更可能、哪些更不可能？** 也就是说，我们想要的不是一个数、一张图，而是一个"可能性的分布"。

再想"创造"。AI 画图，本质是从"图像长什么样"这个分布里抽出一张来。而当你说"给我一只火星猫"时，你其实加了一个条件——于是 AI 要从"满足'火星猫'这个条件的图像分布"里抽样本。

**发现了吗？两边最终指向的都是"条件分布"。** 需要澄清的是：逆问题与生成问题所求的分布并不完全相同——逆问题要的是**后验分布** $p(\mathbf{x}|\mathbf{y})$（给定观测之后，原图的条件分布）；无条件生成要的是**数据分布** $p(\mathbf{x})$ 本身，条件生成则近似 $p(\mathbf{x}|\mathbf{c})$（给定文本等条件 $\mathbf{c}$ 的图像分布）。但它们在数学上同根同源：数据分布正是后验在"无观测"时的特例，而求解逆问题最好的办法，恰恰是去采样整个后验。两者的区别只在于使用方式：

- 逆问题想要这个分布的"典型代表"（比如最可能的那张，或平均那张）；
- 生成问题想要从这个分布里"多抽几张"，看看各种可能性。

**既然两边要的是同一族数学对象，那么把"观测信息"和"图像该长什么样"合到一起、给出这个分布的，正是贝叶斯定理。** 贝叶斯定理（Bayes' theorem）是一种把"新证据"与"已有信念"合成为概率的规则。为什么我们需要这样一个规则？因为光靠观测 $\mathbf{y}$ 不足以唯一确定原图（你后面会亲眼看到），光靠"图像该长什么样"的信念又无视了证据；我们需要一条规则，把两者公平地合成为"看到证据之后、原图的可能性分布"。这条规则写成：

$$p(\mathbf{x}|\mathbf{y}) \propto p(\mathbf{y}|\mathbf{x})\,p(\mathbf{x})$$

读这个公式不必紧张，它只是给直觉"标点"。逐项解释其现实含义如下：

- 左边 $p(\mathbf{x}|\mathbf{y})$ 是**后验（posterior，在看到观测 $\mathbf{y}$ 之后，原图 $\mathbf{x}$ 的可能性分布）**——这是我们真正想要的"完整答案"；
- 右边第一项 $p(\mathbf{y}|\mathbf{x})$ 是**似然（likelihood，如果原图真是 $\mathbf{x}$，观测到 $\mathbf{y}$ 的概率。它负责"保真"，让答案贴合数据）**；
- 右边第二项 $p(\mathbf{x})$ 是**先验（prior，我们对"图像一般长什么样"的预先信念。它负责"合理"，剔除明显荒谬的还原）**；
- 中间那个"正比于" $\propto$ 藏着第四位角色——**证据（evidence，也叫归一化常数，让整个分布积分为 1 的那个数）**，后面你会看到它正是计算上的主要障碍。

> **读心小结**：逆问题要的是后验的"均值/众数"（最可能的图）；生成要的是从后验"采样"（画出各种可能的图）。一旦你会从后验采样，复原和创造就同时到手了——反之亦然。

从更深层次看，这一转变意味着：求解逆问题不再是"猜一个正确答案"，而是"形成并更新一个信念"。贝叶斯推断因此不只是一种统计工具，而是一种从不确定数据中形成合理信念的机制。于是本章大思想的前半句可以先收束一下：

> **不确定性是固有的。我们不追求唯一答案，而是诚实地描述"哪些答案更可能"。**

## 0.3 先猜一个数字：为什么"先验"比你想的重要得多

讲一个经典的反直觉案例，请你先**猜一个数字**，再往下看。

假设某种疾病在人群中的患病率是 **1%**（基础率）。现在有一种检测试剂，对病人 **95%** 能检出阳性（灵敏度），对健康人 **90%** 不会误报（特异度）。如果某人检测结果呈阳性，你觉得他**真正患病的概率**是多少？

先别算，凭直觉猜一个：50%？80%？还是更高？——**把你的数字记在心里。**

现在揭晓。用贝叶斯定理粗略一算：10000 人里真正患病的大约 100 人，几乎全被检出（约 95 个真阳性）；其余 9900 个健康人里，有 10% 会被误报，约 990 个假阳性。所以阳性总数约 1085 人，其中真病人只有约 95 人：

$$\text{后验} = \frac{95}{95 + 990} \approx 8.76\%$$

**结果出人意料：阳性之后真正患病的概率只有约 8.76%，而不是直觉里的百分之九十多。** 这就是贝叶斯最反直觉、也最该记住的一课：**基础率（先验）不够高时，再"灵敏"的检测也难以扭转后验**——证据要乘以先验，先验太小，结果就被拉了下去。

> 这个例子刻意放在这里，是为了给你种下一颗种子：后面书里反复出现的"先验 $p(\mathbf{x})$"，绝不是装饰品。先验也不是人为的偏见，而是系统已有经验与结构化知识的表达——在逆问题里，它就是那个把"无穷多可能的清晰图"筛成"合理少数"的守门人。

> **与第1章的对应**：这里只给了结论和直觉；一步步的完整推导（含算表）在第 1 章 1.5 节，两处数字完全一致。

正是因为先验如此关键，才有了下一节要讲的"信念如何随证据更新"。

## 0.4 信念如何随证据更新：先验随数据量增加而淡出

贝叶斯最动人之处，不是公式，而是它讲了一个**信念成长的故事**。

想象你在抛一枚硬币，想知道它是否公平。一开始你**毫无头绪**——它可能是偏的、也可能是正的，你先假定"正面概率在 0 到 1 之间均匀都有可能"，这就是**先验（prior，你动手之前对真相的预先信念）**。

- 抛了 **0 次**：你的后验就是那个平坦的先验，几乎一无所知；
- 抛了 **2 次**，1 正 1 反：后验开始隆起一个小峰，但仍很宽——你还不确定；
- 抛了 **10 次**，7 正 3 反：后验明显偏向"偏正面"，峰更尖了；
- 抛了 **50 次**，35 正 15 反：后验的尖峰牢牢钉在 0.7 附近；
- 抛了 **500 次**，350 正 150 反：后验变成一根极窄的针，几乎锁定在 0.7。

**随着数据越来越多，你最初那个"均匀、什么都觉得可能"的先验，被证据一点点"淡化"了**——后验不再主要听从先验，而是听从数据；同时，随着证据增加，后验从又宽又平变得越来越窄、越来越确定。这就是"**先验随数据淡出、后验移动并收拢**"。

这一现象值得多说一句。后验收拢的快慢，本身就是信息的度量：数据少时后验宽，坦率地承认"我不知道"；数据多时后验窄，才敢给出确定判断。**知道自己不知道什么，恰是智能的体现**——后验分布的宽度不是缺陷，而是这个框架最可贵的品质。

> 四个角色再小结一遍（你随时可回看）：
> - **先验**：动手前的老信念；
> - **似然**："如果真相是某值，看到这批数据有多合理"；
> - **后验**：看完数据后的新信念（我们最终要的）；
> - **证据**：让后验积分为 1 的归一化常数（下一节它就成了计算上的主要障碍）。

这个"信念更新"的叙事，是全书的灵魂：无论逆问题还是生成，本质上都是"用观测数据更新我们对图像的信念"。学习在这里不是简单改变参数，而是根据经验重新组织信念。把这段直觉记住，后面 18 章都是它的展开。

## 0.5 两条路，殊途同归于扩散模型

好，钥匙公式有了，信念更新的故事也讲完了。但残酷的现实是：**在高维图像空间里，后验 $p(\mathbf{x}|\mathbf{y})$ 根本算不出来**。

**为什么算不出？** 因为上节提到的"证据"那个归一化常数，需要计算一个高维积分 $Z = \int p(\mathbf{y}|\mathbf{x})p(\mathbf{x})\,\mathrm{d}\mathbf{x}$。而一张图像有上百万个像素，这个积分的复杂度随维度指数增长——直接计算，在可预见的时间内无法完成。于是，一个最自然的问题冒出来了：

> **后验算不出，怎么办？**

历史上，两条性格迥异的策略各自长成了一条完整的理论路线。它们起点不同、路径不同，但终点竟然是同一座城——**扩散模型（diffusion model，一类通过"逐步加噪再逐步去噪"来生成图像的模型）**。

### 路线一：采样路径——直接去"遍历"后验（when / why / how）

- **什么时候用**：你想直接从那个算不出的后验里"抽出样本"来用（比如做生成、做复原的随机采样）。
- **为什么难**：写不出后验的解析式，更别提直接抽样。
- **怎么做**：既然写不出，就用"随机游走"去探索它。蒙特卡洛（Monte Carlo，用大量随机样本估计分布的统计方法）的思想极为朴素：造一条马尔可夫链（一种"下一步只取决于当前位置"的随机过程），让它的平稳分布恰好等于目标后验，跑得够久，就能从后验里采到样本。

这条路的演化逻辑长这样（逐步演进，每一步都在解决上一步的瓶颈）：

$$\text{MCMC} \;\rightarrow\; \text{ULA} \;\rightarrow\; \text{Langevin 动力学} \;\rightarrow\; \text{得分匹配} \;\rightarrow\; \text{扩散模型（SDE 视角）}$$

- 从通用的 MCMC（马尔可夫链蒙特卡洛）出发，但它在高维空间里混合极慢、效率低下；
- 于是 ULA（利用梯度信息加速采样的算法）借用"往概率高处走"的指引提速；
- Langevin 动力学把它连续化，关键角色登场：**得分函数（score function，即对数概率的梯度 $\nabla_\mathbf{x}\log p(\mathbf{x})$，它指向"概率升高最快的方向"）**；
- 对数求梯度会消去归一化常数，得分函数因此绕开了 $Z$ 这一障碍；但对自然图像而言，先验 $p(\mathbf{x})$ 本身没有解析形式，得分仍无从直接计算，于是**得分匹配**想出办法：用一个去噪器来间接学习它；
- 最后，把"单步去噪"推广成"多步逐步去噪"的扩散过程——扩散模型的 SDE（随机微分方程）视角就此诞生：**从纯噪声一路去噪，走到清晰图像**。

### 路线二：变分路径——用一个简单分布"近似"后验（when / why / how）

- **什么时候用**：你不想（也很难）精确采样后验，只想要一个"够用、好算"的近似分布。
- **为什么难**：精确后验求不出来，且没法直接比较"近似"与"真相"相差多远（因为真相里含有算不出的常数）。
- **怎么做**：既然精确后验求不出，那就用一个简单的分布族 $q_\phi(\mathbf{x})$ 去**近似**它，并让这个近似尽量贴近真相。怎么衡量"贴近"又绕开难算的积分？最大化**证据下界 ELBO（Evidence Lower Bound，一种既可优化又绕开难算积分的目标函数）**。

这条路同样演进有序：

$$\text{ELBO} \;\rightarrow\; \text{VAE} \;\rightarrow\; \text{层级 VAE} \;\rightarrow\; \text{扩散模型（变分视角）}$$

- 从 Jensen 不等式推出 ELBO；
- 用编码器-解码器（神经网络里把数据压缩为低维表示再还原的部件）把变分推断神经网络化，就是 **VAE（变分自编码器）**；
- 把单层潜变量推广成多层，得到**层级 VAE**；
- 当层数趋向无穷、编码器退化为一个固定的"高斯加噪"过程时——一个深刻的结果浮现出来：层级 VAE 的下界，恰好等于扩散模型的训练目标。**扩散模型，就是无穷层级的层级 VAE。**

从更深层次看，这并非命名上的巧合。正向加噪过程可以理解为**信念的逐步稀释**——每加一步噪声，数据中的信息就被冲淡一分；逆向去噪过程则是**信念的逐步重建**——每去一步噪声，模型就把"图像应该长什么样"的先验知识重新注入一分。扩散模型不是凭空出现的黑魔法，而是 VAE 在"层级结构 + 高斯转移 + 无穷层"假设下的自然极限。

> **点 vs 分布的小对比**：传统机器学习（比如最大似然估计）通常只给你一个"最佳单点"参数；而贝叶斯/变分这条路，给你的是一整个"带有宽度的后验分布" $p(\mathbf{x}|\mathbf{y})$。前者快但容易盲目自信，后者慢一点，却诚实地说"我不确定"。

### 两条路的交汇：全书的理论高潮

尤其值得强调的是：这两条从不同哲学出发、经过不同数学工具的路，最后停在了同一个站点——扩散模型。而且在数学上可以严格证明：

$$\boxed{\text{得分匹配损失} \equiv \text{变分下界（VLB）}}$$

采样路径学的"得分函数"，和变分路径优化的"下界"，**训练的是同一个目标的不同写法**。这不是巧合，而是贝叶斯框架内在统一性的必然结果。这一等价性，是全书的华彩段落，也是"统一性"主张最有力的证据。

## 0.6 全书是一场旅程：18 章，六个驿站

现在给你一张"地图"。但别把它当清单死记——请把它想成一段有方向的徒步：

**第一站 · 贝叶斯基石（第 1–3 章）。** 出发前先打地基。第 1 章正式定义"什么是逆问题"，并用贝叶斯框架把后验 $p(\mathbf{x}|\mathbf{y})$ 立起来——记住，它才是逆问题的"完整解"，不仅给答案，还附带全部不确定性。第 2 章讲**先验**：它就是把"正则化"（一种防止过拟合、保持结果合理的约束）翻译成概率语言；先验好不好，直接决定重建质量。第 3 章讲从 MAP（最大后验，取后验众数作为点估计）到"想要更多信息"的分叉——MAP 只给一个点，而我们想看整个分布。

## 0.7 五座桥：让"看似无关"连成"本就一体"

旅程里散落着五座理论桥，它们把不同章节连成一个整体。读的时候不必背，遇到时回看即可：

1. **PnP 去噪器 → 得分函数（Tweedie 等式）。** 第 2 章的贝叶斯去噪器，到第 5 章被证明等于得分函数，第 6 章用得分匹配训练它——"去噪即学先验梯度"贯穿整条采样路。
2. **ULA → 扩散模型。** 第 4 章的单步 Langevin，是第 7 章多步扩散的连续时间推广。扩散不是凭空冒出，而是 Langevin 的自然延伸。
3. **"离散→连续→再离散"螺旋。** ULA（离散）→ Langevin SDE（连续）→ Euler 离散 → DDPM。每转一圈，都在更高处重新理解采样。
4. **VAE 编码/解码 → 扩散加噪/去噪。** 当 VAE 层数趋于无穷、编码器固定为加噪，编码器变成前向过程、解码器变成逆向去噪——扩散 = 无穷层 VAE。
5. **条件生成 = 逆问题求解。** 全书终极之桥：能采样 $p(\mathbf{x}|\mathbf{y})$，既解决条件生成（给文本出图），也解决逆问题（给退化观测做复原）。第 13 章以此闭环。

## 0.9 动手感受一下（一）：同一份模糊图，藏着无数种清晰原图

下面这段 Python（只用 numpy + matplotlib，无私有依赖）想让你**亲手体会逆问题的"不适定（ill-posed，即解不唯一、不稳定）"**：给你一份模糊观测 $\mathbf{y}$，其实存在无穷多张清晰图 $\mathbf{x}$ 都能产生它。这说明——没有额外的"信念"（先验），答案根本不唯一。这，正是全书要用量化不确定性来对付的东西。

```python
# -*- coding: utf-8 -*-
# 可选运行：直观感受"逆问题不适定" —— 同一份模糊观测 y，对应无穷多种清晰原图 x。
# 需要：pip install numpy matplotlib
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(0)

# 1) 造一张"清晰原图" x0：黑白条纹（0/1 的二维数组）
N = 64
x0 = (np.arange(N) // 8) % 2 == 0
x0 = x0.astype(float)

# 2) 正向模型：模糊 = 对每一行做简单平均平滑（这里是线性算子 A 的简化版）
#    观测 y = A x0 + 噪声 eps
blur = np.ones((1, 5)) / 5.0
def apply_A(x):
    # 用一维卷积近似"水平方向模糊"
    from numpy.lib.stride_tricks import sliding_window_view
    win = sliding_window_view(x, 5, axis=1)   # 形状 (N, N-4, 5)
    return (win * blur).sum(axis=2)

y = apply_A(x0)
noise = 0.02 * rng.standard_normal(y.shape)
y_noisy = np.clip(y + noise, 0, 1)

# 3) 关键直觉：A x = y 这个"方程"对 x 有无穷多解。
#    我们构造两个不同的"清晰图"候选，它们经过同一个模糊算子后，都得到几乎相同的 y。
#    候选 A：原始条纹
x_candidate_a = x0.copy()

#    候选 B：在"模糊后相互抵消"的位置上注入高频噪声（A 作用后这部分噪声被抹平）
#    也就是说，加进去的扰动位于算子 A 的"零空间"——模糊后看不见。
high_freq = rng.choice([-1, 1], size=x0.shape).astype(float)
# 只在每个 8 像素窗口内部加，保证 5 邻域平均后接近 0
block = np.zeros_like(x0)
for i in range(0, N, 8):
    block[:, i:i+8] = high_freq[:, i:i+8] * 0.0  # 占位，下面用更稳妥的方式
# 更稳妥：直接构造一个"逐块常量的扰动"，模糊后被严重衰减
perturb = np.zeros_like(x0)
for i in range(0, N-4, 8):
    v = rng.uniform(-0.5, 0.5)
    perturb[:, i:i+8] = v
x_candidate_b = np.clip(x0 + perturb, 0, 1)

# 4) 验证：两个不同原图，模糊后都≈同一份观测 y
yb = apply_A(x_candidate_b)
print("原图A与观测的均方误差:", np.mean((apply_A(x_candidate_a) - y_noisy)**2))
print("原图B与观测的均方误差:", np.mean((yb - y_noisy)**2))
print("但 A 和 B 本身的差异（说明它们不是同一张图）:", np.mean((x_candidate_a - x_candidate_b)**2))

# 5) 画图：你看到的"证据"一样，但"真相"可以很不一样
fig, axes = plt.subplots(1, 3, figsize=(12, 4))
axes[0].imshow(x_candidate_a, cmap='gray'); axes[0].set_title("候选清晰图 A（条纹）")
axes[1].imshow(x_candidate_b, cmap='gray'); axes[1].set_title("候选清晰图 B（带扰动）")
axes[2].imshow(y_noisy, cmap='gray'); axes[2].set_title("同一份模糊观测 y")
plt.tight_layout(); plt.show()

# 结论：仅凭观测 y，你无法唯一确定 x。必须引入"先验信念"（书里 p(x)）来缩小可能性。
```

跑完你会看到：两张明显不同的"清晰图"，经过模糊后都变成了**几乎同一张**模糊观测。这正是逆问题的核心困难——**没有先验，答案不唯一、也不稳定**。这也回答了"为什么我们需要贝叶斯"：先验 $p(\mathbf{x})$ 就是用来从这片"无穷可能"里挑出更合理那些的。这一转变同时意味着：先验不是可选项，而是任何逆问题求解中不可回避的一部分——区别只在于它是显式写出的，还是从数据里学出来的。
