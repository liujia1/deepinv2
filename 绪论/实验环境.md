# 实验环境与代码运行指南

本书十八章共配有 **143 个实验目录、253 个 Python 脚本**，全部随书分发。这份指南只回答三个问题：需要装什么、脚本怎么跑、哪些实验对硬件有要求。它不替代各章实验块里的输入表与运行说明，而是把散落在各章的运行前提集中到一处，供动手之前一次性核对。

## 一、统一环境

全书实验在同一套工具链上完成。第 18 章开头的"实验环境与工具准备"给出的是完整清单，这里复述并补上版本口径：

| 工具 | 版本口径 | 用途 | 安装 |
|---|---|---|---|
| Python | ≥3.9 | 解释器 | — |
| PyTorch | ≥2.0 | 网络训练、GPU 加速 | `pip install torch torchvision` |
| NumPy / SciPy | 不限定 | 数值计算 | `pip install numpy scipy` |
| Matplotlib | 不限定 | 全部插图 | `pip install matplotlib` |

本书有意**不锁定第三方库的小版本号**。一方面，各实验只依赖稳定的公开 API；另一方面，deepinv 等库的参数名在不同版本间确有变动（第 18.0 节点明了扩散求解器的 `model`/`denoiser` 之争），把版本钉死在某一小版本，反而让读者在升级环境后遭遇更多不一致。遇到 API 差异时，以你安装版本的文档为准——管线五步的逻辑不受影响。


## 三、脚本怎么跑

**随书代码仓库**：<https://gitee.com/mylaujia/txsc>。本书的实验代码在此仓库；克隆到本地后，按下文的目录约定进入对应实验目录运行。

目录约定：第 N 章的代码在 `第N章 …/第N章 配套实验/实验X.Y-Z/` 下（第 6 章目录名为"配套实现"，是全书唯一的命名例外）。脚本名与正文实验块的编号一致，例如 1.2 节的第一个实验对应 `实验1.2-1/1.2-1.py`。

**先 cd 到实验目录再执行**：

```bash
cd "第1章 逆问题与贝叶斯推断/第一章 配套实验/实验1.2-1"
python 1.2-1.py
```

这不是风格偏好，而是脚本的路径约定：脚本以相对路径 `sys.path.insert(0, '.chinese')` 导入中文字体模块，并以脚本所在目录作为图片与结果的落盘位置（151 个脚本显式使用 `os.path.dirname(os.path.abspath(__file__))`）。从别处启动会同时踩中"找不到 chinese_font"与"产物写错目录"两个问题。

其余约定：

- **没有命令行参数**。全书没有一个脚本使用 argparse，超参集中在文件头部的常量区，改参数就改那里。
- **产物就地保存**。146 个脚本调用 `savefig`，143 个实验目录全部带有作者运行时的 PNG，其中 126 个还附 `results_summary.json`（另有几个目录附其他命名的 JSON）——正文引用的数值即来自这些文件。
- **Colab 兼容**。147 个脚本会检测 `/content/drive/MyDrive`：存在则读写 Drive 中的同名实验目录，否则退回脚本所在目录。同一份代码在本地与 Colab 下都能直接运行。
- **中文字体**。`.chinese/chinese_font.py` 负责字体设置：Windows 下自动选用系统中文字体（SimHei、微软雅黑等）；Linux/Colab 下若系统没有中文字体，首次运行会下载 NotoSansSC（需联网），下载失败时中文显示为方框，但不影响数值结果。
- **样例数据**。`skimage.data` 的内置样例图（astronaut、shepp_logan_phantom 等）首次调用会联网下载并缓存；离线环境请提前准备。

## 四、硬件需求分档

绝大多数实验在普通笔记本 CPU 上即可完成。GPU 只在三类地方出现：

| 档位 | 涉及实验 | 依据 |
|---|---|---|
| CPU 即可 | 第 8 章全部；其余各章的绝大多数 | 脚本以 `torch.cuda.is_available()` 自动选择设备 |
| GPU 建议 | 4.7（GPU 约 8 分钟；CPU 跑完整 PnP-ULA 约 2–2.5 小时）、18.4、18.5 | 各实验块给出了实测耗时 |
| GPU 必需 | 13.3-2、13.4-1、13.4-4、13.6-4、13.6-5 | 13.3-2 写明"CPU 环境下无法运行"；13.4-4 的 ControlNet 权重约 1.4 GB；13.6-4/13.6-5 的 SD 1.5 fp16 需 4–6 GB 显存 |

三处值得单独说明的降级路径：

- **CT 重建（16.1 / 16.2）**：ASTRA 版本（16.1-2、16.2-2）以 `astra.use_cuda()` 判断可用性，检测不到 CUDA 时自动回退到 scikit-image 平行束版本；16.1-1 与 16.2-1 本身就是纯 scikit-image 实现，不需要 GPU。
- **4.7 的 PnP-ULA**：没有 GPU 时默认走 MYULA；若要在 CPU 上强制跑完整 PnP-ULA，设置环境变量 `FORCE_PNP_CPU=1`（实测约 2–2.5 小时）。
- **13.5-1**：运行前提是 CPU 可运行、约 10 分钟。

13.6-3 没有写运行说明，但它同样加载 SD img2img 管线，实际也落在"GPU 必需"一档。

## 五、外部权重与预训练模型

代码依赖的外部资源分两类，性质完全不同：

| 资源 | 用于 | 获取方式 |
|---|---|---|
| `RealSN_DnCNN_noise{5,15,40}.pth` | 4.7、5.3、5.4-2、5.5-1、6.7-2 | 真实噪声 DnCNN 去噪器。`Pretrained_models/` 目录不随代码分发，需按脚本打印的地址自行下载（uclaopt/Provable_Plug_and_Play 仓库）；4.7 在权重缺失时自动回退到 MYULA |
| Stable Diffusion v1-4 / v1-5 与 ControlNet | 13.4-1、13.4-4、13.6-3 至 13.6-5 | diffusers 首次运行自动下载；仓库不可用时按 13.6 正文给出的镜像替换 |
| `ncsnpp.pth`、`drunet_color.pth` | 13.3-2 | 由 deepinv 的 `pretrained="download"` 自动下载（该脚本还会自动安装 deepinv） |
| 其余 `*_checkpoint.pth` / `*_final.pth` | 各章训练类实验 | **由脚本训练后自行产生**，属断点续训缓存，无需外部提供；删掉只会导致重新训练 |

## 六、可复现性：种子与结果对照

253 个脚本中有 133 个固定了随机种子，绝大多数取 42，另有 123、0 等少量取值。固定种子的实验，图与正文数值可以逐次复现；未固定种子的少数实验，重复运行时数值会有轻微波动，属正常现象。

核对数据时建议的顺序是：先看目录中的 `results_summary.json`（若有）与随书 PNG，再对照正文表格。若差异超出"轻微波动"的量级，优先检查 PyTorch 版本与是否使用 GPU——浮点累加顺序不同会带来末位差异。

## 七、常见问题

| 症状 | 处理 |
|---|---|
| 图中中文变方框 | 见第三节字体说明；Linux 下确认首次运行能联网 |
| `ModuleNotFoundError: chinese_font` | 没有在实验目录内启动脚本，见第三节的 cd 约定 |
| ASTRA 报错（扇形束 / `FBP_CUDA`） | 确认 ASTRA 的 CUDA 可用性；16.1-2 与 16.2-2 检测到 CUDA 不可用会自动回退 scikit-image 版本，也可直接跑 16.1-1 或 16.2-1 |
| HuggingFace 下载失败 | 按 13.6 正文给出的镜像仓库替换模型名 |
| deepinv 参数名不匹配 | 以安装版本文档为准，见 18.0 的说明 |
