## 一、已确认的问题清单

### 实验 5.1-1（ULA / 步长 / 稳定边界）
1. **结果不同步**：正文写 `0.901, 1.047, 1.334, 1.998`；当前 JSON 为 `0.989517 / 1.047797 / 1.337888 / 1.99398`。0.901 是旧版单链值（脚本注释已说明）。
2. **理论表述错误**：正文第 173 行“δ ≤ 1/L 是保证 ULA 不发散的必要条件”与事实不符。脚本步骤 3 实测：δ<2 二阶矩有界（δ=1.9 → 20），δ=2 线性增长，δ>2 几何发散。应改为“充分条件/标准理论假设，实际稳定边界由具体势能决定”。
3. **实验产物未被引用**：步骤 3（`步骤3_稳定边界验证.png`）与 JSON 字段存在，正文只写步骤 1/2。
4. 公式无误：`σ²=1/(1-δ/2)`、`v_m=2δ[(1-δ)^{2m}-1]/[(1-δ)²-1]`、δ=2 时 `4m`。

### 实验 5.2-1（得分向量场 / 模式混合）
5. **公式一般性缺陷**：正文第 131–132 行 `w_i(x)=exp(-½(x-μ_i)^TΣ_i^{-1}(x-μ_i))` 缺归一化因子 `1/(2π√det Σ_i)`；本实验两分量 `det Σ=0.91` 相同，数值不受影响，但公式在一般情形不成立。
6. **措辞不精确（非 bug）**：正文“单链占用率由 0.25/0.71 量级收敛”，JSON 为 seed1 `0.302@5k→0.246@10k`、seed2 `0.709@5k`、seed3 `0.472@5k`，三链均值 `0.4947→0.5071`（200k）。
7. 鞍点、Hessian 特征值、势垒数值均正确。

### 实验 5.3-1（Tweedie 等式）
8. **无设计缺陷**：1D 解析误差 `3.1e-11`；图像部分“残差=ε×得分”按构造恒等（正文已承认）；GMM 合成先验独立检验有效。
9. **口径需注明（非 bug）**：正文写“R=8 次平均后余弦 0.90/0.91/0.87”，未说明是“逐实现余弦再平均”。σ=40/255 的平均 cos（0.8735）低于单次实现（0.9577）正是个别低 cos 实现拉低均值，不应被读成“平均后反而更差”。

### 实验 5.4-1（Moreau 包络）
10. **结果不同步**：正文第 97 行平均绝对误差 `8.0×10⁻⁵`；JSON 为 `9.455e-05`（最大 `1.431e-03`、相对 `7.6e-05`）。
11. `DivergenceIm` 严格负伴随修复在所有副本一致；Moreau 包络公式与 Chambolle 的 λ 约定一致。

### 实验 5.4-2（TV-ULA vs PnP-ULA / 温度扫描）
12. **温度概念混用**：本实验 T 是“后验温度 / 噪声幅度 √(2Tδ)”；5.4 正文 T 是“softmin→min 的 Gibbs 软化温度”。正文“数值验证了从众数到均值的连续过渡”须限定为**后验温度**。
13. **字段名误导**：T=0 的“平均标准差 0.001373/0.001617”是确定性链末段漂移 std（应≈0），不是后验标准差。脚注已写“末段漂移std”，但 JSON 键仍是“平均标准差”。
14. **比较条件不对等**：TV burn-in 4800/12000（40%），PnP 1000/10000（10%）；两链后 1/4 段仍提升 0.159/0.156 dB，均未完全到平台。
15. 步长、σ、L_y 与 JSON 一致。

### 实验 5.5-1（PnP-ULA）

17. **口径差异非 bug**：Welford 累积 9500 个状态（burnin 处初始化 1 个 + 9499 次 update），`trace_fid` 长度 9499，二者都正确。

### 实验 5.6-3（MAP vs MMSE / 参数扫描）
