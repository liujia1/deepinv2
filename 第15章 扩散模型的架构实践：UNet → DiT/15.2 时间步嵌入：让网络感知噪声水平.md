# 15.2 时间步嵌入：让网络“看见”噪声有多重

> “同一个去噪网络，面对一张‘轻微雪花’的图和一张‘满屏噪点’的图，该用完全不同的手法。可网络怎么知道现在噪到什么程度了？这一节讲的就是这个‘告诉网络时间’的机制——就像给工人发一块表，让他知道现在是凌晨还是正午，好调整干活节奏。”

**本章目标**（读完后你应该能）：
- 说清为什么扩散去噪器“必须”知道时间步 $t$，而不是一个固定噪声水平的普通去噪器；
- 解释正弦位置编码怎么把“一个数字 $t$”变成网络能区分的“时间步指纹”；
- 对比三种条件注入方式（加法 / FiLM / adaLN-Zero），并说清 adaLN-Zero 为什么最重要；
- 跑通一段代码，亲眼看正弦编码“低维慢变、高维快变”的多尺度指纹长什么样。

## 15.2.1 为什么需要时间步条件？

**从痛点出发**：普通去噪器对付的是固定噪声水平——一个网络对应一个 $\sigma$。但扩散模型里，噪声水平是随时间步 $t$ 连续变浓变淡的（回顾第10章10.2节的 DDPM 参数化 $x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$）。同一个网络 $D_\theta(x_t,t)$ 必须“看 $t$ 下菜碟”：

- **$t$ 接近 0（信噪比低、高噪声）**：要“大刀阔斧”去噪，动作像低通滤波（白话：把高频抖动抹掉）；
- **$t$ 接近 $T$（信噪比高、低噪声）**：要“精雕细琢”保留细节，动作像细节增强；
- **中间 $t$**：在两者间平滑过渡。

时间步条件其实贯穿了全书，只是从没说过“网络层里怎么实现”：第6章6.6节 DRUNet 的“条件噪声水平”、第7章“不同 $t$ 的得分函数 $\nabla\log p_t(x_t)$ 不同”、第11章11.3节三种参数化 $\epsilon_\theta/s_\theta/\hat x_\theta$ 全都是 $(x_t,t)$ 的函数。

先做一个“点 vs 分布”的对比来帮助理解：如果只用一个**固定**去噪器（一个“点”策略），就相当于给所有噪声水平配同一副眼镜——看轻噪还行，看重噪就全糊；扩散模型要的是“随时间步连续变化的一整族去噪器”，也就是把条件行为当成**分布**来学。所以问题变成了：**怎么让一个网络同时扮演这一整族角色？**

**when / why / how 来看这件事**：
- **when 用**：扩散去噪器要遍历数百个时间步做逆向采样，每个步的噪声水平都不同；
- **why 难**：你没法为每一个 $t$ 单独训一个去噪器——那是 $N$ 个网络，代价高、不灵活（这就是“无条件策略”的死穴）；
- **how 解**：训**一个**条件去噪器 $D_\theta(x_t,t)$，让它自己学会按 $t$ 调整行为。实践中这是唯一可行的方案。

## 15.2.2 正弦位置编码：把“一个数字 $t$”变成“一幅指纹”

**核心问题**：时间步 $t$ 本来只是个标量（一个数）。直接当网络输入，表达力太弱——网络很难区分“相邻两个时间步”的细微差别。得把它映射成一个高维向量（embedding，白话：把离散/标量信息压进一串有意义的数字），让不同 $t$ 有不同“指纹”。

这个想法来自 Transformer 的位置编码（Vaswani et al., 2017）：文本里每个词的位置也被编成高维向量。扩散模型借来，把连续时间步 $t$ 编成高维向量。具体公式：

$$\text{PE}(t, 2i) = \sin\left(\frac{t}{10000^{2i/d}}\right), \quad \text{PE}(t, 2i+1) = \cos\left(\frac{t}{10000^{2i/d}}\right)$$

其中 $d$ 是嵌入维度，$i = 0,1,\dots,d/2-1$ 是维度索引。

**为什么需要这个公式？** 因为标量 $t$ 塞进网络，相邻时间步几乎无法区分；我们得把“时间”摊开成很多个频率的波，让不同 $t$ 留下独特组合。**直觉**是：每一维对应一个不同频率——低维（$i$ 小）是低频（慢变化），高维（$i$ 大）是高频（快变化）。合起来是一幅**多尺度的时间步指纹**（multi-scale fingerprint，白话：像音乐泛音，基频定音高、泛音定音色，每维像一个泛音共同定出 $t$ 的“音色”）。不同 $t$ 产生不同的编码模式，网络就能区分它们。

**为什么偏偏用正弦？**四个理由：
1. **频率递减**：低频抓大范围时间趋势，高频抓相邻时间步的细微差别——和图像处理的多尺度思想一致（回顾第3章3.5节）；
2. **相对位置可线性表达**：存在旋转矩阵 $M(\Delta t)$ 使 $\text{PE}(t+\Delta t)=M(\Delta t)\cdot\text{PE}(t)$（数学细节见附录15B）——意味着“时间步之间的距离”能在编码空间里用线性变换表示；
3. **无需学习**：正弦编码是固定的，不增加训练参数，质量不依赖训练数据；
4. **有界性**：$\sin/\cos$ 输出恒在 $[-1,1]$，数值稳定。

**但正弦编码还不是终点**。它是固定、通用的，不针对你的任务。所以要过一道 MLP（多层感知机，白话：几层全连接网络）把它变成“任务相关”的嵌入：

$$e(t) = \text{MLP}(\text{PE}(t)) = W_2\cdot\text{SiLU}(W_1\cdot\text{PE}(t)+b_1)+b_2$$

MLP 在训练中学会“哪些时间步信息对去噪最重要”。DDPM 的实现（注意它先 $\cos$ 后 $\sin$，与原始 Transformer 顺序相反但数学等价）：

```python
def timestep_embedding(t, dim, max_period=10000):
    """将时间步 t 编码为 dim 维向量。
    t: 形状 [B] 的整数时间步张量
    dim: 嵌入维度（应为偶数）
    返回: 形状 [B, dim] 的编码向量
    """
    half = dim // 2
    # 生成频率: log 空间均匀分布的 1/10000^(2i/d)
    freqs = torch.exp(
        -math.log(max_period) * torch.arange(half) / half
    )
    # 时间步乘频率 -> 各维度不同相位
    args = t[:, None] * freqs[None, :]
    # 先 cos 后 sin（DDPM 约定，数学上和原文等价）
    return torch.cat([torch.cos(args), torch.sin(args)], dim=-1)
```

## 15.2.3 条件注入：从“加一下”到“调制”——把 $e(t)$ 真正喂进网络

生成时间步嵌入 $e(t)\in\mathbb{R}^d$ 后，得把它**注入**到网络的每一层。不同注入方式，表达力和稳定性差很多。

**方式一：加法注入**——最简单，把 $e(t)$ 加到某层特征上：
$$h' = h + e(t)$$
- 优点：简单、参数最少；
- 缺点：只改了特征的“偏移”，不改“尺度或分布”，遇到扩散这种需要大幅随 $t$ 变行为的场景，表达力不够。早期条件生成用过，扩散里已被更强的方式取代。

**方式二：缩放-偏移注入（FiLM）**——从 $e(t)$ 生成缩放因子 $\gamma(t)$ 和偏移因子 $\beta(t)$，做仿射变换：
$$h' = \gamma(t) \odot h + \beta(t),\qquad \gamma(t)=W_\gamma e(t)+b_\gamma,\ \beta(t)=W_\beta e(t)+b_\beta$$
- 优点：同时调尺度和偏移，$\gamma>1$ 放大、$\gamma<1$ 抑制，$\beta$ 调激活水平，表达力强得多；
- 直觉：像音响的“均衡器”——不改波形结构，只调各频段增益；StyleGAN 里叫“风格调制”；
- 缺点：对未归一化的特征，最优 $\gamma,\beta$ 会随特征分布飘，训练不够稳。

**方式三：adaLN-Zero**（Adaptive Layer Normalization with Zero init，DiT 提出，扩散里最重要）——在 FiLM 前先对特征做 LayerNorm（层归一化，白话：把一层特征归一化成零均值、单位方差），再调制：
$$h' = (1+\gamma(t)) \odot \text{LN}(h) + \beta(t)$$
其中 $\text{LN}(h)=\frac{h-\mu}{\sigma+\epsilon}$。

**为什么先归一化再调制？** 归一化消除了特征的量级差异，让 $\gamma,\beta$ 在统一尺度上操作——$\gamma$ 只需决定“归一化后要多大幅度”，$\beta$ 只需决定“偏移多少”，比没归一化时容易优化得多。写成 $(1+\gamma)$ 的形式，则 $\gamma=0$ 时 $h'=\text{LN}(h)$，比 $\gamma=1$ 更自然的初始化。

**关键的 Zero 初始化**：adaLN-Zero 把 $\gamma,\beta$ 以及残差缩放 $\alpha$ 全初始化为 0：
$$\gamma\leftarrow 0,\ \beta\leftarrow 0,\ \alpha\leftarrow 0$$
于是训练初期：
$$h'=(1+0)\odot\text{LN}(h)+0=\text{LN}(h),\qquad \text{Block}(h)=h+0\cdot\text{MHA}(\cdots)=h$$
**每个 DiT Block 在训练初期就是恒等映射**（identity map，白话：输入啥输出啥，原样通过）——时间步调制从零逐步长出来。

**Zero 初始化的意义**（DiT 论文的关键发现之一）：训练更稳定（初期像无条件模型，不会被随机调制破坏特征）、收敛更快（网络只需学“要调多少”，而非从随机调制里乱搜）。Peebles & Xie (2023) 实测 adaLN-Zero 把 FID 从 25.21 降到 19.47（DiT-XL/2）。先猜一下：从 25.21 降到多少你会觉得“这改动真值”？——实际上直接砍到 19.47，差距接近 23%，这是扩散架构里少见的“一招鲜”量级收益。

三种方式对比（adaLN-Zero 的 $6d$ 来自：每个 Block 要 6 个调制参数——MHA 前的 $(\gamma_1,\beta_1)$、MHA 后的残差门控 $\alpha_1$、MLP 前的 $(\gamma_2,\beta_2)$、MLP 后的残差门控 $\alpha_2$，都从 $e(t)$ 线性预测：$[\gamma_1,\beta_1,\alpha_1,\gamma_2,\beta_2,\alpha_2]=W_{\text{adaLN}}\cdot\text{SiLU}(e(t))$，$W_{\text{adaLN}}\in\mathbb{R}^{6d\times d}$ 且零初始化）：

| 方式 | 公式 | 额外参数 | 调制能力 | 训练稳定性 | 适用场景 |
|---|---|---|---|---|---|
| 加法 | $h + e(t)$ | 最少（$d$维） | 弱 | 一般 | 简单条件任务 |
| FiLM | $\gamma(t) \odot h + \beta(t)$ | 中等（$2d$维） | 中等 | 较好 | StyleGAN等 |
| adaLN-Zero | $(1+\gamma(t)) \odot \text{LN}(h) + \beta(t)$ | 中等（$6d$维） | 强 | 最好 | DiT/MMDiT |

## 实验15.2-1：UNet去噪器实现与时间步嵌入

实验 `15.2-1.py` 演示 **时间步条件对UNet去噪器的重要性**，通过对比DnCNN（无条件）与UNet（时间步条件）、可视化正弦位置编码、对比三种条件注入方式，揭示扩散去噪器与普通去噪器的本质区别。

### 实验场景

实验在MNIST数据集上训练两种去噪架构：

**DnCNN去噪器**（15.1.1节）：
- 堆叠6个Conv+BN+ReLU块，无时间步条件
- 残差学习：预测噪声 $\hat{\epsilon}$ 而非干净图像 $\hat{x}$
- 只能处理固定噪声水平 $\sigma$ 的高斯去噪

**UNet去噪器**（15.1.2节 + 15.2节）：
- 编码器-解码器架构 + 跳跃连接
- 时间步嵌入：正弦位置编码 + MLP
- 同一个网络处理任意噪声水平（时间步 $t \in [0, T]$）

**三种条件注入方式对比**（15.2.3节）：
- **加法注入**：$h + e(t)$ — 弱调制，仅改变偏移
- **FiLM**：$\gamma(t) \odot h + \beta(t)$ — 中等调制，改变尺度和偏移
- **adaLN-Zero**：$(1+\gamma(t)) \odot \text{LN}_C(h) + \beta(t)$ — 强调制 + Zero初始化 + 残差门控

### 实验目的

1. **验证扩散去噪器与普通去噪器的区别**：DnCNN（固定噪声水平）vs UNet（时间步条件）
2. **可视化正弦位置编码的多尺度"时间步指纹"**：低维度捕获大范围变化，高维度区分相邻时间步
3. **对比三种条件注入方式的训练效果**：收敛速度、去噪质量
4. **观察不同噪声水平下的去噪行为**：验证"大刀阔斧"vs"精雕细琢"的时间步自适应策略

### 实验输入

| 参数 | 设置 |
|------|------|
| 数据集 | MNIST，图像尺寸28×28 |
| 噪声调度 | DDPM线性调度，T=200步 |
| DnCNN架构 | 6个Conv+BN+ReLU块，固定 $\sigma=0.3$ |
| UNet架构 | SmallUNet，通道数[1,16,32,64] |
| 时间步嵌入 | 正弦编码（dim=64）+ MLP |
| 训练轮数 | DnCNN: 10 epochs；UNet: 10-30 epochs |
| 优化器 | Adam，lr=2e-4 |

### 预期结果

- UNet训练收敛优于DnCNN，因为时间步嵌入提供了额外的条件信息
- 正弦编码呈现多尺度结构：低维度低频（慢变化），高维度高频（快变化）
- adaLN-Zero训练最稳定，验证DiT论文的关键发现
- 高噪声（大t）时去噪输出模糊，低噪声（小t）时保留细节

## 动手感受一下：可视化正弦位置编码（可运行）

> 下面这段**可运行**代码（依赖 `torch`、`matplotlib`）把 15.2.2 的“多尺度指纹”画出来：低维慢变、高维快变。存成 `sin_pe.py` 后 `python sin_pe.py` 即可看到热力图。

```python
# ============================================================
# 正弦位置编码可视化（可运行）
# 依赖: torch, matplotlib。运行: python sin_pe.py
# 目标: 亲眼看到"低维慢变、高维快变"的时间步指纹
# ============================================================
import math
import torch
import matplotlib.pyplot as plt

def timestep_embedding(t, dim, max_period=10000):
    """和 DDPM 一致的实现: 先 cos 后 sin。"""
    half = dim // 2
    freqs = torch.exp(-math.log(max_period) * torch.arange(half) / half)
    args = t[:, None] * freqs[None, :]
    return torch.cat([torch.cos(args), torch.sin(args)], dim=-1)

# 取 200 个时间步, 嵌入维度 64
T = 200
dim = 64
t = torch.arange(T)
pe = timestep_embedding(t, dim).numpy()   # 形状 [200, 64]

# 画热力图: 横轴时间步, 纵轴嵌入维度
plt.figure(figsize=(8, 5))
plt.imshow(pe.T, aspect='auto', cmap='RdBu', vmin=-1, vmax=1)
plt.colorbar(label='编码值')
plt.xlabel('时间步 t')
plt.ylabel('嵌入维度 i')
plt.title('正弦位置编码：低维(下)慢变，高维(上)快变')
plt.tight_layout()
plt.show()
```

跑出来你会看到：纵轴下方（低维）是缓慢起伏的色带，上方（高维）是密密麻麻的振荡条纹——这正是“基频定大趋势、泛音定精细差别”的具象化。

## 收尾：为什么这件事重要

这一节我们给去噪器装上了“感知噪声水平”的眼睛。核心就一句话：**把标量时间步 $t$ 编成高维指纹（正弦编码 + MLP），再用 adaLN-Zero 把指纹“调制”进网络每一层**。没有它，一个 UNet 就只能干“固定噪声水平”的活；有了它，同一个网络才能在数百个噪声水平上各自变身。更妙的是，adaLN-Zero 让网络从“什么都不做”的恒等映射起步、只学“调多少”——这正是下一节 DiT 能够把 Transformer 直接搬进扩散去噪器的关键支点。

**连接下一节**：时间步嵌入解决了“网络怎么感知噪声”，但 UNet 的 CNN 骨子里有个根本局限——**局部感受野**。无论堆多少层卷积，每个像素的视野始终有限。而 Transformer 的自注意力（self-attention，白话：让每个位置直接“看”全图所有位置）提供了完全不同的信息聚合方式，这正是它成为下一代去噪架构的理由。
