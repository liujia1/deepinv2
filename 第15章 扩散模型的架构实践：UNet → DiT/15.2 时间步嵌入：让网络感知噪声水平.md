# 15.2 时间步嵌入：让网络感知噪声水平

> **核心观点**：扩散模型的去噪器与普通去噪器的根本区别在于时间步条件——同一个网络需要根据噪声水平 $t$ 调整去噪策略。时间步嵌入通过正弦位置编码将标量 $t$ 映射为高维向量，再通过各种注入方式（加法、FiLM、adaLN-Zero）调制网络特征。时间步嵌入的质量直接影响去噪器在不同噪声水平下的表现。

## 15.2.1 为什么需要时间步条件？

### 扩散去噪器的特殊需求

普通去噪器处理固定噪声水平的输入：$D_\theta(y) \approx x$，其中 $y = x + \sigma\epsilon$，$\sigma$ 是固定的。一个去噪器对应一个噪声水平。

扩散去噪器面临完全不同的挑战：噪声水平随时间步 $t$ 连续变化——$x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon$（DDPM参数化，回顾第10章10.2节）。同一个网络 $D_\theta(x_t, t)$ 必须根据 $t$ 调整行为：

- **$t$ 接近0**（信噪比低，高噪声）：需要"大刀阔斧"地去除噪声——此时的去噪策略类似于低通滤波
- **$t$ 接近 $T$**（信噪比高，低噪声）：需要"精雕细琢"地保留细节——此时的去噪策略类似于细节增强
- **中间 $t$**：需要在这两种极端之间平滑过渡

### 回顾全书中的时间步依赖

时间步条件贯穿全书的扩散模型理论，但网络层面如何实现这一条件从未展开：

- **第6章6.6节**：DRUNet的条件噪声水平设计——去噪器需要知道当前噪声水平才能正确去噪
- **第7章**：不同时间步 $t$ 的得分函数 $\nabla\log p_t(x_t)$ 不同——扩散模型的得分函数是时间步相关的函数 $s_\theta(x_t, t)$
- **第11章11.3节**：三种参数化（$\epsilon$-预测、$s$-预测、$x_0$-预测）都与时间步相关——$\epsilon_\theta(x_t, t)$、$s_\theta(x_t, t)$、$\hat{x}_{\theta}(x_t, t)$ 都是 $(x_t, t)$ 的函数

### 无条件 vs 条件去噪器

**无条件策略**：为每个噪声水平训练一个独立的去噪器 $D_{\theta_\sigma}(y)$

- 优点：每个去噪器专精于一个噪声水平
- 缺点：需要训练和存储 $N$ 个去噪器（$N$ 为噪声水平数），代价高、不灵活

**条件策略**：训练一个统一的条件去噪器 $D_\theta(x_t, t)$

- 优点：一个网络处理所有噪声水平，高效、统一
- 缺点：网络需要额外接收时间步信息并学会根据 $t$ 调整行为

实践中，条件策略是唯一可行的方案——扩散模型的逆向采样需要遍历数百个时间步，无条件策略不可接受。

## 15.2.2 正弦位置编码

### 从NLP到扩散模型

正弦位置编码最早由Vaswani et al. (2017) 在Transformer中提出，用于将序列中的位置索引编码为高维向量。扩散模型借鉴了这一思路，将连续时间步 $t \in [0, T]$ 编码为高维向量。

**核心问题**：时间步 $t$ 是一个标量（或低维向量），直接作为网络输入的表达力不足。需要将其映射为高维嵌入，使网络能够区分不同时间步的细微差异。

### 正弦位置编码公式

$$\text{PE}(t, 2i) = \sin\left(\frac{t}{10000^{2i/d}}\right), \quad \text{PE}(t, 2i+1) = \cos\left(\frac{t}{10000^{2i/d}}\right)$$

其中 $d$ 是嵌入维度，$i = 0, 1, \ldots, d/2 - 1$ 是维度索引。

**直觉理解**：

- 每个维度对应不同的频率——低维度（$i$小）对应低频（慢变化），高维度（$i$大）对应高频（快变化）
- 这形成了一个多尺度的"时间步指纹"——不同时间步产生不同的编码模式
- 类比：就像音乐中的泛音序列——基频决定音高，泛音决定音色。正弦编码的每个维度就像一个泛音，共同构成时间步的"音色"

**为什么用正弦编码？**

1. **频率递减**：低频维度捕获大范围时间变化（$t$ 从0到 $T$ 的整体趋势），高频维度捕获精细时间差异（相邻时间步的区别）。这与图像处理中的多尺度分析思想一致——回顾第3章3.5节的多尺度方法
2. **相对位置可线性表达**：存在矩阵 $M(\Delta t)$ 使得 $\text{PE}(t + \Delta t) = M(\Delta t) \cdot \text{PE}(t)$（旋转矩阵），即时间步的相对偏移可以通过编码的线性变换表示（数学细节见附录15B）
3. **无需学习**：正弦编码是固定的，不增加训练参数。这意味着编码质量不依赖于训练数据和训练过程
4. **有界性**：$\sin$ 和 $\cos$ 的输出始终在 $[-1, 1]$，有利于数值稳定性

### 从正弦编码到时间步嵌入

正弦编码 $\text{PE}(t) \in \mathbb{R}^d$ 提供了一个固定的时间步表示，但它不是直接可用的——需要通过MLP进一步变换为任务相关的时间步嵌入：

$$e(t) = \text{MLP}(\text{PE}(t))$$

其中MLP通常为两层全连接网络：

$$e(t) = W_2 \cdot \text{SiLU}(W_1 \cdot \text{PE}(t) + b_1) + b_2$$

**为什么需要MLP？**

- 正弦编码是固定的、通用的——它不针对特定任务优化
- MLP将固定编码映射为可学习的、任务相关的时间步表示
- MLP的参数在训练中学习到"哪些时间步信息对去噪最重要"

**DDPM的实现**（Ho et al., 2020）：

```python
def timestep_embedding(t, dim, max_period=10000):
    """将时间步 t 编码为 dim 维向量"""
    half = dim // 2
    freqs = torch.exp(
        -math.log(max_period) * torch.arange(half) / half
    )
    args = t[:, None] * freqs[None, :]
    return torch.cat([torch.cos(args), torch.sin(args)], dim=-1)
```

注意：DDPM使用先 $\cos$ 后 $\sin$ 的顺序，与Transformer原始论文（先 $\sin$ 后 $\cos$）略有不同，但数学上等价。

## 15.2.3 条件注入方式：从加法到调制

时间步嵌入 $e(t) \in \mathbb{R}^d$ 生成后，需要注入到网络的各个层中。不同的注入方式在表达力和训练稳定性上有显著差异。

### 方式一：加法注入

最简单的方式——将时间步嵌入加到网络某一层的特征上：

$$h' = h + e(t)$$

- **优点**：实现简单，参数量最少
- **缺点**：调制能力弱，仅改变特征的偏移，不改变其尺度或分布。对于需要根据时间步大幅调整行为的场景（如扩散去噪），表达力不足

加法注入在早期的条件生成模型中使用，但在扩散模型中已被更强大的调制方式取代。

### 方式二：缩放-偏移注入（FiLM）

FiLM（Feature-wise Linear Modulation，Perez et al., 2018）从时间步嵌入生成缩放因子 $\gamma(t)$ 和偏移因子 $\beta(t)$，对特征进行仿射变换：

$$h' = \gamma(t) \odot h + \beta(t)$$

其中 $\gamma(t) = W_\gamma e(t) + b_\gamma$，$\beta(t) = W_\beta e(t) + b_\beta$。

- **优点**：同时调制特征的尺度（$\gamma$）和偏移（$\beta$），表达力比加法注入强得多。$\gamma > 1$ 放大特征，$\gamma < 1$ 抑制特征；$\beta$ 控制特征的激活水平
- **缺点**：对未归一化的特征调制时，$\gamma$ 和 $\beta$ 的最优值可能随特征分布变化，训练不够稳定
- **直觉**：FiLM像是一个"均衡器"——它不改变信号的波形结构（由卷积/注意力决定），而是调整各频段的增益和偏移

FiLM在StyleGAN（Karras et al., 2019）中被称为"风格调制"（style modulation），是条件生成的经典技术。

### 方式三：adaLN-Zero

adaLN-Zero（Adaptive Layer Normalization with Zero initialization）是DiT（Peebles & Xie, 2023）提出的条件注入方式，在FiLM基础上做了两个关键改进：

**改进一：自适应Layer Normalization**

在FiLM调制之前先对特征做Layer Normalization：

$$h' = \gamma(t) \odot \text{LN}(h) + \beta(t)$$

Layer Normalization将特征归一化到零均值、单位方差：

$$\text{LN}(h) = \frac{h - \mu}{\sigma + \epsilon}$$

然后 $\gamma(t)$ 和 $\beta(t)$ 重新设定归一化后特征的尺度和偏移。

**为什么先归一化再调制？**

- 归一化消除了特征分布的量级差异——$\gamma$ 和 $\beta$ 在统一的尺度上操作，更易优化
- 没有归一化时，$\gamma$ 需要同时补偿特征的原始分布和调制目标，优化困难
- 归一化后，$\gamma$ 只需决定"归一化后的特征应该有多大的幅度"，$\beta$ 只需决定"偏移多少"

实践中，adaLN通常改写为：

$$h' = (1 + \gamma(t)) \odot \text{LN}(h) + \beta(t)$$

这样 $\gamma(t) = 0$ 时 $h' = \text{LN}(h)$（保持归一化后的特征不变），比 $\gamma(t) = 1$ 的初始化更自然。

**改进二：Zero初始化**

adaLN-Zero的 $\gamma$, $\beta$ 以及残差缩放因子 $\alpha$ 都初始化为零：

$$\gamma(t) \leftarrow 0, \quad \beta(t) \leftarrow 0, \quad \alpha(t) \leftarrow 0$$

这意味着训练初期：

$$h' = (1 + 0) \odot \text{LN}(h) + 0 = \text{LN}(h)$$

$$\text{Block}(h) = h + 0 \cdot \text{MHA/LN}(\text{LN}(h)) = h$$

即**每个DiT Block在训练初期是恒等映射**——时间步条件的调制从零逐步增强。

**Zero初始化的意义**：

- **训练更稳定**：初期网络如同无条件模型，不会因为随机初始化的时间步调制而破坏特征
- **收敛更快**：恒等映射提供了一个好的起点——网络只需学习"需要多大程度的调制"，而非从随机调制中搜索正确方向
- **这是DiT论文的关键发现之一**：Peebles & Xie (2023) 实验表明，adaLN-Zero显著优于普通adaLN（FID从25.21降至19.47，在DiT-XL/2上）

### 三种注入方式对比

| 方式 | 公式 | 额外参数 | 调制能力 | 训练稳定性 | 适用场景 |
|---|---|---|---|---|---|
| 加法 | $h + e(t)$ | 最少（$d$维） | 弱 | 一般 | 简单条件任务 |
| FiLM | $\gamma(t) \odot h + \beta(t)$ | 中等（$2d$维） | 中等 | 较好 | StyleGAN等 |
| adaLN-Zero | $(1+\gamma(t)) \odot \text{LN}(h) + \beta(t)$ | 中等（$6d$维） | 强 | 最好 | DiT/MMDiT |

**为何adaLN-Zero的参数是 $6d$ 维？** 在DiT Block中，每个Block需要6个调制参数：MHA前的 $(\gamma_1, \beta_1)$、MHA后的残差缩放 $\alpha_1$、MLP前的 $(\gamma_2, \beta_2)$、MLP后的残差缩放 $\alpha_2$。这6个参数都从 $e(t)$ 线性预测：

$$[\gamma_1, \beta_1, \alpha_1, \gamma_2, \beta_2, \alpha_2] = W_{\text{adaLN}} \cdot \text{SiLU}(e(t))$$

其中 $W_{\text{adaLN}} \in \mathbb{R}^{6d \times d}$，且初始化为零矩阵（Zero初始化）。

## 实验15.2-1：UNet去噪器实现与时间步嵌入

实验 `15.2-1.py` 演示 **时间步条件对UNet去噪器的重要性**，通过对比DnCNN（无条件）与UNet（时间步条件）、可视化正弦位置编码、对比三种条件注入方式，揭示扩散去噪器与普通去噪器的本质区别。

### 实验场景

实验在MNIST数据集上训练两种去噪架构：

**DnCNN去噪器**（15.1.1节）：
- 堆叠6个Conv+BN+ReLU块，无时间步条件
- 残差学习：预测噪声 $\hat{\epsilon}$ 而非干净图像 $\hat{x}$
- 只能处理固定噪声水平 $\sigma$ 的高斯去噪

**UNet去噪器**（15.1.2节 + 15.2节）：
- 编码器-解码器架构 + 跳跃连接
- 时间步嵌入：正弦位置编码 + MLP
- 同一个网络处理任意噪声水平（时间步 $t \in [0, T]$）

**三种条件注入方式对比**（15.2.3节）：
- **加法注入**：$h + e(t)$ — 弱调制，仅改变偏移
- **FiLM**：$\gamma(t) \odot h + \beta(t)$ — 中等调制，改变尺度和偏移
- **adaLN-Zero**：$(1+\gamma(t)) \odot \text{LN}_C(h) + \beta(t)$ — 强调制 + Zero初始化 + 残差门控

### 实验目的

1. **验证扩散去噪器与普通去噪器的区别**：DnCNN（固定噪声水平）vs UNet（时间步条件）
2. **可视化正弦位置编码的多尺度"时间步指纹"**：低维度捕获大范围变化，高维度区分相邻时间步
3. **对比三种条件注入方式的训练效果**：收敛速度、去噪质量
4. **观察不同噪声水平下的去噪行为**：验证"大刀阔斧"vs"精雕细琢"的时间步自适应策略

### 实验输入

| 参数 | 设置 |
|------|------|
| 数据集 | MNIST，图像尺寸28×28 |
| 噪声调度 | DDPM线性调度，T=200步 |
| DnCNN架构 | 6个Conv+BN+ReLU块，固定 $\sigma=0.3$ |
| UNet架构 | SmallUNet，通道数[1,16,32,64] |
| 时间步嵌入 | 正弦编码（dim=64）+ MLP |
| 训练轮数 | DnCNN: 10 epochs；UNet: 10-30 epochs |
| 优化器 | Adam，lr=2e-4 |

### 预期结果

- UNet训练收敛优于DnCNN，因为时间步嵌入提供了额外的条件信息
- 正弦编码呈现多尺度结构：低维度低频（慢变化），高维度高频（快变化）
- adaLN-Zero训练最稳定，验证DiT论文的关键发现
- 高噪声（大t）时去噪输出模糊，低噪声（小t）时保留细节

4. **去噪行为的时间步自适应性**：网络根据噪声水平自动在"强平滑"与"细节保留"之间切换

时间步嵌入解决了"如何让网络感知噪声水平"的问题，但UNet的CNN架构本身有一个根本性局限：局部感受野。无论堆叠多少层卷积，每个像素的"视野"始终有限。而Transformer的自注意力机制提供了一种完全不同的信息聚合方式——每个位置可以直接"看到"整幅图像的所有位置，这一特性使得Transformer成为扩散模型去噪器的下一代架构选择。
