# 15.0 本章导读：架构即先验——去噪器的设计如何影响生成质量

前14章回答了扩散模型"学什么"和"怎么学"——第5-6章的采样路径告诉我们要学得分函数 $s(x_t) = \nabla\log p_t(x_t)$，第8-11章的变分路径告诉我们要学去噪参数 $\epsilon_\theta$，第12章证明 Score ≡ ELBO，殊途同归，第14章的Flow Matching告诉我们可以直接学向量场 $v_t(x_t)$。但有一个隐含的前提始终未被展开：**用什么网络去实现这些目标？**

这个问题的答案不是任意的。去噪器 $D_\theta(x_t, t)$ 的架构选择不是一个可以推迟到"工程实现"阶段再考虑的细节——它决定了所学隐式先验 $p_\theta(x)$ 的表达能力。回顾第5章5.3节的Tweedie等式：去噪器与得分函数等价，去噪器的质量直接决定得分估计的质量；回顾第6章的DSM定理：训练去噪器等价于学习得分函数——但"训练一个去噪器"的具体实现，完全依赖于去噪器的架构设计。一个容量不足或设计不合理的去噪器，无论训练目标多么精确，都无法学到高质量的先验。

**架构即先验**——这是本章的核心论点。去噪器不仅是函数逼近器，更是隐式先验的载体。UNet的多尺度特征提取编码了"图像具有多尺度结构"的归纳偏置，DiT的全局自注意力编码了"图像任意位置间可能存在长程依赖"的假设。不同的架构选择，本质上是不同的先验假设。

本章从这个问题出发，走一条"理解现状→补充关键机制→架构革命→实践选择→工程落地"的路径：

**去噪器的经典架构**（15.1）：CNN利用卷积的局部感受野和参数共享，天然适合图像去噪——DnCNN证明了深度CNN可以超越传统方法。UNet在CNN基础上引入编码器-解码器结构和跳跃连接，实现了多尺度特征的提取与融合，成为扩散模型第一个十年的标准去噪架构。UNet在DDPM、Score-SDE等里程碑工作中扮演了核心角色。

**时间步嵌入**（15.2）：扩散去噪器与普通去噪器的根本区别在于时间步条件——同一个网络需要根据噪声水平 $t$ 调整去噪策略。正弦位置编码将标量 $t$ 映射为高维向量，adaLN-Zero等注入方式将时间步信息调制到网络特征中。这一关键机制在前14章中被反复使用（第6章的DRUNet条件噪声水平、第7章的扩散时间步、第11章的三种参数化），但从未系统展开——本节补上这一环。

**从ViT到DiT**（15.3）：Vision Transformer将图像分割为patch序列并用自注意力处理，证明Transformer可以在图像任务上与CNN竞争。Diffusion Transformer（DiT）将ViT的思路移植到扩散去噪器——Patchify将含噪图像转化为token序列，adaLN-Zero注入时间步条件，Transformer Block处理全局依赖。DiT的核心优势是缩放性：参数量增加时，生成质量遵循可预测的提升曲线。

**UNet vs DiT**（15.4）：两种架构代表了截然不同的设计哲学——CNN的归纳偏置 vs Transformer的数据驱动学习。"归纳偏置是'小数据的朋友，大数据的敌人'"——UNet在小数据和中等规模下依然有优势，DiT在大数据和大规模下展现可预测的缩放优势。对于逆问题求解，UNet在PnP框架中更成熟；DiT在Flow Matching框架中更契合——全局注意力与直线路径天然匹配。

**训练最佳实践**（15.5）：好的架构只是起点，好的训练才能让架构发挥潜力。优化器选择（AdamW）、学习率调度（warmup + cosine decay）、初始化策略（He初始化 + adaLN-Zero零初始化）、早停与验证、以及过参数化与双重下降现象——这些实践知识是连接"好的架构设计"和"好的生成质量"的最后一英里。

```
经典架构(15.1) → 时间步嵌入(15.2) → ViT→DiT(15.3) → 架构选择(15.4) → 训练实践(15.5)
```

本章结束时，读者将理解：去噪器的架构选择是扩散模型设计中不可忽视的关键决策。UNet和DiT各有适用场景——理解它们的设计哲学和性能特征，才能在实践中做出正确的选择。更深层地，读者将意识到：**架构不是理论之外的"实现细节"，而是隐式先验的具体表达——架构选择本身就是一种先验设计**。
