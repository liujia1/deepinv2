# 15.1 去噪器的经典架构：CNN与UNet

> **核心观点**：去噪器的核心任务是映射含噪图像 $x_t$ 到干净估计 $\hat{x}_0$（或噪声估计 $\hat{\epsilon}$）。CNN利用卷积的局部感受野和参数共享，天然适合图像处理；UNet在CNN基础上引入编码器-解码器结构和跳跃连接，实现了多尺度特征的提取与融合，成为扩散模型第一个十年的标准去噪架构。

## 15.1.1 CNN去噪器：DnCNN

### 图像去噪作为回归问题

回顾第2章2.3节的贝叶斯去噪器：给定含噪观测 $y = x + \epsilon$（$\epsilon \sim \mathcal{N}(0, \sigma^2 I)$），MMSE估计器为

$$\hat{x}_{\text{MMSE}} = \mathbb{E}[x|y] = y + \sigma^2 \nabla\log p(y)$$

这正是第5章5.3节Tweedie等式的内容。但在实践中，我们不需要显式计算 $\nabla\log p(y)$——可以直接用神经网络学习从 $y$ 到 $\hat{x}$ 的映射。

**监督去噪的回归框架**：

- 输入：含噪图像 $y = x + \epsilon$
- 输出：去噪估计 $\hat{x} = D_\theta(y)$
- 训练目标：$\min_\theta \mathbb{E}[\|D_\theta(y) - x\|^2]$
- 回顾第9章9.4节四种学习设定：这属于"自监督"设定——已知噪声模型，训练数据为干净图像+合成噪声

### DnCNN架构

DnCNN（Zhang et al., 2017）是深度学习去噪的开创性工作，其核心设计影响了后续几乎所有图像恢复网络：

**残差学习**：DnCNN不直接预测干净图像 $\hat{x}$，而是预测噪声 $\hat{\epsilon} = D_\theta(y)$，去噪结果为 $\hat{x} = y - \hat{\epsilon}$。

为什么残差学习更有效？

- **信号-噪声的复杂度不对称**：噪声 $\epsilon$ 是独立同分布的高斯随机变量，结构简单；干净图像 $x$ 包含复杂的纹理和语义，结构丰富。学习简单目标（噪声）比学习复杂目标（干净图像）更容易
- **梯度传播更高效**：残差连接使梯度可以绕过中间层直接传播到输入
- **与扩散模型的呼应**：回顾第11章11.3节的三种参数化——DnCNN的残差学习对应 $\epsilon$-预测参数化，这是DDPM的默认选择

**网络结构**：堆叠17个"Conv(3×3) + BN + ReLU"块，中间层通道数为64。有效感受野约35×35像素——足以捕获局部噪声模式。

**CNN的局限**：

- **感受野有限**：局部卷积核无法捕获长程依赖。堆叠更多层可以扩大感受野，但边际效益递减
- **单尺度处理**：所有卷积在同一分辨率上操作，缺乏多尺度信息。大尺度结构（如全局光照）和小尺度细节（如纹理）需要不同的处理策略
- **对大尺度结构建模不足**：去噪效果好，但对图像全局结构（如物体的整体形状）的理解有限

这些局限推动了从DnCNN到UNet的架构升级——UNet通过多尺度特征提取解决了上述问题。

## 15.1.2 UNet：编码器-解码器+跳跃连接

### UNet的诞生

UNet由Ronneberger, Fischer和Brox于2015年提出，原始动机是医学图像分割——需要精确的像素级输出。虽然最初不是为去噪设计的，但其编码器-解码器+跳跃连接的架构天然适合图像恢复任务。

**核心思想**：编码器提取多尺度特征，解码器逐步恢复分辨率，跳跃连接传递细节。

### 编码器路径

编码器逐层下采样：分辨率减半，通道数加倍。每一层的基本操作为：

$$\text{Conv} \to \text{BN} \to \text{ReLU} \to \text{Conv} \to \text{BN} \to \text{ReLU} \to \text{MaxPool}$$

典型的4层编码器：

| 层 | 输入通道 | 输出通道 | 分辨率变化 |
|---|---|---|---|
| 编码器第1层 | 1（灰度）或3（RGB） | 32 | $H \times W \to H/2 \times W/2$ |
| 编码器第2层 | 32 | 64 | $H/2 \times W/2 \to H/4 \times W/4$ |
| 编码器第3层 | 64 | 128 | $H/4 \times W/4 \to H/8 \times W/8$ |
| 编码器第4层 | 128 | 256 | $H/8 \times W/8 \to H/16 \times W/16$ |

功能：提取从细粒度到粗粒度的多尺度特征。低层捕获边缘和纹理，高层捕获语义和全局结构。

### 解码器路径

解码器逐层上采样：分辨率加倍，通道数减半。每一层的基本操作为：

$$\text{Upsample}(\text{或 ConvTranspose2d}) \to \text{Concat}(\text{跳跃连接}) \to \text{Conv} \to \text{BN} \to \text{ReLU} \to \text{Conv} \to \text{BN} \to \text{ReLU}$$

上采样方式：

- **双线性插值 + Conv**：简单，参数少，但可能引入伪影
- **转置卷积（ConvTranspose2d）**：可学习的上采样，更灵活，但可能产生棋盘格伪影
- **最近邻上采样 + Conv**：避免棋盘格，实践中常用

### 跳跃连接（Skip Connections）

跳跃连接是UNet最关键的设计——编码器第 $l$ 层的特征图直接传递（拼接）到解码器第 $l$ 层：

$$h_{\text{dec}}^{(l)} = \text{Concat}\left(h_{\text{up}}^{(l)},\; h_{\text{enc}}^{(l)}\right)$$

**为什么跳跃连接如此重要？**

- **信息保留**：下采样过程不可避免地丢失空间细节。跳跃连接将编码器的高分辨率特征直接传递给解码器，弥补了这一损失
- **梯度流通畅**：跳跃连接为梯度提供了一条从输出到输入的"高速公路"，缓解了深层网络的梯度消失问题。这与ResNet的残差连接（He et al., 2016）异曲同工
- **多尺度融合**：不同层的跳跃连接携带不同尺度的信息——浅层传递边缘和纹理，深层传递语义和结构

**直觉**：编码器是"分析师"（提取抽象特征），解码器是"重建师"（恢复空间细节），跳跃连接是"分析师给重建师递便签"——如果没有便签，重建师只能凭模糊的记忆重建，细节必然丢失。

### UNet的关键优势

1. **多尺度特征融合**：同时利用细粒度（边缘/纹理）和粗粒度（语义/结构）信息，这是DnCNN等单尺度架构无法做到的
2. **梯度流通畅**：跳跃连接缓解了深层网络的梯度消失问题，使得训练更深的UNet成为可能
3. **参数高效**：编码器-解码器的对称设计使得参数量可控——下采样减半分辨率，上采样加倍分辨率，总参数量主要由通道数决定
4. **灵活性**：可以轻松插入各种改进——注意力机制、时间步嵌入、条件输入等

## 实验15.1-1：扩散UNet深度架构实现（D9风格）

实验 `15.1-1.py` 演示 **D9风格的完整DiffusionUNet架构实现与训练**，包括ConvNext块、线性注意力、PreNorm归一化等关键组件，验证UNet编码器-解码器架构与跳跃连接的有效性。

### 实验场景

实验实现一个深度扩散UNet（参考lilianweng/diffusion-models论文实现），在MNIST数据集上训练去噪网络。架构包括：

**核心组件**：
- **ConvNext块**：7×7深度可分离卷积 + 时间步MLP注入 + 残差连接
- **Linear Attention**：O(N·d²)复杂度，相比Full Attention的O(N²)更节省显存
- **PreNorm模式**：归一化在残差之前，稳定深层网络训练
- **时间步嵌入**：正弦位置编码 + MLP，让网络感知当前噪声水平

**架构流程**：
```
init_conv → 下采样块（ConvNext×2 + LinearAttention + Downsample）×N
          → 中间块（ConvNext + FullAttention + ConvNext）
          → 上采样块（ConvNext×2 + LinearAttention + Upsample）×N
          → final_conv
```

### 实验目的

1. **验证UNet编码器-解码器架构的有效性**：多尺度特征融合、跳跃连接的信息传递能力
2. **理解ConvNext块的设计优势**：大感受野（7×7深度可分离卷积）+ 低参数量 + 时间步注入
3. **对比注意力机制的复杂度**：Linear Attention vs Full Attention在不同分辨率下的显存开销
4. **演示PreNorm模式的训练稳定性**：深层网络的梯度流通畅性
5. **验证完整UNet在扩散模型中的收敛性**：训练曲线、采样质量

## 15.1.3 UNet在扩散模型中的角色

### 从去噪器到扩散去噪器

回顾第6章6.6节：DRUNet是一个条件噪声水平的UNet去噪器，输入 $(x_t, \sigma)$，输出 $\hat{x}_\theta(x_t, \sigma)$。这是扩散UNet的雏形。

**普通UNet vs 扩散UNet**——关键区别在于时间步条件的注入（15.2节将详细展开）：

| 特性 | 普通UNet去噪器 | 扩散UNet去噪器 |
|---|---|---|
| 输入 | 含噪图像 $y$ | 含噪图像 + 时间步 $(x_t, t)$ |
| 输出 | 去噪估计 $\hat{x}$ | 噪声估计 $\hat{\epsilon}_\theta(x_t, t)$ |
| 条件性 | 无条件（固定噪声水平） | 条件（随时间步变化） |
| 训练目标 | $\|D_\theta(y) - x\|^2$ | $\|\epsilon_\theta(x_t, t) - \epsilon\|^2$ |

扩散UNet需要在**不同噪声水平**下表现不同——$t$ 接近0时（高噪声），需要"大刀阔斧"地去除噪声；$t$ 接近 $T$ 时（低噪声），需要"精雕细琢"地保留细节。这种条件性是扩散模型的核心需求，也是时间步嵌入（15.2节）要解决的问题。

### DDPM中的UNet

DDPM（Ho et al., 2020）使用的UNet基于OpenAI的Guided Diffusion架构（Dhariwal & Nichol, 2021），在标准UNet基础上做了关键改进：

- **注意力机制**：在低分辨率层引入自注意力，捕获全局依赖
- **时间步嵌入**：通过正弦位置编码 + MLP将时间步 $t$ 注入网络
- **残差块**：将"Conv + BN + ReLU"替换为"Conv + GroupNorm + SiLU + Conv + GroupNorm + SiLU + 残差连接"
- **归一化方式**：用GroupNorm替代BatchNorm，更适合小batch训练

**DDPM-UNet的典型参数量**：约554M参数（ADM架构），在256×256 ImageNet上训练。

### Score-SDE中的NCSNpp

NCSNpp（Song et al., 2021）是Score-SDE框架的UNet变体：

- **连续时间条件**：时间步 $t \in [0, T]$ 是连续值，而非DDPM的离散时间步
- **多尺度噪声水平的统一处理**：不同噪声水平共享同一个网络，通过时间步嵌入区分
- **与DDPM-UNet的结构差异**：更深的网络、更宽的通道、更细致的注意力放置策略

### UNet去噪器的实践代码示意

基于CompImLab25 Part 3的UNetMini（简化版UNet用于MNIST去噪）：

```python
class UNetMini(nn.Module):
    def __init__(self):
        super().__init__()
        # 编码器
        self.enc1 = nn.Sequential(
            nn.Conv2d(1, 32, 3, padding=1), nn.ReLU(),
            nn.Conv2d(32, 32, 3, padding=1), nn.ReLU()
        )
        self.pool = nn.MaxPool2d(2)
        self.enc2 = nn.Sequential(
            nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(),
            nn.Conv2d(64, 64, 3, padding=1), nn.ReLU()
        )
        # 解码器
        self.up = nn.Upsample(scale_factor=2, mode='nearest')
        self.dec1 = nn.Sequential(
            nn.Conv2d(64+32, 32, 3, padding=1), nn.ReLU(),  # +32 来自跳跃连接
            nn.Conv2d(32, 32, 3, padding=1), nn.ReLU()
        )
        self.dec2 = nn.Conv2d(32, 1, 1)  # 1x1 卷积，输出1通道

    def forward(self, x):
        # 编码
        e1 = self.enc1(x)         # [B, 32, H, W]
        e2 = self.enc2(self.pool(e1))  # [B, 64, H/2, W/2]
        # 解码
        d1 = self.up(e2)                    # [B, 64, H, W]
        d1 = torch.cat([d1, e1], dim=1)     # 跳跃连接 [B, 96, H, W]
        d1 = self.dec1(d1)                  # [B, 32, H, W]
        return self.dec2(d1)                # [B, 1, H, W]
```

**训练流程**（基于CompImLab25 Part 3）：

1. **数据加载**：MNIST训练集，干净图像 $x$
2. **加噪**：$x_t = x + \sigma \cdot \epsilon$，$\epsilon \sim \mathcal{N}(0, I)$
3. **前向传播**：$\hat{x} = D_\theta(x_t)$
4. **计算损失**：$\mathcal{L} = \|D_\theta(x_t) - x\|^2$（MSE损失）
5. **反向传播**：$\theta \leftarrow \theta - \eta \nabla_\theta \mathcal{L}$
6. **重复**：20-50 epochs

**典型结果**（CompImLab25）：平均MSE从0.004478（噪声图像）降至0.000493（去噪后），PSNR提升约9.6 dB。

UNet之所以能成为扩散模型的标准去噪架构，不仅因为其编码器-解码器+跳跃连接的设计，更因为一个被我们在前14章中反复使用但从未展开的关键机制——**时间步嵌入**。它让同一个网络在不同噪声水平下表现出不同的去噪策略。
