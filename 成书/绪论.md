# 绪论：从逆问题到生成——一场贝叶斯之旅

---

## 0.1 图像的两个基本问题

请想象以下两个场景。

**场景一：** 一位放射科医生拿到一张模糊、带噪声的CT扫描图像，想知道患者的肿瘤究竟在哪里、有多大。这里的数学问题是：给定退化观测 $\mathbf{y} = \mathbf{A}\mathbf{x} + \boldsymbol{\varepsilon}$，如何恢复原始图像 $\mathbf{x}$？这是**图像逆问题**（inverse problem）——从结果推断原因。

**场景二：** 一位艺术家用AI工具输入"一只在火星上漫步的猫"，系统生成了一幅从未存在过的画面。这里的数学问题是：如何从数据分布 $p(\mathbf{x})$ 中采样出全新的图像？这是**图像生成**（image generation）——从分布中创造样本。

这两个场景看似截然不同：一个是"恢复"已存在的图像，一个是"创造"不存在的图像。然而，本书将论证一个核心事实——

> **图像逆问题求解与图像生成是同一本质问题的不同表达。逆问题求解就是条件图像生成。**

这一洞察并非书名的修辞技巧，而是有着深刻的数学根基：两者求解的都是后验概率分布 $p(\mathbf{x}|\mathbf{y})$。逆问题关心的是这个分布的统计特性（均值、众数、方差），而生成问题关心的是从中采样。当你拥有了从后验采样的能力，你就同时拥有了求解逆问题的能力——反之亦然。

---

## 0.2 核心主张：逆问题求解 = 条件图像生成

贝叶斯定理是连接两个问题的数学纽带：

$$p(\mathbf{x}|\mathbf{y}) \propto p(\mathbf{y}|\mathbf{x})\,p(\mathbf{x})$$

等号左边是后验分布——在观测到 $\mathbf{y}$ 的条件下，原图 $\mathbf{x}$ 的一切可能性。等号右边是似然与先验的乘积——观测带来的信息与我们对图像的先验知识的融合。

从这个等式出发，两条截然不同的技术路线各自发展了数十年：

- **逆问题社区**关注如何从后验中提取最优估计（MAP、MMSE），发展了正则化理论、变分方法、近端算法等工具；
- **生成模型社区**关注如何从数据分布中高效采样，发展了VAE、GAN、扩散模型等工具。

两个社区各自积累了一系列平行的概念：正则化对应先验，数据项对应似然，优化迭代对应采样迭代，去噪器对应得分函数……这些平行并非巧合，而是同一数学结构在不同语境下的投影。

本书的使命，就是将这些平行线交汇于贝叶斯框架之下，揭示它们背后统一的数学逻辑，并以扩散模型作为交汇点，完成"逆问题求解 = 条件图像生成"的完整论证。

## 0.3 两条路径：从贝叶斯出发

贝叶斯定理给出了后验的形式，但直接计算 $p(\mathbf{x}|\mathbf{y})$ 在高维空间中几乎不可能——归一化常数（配分函数）$Z = \int p(\mathbf{y}|\mathbf{x})p(\mathbf{x})\,d\mathbf{x}$ 的计算是指数级复杂的。于是，一个核心问题自然浮现：

> **如何处理无法直接计算的高维后验分布？**

历史上，两种策略各自演化为一条完整的理论路径：

### 采样路径：直接探索后验

既然无法写出后验的解析形式，那就用随机游走来探索它。蒙特卡洛方法的思想很简单：只要能构造一个马尔可夫链，其平稳分布恰好是目标后验，那么运行这个链足够久，就能从后验中采到样本。

这条路径的演化脉络清晰：

$$\text{MCMC} \;\rightarrow\; \text{ULA} \;\rightarrow\; \text{Langevin动力学} \;\rightarrow\; \text{得分匹配} \;\rightarrow\; \text{扩散模型（SDE视角）}$$

核心洞察是逐步演进的：从通用的Metropolis-Hastings算法，到利用梯度信息加速采样的ULA；从需要知道得分函数 $\nabla_\mathbf{x}\log p(\mathbf{x})$ 的Langevin方程，到用去噪器通过Tweedie等式学习得分函数的得分匹配方法；最终，将单步Langevin推广到多步扩散过程，便得到了扩散模型的SDE视角——通过逐步去噪完成从纯噪声到图像的生成。

### 变分路径：近似后验

既然无法精确计算后验，那就用一个简单的分布族 $q_\phi(\mathbf{x})$ 去近似它，并最大化证据下界（ELBO）来使近似尽可能接近真实后验。

这条路径同样演化有序：

$$\text{ELBO} \;\rightarrow\; \text{VAE} \;\rightarrow\; \text{层级VAE} \;\rightarrow\; \text{扩散模型（变分视角）}$$

核心洞察同样逐步推进：从Jensen不等式推导出ELBO，到用编码器-解码器架构参数化变分分布的VAE；从单层潜变量的VAE到多层潜变量的层级VAE；最终，当层级趋于无穷、编码器退化为高斯加噪过程时，层级VAE的变分下界恰好等价于扩散模型的训练目标——扩散模型就是无穷层级的层级VAE。

### 两条路径的交汇

最令人惊叹的是：这两条从不同哲学出发、经过不同数学风景的路径，最终抵达了同一个目的地——扩散模型。不仅如此，在数学上可以严格证明：

$$\boxed{\text{得分匹配损失} \equiv \text{变分下界（VLB）}}$$

采样路径学到的得分函数，与变分路径优化的下界，训练的是同一个目标的不同表达。这一等价性是全书的理论高潮，也是贝叶斯框架统一性的终极印证。

## 0.4 全书架构与章节安排

全书共六编、十八章，遵循"奠基→分径→统一→前沿→实践"的叙事结构。

### Part I 贝叶斯基石（第1—3章）

这是全书的共同出发点。三件事必须在出发前完成：定义问题、选择先验、建立优化基础。

**第1章 逆问题与贝叶斯推断。** 从图像去模糊、CT重建等具体应用出发，建立正向模型 $\mathbf{y}=\mathbf{A}\mathbf{x}+\boldsymbol{\varepsilon}$ 与贝叶斯框架。关键结论：后验 $p(\mathbf{x}|\mathbf{y})$ 是逆问题的完整解——它不仅给出最优估计，还包含全部不确定性信息。

**第2章 先验：贝叶斯推断的灵魂。** 先验是贝叶斯框架区别于纯似然方法的关键。$-\ln p(\mathbf{x}|\mathbf{y}) = \text{数据项} + \text{正则项}$——先验即正则化的概率诠释。从高斯先验（Tikhonov）到TV先验，从显式先验到隐式先验，这一章建立了"先验质量决定重建质量"的核心认知。

**第3章 从MAP到后验探索。** MAP估计给出后验众数，但丢失了不确定性。这一章建立优化工具箱（梯度下降、近端方法、ISTA/FISTA、Chambolle-Pock），同时也设置了全书的第一个分叉点：**MAP只是后验的一个点，如何获取后验的完整信息？** 两条路：采样还是近似？

```
Part I 结束时的读者位置：
┌─────────────────────────────────────────────────┐
│  后验 p(x|y) 已经形式化定义，但无法直接计算。   │
│  MAP给出了点估计，但我们想要更多。               │
│  分叉：采样还是近似？                           │
└─────────────────────────────────────────────────┘
```

### Part II 采样路径（第4—7章）

选择"直接探索后验"的路线，从MCMC出发，逐步走向扩散模型。

**第4章 MCMC与ULA算法。** 从Monte Carlo积分到Metropolis-Hastings，再到利用梯度信息的ULA。ULA的核心递推式 $\mathbf{x}^{(k+1)} = \mathbf{x}^{(k)} + \delta\,\nabla\log p(\mathbf{x}^{(k)}|\mathbf{y}) + \sqrt{2\delta}\,\mathbf{z}^{(k)}$ 是全书第一个采样器，也是Langevin动力学的离散版本。

**第5章 朗之万动力学与得分函数。** 将ULA连续化，得到Langevin SDE $\mathrm{d}\mathbf{x} = \nabla_\mathbf{x}\log p(\mathbf{x})\,\mathrm{d}t + \sqrt{2}\,\mathrm{d}\mathbf{W}$。得分函数 $\nabla_\mathbf{x}\log p(\mathbf{x})$ 成为关键量。Tweedie等式 $\nabla_\mathbf{x}\log p_\varepsilon(\mathbf{x}) = (\mathbf{D}_\varepsilon(\mathbf{x}) - \mathbf{x})/\varepsilon$ 揭示了去噪器与得分函数的深刻联系——**去噪即学习先验梯度**。PnP框架将这一洞察工程化：用学习到的去噪器替换先验梯度，驱动后验采样。

**第6章 得分匹配：从去噪中学习得分。** 得分函数不可直接计算（归一化常数 $Z$ 不可解），但可以间接学习。去噪得分匹配（DSM）的核心结果是：训练一个去噪器的目标函数，在数学上等价于训练一个得分估计器。这一章完成了"去噪器 → 得分函数"的理论闭环，也让第5章的PnP-ULA从概念走向实践。

**第7章 扩散模型：SDE视角。** 从单步Langevin到多步扩散的连续时间推广。正向SDE逐步加噪，逆向SDE逐步去噪。概率流ODE揭示了随机采样的确定性等价。DDPM是逆向SDE的特定离散方案，DDIM是概率流ODE的离散方案。这一章是采样路径的终点——通过得分匹配学到得分函数，用逆向SDE驱动采样，扩散模型便完成了从噪声到图像的生成。

```
采样路径的演进逻辑：
MCMC(通用但慢) → ULA(用梯度加速) → Langevin(连续化)
→ Score(学梯度) → Diffusion(多步推广)
```

### Part III 变分路径（第8—11章）

回到第3章的分叉点，选择"近似后验"的路线，从ELBO出发，同样走向扩散模型。

**第8章 变分推断与ELBO。** 为什么不用采样而用近似？因为MCMC在每次推理时都需要运行一条链，计算代价高。变分推断用优化代替采样：$\log p(\mathbf{x}) = \text{ELBO} + \text{KL}(q_\phi\|p)$，最大化ELBO等价于最小化近似分布与真实后验的KL散度。Fenchel共轭揭示了变分下界的优化理论根基。

**第9章 VAE与重参数化。** VAE是变分推断的神经网络化实现。编码器 $q_\phi(\mathbf{z}|\mathbf{x})$ 参数化变分分布，解码器 $p_\theta(\mathbf{x}|\mathbf{z})$ 参数化生成模型，重参数化技巧让梯度穿透随机节点。ELBO训练、KL正则化、$\beta$-VAE——这些工具构成了变分路径的基本词汇。

**第10章 层级VAE与扩散的变分推导。** 关键一步：将VAE的单层潜变量 $\mathbf{z}$ 推广为多层 $\mathbf{z}_1, \ldots, \mathbf{z}_L$，形成马尔可夫推断链。当编码器选择为高斯加噪过程时，层级VAE的结构与扩散模型的前向过程完全一致。随着层数 $L \to \infty$，离散的层级VAE连续化为扩散过程，层级ELBO趋近于扩散模型的变分下界。**扩散模型就是无穷层级的层级VAE。**

**第11章 扩散模型：变分视角。** 从变分下界出发推导DDPM的训练目标。VLB分解为 $L_T + L_{t-1} + L_0$，三种参数化（噪声预测 $\boldsymbol{\varepsilon}_\theta$、得分预测 $\mathbf{s}_\theta$、数据预测 $\hat{\mathbf{x}}_0$）从不同角度描述同一个去噪过程。DDPM的简化训练目标 $\|\boldsymbol{\varepsilon} - \boldsymbol{\varepsilon}_\theta(\mathbf{x}_t, t)\|^2$ 是VLB的加权简化，在实践中更为稳定。

```
变分路径的演进逻辑：
ELBO(下界) → VAE(神经网络化) → 层级VAE(多层推广)
→ Diffusion(VLB, 无穷层极限)
```

### Part IV 统一（第12—13章）

两条路径在扩散模型处交汇。这一编完成全书的理论闭环。

**第12章 Score ≡ ELBO：殊途同归。** 这是全书的高潮章节。采样路径的终点是"通过得分匹配训练得分函数"，变分路径的终点是"通过变分下界训练去噪网络"。本章证明：**去噪得分匹配（DSM）损失与变分下界（VLB）在数学上等价**。同一个扩散模型，用得分匹配训练还是用变分下界训练，优化的是同一个目标的不同表达。这不是巧合，而是贝叶斯框架内在统一性的必然结果。

**第13章 条件生成与逆问题求解。** 回到第1章的逆问题，但现在手中有了扩散模型这一强大工具。条件扩散模型直接从 $p(\mathbf{x}|\mathbf{y})$ 采样，分类器引导与无分类器引导提供了生成质量与多样性的可控权衡。DDRM、DiffPIR、DPS等算法将扩散先验嵌入逆问题求解流程。至此，全书的叙事完成闭环：**从逆问题出发，经过贝叶斯→采样/变分→扩散，最终回到逆问题——但现在，我们有了后验采样的完整能力。**

```
闭环结构：
第1章定义逆问题 → 第2-3章建立贝叶斯+优化基础
→ 第4-7章(采样路径) → 第8-11章(变分路径)
→ 第12章两条路径统一 → 第13章条件生成=逆问题求解 ← 回到第1章
```

### Part V 前沿（第14章）

**第14章 Flow Matching与最优传输。** 扩散模型并非生成模型的终局。Flow Matching从最优传输的视角重新审视生成问题：与其用随机扩散逐步去噪，不如学习一条从噪声到数据的最短路径。连续归一化流（CNF）、条件Flow Matching、Rectified Flow——这些方法用向量场替代得分函数，用确定性流替代随机扩散，在某些场景下展现出更高效的采样路径。SD3与Flux等前沿模型正是Rectified Flow与Transformer架构的结合。

### Part VI 实践与应用（第15—18章）

理论落地为代码。这一编覆盖从架构选择到领域应用的完整实践链。

**第15章 扩散模型的架构实践：UNet → DiT。** 去噪网络的架构选择：从卷积UNet到Vision Transformer。DiT的核心设计（Patchify、adaLN-Zero）将Transformer引入扩散模型，这是架构选择而非新理论——扩散的数学框架不变，只是去噪网络从卷积换成了注意力。

**第16章 CT/MRI重建。** 扩散模型在医学成像中的应用。CT重建涉及Radon变换、滤波反投影、有限角不适定性；MRI重建涉及k-space采样、压缩感知、欠采样掩码。扩散先验（DiffPIR）为这些经典逆问题带来了新的求解范式。

**第17章 自监督学习与等变架构。** 当没有干净训练数据时如何学习去噪器？Noise2Self、SURE、R2R等自监督方法无需配对数据即可训练。等变架构则将物理对称性（平移、旋转）编码进网络，确保测量一致性。

**第18章 综合项目：用扩散模型求解自定义逆问题。** 全书知识的整合：定义前向算子、选择扩散先验、运行条件采样、量化不确定性。读者将亲手完成从贝叶斯建模到扩散求解的完整流程。

## 0.5 五座理论桥梁

在全书的叙事中，有五座关键的"桥梁"连接了看似不同的概念。它们既是各章节之间的理论纽带，也是理解全书统一性的钥匙。

**桥梁一：PnP去噪器 → 得分函数估计器（Tweedie等式）。** 第2章引入贝叶斯去噪器作为隐式先验，第5章通过Tweedie等式揭示去噪器与得分函数的等价性，第6章用得分匹配训练去噪器——"去噪即学习先验梯度"这一洞察贯穿采样路径。

**桥梁二：ULA朗之万采样 → 扩散模型。** 第4章的ULA是单步Langevin采样，第7章的扩散模型是多步Langevin的连续时间推广。扩散过程不是凭空发明的，而是Langevin动力学的自然延伸——从单步到多步，从离散到连续。

**桥梁三："离散→连续→再离散"螺旋。** ULA（离散迭代）→ Langevin SDE（连续方程）→ Euler-Maruyama离散化（再离散化）→ DDPM（特定离散方案）。这不是循环，而是螺旋上升：每一次"离散化"都在更高层次上重新理解了采样算法。第4章与第7章通过这一螺旋紧密相连。

**桥梁四：VAE编码/解码 → 扩散加噪/去噪。** VAE的编码器将数据映射到潜空间，解码器从潜空间恢复数据。当潜变量层数趋于无穷且编码器固定为高斯加噪时，编码器变成扩散的前向过程，解码器变成逆向去噪过程——**扩散 = 无穷层级的VAE**。第9章与第10-11章通过这一桥梁连接。

**桥梁五：条件生成 = 逆问题求解。** 这是全书的终极桥梁。从 $p(\mathbf{x}|\mathbf{y})$ 采样的能力，既解决了条件生成问题（给定文本/类别生成图像），也解决了逆问题（给定退化观测恢复图像）。第13章通过这一桥梁完成从第1章到第13章的闭环。

## 0.6 本书的定位与阅读建议

### 目标读者

本书面向具备线性代数、概率论与基础微积分知识的读者，不要求先修逆问题或生成模型课程。如果你有以下任一背景，本书将特别适合：

- 从事图像处理或计算成像的研究者，希望理解扩散模型的理论基础；
- 研究生成模型的读者，希望从贝叶斯推断的视角获得更深的理解；
- 对逆问题与生成模型之间的联系感到好奇的学生或工程师。

全书附有丰富的代码实验（基于Python + PyTorch + deepinv库），理论与实践交替推进。

### 阅读路径

**线性阅读（推荐首次阅读）：** 第1—13章按顺序阅读，完整体验"奠基→分径→统一→闭环"的叙事。第14—18章可根据兴趣选读。

**采样路径优先：** 如果你更关心扩散模型如何从采样理论中自然涌现，可以阅读第1—3章→第4—7章→第12—13章，跳过变分路径，之后再回填第8—11章。

**变分路径优先：** 如果你更关心扩散模型的似然视角和VAE联系，可以阅读第1—3章→第8—11章→第12—13章，跳过采样路径，之后再回填第4—7章。

**实践导向：** 如果你急于动手，可以阅读第1—3章→第7章→第13章→第15—18章，快速建立贝叶斯直觉、了解扩散模型、动手实践，之后再补充理论细节。

无论选择哪条路径，第12章"殊途同归"是全书的必经之地——只有在此处，两条路径的统一性才得以完整展现。
