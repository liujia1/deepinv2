# 第6章 得分匹配：从去噪中学习得分 — 提纲

> **章节定位**：承接第5章的Tweedie等式——去噪器可以提取得分函数，但前提是我们有一个好的去噪器。本章回答核心问题：**如何从数据中系统地学习得分函数？** 得分匹配（Score Matching）是答案——它提供了一套无需归一化常数的训练框架，使得得分函数可以从数据中直接学习。从ESM的原始想法，到ISM的分部积分技巧，再到DSM的实用突破和SSM的随机投影方案，每一步演进都源于同一个动机：**绕过归一化常数Z的不可计算性**。最终，多尺度得分匹配（NCSN）将单一噪声水平扩展为噪声调度，架起了从得分匹配到扩散模型的关键桥梁。本章是采样路径的核心环节——从"得分函数不可得"到"得分函数可学习"，为第7章的扩散模型铺平道路。

> **逆问题动机**：第5章建立了PnP-ULA框架——用去噪器通过Tweedie等式提供先验得分，但去噪器的训练需要什么目标函数？得分匹配给出了答案：训练一个网络近似得分函数，等价于训练一个去噪器。更深层地，逆问题中"先验p(x)未知但数据可获取"这一现实，正是得分匹配存在的根本理由——我们无法写出p(x)的解析式，但可以从数据中学习其得分函数。

> **叙事主线**：为什么需要学习得分(6.1) → ESM：直接方法及其失败(6.2) → DSM：实用突破(6.3) → SSM：替代路径(6.4) → 多尺度得分匹配：从单噪声到噪声调度(6.5) → 去噪器架构实践(6.6) → 用学习得分驱动采样(6.7)

## 6.0 本章导读：从"得分不可得"到"得分可学习"

第5章揭示了Langevin动力学的核心驱动力——得分函数 $s(x) = \nabla_x\log p(x)$，并通过Tweedie等式架起了从去噪器到得分函数的桥梁。然而，一个根本性的问题仍未解决：**去噪器本身从何而来？** 更一般地，**如何从数据中学习得分函数？**

本章围绕这个问题展开，走一条"尝试→失败→突破→扩展→实践→应用"的路径：

**为什么需要学习得分**（6.1）：得分函数不可直接计算——归一化常数 $Z$ 的不可解性是根本障碍。直接计算 $\nabla\log p(x)$ 需要知道 $p(x)$ 的解析形式，但自然图像的分布远比任何参数化模型复杂。然而，得分函数有一个关键优势：它不需要归一化常数——$\nabla\log p(x) = \nabla\log \tilde{p}(x)$，其中 $\tilde{p}(x) = Zp(x)$。这一"无需Z"的性质，是得分匹配所有方法的出发点。

**显式得分匹配与隐式得分匹配**（6.2）：ESM（Explicit Score Matching）是最直接的想法——训练网络 $s_\theta(x)$ 近似 $\nabla\log p(x)$，但目标函数需要 $\nabla\log p_{\text{data}}(x)$ 作为监督信号，而这正是我们不知道的。ISM（Implicit Score Matching）通过分部积分消去了 $\nabla\log p(x)$，但引入了Jacobian矩阵的迹 $\text{Tr}(\nabla_x s_\theta(x))$——在高维空间中计算代价为 $O(d)$ 或 $O(d^2)$，对图像这样的高维数据不可行。

**去噪得分匹配**（6.3）：DSM（Denoising Score Matching）是实用突破——用噪声扰动分布替换原始分布，目标函数中的条件得分 $\nabla\log q_\sigma(\tilde{x}|x)$ 有闭式解。更惊人的是，Vincent (2011) 证明 $\mathcal{J}_{\text{DSM}}(\theta) = \mathcal{J}_{\text{ESM}}(\theta) + C$——DSM与ESM优化的是同一个目标，仅差一个与 $\theta$ 无关的常数。DSM的训练目标等价于：给定含噪图像 $\tilde{x} = x + \sigma z$，预测噪声 $z/\sigma$——这正是去噪！去噪=得分匹配的等价性，呼应了第5章Tweedie等式的洞见。

**切片得分匹配**（6.4）：SSM（Sliced Score Matching）是ISM的随机化版本——用Hutchinson迹估计替代精确的Jacobian迹计算，将 $O(d^2)$ 降为 $O(d)$ 的随机估计。SSM估计的是未扰动数据分布的得分，与DSM形成互补。四种方法（ESM/ISM/DSM/SSM）构成完整的得分匹配谱系。

**多尺度得分匹配**（6.5）：单一噪声水平的得分匹配在实践中效果不佳——数据集中在低维流形上，低密度区域的得分估计不准确。Song & Ermon (2019) 的关键洞见：使用多个噪声水平 $\sigma_1 > \sigma_2 > \cdots > \sigma_L$，大噪声"填满"低密度区域，小噪声保留细节。NCSN（Noise Conditional Score Network）是第一个成功的多尺度得分匹配框架，也是扩散模型的直接前身。

**去噪器作为得分估计器**（6.6）：实践层面——得分网络需要什么架构？DRUNet通过条件噪声水平输入实现"一网多噪"，三种参数化（$\varepsilon$预测/$s$预测/$x_0$预测）各有优劣。Tweedie等式在实践中将训练好的去噪器转化为得分估计器。

**用学习到的得分驱动采样**（6.7）：从理论到应用——学习到的得分函数如何驱动采样？退火Langevin动力学（Annealed Langevin Dynamics）是多尺度得分匹配的自然采样方法，也是扩散采样的离散版前身。实验对比：学习得分驱动的PnP-ULA vs 手工先验，展示数据驱动先验的优势。

```
得分不可得(6.1) → ESM失败(6.2) → DSM突破(6.3) → SSM替代(6.4) → 多尺度扩展(6.5) → 架构实践(6.6) → 采样应用(6.7)
```

本章结束时，读者将理解：得分函数可以从数据中系统学习（得分匹配），而学习得分等价于训练去噪器（DSM=Tweedie），多尺度得分匹配架起了通往扩散模型的桥梁（NCSN→DDPM）。这一章完成了从"得分不可得"到"得分可学习"的跨越，为第7章的扩散模型铺平道路——**采样路径继续向扩散模型演化**。

## 6.1 为什么需要学习得分？

**核心观点**：Langevin动力学以得分函数 $\nabla\log p(x)$ 为驱动力，但得分函数在逆问题中通常不可直接计算——归一化常数 $Z$ 的不可解性和先验分布的复杂性是双重障碍。然而，得分函数具有"无需Z"的关键优势，使得从数据中间接学习成为可能——这正是得分匹配的出发点。

- **回顾：得分函数是Langevin的驱动力**
  - ULA递推式：$X_{m+1} = X_m + \delta\,\nabla\log p(X_m|y) + \sqrt{2\delta}\,Z_{m+1}$
  - 后验得分分解：$\nabla\log p(x|y) = \nabla\log p(y|x) + \nabla\log p(x)$
  - 似然得分 $\nabla\log p(y|x)$ 通常可计算（已知正向模型和噪声模型）
  - **先验得分 $\nabla\log p(x)$ 是瓶颈**——第5章已指出

- **归一化常数的困境**
  - 先验通常写作 $p(x) = \frac{1}{Z}\exp(-R(x))$，其中 $Z = \int\exp(-R(x))\,dx$
  - 看似 $Z$ 被消去：$\nabla\log p(x) = -\nabla R(x)$
  - 但对于"看起来像自然图像"这样的复杂先验，$R(x)$ 本身没有解析形式——$p(x)$ 的结构完全未知
  - 这是与第1-3章的根本区别：经典方法（Tikhonov/TV）有显式 $R(x)$，但复杂先验没有

- **得分函数的关键优势：无需归一化常数**
  - 对任意正比例函数 $\tilde{p}(x) = Z\,p(x)$：$\nabla\log \tilde{p}(x) = \nabla\log p(x)$
  - 这意味着：不需要知道 $Z$，就能计算得分函数
  - 这是得分匹配方法的基石——如果我们能找到一种只依赖得分函数的训练方法，就绕过了 $Z$ 的障碍

- **从数据中学习得分的可能性**
  - 数据样本 $\{x_i\}_{i=1}^N \sim p(x)$ 隐含了 $p(x)$ 的信息
  - 目标：训练参数化网络 $s_\theta(x)$，使 $s_\theta(x) \approx \nabla\log p(x)$
  - 核心困难：监督信号 $\nabla\log p(x)$ 不可得——不像分类任务有标签
  - 得分匹配的思路：设计目标函数，不需要 $\nabla\log p(x)$ 作为监督信号

- **本章要回答的问题**
  - 如何设计不依赖 $\nabla\log p(x)$ 的训练目标？（6.2-6.4）
  - 单一噪声水平够不够？为什么需要多尺度？（6.5）
  - 如何在实践中实现得分估计器？（6.6）
  - 学习到的得分能否驱动有效的采样？（6.7）

**来源**：Pereyra L1 P58-60; Hyvärinen (2005); Song & Ermon (2019)

得分函数有"无需Z"的关键优势，但如何利用这一优势设计训练方法？最直接的想法是显式得分匹配——让网络直接逼近 $\nabla\log p(x)$。

## 6.2 显式得分匹配（ESM）与隐式得分匹配（ISM）

**核心观点**：ESM试图直接训练 $s_\theta(x) \approx \nabla\log p(x)$，但目标函数需要 $\nabla\log p_{\text{data}}(x)$ 作为监督信号——这恰恰是我们不知道的。ISM通过分部积分技巧消去了 $\nabla\log p(x)$，但引入了Jacobian迹的计算，在高维空间中代价过高。ESM的失败和ISM的瓶颈共同指向了需要更实用的替代方案。

- **显式得分匹配（ESM）**
  - 目标：训练 $s_\theta:\mathbb{R}^d \to \mathbb{R}^d$ 使得 $s_\theta(x) \approx \nabla_x\log p(x)$
  - ESM目标函数：
    $$\mathcal{J}_{\text{ESM}}(\theta) = \frac{1}{2}\mathbb{E}_{p(x)}\left[\|s_\theta(x) - \nabla_x\log p(x)\|^2\right]$$
  - 最优解：$s_{\theta^*}(x) = \nabla_x\log p(x)$（Fisher一致性）
  - **不可行性**：$\nabla_x\log p(x)$ 正是我们要学习的——无法用它作为监督信号
  - 实践中的近似：用核密度估计 $q_h(x) \approx p(x)$，则 $\nabla\log q_h(x)$ 可计算
    - 但核密度估计在高维空间中效果极差（维数灾难）
    - 高维情况下 $q_h$ 与 $p$ 的偏差导致ESM目标偏离真实得分

- **隐式得分匹配（ISM）：分部积分的突破**
  - Hyvärinen (2005) 的关键观察：ESM目标可以重写为不含 $\nabla\log p(x)$ 的形式
  - 展开 $\|s_\theta(x) - \nabla\log p(x)\|^2 = \|s_\theta(x)\|^2 - 2s_\theta(x)^T\nabla\log p(x) + \|\nabla\log p(x)\|^2$
  - 关键步骤：对交叉项用分部积分
    $$\mathbb{E}_{p(x)}[s_\theta(x)^T\nabla\log p(x)] = -\mathbb{E}_{p(x)}[\nabla\cdot s_\theta(x)]$$
    - 其中 $\nabla\cdot s_\theta(x) = \text{Tr}(\nabla_x s_\theta(x))$ 是 $s_\theta$ 的散度
    - 这一分部积分是ISM的核心——将 $\nabla\log p(x)$ 转移为对 $s_\theta$ 的导数
  - ISM目标函数（第三项与 $\theta$ 无关，可忽略）：
    $$\boxed{\mathcal{J}_{\text{ISM}}(\theta) = \mathbb{E}_{p(x)}\left[\text{Tr}(\nabla_x s_\theta(x)) + \frac{1}{2}\|s_\theta(x)\|^2\right]}$$
  - 不需要 $\nabla\log p(x)$！只需要数据样本和 $s_\theta$ 的Jacobian
  - **最优性**：$\mathcal{J}_{\text{ISM}}(\theta) = \mathcal{J}_{\text{ESM}}(\theta) + C$（与 $\theta$ 无关的常数）

- **ISM的计算瓶颈：Jacobian迹**
  - $\text{Tr}(\nabla_x s_\theta(x))$ 需要计算 $s_\theta$ 的Jacobian矩阵的迹
  - 直接计算：$O(d^2)$ 前向传播——对 $d = 256 \times 256 = 65536$ 的图像不可行
  - 逐列计算：$d$ 次前向传播——同样不可行
  - **ISM在理论上是优雅的，但在高维实践中不可用**
  - 这一瓶颈催生了两种解决方案：
    - DSM：完全避免Jacobian计算（6.3节）
    - SSM：用随机估计替代精确计算（6.4节）

- **ESM与ISM的关系图**
  - ESM：直接但不可行（需要 $\nabla\log p(x)$）
  - ISM：消去 $\nabla\log p(x)$ 但引入Jacobian迹（高维不可行）
  - 两条路都走不通 → 需要新的思路

**来源**：Hyvärinen (2005); Vincent (2011); Song & Ermon (2019); Tutorial_Diffusion_Imaging_Vision Sec 3.3

至此，ISM的Jacobian迹计算在高维空间中不可行，但两条截然不同的路径可以绕过这一障碍：DSM通过噪声扰动完全避免Jacobian计算，SSM通过随机投影降低计算代价。我们先看DSM——它是实践中最成功的方法。

## 6.3 去噪得分匹配（DSM）

**核心观点**：DSM（Denoising Score Matching）是得分匹配的实用突破——通过引入噪声扰动，目标函数中的条件得分有闭式解，完全避免了Jacobian迹的计算。更关键的是，Vincent (2011) 证明DSM与ESM优化的是同一个目标（仅差常数），且DSM的训练目标等价于去噪——给定含噪观测预测添加的噪声。这呼应了第5章Tweedie等式的洞见：去噪=得分估计。

- **核心思想：噪声扰动分布**
  - 不直接估计 $s(x) = \nabla\log p(x)$，而是估计噪声扰动后的得分 $s_\sigma(x) = \nabla\log p_\sigma(x)$
  - 噪声扰动分布：$p_\sigma(\tilde{x}) = \int p(x)\,\mathcal{N}(\tilde{x}|x, \sigma^2 I)\,dx$
  - 第5章已讨论噪声扰动的好处：光滑化、全覆盖、与去噪器天然联系
  - DSM的额外好处：**条件得分 $\nabla_{\tilde{x}}\log q_\sigma(\tilde{x}|x)$ 有闭式解**

- **DSM目标函数推导**
  - 定义联合分布 $q_\sigma(\tilde{x}, x) = p(x)\,q_\sigma(\tilde{x}|x)$
  - DSM目标函数：
    $$\mathcal{J}_{\text{DSM}}(\theta) = \frac{1}{2}\mathbb{E}_{q_\sigma(\tilde{x}, x)}\left[\left\|s_\theta(\tilde{x}) - \nabla_{\tilde{x}}\log q_\sigma(\tilde{x}|x)\right\|^2\right]$$
  - 条件得分的闭式解：$q_\sigma(\tilde{x}|x) = \mathcal{N}(\tilde{x}|x, \sigma^2 I)$，故
    $$\nabla_{\tilde{x}}\log q_\sigma(\tilde{x}|x) = -\frac{\tilde{x} - x}{\sigma^2} = -\frac{z}{\sigma}$$
    其中 $z = (\tilde{x} - x)/\sigma \sim \mathcal{N}(0, I)$
  - 代入得DSM目标的实用形式：
    $$\boxed{\mathcal{J}_{\text{DSM}}(\theta) = \frac{1}{2}\mathbb{E}_{p(x)}\mathbb{E}_{z \sim \mathcal{N}(0,I)}\left[\left\|s_\theta(x + \sigma z) + \frac{z}{\sigma}\right\|^2\right]}$$
  - 解读：$s_\theta$ 接收含噪图像 $x + \sigma z$，预测 $-z/\sigma$（即噪声方向的反向归一化）

- **DSM与ESM的等价性（Vincent 2011定理）**
  - **定理**：$\mathcal{J}_{\text{DSM}}(\theta) = \mathcal{J}_{\text{ESM}}(\theta) + C(\sigma)$
    - $C(\sigma)$ 是与 $\theta$ 无关的常数
    - 证明概要（详细证明见附录6A）：
      1. 展开 $\mathcal{J}_{\text{DSM}}$ 并利用 $q_\sigma(\tilde{x}) = \int p(x)q_\sigma(\tilde{x}|x)\,dx$
      2. 交叉项中条件期望 $\mathbb{E}_{q_\sigma(x|\tilde{x})}[\nabla\log q_\sigma(\tilde{x}|x)] = \nabla\log q_\sigma(\tilde{x}) - \nabla\log p(x)$
      3. 整理后得到 $\mathcal{J}_{\text{DSM}} = \mathcal{J}_{\text{ESM}} + C$
  - **重要性**：DSM的最优解 $s_{\theta^*}$ 同时也是ESM的最优解（在噪声扰动分布 $p_\sigma$ 上）
  - 当 $\sigma$ 较小时，$p_\sigma \approx p$，DSM最优解近似真实得分

- **去噪 = 得分匹配：两种等价视角**
  - DSM目标：训练 $s_\theta$ 从 $x + \sigma z$ 预测 $-z/\sigma$
  - 去噪目标：训练 $D_\phi$ 从 $x + \sigma z$ 预测 $x$（即 $D_\phi(x + \sigma z) \approx x$）
  - 两者的联系（通过Tweedie等式，第5章5.3节）：
    - $s_\sigma(\tilde{x}) = \nabla\log p_\sigma(\tilde{x}) = \frac{D_\sigma^*(\tilde{x}) - \tilde{x}}{\sigma^2}$
    - 因此：$D_\sigma^*(\tilde{x}) = \tilde{x} + \sigma^2 s_\sigma(\tilde{x})$
    - 训练得分网络 $s_\theta$ 等价于训练去噪网络 $D_\phi$，两者仅差一个线性变换
  - **统一认识**：
    - 得分匹配视角：学习 $\nabla\log p_\sigma(x)$ → 用于Langevin采样
    - 去噪视角：学习 $\mathbb{E}[x|\tilde{x}]$ → 用于PnP重建
    - 两者是同一问题的两种表述，Tweedie等式是桥梁
  - **参数化的选择**
    - 直接预测得分 $s_\theta$：DSM原始形式
    - 预测噪声 $\varepsilon_\theta = -\sigma s_\theta$：DDPM的参数化（→第7/11章）
    - 预测原始信号 $D_\theta = \tilde{x} + \sigma^2 s_\theta$：去噪器参数化
    - 三者等价，但训练动态不同（→6.6节深入讨论）

- **DSM的训练算法**
  - 输入：训练数据 $\{x_i\}_{i=1}^N$，噪声水平 $\sigma$
  - 对每个小批量：
    1. 采样 $x \sim \{x_i\}$
    2. 采样 $z \sim \mathcal{N}(0, I)$
    3. 计算 $\tilde{x} = x + \sigma z$
    4. 计算损失 $\ell(\theta) = \frac{1}{2}\|s_\theta(\tilde{x}) + z/\sigma\|^2$
    5. 梯度更新 $\theta$
  - 训练完成后，$s_\theta(\cdot) \approx \nabla\log p_\sigma(\cdot)$

**来源**：Vincent (2011); Hyvärinen (2005); Tutorial_Diffusion_Imaging_Vision Sec 3.3; Song & Ermon (2019)

DSM通过噪声扰动巧妙避免了Jacobian迹的计算，但它估计的是噪声扰动分布 $p_\sigma$ 的得分，而非原始分布 $p$ 的得分。那么，是否存在一种方法，既能估计原始分布的得分，又不需要计算Jacobian迹？切片得分匹配给出了答案。

## 6.4 切片得分匹配（SSM）与Hutchinson迹估计

**核心观点**：ISM需要计算 $\text{Tr}(\nabla_x s_\theta(x))$，在高维空间中代价过高。Hutchinson迹估计提供了一种随机近似——用随机投影将精确迹降为无偏估计，将 $O(d^2)$ 降为 $O(M)$（$M$ 为投影次数）。基于此，SSM（Sliced Score Matching）用随机方向的得分匹配替代全空间匹配，估计未扰动分布的得分，与DSM形成互补。四种方法（ESM/ISM/DSM/SSM）构成完整的得分匹配谱系。

- **Hutchinson迹估计**
  - 定理：对任意方阵 $A \in \mathbb{R}^{d \times d}$ 和随机向量 $v$ 满足 $\mathbb{E}[vv^T] = I$：
    $$\text{Tr}(A) = \mathbb{E}[v^T A v]$$
  - 无偏估计：$\widehat{\text{Tr}}(A) = \frac{1}{M}\sum_{j=1}^M v_j^T A v_j$，其中 $v_j \sim p_v$
  - 计算优势：$v^T A v = v^T(\nabla_x s_\theta(x))v$ 可通过一次前向自动微分计算，不需要构造完整Jacobian
  - $v$ 的选择：标准高斯 $v \sim \mathcal{N}(0, I)$ 或Rademacher $v \in \{-1, +1\}^d$
  - 方差分析：Rademacher向量的方差更低
  - 证明见附录6B

- **从ISM到SSM：用随机投影替换精确迹**
  - ISM目标：$\mathbb{E}_{p(x)}[\text{Tr}(\nabla_x s_\theta(x)) + \frac{1}{2}\|s_\theta(x)\|^2]$
  - 用Hutchinson估计替换 $\text{Tr}(\nabla_x s_\theta(x)) = \mathbb{E}_v[v^T\nabla_x s_\theta(x)\,v]$
  - SSM目标函数：
    $$\boxed{\mathcal{J}_{\text{SSM}}(\theta) = \mathbb{E}_{p(x)}\mathbb{E}_{p_v}\left[v^T\nabla_x s_\theta(x)\,v + \frac{1}{2}\|s_\theta(x)\|^2\right]}$$
  - $v^T\nabla_x s_\theta(x)\,v$ 可通过前向自动微分高效计算：
    - 令 $g(t) = v^T s_\theta(x + tv)|_{t=0}$，则 $g'(0) = v^T\nabla_x s_\theta(x)\,v$
    - 仅需一次前向传播 + 一次前向自动微分

- **SSM的特点与优势**
  - 估计未扰动分布的得分：$\nabla\log p(x)$ 而非 $\nabla\log p_\sigma(x)$
  - 不引入额外噪声——适用于需要精确得分的场景
  - 计算量：每次迭代需要 $M$ 次前向自动微分（$M \ll d$）
  - 与DSM的对比：SSM更精确但计算量约4倍于DSM

- **四种得分匹配方法的统一对比**

  | 方法 | 目标函数 | 需要 $\nabla\log p$ | Jacobian迹 | 估计的得分 | 计算量 |
  |---|---|---|---|---|---|
  | ESM | $\frac{1}{2}\mathbb{E}\|s_\theta - \nabla\log p\|^2$ | 是 | 否 | $\nabla\log p$ | 不可行 |
  | ISM | $\mathbb{E}[\text{Tr}(\nabla s_\theta) + \frac{1}{2}\|s_\theta\|^2]$ | 否 | 精确计算 | $\nabla\log p$ | $O(d^2)$ |
  | DSM | $\frac{1}{2}\mathbb{E}\|s_\theta + z/\sigma\|^2$ | 否 | 否 | $\nabla\log p_\sigma$ | $O(1)$ |
  | SSM | $\mathbb{E}[v^T\nabla s_\theta v + \frac{1}{2}\|s_\theta\|^2]$ | 否 | 随机估计 | $\nabla\log p$ | $O(M)$ |

  - **关键洞察**：ESM和ISM估计原始分布的得分，但不可行或代价高；DSM通过噪声扰动降为 $O(1)$ 但估计扰动分布的得分；SSM通过随机投影降为 $O(M)$ 且估计原始得分
  - 实践中的选择：**DSM为主流**（简单高效），**SSM为理论互补**（估计精确得分）

**来源**：Song et al. (2019) Sliced Score Matching; Hutchinson (1990); Hyvärinen (2005)

至此，DSM是实践中最成功的得分匹配方法，但单一噪声水平的DSM存在一个根本问题：低密度区域的得分估计不准确。这源于数据分布的几何结构——高维数据往往集中在低维流形上，解决这一问题需要多尺度策略。

## 6.5 多尺度得分匹配：从单一噪声到噪声条件网络

**核心观点**：单一噪声水平的得分匹配在实践中面临"低密度区域"困境——数据集中在低维流形上，远离流形的区域没有足够训练样本来准确估计得分。Song & Ermon (2019) 的关键洞见：使用多个噪声水平 $\sigma_1 > \sigma_2 > \cdots > \sigma_L$，大噪声"填满"低密度区域保证全局覆盖，小噪声保留分布细节保证局部精度。NCSN（Noise Conditional Score Network）是第一个成功的多尺度得分匹配框架——噪声条件网络 $s_\theta(x, \sigma_i)$ 同时学习所有噪声水平的得分，退火Langevin动力学从大噪声到小噪声逐步采样。NCSN是扩散模型的直接前身：噪声调度即扩散时间步，退火采样即扩散去噪。

- **单一噪声水平的困境**
  - **低密度区域问题**：数据集中在低维流形上，远离流形的区域样本稀少
    - 得分估计在不充分覆盖的区域不准确
    - Langevin采样时，粒子可能"迷路"在低密度区域
  - **流形假设（Manifold Hypothesis）**：高维数据（如图像）实际分布在内嵌于高维空间的低维流形上
    - 流形之外，$p(x) = 0$，得分函数无定义
    - 即使 $p(x) > 0$ 但很小，训练样本不足也导致估计不准确
  - **实验证据**（Song & Ermon 2019, Figure 1）：
    - CIFAR-10上，无噪声扰动时SSM损失不收敛
    - 加入小的高斯扰动后，训练稳定收敛
    - 但噪声过大会模糊分布细节

- **多噪声水平策略**
  - 核心思想：用一系列噪声水平 $\sigma_1 > \sigma_2 > \cdots > \sigma_L$ 覆盖不同尺度
    - 大噪声 $\sigma_1$：填满低密度区域，得分全局可估
    - 中噪声 $\sigma_i$：过渡尺度
    - 小噪声 $\sigma_L$：保留分布细节，得分局部精确
  - 每个噪声水平训练一个得分估计器 $s_\theta(x, \sigma_i) \approx \nabla\log p_{\sigma_i}(x)$
  - 采样时从大噪声到小噪声逐步精细化——退火Langevin动力学

- **NCSN（Noise Conditional Score Network）训练**
  - 架构：单一网络 $s_\theta(x, \sigma)$，以噪声水平 $\sigma$ 为条件输入
  - 训练目标（多噪声水平DSM）：
    $$\mathcal{J}_{\text{NCSN}}(\theta) = \frac{1}{L}\sum_{i=1}^L \lambda(\sigma_i)\,\ell(\theta; \sigma_i)$$
  - 单噪声水平损失：
    $$\ell(\theta; \sigma) = \frac{1}{2}\mathbb{E}_{p(x)}\mathbb{E}_{z \sim \mathcal{N}(0,I)}\left[\left\|s_\theta(x + \sigma z, \sigma) + \frac{z}{\sigma}\right\|^2\right]$$
  - 加权函数 $\lambda(\sigma)$ 的选择：
    - 目标：使不同噪声水平的损失量级相当
    - 经验选择：$\lambda(\sigma) = \sigma^2$（使 $\|\sigma \cdot s_\theta(x, \sigma)\|$ 量级一致）
  - 噪声调度 $\{\sigma_i\}$ 的设计：
    - 几何级数：$\sigma_1/\sigma_2 = \sigma_2/\sigma_3 = \cdots = r > 1$
    - $\sigma_1$ 足够大以覆盖低密度区域
    - $\sigma_L$ 足够小以保留分布细节

- **退火Langevin动力学（Annealed Langevin Dynamics）**
  - 从大噪声得分到小噪声得分的逐步采样
  - 算法流程：
    1. 初始化 $x_0$（随机噪声）
    2. 对每个噪声水平 $i = 1, 2, \ldots, L$：
       - 运行 $T_i$ 步Langevin采样：
         $$x_{t+1} = x_t + \frac{\alpha_i}{2}s_\theta(x_t, \sigma_i) + \sqrt{\alpha_i}\,z_t$$
       - 步长 $\alpha_i = \sigma_i^2 / \sigma_L^2 \cdot \epsilon$（大噪声时大步长，小噪声时小步长）
    3. 输出最终样本 $x_{T_L}$
  - 直觉：先在高噪声的"粗糙地形"中快速移动到高概率区域，再在低噪声的"精细地形"中精细调整
  - **与扩散采样的对应**：退火Langevin动力学是第7章扩散采样的离散版前身

- **从NCSN到扩散模型的桥梁**
  - NCSN的噪声调度 $\{\sigma_i\}$ → 扩散模型的时间步 $\{t_i\}$
  - NCSN的条件得分 $s_\theta(x, \sigma_i)$ → 扩散模型的时间条件得分 $s_\theta(x, t)$
  - 退火Langevin → 离散扩散采样
  - 关键区别：NCSN是"跳跃式"切换噪声水平，扩散模型是"连续"变化——第7章将展示这种连续化的数学框架
  - **核心洞见**：NCSN = 离散化扩散模型，扩散模型 = 连续化NCSN

**来源**：Song & Ermon (2019) NCSN; Song & Ermon (2020) NCSNv2; Tutorial_Diffusion_Imaging_Vision Sec 3.3

NCSN将得分匹配从单一噪声水平扩展到多噪声水平，架起了通往扩散模型的桥梁。然而理论框架需要工程实现：得分网络用什么架构？条件噪声水平如何输入？三种参数化如何选择？

## 6.6 去噪器作为得分估计器：实践与架构

**核心观点**：得分匹配的理论框架需要工程实现。本节讨论实践层面：得分网络用什么架构，条件噪声水平如何输入，三种参数化如何选择，Tweedie等式在实践中如何将训练好的去噪器转化为得分估计器。DRUNet是当前最常用的条件去噪器架构，其"噪声水平条件输入"设计使得单一网络可以处理多个噪声水平——这正是多尺度得分匹配和扩散模型所需的。

- **得分网络的架构选择**
  - 从通用到专用：MLP → CNN → UNet → DRUNet
  - UNet架构回顾（第2章2.4节简要提及）
    - 编码器-解码器结构 + 跳跃连接
    - 多尺度特征提取，适合图像去噪
  - DRUNet的关键设计（Zhang et al. 2021）
    - 在UNet基础上增加噪声水平条件输入
    - 条件输入方式：将 $\sigma$ 编码后注入每个残差块
    - **一网多噪**：同一个网络处理不同噪声水平 $\sigma$
    - 这对应于NCSN中 $s_\theta(x, \sigma)$ 的条件得分设计
  - 架构演进路线：DnCNN（固定噪声）→ UNet → DRUNet（条件噪声）→ DiT（→第15章）

- **三种参数化：得分预测、噪声预测与信号预测**
  - 同一个去噪问题，三种等价的参数化方式：
    1. **得分预测**：$s_\theta(\tilde{x}, \sigma) \approx \nabla\log p_\sigma(\tilde{x})$
       - DSM训练目标：$\|s_\theta(x+\sigma z, \sigma) + z/\sigma\|^2$
       - 直接输出得分函数
    2. **噪声预测**：$\varepsilon_\theta(\tilde{x}, \sigma) \approx z$，其中 $s_\theta = -\varepsilon_\theta/\sigma$
       - 训练目标：$\|\varepsilon_\theta(x+\sigma z, \sigma) - z\|^2$
       - DDPM采用的参数化（→第7/11章）
       - 优势：预测目标（噪声）的量级不随 $\sigma$ 变化，训练更稳定
    3. **信号预测**：$D_\theta(\tilde{x}, \sigma) \approx x$，其中 $s_\theta = (D_\theta - \tilde{x})/\sigma^2$
       - 训练目标：$\|D_\theta(x+\sigma z, \sigma) - x\|^2$
       - 去噪器的自然参数化
       - Tweedie等式的直接体现
  - **三种参数化的等价性与选择**
    - 数学上完全等价（可通过线性变换互推）
    - 训练动态不同：
      - $\sigma$ 大时：得分预测目标 $\|z/\sigma\|^2$ 量级小，噪声预测目标 $\|z\|^2$ 量级稳定
      - $\sigma$ 小时：得分预测目标量级大，可能导致梯度不稳定
    - **实践建议**：多噪声水平训练时，噪声预测（$\varepsilon$-prediction）最为稳定

- **Tweedie等式在实践中的角色**
  - 回顾第5章5.3节：$\nabla\log p_\sigma(\tilde{x}) = (D_\sigma^*(\tilde{x}) - \tilde{x})/\sigma^2$
  - 实践意义：训练一个去噪器 $D_\theta$，就自动获得得分估计器
    - $s_\theta(\tilde{x}, \sigma) = (D_\theta(\tilde{x}, \sigma) - \tilde{x})/\sigma^2$
  - 反过来：训练一个得分网络 $s_\theta$，也自动获得去噪器
    - $D_\theta(\tilde{x}, \sigma) = \tilde{x} + \sigma^2 s_\theta(\tilde{x}, \sigma)$
  - **实践中的选择**：通常训练噪声预测网络 $\varepsilon_\theta$，推理时按需转换为得分或去噪器
    - $s_\theta = -\varepsilon_\theta/\sigma$
    - $D_\theta = \tilde{x} - \sigma\varepsilon_\theta$

- **训练细节与工程考量**
  - 数据预处理：归一化到 $[-1, 1]$ 或 $[0, 1]$
  - 优化器：Adam，学习率调度
  - 噪声水平采样：训练时随机采样 $\sigma \sim \text{Uniform}\{\sigma_1, \ldots, \sigma_L\}$ 或对数均匀分布
  - 批量大小与训练时长
  - 常见问题与调试策略

**来源**：Zhang et al. (2021) DRUNet; Ho et al. (2020) DDPM; Pock L2 P10-13; Tutorial_Diffusion_Imaging_Vision Sec 3.3

有了训练好的得分估计器，如何用它来驱动采样？退火Langevin动力学是多尺度得分匹配的自然采样方法，PnP-ULA则是逆问题中的条件采样方法，两者与手工先验方法的对比将展示数据驱动先验的优势。

## 6.7 用学习到的得分驱动采样

**核心观点**：学习到的得分函数可以驱动两类采样：无条件采样（退火Langevin动力学生成图像）和条件采样（PnP-ULA求解逆问题）。实验表明，学习得分驱动的采样在重建质量和不确定性量化方面显著优于手工先验方法。退火Langevin动力学是扩散采样的离散版前身，本章的终点自然指向第7章的扩散模型——多尺度得分匹配+连续时间采样=扩散模型。

- **退火Langevin动力学：从学习得分到图像生成**
  - 6.5节已介绍算法流程
  - 无条件图像生成实验：
    - 在CIFAR-10/Face数据集上训练NCSN
    - 退火Langevin生成样本的视觉质量
    - 与真实数据分布的对比（FID指标）
  - 采样轨迹可视化：从噪声到清晰图像的逐步去噪过程

- **PnP-ULA：用学习得分求解逆问题**
  - 回顾第5章5.5节：PnP-ULA用去噪器（通过Tweedie等式）替换先验梯度
  - 现在有了训练好的得分估计器 $s_\theta$，PnP-ULA可以直接使用：
    $$X_{m+1} = X_m - \delta\nabla f(X_m) + \delta\,s_\theta(X_m, \varepsilon) + \sqrt{2\delta}\,Z_{m+1}$$
  - 三种先验的对比实验：
    - 手工先验（TV/L1）：简单但表达能力有限
    - 学习先验（DRUNet去噪器+Tweedie）：更强但单一尺度
    - 多尺度学习先验（NCSN+退火采样）：最强但计算量大

- **实验对比：学习先验 vs 手工先验**
  - 去卷积实验：模糊核 + 高斯噪声
    - 重建质量（PSNR/SSIM）：学习先验显著优于手工先验
    - 不确定性量化：学习先验的后验样本更真实
    - 计算代价：学习先验需要预训练去噪器，但推理速度与MYULA相当
  - 超分辨率实验
  - 结果可视化：重建图、误差图、不确定性图

- **从得分匹配到扩散模型：全书路径的推进**
  - 回顾推理链：
    - 第4章：后验采样需要ULA → 需要得分函数
    - 第5章：得分函数可从去噪器提取（Tweedie）→ 但去噪器从哪来？
    - 第6章：去噪器可通过得分匹配训练（DSM）→ 多尺度得分匹配（NCSN）
  - 下一步（第7章）：
    - NCSN的离散噪声调度 → 连续时间的扩散SDE
    - 退火Langevin → 连续时间的逆向SDE
    - 多尺度得分匹配训练 → 扩散模型的训练框架
  - **核心洞见**：得分匹配解决了"得分从哪来"的问题，扩散模型解决"如何用多时间步得分做高质量采样"的问题——两者组合构成完整的生成建模框架

## 附录6A ESM与DSM等价性的完整证明

> 定位：为6.3节提供Vincent (2011) 定理 $\mathcal{J}_{\text{DSM}}(\theta) = \mathcal{J}_{\text{ESM}}(\theta) + C$ 的完整数学证明。证明涉及条件期望的分解和交叉项的化简，放在附录以保持主线叙事的流畅。

- **前提与记号**
  - $p(x)$：数据分布，$q_\sigma(\tilde{x}|x) = \mathcal{N}(\tilde{x}|x, \sigma^2 I)$
  - $q_\sigma(\tilde{x}) = \int p(x)q_\sigma(\tilde{x}|x)\,dx$：噪声扰动边际分布
  - $q_\sigma(x|\tilde{x}) = p(x)q_\sigma(\tilde{x}|x)/q_\sigma(\tilde{x})$：后验分布

- **ESM目标（在扰动分布上）**
  $$\mathcal{J}_{\text{ESM}}(\theta) = \frac{1}{2}\mathbb{E}_{q_\sigma(\tilde{x})}\left[\|s_\theta(\tilde{x}) - \nabla\log q_\sigma(\tilde{x})\|^2\right]$$

- **DSM目标展开**
  $$\mathcal{J}_{\text{DSM}}(\theta) = \frac{1}{2}\mathbb{E}_{q_\sigma(\tilde{x}, x)}\left[\|s_\theta(\tilde{x}) - \nabla\log q_\sigma(\tilde{x}|x)\|^2\right]$$
  展开 $\|s_\theta - \nabla\log q_\sigma(\tilde{x}|x)\|^2 = \|s_\theta\|^2 - 2s_\theta^T\nabla\log q_\sigma(\tilde{x}|x) + \|\nabla\log q_\sigma(\tilde{x}|x)\|^2$

- **交叉项的化简**
  - $\mathbb{E}_{q_\sigma(\tilde{x}, x)}[s_\theta(\tilde{x})^T\nabla\log q_\sigma(\tilde{x}|x)] = \mathbb{E}_{q_\sigma(\tilde{x})}\left[s_\theta(\tilde{x})^T\,\mathbb{E}_{q_\sigma(x|\tilde{x})}[\nabla\log q_\sigma(\tilde{x}|x)]\right]$
  - 由Tweedie等式：$\mathbb{E}_{q_\sigma(x|\tilde{x})}[\nabla\log q_\sigma(\tilde{x}|x)] = \nabla\log q_\sigma(\tilde{x})$
  - 因此交叉项 = $\mathbb{E}_{q_\sigma(\tilde{x})}[s_\theta(\tilde{x})^T\nabla\log q_\sigma(\tilde{x})]$

- **代入整理**
  $$\mathcal{J}_{\text{DSM}}(\theta) = \frac{1}{2}\mathbb{E}_{q_\sigma(\tilde{x})}\left[\|s_\theta(\tilde{x})\|^2 - 2s_\theta(\tilde{x})^T\nabla\log q_\sigma(\tilde{x})\right] + C_1$$
  $$= \frac{1}{2}\mathbb{E}_{q_\sigma(\tilde{x})}\left[\|s_\theta(\tilde{x}) - \nabla\log q_\sigma(\tilde{x})\|^2\right] + C_2 = \mathcal{J}_{\text{ESM}}(\theta) + C$$

**来源**：Vincent (2011); Tutorial_Diffusion_Imaging_Vision Theorem 3.4

## 附录6B Hutchinson迹估计的无偏性与方差分析

> 定位：为6.4节提供Hutchinson迹估计的数学基础。证明无偏性，分析方差，比较不同采样分布的效率。

- **无偏性证明**
  - 设 $A \in \mathbb{R}^{d \times d}$，$v \sim p_v$ 满足 $\mathbb{E}[vv^T] = I$
  - $\mathbb{E}[v^T A v] = \mathbb{E}[\text{Tr}(v^T A v)] = \text{Tr}(A\,\mathbb{E}[vv^T]) = \text{Tr}(A)$

- **方差分析**
  - $\text{Var}(v^T A v) = \mathbb{E}[(v^T A v)^2] - (\text{Tr}(A))^2$
  - 高斯采样：$\text{Var} = 2\|A\|_F^2$（$\|A\|_F$为Frobenius范数）
  - Rademacher采样：$\text{Var} = 2\|A\|_F^2 - 2\sum_i A_{ii}^2 \leq 2\|A\|_F^2$
  - Rademacher的方差更低——实践中推荐

- **M次估计的方差**
  - $\widehat{\text{Tr}}_M(A) = \frac{1}{M}\sum_{j=1}^M v_j^T A v_j$
  - $\text{Var}(\widehat{\text{Tr}}_M) = \text{Var}(v^T A v) / M$
  - $M$ 越大方差越小，但计算量正比于 $M$

- **在得分匹配中的应用**
  - $A = \nabla_x s_\theta(x)$ 是 $s_\theta$ 的Jacobian
  - $v^T\nabla_x s_\theta(x)\,v$ 可通过前向自动微分高效计算
  - 实践中 $M = 1$ 即可获得无偏估计，多次平均可降低方差

**来源**：Hutchinson (1990); Song et al. (2019) Sliced Score Matching
