# 6.8 本章小结：得分匹配 = 从数据中学习得分 = 训练去噪器

> 核心观点：第 5 章建立了"去噪器 = 得分估计器"，但去噪器本身需要训练目标。本章回答：如何从数据中系统地学习得分函数？得分匹配（Score Matching）提供了无需归一化常数的训练框架——从 ESM 的不可行、ISM 的 Jacobian 瓶颈，到 DSM 的实用突破、SSM 的随机投影，每一步演进都源于同一动机：**绕过归一化常数 $Z$ 的不可计算性**。最终多尺度得分匹配（NCSN）把单一噪声水平扩展为噪声调度，架起通往扩散模型的桥梁。

## 一、本章走过了什么

```
6.1 为什么需要学习得分（得分"无需 Z"但不可直接计算）
  │
6.2 ESM 与 ISM（ESM 不可行；ISM 有 Jacobian 迹瓶颈）
  │
6.3 DSM：噪声扰动 + 闭式条件得分 → 实用突破
  │
6.4 SSM：Hutchinson 迹估计 → 随机投影替代
  │
6.5 多尺度得分匹配：NCSN（噪声调度 → 扩散前身）
  │
6.6 去噪器架构实践：DRUNet + 三种参数化
  │
6.7 用学习得分驱动采样（退火 Langevin + PnP-ULA）
```

- **6.1**：得分函数无需归一化常数（$\nabla\log\tilde p=\nabla\log p$），但 $\nabla\log p(x)$ 本身不可直接计算——这既是障碍也是机会。
- **6.2**：ESM 需要 $\nabla\log p$ 当监督信号（循环依赖，不可行）；ISM 用分部积分消去 $\nabla\log p$，但引入 Jacobian 迹 $\text{Tr}(\nabla_x s_\theta)$——高维 $O(d^2)$ 不可行。
- **6.3**：DSM 是实用突破——引入噪声扰动后条件得分有闭式解 $-\frac{z}{\sigma}$，完全避开 Jacobian。Vincent (2011) 定理：$\mathcal{J}_{\text{DSM}}=\mathcal{J}_{\text{ESM}}+C$。**DSM 目标等价于去噪**：预测噪声 $z/\sigma$ = 去噪，呼应 Tweedie 等式。
- **6.4**：SSM 用 Hutchinson 迹估计随机化 ISM，把 $O(d^2)$ 降为 $O(M)$，估计未扰动分布的得分，与 DSM 互补。
- **6.5**：单一噪声水平遭遇"低密度区域"困境（流形假设）。NCSN 用几何级数噪声调度 $\sigma_1>\cdots>\sigma_L$，大噪声填满低密度区域、小噪声保留细节；退火 Langevin 逐步精细化。**NCSN = 离散化扩散模型，扩散模型 = 连续化 NCSN**。
- **6.6**：DRUNet 以噪声水平为条件输入实现"一网多噪"；三种参数化（ε 预测 / s 预测 / x₀ 预测）数学等价、训练动态不同，实践推荐 ε 预测。
- **6.7**：学习到的得分驱动两类采样——无条件（退火 Langevin 生成图像）与条件（PnP-ULA 求解逆问题），学习先验显著优于手工先验。

## 二、四种得分匹配方法对照

| 方法 | 需要 $\nabla\log p$ | Jacobian 迹 | 估计的得分 | 计算量 |
|---|---|---|---|---|
| ESM | 是 | 否 | $\nabla\log p$ | 不可行 |
| ISM | 否 | 精确计算 | $\nabla\log p$ | $O(d^2)$ |
| DSM | 否 | 否 | $\nabla\log p_\sigma$ | $O(1)$ |
| SSM | 否 | 随机估计 | $\nabla\log p$ | $O(M)$ |

## 三、与前后章的呼应

- **承接第 5 章**：Tweedie 等式说明"去噪 = 得分估计"，本章给出训练这种去噪器/得分估计器的目标函数（DSM）。
- **关键伏笔（三种参数化）**：ε 预测 / s 预测 / x₀ 预测在第 11 章变分视角中再次出现；DSM 与 VLB 的等价性是第 12 章的核心结论。
- **向前开放（第 7 章）**：NCSN 的离散噪声调度 → 连续时间扩散 SDE；退火 Langevin → 逆向 SDE；多尺度得分匹配训练 → 扩散模型的训练框架。

## 四、展望

下一章把 NCSN/DDPM 的离散加噪-去噪过程推广为连续时间的随机微分方程（SDE）。第 7 章将建立扩散模型的 SDE 统一视角：正向 SDE 加噪、逆向 SDE 去噪、概率流 ODE 提供确定性等价——DDPM 和 NCSN 不再是独立方法，而是同一连续框架的不同离散化方案。

从更深层次看，本章真正完成的是先验知识来源的更替：我们不再需要人为刻写正则项 $R(x)$，而是通过得分匹配，让数据自己交出先验的梯度 $\nabla\log p(x)$。"去噪即学先验梯度"，因此不仅是本章的核心结论，更是通向扩散模型的自然极限——因为一旦你拥有一族覆盖所有噪声水平的得分，剩下的只是一个连续化的采样过程而已。

**一句话总结全章**：把整章压缩成一句话——**"得分算不出来"曾是把贝叶斯采样挡在图像门外的墙；得分匹配把这堵墙拆了——因为"让网络学会去噪"和"让网络学会得分"根本是同一件事。**
