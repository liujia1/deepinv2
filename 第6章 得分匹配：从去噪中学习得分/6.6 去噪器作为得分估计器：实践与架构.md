# 6.6 去噪器作为得分估计器：实践与架构

> 得分匹配的理论要落地，得有能打的架构。DRUNet 是当前最常用的条件去噪器——它把噪声水平 $\sigma$ 当条件输入，做到"一网多噪"，正好对应 NCSN 的 $s_\theta(x,\sigma)$。三种参数化（$\varepsilon$/ $s$/ $x_0$ 预测）各有优劣；而 Tweedie 等式让我们训练一个去噪器，就能现场变身成得分估计器。

---

## 开场：理论很美，网络怎么搭？

上一节我们把多尺度框架 NCSN 搭好了——一个以噪声水平为条件的得分网络 $s_\theta(x,\sigma)$。可"网络"二字到此还是个抽象符号。现在回到工程现实：这个 $s_\theta$ 到底长啥样？用什么结构才能真正吃进噪声水平、吐出正确的得分方向？

**本章目标（roadmap）**：
1. 理清从 MLP → CNN → UNet → DRUNet 的架构演进；
2. 搞懂 DRUNet "一网多噪" 的条件输入设计；
3. 比较三种参数化，知道该用哪个；
4. 用 Tweedie 等式在"去噪器"和"得分"之间自由切换。

先抛个反直觉，帮你放下心理包袱：你以为要专门设计一个"得分网络"？其实**一个普通的去噪网络就够**——只要它能吃进噪声水平、吐出干净图，Tweedie 等式就帮你把得分算出来。一次训练，多种用途。

---

## 架构选择：从通用到专用

得分网络要满足两件事：图像→图像的映射（输入 $d$ 维、输出 $d$ 维），以及**噪声水平条件**（同一网络适应不同 $\sigma$）。

| 架构 | 特点 | 支持条件 $\sigma$？ | 适用 |
|---|---|---|---|
| MLP | 全连接，参数少 | 可（拼接输入） | 低维数据 |
| CNN | 局部连接，参数共享 | 难 | 固定噪声去噪 |
| UNet | 编码–解码 + 跳跃连接 | 可（注入） | 图像去噪/得分 |
| DRUNet | UNet + $\sigma$ 条件输入 | 原生支持 | 多噪声水平得分 |

**UNet**（Ronneberger 2015）是图像去噪/得分的事实标准：编码器逐步下采样提多尺度特征，解码器上采样恢复分辨率，跳跃连接把编码器特征直送解码器对应层以保空间细节。它同时抓全局结构和局部纹理，参数效率还高（层次结构详见第15章）。

**DRUNet**（Zhang 2021）在 UNet 上加了**噪声水平条件输入**，成为多尺度得分估计的理想架构。做法：把标量 $\sigma$ 经一个小 MLP 映射成特征向量 $e_\sigma$，再注入每个残差块（相加或用 adaLN 调制）。

```
输入: x（含噪图）, σ（噪声水平）
        │
   [σ → MLP → e_σ]
        │
   编码器: Conv(x) + e_σ → 下采样 → ...
        ↕ 跳跃连接
   解码器: ... → 上采样 + e_σ → Conv → 输出
        │
   输出: s_θ(x,σ) 或 ε_θ(x,σ)
```

**"一网多噪"的理念**：同一网络处理不同噪声水平，参数共享更高效；条件输入让网络区分不同尺度的得分——这正是 NCSN 里 $s_\theta(x,\sigma_i)$ 的工程实现。

架构演进路线：`DnCNN（固定噪声）→ UNet（通用）→ DRUNet（条件噪声）→ DiT（扩散Transformer，第15章）`。

## 三种参数化：哪种训得稳？

6.3 节提过三种写法，这里从**训练实践**角度比较。

**得分预测（$s$-prediction）**：直接输出 $s_\theta(\tilde x,\sigma)\approx\nabla\log p_\sigma(\tilde x)$，目标 $\|s_\theta+z/\sigma\|^2$。
- 优点：直接是得分，无需变换即可用于 Langevin；理论最自然。
- 缺点：输出量级随 $\sigma$ 变（$\|s_\theta\|\propto1/\sigma$）；$\sigma$ 小时目标 $\|z/\sigma\|^2$ 大，梯度不稳；多尺度时各尺度损失量级不一致。

**噪声预测（$\varepsilon$-prediction）**：输出噪声 $\varepsilon_\theta(\tilde x,\sigma)\approx z$，关系 $s_\theta=-\varepsilon_\theta/\sigma$，目标 $\|\varepsilon_\theta-z\|^2$。
- 优点：**预测目标 $z$ 量级不随 $\sigma$ 变**（$\|z\|^2\approx d$ 常数），多尺度损失量级天然一致，训练最稳。这是 DDPM 的标准选择。
- 缺点：用于 Langevin 时要除 $\sigma$，$\sigma$ 太小会放大数值误差。

**信号预测（$x_0$-prediction）**：输出干净 $x$，$s_\theta=(D_\theta-\tilde x)/\sigma^2$，目标 $\|D_\theta-x\|^2$。
- 优点：去噪器最自然写法，Tweedie 直接体现，输出即去噪结果，可直接插进 PnP（第5章）。
- 缺点：高噪声时 $x$ 与 $\tilde x$ 差大、网络要"猜"更多；低噪声时损失天然小但信息量少。

**实践建议**：
- **多噪声水平训练** → 用 $\varepsilon$-预测（最稳，DDPM 标配）；
- **逆问题求解** → 用 $x_0$-预测（输出即去噪结果，直接进 PnP）；
- **理论分析** → 用 $s$-预测（直接对应 Langevin 驱动力）。

三者可自由转换（VE-SDE 形式）：`s_θ = -ε_θ/σ = (D_θ - x̃)/σ²`。VP-SDE 形式的转换（用 $\bar\alpha_t$）见第11章 11.3 节。

## Tweedie 等式在实践中的角色

理论讲了三种参数化等价，但工程上你总得先训一个、再按需转换。第5章 5.3 节的 Tweedie 等式，在这里就是那个**去噪器与得分估计器的双向转换器**——只要你训好了其中一种，它立刻给你另外两种：

$$\nabla\log p_\sigma(\tilde x) = \frac{D_\sigma^*(\tilde x)-\tilde x}{\sigma^2}.$$

- **从去噪器到得分**：训好 $D_\theta$ 后，$s_\theta(\tilde x,\sigma)=\dfrac{D_\theta(\tilde x,\sigma)-\tilde x}{\sigma^2}$。
- **从得分到去噪器**：训好 $s_\theta$ 后，$D_\theta(\tilde x,\sigma)=\tilde x+\sigma^2 s_\theta(\tilde x,\sigma)$。

**实践里通常训 $\varepsilon_\theta$，推理时按需转**：
- 要得分（Langevin）：$s_\theta=-\varepsilon_\theta/\sigma$；
- 要去噪器（PnP）：$D_\theta=\tilde x-\sigma\varepsilon_\theta$；
- 要 $x_0$（扩散推理）：$x_0=\tilde x-\sigma\varepsilon_\theta$。

一次训练、多种用途——这正是数据驱动先验的魅力。

## 训练细节与工程考量

- **数据预处理**：像素归一化到 $[-1,1]$ 或 $[0,1]$（影响 $\sigma$ 的设置）；数据增强（随机裁剪、翻转）增加多样性。
- **优化器**：Adam（$\beta_1=0.9,\beta_2=0.999$），lr $10^{-4}$–$2\times10^{-4}$，余弦退火或常数 lr，梯度裁剪防不稳。
- **噪声水平采样**：均匀 $i\sim\mathrm{Uniform}\{1,\dots,L\}$（简单但各尺度样本不均）；更推荐**对数均匀** $\log\sigma\sim\mathrm{Uniform}[\log\sigma_L,\log\sigma_1]$（保证小噪声也有足够样本）；重要性采样更高效但复杂。
- **批量与时长**：batch 64–256；通常需数十万到数百万次迭代；用留出集监控去噪 PSNR。
- **常见问题**：训练不稳→降 lr 或缩 $\sigma$ 范围；小噪声精度不足→增大 $\sigma_L$ 或加数据；大噪声过度平滑→减小 $\sigma_1$。
