# 17.6 测量一致性与等变架构

> **核心观点**：测量一致性确保重建结果与观测数据一致（$Af(y) \approx y$），等变架构将物理对称性编码进网络结构——两者从不同角度融入物理先验，与自监督损失形成互补。deepinv库提供了完整的自监督训练API。

## 17.6.1 测量一致性损失

### 定义与物理含义

测量一致性（Measurement Consistency, MC）损失是最基本的物理约束：

$$\mathcal{L}_{\text{MC}}(y, f) = \|y - Af(y)\|^2$$

**物理含义**：若$f(y)$是真实的重建结果，那么对它做正向测量应该能还原观测$y$。这是逆问题中"数据项"（第3章3.1节）在网络输出上的直接体现。

### 与变分方法数据项的关系

回顾第3章的变分正则化：

$$\hat{x} = \text{argmin}_x \|Ax - y\|^2 + \lambda R(x)$$

其中$\|Ax - y\|^2$是数据项。测量一致性损失$\|y - Af(y)\|^2$本质上是同一个数据项，但不是通过优化求解$x$，而是直接约束网络输出$f(y)$。

**区别**：变分方法通过迭代优化满足数据项；学习型方法通过网络训练满足MC损失——后者一旦训练完成，单次前向传播即可输出满足测量一致性的结果。

### 在自监督训练中的作用

- **SURE/MOI等损失已隐含测量一致性**：$\|y - Af(y)\|^2$已经是SURE和MOI损失的一部分
- **显式添加MC损失**可增强约束，特别是在低噪声场景中，当数据拟合的精度要求很高时
- **与EI的互补**：MC约束值空间方向，EI约束零空间方向——两者覆盖不同的方向

### 测量一致性的局限

MC损失仅约束$A$的值空间方向——如果$Af(y) \approx y$但$f(y)$在零空间方向与$x$相差甚远，MC损失无法检测。这正是等变性约束需要填补的空白。

## 17.6.2 等变网络架构设计

等变架构将对称性"硬编码"进网络结构，使得等变性不是通过损失函数"鼓励"，而是由架构"保证"。

### 平移等变架构

**标准卷积**天然平移等变——这是CNN成功的核心原因之一。离散卷积$(w * x)_i = \sum_k w_k x_{i-k}$满足$(w * T_g x) = T_g(w * x)$对循环平移成立。

### 旋转等变架构

**群卷积**（Cohen & Welling 2016）：将卷积推广到旋转群——在多个旋转角度上同时卷积，旋转输出也随之旋转。

**Steerable CNN**（Weiler & Cesa 2019）：通过特殊设计的卷积核保证旋转等变性——卷积核的权重被参数化为圆谐函数的线性组合。

### 尺度等变架构

**尺度等变卷积**：通过多尺度卷积核或膨胀卷积实现尺度等变性。

### 等变Transformer

最近的研究将等变性扩展到注意力机制——等变Transformer在保持全局感受野的同时保证对称性。

### 两种实现策略

| 策略 | 机制 | 优势 | 局限 |
|------|------|------|------|
| **软约束**（损失函数） | $\mathcal{L}_{\text{EI}}$鼓励等变性 | 灵活，适用于任何架构 | 不保证精确等变 |
| **硬约束**（架构） | 网络结构保证等变性 | 精确等变，无需额外损失 | 架构选择受限 |
| **组合** | 架构+损失函数 | 最强约束 | 实现复杂 |

实践中，**软约束（EI损失）+ 标准架构**是最常用的组合——因为CNN/UNet已经天然平移等变，而旋转/缩放等变性通过$\mathcal{L}_{\text{EI}}$来鼓励。

## 17.6.3 两种约束的互补性

测量一致性和等变性约束从不同角度融入物理先验，形成互补：

### 方向覆盖

- **测量一致性**：约束$A$的值空间方向——确保$f(y)$在"可见"方向上与数据一致
- **等变性约束**：约束$A$的零空间方向——利用对称性填补"不可见"方向的信息

```
信号空间 R^n
├── A的值空间 (dim=m)  ← MC约束
└── A的零空间 (dim=n-m) ← EI约束
```

### 组合损失

综合自监督训练的完整损失为：

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{UNSURE}} + \lambda_{\text{EI}}\mathcal{L}_{\text{EI}} + \lambda_{\text{MC}}\mathcal{L}_{\text{MC}}$$

- **$\mathcal{L}_{\text{UNSURE}}$**：值空间方向的自监督去噪（自动估计噪声水平）
- **$\mathcal{L}_{\text{EI}}$**：零空间方向的对称性约束
- **$\mathcal{L}_{\text{MC}}$**：值空间方向的显式数据一致性（加强UNSURE中的隐式MC）

**权重选择**：$\lambda_{\text{EI}}$和$\lambda_{\text{MC}}$通常通过验证集调参。$\lambda_{\text{MC}}$在低噪声时较大（数据可靠，应严格拟合），高噪声时较小（数据不可靠，应更多依赖先验）。

### 与全书叙事的呼应

这种"数据约束+先验约束"的组合与全书的核心思想完全一致：

- 第1-3章：贝叶斯框架$p(x|y) \propto p(y|x)p(x)$ → 数据项（MC）+ 先验项（EI）
- 第5章：PnP框架中，数据项$A^\top(Ax-y)$ + 先验项（去噪器）→ MC + EI
- 第13章：条件扩散中，似然得分$\nabla\log p(y|x_t)$ + 先验得分$\nabla\log p(x_t)$ → MC + EI

**统一视角**：无论是变分方法、PnP、条件扩散还是自监督训练，物理约束的融入方式始终是"数据一致性+先验约束"——只是具体形式从显式正则化到隐式网络训练不断演化。

## 17.6.4 deepinv实现

deepinv库提供了完整的自监督训练API，使得本章的方法可以直接在实践中使用。

### 自监督损失API

```python
# SURE损失（已知高斯噪声水平）
from deepinv.loss import SureGaussianLoss
loss_sure = SureGaussianLoss(sigma=0.1)

# SURE损失（Poisson-Gaussian噪声）
from deepinv.loss import SurePGLoss
loss_pg = SurePGLoss()

# R2R损失
from deepinv.loss import R2RLoss
loss_r2r = R2RLoss()

# 盲点网络变体
from deepinv.loss import SplittingLoss, Neighbor2Neighbor
loss_split = SplittingLoss()
loss_n2n = Neighbor2Neighbor()

# 等变成像损失
from deepinv.loss import EILoss
loss_ei = EILoss(transforms=transforms)
```

### UNSURE实现

UNSURE通过`SureGaussianLoss`的`unsure=True`选项实现：

```python
loss_unsure = SureGaussianLoss(unsure=True)
```

此时Lagrange乘子$\eta$作为可训练参数自动优化。

### 训练编排

```python
from deepinv import Trainer

trainer = Trainer(
    model=model,
    physics=physics,
    optimizer=optimizer,
    losses=[loss_unsure, loss_ei],  # 组合UNSURE + EI
    device=device,
)

trainer.train(train_dataloader, epochs=100)
```

## 本节小结

| 约束类型 | 约束方向 | 机制 | deepinv API |
|---------|---------|------|-------------|
| 测量一致性(MC) | 值空间 | $\|y - Af(y)\|^2$ | 隐含在SURE/MOI中 |
| 等变性(EI) | 零空间 | $\mathbb{E}_g\|T_g\hat{x} - f(AT_g\hat{x})\|^2$ | `EILoss` |
| 硬等变架构 | 全空间 | 群卷积/Steerable CNN | 需自定义网络 |

MC与EI互补：MC确保"可见方向"的准确性，EI利用对称性填补"不可见方向"。这种"数据+先验"的组合与全书从贝叶斯框架到条件扩散的核心思想一脉相承。

> **过渡**：从Noise2Noise到等变成像，自监督学习方法构成了一个从简单到复杂、从去噪到逆问题的完整工具箱——它解决了全书实践中最根本的数据瓶颈。
