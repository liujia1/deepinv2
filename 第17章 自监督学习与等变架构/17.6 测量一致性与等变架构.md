# 17.6 测量一致性与等变架构

> **核心观点**：测量一致性确保重建结果与观测数据一致（$Af(y) \approx y$），等变架构将物理对称性编码进网络结构——两者从不同角度融入物理先验，与自监督损失形成互补。deepinv库提供了完整的自监督训练API。

## 17.6.1 测量一致性损失

### 定义与物理含义

测量一致性（Measurement Consistency, MC）损失是最基本的物理约束：

$$\mathcal{L}_{\text{MC}}(y, f) = \|y - Af(y)\|^2$$

**物理含义**：若$f(y)$是真实的重建结果，那么对它做正向测量应该能还原观测$y$。这是逆问题中"数据项"（第3章3.1节）在网络输出上的直接体现。

### 与变分方法数据项的关系

回顾第3章的变分正则化：

$$\hat{x} = \text{argmin}_x \|Ax - y\|^2 + \lambda R(x)$$

其中$\|Ax - y\|^2$是数据项。测量一致性损失$\|y - Af(y)\|^2$本质上是同一个数据项，但不是通过优化求解$x$，而是直接约束网络输出$f(y)$。

**区别**：变分方法通过迭代优化满足数据项；学习型方法通过网络训练满足MC损失——后者一旦训练完成，单次前向传播即可输出满足测量一致性的结果。

### 在自监督训练中的作用

- **SURE/MOI等损失已隐含测量一致性**：$\|y - Af(y)\|^2$已经是SURE和MOI损失的一部分
- **显式添加MC损失**可增强约束，特别是在低噪声场景中，当数据拟合的精度要求很高时
- **与EI的互补**：MC约束值空间方向，EI约束零空间方向——两者覆盖不同的方向

### 测量一致性的局限

MC损失仅约束$A$的值空间方向——如果$Af(y) \approx y$但$f(y)$在零空间方向与$x$相差甚远，MC损失无法检测。这正是等变性约束需要填补的空白。

## 17.6.2 等变网络架构设计

等变架构将对称性"硬编码"进网络结构，使得等变性不是通过损失函数"鼓励"，而是由架构"保证"。本节介绍三种核心的等变架构：群卷积、Steerable CNN和等变Transformer。

### 平移等变架构

**标准卷积**天然平移等变——这是CNN成功的核心原因之一。离散卷积$(w * x)_i = \sum_k w_k x_{i-k}$满足$(w * T_g x) = T_g(w * x)$对循环平移成立。

平移等变性来自卷积的**权值共享**机制：同一个卷积核在所有位置使用相同的权重，因此对输入做平移等价于对输出做平移。这是最基本也最广泛使用的等变架构——第15章的UNet和DiT都依赖卷积的平移等变性。

### 旋转等变架构：群卷积

**问题**：标准卷积只对平移等变，不对旋转等变。如果输入图像旋转90度，卷积的输出不会相应旋转——因为卷积核本身有固定的朝向。

**群卷积**（Group Equivariant CNN, Cohen & Welling 2016）将卷积从平移群$\mathbb{Z}^2$推广到更大的群$G$（如平移-旋转群$p4$或平移-旋转-反射群$p4m$），使网络对群$G$的所有元素等变。

**核心思想**：在群$G$上定义卷积。标准卷积在平移群上积分：

$[w * x](g) = \sum_{k} w(g^{-1}k)\, x(k)$

群卷积将求和推广到群元素$g \in G$：

$[w *_G x](g) = \sum_{h \in G} w(g^{-1}h)\, x(h)$

**直觉**：标准卷积用一个"模板"$w$在所有平移位置上匹配输入；群卷积则用一组"旋转模板"$\{w(g^{-1}h)\}_{h \in G}$在所有群元素位置上匹配——相当于同时在多个旋转角度上卷积。输出是一个"群上的特征图"：每个位置不仅有空间坐标，还有一个旋转角度维度。

**等变性证明**：对输入做群变换$g'$（如旋转），输出也做同样的群变换$g'$——因为卷积在群上的定义保证了$[w *_G (L_{g'} x)] = L_{g'}[w *_G x]$，其中$L_{g'}$是左正则表示。

**实现**：群卷积可以通过将输入旋转到多个角度、在每个角度上做标准卷积、再堆叠结果来实现。对于$p4$群（4个旋转），这相当于4倍的计算量，但网络自动学到了旋转不变的表示。

### 旋转等变架构：Steerable CNN

群卷积在离散群上操作（如4个或8个旋转角度），只能处理特定的旋转角度。**Steerable CNN**（Weiler & Cesa 2019）通过连续参数化卷积核，实现对连续旋转群的精确等变性。

**核心思想**：约束卷积核的权重，使其只能取满足等变性的形式。具体地，将卷积核参数化为**圆谐函数**（circular harmonics）的线性组合：

$w(r, \phi) = \sum_{l} a_l(r)\, e^{il\phi}$

其中$(r, \phi)$是极坐标，$l$是角频率（谐波阶数），$a_l(r)$是径向权重（可学习参数）。

**为什么这样参数化保证等变性**：旋转输入图像等价于对所有卷积核的$\phi$坐标做旋转$\phi \to \phi + \theta$。由于$e^{il(\phi+\theta)} = e^{il\theta} e^{il\phi}$，旋转只引起系数的相位变化$e^{il\theta}$，而不改变径向权重$a_l(r)$——因此输出特征图也随之旋转，等变性得到精确保证。

**与群卷积的对比**：

| 性质 | 群卷积 | Steerable CNN |
|------|--------|---------------|
| 群 | 离散群（$C_n$, $D_n$） | 连续群（$SO(2)$, $O(2)$） |
| 旋转角度 | 仅$n$个特定角度 | 任意角度 |
| 卷积核 | 自由权重 | 圆谐参数化约束 |
| 计算量 | 角度倍数（如4x） | 与标准CNN相近 |
| 精度 | 离散近似 | 精确等变 |

**在逆问题中的应用**：Steerable CNN特别适合CT/MRI重建——这些问题的正向算子（Radon变换、k-space采样）本身具有旋转等变性或近似等变性。使用旋转等变网络可以确保重建结果不会因输入朝向不同而产生系统性偏差。

### 尺度等变架构

**尺度等变卷积**：通过多尺度卷积核或膨胀卷积（dilated convolution）实现尺度等变性。其核心思想类似于群卷积对旋转的处理：在不同尺度上使用不同膨胀率的卷积核，使输出对输入的尺度变化做出一致响应。尺度等变架构在处理多分辨率医学图像（如不同视野的CT切片）时有潜在优势，但目前应用较少。

### 等变Transformer

最近的研究将等变性扩展到注意力机制。**等变Transformer**的核心设计是用等变线性层替换标准Transformer中的线性层，用等变注意力机制替换标准自注意力——在保持全局感受野的同时保证对称性。

在逆问题中的典型应用：**等变DiT**将第15章的DiT架构与Steerable CNN结合，在扩散模型的去噪网络中引入旋转等变性，使CT/MRI重建结果具有旋转一致性。这在有限角CT等对称性信息丰富的场景中特别有效。

### 两种实现策略

| 策略 | 机制 | 优势 | 局限 |
|------|------|------|------|
| **软约束**（损失函数） | $\mathcal{L}_{\text{EI}}$鼓励等变性 | 灵活，适用于任何架构 | 不保证精确等变 |
| **硬约束**（架构） | 网络结构保证等变性 | 精确等变，无需额外损失 | 架构选择受限 |
| **组合** | 架构+损失函数 | 最强约束 | 实现复杂 |

实践中，**软约束（EI损失）+ 标准架构**是最常用的组合——因为CNN/UNet已经天然平移等变，而旋转/缩放等变性通过$\mathcal{L}_{\text{EI}}$来鼓励。在需要精确等变的场景（如有限角CT的旋转等变性），则采用**Steerable CNN + EI损失**的组合。

## 17.6.3 两种约束的互补性

测量一致性和等变性约束从不同角度融入物理先验，形成互补：

### 方向覆盖

- **测量一致性**：约束$A$的值空间方向——确保$f(y)$在"可见"方向上与数据一致
- **等变性约束**：约束$A$的零空间方向——利用对称性填补"不可见"方向的信息

```
信号空间 R^n
├── A的值空间 (dim=m)  ← MC约束
└── A的零空间 (dim=n-m) ← EI约束
```

### 组合损失

综合自监督训练的完整损失为：

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{UNSURE}} + \lambda_{\text{EI}}\mathcal{L}_{\text{EI}} + \lambda_{\text{MC}}\mathcal{L}_{\text{MC}}$$

- **$\mathcal{L}_{\text{UNSURE}}$**：值空间方向的自监督去噪（自动估计噪声水平）
- **$\mathcal{L}_{\text{EI}}$**：零空间方向的对称性约束
- **$\mathcal{L}_{\text{MC}}$**：值空间方向的显式数据一致性（加强UNSURE中的隐式MC）

**权重选择**：$\lambda_{\text{EI}}$和$\lambda_{\text{MC}}$通常通过验证集调参。$\lambda_{\text{MC}}$在低噪声时较大（数据可靠，应严格拟合），高噪声时较小（数据不可靠，应更多依赖先验）。

### 与全书叙事的呼应

这种"数据约束+先验约束"的组合与全书的核心思想完全一致：

- 第1-3章：贝叶斯框架$p(x|y) \propto p(y|x)p(x)$ → 数据项（MC）+ 先验项（EI）
- 第5章：PnP框架中，数据项$A^\top(Ax-y)$ + 先验项（去噪器）→ MC + EI
- 第13章：条件扩散中，似然得分$\nabla\log p(y|x_t)$ + 先验得分$\nabla\log p(x_t)$ → MC + EI

**统一视角**：无论是变分方法、PnP、条件扩散还是自监督训练，物理约束的融入方式始终是"数据一致性+先验约束"——只是具体形式从显式正则化到隐式网络训练不断演化。

## 17.6.4 deepinv实现

deepinv库提供了完整的自监督训练API，使得本章的方法可以直接在实践中使用。

### 自监督损失API

```python
# SURE损失（已知高斯噪声水平）
from deepinv.loss import SureGaussianLoss
loss_sure = SureGaussianLoss(sigma=0.1)

# SURE损失（Poisson-Gaussian噪声）
from deepinv.loss import SurePGLoss
loss_pg = SurePGLoss()

# R2R损失
from deepinv.loss import R2RLoss
loss_r2r = R2RLoss()

# 盲点网络变体
from deepinv.loss import SplittingLoss, Neighbor2Neighbor
loss_split = SplittingLoss()
loss_n2n = Neighbor2Neighbor()

# 等变成像损失
from deepinv.loss import EILoss
loss_ei = EILoss(transforms=transforms)
```

### UNSURE实现

UNSURE通过`SureGaussianLoss`的`unsure=True`选项实现：

```python
loss_unsure = SureGaussianLoss(unsure=True)
```

此时Lagrange乘子$\eta$作为可训练参数自动优化。

### 训练编排

```python
from deepinv import Trainer

trainer = Trainer(
    model=model,
    physics=physics,
    optimizer=optimizer,
    losses=[loss_unsure, loss_ei],  # 组合UNSURE + EI
    device=device,
)

trainer.train(train_dataloader, epochs=100)
```

## 本节小结

| 约束类型 | 约束方向 | 机制 | deepinv API |
|---------|---------|------|-------------|
| 测量一致性(MC) | 值空间 | $\|y - Af(y)\|^2$ | 隐含在SURE/MOI中 |
| 等变性(EI) | 零空间 | $\mathbb{E}_g\|T_g\hat{x} - f(AT_g\hat{x})\|^2$ | `EILoss` |
| 硬等变架构 | 全空间 | 群卷积/Steerable CNN | 需自定义网络 |

MC与EI互补：MC确保"可见方向"的准确性，EI利用对称性填补"不可见方向"。这种"数据+先验"的组合与全书从贝叶斯框架到条件扩散的核心思想一脉相承。

从Noise2Noise到等变成像，自监督学习方法构成了一个从简单到复杂、从去噪到逆问题的完整工具箱——它解决了全书实践中最根本的数据瓶颈。
