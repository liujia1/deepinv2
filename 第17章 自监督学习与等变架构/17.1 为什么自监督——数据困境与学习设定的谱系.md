# 17.1 为什么自监督？——数据困境与学习设定的谱系

> **核心观点**：监督学习需要配对的$(x_i, y_i)$数据，但医学和科学成像中干净参考$x_i$往往无法获取。四种学习设定构成数据可用性的递减谱系——从监督到自监督到无监督，每一步都是对数据需求的放松，也带来新的技术挑战。自监督风险估计的核心目标是构建仅依赖观测$y$的损失，使其期望等于监督风险。

## 17.1.1 数据困境：干净数据为何稀缺

第16章展示了CT/MRI重建中学习型方法的强大——UNet端到端重建、Learned Gradient Descent、扩散先验重建——这些方法远超传统FBP和TV正则化。但它们有一个共同的隐含假设：**训练需要配对的干净-退化数据$\{(x_i, y_i)\}$**。

在自然图像领域，这个假设轻而易举：ImageNet有数百万张干净图像，加噪后即可构造训练对。但在医学和科学成像中，情况截然不同：

- **CT成像**：无法对同一患者同时进行"完全采样"和"稀疏采样"的CT扫描。所谓"干净参考"本身也需要从测量中重建，已经包含了重建算法的偏差
- **MRI成像**：全采样MRI扫描时间长（分钟级），患者无法长时间保持静止；加速采集是刚需，但"全采样参考"本身可能也有伪影
- **Cryo-EM**：信噪比极低（SNR < 0.1），"干净"图像根本不存在——每帧观测都是极度噪声化的
- **天文成像**：望远镜获取的图像总是受到大气扰动和探测器噪声的影响，无法获取"无噪声"版本

**分布偏移**是另一个容易被忽视的问题。即使有干净数据，训练数据的分布可能与测试数据不同（Belthangady & Royer 2019）。例如，用健康志愿者数据训练的去噪器可能无法正确处理病理图像——因为病理图像的"信号分布"超出了训练分布。

这些困境指向一个核心问题：**能否仅从带噪观测$\{y_i\}$训练重建网络，而不需要任何干净参考$x_i$？**

## 17.1.2 四种学习设定的统一框架

根据训练数据的可用性，可以将学习设定分为四种，构成数据需求的递减谱系：

### 设定1：监督学习（Supervised）

$$\text{数据}：\{(x_i, y_i)\}_{i=1}^N \quad \text{配对的干净-退化数据}$$
$$\text{目标}：\min_f \mathbb{E}_{x,y}\|x - f(y)\|^2$$

这是最理想的情况。有配对数据，直接用MSE损失训练即可。第16章的UNet端到端重建和算法展开都依赖这个设定。

**优势**：理论最优（MSE最优解=MMSE估计器$\mathbb{E}[x|y]$）；实现简单
**局限**：需要配对数据，在很多场景中不可获取

### 设定2：合成配对学习（已知噪声模型）

$\text{数据}：\{x_i\}_{i=1}^N + \text{噪声模型} \; p(y|x) \quad \text{干净图像+已知噪声分布}$

虽然没有配对数据，但噪声模型已知（如$y = x + \varepsilon, \varepsilon \sim \mathcal{N}(0, \sigma^2 I)$），因此可以合成配对数据：采样$\varepsilon_i \sim p_\varepsilon$，构造$y_i = x_i + \varepsilon_i$，然后按监督方式训练。

**注意**：此设定仍需干净图像，与本章后续讨论的"自监督风险估计"（仅用$\{y_i\}$）不同。这里称之为"合成配对学习"以避免混淆。

**优势**：不需要真实的配对测量数据
**局限**：仍需干净图像$x_i$；噪声模型必须已知且准确

### 设定3：无监督-x（Unsupervised-x，仅干净图像）

$\text{数据}：\{x_i\}_{i=1}^N \quad \text{仅干净图像}$

只有干净图像，噪声模型未知。策略是先学习先验分布$p(x)$（如通过Tweedie公式或生成模型），再自适应地确定噪声模型。

**与第6章的联系**：第6章的得分匹配和第7章的扩散模型训练正是这种设定——从干净图像学习$p(x)$的得分函数，无需噪声观测。

**优势**：不需要任何噪声观测
**局限**：需要干净图像（很多场景仍不可获取）

### 设定4：无监督-y（Unsupervised-y，仅噪声观测）

$\text{数据}：\{y_i\}_{i=1}^N \quad \text{仅噪声观测}$

这是最困难但也最实用的设定——只有带噪观测，既没有干净参考，也可能不知道噪声模型。Cryo-EM、天文成像等场景都属于此类。

**特殊子设定——配对噪声观测**：Noise2Noise（17.2节）需要同一信号的多帧独立噪声观测$(y, y')$——数据需求介于设定1和设定4之间。

**优势**：数据需求最低，最贴合实际
**局限**：需要特殊的自监督技术

**关键观察**：从设定1到设定4，数据需求逐步降低，但技术挑战逐步升高。本章的重点正是**设定4**——如何仅从噪声观测$\{y_i\}$训练重建网络。

## 17.1.3 自监督风险估计器的目标

设定4的核心挑战是：如何仅从$\{y_i\}$构建训练目标？

**朴素思路**：直接用$\|y - f(y)\|^2$作为损失？不行——这会低估真实风险，因为$f$可以"拟合噪声"使残差很小，但重建结果远离$x$。

**正确思路**：构建一个自监督损失$\mathcal{L}_{\text{SELF}}(y, f)$，使其期望等于监督风险（加常数）：

$$\boxed{\mathbb{E}_y[\mathcal{L}_{\text{SELF}}(y, f)] = \mathbb{E}_{x,y}\|x - f(y)\|^2 + \text{const.}}$$

这个等式意味着：
- **无偏估计**：自监督损失的期望与监督风险成正比
- **相同全局最小值**：$\text{argmin}_f \mathbb{E}_y[\mathcal{L}_{\text{SELF}}] = \text{argmin}_f \mathbb{E}_{x,y}\|x - f(y)\|^2$
- **在受限函数族$\mathcal{F}$中也有相同最小值**（这对网络架构的选择很重要）

更精细地分析，等价性有三个层次：

1. **无偏但不够**：$\mathbb{E}_y[\mathcal{L}_{\text{SELF}}] = R_{\text{SUP}} + c$仅保证期望一致，但最小值位置可能不同（常数$c$依赖$f$时不影响，但若$c$随$f$变化则有问题）

2. **全局最优一致**：$\text{argmin}_f \mathbb{E}[\mathcal{L}_{\text{SELF}}] = \text{argmin}_f R_{\text{SUP}}$——这已经很好，但若函数族$\mathcal{F}$受限，最小值可能不同

3. **约束最优一致**：$\text{argmin}_{f \in \mathcal{F}} \mathbb{E}[\mathcal{L}_{\text{SELF}}] = \text{argmin}_{f \in \mathcal{F}} R_{\text{SUP}}$——最强的等价性

MMSE最优性的参考点是后验均值：

$$f^*(y) = \mathbb{E}[x|y] = \text{argmin}_f \mathbb{E}_{x,y}\|x - f(y)\|^2$$

理想的自监督方法应使$\text{argmin}_f \mathbb{E}[\mathcal{L}_{\text{SELF}}] = \mathbb{E}[x|y]$——即自监督最优解等于MMSE估计器。我们将看到，SURE满足这一条件，而盲点网络由于施加了额外约束，其最优解只是受限最优。

## 本节小结

| 学习设定 | 数据需求 | 核心挑战 |
|---------|---------|---------|
| 监督 | $\{(x_i, y_i)\}$ | 数据获取 |
| 合成配对(已知噪声) | $\{x_i\}$ + 噪声模型 | 仍需干净图像 |
| 无监督-x | $\{x_i\}$ | 噪声模型未知；需学习先验（第6-7章） |
| 无监督-y | $\{y_i\}$ | 构建等价于监督的自监督损失 |
| N2N(配对噪声) | $\{(y_i, y_i')\}$ | 需配对噪声观测 |

核心目标：构建$\mathcal{L}_{\text{SELF}}(y, f)$使得$\mathbb{E}_y[\mathcal{L}_{\text{SELF}}] = R_{\text{SUP}} + c$，从而仅用$\{y_i\}$即可训练与监督学习等价的重建网络。

> **过渡**：最简单的自监督思路是——既然无法获取干净标签，能否用另一帧噪声数据替代？如果噪声是零均值的，那么另一帧噪声的期望恰好就是干净信号本身。这就是Noise2Noise的核心洞察。
