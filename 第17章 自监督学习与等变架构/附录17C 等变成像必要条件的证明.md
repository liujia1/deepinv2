# 附录17C 等变成像必要条件的证明

> 定位：17.5.3节给出了定理陈述，本附录提供完整证明。

## A. 虚拟算子的秩分析

**设定**：给定测量算子$A \in \mathbb{R}^{m \times n}$（$m < n$），变换群$G$，变换$T_g$。

**虚拟算子**：$A_g = AT_g$，即先对信号做变换$T_g$，再用$A$测量。

**目标**：分析$\mathbb{E}_g[A_g^\top A_g] = \mathbb{E}_g[T_g^\top A^\top A T_g]$的秩。

## B. 等变算子的退化情况

**命题**：若$A$是$G$-等变的（即$AT_g = T_g A$对所有$g \in G$），则

$$\text{rank}\left(\mathbb{E}_g[T_g^\top A^\top A T_g]\right) = \text{rank}(A^\top A) = m < n$$

### 证明

若$AT_g = T_g A$，则$A_g = AT_g = T_g A$，因此：

$$A_g^\top A_g = (T_g A)^\top(T_g A) = A^\top T_g^\top T_g A$$

若$T_g$是正交变换（$T_g^\top T_g = I$），则：

$$A_g^\top A_g = A^\top A$$

因此：

$$\mathbb{E}_g[A_g^\top A_g] = A^\top A$$

其秩为$\text{rank}(A^\top A) = m < n$（因为$A$是$m \times n$且$m < n$）。

这意味着：当$A$是$G$-等变的时，虚拟算子$AT_g$与$A$完全等价——它们的零空间相同，等变性无法提供任何新信息。$\blacksquare$

## C. 非等变算子的满秩条件

**定理**（Tachella et al. 2023, JMLR）：等变成像的满秩条件要求$A$不是$G$-等变的。具体地，若存在$g \in G$使得$AT_g \neq T_g A$，则在适当的群分布下：

$$\text{rank}\left(\mathbb{E}_g[T_g^\top A^\top A T_g]\right) > \text{rank}(A^\top A) = m$$

即虚拟算子的联合秩严格大于单个算子的秩——等变性提供了新信息。

### 证明思路

**第一步**：定义"缺陷矩阵"$D_g = AT_g - T_g A$。$A$是$G$-等变的当且仅当$D_g = 0$对所有$g$。

**第二步**：若$D_g \neq 0$（$A$不是$G$-等变的），则$AT_g$的值空间与$A$的值空间不同。具体地：

$$AT_g = T_g A + D_g$$

$D_g$的非零部分恰好包含了$A$的零空间中被$AT_g$覆盖的额外方向。

**第三步**：对群取平均：

$$\mathbb{E}_g[T_g^\top A^\top A T_g] = \mathbb{E}_g[A^\top T_g^\top T_g A] + \mathbb{E}_g[T_g^\top A^\top D_g]$$

$$= A^\top A + \mathbb{E}_g[T_g^\top A^\top(AT_g - T_g A)]$$

第二项$\mathbb{E}_g[T_g^\top A^\top(AT_g - T_g A)]$在$A$不是$G$-等变时非零，它包含了零空间方向的额外信息。

**第四步**：当$D_g$在群元素上变化足够丰富时，$\mathbb{E}_g[T_g^\top A^\top D_g]$的秩可以使联合矩阵$\mathbb{E}_g[T_g^\top A^\top AT_g]$的秩超过$m$。$\blacksquare$

## D. 具体算子的分析

### 图像修复（Inpainting）+ 平移群

设$A$是保留像素位置集合$\Omega$的掩码算子。对平移$T_g$：

- $AT_g$：先平移图像，再保留$\Omega$位置的像素——等价于保留平移后的位置集$T_g\Omega$
- $T_g A$：先保留$\Omega$位置的像素，再平移——等价于保留$\Omega$位置但结果被平移

一般地$AT_g \neq T_g A$（除非$\Omega$是周期性的），因此平移等变性在inpainting中可用。

### 加速MRI + 平移群

MRI的正向算子$A = M_\Omega F$（欠采样傅里叶），其中$F$是傅里叶变换。

- $AT_g = M_\Omega F T_g = M_\Omega T_g F$（傅里叶变换与平移可交换，$FT_g = T_g^{(\text{freq})}F$）
- $T_g A = T_g M_\Omega F$

若$M_\Omega$是固定的k-space掩码，$T_g M_\Omega = M_\Omega T_g$（平移不改变掩码），因此$AT_g = T_g^{(\text{freq})}M_\Omega F \neq T_g M_\Omega F = T_g A$——除非$T_g^{(\text{freq})} = T_g$（平移在频域和空间域的等变性关系）。

实际上，对于Cartesian采样模式，$F$和空间平移$T_g$的关系为$FT_g = \text{mod}(\cdot, \text{period})F$，因此$AT_g \neq T_g A$，平移等变性在加速MRI中**部分可用**（取决于掩码结构）。

### 稀疏视角CT + 任意群

Radon变换$\mathcal{R}$关于旋转是等变的（$\mathcal{R}T_g^{\text{rot}} = T_g^{\text{rot, sino}}\mathcal{R}$），但稀疏视角CT的采样模式$M$关于旋转不是等变的（采样角度不随旋转变化）。因此$AT_g = M\mathcal{R}T_g = MT_g^{\text{rot, sino}}\mathcal{R} \neq T_g M\mathcal{R} = T_g A$——旋转等变性在稀疏视角CT中可用。

类似地，平移等变性在CT中也通常可用（因为Radon变换关于平移不是等变的——平移改变sinogram的相位）。
