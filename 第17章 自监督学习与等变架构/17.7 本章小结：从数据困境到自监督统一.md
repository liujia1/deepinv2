# 17.7 本章小结：从数据困境到自监督统一

## 方法谱系的统一视角

本章从"没有干净数据如何训练重建网络"这一根本问题出发，逐步构建了自监督学习的完整框架。所有方法共享同一目标：构建仅依赖观测$y$的损失$\mathcal{L}_{\text{SELF}}$，使其期望等于监督MSE风险。不同方法用不同策略实现这一目标，适用于不同的数据条件和噪声模型：

| 方法 | 数据需求 | 噪声知识 | MMSE最优 | A≠I支持 | 核心机制 |
|------|---------|---------|---------|--------|---------|
| 监督学习 | 配对$(x,y)$ | 任意 | ✅ | ✅ | 直接MSE |
| Noise2Noise | 配对$(y,y')$ | 零均值 | ✅ | ❌ | 零均值替代 |
| SURE | 单帧$y$ | 已知$\sigma^2$ | ✅ | 需组合EI | 自由度修正 |
| R2R | 单帧$y$ | 已知$\sigma^2$ | ✅ | 需组合EI | 重新加噪 |
| 盲点网络 | 单帧$y$ | 逐像素独立 | ❌ | 需组合EI | 结构约束 |
| UNSURE | 单帧$y$ | 未知$\sigma^2$ | ≈ | 需组合EI | Lagrange自适应 |
| EI+UNSURE | 单帧$y$ | 未知$\sigma^2$ | ≈ | ✅ | 对称性+自适应 |

方法的演化遵循一条清晰的逻辑链：

```
Noise2Noise ──→ SURE ──→ R2R ──→ 盲点网络 ──→ UNSURE ──→ EI+UNSURE
   │              │        │         │              │           │
   │需要配对      │需知σ²   │需知σ²    │次优           │σ²未知      │A≠I
   │噪声数据      │散度计算  │避免散度   │实现简单       │Lagrange    │零空间约束
   ▼              ▼        ▼         ▼              ▼           ▼
   └──────────────┴────────┴─────────┴──────────────┴───────────┘
                    每一步都是前一步局限性的回应
```

## 与全书叙事的呼应

### SURE→Tweedie闭环

本章最重要的理论贡献是SURE→Tweedie闭环，它将自监督学习与全书的核心理论链连接起来：

```
噪声数据 → SURE训练 → 去噪器f* → Tweedie公式 → 得分函数 → 扩散采样
```

- **第5章**：Tweedie等式连接了去噪器与得分函数，$\nabla\log p_\varepsilon(y) = (f^*(y) - y)/\sigma^2$
- **第6章**：得分匹配从数据中学习得分函数，训练去噪器
- **本章**：即使没有干净数据，SURE也能训练出去噪器，其最优解就是Tweedie公式

这条链意味着：**从噪声数据出发，通过自监督训练，我们同样可以获得可驱动PnP和扩散采样的得分估计器**——干净数据不再是必要条件。

### 先验的演化

从第2章到本章，先验的形式经历了以下演化：

```
显式先验(TV/小波) → 学习型先验(UNet/展开) → 隐式先验(扩散) → 对称性先验(等变)
    第2-3章             第16章               第13章            第17章
```

等变架构代表了一种新型的先验——不是从数据中学习，而是从物理世界的对称性中"继承"。这与第2章的显式先验有本质区别：显式先验是人为设计的（TV假设分段常数），而对称性先验是物理规律所决定的（自然图像平移不变）。

### 数据瓶颈的解决

第16章的扩散先验"不需要配对训练数据"（预训练模型可直接用于新逆问题），但扩散模型本身的训练仍需大量干净图像。本章进一步使**训练去噪器也不需要配对数据**——甚至连噪声水平都不需要知道。这使得全书的核心论点更加完整：

**从逆问题出发，经过贝叶斯→采样→得分→扩散的漫长旅途，最终连训练数据都不再是障碍。**

## 与第18章的衔接

第18章的综合项目将整合本章的自监督训练方法与扩散模型，实现端到端的零样本逆问题求解管线：

1. **自监督训练去噪器**：用SURE/UNSURE从噪声观测训练去噪器
2. **去噪器作为得分估计器**：通过Tweedie等式将去噪器转化为得分函数
3. **扩散采样求解逆问题**：用学习到的得分驱动条件扩散采样

这条管线**从零开始**——不需要干净数据，不需要预训练模型，只需要带噪观测数据。这正是"扩散模型是逆问题自然发展的终点"这一核心论点在实践中的最终落地。

## 展望

自监督学习仍有一些开放问题：

- **非线性逆问题**：本章的方法主要针对线性正向模型$y = Ax + \varepsilon$，非线性问题的自监督训练更具挑战
- **复杂噪声模型**：空间相关噪声、信号依赖噪声（如Poisson）的自监督方法仍在发展中
- **与扩散模型的深度整合**：用SURE训练扩散模型（Daras et al. 2024）是一个新兴方向
- **不确定性量化的自监督**：SURE本身可用于估计重建误差（SURE4SURE, Bellec et al. 2021），但系统性的自监督不确定性量化框架仍待完善
