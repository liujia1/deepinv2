# 17.7 本章小结：从数据困境到自监督统一

> "自监督不是监督学习的低配山寨版，而是一个有独立理论根基的完整框架——它让全书的逆问题长旅，连训练数据都不再是障碍。"

**本章目标回顾**（我们这一章实际带走了什么）：
- 看清"干净数据稀缺"是全书实践的真正瓶颈；
- 排出了"数据需求递减"的学习设定谱系，知道自己在第几档；
- 学会了 Noise2Noise / SURE / R2R / 盲点 / UNSURE / 等变 各怎么填坑；
- 串起了"噪声数据 → SURE → Tweedie → 得分 → 扩散"这条闭环；
- 为第 18 章"零样本端到端逆问题管线"铺好了路。

---

本章从一个根本问题出发："没有干净数据，怎么训练重建网络？"我们一步步搭起了自监督学习的完整框架。所有方法共享同一目标——造一个只依赖观测 $y$ 的损失 $\mathcal{L}_{\text{SELF}}$，让它的期望等于监督 MSE 风险。不同方法用不同策略实现，适用于不同数据条件和噪声模型。

## 方法谱系的统一视角

| 方法 | 数据需求 | 噪声知识 | MMSE 最优 | $A\neq I$ 支持 | 核心机制 |
|------|---------|---------|---------|--------|---------|
| 监督学习 | 配对 $(x,y)$ | 任意 | ✅ | ✅ | 直接 MSE |
| Noise2Noise | 配对 $(y,y')$ | 零均值 | ✅ | ❌ | 零均值替代 |
| SURE | 单帧 $y$ | 已知 $\sigma^2$ | ✅ | 需组合 EI | 自由度修正 |
| R2R | 单帧 $y$ | 已知 $\sigma^2$ | ✅ | 需组合 EI | 重新加噪 |
| 盲点网络 | 单帧 $y$ | 逐像素独立 | ❌ | 需组合 EI | 结构约束 |
| UNSURE | 单帧 $y$ | 未知 $\sigma^2$ | ≈ | 需组合 EI | Lagrange 自适应 |
| EI+UNSURE | 单帧 $y$ | 未知 $\sigma^2$ | ≈ | ✅ | 对称性 + 自适应 |

方法的演化是一条清晰的逻辑链——**每一步都是对前一步短板的回应**：

```
Noise2Noise ──→ SURE ──→ R2R ──→ 盲点网络 ──→ UNSURE ──→ EI+UNSURE
   │              │        │         │              │           │
   │需配对         │需知σ²   │需知σ²   │次优           │σ²未知      │A≠I
   │噪声数据       │散度计算  │避散度    │实现简单        │Lagrange    │零空间约束
   ▼              ▼        ▼         ▼              ▼           ▼
   └──────────────┴────────┴─────────┴──────────────┴───────────┘
```

因为 Noise2Noise 需要配对噪声数据，所以 SURE 把它降到单帧 $y$；因为 SURE 要算散度又需知 $\sigma^2$，所以 R2R 绕开散度、盲点网络干脆不用散度、UNSURE 把 $\sigma^2$ 也估出来；又因为这些方法在 $A\neq I$ 时栽在零空间，所以等变成像借对称性把零空间补上。因果一环扣一环。

回看整张表，一条主线始终清晰：**每一代都在问同一个问题——还能再把哪种"外部便利"省掉？** 干净标签省掉了（N2N→SURE）、配对观测省掉了（SURE→单帧）、散度计算省掉了（SURE→R2R/盲点）、噪声知识省掉了（SURE/R2R→UNSURE）、算子知识也被对称性替代了（MOI→EI）。与之相对的，是每一代都从数据的**内在结构**里重新调用某种统计量来补偿——从噪声均值，到散度，到独立副本，到盲点约束，到对称群。这正是本章要你记住的那件事：**自监督的进化，不是"越来越省力"的偷懒史，而是"越来越懂得从数据内部自我供给监督信号"的智慧史。**

## 统一框架：噪声与对称，是同一种"内在老师"的两种形态

让我们把这些方法的知识放回 §17.1 立下的总纲。当时我们承诺：从设定 4 这类"看似什么都没有"的数据里，噪声的统计结构本身会培养出一个堪当大任的"虚拟老师"。走完全章，这个承诺兑现了，而它的面貌比预想更统一：

- **Noise2Noise / SURE / R2R / 盲点 / UNSURE** 这一簇，老师藏在**噪声的统计**里——零均值、散度、独立副本、逐像素独立、未知方差的自适应；
- **等变成像 / 等变架构**这一簇，老师藏在**信号的几何**里——平移、旋转这些对称性本身就是一套天然的约束。

**从更深层次看，这两簇是同一条原理的两副面孔**：噪声的统计和信号的对称，本质上都是数据分布的"内在结构"。自监督的成功，不在于发明了什么花哨的目标函数，而在于一遍遍地把同一个朴素信念落到可计算的实处——**当我们不再依赖外部的干净老师，数据内部的结构（统计的、几何的）就会亲自出场，充当一位和监督者同等水平的老师。** 这就是"从数据困境到自监督统一"这八个字的分量。

> 这一认识也反过来照亮了全书：第 2 章我们说先验是"结构化知识"，第 13 章我们说扩散先验是从干净数据里学到的隐式先验；本章则证明，即便连干净数据都缺席，先验的一半内容——噪声统计与对称性——仍然可以自己从原始观测里长出来。这让我们对"先验可从数据内在结构习得"有了最彻底的信心。

## 与全书叙事的呼应

### SURE → Tweedie 闭环

本章最重要的理论贡献，是把自监督学习和全书核心理论链接了起来：

```
噪声数据 → SURE训练 → 去噪器f* → Tweedie公式 → 得分函数 → 扩散采样
```

- **第 5 章**：Tweedie 等式连接去噪器与得分函数，$\nabla\log p_\varepsilon(y) = (f^*(y) - y)/\sigma^2$；
- **第 6 章**：得分匹配从数据学得分、训去噪器；
- **本章**：即使没有干净数据，SURE 也能训出这个去噪器，且最优解就是 Tweedie 公式。

这条链的意义：**从噪声数据出发，通过自监督训练，我们同样能拿到驱动 PnP 和扩散采样的得分估计器**——干净数据不再是必要条件。

### 先验的演化

从第 2 章到本章，先验的形式一路演化：

```
显式先验(TV/小波) → 学习型先验(UNet/展开) → 隐式先验(扩散) → 对称性先验(等变)
    第2-3章             第16章               第13章            第17章
```

等变架构代表一种**新型先验**——不是从数据里学，而是从物理世界的对称性里"继承"。这和显式先验有本质区别：显式先验（如 TV）是人为假设设计的（假设图像分段常数），对称性先验是物理规律决定的（自然图像平移不变）。这也呼应了你在本章开头读到的"焊进架构"思路——把对称性的归纳偏置（inductive bias，指"网络天生偏向某类解"的先天结构）直接做进网络。

> **顺着"先验演化"这条线，我们能看到本书最核心的命题在第 17 章走到了末端**：逆问题求解所需的先验，从"人手工指定"（TV/小波），到"从干净数据里学"（学习型、隐式扩散），再到"从数据的内在结构里自己长"（噪声统计、信号对称）。先验的来源一路向内收拢，直到连"干净数据"这条最初的生命线都不再必要。这正是"自监督统一"这句话的完整含义。

### 数据瓶颈的解决

第 16 章的扩散先验"不需要配对训练数据"（预训练模型可直接用于新逆问题），但扩散模型本身的训练仍需大量干净图。本章更进一步——**连训练去噪器都不需要配对数据**，甚至噪声水平都不必知道。这让全书核心论点更完整：

> **从逆问题出发，经贝叶斯→采样→得分→扩散的漫长旅途，最终连训练数据都不再是障碍。**

## 与第 18 章的衔接

第 18 章的综合项目会把本章的自监督训练与扩散模型整合，实现端到端的零样本逆问题求解管线：

1. **自监督训去噪器**：用 SURE/UNSURE 从噪声观测训去噪器；
2. **去噪器当得分估计器**：通过 Tweedie 等式把去噪器转成得分函数；
3. **扩散采样解逆问题**：用学到的得分驱动条件扩散采样。

这条管线**从零开始**——不需要干净数据、不需要预训练模型，只要带噪观测。这正是"扩散模型是逆问题自然发展的终点"这一核心论点在实践中的最终落地。

## 展望（开放问题）

- **非线性逆问题**：本章方法主要针对线性正向模型 $y = Ax + \varepsilon$，非线性的自监督训练更具挑战；
- **复杂噪声模型**：空间相关噪声、信号依赖噪声（如 Poisson）的自监督方法仍在发展中；
- **与扩散模型深度整合**：用 SURE 训扩散模型（Daras et al. 2024）是新方向；
- **自监督的不确定性量化**：SURE 本身可估重建误差（SURE4SURE, Bellec et al. 2021），但系统性的自监督不确定性框架仍待完善。

## 直觉：等变"焊进架构"，与一个最简自监督 pretext

**等变性靠结构而非训练保证。** 普通卷积因为权值共享，天然对"平移"等变：把输入循环平移（用 circular 填充保证边界首尾相接、不丢信息），输出也会平移同样的量——"先转输入再卷积"和"先卷积再转输出"两条路径逐像素一致，差可达机器精度量级。这类对称性不靠数据、不靠训练，而是由架构直接写死，所以叫"焊进架构"；更复杂的旋转等变则需群卷积 / Steerable CNN（见 17.6.3）。它的可训练实证见配套实验 **17.6-1（Step 2、4）**。

**最简 Noise2Noise 直觉。** 回到本章最初那条信念——零均值噪声的期望就是信号。设想同一干净信号 $x$ 有两帧独立带噪观测 $y,y'$；若网络从 $y$ 出发、以 $y'$ 为标签做 MSE 回归，其最优解与直接对真实 $x$ 回归完全相同（交叉项里 $\mathbb{E}[\varepsilon']=0$ 把噪声消掉了）。于是**即便标签本身也是脏的，网络学到的仍是干净信号**，去噪 MSE 会明显低于"直接把噪声图当答案"的基线。这正是 17.2 的核心，配套的完整 MNIST 训练与四设定对比见配套实验 **17.2-1（Step 2–3）**。

## 收尾：为什么这件事重要

回到本章开篇立下的那个最根本的问题：没有干净数据，怎么训练重建网络？现在可以给出一个完成度很高的答案——**自监督学习把"需要干净标签"这条铁律废止了，它用噪声本身、用对称性本身，造出和监督一样好的老师。**

这意味着全书从逆问题出发、经贝叶斯到扩散的整条路，最后的最后一块拼图也嵌上了：哪怕一张干净图都没有，你照样能训出驱动采样、驱动重建的网络。数据困境，不再是困境。而真正让这一章与本书其余部分连成一体的，是那句一路被反复印证的判断——**先验与监督信号，既可以来自人类的经验，也可以从数据的内在结构（噪声统计与信号对称）中自行习得。** 正是这种"自我供给"的能力，让逆问题求解的信仰最终闭合：智能不必等别人来教，它可以从混乱的数据自己长出来。
