# 17.3 SURE：Stein无偏风险估计与R2R

> **核心观点**：SURE仅利用单帧噪声观测$y$，通过添加"自由度修正项"无偏估计监督MSE风险——这是自监督学习的理论基石。SURE的最优解恰好是Tweedie公式，与第5章形成闭环。R2R提供了避免散度计算的实用替代方案。

## 17.3.1 监督风险与自监督风险的桥梁

回到核心问题：能否仅从单帧观测$y$无偏估计监督风险$R_{\text{SUP}}(f) = \mathbb{E}_{x,y}\|x - f(y)\|^2$？

**朴素自监督损失**：$\|y - f(y)\|^2$

这个损失可直接计算（只需$y$），但它是否是$R_{\text{SUP}}$的无偏估计？展开分析：

$$\mathbb{E}_y\|y - f(y)\|^2 = \mathbb{E}_{x,y}\|(y - x) + (x - f(y))\|^2$$

利用$\varepsilon = y - x$：

$$= \mathbb{E}\|\varepsilon\|^2 + \mathbb{E}\|x - f(y)\|^2 + 2\mathbb{E}[\varepsilon^\top(x - f(y))]$$

$$= n\sigma^2 + R_{\text{SUP}}(f) + 2\mathbb{E}[\varepsilon^\top(x - f(y))]$$

**关键项**：$\mathbb{E}[\varepsilon^\top(x - f(y))] = -\mathbb{E}[\varepsilon^\top f(y)] + \mathbb{E}[\varepsilon^\top x]$

其中$\mathbb{E}[\varepsilon^\top x] = 0$（$\varepsilon$与$x$独立且$\mathbb{E}[\varepsilon]=0$），但$\mathbb{E}[\varepsilon^\top f(y)]$一般不为零——**因为$f(y)$依赖于$y = x + \varepsilon$，所以$f(y)$与$\varepsilon$相关**。

这意味着朴素MSE损失有偏：$\mathbb{E}\|y - f(y)\|^2 \neq R_{\text{SUP}}(f) + c$。偏差的方向是$\|y - f(y)\|^2$系统地低估$R_{\text{SUP}}(f)$——因为网络可以"拟合噪声"使残差变小。

**SURE的核心洞察**：$\mathbb{E}[\varepsilon^\top f(y)]$可以用$\sigma^2 \mathbb{E}[\text{div}\, f(y)]$替代（Stein引理），从而消除对$x$的依赖。

## 17.3.2 Stein引理与SURE公式推导

**Stein引理**：设$y|x \sim \mathcal{N}(x, \sigma^2 I_n)$，$f: \mathbb{R}^n \to \mathbb{R}^n$是弱可微函数，则

$$\mathbb{E}[\varepsilon^\top f(y)] = \sigma^2 \mathbb{E}\left[\sum_{i=1}^n \frac{\partial f_i}{\partial y_i}(y)\right] = \sigma^2 \mathbb{E}[\text{div}\, f(y)]$$

**直觉**：当$y$的某个分量$y_i$增加时，$f_i(y)$如果也增加（$\partial f_i/\partial y_i > 0$），说明$f$在"追踪噪声"——这正是过拟合的表现。Stein引理将这种"追踪噪声"的倾向量化为散度$\text{div}\, f = \sum_i \partial f_i / \partial y_i$。

**SURE公式的推导**：

由17.3.1节的分析：

$$R_{\text{SUP}}(f) = \mathbb{E}_y\|y - f(y)\|^2 - n\sigma^2 - 2\mathbb{E}[\varepsilon^\top(x - f(y))]$$

$$= \mathbb{E}_y\|y - f(y)\|^2 - n\sigma^2 + 2\mathbb{E}[\varepsilon^\top f(y)] - 2\mathbb{E}[\varepsilon^\top x]$$

利用Stein引理替代$\mathbb{E}[\varepsilon^\top f(y)] = \sigma^2 \mathbb{E}[\text{div}\, f(y)]$和$\mathbb{E}[\varepsilon^\top x] = 0$：

$$R_{\text{SUP}}(f) = \mathbb{E}_y\left[\|y - f(y)\|^2 + 2\sigma^2 \text{div}\, f(y) - n\sigma^2\right]$$

因此定义SURE损失：

$$\boxed{\mathcal{L}_{\text{SURE}}(y, f) = \|y - f(y)\|^2 + 2\sigma^2 \sum_{i=1}^n \frac{\partial f_i}{\partial y_i}(y)}$$

**无偏性**：

$$\mathbb{E}_y[\mathcal{L}_{\text{SURE}}(y, f)] = R_{\text{SUP}}(f) + n\sigma^2$$

常数$n\sigma^2$不影响最小化，因此：

$$\text{argmin}_f \mathbb{E}_y[\mathcal{L}_{\text{SURE}}] = \text{argmin}_f R_{\text{SUP}}(f) = \mathbb{E}[x|y]$$

**SURE的两个组成部分**：
- $\|y - f(y)\|^2$：**残差项**——直觉上，好的$f$应使输出接近输入，但单看这一项会低估风险
- $2\sigma^2 \text{div}\, f(y)$：**自由度修正项**——补偿$f$拟合噪声的倾向，$\text{div}\, f$越大（$f$越"灵活"），修正越大

这种结构与统计中的AIC/BIC信息准则完全类比：AIC = 对数似然 + 自由度惩罚。

## 17.3.3 散度的计算：Monte Carlo SURE与Autodiff SURE

SURE的实用瓶颈是散度$\text{div}\, f(y) = \sum_{i=1}^n \partial f_i / \partial y_i$的计算。对神经网络$f$，精确计算需要对$y$的每个分量做一次反向传播，总计算量$O(n)$——对于高维图像（$n$可达百万级）不可接受。

### Monte Carlo SURE

Ramani et al. (2007) 提出用随机投影近似散度：

$$\sum_{i=1}^n \frac{\partial f_i}{\partial y_i}(y) \approx \frac{1}{\alpha}\omega^\top[f(y + \alpha\omega) - f(y)]$$

其中$\omega \sim \mathcal{N}(0, I_n)$，$\alpha$是小常数。

**原理**：这是方向导数的有限差分近似。$\omega^\top \frac{\partial f}{\partial y}\omega$是散度在随机方向$\omega$上的投影，取期望后恢复完整散度：

$$\mathbb{E}_\omega\left[\frac{1}{\alpha}\omega^\top(f(y + \alpha\omega) - f(y))\right] \xrightarrow{\alpha \to 0} \mathbb{E}_\omega\left[\omega^\top \frac{\partial f}{\partial y}\omega\right] = \text{div}\, f(y)$$

**计算代价**：仅需2次前向传播（$f(y)$和$f(y + \alpha\omega)$），与精确散度的$O(n)$次反向传播形成鲜明对比。

### Autodiff SURE

Soltanayev et al. (2020) 利用自动微分直接计算Hutchinson迹估计：

$$\text{div}\, f(y) = \text{tr}\left(\frac{\partial f}{\partial y}\right) \approx \omega^\top \frac{\partial f}{\partial y}\omega$$

其中$\omega \sim \mathcal{N}(0, I_n)$。

**与第6章的联系**：这正是第6章6.4节介绍的Hutchinson迹估计——同一技术在得分匹配和SURE中扮演着同样的角色：**避免Jacobian的精确计算**。

## 17.3.4 SURE→Tweedie闭环：得分函数的自监督学习

SURE不仅是风险估计工具——它的最优解揭示了一个深刻的联系。

对SURE做变分：考虑$f$的扰动$f + \delta g$，令$\delta \to 0$：

$$\frac{\delta}{\delta f}\mathbb{E}_y[\mathcal{L}_{\text{SURE}}] = 0 \implies f^*(y) - y + \sigma^2 \nabla_y \cdot I = 0$$

更严格地，通过分部积分可以证明（详见附录17A），SURE的最优解为：

$$\boxed{f^*(y) = y + \sigma^2 \nabla_y \log p_y(y)}$$

**这正是Tweedie公式！**（第5章5.3节）

这个结果令人震撼——它意味着：

1. **SURE闭环**：用SURE训练的去噪器，其最优解恰好是Tweedie公式——去噪器=信号+噪声方差×得分函数
2. **与第5章的呼应**：第5章告诉我们"去噪器=得分估计器"，第6章告诉我们"得分匹配训练去噪器"，本章告诉我们"即使没有干净数据，SURE也能训练出去噪器，其最优解就是Tweedie公式"
3. **从噪声数据到扩散模型**：从噪声数据→SURE训练→去噪器→Tweedie→得分函数→扩散采样——即使没有干净数据，也能获得可驱动扩散采样的得分估计器

**Noise2Score**（Kim & Ye 2021）：这一方法的思路正是——从噪声数据学习$\nabla_y \log p_y(y)$（得分函数），再用Tweedie公式去噪。这与第6章的得分匹配训练和第7章的扩散模型形成了完整的闭环。

**Daras et al. (2024)** 进一步证明：扩散模型本身可以用SURE训练——这意味着**扩散模型的训练也可以完全自监督**，不需要任何干净数据。

## 17.3.5 R2R：避免散度计算的SURE替代

SURE有一个实用痛点：散度项$\text{div}\, f(y)$需要Monte Carlo近似或自动微分，计算代价高，且对$f$的可微性有要求。R2R（Recorrupted-to-Recorrupted）提供了完全避免散度计算的替代方案。

### 核心思想

Pang et al. (2021) 的关键观察：通过"重新加噪"构造两个独立的噪声副本，它们之间的MSE可以替代SURE。

**构造**：给定观测$y$，定义

$$y_a = y + \alpha\omega, \quad y_b = y - \omega/\alpha$$

其中$\omega \sim \mathcal{N}(0, \sigma^2 I_n)$，$\alpha \in \mathbb{R}$是参数。

**关键性质**：$y_a$和$y_b$在给定$x$时条件独立。

**证明**：$y_a = x + \varepsilon + \alpha\omega$，$y_b = x + \varepsilon - \omega/\alpha$。定义$\varepsilon_a = \varepsilon + \alpha\omega$，$\varepsilon_b = \varepsilon - \omega/\alpha$。可以验证$\text{Cov}(\varepsilon_a, \varepsilon_b | x) = \sigma^2 I - \sigma^2 I = 0$（联合高斯下协方差为零即独立）。$\blacksquare$

**R2R损失**：

$$\boxed{\mathcal{L}_{\text{R2R}}(y, f, \alpha) = \mathbb{E}_\omega\|y_b - f(y_a)\|^2}$$

### 与SURE的关系

**渐近等价性**：

$$\lim_{\alpha \to 0} \mathcal{L}_{\text{R2R}}(y, f, \alpha) = \mathcal{L}_{\text{SURE}}(y, f)$$

直觉：当$\alpha \to 0$时，$y_a \to y$，$y_b$成为$y$的"正交投影"，R2R损失退化为SURE。严格证明见附录17B。

**实践中的$\alpha$选择**：$\alpha$不能太小（数值不稳定），也不能太大（近似误差大）。典型选择$\alpha \in [0.01, 0.1]$。

### Generalized R2R

Monroy, Bacca & Tachella (CVPR 2025) 将R2R推广到更一般的噪声模型：
- **Poisson噪声**：重新采样泊松噪声构造副本
- **Gamma噪声**：利用Gamma分布的可加性
- **Binomial噪声**：二项分布的重新采样

这些推广使得R2R可以处理更广泛的科学成像噪声模型。

### SURE vs R2R的对比

| 方面 | SURE | R2R |
|------|------|-----|
| 散度计算 | 需要（MC近似或autodiff） | 不需要 |
| 前向传播次数 | 2（MC SURE）或1+自动微分 | 2（$f(y_a)$和$y_b$的计算） |
| 对$f$的要求 | 弱可微 | 无可微性要求 |
| 噪声模型 | 高斯（可扩展到Poisson-Gaussian） | 高斯（Generalized R2R扩展到更多） |
| 精确性 | 精确无偏 | $\alpha$小时近似无偏 |

## 本节小结

```
朴素MSE ──→ 偏低（过拟合噪声）
              │
              ├── SURE：加自由度修正项 ──→ 无偏估计 ──→ 最优解=Tweedie公式 ──→ 闭环第5章
              │
              └── R2R：重新加噪构造独立副本 ──→ 避免散度计算 ──→ 渐近等价于SURE
```

SURE的核心贡献不仅是"无偏估计监督风险"——更深刻的是，它揭示了自监督去噪与得分函数之间的内在联系：**自监督训练的最优去噪器就是Tweedie公式给出的MMSE估计器，而Tweedie公式又将去噪器与得分函数联系起来**。这条链从噪声数据出发，经过SURE训练，最终到达可驱动扩散采样的得分估计器——即使没有干净数据，理论闭环依然成立。

SURE和R2R提供了理论最优的自监督损失，但它们都需要已知噪声方差$\sigma^2$。另一种更简单的策略是：直接限制网络不看某些像素，从而从结构上防止过拟合噪声——这就是盲点网络，虽然简单，但以MMSE最优性为代价。
