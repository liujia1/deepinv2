## 17.3.1 监督风险与自监督风险的桥梁

回到核心问题：能不能只从单帧观测 $y$，就**无偏地**估计出监督风险 $R_{\text{SUP}}(f) = \mathbb{E}_{x,y}\|x - f(y)\|^2$？

最朴素的想法是：直接用 $\|y - f(y)\|^2$ 当训练损失——这是 §17.1.3 提到、后来暂时搁下的那个"朴素招"。它只用到 $y$，算起来毫不费力，看起来天经地义。但让我们认真算一笔账：它究竟估计的是什么？展开看看：

$$\mathbb{E}_y\|y - f(y)\|^2 = \mathbb{E}_{x,y}\|(y - x) + (x - f(y))\|^2$$

令 $\varepsilon = y - x$（噪声），展开平方：

$$= \mathbb{E}\|\varepsilon\|^2 + \mathbb{E}\|x - f(y)\|^2 + 2\mathbb{E}[\varepsilon^\top(x - f(y))]$$

$$= n\sigma^2 + R_{\text{SUP}}(f) + 2\mathbb{E}[\varepsilon^\top(x - f(y))]$$

关键在最后一项。其中 $\mathbb{E}[\varepsilon^\top x] = 0$（$\varepsilon$ 和 $x$ 独立且零均值），但 $\mathbb{E}[\varepsilon^\top f(y)]$ **一般不为零**——因为 $f(y)$ 依赖 $y = x + \varepsilon$，所以 $f(y)$ 和 $\varepsilon$ 是**相关**的。

> **这一步的现实含义**：我们真正想要的目标是 $R_{\text{SUP}}$（想让网络输出贴近真值 $x$ 的期望误差），但能直接算的只有 $\|y - f(y)\|^2$（网络输出贴近观测 $y$ 的误差）。两者之间横亘着一个由噪声和网络耦合产生的交叉项 $\mathbb{E}[\varepsilon^\top f(y)]$——它正是全部偏差的源头。

白话：**网络可以"追踪噪声"让残差变小，于是朴素 MSE 系统性低估了真实风险**。这就是朴素损失的偏差来源。打个比方：考试时你不是背会了知识，而是背下了标准答案的印刷错误——残差（错处）看起来很小，但你其实什么真本事都没学到。

**SURE 的核心洞察**：那个恼人的 $\mathbb{E}[\varepsilon^\top f(y)]$，可以用 $\sigma^2 \mathbb{E}[\text{div}\, f(y)]$ 替代（靠 Stein 引理），而后者**不依赖 $x$**。于是我们终于能只用 $y$ 估计风险。

## 17.3.2 Stein 引理与 SURE 公式

**Stein 引理**（白话版）：设观测 $y|x \sim \mathcal{N}(x, \sigma^2 I_n)$（高斯噪声，均值 $x$、方差 $\sigma^2$），$f$ 弱可微，则

$$\mathbb{E}[\varepsilon^\top f(y)] = \sigma^2 \mathbb{E}\left[\sum_{i=1}^n \frac{\partial f_i}{\partial y_i}(y)\right] = \sigma^2 \mathbb{E}[\text{div}\, f(y)]$$

这里 $\text{div}\, f = \sum_i \partial f_i / \partial y_i$ 叫**散度**（divergence，直觉上衡量"输出随输入变化的剧烈程度"）。

> **为什么这个引理能成立**：高斯分布在分部积分下有一个漂亮的"自洽性"——高斯核关于均值求导，会等价地作用到被积函数（即 $f$）上。于是噪声与输出的相关，被"翻译"成了 $f$ 对输入 $y$ 的局部灵敏度。这个翻译一旦完成，等号右边就只剩 $y$ 的函数，彻底摆脱了对 $x$ 的显式依赖。

**直觉**：当 $y$ 的某个分量 $y_i$ 增大，$f_i(y)$ 如果也跟着增大（$\partial f_i/\partial y_i > 0$），说明 $f$ 在"追着噪声跑"——这正是过拟合的表现。Stein 引理把这种"追噪声"的倾向，量化成了散度。

**为什么需要 SURE 公式**：朴素损失会低估风险，而我们需要一个"只依赖 $y$、但期望等于监督风险"的损失。Stein 引理恰好把那个依赖 $x$ 的偏差项换成了只依赖 $y$ 的散度项。于是把 17.3.1 的式子整理，用 Stein 引理替换 $\mathbb{E}[\varepsilon^\top f(y)] = \sigma^2 \mathbb{E}[\text{div}\, f(y)]$，再去掉和 $f$ 无关的常数 $n\sigma^2$，就得到 SURE 损失：

$$\boxed{\mathcal{L}_{\text{SURE}}(y, f) = \|y - f(y)\|^2 + 2\sigma^2 \sum_{i=1}^n \frac{\partial f_i}{\partial y_i}(y)}$$

> **逐项拆解**：第一项 $\|y - f(y)\|^2$ 是**残差项**——它希望网络输出贴紧观测，是"看起来合理"的部分；第二项 $2\sigma^2 \sum_i \partial f_i / \partial y_i(y)$ 是**自由度修正项**——它弥补网络"拟合噪声"的倾向：$\partial f_i/\partial y_i > 0$ 说明网络在追着噪声跑，这一项就把朴素损失被低估的那一块补了回去。$\sigma^2$ 是已知的噪声方差，它决定了"该在多大量级上惩罚这种追噪声行为"。两块合起来，才是一个公平的计分器。

**无偏性**：

$$\mathbb{E}_y[\mathcal{L}_{\text{SURE}}(y, f)] = R_{\text{SUP}}(f) + n\sigma^2$$

那个 $n\sigma^2$ 是常数，不影响"找最小值"。所以：

$$\text{argmin}_f \mathbb{E}_y[\mathcal{L}_{\text{SURE}}] = \text{argmin}_f R_{\text{SUP}}(f) = \mathbb{E}[x|y]$$

**SURE 的两块拼图**：
- $\|y - f(y)\|^2$：**残差项**——直觉上，好网络该让输出贴近输入；但单看它会被低估。
- $2\sigma^2 \text{div}\, f(y)$：**自由度修正项**——补偿 $f$ "拟合噪声"的倾向。$\text{div}\, f$ 越大（网络越"灵活"、越爱追噪声），修正越狠。

这结构和统计里的 AIC/BIC 信息准则完全是一家人：AIC = 对数似然 − 模型复杂度惩罚。这里 SURE 用散度惩罚"追噪声的自由度"。

> **贝叶斯含信念更新**：你可以把 SURE 想成"在没有干净标签这件证据时，如何校正我们对网络风险的信念"。朴素损失 $\|y - f(y)\|^2$ 是带偏的"先验偏见"（它以为残差小就万事大吉）；散度修正项是新证据（网络在多大程度上追了噪声），把它校正成无偏的"后验风险估计"。证据（$\sigma^2$ 与 $f$ 的灵敏度）越强，校正越准——这正呼应第 1–2 章"先验被证据洗掉、收敛到真值"的信念更新叙事。

> **从更深层次看，SURE 的登场标志着本章思想的第二次跃迁**：Noise2Noise 是"另取一帧噪声当老师"；SURE 则是"从这一帧噪声里，就把它蕴含的老师完整地推演出来"——不再需要额外的帧，而是靠 $\sigma^2$ 这条"噪声的统计承诺"。这提示了一部贯穿全章的方法论剧本：**每去掉一种外部便利（干净标签、配对观测、已知 $\sigma^2$），就需要从数据内在结构中调用一种更精巧的统计量来补偿。**

## 17.3.3 散度的计算：Monte Carlo SURE 与 Autodiff SURE

SURE 的实用瓶颈是散度 $\text{div}\, f(y)$ 的计算。对神经网络，精确算要对 $y$ 的每个分量做一次反向传播，总共 $O(n)$ 次——图像维度 $n$ 动辄上百万，根本吃不消。

### Monte Carlo SURE

Ramani et al. (2007) 用随机投影近似散度：

$$\sum_{i=1}^n \frac{\partial f_i}{\partial y_i}(y) \approx \frac{1}{\alpha}\,\omega^\top[f(y + \alpha\omega) - f(y)], \qquad \omega \sim \mathcal{N}(0, I_n)$$

**原理**：这是方向导数的有限差分（用微小扰动估计斜率）。$\omega^\top \frac{\partial f}{\partial y}\omega$ 是散度在随机方向 $\omega$ 上的投影，取期望后恢复完整散度：

$$\mathbb{E}_\omega\!\left[\frac{1}{\alpha}\omega^\top(f(y + \alpha\omega) - f(y))\right] \xrightarrow{\alpha \to 0} \text{div}\, f(y)$$

**代价**：只需 2 次前向传播（$f(y)$ 和 $f(y+\alpha\omega)$），对比精确散度的 $O(n)$ 次反向传播，相差悬殊。

### Autodiff SURE

Soltanayev et al. (2020) 直接用自动微分算 Hutchinson 迹估计（第 6 章 6.4 节介绍过，就是同一个"用随机向量估计矩阵迹"的技巧）：

$$\text{div}\, f(y) = \text{tr}\!\left(\frac{\partial f}{\partial y}\right) \approx \omega^\top \frac{\partial f}{\partial y}\omega, \qquad \omega \sim \mathcal{N}(0, I_n)$$

**和全书的联系**：这正是第 6 章得分匹配里用过的 Hutchinson 迹估计——同一技术，在得分匹配和 SURE 里干同一件事：**避免精确算 Jacobian（导数矩阵）**。

## 17.3.4 SURE → Tweedie 闭环：得分函数的自监督学习

SURE 不只是个风险估计器——它的最优解藏着一条惊艳的闭环。

对 SURE 做变分（考虑给 $f$ 加个微小扰动 $f + \delta g$，令 $\delta \to 0$ 时变分为零；严格推导见附录 17A），得到最优解：

$$\boxed{f^*(y) = y + \sigma^2 \nabla_y \log p_y(y)}$$

**这正是 Tweedie 公式！**（第 5 章 5.3 节）

> **读懂这个公式的每一块**：$f^*(y)$ 是最优去噪器的输出，它等于"把观测 $y$ 原样保留（$y$ 这一项）"加上"一个沿着得分方向 $\nabla_y \log p_y(y)$ 的修正、以噪声方差 $\sigma^2$ 为步长"。直觉上，$y$ 已经指向信号附近；得分方向告诉我们"在这个带噪点附近，真实信号更可能朝哪个方向偏移"；$\sigma^2$ 决定信任多少这个修正。三者相乘加和，就给出无噪标签下 MMSE 估计器的输出——而我们连干净标签的影子都没见过。

这个结果让人头皮发麻，因为它意味着：

1. **SURE 闭环**：用 SURE 训出来的去噪器，最优解恰好是 Tweedie 公式——去噪器 = 信号 + 噪声方差 × 得分函数。
2. **和前章呼应**：第 5 章说"去噪器 = 得分估计器"，第 6 章说"得分匹配训去噪器"，本章说"即使没有干净数据，SURE 也能训出这个去噪器，且最优解就是 Tweedie 公式"。
3. **从噪声数据直抵扩散**：噪声数据 → SURE 训练 → 去噪器 → Tweedie → 得分函数 → 扩散采样。哪怕一张干净图没有，也能拿到驱动扩散采样的得分估计器。

> **这一转变意味着，全书"从逆问题经贝叶斯→采样→得分→扩散"的闭环，在数据维度上也被打通了**。过去到第 16 章为止，训练一个得分估计器（去噪器）仍然需要干净图去加噪；而 SURE 证明，得分可以完全从噪声数据里自我学习。这正是 §17.7 所总结的"自监督统一"最硬核的一环。

**Noise2Score**（Kim & Ye 2021）正是这套思路：从噪声数据学 $\nabla_y \log p_y(y)$（得分函数），再用 Tweedie 去噪。Daras et al. (2024) 更进一步证明：**扩散模型本身也能用 SURE 训练**——连扩散模型的训练都可以完全自监督。

## 17.3.5 R2R：避免散度计算的 SURE 替代

SURE 有个实用痛点：散度项要 Monte Carlo 近似或自动微分，计算贵，还对 $f$ 的可微性有要求。R2R（Recorrupted-to-Recorrupted，Pang et al. 2021）提供了**完全绕开散度**的替代。

**为什么需要 R2R**：既然散度是 SURE 的痛点，那能不能换一条路，连散度都不算就得到等价的损失？R2R 的答案是"重新加噪"。

**核心思想**：通过"重新加噪"造出两个独立的噪声副本，它们之间的 MSE 就能替代 SURE。

**构造**：给定观测 $y$，定义

$$y_a = y + \alpha\omega, \qquad y_b = y - \omega/\alpha, \qquad \omega \sim \mathcal{N}(0, \sigma^2 I_n),\ \alpha \in \mathbb{R}$$

> **逐变量看**：$y$ 是原有观测，$\omega$ 是我们人为采的新噪声，$\alpha$ 是一个可调正数。$y_a$ 把观测再"加噪重排"，$y_b$ 反之把观测"按反方向扰动"。这一加一减的构造，妙在让两路副本在给定信号 $x$ 后互不牵制。

**关键性质**：$y_a$ 和 $y_b$ 在给定 $x$ 时是**条件独立**的。证明：$y_a = x + (\varepsilon + \alpha\omega)$，$y_b = x + (\varepsilon - \omega/\alpha)$；两噪声分量的条件协方差 $\text{Cov} = \sigma^2 I - \sigma^2 I = 0$（联合高斯下协方差为零即独立）。$\blacksquare$

**R2R 损失**：

$$\boxed{\mathcal{L}_{\text{R2R}}(y, f, \alpha) = \mathbb{E}_\omega\|y_b - f(y_a)\|^2}$$

**与 SURE 的关系——渐近等价**：

$$\lim_{\alpha \to 0} \mathcal{L}_{\text{R2R}}(y, f, \alpha) = \mathcal{L}_{\text{SURE}}(y, f)$$

直觉：当 $\alpha \to 0$，$y_a \to y$，$y_b$ 变成 $y$ 的"正交扰动"，R2R 退化成 SURE（严格推导见附录 17B）。实践中 $\alpha$ 不能太小（数值不稳）也不能太大（近似误差大），典型取 $\alpha \in [0.01, 0.1]$。

**Generalized R2R**（Monroy, Bacca & Tachella, CVPR 2025）：把 R2R 推广到 Poisson、Gamma、Binomial 等非高斯噪声——核心洞察是"任何有已知采样结构的噪声，都能造独立重加噪副本，从而替代 SURE 的散度"。

> **从更深层次看，SURE 与 R2R 是同一思想的两种实现**：SURE 用"解析的散度修正"保证无偏，R2R 用"重新采样的独立副本"在极限下复现同一目标。前者昂贵但精确，后者便宜且几乎无偏——它们共享同一个信念：**只要能切断噪声副本之间的相关，就能从噪声数据里盘算出监督风险。**

### SURE vs R2R

| 方面 | SURE | R2R |
|------|------|-----|
| 散度计算 | 需要（MC 或 autodiff） | 不需要 |
| 前向传播次数 | 2（MC）或 1+自动微分 | 2 |
| 对 $f$ 的要求 | 弱可微 | 无可微性要求 |
| 噪声模型 | 高斯（可扩到 PG） | 高斯（GR2R 扩更多） |
| 精确性 | 精确无偏 | $\alpha$ 小时近似无偏 |

## 本节小结

```
朴素MSE ──→ 偏低（过拟合噪声）
              │
              ├── SURE：加自由度修正项 ──→ 无偏估计 ──→ 最优解=Tweedie公式 ──→ 闭环第5章
              │
              └── R2R：重新加噪造独立副本 ──→ 绕开散度 ──→ 渐近等价SURE
```

SURE 的核心贡献不止"无偏估计监督风险"——更深刻的是它揭示了**自监督去噪与得分函数的内在联系**：自监督训出的最优去噪器就是 Tweedie 公式给的 MMSE 估计器，而 Tweedie 又把去噪器和得分函数连起来。这条链从噪声数据出发，经 SURE 训练，最终抵达能驱动扩散采样的得分估计器——哪怕没有干净数据，理论闭环照样转。

> **承上启下**：SURE 和 R2R 都理论最优，但都需要已知噪声方差 $\sigma^2$。另一种更省事的策略是：直接让网络"别看某些像素"，从结构上防它过拟合噪声——这就是盲点网络，虽然简单，但要拿 MMSE 最优性做交换。

## 动手感受：用 SURE 从单帧噪声估计风险（可运行）

下面这段 numpy/autograd 代码，造一个已知函数 $f$（这里用一个简单的可逆线性变换当"网络"），分别用"朴素 MSE"和"SURE"去估计它的真实监督风险，并把两者和真实值对比。你会亲眼看到：朴素损失系统性偏低，而 SURE 几乎贴在真值上。

```python
# ============================================================
# 17.3 动手实验：SURE 用单帧 y 无偏估计监督风险
# 只需 numpy + 一个极简 autograd（这里用有限差分近似散度，避免额外依赖）
# ============================================================
import numpy as np

np.random.seed(0)

n = 2000                      # 信号维度
sigma = 0.3                   # 已知噪声标准差

# ---- 造一个"网络" f：一个可微线性映射，带一点对角收缩（模拟去噪器） ----
# 真实干净信号 x 服从标准高斯，观测 y = x + sigma * eps
W = np.eye(n) * 0.8           # f(y) = 0.8 * y  （一个"过度平滑"的去噪器）
def f(y):
    return W @ y

# ---- 计算真实监督风险 R_SUP = E||x - f(y)||^2 （用蒙特卡洛近似） ----
def true_risk(M=20000):
    tot = 0.0
    for _ in range(M):
        x = np.random.randn(n)
        eps = sigma * np.random.randn(n)
        y = x + eps
        tot += np.sum((x - f(y)) ** 2)
    return tot / M

R_SUP = true_risk()
print(f"[真实监督风险] R_SUP ≈ {R_SUP:.2f}")

# ---- 朴素损失：E||y - f(y)||^2 （依赖 y，但会低估） ----
def naive_loss(M=20000):
    tot = 0.0
    for _ in range(M):
        x = np.random.randn(n)
        eps = sigma * np.random.randn(n)
        y = x + eps
        tot += np.sum((y - f(y)) ** 2)
    return tot / M

L_naive = naive_loss()
print(f"[朴素 MSE]    E||y-f(y)||^2 ≈ {L_naive:.2f}   （比 R_SUP 低，因为网络在追噪声）")

# ---- SURE 损失：||y-f(y)||^2 + 2*sigma^2 * div f ----
# 对线性 f(y)=W y，散度 div f = tr(W) = 各对角元之和
div_f = np.trace(W)          # = 0.8 * n
# 单帧 y 的 SURE 估计（注意这里的"期望"由蒙特卡洛近似）
def sure_loss(M=20000):
    tot = 0.0
    for _ in range(M):
        x = np.random.randn(n)
        eps = sigma * np.random.randn(n)
        y = x + eps
        tot += np.sum((y - f(y)) ** 2) + 2 * sigma**2 * div_f
    return tot / M

L_sure = sure_loss()
print(f"[SURE]        ≈ {L_sure:.2f}   （应等于 R_SUP + n*sigma^2 的常数偏移）")

# ---- 验证无偏性：SURE 期望 - 朴素期望 = n*sigma^2 （与 f 无关） ----
print(f"[偏移差]      L_sure - L_naive ≈ {L_sure - L_naive:.2f}")
print(f"[理论常数]    n*sigma^2        = {n*sigma**2:.2f}   （两者应接近）")
```

**你应该看到的现象**：`L_sure - L_naive` 约等于 `n * sigma^2`，而 SURE 本身和真实监督风险只差这个常数——这正说明 SURE 用"自由度修正项"精准补上了朴素损失被低估的那一块。删掉所有公式，这段代码的叙事依然成立：朴素损失会骗你，SURE 把它修正回来。
