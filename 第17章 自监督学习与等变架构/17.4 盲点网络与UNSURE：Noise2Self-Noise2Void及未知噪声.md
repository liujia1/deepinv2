# 17.4 盲点网络与 UNSURE：Noise2Self / Noise2Void 及未知噪声

> "与其让网络去'硬学'别追噪声，不如干脆焊死它的眼睛——让它压根看不到自己要预测的那个像素。看不见噪声，自然就只能靠信号。"

**本节目标**（读完你会做到这几件事）：
- 用"填空题"类比说清盲点网络为什么能去噪又不会抄噪声；
- 记住 Noise2Void / 盲点网络 / $\mathcal{J}$-不变性的关系与理论保证；
- 从 SURE 视角看懂"盲点网络 = SURE 的约束版"，以及它为何牺牲 MMSE 最优性；
- 理解 UNSURE 怎么在"噪声水平未知"时，用 Lagrange 乘子把 $\sigma^2$ 也估出来。

---

这是自监督里"用结构换简单"的一脉。如果说 SURE（§17.3）是用"算出来"的散度修正赢得无偏，那本节则换一条更省事的思路：**能不能让噪声从一开始就无法进入网络的"视野"，从而连修补都省了？** 先讲直觉，再讲 Noise2Void / 盲点网络 / Noise2Self，最后用 SURE 的视角把它们统一起来，并引出"噪声水平未知"的 UNSURE。

## 17.4.1 核心思想：不看就能学

SURE 用精确的"自由度修正"实现无偏，但散度计算毕竟麻烦。另一套路更直觉、更轻量：**直接限制网络别看某些像素**。

**过拟合噪声的机制**：去噪时，$f(y)$ 要预测每个像素的干净值。如果 $f_i(y)$ 可以依赖输入的第 $i$ 个像素 $y_i$，网络就能直接"抄"$y_i$ 里的噪声，让 $f_i(y) \approx y_i$——残差 $\|y - f(y)\|^2$ 很小，可重建结果就是噪声本身。

**约束策略**：限制 $f_i(y)$ 不依赖 $y_i$，即 $\frac{\partial f_i}{\partial y_i}(y) = 0$。这样网络没法"偷看"$y_i$ 的噪声值，只能靠邻域信息推断像素 $i$ 的干净值。

**直觉类比**：想象你在做填空题——如果答案不在题目里，你只能靠上下文（邻域像素）推。对图像而言，邻域像素富含"这个像素该是什么"的信息（图像的局部相关性），可噪声是逐像素独立的，邻域里**不含**该像素噪声的信息。所以"不看自己"既能去噪，又不会把噪声抄进来。

> **这个类比背后的限制条件是关键**：盲点的合法性，取决于"噪声在邻域里完全缺席"。这要求噪声逐像素独立：

$$p(y|x) = \prod_{i=1}^n p(y_i|x_i)$$

若噪声有空间相关性（如相关高斯噪声），邻域里也夹带了该像素的噪声信息，盲点策略就不安全了。所以这是一条**用"噪声结构的简单性"换取"方法的简洁性"**的路线——它牺牲的正是 SURE 对更一般噪声的适用性。

## 17.4.2 Noise2Void：掩码策略与盲点网络

### Noise2Void（Krull et al. 2019）

最简单的盲点实现：

1. 对输入 $y$ 随机挑像素位置 $i$；
2. 用邻域像素替换 $y_i$（如 4 邻域均值），得到 $\tilde{y}$；
3. 只在被替换的像素上算损失：$\mathcal{L} = (y_i - f_i(\tilde{y}))^2$。

**掩码策略的实质**：$f_i(\tilde{y})$ 不依赖 $y_i$（因为它被换掉了），只依赖其他像素。网络被迫从邻域推断——这正是去噪。

- **优点**：实现极简，只改训练循环的预处理。
- **缺点**：每次只在一个像素上算损失，训练效率低；替换本身引入偏差。

### 盲点网络（Blind-Spot Network，Laine et al. 2019）

更优雅：直接靠架构实现盲点。把卷积核中心权重置零，让输出像素 $i$ 不依赖输入像素 $i$：

```
标准3×3卷积核：         盲点3×3卷积核：
[a  b  c]              [a  b  c]
[d  e  f]    →         [d  0  f]    中心权重置零
[g  h  i]              [g  h  i]
```

- **优点**：每个像素都能算损失（不用掩码），训练高效；约束写进架构，不依赖训练技巧。
- **缺点**：限制了感受野中心；大感受野需更多层。

> ⚠️ **"写进架构"要分清是哪一层**：中心置零只保证**单层**内 $\partial f_i/\partial y_i = 0$。多层堆叠（尤其带池化与转置卷积的 UNet）后端到端仍会"绕路"泄漏，而且训练会主动放大它——实测见本节下方 **实验 17.4-1（步骤 4）**。

### Noise2Self（Batson & Royer 2019）

更一般的理论框架——**$\mathcal{J}$-不变性**（J-invariance，指"预测某组坐标时，不看这组坐标的输入"）。

**定义**：设 $\mathcal{J}$ 是坐标的一个划分（把像素分成若干组），函数 $f$ 是 $\mathcal{J}$-不变的，若对每组 $J$，预测 $J$ 的值时不看 $y_J$ 的输入。

**直觉**：Noise2Void 的逐像素盲点对应 $\mathcal{J} = \{\{1\},\{2\},\dots,\{n\}\}$（每像素一组）；但 $\mathcal{J}$-不变性允许更灵活的分组——比如把图像分成棋盘格两组，一组预测另一组。

**Noise2Self 定理**：若 $f$ 是 $\mathcal{J}$-不变的，且噪声逐像素独立，则在 $\mathcal{J}$-不变函数族 $\mathcal{F}_{\mathcal{J}}$ 内：

$$\text{argmin}_{f \in \mathcal{F}_{\mathcal{J}}} \mathbb{E}_y\|y - f(y)\|^2 = \text{argmin}_{f \in \mathcal{F}_{\mathcal{J}}} \mathbb{E}_{x,y}\|x - f(y)\|^2$$

> **读解这条定理**：等号左边是最小化"不需要干净标签"的朴素损失，右边是最小化"需要干净标签"的真实 MSE，两者都在同一个受限函数族 $\mathcal{F}_{\mathcal{J}}$ 内取最小。它告诉我们：**在盲点的约束下，单纯对准观测 $y$ 的自监督损失，其最优解不再被骗向噪声，而是与真正的去噪目标一致**——因为网络的"盲点"结构替我们挡掉了噪声的诱惑。

**证明思路**（可跳过，记住结论即可）：关键是证 $\mathbb{E}[\varepsilon^\top f(y)] = 0$。由噪声独立性，$\varepsilon_i$ 与 $y$ 中除第 $i$ 组外的部分独立；而 $\mathcal{J}$-不变性又让 $f_i(y)$ 不依赖 $\varepsilon_i$（因为它不看自己那组）。于是 $\mathbb{E}[\varepsilon_i f_i(y)] = \mathbb{E}[\varepsilon_i]\,\mathbb{E}[f_i(y)] = 0$。由此 $\mathbb{E}_y\|y - f(y)\|^2 = \mathbb{E}_{x,y}\|x - f(y)\|^2 + n\sigma^2$，常数不影响最小化。$\blacksquare$

**意义**：在 $\mathcal{J}$-不变函数族内，最小化这个不需要干净标签的自监督损失，等于最小化需要干净标签的真实 MSE——这就是盲点策略的理论保证。

## 17.4.3 SURE 视角：盲点网络是 SURE 的约束版本

到这里，你可能会觉得"SURE 用散度修正"和"盲点网络用结构挡噪声"是两条各走各的路线。但把它们并排放在一起，一条深刻的数学联系就浮现出来——**它们其实共享同一个 SURE 骨架**。

**回顾 SURE**：

$$\mathcal{L}_{\text{SURE}}(y, f) = \|y - f(y)\|^2 + 2\sigma^2 \underbrace{\sum_i \frac{\partial f_i}{\partial y_i}(y)}_{\text{div}\, f(y)}$$

**盲点约束**：$\frac{\partial f_i}{\partial y_i}(y) = 0,\ \forall i, \forall y$。

在盲点约束下，SURE 的修正项整个归零：

$$\mathcal{L}_{\text{SURE}}\big|_{\text{blind-spot}} = \|y - f(y)\|^2 + 0 = \|y - f(y)\|^2$$

**这就是盲点网络的损失！**

> **这条公式讲清了盲点网络的本质**：当 $f$ 被约束为盲点时，散度项恒等于零。于是 SURE 退回到最朴素的 $\|y - f(y)\|^2$——但**因为约束本身把噪声挡在了门外，这个朴素损失不再会被"抄噪声"骗到**。SURE 靠"事后补一笔散度账"来修正，盲点网络靠"让这笔账天生为零"来省略——两者收敛到同一套无偏逻辑。

所以盲点网络 = SURE 在 $\text{div}\, f = 0$ 约束下的特例。代价是函数族缩小了——从所有可微函数 $\mathcal{F}$ 缩到 $\mathcal{J}$-不变函数 $\mathcal{F}_{\mathcal{J}}$——最优解不再是全局 MMSE 估计器 $\mathbb{E}[x|y]$，而是**受限最优**：

$$f^*_{\text{blind}} = \text{argmin}_{f \in \mathcal{F}_{\mathcal{J}}} \mathbb{E}_{x,y}\|x - f(y)\|^2$$

**关键结论**：盲点网络以牺牲 MMSE 最优性，换来了实现简单、且**不依赖噪声水平**。Tachella 研讨会上也明确指出：从 SURE 视角看，盲点网络不是 MMSE 最优的——因为约束 $\partial f_i/\partial y_i = 0$ 太严，把全局最优解 $\mathbb{E}[x|y]$ 排除在外了（后者一般 $\partial f_i/\partial y_i \neq 0$）。这条"只牺牲一点最优性"的推论有一个隐含前提——约束**真的**成立；实测边界见本节下方 **实验 17.4-1（步骤 4）**。

> **这一处"次优"，恰是方法论演化的润滑剂**：放弃全局最优，换来"连 $\sigma^2$ 都不必知道"的简洁。盲点网络是本章第四条"卸负担"的路——干净标签没了（相对 §17.2/17.3）、配对观测没了（相对 §17.2）、散度计算没了（相对 SURE）、现在连噪声水平都不必知道（相对 SURE/R2R）。负担越卸越多，条件也从"需要精确统计知识"滑向"只需结构独立"。

## 实验 17.4-1：SURE 与盲点网络——省掉散度，到底省掉了什么

实验 `17.4-1.py` 在同一个 MNIST 去噪流程里并排跑出**六种训练设定**（监督 / SURE / R2R / 盲点 / 盲点+N2V masking / 朴素），把本节"SURE 骨架 + 盲点约束"这条统一线索拆成五个可验证的层次：①确认 SURE 的自由度修正项真的把朴素 MSE 的低报补了回来（散度可算，是后面一切的前提）；②对比 MC-SURE 与 Autodiff-SURE 两种散度实现；③验证 R2R 不用散度也能达到同级、并标定其 $\alpha$ 的实际作用方向；④**本实验的主戏**——把卷积核中心置零做成盲点架构，数值实测端到端 $\partial f_i/\partial y_i$ 是否真为零，并用 Noise2Void 的输入 masking 做堵漏对照；⑤验证 SURE 训练出的去噪器满足 Tweedie 公式，也就是 §17.4.4 那个 $f_{\text{ZED}}$ 闭式解所同构的对象。

> 说明：①②③⑤ 的公式定义在 §17.3 已给出，这里把它们与 ④ 放进同一套代码、同一批随机流，是为了让 §17.4.3「盲点网络 = SURE 在 $\text{div}\,f=0$ 约束下的特例」这句话有一条完整的实证链——先确认散度版可用，再检查"把散度焊成零"是否真的成立。

### 实验场景

纯去噪问题（$A=I$）：

$$y = x + \sigma\varepsilon,\qquad \varepsilon\sim\mathcal{N}(0,I),\quad \sigma=0.3,\quad x\in\text{MNIST},\ 32\times32$$

$\sigma=0.3$ 相对像素峰值 1 属于强噪声：含噪图自身的 PSNR 只有 $-10\log_{10}\sigma^2=10.46$ dB，这条"什么都不做"的恒等地板是全实验的参照点。六种设定只差**损失函数与网络架构**，训练预算完全相同：

| 设定 | 损失 | 网络 | 需要 $\sigma^2$ | 需要散度 |
|---|---|---|---|---|
| 监督 | $\|x-f(y)\|^2$ | SmallUNet（带 skip） | — | 否 |
| SURE | $\|y-f(y)\|^2+2\sigma^2\text{div}\,f$ | SmallUNet | ✅ | ✅（MC，$n_{mc}=1$） |
| Autodiff-SURE | 同上，Hutchinson $\omega^\top J_f\omega$ | SmallUNet | ✅ | ✅（自动微分） |
| R2R | $\|y_b-f(y_a)\|^2$，$y_a=y+\alpha\sigma\omega$，$y_b=y-\tfrac{\sigma}{\alpha}\omega$ | SmallUNet | ✅ | 否 |
| 盲点 | $\|y-f(y)\|^2$ | StrictBlindSpotUNet（中心置零、无 skip） | ❌ | 否 |
| 盲点 + N2V mask | 同上，只在被 mask 的像素上算 | StrictBlindSpotUNet | ❌ | 否 |
| 朴素 | $\|y-f(y)\|^2$ | SmallUNet | ❌ | 否 |

盲点卷积 `StrictBlindSpotConv2d` 的实现是 `pixel_unshuffle(2)` $\to$ `groups=4` 的 3×3 卷积（**在下采样域把核中心置零**）$\to$ `pixel_shuffle`，从而保证**单层内** $\partial f_i/\partial y_i=0$；作为对照另有 `ApproximateBlindSpotConv2d`（普通 3×3 直接把中心元素置零，最短泄漏路径距离 1）。两种盲点网络都去掉了 skip connection。泄漏程度由 `verify_blind_spot_property()` 实测：对固定探针输入 $x\sim\mathcal{N}(0,I)$（$1\times1\times32\times32$）抽样 10% 像素（102/1024），逐个反传读 $\partial f_i/\partial y_i$，以 $10^{-6}$ 为"泄漏"判定线。

### 实验目的

1. **确认散度版 SURE 可用**：$2\sigma^2\text{div}\,f$ 修正项能把朴素 MSE 的低报补回来，使 SURE 逼近监督——这是 §17.4.3 拿 SURE 当"统一骨架"的前提；
2. **确认散度的两种实现（MC / Autodiff）给出一致的 $\text{div}\,f$**：否则第 1 条的归因不成立；
3. **确认"不用散度"的另一条路（R2R）同样达标**，并标定其 $\alpha$ 的实际作用方向；
4. **检验 §17.4.2 的架构断言**：卷积核中心置零后，端到端是否真的 $\partial f_i/\partial y_i\equiv0$、$\text{div}\,f$ 是否真的恒为零；
5. **检验 §17.4.3 的代价断言**：若盲点约束严格成立，朴素损失的最优解应当只比 SURE 差"函数族缩小"那一点（1–2 dB 量级），而不是崩到恒等地板附近；
6. **检验 Noise2Void 输入 masking 的作用机制**（§17.4.2）：它与盲点架构是"二选一的重复设计"，还是各自堵住不同的漏洞；
7. **给 §17.4.4 备好对照组**：SURE 训练的去噪器满足 Tweedie 公式 $f^*(y)=y+\sigma^2\nabla_y\log p_y(y)$——UNSURE 的 $f_{\text{ZED}}=y+\hat{\eta}\nabla\log p_y(y)$ 正是把其中的 $\sigma^2$ 换成自动估出的 $\hat{\eta}$。

> **目的匹配自查**：七项目的全部落在 §17.4 的论证链上——1–3 支撑 §17.4.3「盲点 = SURE 的约束版」所依赖的 SURE 骨架，4–6 直接对应 §17.4.2 的架构断言与 §17.4.3 的代价断言，7 对应 §17.4.4 闭式解的同构对象。脚本头标注"对应知识点 17.3、17.4 节"，其中 17.3 部分（SURE / R2R / Tweedie）在此只作为 §17.4 统一视角的**前提校验**出现；全程 $A=I$，不触及 §17.5–17.6 的 $A\neq I$ 情形。**需要划清的一条边界**：脚本没有任何 UNSURE / $\hat{\eta}$ 估计的代码（$\sigma$ 全程已知），故本实验只验证"与 UNSURE 同构的那个 Tweedie 对象"，**不能**用来支持 §17.4.4 的 $\hat{\eta}$ 收敛性或误差界。

### 预期结果

- **Step 1（SURE 修正）**：朴素 $\|y-f(y)\|^2$ 低报风险、把网络推向抄噪声，PSNR 应贴近恒等地板；SURE 加上 $2\sigma^2\text{div}\,f$ 后应逼近监督。训练过程中修正项恒为正、量级远小于残差项（只占百分之几），却足以改变最优解的位置。
- **Step 2（两种散度实现）**：MC 与 Autodiff 给出的 $\text{div}\,f$ 应同量级、相对偏差落在 MC 方差内；$\alpha$ 越小 MC 应越接近 Autodiff（过小则撞浮点精度）。
- **Step 3（R2R）**：不用散度也应达到 SURE 同级；$\alpha\to0$ 时 R2R 损失渐近等价 SURE，故小 $\alpha$ 端应看到与 SURE 相当的行为。
- **Step 4（盲点架构）**：中心置零后单层 $\partial f_i/\partial y_i=0$ 应表现为机器精度的零；端到端散度实测应接近 0；于是朴素损失在盲点族内无偏，PSNR 应落在"略低于 SURE"的**受限最优**位置（差距 1–2 dB 量级）。
- **Step 4b（N2V masking）**：masking 与盲点架构解决的是同一个"别看自己"的问题，二者叠加应只是"再加一道保险"，不应成为成败的决定因素。
- **Step 5（Tweedie 闭环）**：人工高斯上 SURE 去噪器反推的得分应与解析得分强相关（corr $\to1$）、RMSE 小于 0.1；Stein 恒等式反推的散度与 MC 估计一致；score map 应与真噪声图近乎反相关（corr $\approx-1$）。

### 实验结果

#### 步骤1：SURE 的自由度修正把朴素 MSE 的低报补了回来

朴素 13.19 dB $\to$ SURE 24.45 dB：**同一架构、同一数据、同一预算，只多了一项 $2\sigma^2\text{div}\,f$，PSNR 抬高 11.3 dB**，从"比恒等地板高 2.7 dB"（等于没去噪）回到"距监督 2.2 dB"。

#### 步骤3：R2R 不用散度也达标，但 $\alpha$ 的作用方向与"渐近等价"的直觉相反

![实验17.4-1 步骤3：R2R与alpha扫描](<./第十七章 配套实验/实验17.4-1/step3_r2r.png>)

R2R（$\alpha=0.1$）25.42 dB，比 SURE 还高 0.97 dB——散度确实可以整个绕开。但 $\alpha$ 扫描（右图）给出与"$\alpha\to0$ 渐近等价 SURE"**相反**的走势：

| $\alpha$ | 0.01 | 0.05 | 0.10 | 0.50 | 1.00 |
|---|---|---|---|---|---|
| PSNR | 23.82 | 24.71 | 25.37 | **26.33** | 26.22 |
| SSIM | 0.9296 | 0.9370 | 0.9418 | 0.9565 | 0.9524 |

> 注：α 扫描为各档独立训练，故 $\alpha=0.1$ 档实测 25.37 dB 与上方总览中 R2R 主结果 25.42 dB 略有出入（差 0.05 dB），属单次训练波动、并非同一模型。

原因在实现细节：本实现的 $y_a=y+\alpha\sigma\omega$、$y_b=y-\tfrac{\sigma}{\alpha}\omega$ 让 $\alpha$ **同时**决定输入与标签的噪声分配（$\mathrm{Var}(y_a)=\alpha^2\sigma^2$，$\mathrm{Var}(y_b)=\sigma^2/\alpha^2$）。$\alpha$ 越大，标签 $y_b$ 越干净、输入 $y_a$ 越脏，设定越接近"含噪输入 $\to$ 干净标签"的监督形态，于是 $\alpha=0.5$ 几乎追平监督（26.33 vs 26.66 dB）。"$\alpha\to0$ 时 R2R 损失趋于 SURE"是**风险泛函**层面的渐近陈述，不等于小 $\alpha$ 端可优化：$\alpha=0.01$ 时 $\sigma/\alpha=30\sigma$ 的标签噪声使梯度方差爆炸，实测确实回落到 23.82 dB（脚本注释预警过 $\alpha<0.05$ 不稳）。

> **预期匹配自查**：预期"R2R 达 SURE 同级"✅；预期"$\alpha\to0$ 端行为与 SURE 相当"❌——实测随 $\alpha$ 单调上升，已用"输入/标签噪声分配"给出机制解释，并区分"泛函渐近"与"优化可达"。对 §17.4 的意义：R2R 与 SURE 同属"**已知 $\sigma^2$**"那一栏（见本节小结表），它们与盲点的真正分界是"要不要知道噪声水平"，这条对照成立。

#### 步骤4：主戏——"硬约束不会意外泄漏"只在单层意义下成立

![实验17.4-1 步骤4：盲点卷积核中心置零](<./第十七章 配套实验/实验17.4-1/step4_blindspot_kernels.png>)

先确认架构按预期工作：上排四个盲点核的中心被强制为零（× 标记），下排标准核中心非零。单层屏蔽 ✅。

但端到端是否 $\partial f_i/\partial y_i\equiv0$？`verify_blind_spot_property()` 的 2×2 实测（架构 × 训练状态）：

| | 随机初始化 | 训练后 |
|---|---|---|
| **StrictBlindSpot**（pixel-shuffle + 中心置零） | leak 0.00，$\max\|\partial f_i/\partial y_i\|=1.08\times10^{-7}$ | **leak 1.00**，max **6.46**，mean 0.312 |
| **ApproximateBlindSpot**（普通 3×3 中心置零） | leak 0.00，max $1.78\times10^{-7}$ | （未单独训练） |

三点必须读准：

1. **随机初始化下两档 leak 都是 0，这是阈值假象、不是"严格"**：$10^{-7}$ 远低于 $10^{-6}$ 判定线，只说明"12 层小权重连乘把泄漏压到了判定线以下"。真正区分架构严格性的是连续量：Strict 的 max 梯度比 Approximate 小约 39%，对应"最短泄漏路径从距离 1 被推到距离 $\ge2$"——**更远，但不是无穷远**。
2. **盲点是架构性质，训练却会把它填满**：训练后 Strict 抽样的 102 个像素 **100% 泄漏**，max 梯度比随机初始化大 7 个数量级（$10^{-7}\to6.46$）。架构留下的绕路通道（尤其 MaxPool 会把含中心的 2×2 邻域整体混给下一层的"非中心"位置）被梯度下降主动利用——因为沿这条路增大 $\text{div}\,f$ 可以直接降低朴素损失 $\mathbb{E}\|y-f\|^2=R(f)+n\sigma^2-2\sigma^2\text{div}\,f$。按 mean 0.312 粗估，$32\times32$ 图的端到端 $\text{div}\,f\approx3\times10^{2}$，而恒等映射的 $\text{div}\,f=n=1024$——量级上已走到"接近抄自己"那一侧（探针输入下的粗估，仅作量级参考）。
3. **后果与"受限最优"完全不是一个量级**：盲点（无 mask）只有 **14.05 dB**，比 SURE 低 10.40 dB，甚至比**完全不盲点的朴素训练**（13.19 dB）只高 0.87 dB，距恒等地板仅 3.6 dB。§17.4.3 的"牺牲 MMSE 最优性、退到受限最优"解释不了这个跌幅——受限最优指的是"在 $\mathcal{F}_{\mathcal{J}}$ 内仍取最优"，而这里网络根本没待在 $\mathcal{F}_{\mathcal{J}}$ 内。

定性图给出同一件事的视觉版本：

![实验17.4-1 步骤4：六种方法定性对比](<./第十七章 配套实验/实验17.4-1/qualitative_comparison.png>)

"盲点"一行与"有噪 $y$"行几乎无法区分（噪声原样保留），"盲点+mask"一行已接近 SURE。**这就是 $\text{div}\,f\neq0$ 时朴素损失的失效模式：解被吸向恒等映射。**

> **预期匹配自查**：预期"单层 $\partial f_i/\partial y_i=0$ 表现为机器精度的零"✅（核可视化 + 随机初始化 $10^{-7}$）；预期"端到端散度接近 0"❌（训练后 leak 1.00、max 6.46）；预期"PSNR 略低于 SURE（1–2 dB）"❌（实际低 10.4 dB）。**两处不匹配恰是本实验最有价值的产出**：它们把 §17.4.2 那句「硬约束，不会意外泄漏」限定在它成立的范围内——**逐层中心置零 $\neq$ 端到端盲点**；要端到端严格，需要 Laine et al. 那种"整个网络只做一次中心屏蔽 + 方向位移卷积集成"的架构，而不是把"各自严格"的层堆起来。这也反向印证 §17.4.3 的公式：散度项不是能凭结构"顺手省掉"的，省的前提是真的恒为零。

#### 步骤4b：Noise2Void 的输入 masking 不是"重复保险"，而是堵住架构漏掉的那道缝

同一套盲点架构上，N2V masking 把 PSNR 从 14.05 dB 拉回 **22.67 dB（+8.61 dB）**，SSIM 从 0.5145 跳到 0.9046。它的机制与"别看自己"的架构说法不同、却互补：被 mask 位置的输入替换为**不含中心**的 8 邻域均值，于是网络即便沿泄漏路径绕回该位置，拿到的也只是邻域均值、不含该像素的噪声——"复制中心"这条降低朴素损失的路被**从数据侧**切断，恒等映射不再是损失的最小点。

剩下的 22.67 vs 24.45 dB（比 SURE 低 1.78 dB）才是真正属于"受限最优 + 每次只有约 2% 像素参与损失"的那部分代价，量级与 §17.4.3 的理论定位相称。

> **预期匹配自查**：预期"masking 只是再加一道保险、不应决定成败"❌——实测它决定成败（+8.61 dB）。改述后的结论与 §17.4.2 的原始表述并不矛盾：在**理想单层**语境下 N2V 掩码与盲点架构确实等价，但在真实多尺度网络里只有前者能兑现约束。本节因此把两者的关系从"二选一的重复设计"修正为"架构负责把泄漏推远、masking 负责把残余泄漏的收益清零"。

## 17.4.4 UNSURE：未知噪声水平的自监督学习

SURE 和 R2R 都要已知 $\sigma^2$。可真实场景里噪声水平常常**未知**——Cryo-EM 的噪声分布复杂难建模，天文图像的噪声随观测条件变。

**问题**：$\sigma^2$ 未知，SURE 里那个 $2\sigma^2 \text{div}\, f(y)$ 就没法算。能不能同时把 $f$ 和 $\sigma^2$ 一起估出来？

### UNSURE 公式（Tachella et al., ICLR 2025）

用 Lagrange 乘子（Lagrange multiplier，一种"带约束优化"的技巧，这里把未知的 $\sigma^2$ 变成一个可训练的乘子 $\eta$）替代已知 $\sigma^2$：

$$\min_f \max_\eta \mathbb{E}_y\left[\|y - f(y)\|^2 + 2\eta \sum_{i=1}^n \frac{\partial f_i}{\partial y_i}(y)\right]$$

其中 $\eta$ 扮演 SURE 里 $\sigma^2$ 的角色，但不必预先给定。$\min$-$\max$ 结构的意思是：$f$ 想让整体损失最小，而 $\eta$ 则会主动去适配散度项的权重——两者博弈，最终收敛到那个连噪声水平都无需指定的平衡点。

### 闭式解

UNSURE 的解有和 Tweedie 一样优美的闭式（closed-form，指能写成明确公式、不用迭代求解）：

$$\boxed{f_{\text{ZED}}(y) = y + \hat{\eta}\,\nabla_y \log p_y(y)}$$

其中 $\hat{\eta}$ 自动估为：

$$\hat{\eta} = \left(\frac{1}{n}\mathbb{E}_y\|\nabla_y \log p_y(y)\|^2\right)^{-1}$$

> **这里的现实含义**：$f_{\text{ZED}}(y)$ 中，ZED 是"零散度（zero-divergence）估计器"的缩写——它正是 UNSURE 在约束"期望散度为零"下得到的最优解。形式上它与 Tweedie 的 $y + \sigma^2 \nabla_y \log p_y(y)$ 逐项同构：$y$ 是保留的观测，$\nabla_y \log p_y(y)$ 是得分方向，区别仅在 $\hat{\eta}$ 替换了 $\sigma^2$。$\hat{\eta}$ 的表达式里，$n$ 是总维度，$\|\nabla_y \log p_y(y)\|^2$ 是得分在该点的平方范数——取期望再取倒数，得到一个"由数据测得的有效噪声水平"。

**与 Tweedie 的关系**：Tweedie 给的是 $f^*(y) = y + \sigma^2 \nabla_y \log p_y(y)$；UNSURE 形式完全一致，只是用自动估出的 $\hat{\eta}$ 换掉了 $\sigma^2$。

### 误差分析

UNSURE 的期望 MSE 为：

$$\frac{1}{n}\mathbb{E}_{x,y}\|f_{\text{ZED}}(y) - x\|^2 = \frac{\text{MMSE}}{1 - \text{MMSE}/\sigma^2} \approx \text{MMSE} + \frac{\text{MMSE}^2}{\sigma^2}$$

> **读解这个误差界**：$\text{MMSE}$ 是可达到的最小均方误差（有监督上限），$\sigma^2$ 是真实噪声方差。等号右边说明，UNSURE 的 MSE 比 MMSE 略高一点（多出 $\text{MMSE}^2/\sigma^2$ 这一项）——这是"不事先知道 $\sigma^2$"付出的边际代价；当 $\text{MMSE}$ 远小于 $\sigma^2$（即去噪效果本就好、信号高度结构化）时，这个额外项趋近于零，UNSURE 逼近最优。

也就是说，UNSURE 的 MSE 比 MMSE 略高一点（多了 $\text{MMSE}^2/\sigma^2$ 项），但**完全不需要知道 $\sigma^2$**。当 MMSE 远小于 $\sigma^2$（即去噪效果本来就好）时，这点额外误差很小。

### 推广

UNSURE 还能扩到更复杂的噪声模型：
- **未知噪声协方差**：$\Sigma$ 未知，用矩阵 Lagrange 乘子估；
- **Poisson-Gaussian 噪声**：同时估 Poisson 参数和高斯方差；
- **实践意义**：Cryo-EM 的噪声近似 PG 且参数未知，UNSURE 特别对路。

## 本节小结

| 方法 | 数据需求 | 噪声知识 | MMSE 最优 | 实现难度 |
|------|---------|---------|---------|---------|
| SURE | 单帧 $y$ | 已知 $\sigma^2$ | ✅ | 中（散度计算） |
| R2R | 单帧 $y$ | 已知 $\sigma^2$ | ✅ | 低（无散度） |
| 盲点网络 | 单帧 $y$ | 仅需独立性 | ❌（受限最优） | 低 |
| UNSURE | 单帧 $y$ | 未知 $\sigma^2$ | ≈ | 中（Lagrange） |

> 表中"盲点网络 ❌（受限最优）"是**理论定位**。实测提醒：本实验的盲点 UNet 因多层绕路泄漏只拿到 14.05 dB（对照 SURE 24.45 dB），补上 Noise2Void 的输入 masking 才回到 22.67 dB——实际掉分幅度可以远大于"受限最优"的理论代价，见上方 **实验 17.4-1（步骤 4/4b）**。

盲点网络和 UNSURE 代表两种不同策略：
- **盲点网络**：用简单约束防过拟合，牺牲最优性换简洁；
- **UNSURE**：用优化自动估噪声参数，近似保持最优性。

> **SURE 视角的统一**：所有方法都能从 SURE 出发理解——盲点网络是 SURE 的约束版，UNSURE 是 SURE 的参数自适应版。

这就是本章"从噪声数据里自学"近一半的图景。**但我们至今都默认 $A = I$（纯去噪）**。可当 $A \neq I$（不完整测量，如图像修复、CT、MRI），自监督风险会撞上一个根本性的新麻烦：**零空间问题**。在 $A$ 的零空间方向上，自监督损失一点都约束不了网络。等变成像（Equivariant Imaging）用信号分布的对称性来补这块空白——自然地把本章主线的"内在结构"从噪声的统计扩展到了信号的几何。

## 直觉：盲点为什么"看不见噪声"

拿一段平滑的一维信号来想：邻域能预测中心，噪声却逐点独立。比较两种"预测自己"的做法——

- **非盲点（抄自己）**：直接把观测 $y_i$ 当预测。残差看着很小，其实它原样把噪声留了下来，MSE 约等于噪声方差 $\sigma^2$；
- **盲点（邻域均值）**：用左右邻居 $(y_{i-1}+y_{i+1})/2$ 替代自己。信号因平滑被邻域接住，噪声因独立而相互抵消，MSE 明显更小。

关键不在"邻域均值"这个具体算子，而在背后的结构约束：只要网络预测第 $i$ 个像素时**看不到 $y_i$ 本身**，它就无法走"抄自己"这条捷径去记噪声，只能被迫去学习邻域里的真实信号。这正是真实盲点网络把卷积核中心置零所要实现的机制，也是配套实验 **17.4-1（步骤 4）** 用可训练盲点架构在 MNIST 上实测的内容。该实验同时给这条直觉划出边界：中心置零只在**单层**内严格成立，端到端仍会绕路泄漏，直觉要兑现得靠 Noise2Void 的输入 masking 补一刀（完整数据见上方 **实验 17.4-1**）。
