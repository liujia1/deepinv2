## 17.4.1 核心思想：不看就能学

SURE 用精确的"自由度修正"实现无偏，但散度计算毕竟麻烦。另一套路更直觉、更轻量：**直接限制网络别看某些像素**。

**过拟合噪声的机制**：去噪时，$f(y)$ 要预测每个像素的干净值。如果 $f_i(y)$ 可以依赖输入的第 $i$ 个像素 $y_i$，网络就能直接"抄"$y_i$ 里的噪声，让 $f_i(y) \approx y_i$——残差 $\|y - f(y)\|^2$ 很小，可重建结果就是噪声本身。

**约束策略**：限制 $f_i(y)$ 不依赖 $y_i$，即 $\frac{\partial f_i}{\partial y_i}(y) = 0$。这样网络没法"偷看"$y_i$ 的噪声值，只能靠邻域信息推断像素 $i$ 的干净值。

**直觉类比**：想象你在做填空题——如果答案不在题目里，你只能靠上下文（邻域像素）推。对图像而言，邻域像素富含"这个像素该是什么"的信息（图像的局部相关性），可噪声是逐像素独立的，邻域里**不含**该像素噪声的信息。所以"不看自己"既能去噪，又不会把噪声抄进来。

**前提条件**：这招要求噪声逐像素独立：

$$p(y|x) = \prod_{i=1}^n p(y_i|x_i)$$

若噪声有空间相关性（如相关高斯噪声），邻域里也夹带了该像素的噪声信息，盲点策略就不安全了。

## 17.4.2 Noise2Void：掩码策略与盲点网络

### Noise2Void（Krull et al. 2019）

最简单的盲点实现：

1. 对输入 $y$ 随机挑像素位置 $i$；
2. 用邻域像素替换 $y_i$（如 4 邻域均值），得到 $\tilde{y}$；
3. 只在被替换的像素上算损失：$\mathcal{L} = (y_i - f_i(\tilde{y}))^2$。

**掩码策略的实质**：$f_i(\tilde{y})$ 不依赖 $y_i$（因为它被换掉了），只依赖其他像素。网络被迫从邻域推断——这正是去噪。

- **优点**：实现极简，只改训练循环的预处理。
- **缺点**：每次只在一个像素上算损失，训练效率低；替换本身引入偏差。

### 盲点网络（Blind-Spot Network，Laine et al. 2019）

更优雅：直接靠架构实现盲点。把卷积核中心权重置零，让输出像素 $i$ 不依赖输入像素 $i$：

```
标准3×3卷积核：         盲点3×3卷积核：
[a  b  c]              [a  b  c]
[d  e  f]    →         [d  0  f]    中心权重置零
[g  h  i]              [g  h  i]
```

- **优点**：每个像素都能算损失（不用掩码），训练高效；硬约束，不会意外泄漏。
- **缺点**：限制了感受野中心；大感受野需更多层。

### Noise2Self（Batson & Royer 2019）

更一般的理论框架——**$\mathcal{J}$-不变性**（J-invariance，指"预测某组坐标时，不看这组坐标的输入"）。

**定义**：设 $\mathcal{J}$ 是坐标的一个划分（把像素分成若干组），函数 $f$ 是 $\mathcal{J}$-不变的，若对每组 $J$，预测 $J$ 的值时不看 $y_J$ 的输入。

**直觉**：Noise2Void 的逐像素盲点对应 $\mathcal{J} = \{\{1\},\{2\},\dots,\{n\}\}$（每像素一组）；但 $\mathcal{J}$-不变性允许更灵活的分组——比如把图像分成棋盘格两组，一组预测另一组。

**Noise2Self 定理**：若 $f$ 是 $\mathcal{J}$-不变的，且噪声逐像素独立，则在 $\mathcal{J}$-不变函数族 $\mathcal{F}_{\mathcal{J}}$ 内：

$$\text{argmin}_{f \in \mathcal{F}_{\mathcal{J}}} \mathbb{E}_y\|y - f(y)\|^2 = \text{argmin}_{f \in \mathcal{F}_{\mathcal{J}}} \mathbb{E}_{x,y}\|x - f(y)\|^2$$

**证明思路**（可跳过，记住结论即可）：关键是证 $\mathbb{E}[\varepsilon^\top f(y)] = 0$。由噪声独立性，$\varepsilon_i$ 与 $y$ 中除第 $i$ 组外的部分独立；而 $\mathcal{J}$-不变性又让 $f_i(y)$ 不依赖 $\varepsilon_i$（因为它不看自己那组）。于是 $\mathbb{E}[\varepsilon_i f_i(y)] = \mathbb{E}[\varepsilon_i]\,\mathbb{E}[f_i(y)] = 0$。由此 $\mathbb{E}_y\|y - f(y)\|^2 = \mathbb{E}_{x,y}\|x - f(y)\|^2 + n\sigma^2$，常数不影响最小化。$\blacksquare$

**意义**：在 $\mathcal{J}$-不变函数族内，最小化这个不需要干净标签的自监督损失，等于最小化需要干净标签的真实 MSE——这就是盲点策略的理论保证。

## 17.4.3 SURE 视角：盲点网络是 SURE 的约束版本

盲点网络和 SURE 看着八竿子打不着，其实有深刻数学联系。

**回顾 SURE**：

$$\mathcal{L}_{\text{SURE}}(y, f) = \|y - f(y)\|^2 + 2\sigma^2 \underbrace{\sum_i \frac{\partial f_i}{\partial y_i}(y)}_{\text{div}\, f(y)}$$

**盲点约束**：$\frac{\partial f_i}{\partial y_i}(y) = 0,\ \forall i, \forall y$。

在盲点约束下，SURE 的修正项整个归零：

$$\mathcal{L}_{\text{SURE}}\big|_{\text{blind-spot}} = \|y - f(y)\|^2 + 0 = \|y - f(y)\|^2$$

**这就是盲点网络的损失！**

所以盲点网络 = SURE 在 $\text{div}\, f = 0$ 约束下的特例。代价是函数族缩小了——从所有可微函数 $\mathcal{F}$ 缩到 $\mathcal{J}$-不变函数 $\mathcal{F}_{\mathcal{J}}$——最优解不再是全局 MMSE 估计器 $\mathbb{E}[x|y]$，而是**受限最优**：

$$f^*_{\text{blind}} = \text{argmin}_{f \in \mathcal{F}_{\mathcal{J}}} \mathbb{E}_{x,y}\|x - f(y)\|^2$$

**关键结论**：盲点网络以牺牲 MMSE 最优性，换来了实现简单、且**不依赖噪声水平**。Tachella 研讨会上也明确指出：从 SURE 视角看，盲点网络不是 MMSE 最优的——因为约束 $\partial f_i/\partial y_i = 0$ 太严，把全局最优解 $\mathbb{E}[x|y]$ 排除在外了（后者一般 $\partial f_i/\partial y_i \neq 0$）。

## 17.4.4 UNSURE：未知噪声水平的自监督学习

SURE 和 R2R 都要已知 $\sigma^2$。可真实场景里噪声水平常常**未知**——Cryo-EM 的噪声分布复杂难建模，天文图像的噪声随观测条件变。

**问题**：$\sigma^2$ 未知，SURE 里那个 $2\sigma^2 \text{div}\, f(y)$ 就没法算。能不能同时把 $f$ 和 $\sigma^2$ 一起估出来？

### UNSURE 公式（Tachella et al., ICLR 2025）

用 Lagrange 乘子（Lagrange multiplier，一种"带约束优化"的技巧，这里把未知的 $\sigma^2$ 变成一个可训练的乘子 $\eta$）替代已知 $\sigma^2$：

$$\min_f \max_\eta \mathbb{E}_y\left[\|y - f(y)\|^2 + 2\eta \sum_{i=1}^n \frac{\partial f_i}{\partial y_i}(y)\right]$$

其中 $\eta$ 扮演 SURE 里 $\sigma^2$ 的角色，但不必预先给定。

### 闭式解

UNSURE 的解有和 Tweedie 一样优美的闭式（closed-form，指能写成明确公式、不用迭代求解）：

$$\boxed{f_{\text{ZED}}(y) = y + \hat{\eta}\,\nabla_y \log p_y(y)}$$

其中 $\hat{\eta}$ 自动估为：

$$\hat{\eta} = \left(\frac{1}{n}\mathbb{E}_y\|\nabla_y \log p_y(y)\|^2\right)^{-1}$$

**与 Tweedie 的关系**：Tweedie 给的是 $f^*(y) = y + \sigma^2 \nabla_y \log p_y(y)$；UNSURE 形式完全一致，只是用自动估出的 $\hat{\eta}$ 换掉了 $\sigma^2$。

### 误差分析

UNSURE 的期望 MSE 为：

$$\frac{1}{n}\mathbb{E}_{x,y}\|f_{\text{ZED}}(y) - x\|^2 = \frac{\text{MMSE}}{1 - \text{MMSE}/\sigma^2} \approx \text{MMSE} + \frac{\text{MMSE}^2}{\sigma^2}$$

也就是说，UNSURE 的 MSE 比 MMSE 略高一点（多了 $\text{MMSE}^2/\sigma^2$ 项），但**完全不需要知道 $\sigma^2$**。当 MMSE 远小于 $\sigma^2$（即去噪效果本来就好）时，这点额外误差很小。

### 推广

UNSURE 还能扩到更复杂的噪声模型：
- **未知噪声协方差**：$\Sigma$ 未知，用矩阵 Lagrange 乘子估；
- **Poisson-Gaussian 噪声**：同时估 Poisson 参数和高斯方差；
- **实践意义**：Cryo-EM 的噪声近似 PG 且参数未知，UNSURE 特别对路。

## 本节小结

| 方法 | 数据需求 | 噪声知识 | MMSE 最优 | 实现难度 |
|------|---------|---------|---------|---------|
| SURE | 单帧 $y$ | 已知 $\sigma^2$ | ✅ | 中（散度计算） |
| R2R | 单帧 $y$ | 已知 $\sigma^2$ | ✅ | 低（无散度） |
| 盲点网络 | 单帧 $y$ | 仅需独立性 | ❌（受限最优） | 低 |
| UNSURE | 单帧 $y$ | 未知 $\sigma^2$ | ≈ | 中（Lagrange） |

盲点网络和 UNSURE 代表两种不同策略：
- **盲点网络**：用简单约束防过拟合，牺牲最优性换简洁；
- **UNSURE**：用优化自动估噪声参数，近似保持最优性。

> **SURE 视角的统一**：所有方法都能从 SURE 出发理解——盲点网络是 SURE 的约束版，UNSURE 是 SURE 的参数自适应版。

至此，所有方法都假设 $A = I$（纯去噪）。可当 $A \neq I$（不完整测量，如图像修复、CT、MRI），自监督风险会撞上一个根本性的新麻烦：**零空间问题**。在 $A$ 的零空间方向上，自监督损失一点都约束不了网络。等变成像（Equivariant Imaging）用信号分布的对称性来补这块空白。

**来源**：Tachella P15-19（盲点网络与 UNSURE）；Krull et al. (2019) Noise2Void；Batson & Royer (2019) Noise2Self；Laine et al. (2019) 盲点网络；Tachella et al. (ICLR 2025) UNSURE

## 动手感受：盲点网络怎么"看不见噪声"（可运行）

下面这段 numpy 代码演示盲点思想的精髓：对一个一维信号，比较"网络能看自己像素"和"网络盲掉自己像素（用邻域均值替代）"两种情形下，去噪 MSE 的差异。你会看到盲点如何让网络被迫依赖信号结构、而不是抄噪声。

```python
# ============================================================
# 17.4 动手实验：盲点 vs 非盲点 去噪对照
# 只需 numpy，无需外部数据
# ============================================================
import numpy as np

np.random.seed(0)
N = 512
sigma = 0.4

# 造一个平滑的"干净信号"（局部相关，邻域能预测自己）
t = np.linspace(0, 4*np.pi, N)
x_clean = np.sin(t) + 0.5*np.sin(3*t)
y = x_clean + sigma * np.random.randn(N)     # 带噪观测

# 非盲点预测：直接抄自己像素（极端过拟合噪声）
x_copy = y

# 盲点预测：用左右邻域均值替代自己像素（网络"看不见"y_i）
x_blind = (np.roll(y, 1) + np.roll(y, -1)) / 2.0

mse = lambda a, b: np.mean((a - b) ** 2)
print(f"[非盲点 抄自己] MSE = {mse(x_copy, x_clean):.4f}   <- 残差小但学到的是噪声")
print(f"[盲点 邻域均值] MSE = {mse(x_blind, x_clean):.4f}   <- 被迫靠邻域信号")

# 直觉对照：盲点 MSE 通常明显小于"抄自己"，因为噪声逐点独立、邻域不含它
print("注：真实盲点网络用可训练架构学邻域映射，这里用邻域均值演示同一思想。")
```

**你应该看到的现象**："抄自己"的 MSE 约等于噪声方差 $\sigma^2$（它把噪声原样留下了），而盲点（邻域均值）的 MSE 更小——因为平滑信号的邻域能预测自己，而噪声在邻域里互相独立、平均会抵消。这正呼应"不看自己 → 看不见噪声 → 只能靠信号"的核心直觉。
