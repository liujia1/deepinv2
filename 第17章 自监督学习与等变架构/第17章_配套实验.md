## 实验17.1 Noise2Noise与自监督去噪

> **对应知识点**：17.1.1节数据困境、17.1.2节四种学习设定、17.1.3节自监督风险估计目标、17.2.1节N2N核心思想、17.2.2节理论保证、17.2.3节实践局限与Neighbor2Neighbor
>
> **实验目的**：理解四种学习设定的数据需求差异，验证Noise2Noise与监督学习的等价性，揭示朴素自监督损失‖y-f(y)‖²的偏差来源，实践Neighbor2Neighbor空间配对策略
>
> **素材来源**：MiniProject_Self_Supervised中N2N思路、deepinv.loss API

### 场景描述

自监督学习的起点是数据困境（17.1.1节）：监督学习需要配对(x,y)数据，但医学/科学成像中干净参考x往往无法获取。四种学习设定（17.1.2节）构成数据需求的递减谱系：

$$\text{监督}(x,y) \;\to\; \text{合成配对}(x+\text{噪声模型}) \;\to\; \text{无监督-x}(仅x) \;\to\; \text{无监督-y}(仅y)$$

Noise2Noise（17.2节）是设定4与设定1之间的桥梁——用零均值噪声标签y'替代干净标签x，最优解不变。但在只有单帧噪声观测时，朴素损失‖y-f(y)‖²有偏（17.3.1节）。

使用MNIST 32×32 + 高斯噪声(σ=0.3)，训练SmallUNet去噪器。

### 实验步骤

#### 步骤1：四种学习设定的数据构造与对比（17.1.2节）

**场景**：在同一组图像上，展示四种学习设定下的数据可用性。

**输入**：MNIST测试集8张图像，加高斯噪声σ=0.3

**预期结果**：设定1-3需要干净数据x，设定4仅需要噪声观测y——本章的核心挑战

**实际效果**：

生成图`step1_four_settings.png`，4行×8列：第1行设定1(监督)显示配对(x,y)，第2行设定2(合成配对)显示x+合成噪声，第3行设定3(无监督-x)显示仅干净图像，第4行设定4(无监督-y)显示仅噪声观测。直观展示：从上到下，数据需求递减，但技术挑战递增。

#### 步骤2：Noise2Noise原理验证（17.2.1—17.2.2节）

**场景**：验证Noise2Noise的核心定理——argmin E‖y'-f(y)‖² = argmin E‖x-f(y)‖² = E[x|y]

**核心公式**（17.2.2节）：
- 监督：min_f E‖x - f(y)‖² → f* = E[x|y]
- N2N：min_f E‖y' - f(y)‖² → f* = E[y'|y] = E[E[y'|x]|y] = E[x|y]

**预期结果**：N2N的PSNR接近监督基线——验证零均值噪声下E[y'|x]=x的等价性

**实际效果**：

生成图`step2_n2n_vs_supervised.png`，3行×6列：噪声输入、监督去噪、N2N去噪。N2N PSNR ≈ 监督PSNR（差距<1dB），验证了定理17.2.2——零均值噪声的期望即信号。

#### 步骤3：朴素自监督损失偏差分析（17.3.1节）

**场景**：揭示‖y-f(y)‖²的偏差——它系统性地低估真实风险。

**核心公式**（17.3.1节）：

$$\mathbb{E}\|y-f(y)\|^2 = R_{\text{SUP}}(f) + n\sigma^2 - 2\mathbb{E}[\varepsilon^\top f(y)]$$

偏差来源于$\mathbb{E}[\varepsilon^\top f(y)] = \sigma^2 \mathbb{E}[\text{div}\, f(y)] \neq 0$（Stein引理）

**预期结果**：朴素自监督PSNR显著低于监督和N2N；散度div f(y)非零导致偏差

**实际效果**：

生成图`step3_naive_bias.png`，左图为训练损失曲线（监督/N2N/朴素三条线），右图为PSNR柱状图。朴素‖y-f(y)‖²的PSNR明显低于监督和N2N，因为网络可以"拟合噪声"使残差小但重建差。散度分析显示：朴素模型的div f(y)显著大于监督模型——这解释了偏差的方向和大小。

#### 步骤4：Neighbor2Neighbor空间配对（17.2.3节）

**场景**：当无法获取配对噪声数据时，利用空间邻域结构构造"伪配对"。

**核心思想**（17.2.3节）：空间独立的噪声在相邻像素间也独立，因此将图像按棋盘格分成两个子图，可近似作为同一信号的配对噪声观测。

**预期结果**：N2B的PSNR接近N2N但略低——空间独立性假设引入近似误差

**实际效果**：

生成图`step4_comparison.png`，5行×3列综合对比：干净图像、噪声输入、监督、N2N、朴素方法。PSNR排序：监督 ≈ N2N > N2B > 朴素，验证了17.2.3节的分析——N2B是N2N在不具备配对数据时的实用替代，但近似配对引入的误差使性能略低。

### 补充说明

1. **Noise2Noise等价性不限于高斯噪声**：17.2.2节指出，任何零均值噪声都成立，包括Poisson噪声（信号强度足够大时近似零均值）
2. **散度与偏差的定量关系**：偏差=2σ²·div f，这是SURE的核心（17.3.2节），实验17.2将利用这一关系消除偏差
3. **Neighbor2Neighbor的前提**：噪声必须逐像素空间独立（17.4.1节条件），空间相关噪声下N2B可能失效
4. **四种学习设定的递进关系**：每一步都是前一步局限性的回应——这是本章的叙事弧

## 实验17.2 SURE与盲点网络

> **对应知识点**：17.3.1节朴素MSE偏差、17.3.2节Stein引理与SURE公式、17.3.3节MC-SURE与Autodiff-SURE、17.3.4节SURE→Tweedie闭环、17.3.5节R2R、17.4.1节盲点核心思想、17.4.2节Noise2Void/盲点网络/Noise2Self、17.4.3节盲点=SURE约束版、17.4.4节UNSURE
>
> **实验目的**：验证SURE的自由度修正项消除偏差，对比MC-SURE与Autodiff-SURE，实践R2R避免散度计算，实现盲点网络并验证其受限最优性，确认SURE→Tweedie闭环
>
> **素材来源**：MiniProject_Self_Supervised中SURE API、deepinv.loss API

### 场景描述

SURE（17.3节）是自监督学习的理论基石——仅用单帧噪声观测y，通过自由度修正项2σ²div f消除朴素MSE的偏差。其最优解恰好是Tweedie公式（17.3.4节），与第5章形成闭环。

R2R（17.3.5节）通过重新加噪构造独立副本，完全避免散度计算。盲点网络（17.4节）通过架构约束∂f_i/∂y_i=0，使SURE退化为‖y-f(y)‖²——简单但受限最优。

使用MNIST 32×32 + 高斯噪声(σ=0.3)，训练SmallUNet和BlindSpotUNet。

### 实验步骤

#### 步骤1：SURE原理验证——自由度修正项消除偏差（17.3.2节）

**场景**：用MC-SURE训练去噪器，追踪残差项和修正项随训练的演化。

**核心公式**（17.3.2节）：

$$\mathcal{L}_{\text{SURE}}(y, f) = \underbrace{\|y - f(y)\|^2}_{\text{残差项}} + \underbrace{2\sigma^2 \sum_i \frac{\partial f_i}{\partial y_i}(y)}_{\text{自由度修正项}}$$

**预期结果**：SURE的PSNR接近监督基线；修正项随训练逐渐减小（网络逐渐停止过拟合噪声）

**实际效果**：

生成图`step1_sure_correction.png`，左图为训练过程中残差项/修正项/SURE总损失的演化曲线，右图为PSNR柱状图（监督/SURE/朴素）。SURE PSNR ≈ 监督PSNR，显著高于朴素‖y-f(y)‖²。修正项在训练初期较大（网络灵活，容易过拟合噪声），随训练逐渐减小——这验证了17.3.2节的直觉：div f衡量"f追踪噪声的倾向"。

#### 步骤2：Monte Carlo SURE vs Autodiff SURE（17.3.3节）

**场景**：对比两种散度估计方法的精度。

**核心公式**（17.3.3节）：
- MC-SURE：div f ≈ (1/α)ω^T[f(y+αω) - f(y)]，Ramani et al. (2007)
- Autodiff-SURE：div f ≈ ω^T(∂f/∂y)ω，Hutchinson迹估计

**预期结果**：Autodiff精确但需反向传播；MC近似受α参数影响

**实际效果**：

生成图`step2_mc_vs_autodiff.png`，柱状图对比MC(α=0.01/0.001/0.0001)和Autodiff的散度估计值。α太大→近似误差大，α太小→数值不稳定。Autodiff提供精确的散度估计但需要额外的反向传播。这呼应17.3.3节的分析：MC-SURE仅需2次前向传播，计算高效但受α影响；Autodiff精确但计算代价更高。

#### 步骤3：R2R——避免散度计算的SURE替代（17.3.5节）

**场景**：用R2R训练去噪器，避免散度计算，并分析α参数敏感性。

**核心公式**（17.3.5节）：

$$\mathcal{L}_{\text{R2R}}(y, f, \alpha) = \mathbb{E}_\omega\|y_b - f(y_a)\|^2$$

其中$y_a = y + \alpha\omega$，$y_b = y - \omega/\alpha$，关键性质：$y_a$和$y_b$给定$x$时条件独立。

**预期结果**：R2R PSNR接近SURE；α∈[0.05, 0.5]效果较好，太小数值不稳定，太大近似误差大

**实际效果**：

生成图`step3_r2r.png`，左图为SURE vs R2R的PSNR柱状图，右图为α参数敏感性曲线。R2R PSNR ≈ SURE PSNR（差距<1dB），验证了17.3.5节的渐近等价性。α敏感性：α≈0.05-0.1时效果最好，α=1.0时近似误差增大，α=0.01时数值不稳定——呼应17.3.5节"α不能太小（数值不稳定），也不能太大（近似误差大）"的分析。

#### 步骤4：盲点网络——架构约束防止过拟合（17.4.2—17.4.3节）

**场景**：实现盲点卷积（中心权重置零），验证∂f_i/∂y_i≈0，对比盲点网络与SURE的PSNR。

**核心公式**（17.4.3节）：在盲点约束∂f_i/∂y_i=0下，SURE退化为：

$$\mathcal{L}_{\text{SURE}}\big|_{\text{blind-spot}} = \|y - f(y)\|^2 + 0 = \|y - f(y)\|^2$$

代价：函数族缩小→受限最优 < 全局最优（MMSE）

**预期结果**：盲点网络散度≈0；PSNR低于SURE——受限最优性的代价

**实际效果**：

生成图`step4_blindspot_kernels.png`，上排展示盲点卷积核（中心权重=0，用×标记），下排展示标准卷积核（中心权重非零）。盲点网络的散度div f(y)≈0（验证∂f_i/∂y_i=0），而标准UNet的散度非零。PSNR：盲点 < SURE，验证17.4.3节的核心结论——盲点网络是SURE在div f=0约束下的特例，牺牲MMSE最优性换取实现简洁和噪声水平无依赖。

#### 步骤5：SURE→Tweedie闭环验证（17.3.4节）

**场景**：验证SURE训练的去噪器满足Tweedie公式。

**核心公式**（17.3.4节）：

$$f^*(y) = y + \sigma^2 \nabla_y \log p_y(y) \quad \text{(Tweedie公式)}$$

**预期结果**：(f(y)-y)/σ² ≈ ∇log p_y(y)，即去噪器=得分估计器

**实际效果**：

生成图`step5_tweedie_closure.png`，上排展示去噪器输出f(y)，下排展示Tweedie得分(f(y)-y)/σ²。得分图呈现有意义的结构（非随机噪声），验证了17.3.4节的SURE→Tweedie闭环：从噪声数据出发，SURE训练的去噪器最优解恰好是Tweedie公式给出的MMSE估计器，而Tweedie公式又将去噪器与得分函数联系起来——这条链从噪声数据→SURE→去噪器→得分→扩散采样，即使没有干净数据，理论闭环依然成立。

### 补充说明

1. **SURE→Tweedie是本章最重要的理论贡献**：它将自监督学习与全书核心理论链连接起来（17.3.4节），与第5章Tweedie等式、第6章得分匹配形成闭环
2. **R2R与SURE的渐近等价性**：α→0时L_R2R→L_SURE（附录17B），实践中α∈[0.05,0.1]即可达到接近的效果
3. **盲点网络的简化**：∂f_i/∂y_i=0使损失函数简化为‖y-f(y)‖²，但代价是函数族缩小→次优（17.4.3节）
4. **UNSURE的推广**：当σ²未知时，用Lagrange乘子η替代σ²（17.4.4节），解的形式仍为Tweedie公式但σ²自动估计

## 实验17.3 等变成像与测量一致性

> **对应知识点**：17.5.1节零空间问题、17.5.2节多算子成像MOI、17.5.3节等变性数学定义与算子-等变性对照表、17.5.4节EI原理与损失函数、17.5.5节REI++、17.5.6节实验与应用、17.6.1节测量一致性MC损失、17.6.2节等变架构设计、17.6.3节MC+EI互补性
>
> **实验目的**：直观理解零空间问题（自监督损失不约束缺失区域），实践EI损失利用平移对称性约束零空间，验证MC约束值空间/EI约束零空间的互补性，数值验证算子-等变性对照表
>
> **素材来源**：deepinv.loss.EILoss思路、17.5节理论、17.6节MC损失

### 场景描述

当A≠I时（17.5节），自监督风险E‖A(x-f(y))‖²仅在A的值空间惩罚误差，零空间方向完全不受约束（17.5.1节）。等变成像（17.5.4节）利用信号分布的对称性（如平移不变性）"虚拟"产生多个算子AT_g——若A不是G-等变的，则AT_g与A有不同的零空间，相当于"免费"获得约束。

测量一致性（17.6.1节）约束值空间方向，等变性约束零空间方向——两者互补（17.6.3节）。

使用MNIST 32×32 + 随机inpainting（保留50%像素）+ 低噪声(σ=0.05)，训练SmallUNet。

### 实验步骤

#### 步骤1：零空间问题——自监督损失不约束缺失区域（17.5.1节）

**场景**：用inpainting（最直观的零空间问题）展示仅用MC损失时缺失像素区域的重建失败。

**核心公式**（17.5.1节）：零空间null(A)中的分量不受约束：

$$\mathcal{L}_{\text{SURE}}^A = \|y - Af(y)\|^2 + 2\sigma^2 \text{tr}\left(A^\top \frac{\partial f}{\partial y}\right)$$

对于被遮蔽的像素，Af(y)不包含这些像素的信息→损失无法惩罚

**预期结果**：仅MC损失的模型在缺失像素区域重建差（零空间方向自由发挥）

**实际效果**：

生成图`step1_nullspace.png`，3行×6列：干净图像、观测y=M⊙x、朴素MC重建。朴素MC重建的PSNR较低，缺失像素区域出现伪影或不合理的填充——因为MC损失仅保证Af(y)≈y（观测像素正确），但不约束零空间方向（缺失像素的值可以任意）。

#### 步骤2：等变成像（EI）损失——平移对称性约束零空间（17.5.4节）

**场景**：实现EI损失，利用平移不变性"虚拟"产生多个算子约束零空间。

**核心公式**（17.5.4节）：

$$\mathcal{L}_{\text{EI}}(y, f) = \mathbb{E}_g\|T_g \hat{x} - f(AT_g \hat{x})\|^2$$

其中$\hat{x} = f(y)$作为参考重建。对重建结果做平移T_g后再重新测量AT_g x̂、重建，结果应与平移后的重建T_g x̂一致。

**预期结果**：MC+EI的PSNR显著高于纯MC——EI约束了零空间方向

**实际效果**：

MC+EI模型的PSNR高于纯MC模型。EI通过平移对称性"虚拟"产生不同零空间的算子AT_g，使零空间方向也受到约束——被遮蔽像素必须满足：平移后重新测量再重建，结果应等于平移后的重建。这验证了17.5.4节的核心思想：若A不是G-等变的，则AT_g与A有不同的零空间。

#### 步骤3：测量一致性（MC）损失增强（17.6.1节）

**场景**：分析纯MC损失的效果——它约束值空间方向但无法约束零空间。

**核心公式**（17.6.1节）：$\mathcal{L}_{\text{MC}} = \|y - Af(y)\|^2$

**预期结果**：纯MC在观测像素上PSNR高，缺失像素PSNR低

**实际效果**：

纯MC模型在观测像素（值空间）的PSNR较高（Af(y)≈y得到满足），但缺失像素（零空间）的PSNR低——MC无法提供零空间方向的约束。这验证了17.6.1节的分析：MC损失仅约束"可见"方向。

#### 步骤4：MC + EI互补性验证（17.6.3节）

**场景**：对比MC+EI联合训练 vs 纯MC vs 监督，分别统计观测像素和缺失像素的PSNR。

**核心公式**（17.6.3节）：

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{UNSURE}} + \lambda_{\text{EI}}\mathcal{L}_{\text{EI}} + \lambda_{\text{MC}}\mathcal{L}_{\text{MC}}$$

- MC约束值空间方向（Af(y)≈y）
- EI约束零空间方向（f(AT_g x)≈T_g f(Ax)）

**预期结果**：MC+EI在缺失像素的PSNR显著高于纯MC——EI填补了零空间的约束空白

**实际效果**：

生成图`step4_mc_ei_complement.png`，左图为总体PSNR对比（监督>MC+EI>纯MC>朴素），右图为值空间/零空间分别对比。关键发现：
- **值空间（观测像素）**：MC+EI ≈ 纯MC（MC已经很好地约束值空间）
- **零空间（缺失像素）**：MC+EI >> 纯MC（EI提供了零空间方向的约束）

这直接验证了17.6.3节的核心结论：MC约束"可见方向"的准确性，EI利用对称性填补"不可见方向"的信息——两者互补。

生成图`step4_reconstruction.png`，5行×6列重建结果对比，MC+EI的缺失区域填充效果明显优于朴素MC。

#### 步骤5：算子-等变性对照实验（17.5.3节）

**场景**：数值验证17.5.3节算子-等变性对照表中的结论——AT_g vs T_g A的差异。

**核心判断**（17.5.3节）：
- 若AT_g ≈ T_g A → 等变 → 虚拟算子AT_g与A零空间相同 → EI无法利用
- 若AT_g ≠ T_g A → 非等变 → AT_g与A零空间不同 → EI可以利用

**预期结果**：与17.5.3节对照表一致——高斯模糊+平移等变，Inpainting+平移非等变，MRI+旋转非等变

**实际效果**：

生成图`step5_equivariance_check.png`，柱状图展示各"算子×变换"组合的‖AT_g - T_g A‖值（对数刻度）：

| 算子 | 平移 | 旋转90° |
|------|------|---------|
| 高斯模糊 | ≈0 (等变) | >>0 (非等变) |
| Inpainting(随机) | >>0 (非等变) | >>0 (非等变) |
| MRI欠采样 | ≈0 (近似等变) | >>0 (非等变) |

这与17.5.3节对照表完全一致：
- 高斯模糊+平移等变→EI无法利用平移对称性
- 随机Inpainting+平移/旋转非等变→EI可利用两种对称性
- MRI+平移近似等变→EI难以利用平移对称性，但+旋转非等变→可利用旋转对称性（17.5.6节FastMRI实验的原理）

### 补充说明

1. **零空间是自监督从去噪到逆问题的根本障碍**：A=I时没有零空间，A≠I时零空间方向完全不受约束（17.5.1节）
2. **EI的核心洞察**：对称性"免费"产生多个算子——不需要实际获取不同算子的数据（17.5.4节）
3. **MC与EI互补**：MC保证Af(y)≈y（值空间一致性），EI保证f(AT_g x)≈T_g f(Ax)（零空间对称性），覆盖整个信号空间（17.6.3节）
4. **REI++**：UNSURE + EI的组合同时处理噪声未知和零空间两个挑战（17.5.5节），是当前最完整的自监督框架
5. **等变架构**：除软约束（EI损失）外，还可通过群卷积/Steerable CNN硬编码等变性（17.6.2节），实践中软约束+标准架构最常用
