# 17.2 Noise2Noise：用噪声替代干净标签

> **核心观点**：当噪声是零均值时，多帧噪声观测的条件期望等于干净信号：$\mathbb{E}[y'|x] = x$。因此，用噪声标签替代干净标签训练网络，其最优解与监督学习完全一致——这是自监督学习最简单、最直觉的起点。

## 17.2.1 核心思想：零均值噪声的期望即信号

考虑标准的去噪问题：$y = x + \varepsilon$，其中$\varepsilon$是零均值噪声，$\mathbb{E}[\varepsilon] = 0$。

监督学习的目标是：

$$\min_f \mathbb{E}_{x,y}\|x - f(y)\|^2$$

这个目标需要知道干净信号$x$。但如果我们有同一信号$x$的两帧独立噪声观测$y$和$y'$呢？

**关键观察**：由于$\mathbb{E}[\varepsilon] = 0$，对任意给定的$x$：

$$\mathbb{E}[y'|x] = \mathbb{E}[x + \varepsilon'|x] = x$$

**直觉**：零均值噪声在期望意义下"相互抵消"——多次观测的平均趋向于干净信号。那么，能否用$y'$替代$x$作为训练目标？

Noise2Noise（Lehtinen et al. 2018）提出的目标函数：

$$\min_f \mathbb{E}_{y,y'}\|y' - f(y)\|^2$$

其中$y$和$y'$是同一$x$的两帧独立噪声观测。

## 17.2.2 理论保证

**定理**（Noise2Noise等价性）：在零均值噪声条件下，若$y, y'$给定$x$条件独立，则

$$\text{argmin}_f \mathbb{E}_{y,y'}\|y' - f(y)\|^2 = \text{argmin}_f \mathbb{E}_{x,y}\|x - f(y)\|^2 = \mathbb{E}[x|y]$$

**证明思路**：

**第一步**：展开Noise2Noise目标

$$\mathbb{E}_{y,y'}\|y' - f(y)\|^2 = \mathbb{E}_y\left[\|f(y)\|^2 - 2f(y)^\top \mathbb{E}_{y'|y}[y'] + \mathbb{E}_{y'|y}[\|y'\|^2]\right]$$

**第二步**：利用条件期望的塔性质

$$\mathbb{E}_{y'|y}[y'] = \mathbb{E}_x[\mathbb{E}[y'|x] \mid y] = \mathbb{E}[x|y]$$

这里用到了：(1) $y'$给定$x$条件独立于$y$；(2) $\mathbb{E}[y'|x] = x$（零均值噪声）。

**第三步**：代入得

$$\mathbb{E}_{y,y'}\|y' - f(y)\|^2 = \mathbb{E}_y\left[\|f(y)\|^2 - 2f(y)^\top \mathbb{E}[x|y]\right] + \text{const.}$$

**第四步**：对$f$求最优

$$f^*(y) = \mathbb{E}[x|y]$$

这与监督MSE的最优解完全一致。$\blacksquare$

**推广**：Noise2Noise的等价性不限于高斯噪声——任何零均值噪声都成立，包括Poisson噪声（当信号强度足够大时近似零均值）、混合噪声等。

**与贝叶斯估计的联系**：$f^*(y) = \mathbb{E}[x|y]$正是MMSE估计器（第2章2.3节），也是后验分布的均值（第1章1.5节）。Noise2Noise的优势在于：无需知道后验分布$p(x|y)$的具体形式，只要网络有足够的表达能力，就能自动学到这个最优估计。

## 17.2.3 实践局限

Noise2Noise虽然理论优雅，但有一个关键前提：**需要同一信号的配对噪声观测$(y_i, y_i')$**。

**可以获取配对数据的场景**：
- **Cryo-EM**：同一粒子在不同micrograph中的投影，天然形成配对
- **荧光显微镜**：同一标本的连续帧
- **合成数据**：已知噪声模型时，可从干净图像合成配对噪声数据（退化为设定2）

**难以获取配对数据的场景**：
- **CT/MRI**：患者不能被扫描两次，且两次扫描间解剖结构可能变化
- **自然图像**：同一场景的两次拍摄可能存在运动、光照变化
- **单帧场景**：只有一帧观测，无法配对

**部分缓解——Neighbor2Neighbor**（Huang et al. 2021）：

对于空间独立的噪声（如泊松-高斯噪声），可以利用图像的空间邻域结构构造"伪配对"。将相邻像素分配到两个子图像中，利用噪声的空间独立性近似配对条件。这种方法放宽了配对要求，但仍需噪声具有空间独立性。

## 本节小结

| 方面 | Noise2Noise |
|------|------------|
| 数据需求 | 配对噪声观测$(y, y')$ |
| 噪声假设 | 零均值，条件独立 |
| 最优解 | $\mathbb{E}[x\|y]$（与监督MSE相同） |
| 优势 | 理论最优，无需知道噪声分布的具体形式 |
| 局限 | 需要配对噪声数据 |

Noise2Noise是自监督学习的"零阶解"——用最直接的方式消除对干净标签的依赖。但它仍需要一种"数据奢侈"（配对噪声观测）。下一步我们将看到：能否仅用**单帧**噪声观测训练去噪器？

> **过渡**：Noise2Noise需要配对噪声数据——这仍是一种数据奢侈。能否仅用单帧噪声观测训练去噪器？SURE提供了肯定答案：通过添加一个"自由度修正项"，我们可以仅从单帧$y$无偏估计监督MSE风险。
