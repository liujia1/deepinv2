# 17.0 本章导读：没有干净数据时，怎么训练网络？

> "我们常以为，要让网络学会重建图像，就必须先给它看成千上万张'干净答案'。但很多监督信号，其实就藏在数据自己身上。"

**本章目标**（读完你会带走这些）：
- 说清为什么在医学/科学成像里"干净答案"常常根本拿不到——这是全书实践的真正瓶颈；
- 把学习设定排成一条"数据需求递减"的谱系，知道自己处在第几档；
- 理解自监督风险估计器的核心追求：一个期望等于监督损失的"只看观测 $y$ 的损失"；
- 看懂 Noise2Noise / SURE / R2R / 盲点网络 / UNSURE / 等变成像各自怎么填坑，以及它们如何串成一条进化链；
- 体会到自监督如何让全书"逆问题 → 贝叶斯 → 采样 → 得分 → 扩散"这条长旅，连训练数据都不再是障碍。

---

前 16 章我们搭起了一条漂亮的理论闭环：**逆问题需要后验采样 → 采样需要得分函数 → 得分能从去噪器里提取 → 去噪器靠得分匹配来训练 → 多步得分驱动采样就是扩散模型 → 条件扩散采样等于在解逆问题**。第 16 章把这条闭环在 CT/MRI 重建里真正跑了起来，从最古老的 FBP 一直走到扩散先验。

但有一个假设一直悄悄躺在底下没被搬开：**训练去噪器、训练重建网络，都需要配对的"干净-退化"数据 $(x_i, y_i)$**。第 16 章的 UNet 端到端重建要成对数据，算法展开要成对数据，就连扩散模型本身的训练——也得先有海量干净图像来加噪造对。

在自然图像领域（比如 ImageNet），这没问题，干净图随手可得。但到了医学和科学成像，这个假设会直接塌掉：

- 你没法对同一个病人同时扫一次"有噪声"和一次"无噪声"的 CT——所谓"干净参考"本身也是从测量里重建出来的，自带算法偏差；
- Cryo-EM（冷冻电镜）信噪比低到 SNR < 0.1，"干净"图像根本不存在，每帧都是重度噪声化的；
- 天文成像里，望远镜看到的永远是大气扰动加探测器噪声的混合物。

**所以本章要正面回答一个根本问题：没有干净数据，怎么训练重建网络？**

答案比你想的优雅。核心洞察只有一句话——**我们不需要知道 $x$ 是什么，只要能构造一个只看观测 $y$ 的损失函数，让它的期望恰好等于"假如我们有干净标签时的监督损失"，那我们就能在零干净数据下，训练出和监督学习一样好的网络。**

为什么"期望相等"就够用？因为训练网络本质是"找让损失最小的那个函数"，而给损失整体加一个**常数**，最小值位置一点没变。所以用公式把这个"恰好等于"写清楚（先别慌，后面每节会把它拆开揉碎）：

$$\mathbb{E}_y[\mathcal{L}_{\text{SELF}}(y, f)] = \mathbb{E}_{x,y}\|x - f(y)\|^2 + \text{const.}$$

左边是自监督损失（只依赖观测 $\{y_i\}$），右边是监督 MSE 风险（需要干净 $x$）。中间的 const. 只是个常数，不影响"找最优网络"这件事。这意味着：**期望意义上，只用带噪观测，就能训练出和监督等价的重建网络。**

本章要带你认识的几种方法，其实是一条"从简单到复杂、每一步都在回应上一步短板"的进化链：

- **Noise2Noise**（17.2）：用"另一帧噪声"替代干净标签——零均值噪声的期望，本来就是信号本身。
- **SURE**（17.3）：只给一帧噪声观测，加一个"自由度修正项"来无偏估计真实风险，理论最优。
- **R2R**（17.3）：用"重新加噪"造出独立副本，绕开 SURE 里那个费劲的散度计算。
- **盲点网络**（17.4）：干脆让网络"别看某些像素"，从结构上杜绝它偷记噪声——更简单，但代价是放弃了理论最优。
- **UNSURE**（17.4）：把 SURE 推广到"噪声水平都不知道"的真实场景。
- **等变成像**（17.5–17.6）：当测量不完整（$A \neq I$，比如 CT/MRI 只采了部分数据）时，用信号本身的对称性（平移、旋转…）去约束那些"测量看不见"的方向。

> **和全书的因果串联**：第 5 章说"去噪器 = 得分估计器"（Tweedie 公式），第 6 章说"得分匹配训练去噪器"。本章会揭示一个闭环惊喜——**SURE 训练出来的最优去噪器，恰好就是 Tweedie 公式本身**。于是"从噪声数据 → SURE 训练 → 去噪器 → 得分函数 → 扩散采样"这条链，哪怕没有一张干净图也成立。自监督学习，是全书"从逆问题出发，经贝叶斯→采样→得分→扩散"这趟长旅的最后一环：**连训练数据都不再是障碍。**

读完本章，你会明白：自监督学习不是监督学习的"低配山寨版"，而是一个有独立理论根基的完整框架。从 Stein 引理到 Tweedie 公式，从等变性到测量一致性，这些工具让"无干净数据训练"不仅在纸面上可行，实践中也逼近监督学习的性能。

```
数据困境与学习设定(17.1) → Noise2Noise(17.2) → SURE与R2R(17.3) → 盲点网络与UNSURE(17.4) → 等变成像(17.5) → 测量一致性与等变架构(17.6) → 小结(17.7)
```
