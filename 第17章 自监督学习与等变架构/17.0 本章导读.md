# 17.0 本章导读：没有干净数据时如何学习？

> **核心观点**：自监督风险估计——构建仅依赖观测数据$\{y_i\}$的损失函数$\mathcal{L}_{\text{SELF}}$，使其期望等于监督损失加常数：$\mathbb{E}_y[\mathcal{L}_{\text{SELF}}] = \mathbb{E}_{x,y}\|x - f(y)\|^2 + \text{const.}$。这意味着无需任何干净数据，仅用带噪观测即可训练与监督学习等价的重建网络。

前16章建立了一个宏大的理论闭环：逆问题需要后验采样→采样需要得分函数→得分可以从去噪器中提取→去噪器可通过得分匹配训练→多步得分驱动采样即扩散模型→条件扩散采样=逆问题求解。第16章将这一理论在CT/MRI重建中落地，展示了从FBP到扩散先验的演化路径。但贯穿始终有一个隐含假设：**训练去噪器/重建网络需要配对的干净-退化数据**。

第16章的UNet端到端重建需要$\{(y_i, x_i)\}$配对，算法展开需要配对训练，甚至扩散模型的训练也需要大量干净图像来构造加噪数据对。在自然图像领域（如ImageNet），干净数据随手可得；但在医学和科学成像中，这个假设根本不成立——CT扫描无法对同一患者同时获取"有噪声"和"无噪声"的图像，Cryo-EM的极低信噪比使得"干净"参考图像根本不存在。

这就是本章要解决的核心问题：**没有干净数据时，如何训练重建网络？**

答案令人惊讶地优雅：**自监督风险估计**。核心洞察是——我们不需要知道$x$是什么，只需要构建一个仅依赖$y$的损失函数，使其期望等于监督MSE风险。不同方法用不同策略实现这一目标：

- **Noise2Noise**：用另一帧噪声观测替代干净标签，零均值噪声的期望就是信号本身
- **SURE**：添加"自由度修正项"来补偿朴素MSE的偏差，实现风险的无偏估计
- **R2R**：通过重新加噪构造独立副本，避免SURE的散度计算
- **盲点网络**：限制网络不看某些像素，从结构上防止过拟合噪声
- **UNSURE**：将SURE推广到噪声水平未知的实际场景
- **等变成像**：利用信号分布的对称性约束，从不完整测量中学习

这些方法构成一条从简单到复杂的逻辑链：Noise2Noise最直觉但需要配对噪声数据→SURE理论最优但需已知噪声水平→盲点网络更简单但次优→UNSURE处理未知噪声→等变成像扩展到不完整测量。每一步都是前一步局限性的回应，与全书的叙事弧完全一致。

更重要的是，SURE的最优解恰好是Tweedie公式——这与第5章形成了闭环。第5章告诉我们"去噪器=得分估计器"，第6章告诉我们"得分匹配训练去噪器"，而本章告诉我们"即使没有干净数据，SURE也能训练出去噪器，其最优解就是Tweedie公式"。这条链意味着：**从噪声数据出发，通过自监督训练，我们同样可以获得可驱动PnP和扩散采样的得分估计器**。

```
数据困境与学习设定(17.1) → Noise2Noise(17.2) → SURE与R2R(17.3) → 盲点网络与UNSURE(17.4) → 等变成像(17.5) → 测量一致性与等变架构(17.6) → 小结(17.7)
```

本章结束时，读者将理解：自监督学习不是监督学习的"低配替代"，而是一个拥有独立理论根基的完整框架。从Stein引理到Tweedie公式，从等变性到测量一致性，这些工具使得"无干净数据训练"不仅在理论上可行，在实践中也能达到接近监督学习的性能。更深层地，读者将看到：**自监督学习是全书核心论点的最后一环——从逆问题出发，经过贝叶斯→采样→得分→扩散的漫长旅途，最终连训练数据都不再是障碍**。

让我们从最基本的问题开始——为什么需要自监督学习？数据困境的根源是什么？
