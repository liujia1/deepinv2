# 14.6 离散扩散与掩码语言模型：从向量场到速率矩阵

> **核心观点**：离散数据（文本、DNA）上根本没有 SDE/ODE——token 之间没有"之间"，$d\mathbf{x}_t/dt$ 无从定义。但 14.3 的整套配方——**条件化拆解、边际化技巧、免仿真训练**——逐字照搬过来仍然成立，只需把三个角色换掉：向量场 $v_t$ 换成**速率矩阵** $Q_t$，Fokker-Planck 方程换成 **Kolmogorov Forward 方程**，回归（MSE）换成**分类（交叉熵）**。这套配方训练出的模型就是掩码扩散语言模型（MDLM）——"BERT 式填空"其实是生成模型的一次伪装。

> **本节定位**：本书的先验 $p(\mathbf{x})$ 一直是连续图像（CT/MRI 重建），本节看似离题，实则回答一个更深的问题：14.3 的"条件化拆解 + 免仿真"配方究竟是连续空间的巧合，还是普适原理？离散扩散给出了最有力的证据——**换个数学世界，配方原样工作**。理解这一点，会反过来加深你对 14.3 本身的理解。

> **记号约定**：本节沿用全书约定 $t=0$ 噪声、$t=1$ 数据。干净数据序列记作 $\mathbf{x}_0 = (\mathbf{x}_{0,1}, \dots, \mathbf{x}_{0,d}) \in \mathcal{V}^d$（类比连续情形的 $\mathbf{x}_0$），含噪状态记作 $\mathbf{x}_t$。

## 反直觉开场：没有 $dx/dt$ 的世界，怎么"流动"？

连续世界里，生成 = 把概率质量从噪声**搬运**到数据：每个粒子沿向量场连续滑动，路径上每一点都有定义。但离散世界里这套直觉全部失效：

- "猫"和"狗"之间**没有中间词**——状态之间不可连续滑动，只能**跳变**；
- 没有 $d\mathbf{x}_t/dt$，没有向量场，没有 ODE/SDE——SDE 在离散状态空间根本不存在[@campbell2022discrete]；
- 甚至"路径"本身都要重新发明。

那还能剩下什么？答案是**骨架**：14.3 的证明从头到尾只用了三件事——①构造一条从噪声到数据的概率路径；②用贝叶斯后验把"未知的边际量"写成"已知的条件量的后验平均"；③证明回归条件量 = 回归边际量（梯度等价）。这三件事**没有一个用到连续性**。本节的任务就是把它们在离散世界里重新实现一遍。

> **这一转变意味着**：学习目标从"连续滑动的驱动力"（向量场）变成"随机跳变的瞬时概率"（速率矩阵），但"条件化拆解 + 免仿真"的母题原封不动。这是全书母题第三次出现：第 6 章 DSM 用条件化拆解得分匹配，14.3 用它拆解向量场回归，本节用它拆解速率矩阵学习。

## 14.6.1 CTMC：离散世界的"SDE"

### 状态空间与马尔可夫链

词表 $\mathcal{V} = \{v_1, \dots, v_V\}$（$V$ 为词表大小），状态空间 $\mathcal{S} = \mathcal{V}^d$（$d$ 为序列长度）。对语言来说，$\mathcal{V}$ 枚举所有 token，$\mathcal{S}$ 是所有长度为 $d$ 的句子；对 DNA，$\mathcal{V} = \{A, C, G, T\}$。注意 $|\mathcal{S}| = V^d$ **指数爆炸**——这个事实稍后会迫使模型结构做妥协。

随机过程 $X_t : [0,1] \to \mathcal{S}$ 若满足无记忆性：

$$p(X_{t+h} \mid X_t, X_{t_1}, \dots, X_{t_k}) = p(X_{t+h} \mid X_t)$$

就叫（连续时间）**马尔可夫链（CTMC）**。未来只依赖现在，与历史无关——ODE/SDE 也满足这条（它们同样是马尔可夫过程），所以 CTMC 正是 SDE 的离散表亲。

### 速率矩阵：离散版的"向量场"

连续世界里向量场 $v_t(\mathbf{x})$ 回答"此刻该往哪个方向滑多快"；离散世界里没有方向，只有"跳到别的状态"。于是用**速率矩阵** $Q_t(\mathbf{y} \mid \mathbf{x})$ 回答"此刻从状态 $\mathbf{x}$ 跳到状态 $\mathbf{y}$ 的瞬时概率速率是多少"：

$$\boxed{\begin{aligned} &(1)\ \text{离席速率非负：} && Q_t(\mathbf{y} \mid \mathbf{x}) \geq 0 \quad \text{ whenever } \mathbf{x} \neq \mathbf{y} \\ &(2)\ \text{对角 = 负的离开总率：} && Q_t(\mathbf{x} \mid \mathbf{x}) = -\sum_{y \neq \mathbf{x}} Q_t(\mathbf{y} \mid \mathbf{x}) \quad \text{ for all } \mathbf{x} \end{aligned}}$$

两条约束各有直白语义：第一条说"跳走的速率不能是负的"（不跳就是 0）；第二条是守恒条件——一个粒子要么留在 $\mathbf{x}$ 要么离开 $\mathbf{x}$，没有第三种选择，所以"留下的速率"必须恰好抵消"离开的总速率"。推论：$Q_t$ 的对角元全非正、非对角元全非负。

CTMC 与速率矩阵的关系由下式定义（离散版的"状态沿向量场演化"）：

$$\frac{d}{dh} p_{t+h|t}(X_{t+h} = \mathbf{y} \mid X_t = \mathbf{x})\Big|_{h=0} = Q_t(\mathbf{y} \mid \mathbf{x})$$

即转移概率在 $h=0$ 处的瞬时变化率由 $Q_t$ 给出。反过来也给力：

> **定理（CTMC 存在唯一性）**。对任意（有界、时间连续的）速率矩阵 $Q_t$，存在**唯一**的 CTMC 以它为瞬时速率。
>
> 对机器学习而言这条定理是通行证：我们可以放心地用神经网络输出一个 $Q_t^\theta$，然后假定它背后有一个唯一对应的随机过程——和"神经网络输出向量场 $v_\theta$，背后有一个唯一对应的流 ODE"完全平行。

**一个最小例子（两状态翻转链）。** $\mathcal{S} = \{a, b\}$，以恒定速率 $\lambda$ 互跳：

$$Q = \begin{pmatrix} -\lambda & \lambda \\ \lambda & -\lambda \end{pmatrix} \quad\Longrightarrow\quad P(h) = \frac{1}{2}\begin{pmatrix} 1 + e^{-2\lambda h} & 1 - e^{-2\lambda h} \\ 1 - e^{-2\lambda h} & 1 + e^{-2\lambda h} \end{pmatrix}$$

可以直接代入验证：转移概率对 $h$ 求导在 $h=0$ 处恰好还原 $Q$。指数项 $e^{-2\lambda h}$ 刻画"初始状态记忆"的衰减——$h \to \infty$ 时链彻底忘记起点，落在 $a$、$b$ 的概率各半；$\lambda$ 越大遗忘越快。

**模拟：欧拉步的离散表亲。** 连续 ODE 有欧拉法 $\mathbf{x}_{t+h} \approx \mathbf{x}_t + h\,v_t(\mathbf{x}_t)$；CTMC 的对应物是把速率矩阵"线性化"成一个合法的离散分布：

$$\tilde{p}_{t+h|t}(\mathbf{y} \mid \mathbf{x}) = \mathbb{1}_{y=\mathbf{x}} + h\, Q_t(\mathbf{y} \mid \mathbf{x})$$

注意两条速率约束在此刻发挥第二重作用：$\mathbf{y} \neq \mathbf{x}$ 时 $\tilde{p} = hQ_t(\mathbf{y}|\mathbf{x}) \geq 0$；$\mathbf{y} = \mathbf{x}$ 时 $\tilde{p} = 1 + hQ_t(\mathbf{x}|\mathbf{x}) = 1 - h\sum_{y \neq \mathbf{x}} Q_t(\mathbf{y}|\mathbf{x}) \geq 0$（$h$ 足够小）。**约束保证小步长下这是一个可以采样的合法分布**——每步按 $\tilde{p}$ 做分类采样、迭代即可模拟 CTMC。

### CTMC 模型与因子化：指数爆炸逼出来的稀疏性

**CTMC 生成模型** = 初始分布 $p_{\text{init}}$ + 神经网络 $Q_t^\theta$（输入状态 $\mathbf{x}$，输出速率矩阵的一整列 $\{Q_t^\theta(\mathbf{y} \mid \mathbf{x})\}_{y \in \mathcal{S}}$，模拟下一跳需要整列）。但 $|\mathcal{S}| = V^d$ 指数爆炸，整列根本存不下。出路是**因子化**——一步只允许改一个 token：

$$Q^\theta(\mathbf{y} \mid \mathbf{x}) = 0 \quad \text{whenever } \mathbf{y} \text{ 与 } \mathbf{x} \text{ 在多于一个位置上不同}$$

只差一个 token 的状态叫 $\mathbf{x}$ 的**邻居** $\mathcal{N}(\mathbf{x})$。因子化模型的输出缩成一个 $d \times V$ 矩阵（每个位置一行，该位置跳到每个词的速率），规模随 $d$ 线性而非指数增长——Transformer 天然适配这种"逐位置输出"形状。每个位置上的速率仍须满足两条约束：

$$Q_t^\theta(v_i, j \mid \mathbf{x}) \geq 0 \ \text{ if } v_i \neq x_j, \qquad Q_t^\theta(x_j, j \mid \mathbf{x}) = -\sum_{v_i \neq x_j} Q_t^\theta(v_i, j \mid \mathbf{x})$$

### Kolmogorov Forward 方程：离散版的 Fokker-Planck

连续世界里"分布沿向量场演化"由连续性方程 / Fokker-Planck 方程刻画（第 12 章连续时间视角）。离散世界的对应物是 **Kolmogorov Forward 方程（KFE）**：

$$\boxed{\frac{d}{dt} p_t(\mathbf{x}) = \sum_{y \in \mathcal{S}} Q_t(\mathbf{x} \mid \mathbf{y})\, p_t(\mathbf{y})}$$

逐项读：右边的 $Q_t(\mathbf{x} \mid \mathbf{y})\,p_t(\mathbf{y})$ 是"从 $\mathbf{y}$ 跳入 $\mathbf{x}$ 的速率 × 当前停在 $\mathbf{y}$ 的概率"，对所有来源 $\mathbf{y}$ 求和——**流入总量**（$\mathbf{y} = \mathbf{x}$ 的对角项是负的流出，自动并入）。矩阵形式 $dp_t/dt = Q_t p_t$ 是 $\mathbb{R}^{\mathcal{S}}$ 上的线性 ODE，由初值唯一决定——与连续情形"给定初始分布与向量场，概率路径唯一"完全同构。

**连续↔离散对照表**（建议对照 14.3.1-14.3.3 阅读一遍）：

| 连续（14.3 节） | 离散（本节） |
|---|---|
| 状态空间 $\mathbb{R}^d$ | 序列空间 $\mathcal{S} = \mathcal{V}^d$ |
| SDE / 流 ODE | CTMC |
| 向量场 $v_t(\mathbf{x})$ | 速率矩阵 $Q_t(\mathbf{y} \mid \mathbf{x})$ |
| Fokker-Planck / 连续性方程 | Kolmogorov Forward 方程 |
| 条件高斯路径 $p_t(\mathbf{x}_t \mid \mathbf{x}_0)$ | 因子化混合路径（14.6.2） |
| 边际场 $v_t^* = \mathbb{E}[v \mid \mathbf{x}_t]$（14.3.2） | 边际速率矩阵 $\mathbb{E}[Q_t^{\mathbf{x}_0} \mid \mathbf{x}_t]$（14.6.2） |
| 免仿真训练 = 回归（MSE） | 免仿真训练 = 分类（交叉熵） |

## 14.6.2 条件路径与离散边际化

### 条件概率路径：离散版的"插值"

离散条件概率路径 $p_t(\mathbf{x} \mid \mathbf{x}_0)$ 只要求两端固定：

$$p_0(\cdot \mid \mathbf{x}_0) = p_{\text{init}}, \qquad p_1(\cdot \mid \mathbf{x}_0) = \delta_{\mathbf{x}_0}$$

边际路径同样是对数据分布的边际化：$p_t(\mathbf{x}) = \sum_{\mathbf{x}_0 \in \mathcal{S}} p_t(\mathbf{x} \mid \mathbf{x}_0)\, p_{\text{data}}(\mathbf{x}_0)$，且自动满足 $p_0 = p_{\text{init}}$、$p_1 = p_{\text{data}}$。到这里为止与连续情形逐字平行。

**因子化混合路径（离散版的高斯路径）。** 固定调度 $0 \leq \kappa_t \leq 1$，满足 $\kappa_0 = 0$、$\kappa_1 = 1$、$\dot{\kappa}_t \geq 0$（具体形状是自由超参数，实践中常用线性等简单调度）。定义：

$$\boxed{p_t(\mathbf{x} \mid \mathbf{x}_0) = \prod_{j=1}^{d} \Bigl[ (1 - \kappa_t)\, p_{\text{init}}^{(j)}(x_j) + \kappa_t\, \delta_{\mathbf{x}_{0,j}}(x_j) \Bigr]}$$

采样视角更直观：每个位置独立掷硬币，$m_j \sim \text{Bernoulli}(\kappa_t)$，再采噪声 token $\xi_j \sim p_{\text{init}}^{(j)}$：

$$\mathbf{x}_{t,j} = \begin{cases} \mathbf{x}_{0,j} & m_j = 1 \ \ (\text{以概率 } \kappa_t \text{ 保留干净 token}) \\ \xi_j & m_j = 0 \ \ (\text{以概率 } 1-\kappa_t \text{ 替换为噪声 token}) \end{cases}$$

（这就是"因子化混合"：每位置的分布是 $p_{\text{init}}^{(j)}$ 与 $\delta_{\mathbf{x}_{0,j}}$ 按 $\kappa_t$ 配比的混合；各位置独立。）$t=0$ 时 $\kappa_0=0$、信息全毁；$t=1$ 时 $\kappa_1=1$、信息全存。与高斯路径一样，信息按调度 $\kappa_t$ 渐进销毁。

> **但有一个本质差异：搬运 vs 淡入淡出。** 高斯路径 $p_t(\mathbf{x}_t \mid \mathbf{x}_0) = \mathcal{N}(\alpha_t \mathbf{x}_0, \beta_t^2 I)$ 是把概率质量**搬运**过去——$\mathbf{x}_t$ 在 $\mathbf{x}_0$ 附近连续滑动，有方向、有位移。混合路径不做任何搬运：它只是把"噪声分布"逐渐**淡出**、把"数据点"逐渐**淡入**（配比从 $(1,0)$ 调到 $(0,1)$）。用图像类比：高斯路径是"把图慢慢挪过去"，混合路径是"两张图的透明度交叉渐变"。没有位移，自然没有方向——这就是为什么离散世界不需要向量场。

### 条件速率矩阵与边际化技巧

**条件速率矩阵** $Q_t^{\mathbf{x}_0}$ 的定义与连续情形平行：它的 CTMC 恰好沿条件路径演化——

$$X_0 \sim p_{\text{init}},\ X_t \text{ 是 } Q_t^{\mathbf{x}_0} \text{ 的 CTMC} \quad\Longrightarrow\quad X_t \sim p_t(\cdot \mid \mathbf{x}_0)$$

然后是本节的"aha"——离散边际化技巧（与 14.3.3 的条件 Flow Matching 定理同构）：

> **定理（离散边际化技巧）**。定义边际速率矩阵
>
> $$Q_t(\mathbf{y} \mid \mathbf{x}_t) = \sum_{\mathbf{x}_0 \in \mathcal{S}} Q_t^{\mathbf{x}_0}(\mathbf{y} \mid \mathbf{x}_t)\; p_{1|t}(\mathbf{x}_0 \mid \mathbf{x}_t), \qquad p_{1|t}(\mathbf{x}_0 \mid \mathbf{x}_t) := \frac{p_t(\mathbf{x}_t \mid \mathbf{x}_0)\, p_{\text{data}}(\mathbf{x}_0)}{p_t(\mathbf{x}_t)}$$
>
> 则 $Q_t$ 是合法速率矩阵，且它的 CTMC 沿边际路径演化：$X_0 \sim p_{\text{init}} \Rightarrow X_1 \sim p_{\text{data}}$。

逐字对比 14.3.2 的边际流 $v_t^*(\mathbf{x}_t) = \mathbb{E}[v_t^{[\mathbf{z}, \mathbf{x}_0]}(\mathbf{x}_t) \mid \mathbf{x}_t]$：**边际速率矩阵 = 条件速率矩阵的后验加权平均**，权重正是"给定当前含噪状态、干净数据是 $\mathbf{x}_0$"的后验。证明用 KFE 即可：对边际路径求导、代入条件 KFE、重新组合出 $Q_t$——与 14.3.3 梯度等价定理的证明是同一套逻辑（先条件、后边际、交换求和与求导）。

于是训练目标被锁定为：**学边际速率矩阵** $Q_t$。剩下的问题与 14.3.3 一模一样——$p_{1|t}(\mathbf{x}_0 \mid \mathbf{x}_t)$ 未知（依赖 $p_t$，而 $p_t$ 依赖整条路径）。下一节的边际化 trick 把它变成"逐位置去噪分类器"。

## 14.6.3 离散 Flow Matching：免仿真训练

**when / why / how。**
- **when**：拿到了因子化混合路径，想训练 $Q_t^\theta$ 但后验 $p_{1|t}(\mathbf{x}_0 \mid \mathbf{x}_t)$ 不可算。
- **why（痛点）**：边际速率矩阵要后验加权平均，$\mathbf{x}_0$ 遍历 $\mathcal{V}^d$ 指数多个——不可算。
- **how（突破）**：对因子化混合路径，边际速率矩阵有一个闭式重参数化——后验 $p_{1|t}$ 直接当参数，交叉熵训练。

第一步算出**条件速率矩阵**（因子化混合路径下有闭式解）：

$$Q_t^{\mathbf{x}_0}(v_i, j \mid \mathbf{x}_{t,j}) = \frac{\dot{\kappa}_t}{1 - \kappa_t}\bigl(\delta_{\mathbf{x}_{0,j}}(v_i) - \delta_{\mathbf{x}_{t,j}}(v_i)\bigr)$$

分四种情形读（$j$ 号位置）：

| 情形 | 速率 | 直觉 |
|---|---|---|
| $\mathbf{x}_{t,j} = \mathbf{x}_{0,j}$（已到目标） | $0$ | 已经是干净 token，别动 |
| $v_i = \mathbf{x}_{0,j},\ \mathbf{x}_{t,j} \neq \mathbf{x}_{0,j}$ | $\frac{\dot{\kappa}_t}{1-\kappa_t}$ | 以该速率跳向正确答案 |
| $v_i \neq \mathbf{x}_{0,j},\ \mathbf{x}_{t,j} \neq \mathbf{x}_{0,j}$ | $0$ | 跳向别的错词？禁止 |
| $v_i = \mathbf{x}_{t,j}$（离开当前态） | $-\frac{\dot{\kappa}_t}{1-\kappa_t}$ | 对角项，守恒条件 |

极简：**一旦跳变，只能跳向干净答案** $\mathbf{x}_{0,j}$，且只在"还没到"时跳。

> **一个值得停下来看的细节（本书评注）**：分母里的 $1 - \kappa_t$ 在 $t \to 1$ 时趋于 0，速率发散——这不是 bug，而是**风险率（hazard）**："尚未揭示"的概率是 $1-\kappa_t$，其风险率恰为 $\frac{d}{dt}[-\log(1-\kappa_t)] = \frac{\dot{\kappa}_t}{1-\kappa_t}$。正是这个发散的速率强迫所有未揭示 token 在 $t=1$ 之前跳完（保证 $p_1 = \delta_{\mathbf{x}_0}$）。采样实现中在 $t$ 逼近 1 时截断步长即可。

第二步做边际化——**定理（因子化混合路径的边际化技巧）**：

$$\boxed{Q_t(v_i, j \mid \mathbf{x}_t) = \frac{\dot{\kappa}_t}{1 - \kappa_t}\Bigl( p_{1|t}(\mathbf{x}_{0,j} = v_i \mid \mathbf{x}_t) - \delta_{\mathbf{x}_{t,j}}(v_i) \Bigr)}$$

其中 $p_{1|t}(\mathbf{x}_{0,j} = v_i \mid \mathbf{x}_t)$ 是"给定整个含噪序列 $\mathbf{x}_t$，第 $j$ 个位置的干净 token 是 $v_i$"的后验概率。证明只有三行：非邻居的速率为零（因子化被边际化继承）；对邻居位置，把条件速率矩阵代入后验求和，$\delta_{\mathbf{x}_{t,j}}$ 项从求和里提出来（后验归一），$\delta_{\mathbf{x}_{0,j}}$ 项求和后恰是后验概率。

这个定理的惊人之处：**边际速率矩阵只是逐位置去噪分类器的重参数化**。对比 14.3.2 的边际流（"所有粒子速度的后验平均"），离散版本更彻底——速率矩阵里只剩后验概率本身。于是不再"学速率"，直接"学后验"：

$$p_{1|t}^{\theta} : \underbrace{\mathbf{x}_t}_{\text{网络输入}} \mapsto \underbrace{\bigl(p_{1|t}^{\theta}(\mathbf{x}_{0,j} = v_i \mid \mathbf{x}_t)\bigr)_{j=1,\dots,d,\ v_i \in \mathcal{V}}}_{\text{网络输出 } d \times V}$$

网络就是标准序列到序列模型（Transformer），每个位置一个 $V$ 维 softmax。**softmax 参数化还免费附赠合法性**：$p_{1|t}^\theta(\cdot \mid \mathbf{x}_t)$ 是概率分布，代入边际化技巧定理的右端——非对角处 $\frac{\dot{\kappa}_t}{1-\kappa_t} p_{1|t}^\theta \geq 0$ ✓；对角处 $\frac{\dot{\kappa}_t}{1-\kappa_t}\bigl(p_{1|t}^\theta(\mathbf{x}_{t,j} \mid \mathbf{x}_t) - 1\bigr) = -\frac{\dot{\kappa}_t}{1-\kappa_t} \sum_{v \neq \mathbf{x}_{t,j}} p_{1|t}^\theta(v \mid \mathbf{x}_t)$ ✓。两条速率约束被 softmax 自动满足——"学概率分布"而不是"学速率"的设计在此刻兑现红利。

第三步写出损失。既然目标是逐位置分类，就用逐位置交叉熵——**离散 Flow Matching（DFM）损失**：

$$\boxed{\mathcal{L}_{\text{DFM}}(\theta) = \mathbb{E}_{\mathbf{x}_0 \sim p_{\text{data}},\ t \sim U[0,1],\ \mathbf{x}_t \sim p_t(\cdot \mid \mathbf{x}_0)} \Bigl[ \sum_{j=1}^{d} -\log p_{1|t}^{\theta}(\mathbf{x}_{0,j} \mid \mathbf{x}_t) \Bigr]}$$

**为什么交叉熵的最优解恰是真后验？** 与连续情形"MSE 回归的最优解是条件期望"（14.3.2 的边际流）平行：逐点最小化 $-\log p^\theta(\mathbf{x}_{0,j} \mid \mathbf{x}_t)$ 对任意分布 $p^\theta$ 的最优解是 $p^\theta = p_{1|t}(\cdot \mid \mathbf{x}_t)$（吉布斯不等式：$\mathrm{CE}(p, q) \geq H(p)$，等号当且仅当 $q = p$）。所以训练收敛后网络给出的就是后验 $p_{1|t}^{\theta} \approx p_{1|t}$，代回边际化技巧定理就得到边际速率矩阵。

训练算法（每步与扩散 DSM 一样便宜，**无需求任何 CTMC 轨迹**）：

> **DFM 训练（单步采样版）**
> 1. 采干净序列 $\mathbf{x}_0 \sim p_{\text{data}}$，采时间 $t \sim U[0,1]$，算 $\kappa_t$；
> 2. 逐位置独立采样含噪序列 $\mathbf{x}_t$：$m_j \sim \text{Bernoulli}(\kappa_t)$，$\mathbf{x}_{t,j} = \mathbf{x}_{0,j}$ 若 $m_j = 1$，否则 $\mathbf{x}_{t,j} \sim p_{\text{init}}^{(j)}$；
> 3. 网络前向 $\mathbf{x}_t \mapsto$ 每位置 logits，softmax 得 $p_{1|t}^\theta(\cdot \mid \mathbf{x}_t)$；
> 4. 损失 $\mathcal{L} = \sum_j -\log p_{1|t}^\theta(\mathbf{x}_{0,j} \mid \mathbf{x}_t)$，梯度下降。

采样时用 14.6.1 的欧拉步：每步算 $d \times V$ 速率矩阵、逐位置独立做分类采样。因子化还带来一个工程红利：**各位置可以并行更新**——每步允许多个 token 同时跳变，与严格的单跳 CTMC 欧拉步在一阶 $h$ 内一致（多 token 同步更新的概率是 $O(h^2)$）。

> **从更深层次看**，离散 FM 与连续 FM 的对偶在这一刻完全显形：**连续 FM 把生成归结为回归**（回归条件速度 $\mathbf{x}_0 - \mathbf{z}$ 或条件向量场），**离散 FM 把生成归结为分类**（预测每个位置的干净 token）。两者都是"单步监督学习"——第 6 章说"训练扩散模型不需要仿真"，14.3 说"训练 CNF 不需要解 ODE"，本节说"训练语言生成模型不需要模拟跳变链"。同一个母题，第三次验证。

## 14.6.4 MDLM：把 [MASK] 当噪声

上述框架中 $p_{\text{init}}$ 是自由参数，最著名的选择把"噪声"定义成**全掩码**——掩码扩散语言模型（MDLM）：

$$\mathcal{V} \leftarrow \mathcal{V} \cup \{[\text{MASK}]\}, \qquad p_{\text{init}} = \delta_{[\text{MASK}]^d}$$

起点是全 [MASK] 序列（确定性，连采样 $p_{\text{init}}$ 都省了），生成过程就是**从全掩码里逐步揭示**。一条真实的揭示轨迹长这样：

| $t$ | 序列状态 |
|---|---|
| $0.00$ | [MASK] [MASK] [MASK] [MASK] [MASK] [MASK] [MASK] |
| $0.25$ | [MASK] [MASK] [MASK] on [MASK] [MASK] [MASK] |
| $0.75$ | [MASK] cat [MASK] on the mat [MASK] |
| $1.00$ | The cat sat on the mat . |

对照 DFM 损失 $\sum_j -\log p_{1|t}^\theta(\mathbf{x}_{0,j} \mid \mathbf{x}_t)$ 会发现一个细节：损失覆盖**所有**位置，但已揭示位置（$\mathbf{x}_{t,j} = \mathbf{x}_{0,j}$）的预测是平凡复制、几乎零损失——**学习信号集中在 [MASK] 位置**，网络真正练的就是"看上下文填空"。

> **本书评注**：这个目标与 BERT 的 masked language modeling[@devlin2019bert]在形式上同构——都是"随机遮住一部分 token、用交叉熵预测原词"。区别在**用途**：BERT 是判别式的理解模型（拿去微调做分类、抽取，从不"从噪声采样"）；MDLM 把同一个目标重新解释为**生成模型的训练损失**，配上调度 $\kappa_t$、从全 [MASK] 出发的迭代揭示、以及边际速率矩阵的语义，BERT 式填空就升级成了一个可以采样、可以控制长度的文本**生成**模型。"预训练好的 MLM 权重约等于一个掩码扩散模型的一部分"——这是近年来离散扩散研究最诱人的观察之一。

**均匀噪声 vs [MASK]**（$p_{\text{init}}$ 的两种主流选择）：

| 维度 | 均匀噪声（D3PM 风格） | [MASK] 掩码（MDLM 风格） |
|---|---|---|
| $p_{\text{init}}$ | 均匀分布 $\mathrm{Unif}_{\mathcal{V}}$ | $\delta_{[\text{MASK}]^d}$（确定点） |
| "噪声" token | 随机词——可能碰巧拼成真词 | 明确标记"此处缺失" |
| 生成轨迹 | 渐进改写（词 → 词替换） | 从全 [MASK] 逐步揭示 |
| 网络任务 | 每位置都要预测干净词 | 已揭示位置=复制，掩码位置=预测 |
| 工程便利 | 需处理"假词噪声"的语义干扰 | 掩码语义无歧义；可复用 MLM 生态 |

均匀噪声的隐蔽麻烦：随机替换出的 token 可能碰巧构成一个"貌似合理"的假句子，网络要花力气区分"真词噪声"与"干净数据"；[MASK] 则把"缺失"显式编码进词表，噪声无歧义。这就是为什么当代离散扩散语言模型（如 MDLM、SEDD）几乎都选掩码路线。

> **配套实验**（`第十四章 配套实验/实验14.6-1/14.6-1.py`）：CPU 几分钟可跑完的玩具级 MDLM——6 个 6 词模板句、15 词小词表、两层的微型 Transformer。同一套 DFM 损失训练两个模型（$p_{\text{init}}$ 分别取全 [MASK] 与均匀噪声），以时间×位置揭示热图与揭示置信度图呈现"揭示式"轨迹的时空结构与机制，并定量对比两种 $p_{\text{init}}$ 的质量-步数权衡；最后数值验证 softmax 参数化自动满足两条速率约束、线性调度 + 均匀时间网格下欧拉步 $h \cdot h_t \le 1$ 恰好成立（无需任何截断）。实测需要诚实解读：玩具语料上两版命中率相近（均匀版 0.977 甚至略高于 MDLM 的 0.938，任务太简单、不构成卖点），MDLM 被定量证实的红利在**轨迹形态**（token 改写率低约 31 倍：0.0010 vs 0.0302，分母为“更新前处于实词状态”的步·位）与**噪声语义无歧义**，而非命中率本身。

### 实验 14.6-1：玩具级 MDLM——揭示式与改写式的对照

实验 `14.6-1.py` 是一个 CPU 几分钟跑完的玩具级离散 Flow Matching：同一套 DFM 损失（14.6.2）训练两个微型模型，$p_{\text{init}}$ 分别取全 [MASK]（MDLM，14.6.4）与均匀噪声（D3PM 风格），并排对比两种 $p_{\text{init}}$ 的生成轨迹形态与质量-步数权衡；最后数值验证 14.6.1 的两条速率约束与 14.6.3 的 softmax 参数化红利。

#### 实验场景

语料为 6 个 6 词模板句（"the cat sat on the mat" 等），词表 15 词（含 [MASK]；均匀噪声版不需 [MASK]，词表 14 词）。去噪网络是两层微型 Transformer（$d_{\text{model}}=64$，2 头，FFN 128，正弦时间嵌入，参数量 75,535），输出经 softmax 即 $p_{1|t}^\theta(\cdot\mid \mathbf{x}_t)$。调度取线性 $\kappa_t=t$（风险率 $h_t=\dot{\kappa}_t/(1-\kappa_t)=\frac{1}{1-t}$，$t\to1$ 发散——正是 14.6.3 评注中需要欧拉步校验的情形）。采样用均匀时间网格上的欧拉步：每步按 $\tilde p = (1 - h\cdot h_t)\,\delta_{\mathbf{x}_t} + h\cdot h_t\,p_{1|t}^\theta(\cdot\mid \mathbf{x}_t)$ 更新（即以概率 $h\cdot h_t$ 按后验重采、否则保持），与连续时间 CTMC 的同族离散化。

#### 实验目的

1. **看到两种噪声语义的轨迹差异**：全 [MASK] 起点应呈现"逐步揭示、落子无悔"；均匀起点应呈现"整句反复改写"
2. **定量对比质量-步数权衡**：以"生成句逐词命中某模板句"为严格指标扫 $N\in\{1,\dots,64\}$；以“更新前为实词的位置被改写率”量化轨迹形态差异（两版同一条件语义）
3. **验证 softmax 参数化"免费合法"**（14.6.3）：非对角速率 $\ge0$、对角 $=-\sum$非对角两条约束在数值上自动成立；对照组"不过 softmax 直接输出"应破坏约束
4. **验证欧拉步合法性**：线性调度 + 均匀网格下 $h\cdot h_t \le 1$ 恰好成立（最大值恰为 1，无需任何截断）

#### 实验输入

| 参数 | 设置 |
|------|------|
| 语料 | 6 个模板句 × 6 词；词表 15（含 [MASK]）/ 14（均匀版） |
| 网络 | 2 层 Transformer，$d_{\text{model}}=64$，2 头，FFN 128，参数量 75,535 |
| 训练 | DFM 损失，3000 步，batch 128，Adam lr=3e-4，两版共用全局种子（seed=42）先后训练，结果逐位可复现 |
| 调度 | $\kappa_t=t$（线性），风险率 $1/(1-t)$ |
| 采样 | 欧拉步，主对比 $N=32$、扫步 $N\in\{1,2,4,8,16,32,64\}$，每档 256 句 |
| 揭示轨迹 | 固定 seed=2025，MDLM 版 $N=32$ 一条样本 |

#### 预期结果

- MDLM 轨迹逐步揭示，改写率接近 0；均匀版逐步改写，改写率显著非零
- 玩具任务太简单，两版命中率都应很高且相近——命中率的差异**不是**本实验的卖点
- softmax 版两条约束违反量 $\approx 0$（浮点舍入水平）；raw 对照组大面积负速率、行和严重偏离 1
- 欧拉步系数 $h\cdot h_t$ 最大值恰为 1（$t$ 网格末段）

| 指标（$N=32$） | MDLM | 均匀噪声 |
|------|------|------|
| 模板命中率 | 0.938 | 0.977 |
| token 改写率（更新前为实词） | **0.0010** | 0.0302 |
| 最终训练损失（CE） | **0.202** | 0.560 |

改写率相差约 **31 倍**（面板 (d)）。口径：改写 = 更新前该位置已是实词、这一步又被换成另一个实词（MDLM 的 [MASK]→实词属揭示，不计入分子）；分母取"更新前处于实词状态"的步·位——MDLM 共 23,654 个、均匀版 49,152 个（均匀版无 [MASK]，分母即全部步·位），两版是同一条件语义下的改写概率。MDLM 的改写率低到 0.10%：约 2.4 万个可改写步·位中仅约 23 次改写，近乎“落子无悔”；均匀版则持续对已正确的 token 做词换词改写（每 100 个实词步·位约 3 次），且需要额外区分“碰巧成词的噪声”。面板 (a) 的模板覆盖进一步说明聚合命中率的差距不来自模式坍塌：MDLM 命中在 6 个模板上的分布为 29~49 句/模板，均匀版 27~66（T4 明显偏食），两版都没把概率质量收缩到少数模板上。另外 MDLM 的训练 CE 更低（0.202 vs 0.560）：已揭示位置只需复制、学习信号集中在 [MASK] 位置，任务更“对口”；均匀版每个位置都在变，预测更难。

softmax 参数化（14.6.3）让两条约束**构造性自动成立**——不是训练出来的，是参数化免费送的；raw 对照组则两条约束大面积破坏，采样结果失去概率意义。同时验证了线性调度 + 均匀时间网格下欧拉步系数 $h\cdot h_t$ 最大值恰为 1（$N=32$ 时末步 $t=31/32$，$h\cdot h_t=\frac{1}{32}\cdot 32=1$）——凸组合性质恒成立，无需任何截断。

## 14.6.5 全书视角：配方为什么能跨界

回望全章，"生成 = 学一个驱动力"的谱系在此补全最后一块：

$$\text{得分 } \nabla \log p_t \ \text{（第 5-7 章）} \;\longrightarrow\; \text{向量场 } v_t \ \text{（14.3）} \;\longrightarrow\; \text{速率矩阵 } Q_t \ \text{（本节）}$$

三者的训练全部免仿真，全部靠"条件化拆解"把不可算的边际量变成可算的条件量（DSM → CFM → DFM），全部归结为单步监督学习（回归得分 → 回归速度 → 分类 token）。配方甚至比我们以为的更普适：向量场与速率矩阵其实都是**马尔可夫过程生成元（generator）**的特例——Generator Matching 框架证明，同一套"条件化 + 免仿真"原理可以在光滑流形（几何数据）、混合状态空间（图文联合生成）、跳过程等任意马尔可夫过程上重建生成模型。

> **从更深层次看**，离散扩散给全书主线上了一课：第 1 章说逆问题的贝叶斯解需要先验 $p(\mathbf{x})$，本书通篇用连续图像先验；但"学先验"这件事的数学核心——概率路径、边际化、免仿真监督——与数据是不是连续**无关**。当你下次遇到离散先验（离散层析的能级、序列模态、类别标签场）时，14.3 的配方换个"驱动力"的封装就能直接开工。
