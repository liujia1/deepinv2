# 14.2 连续归一化流（CNF）：把"可逆变换"推向连续，却卡在仿真上

> **核心观点**：归一化流用一串可逆变换把简单分布拧成复杂分布。离散 NF 为了能算 Jacobian 行列式，架构被绑死；连续 NF（CNF）用 Neural ODE 释放了架构自由，代价是训练要解 ODE——又慢又可能不稳。Flow Matching 的突破，正是"不仿真也能训练 CNF"。

## 反直觉开场：自由是有代价的

回顾第7章的 PF-ODE（概率流 ODE）：

$$\frac{dx}{dt} = f(x,t) - \frac{1}{2}g^2(t)\nabla_x\log p_t(x)$$

它的右端**就是一个向量场**（vector field，白话：每点一个"该往哪走、走多快"的箭头）。而得分函数 $\nabla_x\log p_t(x)$ 是通过训练去噪网络间接学来的。

*一个自然的念头*：既然最终要的是这个向量场，得分函数只是它的一个分量——**能不能绕开得分，直接学整个向量场？** 这个念头把我们带向 Flow Matching。但在此之前，得先认识一个更一般的框架：连续归一化流（CNF）。因为 Flow Matching 本质上就是"用一种新方式训练 CNF"。

> **从更深层次看**，这一节的叙事正好对应第5-7章的来时路：那时我们想得到"概率分布的梯度"（得分），于是从去噪网络间接学；现在我们把目标升级为"整个向量场"，那么一种朴素的做法就是把它当作普通网络参数直接训练——CNF 正是这种朴素想法的自然归宿，也暴露了它训练上的困境，从而逼出 14.3 的 Flow Matching。

> **时间约定（先说清楚，免得后面乱）**：本章用 $t=0$ 为噪声端、$t=1$ 为数据端，和第7章（$t=0$ 数据、$t=T$ 噪声）相反。这是 Flow Matching 文献的标准做法，DDIM 与 FM 的等价性靠时间重参数化衔接（见14.3.6）。

## 14.2.1 离散归一化流回顾：想精确似然，就被行列式绑住

**when / why / how。**
- **什么时候用**：第8章 VAE 用不可逆的编码器-解码器换来了架构自由，但只给下界（ELBO）而非精确似然。如果你想要**精确**的对数似然，就需要可逆变换——这就是归一化流（NF）的出发点。
- **为什么难**：可逆变换要求你能精确算"变换后密度变成啥"，而这牵扯到 Jacobian 行列式。
- **怎么做**：用一串可逆变换 $f = f_K\circ\cdots\circ f_1$，把基础分布 $q(z_0)$（通常标准高斯）拧成目标分布 $p(x)$。前向 $z_K=f(z_0)$（噪声→数据），逆向 $z_0=f^{-1}(z_K)$（数据→噪声）。

**数学（变量替换公式）。** 由概率论的变量替换定理：

$$\log p(z_K) = \log q(z_0) - \sum_{k=1}^{K}\log\left|\det\frac{\partial f_k}{\partial z_{k-1}}\right|$$

每一层对密度的影响由它的 Jacobian 行列式（determinant，白话：变换把局部体积放大几倍）完全决定。$\det(\cdot)$ 的计算是 $O(d^3)$——对图像这种 $d=3\times256\times256$ 的高维，根本扛不住。

**离散 NF 的局限（痛点）。** 为了能算行列式，架构必须精心设计：
- Planar/Radial Flow：简单仿射，行列式 $O(d)$ 但表达力有限；
- RealNVP：维度劈两半只变一半，三角矩阵行列式 $O(d)$；
- Glow：可逆 1×1 卷积。

**这些都是对"行列式可计算"的妥协**——为了算得动，牺牲了网络表达力。而且深度 $K$ 固定，不能自适应精度。

**VAE vs NF（点 vs 分布视角的对照）：**

| 特性 | VAE | NF |
|---|---|---|
| 可逆性 | 不可逆（编码器有信息损失） | 可逆 |
| 似然计算 | 下界（ELBO） | 精确 |
| 架构自由度 | 高 | 低（必须可逆且行列式可算） |
| 训练目标 | 最大化 ELBO | 最大化似然 |

> 因果引子：CNF 想做"两者最佳结合"——既要可逆（精确似然），又要架构自由（无行列式约束）。怎么做到？把离散推到连续极限。这一转变意味着，我们把"每一层的体积变化都用行列式细算"的做法，换成"用连续微分方程跟踪整段密度演化"——复杂度从 $O(d^3)$ 大幅跳水。

## 14.2.2 Neural ODE：把"有限步变换"变成"连续流动"

**直觉先行。** 离散 NF 是 $K$ 步跳跃；如果让 $K\to\infty$、每步幅度 $\Delta t\to0$，跳跃就退化成一条**连续的轨迹**——状态随时间平滑变化，由一个神经网络给出的"速度"驱动。这就是 Neural ODE（Chen et al., 2018）。

**数学（从离散到连续）。**
- 离散：$z_{k+1} = z_k + f_\theta(z_k, t_k)\Delta t$
- 连续极限：

$$\boxed{\frac{dz(t)}{dt} = v_\theta(z(t), t)}$$

这里 $v_\theta$ 就是我们用神经网络参数化的向量场。它的现实含义很直接：在 $t$ 时刻位于 $z(t)$ 这个位置，网络告诉你该以多快的速度往哪个方向移动，于是你沿着它一点点积分出整条轨迹。

**Neural ODE 三个根本性优势（因果：这解释了它为什么诱人）：**
1. **自适应求解**：ODE 求解器按误差容限自动选步长，变化剧烈处加密、平缓处放宽——解决离散 NF 深度固定的问题。
2. **自动可逆**：前向和逆向用同一套动力学，只需翻转时间方向，不用像离散 NF 那样显式构造逆。
3. **内存高效**：伴随方法（adjoint method）解一个辅助 ODE 算梯度，内存 $O(1)$，不随步数增长。

**解与目标分布。** 给定 $z(0)=z_0$，解是 $z(t)=\text{ODESolve}(v_\theta, z_0, 0, t)$。从分布角度看，它定义了一个**推前映射**——把初始分布 $q$ 经向量场 $v_\theta$ 推前成目标分布 $p_\theta$。这个"流（flow）"的概念，正是 14.3 节 Flow Matching 的核心。

## 14.2.3 瞬时变量替换公式：行列式 → 迹，复杂度大跳水

**为什么重要（直觉）。** 离散 NF 的变量替换里有 $\det(\partial f/\partial z)$（计算 $O(d^3)$）。在连续极限下，它奇迹般地简化成**迹（trace，白话：矩阵对角线元素之和 $\sum_i A_{ii}$，计算 $O(d)$）**。这是 CNF 的核心数学红利。

**定理（Chen et al., 2018, Theorem 1）。** 设 $z(t)$ 由 $\frac{dz}{dt}=v_\theta(z,t)$ 定义，且 $v_\theta$ Lipschitz 连续，则：

$$\boxed{\frac{\partial \log p(z(t))}{\partial t} = -\nabla \cdot v_\theta(z(t), t) = -\text{tr}\left(\frac{\partial v_\theta}{\partial z}\right)}$$

从 $t=0$ 积分到 $T$，得 CNF 的完整似然：

$$\log p(z(T)) = \log q(z(0)) - \int_0^T \text{tr}\left(\frac{\partial v_\theta(z(t), t)}{\partial z}\right)dt$$

**对比（因果：连续比离散省一个量级）：**
- 离散：$\log p(z_K)=\log q(z_0)-\sum_k\log|\det(\partial f_k/\partial z_{k-1})|$
- 连续：$\log p(z(T))=\log q(z_0)-\int_0^T\text{tr}(\partial v_\theta/\partial z)\,dt$

$\det$ 是 $O(d^3)$，$\text{tr}$ 是 $O(d)$。更妙的是，迹还能用 **Hutchinson 无偏估计器**进一步降成本（Grathwohl et al., 2019 的 FFJORD）：

$$\text{tr}\left(\frac{\partial v_\theta}{\partial z}\right) = \mathbb{E}_{\epsilon\sim\mathcal{N}(0,I)}\left[\epsilon^T \frac{\partial v_\theta}{\partial z}\epsilon\right] \approx \epsilon^T \frac{\partial v_\theta}{\partial z}\epsilon$$

只需一次向量-雅可比乘积（VJP），复杂度从 $O(d^2)$ 降到 $O(d)$，让 CNF 在高维实际可行。

## 14.2.4 CNF 的训练瓶颈：仿真代价——致命伤

**数学（最大似然训练）。** 标准训练是最大化数据对数似然：

$$\max_\theta \mathbb{E}_{x \sim p_{\text{data}}}[\log p_\theta(x)] \quad\Longleftrightarrow\quad \mathcal{L}_{\text{CNF}}(\theta) = \mathbb{E}_{x}\left[-\log q(z(0)) + \int_0^T \text{tr}\left(\frac{\partial v_\theta}{\partial z}\right)dt\right]$$

**三重瓶颈（痛点，因果串接）：**
1. **ODE 求解代价**：每个训练样本都要解一次完整 ODE（多次评估向量场），高维下巨慢。
2. **迹估计方差**：Hutchinson 虽无偏，但方差大，常只取 1 个探针，训练抖动。
3. **刚性 ODE**：训练后期向量场可能在某区剧烈变化，求解器被迫用小步长，更慢。

**和扩散模型比（点 vs 分布 + when/why/how）：**

| 特性 | CNF（最大似然） | 扩散模型（DSM） |
|---|---|---|
| 训练时是否仿真 | ✅ 需要解 ODE | ❌ 不需要（单步损失） |
| 每步计算量 | ODE求解 + 迹估计 | 单次前向 |
| 似然计算 | 精确（需迹估计） | 精确（需 K 积分，第8章） |
| 采样方式 | ODE求解 | SDE或ODE |
| 路径形态 | 自由（由 $v_\theta$ 定） | 固定（由 SDE 结构定） |

**关键洞察（反直觉的对照）。** 扩散模型训练之所以高效，核心就是 **DSM 绕过了仿真**——每步只需一次前向（预测噪声/得分），不用解任何微分方程。而 CNF 每步都要仿真 ODE。

*于是根本问题来了*：**能否保留 CNF 的架构自由，又拿到扩散模型那种"仿真自由"的训练？**

> 这正是 Flow Matching 要回答的。答案一句话剧透：不通过最大似然训练 CNF，而是像扩散模型回归得分那样，**直接回归向量场**——既保住架构自由，又免掉仿真。下一节展开。

## 实验 14.2-1：CNF训练对比——Neural ODE vs Flow Matching

实验 `14.2-1.py` 演示**Neural ODE（最大似然训练）与Flow Matching（CFM训练）在CNF上的效率和质量对比**，揭示仿真代价对训练效率的决定性影响。

### 实验场景

实验在2D点云（8-Gaussian分布）上训练CNF模型。对比两种训练方式：

**Neural ODE（最大似然训练）**：求解ODE计算对数似然，使用Hutchinson迹估计器近似Jacobian行列式。瞬时变量替换公式（14.2.3节）将$\det$简化为$\text{tr}$，但$\text{tr}$仍需随机探针估计。

**Flow Matching（CFM训练）**：回归条件向量场$v_t = x_0 - z$（直线插值路径）。CFM定理（14.3.3节）保证其梯度与回归边际向量场损失梯度相同，但条件向量场是闭式可计算的——无需模拟ODE。

网络结构：`VectorFieldMLP`——3层MLP（2+64→128→128→128→2），输入$x_t(2)$+正弦时间编码(64)，输出$v(2)$，隐藏层128维SiLU激活，零初始化最后一层使初始向量场接近零。

### 实验目的

1. **验证14.2.4节的训练瓶颈**：Neural ODE每步需求解ODE，Flow Matching无需仿真，直接对比训练效率
2. **对比两种方法的训练稳定性**：Hutchinson迹估计的高方差 vs CFM损失的平滑性
3. **验证采样质量的等价性**：理论上两者学习相同的边际向量场，采样质量应相近
4. **理解路径形态差异**：独立耦合下两种方法产生的轨迹曲率对比

### 实验输入

| 参数 | 设置 |
|------|------|
| 目标分布 | 8-Gaussian（8个高斯均匀分布在半径为2的圆上，噪声0.15） |
| 训练样本数 | 2000 |
| 网络架构 | VectorFieldMLP（hidden_dim=128） |

| 批大小 | 256 |

| 采样样本数 | 2000 |
| 曲率统计样本数 | 2000 |

### 预期结果

- Flow Matching训练速度显著快于Neural ODE（加速比约10-20x）
- Flow Matching的loss曲线更平滑，Neural ODE因Hutchinson迹估计高方差而抖动

### 14.2.5 条件归一化流：高维逆问题的后验采样（新增）

前面把 CNF 当作"无条件生成模型"训练 $p(x)$。但在逆问题（第1、13、16 章）中，我们真正想要的是**条件后验 $p(x|y)$**——对给定观测 $y=\mathcal{A}(x)+\varepsilon$ 采样它所有可能的解。

> **从更深层次看**，这里又一次呼应第13章的"条件化"主题：无条件生成解决"从先验采样"问题，条件生成解决"从后验采样"问题。CNF 提供了一条与扩散互补的实现路线——不是靠得分迭代，而是靠可逆映射直接建立"条件 → 样本"的端到端函数。

**条件归一化流（cINN, Ardizzone et al., 2019）** 的做法：让可逆网络同时接受数据 $x$ 与条件 $y$ 作为输入，把联合 $(x,y)$ 映射到潜变量 $z$：
$$z = f_\phi(x;\,y), \qquad x = f_\phi^{-1}(z;\,y) \tag{14.13}$$
训练目标与 14.2.3 的似然损失相同（最小化 $-\log p(z)$），但耦合层在 $x\leftrightarrow z$ 的映射中**显式条件于 $y$**——例如把 $y$ 作为仿射耦合层的尺度/偏置，或作为附加通道拼入网络。训练完成后，对**任意新观测 $y$**，只需从标准高斯采 $z\sim\mathcal{N}(0,I)$ 再经一次前向 $x=f_\phi^{-1}(z;y)$ 即得一个后验样本——无需像 §13.3.3 的变分推断那样逐观测迭代优化变分参数。这正是 APS（Amortized Posterior Sampling，第13章）所"摊销"的目标：**一个网络处理所有 $y$**。

cINN 的优势在于**精确可逆 + 精确对数似然**：因此既能做后验采样，也能给出每个样本的精确密度 $p(x|y)$（用于不确定性量化与异常检测）。代价是耦合层要同时容纳 $x$ 与 $y$ 的维度——当二者都是高分辨率图像时，训练与显存成本显著上升，这正是 Pereyra（Lecture 3, §6 "Scaling to high dimensions with conditional normalising flow models"）强调的"高维扩展"难点。常见缓解办法是先把 $x,y$ 各自下采样/编码到潜空间，再让 cINN 在潜空间里建模条件分布（与第15章 Latent Diffusion 的"先压缩、再生成"思路一致）。

> **与扩散式逆问题方法的对照**：cINN 提供的是"一次性"的端到端后验映射，第13章的 DPS/扩散先验则是"迭代去噪 + 数据一致性"的采样。两者都把生成式先验（或条件生成）用于逆问题，区别在于——cINN 用可逆网络的双向映射换取**速度 + 密度精确性**，扩散用**得分场的迭代精炼**换取对高分辨率图像的表达力。它们与第3章 PnP-ULA、第17章等变成像共同构成"数据驱动先验求解逆问题"的工具箱；而本书第12章"Score ≡ ELBO：殊途同归"的核心论点在此也得到了再次印证——cINN 的最大似然训练（精确 $-\log p$）与扩散的得分匹配/ELBO 本质上都在拟合同一数据分布。

> **这一转变意味着**：cINN 与扩散在逆问题上的分工，正是本章"从得分到向量场"叙事的又一个侧面——同样是"用生成先验采样后验"，扩散走"得分驱动的缓慢迭代"，cINN 走"可逆映射驱动的一次前向"；二者各有取舍，但都服务于同一目标：把对 $p(x|y)$ 的采样转化为一次可学习的传输/映射。
