# 14.0 本章导读：为什么我们要"直接学一条把噪声变成数据的直线"？

> "前13章我们一直在玩一个游戏——先把数据加噪，再试着把噪声去掉。可是你有没有想过：如果目的地就是数据，起点就是噪声，为什么不直接修一条从噪声直达数据的'直路'，非要走'加噪→去噪'这条弯弯绕绕的回头路？"

这就是本章的"反直觉"开场。读到第13章，你已经很熟练地：用SDE逐步加噪、用得分函数（score，白话就是"密度梯度方向"——告诉你在某点该往哪儿走能让概率变大）$\nabla\log p_t(x)$ 逆转这个过程、用PF-ODE（概率流常微分方程，把扩散采样写成一条确定性轨迹）把噪声还原成数据。一切的核心引擎，都是**得分函数**。

但本章要你做一个思维跳跃：**能不能绕开得分函数，直接学那个"驱动力"本身——一个向量场（vector field，白话就是"每个位置上写着'你应该往哪个方向、以多快速度走'的箭头场"）？**

如果这一步成立，生成模型就从"学得分函数 → 再套公式推出驱动力"变成了"直接学驱动力"。训练时不再需要模拟任何微分方程，采样时只走一条 ODE（常微分方程，用初值一步步积分出轨迹）。更妙的是——这条路径可以是**直线**。

**一句话先说结论**：本章不是推翻前13章，而是对全书的"平行推广"。第12章证明的 **Score ≡ ELBO**（得分匹配等价于优化变分下界，白话：两条看似不同的训练路线其实殊途同归）依然完全成立。本章只是换了一把更一般的尺子：把生成建模统一写成"**选路径 + 学向量场 + 解 ODE**"。扩散模型恰好是其中"选扩散路径 + 学得分以间接得到向量场"的特殊情形。所以"从得分到向量场"是**换了描述语言与最优路径标准**，而非否定前面的结论；第13章讲的"条件生成 = 逆问题求解"在 Flow Matching 框架下照样成立。

读完本章，你应该能回答三件事：
- 理解**最优传输（OT，Optimal Transport——白话：如何以最小代价把一堆概率"搬运"成另一堆）**为什么给了生成模型一条"最短路径"的数学标准；
- 会说清楚 **Flow Matching 凭什么"无需仿真就能训练"**——以及它和扩散模型 DSM 训练（去噪得分匹配）在结构上是亲兄弟；
- 能跑通一段代码，亲眼看到"学一个向量场把标准高斯推前到目标分布"这件事是可行的。

## 我们为什么需要这一章：三个没被前面回答的追问

从全书主线（分布打底 → 高斯成噪 → 似然保真 → 贝叶斯合成 → 共轭直解 → 难则变分或扩散）走到第13章，有三个痛点浮出来：

1. **采样效率卡在路径弯曲上。** 扩散过程的 ODE 轨迹从噪声到数据走的是弯线——因为噪声调度（noise schedule，白话：每步加多少噪的人为配方）是手工拍的，没有任何"最短路径"保证。弯的路径意味着欧拉离散（Euler，白话：用直线段近似曲线的最朴素积分法）需要很小步长，实际要 20–1000 步。*能不能找一条更直的路径，做到少步甚至单步生成？*

2. **噪声调度是经验性的。** DDPM 的 $\beta_t$ 调度、扩散 SDE 的 $g(t)$ 选择基本靠调参——不同选择给出不同弯曲度的路径，但缺一个"最优性"标准。而**最优传输恰好补上了这个标准**：OT 测地线（geodesic，白话：分布空间里的"直线"）就是两个分布之间的最短路径。

3. **得分函数是"间接"的。** 第7章的概率流 ODE $\frac{dx}{dt} = f(x,t) - \frac{1}{2}g(t)^2\nabla\log p_t(x)$ 右端明明就是一个向量场，得分函数只是它的一个分量。我们通过学得分来间接拿到向量场——*能不能换一种更直接的参数化，直接学向量场本身？*

这三层追问指向同一个方向：**从"学得分驱动 SDE"扩展到"学向量场驱动 ODE"**——用最优传输给路径选择提供理论标准。这就是 Flow Matching 的出发点。

## 本章路线图（动机 → 基础 → 突破 → 优化 → 实践）

我们沿一条因果链往下走，每一站都为下一站铺路：

**① 最优传输基础（14.1）**：OT 研究如何以最小代价把一堆分布"搬"成另一堆。Monge 问题找确定性搬运映射，Kantorovich 松弛放松成"概率耦合"的凸优化，Wasserstein 距离（白话：搬运的最小总代价）和测地线刻画了"最短传输路径"。→ *这给 Flow Matching 提供了"路径最优"的数学标准。*

**② 连续归一化流 CNF（14.2）**：归一化流（NF，白话：用一串可逆变换把简单分布拧成复杂分布）需要算 Jacobian 行列式（行列式，衡量变换把体积放大几倍），限制了架构自由；CNF 用 Neural ODE（用神经网络参数化的微分方程）释放了自由度，但训练要解 ODE，太慢。→ *这引出核心问题：能否不仿真就训练 CNF？*

**③ Flow Matching（14.3）**：核心突破是**条件 Flow Matching 定理**——回归"条件向量场"的损失和回归"边际向量场"的损失梯度完全相同，而条件向量场闭式可算（白话：代入公式就能算，不用解任何方程）。选 OT 耦合（coupling，白话：噪声点和数据点怎么配对）得到更直的路径。DDIM 其实是 Flow Matching 在扩散耦合下的特例。→ *这回答了 ② 的问题。*

**④ Rectified Flow（14.4）**：选直线插值作条件路径，速度场恒为 $x_0 - z$。Reflow（重新配对）通过迭代把弯曲轨迹逐步拉直，极限情况单步生成。→ *这解决了"初始配对仍可能交叉"的残留问题。*

**⑤ 前沿组合（14.5）**：Stable Diffusion 3 / Flux 把 Rectified Flow 与 DiT（Diffusion Transformer，用 Transformer 替代 UNet 的架构）结合，在文生图上达到 SOTA（state-of-the-art，当前最好水平）。→ *算法就绪，架构如何配合？*

```
OT基础(14.1) → CNF困境(14.2) → Flow Matching(14.3) → Rectified Flow(14.4) → SD3/Flux(14.5)
```

章末你会发现：Flow Matching 是一个比扩散模型**更一般**的框架——扩散模型只是它在特定耦合和条件路径下的特例。核心洞见是**从"学得分"到"学向量场"的视角扩展**，向量场直接定义传输路径，无需通过 SDE 间接获取。而 14.5 把 Rectified Flow 与 DiT 结合，正是顺着"学向量场"的思路，自然过渡到第15章的架构实践——Part V（方法）与 Part VI（架构）的耦合是刻意的，不是编排错位。

> **为什么这件事重要（先埋个伏笔）**：前13章你一直在"随机地"加噪再去噪；本章告诉你，有更短、更直接的路——直接学一条把噪声变成数据的"直线流"。记住这个直觉，后面四节都是在为它补齐因果链条。

## 动手感受一下（可运行代码）

读完上面这些，你可能还是觉得"学一个向量场把噪声推前成数据"有点虚。下面这段**重度注释的 numpy 代码**让你亲手跑一遍：我们造一个极简目标分布（两个二维高斯，交叉结构），用一个小型 MLP（多层感知机，白话：最简单的神经网络）去学速度场 $v_\theta$，然后解 ODE 把标准高斯"流"过去，并画出几条轨迹。

> 这是全书配套实验 `14.2-1.py` / `14.3-1.py` 的**极简教学版**（无依赖、纯 numpy，约 80 行）。想看完整版和真实图片请运行配套实验。

```python
# -*- coding: utf-8 -*-
# 极简 Flow Matching 演示：学一个向量场 v_theta，把标准高斯推前到目标分布
# 仅依赖 numpy (+matplotlib 仅用于画图)。跑法：python this_snippet.py
import numpy as np

# ---------- 1. 造目标分布 p_data：两个交叉的 2D 高斯 ----------
rng = np.random.default_rng(0)
def sample_data(n):
    # 一半来自左上高斯(均值[-2,2])，一半来自右下高斯(均值[2,-2])
    a = rng.normal([-2.0, 2.0], 0.3, size=(n // 2, 2))
    b = rng.normal([ 2.0, -2.0], 0.3, size=(n - n // 2, 2))
    return np.vstack([a, b])

# ---------- 2. 极小神经网络：v_theta(x, t) -> 2维速度 ----------
# 我们用"tanh 隐藏层 + sin/cos 时间编码"的简陋网络，纯为教学可跑。
# 参数用向量化的 MSE 解析梯度(梯度下降)更新，几秒就能跑完。
W1 = rng.normal(0, 0.3, size=(6, 2 + 2))   # 输入: x(2) 拼时间编码(2)
b1 = np.zeros(6)
W2 = rng.normal(0, 0.3, size=(2, 6))
b2 = np.zeros(2)
lr = 0.05

def net_forward(x, t):
    # x: (n,2), t: 标量 -> 输出 (n,2) 速度场
    te = np.array([np.sin(np.pi * t), np.cos(np.pi * t)])[None, :]   # 时间编码
    h = np.tanh(x @ W1[:, :2].T + te @ W1[:, 2:].T + b1)            # 隐藏层 (n,6)
    return h @ W2.T + b2                                             # 输出速度 (n,2)

def net_step(x, t, target):
    # 用 MSE 的解析梯度做一步梯度下降（教学用，真实训练用 autograd）
    n = x.shape[0]
    te = np.array([np.sin(np.pi * t), np.cos(np.pi * t)])[None, :]
    xt = x @ W1[:, :2].T + te @ W1[:, 2:].T + b1        # (n,6) 隐藏pre
    h = np.tanh(xt)                                     # (n,6) 隐藏
    out = h @ W2.T + b2                                 # (n,2) 预测速度
    d_out = 2.0 / n * (out - target)                    # MSE 对 out 的导数
    # 反传：W2, b2
    gW2 = d_out.T @ h
    gb2 = d_out.sum(0)
    d_h = d_out @ W2 * (1 - h ** 2)                     # tanh 导数
    gW1 = d_h.T @ np.hstack([x, np.tile(te, (n, 1))])
    gb1 = d_h.sum(0)
    W2[:] -= lr * gW2; b2[:] -= lr * gb2
    W1[:] -= lr * gW1; b1[:] -= lr * gb1
    return np.mean(np.sum((out - target) ** 2, axis=1))

# ---------- 3. 训练：条件 Flow Matching（直线插值，独立耦合） ----------
# 直观：对每个 (x0=数据, z=噪声) 对，直线插值 x_t=(1-t)z+t x0，
#       目标速度恒为 v = x0 - z。只回归这个速度，无需解任何 ODE。
print("训练一个把标准高斯推前到目标分布的向量场 v_theta ...")
for step in range(400):
    x0 = sample_data(256)                          # 数据点
    z = rng.normal(0, 1, size=x0.shape)            # 噪声点（标准高斯）
    t = float(rng.uniform(0, 1))                   # 标量时间
    xt = (1 - t) * z + t * x0                       # 直线插值点
    target = x0 - z                                # 条件向量场（常数速度）
    loss = net_step(xt, t, target)
    if step % 80 == 0:
        print(f"  step {step:4d}  MSE={loss:.3f}")

# ---------- 4. 采样：解 ODE dx/dt = v_theta(x,t)，从 t=0(噪声) 到 t=1(数据) ----------
def euler_flow(z, n_steps=50):
    x = z.copy()
    dt = 1.0 / (n_steps - 1)
    for i in range(n_steps):
        t = i / (n_steps - 1)
        x = x + dt * net_forward(x, t)
    return x

z_test = rng.normal(0, 1, size=(2000, 2))
x_gen = euler_flow(z_test)
print(f"生成样本均值≈{x_gen.mean(0).round(2)}（目标≈[0,0]），分布应呈现两个交叉高斯。")

# ---------- 5. 画三条轨迹，直观感受"向量场把噪声流成数据" ----------
import matplotlib.pyplot as plt
fig, ax = plt.subplots(1, 1, figsize=(5, 5))
ax.scatter(sample_data(800)[:, 0], sample_data(800)[:, 1], s=4, c='orange', alpha=0.3, label='target p_data')
for k in range(3):
    z0 = rng.normal(0, 1, size=2)
    pts = [z0]
    x = z0.copy()
    for i in range(50):
        t = i / 49.0
        x = x + (1.0 / 49.0) * net_forward(x[None, :], t)[0]
        pts.append(x.copy())
    pts = np.array(pts)
    ax.plot(pts[:, 0], pts[:, 1], '-o', ms=2, label=f'trajectory {k+1}')
ax.set_title("Flow Matching: 噪声 -> 数据的 ODE 轨迹")
ax.legend(fontsize=7)
plt.show()
```

跑完你会看到：三条从原点附近（噪声）出发的轨迹，被学到的速度场"推"向了橙色的目标分布——**这就是 Flow Matching 的全部：学一个向量场，解一条 ODE，噪声变数据。** 后四节会把它从"能跑"升级到"跑得直、跑得快、跑得工业级"。
