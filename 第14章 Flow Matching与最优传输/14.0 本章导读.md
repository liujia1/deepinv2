# 14.0 本章导读：从得分到向量场——主线在最优传输视角下的平行推广

前13章的生成模型都以得分函数 $\nabla\log p_t(x)$ 为核心驱动力——第5章的Langevin动力学用得分函数驱动采样，第7章的逆向SDE用得分函数逆转加噪过程，第12章证明Score ≡ ELBO统一了得分路径和变分路径。无论是SDE采样还是ODE采样，得分函数始终是"引擎"。

**本章与全书主线是什么关系（先说结论）**：本章不是推翻前 12 章，而是对主线采样路径的**平行推广**。第 12 章证明的 Score ≡ ELBO 依然完全成立——它刻画的是"扩散耦合下，学习得分函数"与"优化变分下界"的等价性，这一结论不受本章影响。本章只是换了一把更一般的尺子：把生成建模统一表示为"选路径 + 学向量场 + 解 ODE"，而扩散模型恰好是其中"选扩散路径 + 学得分以间接得到向量场"的特殊情形。因此，"从得分到向量场"是**更换了描述语言与最优路径标准**，而非否定前面的结论；第 13 章的"条件生成 = 逆问题求解"在 Flow Matching 框架下同样适用。

从主线采样路径的视角出发，仍有三个值得追问、且现有框架未直接回答的方向：

1. **采样效率受限于路径弯曲**。扩散过程的ODE轨迹从噪声到数据走的是一条弯曲线——因为噪声调度是手工设计的，没有"最短路径"的保证。弯曲的路径意味着Euler离散化需要小步长，实际采样需要20-1000步。能否找到更直的路径，实现少步甚至单步生成？

2. **噪声调度的经验性**。DDPM的 $\beta_t$ 调度和扩散SDE的 $g(t)$ 选择主要靠经验调参——不同的选择给出不同弯曲度的路径，但缺乏最优性标准。最优传输（OT）恰好提供了这个标准：OT测地线是分布间的最短路径。

3. **得分函数的间接性**。第7章的概率流ODE $\frac{dx}{dt} = f(x,t) - \frac{1}{2}g(t)^2\nabla\log p_t(x)$ 的右端是一个向量场，得分函数只是向量场的一个分量。我们通过学习得分函数来间接获得向量场——能否换一种更直接的参数化，直接学习向量场本身？

这三层追问指向同一个方向：**从"学习得分驱动SDE"到"学习向量场驱动ODE"的视角扩展与平行推广**——用最优传输为路径选择提供理论标准。这就是Flow Matching的出发点。

本章从这个问题出发，走一条"动机→基础→突破→优化→实践"的路径：

**最优传输基础**（14.1）：最优传输研究如何以最小代价将一个概率分布"搬运"到另一个分布。Monge问题和Kantorovich松弛为分布间的传输提供了数学基础，Wasserstein距离和测地线刻画了"最短传输路径"。OT为生成模型提供了路径最优性的数学标准——沿着OT测地线传输，路径最短、效率最高。

**连续归一化流**（14.2）：归一化流通过可逆变换将简单分布映射到复杂分布。离散NF需要计算Jacobian行列式，限制了架构自由度；连续NF（CNF）用Neural ODE释放了架构设计自由度，但训练时需要求解ODE，计算代价高昂。这一瓶颈引出了核心问题：**能否无需仿真ODE即可训练CNF？**

**Flow Matching**（14.3）：Flow Matching的核心突破是条件Flow Matching定理——回归条件向量场的损失函数与回归边际向量场的损失函数梯度完全相同，而条件向量场是闭式可计算的。选择OT耦合（OT-CFM）产生更直的路径。DDIM是Flow Matching在扩散耦合下的特例，揭示了扩散模型与Flow Matching的深层统一。

**Rectified Flow**（14.4）：Rectified Flow选择直线插值作为条件路径，速度场恒为 $x_0 - x_1$。Reflow过程通过迭代"重新配对"将弯曲的ODE轨迹逐步拉直，极限情况下实现单步生成。直线化使得Euler离散化误差最小，采样效率最高。

**前沿组合**（14.5）：Stable Diffusion 3和Flux将Rectified Flow与Diffusion Transformer（DiT）结合，在文本到图像生成中达到SOTA性能。Logit-Normal时间采样和MMDiT双模态架构是关键创新。

```
OT基础(14.1) → CNF困境(14.2) → Flow Matching(14.3) → Rectified Flow(14.4) → SD3/Flux(14.5)
```

本章结束时，读者将理解：Flow Matching是一个比扩散模型更一般的生成框架——扩散模型是Flow Matching在特定耦合和条件路径下的特例。Flow Matching的核心洞见是**从学习得分函数到学习向量场的视角扩展与平行推广**——向量场直接定义传输路径，无需通过SDE间接获取。OT耦合和Reflow过程从不同角度优化路径的直线度，使得少步甚至单步生成成为可能。本章的核心论点是：**生成模型 = 选择路径 + 学习向量场 + ODE求解**——三位一体，完成了从"学习得分驱动SDE"到"学习向量场驱动ODE"的平行推广：第 12 章的 Score ≡ ELBO 在此成为扩散耦合下的特例，而非被取代。14.5 把 Rectified Flow 与 DiT 结合，正是顺着"学向量场"的思路自然过渡到第 15 章的架构实践——Part V 与 Part VI 的耦合是刻意的，而非章节编排的错位。
