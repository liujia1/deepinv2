## 14.1 最优传输基础
**知识点**：
- Monge问题：寻找确定性传输映射$T$，最小化$\int c(x,T(x))dp_0(x)$
- Monge问题的三重困难：无限维约束、映射可能不存在、优化非凸
- Kantorovich松弛：从确定性映射到概率耦合$\gamma$
- Kantorovich问题的优势：始终有解、线性规划（凸优化）、Monge映射是特例
- 耦合的选择对路径形态的决定性影响：
  - 独立耦合：$\gamma_{\text{ind}} = p_0 \otimes p_1$，路径弯曲交叉
  - 最优耦合：OT映射下的McCann插值，路径短且直
- Wasserstein距离：$W_2(p_0, p_1) = \sqrt{\min_\gamma \int \|x_0 - x_1\|^2 d\gamma}$
- OT测地线（McCann插值）：$p_t = ((1-t)\cdot\text{id} + t\cdot T^*)_\# p_0$
- OT测地线是Wasserstein空间的最短路径

**实验对应**：
- 实验14.1「Flow Matching与最优传输：2D点云教学演示」——步骤1：OT vs独立耦合路径形态对比（OT耦合路径短且直，传输代价更低）

## 14.2 连续归一化流（CNF）
**知识点**：
- 归一化流（NF）的基本思想：通过可逆变换将基础分布映射到目标分布
- 变量替换公式：$\log p(z_K) = \log q(z_0) - \sum_k \log|\det \frac{\partial f_k}{\partial z_{k-1}}|$
- 离散NF的局限：Jacobian行列式计算代价$O(d^3)$，限制架构自由度
- 常见离散NF架构：Planar/Radial Flow、RealNVP、Glow
- Neural ODE：$\frac{dz(t)}{dt} = v_\theta(z(t), t)$
- Neural ODE的三大优势：自适应求解、自动可逆、内存高效（伴随方法）
- 瞬时变量替换公式：$\frac{d}{dt}\log p_t(x_t) = -\text{tr}(\nabla_x v_\theta(x_t, t))$
- CNF的最大瓶颈：训练时需要求解ODE（慢且可能不稳定）
- 核心问题：能否无需仿真ODE即可训练CNF？

**实验对应**：
- 实验14.2-1「CNF训练对比——Neural ODE vs Flow Matching」——步骤1：Neural ODE训练（伴随方法，慢）；步骤2：Flow Matching训练（CFM目标，快）；步骤3：训练效率、采样质量、轨迹曲率对比

## 14.3 Flow Matching
**知识点**：
- 流ODE：$\frac{dx_t}{dt} = v_t(x_t)$，$x_0 = z \sim q$
- Flow Matching的目标：学习向量场$v^*$使得$q \xrightarrow{v^*} p_{\text{data}}$
- 与PF-ODE的关系：PF-ODE向量场间接（由得分函数决定），Flow ODE向量场直接学习
- 点wise流：给定$(z, x_0)$，满足边界条件的向量场
- 直线插值：$x_t = (1-t)z + t x_0$，条件向量场$v_t = x_0 - z$
- 条件Flow Matching（CFM）定理：$\nabla_\theta L_{\text{FM}} = \nabla_\theta L_{\text{CFM}}$
  - 核心突破：回归条件向量场的损失梯度与回归边际向量场的损失梯度相同
  - 条件向量场闭式可计算，无需模拟ODE
- 高斯条件路径：$x_t = \sigma_t z + \mu_t x_0$
- OT-CFM：选择最优传输耦合，产生更直的路径
- DDIM = Flow Matching with diffusion coupling（扩散耦合下的特例）
- 时间约定：本章$t=0$为噪声端、$t=1$为数据端（与第7章相反）

**实验对应**：
- 实验14.1「Flow Matching与最优传输：2D点云教学演示」——步骤2：CFM训练（OT-CFM Loss低一个数量级，采样质量更好）；步骤3：扩散路径 vs FM路径 vs OT-CFM路径对比（曲率量化：OT-CFM最直$\kappa$=0.0026）
- 实验14.2「Rectified Flow图像生成」——步骤1：训练Rectified Flow（速度预测）；步骤2：Flow ODE少步采样对比（1/5/10/50步）；步骤3：DDPM vs RF少步采样对比（RF 50步ODE≈DDPM 200步SDE）
- 实验14.3-3「Minibatch OT近似——Sinkhorn算法」——步骤1：匈牙利算法精确求解OT；步骤2：Sinkhorn算法近似求解OT（不同正则化参数ε）；步骤3：精度-效率权衡分析（随样本量增长的扩展性）

## 14.4 Rectified Flow
**知识点**：
- Rectified Flow的基本设定：直线插值$x_t = (1-t)z + t x_0$
- 条件向量场恒定：$v_t(x_t|x_0,z) = x_0 - z$（与时间$t$和位置$x_t$无关）
- 训练目标：$\mathcal{L}_{\text{RF}} = \mathbb{E}[\|v_\theta(x_t,t) - (x_0 - z)\|^2]$
- 与DDPM训练的对比：插值方式不同（弯曲高斯插值 vs 笔直线性插值）
- 路径交叉与弯曲的根源：独立耦合导致轨迹交叉，边际向量场需取折中方向
- 曲率定义：$\kappa = 1 - \frac{\|x_0 - z\|}{\sum_i \|x_{i+1} - x_i\|}$
- Reflow过程：
  - 用当前模型的ODE端点重新配对
  - 迭代"解缠"路径交叉
  - 极限趋近OT映射
  - Reflow定理：$\kappa(Z^{k+1}) \leq \kappa(Z^k)$（Reflow不增加弯曲度）
- Reflow的实践价值：1-RF需50-100步，2-RF可减至5-10步，多次Reflow可趋近单步生成
- 与扩散模型的关系：扩散模型是Flow Matching在特定耦合下的特例

**实验对应**：
- 实验14.1「Flow Matching与最优传输：2D点云教学演示」——步骤4：Rectified Flow与Reflow（1-RF→2-RF→3-RF，曲率显著降低0.0233→0.0013）
- 实验14.2「Rectified Flow图像生成」——步骤4：Reflow蒸馏为少步模型（2-RF 1步质量优于1-RF 1步，Loss从0.046降至0.009）
- 实验14.4-3「曲率单调性数值验证——Reflow定理」——步骤1：训练1-RF并计算曲率；步骤2：多轮Reflow（1-RF→2-RF→3-RF），每轮计算曲率；步骤3：验证κ(Z^{k+1})≤κ(Z^k)单调递减

## 14.5 前沿组合：SD3/Flux = Rectified Flow + DiT
**知识点**：
- SD3选择Rectified Flow作为训练框架（60种轨迹对比实验）
- Rectified Flow在少步采样（4步、8步）下显著优于其他轨迹
- Logit-Normal时间采样：
  - 问题：均匀采样对所有时间步同等对待
  - 改进：$\pi_{\ln}(t; m, s)$使中间时间步采样概率更高
  - 参数$m$（重心位置）和$s$（集中程度）
  - 效果：少步采样FID显著优于均匀采样
- MMDiT架构：
  - 从UNet到DiT的架构演进
  - 双权重设计：图像token和文本token使用独立权重
  - 双向信息流：图像→文本 + 文本→图像的联合注意力
- 可预测缩放规律：增加参数量遵循可预测的性能提升曲线
- Flux：进一步扩展MMDiT，在大规模数据上训练

**实验对应**：
- 实验14.5-1「Logit-Normal时间采样」——步骤1：可视化均匀采样vs Logit-Normal采样的时间分布；步骤2：MNIST上训练RF（均匀时间采样）；步骤3：MNIST上训练RF（Logit-Normal时间采样）；步骤4：对比两种策略的少步采样质量
