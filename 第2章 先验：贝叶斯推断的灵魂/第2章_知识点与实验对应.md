- 本章逻辑链：先验=正则项 → 经典先验族 → MMSE vs MAP → 从显式到隐式

## 2.1 先验的数学角色：正则化的概率诠释
**知识点**：
- 后验能量 = 数据项 + 正则项
- 取负对数的深层含义：概率空间 → 能量空间
- 贝叶斯到变分的完整对应表
- 高斯噪声 + 高斯先验 → Tikhonov正则化
- 正则化参数 λ = σ²/σₓ² 的贝叶斯含义
- 先验不是玄学，而是正则化的概率诠释

**实验对应**：
- 实验2.1「先验 = 正则化的数值验证」——验证后验能量分解，高斯/Laplace先验对比，MAP闭式解验证
- 实验2.2「正则化参数 λ 对重建的影响」——λ扫描，过拟合vs过正则化，L-curve

---

## 2.2 经典先验族
**知识点**：
- 高斯先验：假设"值小" → L²正则项 → Tikhonov正则化
- 高斯先验的闭式解与局限：偏好平滑，丢失边缘
- Laplace先验：假设"值稀疏" → L¹正则项 → LASSO
- Laplace先验的软阈值解
- TV先验：假设"梯度稀疏" → 全变差正则化
- TV先验的保边特性与阶梯效应
- 三种先验的递进逻辑与对比
- 推广：梯度高斯先验 → Sobolev平滑
- Perona-Malik非线性扩散

**实验对应**：
- 实验2.3「高斯随机场采样与广义Tikhonov估计」——高斯先验采样，广义Tikhonov，共轭先验闭式后验
- 实验2.4「Perona-Malik非线性扩散：保边去噪」——非线性扩散与线性扩散对比，边缘保持
- 实验2.5「TV去噪：阶梯效应与保边性」——TV vs Tikhonov，保边特性，阶梯效应展示
- 实验2.6「四阶PDE去噪：避免阶梯效应」——四阶PDE，分段线性解，TGV直觉

## 2.3 先验的质量：MMSE vs MAP估计器
**知识点**：
- MMSE估计器：后验均值，平方损失下的贝叶斯最优
- MAP估计器：后验众数，优化视角
- MMSE vs MAP的分歧：后验非对称时
- 贝叶斯去噪器 = 先验下的MMSE估计器
- 先验质量决定去噪器质量
- 去噪器揭示先验

**实验对应**：
- 实验2.7「二维十字形去噪：去噪器误差对比」——四种去噪器对比（恒等/Tikhonov/LASSO/贝叶斯），验证MMSE最优性
