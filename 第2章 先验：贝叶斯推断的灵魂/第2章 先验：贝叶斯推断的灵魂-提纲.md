## 2.1 先验的数学角色：正则化的概率诠释

**核心观点**：第1章末尾得到后验 $p(x|y) \propto p(y|x)\,p(x)$。取负对数后，先验 $p(x)$ 恰好对应正则化中的正则项——先验不是玄学，而是正则化的概率诠释。

- **从贝叶斯定理到正则化**：
  - 负对数后验：$-\ln p(x|y) = -\ln p(y|x) - \ln p(x) + \text{const}$
  - 即：**后验能量 = 数据项 + 正则项**
  - 先验 → 正则项；先验参数 → 正则化参数
  - 正则化不再只是"数学技巧"，而是对先验知识的概率表达

- **贝叶斯→变分完整对应表**（Calatroni P29-44）：

  | 概率框架 | 变分框架 | 含义 |
  |---|---|---|
  | 噪声模型 | 数据项形式 | 由物理决定 |
  | 先验 p(x) | 正则项 R(x) | 由领域知识决定 |
  | 超参数(σ², λ) | 正则化参数 | 控制数据拟合与正则化的权衡 |
  | 后验 p(x\|y) | 目标函数 -ln p(x\|y) | 同一东西的两种语言 |

- **先验选择的核心问题**：
  - 先验决定了正则项的形式 → 决定了解的形态
  - 好的先验编码了关于x的正确知识 → 正则化参数有概率解释
  - 差的先验编码了错误假设 → 引入系统性偏差
  - 本章后续回答：有哪些先验可选？如何评判先验好坏？

**来源**：Calatroni P29-44; Pock L2 P7-13

既然先验就是正则项，那么不同的先验自然对应不同的正则化策略。下面巡览经典先验族——每种先验编码了关于图像的不同假设。

---

## 2.2 经典先验族

**核心观点**：经典先验从简到繁，每种先验都是对"图像长什么样"的一种数学假设，映射到一种正则项。三种核心先验（高斯、Laplace、TV）构成正则化工具箱的基石。

- **高斯先验 → Tikhonov正则化**
  - 假设：x 的各分量独立服从高斯分布 $x_i \sim \mathcal{N}(0, \sigma_x^2)$
  - $-\ln p(x) \propto \frac{1}{2\sigma_x^2}\|x\|^2$ → $\ell^2$ 正则项
  - 对应正则化：$\min_x \|Ax-y\|^2 + \lambda\|x\|^2$（Tikhonov / 岭回归）
  - 假设的局限：偏好小幅值解，天然倾向平滑，无法刻画图像的边缘和纹理
  - **推广**：对梯度施加高斯先验 $\nabla x \sim \mathcal{N}(0, \sigma_\nabla^2)$ → Sobolev平滑正则化 $\lambda\|\nabla x\|^2$
    - 比直接对x加高斯更合理（图像相邻像素相关），但仍倾向过度平滑
    - **来源**：Calatroni P43

- **Laplace先验 → L1/稀疏正则化**
  - 假设：$x_i \sim \text{Laplace}(0, b)$（重尾分布，概率质量集中在零附近）
  - $-\ln p(x) \propto \frac{1}{b}\|x\|_1$ → $\ell^1$ 正则项
  - 对应正则化：$\min_x \|Ax-y\|^2 + \lambda\|x\|_1$（LASSO / 稀疏正则化）
  - 核心优势：L1促稀疏——大多数分量被推向零，少数非零分量保留显著特征
  - 应用场景：稀疏表示框架下（小波/字典），图像可被少量基函数逼近
  - L1 vs L2：L1产生稀疏解，L2产生分散的小值解——几何解释（菱形 vs 球形等高线与约束集的交点）

- **TV先验 → 全变差正则化**
  - 假设：图像的梯度是稀疏的（大部分区域平滑，少数位置有边缘）
  - $-\ln p(x) \propto \text{TV}(x) = \|\nabla x\|_1$（梯度的L1范数）
  - 对应正则化：$\min_x \|Ax-y\|^2 + \lambda\,\text{TV}(x)$（Rudin-Osher-Fatemi模型）
  - 核心优势：同时实现平滑（平坦区域）和保边（边缘处梯度大但不被过度惩罚）
  - 与Laplace先验的关系：TV = 对梯度施加Laplace先验
  - **已知局限**：阶梯效应——TV假设图像是分段常数的，在渐变区域（如天空渐变、皮肤过渡）产生人工阶梯
    - > 改进思路见附录2B：TGV（广义全变差）通过引入二阶信息允许分段仿射解，缓解阶梯效应，详见 Bredies et al. (2010)

- **三种先验的对比总结**：

  | 先验 | 假设 | 正则项 | 解的形态 | 局限 |
  |---|---|---|---|---|
  | 高斯 | x值小 | $\|x\|^2$ | 平滑 | 过度平滑，丢边缘 |
  | Laplace | x值稀疏 | $\|x\|_1$ | 稀疏 | 需稀疏表示前提 |
  | TV | 梯度稀疏 | $\|\nabla x\|_1$ | 分段平滑 | 阶梯效应 |

**来源**：Calatroni P29-34; Calatroni P35; Calatroni P43; Benning L1 P75-83; Benning L1 P138-139; Siltanen D2; Pock L3 P1-9

至此我们有了一个先验工具箱，但同一个后验分布可以给出不同的"答案"——取决于你问什么问题。MMSE和MAP是两种最常用的询问方式，它们对应不同的估计器，也揭示了先验质量的不同侧面。

## 2.3 先验的质量：MMSE vs MAP估计器

**核心观点**：给定后验分布 p(x|y)，不同的估计策略给出不同的结果。MMSE估计器（后验均值）最小化均方误差，MAP估计器（后验众数）最大化后验概率。理解两者的区别，是评判先验质量、理解后续章节中"去噪器即估计器"的关键。

- **MMSE估计器：后验均值**
  - 定义：$\hat{x}_{\text{MMSE}} = \mathbb{E}[x|y] = \int x\,p(x|y)\,dx$
  - 性质：在平方损失下贝叶斯最优（最小化 $\mathbb{E}[\|x-\hat{x}\|^2|y]$）
  - 计算代价：需要后验分布的完整信息（积分），通常不可解析计算

- **MAP估计器：后验众数**
  - 定义：$\hat{x}_{\text{MAP}} = \arg\max_x p(x|y) = \arg\min_x [-\ln p(y|x) - \ln p(x)]$
  - 性质：在0-1损失下贝叶斯最优；等价于正则化优化问题
  - 计算代价：只需优化，不需要积分——这就是为什么第3章从MAP开始

- **MMSE vs MAP：当后验对称时两者一致，不对称时产生分歧**
  - 高斯后验：MMSE = MAP（对称单峰分布，均值=众数）
  - 非高斯后验：MMSE ≠ MAP（多峰或偏斜分布中，均值偏离众数）
  - 直觉：MAP只看"最可能的点"，MMSE看"所有可能性的加权平均"
  - 第3章走MAP路径（优化），第4-7章走MMSE路径（采样求期望）

- **贝叶斯去噪器：去噪器=先验下的MMSE估计器**（→第5章铺垫）
  - 纯去噪问题：y = x + ε，ε ~ N(0, σ²I)（A=I的特例）
  - 贝叶斯去噪器：$\hat{x}_{\text{MMSE}}(y) = \mathbb{E}[x|y]$
  - **关键等式**：给定先验 p(x)，去噪器 D_σ(y) = E[x|y] 就是该先验下的最优去噪器
  - 换言之：**先验决定去噪器，去噪器揭示先验**——这为第5章的Tweedie等式和PnP框架埋下伏笔
  - **来源**：Ratti P1-13

- **共轭先验：高斯似然+高斯先验→高斯后验**（→第3章铺垫）
  - 定义：若先验与似然属于同一分布族，后验也属于该族，则称共轭先验
  - 高斯情形：$p(y|x)=\mathcal{N}(Ax,\sigma^2 I)$，$p(x)=\mathcal{N}(0,\sigma_x^2 I)$
    - 后验 $p(x|y) = \mathcal{N}(\mu_{\text{post}}, \Sigma_{\text{post}})$ 仍为高斯——可解析计算
    - 后验均值 = Tikhonov正则化解（第3章将详细展开）
  - 共轭先验的意义：后验有闭式解 → MMSE=MAP → 理论分析可完全解析
  - 非共轭情形（如Laplace先验、TV先验）：后验无闭式解 → 必须用优化（第3章）或采样（第4章）

- **误差分解五层次**（Ratti P49-57，已升格为2.3节内独立小节）
  - 贝叶斯估计的完整误差链条：
    1. 不可约误差：真解的固有随机性（后验方差）
    2. 近似误差：用简单变分族近似真实后验
    3. 采样误差：有限样本估计期望（MCMC的有限步）
    4. 优化误差：梯度下降等迭代方法的有限精度
    5. 训练误差：神经网络学习先验/似然时的泛化误差
  - 这五层贯穿全书：第3章处理第4层，第4章处理第3层，第6/9章处理第5层

**来源**：Ratti P10-13; Pock L2 P7-13; Ratti P1-13; Ratti P49-57; Calatroni P29-34

经典先验族虽有优美的数学结构，但它们的假设（高斯、稀疏、分段常数）与真实图像的复杂性之间存在鸿沟。有没有可能让数据自己告诉我们先验长什么样？

## 2.4 从显式先验到隐式先验

**核心观点**：显式先验（高斯/Laplace/TV）需要人为指定分布形式，其表达能力受限于假设的合理性。学习型先验让神经网络从数据中自动学习 p(x) 的结构，是通向扩散模型的必经之路。

- **显式先验的局限**：
  - 必须预先指定分布形式（高斯？Laplace？TV？）——选择本身就需要领域知识
  - 参数化限制了表达能力：真实图像分布远比高斯或Laplace复杂
  - 正则化参数 λ 需要手动调节或交叉验证——缺乏自适应能力

- **从显式到隐式的过渡谱系**：

  ```
  完全显式                    半学习                      完全隐式
  (手工先验)                 (参数化先验)               (深度生成模型)
  
  高斯/Laplace/TV  ──→  Fields of Experts  ──→  VAE/扩散模型的隐式先验
  完全人为指定            学习滤波器参数              学习完整分布
  ```

- **Fields of Experts（FoE）**：半学习的先驱
  - 思想：先验形式仍为 $p(x) \propto \exp(-\sum_k \rho_k(\mathbf{f}_k^T x))$，但滤波器 $\mathbf{f}_k$ 和势函数 $\rho_k$ 从数据中学习
  - 意义：仍保持"可解释的先验结构"，但参数由数据驱动——显式与隐式的折中
  - 局限：表达能力仍受限于参数化形式，无法捕捉图像的高阶统计结构
  - **来源**：Pock L1 P6-20

- **深度生成模型：完全隐式先验**
  - VAE：通过编码器-解码器学习 p(x) 的隐式表示（第9章展开）
  - 得分匹配：通过学习得分函数 $\nabla_x \ln p(x)$ 间接刻画 p(x)（第6章展开）
  - 扩散模型：通过多步去噪过程隐式定义先验（第7/11章展开）

- **本章收尾：逆问题驱动的方法演化**
  - 有了先验 p(x) 和似然 p(y|x)，后验 p(x|y) 在形式上已完全确定
  - 但如何从后验中**提取解**？这取决于我们问什么问题：
    - **路径一（点估计）**：求后验众数 → MAP → 优化方法 → 第3章
    - **路径二（分布采样）**：求后验分布 → MCMC/ULA → 第4-7章（主线，逆问题驱动）
  - 两条路径的终点都是扩散模型，第12章殊途同归
  - 先验的学习本身也分两条路径：得分匹配（第6章）和变分推断（第9章）
  - 📌 **核心论点铺垫**：从逆问题出发，先验的演化有一条清晰因果链——显式先验的表达能力不足→需要学习型先验→PnP表明去噪器可充当先验→Tweedie等式揭示去噪器编码了得分函数→得分匹配从数据中学习得分→多步得分驱动采样即扩散模型。**扩散模型是逆问题需求驱动下先验演化的自然终点**

**来源**：Pock L1 P20-56; Pereyra L3 P36-52

## 附录 2A 共轭先验与闭式后验推导

> 定位：2.3节中共轭先验的数学细节，供有兴趣的读者深入理解为何高斯+高斯有闭式解。

- 高斯似然 $p(y|x) = \mathcal{N}(Ax, \sigma^2 I)$ + 高斯先验 $p(x) = \mathcal{N}(0, \sigma_x^2 I)$
- 后验 $p(x|y) = \mathcal{N}(\mu_{\text{post}}, \Sigma_{\text{post}})$ 其中：
  - $\Sigma_{\text{post}} = (\frac{1}{\sigma^2}A^TA + \frac{1}{\sigma_x^2}I)^{-1}$
  - $\mu_{\text{post}} = \frac{1}{\sigma^2}\Sigma_{\text{post}} A^T y$
- 后验均值 = Tikhonov解 $\hat{x} = (A^TA + \lambda I)^{-1}A^Ty$，其中 $\lambda = \sigma^2/\sigma_x^2$
- 正则化参数 λ 的概率解释：λ = 噪声方差/先验方差 = 信噪比的倒数

**来源**：Calatroni P29-34; Benning L1 P75-83

## 附录 2B TGV：TV的改进

> 定位：2.2节TV先验阶梯效应的改进思路，供对正则化理论有深入兴趣的读者参考。

- TV的局限：假设图像分段常数，渐变区域出现人工阶梯
- TGV（Total Generalized Variation, Bredies et al. 2010）的核心思想：
  - TV = 一阶导数的L1范数：$\text{TV}(x) = \|\nabla x\|_1$
  - TGV = 同时惩罚一阶和二阶导数：$\text{TGV}^2_\alpha(x) = \alpha_1\|\nabla x - v\|_1 + \alpha_2\|\mathcal{E}(v)\|_1$
  - 允许分段仿射（而非分段常数）解，自然处理渐变区域
- 应用：PET重建、MRI重建等对平滑区域精度要求高的场景
- 为何本书不展开：TGV属于显式先验的精细化改良，不参与"贝叶斯→扩散"的主线叙事

**参考文献**：Bredies K., Kunisch K., Pock T. "Total Generalized Variation" SIAM J. Imaging Sciences, 2010.

**来源**：Siltanen D2 P11; Pock L3
