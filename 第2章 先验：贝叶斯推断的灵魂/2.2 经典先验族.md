# 2.2 经典先验族

> 你走进一间工具房（正则化工具箱），墙上挂满扳手：Tikhonov、LASSO、TV……每一把都贴着"适用什么场景"的标签。但你有没有想过：这些工具为什么长成这个样子？它们究竟在假设"图像长什么样"？

承接上一节，我们已经拿到那张"贝叶斯 ↔ 变分"对照表，核心结论只有一句：**数据项由噪声物理唯一决定，正则项由先验决定——先验是我们唯一能主动施加影响的地方。**

所以"选择先验"到底意味着什么？答案就藏在对照表里：**选择先验，就是选择关于 $\mathbf{x}$ 的数学假设。** 每种先验编码了"图像长什么样"的一种结构化知识——或来自物理约束，或来自统计规律；取负对数之后，这种信念变成正则项，引导优化算法走向满足该信念的解。从更深层次看，先验不是人为偏见，而是系统已有经验的数学化表达；本节要做的，正是把每一种经典正则项"翻译"回它所代表的那条知识，再逐一检验：这条知识在什么场景下为真，在什么场景下会伤害解。

**本章目标**：
- 理清三种经典先验的递进：高斯说"值小" → Laplace 说"值稀疏" → TV 说"梯度稀疏"
- 看懂每种先验对应的正则项和解的形态，以及各自的"阿喀琉斯之踵"
- 理解"零点奇性"这个关键点——它才是稀疏性的概率根源

## 一、高斯先验：从"值小"到 Tikhonov 正则化

### 假设与推导

在写下任何公式之前，先问一个认知层面的问题：如果我们对图像几乎一无所知，只知道"它不可能具有任意大的能量"，那么最保守的信念是什么？答案是各分量围绕零集中、彼此互不相关的分布——高斯分布。它编码的结构知识极为克制：信号分量的幅值是有界的，偏离零越远越不可信，且偏离量以平方速率被否定。这正对应一条朴素的物理约束：成像系统的动态范围有限，信号能量不可能发散。

最简单的先验假设：**图像 $\mathbf{x}$ 的各分量独立，且服从零均值高斯分布**。

$$p(\mathbf{x}) = \prod_{i=1}^n \frac{1}{\sqrt{2\pi\sigma_x^2}} \exp\!\Big(-\frac{x_i^2}{2\sigma_x^2}\Big) = \frac{1}{(2\pi\sigma_x^2)^{n/2}} \exp\!\Big(-\frac{1}{2\sigma_x^2}\|\mathbf{x}\|_2^2\Big)$$

其中 $\sigma_x^2$ 是先验对方差（即信号典型能量）的估计。取负对数：

$$-\ln p(\mathbf{x}) = \frac{1}{2\sigma_x^2}\|\mathbf{x}\|_2^2 + \text{const}$$

正则项 $\frac{1}{2\sigma_x^2}\|\mathbf{x}\|_2^2$ 正是 $\ell^2$ 正则项。配合高斯噪声的 $\ell^2$ 数据项，对应 MAP 估计：

$$\hat{x}_{\text{MAP}} = \arg\min_x \|\mathbf{y} - Ax\|_2^2 + \lambda\|\mathbf{x}\|_2^2$$

其中 $\lambda = \sigma^2 / \sigma_x^2$ 是两个方差的比值：噪声越强、或先验认为信号越弱，正则化就越强——数据与信念的相对权重，在这里获得了清晰的概率诠释。这就是 **Tikhonov 正则化**（岭回归），应用最广。

### 解的形态与闭式解

高斯先验的一大独特优势：后验仍是高斯分布，MAP 估计有**闭式解**：

$$\hat{x} = (A^\top A + \lambda I)^{-1} A^\top \mathbf{y}$$

更一般地，当 $L \neq I$（如 $L = \nabla$）时，广义 Tikhonov 正则化 $\|\mathbf{y} - Ax\|_2^2 + \lambda\|Lx\|_2^2$ 的解为：

$$\hat{x} = (A^\top A + \lambda L^\top L)^{-1} A^\top \mathbf{y}$$

闭式解意味着不用迭代优化，直接解线性方程组就行——这一转变把计算成本从"迭代收敛问题"降格为"一次线性求解"，是计算上的巨大优势。代价是，$\ell^2$ 的二次惩罚性质决定了解的整体形态：**所有分量被均匀压缩，但没有分量被推到精确的零。**

### 局限：偏好平滑，丢失边缘

高斯先验的假设——"$\mathbf{x}$ 的值小（0 均值）"——隐含了对低能量解的偏好，这就是过度平滑的根源。具体来说，这个假设在图像上有两种表现形式：

**在图像空间上**，平坦、低幅值的区域恰好符合"值小"的预期，被正确平滑；但边缘和纹理处的像素值突变意味着大的局部偏差与大的 $|x_i - x_{i-1}|$，而 $\ell^2$ 对大值施加**二次惩罚**，强烈抑制突变——无论惩罚作用于 $\mathbf{x}$ 还是 $\nabla \mathbf{x}$，结果都是边缘被模糊、纹理被抹平。

**在解的结构上**，$\ell^2$ 无法产生精确的零分量。这在图像重建等逆问题中成为主要瓶颈：真实信号往往稀疏（边缘仅占少数像素、频谱仅有少数活跃频率），而 $\ell^2$ 的非稀疏性使其无法匹配这种结构。其后果是重建结果整体偏模糊——能量被泄漏到本应为零的分量上；同时丧失特征选择能力，且增大 $\lambda$ 只会将所有分量同步缩小，而非将无关分量精确置零。

归根结底：Tikhonov 正则化天然倾向过度平滑：边缘模糊、纹理丢失。

### 推广：梯度高斯先验 → Sobolev 平滑

对 $\mathbf{x}$ 本身加高斯先验假设"像素值小"，在图像里不太合理——整体亮度是场景属性，本不该由先验裁决。更自然的假设是"相邻像素差值小"，即图像平滑。这一转变意味着先验编码的对象从"数值"换成了"空间结构"：图像是连续物理量的采样，相邻像素天然相关。把高斯先验加在梯度上：

$$\nabla \mathbf{x} \sim \mathcal{N}(0, \sigma_\nabla^2 I)$$

取负对数得：

$$-\ln p(\mathbf{x}) = \frac{1}{2\sigma_\nabla^2}\|\nabla \mathbf{x}\|_2^2 + \text{const}$$

对应正则项 $\|\nabla \mathbf{x}\|_2^2$，即 **Sobolev 平滑正则化**（也称 $H^1$ 正则化）：

$$\min_x \|\mathbf{y} - Ax\|_2^2 + \lambda\|\nabla \mathbf{x}\|_2^2$$

这比对 $\mathbf{x}$ 直接加高斯更合理——它编码"相邻像素相关"的空间结构。但 $\ell^2$ 的二次惩罚没有变：大梯度（边缘处）仍被过度惩罚，过度平滑只是缓解，没有根治。

> **高斯先验的本质**：高斯分布没有"零点奇性"——密度在零点取到的是一处光滑的最大值，$p(\mathbf{x})$ 在零附近平缓变化，没有任何"偏好零"的特殊力量。这意味着 $\ell^2$ 正则项只会均匀缩小所有值，而不会把小值推向精确的零。高斯先验的解是"分散的小值"，不是"稀疏的少量非零值"。

## 实验 2.2-1：高斯先验的推广——从 Tikhonov 到 Sobolev 平滑

实验 `2.2-1.py` 演示**简单高斯先验（Tikhonov）与梯度高斯先验（Sobolev）的去噪效果对比**，揭示协方差结构对正则化效果的影响。脚本包含三个层次的验证：①把 Tikhonov 的参数选择细分为四档（含一个刻意保留的反面教材），说明先验的**均值与方差必须与数据配套**；②验证 Sobolev 迭代解与频域闭式解在机器精度下等价；③新增周期（DFT）与镜像（DCT）两种边界条件的定量对照，澄清边缘伪影的真正来源。

### 实验场景

实验考虑纯去噪问题：观测模型 $\mathbf{y} = \mathbf{x} + \varepsilon$，其中 $\varepsilon \sim \mathcal{N}(0, \sigma^2 I)$ 为加性高斯白噪声。对比两种高斯先验：

**简单高斯先验（Tikhonov）**：假设 $\mathbf{x} \sim \mathcal{N}(0, \sigma_x^2 I)$，正则项为 $\|\mathbf{x}\|_2^2$。MAP 估计有闭式解：

$$\hat{x} = \frac{y}{1 + \lambda}, \quad \lambda = \frac{\sigma^2}{\sigma_x^2}$$

这里有一个容易被忽略、但本实验要专门验证的口径问题：**$\sigma_x^2$ 必须是"关于模型均值的二阶矩"**。零均值模型中 $\sigma_x^2 = \mathbb{E}[\mathbf{x}^2]$（关于 0 的 rms²，含均值能量 $\mu^2$）；若先验写成非零均值形式 $\mathbf{x}\sim\mathcal{N}(\mu,\sigma_x^2 I)$（$\mu$ 用 $\bar{\mathbf{y}}$ 估计），则 $\sigma_x^2 = \mathrm{Var}(\mathbf{x})$，且必须先去均值：

$$\hat{x} = \bar{\mathbf{y}} + \frac{y - \bar{\mathbf{y}}}{1 + \lambda}, \quad \lambda = \frac{\sigma^2}{\mathrm{Var}(\mathbf{x})}$$

把关于均值的方差错配给零均值模型（用 $\sigma^2/\mathrm{Var}(\mathbf{x})$ 却仍向 0 收缩、不去均值），会得到比含噪图还差的结果——脚本把这一做法作为第④档"反面教材"刻意保留。经验贝叶斯的插件估计只允许使用观测 $\mathbf{y}$（噪声方差已知时 $\mathbb{E}[\mathbf{y}^2]=\mathbb{E}[\mathbf{x}^2]+\sigma^2$、$\mathrm{Var}(\mathbf{y})=\mathrm{Var}(\mathbf{x})+\sigma^2$），真值统计量仅在结果中作教学对照。

**梯度高斯先验（Sobolev）**：假设 $\nabla \mathbf{x} \sim \mathcal{N}(0, \sigma_\nabla^2 I)$，正则项为 $\|\nabla \mathbf{x}\|_2^2$。MAP 估计可通过梯度下降迭代求解，也可通过频域闭式解直接计算：周期边界下为 DFT 滤波 $\hat X(\omega)=Y(\omega)/(1-\lambda\mu_P(\omega))$（$\mu_P=2\cos(2\pi\omega_x)+2\cos(2\pi\omega_y)-4\le 0$ 为四邻域周期拉普拉斯的特征值），Neumann 镜像边界下为 DCT 滤波（特征值见步骤 5），二者复杂度同为 $O(n^2\log n)$。

### 实验目的

1. **验证 Tikhonov 参数的概率诠释与口径一致性**：在四档参数化（主观先验 / 零均值模型的一致经验贝叶斯 / 均值中心化经验贝叶斯 / 错配反面教材）下，说明 $\sigma_x^2$ 必须取"关于模型均值的二阶矩"、且先验均值要与数据配套
2. **对比两种高斯先验的去噪效果**：Tikhonov（假设值小）vs Sobolev（假设相邻像素相似）
3. **验证 Sobolev 迭代解与频域闭式解的等价性**：理论上两者应给出相同结果（周期边界内部一致性）
4. **展示超参数敏感性**：不同 $\lambda$ 对 Sobolev 去噪效果的影响
5. **澄清边缘伪影的来源**：用周期（DFT）与镜像（DCT）两种边界条件的定量对照，证明边界伪影是边界建模的代价而非频域方法的固有属性

### 实验输入

| 参数 | 设置 |
|------|------|
| 测试图像 | camera，$64 \times 64$ 像素 |
| 噪声模型 | 加性高斯白噪声，$\sigma = 0.1$ |
| 真值统计量（仅教学对照，实际逆问题不可得） | 均值 $\mu=0.5061$，标准差 $s=0.2755$，$\mathrm{Var}(\mathbf{x})=0.0759$，$\mathbb{E}[\mathbf{x}^2]=0.3321$ |
| 从观测 $\mathbf{y}$ 的插件估计 | $\hat{\mu}=\bar{\mathbf{y}}=0.5078$；$\widehat{\mathbb{E}[\mathbf{x}^2]}=\mathrm{mean}(\mathbf{y}^2)-\sigma^2=0.3336$；$\widehat{\mathrm{Var}}(\mathbf{x})=\mathrm{var}(\mathbf{y})-\sigma^2=0.0758$ |
| Tikhonov 参数（四档） | ① 主观先验 $\sigma_x=1$：$\lambda=0.0100$；② 零均值模型一致 EB，$\sigma_x^2=\mathbb{E}[\mathbf{x}^2]$：$\lambda=0.0300$；③ 均值中心化，$\sigma_x^2=\mathrm{Var}(\mathbf{x})$：$\lambda=0.1320$；④ 反面教材（取③的 $\lambda$ 但不中心化）：$\lambda=0.1320$ |
| Sobolev 参数 | $\lambda \in \{0.05, 0.2, 0.5, 1.0, 2.0\}$（扩展网格以覆盖 PSNR 峰值） |
| 边界条件对照 | 周期（`np.roll`/DFT）vs 镜像（Neumann/DCT-II）；外缘环宽 4 像素；步骤 5 取 $\lambda=1.0$ |
| 求解方法 | Tikhonov：闭式解；Sobolev：梯度下降迭代 + DFT/DCT 两种频域闭式解 |

### 预期结果

- Tikhonov 四档呈现清晰梯度：主观 $\sigma_x=1$（20.10 dB）几乎不收缩；零均值模型的一致 EB（20.17 dB）是标量模型的总体最优点；均值中心化（20.56 dB）为 Tikhonov 族最佳；错配反面教材（19.17 dB）PSNR 不升反降，低于含噪图（20.03 dB）。③与④仅差一次去均值、结果相差约 1.4 dB
- 即使 Tikhonov 族取到最佳（20.56 dB），仍远逊于 Sobolev（25.37 dB），差距来自先验协方差是否编码空间结构，调参无法弥补
- Sobolev 迭代解与频域闭式解数值差异应达到迭代容差精度（$10^{-12}\!\sim\!10^{-14}$）
- 周期 DFT 与镜像 DCT 在图像内部的 MSE 应几乎完全相同；大 $\lambda$ 下周期边界的边缘环 MSE 显著更高（$\lambda=1$ 时 0.00448 vs 0.00185，全局 24.91 vs 25.83 dB），证实边缘伪影源于边界建模

四档 Tikhonov 把"先验的均值与方差必须与数据配套"拆成了可验证的梯度：

- **① 主观先验 $\sigma_x=1$**（$\lambda=0.01$）：先验允许像素扩散到约 $[-3,3]$，方差远大于真实信号能量，$\lambda$ 过小、几乎不收缩，20.10 dB 与含噪持平；
- **② 零均值模型的一致经验贝叶斯**（$\widehat{\sigma_x^2}=\mathbb{E}[\mathbf{x}^2]=0.334$，$\lambda=0.03$）：这才是与 $\mathbf{x}\sim\mathcal{N}(0,\sigma_x^2 I)$ 配套的无偏插件估计；标量模型的 MSE 总体最优参数恰为 $\lambda^*=\sigma^2/\mathbb{E}[\mathbf{x}^2]$，20.17 dB；
- **③ 均值中心化**（$\hat{\mathbf{x}}=\bar{\mathbf{y}}+(\mathbf{y}-\bar{\mathbf{y}})/(1+\lambda)$，$\lambda=\sigma^2/\widehat{\mathrm{Var}}(\mathbf{x})=0.132$）：显式承认真值均值 $\mu\approx0.506$、先去均值再收缩，是 Tikhonov 族最佳，20.56 dB；
- **④ 反面教材**：沿用旧版做法，用 $\sigma^2/s^2=0.132$（关于*均值*的方差）却仍套零均值闭式解、不中心化——等于强迫解向 0 靠拢，过度收缩使 PSNR 掉到 19.17 dB，**比不处理还低**。

③与④使用**完全相同的 $\lambda$，只差一次去均值，PSNR 相差 1.39 dB**：问题从来不是 $\sigma_x$ 数字本身，而是模型均值与数据均值是否匹配。这把旧版实验里"数据估计反而更差"的反常现象，从一个令人困惑的失败，转化成了一条清晰的教学证据。

Sobolev 一侧，PSNR 随 $\lambda$ 先升后降：$\lambda=0.5$ 处达峰值 25.37 dB，$\lambda=2.0$ 因过平滑回落到 23.41 dB——扩展后的网格真正演示出了超参数的最优点（旧网格 $\{0.05,0.1,0.2\}$ 只覆盖单调上升支，"最优 $\lambda=0.2$"实为区间边缘而非峰值）。

| Sobolev（$\lambda = 0.20$） | 0.0220 |
| Sobolev（$\lambda = 0.50$） | 0.0162 |
| Sobolev（$\lambda = 1.00$） | 0.0123 |
| Sobolev（$\lambda = 2.00$） | 0.0092 |

两档弱正则 Tikhonov（①②）局部方差**高于**真实值（0.0332/0.0320 vs 0.0254）——噪声未被充分收缩，与它们 PSNR 贴近含噪基线互为印证。③与④的局部方差完全相同（0.0265）：中心化与不中心化两个解只相差一个常数平移，方差不受影响——但两者 PSNR 相差 1.39 dB，说明该常数平移（亮度偏差）恰是④失败的全部原因，方差类指标对此完全无感。Sobolev 一侧，小 $\lambda$（0.05）局部方差高于真实值、大 $\lambda$（0.5/1.0/2.0）低于真实值；PSNR 最优的 $\lambda=0.5$ 对应 0.0162，已明显低于真实的 0.0254，说明"按 MSE/PSNR 选参"与"保持局部方差（纹理）"并非同一目标，这正是高斯先验过平滑的体现。

#### 步骤4：迭代解与频域闭式解对比（图 2.8）

![图 2.8　迭代解与闭式解对比](<./第二章 配套实验/实验2.2-1/步骤4_迭代解与闭式解对比.png>)

Sobolev 去噪可通过两种方法求解：
- **迭代法**：空域梯度下降，复杂度 $O(k \cdot n^2)$，$k$ 为迭代次数
- **闭式解**：频域 DFT 滤波（周期边界），复杂度 $O(n^2 \log n)$；Neumann 镜像边界的 DCT 闭式解见步骤 5

理论上两者等价。实验验证了数值差异：

| $\lambda$ | 最大差异 | 迭代次数 | 迭代解 PSNR | 闭式解 PSNR |
|-----------|----------|----------|-------------|-------------|
| 0.05 | $1.97 \times 10^{-14}$ | 25 | 21.51 dB | 21.51 dB |
| 0.20 | $1.55 \times 10^{-13}$ | 57 | 24.02 dB | 24.02 dB |
| 0.50 | $4.12 \times 10^{-13}$ | 117 | 25.37 dB | 25.37 dB |
| 1.00 | $8.28 \times 10^{-13}$ | 215 | 24.91 dB | 24.91 dB |
| 2.00 | $1.70 \times 10^{-12}$ | 406 | 23.41 dB | 23.41 dB |

差异量级为 $10^{-12}\!\sim\!10^{-14}$（受迭代容差 $10^{-13}$ 控制），远小于像素值范围，验证了两种方法在数值上的等价性。注意：早期版本以"目标函数相对变化"作停止判据，会在解尚未收敛时（仅 6–11 步）提前终止，使差异停留在 $10^{-4}$ 量级；现改用"解的逐像素最大变化 $\max|\Delta \mathbf{x}|<$ 容差"判据，迭代解才真正逼近闭式解。

#### 步骤5：边界条件对照——周期（DFT）vs 镜像（DCT）（图 2.9）

![图 2.9　边界条件DFT与DCT对照](<./第二章 配套实验/实验2.2-1/步骤5_边界条件DFT与DCT对照.png>)

频域求解必须指定边界条件。迭代法中的 `np.roll` 与 DFT 闭式解共享同一假设：**周期性边界**——图像的上下边、左右边首尾相连。cameraman 不是周期信号（上下/左右边缘均值跳变约 0.29/0.23），周期延拓会在拼接处人为制造不连续，大 $\lambda$ 时表现为四条边缘上的明显伪影。另一种标准选择是 **Neumann 镜像边界**：图像在边界外镜像翻转延拓，不存在对边拼接；它对应路径图（端点度 1）五点拉普拉斯，其正交特征基恰为 DCT-II，二维特征值为

$$\mu(k,l)=4-2\cos\!\frac{\pi k}{n}-2\cos\!\frac{\pi l}{n},\qquad \tilde X=\frac{\tilde Y}{1+\lambda\mu(k,l)}$$

（该特征值已用稠密矩阵谱分解核对到 $10^{-14}$，DCT 解满足正规方程的残差为 $10^{-15}$。）两种解法的**唯一差别是边界条件**，复杂度同为 $O(n^2\log n)$。

为隔离边界效应，把图像分成外缘 4 像素环与内部区域，分别统计 MSE：

| $\lambda$ | DFT 边界环 MSE | DCT 边界环 MSE | DFT 内部 MSE | DCT 内部 MSE | DFT PSNR | DCT PSNR |
|-----------|---------------|---------------|-------------|-------------|----------|----------|
| 0.05 | 0.00725 | 0.00736 | 0.00700 | 0.00700 | 21.51 dB | 21.50 dB |
| 0.20 | 0.00433 | 0.00406 | 0.00385 | 0.00385 | 24.02 dB | 24.09 dB |
| 0.50 | 0.00369 | 0.00239 | 0.00266 | 0.00266 | 25.37 dB | **25.86 dB** |
| 1.00 | 0.00448 | **0.00185** | 0.00285 | 0.00285 | 24.91 dB | **25.83 dB** |
| 2.00 | 0.00634 | 0.00186 | 0.00401 | 0.00399 | 23.41 dB | **24.57 dB** |

对照得出三点结论：

- **内部区域两者 MSE 一致到 0.1% 以内**（如 $\lambda=1$ 时 0.002848 vs 0.002846，$\lambda=2$ 时 0.004011 vs 0.003994）——两种解在远离边界处是同一个解，差异被干净地隔离在边界；
- **差距随 $\lambda$ 增大而拉大**：小 $\lambda$ 时扩散范围达不到边界，两者无差别（$\lambda=0.05$ 时 DFT 边界环 MSE 甚至略低）；$\lambda \geq 1$ 后周期拼接的假边缘被反复平均进图内，DFT 边界环 MSE 反超 DCT 2.4～3.4 倍（$\lambda=1$：2.43 倍；$\lambda=2$：3.41 倍），$\lambda=0.5$ 时约为 1.5 倍；
- 步骤 5 图（取 $\lambda=1$）的误差热图直观显示：周期解的绝对误差沿四条边缘集中，镜像解的边缘误差基本消失，全局 PSNR 高出 0.92 dB。

因此，边缘伪影是**"周期性边界 + 非周期图像"这一建模选择的代价，不是频域方法的固有属性**——同为频域闭式解的 DCT 即可消除大部分伪影。实践中除镜像边界外，边界加 padding（去噪后裁回）也是常用缓解手段。

#### 核心知识点：MAP 与 MMSE 的等价性

在高斯-高斯模型下（高斯似然 + 高斯先验），后验分布为高斯分布。由于高斯分布对称，均值 = 众数，因此：

- MAP 估计（后验众数）= MMSE 估计（后验均值）
- Tikhonov 闭式解 $\mathbf{x} = \mathbf{y}/(1+\lambda)$ 既是 MAP 也是 MMSE；均值中心化版本 $\bar{\mathbf{y}}+(\mathbf{y}-\bar{\mathbf{y}})/(1+\lambda)$ 同理（常数均值不改变二次目标的最优性条件）

这是共轭先验的重要性质，详见第2章附录2A。

#### 高斯先验的特点总结

| 特性 | 简单高斯先验（Tikhonov） | 梯度高斯先验（Sobolev） |
|------|-------------------------|------------------------|
| 假设 | 像素 i.i.d.、值小（零均值时） | 相邻像素相似 |
| 协方差 | $\sigma_x^2 I$（对角矩阵，无空间结构） | 涉及梯度算子（含空间相关） |
| 正则项 | $\|\mathbf{x}\|_2^2$ | $\|\nabla \mathbf{x}\|_2^2$ |
| 优点 | 有闭式解，计算高效；高斯下 MAP=MMSE | 编码空间结构，比简单高斯合理得多（本实验 +4.8 dB） |
| 缺点 | 过度平滑、丢失边缘；模型均值与数据不匹配时 PSNR 可低于含噪图 | 仍会过度平滑边缘 |
| 参数选择 | $\sigma_x^2$ 取关于模型均值的二阶矩（零均值用 $\mathbb{E}[\mathbf{x}^2]$，非零均值先去均值用 $\mathrm{Var}(\mathbf{x})$），二者不可混用 | $\lambda$ 影响平滑程度，需调参（本实验 oracle 最优 $\lambda\approx0.5$） |
| 边界条件 | 标量收缩，逐像素独立，无边界问题 | DFT/`np.roll` 为周期边界，非周期图像边缘有拼接伪影；镜像 DCT 可消除大部分，复杂度相同 |

## 二、Laplace 先验：从"值稀疏"到 L1 正则化

### 假设与推导

第二类结构化知识来自一条被反复验证的统计规律——**可压缩性**：自然信号总能在某个表示下，由少数显著分量承载绝大部分能量，其余分量接近于零。要把这条知识写进先验，所需的分布必须同时满足两点：强烈偏好零，又宽容少数大值。高斯分布做不到——它对大值的二次惩罚恰恰扼杀了显著分量。Laplace 分布正是满足这条要求的最简单选择。

如果图像在某个表示下是**稀疏**的——大多数分量为零或接近零，只有少数显著非零——更合适的先验是 Laplace 分布：

$$p(\mathbf{x}) = \prod_{i=1}^n \frac{1}{2b} \exp\!\Big(-\frac{|x_i|}{b}\Big) = \frac{1}{(2b)^n} \exp\!\Big(-\frac{1}{b}\|\mathbf{x}\|_1\Big)$$

其中 $b$ 控制分布的尺度：$b$ 越小，先验对零的偏好越尖锐。Laplace 与高斯的关键区别在于**零点处的概率集中**：Laplace 在 $x_i = 0$ 处有一个尖峰（不可导的峰），高斯在零处是光滑的。取负对数：

$$-\ln p(\mathbf{x}) = \frac{1}{b}\|\mathbf{x}\|_1 + \text{const}$$

正则项是 $\ell^1$ 正则项。配合高斯噪声数据项：

$$\hat{x}_{\text{MAP}} = \arg\min_x \|\mathbf{y} - Ax\|_2^2 + \lambda\|\mathbf{x}\|_1$$

这就是著名的 **LASSO**（最小绝对收缩与选择算子）或**稀疏正则化**。

### L1 促稀疏：为什么 $\ell^1$ 产生稀疏解？

$\ell^1$ 为什么能产生稀疏解？我们可以从三个不同的角度来建立直觉。

**概率角度**：Laplace 分布在零点有尖峰，概率质量高度集中在零附近。先验偏好 $x_i = 0$，MAP 自然会令许多分量精确为零。

**几何角度**：二维情形下，$\ell^1$ 的等高线是菱形，$\ell^2$ 的等高线是圆形。数据项 $\|\mathbf{y} - Ax\|_2^2$ 的等高线是以最小二乘解为中心的椭圆。正则化解就是数据项椭圆与正则项等高线的切点：
- $\ell^2$（圆形）等高线与椭圆的切点通常在坐标轴之间——各分量均非零
- $\ell^1$（菱形）等高线的角点恰好在坐标轴上，椭圆更容易在角点处相切——某些分量精确为零

这个直觉在高维也成立：$\ell^1$ 球的角点在坐标轴上，优化更倾向在角点取到——这正是稀疏性的来源。（图 2.10）

![图 2.10　L1 vs L2 几何解释](<./第二章 配套实验/实验2.2-1/图2-1_L1_vs_L2几何解释.png>)

**优化角度**：$\ell^1$ 对 $x_i$ 的惩罚是线性的 $|x_i|$，其次梯度在 $x_i>0$ 时恒为 $+1$，在 $x_i<0$ 时恒为 $-1$。无论 $x_i$ 多小，把它推向零的力都一样大——小值被推到零，大值只受温和的线性惩罚。相比之下 $\ell^2$ 惩罚 $x_i^2$ 的梯度是 $2x_i$——$x_i$ 越小推力越弱，小值永远推不到精确零。

> **$\ell^0$ 与 $\ell^1$ 的关系**：最"理想"的稀疏度量是 $\ell^0$ 伪范数 $\|\mathbf{x}\|_0 = \#\{i : x_i \neq 0\}$（非零分量个数），但最小化 $\|\mathbf{y}-Ax\|_2^2 + \lambda\|\mathbf{x}\|_0$ 是 NP 困难的（组合搜索）。$\ell^1$ 是 $\ell^0$ 的**最紧凸松弛**——在保持凸性（可优化）前提下，$\ell^1$ 是最接近 $\ell^0$ 的范数。这让稀疏正则化既理论可证收敛，又实践中真能促稀疏。

### 应用场景：稀疏表示框架

Laplace 先验的直接应用是假设图像本身稀疏——但自然图像的像素值通常并不稀疏。Laplace 真正发挥作用的是**稀疏表示框架**：

图像 $\mathbf{x}$ 可在某个变换域（小波、字典学习）下被少量基函数逼近：

$$\mathbf{x} = W\alpha, \quad \|\alpha\|_0 \ll n$$

其中 $W$ 是变换矩阵，$\alpha$ 是稀疏系数（例如 JPEG 中 $W$ 为分块 DCT 基，量化后绝大多数高频系数为零，仅保留极少数低频分量即可重建视觉可接受的图像）。对 $\alpha$ 施加 Laplace 先验（其负对数密度即 $\ell^1$ 范数）：

$$\min_\alpha \|\mathbf{y} - AW\alpha\|_2^2 + \lambda\|\alpha\|_1$$

这是**合成形式**（synthesis form）稀疏正则化——在系数空间找稀疏解。当 $W$ 正交时与之严格等价的**分析形式**（analysis form）直接在图像空间操作：

$$\min_x \|\mathbf{y} - Ax\|_2^2 + \lambda\|W^\top \mathbf{x}\|_1$$

其中 $W^\top$ 是分析算子（如小波分解）。关键洞察：自然图像本身不稀疏，但在合适的变换域下可由少量系数有效表示。Laplace 先验 + 合适变换 = 稀疏性先验。该方法的重要性并不只在于提供了一个可解的优化问题，而在于它把"稀疏"从对信号本身苛刻的要求，转化为对表示域的一次选择——先验与表示共同构成知识，二者缺一不可。

### 局限：稀疏假设需要前提

Laplace 的核心假设是"稀疏"。如果图像在选定表示下确实稀疏（如小波稀疏），L1 效果优秀。但若表示选错——图像在该表示下并不稀疏——Laplace 先验会强制引入稀疏性，导致重建偏差。

### 从 ℓ¹ 到 ℓ⁰：迭代硬阈值与重加权逼近

上面把 $\ell^1$ 定位为 $\ell^0$ 的**最紧凸松弛**——理论最优凸近似。这里补充**实用地逼近 $\ell^0$** 的三类算法，都直接面向"非零分量很少"这一真实 $\ell^0$ 目标：

- **迭代硬阈值（Iterative Hard Thresholding, IHT）**：合成稀疏模型 $\mathbf{y}=A\alpha$ 下，交替做"梯度步 + 硬阈值"：
  $$\alpha^{k+1} = H_\lambda\!\left(\alpha^k + A^\top(\mathbf{y} - A\alpha^k)\right)$$
  其中 $H_\lambda$ 只保留绝对值大于 $\lambda$ 的分量、其余置零。这类"测量数远少于未知数、却靠稀疏性精确恢复"的问题统称**压缩感知**；IHT 正是它在约束等距（RIP）条件下最朴素的迭代求解器。
- **重加权 ℓ¹（reweighted ℓ¹ / IRL1）**：把固定权重 $\lambda\|\alpha\|_1$ 换成迭代权重 $\sum_i w_i^{(k)}|\alpha_i|$，其中 $w_i^{(k)} = 1/(|\alpha_i^{(k)}|+\varepsilon)$。权重随解更新，目标越来越逼近 $\ell^0$（小系数被更强惩罚）；实验上比固定 ℓ¹ 更稀疏、更接近真 ℓ⁰ 解。
- **贪婪法（匹配追踪 / OMP）**：每次迭代挑一个最能降低残差的原子（基函数），逐步搭起稀疏支撑集——与 IHT 的"全局阈值"互补。

**逆问题中的应用**：超分辨荧光显微（super-resolution microscopy）中，点光源在图像中天然高度稀疏，直接用 $\ell^{2}\text{-}\ell^{0}$ 模型即可恢复亚衍射极限的发光点位置。这类"对象本身稀疏，于是稀疏性直接当先验用"的思路，正是第 13、16 章要展开的主线——把稀疏先验用到 CT、MRI 等逆问题的重建中，此时并不需要 TV 或学习类先验。注意这和 2.2 节"ℓ¹ 是最紧凸松弛"并不矛盾，而是**在同一条稀疏先验主线上，从凸近似走向更贴近 ℓ⁰ 的实用算法**。

## 实验 2.2-2：Laplace 先验的稀疏机制——为什么它能把系数精确置零

上一节从几何、概率、优化三个视角论证了 Laplace 先验的零点奇性"应该"促稀疏。本实验用一个一维稀疏恢复问题，把抽象的零点尖峰变成肉眼可见的"置零"效果，并与同强度的高斯先验作直接对照；进而延伸到压缩感知设定，对比 IHT、重加权 ℓ¹、OMP 三种"从 ℓ¹ 到 ℓ⁰"的实用逼近算法。

### 实验场景

实验 `2.2-2.py` 分为两部分：

**Part A（软阈值）** 构造一条只有 5 个非零系数的 50 维稀疏信号 $\mathbf{x}^*$，加高斯噪声得观测 $\mathbf{y}$，在同一个 $\lambda$ 下分别用 Laplace 先验（LASSO，闭式软阈值）和高斯先验（Ridge，闭式缩放）做 MAP 估计，对比两者恢复出的系数。这一 Part 对应本章"Laplace 先验的零点奇性促稀疏"及"三视角统一"的核心论述。

**Part B（压缩感知）** 把视角搬到"观测维度 $M$ 远小于信号维度 $N$"的**欠定**情形——这正是压缩感知的典型设定：依靠稀疏性，用极少量观测恢复出信号。具体做法是把 Laplace 先验真正作用的"变换域稀疏系数 $\alpha$"搬进合成形式 $\min_\alpha\|\mathbf{y}-A\alpha\|_2^2 + \lambda\|\alpha\|_1$，构造一个真正欠定（$A$ 为 $80\times256$，$M<N$）的 1D 压缩感知问题，对比 IHT、重加权 ℓ¹、OMP 三种算法如何把 $\ell^1$ 推向更贴近 $\ell^0$ 的解。这一 Part 对应上文"从 ℓ¹ 到 ℓ⁰：迭代硬阈值与重加权逼近"与"应用场景：稀疏表示框架"两部分的内容。

### 实验目的

1. **验证零点奇性的"硬置零"机制**：看 L1 软阈值在死区 $[-\lambda, \lambda]$ 内把小系数精确压成 0，而 L2 只均匀缩小、不产生任何精确零。
2. **公平对比同 $\lambda$ 下的恢复质量**：用 MSE 与支撑集双侧指标（召回率、精确率、误报数）量化 Laplace 先验 vs 高斯先验的差距，理解为何 $\ell^1$ 促稀疏而 $\ell^2$ 不促稀疏。
3. **把三视角统一到一次实验上**：先验密度图（概率视角）、系数估计对比（恢复效果）、软阈值函数（优化视角）三者互相印证。
4. **验证"从 ℓ¹ 到 ℓ⁰"的三类实用算法**：在欠定压缩感知条件下对比 IHT（硬阈值）、重加权 ℓ¹（迭代权重）、OMP（贪心匹配）对 $\ell^0$ 的不同逼近策略。
5. **展示不同逼近策略的代价与权衡**：三种策略在恢复精度与非零个数上的不同表现，直观说明"逼近 ℓ⁰"不是唯一答案，而是有方向的工程选择。

### 实验输入

| 参数 | Part A | Part B |
|------|--------|--------|
| 信号维度 $N$ | 50 | 256 |
| 真实非零系数个数 $K$ | 5 | 10 |
| 观测数 $M$ | —（$A=I$，纯去噪） | 80（$M<N$，欠定） |
| 正则强度 $\lambda$ | 0.1（≈1.9σ，与噪声水平匹配） | 重加权 ℓ¹ 取 $1.2\sigma\approx0.020$（随噪声自适应）；IHT/OMP 不需要 λ |
| 目标观测 SNR | 20 dB（实测 20.4 dB） | 30 dB（实测 30.3 dB） |
| 随机种子 | 信号 7 / 噪声 42 | 7（另做 seeds 0–29 的多 seed 验证） |
| 测量矩阵 | — | 高斯随机矩阵（列归一化） |

> **定标口径（2026-10 复核修正）**：SNR 一律按向量能量定义 $\mathrm{SNR}=20\log_{10}(\|\text{信号}\|/\|\text{噪声}\|)$，由 $\mathbb{E}\|e\|^2=d\sigma^2$（$d=N$ 或 $M$）得 $\sigma=\|\text{信号}\|/(\sqrt d\cdot10^{\mathrm{SNR}/20})$。旧版脚本漏除 $\sqrt d$，导致 Part A 实际 SNR 仅 3.4 dB、Part B 仅 11.2 dB；本节所有数值与图均为修正定标后重算，$\lambda$ 也相应改为随噪声水平选取（旧固定值 0.6/0.1 在正确 SNR 下属严重过正则）。

### 预期结果

- **Part A**：Ridge 的精确置零数应为 0——$\ell^2$ 只均匀缩小、永不让分量精确为零，但它因此对 45 个纯噪声位置全部"误报"，支撑精确率仅 $5/50=10\%$；在与噪声匹配的 $\lambda=0.1$ 下，LASSO 应既保住全部 5 个真峰（召回 100%）、又把约 43 个分量精确置零（仅 2 个误报），MSE 显著低于 Ridge。$\lambda$ 扫描应展示固有代价：软阈值对 $|y_i|<\lambda$ 的分量无差别置零，$\lambda$ 一旦超过最弱峰的观测量级（本例 $|\mathbf{y}|=0.142$，即 $\lambda\ge0.15$），弱峰就会和噪声一起被"误杀"——误杀机制是 L1 固有的，但是否发生取决于 $\lambda$ 与噪声水平是否匹配，而非 L1 在任何工作点上都必然牺牲弱峰。
- **Part B**：真实 30 dB 下三种算法都应做到近精确恢复（相对误差 $O(10^{-2})$，量级接近"已知真支撑做最小二乘"的 oracle 地板 0.010）：IHT 与 OMP 输出恰好 $K=10$ 个非零分量（硬阈值"只留 top-$K$"与贪心"选 $K$ 个原子"的构造必然，不代表支撑全对）；重加权 ℓ¹ 输出更少的非零（9 个）且零误报，代价是相对误差略大。单 seed 不足以评判算法，30 个随机种子的统计（图 2.16）预计显示：OMP 最稳健（均值 0.012、失败率 0）；重加权 ℓ¹ 在所有 seed 上零误报、最保守（0.035、0% 失败）；朴素固定步长 IHT 在 $M=80$ 这一偏紧的测量数下呈双峰分布、约 47% 的 seed 失败——这是该简化算法的真实局限，而非压缩感知失效。

#### Part A：软阈值——Laplace 先验的"硬置零"机制

**质量指标对比**（真实 SNR=20.4 dB，$\sigma=0.0537$，$\lambda=0.1$）：

| 方法 | 先验 | MSE | 召回率 | 精确率 | 误报 | 精确置零数 |
|------|------|-----|-------|-------|------|-----------|
| Ridge (L2) | 高斯 $\mathcal{N}(0, 1/\lambda)$ | 0.0049 | 100% | 10%（5/50） | 45 | 0 |
| LASSO (L1) | Laplace $(0, b)$ | 0.0014 | 100% | 71%（5/7） | 2 | 43 |

**关键观察**：

- **Ridge 的精确置零数为 0**——$\ell^2$ 二次惩罚把每个小系数都按比例缩小，但从不让任何分量真正等于 0，于是 45 个纯噪声位置全部残留（图2 中景的一片细小毛刺）。
- **LASSO 精确置零了 43 个分量，仅 2 个误报，且 5 个真峰全部保住**，MSE（0.0014）仅为 Ridge（0.0049）的约 28%——在与噪声匹配的 $\lambda$ 下，"该压成零的压成零、该保留的保留"，这正是一维情形下零点奇性 → 稀疏性的直接证据。
- **双侧指标戳穿"Ridge 支撑恢复率 100%"的假象**：旧版用单侧召回率，Ridge 因 50 个分量全非零而白拿 100%。改用精确率后，Ridge 只有 10%（报出的 50 个"非零"里 45 个是噪声）；LASSO 精确率 71%、且随 $\lambda$ 增大迅速升到 100%。
- **固有代价的正确表述（λ 扫描，数据存于 `results.json`）**：软阈值对所有 $|y_i|<\lambda$ 的分量无差别置零，机制本身不区分"弱峰"与"噪声"。本例最弱峰真值 $-0.160$（约 $2.99\sigma$），其观测 $|\mathbf{y}|=0.142$（约 $2.64\sigma$）：$\lambda\le0.14$ 时它始终保留（召回 100%），$\lambda\ge0.15$ 即被误杀（召回掉到 80%、精确率升至 100%）；$\lambda\to0$ 时置零数归零，LASSO 退化为恒等映射。所以"置零"与"误杀弱峰"是同一机制的一体两面，**是否真的牺牲弱峰取决于 $\lambda$ 与噪声水平是否匹配**——这也正是实践中要用交叉验证选 $\lambda$、并在小波/DCT 等更稀疏的变换域做 LASSO（弱峰更少、阈值更易选取）的原因。MSE 在 $\lambda\approx0.06$ 处最优（0.00080），但那时精确率仅 26%；本实验取 $\lambda=0.1$ 是"误差—稀疏度"的折中工作点。

## 三、TV 先验：从"梯度稀疏"到全变差正则化

### 假设与推导

第三类结构化知识不再关注数值或系数本身，而是关注几何：自然场景由物体构成，物体内部亮度近似恒定，物体之间以锐利边界分隔。因此梯度在绝大多数位置为零、在极少数位置显著——这就是"梯度稀疏"。注意，这一假设既不是"值小"也不是"值稀疏"：自然图像的像素值本身既不小也不稀疏，真正稀疏的是它的**差分**。

自然图像有个重要统计特性：**梯度稀疏**——大部分区域平滑（梯度接近零），只有少数位置有边缘（梯度较大）。TV（Total Variation，全变差）先验直接编码了这一假设。

> **梯度稀疏的实证依据：**
> "梯度稀疏"并非凭空设定的先验信念，而是自然图像的**实测统计**。对约 1500 万（$15$ million）个 $2\times2$ 图像块的梯度 $\nabla u$ 做直方图，其对数统计（log-statistics）形状像一个**"倒扣的冰淇淋蛋筒"（upside-down ice-cream cone）**——即梯度分布是**重尾（heavy-tailed）**的：绝大多数梯度接近零，但拖出一条延伸到很大值的长尾（对应边缘）。下图展示了真实自然图像在多角度各向同性采样下的 3D 对数联合梯度分布：

图 2.17 给出自然图像梯度的 3D 对数联合分布。

![图 2.17　自然图像梯度的 3D 对数联合分布：水平轴为水平梯度 $\nabla_x$ 与垂直梯度 $\nabla_y$，纵轴为对数概率密度 $\ln P(\nabla_x,\nabla_y)$；尖峰高耸于原点（绝大多数像素对的梯度接近零），向四周拖出厚重的长尾（对应边缘）](<图2-2_图像梯度3D对数联合分布.png>)

> 对这条负对数统计曲线做最简单的最小二乘拟合，得到的正是 $\ell_2$ 范数，于是自然导出全变差
> $$\operatorname{TV}(u)=\|Du\|_{2,1}=\sum_{i,j}\sqrt{(u_{i+1,j}-u_{i,j})^2+(u_{i,j+1}-u_{i,j})^2}$$
> 这正是 Rudin–Osher–Fatemi（1992）的 ROF 模型。换言之，TV 不是人为选择的正则项，而是对自然图像梯度**重尾统计的最小二乘拟合结果**；它也解释了为何 TV 解允许边缘（不连续）：统计上它正确区分了"平滑区域（梯度≈0）"与"边缘（梯度大但概率非零）"，而不是像 $\ell^2$ 那样对大梯度施加二次惩罚。

TV 先验假设图像的梯度服从 Laplace 分布：

$$\nabla \mathbf{x} \sim \text{Laplace}(0, bI)$$

取负对数：

$$-\ln p(\mathbf{x}) = \frac{1}{b}\|\nabla \mathbf{x}\|_1 + \text{const}$$

其中 $\|\nabla \mathbf{x}\|_1$ 就是全变差 $\text{TV}(\mathbf{x})$。配合高斯噪声数据项，得到 **Rudin-Osher-Fatemi（ROF）模型**（1992）：

$$\min_x \|\mathbf{y} - Ax\|_2^2 + \lambda\,\text{TV}(\mathbf{x})$$

离散情形下，各向同性 TV 定义为：

$$\text{TV}(\mathbf{x}) = \sum_i \sqrt{(D_h \mathbf{x})_i^2 + (D_v \mathbf{x})_i^2}$$

其中 $D_h$、$D_v$ 分别是水平和垂直有限差分算子。也可用各向异性 TV：$\|\nabla \mathbf{x}\|_1 = \|D_h \mathbf{x}\|_1 + \|D_v \mathbf{x}\|_1$。还应注意：这一先验只作用于梯度，常数分量不受任何惩罚——这恰好对应一条物理事实：先验陈述的是图像的结构（边缘在哪里），而非整体亮度（图像有多亮）。

### TV 与 Laplace 先验的关系

仔细看：**TV 先验 = 对梯度施加 Laplace 先验**。这和"对 $\mathbf{x}$ 本身施加 Laplace 先验"有本质区别：
- Laplace 先验（$\|\mathbf{x}\|_1$）：假设像素值本身稀疏——适用于稀疏表示框架
- TV 先验（$\|\nabla \mathbf{x}\|_1$）：假设像素梯度稀疏——直接适用于自然图像

从 Laplace 到 TV，假设从"$\mathbf{x}$ 本身稀疏"变为"$\nabla \mathbf{x}$ 稀疏"——这一转变意味着先验的作用对象从信号本身移到了信号的结构（边缘）上，从而更贴近自然图像的真实统计。

### 核心优势：同时平滑与保边

TV 正则化的核心优势是**同时平滑与保边**：
- **平坦区域**：梯度接近零，$\|\nabla \mathbf{x}\|_1$ 惩罚很轻，平滑去噪类似高斯先验
- **边缘处**：梯度较大，但 $\ell^1$ 只产生线性代价（不像 $\ell^2$ 二次代价过度惩罚大梯度），边缘得以保留

从认知角度看，TV 的软阈值发生在梯度域：小梯度被判定为噪声并压为零，大梯度被判定为边缘并保留——这与像素域的软阈值是同一条"证据裁决"规则在不同空间中的再现。

这种"平滑但不模糊边缘"使 TV 成为最成功的显式先验之一。函数空间上，TV 解属于 **BV（有界变差）空间**而非 Sobolev 空间——BV 允许不连续函数（边缘），Sobolev 要求函数连续可微。

### 已知局限：阶梯效应

TV 假设"梯度稀疏"等价于假设图像是**分段常数**的。这对卡通类图像（大平坦区域 + 锐利边缘）很合适，但对渐变区域就有问题：
- **天空渐变**：真实亮度从地平线到天顶平滑渐变，但 TV 假设分段常数，把渐变近似成一系列阶梯——**阶梯效应**（staircase effect）
- **皮肤过渡**：面部光影柔和过渡被近似成色块
- **斜坡区域**：任何缓慢变化区域都会被"楼梯化"

从更深层次看，阶梯效应是信念强制的结果：当现实包含渐变，而先验坚持"梯度要么为零、要么显著"时，优化器只能以有限次跃变去逼近连续变化。这不是算法的失败，而是先验与真实结构错位的直接后果——先验编码什么，解就只能呈现什么。

阶梯效应的根源是 TV 只用了一阶信息（梯度），把函数空间限制为分段常数。改进思路是引入二阶信息——附录 2B 的 **TGV**（Total Generalized Variation）通过同时惩罚一阶和二阶导数，允许分段仿射解，有效缓解阶梯效应。

> **TV 先验的启示**：TV 的成功和局限都来自同一个假设——"梯度稀疏"。假设与真实一致（卡通图像），TV 优秀；假设过于简化（渐变区域），TV 引入系统性偏差。这印证了 2.1 节的结论：**好先验编码正确知识，差先验引入系统性偏差。**

## 实验 2.2-3：TV 先验的局限——阶梯效应

实验 `2.2-3.py` 演示 **Sobolev 平滑先验与 TV 全变差先验的去噪效果对比**，揭示两种先验在保边性和平滑性上的本质差异，以及 TV 先验的阶梯效应局限。

### 实验场景

实验考虑纯去噪问题：观测模型 $\mathbf{y} = \mathbf{x} + \varepsilon$，其中 $\varepsilon \sim \mathcal{N}(0, \sigma^2 I)$ 为加性高斯白噪声。对比两种先验：

**Sobolev 平滑先验**：假设 $\nabla \mathbf{x} \sim \mathcal{N}(0, \sigma_\nabla^2 I)$，正则项为 $\|\nabla \mathbf{x}\|_2^2$。MAP 估计在周期边界下可通过 FFT 频域闭式解直接计算。

**TV 全变差先验**：假设 $\nabla \mathbf{x} \sim \text{Laplace}(0, bI)$，正则项为 $\|\nabla \mathbf{x}\|_1$。MAP 估计（ROF 模型）通过 Chambolle 原始-对偶投影算法求解。

### 实验目的

1. **对比 Sobolev 与 TV 先验的去噪效果**：展示 $\ell^2$ 梯度惩罚与 $\ell^1$ 梯度惩罚的定性差异
2. **揭示 TV 先验的保边优势**：TV 能保留锐利边缘，而 Sobolev 会过度平滑
3. **展示 TV 先验的阶梯效应局限**：借助合成斜坡信号无歧义地演示渐变区域的阶梯状伪影
4. **理解两种先验的适用场景**：Sobolev 适合平滑区域，TV 适合分段常数区域

### 实验输入

| 参数 | 设置 |
|------|------|
| 测试图像 | camera，$128 \times 128$ 像素 |
| 噪声模型 | 加性高斯白噪声，$\sigma = 0.1$ |
| Sobolev 参数 | $\lambda = 2.9$，调至其 SSIM 最优的去噪工作点 |
| TV 参数 | $\alpha = 0.08$，调至保边与去噪平衡的工作点 |
| 求解方法 | Sobolev：FFT 频域闭式解；TV：Chambolle 原始-对偶算法 |
| 合成信号（步骤2） | 一维"平台—线性渐变—平台—阶跃"信号，$m=128$、$\sigma=0.1$，Sobolev $\lambda=3.0$、TV $\alpha=0.08$ |

> **参数选择说明**：Sobolev 的 $\lambda$ 与 TV 的 $\alpha$ 量纲不同——$\lambda$ 惩罚 $\|\nabla \mathbf{x}\|_2^2$（二次惩罚），$\alpha$ 惩罚 $\|\nabla \mathbf{x}\|_1$（线性惩罚），二者数值不可直接比较。本实验将两者各自调至接近最优的去噪工作点（Sobolev $\lambda=2.9$、TV $\alpha=0.08$，后者是 PSNR 最优约 0.07 与 SSIM 最优约 0.09 的折中），以便在公平的噪声抑制水平下对比其边缘保持行为（Sobolev 磨边 vs TV 保边）。

### 预期结果

- TV 先验在边缘处表现优于 Sobolev：边缘更锐利，PSNR 和 SSIM 更高
- Sobolev 先验在平滑区域表现自然，但边缘模糊
- TV 先验在渐变区域会出现阶梯状伪影（staircase effect）
- 两种先验各有优劣，适用于不同类型的图像区域

#### TV 先验的特点总结

**优势**：
1. **保边性**：$\ell^1$ 惩罚对大梯度的代价是线性的，边缘不会被过度平滑
2. **稀疏性**：梯度稀疏假设对自然图像合理——大部分区域平滑，少数位置有边缘
3. **凸性**：优化问题可高效求解（近端方法、原始-对偶方法）

**局限**：
1. **阶梯效应**：渐变区域出现阶梯状伪影，因为 TV 偏好分段常数函数
2. **分段常数假设**：无法自然表示渐变、斜坡等缓慢变化的区域
3. **参数敏感**：$\alpha$ 需要仔细调节，过大导致过度阶梯化，过小导致去噪不足

**改进方向**：
- **TGV**（Total Generalized Variation，见附录2B）：引入二阶导数信息，允许分段仿射解，有效缓解阶梯效应
- **隐式先验**（见2.4节）：从数据中学习先验，而非手工设计正则项

## 四、三种先验的对比：从简到繁的递进

三种经典先验构成一个清晰的递进结构，每一层都是对上一层的修正：

| | 高斯先验 | Laplace 先验 | TV 先验 |
|---|---|---|---|
| **假设** | $\mathbf{x}$ 的值小 | $\mathbf{x}$ 的值稀疏 | $\nabla \mathbf{x}$ 稀疏 |
| **先验分布** | $\mathbf{x} \sim \mathcal{N}(0, \sigma_x^2 I)$ | $\mathbf{x} \sim \text{Laplace}(0, bI)$ | $\nabla \mathbf{x} \sim \text{Laplace}(0, bI)$ |
| **正则项** | $\|\mathbf{x}\|_2^2$ | $\|\mathbf{x}\|_1$ | $\|\nabla \mathbf{x}\|_1$ |
| **正则化方法** | Tikhonov / 岭回归 | LASSO / 稀疏正则化 | ROF / 全变差正则化 |
| **解的形态** | 平滑（所有值被均匀压缩） | 稀疏（小值被推到零） | 分段平滑（平坦+保边） |
| **函数空间** | $L^2$ / Sobolev $H^1$ | $\ell^1$ 稀疏空间 | BV（有界变差） |
| **边缘保持** | 不能（过度平滑） | 间接（需稀疏表示） | 直接保边 |
| **局限** | 过度平滑，丢边缘 | 需稀疏表示前提 | 阶梯效应 |

### 递进逻辑

```
高斯：假设"值小" → 平滑但丢边缘
  │
  │ 修正：从"值小"到"值稀疏"
  ▼
Laplace：假设"值稀疏" → 保稀疏但需稀疏表示前提
  │
  │ 修正：从"值稀疏"到"梯度稀疏"
  ▼
TV：假设"梯度稀疏" → 保边但有阶梯效应
```

每次修正都让假设更贴近真实图像的统计特性，但也让数学结构更复杂：Tikhonov 有闭式解，LASSO 需迭代优化（近端方法），TV 优化更复杂（原始-对偶方法）。同时每种先验都保留了前一种的某些局限——TV 解决了过度平滑，但引入新问题（阶梯效应）。从更深层次看，这条递进线索并非偶然的算法演化，而是"先验即结构化知识"这一思想的逐步展开：每前进一步，我们就把一条更真实的统计规律写进负对数密度，让解的形态被知识本身而非被计算便利所决定。

### 零点奇性的关键作用

高斯与 Laplace 的本质差异在于**零点处的概率集中**：
- **高斯分布**：$p(\mathbf{x})$ 在零点光滑可导，概率质量从零向两侧平缓扩散——没有"偏好零"的特殊力量。$\ell^2$ 正则项只能均匀缩小值，无法产生精确零。
- **Laplace 分布**：密度在零点不可导（尖峰/cusp），$p(\mathbf{x})$ 从两侧以指数速率衰减——零点处的"尖"意味着先验强烈偏好零。$\ell^1$ 正则项的软阈值效应（soft thresholding）将小值推到精确零。

这个差异解释了为什么 $\ell^1$ 促稀疏而 $\ell^2$ 不促稀疏——**零点奇性是稀疏性的概率根源**。这里所谓"奇性"，指的不是密度值无穷大（Laplace 在零点的密度 $1/(2b)$ 是有限值），而是密度及其负对数在零点不可导所形成的尖点：正是这个尖点，使 MAP 的最优性条件允许解精确落在零上。软阈值规则因此可以读作一条证据裁决准则：观测证据不足阈值时，先验对零的偏好压过数据，分量被判定为噪声而精确归零；观测超过阈值时，只有超出证据的部分被保留。TV 先验把这种零点奇性从像素空间转移到了梯度空间：梯度在零点有尖峰偏好，意味着大部分区域梯度被推到零（平滑），少数位置梯度非零（边缘）。

## 实验 2.2-4：经典先验族全景对比——高斯、Laplace 与 TV

实验 `2.2-4.py` 演示**三种经典先验（高斯、Laplace、TV）在同一去噪任务下的重建效果对比**，通过可视化重建图像、PSNR-lambda 扫描曲线和重建误差柱状图，全景展示"选先验就是选假设"的核心思想。

### 实验场景

实验考虑纯去噪问题：观测模型 $\mathbf{y} = \mathbf{x} + \varepsilon$，其中 $\varepsilon \sim \mathcal{N}(0, \sigma^2 I)$ 为加性高斯白噪声。在同一噪声水平下，分别施加三种先验并求解 MAP 估计：

**高斯先验（Tikhonov）**：假设 $\mathbf{x} \sim \mathcal{N}(0, \sigma_x^2 I)$，正则项为 $\|\mathbf{x}\|_2^2$。MAP 估计有闭式解：

$$\hat{x} = \frac{y}{1 + \lambda}, \quad \lambda = \frac{\sigma^2}{\sigma_x^2}$$

**Laplace 先验（LASSO）**：假设 $\mathbf{x} \sim \text{Laplace}(0, bI)$，正则项为 $\|\mathbf{x}\|_1$。MAP 估计为软阈值操作：

$$\hat{x}_i = \text{sign}(y_i) \cdot \max(|y_i| - \lambda, 0), \quad \lambda = \frac{\sigma^2}{b}$$

**TV 先验（ROF 模型）**：假设 $\nabla \mathbf{x} \sim \text{Laplace}(0, bI)$，正则项为 $\|\nabla \mathbf{x}\|_1$。MAP 估计通过 Chambolle 对偶投影算法迭代求解：

$$\min_x \frac{1}{2}\|\mathbf{x} - \mathbf{y}\|_2^2 + \lambda\,\text{TV}(\mathbf{x})$$

### 实验目的

1. **验证"选先验就是选假设"**：三种先验在同一任务下产生截然不同的重建结果，假设越贴近真实图像统计特性，效果越好
2. **展示 LASSO 在像素域的局限性**：自然图像的像素值本身不稀疏，直接在像素域施加 $\ell^1$ 正则化效果有限
3. **对比三种方法的 PSNR-lambda 曲线**：展示不同先验对正则化参数的敏感度和最优工作区间
4. **理解参数量纲差异**：$\|\mathbf{x}\|_2^2$、$\|\mathbf{x}\|_1$、$\|\nabla \mathbf{x}\|_1$ 作用于不同域（像素值 vs 梯度值），$\lambda$ 的数值大小不可直接对比

### 实验输入

| 参数 | 设置 |
|------|------|
| 测试图像 | camera，$128 \times 128$ 像素 |
| 噪声模型 | 加性高斯白噪声，$\sigma = 0.1$ |
| 高斯先验参数 | $\sigma_x = 1.0$，$\lambda = \sigma^2/\sigma_x^2 = 0.01$ |
| Laplace 先验参数 | $b = 0.5$，$\lambda = \sigma^2/b = 0.02$ |
| TV 先验参数 | $\lambda = 0.08$（手动调参），Chambolle 迭代 200 次 |
| PSNR 扫描 | $\lambda \in [10^{-4}, 10^1]$，30 个对数均匀采样点 |

> **参数量纲说明**：Tikhonov、LASSO 与 TV 三者的 $\lambda$ 分别作用于像素值 $\|\mathbf{x}\|_2^2$、像素值 $\|\mathbf{x}\|_1$、梯度 $\|\nabla \mathbf{x}\|_1$，量纲不同，$\lambda$ 数值大小不可直接对比。PSNR 数值仅在**同一方法内**不同 $\lambda$ 之间可比，跨方法对比 PSNR 需谨慎。实验另外计算了**梯度域 Tikhonov**（惩罚 $\|\nabla \mathbf{x}\|_2^2$，$\lambda=0.794328$）作为"同样利用梯度、但用二次惩罚"的对照，以区分"梯度域先验"与"$\ell^1$ 保边"两种收益来源。

### 预期结果

- TV 先验 PSNR 显著高于高斯和 Laplace 先验，因为"梯度稀疏"假设最贴近自然图像
- 高斯和 Laplace 先验 PSNR 接近，均显著低于 TV——两者假设（值小/值稀疏）对自然图像不够准确
- LASSO 在像素域的直接应用效果有限，验证了稀疏表示框架的必要性
- PSNR-lambda 曲线展示三种方法的不同敏感度：TV 曲线峰值更尖锐，对 $\lambda$ 更敏感

#### 步骤1：三种先验重建对比（图 2.21）

![图 2.21　三种先验对比](<./第二章 配套实验/实验2.2-4/步骤1_三种先验对比.png>)

**质量指标对比**：

| 方法 | 假设 | 正则项 | $\lambda$ | PSNR |
|------|------|--------|-----------|------|
| 含噪图像 | — | — | — | 19.97 dB |
| Tikhonov（高斯先验，像素域） | 值小 | $\|\mathbf{x}\|_2^2$ | 0.0100 | 20.05 dB |
| LASSO（Laplace 先验） | 值稀疏 | $\|\mathbf{x}\|_1$ | 0.0200 | 20.05 dB |
| Tikhonov（高斯先验，梯度域） | 梯度小 | $\|\nabla \mathbf{x}\|_2^2$ | 0.7943 | 26.18 dB |
| TV（TV 先验） | 梯度稀疏 | $\|\nabla \mathbf{x}\|_1$ | 0.0800 | **28.54 dB** |

结果分析：
- **TV 先验** PSNR 达到 28.54 dB，比像素域高斯/Laplace 高 **+8.49 dB**，验证了"梯度稀疏"假设对自然图像的适用性
- **梯度域是主要的收益来源**：同样只用梯度、但用二次惩罚的梯度域 Tikhonov 已达 26.18 dB（比像素域 Tikhonov 高 +6.13 dB）；TV 再靠 $\ell^1$ 的保边特性把 PSNR 推高到 28.54 dB（再 +2.36 dB）。可见"梯度域"贡献了大头，"稀疏/保边"贡献了剩余部分
- **高斯先验**和**Laplace 先验** PSNR 接近（20.05 dB），仅比含噪图像略好——两者的假设（值小/值稀疏）对自然图像像素值本身不够准确
- **LASSO 的局限性**：在像素域直接施加 $\ell^1$ 正则化，其软阈值在 $\lambda=0.02$ 时仅把约 $2.7\%$ 的暗像素推到零，对其余绝大多数像素只是施加一个不超过 $\lambda$ 的近常量整体下移，几乎不改变噪声结构——故 PSNR（20.05 dB）与含噪图像（19.97 dB）几乎持平，去噪能力名不副实。根因是自然图像的**像素值本身并不稀疏**（大部分像素显著非零），$\ell^1$ 找不到可牺牲的稀疏分量。这正是 LASSO 需要在变换域（小波、DCT）中使用的原因——自然图像只有在变换域下才近似稀疏
- 右下角剖面图清晰展示：TV 重建（红色）最贴近真实信号（黑色虚线），Tikhonov（蓝色）和 LASSO（绿色）偏离较大

#### 步骤2：正则项形态与性能对比（图 2.22）

![图 2.22　正则项形态与性能对比](<./第二章 配套实验/实验2.2-4/步骤2_正则项形态与性能对比.png>)

**左图：正则项形态对比**

对比了 L2（高斯先验）和 L1（Laplace/TV 先验）的惩罚函数形态：
- **L2（$t^2$）**：二次惩罚，对小值惩罚轻、对大值惩罚重——均匀压缩所有值
- **L1（$|t|$）**：线性惩罚，对所有非零值施加相同的单位梯度——小值被推向零，大值只受温和抑制

**中图：PSNR-lambda 曲线**

展示了四种方法在不同 $\lambda$ 下的 PSNR 变化：
- **Tikhonov（像素域，蓝色）**：曲线较平缓，对 $\lambda$ 不太敏感，最优 PSNR 约 20 dB
- **LASSO（绿色）**：曲线在 $\lambda \lesssim 10^{-2}$ 前基本平坦（贴合含噪基线），超过约 $10^{-2}$ 后快速跌落至地板——$\ell^1$ 软阈值对 $\lambda$ 敏感，$\lambda$ 稍大就会将过多像素推到零
- **Tikhonov（梯度域，橙色虚线）**：峰值明显高于像素域版本（$\lambda \approx 0.8$ 处约 26.2 dB），但用二次惩罚，边缘被磨圆
- **TV（红色）**：曲线有明显峰值，最优 $\lambda$ 附近 PSNR 达 **28.5 dB**，但偏离最优值后性能急剧下降
- **含噪基线（黑色虚线）**：PSNR 约 20 dB，Tikhonov 和 LASSO（像素域）仅略高于此线

**右图：重建误差（MSE）对比**

柱状图展示三种方法的均方误差：
- TV 的 MSE 最低（0.0014），约为像素域 Tikhonov（0.0099）和 LASSO（0.0099）的 **1/7**
- Tikhonov 和 LASSO 的 MSE 接近，印证了两者在像素域的直接应用效果有限

#### 三种先验的特点总结

| 特性 | 高斯先验（Tikhonov） | Laplace 先验（LASSO） | TV 先验（ROF） |
|------|---------------------|----------------------|----------------|
| 假设 | 图像值小 | 图像值稀疏 | 图像梯度稀疏 |
| 正则项 | $\|\mathbf{x}\|_2^2$ | $\|\mathbf{x}\|_1$ | $\|\nabla \mathbf{x}\|_1$ |
| 求解 | 闭式解 | 软阈值（闭式） | Chambolle 迭代 |
| 优点 | 计算高效，有闭式解 | 促稀疏，保留显著特征 | 同时平滑与保边 |
| 缺点 | 过度平滑，丢失边缘 | 像素域直接应用效果有限 | 可能产生阶梯效应 |
| 适用场景 | 简单去噪，计算资源受限 | 变换域稀疏表示 | 自然图像去噪，保边需求高 |

> **核心洞察**：本实验直观验证了 2.2 节的递进逻辑——从"值小"到"值稀疏"再到"梯度稀疏"，每一次假设修正都使先验更贴近真实图像的统计特性。TV 先验相对像素域高斯/Laplace 的显著优势（+8.49 dB）证明：**先验假设的质量直接决定重建效果的上限**；而梯度域 Tikhonov（26.18 dB）的存在进一步说明，这 +8.49 dB 中约 +6.13 dB 来自"把约束放到梯度域"，另有约 +2.36 dB 才来自 $\ell^1$ 的保边特性。同时，LASSO 在像素域的失败提醒我们：稀疏先验需要配合合适的稀疏表示框架才能发挥作用。

---
**选先验，就是选"你相信图像长什么样"——而选错了，不是数值算得不准，而是把错误的信念直接刻进了重建结果里。** 高斯信"平滑"、Laplace 信"稀疏"、TV 信"边缘"，每一种正则项背后都是一个关于图像形态的具体赌注；赌注越贴近真实图像统计，重建越好，反之则引入系统性偏差。这也意味着：手写先验的天花板，其实就是人类视觉直觉的编码能力——下一节我们会看到，这种能力终究是有限的。
