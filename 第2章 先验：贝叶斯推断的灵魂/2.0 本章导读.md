# 2.0 本章导读：先验——从正则化的"技巧"到概率推理的"灵魂"

上一章的结尾，我们得到了贝叶斯定理：

$$p(x|y) \propto p(y|x) \cdot p(x)$$

似然 $p(y|x)$ 说了"数据告诉我们什么"，但单靠似然无法解决不适定性。贝叶斯定理告诉我们：还需要另一条信息——先验 $p(x)$。它编码了我们在观测数据之外对 $x$ 的已有知识：图像倾向平滑、边缘稀疏、自然场景有特定统计规律……

取负对数，先验的概率身份立刻显形：

$$-\ln p(x|y) = \underbrace{-\ln p(y|x)}_{\text{数据项}} + \underbrace{-\ln p(x)}_{\text{正则项}} + \text{const}$$

原来，正则化中的正则项就是先验的负对数——先验不是什么神秘的概率论概念，而是我们早已熟悉的正则化的概率诠释。差别在于视角：正则化是在"猜"该加什么约束，而贝叶斯框架要求我们明确说出约束从何而来、意味着什么。

本章围绕"先验"展开四个层面的讨论：

**为什么需要先验**（2.1）：先验在数学上等价于正则项，在概念上则更深刻——它把正则化从经验性的"技巧"提升为有概率根基的"推理"。贝叶斯→变分的完整对应表将揭示两种语言之间的系统映射。

**有哪些先验可选**（2.2）：从高斯到Laplace再到TV，经典先验族从简到繁，每一种都编码了关于图像的一种假设，对应一种正则项。高斯假设"图像值小"，Laplace假设"图像值稀疏"，TV假设"图像梯度稀疏"——假设越贴近真实，正则化效果越好。

**先验质量如何评判**（2.3）：同一后验分布可以给出不同的估计——MMSE取后验均值，MAP取后验众数，两者仅在特殊情形下一致。更重要的发现是：**贝叶斯去噪器就是先验下的MMSE估计器**——先验决定去噪器，去噪器揭示先验。这一等价关系是后续Tweedie等式和PnP框架的根基。

**先验走向何方**（2.4）：经典先验受限于人为假设，无法捕捉真实图像分布的复杂性。从显式先验到学习型隐式先验的过渡，指向了全书的两个核心方向——通过得分匹配学习先验（第6章），通过变分推断学习先验（第9章）。

```
先验=正则项(2.1) → 经典先验族(2.2) → MMSE vs MAP与贝叶斯去噪器(2.3) → 从显式到隐式先验(2.4)
```

本章结束时，我们将拥有完整的贝叶斯推断框架：似然（第1章）+ 先验（本章）= 后验。接下来的问题变为：如何从后验中提取解？第3章走点估计路线（MAP→优化），第4章走分布采样路线（MCMC→ULA）——两条路终将在扩散模型处汇合。
