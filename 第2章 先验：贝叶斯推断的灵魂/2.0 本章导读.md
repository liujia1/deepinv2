# 2.0 本章导读：先验——从正则化的"技巧"到概率推理的"灵魂"

> "你以为你在调一个叫 λ 的旋钮，其实你在调的是你**对世界的信念**有多重。"

上一章结尾，我们好不容易拼出了贝叶斯定理这张"地图"：

$$p(x|y) \propto p(y|x) \cdot p(x)$$

左边是后验（观测之后你对 $x$ 的认识），右边第一项是似然（数据告诉你什么），第二项就是**先验** $p(x)$（数据之外，你本来就相信 $x$ 长什么样——图像偏好平滑、边缘稀疏……）。

第 1 章里我们已经给先验办了"身份证"：先说清它是什么、从物理约束/统计规律/专家知识这三大来源来，又演示了一个关键戏法——把先验取个负对数，它就摇身一变成了正则项；并拿"高斯先验叠高斯噪声 = Tikhonov 正则化"完整跑了一遍，最后还列了一张先验应用场景的对照表（高斯、Laplace、TV……）。本章要做的，是把这张表上的每一项都打开来细看：为什么偏偏是这几种先验、它们在各自的假设下会让图像长什么样、这些假设到底靠不靠谱，以及——如果靠人手写出来的假设终究不够用，我们能不能让数据自己告诉我们先验长什么样？

顺带再温习一下第 1 章见过的那个能量函数（它在全章会反复出场）：

$$-\ln p(x|y) = \underbrace{-\ln p(y|x)}_{\text{数据项}} + \underbrace{-\ln p(x)}_{\text{正则项}} + \text{const}$$

**所谓正则化里那个神秘的"正则项"，扒开外衣就是先验的负对数。** 先验一点也不玄乎——它就是各种正则化方法的"概率版身份证"。差别只在视角：以前你拍脑袋"加个约束"，现在你得说清楚"我到底相信 $x$ 长什么样、凭什么这么信"。第 1 章我们只用最简单的高斯先验演示了一遍；2.1 节会把这层关系推广到任意指数族先验，并给你一张"贝叶斯 ↔ 变分"的完整对照表，让你看清"概率"和"优化"其实是同一枚硬币的两面。2.1 节还会用一个抛硬币的小算例，把先验的分量直观地称出来：就算你真抛了 10 次、7 正 3 反，一个 Beta(5,5) 先验也能把结论从 0.7 硬拽回 0.6。

本章我们沿着"先验"这条线，从四个层面一层层剥开：

**① 先验的数学角色（2.1 节）**。任意指数族先验，一旦取负对数就会自动裂成"数据项 + 正则项"，所以"概率推理 ≡ 优化"不是巧合，而是结构性的必然。配合那个抛硬币游戏，你会第一次看清：正则化调参的每一个旋钮，背后其实都是一次"我有多信数据、又有多信自己的经验"的表态。

**② 有哪些先验可选（2.2 节）**。从最简单的高斯，到 Laplace，再到 TV（全变差），经典先验族由简到繁排开，每一种都对应一条关于"图像长什么样"的假设，也对应一种正则项：高斯偏爱"值小"、Laplace 偏爱"值稀疏"、TV 偏爱"梯度稀疏"——假设越贴近真实图像，正则化的效果就越好。

**③ 先验好不好怎么评判（2.3 节）**。面对同一个后验分布，你可以取它的均值（MMSE 估计），也可以取它的峰值（MAP 估计），两者通常不是一回事。我们还会撞见一个惊掉下巴的等式：**贝叶斯去噪器，其实就是该先验下的 MMSE 估计器**——先验决定了去噪器，反过来去噪器又泄露了先验。这条线后面会直接通往 Tweedie 等式和 PnP 框架。

**④ 先验往哪走（2.4 节）**。手工编写的先验终究有天花板：真实图像太复杂，写不出一个漂亮的闭式分布来。于是人们很自然地转向"从数据里学先验"——隐式先验就此登场，也为全书的扩散模型、VAE 埋下了伏笔。

```
先验=正则项(2.1) → 经典先验族(2.2) → MMSE vs MAP 与贝叶斯去噪器(2.3) → 从显式到隐式先验(2.4)
```

读完本章，你会手握完整的贝叶斯推断框架：**似然（第1章）+ 先验（本章）= 后验**。剩下的问题只是：怎么从这个后验里把解"取"出来？第3章走点估计路线（MAP → 优化），第4章走分布采样路线（MCMC → ULA）——两条路，最后在扩散模型处汇合。


---


把整章塌缩成一句话：**先验不是你硬塞给算法的"额外假设"，它就是正则化本身的真实身份——正则项不过是先验的负对数。** 一旦你承认这一点，正则化就从"拍脑袋调参的玄学"变成了"有概率根基的推理"。这也正是我们整本书的支点：后面所有的去噪器、扩散模型、得分函数，追根溯源都是在回答同一个问题——"你到底相信图像长什么样？"
