# 2.0 本章导读：先验——从正则化的"技巧"到概率推理的"灵魂"

> "你以为你在调一个叫 λ 的旋钮，其实你在调的是你**对世界的信念**有多重。"

上一章结尾，我们好不容易拼出了贝叶斯定理这张"地图"：

$$p(x|y) \propto p(y|x) \cdot p(x)$$

左边是后验（观测之后你对 $x$ 的认识），右边第一项是似然（数据告诉你什么），第二项就是**先验** $p(x)$（数据之外，你本来就相信 $x$ 长什么样——图像偏好平滑、边缘稀疏、自然场景有固定套路……）。

但上一章我们只给先验留了一句话："你事先的信念"。这太草率了。你想想：一个逆问题之所以"不适定"（解不唯一、不连续），正是因为**只靠数据（似然）不够**。那凭什么你随便加一个"信念"进去，问题就变好了？这个信念从哪来、凭什么信它、加多加强合适？——这就是本章要彻底讲清楚的事。

先给你吃一颗定心丸。我们对后验取个负对数（别慌，这就是把"乘积"变成"求和"，概率相乘变能量相加），先验的身份立刻现原形：

$$-\ln p(x|y) = \underbrace{-\ln p(y|x)}_{\text{数据项}} + \underbrace{-\ln p(x)}_{\text{正则项}} + \text{const}$$

看明白了吗？**正则化里那个神秘的"正则项"，其实就是先验的负对数**。所谓先验，一点都不玄乎——它就是你在第 1 章就见过的各种正则化方法的"概率版身份证"。差别只在视角：以前你拍脑袋"加个约束"，现在你得说清楚"我到底相信 $x$ 长什么样、为什么这么信"。

本章我们沿着"先验"这条线，从四个层面一层层剥开：

**① 为什么需要先验（2.1）**。先验在数学上就是正则项；但更深刻的在于，它把正则化从"经验技巧"升级成了"有概率根基的推理"。我们会给出一张"贝叶斯 ↔ 变分"完整对照表，让你看到两套语言其实是同一个东西。

**② 有哪些先验可选（2.2）**。从最简单的高斯，到 Laplace，再到 TV（全变差），经典先验族由简到繁，每一种都对应一条关于图像"长什么样"的假设，也对应一种正则项：高斯说"值要小"、Laplace 说"值要稀疏"、TV 说"梯度要稀疏"——假设越贴近真实图像， regularization 效果越好。

**③ 先验好不好怎么评判（2.3）**。同一个后验分布，你可以取均值（MMSE 估计），也可以取峰值（MAP 估计），两者通常不一样。我们还会发现一个惊掉下巴的等式：**贝叶斯去噪器，就是该先验下的 MMSE 估计器**——先验决定去噪器，去噪器反过来揭露先验。这条线直接通向后面的 Tweedie 等式和 PnP 框架。

**④ 先验往哪走（2.4）**。手写先验终究有天花板：真实图像太复杂，写不出一个漂亮分布来。于是自然走向"从数据里学先验"——隐式先验登场，也为全书的扩散模型、VAE 埋下伏笔。

```
先验=正则项(2.1) → 经典先验族(2.2) → MMSE vs MAP 与贝叶斯去噪器(2.3) → 从显式到隐式先验(2.4)
```

读完本章，你会手握完整的贝叶斯推断框架：**似然（第1章）+ 先验（本章）= 后验**。剩下的问题只是：怎么从这个后验里把解"取"出来？第3章走点估计路线（MAP → 优化），第4章走分布采样路线（MCMC → ULA）——两条路，最后在扩散模型处汇合。

**路标**：上一章（1.5）把后验写成"后验 ∝ 似然 × 先验 ÷ 证据"，但先验只是"你事先的信念"一句话带过 → 本章深讲"为什么先验是贝叶斯的灵魂" → 下一章（第3章）把"先验=正则化"变成可求解的优化问题。

---

## 收尾：为什么这件事重要

把整章塌缩成一句话：**先验不是你硬塞给算法的"额外假设"，它就是正则化本身的真实身份——正则项不过是先验的负对数。** 一旦你承认这一点，正则化就从"拍脑袋调参的玄学"变成了"有概率根基的推理"。这也正是我们整本书的支点：后面所有的去噪器、扩散模型、得分函数，追根溯源都是在回答同一个问题——"你到底相信图像长什么样？"

> 小提示：本章所有"公式"都是给直觉打标点的，不是骨架。你就算把公式全遮住，也应该能顺着故事读下去。实验部分（含图片）我们原样保留，方便你对照代码和结果。
