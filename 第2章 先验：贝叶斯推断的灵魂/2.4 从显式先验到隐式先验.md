# 2.4 从显式先验到隐式先验

> 你有没有过这种体验：给朋友描述"什么样的照片好看"，嘴巴说了一大堆——"要清晰、要自然、边缘别糊"——结果他拍出来还是不对。原因很简单：**有些东西你心里知道，但说不出精确的公式。** 图像的"先验"恰恰就是这种东西。

承接 2.2 和 2.3：我们巡览了三种经典先验——高斯、Laplace、TV，也看到同一先验下 MMSE 与 MAP 的分歧、以及"去噪器即先验下 MMSE 估计器"的关键等式。现在退后一步，审视更根本的问题：**经典先验的表达能力，存在天花板吗？**

答案是肯定的。三种经典先验的局限，根源都在同一个问题：**必须预先指定分布形式**。

- **高斯先验**假设 $x$ 的分量独立、服从高斯分布——但自然图像的像素值既不独立也不高斯。$\ell^2$ 只能均匀压缩值，无法区分"该保留的边缘"与"该抑制的噪声"。
- **Laplace 先验**假设分量独立、服从 Laplace 分布——稀疏性假设比高斯合理，但需要图像在某个变换域下确实稀疏。选错变换域，Laplace 就强制引入不合理的稀疏性。
- **TV 先验**假设 $\nabla x$ 稀疏——比 Laplace 更接近自然图像梯度统计，但"梯度稀疏"等价于"分段常数"，在渐变区域产生阶梯效应。

但是**真实图像的统计分布远比高斯、Laplace 或任何手工参数化分布复杂。** 无论怎么调参，高斯假设无法捕捉稀疏性，Laplace 无法保边，TV 无法处理渐变。这不是参数选择问题，而是**模型表达能力**的根本局限。

更深层地，显式先验还面临三个实践困难：
1. **依赖领域知识**：选高斯还是 Laplace 还是 TV，本身需专业判断。医学、遥感、自然照片最合适的先验可能不同——如何系统选择？
2. **参数需手动调**：$\lambda$ 最优值通常靠 L-曲线法、交叉验证等启发式确定，缺自适应性。噪声水平一变，$\lambda$ 需重调。
3. **无法捕捉高阶统计**：经典先验只编码低阶统计（一阶矩、梯度稀疏性），但自然图像统计包含丰富高阶结构——纹理周期性、物体形状先验、场景语义约束——远超高斯或 Laplace 的表达能力。

从发展脉络来看，简单手工正则项必须被改进。方向正是从人为指定走向数据驱动——**让数据自己告诉我们先验长什么样。**

**本章目标**：
- 看清显式先验的"天花板"在哪
- 理解一条从"完全手工"到"完全数据驱动"的过渡谱系
- 认识半学习先驱 FoE / TDV，以及三种隐式先验（GAN / VAE·流 / PnP）各自的作用机制与适用边界
- 体会到：当图像太复杂写不出显式分布时，把训练好的（扩散）模型当作先验

## 一、从显式到隐式：一条过渡谱系

从完全手工的显式先验到完全数据驱动的隐式先验，不是一蹴而就的跳跃，而是渐进谱系。按"人为指定"与"数据学习"的比例，可排为三阶段：

| | **完全显式** | **半学习** | **完全隐式** |
|---|---|---|---|
| **先验类型** | 手工先验 | 参数化先验 | 深度生成模型 |
| **代表方法** | 高斯 / Laplace / TV | FoE → TDV | VAE / 得分匹配 / 扩散模型 |
| **人为指定** | 完全人为指定 | 学习滤波器/CNN参数 | 学习完整分布 |
| **适应性** | 无法适应数据 | 结构固定、参数需要学习 | 结构和参数都从数据学习 |

谱系上每一步，都是对"人为假设"的进一步解放：显式先验中，分布形式和参数都由人指定；半学习先验中，形式由人指定，关键参数从数据学；隐式先验中，形式和参数都从数据学——我们不再假设图像服从某已知分布族，而是让模型自己发现数据中的统计规律。

下面依次看谱系上两个关键节点。

## 二、Fields of Experts（专家场）：半学习的先驱

### 动机：从自然图像统计到 Student-t 势函数

经典先验的局限引发追问：自然图像的滤波器响应到底服从什么分布？大量的统计实验表明——自然图像的零均值滤波器响应，边缘分布呈**重尾分布**（heavy-tailed），远比高斯尾部衰减缓慢。这意味着：大部分位置响应很小（平滑区域），少数位置响应很大（边缘和纹理）——介于 Laplace 和高斯之间。

高斯先验的 $\ell^2$ 对大响应过度惩罚（尾部衰减太快），Laplace 的 $\ell^1$ 对所有非零响应施加相同线性惩罚（不够灵活）。更贴合实验数据的，是 **Student-t 分布——一种经典的重尾分布**。

2.1 节中我们已经建立过一个关键等式——**先验 = 正则项**。某个分布的负对数，正是优化里可以直接相加的"能量项 / 惩罚项"。换句话说：

$$\underbrace{p(t)}_{\text{概率密度}} \quad\xleftrightarrow[-\log]{\text{取负对数}}\quad \underbrace{\rho(t)=-\log p(t)}_{\text{势函数（能量项）}}$$

这里的 $\rho(t)$ 就是**势函数（potential function）**：它把"响应服从 Student-t 分布"这一概率假设，转化为"对大响应施加对数级惩罚"的能量约束。在 FoE 中，$\rho$ 是正则项里**针对每一个滤波器响应的核心代价单元**（总惩罚是所有响应的 $\rho$ 求和）。用一句话记住二者的角色区别：

> **Student-t 分布描述"数据长什么样"，Student-t 势函数描述"模型怎么罚"——前者是概率，后者是前者取负对数得到的能量。**

把 Student-t 分布取负对数，并允许乘一个缩放系数 $\alpha_k$ 调节惩罚强度（ FoE 需要的自由度），就得到专门用于惩罚滤波响应的势函数：

$$\rho_k(t) = \alpha_k \log(1 + |t|^2)$$

> 标准 Student-t 密度的负对数为 $\frac{\nu+1}{2}\log(1 + t^2/\nu)$，FoE 取自由度 $\nu=1$ 将其简化为 $\log(1+t^2)$，再乘可学缩放 $\alpha_k$ 得到上式。

它在零点平滑（不像 Laplace 不可导），但尾部衰减远比高斯缓慢——恰好匹配自然图像滤波器响应的重尾特征。由于多了 $\alpha_k$ 这个缩放，它其实是比标准 Student-t 分布族**更宽**的一族"Student-t 型势函数"；它常被简称为 Student-t 势函数，记住它和"Student-t 分布"是同一件事的负对数两面即可。

### FoE 模型

**Fields of Experts（FoE）** 模型正是将 Student-t 势函数纳入结构化先验的自然载体。它不再依赖单一固定的正则项，而是构建一组可学习的滤波器-势函数对（即experts/专家组），每个专家独立捕获某一类局部结构的重尾统计特性，并通过乘积形式在全局上聚合这些局部约束。具体而言，FoE 先验定义为：

$$p(x) \propto \exp\!\Big(-\sum_{k=1}^{K}\sum_{i,j} \rho_k\big((K_k x)_{i,j}\big)\Big)$$

其中：
- $K_k$ 是第 $k$ 个线性算子，实现与滤波器 $f_k$ 的 2D 卷积：$(K_k x)_{i,j} = (f_k * x)_{i,j}$
- $\rho_k(t) = \alpha_k \log(1 + |t|^2)$ 是 Student-t 型势函数（前述 Student-t 分布取负对数再加缩放得到）
- 可学习参数汇总为 $\theta = \{(\alpha_k, f_k)\}_{k=1}^{K}$

对应正则项：

$$R_\theta(x) = \sum_{k=1}^{K}\sum_{i,j} \rho_k\big((K_k x)_{i,j}\big)$$

仔细观察，FoE 框架可以通过选择不同的势函数，包含 TV、二次平滑等经典先验：
- 若 $K = 1$，$f_1$ 为有限差分滤波器，$\rho_1(t) = |t|$，FoE 退化为 TV 先验
- 若 $\rho_k(t) = t^2$，FoE 退化为 Sobolev 平滑先验
- Student-t 势函数则提供了一种具有重尾特性的非凸先验——零点附近接近二次（高斯行为），远处趋于对数增长（重尾行为），介于两者之间

FoE 的关键创新：**滤波器 $f_k$ 和势函数参数 $\alpha_k$ 不再由人指定，而是从数据中学习。** 这意味着先验不再是固定数学假设，而是可根据训练数据自适应调整的参数化模型。

### 学习方法：双层优化

FoE 参数通过**双层优化**（bilevel optimization）学习。给定训练数据 $\{(y_i, x_i^*)\}_{i=1}^n$（$y_i$ 含噪观测、$x_i^*$ 真实图像），双层优化：

$$\min_\theta \; \frac{1}{n}\sum_{i=1}^n \ell(x_i^*, \hat{x}_i), \quad \text{s.t.} \;\; \hat{x}_i \in \arg\min_x R_\theta(x) + \frac{1}{2}\|x - y_i\|_2^2$$

上层最小化重建误差 $\ell$，下层求解正则化模型最优解。关键技术挑战：如何计算损失对参数 $\theta$ 的梯度？

答案是**隐微分**（implicit differentiation）。当下层目标关于 $x$ 强凸且二阶连续可微时，可把下层优化替换为一阶最优性条件：

$$\sum_{k=1}^{K} K_k^* \phi_k(K_k \hat{x}) + \hat{x} - y = 0$$

其中 $\phi_k(t) = \text{diag}(\ldots, \rho_k'(t_{ij}), \ldots)$ 是势函数导数。引入拉格朗日乘子 $p$ 可解出 $\theta$ 的梯度——这就是隐微分核心思想。

Chen, Ranftl 和 Pock（2014）用此方法在约 200 张图像库上学了 80 个 $9 \times 9$ 滤波器及对应势函数参数，共 6480 个参数。学出的滤波器呈现多种方向和频率的特征检测模式——水平、垂直、对角线边缘检测器，不同尺度纹理检测器。这些滤波器不是人为设计的，而是从数据自动涌现的，验证了 FoE "让数据说话"的理念。

## 实验 2.4-1：FoE 半学习先验的去噪验证

本实验配套代码位于 `第二章 配套实验/实验2.4-1/2.4-1.py`（FoE 双层优化去噪，Chen, Ranftl 和 Pock 2014 简化复现）。

### 实验场景

经典先验（高斯 / Laplace / TV）的形态完全由人指定，无法适应真实图像复杂统计。本实验置身于"让数据自己决定先验参数"的场景：用一组可学习的局部滤波器与 Student-t 势函数权重，让模型从噪声—干净配对数据中自动涌现出"什么样的局部结构更自然"。具体任务为图像去噪——这是检验一个先验是否有效的天然试验场：先验越好，去掉的噪声越多、保住的结构越完整。

实验采用**本地合成几何数据集**：训练集为 128 张 64×64 含"方框 + 横 / 竖 / 对角 / 反对角线段"的图块，测试图为同分布的一张合成几何图；加性高斯噪声 $\sigma=0.12$。CPU/GPU 均可运行，无需下载任何权重。实验固定随机种子（seed=42），构造一个"未训练的随机初始化模型"作为训练前对照，与训练 30 轮后的模型做确定性对比。

### 实验目的

1. **验证 FoE 的"半学习"理念**：滤波器 $f_k$ 与势函数权重 $\alpha_k$ 从数据中自动学习，而非手工指定
2. **复现双层优化流程**：外层以 unrolled 去噪结果逼近真值为监督、用梯度反传学专家参数；内层固定参数、用展开式梯度下降求去噪解 $\hat{x}$
3. **观察学得的专家滤波器**：6 个 7×7 滤波器是否从随机初始化收敛为具有方向选择性（水平 / 垂直 / 对角线）的基元
4. **验证"半学习"增益**：对比训练前（随机先验）与训练后（学得的先验）的去噪质量，证明从数据学出的先验优于随机先验

### 实验输入

| 参数 | 值 |
|------|------|
| 问题 | 图像去噪（含噪观测 $y$ → 估计 $\hat{x}$） |
| 推理测试图像 | 本地合成几何图，64×64（方框 + 多方向线段） |
| 噪声模型 | 加性高斯白噪声，$\sigma = 0.12$ |
| 训练数据 | 本地合成几何图块 128 张，64×64（方框 + 横 / 竖 / 对角 / 反对角线段） |
| 专家数量 | $K = 6$ 个滤波器 |
| 滤波器尺寸 | $7 \times 7$ |
| 下层迭代步数 | 训练时展开 25 步（步长 0.2），测试时展开 50 步（步长 0.15） |
| 势函数 | Student-t 势 $\rho_k(t) = \alpha_k \log(1 + t^2)$，先验能量 $E_{\text{prior}}=\sum_k \alpha_k \log(1 + \lVert f_k * x\rVert^2)$；总能量 $E = \tfrac12\lVert x-y\rVert^2 + \lambda E_{\text{prior}}$，$\lambda = 0.01$ |
| 训练策略 | 双层优化：外层重建误差驱动更新 $f_k,\alpha_k$；30 epoch，batch=16，Adam；每 epoch 保存权重并支持断点续训；最终权重存在时直接加载跳过训练 |

### 预期结果

1. **去噪有效**：含噪输入 PSNR 约 18 dB，训练后去噪显著提升（接近干净真值），且明显优于训练前随机先验
2. **滤波器方向性**：6 个学得的 7×7 滤波器从随机初始化收敛为水平 / 垂直 / 对角等方向选择性基元
3. **响应与能量对齐**：训练后特征响应图在图像结构边缘处激活更强、联合惩罚能量图更集中，说明学得的先验与图像内容一致
4. **能量单调下降**：展开式 MAP 推断过程中，后验能量 $E(x_t)$ 随迭代步持续下降并收敛（见图 3）
5. **双层优化闭环成立**：外层学到的滤波器改变内层 unrolled 推断的梯度场（见响应图与能量图）

### 核心结论

本实验把本章 2.4 的抽象论点变成了可运行事实：

- **"让数据说话"得到验证**：滤波器与 $\alpha_k$ 全部从本地合成几何数据块学出，而非手工指定；学得的滤波器呈现方向选择性，呼应原文"学出的滤波器不是人为设计的，而是从数据自动涌现的"。
- **双层优化闭环成立**：外层重建误差驱动参数更新、内层展开式梯度下降求解，二者经自动微分打通；训练后 PSNR 较训练前随机先验提升 2.84 dB，证明"半学习"带来的增益。
- **与本章原规模差异（教学取舍）**：原论文学 80 个 $9 \times 9$ 滤波器（6480 参数、训练耗时约两周）；本实验为教学演示用 6 个 $7 \times 7$ 滤波器 + 本地合成数据，规模更小、可在单卡数分钟完成，结论方向一致但表达容量较低。
- **求解器实现说明**：本实验的下层用"展开式 MAP + 端到端自动微分"实现，未采用本章正文所述的隐微分（implicit differentiation）梯度技巧；隐微分将在第 10/11 章展开。这不影响本章结论的演示，但读者应知道两者在梯度计算路径上的区别。

### FoE 的意义与局限

**意义**：FoE 是显式与隐式先验的桥梁——保留"可解释的先验结构"（卷积滤波器 + 势函数形式由人指定），但关键参数由数据驱动。这标志着先验设计从"完全人为指定"走向"数据驱动"的第一步。

**局限**：FoE 表达能力仍受参数化形式限制。先验结构（卷积 + Student-t 势函数）是人为选定的，只有滤波器系数和势函数参数可从数据学。这意味着 FoE 无法捕捉超越其参数化形式的高阶统计结构——正如高斯无法捕捉稀疏性，FoE 的参数化形式也设定了表达上限。

此外，FoE 双层优化训练计算量大（Chen 等人报告训练耗时两周），且学出的正则项通常非凸，给优化带来额外困难。

作为 FoE 进一步发展，Kobler, Effland, Kunisch 和 Pock（2020）提出 **Total Deep Variation（TDV）**——基于 CNN 的学习型正则项：

$$\text{TDV}(x, \theta) = \sum_{i,j} r_{i,j}(x, \theta)$$

其中 $r(x, \theta) = \Psi(w \cdot N(Kx))$，$K$ 是学习的 $3 \times 3$ 卷积核（32 通道），$N$ 是多尺度 CNN，$w$ 是 $1 \times 1$ 卷积核，$\Psi$ 是势函数。TDV 在保持"正则项"结构同时，用 CNN 替代 FoE 手工势函数——$\sigma = 25$ 去噪实验中，TDV-VN 达 32.81 dB，而 TV 仅 29.91 dB，提升近 3 dB。TDV 代表半学习先验的极致：正则项"结构"（像素级求和）仍由人指定，但内部滤波、非线性变换全部由数据学。

> **FoE 的启示**：FoE 证明了一个重要原则——**先验的参数可从数据学，无需人为指定**。但 FoE 及其改进（TDV）也表明，仅学参数甚至特征提取器，仍受"正则项"人为框架限制。能否彻底放弃先验形式假设，让数据完全决定先验"形状"？这就是从半学习走向完全隐式的驱动力。

## 三、深度生成模型：完全隐式先验

### 从学习参数到学习分布

FoE 迈出从显式到隐式的第一步，但参数化形式仍限制表达。下一步自然的问题：**能否让模型不仅学参数，还学分布的形式本身？**

深度生成模型正是这一思路的实现。它们不再假设先验 $p(x)$ 属某已知分布族，而是通过神经网络参数化一个灵活分布族，从训练数据学完整分布。

学习正则化函数的方法可以分为两条根本不同的路线：
1. **判别式（任务驱动）学习**：直接学后验

   $$p_\theta(x\mid y) \propto \exp\!\bigl(-R_\theta(x) - D_\theta(x, y)\bigr)$$

   ——从观测 $y$ 直接到估计 $\hat{x}$，跳过先验建模。这里 $R_\theta(x)$ 是先验/正则能量，$D_\theta(x,y)$ 是**数据保真项**（data-fidelity，衡量 $x$ 与观测 $y$ 的吻合程度，如 $\tfrac12\|x-y\|_2^2$）。这类方法（如 AUTOMAP、端到端网络）性能强，但**忽略正向算子的物理知识**，泛化性受限。

   > 注意：此处的 $D_\theta(x,y)$（数据保真项）与 2.3 节的 $D_\sigma(y)$（去噪器 denoiser）**字母相同但含义不同**——后者是把观测映射为估计的函数，前者是能量中的一项。阅读时请注意区分。
2. **生成式（任务无关）学习**：学先验 $p_\theta(x) \propto \exp(-R_\theta(x))$，再用于贝叶斯框架 $p(x|y) \propto p(y|x) p_\theta(x)$——先验与似然解耦，学到的先验可用于**任何**成像模态。这正是本书主线方向。

本节关注生成式路线中三种代表性方法。

### 合成式方法：GAN 先验

**生成对抗网络**（GAN）是一种隐式定义分布的方法：训练生成器 $G_\theta: \mathbb{R}^p \to \mathbb{R}^d$，把低维隐变量 $z \sim \mathcal{N}(0, I_p)$ 映射到图像空间，使 $G_\theta(z)$ 分布近似训练数据分布。

GAN 训练通过生成器与判别器的对抗博弈实现：生成器试图产生逼真图像，判别器试图区分真实与生成图像。训练目标为极小极大博弈：

$$\min_G \max_D \; \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)] + \mathbb{E}_{z \sim p_Z}[\log(1 - D(G(z)))]$$

可证明，当判别器最优时，GAN 目标函数等价于数据分布 $p_{\text{data}}$ 与生成分布 $p_G$ 之间的 **Jensen-Shannon 散度**——最小化这一散度，就是让生成分布逼近真实分布。

GAN 作为先验的优势：**训练与成像模态无关，不需要配对噪声-干净数据**。一旦训练完成，GAN 先验可用于任何逆问题——去噪、去模糊、修复、MRI 重建——只需在隐空间求解：

$$\hat{z} = \arg\min_{z \in \mathbb{R}^p} \frac{1}{2}\|AG_\theta(z) - y\|_2^2, \quad \text{s.t.} \;\|z\| \leq \sqrt{p}$$

重建图像 $\hat{x} = G_\theta(\hat{z})$。Bora 等人（2017）和 Narnhofer 等人（2019）将这一方法成功用于 MRI 重建等实际问题。

但 GAN 先验有根本性局限：**生成器定义的分布是隐式的**——无法计算 $p_G(x)$ 的值，也无法直接采样后验 $p(x|y)$。GAN 只能提供 MAP 类型点估计，无法量化不确定性。此外，GAN 训练中的**模式坍缩**（mode collapse）意味着生成分布可能只覆盖真实分布一部分，导致重建多样性不足。

### 生成式先验：VAE 和流模型

为克服 GAN 局限，Pereyra 等人探索了基于 VAE 和归一化流的生成式先验，并建立严格贝叶斯推断框架。

核心思想是**流形假设**：自然图像近似分布在一个低维流形上。设图像 $x \in \mathbb{R}^d$，引入低维隐变量 $z \in \mathbb{R}^p$（$p \ll d$），通过映射 $\nu_\theta: \mathbb{R}^p \to \mathbb{R}^d$（神经网络实现），把标准正态分布 $z \sim \mathcal{N}(0, I_p)$ 推送到图像空间，近似训练数据分布。

给定生成式先验 $\nu_\theta$ 和似然 $p(y|x)$，后验：

$$p(z|y) = \frac{p(y|x = \nu_\theta(z)) \, p(z)}{p(y)}$$

将 $(z|y)$ 通过 $\nu_\theta$ 推送，即得到图像空间后验 $(x|y)$。Holden, Pereyra 和 Zygalakis（2022）证明此后验在 Hadamard 意义下适定，且具有限矩——为生成式先验的贝叶斯推断提供理论基础。

MNIST 数据集上的实验揭示几个重要现象：
1. **流形维度识别**：当隐空间维度 $p \approx 12$ 时，先验编码信息趋于饱和——增加维度不再显著提升性能。这表明 MNIST 图像有效维度远低于像素空间维度 $d = 784$，验证流形假设。
2. **MMSE vs MAP 的差异**：去噪、修复、去模糊任务中，高噪声下 MMSE（后验均值）显著优于 MAP——如 $\sigma = 0.25$ 去模糊任务，MMSE PSNR 达 24.41 dB，MAP 仅 15.20 dB。印证 2.3 结论：高噪声下后验高度非高斯，MMSE 利用后验完整信息，MAP 只看众数。
3. **分布外检测**：通过边际似然 $\log p(y)$ 可有效区分分布内与分布外观测——为生成式先验提供天然异常检测机制。

为将生成式先验扩展到高维，Pereyra 等人进一步提出**条件生成式先验**：给定侧信息 $u$（如低分辨率版本），条件模型 $x = \nu_\theta^u(z)$ 将先验约束在与观测一致的子空间内，大幅降低学习难度。用归一化流实现的条件模型，在图像去模糊和全色锐化等任务上取得优于 PnP-ADMM 的结果。

### Plug-and-Play 先验：去噪器即先验

PnP（Plug-and-Play）代表一种独特隐式先验策略——它不显式定义 $p(x)$，而是通过预训练去噪器 $D_\epsilon$ 间接编码先验信息。

PnP 思想源于正则化优化的**近端算子**（proximal operator）。前向-后向分裂算法中：

$$x^{k+1} = \text{prox}_{\tau R}\!\big(x^k - \tau A^*(Ax^k - y)\big)$$

近端算子定义为：

$$\text{prox}_{\tau R}(v) = \arg\min_x \left\{R(x) + \frac{1}{2\tau}\|x - v\|_2^2\right\}$$

仔细观察：**近端算子就是在先验 $p(x) \propto \exp(-R(x))$ 和噪声水平 $\tau$ 下的 MAP 去噪器**——它对输入 $v$ 施加先验约束，输出最可能的去噪结果。

PnP 核心操作：**用预训练去噪器 $D_\epsilon$ 替换近端算子**：

$$x^{k+1} = D_\epsilon\!\big(x^k - \tau A^*(Ax^k - y)\big)$$

去噪器 $D_\epsilon$ 可手工设计（如 BM3D），也可深度学习（如 DnCNN）。关键洞察来自 2.3 节建立的"去噪器 ↔ 先验"映射（Tweedie 等式，第5章详述）：若 $D_\epsilon$ 近似真实分布下 oracle MMSE 去噪器 $D_\epsilon^*$，则：

$$\epsilon \nabla \log p_\epsilon^*(x) = D_\epsilon^*(x) - x$$

去噪器残差 $D_\epsilon(x) - x$ 正比于先验得分函数——**去噪器隐式编码了先验的梯度信息**。

Pereyra 等人建立 PnP 严格贝叶斯基础：PnP-ULA 以几何速率收敛到 oracle 后验 $p_\epsilon^*(x|y)$ 邻域，精度取决于 $D_\epsilon$ 对 $D_\epsilon^*$ 的近似程度；PnP-SGD 收敛到 oracle 后验临界点邻域。这些收敛保证只需 $D_\epsilon$ 是 Lipschitz 连续（通过谱归一化实现），不要求它是梯度算子或近端算子——比早期 PnP 要求宽松得多。

PnP 先验独特之处：**它绕过了显式建模 $p(x)$ 的困难**。我们无需写出先验解析形式，也无需算归一化常数——只需训练一个好的去噪器，即可间接利用数据驱动先验信息。这一策略在第5章 PnP 框架中进一步展开。

### 实验：PnP 先验 vs 显式先验

#### 实验目的

1. **验证 PnP 的核心思想**：用去噪器替换近端算子，实现隐式先验
2. **对比显式先验与隐式先验**：Tikhonov（L2）、TV（L1梯度）vs PnP（去噪器）
3. **理解去噪器类型与数据驱动的关系**：手工设计 vs 数据驱动

#### 实验输入

| 参数 | 设置 |
|------|------|
| 问题 | 图像去模糊 |
| 测试图像 | 嵌套矩形，$64 \times 64$ 像素 |
| 模糊核 | 高斯模糊，$5 \times 5$，$\sigma = 1.0$ |
| 噪声水平 | $\sigma = 0.05$ |
| Tikhonov 参数 | $\lambda = 0.01$ |
| TV 参数 | $\lambda = 0.05$，迭代 100 次 |
| PnP 去噪器 | 邻域自适应加权平均（手工设计，非数据驱动） |
| PnP 参数 | $\tau = 0.2$ |

#### 预期结果

- Tikhonov：闭式解，计算快，但过度平滑，PSNR 较低
- TV：保边效果好，PSNR 较高，但需迭代求解
- PnP：无需显式定义正则项，效果取决于去噪器质量

#### 核心知识点：去噪器类型与数据驱动的关系

本实验的 `simple_denoiser` 是**手工设计**的去噪器，不需要任何外部训练数据，属于**非数据驱动方法**。这与"隐式先验无需显式定义 $p(x)$"的章节论点一致。

PnP 框架本身对去噪器来源无限制：
- **手工设计去噪器**（NLM、BM3D）：不需要训练数据
- **数据驱动去噪器**（DnCNN、DRUNet）：需要外部训练数据

数据驱动去噪器已进入第3章"学习型先验"范畴。本实验使用手工设计去噪器，旨在演示 PnP 的核心思想——**去噪器即先验**——而非追求最佳性能。

### 三种隐式先验的对比

| | GAN 先验 | VAE/流先验 | PnP 先验 |
|---|---|---|---|
| **先验表示** | 生成器 $G_\theta(z)$ | 编码-解码器 $\nu_\theta(z)$ | 去噪器 $D_\epsilon(y)$ |
| **$p(x)$ 可计算** | 否（隐式分布） | 是（通过隐空间） | 否（只知道梯度） |
| **后验推断** | 隐空间优化（MAP） | 隐空间 MCMC（MMSE+MAP） | PnP-ULA/SGD（MMSE+MAP） |
| **不确定性量化** | 不能 | 能 | 能 |
| **训练独立性** | 与成像模态无关 | 与成像模态无关 | 与成像模态无关 |
| **理论保证** | 有限 | Hadamard 适定性 | 收敛到 oracle 邻域 |
| **局限** | 模式坍缩，无密度 | 流形假设，尺度受限 | 依赖去噪器质量 |

三种隐式先验代表不同"先验编码"策略：GAN 通过生成器隐式定义分布支撑集，VAE/流通过隐变量模型提供可计算后验，PnP 通过去噪器间接提供先验梯度信息。它们共同特点：**先验的"形状"不再由人指定，而是从数据中学。**

## 四、两条路径的起点

### 先验之旅的回顾

本章从"先验为什么等于正则项"出发（2.1），巡览经典先验族（2.2），深入 MMSE 与 MAP 分歧（2.3），最终走到显式先验天花板与隐式先验兴起（2.4）。整条叙事线索可浓缩为一句话：**先验是贝叶斯推断的灵魂，它将正则化从"数学技巧"提升为"概率推理"，而先验自身也正从"人为假设"走向"数据驱动"。**

### 两条路径的起点

有了先验 $p(x)$ 和似然 $p(y|x)$，后验 $p(x|y)$ 在形式上已完全确定。但如何从后验中**提取解**？取决于我们问什么问题：

**路径一（点估计）**：求后验众数 → MAP → 优化方法。MAP 把贝叶斯推断转化为正则化优化问题，高效可行——这是第3章起点。FoE 双层优化、GAN 隐空间优化、PnP-SGD，都属这条路径。

**路径二（分布采样）**：求后验分布 → MCMC/ULA → 采样方法。采样利用后验完整信息，不仅能给 MMSE 估计，还能提供不确定性量化——这是第4章起点。VAE/流隐空间 MCMC、PnP-ULA，都属这条路径。

两条路径的终点都是扩散模型。扩散模型既可通过得分匹配学隐式先验（路径一），又可通过去噪采样生成后验样本（路径二）。先验的学习本身也分两条路径：得分匹配（第6章）学得分函数 $\nabla_x \ln p(x)$，变分推断（第9章）通过 VAE 学隐式先验。所有这些路径，终将在第12章殊途同归。

> **从先验到计算**：先验给出后验形式，但从后验到具体的解，需要计算。第3章走优化之路（MAP），第4章走采样之路（MCMC）——两条路的交汇处，正是"去噪即采样"的扩散模型。而 2.3 节的"去噪器 = 先验下的 MMSE 估计器"和本节的 PnP 先验，已为这一交汇埋下伏笔：去噪器编码了先验，得分匹配从去噪器提取先验梯度，扩散模型用先验梯度驱动采样——从先验到计算的闭环，即将形成。

> 回顾本章，先验的演化有一条由逆问题需求驱动的清晰因果链——显式先验（高斯/Laplace/TV）表达能力有根本局限 → 需要学习型先验 → PnP 表明去噪器可充当隐式先验 → Tweedie 等式揭示去噪器编码了得分函数 $\nabla_x \ln p(x)$ → 得分匹配从数据中学得分函数 → 多步得分驱动采样即扩散模型。**扩散模型不是凭空出现的，而是逆问题需求驱动下先验演化的自然终点。** 下一章将从 MAP 优化开始这段旅程。

## 六、收尾：为什么这件事重要

把整章塌缩成一句话：**先验不是正则化方法的"装饰品"，它就是正则化本身——先验收到的"约束"，不过是概率告诉我们的"你该相信什么"。** 当你承认这一点，正则化就从"拍脑袋调参"变成了"有根有据的推理"，而这也正是贝叶斯框架最迷人的地方。
