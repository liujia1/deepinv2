> 前面三节你造了引擎（18.2 的 $A$）、选了策略（18.3 的方法谱）。现在到了"毕业设计答辩"环节——把它们接成一根完整的管子，真跑一遍。先问你一个反直觉的问题：**同样一张被糊掉、又加了噪的图，TV 正则化几秒出结果，扩散模型要慢上几十倍，那扩散到底贵得有没有道理？** 这一节用三个递进项目（去模糊、超分、修复）把"贵得值不值"用数字摊开。结论先剧透：**"退化越重、扩散越强"这个流行说法在本实验里并没有成立**——决定排序的不是退化有多重，而是退化属于哪一类（缺纹理还是缺像素），以及你给自己的方法调了什么参数。本实验里，修复场景的排名甚至被一次参数修复整体改写：同一张 DRUNet 去噪器，换个噪声调度就从 12 dB 量级跳到 33 dB。

- 亲手验证：方法强 ≠ 永远强，**退化类型 + 参数配置**共同决定一切。

## 18.4.1 项目 1：图像去模糊

### 问题定义（这就是第 1 章的 $\mathbf{y}=Ax$）

去模糊是最经典的线性逆问题，正向模型：

$$\mathbf{y} = Kx + \varepsilon, \quad \varepsilon \sim \mathcal{N}(0,\sigma^2 I)$$

为什么从去模糊开刀？因为它最"朴素"——模糊核 $K$ 一卷积、噪声一加，就是你的观测 $\mathbf{x}$ 变 $\mathbf{y}$ 的全过程，最能看清管线的每一步。我们看两档难度：
- **轻度**：小模糊（$\sigma_K=1.5$）+ 低噪（$\sigma=0.01$）
- **重度**：大模糊（$\sigma_K=3.0$）+ 高噪（$\sigma=0.05$）

### 步骤 1：定义正向算子（回到 18.2）

```python
import torch, deepinv as dinv
device = dinv.utils.get_freer_gpu() if torch.cuda.is_available() else "cpu"
x_true = dinv.utils.load_example("celeba_example.jpg", img_size=(256, 256))

# 自定义模糊核（也可直接用 dinv.physics.functional.blur.gaussian_blur）
from deepinv.physics.functional.blur import gaussian_blur
kernel = gaussian_blur(sigma=(3.0, 3.0))   # 重度档
# 用 BlurFFT（FFT 实现、可 SVD 分解）：PnP/DiffPIR 的数据保真步 prox_l2 有闭式解，性能稳定
physics = dinv.physics.BlurFFT(img_size=(3, 256, 256), filter=kernel)
physics.set_noise_model(dinv.physics.GaussianNoise(sigma=0.05))
y = physics(x_true)   # 制造一次观测
```

### 步骤 2–3：选策略 + 加载去噪器（回到 18.1 的方法谱系）

```python
denoiser_drunet = dinv.models.DRUNet().to(device)    # PnP 用
denoiser_diffunet = dinv.models.DiffUNet().to(device)  # 扩散用
```

### 步骤 4：三种方法同台打擂（对应第 3 / 5 / 13 章）

**优化——TV 正则化**（第 3 章 3.5 节，Chambolle-Pock 解）：

$$\hat{x} = \arg\min_x \frac{1}{2\sigma^2}\|Kx - \mathbf{y}\|^2 + \lambda\|Dx\|_1$$

```python
from deepinv.optim import ADMM
model_tv = ADMM(...)   # TV 正则化配置
x_tv = model_tv(y, physics)
```

**PnP——DPIR**（第 5 章的去噪器即先验）：
```python
from deepinv.optim import DPIR
# 0.4.1 的 DPIR 只接受单个 sigma（没有 params 参数）
model_dpir = DPIR(sigma=0.05, denoiser=denoiser_drunet)
x_dpir = model_dpir(y, physics)
```

**扩散——DiffPIR**（第 13 章条件扩散采样）：
```python
from deepinv.sampling import DiffPIR
from deepinv.optim import L2
# 0.4.1 的首个参数名为 model（不是 denoiser），步数用 max_iter
model_diffpir = DiffPIR(model=denoiser_diffunet, data_fidelity=L2(),
                        max_iter=100, zeta=0.1, lambda_=7.0)
x_diffpir = model_diffpir(y, physics)
```

> 说明：以上代码按 deepinv 0.4.1 的构造签名书写，并已实测可实例化。实验脚本里的 DPIR 用 `optim_builder(iteration="HQS", prior=PnP(...), params_algo=...)` 实现逐轮递减的 σ 调度（`DPIR` 类本身只接受单个 `sigma`）；DiffPIR 的完整参数见 18.4-1。换版本运行时请以 `inspect.signature` 的输出为准。

### 步骤 5：结果对比（先猜后揭）

**先猜一下**：重度模糊+高噪下，TV、DPIR、DiffPIR 三者 PSNR 谁高？差距会有多大？
> 揭晓（来自 18.4-1 实验实测，见本节末尾）：重度模糊下 **DPIR≈29.3 dB 最高**，TV≈27.3 dB 与 DiffPIR≈27.2 dB（后验均值图 28.8 dB）紧随其后；轻度模糊下 **DPIR≈34.7 dB 领先**，DiffPIR≈31.7 dB（均值图 33.7 dB）、TV≈31.6 dB 次之，Tikhonov≈31.2 dB。DPIR 单次约 0.2 s，DiffPIR 单样本约 9.6 s——慢约 40 倍，却没有更准。

| 方法 | 轻度 PSNR/SSIM | 重度 PSNR/SSIM | 速度（GPU 实测） |
|------|----------------|----------------|------|
| Tikhonov | 31.21/0.85 | 25.35/0.57 | 快（<0.2 s） |
| TV 正则化 | 31.58/0.86 | 27.34/0.74 | 较快（≈0.7–0.8 s） |
| DPIR | **34.68**/0.92 | **29.29**/0.80 | 快（≈0.2 s） |
| DiffPIR | 31.67±0.20/0.90 | 27.16±0.13/0.77 | 慢（≈9.6 s/样本） |

（数值取自 18.4-1 实验实测的 `results_summary.json`；耗时为 GPU 环境实测（GTX 1660 Ti），CPU 上整体再慢一个数量级。DiffPIR 一栏为 3 次独立采样 PSNR 的均值±标准差，其 3 样本平均图即后验均值（MMSE）估计，PSNR 分别为 33.70 / 28.84 dB，反而更接近 DPIR——同一方法、两种口径，正是 18.5 要讲的"点估计 vs 后验分布"的实物预演。）这里有两点值得注意：其一，**同一条管子下参数决定成败**——早期版本的 TV 因参数被静默忽略、退化到默认值，在轻度模糊上只有 21.5 dB；修正为适配良态模糊算子的 $(\lambda,\text{stepsize})=(0.01,1.0)$ 后升到 31.58 dB。其二，本实验中 DiffPIR 使用 $\sigma$ 随场景设定（重度模糊 0.05、其余 0.01）、$\zeta=0.1$、$\lambda=7.0$ 加 100 步的**教学简化配置**（代码注释自陈未按场景调优），因此它的成绩应读作"该配置下的成绩"，不能当作扩散方法的性能上限。这说明**方法强 ≠ 永远强**，参数和退化程度共同决定结果。

**视觉差异一句话**：TV 太滑（丢纹理）、DPIR 恢复细节最好、DiffPIR 纹理自然但受上述配置拖累，细节之外仍留残噪。

## 18.4.2 项目 2：超分辨率重建

### 问题定义

正向模型是"模糊 + 下采样"：

$$\mathbf{y} = DSx + \varepsilon$$

$S$ 抗混叠模糊，$D$ 下采样。$s$ 倍下采样把 $n\times n$ 图压成 $(n/s)\times(n/s)$。为什么超分是"扩散的秀场"？因为每测 1 个像素对应 $s^2$ 个未知像素，测量信息被成倍吃掉，越高的倍率，这种"信息真空"越夸张。

### 步骤 1：定义正向算子

```python
physics_sr = dinv.physics.Downsampling(factor=4, img_size=(3,256,256), filter="gaussian")
physics_sr.set_noise_model(dinv.physics.GaussianNoise(sigma=0.02))
y_sr = physics_sr(x_true)
```

（实验 18.4-1 中超分场景的噪声水平取 $\sigma=0.01$。）

### 求解与对比（先猜后揭）

**先猜**：4 倍超分下，Tikhonov（纯优化）能到多少 dB？DPIR/DiffPIR 呢？
> 揭晓（18.4-1 实测）：4 倍超分时 DPIR≈30.2 dB 为样本口径最高，但 DiffPIR 的后验均值图 30.73 dB 实际反超——同一方法两种口径给出不同排名；Tikhonov 29.15 dB、TV 27.83 dB、插值基线（无先验）26.87 dB 随后，**学习型先验比无先验基线高约 3 dB**。注意 Tikhonov 已不是早期提纲预期的 12.5 dB：v8 版把正则权重改成按算子范数自适应（$\lambda=0.01\|A\|_2^2$；v7 是 $0.1\|A\|_2^2$）后，它在欠定下采样场景里也能给出合理的平滑解，甚至略超无先验插值基线。

| 方法 | 2× PSNR/SSIM | 4× PSNR/SSIM | 8× PSNR/SSIM |
|------|-------------|-------------|-------------|
| 插值基线（无先验） | 33.07/0.91 | 26.87/0.77 | — |
| Tikhonov | 33.20/0.89 | 29.15/0.81 | — |
| TV 正则化 | 34.12/0.92 | 27.83/0.79 | — |
| DPIR | **35.68**/0.94 | **30.19**/0.85 | — |
| DiffPIR | 33.07±0.09/0.92 | 29.31±0.12/0.84 | — |

"—" 表示 8× 倍率未实测。"插值基线"是超分场景下无先验重建的别名：本实验里它是**双线性插值上采样**的输出（不是 $A^\top \mathbf{y}$——下采样算子的伴随是零填充上采样，4× 时仅 8.9 dB、极暗不可用），其余场景仍叫伴随重建。DiffPIR 一栏的 PSNR 是 3 个样本各自 PSNR 的均值（±总体标准差，`np.std` 默认 ddof=0）；SSIM 是在 3 样本平均图上计算的，与 PSNR 不是同一张图。其后验均值图 PSNR 在 2×/4× 分别为 34.88/30.73 dB，4× 档反超 DPIR；S=3 的均值图只是粗蒙特卡洛估计，不是精确 MMSE。

**为什么高倍率更需要强先验**：倍率越大，零空间维度越大。4 倍时每测 1 个像素对应 16 个未知像素，测量信息被大幅吃掉，无先验插值基线停在 26.87 dB，而学习型先验（DPIR 30.19 dB）与适配过的显式先验（Tikhonov 29.15 dB）都能把它往上拉——先验的价值不分"手写"与"学习"，区别在于拉动的幅度与适用的退化类型。

## 18.4.3 项目 3：图像修复

### 问题定义

$$\mathbf{y} = Mx + \varepsilon$$

$M$ 是对角掩码（保留部分像素、其余置零），比如"只留 20% 像素"。为什么修复最考验"敢不敢编"？因为缺失的像素彻底没信息，求解器要么保守留洞，要么靠先验"脑补"——而脑补的质量，正是三代方法的分水岭。

### 步骤 1：定义正向算子

```python
physics_inpaint = dinv.physics.Inpainting(img_size=(3,256,256), mask=0.20, device=device)
physics_inpaint.set_noise_model(dinv.physics.GaussianNoise(sigma=0.01))
y_inpaint = physics_inpaint(x_true)
```

### 求解与对比（一个被参数改写的结论）

**先猜**：一半像素缺失时，TV 和 DPIR 谁强？换成 80% 缺失呢？
> 揭晓（18.4-1 实测，50%/80% 两档缺失）：**DPIR 两档都是第一**——50% 档 DPIR 33.12 dB、DiffPIR 31.47 dB、TV 28.84 dB、Tikhonov 11.28 dB；80% 档 DPIR 27.99 dB、TV 20.91 dB、DiffPIR 20.27 dB、Tikhonov 9.31 dB。但这个故事有个重要前提：**DPIR 的领先是"任务匹配的噪声调度"换来的**。早期版本直接套用为去模糊/超分设计的默认调度（8 步、σ 从 0.19 降到测量噪声），同一张 DRUNet 在 50%/80% 缺失上只有 12.34/9.79 dB，几乎退回无先验基线——当时"TV 断层领先学习型先验 11–17 dB"的结论就是那么来的；换成修复专用调度（20 步、σ 从 0.5 到 0.05 对数递减、数据锁定随 σ² 缩放）后，DPIR 反超 TV 4–7 dB。所以本节真正的教训不是"修复场景 TV 最强"，而是：**修复场景的排名由"先验 × 调度参数"共同决定**——同一方法，换个参数就从垫底到第一。

| 方法 | 50% PSNR/SSIM | 80% PSNR/SSIM |
|------|---------------|---------------|
| 无先验基线（伴随） | 11.28/0.21 | 9.31/0.10 |
| Tikhonov | 11.28/0.21 | 9.31/0.10 |
| TV 正则化 | 28.84/0.79 | 20.91/0.54 |
| DiffPIR | 31.47±0.05/0.91 | 20.27±0.97/0.60 |
| DPIR | **33.12**/0.88 | **27.99**/0.76 |

（DiffPIR 一栏的 PSNR 是 3 个样本各自 PSNR 的均值（±总体标准差，ddof=0）；SSIM 在 3 样本平均图上计算，与 PSNR 不同图。其后验均值图 PSNR 在 50%/80% 分别为 33.54/21.58 dB；S=3 的均值图只是粗蒙特卡洛估计。Tikhonov 与无先验基线的 PSNR 四舍五入后相同（SSIM 0.2134 vs 0.2132，略有差异），这不是巧合：缺失像素处数据项不提供任何梯度，零均值 L2 先验的解析最优值就是 0；观测像素则被 $\lambda=0.01$ 轻微收缩为 $y/(1+\lambda)$——所以是"几乎相同"而非严格相等，这是先验的固有特性，不是 bug。）

**退化严重性与方法选择的关系**（一句话地图）：

```
退化严重性（信息缺失）  低 ──────────────────────── 高
候选方法：              优化 / TV      PnP         扩散采样
实测结论：            快、轻度够用  六场景全胜    样本口径未超 PnP
缺的是什么：            高频纹理      高频纹理      缺失像素（靠先验"编"内容）
```

（本实验最有意思的一课：**"缺纹理"和"缺像素"是两类不同的退化**，但决定排序的不是退化类别本身，而是"退化类型 × 参数配置"的组合——缺像素时 DPIR 换个调度就能从 9.79 dB 跳到 27.99 dB，TV 则是不需要任何调参的最强显式先验，DiffPIR 在 80% 大洞上抖动明显（±0.97 dB，80% 档已落到 TV 之下）。）

## 18.4.4 多方法综合对比

### 定量总表（来自 18.4-1 实验实测，最可信的一版）

| 场景 | 无先验基线 | Tikhonov | TV 正则化 | DPIR (PnP) | DiffPIR (扩散) |
|------|---------|----------|-----------|-----------|---------------|
| 轻度模糊 | 27.74（伴随） | 31.21 | 31.58 | **34.68** | 31.67±0.20（均值图 33.70） |
| 重度模糊 | 23.91（伴随） | 25.35 | 27.34 | **29.29** | 27.16±0.13（均值图 28.84） |
| 2 倍超分 | 33.07（插值） | 33.20 | 34.12 | **35.68** | 33.07±0.09（均值图 34.88） |
| 4 倍超分 | 26.87（插值） | 29.15 | 27.83 | **30.19** | 29.31±0.12（均值图 30.73） |
| 50% 修复 | 11.28（伴随） | 11.28 | 28.84 | **33.12** | 31.47±0.05（均值图 33.54） |
| 80% 修复 | 9.31（伴随） | 9.31 | 20.91 | **27.99** | 20.27±0.97（均值图 21.58） |

（DiffPIR 一栏的 PSNR 是 3 个样本各自 PSNR 的均值（±总体标准差，ddof=0）；SSIM 在 3 样本平均图上计算，与 PSNR 不同图。"均值图"为 3 样本平均图的 PSNR，是后验均值的粗蒙特卡洛估计（S=3），不是精确 MMSE。耗时为 GPU 实测（GTX 1660 Ti）：Tikhonov 与基线 <0.2 s，TV 0.7–1.1 s，DPIR 0.17–0.74 s，DiffPIR 约 9.6 s/样本；CPU 上整体再慢一个数量级。）

**读表四句话**：
1. **修复场景的无先验基线最差、先验的价值最明显**（80% 缺失时伴随重建 9.31 dB，DPIR 拉到 27.99 dB、TV 拉到 20.91 dB）；但在超分场景，无先验的插值基线本身就有 26.9–33.1 dB，先验的增益只有约 3 dB。
2. **DPIR 在全部六个场景都是第一**（模糊 34.68/29.29、超分 35.68/30.19、修复 33.12/27.99）——但修复场景的领先是任务匹配的噪声调度换来的（见 18.4.3），默认调度下它只有 12.34/9.79 dB。
3. **TV 是最强的显式先验、且无学习参数**（但每个场景的 $\lambda$/stepsize 仍是人为设定的，不是"零调参"）：修复场景仅次于 DPIR（28.84/20.91），去模糊与 DiffPIR 相当；但 4× 超分时被分段常数化拖累（27.83 dB，反而低于 Tikhonov 的 29.15 dB）——显式先验的强项是"缺失像素的稀疏梯度填充"，不是"恢复高频纹理"。
4. **DiffPIR 样本 PSNR 在全部场景低于 DPIR**，GPU 实测约 9.6 s/样本（比 DPIR 的 0.2–0.7 s 慢约 13–56 倍；CPU 上再慢一个数量级）。这不构成"扩散不如 PnP"的结论：其 $\sigma/\zeta/\lambda$ 为未调优的教学配置、步数仅 100；且若改用后验均值（MMSE）口径，4× 超分（30.73 vs 30.19，差 0.54 dB）反超 DPIR——3 个样本的均值本身带约 $0.119/\sqrt{3}\approx0.07$ dB 的标准误，0.54 dB 远大于它，但后验均值图与 DPIR 的点估计毕竟是两种不同的口径，这里的"反超"应读作量级上的领先，而非严格的统计显著性结论——**同一方法两种口径给出不同排名，这正是"点估计 vs 后验分布"的实物教材**（18.5 展开）。50% 修复的均值图 33.54 vs 33.12（差 0.42 dB）看着也能"反超"，但 S=3 的均值图只是粗蒙特卡洛估计，其自身的蒙特卡洛误差没有可靠的样本量支撑，**不宜据此宣布反超**——这正是 18.5 要用覆盖率与可靠性曲线去检验的东西。

需要说明的是，本实验中 DiffPIR 采用 100 步采样（库默认/论文标准配置，低于典型的 1000 步），GPU 实测单样本约 9.6 s，低于 18.3 表中"分钟级"的一般情形——18.3.5 的加速手段正在于此。

从更深层次看，这张表的意义不在给方法排名，而在把 18.3 的"阶梯"从论断变成了实测事实：三类方法的差距随信息缺失程度拉开，且没有一个方法在所有场景称王。这一转变意味着，工程上真正的功夫在"先诊断退化、再选方法"，而不是背一个最优解。

### 定性对比（人眼看啥区别）

- **优化**：Tikhonov 太滑（丢高频）；TV 还可能出阶梯，但绝不"编"不存在的东西。**在修复场景，这份"保守"很能打**——TV 把已知像素间的缺失区填成稀疏梯度，是不需要任何调参的最强显式先验（28.84/20.91 dB）。
- **PnP**：细节最多，实测分数也最高（六个场景全胜）。关键在修复场景必须换任务匹配的噪声调度：默认去模糊调度下会假性失败（12.34/9.79 dB，几乎退回无先验基线），换成 20 步修复专用调度后 33.12/27.99 dB 反超 TV——**参数是 PnP 的"隐藏开关"**。
- **扩散**：纹理自然，理论上能"编"出合理的缺失内容，多次采样还能给出一族合理解（→ 不确定性，接 18.5）。但本实验里 DiffPIR 的教学配置与 100 步采样让它没能兑现质量优势（样本口径全部低于 DPIR），这一条**要靠调好采样超参才成立**。

### 计算效率 vs 质量权衡（决策者视角）

```
重建质量
  ▲
  │  ● PnP（≈0.2–0.7 s，六场景全胜；修复场景须任务匹配调度）
  │
  │        ● 扩散采样（≈9.6 s/样本，样本口径未超 PnP；后验均值口径在 4× 超分反超）
  │     ● TV（≈0.7–1.1 s；修复场景第二，去模糊/2× 超分中游，4× 超分被阶梯化拖累）
  │  ● Tikhonov（<0.2 s，轻度退化性价比高）
  │ ● 无先验基线（伴随/插值，0 s）
  └──────────────────────────▶ 计算时间
```
- 时间敏感（实时成像）→ PnP（本实验里既快又准）
- 质量敏感（医学诊断）→ 本实验实测 PnP 第一；扩散要先调好采样超参
- 修复场景（缺像素）→ 有去噪器可用时 DPIR（须配修复专用调度）；只能用显式先验时 → TV
- 要不确定性 → **只有扩散**

（耗时为 GPU 实测；CPU 上 PnP 约 0.2–0.35 s、扩散约 10 s 的量级会整体放大到几十至几百秒。）

# 选项C 扩散（0.4.1：首参名为 model，步数用 max_iter）：
# model = dinv.sampling.DiffPIR(model=dinv.models.DiffUNet(pretrained="download"),
#                               data_fidelity=dinv.optim.L2(), max_iter=100)

# ===== 步骤3：先验/去噪器（已并入步骤2）=====
# 若要自监督训，见第17章，训完把 denoiser 传给求解器

# ===== 步骤4：求解 =====

# ===== 步骤5：评估 + 不确定性（扩散需多次采样，见18.5）=====

## 实验 18.4-1：端到端求解策略对比

实验 `18.4-1.py` 在统一框架下对比**优化方法（Tikhonov、TV 正则化）、PnP 方法（DPIR）和扩散方法（DiffPIR）**在六种退化场景中的重建质量与计算效率，验证 18.3 节的方法选择决策指南。

### 实验场景

实验构造六类逆问题场景，覆盖退化程度从轻到重的完整谱系：

**去模糊**：轻度模糊（高斯核 $\sigma_K=1.5$，噪声 $\sigma=0.01$）与重度模糊（高斯核 $\sigma_K=3.0$，噪声 $\sigma=0.05$）。

**超分辨率**：2 倍下采样（噪声 $\sigma=0.01$）与 4 倍下采样（噪声 $\sigma=0.01$），使用双三次抗混叠滤波。

**图像修复**：50% 像素缺失（噪声 $\sigma=0.01$）与 80% 像素缺失（噪声 $\sigma=0.01$）。

每类场景均使用相同的测试图像（celeba_example.jpg，$256 \times 256$），并在相同观测下对比五种重建结果：无先验基线（伴随重建 $A^\top \mathbf{y}$，超分场景为双线性插值，记作"插值基线"）、Tikhonov 正则化（100 次梯度下降，$\lambda=0.01\|A\|_2^2$ 按算子范数自适应，步长 $1/(\|A\|_2^2+\lambda)$）、TV 正则化（PGD，150 次迭代，$(\lambda,\text{stepsize})$ 按算子类型分场景设置）、DPIR（PnP-HQS，DRUNet 去噪器；去模糊/超分用 `get_DPIR_params` 默认调度，修复场景用 20 步修复专用调度）和 DiffPIR（扩散去噪器 DiffUNet，100 步采样，$\zeta=0.1$、$\lambda=7.0$，$\sigma$ 随场景设定）。

DiffPIR 在全部六个场景上运行（Inpainting 的 L2 prox 有闭式解，无需 SVD；GPU 上每样本约 9.6 s），每场景独立采样 3 次（种子 42/123/2024）：PSNR 报告 3 次采样各自 PSNR 的均值±总体标准差（`np.std` 默认 ddof=0）；SSIM 在 3 样本平均图上计算（不是单样本 SSIM 的均值），重建配图取 3 样本平均（后验均值的粗蒙特卡洛估计，S=3）。

> **掩码可复现性与版本溯源**：修复场景的掩码由固定 CPU Generator（seed=123）生成，三通道一致；脚本会打印 MD5 hash（50%: `e680e2cd8386ed76`，80%: `eaaad88cd8884c90`）。当前脚本 `CACHE_VERSION=10`，而归档的 `results_summary.json` 就是本脚本在 deepinv 0.4.1 + torch 2.11.0+cu126（GTX 1660 Ti）下的**全量重跑产物**——掩模固定、DiffPIR 六场景齐全；JSON 顶部的 `_meta` 块自声明了运行环境、各场景算子配置、指标口径、完整性自检（`completeness.complete = true`）与版本沿革，使"脚本变了但归档没跟上"这类漂移不会再次静默发生。更早的归档（v8）用的是 deepinv 内部随机掩模，与本脚本不可复现；两版对比：非扩散方法 PSNR 差异 ≤ 0.21 dB，六场景的方法排序完全不变（修复场景的差异源于掩模像素分布不同，而非算法改动）。
>
> **离线/国内网络下的权重获取**：DiffUNet 权重托管在 HuggingFace（仓库 `deepinv/diffunet`，文件 `diffusion_ffhq_10m.pt`），国内直连常不可达。两种办法：① 设环境变量 `HF_ENDPOINT=https://hf-mirror.com` 后再运行；② 直接下载权重文件放到 torch 缓存目录 `~/.cache/torch/hub/checkpoints/diffusion_ffhq_10m.pt`（文件名固定），脚本会命中缓存、不再联网。DRUNet 权重 `drunet_deepinv_color_finetune_22k.pth` 同理。若权重确实缺失，脚本会打印可操作提示，并在 JSON 的 `_meta.warnings` 中标注"本次运行不含 DiffPIR"，避免半份归档被误读。

### 实验目的

1. **验证退化严重性与方法选择的关系**：同样是"退化"，缺高频纹理（模糊/超分）与缺像素（修复）对方法的要求并不相同——前者学习型先验（DPIR）领先且极快；后者的排名由"先验 × 调度参数"共同决定（DPIR 换修复专用调度后第一，TV 是不调参的最强显式先验）
2. **对比三类方法的计算效率-重建质量权衡**：优化方法秒级完成、质量居中；PnP 方法质量最高（六场景全胜）；扩散方法慢一个数量级以上，样本口径未取得质量优势，但后验均值口径在 4× 超分上反超（50% 修复的 0.42 dB 差异在 S=3 下同样不宜当作反超结论）
3. **观察不同方法的重建视觉特征**：Tikhonov 过度平滑（修复场景输出黑洞，系零均值 L2 先验的固有特性）、TV 保边但可能阶梯效应、DPIR 恢复细节最好、DiffPIR 生成纹理自然
4. **量化无先验基线的水平**：伴随重建 $A^\top \mathbf{y}$（超分场景为双线性插值）作为无先验基线，展示先验信息的价值——在修复场景差距最大，在超分场景差距最小

### 实验输入

### 预期结果（已按实测更新）

原提纲预期与实测差异很大（详见下文各场景表），这里先给出结论：

- **去模糊**（轻度/重度）：DPIR 最高（34.68 / 29.29 dB），TV（31.58 / 27.34 dB）与 DiffPIR（31.67 / 27.16 dB）接近，Tikhonov 31.21 / 25.35 dB
- **超分**（2×/4×）：DPIR 最高（35.68 / 30.19 dB），TV（34.12 / 27.83 dB）与 DiffPIR（33.07 / 29.31 dB）次之；Tikhonov（33.20 / 29.15 dB）已不低于无先验插值基线（33.07 / 26.87 dB）——**优化方法并未像提纲预期那样崩到 10–12 dB**，自适应 $\lambda$ 与分场景 TV 参数起了作用
- **修复**（50%/80% 缺失）：DPIR 第一（33.12 / 27.99 dB），但领先是修复专用调度换来的（默认调度下仅 12.34 / 9.79 dB）；TV 是不调参的最强显式先验（28.84 / 20.91 dB）；DiffPIR（31.47 / 20.27 dB）居中，80% 档采样抖动 ±0.97 dB
- **计算时间**（GPU 实测）：Tikhonov 与基线 <0.2 s，TV 0.7–1.1 s，DPIR 0.17–0.74 s，DiffPIR ≈9.6 s/样本（CPU 上整体再慢一个数量级）
- **无先验基线**：在修复场景最差（9.3–11.3 dB），在超分场景却不差（26.9–33.1 dB）——说明"先验值不值"取决于算子零空间有多大、以及基线本身能走多远

50% 修复场景下 DPIR 第一（33.12 dB）——但这是修复专用噪声调度（20 步，σ 从 0.5 到 0.05 对数递减）换来的：早期版本套用默认去模糊调度时只有 12.34 dB，几乎等于伴随基线。TV（28.84 dB）是无学习参数的最强显式先验（其 $\lambda$/stepsize 仍按场景设定）。Tikhonov（11.28 dB）与伴随基线的 PSNR 四舍五入后相同（SSIM 0.2134 vs 0.2132，略有差异）：缺失像素处零均值 L2 先验的解析最优值就是 0（黑洞），观测像素被 $\lambda=0.01$ 轻微收缩——这是先验的固有特性，不是 bug。

#### 核心知识点总结

| 知识点 | 实验验证 |
|--------|---------|
| 退化类型 × 参数配置共同决定排序 | 缺高频纹理（模糊/超分）：DPIR 全胜（29.29–35.68 dB）；缺像素（修复）：DPIR 在任务匹配调度下同样第一（33.12/27.99 dB），TV 是不调参的最强显式先验（28.84/20.91 dB） |
| 参数是方法的"隐藏开关" | 同一 DRUNet：默认去模糊调度在 50%/80% 修复上仅 12.34/9.79 dB，换 20 步修复专用调度后 33.12/27.99 dB，排名从垫底到第一 |
| 计算效率-质量权衡 | Tikhonov/基线 <0.2 s，TV 0.7–1.1 s，DPIR 0.17–0.74 s，DiffPIR ≈9.6 s/样本（GPU 实测；CPU 上整体再慢一个数量级） |
| 先验信息的价值 | 无先验基线在修复场景最差（9.31–11.28 dB），在超分场景已有 26.87–33.07 dB，先验增益仅约 3 dB |
| 学习型先验 vs 显式先验 | 超分：DPIR 35.68/30.19 dB 优于 TV 34.12/27.83 dB；修复：DPIR 33.12/27.99 dB 优于 TV 28.84/20.91 dB，但 TV 胜在无学习参数（$\lambda$/stepsize 仍按场景设定） |
| 点估计 vs 后验分布 | DiffPIR 样本口径全部低于 DPIR，但 3 样本后验均值（MMSE）在 4× 超分（30.73 vs 30.19）反超——同一种扩散先验，两种评价口径；50% 修复的 0.42 dB 差异在 n=3 下不足以支撑"反超"结论 |
| 扩散方法的条件性 | DiffPIR 样本口径均低于 DPIR——其 $\sigma/\zeta/\lambda$ 为教学配置、步数仅 100，属未调优的简化配置；80% 大洞上采样抖动 ±0.97 dB（已落到 TV 的 20.91 dB 之下） |

> **实践启示**：实测结果修正了 18.3 节决策树的一处想当然——"退化越重，扩散越强"并不自动成立。真正决定排序的是**退化类型与参数配置的组合**：缺高频纹理时 DPIR 又快又准；缺像素时，方法排名会被调度参数整体改写（12 dB → 33 dB），TV 则是无需调参的保底选择。此外，本实验中 DiffPIR 的教学超参与 100 步采样使其未能发挥扩散的生成能力——评价扩散方法时须先把采样超参调好，否则得到的只是"配置的成绩"而非"方法的成绩"；而它"多样本 + 后验均值"的输出形态，正是 18.5 不确定性量化的入口。
