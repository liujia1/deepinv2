# 18.4 端到端实战：扩散模型求解自定义逆问题

> **核心观点**：理论框架和方法对比只有在实践中才能得到验证。本节通过三个递进的实战项目——图像去模糊、超分辨率重建、图像修复——完整演示端到端管线，并在每个项目中对比优化/PnP/扩散三类方法的表现。退化越严重，扩散方法的优势越大。

## 项目1：图像去模糊

### 问题定义

图像去模糊是最经典的线性逆问题之一。前向模型为：

$$y = Kx + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2 I)$$

其中$K$是卷积模糊核（Toeplitz矩阵），$\epsilon$是高斯噪声。

我们考虑两种难度级别：
- **轻度退化**：小模糊核（$\sigma_K = 1.5$）+ 低噪声（$\sigma = 0.01$）
- **重度退化**：大模糊核（$\sigma_K = 3.0$）+ 高噪声（$\sigma = 0.05$）

### 步骤1：定义前向算子

```python
import torch
import deepinv as dinv

# 设置设备
device = dinv.utils.get_freer_gpu() if torch.cuda.is_available() else "cpu"

# 加载测试图像
x_true = dinv.utils.load_example("celeba_example.jpg", img_size=(256, 256))

# 定义模糊核
kernel = dinv.physics.blur.gaussian_blur(sigma=(3.0, 3.0))

# 定义前向算子
physics = dinv.physics.Blur(img_size=(3, 256, 256), filter=kernel)
physics.set_noise_model(dinv.physics.GaussianNoise(sigma=0.05))

# 生成测量数据
y = physics(x_true)
```

### 步骤2-3：选择求解策略与加载去噪器

我们同时准备三种方法的求解器：

```python
# 加载去噪器
denoiser_drunet = dinv.models.DRUNet().to(device)   # PnP用
denoiser_diffunet = dinv.models.DiffUNet().to(device) # 扩散用
```

### 步骤4：运行求解

**优化方法——TV正则化**：

TV正则化是去模糊的经典方法（第3章3.5节），使用Chambolle-Pock算法求解：

$$\hat{x} = \arg\min_x \frac{1}{2\sigma^2}\|Kx - y\|^2 + \lambda\|Dx\|_1$$

```python
# TV去模糊（使用deepinv优化模块）
# 具体实现取决于deepinv版本，以下为概念代码
from deepinv.optim import ADMM
model_tv = ADMM(...)  # TV正则化配置
x_tv = model_tv(y, physics)
```

**PnP方法——DPIR**：

```python
from deepinv.optim import DPIR

model_dpir = DPIR(
    denoiser=denoiser_drunet,
    params={"stepsize": 1.0, "sigma": [0.1, 0.05, 0.025, 0.01]}
)
x_dpir = model_dpir(y, physics)
```

**扩散方法——DiffPIR**：

```python
from deepinv.sampling import DiffPIR

model_diffpir = DiffPIR(
    denoiser=denoiser_diffunet,
    data_fidelity="L2",
    params={"step_size": 1.0}
)
x_diffpir = model_diffpir(y, physics)
```

### 步骤5：结果对比

三种方法在去模糊任务上的典型表现：

| 方法 | 轻度退化PSNR/SSIM | 重度退化PSNR/SSIM | 计算时间 |
|------|-------------------|-------------------|---------|
| TV正则化 | ~30/0.85 | ~24/0.65 | 最快 |
| DPIR | ~32/0.90 | ~27/0.78 | 中等 |
| DiffPIR | ~33/0.92 | ~29/0.85 | 最慢 |

**关键观察**：
- 轻度退化：三种方法差距较小，TV正则化的性价比最高
- 重度退化：扩散方法显著优于其他方法，尤其在纹理恢复方面
- DPIR是速度与质量的良好折中

**视觉效果差异**：
- TV正则化：重建过于平滑，丢失纹理细节，可能出现阶梯效应
- DPIR：恢复大部分细节，偶尔出现不自然的平滑区域
- DiffPIR：恢复最多细节，生成感知最优的结果，纹理最自然

## 项目2：超分辨率重建

### 问题定义

超分辨率重建的前向模型为：

$$y = DSx + \epsilon$$

其中$S$是抗混叠模糊核，$D$是下采样算子。$s$倍下采样将$n \times n$图像变为$(n/s) \times (n/s)$。

### 步骤1：定义前向算子

```python
# 定义超分辨率前向算子（4倍下采样）
physics_sr = dinv.physics.Downsampling(
    factor=4,
    img_size=(3, 256, 256),
    filter="gaussian"  # 抗混叠滤波
)
physics_sr.set_noise_model(dinv.physics.GaussianNoise(sigma=0.02))

# 生成测量数据
y_sr = physics_sr(x_true)
```

### 求解与对比

三种方法在不同倍率超分辨率上的典型表现：

| 方法 | 2× PSNR/SSIM | 4× PSNR/SSIM | 8× PSNR/SSIM |
|------|-------------|-------------|-------------|
| 双三次插值 | ~28/0.80 | ~24/0.65 | ~21/0.55 |
| DPIR | ~30/0.88 | ~27/0.78 | ~24/0.68 |
| DiffPIR | ~31/0.90 | ~28/0.82 | ~26/0.75 |

**关键观察**：
- 2倍超分辨率：PnP与扩散差距较小，双三次插值已可接受
- 4倍超分辨率：扩散方法开始显示明显优势
- 8倍超分辨率：扩散方法是唯一可行的高质量方案——此时测量信息严重不足，只有生成式先验能提供足够的补充信息

**为什么高倍率需要扩散方法**？随着倍率增大，$A$的零空间维度急剧增加。4倍下采样时，每个测量像素对应16个未知像素；8倍下采样时，比例达到1:64。在如此严重的信息缺失下，显式先验（TV、稀疏）提供的约束远远不够，只有学到了完整图像分布$p(x)$的扩散模型才能合理地"填补"缺失信息。

## 项目3：图像修复

### 问题定义

图像修复的前向模型为：

$$y = Mx + \epsilon$$

其中$M$是对角掩码矩阵，$M_{ii} \in \{0, 1\}$，将部分像素置零。

### 步骤1：定义前向算子

```python
# 定义图像修复前向算子（80%像素缺失）
physics_inpaint = dinv.physics.Inpainting(
    img_size=(3, 256, 256),
    mask=0.20,  # 保留20%像素
    device=device
)
physics_inpaint.set_noise_model(dinv.physics.GaussianNoise(sigma=0.01))

# 生成测量数据
y_inpaint = physics_inpaint(x_true)
```

### 求解与对比

三种方法在不同缺失比例下的表现：

| 方法 | 50%缺失 PSNR/SSIM | 80%缺失 PSNR/SSIM | 95%缺失 PSNR/SSIM |
|------|-------------------|-------------------|-------------------|
| TV修复 | ~28/0.82 | ~22/0.60 | ~16/0.35 |
| DPIR | ~31/0.90 | ~26/0.78 | ~21/0.55 |
| DiffPIR | ~32/0.92 | ~28/0.85 | ~25/0.72 |

**关键观察**：
- 50%缺失：三种方法均可产生可接受的重建
- 80%缺失：扩散方法开始显示明显的生成能力——缺失区域的内容主要靠"生成"而非"恢复"
- 95%缺失：只有扩散方法能产生合理结果——此时问题已接近无条件生成，因为可用信息极少

**退化严重性与方法选择的关系**：

```
退化严重性（信息缺失程度）低 ──────────────────────── 高

方法选择：  优化      PnP      扩散采样
           快速足够   性价比高  唯一可行
```

## 多方法综合对比

### 定量对比总表

综合三个项目的定量结果：

| 问题 | 难度 | 优化PSNR/SSIM | PnP PSNR/SSIM | 扩散PSNR/SSIM |
|------|------|--------------|--------------|--------------|
| 去模糊 | 轻度 | ~30/0.85 | ~32/0.90 | ~33/0.92 |
| 去模糊 | 重度 | ~24/0.65 | ~27/0.78 | ~29/0.85 |
| 超分辨率 | 4× | ~24/0.65 | ~27/0.78 | ~28/0.82 |
| 超分辨率 | 8× | ~21/0.55 | ~24/0.68 | ~26/0.75 |
| 图像修复 | 50% | ~28/0.82 | ~31/0.90 | ~32/0.92 |
| 图像修复 | 80% | ~22/0.60 | ~26/0.78 | ~28/0.85 |
| 图像修复 | 95% | ~16/0.35 | ~21/0.55 | ~25/0.72 |

### 定性对比

三种方法在视觉特征上的差异：

**优化方法**：
- 重建过于平滑，丢失高频细节
- 边缘可能模糊或出现阶梯效应（TV）
- 不会"生成"不存在的内容——保守但信息缺失

**PnP方法**：
- 恢复部分细节，纹理比优化方法更丰富
- 偶尔出现不自然的伪影（去噪器的"偏好"泄漏）
- 在退化严重时恢复能力有限

**扩散方法**：
- 恢复最多细节，生成感知最优的结果
- 纹理最自然，与人眼对"真实图像"的判断一致
- 在严重退化时可"生成"合理的缺失内容
- 多次采样可产生不同的合理重建（不确定性量化）

### 计算效率-重建质量权衡

实际应用中需要在计算效率与重建质量之间权衡：

```
重建质量
  ▲
  │              ● 扩散采样
  │            ╱
  │          ╱
  │        ● PnP
  │      ╱
  │    ╱
  │  ● 优化
  │╱
  └──────────────────────▶ 计算时间
```

- 如果应用场景对时间敏感（如实时成像），选择优化或PnP方法
- 如果应用场景对质量敏感（如医学诊断），选择扩散方法
- 如果需要不确定性量化，扩散方法是唯一选择

## deepinv端到端代码模板

将三个项目的经验总结为通用管线代码模板：

```python
import torch
import deepinv as dinv

# ============================================================
# 步骤1：定义前向算子
# ============================================================
# 选择或自定义前向算子
physics = dinv.physics.Blur(...)        # 去模糊
# physics = dinv.physics.Downsampling(...) # 超分辨率
# physics = dinv.physics.Inpainting(...)   # 图像修复
# physics = CustomPhysics(...)             # 自定义

# 设定噪声模型
physics.set_noise_model(dinv.physics.GaussianNoise(sigma=0.05))

# 生成或加载测量数据
y = physics(x_true)

# ============================================================
# 步骤2：选择求解策略
# ============================================================
# 选项A：优化方法
# model = dinv.optim.ADMM(...)

# 选项B：PnP方法
model = dinv.optim.DPIR(
    denoiser=dinv.models.DRUNet(),
    params={"sigma": [0.1, 0.05, 0.025, 0.01]}
)

# 选项C：扩散方法
# model = dinv.sampling.DiffPIR(
#     denoiser=dinv.models.DiffUNet(),
#     data_fidelity="L2"
# )

# ============================================================
# 步骤3：准备先验/去噪器（已在步骤2中集成）
# ============================================================
# 注：步骤2中的denoiser参数即为步骤3——若需自监督训练，
# 参见第17章方法，训练完成后将denoiser传入求解器

# ============================================================
# 步骤4：运行求解
# ============================================================
x_hat = model(y, physics)

# ============================================================
# 步骤5：评估与不确定性量化
# ============================================================
psnr = dinv.utils.cal_psnr(x_hat, x_true)
ssim = dinv.utils.cal_ssim(x_hat, x_true)
print(f"PSNR: {psnr:.2f} dB, SSIM: {ssim:.4f}")

# 不确定性量化（仅扩散方法支持，需多次采样）
# samples = []
# for s in range(30):
#     torch.manual_seed(s)
#     x_s = model(y, physics)
#     samples.append(x_s)
# x_mean = torch.stack(samples).mean(dim=0)
# x_std = torch.stack(samples).std(dim=0)  # 不确定性图

# 可视化
dinv.utils.plot([x_true, y, x_hat],
                titles=["Ground Truth", "Measurement", "Reconstruction"])
```

### 管线设计原则

1. **前向算子与求解器解耦**：更换求解器无需修改前向算子定义
2. **统一接口**：所有求解器共享`model(y, physics)`调用接口
3. **噪声模型独立**：更换噪声模型无需修改前向算子和求解器
4. **可扩展性**：自定义算子和自定义求解器遵循相同的接口规范

端到端实战展示了扩散模型求解逆问题的强大能力，但我们目前只得到了一个点估计$\hat{x}$。对于许多应用（如医学诊断），仅有一个重建结果是不够的——我们还需要知道这个结果有多可靠。这就需要不确定性量化。

## 实验 18.4-1：端到端求解策略对比

实验 `18.4-1.py` 在统一框架下对比**优化方法（Tikhonov、TV 正则化）、PnP 方法（DPIR）和扩散方法（DiffPIR）**在六种退化场景中的重建质量与计算效率，验证 18.3 节的方法选择决策指南。

### 实验场景

实验构造六类逆问题场景，覆盖退化程度从轻到重的完整谱系：

**去模糊**：轻度模糊（高斯核 $\sigma_K=1.5$，噪声 $\sigma=0.01$）与重度模糊（高斯核 $\sigma_K=3.0$，噪声 $\sigma=0.05$）。

**超分辨率**：2 倍下采样（噪声 $\sigma=0.01$）与 4 倍下采样（噪声 $\sigma=0.01$），使用双三次抗混叠滤波。

**图像修复**：50% 像素缺失（噪声 $\sigma=0.01$）与 80% 像素缺失（噪声 $\sigma=0.01$）。

每类场景均使用相同的测试图像（celeba_example.jpg，$256 \times 256$），并在相同观测下对比四种重建方法：Tikhonov 正则化（梯度下降，$\lambda=0.1$，100 次迭代）、TV 正则化（PGD/ADMM，$\lambda=0.05$，30 次迭代）、DPIR（PnP-HQS，DRUNet 去噪器，递减噪声调度 $[0.1, 0.05, 0.025, 0.01]$）和 DiffPIR（扩散去噪器 DiffUNet，100 步采样）。

### 实验目的

1. **验证退化严重性与方法选择的关系**：轻度退化时优化方法性价比最高，重度退化时扩散方法优势最大
2. **对比三类方法的计算效率-重建质量权衡**：优化方法秒级完成但质量有限，PnP 方法秒级且质量较好，扩散方法分钟级但质量最优
3. **观察不同方法的重建视觉特征**：Tikhonov 过度平滑、TV 保边但可能阶梯效应、DPIR 恢复细节但偶尔过平滑、DiffPIR 生成感知最优的纹理
4. **量化伴随重建（$A^\top y$）的基线水平**：伪逆重建作为无先验基线，展示先验信息的价值

### 实验输入

| 参数 | 设置 |
|------|------|
| 测试图像 | celeba_example.jpg，$256 \times 256$ 像素 |
| 去模糊场景 | 轻度：$\sigma_K=1.5, \sigma=0.01$；重度：$\sigma_K=3.0, \sigma=0.05$ |
| 超分场景 | 2 倍/4 倍下采样，bicubic 抗混叠，$\sigma=0.01$ |
| 修复场景 | 50%/80% 像素缺失，$\sigma=0.01$ |
| Tikhonov | $\lambda=0.1$，100 次梯度下降，自适应步长（幂迭代估计 $\|A\|^2$） |
| TV 正则化 | $\lambda=0.05$，PGD/ADMM 30 次迭代 |
| DPIR | DRUNet 去噪器，噪声调度 $[0.1, 0.05, 0.025, 0.01]$ |
| DiffPIR | DiffUNet 扩散去噪器，100 步采样 |

### 预期结果

- **轻度退化**（轻度模糊）：Tikhonov 和 DiffPIR 均可达到较高 PSNR（$\approx 27$ dB），简单正则化已足够有效；但 TV 和 DPIR 的表现受参数选择影响较大，可能反而不如 Tikhonov
- **中度退化**（重度模糊、2 倍超分）：学习型先验（DPIR、DiffPIR）在超分场景中显著优于优化方法（$>14$ dB 提升）；重度模糊下 Tikhonov 和 DiffPIR 表现接近
- **严重退化**（4 倍超分）：DPIR 和 DiffPIR 保持 29-30 dB，而优化方法降至 10-12 dB，扩散方法优势最大（$>18$ dB 提升）
- **修复场景**（50%/80% 缺失）：TV 正则化表现最稳健（19-21 dB），显式先验在高缺失比例下比学习型先验更可靠
- **计算时间**：优化方法秒级（$<5$ s），PnP 方法 30-40 s，扩散方法 10-20 s（DiffPIR 因扩散步数少而较快）
- **伴随重建**：无先验基线 PSNR 最低，尤其在超分和修复场景中严重退化，验证先验信息的必要性

#### 核心知识点总结

| 知识点 | 实验验证 |
|--------|---------|
| 退化严重性与方法选择 | 轻度退化：优化方法性价比最高；重度退化：PnP/扩散方法优势显著 |
| 计算效率-质量权衡 | 优化方法秒级（$<5$ s），PnP 方法 30-40 s，扩散方法 10-20 s |
| 先验信息的价值 | 伴随重建（无先验）PSNR 最低，尤其在超分和修复场景中严重退化 |
| 学习型先验 vs 显式先验 | 超分场景：DPIR/DiffPIR 显著优于 Tikhonov/TV；修复场景：TV 更稳健 |
| 扩散方法的生成能力 | 4 倍超分下 DiffPIR 恢复 29 dB 纹理细节，而 Tikhonov 仅 12 dB |

> **实践启示**：实验结果验证了 18.3 节的决策树——轻度退化时优先选择优化方法（快速且足够好），重度退化时选择 PnP 或扩散方法（质量最优）。修复场景下 TV 正则化的稳健表现提醒我们：显式先验在特定问题中可能比学习型先验更可靠，方法选择需结合具体应用场景。
