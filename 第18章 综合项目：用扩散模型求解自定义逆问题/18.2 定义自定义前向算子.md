# 18.2 定义自定义前向算子

> **核心观点**：前向算子$\mathcal{A}$将图像空间映射到测量空间，是逆问题的"物理引擎"。定义准确的前向算子是求解逆问题的第一步，也是决定重建质量上限的关键。deepinv的Physics类提供了灵活的框架，使得自定义算子的实现和验证变得简单。

## 前向算子的数学描述

逆问题的核心是前向模型——它描述了从真实图像$x$到测量数据$y$的映射关系。在第1章中我们已经建立了这一框架：

### 线性前向模型

最常见的情形是线性前向模型加噪声：

$$y = Ax + \epsilon$$

其中$A \in \mathbb{R}^{m \times n}$（或更一般地，$A: \mathbb{R}^n \to \mathbb{R}^m$）是前向算子，$\epsilon$是噪声。

不同逆问题对应不同的前向算子：

| 逆问题 | 前向算子$A$ | 退化效果 | deepinv类 |
|--------|------------|---------|----------|
| 去噪 | $A = I$（恒等） | 加性噪声 | `Denoising` |
| 去模糊 | $A = K$（卷积核） | 模糊+噪声 | `Blur` |
| 超分辨率 | $A = DS$（下采样×模糊） | 低分辨率+噪声 | `Downsampling` |
| 图像修复 | $A = M$（掩码矩阵） | 像素缺失+噪声 | `Inpainting` |
| CT重建 | $A = \mathcal{R}$（Radon变换） | 投影数据+噪声 | `Tomography` |
| MRI重建 | $A = \mathcal{F}_u$（欠采样傅里叶） | k-space缺失+噪声 | `MRI` |
| 压缩感知 | $A = \Phi$（随机感知矩阵） | 随机投影+噪声 | 自定义 |

### 非线性前向模型

某些逆问题的前向模型是非线性的：

$$y = \mathcal{A}(x) + \epsilon$$

例如：
- 相位恢复：$y = |\mathcal{F}(x)|^2 + \epsilon$（强度测量丢失相位）
- 盲去卷积：$y = K * x + \epsilon$，$K$本身未知
- PET重建：测量与衰减系数的关系是非线性的

非线性前向模型的梯度需要通过链式法则计算，在deepinv中通过`NonLinearPhysics`类处理。本章主要聚焦于更常见的线性情形。

### 自定义逆问题的核心

面对一个书中未涉及的全新逆问题，核心任务就是**选择或定义合适的$A$**。这要求：
1. 理解物理测量过程——$A$应该忠实地描述从$x$到$y$的物理变换
2. 能够实现高效的矩阵-向量乘法$Ax$和$A^\top y$
3. 了解噪声特性以选择正确的噪声模型

## deepinv Physics类设计哲学

deepinv库的Physics模块围绕三个核心原则设计：

### 原则一：前向算子与伴随算子成对定义

对于线性算子$A$，几乎所有求解算法都需要伴随算子$A^\top$（或Hermitian转置$A^H$）。例如：
- 梯度下降：$x_{k+1} = x_k - \alpha A^\top(Ax_k - y)$
- PnP-ADMM：需要$A^\top$计算数据一致性步骤
- DPS/DiffPIR：需要$A^\top$计算似然梯度

deepinv要求自定义算子同时实现`A(x)`和`A_adjoint(y)`两个方法，确保二者的一致性。

### 原则二：噪声模型与确定性退化分离

前向过程可以分解为两步：
1. 确定性退化：$\tilde{y} = Ax$
2. 随机噪声：$y = \tilde{y} + \epsilon$

这种分离使得：
- 更换噪声模型无需修改前向算子
- 同一前向算子可用于不同噪声水平的实验
- 便于比较不同噪声模型的影响

### 原则三：算子可组合

复杂的前向模型可以通过简单算子的组合构建：

$$A_{\text{composed}} = A_2 \circ A_1$$

例如，超分辨率的前向算子是模糊+下采样：$A = D \cdot S$。deepinv支持这种组合操作。

### 核心类层次

deepinv的Physics类层次如下：

```
Physics（基类）
├── LinearPhysics（线性算子）
│   ├── Denoising（A=I）
│   ├── Blur / BlurFFT（卷积模糊）
│   ├── Downsampling（下采样+抗混叠）
│   ├── Inpainting（像素掩码）
│   └── Tomography（Radon变换）
├── DecomposablePhysics（可SVD分解的线性算子）
│   └── MRI（傅里叶采样）
└── NonLinearPhysics（非线性算子）
```

**关键方法**（以`LinearPhysics`为例）：

| 方法 | 数学对应 | 功能 |
|------|---------|------|
| `A(x)` | $y = Ax$ | 前向运算 |
| `A_adjoint(y)` | $z = A^\top y$ | 伴随运算 |
| `A_dagger(y)` | $\hat{x} = A^\dagger y$ | 伪逆（最小二乘解） |
| `noise(x)` | $y + \epsilon$ | 加噪 |
| `adjointness_test(x)` | $\langle Ax,y\rangle = \langle x,A^\top y\rangle$ | 伴随验证 |
| `compute_norm(x)` | $\|A\|_2$ | 算子范数（幂迭代） |

## 自定义线性前向算子

### 基本步骤

定义自定义线性前向算子的基本步骤是：

1. **继承`LinearPhysics`类**
2. **实现`A(x)`方法**：定义前向映射$y = Ax$
3. **实现`A_adjoint(y)`方法**：定义伴随映射$z = A^\top y$
4. **设定噪声模型**：通过`set_noise_model()`方法

### 实例：多视角下采样算子

我们以MiniProject_DefiningOperator中的多视角下采样问题为例，演示自定义算子的完整实现。

**问题定义**：我们有$J$个测量向量$y_1, \ldots, y_J$，每个视角的测量模型为：

$$y_j = A \, T_j \, x + \epsilon_j, \quad j = 1, \ldots, J$$

其中$A$是下采样算子（如4倍下采样），$T_j$是仿射变换（旋转+平移+缩放），$\epsilon_j$是高斯噪声。

将所有视角拼接，整体前向模型为：

$$y = \begin{pmatrix} AT_1 \\ AT_2 \\ \vdots \\ AT_J \end{pmatrix} x + \epsilon$$

**代码实现框架**：

```python
import torch
import deepinv as dinv

class MultiViewPhysics(dinv.physics.LinearPhysics):
    def __init__(self, base_physics, transf=None, device='cpu', **kwargs):
        super().__init__(**kwargs)
        self.base_physics = base_physics  # 下采样算子 A
        self.transf = transf              # 仿射变换 T_j, shape (J, 2, 3)
        self.device = device

    def A(self, x, **kwargs):
        """前向运算: y_j = A * T_j * x"""
        J = self.transf.shape[0]
        y_list = []
        for j in range(J):
            # 应用仿射变换 T_j
            grid = torch.nn.functional.affine_grid(
                self.transf[j:j+1], x.shape, align_corners=False
            )
            x_transformed = torch.nn.functional.grid_sample(
                x, grid, align_corners=False
            )
            # 应用基础算子 A（下采样+噪声由base_physics处理）
            y_j = self.base_physics.A(x_transformed)
            y_list.append(y_j)
        # 拼接所有视角: shape (batch, J, C, H', W')
        return torch.stack(y_list, dim=1)

    def A_adjoint(self, y, **kwargs):
        """伴随运算: x = sum_j T_j^T * A^T * y_j

        注意：仿射变换的伴随算子涉及逆变换和散布操作，
        手动实现容易出错。这里使用deepinv的自动伴随函数
        （见18.2.4节），可确保正确性。
        """
        # 推荐方式：使用自动伴随函数（adjoint_function）
        # 以下为概念性代码框架，实际实现建议使用 autograd
        x = torch.zeros(...)  # 原始图像尺寸
        J = y.shape[1]
        for j in range(J):
            # 基础算子的伴随
            z_j = self.base_physics.A_adjoint(y[:, j, ...])
            # 仿射变换的伴随——推荐使用自动微分计算
            # 手动实现需要逆仿射矩阵+scatter操作，容易出错
            # 这里用 autograd 的 adjoint_function 确保正确性
            x = x + self._adjoint_affine(z_j, j)
        return x

    def _adjoint_affine(self, z, j):
        """仿射变换的伴随——使用自动微分计算"""
        from deepinv.physics import adjoint_function
        def apply_Tj(x):
            grid = torch.nn.functional.affine_grid(
                self.transf[j:j+1], x.shape, align_corners=False
            )
            return torch.nn.functional.grid_sample(x, grid, align_corners=False)
        adj_fn = adjoint_function(apply_Tj, z.shape)
        return adj_fn(z)

    def update_parameters(self, transf=None, **kwargs):
        """更新仿射变换参数"""
        if transf is not None:
            self.transf = transf
```

**关键实现细节**：

1. **仿射变换$T_j$**：使用`torch.nn.functional.affine_grid`和`grid_sample`实现空间变换，支持旋转、平移、缩放和剪切
2. **前向运算**：对每个视角先做仿射变换再做下采样
3. **伴随运算**：对每个视角做下采样的伴随（上采样）再做仿射变换的伴随，然后求和
4. **参数更新**：通过`update_parameters`方法动态更新仿射变换参数

### 实例：自定义卷积模糊算子

除了deepinv内置的`Blur`类，我们也可以定义自己的模糊核：

```python
import torch
import deepinv as dinv

# 构建运动模糊核
def motion_blur_kernel(length=15, angle=0):
    """创建运动模糊核"""
    kernel = torch.zeros(length, length)
    center = length // 2
    cos_a, sin_a = torch.cos(torch.tensor(angle)), torch.sin(torch.tensor(angle))
    for i in range(length):
        offset = i - center
        row = int(center + offset * sin_a)
        col = int(center + offset * cos_a)
        if 0 <= row < length and 0 <= col < length:
            kernel[row, col] = 1
    return kernel / kernel.sum()

# 使用deepinv内置模糊算子
kernel = dinv.physics.blur.gaussian_blur(sigma=(3, 3))
physics = dinv.physics.Blur(img_size=(3, 256, 256), filter=kernel)
physics.set_noise_model(dinv.physics.GaussianNoise(sigma=0.02))
```

## 伴随算子的验证

### 为什么需要验证伴随算子

伴随算子的正确性是所有基于梯度的求解方法的前提条件：

- **梯度下降**需要$A^\top$来计算梯度$\nabla_x \|Ax - y\|^2 = 2A^\top(Ax - y)$
- **PnP方法**需要$A^\top$来执行数据一致性步骤
- **扩散采样方法**（DPS/DiffPIR）需要$A^\top$来计算似然梯度

如果伴随算子实现错误，梯度方向就不正确，迭代算法可能：
- 收敛到错误的解
- 震荡不收敛
- 产生难以解释的伪影

### 内积检验法

验证伴随算子正确性的标准方法是**内积检验法**（Dot product test）：

$$\langle Ax, y \rangle = \langle x, A^\top y \rangle \quad \forall x, y$$

即对随机向量$x$和$y$，验证：

$$\frac{|\langle Ax, y \rangle - \langle x, A^\top y \rangle|}{|\langle Ax, y \rangle|} < \epsilon$$

其中$\epsilon$应接近机器精度（$\sim 10^{-10}$到$10^{-14}$）。

**deepinv中的验证工具**：

```python
# 方法1：使用内置的adjointness_test
x = torch.randn(1, 3, 256, 256)
result = physics.adjointness_test(x)
print(f"伴随验证结果: {result}")  # 应接近0

# 方法2：手动验证
x = torch.randn(1, 3, 256, 256)
y = torch.randn_like(physics.A(x))

lhs = torch.sum(physics.A(x) * y)      # <Ax, y>
rhs = torch.sum(x * physics.A_adjoint(y))  # <x, A^T y>
relative_error = abs(lhs - rhs) / abs(lhs)
print(f"相对误差: {relative_error}")   # 应 < 1e-10
```

### 自动伴随算子

如果伴随算子的手动实现困难或容易出错，deepinv提供了基于PyTorch自动微分的自动伴随算子：

```python
# 使用自动微分计算伴随
from deepinv.physics import adjoint_function

# 自动计算 A^T y
auto_adjoint = adjoint_function(physics.A, x.shape)
z = auto_adjoint(y)  # 等价于 A^T y
```

自动伴随算子的原理是利用PyTorch的`torch.autograd.grad`接口，通过向量-Jacobian乘积（vJP）计算$A^\top y$。其优势是无需手动推导伴随，缺点是计算效率略低于手动实现。

### 常见错误与排查

实现伴随算子时的常见错误：

| 错误类型 | 表现 | 排查方法 |
|---------|------|---------|
| 边界条件不匹配 | 内积检验误差$\sim 10^{-3}$到$10^{-5}$ | 检查零填充vs循环卷积的一致性 |
| 仿射变换逆计算错误 | 伴随验证通过但重建质量差 | 用简单变换（纯平移）验证 |
| 下采样与上采样不匹配 | 伪逆结果有棋盘格伪影 | 确认上采样使用与下采样匹配的插值方式 |
| 维度顺序错误 | shape不匹配或结果异常 | 打印中间结果的shape |
| 忘记归一化 | 重建结果幅度偏大或偏小 | 检查kernel是否归一化、变换矩阵是否单位行列式 |

## 噪声模型的选择

噪声模型决定了似然函数$p(y|x)$的形式，进而影响求解方法中数据项的选择。

### 常见噪声模型

**高斯噪声**：

$$y = Ax + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2 I)$$

- 似然：$p(y|x) \propto \exp\left(-\frac{1}{2\sigma^2}\|Ax - y\|^2\right)$
- 数据项：$\|Ax - y\|^2$（L2数据项）
- 适用场景：热噪声、电子噪声、大多数通用场景
- deepinv：`GaussianNoise(sigma=0.05)`

**泊松噪声**：

$$y \sim \text{Poisson}(Ax / \text{gain}) \times \text{gain}$$

- 似然：$p(y|x) = \prod_i \frac{(A_i x / \text{gain})^{y_i/\text{gain}}}{(y_i/\text{gain})!} e^{-A_i x / \text{gain}}$
- 数据项：KL散度$\sum_i y_i \log(y_i / A_i x) - (y_i - A_i x)$（第1章1.4节）
- 适用场景：光子计数（CT、PET、天文成像）
- deepinv：`PoissonNoise(gain=1.0)`

**泊松-高斯混合噪声**：

$$y = \text{Poisson}(Ax / \text{gain}) \times \text{gain} + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2 I)$$

- 适用场景：低光成像（Cryo-EM、荧光显微镜）
- deepinv：`PoissonGaussianNoise(gain=1.0, sigma=0.1)`

### 噪声模型对求解策略的影响

噪声模型不仅影响似然函数的形式，还决定了哪些求解方法适用：

| 噪声模型 | 优化方法 | PnP方法 | 扩散方法 |
|---------|---------|---------|---------|
| 高斯 | ✅ L2数据项 | ✅ DPIR | ✅ DPS/DiffPIR |
| 泊松 | ✅ KL数据项 | 🟡 需修改数据项 | 🟡 需修改似然 |
| 泊松-高斯 | ✅ 混合数据项 | 🟡 需修改数据项 | 🟡 需修改似然 |

**注意**：大多数PnP和扩散方法的默认实现假设高斯噪声。对于非高斯噪声，需要相应地修改数据一致性步骤中的损失函数。这是实践中容易忽略的问题。

### 在deepinv中设定噪声模型

```python
# 高斯噪声
physics.set_noise_model(dinv.physics.GaussianNoise(sigma=0.05))

# 泊松噪声
physics.set_noise_model(dinv.physics.PoissonNoise(gain=1.0))

# 泊松-高斯混合噪声
physics.set_noise_model(dinv.physics.PoissonGaussianNoise(gain=1.0, sigma=0.1))

# 生成含噪测量
y = physics(x)  # 自动执行 A(x) + noise
```

有了正确的前向算子和噪声模型，下一步是选择合适的求解策略。不同的逆问题和不同的性能需求对应不同的方法——从快速的优化方法到强大的扩散采样。
