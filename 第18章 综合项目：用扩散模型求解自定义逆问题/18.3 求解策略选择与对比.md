# 18.3 求解策略选择：优化、PnP、扩散——你的"前一步"决定了"这一步怎么选"

> 前向算子 $A$ 和噪声模型定好了，似然 $p(y|x)$ 就定了。现在问题来了：**怎么从这一个 $y$ 倒推出 $x$？** 很多人一上来就选最炫的扩散模型，结果跑半小时，发现其实用 2 秒的 TV 正则化就够了。这一节教你用一张"决策树"把方法选对——什么时候该快、什么时候该强、什么时候非得要"不确定性"。

读完这节，你应该能：
- 用 when/why/how 讲清优化、PnP、扩散三类方法各自卡在哪、强在哪；
- 看懂"扩散先验即去噪器当先验"这句全书收官的话是怎么落到代码上的；
- 对着一个新问题，画出该走哪条路的决策树。

## 18.3.1 优化类方法：最快，但只给你一个点（第 3 章）

### when / why / how

- **什么时候用**：问题轻度退化、你要快、你不需要知道"靠不靠谱"、你手头有现成的显式先验（比如"图应该平滑"）。
- **为什么难**：逆问题不适定，直接求 $Ax=y$ 要么无解要么无穷多解。所以第 3 章的办法是**加一个正则项当"刹车"**，把解拉向"合理的图"。
- **怎么做**：解一个带正则的最优化问题（MAP 估计，白话：在"别和测量差太远"和"别太不像图"之间找平衡）。

为什么需要这个公式？因为你不能只盯着一个 $y$ 硬猜——一个观测对应无数张可能的图，得用"先验"当裁判挑出最合理那张。把"别和测量差太远"和"别太不像图"两件事压成一个数，求它最小化的 $x$：

$$\hat{x}_{\text{MAP}} = \arg\min_x \underbrace{\frac{1}{2\sigma^2}\|Ax - y\|^2}_{\text{数据项（似然）}} + \underbrace{\lambda R(x)}_{\text{正则项（先验）}}$$

根据 $R(x)$ 长啥样，挑算法：
- **梯度下降**（$R$ 光滑，如 Tikhonov $R=\|x\|^2$）：
  $$x_{k+1} = x_k - \alpha\left(\frac{1}{\sigma^2}A^\top(Ax_k - y) + \lambda \nabla R(x_k)\right)$$
  步长 $\alpha$ 得满足 $\alpha \le 1/L$（$L$ 是 Lipschitz 常数，管收敛）。
- **ISTA/FISTA**（$R$ 不可微但可分，如 $R=\|x\|_1$）：用"近端算子" $\text{prox}$ 代替梯度步，FISTA 用 Nesterov 加速把收敛从 $O(1/k)$ 提到 $O(1/k^2)$。
- **ADMM / Chambolle-Pock**：适合复合或 TV 这类非光滑正则。

### 优势 vs 局限（直说）

- ✅ 快（10–100 次迭代）、理论牢、不用训网络、每步意义清楚。
- ❌ **只给一个点 $\hat x$**——第 3 章就警告过，MAP 把不确定性整个扔了；重建质量被显式先验 $R(x)$ 的天花板卡住（高斯→糊，TV→阶梯）；还得手调 $\lambda$。

> **点 vs 分布（这里第一次点题）**：优化方法像个"下结论的人"——它只递给你一张图，不告诉你"这张图周围还有多少种可能"。而 18.5 的扩散方法像个"给整片可能性云"的人。你要的到底是结论，还是可能性？这决定了你走不走优化这条路。

deepinv 里就是 `deepinv.optim` 下的 `ADMM` / `HQS` 等。

## 18.3.2 PnP 类方法：把"去噪器"当先验用（第 5 章）

### when / why / how

- **什么时候用**：你有/能训一个去噪器；想要比手写先验更好的质量；但还是只要一个点、速度还得凑合。
- **为什么难**：显式先验 $R(x)$ 写不出好图像统计。第 5 章的洞见是——**别写 $R$ 了，直接用去噪器 $D_\sigma$ 替掉近端算子**。
- **怎么做**：在 ADMM/HQS 分裂框架里，把"往先验拉一步"换成"去噪一步"。

为什么这招合法？因为第 5 章的 Tweedie 等式说：去噪器擦一步 = 沿得分方向走一步。于是"近端算子"（白话：往先验方向拉一步）直接被去噪器取代：

$$\text{prox}_{\lambda R}(\cdot) \approx D_\sigma(\cdot)$$

而 Tweedie 把去噪器写成了"当前图 + 得分×噪声方差"的形式，这让你看清它本质就是个得分/先验：

$$D_\sigma(x) = x + \sigma^2 \nabla_x \log p_\sigma(x)$$

**PnP-ADMM**：把 ADMM 里的近端换成去噪器：
1. $x$-更新（数据一致性）：$x_{k+1} = (A^\top A + \rho I)^{-1}(A^\top y + \rho(z_k - u_k))$
2. $z$-更新（去噪替代近端）：$z_{k+1} = D_\sigma(x_{k+1} + u_k)$
3. 对偶更新：$u_{k+1} = u_k + x_{k+1} - z_{k+1}$

**PnP-HQS / DPIR**：半二次分裂，更轻。DPIR（Zhang et al. 2021）还玩了个聪明的招——**噪声水平 $\sigma_k$ 逐轮递减**，先大步走（大幅修正）再小步走（精修）。这思路和扩散模型的噪声调度异曲同工。

### 优势 vs 局限

- ✅ 不用手写先验；去噪器学到的统计比 $R(x)$ 丰富；同一 DRUNet 跨任务复用；速度中等（10–50 次去噪调用）。
- ❌ 还是点估计（要不确定性得接 PnP-ULA，第 5 章）；收敛性依赖去噪器性质（非扩张才稳）；分布偏移会掉链子。

```python
from deepinv.optim import DPIR
model = DPIR(denoiser=dinv.models.DRUNet(),
             params={"sigma": [0.1, 0.05, 0.025, 0.01]})  # 递减噪声调度
x_hat = model(y, physics)
```

## 18.3.3 扩散采样类方法：直接从后验里"取样"（第 7、13 章）

### when / why / how

- **什么时候用**：你要不确定性量化；退化很严重（测量快没信息了）；质量优先、算力和时间管够；或者你想"零样本"套用预训练模型。
- **为什么难**：后验 $p(x|y)$ 是个高维分布，积分算不出、采样又难。第 13 章的答案是——**条件扩散采样**，直接从这个分布里抽 $x$。
- **怎么做**：贝叶斯定理把后验拆成似然×先验。

为什么贝叶斯定理是这步的"发动机"？因为逆问题真正想要的不是一个点，而是"哪些 $x$ 更可能成立"。贝叶斯定理正把"后验"拆成两个你都拿得到的零件——似然（你的测量告诉我啥）和先验（自然图长啥样）：

$$p(x|y) \propto \underbrace{p(y|x)}_{\text{似然}} \underbrace{p(x)}_{\text{先验}}$$

扩散的逆向过程里，把"得分"（白话：指向高概率方向的梯度）拆成两半（这是第 13 章的心脏公式，先白话后公式）：
- 一半是**无条件得分** $\nabla_x\log p(x_t)$——由你预训的扩散模型提供，它知道"自然图长啥样"；
- 一半是**似然梯度** $\nabla_x\log p(y|x_t)$——保证"和你的测量一致"。

把这两股力加在一起，就是"既像真图、又贴合测量"的后验得分：

$$\nabla_x \log p(x_t|y) = \underbrace{\nabla_x \log p(x_t)}_{\text{无条件得分（先验）}} + \underbrace{\nabla_x \log p(y|x_t)}_{\text{似然梯度（保真）}}$$

### 三大算法对比（先认脸，再记公式）

| 维度 | DPS | DDRM | DiffPIR |
|------|-----|------|---------|
| 提出者 | Chung et al. 2023 | Kawar et al. 2022 | Zhu et al. 2023 |
| 条件化方式 | 梯度替换 | SVD 分解+条件采样 | PnP+扩散混合 |
| 核心公式 | $\nabla\log p(x_t\|y) \approx s_\theta + \nabla\log p(y\|\hat{x}_0)$ | $x_t = V(\Sigma^+ U^\top y + \bar{\Sigma}^{-1}z)$ | 数据一致性步+去噪步交替 |
| 算子要求 | 需 $A$ 和 $A^\top$ | 需 SVD 分解 | 需 $A$ 和 $A^\top$ |
| 适用范围 | 任意线性/非线性 | 仅可 SVD 的线性 | 任意线性 |
| deepinv | ✅ `DiffPIR`（参数化实现） | — | ✅ `DiffPIR` |

> 注意：deepinv 的 `DiffPIR` 靠不同参数既能跑 DPS 也能跑 DiffPIR。DDRM 要算 $A$ 的 SVD，对大算子（高分辨率 CT）代价高，deepinv 求解器 API 暂未直接支持；可 SVD 的（如 MRI 傅里叶采样）可用 `DecomposablePhysics` 配自定义采样。

> **承接说明**：DPS / DDRM / DiffPIR 三类方法的理论背景、推导与完整算法已在第 13 章 13.3 系统讲解（DPS 见 13.3.2，DiffPIR 见 13.3.4，DDRM 见 13.3.1 及附录 13B）。本节只站在"综合项目选型"的角度浓缩它们的公式与工程口径，不再重推推导。

**DPS 详解**（最通用的一个）：逆向 SDE 里把后验得分替换进去

$$dx_t = [f(x_t,t) - g(t)^2 \nabla_{x_t}\log p(x_t|y)]dt + g(t)d\bar{w}$$

难点是 $\nabla_{x_t}\log p(y|x_t)$ 在噪声图 $x_t$ 上算不出。DPS 用 Tweedie 估计 $\hat{x}_0=\mathbb{E}[x_0|x_t]$（"当前这一步大概对应哪张干净图"）去近似：

$$\nabla_{x_t}\log p(y|x_t) \approx \nabla_{x_t}\log p(y|\hat{x}_0(x_t))$$

白话：我先猜一下这步对应的干净图 $\hat x_0$，再用它算"和测量差多少"的梯度，拽着采样往测量靠。

**DDRM 详解**：利用 $A=U\Sigma V^\top$ 的 SVD，在奇异值空间里每个方向独立采样，理论优雅，但要求 SVD 算得动。

**DiffPIR 详解**：把逆向扩散重新解释成 PnP 迭代——每步先"数据一致性"（往测量靠），再"去噪"（往先验靠）：
1. 数据一致性：$x_t^{\text{DC}} = x_t - \eta_t A^\top(A\hat{x}_0 - y)$
2. 去噪：$x_{t-1} = D_{\sigma_t}(x_t^{\text{DC}})$
和 DPIR 同构，只是去噪器换成扩散专用的 DiffUNet，先验更强。

### 优势 vs 局限

- ✅ **后验采样**（天然量化不确定性，18.5 详述）；生成式先验（学的是整图分布 $p(x)$）；零样本迁移；退化越重越能打。
- ❌ 慢（100–1000 次去噪前向）；要预训练扩散模型；条件化是近似，偶尔"过度生成"；调参（步长 $\eta_t$、调度）影响大。

## 18.3.4 方法选择决策指南：一张树，别拍脑袋

把上面三类的"什么时候"拧成一棵树：

```
需要不确定性量化吗？
├── 是 → 扩散采样类（多次后验采样 → 置信区间）
└── 否 → 有预训练去噪器 / 扩散模型吗？
          ├── 是 → 退化严重吗？
          │        ├── 严重（高噪/大欠采样）→ 扩散采样类
          │        └── 轻度（低噪/小欠采样）→ PnP 类（更快）
          └── 否 → 有显式先验吗？
                    ├── 是 → 优化类
                    └── 否 → 自监督训去噪器（第17章）→ PnP / 扩散类
```

### 计算效率（心里有个数）

| 方法 | 迭代次数 | 每次成本 | 典型耗时 |
|------|---------|---------|---------|
| 优化(TV) | 50–200 | $A+A^\top$ | 秒级 |
| PnP(DPIR) | 10–50 | $A+A^\top+D_\sigma$ | 秒级 |
| 扩散(DiffPIR) | 100–1000 | $A+A^\top+D_\sigma^{\text{diff}}$ | 分钟级 |

### 质量规律（一句口诀）

- 轻度退化：三类差不多，优化性价比最高；
- 中度退化：PnP 开始明显超过优化；
- 严重退化：扩散优势最大，能捡回别的捡不回的细节。

> **因果串联收尾**：选好策略，$A$、噪声、先验、求解器就齐了。下一节（18.4）我们端到端真刀真枪跑三个项目——去模糊、超分、修复，把"退化越重、扩散越香"这句话用数字坐实。

deepinv 统一接口一览（注意所有方法都共用 `model(y, physics)`）：

```python
from deepinv.optim import ADMM, DPIR
from deepinv.sampling import DiffPIR

# 优化（TV）
# model = ADMM(...)
# PnP
model_dpir = DPIR(denoiser=dinv.models.DRUNet(), params={"sigma": [0.1,0.05,0.025,0.01]})
# 扩散
model_diffpir = DiffPIR(denoiser=dinv.models.DiffUNet(), data_fidelity="L2")
x_hat = model(y, physics)   # 三种方法同一个调用姿势
```

## 18.3.5 扩散加速采样：谁说非得 1000 步

上表把扩散写在"分钟级"，这是它如今唯一的短板。但"慢"不是扩散的宿命——加速是扩散近年最活跃的方向之一。先建立两个直觉，你就不会再被"1000 步"吓到。

**直觉一：逆向过程有条"确定性捷径"。** 第 7 章讲过逆向 SDE $dx = [f(x,t) - g(t)^2\nabla_x\log p_t(x)]\,dt + g(t)\,d\bar w$ 带一个随机项 $d\bar w$。这条 SDE 存在一条对应的**概率流 ODE（probability flow ODE）**——去掉随机项、把涨落折进一个修正的漂移项，但每时刻的边缘分布 $p_t(x)$ 一模一样。既然分布不变，你完全可以**沿这条 ODE 做确定性积分**来采样，不必每步重新注入噪声。而 ODE 允许大步跨——这正是 DDIM 能从 1000 步降到 20–50 步、质量只微降的原因。

**直觉二：步数还能"砸"成一步。** 若还不满足于 ODE 大步，可以训练一个函数**直接从任意噪声水平一步映射回干净图**——把整条逆向链"蒸馏"进一个快模型。这就是一致性模型、LCM、引导蒸馏的思路，把步数压到 1–8。代价是要多花一次蒸馏 / 训练，但推理时真正"实时"。

四类主流路线的"加速-质量-代价"格局：

| 路线 | 原理 | 典型步数 | 代价 |
|------|------|---------|------|
| DDIM（Song et al. 2021） | 沿概率流 ODE 确定性积分（隐式采样） | 20–50 | 零（仅换采样器） |
| DPM-Solver（Lu et al. 2022） | 对概率流 ODE 用高阶数值解 / 指数积分器 | 10–25 | 零（仅换采样器） |
| 引导蒸馏（guidance distillation） | 把增广引导项蒸馏进模型再采样 | 4–8 | 需额外蒸馏训练 |
| 一致性模型 / LCM | 学"任意噪声→干净图"一步映射 | 1–2 | 需额外蒸馏训练 |

关键提醒：前两类（DDIM、DPM-Solver）**不需要任何额外训练**，只要换一个采样器——所以深潜项目里几乎总是默认开箱即用，先把推理成本降一两个数量级。

> **在逆问题里的注意**：加速主要作用在**先验步**。当你的求解器额外叠了条件引导（DPS / DiffPIR 的数据一致梯度），步数太少会让引导项"来不及"把轨迹拉向测量。实践中 DDIM 配 20–50 步对多数逆问题够用；若还想更大跨步，要配合"一步先验 + 多轮引导"那一类变体。具体数值与 deepinv 的接法见 18.6.4。

## 收尾：为什么这一节重要

这一节的核心只有一句话：**先验越强、测量越弱，你就越该用会"编图"的方法**。优化只给一个点、PnP 也是点但先验更聪明、扩散直接给你一整片云——三代方法不是谁取代谁，而是"你愿意为不确定性付多少代价"的阶梯。把决策树刻进脑子，下一节我们就能让它跑起来。
