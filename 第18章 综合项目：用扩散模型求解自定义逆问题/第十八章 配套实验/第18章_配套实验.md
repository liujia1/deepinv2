## 实验18.1：自定义前向算子与伴随验证

**对应知识点**: 18.2节（定义自定义前向算子）

### 实验内容

| Step | 内容 | 知识点 | 原创 |
|------|------|--------|------|
| 1 | deepinv Physics类体系与设计三原则 | Physics类设计：配对性、噪声分离、可组合性 | |
| 2 | 实现多视角下采样算子 MultiViewPhysics | 自定义LinearPhysics子类，A(x)与A_adjoint(y) | |
| 3 | 伴随验证与自伴随检测 | dot product test，autograd自动伴随 | ★ |
| 4 | 噪声模型对比 | 高斯/泊松/泊松-高斯复合噪声 | ★ |
| 5 | 自定义模糊核与MRI掩模算子 | 算子可组合性验证 | ★ |

### 预期结果

- MultiViewPhysics前向输出: (B, J, C, H/4, W/4) 的多视角低分辨率图像
- 伴随验证: 相对误差 < 1e-3（通过）
- autograd自动伴随误差通常比手动伴随更小
- 泊松噪声残差分布非高斯（信号依赖性）
- 组合算子伴随误差与子算子同量级

### 素材来源

- MiniProject_DefiningOperator.ipynb: 多视角算子实现思路
- deepinv Physics API: LinearPhysics, Downsampling, Blur, MRI等

### 运行方式

```bash
python 18.1.py
```

## 实验18.2：端到端求解策略对比

**对应知识点**: 18.3节（求解策略选择与对比）、18.4节（端到端实战）

### 实验内容

| Step | 内容 | 知识点 | 原创 |
|------|------|--------|------|
| 1 | 三种退化场景构造 | 去模糊(轻/重)、超分辨率(4×)、修复(50%/80%) | |
| 2 | 优化方法求解 | Tikhonov正则化、伪逆、伴随重建 | |
| 3 | PnP方法求解 | DPIR (DRUNet去噪器 + 递减噪声表) | |
| 4 | 扩散方法求解 | DiffPIR (DiffUNet + 数据一致性) | |
| 5 | 方法对比与决策指南 | PSNR/SSIM/时间权衡、决策树 | ★ |

### 预期结果

- 优化方法: 速度快（<1s），轻度退化效果好，重度退化差
- PnP方法(DPIR): 速度适中（1-10s），质量与速度平衡最佳
- 扩散方法(DiffPIR): 质量最高但推理慢（>10s）
- 决策树: 轻度退化→优化/PnP，重度→扩散，需UQ→扩散

### 注意事项

- 需要GPU（Colab T4即可）
- 首次运行会自动下载DRUNet和DiffUNet预训练模型（~100MB）
- 如果DPIR/DiffPIR API不可用，会自动降级为手动PnP-HQS实现

### 运行方式

```bash
python 18.2.py
```

## 实验18.3：不确定性量化与后验采样

**对应知识点**: 18.5节（不确定性量化：从点估计到分布推断）

### 实验内容

| Step | 内容 | 知识点 | 原创 |
|------|------|--------|------|
| 1 | 从点估计到分布 | 点估计的局限性，后验分布p(x\|y)的意义 | |
| 2 | 后验采样实现 | PnP-ULA、DPS扩散采样、加噪PnP近似 | |
| 3 | 不确定性地图计算 | 像素级std、95%置信区间、覆盖图 | |
| 4 | 校准检验 | 覆盖率vs名义覆盖率，按像素强度分析 | ★ |
| 5 | 加速策略对比 | 样本数S影响，PSNR收敛曲线 | ★ |

### 预期结果

- 后验均值PSNR > 任何单次采样PSNR（集成效应）
- 修复场景: 缺失区域不确定性高，观测区域不确定性低
- 校准曲线: 实际覆盖率≈名义覆盖率（良好校准）
- S≥8后PSNR趋于稳定

### 注意事项

- 需要GPU（扩散采样在CPU上极其缓慢）
- S=8个样本需要较长时间（ULA~2min/样本, DPS~5min/样本）
- 如果ULA/DPS不可用，自动降级为加噪PnP近似

### 运行方式

```bash
python 18.3.py
```
