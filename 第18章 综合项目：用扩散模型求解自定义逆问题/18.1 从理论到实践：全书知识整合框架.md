# 18.1 从理论到实践：全书知识整合框架

> **核心观点**：全书的推理链"逆问题→贝叶斯→采样→得分→扩散→条件生成=逆问题求解"不仅仅是理论推演，更是一个可执行的实践路线图。每一步理论推进都对应一个工程步骤，将它们串联起来就构成了求解任意逆问题的端到端管线。三类方法——优化类、PnP类、扩散采样类——构成从简单到强大的谱系，为不同需求提供了不同的解决方案。

## 全书推理链回顾

让我们回顾从第1章到第17章的核心推理链，并标注每一步如何对应到实践步骤：

```
理论推理链：                          实践对应步骤：

逆问题需要求解(Ch1)           ──→  步骤1：定义前向算子 y=Ax+ε
贝叶斯框架(Ch1-2)             ──→  步骤1：确定似然 p(y|x) 和先验 p(x)
MAP的局限：丢弃不确定性(Ch3)   ──→  步骤2：选择超越点估计的方法
需要后验采样(Ch3)              ──→  步骤2：选择采样类方法
ULA/Langevin采样(Ch4-5)       ──→  步骤4：运行Langevin采样
得分函数不可知(Ch5)            ──→  步骤3：需要学习得分函数
得分匹配训练(Ch6)              ──→  步骤3：训练/加载去噪器
扩散模型=多步采样(Ch7)         ──→  步骤4：运行扩散采样
条件化=逆问题求解(Ch13)        ──→  步骤2-4：选择条件化策略并运行
```

这条链的核心逻辑可以浓缩为一句话：**逆问题的需求驱动了方法演化，而每一步演化都留下了可用的工具**。

从贝叶斯框架我们继承了"似然+先验"的问题建模方式；从MAP优化我们继承了梯度下降、近端算子等高效求解工具；从PnP我们继承了"去噪器即先验"的灵活范式；从扩散模型我们继承了后验采样的终极能力。本章的端到端管线就是这些工具的有机组合。

### 核心论点的三重验证

全书的核心论点是"扩散模型是逆问题自然发展的终点"。本章通过三个层面验证这一论点：

1. **理论验证**（第13章已完成）：条件扩散采样的后验一致性
2. **实践验证**（本章18.4节）：扩散方法在三个逆问题上的重建质量优于优化/PnP
3. **能力验证**（本章18.5节）：只有扩散方法能提供不确定性量化——这是逆问题最核心的需求之一

## 三类求解方法谱系

从第1章到第13章，求解逆问题的方法经历了三代演化，形成了三类方法谱系：

### 第一代：优化类方法

优化类方法源自第3章的变分框架，核心思想是将逆问题转化为优化问题：

$$\hat{x}_{\text{MAP}} = \arg\min_x \frac{1}{2\sigma^2}\|Ax - y\|^2 + \lambda R(x)$$

**优势**：
- 计算效率高（通常10-100次迭代）
- 理论成熟（收敛性、正则化理论）
- 实现简单

**局限**：
- 仅给出点估计，无法量化不确定性
- 重建质量受限于显式先验$R(x)$的表达能力
- 需要手动调节超参数$\lambda$

**代表方法**：Tikhonov正则化、TV正则化、ISTA/FISTA、ADMM、Chambolle-Pock

### 第二代：PnP类方法

PnP类方法源自第5章的PnP框架，核心思想是用预训练去噪器替代显式先验的近端算子：

$$\text{prox}_{\lambda R}(\cdot) \approx D_\sigma(\cdot)$$

**优势**：
- 无需显式定义先验——学习型去噪器隐式编码了图像先验
- 比优化方法的重建质量更高
- 去噪器可复用于不同逆问题

**局限**：
- 仍是点估计，不确定性量化需额外机制（PnP-ULA）
- 收敛性依赖于去噪器的性质（非凸、非Lipschitz时可能不收敛）
- 需要预训练去噪器

**代表方法**：PnP-ADMM、PnP-HQS、DPIR

### 第三代：扩散采样类方法

扩散采样类方法源自第7章和第13章，核心思想是通过条件扩散采样从后验分布$p(x|y)$中采样：

$$x \sim p(x|y) \propto p(y|x)p(x)$$

**优势**：
- **后验采样**——天然支持不确定性量化
- **生成式先验**——扩散模型编码了完整的图像分布$p(x)$
- **零样本迁移**——预训练扩散模型可直接用于新逆问题
- **退化严重时优势最大**——当测量信息严重不足时，生成式先验可填补缺失信息

**局限**：
- 计算代价高（100-1000次去噪器前向传播）
- 需要预训练扩散模型
- 采样结果的多样性可能高于实际后验的多样性（条件化近似引入的偏差）

**代表方法**：DPS、DDRM、DiffPIR

### 三类方法的关系

三类方法不是互斥的，而是层层递进的：

```
优化类          PnP类           扩散采样类
(显式先验)      (隐式先验)       (生成式先验)

点估计    →    点估计     →    分布估计
手工先验  →    学习型先验 →    生成式先验
快速收敛  →    中等速度   →    慢但强大
```

每一代方法都是对前一代局限性的回应：
- 优化类→PnP类：显式先验不够好，需要学习型先验
- PnP类→扩散采样类：点估计丢弃不确定性，需要分布估计

在实际应用中，三类方法各有适用场景——本章18.3节将详细讨论方法选择指南。

## 端到端管线设计

基于上述分析，我们将全书知识整合为以下端到端管线：

### 管线架构

```
输入：测量数据 y，前向算子规范，噪声模型
      │
      ▼
┌─────────────────────────────────────────┐
│ 步骤1：定义前向算子                       │
│   - 确定 A (或 A)                        │
│   - 实现伴随算子 A^T                     │
│   - 设定噪声模型 p(ε)                    │
│   - 验证伴随算子正确性                    │
│   → 输出：physics对象                    │
└─────────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────────┐
│ 步骤2：选择求解策略                       │
│   - 评估问题不适定程度                    │
│   - 确定是否需要不确定性量化              │
│   - 选择优化/PnP/扩散方法                │
│   → 输出：求解器配置                     │
└─────────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────────┐
│ 步骤3：准备先验/去噪器                    │
│   - 加载预训练模型(DRUNet/DiffUNet)       │
│   - 或自监督训练(第17章方法)              │
│   → 输出：denoiser模型                   │
└─────────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────────┐
│ 步骤4：运行求解                          │
│   - 优化：迭代梯度/近端方法               │
│   - PnP：迭代去噪+数据一致               │
│   - 扩散：条件扩散采样                    │
│   → 输出：重建结果 x̂ (单次或多次采样)    │
└─────────────────────────────────────────┘
      │
      ▼
┌─────────────────────────────────────────┐
│ 步骤5：评估与不确定性量化                 │
│   - 计算PSNR/SSIM                       │
│   - 多次采样→置信区间                    │
│   - 不确定性可视化                       │
│   → 输出：重建+不确定性报告              │
└─────────────────────────────────────────┘
```

### deepinv库的统一角色

deepinv库贯穿管线的每一步，提供了统一的API：

| 管线步骤 | deepinv模块 | 关键类/函数 |
|---------|------------|-----------|
| 步骤1 | `deepinv.physics` | `LinearPhysics`, `Blur`, `Downsampling`, `Inpainting` |
| 步骤2 | `deepinv.optim` | `DPIR`, `ADMM`, `HQS` |
| 步骤3 | `deepinv.models` | `DRUNet`, `DiffUNet`, `NCSNpp` |
| 步骤4 | `deepinv.sampling` | 扩散采样接口 |
| 步骤5 | `deepinv.utils` | `cal_psnr`, `cal_ssim`, `plot` |

这种统一的API设计使得不同方法的对比和切换变得简单——只需更换求解器，其余管线不变。

管线的第一步——定义前向算子——是所有后续工作的基础。没有一个正确的正向模型，再好的求解方法也无法给出有意义的结果。
