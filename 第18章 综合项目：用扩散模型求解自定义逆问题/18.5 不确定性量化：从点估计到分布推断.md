# 18.5 不确定性量化：从"给一张图"到"给一张'我有多确定'的地图"

> 回到第 1 章我们说的那句话："逆问题不适定，所以我们描述哪些答案更可能，而不是给唯一答案。"可前面 18.4 跑出来的，明明就是一张图 $\hat{\mathbf{x}}$。这一节要补上这个闭环——**不只给你图，还给你一张"地图"，标出我哪块在瞎猜、哪块很有把握**。医生看 CT 重建，最怕的不是噪点，而是"把伪影当成肿瘤"。不确定性地图正是为此而生的：它明确告诉你"这块你别信"。

读完这节，你应该能：
- 用"抛硬币"讲清信念如何被数据洗掉、为何数据少就不确定；
- 从后验采样里算出一张"我有多没底"的热力图；
- 说清为什么"量化不知道的东西"是逆问题最原始的诉求，也只有扩散天然给得起。

## 18.5.1 为什么点估计不够：先来一个信念更新的故事

### 点估计的局限（呼应第 1、3 章）

前 17 章大部分方法给的是点估计——一个"最佳猜测"：
- **MAP**（第 3 章）：$\hat{\mathbf{x}} = \arg\max_x p(\mathbf{x}|\mathbf{y})$
- **MMSE**（第 2 章）：$\hat{\mathbf{x}} = \mathbb{E}[\mathbf{x}|\mathbf{y}]$

点估计有用，但关键场景里**远远不够**。为什么？因为它把"可能性"压成了一个点，把"我其实不确定"的信息全丢了。MAP 保留了"哪张图最可能"，MMSE 保留了"平均而言最接近"，但两者都没有回答："除了这个猜测，还有哪些解释同样说得通？它们之间的分歧有多大？"

### 信念更新叙事：先验怎么被数据"洗掉"

让我们用大白话重新认识第 1 章的贝叶斯四角色：
- **先验（prior）** $p(\mathbf{x})$：你下手前对图的"成见"——"自然图大概长这样"。
- **似然（likelihood）** $p(\mathbf{y}|\mathbf{x})$：给定一张图，生出你手里这个观测的概率——"如果这是真图，观测该多像"。
- **后验（posterior）** $p(\mathbf{x}|\mathbf{y})$：看完观测后，你对图的"新信念"——成见被数据修正后的样子。
- **证据（evidence）** $p(\mathbf{y})$：观测本身的总概率，只是个归一化常数，让后验积分为 1。

贝叶斯定理就是"用新证据更新信念"的数学语言：

$$p(\mathbf{x}|\mathbf{y}) = \frac{p(\mathbf{y}|\mathbf{x})\,p(\mathbf{x})}{p(\mathbf{y})}$$

为什么这个等式是全书最浪漫的一句？因为它说：你的信念不是死的——先有"成见"（先验），再用"看到的数据"（似然）去修正，得到"被数据洗礼后的新信念"（后验）。分子是"旧信念与新证据的相容程度"，分母只是个让概率加总为 1 的归一化因子，不改变各候选解释之间的相对排序。

现在想象一个简单的信念更新实验：你要猜一枚硬币公不公平（偏向正面的概率 $\theta$）。**先验**你假设"$\theta$ 大概在 0.5 附近"（弱成见）。然后不断抛硬币：
- 抛 **0 次**：后验 = 先验，又宽又平，你对 $\theta$ 几乎一无所知；
- 抛 **2 次**（1 正 1 反）：后验稍微收一点；
- 抛 **10 次**：后验明显收窄，中心被拉向观测频率；
- 抛 **50 次**、**500 次**：后验变成又高又瘦的尖峰，**先验被数据彻底"洗掉"**了，你的信念几乎完全由数据决定。

> **这就是不确定性的本质**：数据少 → 后验胖（不确定）；数据多 → 后验瘦（确定）。逆问题里，你的"观测 $\mathbf{y}$"就是那些硬币抛掷——测量信息越多，你的重建越确定；测量信息越少（比如 95% 像素缺失），后验越胖，不确定性地图就越亮。
>
> 从更深层次看，这正是"**不确定性即智能**"的含义：真正的智能不是永远给出确定的答案，而是在不确定条件下知道自己不知道什么。后验分布的宽度本身就是智能的体现——它把"我有多没底"从一种主观感觉，变成了可计算、可校准、可交给下游决策的对象。一个只会给点估计的系统，无论点选得多准，都无法表达这份自知之明。

### 为什么这件事生死攸关

- **医学诊断**：有限角 CT 某些方向几乎没信息。医生得知道"这个阴影是高置信真结构，还是低置信伪影"。
- **科学发现**：Cryo-EM、天文里 SNR 极低，得区分"真实信号"和"噪声涨落"。
- **安全决策**：自动驾驶基于不确定重建做决定，低置信区该保守。

## 18.5.2 从后验采样到不确定性度量

### 基本策略

不确定性量化的核心就一句：**从后验 $p(\mathbf{x}|\mathbf{y})$ 里独立抽 $S$ 次**，看样本怎么散：

$$\{x^{(s)}\}_{s=1}^S \sim p(\mathbf{x}|\mathbf{y})$$

每个 $\mathbf{x}^{(s)}$ 都是一张"完整、合理的候选重建"，它们共同勾勒出后验的形状。为什么"抽多次看散度"就能度量不确定？因为后验胖的地方，抽出来的样本彼此差得远；后验瘦的地方，样本几乎重合。散度本身就是不确定性的影子。

### 后验均值（MMSE 估计）

样本云的第一种读法，是找它的"重心"——所有合理解释的平均位置。它正是第 2 章 MMSE 估计的蒙特卡洛版本：

$$\bar{x} = \frac{1}{S}\sum_{s=1}^S \mathbf{x}^{(s)}$$

把 $S$ 个样本逐像素平均，$\bar{\mathbf{x}}$ 的每个像素就是"该像素在所有合理解释下的平均值"。当 $S\to\infty$，$\bar{\mathbf{x}} \to \mathbb{E}[\mathbf{x}|\mathbf{y}]$。**先猜一下**：用 30 个样本平均出来的图，比单次后验采样更糊还是更清晰？
> 揭晓：更**平滑也更鲁棒**。因为平均把不同样本里的随机波动抵消了——18.5-1 实验里 30 个单样本的 PSNR 挤在 34.06–34.62 dB，而 30 样本平均出的"后验均值"整体 PSNR 为 **37.48 dB**（观测半区 43.10 dB，缺失半区 35.09 dB）。提升几乎全部来自缺失半区：那里正是"不同合理填法"分歧最大的地方，平均把随机填法抵消，留下稳定的结构。

### 像素级标准差（不确定性地图）

均值回答"猜什么"，标准差回答"有多没底"。对每个像素，衡量 $S$ 个样本在其上的散布程度：

$$\sigma_i = \sqrt{\frac{1}{S-1}\sum_{s=1}^S (x_i^{(s)} - \bar{x}_i)^2}$$

其中 $x_i^{(s)}$ 是第 $s$ 个样本在第 $i$ 个像素的取值，$\bar x_i$ 是该像素的样本均值。这张 $\sigma$ 地图把每个像素的"散度"画成热力图：$\sigma_i$ 越大，说明后验在那像素上越发散，你越没底。

### 像素级置信区间（95%）

有了均值与标准差，就能给出一个区间承诺——真值大概率落在哪：

$$[\bar{x}_i - 1.96\sigma_i,\; \bar{x}_i + 1.96\sigma_i]$$

$\bar x_i$ 与 $\sigma_i$ 就是上面算出的均值与标准差，1.96 是标准正态分布的 97.5% 分位数（双侧合计 95%）。若后验近似高斯，真值有约 95% 概率落在这区间里。

### 分位数图 & 像素间协方差（进阶）

- 分位数：$q_\alpha(x_i)=\text{Percentile}(\{x_i^{(s)}\}, \alpha\times100)$，5%/95% 分位给出 90% 预测区间，还能看出后验是否不对称。
- 协方差：$\Sigma_{ij}=\frac{1}{S-1}\sum_s(x_i^{(s)}-\bar x_i)(x_j^{(s)}-\bar x_j)$，反映相邻像素误差是否"同号"（空间结构）。

从点估计到分布推断，这一转变意味着评价一个重建算法的标准变了：不再只问"这张图和真值差几个 dB"，还要问"这族样本是否覆盖了真值的可能范围"——前者考的是点准不准，后者考的是信念诚实不诚实。

## 18.5.3 扩散采样的不确定性量化实践

### 多次独立采样：固定 $\mathbf{y}$，换种子

关键就一句——**测量 $\mathbf{y}$ 不动，每次换随机种子**，让扩散从不同的纯噪声 $\mathbf{x}_T$ 出发走完整条逆向路：

```python
import torch
S = 30
samples = []
for s in range(S):
    torch.manual_seed(s)          # 不同种子 → 不同采样
    x_s = model(y, physics)       # 每次都是一次后验样本
    samples.append(x_s)

samples_tensor = torch.stack(samples)     # (S, C, H, W)
x_mean = samples_tensor.mean(dim=0)       # 后验均值
x_std  = samples_tensor.std(dim=0)        # 不确定性地图
x_lower = samples_tensor.quantile(0.025, dim=0)  # 95% 下界
x_upper = samples_tensor.quantile(0.975, dim=0)  # 95% 上界
```

这段代码把 18.5.2 的四个公式逐个落了地：`mean` 对应后验均值 $\bar{\mathbf{x}}$，`std` 对应 $\sigma$ 地图，两个 `quantile` 对应经验分位数形式的置信区间。`y` 与 `physics` 全程不变——变的只是起点噪声，这正是"数据固定、样本面不同"的直观演示：同一份证据之下，后验给出的合理解释不止一个。

> 配套实验 18.5-1 并不调用现成的扩散求解器，而是用第 5 章的退火 PnP-ULA 把这个思想落地：$S$ 条 Langevin 链作为一个 batch 同时演化（GPU 上快约 $S$ 倍），每条链的随机性来自独立的随机种子。思想与上面这段代码完全一致——固定 $\mathbf{y}$、换种子、看样本云——只是"走一条逆向扩散路"换成了"跑一条退火 Langevin 链"。

### 采样数 $S$ 怎么选（先猜后揭）

**先猜**：$S=4$ 和 $S=30$ 的不确定性地图，质量差多少？
> 揭晓（18.5-1 实验）：后验均值 PSNR 只从 $S=4$ 的 36.80 dB 升到 $S=30$ 的 37.48 dB（**仅 +0.68 dB**）；像素 std 均值从 0.0110 变成 0.0119。也就是说**后验均值本身对 $S$ 并不敏感**——它是个已经收敛的量。真正随 $S$ 收缩的是**后验均值的标准误**（像素均值估计量的标准误 $\mathrm{std}/\sqrt{S}\propto 1/\sqrt{S}$，实测 $5.5\times10^{-3}\to 2.2\times10^{-3}$），而像素 std 作为后验的固有量几乎不变。**不要把这两个量混淆**：像素 std 估计量自身的相对误差约 $\sqrt{1/(2(S-1))}\approx13\%$（$S=30$，见附录 18B），它不随 $1/\sqrt{S}$ 收缩，也不是实验表格里的那一列。所以经验法则要这样理解：**$S$ 决定的是“后验均值和不确定性地图估得准不准”，而不是“图本身像不像”**。

| $S$ | 用途 | 说明 |
|-----|------|------|
| 10 | 粗估 | 地图偏噪 |
| 30 | 常规 | 基本稳定 |
| 100 | 发表级 | 高精度 |
| 1000 | 极少需要 | 过度 |

### 加速策略（30 次采样意味着 30 倍算力，必须省）

- **减步数**：标准 1000 步 → DDIM 100–50 步（质量微降）→ 一致性模型 1–2 步（降较多）。
- **共享早期步**：早期（$t$ 大）主要去全局噪，可先公共走前 $K$ 步再分叉。
- **并行**：多 GPU 线性加速。

### 不确定性地图怎么读（它暴露了 $A$ 的"盲区"）

- **去模糊**：整体低不确定；边缘略高（模糊对边缘退化重）。
- **超分**：中等；纹理区高（低分辨率里看不见纹理形态）。
- **修复**：已知像素区 $\sigma\approx0$；缺失区高；缺失边缘渐高（离已知越远越靠编）。
- **有限角 CT**：已覆盖角度低、未覆盖角度高——地图直接画出"波前集的方向性缺失"。

> **纯 numpy 替代思路**（不装 deepinv 也能体会）：把"多次采样"换成"对一个简单逆问题跑多次带噪重建"，算均值和 std，照样能得到一张'哪块抖得厉害'的地图。核心思想完全一致，只是采样器从扩散换成蒙特卡洛。

## 18.5.4 不同方法的不确定性对比

| 维度 | 优化 | PnP-ULA | 扩散采样 |
|------|------|---------|---------|
| 不确定性量化 | ❌ | ✅ | ✅ |
| 采样效率 | — | 低（$10^3$+ 步） | 高（$10^2$–$10^3$ 步） |
| 采样质量 | — | 中等 | 高 |

- **优化**：只给点，唯一的"近似不确定性"是扰动 $\lambda$ 看解敏不敏感——不是统计意义的不确定。
- **PnP-ULA**（第 5 章 5.5）：把 ULA 里的对数先验梯度换成去噪器得分：

  $$x_{k+1} = x_k - \delta\left(\frac{1}{\sigma^2}A^\top(Ax_k - \mathbf{y}) + \frac{D_{\sigma_s}(x_k) - x_k}{\sigma_s^2}\right) + \sqrt{2\delta}\,z_{k+1}$$

  逐项看：$A^\top(Ax_k-\mathbf{y})/\sigma^2$ 是似然（数据）梯度，把当前解往"满足测量"的方向拉；$(D_{\sigma_s}(x_k)-x_k)/\sigma_s^2$ 是去噪器隐式给出的先验得分（第 5 章 Tweedie 视角），把解往"自然图"的方向拉；$z_{k+1}\sim\mathcal{N}(0,I)$ 是高斯扰动，$\sqrt{2\delta}$ 控制其强度——正是这一项让迭代不再收敛到一个点，而是让样本云的平稳分布逼近后验。它能产生后验样本，但要 $10^3$–$10^5$ 步才稳态，烧入期长（18.5-1 实验取 14 级 × 400 步 = 5600 步/样本）。这里有个初学者最容易踩的坑：**光有步数还不够，链的初值必须落在正确的后验盆域**——18.5-1 的 v2 版本零填充初始化，5600 步跑完全体链仍停在错误盆域（缺失半区只有 13.5 dB，见该实验的 MAP 基线对比）；v3 改用 DPIR-MAP 热启动后才真正采到后验。

- **扩散采样**：每次 100–1000 步去噪即一个样本，质量高、不确定更可靠——是当前最有效的后验采样器。该方法的重要性并不只在于快，而在于它把"后验采样"从 MCMC 时代的手艺活，变成了生成模型的默认能力：先验分布 $p(\mathbf{x})$ 被训练一次性学透，条件化只是推理时叠加证据。

## 18.5.5 可视化、校准与"用不确定性做决策"

### 可视化

- **热力图**：蓝/暗=高置信，红/亮=低置信。
- **置信区间宽度图**：$w_i = x_i^{\text{upper}}-x_i^{\text{lower}}$，越宽越不确定。
- **真值-重建-不确定三联图**：并排看。

### 校准：你的"95%"真覆盖 95% 吗？

不确定性图得"校准"才有用：95% 区间应该真覆盖约 95% 真值像素。

```python
coverage = ((x_true >= x_lower) & (x_true <= x_upper)).float().mean()
print(f"95% 区间实际覆盖率: {coverage:.2%}")   # 理想≈95%
```

**先猜一下**：扩散采样的条件化是近似的（DPS 用 $\hat{\mathbf{x}}_0$ 替似然梯度），它的校准会偏乐观还是偏保守？
> 揭晓（18.5-1 实验）：先看一个反直觉的事实——**名义覆盖率不是正确的比较基准**。$S=30$ 个样本的经验分位数区间，即使在完美校准下，93.33% 名义区间的期望覆盖率也只有 **87.35%**（次序统计量的有限样本效应，解析可算），不是 93.33%。拿实测对名义值打分，会把有限样本离散性误判成"校准偏差"（该实验的 v2 版本就犯过这个错，还把真正的病根——链未收敛——误诊成"先验失配"）。
>
> 按正确的口径（对零模型），实测结果：93.33% 名义区间池化覆盖 **92.17%**，对名义仅 $-1.16\%$，对零模型 $+4.82\%$——方向是**略微保守（区间略宽）**，脚本判"存在偏差"（$|$偏差$|\in[4\%,8\%]$ 档）。四个置信水平（名义 6.67/33.33/66.67/93.33%）实测 7.49/37.23/70.59/92.17%，零模型期望 6.20/31.14/62.42/87.35%，全部略高于零模型。分区看：观测半区 91.21%、缺失半区 93.14%，两者都贴近零模型。
>
> 但比覆盖率更重要的是**归因链**：Step 0 在解析可解问题上证明采样器实现无偏（std 比 1.008/1.104）；MAP 基线对比（缺失 RMS 比 1.06）与 PIT 真值秩（15.2，理论 15）证明链确实到达了后验盆域。三层都验干净之后，残留的 $+4.8\%$ 才可能归因于先验与数据的失配（DRUNet 的自然图像先验与这张 celeba 图不完全一致，且 $\sigma\in[0.196,\infty)$ 无得分可用），且这个量级本身就在"像素高度相关"导致的统计不确定性范围内。提醒你：**不确定性估计本身也要被检验，而且要按"先验检实现→再检收敛→最后检校准"的顺序**——跳过前两层，你就会像该实验的 v2 一样，把一个收敛性 bug 误诊成"固有代价"。

### 用不确定性指导决策

- **医学**：高不确定区标"需复查"，低不确定区直接信。
- **数据采集**：有限角 CT 里，不确定地图指出"补哪些角度最有价值"。
- **可信度分级**：高/中/低三档，决定直接用、人工复核、还是丢弃。

> **因果串联收尾**：从点估计（18.4）到分布（本节），我们终于把第 1 章那句"描述哪些答案更可能"坐实了——也只有扩散采样能天然给你这张地图。下一节（18.6）看看这条路线还能往哪拓：竞赛、加速、新模态。

## 实验 18.5-1：不确定性量化与后验采样

实验 `18.5-1.py` 演示**从点估计到分布推断的完整流程**——通过退火 Unadjusted Langevin Algorithm（ULA）从后验分布 $p(\mathbf{x}|\mathbf{y})$ 中多次采样，计算像素级标准差、经验分位数区间，并通过一套**三层验收**（解析自检 → 收敛性检验 → 校准检验）验证不确定性估计的可靠性。实验开始前还包含一步**采样器自检（Step 0）**：先在一个能写出解析后验的低维问题上跑同一套 ULA，确认采样器本身没有系统性偏差，再去处理真实图像。

### 实验场景

实验考虑图像修复问题：观测模型 $\mathbf{y} = Mx + \varepsilon$，其中 $M$ 是 50% 像素缺失的二值掩码（实测保留比例 0.5014），$\varepsilon \sim \mathcal{N}(0, \sigma^2 I)$ 为加性高斯噪声（$\sigma = 0.01$，观测信噪比 40 dB）。这是一个严重不适定的逆问题——一半的像素信息完全缺失，不同先验可能给出完全不同的重建结果。零填充基线（$A^\dagger \mathbf{y}$）PSNR 为 11.38 dB。

**后验采样方法**：退火 PnP-ULA。先验得分由 DRUNet 去噪器经 Tweedie 公式给出：$\nabla \log p_\sigma(\mathbf{x}) = (D(\mathbf{x},\sigma) - \mathbf{x})/\sigma^2$。退火调度取 14 级**几何序列** $\sigma \in [0.00784, 0.1961]$（$0.1961 = 50/255$ 正是 DRUNet 的训练噪声上限——deepinv 的 DRUNet 直接把 $\sigma$ 作为噪声水平图输入，超出训练范围的 $\sigma$ 没有依据），每级运行 400 步 ULA，总采样步数 5600 步/样本，不使用 burn-in。数据保真项权重 $\lambda_\text{data} = 1.0$——**贝叶斯权重必须是 1**：取 0.05 会让链收敛到 $p_\sigma(\mathbf{x})\,p(\mathbf{y}|\mathbf{x})^{0.05}$ 而不是 $p(\mathbf{x}|\mathbf{y})$，观测像素的"后验 std"会被撑到 $\sigma_d/\sqrt{\lambda}$（Step 0 有定量对照，见下文）。

**v3 的两处关键设计**（本实验从"失败"到"可信"的核心，也是本节最值得学的工程经验）：

1. **DPIR-MAP 热启动**：先用同一个 DRUNet 跑 12 级 × 8 次"去噪 + 观测像素硬投影"（DPIR 式 MAP 近似——只借"去噪 + 硬投影"的结构，没有 DPIR 的逐级噪声调度与数据保真近端步，不是完整 DPIR；额外开销 <2%），把链放进正确的后验盆域，再做退火 Langevin。为什么必须这样？零填充初始化的链在低 $\sigma$ 级只能做 $\pm 0.013$ 量级的局部平衡，而"50% 黑洞"这种粗尺度填充误差只有高 $\sigma$ 级能搬运，5600 步走不完——v2 的失败样本缺失半区只有 13.5 dB，同一个 DRUNet 的 MAP 基线却有 35.6 dB。MAP 解同时作为强基线报告。
2. **MYULA 近端数据项**：数据保真项不用显式梯度，而用近端步 $\text{prox}_{\varepsilon g}$（inpainting 有闭式解：观测像素 $(\mathbf{x} + \frac{\varepsilon}{\sigma_d^2}y)/(1+\frac{\varepsilon}{\sigma_d^2})$，缺失像素恒等），平稳分布不变（$O(\varepsilon)$ 近似），且观测像素无条件稳定。

**采样配置**：生成 $S = 30$ 个独立后验样本（固定观测 $\mathbf{y}$、换随机种子；$S$ 条链作为一个 batch 同时演化，GPU 上快约 $S$ 倍），用于计算后验均值、像素级标准差和经验分位数区间。ULA 参数：步长 $\varepsilon = 0.005\,\sigma^2$（随 $\sigma$ 自动缩小），Langevin 噪声尺度 $1.0$，输出投影区间 $[-0.25, 1.25]$。投影边界远宽于 $[0,1]$，但并非永不生效（缓存样本最小值约 $-0.021$）；下文的 PSNR/std/覆盖率都在**未裁剪**的采样输出上计算，`clamp(0,1)` 只用于绘图。

### 实验目的

1. **验证从点估计到分布推断的必要性**：单次重建（MAP/MMSE 估计）只能给出一个"最佳猜测"，无法量化重建的可靠性；多次后验采样可计算像素级不确定性，为安全关键决策提供依据
2. **计算像素级标准差与经验分位数区间**：从 $S = 30$ 个后验样本中计算每个像素的标准差 $\sigma_i$ 和 93% 经验分位数区间 $[q_{0.033}, q_{0.967}]$，可视化不确定性的空间分布
3. **校准检验**：验证经验分位数区间的实际覆盖率——注意比较基准是 **$S$ 有限样本零模型期望**（$S=30$ 时 93.33% 名义区间的期望覆盖率只有 87.35%），不是名义值；且必须**分区看**（观测半区 / 缺失半区），像素池化会把两类性质完全不同的区域平均掉
4. **量化样本数对不确定性估计的影响**：对比 $S = 4$ 和 $S = 30$ 的不确定性图质量，厘清"后验均值"与"不确定性地图估计精度"对 $S$ 的不同敏感度
5. **验收"这次 UQ 能不能信"（三层）**：Step 0 用解析可解问题验采样器实现；MAP 基线对比 + PIT 真值秩验真实图像上的收敛性（v3 新增，专抓"全体链一致待在错误盆域"这种 Step 0 覆盖不到的失败模式）；最后才验覆盖率

#### 步骤 0：采样器自检（先在能算解析解的问题上验证 ULA）（图 18.13）

![图 18.13　采样器自检](<./第十八章 配套实验/实验18.5-1/step0_sampler_selftest.png>)

在真实图像上跑 ULA 之前，先在一个人为构造、**能写出闭式后验**的低维问题（$10\times10$ 线性高斯 inpainting，后验 $p(\mathbf{x}|\mathbf{y})=\mathcal{N}(\mu_p,C_p)$）上用**同一套代码**采样。左图（Step 0-a）把"解析后验 std"与"采样得到的 std"作散点对比，点落在 $\mathbf{y}=\mathbf{x}$ 上才算收敛；右图（Step 0-b）比较不同配置的 std 比值——理想值 1.00，绿带 $[0.8, 1.25]$ 为可接受范围。

**自检结果**：本版配置的 std 比值为 **1.008（观测半区）/ 1.104（缺失半区）**，93.3% 区间覆盖率 **0.91**，全部落在验收范围内 → 脚本判定"采样器通过解析验证"。作为对照，图中还画出了初版配置（$\lambda=0.05$、50 步/级、$\sigma$ 上探到 1.0）与"只改 $\lambda$"两种历史配置：前者的观测半区 std 是真实后验的约 4.3 倍（$\lambda=0.05$ 的直接后果，解析可算），后者的缺失半区 std 约 3.3 倍（50 步/级退不干净高 $\sigma$ 级注入的方差）——**两个超参错误都被解析基准当场抓住**，这正是先自检再归因的价值。

**自检范围（重要的边界声明）**：该结果只证明迭代公式、$\lambda$、$\sigma$ 调度、步数在【共轭高斯、精确线性 score、单盆域强相关】后验上正确；**不能外推到真实 DRUNet**——自然图像后验非凸、去噪器只是近似 score，"400 步 = 2 个松弛时间"在玩具上成立、在真实图像上远不够。真实实验的收敛性必须另看 MAP 基线对比 / PIT / std 比（Step 3 验收），这正是 v3 增加这些检查的原因。

**补充验证（近端数据项路径）**：真实实验使用的是 MYULA 近端数据项，而 Step 0 走的是显式梯度路径。审查中用同一解析问题补验了近端路径：std 比 1.007/1.104、覆盖率 95.0%，与梯度路径同样正确（prox 闭式解与数值 argmin 吻合到 $10^{-7}$）。复现脚本 `_verify_a.py`（从缓存独立重算全部统计量，核对 JSON）与 `_verify_b.py`（重跑 Step 0 + 补验近端路径）随实验附带，可自行复跑。

#### 步骤 1-3：从点估计到分布、后验采样与不确定性地图（图 18.14）

![图 18.14　不确定性地图](<./第十八章 配套实验/实验18.5-1/step1_3_uncertainty_maps.png>)

本图是一个 $3 \times 6$ 网格，综合展示了从点估计到分布推断的完整流程：

**第一行（6 张）**：真值、观测 $A^\dagger \mathbf{y}$（零填充基线 11.38 dB，保留约 50% 像素）、**MAP 基线**（DPIR 式热启动近似，同一个 DRUNet，缺失 35.61 dB）、后验均值 $\bar{\mathbf{x}}$（整体 37.48 dB / 缺失 35.09 dB）、后验标准差图（观测 0.0077 / 缺失 0.0180）、93% 经验分位数区间宽度图（均值 0.0390）。注意标准差地图的空间结构与掩码高度一致——**不确定性地图画出的正是正向算子 $A$ 的盲区**，这正是 18.5.3 末尾"不确定性地图怎么读"的现场版。

**第二行（5 张）**：从 30 个样本中等间隔抽取 5 个后验样本（PSNR 34.06–34.62 dB）。观测半区每个样本几乎一致（被数据钉住），缺失半区每次"填法"都不同但都合理——这就是"后验是一族合理解释，而非一个点"的直观呈现。

**第三行（4 张）**：分区误差图 $|\bar{\mathbf{x}} - \mathbf{x}|$（缺失半区占全部平方误差的 **86.3%**）、单样本偏差 $\mathbf{x}_1 - \bar{\mathbf{x}}$（仅缺失半区）、重建偏差 $\bar{\mathbf{x}} - x_\text{true}$（仅缺失半区），以及一张**结构诊断**柱状图（下详）。

**结构诊断：偏差是"图像状"还是"白噪声"？** 用 lag-1 空间自相关衡量偏差场是否具有空间结构：

- 缺失半区单样本偏差 lag1 = **0.2141**（全图 0.2329）
- 同像素、同 std 的白噪声对照 lag1 = **−0.0001**
- 重建偏差 lag1 = **0.304**（图像状结构应有的量级）
- 结构比 = **2131 倍** → 偏差**不是白噪声，而是带空间结构的系统性偏差**

**与 MAP 基线的对比（v3 核心验收，专抓"集体未收敛"）**：MAP（后验众数附近）缺失 35.61 dB，后验均值缺失 35.09 dB，缺失 RMS 比 **1.06**——均值只比 MAP 差 6%，落在"1~2 倍"验收范围内。作为失败模式的参照：v2（零填充初始化）这个比值是 **12.8**，链全体停在错误盆域，而那时 lag1、链间相关性、观测半区 std、覆盖率全部"看起来正常"——**没有任何单一诊断能替代"与 MAP 点估计对比"这一条**。PIT 真值秩：观测 15.11 / 缺失 15.20（理论 15），样本整体无偏亮/偏暗（v2 失败样本为 18.8）。

此外链间相关系数均值为 **−0.0345**（四位小数下等于中心化偏差场的代数基线 $-1/(S-1)=-0.03448$，$S=30$）。这是**中心化造成的必然结果**，不是独立性的证据：中心化后每条链的偏差向量和为零，任意两条链的相关系数都被迫接近 $-1/(S-1)$。该统计量只能排除“全体塌缩到同一点”（$\rho\approx0$）或“塌到 $k$ 个模态”（$\rho\approx1/k$），不能区分独立链与部分相关的链；表中的 ESS 30.0 也是由这个 $\rho$ 反推的粗估，同样仅作参照。真正支持“链已到达后验盆域”的是前面的 MAP 基线对比、PIT 真值秩与偏差场 lag1。

| 66.67% | 62.42% | 70.59% | 68.03% | 73.17% | +8.17% | 严重失配 |
| 93.33% | 87.35% | 92.17% | 91.21% | 93.14% | +4.82% | 存在偏差 |

**主置信水平 93.33%**（零模型期望 87.35%）：池化覆盖率 **92.17%**（观测 91.21% / 缺失 93.14%），对名义值仅 $-1.16\%$，对零模型 $+4.82\%$，判"存在偏差"。

**校准分析**：

- **方向**：四个水平的实测覆盖率**一致地略高于**零模型——区间略微偏**宽**（保守侧），而不是 v2 时代的"偏自信（区间偏窄）"。66.67% 一档超出 8% 被判"严重失配"，但这只反映启发式阈值：像素高度相关使覆盖率的统计不确定性远大于二项估计，且偏差方向一致（全在保守侧），对下游决策是安全侧的错误
- **归因（本实验最重要的方法论）**：Step 0 已证明采样器实现无偏（std 比 1.008/1.104），MAP 对比（RMS 比 1.06）与 PIT（15.2）已证明链到达了后验盆域——**实现与收敛两层都排除了**，残留的 $+5\%$ 量级偏差才可能归因于先验与数据的失配（DRUNet 的自然图像先验与这张 celeba 图不完全一致、$\sigma$ 上界被截断在 0.196、MYULA 的 $O(\varepsilon)$ 离散化），且这个量级本身就在像素相关导致的统计不确定性范围内。对比 v2 的教训：那时跳过前两层直接把这个偏差解释成"固有代价"，实际上是在给一个收敛性 bug 贴合理化标签
- **分区**：观测半区（91.21%）与缺失半区（93.14%）都贴近零模型，两个半区没有明显差别

**教学启示**：这张图最有价值的地方在于**它把"哪里偏、偏多少、偏在哪个区域、该跟谁比"逐项暴露出来**。实践中若需更紧的校准，可选的方向是换更贴合数据的先验、放宽 $\sigma$ 上界（配更强的去噪器）、增大 $S$（压缩零模型缺口）、或改用 DPS 类条件采样。

#### 步骤 5：样本数对不确定性估计的影响（图 18.16）

![图 18.16　样本数影响](<./第十八章 配套实验/实验18.5-1/step5_sample_size_effect.png>)

左图（Step 5-a）画后验均值 PSNR 随样本数 $S$ 的变化（横轴对数刻度）；右图（Step 5-b）画"后验均值的标准误"随 $S$ 的变化，并与 $1/\sqrt{S}$ 参考线对比。

**样本数对比**：

| 指标 | $S = 4$ | $S = 30$ | 差异 |
|------|---------|----------|------|
| 后验均值 PSNR | 36.80 dB | 37.48 dB | +0.68 dB |
| 平均像素标准差 | 0.0110 | 0.0119 | +0.0009 |
| 后验均值的标准误 | $5.49\times10^{-3}$ | $2.17\times10^{-3}$ | $\propto 1/\sqrt{S}$ |

**分析**（这里纠正一个常见误解）：

- **后验均值对 $S$ 不敏感**：$S$ 从 4 增到 30，PSNR 只涨 0.68 dB。因为后验均值本身就是一个已经收敛的量，4 个样本已经能把它估得差不多
- **真正随 $S$ 收缩的是"估计精度"**：右图显示"后验均值的标准误"严格按 $1/\sqrt{S}$ 下降（实测 $5.5\times10^{-3}\to 2.2\times10^{-3}$，除以 $\sqrt{30/4}\approx 2.74$ 后吻合）。也就是说 $S$ 决定的是**不确定性地图估得准不准**，而不是"重建图好不好看"
- 这个量是**后验均值估计**的标准误（$\text{std}/\sqrt{S}$），不是"像素 std 本身的标准误"——后者是另一个量：$S=30$ 时像素 std 估计量的相对误差约 $\sqrt{1/(2(S-1))}\approx13\%$（附录 18B），且不随 $1/\sqrt{S}$ 收缩

**实践建议**：若你的目标是"看不确定性地图长什么样"，$S = 4$ 已经能看出大致轮廓；若要**定量**报告不确定性（尤其给下游决策用），$S \geq 30$ 才够稳，发表级可取 $S \geq 100$。

#### 核心知识点总结

| 知识点 | 实验验证 |
|--------|---------|
| 从点估计到分布推断 | 单样本 PSNR 34.06–34.62 dB，后验均值 37.48 dB；观测半区样本几乎一致（被数据钉住），缺失半区给出不同而合理的填法 |
| 像素级不确定性量化 | 观测半区 std 0.0077（$0.77\sigma_d$，被数据钉住）vs 缺失半区 0.0180，相差 2.34 倍，不确定性地图忠实反映信息结构 |
| 经验分位数区间 | 93.33% 区间平均宽度 0.0390，池化覆盖率 92.17%（对名义 $-1.16\%$，对零模型 $+4.82\%$，略保守） |
| 分区校准 | 93.33% 时观测半区 91.21%、缺失半区 93.14%；评级基准是 $S=30$ 零模型（87.35%）而非名义值 |
| 收敛性验收（v3 核心） | MAP 基线缺失 35.61 dB vs 后验均值缺失 35.09 dB（RMS 比 1.06）；PIT 秩 15.11/15.20（理论 15）——专抓"全体链一致待在错误盆域"（v2 失败值 12.8 / 18.8） |
| 偏差的结构诊断 | 缺失半区偏差 lag1 = 0.2141（白噪声对照 −0.0001，结构比 2131×）→ 是系统性、图像状的偏差而非随机噪声 |
| 样本数影响 | 后验均值 PSNR 对 $S$ 不敏感（36.80 → 37.48，+0.68 dB）；随 $S$ 按 $1/\sqrt{S}$ 收缩的是估计精度（$5.5\times10^{-3}\to 2.2\times10^{-3}$） |
| 先自检再归因 | Step 0 在解析可解问题上验证采样器（std 比 1.008/1.104），使 Step 4 的残留偏差可归因于先验失配而非实现错误 |

> **实践启示**：不确定性量化为逆问题重建提供了"置信度标签"——在医学诊断中，高不确定性区域可标记为"需进一步检查"；在数据采集中，不确定性图可指导额外的测量方向。而本实验最值得带走的经验是**验收的顺序**：先用解析可解问题验采样器实现（Step 0），再用 MAP 点估计对比和 PIT 验链的收敛性，最后才验覆盖率——且覆盖率必须对照有限样本零模型、分区报告。该实验的 v2 版本反着来：覆盖率看起来"只差 5%"，于是用"先验失配的固有代价"解释，实际上链从未到达后验盆域；v3 加上 MAP 热启动后，同样的 $\sigma$ 范围、同样的 DRUNet，覆盖率反而更接近名义值。**"看起来接近"和"真的校准"之间，隔着一整套验收程序。**
