# 18.5 不确定性量化：从"给一张图"到"给一张'我有多确定'的地图"

> 回到第 1 章我们说的那句话："逆问题不适定，所以我们描述哪些答案更可能，而不是给唯一答案。"可前面 18.4 跑出来的，明明就是一张图 $\hat x$。这一节要补上这个闭环——**不只给你图，还给你一张"地图"，标出我哪块在瞎猜、哪块很有把握**。医生看 CT 重建，最怕的不是噪点，而是"把伪影当成肿瘤"。不确定性地图正是为此而生的：它明确告诉你"这块你别信"。

读完这节，你应该能：
- 用"抛硬币"讲清信念如何被数据洗掉、为何数据少就不确定；
- 从后验采样里算出一张"我有多没底"的热力图；
- 说清为什么"量化不知道的东西"是逆问题最原始的诉求，也只有扩散天然给得起。

## 18.5.1 为什么点估计不够：先来一个信念更新的故事

### 点估计的局限（呼应第 1、3 章）

前 17 章大部分方法给的是点估计——一个"最佳猜测"：
- **MAP**（第 3 章）：$\hat x = \arg\max_x p(x|y)$
- **MMSE**（第 2 章）：$\hat x = \mathbb{E}[x|y]$

点估计有用，但关键场景里**远远不够**。为什么？因为它把"可能性"压成了一个点，把"我其实不确定"的信息全丢了。MAP 保留了"哪张图最可能"，MMSE 保留了"平均而言最接近"，但两者都没有回答："除了这个猜测，还有哪些解释同样说得通？它们之间的分歧有多大？"

### 信念更新叙事：先验怎么被数据"洗掉"

让我们用大白话重新认识第 1 章的贝叶斯四角色：
- **先验（prior）** $p(x)$：你下手前对图的"成见"——"自然图大概长这样"。
- **似然（likelihood）** $p(y|x)$：给定一张图，生出你手里这个观测的概率——"如果这是真图，观测该多像"。
- **后验（posterior）** $p(x|y)$：看完观测后，你对图的"新信念"——成见被数据修正后的样子。
- **证据（evidence）** $p(y)$：观测本身的总概率，只是个归一化常数，让后验积分为 1。

贝叶斯定理就是"用新证据更新信念"的数学语言：

$$p(x|y) = \frac{p(y|x)\,p(x)}{p(y)}$$

为什么这个等式是全书最浪漫的一句？因为它说：你的信念不是死的——先有"成见"（先验），再用"看到的数据"（似然）去修正，得到"被数据洗礼后的新信念"（后验）。分子是"旧信念与新证据的相容程度"，分母只是个让概率加总为 1 的归一化因子，不改变各候选解释之间的相对排序。

现在想象一个简单的信念更新实验：你要猜一枚硬币公不公平（偏向正面的概率 $\theta$）。**先验**你假设"$\theta$ 大概在 0.5 附近"（弱成见）。然后不断抛硬币：
- 抛 **0 次**：后验 = 先验，又宽又平，你对 $\theta$ 几乎一无所知；
- 抛 **2 次**（1 正 1 反）：后验稍微收一点；
- 抛 **10 次**：后验明显收窄，中心被拉向观测频率；
- 抛 **50 次**、**500 次**：后验变成又高又瘦的尖峰，**先验被数据彻底"洗掉"**了，你的信念几乎完全由数据决定。

> **这就是不确定性的本质**：数据少 → 后验胖（不确定）；数据多 → 后验瘦（确定）。逆问题里，你的"观测 $y$"就是那些硬币抛掷——测量信息越多，你的重建越确定；测量信息越少（比如 95% 像素缺失），后验越胖，不确定性地图就越亮。
>
> 从更深层次看，这正是"**不确定性即智能**"的含义：真正的智能不是永远给出确定的答案，而是在不确定条件下知道自己不知道什么。后验分布的宽度本身就是智能的体现——它把"我有多没底"从一种主观感觉，变成了可计算、可校准、可交给下游决策的对象。一个只会给点估计的系统，无论点选得多准，都无法表达这份自知之明。

### 为什么这件事生死攸关

- **医学诊断**：有限角 CT 某些方向几乎没信息。医生得知道"这个阴影是高置信真结构，还是低置信伪影"。
- **科学发现**：Cryo-EM、天文里 SNR 极低，得区分"真实信号"和"噪声涨落"。
- **安全决策**：自动驾驶基于不确定重建做决定，低置信区该保守。

## 18.5.2 从后验采样到不确定性度量

### 基本策略

不确定性量化的核心就一句：**从后验 $p(x|y)$ 里独立抽 $S$ 次**，看样本怎么散：

$$\{x^{(s)}\}_{s=1}^S \sim p(x|y)$$

每个 $x^{(s)}$ 都是一张"完整、合理的候选重建"，它们共同勾勒出后验的形状。为什么"抽多次看散度"就能度量不确定？因为后验胖的地方，抽出来的样本彼此差得远；后验瘦的地方，样本几乎重合。散度本身就是不确定性的影子。

### 后验均值（MMSE 估计）

样本云的第一种读法，是找它的"重心"——所有合理解释的平均位置。它正是第 2 章 MMSE 估计的蒙特卡洛版本：

$$\bar{x} = \frac{1}{S}\sum_{s=1}^S x^{(s)}$$

把 $S$ 个样本逐像素平均，$\bar x$ 的每个像素就是"该像素在所有合理解释下的平均值"。当 $S\to\infty$，$\bar x \to \mathbb{E}[x|y]$。**先猜一下**：用 30 个样本平均出来的图，比单次后验采样更糊还是更清晰？
> 揭晓：更**平滑也更鲁棒**。因为平均把不同样本里的随机波动抵消了——18.5-1 实验里单样本 PSNR≈12 dB，30 样本平均的"后验均值"PSNR 拉到 **15.71 dB**。

### 像素级标准差（不确定性地图）

均值回答"猜什么"，标准差回答"有多没底"。对每个像素，衡量 $S$ 个样本在其上的散布程度：

$$\sigma_i = \sqrt{\frac{1}{S-1}\sum_{s=1}^S (x_i^{(s)} - \bar{x}_i)^2}$$

其中 $x_i^{(s)}$ 是第 $s$ 个样本在第 $i$ 个像素的取值，$\bar x_i$ 是该像素的样本均值。这张 $\sigma$ 地图把每个像素的"散度"画成热力图：$\sigma_i$ 越大，说明后验在那像素上越发散，你越没底。

### 像素级置信区间（95%）

有了均值与标准差，就能给出一个区间承诺——真值大概率落在哪：

$$[\bar{x}_i - 1.96\sigma_i,\; \bar{x}_i + 1.96\sigma_i]$$

$\bar x_i$ 与 $\sigma_i$ 就是上面算出的均值与标准差，1.96 是标准正态分布的 97.5% 分位数（双侧合计 95%）。若后验近似高斯，真值有约 95% 概率落在这区间里。

### 分位数图 & 像素间协方差（进阶）

- 分位数：$q_\alpha(x_i)=\text{Percentile}(\{x_i^{(s)}\}, \alpha\times100)$，5%/95% 分位给出 90% 预测区间，还能看出后验是否不对称。
- 协方差：$\Sigma_{ij}=\frac{1}{S-1}\sum_s(x_i^{(s)}-\bar x_i)(x_j^{(s)}-\bar x_j)$，反映相邻像素误差是否"同号"（空间结构）。

从点估计到分布推断，这一转变意味着评价一个重建算法的标准变了：不再只问"这张图和真值差几个 dB"，还要问"这族样本是否覆盖了真值的可能范围"——前者考的是点准不准，后者考的是信念诚实不诚实。

## 18.5.3 扩散采样的不确定性量化实践

### 多次独立采样：固定 $y$，换种子

关键就一句——**测量 $y$ 不动，每次换随机种子**，让扩散从不同的纯噪声 $x_T$ 出发走完整条逆向路：

```python
import torch
S = 30
samples = []
for s in range(S):
    torch.manual_seed(s)          # 不同种子 → 不同采样
    x_s = model(y, physics)       # 每次都是一次后验样本
    samples.append(x_s)

samples_tensor = torch.stack(samples)     # (S, C, H, W)
x_mean = samples_tensor.mean(dim=0)       # 后验均值
x_std  = samples_tensor.std(dim=0)        # 不确定性地图
x_lower = samples_tensor.quantile(0.025, dim=0)  # 95% 下界
x_upper = samples_tensor.quantile(0.975, dim=0)  # 95% 上界
```

这段代码把 18.5.2 的四个公式逐个落了地：`mean` 对应后验均值 $\bar x$，`std` 对应 $\sigma$ 地图，两个 `quantile` 对应经验分位数形式的置信区间。`y` 与 `physics` 全程不变——变的只是起点噪声，这正是"数据固定、样本面不同"的直观演示：同一份证据之下，后验给出的合理解释不止一个。

### 采样数 $S$ 怎么选（先猜后揭）

**先猜**：$S=4$ 和 $S=30$ 的不确定性地图，质量差多少？
> 揭晓（18.5-1 实验）：后验均值 PSNR，$S=4$ 是 14.59 dB，$S=30$ 是 15.71 dB（+1.12 dB）；而且 $S=4$ 的地图满是噪声纹理，$S=30$ 才平滑稳定。经验法则：**$S\ge 20$ 才能拿到稳的地图**。

| $S$ | 用途 | 说明 |
|-----|------|------|
| 10 | 粗估 | 地图偏噪 |
| 30 | 常规 | 基本稳定 |
| 100 | 发表级 | 高精度 |
| 1000 | 极少需要 | 过度 |

### 加速策略（30 次采样意味着 30 倍算力，必须省）

- **减步数**：标准 1000 步 → DDIM 100–50 步（质量微降）→ 一致性模型 1–2 步（降较多）。
- **共享早期步**：早期（$t$ 大）主要去全局噪，可先公共走前 $K$ 步再分叉。
- **并行**：多 GPU 线性加速。

### 不确定性地图怎么读（它暴露了 $A$ 的"盲区"）

- **去模糊**：整体低不确定；边缘略高（模糊对边缘退化重）。
- **超分**：中等；纹理区高（低分辨率里看不见纹理形态）。
- **修复**：已知像素区 $\sigma\approx0$；缺失区高；缺失边缘渐高（离已知越远越靠编）。
- **有限角 CT**：已覆盖角度低、未覆盖角度高——地图直接画出"波前集的方向性缺失"。

> **纯 numpy 替代思路**（不装 deepinv 也能体会）：把"多次采样"换成"对一个简单逆问题跑多次带噪重建"，算均值和 std，照样能得到一张'哪块抖得厉害'的地图。核心思想完全一致，只是采样器从扩散换成蒙特卡洛。

## 18.5.4 不同方法的不确定性对比

| 维度 | 优化 | PnP-ULA | 扩散采样 |
|------|------|---------|---------|
| 不确定性量化 | ❌ | ✅ | ✅ |
| 采样效率 | — | 低（$10^4$+ 步） | 高（$10^2$–$10^3$ 步） |
| 采样质量 | — | 中等 | 高 |

- **优化**：只给点，唯一的"近似不确定性"是扰动 $\lambda$ 看解敏不敏感——不是统计意义的不确定。
- **PnP-ULA**（第 5 章 5.5）：把 ULA 里的对数先验梯度换成去噪器得分：

  $$x_{k+1} = x_k - \delta\left(\frac{1}{\sigma^2}A^\top(Ax_k - y) + \frac{D_{\sigma_s}(x_k) - x_k}{\sigma_s^2}\right) + \sqrt{2\delta}\,z_{k+1}$$

  逐项看：$A^\top(Ax_k-y)/\sigma^2$ 是似然（数据）梯度，把当前解往"满足测量"的方向拉；$(D_{\sigma_s}(x_k)-x_k)/\sigma_s^2$ 是去噪器隐式给出的先验得分（第 5 章 Tweedie 视角），把解往"自然图"的方向拉；$z_{k+1}\sim\mathcal N(0,I)$ 是高斯扰动，$\sqrt{2\delta}$ 控制其强度——正是这一项让迭代不再收敛到一个点，而是让样本云的平稳分布逼近后验。它能产生后验样本，但要 $10^4$–$10^5$ 步才稳态，烧入期长。

- **扩散采样**：每次 100–1000 步去噪即一个样本，质量高、不确定更可靠——是当前最有效的后验采样器。该方法的重要性并不只在于快，而在于它把"后验采样"从 MCMC 时代的手艺活，变成了生成模型的默认能力：先验分布 $p(x)$ 被训练一次性学透，条件化只是推理时叠加证据。

## 18.5.5 可视化、校准与"用不确定性做决策"

### 可视化

- **热力图**：蓝/暗=高置信，红/亮=低置信。
- **置信区间宽度图**：$w_i = x_i^{\text{upper}}-x_i^{\text{lower}}$，越宽越不确定。
- **真值-重建-不确定三联图**：并排看。

### 校准：你的"95%"真覆盖 95% 吗？

不确定性图得"校准"才有用：95% 区间应该真覆盖约 95% 真值像素。

```python
coverage = ((x_true >= x_lower) & (x_true <= x_upper)).float().mean()
print(f"95% 区间实际覆盖率: {coverage:.2%}")   # 理想≈95%
```

**先猜一下**：扩散采样的条件化是近似的（DPS 用 $\hat x_0$ 替似然梯度），它的校准会偏乐观还是偏保守？
> 揭晓（18.5-1 实验）：实测 93% 区间实际覆盖 98.82%——**偏保守（区间过宽）**，但至少覆盖住了真值。中低置信水平偏差更大（覆盖 52.9% vs 标称 33.33%），根因是退火 ULA 在 DRUNet 训练噪声范围外跑，采样链偏离真实后验。教学上可接受，但提醒你：**不确定性估计本身也要被检验**。

### 用不确定性指导决策

- **医学**：高不确定区标"需复查"，低不确定区直接信。
- **数据采集**：有限角 CT 里，不确定地图指出"补哪些角度最有价值"。
- **可信度分级**：高/中/低三档，决定直接用、人工复核、还是丢弃。

> **因果串联收尾**：从点估计（18.4）到分布（本节），我们终于把第 1 章那句"描述哪些答案更可能"坐实了——也只有扩散采样能天然给你这张地图。下一节（18.6）看看这条路线还能往哪拓：竞赛、加速、新模态。

## 实验 18.5-1：不确定性量化与后验采样

实验 `18.5-1.py` 演示**从点估计到分布推断的完整流程**——通过退火 Unadjusted Langevin Algorithm（ULA）从后验分布 $p(x|y)$ 中多次采样，计算像素级标准差、经验分位数区间，并通过校准检验验证不确定性估计的可靠性。

### 实验场景

实验考虑图像修复问题：观测模型 $y = Mx + \varepsilon$，其中 $M$ 是 50% 像素缺失的二值掩码，$\varepsilon \sim \mathcal{N}(0, \sigma^2 I)$ 为加性高斯噪声（$\sigma = 0.01$）。这是一个严重不适定的逆问题——一半的像素信息完全缺失，不同先验可能给出完全不同的重建结果。

**后验采样方法**：使用退火 ULA（Unadjusted Langevin Algorithm）从后验分布 $p(x|y)$ 中采样。退火 ULA 通过多级噪声调度 $[\sigma_0, \sigma_1, \ldots, \sigma_K] = [1.0, 0.5, 0.25, 0.1, 0.05, 0.02, 0.01]$ 逐步降低 Langevin 动力学的温度，使采样链从高斯先验附近逐渐收敛到后验分布。每级噪声下运行 50 步 ULA 迭代，总采样步数 350 步/样本。

**采样配置**：生成 $S = 30$ 个独立后验样本（不同随机种子），用于计算后验均值、像素级标准差和经验分位数区间。ULA 参数配置：数据保真项权重 $\lambda = 0.05$，步长系数 $0.005$，Langevin 噪声尺度 $1.0$，每级 $\sigma$ 的 burn-in 步数 $10$。

### 实验目的

1. **验证从点估计到分布推断的必要性**：单次重建（MAP/MMSE 估计）只能给出一个"最佳猜测"，无法量化重建的可靠性；多次后验采样可计算像素级不确定性，为安全关键决策提供依据
2. **计算像素级标准差与经验分位数区间**：从 $S = 30$ 个后验样本中计算每个像素的标准差 $\sigma_i$ 和 93% 经验分位数区间 $[q_{0.033}, q_{0.967}]$，可视化不确定性的空间分布
3. **校准检验**：验证经验分位数区间的实际覆盖率是否与标称水平一致——93% 置信区间应覆盖约 93% 的真值像素；若覆盖率显著偏离 93%，说明不确定性估计存在偏差
4. **量化样本数对不确定性估计的影响**：对比 $S = 4$ 和 $S = 30$ 的不确定性图质量，验证 $S \geq 20$ 的经验法则

### 实验输入

| 参数 | 设置 |
|------|------|
| 测试图像 | celeba_example.jpg，$128 \times 128$ 像素 |
| 退化模型 | 50% 像素缺失（Inpainting），$\sigma = 0.01$ |
| 观测 PSNR | 11.39 dB |
| 采样方法 | 退火 ULA（Annealed ULA） |
| 退火调度 | $[1.0, 0.5, 0.25, 0.1, 0.05, 0.02, 0.01]$（7 级） |
| 每级步数 | 50 步 ULA 迭代 |
| 总步数 | 350 步/样本 |
| 数据保真权重 | $\lambda = 0.05$ |
| 步长系数 | $0.005$ |
| Langevin 噪声尺度 | $1.0$ |
| burn-in 步数 | 10 步/级 |
| 后验样本数 | $S = 30$ |
| 去噪器 | DRUNet（训练噪声范围 $[0, 50/255 \approx 0.196]$） |

### 预期结果

- **后验均值 PSNR**：约 15-16 dB，高于单样本 PSNR（约 12 dB），因为多样本平均抵消了随机波动
- **样本 PSNR 范围**：约 12-13 dB，标准差 $< 0.5$ dB，表明采样链混合充分
- **像素级标准差**：平均约 0.15，缺失区域标准差高于已知像素区域
- **93% 经验分位数区间覆盖率**：应接近 93%（允许 $\pm 5\%$ 偏差）；若覆盖率 $> 98\%$，说明区间偏保守（过宽）；若覆盖率 $< 88\%$，说明区间过于自信（过窄）
- **样本数影响**：$S = 4$ 的不确定性图噪声较大，$S = 30$ 的图更平滑稳定

#### 步骤 4：校准检验

![实验18.5-1 步骤4：校准检验](./第十八章 配套实验/实验18.5-1/step4_calibration.png)

校准检验验证了经验分位数区间的可靠性。左图展示了四个置信水平（6.67%、33.33%、66.67%、93.33%）下，经验分位数区间的实际覆盖率与标称水平的对比。右图展示了校准偏差（实际覆盖率 - 标称水平）。

**校准结果**：

| 标称置信水平 | 实际覆盖率 | 校准偏差 | 校准状态 |
|-------------|-----------|---------|---------|
| 6.67% | 12.08% | +5.41% | 存在偏差 |
| 33.33% | 52.90% | +19.57% | 严重失配 |
| 66.67% | 83.57% | +16.90% | 严重失配 |
| 93.33% | 98.82% | +5.49% | 存在偏差 |

**校准分析**：
- **93% 置信区间**：实际覆盖率 98.82%，偏差 +5.49%，说明区间略偏保守（过宽），但覆盖了真值，教学上可接受
- **中低置信水平**（33.33%、66.67%）：实际覆盖率显著高于标称水平（偏差 +17-20%），说明区间过宽，不确定性被高估
- **根本原因**：DRUNet 的训练噪声范围为 $[0, 0.196]$，而退火调度的前 3 级（$\sigma = 1.0, 0.5, 0.25$）超出此范围，导致去噪器输出不可靠，单样本 PSNR 仅约 12 dB（接近观测水平）；但 30 个独立样本取平均时噪声部分抵消，后验均值 PSNR 提升至 15.71 dB

**教学启示**：校准偏差反映了 ULA 采样的局限性——在 DRUNet 工作范围外的 $\sigma$ 级别，采样链的平稳分布与真实后验存在偏差。若需更精确的校准，可换用 DPS（Diffusion Posterior Sampling）或缩短退火调度至 DRUNet 工作范围 $[0.15, 0.0025]$，但后者会导致样本多样性不足。当前配置（$\lambda = 0.05$，burn-in = 10）是在教学目标下的最佳平衡：后验均值 PSNR 展示了"多样本平均去噪"的效果，校准曲线虽然偏保守，但区间覆盖了真值。

| 知识点 | 实验验证 |

> **实践启示**：不确定性量化为逆问题重建提供了"置信度标签"——在医学诊断中，高不确定性区域可标记为"需进一步检查"；在数据采集中，不确定性图可指导额外的测量方向。本实验的校准偏差提醒我们：不确定性估计的可靠性依赖于采样方法的质量，退火 ULA 在 DRUNet 工作范围外的 $\sigma$ 级别会产生偏差，实际应用中需根据去噪器的训练噪声范围调整退火调度。
