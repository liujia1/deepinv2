## 三类方法的最终对比

| 维度 | 优化类 | PnP 类 | 扩散采样类 |
|------|-------|-------|-----------|
| 先验类型 | 显式 $R(x)$ | 隐式（去噪器） | 生成式（扩散 $p(x)$） |
| 估计类型 | 点估计（MAP） | 点估计 | 分布估计（后验采样） |
| 不确定性量化 | ❌ | 需 ULA 扩展 | ✅ 天然 |
| 计算速度 | ⭐⭐⭐ | ⭐⭐ | ⭐ |
| 重建质量 | ⭐ | ⭐⭐ | ⭐⭐⭐ |
| 零样本迁移 | ❌ | ✅ | ✅ |
| 退化严重时 | 明显退化 | 部分保持 | 优势最大 |
| deepinv | ✅ | ✅ DPIR | ✅ DiffPIR |

**选型口诀**：快速原型→优化；日常→PnP(DPIR)；最优→扩散(DiffPIR)；要不确定→扩散+多次采样。

## 开放问题与未来展望

- **计算效率**：扩散比优化仍慢，但 18.3.5 / 18.6.4 也给出了现成的补丁——**采样器级的 DDIM / DPM-Solver 零训练就能拿到 20–100×**（20–50 步）加速，质量只微降；要把步数压到 1 步才需要一致性 / 蒸馏那类额外训练。
- **模型泛化**：预训练先验受训练数据分布限制，如何通用？
- **条件化精度**：DPS/DiffPIR 的条件化是近似，更忠实的后验仍开放。
- **不确定性校准**：采样样本是否忠实真实后验？偏差怎么纠？
- **非线性逆问题**：相位恢复、盲去卷积的条件扩散更难。
- **联合逆问题**：同时估多个未知量仍早期。

> **最后的话（zoom-out）**：从第 1 章"什么是逆问题"到第 18 章"用扩散解自定义逆问题"，我们走完了从理论到实践的整圈。逆问题的核心挑战——不适定性与不确定性——贯穿全书。扩散不是凭空冒出来的炫技，而是逆问题对"如何从不确定中提取信息"这一问题的自然回答。**当我们不只给一张图、还能告诉用户'这张图哪块我在猜'，我们就真正跨越了从不确定性到确定性的那一步——这，就是贝叶斯与扩散结合的终极价值。**

## 章末可运行代码：纯 numpy 复现"自定义算子 A + 扩散/PnP 求解"的最小闭环

> **说明**：下面这段**不依赖任何私有库**（不用 deepinv、不用 PyTorch），只用 numpy/scipy/matplotlib。它把 18.2–18.5 的核心思想浓缩成一个能直接跑的小实验：① 定义一个你自己的前向算子（这里用"下采样 + 模糊"模拟自定义逆问题）；② 写伴随算子并用内积检验法验证（18.2.4）；③ 用"去噪器即先验"的 PnP 思路迭代求解（18.3.2）；④ 多次采样得到均值与不确定性地图（18.5）。读者不装私有库也能跑通全书的因果链。

```python
# ============================================================
# 第18章章末最小闭环：自定义前向算子 A + PnP式求解 + 不确定性
# 仅依赖 numpy / scipy / matplotlib，无需 deepinv / torch
# 对应：18.2 定义算子 → 18.3 选策略(PnP) → 18.4 实战 → 18.5 不确定性
# ============================================================
import numpy as np
import matplotlib.pyplot as plt
from scipy.ndimage import gaussian_filter, zoom
from scipy.linalg import svd

np.random.seed(0)
N = 64                      # 图像边长（小图，跑得快）
gt = np.zeros((N, N))
gt[20:44, 20:44] = 1.0      # 一张"方块"真图（最朴素的测试图）

# ---------- 步骤1：定义自定义前向算子 A（模糊 + 2倍下采样）----------
# 这里 A 就是 "先高斯模糊，再每2取1"，对应 18.2 说的 y = A x + ε
def A(x):
    """前向算子：模糊 + 下采样（白话：把清晰图变模糊变小）"""
    blurred = gaussian_filter(x, sigma=1.5)
    return blurred[::2, ::2].copy()        # 2倍下采样

def A_adjoint(y):
    """伴随算子：上采样(补零) + 模糊的伴随≈再模糊（白话：把测量拉回原尺寸）"""
    z = np.zeros((N, N))
    z[::2, ::2] = y                         # 上采样：缺失处先补零
    return gaussian_filter(z, sigma=1.5)    # 模糊的伴随近似为同核模糊

# 制造带噪观测
y = A(gt) + 0.05 * np.random.randn(*A(gt).shape)

# ---------- 18.2.4：内积检验法验证伴随（先猜后揭：正确应≈1e-10量级）----------
x_r = np.random.randn(N, N)
y_r = np.random.randn(*A(x_r).shape)
lhs = np.sum(A(x_r) * y_r)                 # <A x, y>
rhs = np.sum(x_r * A_adjoint(y_r))         # <x, Aᵀ y>
print(f"[伴随验证] 相对误差 = {abs(lhs-rhs)/abs(lhs):.2e}  (应很小)")

# ---------- 步骤2-3：PnP式求解（去噪器即先验，见18.3.2的 Tweedie 思想）----------
# 这里我们用一个"非局部均值式"的朴素去噪器 D_sigma 当先验：
# 白话：把图做一点平滑，就当"往自然图拉一步"。真实 PnP 用神经网络去噪器。
def denoiser(x, sigma):
    """朴素去噪器：轻度高斯平滑（替代 DRUNet/DiffUNet，演示用）"""
    return gaussian_filter(x, sigma=sigma)

# PnP-HQS 迭代（对应18.3.2）：交替"数据一致性"和"去噪"
x_hat = A_adjoint(y).copy()                # 用伴随重建当初始化
sigmas = [0.1, 0.05, 0.025, 0.01]          # 递减噪声调度（和 DPIR 同思路）
lam = 0.5                                   # 数据一致性权重
for s in sigmas:
    # 数据一致性步：往"满足测量"的方向拉（用到 A 和 A_adjoint）
    x_hat = x_hat - lam * A_adjoint(A(x_hat) - y)
    # 去噪步：把去噪器当先验（PnP 的核心替换 prox_R ≈ D_sigma）
    x_hat = denoiser(x_hat, s)

psnr = 10*np.log10(1.0 / np.mean((x_hat-gt)**2))
print(f"[PnP重建] PSNR = {psnr:.2f} dB  （无先验基线见下）")
x_base = A_adjoint(y)
psnr_base = 10*np.log10(1.0 / np.mean((x_base-gt)**2))
print(f"[无先验基线] PSNR = {psnr_base:.2f} dB  （先验明显加分）")

# ---------- 步骤5：18.5 不确定性量化（多次采样 → 均值 + 标准差地图）----------
S = 12
samples = []
for seed in range(S):
    rng = np.random.RandomState(seed)
    y_s = A(gt) + 0.05 * rng.randn(*A(gt).shape)   # 固定真图，换观测噪声种子
    x_s = A_adjoint(y_s).copy()
    for s in sigmas:
        x_s = x_s - lam * A_adjoint(A(x_s) - y_s)
        x_s = denoiser(x_s, s)
    samples.append(x_s)
samples = np.stack(samples, 0)
mean_img = samples.mean(0)                  # 后验均值（MMSE）
std_img = samples.std(0)                    # 不确定性地图

# ---------- 可视化 ----------
fig, ax = plt.subplots(1, 4, figsize=(16, 4))
ax[0].imshow(gt, cmap='gray');       ax[0].set_title("真图 x (自定义逆问题的答案)")
ax[1].imshow(y, cmap='gray');        ax[1].set_title("观测 y = A(x)+ε (只有1/4像素)")
ax[2].imshow(x_hat, cmap='gray');    ax[2].set_title(f"PnP重建 (PSNR {psnr:.1f}dB)")
ax[3].imshow(std_img, cmap='hot');   ax[3].set_title("不确定性地图 σ (亮=没底)")
plt.tight_layout(); plt.show()

print("\n[读图提示] 不确定性地图里：下采样'丢掉的'区域整体更亮，")
print("说明前向算子 A 的零空间方向正是我们最没把握的地方——这就是18.5说的'不确定性暴露A的盲区'。")
```

**这段代码复现了什么**：
- `A` / `A_adjoint` + 内积检验 → 对应 **18.2**（自定义算子与伴随验证，呼应第 1 章 $y=Ax$）；
- `denoiser` 当先验 + 交替迭代 → 对应 **18.3.2**（PnP：去噪器即先验，呼应第 5 章 Tweedie）；
- `psnr` 对比基线 → 对应 **18.4**（先验信息的价值）；
- `std_img` 不确定地图 → 对应 **18.5**（从点估计到分布，呼应第 1 章"描述哪些答案更可能"）。

> 想升级成"真扩散"？把上面的朴素 `denoiser` 换成训练好的去噪网络、把单步迭代换成多步逆向 SDE（第 7、13 章），并把"换噪声种子"换成"从纯噪声 $x_T$ 出发的不同随机种子多次采样"——就是 18.4–18.5 里 DiffPIR/DPS 的最小骨架。核心因果链，这段 numpy 代码已经跑给你看了。
