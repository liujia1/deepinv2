## 为什么一定要自己跑一遍？

读公式时，VAE 看起来很顺：编码器输出 $(\mu,\log\sigma^2)$，重参数化采样 $z$，解码器还原，ELBO 一推就上去。但有几个东西**只有跑出来才能感受到**：
1. KL 项一开始几乎为 0，慢慢爬升——你亲眼看到"编码器开始动用隐空间"；
2. 隐空间在 t-SNE 下从"分离的簇 + 空洞"变成"重叠的连续云"；
3. 在隐空间里线性插值，图像从"3"平滑变到"8"，中间不掉进无意义区域。

这些不是修辞，是训练曲线和可视化里的真东西。下面先看一个标准的 PyTorch 实现骨架。

**本节目标**：
- 对照前文数学，读懂一个标准 PyTorch VAE 的核心骨架；
- 会用 t-SNE / 插值 / 先验采样观察隐空间；

## PyTorch 实现 VAE（完整训练示意）

以下实现基于 MNIST 手写数字（$28\times28$ 灰度图，$d_x=784$），隐空间维度 $d_z=20$。**完整可训练脚本见配套实验 `9.5-1.py`**，这里只展示核心骨架，方便你对照前面几节的数学。

### 网络架构

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class Encoder(nn.Module):
    def __init__(self, input_dim=784, hidden_dim=400, latent_dim=20):
        super().__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)

    def forward(self, x):
        h = F.relu(self.fc1(x))
        mu = self.fc_mu(h)
        logvar = self.fc_logvar(h)
        return mu, logvar

class Decoder(nn.Module):
    def __init__(self, latent_dim=20, hidden_dim=400, output_dim=784):
        super().__init__()
        self.fc1 = nn.Linear(latent_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, output_dim)

    def forward(self, z):
        h = F.relu(self.fc1(z))
        # 伯努利输出：sigmoid激活
        x_recon = torch.sigmoid(self.fc2(h))
        return x_recon
```

编码器把 784 维输入压到 400 维隐藏层，再分别吐出均值 $\mu$ 和对数方差 $\log\sigma^2$（各 20 维）。解码器把 20 维隐变量映射回 784 维，用 sigmoid 输出伯努利概率。

### 重参数化采样（就是 9.2 那招）

```python
def reparameterize(mu, logvar):
    std = torch.exp(0.5 * logvar)  # σ = exp(0.5 * logσ²)
    eps = torch.randn_like(std)     # ε ~ N(0, I)
    return mu + std * eps           # z = μ + σε
```

这就是 9.2 节讲的重参数化技巧的实现。$\epsilon$ 由 `torch.randn_like(std)` 生成、与 $\phi$ 无关，梯度可以顺着 `mu` 和 `std` 正常反传。

### ELBO 损失（重建 + KL，9.3 的落地）

```python
def loss_function(x, x_recon, mu, logvar, beta=1.0):
    # 重建项：伯努利似然的负对数（交叉熵）
    BCE = F.binary_cross_entropy(x_recon, x, reduction='sum')

    # KL正则化项：高斯KL散度的闭式解（9.3 / 附录9B）
    # D_KL = 0.5 * Σ(μ² + σ² - logσ² - 1)
    KLD = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())

    # β-VAE：ELBO = -BCE - β * KLD
    return BCE + beta * KLD
```

逐行对应 9.3：`BCE` 是伯努利负对数似然（≡交叉熵）；`KLD` 是 9.3 公式的闭式解；`beta` 是 $\beta$-VAE 旋钮。

### 训练循环（示意）

```python
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

transform = transforms.Compose([transforms.ToTensor()])
train_dataset = datasets.MNIST('./data', train=True, download=True, transform=transform)
train_loader = DataLoader(train_dataset, batch_size=128, shuffle=True)

encoder = Encoder(); decoder = Decoder()
optimizer = torch.optim.Adam(
    list(encoder.parameters()) + list(decoder.parameters()), lr=1e-3)

num_epochs = 50
for epoch in range(num_epochs):
    total_loss = 0
    for x, _ in train_loader:
        x = x.view(-1, 784)                 # 展平为784维
        mu, logvar = encoder(x)
        z = reparameterize(mu, logvar)
        x_recon = decoder(z)
        loss = loss_function(x, x_recon, mu, logvar, beta=1.0)
        optimizer.zero_grad(); loss.backward(); optimizer.step()
        total_loss += loss.item()
    print(f"Epoch {epoch+1}/{num_epochs}, Loss: {total_loss/len(train_loader.dataset):.4f}")
```

### 训练过程该盯什么

1. **总损失**：持续下降；
2. **重建损失（BCE）**：下降，但不应降到 0（否则可能过拟合或后验坍缩）；
3. **KL 散度**：从接近 0 逐步上升再稳定——编码器开始用隐空间了；
4. **活跃维度数**：$D_{\text{KL}}(q_\phi(z_j|x)\|p(z_j)) > \epsilon$ 的维度数。

> **[图示位置]**：训练曲线图——横轴 epoch，纵轴损失值。三条线：总损失、重建损失、KL 散度。KL 从近 0 爬升，重建损失持续下降，最终平衡。

### 隐空间插值（连续性才是 VAE 的杀手锏）

隐空间连续，才能插值生成。线性插值在两点间连线；球面插值（slerp）沿高维球面走，更保范数。

```python
def interpolate(encoder, decoder, x1, x2, num_steps=10):
    with torch.no_grad():
        mu1, _ = encoder(x1.unsqueeze(0)); mu2, _ = encoder(x2.unsqueeze(0))
        alphas = torch.linspace(0, 1, num_steps)
        outs = [decoder((1-a)*mu1 + a*mu2) for a in alphas]
    return torch.cat(outs)

def slerp(z1, z2, num_steps=10):
    """球面线性插值：沿高维球面路径，比线性更保结构"""
    z1n = z1/z1.norm(dim=-1, keepdim=True); z2n = z2/z2.norm(dim=-1, keepdim=True)
    omega = torch.acos(torch.clamp((z1n*z2n).sum(dim=-1, keepdim=True), -1, 1))
    sin_o = torch.sin(omega)
    alphas = torch.linspace(0, 1, num_steps, device=z1.device)
    return torch.cat([(torch.sin((1-a)*omega)/sin_o)*z1 + (torch.sin(a*omega)/sin_o)*z2
                      for a in alphas], dim=0)
```

线性插值简单，但当编码点离原点远时可能穿过低密度区；slerp 更好保持隐空间结构。

> **[图示位置]**：隐空间插值图——从"3"平滑过渡到"8"，中间是合理的过渡形态。对比 AE（插值经过空洞、中间模糊/无意义）与 VAE（始终产生有意义的图）。

## 实验 9.5-1：β-VAE对比与隐空间可视化

实验 `9.5-1.py` 综合演示**β-VAE的核心权衡**：通过训练三个模型（$\beta = 0, 1, 4$），对比隐空间结构、插值质量、活跃维度和先验采样效果，验证9.3节β-VAE理论和9.5节可视化方法。

### 实验场景

实验在MNIST数据集上训练三个VAE模型：
- **$\beta = 0$（AE）**：无KL正则化，退化为传统自编码器
- **$\beta = 1$（标准VAE）**：平衡重建与KL正则化
- **$\beta = 4$（β-VAE）**：强KL正则化，促进解纠缠但可能导致后验坍缩

对比四个方面：
1. **隐空间结构**：t-SNE可视化不同$\beta$下的隐空间分布
2. **插值连续性**：AE vs VAE的隐空间插值质量
3. **活跃维度**：检测后验坍缩程度
4. **先验采样**：生成质量对比

### 实验目的

1. **验证β对隐空间结构的影响**：$\beta$越大，隐空间越规律（各簇越重叠）
2. **验证隐空间插值连续性**：VAE插值平滑过渡，AE插值可能模糊
3. **检测后验坍缩**：$\beta = 4$时活跃维度减少
4. **对比生成质量**：$\beta$越小生成越清晰但不规律，$\beta$越大生成越模糊但规律

### 实验输入

| 参数 | 设置 |
|------|------|
| 数据集 | MNIST，$28 \times 28$ 灰度图像 |
| 隐空间维度 | $d_z = 20$ |
| $\beta$值 | $\{0, 1, 4\}$ |
| 训练轮数 | 15 epochs（每个模型） |
| t-SNE样本数 | 前2000个测试样本 |
| 活跃维度阈值 | KL > 0.01 |
| 插值步数 | 10步线性插值 |

### 预期结果

| $\beta$ | 隐空间结构 | 插值质量 | 活跃维度 | 先验采样 |
|---------|-----------|---------|---------|---------|
| 0 (AE) | 分离、有空洞 | 可能模糊/无意义 | 高（无约束） | 无意义（隐空间不匹配先验） |
| 1 (VAE) | 连续、重叠 | 平滑过渡 | 20/20（全活跃） | 可识别数字 |
| 4 (β-VAE) | 高度重叠 | 平滑 | 可能<20（后验坍缩） | 模糊但规律 |

## β-VAE效果对比（训练观察小结）

通过调节 $\beta$，KL 正则化强度对隐空间与重建质量的影响如下：

### 预期结果

**$\beta = 0$（退化为自编码器）**：
- 隐空间：各簇完全分离，簇间有空洞
- 重建质量：非常好，几乎完美还原
- 生成质量：差，从空洞区域采样生成无意义图像
- 解纠缠：无

**$\beta = 1$（标准VAE）**：
- 隐空间：各簇有重叠，空间连续
- 重建质量：较好，略有模糊
- 生成质量：较好，可生成有意义的数字
- 解纠缠：部分解纠缠

**$\beta = 4$（强正则化）**：
- 隐空间：各簇高度重叠，编码更接近 $\mathcal{N}(0,I)$
- 重建质量：下降，图像模糊
- 生成质量：多样性下降
- 解纠缠：更好，各维度编码更独立的因素

> **[图示位置]**：三列对比图——分别对应 $\beta = 0, 1, 4$，每列包含：隐空间t-SNE图、重建结果示例、从先验采样生成示例、单维度遍历生成示例。

## 训练动态观察

### 重建损失与KL损失的演化

标准 VAE 训练中，两者演化模式：
- **训练初期**：重建损失快速下降，KL 散度缓慢上升——编码器优先学有用表示；
- **训练中期**：两者同步变化，逐步平衡；
- **训练后期**：趋于稳定。

若 KL 一直接近 0，说明后验坍缩了。

### 后验坍缩的检测与处理

```python
    with torch.no_grad():
        kl_per_dim = 0.5 * (mu.pow(2) + logvar.exp() - logvar - 1)
        active_dims = (kl_per_dim.mean(dim=0) > 0.01).sum().item()
        print(f"活跃维度数: {active_dims}/{latent_dim}")
```

活跃维度数远小于 $d_z$，说明很多维度被浪费。对策：降低 $d_z$；KL 退火；自由比特。

### 隐空间维度的影响

| $d_z$ | 重建质量 | 生成质量 | 训练稳定性 |
|---|---|---|---|
| 2 | 差 | 好（可视化方便） | 稳定 |
| 10 | 中 | 较好 | 稳定 |
| 20 | 较好 | 好 | 需注意后验坍缩 |
| 50 | 好 | 差 | 容易后验坍缩 |

原则：$d_z$ 应与数据内在维度匹配，不宜过大。MNIST 取 $d_z=10\sim20$ 合理。

## 章末可运行：最小 toy VAE（numpy，重度注释）

下面这个 toy 不依赖 PyTorch，只用 `numpy`，在一组**人造的 2D 簇数据**上训练一个"2 维隐变量"的极小 VAE。它复现本章最核心的三件事：**(1) 重参数化让梯度穿过随机节点；(2) KL 正则把隐空间规整成连续云；(3) 从先验采样能生成像样样本**。几分钟内就能跑完——这是理解 VAE 最省事的一扇窗。完整、可扩展到 MNIST 的训练脚本请见配套实验 `9.5-1.py`。

```python
# -*- coding: utf-8 -*-
# 最小 toy VAE：用 numpy 在人造 2D 数据上复现 VAE 的核心现象
# 目标：编码器把 2D 数据点压成 2 维隐变量 z，解码器还原，
#       通过 ELBO = 重建 - KL 训练，看隐空间从"乱"变"齐"。
import numpy as np

rng = np.random.default_rng(0)

# ---------- 1) 造数据：4 个高斯簇，每簇 200 点，共 2 维 ----------
def make_data(n_per=200, seed=0):
    g = np.random.default_rng(seed)
    centers = np.array([[3, 3], [-3, 3], [3, -3], [-3, -3]], dtype=float)
    X = []
    for c in centers:
        X.append(c + g.normal(0, 0.4, size=(n_per, 2)))
    return np.vstack(X).astype(float)

X = make_data()
N, D = X.shape          # N 样本数, D=2 数据维度
LAT = 2                 # 隐空间维度（就 2 维，方便看）
HID = 16                # 隐藏层宽度

# ---------- 2) 极简网络（两层线性 + tanh），手动实现前向/反向 ----------
# 编码器: x -> h -> (mu, logvar)   解码器: z -> h -> x_recon
def init_params():
    # 用小型随机初始化；*0.1 让初始梯度别太大
    W = lambda ins, outs: rng.normal(0, 0.1, size=(ins, outs))
    b = lambda outs: np.zeros(outs)
    return {
        'enc_W1': W(D, HID),  'enc_b1': b(HID),
        'enc_Wmu': W(HID, LAT), 'enc_bmu': b(LAT),
        'enc_Wlv': W(HID, LAT), 'enc_blv': b(LAT),
        'dec_W1': W(LAT, HID), 'dec_b1': b(HID),
        'dec_W2': W(HID, D),   'dec_b2': b(D),
    }

def tanh(x):  return np.tanh(x)
def dtanh(x): return 1.0 - np.tanh(x) ** 2

def h_enc(x, p):  # 编码器隐藏层（反向里复用）
    return tanh(x @ p['enc_W1'] + p['enc_b1'])

def forward(p, x):
    # 编码器
    h = h_enc(x, p)
    mu = h @ p['enc_Wmu'] + p['enc_bmu']
    logvar = h @ p['enc_Wlv'] + p['enc_blv']
    # 重参数化采样 z = mu + sigma * eps, eps ~ N(0,I)  —— 9.2 的核心一招
    eps = rng.normal(0, 1, size=mu.shape)
    z = mu + np.exp(0.5 * logvar) * eps
    # 解码器
    h2 = tanh(z @ p['dec_W1'] + p['dec_b1'])
    xr = h2 @ p['dec_W2'] + p['dec_b2']   # 高斯解码器均值（连续数据）
    return mu, logvar, z, xr

def loss_and_grads(p, x, beta=1.0):
    mu, logvar, z, xr = forward(p, x)
    # 重建项：高斯解码器 -> 负 MSE（忽略常数）  —— 9.3
    recon = -np.mean(np.sum((x - xr) ** 2, axis=1)) / 2.0
    # KL 项闭式解，逐样本平均  —— 9.3 / 附录9B
    kl = -0.5 * np.mean(np.sum(1 + logvar - mu ** 2 - np.exp(logvar), axis=1))
    elbo = recon - beta * kl     # 我们要最大化 ELBO，所以损失 = -ELBO
    # ---- 反向传播（对极小网络手推梯度，演示梯度如何穿过重参数化节点）----
    # dL/d(xr) = (xr - x) / batch
    dxr = (xr - x) / x.shape[0]
    # 解码器第二层
    dh2 = dxr @ p['dec_W2'].T * dtanh(z @ p['dec_W1'] + p['dec_b1'])
    g = {}
    g['dec_W2'] = (z[:, :, None] * dxr[:, None, :]).mean(axis=0)
    g['dec_b2'] = dxr.mean(axis=0)
    g['dec_W1'] = (z[:, :, None] * dh2[:, None, :]).mean(axis=0)
    g['dec_b1'] = dh2.mean(axis=0)
    # 梯度经 z 往回传：z = mu + exp(0.5*logvar)*eps
    dmu = dh2 @ p['dec_W1'].T
    dlv = dmu * (0.5 * np.exp(0.5 * logvar) * eps)  # 走 sigma 这条路径
    # KL 对 mu, logvar 的解析梯度（见 9.3 闭式解）
    dmu += -beta * (-mu) / x.shape[0]
    dlv += -beta * (-0.5 * (1 - np.exp(logvar))) / x.shape[0]
    dh = dmu @ p['enc_Wmu'].T + dlv @ p['enc_Wlv'].T
    dh = dh * dtanh(x @ p['enc_W1'] + p['enc_b1'])
    g['enc_Wmu'] = (h_enc(x, p)[:, :, None] * dmu[:, None, :]).mean(axis=0)
    g['enc_bmu'] = dmu.mean(axis=0)
    g['enc_Wlv'] = (h_enc(x, p)[:, :, None] * dlv[:, None, :]).mean(axis=0)
    g['enc_blv'] = dlv.mean(axis=0)
    g['enc_W1'] = (x[:, :, None] * dh[:, None, :]).mean(axis=0)
    g['enc_b1'] = dh.mean(axis=0)
    return -elbo, g, mu, logvar

# ---------- 3) 训练循环 ----------
p = init_params()
lr = 1e-2
for it in range(2000):
    loss, g, mu, logvar = loss_and_grads(p, X, beta=1.0)
    for k in p:
        p[k] -= lr * g[k]
    if it % 400 == 0:
        kl = -0.5 * np.mean(np.sum(1 + logvar - mu ** 2 - np.exp(logvar), axis=1))
        print(f"iter {it:4d}  loss={loss:.3f}  KL={kl:.3f}")

# ---------- 4) 复现核心现象 ----------
# (a) 隐空间：编码均值 mu 应被 KL 拉向原点附近、形成连续云
print("编码均值 mu 的前5个样本：\n", np.round(mu[:5], 2))
# (b) 生成：从先验 N(0,I) 直接采样 z，过解码器得到"新样本"
z_prior = rng.normal(0, 1, size=(5, LAT))
h2 = tanh(z_prior @ p['dec_W1'] + p['dec_b1'])
x_gen = h2 @ p['dec_W2'] + p['dec_b2']
print("从先验采样生成的新样本（前5个）：\n", np.round(x_gen, 2))
# (c) 重建：把原数据过一遍编码器-解码器，看还原误差
_, _, _, xr = forward(p, X)
print("平均重建误差（MSE）：", float(np.mean((X - xr) ** 2)))
```

跑完你会看到：KL 从接近 0 逐渐爬升（编码器开始用隐空间），重建误差下降，且从 $\mathcal{N}(0,I)$ 采样的 $z$ 经解码器能生成落在四个簇附近的点——这正是"VAE 能生成"的最小证据。把 `beta` 调到 0，隐空间会散开、从先验采样开始乱套；调到 4，重建变糊但隐空间更齐——亲手验证 9.3 的权衡。

## 收尾：为什么这件事重要

只有亲手跑过，你才真正相信前面四节的逻辑：KL 从 0 爬升、隐空间从分离的簇变成连续的云、插值不再掉进空洞、从先验采样能生出新图——这些不是修辞，而是代码跑出来的事实。VAE 是变分路径的第一个里程碑，但它的表达力有限。第 10 章将把单层 VAE 扩展为层级 VAE，当层数 $L\to\infty$ 时，层级 VAE 收敛于扩散过程——编码器的加噪结构，将成为扩散模型的前向过程。VAE 的故事，正是变分推断通向扩散模型的序章。
