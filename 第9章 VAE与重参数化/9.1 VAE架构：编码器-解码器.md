# 9.1 VAE架构：编码器-解码器

> **核心观点**：VAE将变分推断的抽象框架具象化为编码器-解码器架构。编码器（识别模型）$q_\phi(z|x)$ 实现"推断"——从观测推断隐变量的分布；解码器（生成模型）$p_\theta(x|z)$ 实现"生成"——从隐变量生成观测。两者联合训练最大化ELBO，构成一个自洽的概率生成模型。与传统自编码器的本质区别在于：VAE建模的是**分布**而非**确定性映射**，这使得VAE不仅能重建，还能生成新样本。

## 从变分推断到VAE

第8章建立了变分推断的一般框架。给定观测 $x$，我们希望推断隐变量 $z$ 的后验分布 $p(z|x)$。由于真实后验通常不可解，我们引入变分分布 $q_\phi(z|x)$ 近似它，通过最大化ELBO实现：

$$\max_\phi \text{ELBO}(\phi) = \max_\phi \mathbb{E}_{q_\phi(z|x)}\left[\log \frac{p(x,z)}{q_\phi(z|x)}\right]$$

第8章讨论了变分族的选择——平均场近似假设 $q_\phi(z|x) = \prod_j q_\phi(z_j|x)$，隐变量各分量独立。这种假设简化了优化，但严重限制了表达力：真实后验 $p(z|x)$ 中的隐变量往往有复杂的相关结构，平均场无法捕捉。

VAE的核心思想是：**不手工设计变分族，而用神经网络自动学习变分族的参数**。具体来说：

- 编码器网络 $q_\phi(z|x)$：输入 $x$，输出 $z$ 的分布参数
- 解码器网络 $p_\theta(x|z)$：输入 $z$，输出 $x$ 的分布参数

这样，变分族不再是手工选择的简化假设，而是一个由神经网络参数化的灵活分布族。网络参数 $(\phi, \theta)$ 通过最大化ELBO联合学习。

**命名解释**：

- **Variational**：因为VAE的训练目标是变分下界（ELBO），本质是变分推断
- **Autoencoder**：因为VAE具有自编码器结构——编码器将 $x$ 映射到 $z$，解码器将 $z$ 映射回 $x$
- 但VAE不是传统自编码器——它是**概率性的**、**可生成的**、**有正则化的**

## 识别模型（编码器）

编码器（也称识别模型，recognition model）定义了近似后验分布 $q_\phi(z|x)$：

$$(\mu_\phi(x), \log \sigma_\phi^2(x)) = \text{Encoder}_\phi(x)$$

$$q_\phi(z|x) = \mathcal{N}(z | \mu_\phi(x), \text{diag}(\sigma_\phi^2(x)))$$

其中：

- $\mu_\phi(x) \in \mathbb{R}^{d_z}$ 是编码器输出的均值向量
- $\sigma_\phi^2(x) \in \mathbb{R}^{d_z}$ 是编码器输出的方差向量（对角元素）
- $d_z$ 是隐空间维度，通常 $d_z \ll d_x$（$d_x$ 是数据维度）

注意这里采用 $\log \sigma_\phi^2(x)$ 而非 $\sigma_\phi^2(x)$ 作为网络输出，原因是：
1. 保证方差为正（$\exp(\log\sigma^2) > 0$）
2. 数值更稳定（避免小方差时的数值问题）
3. 允许网络输出负值，覆盖 $\sigma^2 < 1$ 的情况

**对角协方差假设**：$q_\phi(z|x)$ 的协方差矩阵是对角的，即隐变量各分量在给定 $x$ 时条件独立。这一假设虽然简化，但在实践中效果良好，且使得KL散度可以逐维度分解计算（9.3节）。更灵活的编码器可以使用满秩协方差（9.2节讨论的Cholesky参数化），但计算代价显著增加。

**摊推断（Amortized Inference）**：传统变分推断需要对每个数据点 $x_i$ 单独优化变分参数 $\phi_i$。VAE的编码器通过共享参数 $\phi$ 实现了"摊推断"——一个网络处理所有数据点，$q_\phi(z|x_i)$ 由一次前向传播给出。这大大提高了推断效率，尤其在大规模数据集上。

## 生成模型（解码器）

解码器（也称生成模型，generative model）定义了似然分布 $p_\theta(x|z)$：

$$f_\theta(z) = \text{Decoder}_\theta(z)$$

根据数据类型选择不同的似然分布：

**连续数据**（如自然图像的像素值）：

$$p_\theta(x|z) = \mathcal{N}(x | f_\theta(z), \sigma_{\text{dec}}^2 I)$$

此时 $\log p_\theta(x|z) = -\frac{\|x - f_\theta(z)\|^2}{2\sigma_{\text{dec}}^2} + \text{const}$，重建项等价于MSE损失。

**二值数据**（如二值化的MNIST）：

$$p_\theta(x|z) = \text{Bernoulli}(x | f_\theta(z))$$

此时 $\log p_\theta(x|z) = \sum_{j=1}^{d_x} [x_j \log f_\theta(z)_j + (1-x_j)\log(1-f_\theta(z)_j)]$，重建项等价于交叉熵损失。

其中 $\sigma_{\text{dec}}^2$ 可以是超参数，也可以作为可学习参数。在实践中，通常将 $\sigma_{\text{dec}}^2$ 固定为某个合理值（如1）或令其为可训练标量。

## VAE的概率图模型

VAE的生成过程定义了一个简单的潜变量模型（Latent Variable Model）：

$z \sim p(z) = \mathcal{N}(0, I_{d_z}), \quad x \sim p_\theta(x|z)$

对应的生成图模型为 $z \to x$：先从先验采样隐变量 $z$，再由解码器 $p_\theta(x|z)$ 生成观测 $x$。这看起来非常简单，但结合推断模型后，结构更丰富。VAE的完整概率图模型包含两个方向：

- **生成方向**（实线）：$z \to x$，由先验 $p(z)$ 和似然 $p_\theta(x|z)$ 定义
- **推断方向**（虚线）：$x \to z$，由编码器 $q_\phi(z|x)$ 近似真实后验 $p(z|x)$

> **[图示位置]**：VAE的概率图模型——左侧为生成模型（实线箭头 $z \to x$，方框标注 $p(z)$ 和 $p_\theta(x|z)$），右侧为推断模型（虚线箭头 $x \to z$，方框标注 $q_\phi(z|x)$），中间用双向箭头或并列展示两个方向。外围用plate记号方框标注 $N$（数据点个数）。

这种"生成+推断"的双向结构是VAE的核心特征——**生成模型定义了数据的概率规律，推断模型高效地近似后验分布**。两者通过ELBO训练目标被绑定在一起。

先验 $p(z) = \mathcal{N}(0, I)$ 的选择看似简单，但有几个重要理由：

1. **计算便利性**：标准正态分布的KL散度有闭式解
2. **重参数化友好**：标准正态的采样 $z = \mu + \sigma \odot \epsilon$（$\epsilon \sim \mathcal{N}(0,I)$）天然支持重参数化
3. **隐空间结构**：KL正则化推动编码分布向 $\mathcal{N}(0,I)$ 靠拢，使隐空间连续、有规律，支持插值和采样生成
4. **表达能力**：虽然先验简单，但通过足够灵活的解码器 $f_\theta$，复杂的 $p_\theta(x)$ 可以由简单先验+非线性映射产生

边际分布 $p_\theta(x) = \int p_\theta(x|z) p(z) dz$ 是无穷混合高斯（当 $p_\theta(x|z)$ 为高斯时），理论上有充分的表达力——通用近似定理保证了VAE可以逼近任意连续分布（见附录9C的讨论）。

**VAE的完整数据流**：

```
输入 x
   │
   ▼
┌─────────────────┐
│  编码器 Encoder_φ │
│  输入: x          │
│  输出: μ_φ(x),    │
│        logσ²_φ(x) │
└────────┬────────┘
         │
         ▼
   采样: z = μ_φ(x) + σ_φ(x) ⊙ ε,  ε ~ N(0,I)
         │
         ▼
┌─────────────────┐
│  解码器 Decoder_θ │
│  输入: z          │
│  输出: f_θ(z)     │
└────────┬────────┘
         │
         ▼
   重建: x̂ ≈ x
```

> **[图示位置]**：VAE架构示意图——左端为输入 $x$，经编码器输出 $\mu_\phi(x)$ 和 $\sigma_\phi^2(x)$，重参数化采样 $z$，经解码器输出 $\hat{x} = f_\theta(z)$。图中应标注ELBO的两个组成部分：重建项比较 $x$ 与 $\hat{x}$，KL项比较 $q_\phi(z|x)$ 与 $p(z)$。

## 与传统自编码器的区别

传统自编码器（Autoencoder, AE）和VAE都有编码器-解码器结构，但存在本质差异：

| 特征 | 传统自编码器 (AE) | 变分自编码器 (VAE) |
|---|---|---|
| 编码器输出 | 确定性隐表示 $z = g_\phi(x)$ | 隐变量的分布参数 $\mu_\phi(x), \sigma_\phi^2(x)$ |
| 隐变量 | 确定性向量 | 随机变量 $z \sim q_\phi(z\mid x)$ |
| 解码器输出 | 确定性重建 $\hat{x} = f_\theta(z)$ | 重建分布参数 $p_\theta(x\mid z)$ |
| 训练目标 | 重建误差 $\|x - f_\theta(g_\phi(x))\|^2$ | ELBO（重建 + KL正则化） |
| 正则化 | 无（或需额外添加） | 内置KL正则化 |
| 隐空间结构 | 无保证，可能不连续 | 趋于连续、有规律 |
| 生成能力 | 无（隐空间无先验） | 有（$z \sim \mathcal{N}(0,I)$ → 解码器） |
| 概率解释 | 无 | 完整的概率生成模型 |

**关键区别的直观理解**：

传统自编码器只关心"压缩与重建"——找到一个低维表示 $z$ 使得 $x$ 可以从 $z$ 恢复。但隐空间没有任何约束，两个相似图像的编码可能相距很远，从隐空间随机采样的 $z$ 经解码器可能产生无意义的输出。

VAE通过KL正则化强制编码分布 $q_\phi(z|x)$ 接近标准正态 $\mathcal{N}(0,I)$。这意味着：
- 所有数据点的编码分布相互重叠，隐空间变得连续
- 相邻区域编码的图像平滑过渡，支持插值
- 从 $\mathcal{N}(0,I)$ 采样并通过解码器，可以生成有意义的新图像

> **[图示位置]**：对比图——左侧为传统AE的隐空间，可能呈现不规则的簇状分布，区域间有"空洞"（解码器在这些区域输出无意义图像）；右侧为VAE的隐空间，编码分布相互重叠，形成连续的、有规律的空间结构。
