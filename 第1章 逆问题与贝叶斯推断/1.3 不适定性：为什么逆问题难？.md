# 1.3 不适定性：为什么逆问题难？

## 一个让人心里发毛的实验

1.2 节我们看清了正向模型 $y = Ax$ 的各种样子。既然正向过程不过是个矩阵乘法，逆过程看起来只要"除以 $A$"——求解 $x = A^{-1}y$——不就完了？

先别急。考虑一个 CT 重建实验：对 12×12 像素的幻影图像，从 11 个角度采投影（共 231 个测量值），构建 231×144 的 Radon 矩阵 $A$。如果我们用**完全同一个** $A$ 造数据、再直接求 $x = A \backslash y$，重建几乎完美。可一旦数据里掺进一丁点噪声或建模误差，重建图像就可能变得面目全非——这就是\*\*不适定性（ill-posedness）\*\*的典型表现。

> **方法论警示：Inverse Crime**
> 上面"完美重建"还有个更隐蔽的坑：若用**完全相同的离散化网格与正向矩阵 $A$** 既造数据又做反演，问题会被人为"变良好"——因为 $A$ 与 $A^\top$（或 $A^{-1}$）完美匹配，离散化和建模误差被完全掩盖。这种"用同一模型造数据又反演"的做法称为**逆问题犯罪（inverse crime）**。严格验证必须满足：用**不同的网格$/$不同的前向实现**造测试数据，再交给反演算法——这样离散化与模型不一致才会暴露，解的稳定性才真正受检验。这也正是 Hadamard 第三条（稳定性）在离散世界的实际含义：即使无噪声，离散化/模型不一致本身就会破坏稳定性。第16章 CT 实验应刻意避免用同一 Radon 矩阵既造数据又反演。

本节要回答一个核心问题：**即使没有噪声，为什么直接求逆 $x = A^{-1}y$ 也常常不可靠？**

***

## Hadamard 适定性：三条规定

20 世纪初，法国数学家 Jacques Hadamard 提了判断一个问题是否"合理"的三条标准。你可以把它们想象成"一道数学题能不能被稳妥地解出来"的体检表。对线性方程 $Ax = y$，问题被称为**适定的（well-posed）**，当且仅当下面三个条件同时满足：

### 条件一：存在性——解存在吗？

对任意 $y \in \mathbb{R}^m$，是否存在 $x \in \mathbb{R}^n$ 使 $Ax = y$？矩阵语言里，这要求 $A$ 是**满射的（surjective）**，即值域张满整个观测空间。

**违反实例：** 超定系统（$m > n$，方程多于未知数）。比如从 50 个角度的 CT 投影重建低分辨率图，测量数远多于像素数。此时 $y$ 一般不在 $A$ 的值域内，精确解不存在——只能找"最接近"的近似（最小二乘解）。

### 条件二：唯一性——解唯一吗？

若存在解，它唯一吗？矩阵语言里，这要求 $A$ 是**单射的（injective）**，即零空间只有零向量：$\ker(A) = {0}$。

**违反实例：** 欠定系统（$m < n$，方程少于未知数）。比如从少数角度 CT 投影重建高分辨率图——下采样问题也是典型。此时 $A$ 的零空间非空，$Ax = y$ 有无穷多解：若 $x^*$ 是解，$x^* + z$（$z \in \ker(A)$）也是解。**被 $A$ "抹去"的维度上，任何解都满足方程。**

### 条件三：稳定性——解连续依赖数据吗？

这是最微妙也最致命的一条：当数据 $y$ 发生微小扰动，解 $x$ 是否也只变一点点？矩阵语言里，这要求 $A^{-1}$（或广义逆）是**有界的（bounded）**。

**违反实例：** 几乎所有实际图像逆问题都违反稳定性，而且这是后果最严重的违反——因为真实数据必然含噪。即使解存在且唯一，噪声的微小分量也可能被逆运算急剧放大，重建彻底失真。

> **Hadamard 的洞见**：违反任一条件，就叫**不适定的（ill-posed）**。其中稳定性违反最常见、也最危险。下文深入分析它的数学根源。

## 病态性：误差的放大器

即便 $A$ 可逆（存在性和唯一性都满足），问题仍可能**病态（ill-conditioned）**——$A^{-1}$ 存在但范数极大，导致微小扰动被灾难性放大。

### 条件数：误差放大的标尺

**为什么需要"条件数"这个概念？** 因为我们需要知道：数据里那一点点误差，最多会被放大成多大的灾难。对可逆方阵 $A$，条件数量化这种放大：

$$\kappa(A) = |A| \cdot |A^{-1}|$$

其中 $|\cdot|$ 通常取谱范数（最大奇异值）。它刻画了输入误差与输出误差之间的最坏放大比：

$$\frac{|x - x^\delta|}{|x|} \leq \kappa(A) \frac{|y - y^\delta|}{|y|}$$

其中 $y^\delta = y + \delta y$ 是含扰动的数据，$x^\delta$ 是对应的解。**条件数越大，逆问题越病态。**

- $\kappa(A) \approx 1$：良态，误差几乎不被放大（正交矩阵 $\kappa = 1$）
- $\kappa(A) = 10^3$：轻度病态，约丢 3 位有效数字
- $\kappa(A) = 10^{10}$：严重病态，几乎无法恢复有意义的解

> **先猜一个数（aha 预告）**：假设数据 $y$ 里只有亿分之一（$10^{-8}$）的相对误差，而条件数 $\kappa = 10^{10}$。那重建的相对误差最坏能到多大？先别算——记住这个数字，章末的可运行代码会让你亲眼看到小噪声被放大成一团乱麻。

### 一个经典例子：求导的不适定性

**因为**我们想建立直觉，所以看最简单的不适定问题——**数值微分**。

设 $g(x)$ 光滑，导数 $f(x) = g'(x)$。给 $g$ 加微小扰动：

$$g\_\delta(x) = g(x) + \delta \sin!\Big(\frac{x}{\delta}\Big)$$

扰动在函数空间里很小：$|g - g\_\delta|\_\infty = \delta \to 0$。但扰动后的导数：

$$f\_\delta(x) = g'(x) + \cos!\Big(\frac{x}{\delta}\Big)$$

导数误差 $|f - f\_\delta|\_\infty = 1$，**和 $\delta$ 无关**！不管扰动多小，导数误差都不缩小。

更极端点，取 $\delta = 1/\sqrt{n}$、扰动频率 $n$：

$$|g - g\_\delta|_\infty = \frac{1}{\sqrt{n}} \to 0, \quad |f - f_\delta|\_\infty = \sqrt{n} \to \infty$$

数据趋近完美，重建却趋于无穷——这就是**不稳定性**的精髓。

> **直觉**：求导是个"高通滤波器"——它放大高频分量。而高频噪声正是看似微小却变化剧烈的信号。求导把这些微弱剧烈变化放大成巨大误差。图像逆问题里的正向算子 $A$ 扮演类似角色：它是"低通滤波器"（平滑、压缩、积分），求逆则是"高通滤波"——把数据里被 $A$ 压住的高频噪声急剧放大。

## 实验 1.3-1：条件数与误差放大

实验`1.3-1.py`通过构造不同条件数的对角矩阵，定量演示条件数如何影响误差放大，验证不等式 $\frac{|x - x^\delta|}{|x|} \leq \kappa(A) \frac{|y - y^\delta|}{|y|}$。

### 实验场景

用一维向量 $x \in \mathbb{R}^{100}$ 作待重建信号，构造对角矩阵 $D = \text{diag}(\sigma\_1, \ldots, \sigma\_n)$ 作正向算子，奇异值按对数间隔衰减以模拟真实不适定问题。改变最小奇异值控制系统条件数 $\kappa(D) = \sigma\_{\max}/\sigma\_{\min}$，范围从 $1$ 到 $10^{12}$。观测加固定噪声（$\varepsilon = 10^{-6}$），用朴素逆重建 $x\_{\text{recon}} = D^{-1} y\_{\text{noisy}}$，观察不同条件数下重建误差。

### 实验目的

1. **验证误差放大不等式**：定量展示条件数与重建误差关系
2. **理解病态性的数量级**：建立条件数与有效数字丢失的对应（$\kappa=10^3$ 丢约3位，$\kappa=10^6$ 丢约6位）
3. **识别临界点**：找到误差开始超过信号的临界条件数 $\kappa\_{\text{critical}} = 1/\varepsilon$
4. **建立物理直觉**：通过奇异值衰减理解"小奇异值 → 大放大因子 → 噪声爆炸"

### 实验输入

| 条件数范围 | $\kappa \in {10^0, 10^1, 10^2, 10^3, 10^4, 10^6, 10^8, 10^{10}, 10^{12}}$ |
| 奇异值分布 | 对数间隔：$\sigma\_i = \text{logspace}(0, -\log\_{10}\kappa, n)$               |
| 重建方法  | 朴素逆重建：$x\_{\text{recon}} = D^{-1} y\_{\text{noisy}}$                      |

## SVD 视角：不适定性的根本原因

**既然**条件数已经告诉我们"误差会被放大"，那放大到底发生在哪个方向？\*\*奇异值分解（Singular Value Decomposition, SVD）\*\*是不适定性分析的核心工具，它把矩阵 $A$ 的作用"解耦"成一组独立标度关系，让误差放大机制一目了然。

### SVD 分解

任意矩阵 $A \in \mathbb{R}^{m \times n}$ 可分解：

$$A = U \Sigma V^\top = \sum\_{i=1}^{r} \sigma\_i , \mathbf{u}\_i \mathbf{v}\_i^\top$$

其中 $U, V$ 是正交矩阵，$\Sigma = \mathrm{diag}(\sigma\_1, \ldots, \sigma\_r)$ 含奇异值 $\sigma\_1 \geq \sigma\_2 \geq \cdots \geq \sigma\_r > 0$，$r = \mathrm{rank}(A)$。

SVD 的几何含义：$A$ 的作用分三步——在 $V$ 空间旋转（$V^\top$）、沿各主轴缩放（$\Sigma$）、在 $U$ 空间旋转（$U$）。缩放因子就是奇异值 $\sigma\_i$。

### 伪逆与误差放大

**因为**我们要搞清楚"为什么小噪声会爆炸"，所以把 $y = Ax$ 用 SVD 展开，形式上求逆得到伪逆（Moore-Penrose pseudo-inverse）解：

$$\widetilde{x} = A^\dagger y = \sum\_{i=1}^{r} \frac{\langle \mathbf{u}\_i, y\rangle}{\sigma\_i} , \mathbf{v}\_i$$

这个公式清楚暴露了不稳定性：**数据在第 $i$ 个奇异方向的分量 $\langle \mathbf{u}\_i, y\rangle$ 被除以 $\sigma\_i$**。当 $\sigma\_i$ 很小时，该方向任何噪声分量都会被 $1/\sigma\_i$ 巨大放大。

含噪声数据 $y^\delta = y + e$（$|e| \leq \delta$），重建误差：

$$|\widetilde{x} - \widetilde{x}^\delta| = \sqrt{\sum\_{i=1}^{r} \frac{|\langle \mathbf{u}\_i, e\rangle|^2}{\sigma\_i^2}}$$

关键：噪声对各方向投影 $|\langle \mathbf{u}\_i, e\rangle|$ 量级相当，但 $\sigma\_i$ 随 $i$ 衰减，所以**求和被小奇异值对应的项主导**——这是误差爆炸的根源。

### 奇异值衰减：不适定性的"指纹"

不同类型逆问题，奇异值衰减速率不同，决定不适定性严重程度：

| 衰减类型  | 渐近行为                                         | 严重程度  | 典型例子                            |
| ----- | -------------------------------------------- | ----- | ------------------------------- |
| 多项式衰减 | $\sigma\_i \sim i^{-\beta}$（$\beta > 0$）     | 轻度不适定 | 全角CT（$\sigma\_i \sim 1/i$）、积分算子 |
| 指数衰减  | $\sigma\_i \sim e^{-\alpha i}$（$\alpha > 0$） | 严重不适定 | 有限角CT、热传导逆问题                    |
| 有限衰减  | $\sigma\_i$ 在 $r$ 后为0                        | 欠定问题  | 下采样、图像修复                        |

**全角 CT vs 有限角 CT** 对比极有意义：

- **全角 CT**：角度覆盖 $\[0, \pi)$ 时，Radon 奇异值以 $\sigma\_i \sim 1/i$ 缓慢衰减，属"轻度"不适定——截断小奇异值可得尚可重建（滤波反投影本质）。
- **有限角 CT**：角度受限（如仅 $\[0, \pi/3)$）时，奇异值指数衰减，大、小奇异值跨越数十数量级，即使高信噪比，高频噪声也被灾难性放大。

### Picard 条件：噪声何时成灾难？

并非所有含噪数据都导致重建失败。关键：**数据在各奇异方向的系数是否比奇异值衰减得更快？**

设干净数据系数 $|\langle \mathbf{u}\_i, y\rangle|$，含噪数据 $|\langle \mathbf{u}\_i, y^\delta\rangle|$。若干净系数衰减足够快，使 $|\langle \mathbf{u}\_i, y\rangle|/\sigma\_i$ 也随 $i$ 衰减，伪逆解稳定。这叫 **Picard 条件**。

直觉：干净数据系数衰减，是因为真实图像通常光滑——能量集中在低频，高频系数自然小。而噪声随机，其系数 $|\langle \mathbf{u}\_i, e\rangle|$ 对所有 $i$ 都维持在噪声水平附近，不衰减。所以**含噪数据几乎总违反 Picard 条件**——某个 $i$ 之后噪声项超过信号项，$1/\sigma\_i$ 因 $\sigma\_i \to 0$ 急剧增大，伪逆解被噪声主导。

这也解释了为什么正则化（截断 SVD、Tikhonov 等）核心思想都是**抑制小奇异值方向的贡献**——在拟合与噪声放大间找平衡。

## 逆问题中的"幽灵"：几乎不可见的扰动

两个不同的图像 $x$ 和 $x'$，在测量空间表现几乎相同——$|Ax - Ax'|/|Ax| \approx 0.1%$，但图像本身差异却达 $|x - x'|/|x| \approx 134%$。也就是说：存在某些图像，观测中几乎不可区分，视觉上却截然不同。

这些"幽灵"图像之所以存在，正因它们的差异落在 $A$ 的**近似零空间**中——被正向算子"抹去"了。这深刻说明：**不适定性不是算法的缺陷，而是问题本身的内在性质**。即使零噪声，若不引入额外信息约束"幽灵"方向，逆问题也无法给出唯一稳定解。

关于"几乎幽灵"的定量演示与频域分析，见**实验 1.3-3**。

## 实验 1.3-3：逆问题中的"幽灵"——几乎不可见的扰动

实验`1.3-3.py`通过构造"幽灵图像"，展示两幅视觉截然不同的图像如何产生几乎相同的观测。

### 实验场景

用 $64 \times 64$ Shepp-Logan 幻影作基准 $x$，构造高频振荡图案作"幽灵分量" $d$。高斯模糊在傅里叶域是低通，高频分量被强烈衰减，故 $d$ 落在 $A$ 的近似零空间。叠加得"幽灵图像" $x' = x + d$，验证两图像观测几乎相同但视觉差异巨大。

### 实验目的

1. **理解"几乎幽灵"现象**：两幅视觉截然不同的图像，观测几乎相同
2. **理解近似零空间**：高频扰动落在模糊算子近似零空间，被"抹去"
3. **理解频率-衰减-放大关系**：频率越高，衰减越强，放大因子越大
4. **理解不适定性本质**：问题本身存在"幽灵"方向，非算法缺陷

### 实验输入

| 参数     | 数值                            |
| ------ | ----------------------------- |
| 图像尺寸   | $64 \times 64$，Shepp-Logan 幻影 |
| 模糊算子   | 高斯 PSF（σ=3），循环卷积边界            |
| 幽灵分量频率 | $f = 15$                      |
| 幽灵分量幅度 | $\alpha = 0.3$                |
| 扫描频率范围 | $f \in {5, 10, 15, 20, 25}$   |

### 实际效果

![实验1.3-3 几乎幽灵现象](<./第一章 配套实验/实验1.3-3/实验1_3_3_几乎幽灵.png>)

第一行：原始 $x$ 与幽灵 $x'$ 对比，相对差异约 30%，但 $x'$ 明显叠加高频振荡纹理。频率-衰减曲线显示衰减因子随频率急剧下降，频率 25 时近机器精度。

第二行：Ax 与 Ax' 几乎完全相同，肉眼难辨。观测差异归一化后原值仅为观测幅度 0.3% 左右。放大因子柱状图（对数）：频率 5 约 4 倍，频率 15 约 200 倍，频率 25 超 10000 倍。

第三行频域揭示本质：原始频谱能量集中在低频中心，幽灵分量频谱在高频形成明显峰值（频率 15）。径向平均频谱进一步量化：原始随径向频率快速衰减，幽灵分量在径向频率约 21 处成峰。

结论：高频扰动落模糊算子近似零空间，被正向算子"抹去"，导致两视觉截然不同的图像产生几乎相同观测——不适定性本质。

## Inverse Crime：一个容易被忽视的陷阱

逆问题数值实验里有个常见但危险的错误——**Inverse Crime（逆罪行）**。

### 什么是 Inverse Crime？

指**用与生成数据完全相同的离散化模型和算子来做重建**。若数据由 $y = Ax$ 生成（$A$ 是某离散 Radon 矩阵），重建也用同样 $A$ 求 $x = A^{-1}y$，结果会异常地好——好到不现实。

### 为什么危险？

因为实际中正向模型永远不可能完全精确：

- 离散化误差：真实 Radon 变换是连续积分，矩阵 $A$ 只是某种离散近似
- 模型误差：射线路径、探测器几何、散射效应可能未被完美建模
- 噪声模型误差：实际噪声分布可能与假设不符

Inverse Crime 用相同模型造数据又重建，**人为消除了建模误差**，使重建比实际好得多，给研究者虚假信心。

### 正确做法

避免 Inverse Crime 的原则：**正向模型与重建模型应使用不同的离散化**。例如 CT 重建：

1. **生成数据时**：把原图旋转一个"奇怪角度"（非 $A$ 角度网格整数倍），用 MATLAB 的 `radon()` 算正弦图，再加 Poisson 噪声
2. **重建时**：用预先构建的 Radon 矩阵 $A$ 求解

这样数据含建模误差（旋转角不完全匹配 $A$ 离散化）和噪声，重建结果更能反映真实表现。

> **经验法则**：评估任何逆问题算法时，先检查是否避免了 Inverse Crime。若重建"好得难以置信"，很可能就是 Inverse Crime 作祟。

## 实验 1.3-4：Inverse Crime 警示——建模误差对重建的影响

实验`1.3-4.py`通过对比同模型和异模型条件下的重建质量，定量展示 Inverse Crime 如何导致虚假良好性能。

### 实验场景

用 $512 \times 512$ astronaut 图像，构建两个略有差异的高斯模糊模型：重建模型 $\sigma\_A = 5.0$，数据生成模型 $\sigma\_B = 5.3$（模拟微小建模误差）。同图分别用两模型生成观测，统一用重建模型做 Tikhonov 正则化（$\lambda = 10^{-2}$），对比 PSNR。并扫描多个真实模糊宽度 $\sigma\_{\text{真实}} \in {3.0, 4.0, 4.5, 5.0, 5.3, 5.5, 6.0, 7.0, 8.0, 10.0}$，观察 PSNR 随建模偏差 $\Delta\sigma = \sigma\_{\text{真实}} - \sigma\_A$ 的变化。

> **前置提示**：本实验用 Tikhonov 正则化（$\hat{x} = \arg\min\_x |Ax - y|^2 + \lambda |x|^2$）作工具。其概率来源在第2章系统讲解（2.1 节推导）。此处仅用，核心目标是展示 Inverse Crime 影响。

### 实验输入

| 参数     | 数值                                                                       |
| ------ | ------------------------------------------------------------------------ |
| 图像     | $512 \times 512$ astronaut                                               |
| 重建模型   | 高斯模糊 $\sigma\_A = 5.0$                                                   |
| 数据生成模型 | 高斯模糊 $\sigma\_B \in {3.0, 4.0, 4.5, 5.0, 5.3, 5.5, 6.0, 7.0, 8.0, 10.0}$ |
| 噪声水平   | $\sigma\_{\text{noise}} = 0.01$                                          |
| 正则化方法  | Tikhonov，$\lambda = 10^{-2}$                                             |
| 重建方法   | 频域直接反卷积 + 模截断                                                            |

### 实际效果

![实验1.3-4 不适定性与 Inverse Crime](<./第一章 配套实验/实验1.3-4/实验1_3_4_不适定性与InverseCrime.png>)

主图 $2 \times 3$ 布局展示完整链路：第一行呈现不适定性——原始图经高斯模糊和噪声得观测 $y$（中图），直接频域反卷积（右图）高频噪声被剧烈放大，纯噪声纹理（PSNR≈-5dB）。第二行展示方案与 Inverse Crime 影响——无噪声直接反卷积（左图）因高频信息丢失产生振铃伪影（PSNR≈20dB）；Tikhonov 同模型（中图，IC）抑制振铃但损细节（PSNR≈22dB）；异模型（右图，非 IC）结果相近（PSNR≈22dB）。

有趣现象：左图 PSNR 反而低于中图，但肉眼更清晰。这揭示 **PSNR 指标的局限**——它衡量像素级均方误差，对振铃伪影敏感，却无法准确反映人眼感知质量。

![实验1.3-4 PSNR vs 建模偏差](<./第一章 配套实验/实验1.3-4/实验1_3_4_PSNR_vs_建模偏差.png>)

PSNR 随建模偏差变化曲线：

| $\sigma\_{\text{真实}}$ | 偏差 $\Delta\sigma$ | PSNR (dB) |
| --------------------- | ----------------- | --------- |
| 3.0                   | -2.0              | 20.87     |
| 4.0                   | -1.0              | 22.76     |
| 4.5                   | -0.5              | 22.81     |
| 5.0                   | 0.0               | 22.34     |
| 5.3                   | 0.3               | 21.93     |
| 5.5                   | 0.5               | 21.64     |
| 6.0                   | 1.0               | 20.93     |
| 7.0                   | 2.0               | 19.70     |
| 8.0                   | 3.0               | 18.77     |
| 10.0                  | 5.0               | 17.48     |

IC 条件（$\Delta\sigma=0$）并非 PSNR 最高——轻微负偏差（$\Delta\sigma=-0.5$）达 22.81dB。说明 Tikhonov 对小幅建模误差有一定"补偿"能力，但这是偶然的，依赖图像内容、噪声水平和 $\lambda$ 的特定组合。

**关键结论**：

1. **建模偏差越大，重建质量系统性越低**：$|\Delta\sigma| \geq 2.0$ 时 PSNR 从 22+dB 降至 20dB 以下；$|\Delta\sigma| = 5.0$ 时降至 17.48dB，降幅 4.86dB。
2. **IC 条件下性能不可靠**：虽本实验 IC 不是最高，但它代表理想化、实际无法复现场景。
3. **正则化鲁棒性有限**：Tikhonov 可容忍小幅误差（$|\Delta\sigma| < 1.0$），超"舒适区"后性能显著下降。

> **注**：结论基于 astronaut 单图与固定 $\lambda=10^{-2}$。定量数值随图像、噪声和 $\lambda$ 变化，但 PSNR 随建模偏差系统性下降的趋势具一般性。

## 不适定性：第一层困难（小结）

回顾本节核心结论：

1. **Hadamard 三条件**给出逆问题"合理"标准——存在性、唯一性、稳定性。多数图像逆问题至少违反其一，而**稳定性违反是最大威胁**。
2. **病态性**用条件数量化误差放大：$\kappa(A) = |A||A^{-1}|$。条件数越大，微小噪声被放大越严重。

> **离散不适定性 vs 连续不适定性。** 区分两种：
>
> - **连续不适定性**：无限维算子 $A$ 的逆不是有界算子——算子本身性质，与离散化无关（如积分算子的逆=微分，天生不稳定）。
> - **离散不适定性**：离散化后矩阵 $A$ 的条件数极大——通常是连续不适定性的离散表现：离散化越细，条件数越大。
>
> 实践意义：连续不适定的问题，细化离散化**不能**解决（条件数只会更大），必须引入正则化；离散不适定但连续适定的，选合适离散化可能就够了。

1. **SVD 视角**揭示不稳定性根源：奇异值 $\sigma\_i$ 衰减导致伪逆中 $1/\sigma\_i$ 爆炸增长。衰减越快（指数 vs 多项式），问题越不适定。
2. \*\*"几乎幽灵"\*\*表明不适定性是问题内在性质，非算法缺陷。
3. **Inverse Crime** 提醒：数值实验必须忠实引入建模误差，否则给虚假良好重建。

不适定性意味着：仅靠数据 $y$ 和算子 $A$，无法可靠恢复 $x$——我们需要额外信息"补全"被 $A$ 抹去的部分。
