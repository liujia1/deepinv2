# 1.5 贝叶斯框架：从似然到后验

## 两层困难，一个框架——而且它和深度学习是"一家人"

前两节揭示了逆问题的两层困难：1.3 节说，仅靠数据 $y$ 和算子 $A$ 无法可靠恢复 $x$——不适定性让直接求逆不可行；1.4 节进一步说，实际观测还被噪声污染——$y = Ax + \varepsilon$，而非干净 $y = Ax$。

这两层困难看似独立，实则同根：**信息不足**。不适定性源于 $A$ 抹去 $x$ 的部分信息，噪声进一步模糊保留下的信息。要同时应对，我们得在数据信息之外引入**额外信息**——关于 $x$ 本身的先验知识。

**而在本书更大的故事里（记得 1.0 节那张总纲图吗？），这一步正是"MLE → MAP → 贝叶斯 → 扩散"演进链的关键一跃。** Elmusrati 的综述把话说得很透：最大似然、最大后验、贝叶斯推断、乃至深度学习，本质都是"从含噪或带偏的观测中推断隐藏成因"。具体到图像重建：
- **MLE（最大似然）**只看似然 $p(y|x)$，等价于"只管数据拟合、不管 $x$ 合不合理"——正是 1.4 节实验 1.4-2 里那个会把随机噪声当成"更合理"答案的陷阱。
- **MAP（最大后验）**在似然上乘了先验 $p(x)$，等价于正则化——把"图像该长什么样"的成见加进来。
- **贝叶斯推断**更进一步，不只给一个点，而是给出 $x$ 的完整后验分布 $p(x|y)$——把"我有多确定"也告诉你。

所以贝叶斯框架不是凭空冒出来的新东西，它是 MLE 的自然升级：从"只信数据"升级到"数据 + 成见"，再升级到"把不确定性本身也建模进来"。本节我们就正式建立这个框架，并顺着它一直望到扩散模型。

## 贝叶斯定理：从"不确定"到"概率描述"

### 先猜一个数字（反直觉 aha）

在讲公式前，先玩个游戏。假设某种疾病在人群中的患病率是 **1%**（这叫**基础率 / base rate**）。现在有一种检测试剂：
- **灵敏度 95%**：真患病的人里，95% 被测出阳性（漏掉 5%）
- **特异度 90%**：没病的人里，90% 被测出阴性（也就是 10% 的没病者会被**误报**为阳性）

好，现在你拿着一份**阳性**报告，心里一沉。先别往后看——**你觉得，你真正患病的概率有多大？**

大多数人会脱口而出："95% 吧，毕竟试剂这么灵。"

真相是：**只有大约 8.76%**。

是不是有点反直觉？我们来算。假设人群 10000 人：
- 真正患病：10000 × 1% = **100 人**，其中被测阳：100 × 95% = **95 人**
- 没病：9900 人，其中被误报阳：9900 × 10% = **990 人**
- 阳性总数 = 95 + 990 = **1085 人**

所以"阳性且真患病" = 95 / 1085 ≈ **0.0876 = 8.76%**。

关键点：因为患病率太低（1%），即便试剂"看起来很准"，那 10% 的误报在庞大健康人群里累积出的假阳性（990），远远多过真阳性（95）。**先验（基础率）一句话，就把后验从 95% 拽到了 8.76%。** 这个例子是理解贝叶斯全部思想的钥匙——数据（阳性）要和数据之前的信念（患病率）一起看，才算数。

### 从条件概率到贝叶斯公式

把这个思想搬到逆问题。设 $x$ 为未知图像，$y$ 为观测。把 $x$ 和 $y$ 都当随机变量——这不是说图像本身"随机"，而是用概率语言表达我们对 $x$ 的**不确定性**。

想象看到一张模糊人脸（下图左），不知道原图 $x$ 是什么。它可能是女性面孔（中），也可能是男性面孔（右）。两张候选都与观测兼容，却无法确定哪个是"真实" $x$。

| 观测 $y$（模糊图像） | 可能的 $x_1$（女性） | 可能的 $x_2$（男性） |
|:---:|:---:|:---:|
| ![模糊原图](模糊原图.png) | ![模糊女](模糊女.png) | ![模糊男](模糊男.png) |

这个例子直观展示"不确定性"：观测 $y$ 确定，未知图像 $x$ 有多种可能解释。贝叶斯用概率分布 $p(x|y)$ 量化这种不确定——给定 $y$，各候选图像 $x$ 的"可能性"多大。根据乘法法则，联合分布两种等价分解：

$$p(x, y) = p(y|x) \, p(x) = p(x|y) \, p(y)$$

立即得**贝叶斯定理**：

$$p(x|y) = \frac{p(y|x) \, p(x)}{p(y)}$$

其中 $p(y) = \int p(y|x) \, p(x) \, \mathrm{d}x$ 是边际似然（marginal likelihood），也叫模型证据（model evidence），起归一化作用。因 $p(y)$ 与 $x$ 无关，常写比例式：

$$p(x|y) \propto p(y|x) \, p(x)$$

这句简单公式藏着深意：**后验正比于似然乘以先验。**

> **边际似然 $p(y)$ 的双重角色。** 推断 $x$ 时，$p(y)$ 只是归一化常数，不影响后验形状。但其他场景它本身就是目标：
> - **模型选择**：比较不同正向模型 $A_1, A_2$ 哪个使 $p(y|A_i)$ 更大——第3章经验贝叶斯用于自动选正则化参数
> - **变分推断**：$\log p(y) = \text{ELBO} + \text{KL}(q_\phi \| p)$，最大化 ELBO 等价最小化近似后验与真后验差距——第8章变分路径起点
>
> 暂时记住：$p(y)$ 不影响后验形状，但承载"模型整体多好"的信息。

## 三项解读：似然、先验、后验

贝叶斯定理里三项各有明确物理与认知含义，分别回答三个不同问题。

### 似然 $p(y|x)$：数据说了什么？

（白话注解：在已知候选图像 $x$ 的前提下，观测到数据 $y$ 有多合理——它只管"数据拟合"，不管 $x$ 本身像不像话。）

似然形式完全由正向模型和噪声机制决定（正是 1.4 节内容）：
- 高斯 → $p(y|x) \propto \exp\!\big(-\frac{1}{2\sigma^2}\|y - Ax\|_2^2\big)$
- Poisson → $p(y|x) \propto \prod_i (Ax)_i^{y_i} e^{-(Ax)_i}$
- Laplace → $p(y|x) \propto \exp\!\big(-\frac{1}{b}\|y - Ax\|_1\big)$

似然编码**数据中的信息**：给定候选 $x$，观测 $y$ 多"合理"。似然越大，$x$ 越符合观测。

关键洞察：**似然只关心数据拟合，不关心 $x$ 本身是否合理。** 一个与数据完美拟合的 $x$ 可能完全不像有意义的图像——这正是不适定性的后果，也是 1.4 节实验 1.4-2 把随机噪声当成"更合理"答案的根因。

### 先验 $p(x)$：我们额外知道什么？

（白话注解：在看数据之前，我们对 $x$ 本来抱什么"成见"或"偏好"——它给被 $A$ 抹掉的自由度施加约束，是回应不适定性的关键武器。）

先验编码观测数据之外对 $x$ 的知识或信念，可来自：
- **物理约束**：CT 衰减系数非负，$x \geq 0$
- **统计规律**：自然图像梯度通常稀疏——多数区域平滑，边缘稀疏
- **专家知识**：特定应用结构先验（如天文图像中恒星点状特征）

常见数学形式：

| 先验类型 | 数学形式 | 编码的知识 | 对应正则项 |
|---------|---------|-----------|------------|
| 高斯先验 | $p(x) \propto \exp(-\frac{1}{2\sigma_x^2}\|x\|_2^2)$ | 图像能量有限 | $\|x\|_2^2$（Tikhonov） |
| Laplace 先验 | $p(x) \propto \exp(-\alpha\|x\|_1)$ | 稀疏性 | $\|x\|_1$（L1 正则化） |
| 梯度高斯先验 | $p(x) \propto \exp(-\frac{1}{2}\|\nabla x\|_2^2)$ | 平滑性 | $\|\nabla x\|_2^2$（Sobolev） |
| TV 先验 | $p(x) \propto \exp(-\alpha\|\nabla x\|_1)$ | 分片光滑 | $\|\nabla x\|_1$（全变差） |
| 非负约束 | $p(x) \propto \mathbf{1}_{x \geq 0}$ | 物理非负性 | 示性函数约束 |

> **先验的本质**：先验不是对 $x$ 的"猜测"，而是对解空间的"偏好"。它不要求 $x$ 一定满足某性质，而是使满足该性质的 $x$ 在后验中概率更高。先验越强，偏好越明确，对不适定性抑制越有效——但也越可能引入偏差。先验选择是贝叶斯推断核心议题，第2章深讲。

### 后验 $p(x|y)$：融合后的完整推断

（白话注解：看完数据之后，我们对 $x$ 更新过的"最终信念"——它同时权衡"数据说什么"和"我们本来知道什么"，给出 $x$ 取各个值的完整概率。）

后验是贝叶斯推断的**最终答案**，综合数据信息（似然）和先验知识（先验），给出：观测到 $y$ 之后，$x$ 取各值的概率。

$$\boxed{p(x|y) \propto p(y|x) \cdot p(x)}$$

后验刻画对 $x$ 的完整不确定性，可提取多种信息：
- 后验**众数**（mode）→ 最可能的 $x$，即 MAP 估计
- 后验**均值**（mean）→ 最小均方误差估计（MMSE）
- 后验**方差**（variance）→ 量化估计不确定性
- 后验**形状**（多峰？偏斜？）→ 揭示问题结构

**后验分布就是逆问题的解。** 后续一切——点估计、采样、不确定性量化——都是从后验提取信息。

### 后验的几何直觉：光柱与引力场

想象后验 $p(x|y)$ 是一片地形。似然像从数据投射来的"光柱"，照亮与观测兼容的区域；先验像一片"引力场"，把概率质量拉向先验偏好的区域。后验是两者叠加后的地形——两者都强的区域形成高峰（高概率），任一弱的区域形成低谷（低概率）。

一维示意：似然给一个以 $A^{-1}y$ 为中心的峰（数据偏好），先验给一个以 0 为中心的峰（先验偏好），后验是两者乘积——峰落在两者之间某处，宽度比两者都窄（信息融合缩小不确定性）。这正是贝叶斯核心机制：**数据与先验融合，既移动了估计位置，又缩小了不确定性范围。**

推广到高维：后验"形状"反映问题结构。大奇异值方向对应后验紧致方向（确定性高），小奇异值方向对应先验主导方向（不确定性大）。SVD 视角（1.3 节）与贝叶斯视角在此汇合。

## 信念更新叙事：数据越多，先验话语权越小

贝叶斯最迷人的地方，是它把"学习"描述成一个**信念随时间被洗掉、又被数据收拢**的故事。我们再看一个比疾病检测更"连续"的例子——**世界人口估计（Poisson–Gamma 共轭）**，让你看见后验怎么随数据 0→n 移动、收拢。

> 背景：我们想估计某个"平均人口规模"参数 $\lambda$（比如一种温和场景下，某类区域的均值）。我们采用 **Gamma 先验**（白话：一种"带形状的形状参数 $\alpha$ 和速率 $\beta$"的分布，天然非负，且和 Poisson 数据配对后形式不变——这叫"共轭"）。设一个**弱信息先验**：$\alpha_0 = 2,\ \beta_0 = 1$，先验均值 = $\alpha_0/\beta_0 = 2$。也就是说，在看见任何数据前，我们的"成见"是均值约 2。

现在假设真实世界均值约 7，我们依次观测到 50 个国家的人口数据（均值约 7 的 Poisson 抽样）。贝叶斯更新规则极干净（共轭的美）：

- 看到 $n$ 个数据 $\{y_1, \dots, y_n\}$ 后，后验仍是 Gamma，参数更新为
  $$\alpha_n = \alpha_0 + \sum_{i=1}^n y_i, \qquad \beta_n = \beta_0 + n$$
- 后验均值 = $\alpha_n / \beta_n$

我们来追踪信念怎么变（数字为示意）：
- **看到 0 个数据**：后验 = 先验，均值 = **2.0**（纯成见）
- **看到 1 个数据**（比如 $y=7$）：均值 = (2+7)/(1+1) = **4.5**（被拉向数据，但先验还占一半话语权）
- **看到 10 个数据**（累计和 ≈ 70）：均值 = (2+70)/(1+10) ≈ **6.55**（成见被大幅度洗掉）
- **看到 50 个数据**（累计和 ≈ 350）：均值 = (2+350)/(1+50) ≈ **6.90**（离真值 7 很近，先验几乎被完全淹没）

看清楚这个故事了吗？**一开始，先验（均值 2）说了算；随着数据从 0 增加到 50，后验均值从 2 一路被"拽"向真实数据均值 7，最后停在 6.9——先验那微不足道的 2 被海量数据彻底洗掉。** 同时，后验分布随数据增多越来越"瘦"（方差 $\alpha_n/\beta_n^2$ 随 $n$ 增大而收缩），即不确定性被收拢。这就是贝叶斯"信念更新"的全部精髓：**数据不是简单地覆盖先验，而是按量级逐步把先验的话语权稀释掉。**

> 对比疾病检测那个 aha：那里基础率（先验）只有 1%，数据（阳性）看似很强，但因为"阳性"里混了大量健康人的误报，先验依旧把后验死死摁在 8.76%。两个例子合起来告诉你同一件事——**后验是似然和先验的妥协，谁"嗓门大"（谁的信息量多），谁就主导结局。**

## 后验 = 似然 × 先验：信息融合的数学表达

### 负对数形式：从概率到能量

直接操作概率密度乘积不方便。取负对数，乘法变加法、指数消失：

$$-\ln p(x|y) = -\ln p(y|x) - \ln p(x) + \underbrace{\ln p(y)}_{\text{与 } x \text{ 无关}}$$

忽略常数项，定义**后验能量函数（energy function）**：

$$E(x) = -\ln p(x|y) = \underbrace{-\ln p(y|x)}_{\text{数据项 } D(y, Ax)} + \underbrace{(-\ln p(x))}_{\text{正则项 } R(x)}$$

**后验能量 = 数据项 + 正则项。**

这命名有物理类比：统计物理里概率分布常写玻尔兹曼形式 $p(x) \propto \exp(-E(x))$，$E(x) = -\ln p(x)$ 叫**能量函数**——概率越大的状态能量越低。类比地，$E(x) = -\ln p(x|y)$ 叫**后验能量**：后验概率越大的 $x$，能量越低。最小化后验能量等价最大化后验概率——这就是 MAP 估计的物理图像：找后验能量的"基态"。

这公式是全书最重要公式之一，揭示贝叶斯与正则化方法的对应：

| 贝叶斯模型 | 正则化方法 | 对应关系 |
|-----------|-----------|---------|
| 噪声模型 → 似然 $p(y\|x)$ | 数据拟合项 $D(y, Ax)$ | 噪声机制决定数据项形式 |
| 先验知识 → 先验 $p(x)$ | 正则项 $R(x)$ | 先验偏好决定正则化形式 |
| 噪声参数（$\sigma^2$, $b$） | 正则化参数 $\lambda$ | $\lambda$ = 噪声水平 / 先验强度 |

### 一个完整例子：高斯噪声 + 高斯先验 = Tikhonov 正则化

最经典体现：**高斯噪声 + 高斯先验恰好等价 Tikhonov 正则化**。

设 $y = Ax + \varepsilon$，$\varepsilon \sim \mathcal{N}(0, \sigma^2 I)$，先验 $x \sim \mathcal{N}(0, \sigma_x^2 I)$：

$$p(y|x) \propto \exp\!\Big(-\frac{1}{2\sigma^2}\|y - Ax\|_2^2\Big), \quad p(x) \propto \exp\!\Big(-\frac{1}{2\sigma_x^2}\|x\|_2^2\Big)$$

后验：

$$p(x|y) \propto \exp\!\Big(-\frac{1}{2\sigma^2}\|y - Ax\|_2^2 - \frac{1}{2\sigma_x^2}\|x\|_2^2\Big)$$

取负对数：

$$E(x) = \frac{1}{2\sigma^2}\|y - Ax\|_2^2 + \frac{1}{2\sigma_x^2}\|x\|_2^2$$

等价：

$$E(x) = \|y - Ax\|_2^2 + \underbrace{\frac{\sigma^2}{\sigma_x^2}}_{\lambda}\|x\|_2^2$$

这正是 **Tikhonov 正则化**（岭回归），正则化参数 $\lambda = \sigma^2 / \sigma_x^2$——**噪声方差与先验方差之比**。

因高斯分布完全由均值方差决定，后验也是高斯，其均值（=众数=MAP）和协方差有**闭式解**：

$$\mu_{\text{post}} = \big(\sigma^{-2}A^\top A + \sigma_x^{-2} I\big)^{-1} \sigma^{-2} A^\top y$$

$$\Sigma_{\text{post}} = \big(\sigma^{-2}A^\top A + \sigma_x^{-2} I\big)^{-1}$$

注意 $\Sigma_{\text{post}}$ 正是 Tikhonov 解敏感度矩阵——后验协方差量化了估计对噪声的敏感性。

### 正则化参数的贝叶斯诠释

正则化参数 $\lambda$ 一直是难题——太大会过正则（过度平滑），太小会欠正则（噪声未抑制）。贝叶斯赋予 $\lambda$ 明确物理含义：

$$\lambda = \frac{\sigma^2}{\sigma_x^2} = \frac{\text{噪声水平}}{\text{先验强度}}$$

- **$\lambda$ 小**（噪声低 / 先验弱）：信任数据，重建更接近观测
- **$\lambda$ 大**（噪声高 / 先验强）：依赖先验，重建更平滑

这种"数据拟合 vs 先验约束"的权衡，是全书核心张力。从经典 Tikhonov 到现代扩散模型，都遵循同一逻辑：**在数据告诉我们的和我们已知的之间找最佳平衡**。

> **伏笔：显式先验的天花板**。本节列举的先验——高斯、Laplace、TV——都是"显式先验"：需人为指定分布形式。但真实图像统计远比这些复杂。"看起来像自然图像"无法用高斯或 Laplace 解析式表达——无论怎么调参，高斯抓不住稀疏性，Laplace 保不了边，TV 处理不了渐变。这不是调参问题，是模型表达力根本局限。从显式先验到学习型隐式先验的跨越（第2章 2.4 节），是全书走向扩散模型的第一步。

### 不同先验→不同正则化：贝叶斯框架的统一力量

把 1.4 节三种噪声与不同先验组合，贝叶斯自然生成各种正则化：

| 噪声模型 + 先验 | 数据项 + 正则项 | 经典方法 |
|---------------|---------------|-------------|
| 高斯 + 高斯 | $\|y-Ax\|_2^2 + \lambda\|x\|_2^2$ | Tikhonov 正则化 |
| 高斯 + Laplace | $\|y-Ax\|_2^2 + \lambda\|x\|_1$ | LASSO / 稀疏重建 |
| 高斯 + TV | $\|y-Ax\|_2^2 + \lambda\|\nabla x\|_1$ | ROF 模型 |
| Poisson + 非负 | $\sum_i\big[(Ax)_i - y_i\ln(Ax)_i\big] + \mathbf{1}_{x\geq 0}$ | Poisson 重建 |
| Laplace + Laplace | $\|y-Ax\|_1 + \lambda\|x\|_1$ | 鲁棒稀疏重建 |

这些看似不同的正则化，在贝叶斯框架下有统一起源：都是**特定噪声模型与特定先验知识的组合**。方法差异不是人为选择，而是物理场景和领域知识的自然推论。

## 实验 1.5-1：Tikhonov 正则化的贝叶斯验证

实验`1.5-1.py`完整演示**贝叶斯框架与正则化方法的等价性**：从高斯噪声和高斯先验推导 Tikhonov，验证 $\lambda = \sigma^2/\sigma_x^2$，并展示后验完整推断（均值与方差）。

### 实验场景

用 $32 \times 32$ Shepp-Logan 幻影，构造高斯模糊算子 $A$，加高斯噪声得 $y = Ax + \varepsilon$。设高斯先验 $x \sim \mathcal{N}(0, \sigma_x^2 I)$，推导后验闭式解，验证：
1. 后验均值 = Tikhonov 解
2. $\lambda = \sigma^2/\sigma_x^2$ 期望意义最优
3. 后验方差量化不确定性

### 实验输入

| 参数 | 数值 |
|------|------|
| 测试图像 | Shepp-Logan 幻影，$32 \times 32$，$[0, 1]$ |
| 模糊核 | 高斯 PSF，$\sigma = 2.0$，周期边界 |
| 噪声模型 | 加性高斯白噪声，$\sigma = 0.05$ |
| 先验模型 | 高斯，$x \sim \mathcal{N}(0, \sigma_x^2 I)$，$\sigma_x = 0.5$ |
| 正则化参数 | $\lambda = \sigma^2/\sigma_x^2 = 0.01$（贝叶斯最优） |
| 求解方法 | 闭式：$\mu_{\text{post}} = (A^\top A + \lambda I)^{-1} A^\top y$ |
| λ 扫描 | $\lambda \in [10^{-5}, 10^1]$，50 个对数点 |

### 实际效果

![实验1.5-1 Tikhonov正则化的贝叶斯验证](<./第一章 配套实验/实验1.5-1/实验1_5_1_Tikhonov贝叶斯验证.png>)

数值验证：

| 指标 | 数值 |
|------|------|
| 后验均值 PSNR | 17.71 dB |
| 贝叶斯最优 $\lambda$ | $\sigma^2/\sigma_x^2 = 0.0025/0.25 = 0.01$ |
| $\lambda$ 扫描 PSNR 峰值 | 18.08 dB |
| 峰值对应 $\lambda$ | 0.0268（期望最优 0.01） |

$\lambda^* = 0.01$ 使 PSNR 接近峰值，验证贝叶斯-正则化等价性。单次实验峰值略偏移（0.0268 vs 0.01），因 $\lambda^*$ 最小化**期望 MSE**（对所有噪声样本平均），非保证单次 PSNR 最高。

后验方差图 $\text{diag}(\Sigma_{\text{post}})$ 揭示空间不确定性：边缘区域方差大（对噪声敏感），中心区域方差小（更可靠）。这种不确定性信息是点估计无法提供的，正是贝叶斯独特优势。

$\lambda$ 扫描曲线直观展示权衡：$\lambda$ 过小欠正则（噪声伪影），过大过正则（过度平滑），$\lambda = \sigma^2/\sigma_x^2$ 取平衡。验证本节结论：**$\lambda$ 不是手动调的超参，而是有明确物理意义的量——噪声水平与先验强度之比。**

## 从"点估计"到"后验分布"的视角跃迁

### 点 vs 分布：传统 ML 给一个点，贝叶斯给一整片云

在引入贝叶斯前，先做个关键对比（这正是 Ref B 强调的）：

- **传统 / 频率派 / 最大似然（MLE）**：给你**一个孤零零的点** $\hat{x}$。它说"这就是答案"，但对你"有多确定"只字不提。比如最大似然估计就是找让似然最大的那个 $x$。
- **贝叶斯**：给你**一整个后验分布** $p(x|y)$。它不强迫你接受一个点，而是说"$x$ 在这里概率高、在那里概率低"，把不确定性也交给你。

这个对比是全书动机的核心：逆问题天然不适定、天然含噪，硬塞一个点往往既不稳也不诚实；贝叶斯把"我不确定"也建模进来，反而更靠谱。

**这里值得把 1.0 节那张"统一框架"图再展开一层。** Elmusrati 综述用三个场景说明了 MLE / MAP / 贝叶斯 / 深度学习是怎么"一家人"的：
- **Scenario 1（推断隐藏成因）**：观测 $y_t = f(\mathbf{x},t)+n_t$，反推 $\mathbf{x}$。这正是逆问题、贝叶斯推断与系统辨识（如无线信道估计）共同的设定。
- **Scenario 2（从数据学映射）**：机器学习/深度学习学的是映射 $f(\cdot)$ 本身。当 $f$ 是巨大的神经网络，它就隐含地把"什么样的 $x$ 合理"学进了权重里——这等价于一个**隐式先验**。
- **Scenario 3（大语言模型）**：LLM 本质是"给上文 $x$ 预测下一词 $y$"的自回归模型；用贝叶斯眼光看，它是在用海量语料近似 $p(y|x)$ 与 $p(x)$ 的联合结构。注意力机制（"computer" 这个词比 "this" 更关键）就是在对上下文做加权——一种可学习的"似然塑造"。

**一句话收束**：MLE 是"只信数据"，MAP 是"数据+显式先验"，深度学习是"数据+隐式（学出来的）先验"，贝叶斯是"把整个不确定性都端给你"。它们都是 $y = f(x)+n$ 这一道题的不同作答方式——**这正是本书从逆问题一直讲到扩散模型的底层逻辑**。

### 两种求解策略

有了后验 $p(x|y)$，怎么提取有用信息？经典和贝叶斯给出截然不同回答。

**经典方法：找一个最优 $\hat{x}$（点估计）**

最直接是找后验众数，即**最大后验（MAP）估计**：

$$\hat{x}_{\text{MAP}} = \arg\max_{x} p(x|y) = \arg\min_{x} E(x)$$

这等价最小化后验能量——即正则化目标函数。MAP 给确定重建，计算高效（尤其 $E(x)$ 凸时可用梯度下降、 proximal 方法），但它只用了后验一个特征（众数），**丢弃了关于不确定性的全部信息**。

**贝叶斯方法：刻画整个后验分布（采样）**

更丰富信息蕴含在后验整体。从 $p(x|y)$ **采样**，可：
- 算后验均值 $\mathbb{E}[x|y]$（MMSE 估计）
- 算后验方差 $\mathrm{Var}[x|y]$（不确定性量化）
- 构建置信区间和可信区域
- 检测多模态结构（多个局部最优）

### 不确定性量化：点估计给不了的信息

考虑去噪问题：观测 $y = x + \varepsilon$，$\varepsilon \sim \mathcal{N}(0, \sigma^2 I)$，先验 $x \sim \mathcal{N}(0, \Sigma_{\text{prior}})$。后验均值和协方差：

$$\mu_{\text{post}} = \Sigma_{\text{post}} \, \Sigma_{\text{prior}}^{-1} \, \mu_{\text{prior}} + \Sigma_{\text{post}} \, \sigma^{-2} \, y$$

$$\Sigma_{\text{post}} = \big(\Sigma_{\text{prior}}^{-1} + \sigma^{-2} I\big)^{-1}$$

后验均值给重建，而其对角元素给每个像素**方差**——该像素重建值的不确定性。方差大意味着数据与先验约束弱、可靠性低；反之则高。

实践中这至关重要：
- **医学影像**：医生需知哪些区域可信、哪些不确定——不确定高处可能需追加检查
- **科学发现**：天文重建中，不确定性量化能区分"真实信号"与"统计涨落"
- **自主决策**：机器人视觉中，不确定性信息指导系统何处谨慎

MAP 只给一幅图，无法提供任何不确定性信息——这是点估计根本局限。

### MAP 与 MMSE 的关系

后验两个最重要点估计：

$$\hat{x}_{\text{MAP}} = \arg\max_{x} p(x|y) = \arg\min_{x} E(x)$$

$$\hat{x}_{\text{MMSE}} = \mathbb{E}[x|y] = \int x \, p(x|y) \, \mathrm{d}x$$

关系值得深思：
- 后验**高斯**时，MAP = MMSE（高斯众数=均值）
- 后验**偏斜或多峰**时，MAP 可能 ≠ MMSE，且 MAP 可能不代表后验"典型"样本

计算角度：MAP 是**优化问题**，可确定性算法高效解；MMSE 需算后验均值，一般要**采样算法**（MCMC、ULA 等）。两者对应不同"损失函数"，第3章贝叶斯决策理论下统一论述。

## 全书的起点

贝叶斯框架建立完整逻辑链：**噪声机制 → 似然函数 → 后验分布 → 求解策略**。后验 $p(x|y)$ 是中心节点——后续章节都从它出发。

```
贝叶斯框架 p(x|y) ∝ p(y|x) p(x)
         │
         ├── 先验 p(x) 如何选择？ → 第2章：先验族与正则化对应
         ├── 如何从后验求点估计？ → 第3章：MAP 估计与优化算法
         ├── 如何从后验采样？ → 第4章：MCMC 与 ULA 算法
         ├── 采样的连续化？ → 第5章：Langevin 动力学与得分函数
         └── 从得分到扩散？ → 第7章：扩散模型的 SDE 视角
```

特别值得注意的是，这条链最终通向**扩散模型**：
1. **先验选择**（第2章）：从手工先验到学习型先验
2. **MAP 估计**（第3章）：点估计是后验众数——快但不完整
3. **后验采样**（第4章）：ULA 用后验梯度 $\nabla_x \ln p(x|y)$ 驱动采样
4. **得分函数**（第5章）：后验梯度核心是先验梯度 $\nabla_x \ln p(x)$——**得分函数**
5. **得分匹配**（第6章）：用去噪器估计得分，从数据学先验
6. **扩散模型**（第7章）：多步 Langevin 采样的连续化 = 扩散 SDE

从贝叶斯后验到扩散，这条"采样路径"贯穿全书核心主干。同时后验变分近似引出另一条"变分路径"：从 ELBO 到 VAE 再到扩散似然视角——两条路径第12章"殊途同归"汇合。

## 本章小结

回顾第1章完整逻辑链：

```
1.1  定义逆问题：从效果反推原因
       │
1.2  正向模型 y = Ax："观测如何生成"
       │
1.3  不适定性："直接求逆不行"——第一层困难
       │
1.4  噪声与似然："观测还不精确"——第二层困难
       │
1.5  贝叶斯框架："同时解决两个困难"——后验 = 似然 × 先验
```

本章核心可浓缩为一句话：**逆问题天然困难（不适定 + 噪声），贝叶斯框架天然应对（先验 + 似然 → 后验）。**

具体地：
1. **贝叶斯定理** $p(x|y) \propto p(y|x) \cdot p(x)$ 融合两种信息为一个对象
2. **似然** $p(y|x)$ 编码数据信息，由噪声物理机制唯一决定（1.4 节）
3. **先验** $p(x)$ 编码额外知识，回应不适定性（1.3 节）
4. **后验** $p(x|y)$ 是融合后的完整推断，同时解决噪声与不适定性两难
5. **负对数后验 = 数据项 + 正则项**，揭示贝叶斯与正则化方法的深刻统一
6. **从点估计到分布**的视角跃迁，打开不确定性量化与后验采样大门

**再退一步看全局**：MLE 只信数据、MAP 加了显式先验、贝叶斯端出整个后验、深度学习用学出来的隐式先验——它们都在回答同一个问题："从含噪观测中推断隐藏成因"。第1章埋下全书所有后续章节的种子，也锚定了整本书的总纲。下一章从先验 $p(x)$ 的选择开始——这是贝叶斯推断的灵魂。

此外，本章讨论如何*推断* $x$，但推断好坏还需定量评价。MSE、PSNR、SSIM 等图像质量度量将在后续实验反复使用，定义与选择原则见**附录1A**。

## 动手感受一下：用 numpy 亲眼看见"噪声被放大"与"似然=最小二乘"

下面这段代码完全自包含，不依赖任何图片文件。它干两件事：(1) 构造一个模糊算子 $A$（卷积），对清晰信号加噪得 $y$，用伪逆/最小二乘重建，让你看到小噪声被不适定性放大成一团乱麻；(2) 验证高斯似然的负对数就是最小二乘数据项 $\|y-Ax\|^2$。**建议你在本地跑一遍，改改 `noise_level` 感受放大效应。**

```python
import numpy as np

# ---------- 0. 造一个"清晰信号" x（一维，方便肉眼看） ----------
rng = np.random.default_rng(0)
n = 256
t = np.linspace(0, 1, n)
x_true = np.sin(2 * np.pi * 3 * t) + 0.5 * np.cos(2 * np.pi * 7 * t)

# ---------- 1. 构造模糊正向算子 A（循环卷积矩阵） ----------
# 用频域对角化：A 在 DFT 基下是对角阵，对角元 = PSF 的频谱 H
# 这里 PSF 是一个高斯低通核，sigma 越小越"糊"，高频衰减越狠
sigma_psf = 4.0          # 频域高斯核的标准差（小 => 严重低通 => 病态）
k = np.fft.fftfreq(n) * n  # 频率坐标
H = np.exp(-0.5 * (k / sigma_psf) ** 2)  # 频域传递函数，高频 -> 0

# 正向生成干净观测 y_clean = A x
X = np.fft.fft(x_true)
y_clean = np.real(np.fft.ifft(H * X))

# ---------- 2. 加噪：y = A x + 噪声（第二层困难） ----------
noise_level = 0.01       # 相对很小的噪声！先猜猜重建会被放大成什么样
noise = noise_level * rng.standard_normal(n)
y = y_clean + noise

# ---------- 3. 朴素逆（伪逆/最小二乘）重建 ----------
# 频域里伪逆就是逐元素除以 H：X_recon = Y / H
# 注意：H 在高频趋近 0，1/H 爆炸 => 噪声被剧烈放大
# 这里加一个极小量 eps 防止 H 精确为 0 时除零（真实代码里你也应这么做）
eps = 1e-3
Y = np.fft.fft(y)
X_recon = Y / (H + eps)
x_recon = np.real(np.fft.ifft(X_recon))

# ---------- 4. 量化"放大"：相对误差对比 ----------
rel_noise = np.linalg.norm(noise) / np.linalg.norm(y_clean)      # 数据里的相对噪声
rel_err  = np.linalg.norm(x_recon - x_true) / np.linalg.norm(x_true)  # 重建相对误差
print(f"数据相对噪声   : {rel_noise:.2e}")
print(f"重建相对误差   : {rel_err:.2e}")
print(f"=> 被放大了约  {rel_err / rel_noise:.1e} 倍  （这就是不适定性！）")

# ---------- 5. 验证：高斯似然的负对数 == 最小二乘 ----------
# 高斯噪声假设下  -ln p(y|x) = 0.5/s^2 * ||y - A x||^2 + const
# 直接算最小二乘目标，并和"负对数似然"对比，应该只差一个常数因子
s = 1.0
residual = y - y_clean                      # ||y - A x_true|| 理想应≈噪声
neg_log_lik = 0.5 / s**2 * np.linalg.norm(residual)**2
least_squares = np.linalg.norm(residual)**2
print(f"\n最小二乘 ||y-Ax||^2 = {least_squares:.4f}")
print(f"高斯负对数似然(不计常数) = {neg_log_lik:.4f}  = 0.5 * 最小二乘  [OK]")

# （可选）画图看放大效果
try:
    import matplotlib.pyplot as plt
    plt.figure(figsize=(10, 4))
    plt.plot(t, x_true, label="真实 x", lw=2)
    plt.plot(t, y, label="含噪观测 y=A x+噪声", alpha=0.6)
    plt.plot(t, x_recon, label="伪逆重建（噪声爆炸）", lw=1)
    plt.legend(); plt.title("不适定性：小噪声被伪逆放大"); plt.show()
except Exception:
    pass
```

跑出来你会看到：数据里只有约 $10^{-2}$ 量级的相对噪声，但重建相对误差可能被放大成几十甚至上百倍——这正是 1.3 节"条件数/伪逆放大"的迷你实证。同时，最后两行打印验证了高斯似然的负对数就是最小二乘数据项（只差 $1/(2\sigma^2)$ 的常数因子），也就是 1.4–1.5 节"后验能量 = 数据项 + 正则项"里数据项的来源。把 `noise_level` 调大、或把 `sigma_psf` 调小（更糊、更病态），放大倍数会变得更夸张。

## 收尾：为什么这件事重要

读完这一章，你手里其实已经握住了整本书的钥匙。逆问题之所以难，是因为**信息天生不足**——正向模型抹掉了一部分信息（不适定性），噪声又模糊了剩下的信息。而贝叶斯的优雅在于：它不假装这些问题不存在，而是老老实实地说——"既然数据不够，那我们就把已知的成见也端上桌，然后诚实地告诉你我对每个答案有多不确定"。

**一句话大思想**：从 MLE 到 MAP、从贝叶斯到扩散模型，全人类在"从含噪观测推断隐藏成因"这件事上，其实一直在做的是同一道题的 progressively 更聪明的版本。拥抱不确定性、把先验和似然拧成后验，是这道题最诚实、也最强大的解法。后面每一章，都是从这一个信念更新公式长出来的枝干。
