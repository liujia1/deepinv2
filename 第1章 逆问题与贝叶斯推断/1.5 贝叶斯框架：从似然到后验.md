# 1.5 贝叶斯框架：从似然到后验

## 从"两个困难"到"一个框架"

前两节揭示了逆问题的两层困难：1.3节指出，仅靠数据 $y$ 和算子 $A$ 无法可靠地恢复 $x$——不适定性使得直接求逆不可行；1.4节进一步指出，实际观测还受到噪声污染——$y = Ax + \varepsilon$，而非精确的 $y = Ax$。

这两层困难看似各自独立，实则共享一个根源：**信息不足**。不适定性源于算子 $A$ 抹去了 $x$ 的部分信息，噪声则进一步模糊了保留下来的信息。要同时应对这两个困难，我们需要在数据信息之外引入**额外信息**——关于 $x$ 本身的先验知识。

1.4节末尾指出，似然只解决噪声建模问题，还需要先验 $p(x)$ 来应对不适定性——将两者结合便得到贝叶斯框架的核心等式 $p(x|y) \propto p(y|x) \cdot p(x)$。本节将正式建立完整的贝叶斯框架：从贝叶斯定理的推导，到似然、先验、后验三项的深入解读，再到从"点估计"到"后验分布"的视角跃迁，最后展现后验分布如何成为全书后续章节的起点。

贝叶斯框架正是这样一座桥梁：它将数据信息（似然）与先验知识（先验）融合为统一的数学对象——**后验分布**，从而同时解决噪声建模和不适定性两个问题。这是全书的理论基石。

## 贝叶斯定理

### 从条件概率到贝叶斯公式

设 $x$ 为未知图像，$y$ 为观测数据。将 $x$ 和 $y$ 都视为随机变量——这并不意味着图像本身是"随机的"，而是用概率语言来表达我们对 $x$ 的**不确定性**。

考虑一个具体例子：观测到一张模糊的人物头像（下图左），我们不知道原始图像 $x$ 是什么。它可能是一张女性面孔（下图中），也可能是一张男性面孔（下图右）。两张候选图像都与观测数据兼容，但我们无法确定哪个才是"真实"的 $x$。

| 观测 $y$（模糊图像） | 可能的 $x_1$（女性） | 可能的 $x_2$（男性） |
|:---:|:---:|:---:|
| ![模糊原图](模糊原图.png) | ![模糊女](模糊女.png) | ![模糊男](模糊男.png) |

这个例子直观展示了"不确定性"的含义：观测 $y$ 是确定的，但未知图像 $x$ 存在多种可能的解释。贝叶斯框架用概率分布 $p(x|y)$ 来量化这种不确定性——它告诉我们，给定观测 $y$，各个候选图像 $x$ 的"可能性"有多大。根据概率论的乘法法则，联合分布可以分解为两种等价形式：

$$p(x, y) = p(y|x) \, p(x) = p(x|y) \, p(y)$$

由此立即得到**贝叶斯定理**：

$$p(x|y) = \frac{p(y|x) \, p(x)}{p(y)}$$

其中 $p(y) = \int p(y|x) \, p(x) \, \mathrm{d}x$ 是边际似然（marginal likelihood），也称为模型证据（model evidence），起到归一化的作用。由于 $p(y)$ 不依赖于 $x$，贝叶斯定理通常写成比例形式：

$$p(x|y) \propto p(y|x) \, p(x)$$

这个看似简单的公式，却蕴含着深刻的思想：**后验正比于似然乘以先验。**

> **边际似然 $p(y)$ 的双重角色。** 在推断 $x$ 时，$p(y)$ 只是归一化常数，不影响后验的形状。但在其他场景中，$p(y)$ 本身就是目标：
> - **模型选择**：比较不同正向模型 $A_1, A_2$ 的优劣，看哪个使 $p(y|A_i)$ 更大——这在第3章的经验贝叶斯方法中用于自动选择正则化参数
> - **变分推断**：$\log p(y) = \text{ELBO} + \text{KL}(q_\phi \| p)$，最大化 ELBO 等价于最小化近似后验与真实后验的差距——这是第8章变分路径的起点
>
> 暂时，我们只需记住：$p(y)$ 不影响后验的形状，但它承载着"模型整体有多好"的信息。

## 三项解读：似然、先验、后验

贝叶斯定理中的三项各有明确的物理与认知含义，它们分别回答了三个不同的问题。

### 似然 $p(y|x)$：数据说了什么？

似然函数刻画了在已知 $x$ 的条件下，观测到数据 $y$ 的概率。它的形式完全由正向模型和噪声机制决定——这正是1.4节的核心内容：

- 高斯噪声 → $p(y|x) \propto \exp\!\big(-\frac{1}{2\sigma^2}\|y - Ax\|_2^2\big)$
- Poisson 噪声 → $p(y|x) \propto \prod_i (Ax)_i^{y_i} e^{-(Ax)_i}$
- Laplace 噪声 → $p(y|x) \propto \exp\!\big(-\frac{1}{b}\|y - Ax\|_1\big)$

似然函数编码了**数据中的信息**：它告诉我们，给定一个候选图像 $x$，观测数据 $y$ 有多"合理"。似然越大的 $x$，越符合观测数据。

关键洞察：**似然只关心数据拟合，不关心 $x$ 本身是否合理。** 一个与数据完美拟合的 $x$ 可能完全不像一张有意义的图像——这正是不适定性的后果。似然本身无法区分这些"数据拟合好但视觉无意义"的解。

### 先验 $p(x)$：我们额外知道什么？

先验分布编码了我们在观测数据之外对 $x$ 的知识或信念。它是回应不适定性的关键武器——1.3节指出，不适定性意味着仅靠数据无法唯一确定 $x$；先验则提供了额外的约束，在 $A$ 抹去的自由度上施加偏好。

先验可以来自多种来源：

- **物理约束**：例如 CT 图像中衰减系数非负，$x \geq 0$
- **统计规律**：自然图像的梯度通常稀疏——大部分区域平滑，边缘稀疏
- **专家知识**：特定应用中的结构先验（如天文图像中恒星的点状特征）

先验的数学形式丰富多样，常见的包括：

| 先验类型 | 数学形式 | 编码的知识 | 对应的正则项 |
|---------|---------|-----------|------------|
| 高斯先验 | $p(x) \propto \exp(-\frac{1}{2\sigma_x^2}\|x\|_2^2)$ | 图像能量有限 | $\|x\|_2^2$（Tikhonov） |
| Laplace 先验 | $p(x) \propto \exp(-\alpha\|x\|_1)$ | 稀疏性 | $\|x\|_1$（L1 正则化） |
| 梯度高斯先验 | $p(x) \propto \exp(-\frac{1}{2}\|\nabla x\|_2^2)$ | 平滑性 | $\|\nabla x\|_2^2$（Sobolev） |
| TV 先验 | $p(x) \propto \exp(-\alpha\|\nabla x\|_1)$ | 分片光滑 | $\|\nabla x\|_1$（全变差） |
| 非负约束 | $p(x) \propto \mathbf{1}_{x \geq 0}$ | 物理非负性 | 示性函数约束 |

> **先验的本质**：先验不是对 $x$ 的"猜测"，而是对解空间的"偏好"。它不要求 $x$ 一定满足某种性质，而是使满足该性质的 $x$ 在后验中拥有更高的概率。先验越强，偏好越明确，对不适定性的抑制越有效——但也越可能引入偏差。先验的选择是贝叶斯推断的核心议题，第2章将深入展开。

### 后验 $p(x|y)$：融合后的完整推断

后验分布是贝叶斯推断的**最终答案**。它综合了数据信息（似然）和先验知识（先验），给出的是：在观测到 $y$ 之后，$x$ 取各个值的概率。

$$\boxed{p(x|y) \propto p(y|x) \cdot p(x)}$$

后验分布刻画了对 $x$ 的完整不确定性，从中我们可以提取多种有用的信息：

- 后验的**众数**（mode）给出最可能的 $x$，即 MAP 估计
- 后验的**均值**（mean）给出最小均方误差估计（MMSE）
- 后验的**方差**（variance）量化了估计的不确定性
- 后验的**形状**（是否多峰、是否偏斜）揭示了问题的结构

**后验分布就是逆问题的解**。后续的一切——点估计、采样、不确定性量化——都是从后验分布中提取信息的方式。

### 后验分布的几何直觉

想象后验分布 $p(x|y)$ 是一片地形。似然 $p(y|x)$ 像一道从数据投射过来的"光柱"，照亮了与观测兼容的区域；先验 $p(x)$ 像一片"引力场"，将概率质量拉向先验偏好的区域。后验就是光柱与引力场叠加后的地形——在两者都强的区域形成高峰（高概率），在任一者弱的区域形成低谷（低概率）。

在一维示意中：似然给出一个以 $A^{-1}y$ 为中心的峰（数据偏好），先验给出一个以0为中心的峰（先验偏好），后验是两者的乘积——峰位于两者之间的某处，宽度比两者都窄（信息融合使不确定性减小）。这正是贝叶斯推断的核心机制：**数据与先验的融合不仅移动了估计的位置，还缩小了不确定性的范围。**

这一直觉可以推广到高维：后验分布的"形状"——是单峰还是多峰、是各向同性还是沿某些方向拉伸——直接反映了问题的结构。例如，当 $A$ 在某些方向上信息充分时，后验沿这些方向紧致（确定性高）；在 $A$ 信息缺失的方向上，后验由先验主导（不确定性大）。SVD 视角（1.3节）与贝叶斯视角在此汇合：大奇异值方向对应后验的紧致方向，小奇异值方向对应先验主导的方向。

## 后验 = 似然 × 先验：信息融合的数学表达

### 负对数形式：从概率到能量

直接操作概率密度的乘积并不方便。取负对数后，乘法变为加法，指数消失，得到更简洁的形式：

$$-\ln p(x|y) = -\ln p(y|x) - \ln p(x) + \underbrace{\ln p(y)}_{\text{与 } x \text{ 无关}}$$

忽略常数项，定义**后验能量函数**（energy function）：

$$E(x) = -\ln p(x|y) = \underbrace{-\ln p(y|x)}_{\text{数据项 } D(y, Ax)} + \underbrace{(-\ln p(x))}_{\text{正则项 } R(x)}$$

**后验能量 = 数据项 + 正则项。**

这个命名有深刻的物理类比。在统计物理中，概率分布常写成玻尔兹曼形式 $p(x) \propto \exp(-E(x))$，其中 $E(x) = -\ln p(x)$ 称为**能量函数**——概率越大的状态能量越低，系统自然趋向低能态。类比地，$E(x) = -\ln p(x|y)$ 称为**后验能量**（posterior energy）：后验概率越大的 $x$，后验能量越低。最小化后验能量等价于最大化后验概率——这就是 MAP 估计的物理图像：寻找后验能量的"基态"。

这个等式是全书最重要的公式之一。它揭示了贝叶斯框架与正则化方法的深刻对应关系：

| 贝叶斯模型 | 正则化方法 | 对应关系 |
|-----------|-----------|---------|
| 噪声模型 → 似然函数 $p(y\|x)$ | 数据拟合项 $D(y, Ax)$ | 噪声机制决定数据项形式 |
| 先验知识 → 先验分布 $p(x)$ | 正则项 $R(x)$ | 先验偏好决定正则化形式 |
| 噪声参数（$\sigma^2$, $b$ 等） | 正则化参数 $\lambda$ | $\lambda$ = 噪声水平 / 先验强度 |

### 一个完整的例子：高斯噪声 + 高斯先验 = Tikhonov 正则化

这个对应关系最经典的体现是：**高斯噪声 + 高斯先验恰好等价于 Tikhonov 正则化**。

设观测模型 $y = Ax + \varepsilon$，$\varepsilon \sim \mathcal{N}(0, \sigma^2 I)$，先验 $x \sim \mathcal{N}(0, \sigma_x^2 I)$，则：

$$p(y|x) \propto \exp\!\Big(-\frac{1}{2\sigma^2}\|y - Ax\|_2^2\Big), \quad p(x) \propto \exp\!\Big(-\frac{1}{2\sigma_x^2}\|x\|_2^2\Big)$$

后验为：

$$p(x|y) \propto \exp\!\Big(-\frac{1}{2\sigma^2}\|y - Ax\|_2^2 - \frac{1}{2\sigma_x^2}\|x\|_2^2\Big)$$

取负对数：

$$E(x) = \frac{1}{2\sigma^2}\|y - Ax\|_2^2 + \frac{1}{2\sigma_x^2}\|x\|_2^2$$

等价于：

$$E(x) = \|y - Ax\|_2^2 + \underbrace{\frac{\sigma^2}{\sigma_x^2}}_{\lambda}\|x\|_2^2$$

这正是 **Tikhonov 正则化**（也称岭回归），正则化参数 $\lambda = \sigma^2 / \sigma_x^2$——**噪声方差与先验方差之比**。

更进一步，由于高斯分布是完全由均值和方差决定的，后验也是高斯分布，其均值（= 众数 = MAP 估计）和协方差有**闭式解**：

$$\mu_{\text{post}} = \big(\sigma^{-2}A^\top A + \sigma_x^{-2} I\big)^{-1} \sigma^{-2} A^\top y$$

$$\Sigma_{\text{post}} = \big(\sigma^{-2}A^\top A + \sigma_x^{-2} I\big)^{-1}$$

注意到 $\Sigma_{\text{post}}$ 恰好是 Tikhonov 正则化解的敏感度矩阵——后验协方差量化了估计对噪声的敏感性。

### 正则化参数的贝叶斯诠释

正则化参数 $\lambda$ 的选择一直是正则化方法中的难题——太大则过正则化（重建过度平滑），太小则欠正则化（噪声未被抑制）。贝叶斯框架赋予了 $\lambda$ 明确的物理含义：

$$\lambda = \frac{\sigma^2}{\sigma_x^2} = \frac{\text{噪声水平}}{\text{先验强度}}$$

- **$\lambda$ 小**（噪声低 / 先验弱）：信任数据，重建更接近观测
- **$\lambda$ 大**（噪声高 / 先验强）：依赖先验，重建更平滑

这种"数据拟合 vs 先验约束"的权衡，是全书的核心张力。从经典的 Tikhonov 正则化到现代的扩散模型，都遵循同一逻辑：**在数据告诉我们的和我们已知的之间寻找最佳平衡**。

> **伏笔：显式先验的天花板**。本节列举的先验——高斯、Laplace、TV——都是"显式先验"：需要人为指定分布形式。然而，真实图像的统计分布远比这些参数化分布复杂。"看起来像自然图像"这个先验无法用高斯或 Laplace 的解析式表达——无论怎么调参，高斯假设无法捕捉稀疏性，Laplace 假设无法保边，TV 假设无法处理渐变。这不是参数选择的问题，而是模型表达能力的根本局限。从显式先验到学习型隐式先验的跨越（第2章2.4节），是全书走向扩散模型的第一步。

### 不同先验→不同正则化：贝叶斯框架的统一力量

将1.4节的三种噪声模型与不同先验组合，贝叶斯框架可以自然生成各种正则化方法：

| 噪声模型 + 先验 | 数据项 + 正则项 | 经典正则化方法 |
|---------------|---------------|-------------|
| 高斯 + 高斯 | $\|y-Ax\|_2^2 + \lambda\|x\|_2^2$ | Tikhonov 正则化 |
| 高斯 + Laplace | $\|y-Ax\|_2^2 + \lambda\|x\|_1$ | LASSO / 稀疏重建 |
| 高斯 + TV | $\|y-Ax\|_2^2 + \lambda\|\nabla x\|_1$ | ROF 模型 |
| Poisson + 非负 | $\sum_i\big[(Ax)_i - y_i\ln(Ax)_i\big] + \mathbf{1}_{x\geq 0}$ | Poisson 重建 |
| Laplace + Laplace | $\|y-Ax\|_1 + \lambda\|x\|_1$ | 鲁棒稀疏重建 |

这些看似不同的正则化方法，在贝叶斯框架下有统一的起源：它们都是**特定噪声模型与特定先验知识的组合**。方法之间的差异，不是人为选择的结果，而是物理场景（噪声机制）和领域知识（先验偏好）的自然推论。

## 从"点估计"到"后验分布"的视角跃迁

### 两种求解策略

有了后验分布 $p(x|y)$，如何从中提取有用的信息？经典方法和贝叶斯方法给出了截然不同的回答。

**经典方法：找一个最优的 $\hat{x}$（点估计）**

最直接的方式是寻找后验的众数，即**最大后验概率（MAP）估计**：

$$\hat{x}_{\text{MAP}} = \arg\max_{x} p(x|y) = \arg\min_{x} E(x)$$

这等价于最小化后验能量函数——也就是正则化方法中的目标函数。MAP 估计给出一个确定的重建结果，计算效率高（尤其当 $E(x)$ 是凸函数时，可用梯度下降、近端方法等高效求解），但它只利用了后验分布的一个特征（众数），**丢弃了关于不确定性的全部信息**。

**贝叶斯方法：刻画整个后验分布（采样）**

更丰富的信息蕴含在后验分布的整体中。通过从 $p(x|y)$ 中**采样**，我们可以：

- 计算后验均值 $\mathbb{E}[x|y]$（MMSE 估计）
- 计算后验方差 $\mathrm{Var}[x|y]$（不确定性量化）
- 构建置信区间和可信区域
- 检测多模态结构（多个局部最优解）

### 不确定性量化：点估计无法提供的信息

考虑一个去噪问题：观测 $y = x + \varepsilon$，$\varepsilon \sim \mathcal{N}(0, \sigma^2 I)$，先验 $x \sim \mathcal{N}(0, \Sigma_{\text{prior}})$。后验的均值和协方差分别为：

$$\mu_{\text{post}} = \Sigma_{\text{post}} \, \Sigma_{\text{prior}}^{-1} \, \mu_{\text{prior}} + \Sigma_{\text{post}} \, \sigma^{-2} \, y$$

$$\Sigma_{\text{post}} = \big(\Sigma_{\text{prior}}^{-1} + \sigma^{-2} I\big)^{-1}$$

后验均值 $\mu_{\text{post}}$ 给出重建结果，而 $\Sigma_{\text{post}}$ 的对角元素给出每个像素的**方差**——即对该像素重建值的不确定性。方差大的区域意味着数据与先验提供的约束较弱，重建结果的可靠性较低；方差小的区域则反之。

这种不确定性信息在实践中至关重要：

- **医学影像**：医生需要知道重建结果的哪些区域是可信的，哪些区域不确定——在不确定性高的区域，可能需要追加检查
- **科学发现**：在天文图像重建中，不确定性量化可以区分"真实信号"与"统计涨落"
- **自主决策**：在机器人视觉中，不确定性信息指导系统在何处谨慎行动

MAP 估计只给出一幅重建图像，无法提供任何不确定性信息——这是点估计的根本局限。

### 从后验到点估计：MAP 与 MMSE 的关系

后验分布的两个最重要的点估计是 MAP 和 MMSE：

$$\hat{x}_{\text{MAP}} = \arg\max_{x} p(x|y) = \arg\min_{x} E(x)$$

$$\hat{x}_{\text{MMSE}} = \mathbb{E}[x|y] = \int x \, p(x|y) \, \mathrm{d}x$$

两者之间的关系值得深思：

- 当后验是**高斯分布**时，MAP = MMSE（高斯分布的众数等于均值）
- 当后验是**偏斜或多峰**分布时，MAP 可能不等于 MMSE，且 MAP 可能不代表后验的"典型"样本

从计算的角度看：
- MAP 是一个**优化问题**，可用确定性算法高效求解
- MMSE 需要计算后验均值，一般需要**采样算法**（MCMC、ULA 等）

MAP 和 MMSE 并非仅有的估计器——它们分别对应不同的"损失函数"，第3章将在贝叶斯决策理论的框架下统一论述。

## 全书的起点

贝叶斯框架建立了一个完整的逻辑链条：**噪声机制 → 似然函数 → 后验分布 → 求解策略**。后验分布 $p(x|y)$ 是这个链条的中心节点——所有后续章节都从它出发。

```
贝叶斯框架 p(x|y) ∝ p(y|x) p(x)
         │
         ├── 先验 p(x) 如何选择？ → 第2章：先验族与正则化的对应
         │
         ├── 如何从后验求点估计？ → 第3章：MAP 估计与优化算法
         │
         ├── 如何从后验采样？ → 第4章：MCMC 与 ULA 算法
         │
         ├── 采样的连续化？ → 第5章：Langevin 动力学与得分函数
         │
         └── 从得分到扩散？ → 第7章：扩散模型的 SDE 视角
```

特别值得注意的是，这个逻辑链条最终通向**扩散模型**：

1. **先验选择**（第2章）：从手工先验到学习型先验，先验质量的提升是重建质量的关键
2. **MAP 估计**（第3章）：优化视角下，点估计是后验的众数——快速但不完整
3. **后验采样**（第4章）：ULA 算法利用后验梯度 $\nabla_x \ln p(x|y)$ 驱动采样
4. **得分函数**（第5章）：后验梯度的核心是先验梯度 $\nabla_x \ln p(x)$——**得分函数**
5. **得分匹配**（第6章）：用去噪器估计得分函数，从数据中学习先验
6. **扩散模型**（第7章）：多步 Langevin 采样的连续化，就是扩散过程的 SDE

从贝叶斯后验到扩散模型，这条"采样路径"贯穿全书的核心理论主干。同时，后验分布的变分近似方法引出另一条"变分路径"：从 ELBO 到 VAE 再到扩散模型的似然视角——两条路径在第12章"殊途同归"处汇合。

## 本章小结

回顾第1章的完整逻辑链：

```
1.1  定义逆问题：从效果反推原因
       │
1.2  正向模型 y = Ax："观测如何生成"
       │
1.3  不适定性："直接求逆不行"——第一层困难
       │
1.4  噪声与似然："观测还不精确"——第二层困难
       │
1.5  贝叶斯框架："同时解决两个困难"——后验 = 似然 × 先验
```

本章的核心信息可以浓缩为一句话：**逆问题天然困难（不适定 + 噪声），贝叶斯框架天然应对（先验 + 似然 → 后验）。**

具体地：

1. **贝叶斯定理** $p(x|y) \propto p(y|x) \cdot p(x)$ 将两种信息融合为一个数学对象
2. **似然** $p(y|x)$ 编码数据信息，由噪声物理机制唯一决定（1.4节）
3. **先验** $p(x)$ 编码额外知识，回应不适定性（1.3节）
4. **后验** $p(x|y)$ 是融合后的完整推断，同时解决了噪声建模和不适定性两个困难
5. **负对数后验 = 数据项 + 正则项**，揭示了贝叶斯框架与正则化方法的深刻统一
6. **从点估计到分布**的视角跃迁，打开了不确定性量化和后验采样的大门

第1章埋下了全书所有后续章节的种子。下一章将从先验 $p(x)$ 的选择开始——这是贝叶斯推断的灵魂。

此外，本章讨论了如何*推断* $x$，但推断结果的好坏还需要定量评价。MSE、PSNR、SSIM 等图像质量度量将在后续章节的实验中反复使用，其定义与选择原则见**附录1A**。
