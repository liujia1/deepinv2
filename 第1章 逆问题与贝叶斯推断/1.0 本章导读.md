# 1.0 本章导读：逆问题的两层困难与贝叶斯的统一解法

图像逆问题无处不在：去模糊、超分辨率、CT重建、MRI成像……这些看似不同的任务，其实共享同一个数学结构——从间接的、不完整的观测 $y$ 推断未知的原图 $x$。然而，逆问题之所以被称为"逆"问题，恰恰因为从 $y$ 反推 $x$ 远非易事。

逆问题的困难来自两个层次：

**第一层困难——不适定性**。即使我们的观测完全精确，算子 $A$ 本身的性质也常常让直接求逆 $x = A^{-1}y$ 变得不可靠：解可能不存在、可能不唯一，或者对微小的扰动极度敏感。这是数学结构层面的问题，与观测质量无关。

**第二层困难——噪声**。现实中的观测永远不会完全精确，我们得到的不是 $y = Ax$，而是 $y = Ax + \text{噪声}$。噪声在不适定性的基础上雪上加霜——被 $A^{-1}$ 放大的不仅是模型误差，还有随机噪声。

面对这两层困难，贝叶斯框架提供了一个优雅的统一解法：

$$p(x|y) \propto p(y|x) \cdot p(x)$$

似然 $p(y|x)$ 刻画了"数据告诉我们什么"（应对噪声），先验 $p(x)$ 编码了"我们额外知道什么"（应对不适定性），两者相乘得到后验 $p(x|y)$——一个关于 $x$ 的完整概率描述。从此，逆问题求解不再只是"找一个数"，而是"刻画一个分布"。

本章将沿着这条逻辑链逐步展开：

1. **定义逆问题**（1.1）——从效果反推原因
2. **建立正向模型**（1.2）——构造观测生成的数学描述
3. **揭示第一层困难**（1.3）——分析不适定性，为什么直接求逆不可行
4. **揭示第二层困难**（1.4）——建模噪声与似然，观测为什么不精确
5. **贝叶斯统一收束**（1.5）——后验 = 似然 × 先验，同时应对两个困难

这一章确立的理论基石——**后验 = 似然 × 先验**——将贯穿全书。

```
定义问题(1.1) → 正向模型(1.2) → 第一层困难：不适定性(1.3) → 第二层困难：噪声(1.4) → 贝叶斯统一解法(1.5)
```
