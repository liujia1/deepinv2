# 1.0 本章导读：逆问题的两层困难，与贝叶斯的统一解法

> "我们看到的，往往是真相经过重重扭曲后留下的影子。"——这不是名人名言，而是每个做图像重建的人天天要面对的现实。

你有没有过这样的经历：拿到一张模糊的照片，想把它变清晰；或者医生拿到一组 CT 扫描数据，要从中"看出"人体内部的断层？这些任务看起来风马牛不相及，但在数学上，它们其实是**同一件事**——从间接的、不完整的观测 $y$ 出发，去推断那个我们真正想知道、却看不见的原图 $x$。

---

## 一个更大的故事：为什么"逆问题"是整本书的总纲

在动笔之前，我想先给你一个"上帝视角"，因为这个视角会贯穿全书。

你可能会想：图像去模糊、CT 重建，这些不就是图像处理的小技巧吗？和机器学习、图像生成有什么关系？答案是——**它们本质上是同一个问题的不同侧面**。实际上，从经典估计理论到现代深度学习、大模型，**最大似然（MLE）、最大后验（MAP）、贝叶斯推断、甚至注意力机制和 LLM，都是"从含噪或带偏的观测中推断隐藏成因"这一共同目标的不同表现形式**。

怎么理解这句话？看这个统一模型：

$$y_t = f(\mathbf{x}, t) + n_t$$

它说的是：我们观察到的 $y$，是由某个隐藏的成因 $\mathbf{x}$（可能是一张图、一个参数、一句话的下一词）通过某个映射 $f$ 产生的，再叠加上噪声或偏差 $n_t$。**谁在推断 $\mathbf{x}$，谁就在解逆问题**：

- **系统辨识**：给入已知的输入，测出输出，反推系统参数 $\mathbf{x}$（比如无线信道估计）。
- **图像分类**（猫 vs 狗）：给一张图 $y$，反推它属于哪个隐藏类别 $\mathbf{x}$——这正是贝叶斯分类器干的事。
- **语言生成**：给一串上文 $\mathbf{x}$，预测下一个词 $y$；反过来，整段文本也是在"从残缺上下文推断隐藏语义成因"。
- **图像重建**：给模糊/含噪观测 $y$，反推清晰原图 $\mathbf{x}$——这就是本书的主角。

**最大似然、MAP、贝叶斯分类和深度学习，都代表了一个共同目标的不同侧面：从含噪或带偏的观测中推断隐藏成因。**

> 上面这个统一模型 $y_t = f(\mathbf{x}, t) + n_t$ 是**最一般**的形式。本书**先把 $f$ 收敛到线性、无显式时间项的特例 $y = Ax+\varepsilon$**：现实里的成像系统（相机、CT、MRI）大多能很好地近似成线性，线性让我们可以用矩阵、SVD、算子理论把这些困难"摊开来看"。而通用索引$t$会在本书的下半部分讨论扩散模型生成时以过程步的形式出现。
>

所以你会发现一条清晰的演进链：
- 没有先验知识时，我们用**最大似然（MLE）**——只信数据，找最贴合观测的 $\mathbf{x}$。
- 有了额外知识（比如"衰减系数不能为负"），我们用**最大后验（MAP）**——把知识和数据拧在一起。
- 想要完整的不确定性描述，我们用**贝叶斯推断**——不只给一个点，而是给出 $\mathbf{x}$ 的完整后验分布。
- 当 $\mathbf{x}$ 是极其复杂的自然图像时，显式先验不够用了，于是有了**学习型隐式先验**，最终通向**扩散模型**。

**本书的全部故事，就是这条链的展开。** 而它的起点，正是本章要讲的两层困难和一个框架：逆问题为什么难，以及贝叶斯怎么同时化解这两难。


## 逆问题到底难在哪？两层困难

先给你吃一颗定心丸：逆问题之所以难，根源其实只有一句话——**信息不够**。但这"不够"体现在两个层次上，我们得一层一层拆开看。

**第一层困难——不适定性。** 哪怕你的观测数据 $y$ 精确到没有一丝误差，算子 $A$（它描述了"从原图到观测"这个过程）本身的数学性质，也可能让直接求逆变得不可靠：解可能压根不存在、可能存在但不唯一、或者稍微扰动一下结果就天差地别。这是数学结构层面就注定的麻烦，跟观测质量无关。

**第二层困难——噪声。** 现实里观测永远不可能精确。我们拿到的不是干净利落的 $y = Ax$，而是 $y = Ax + \text{噪声}$。噪声叠加在不适定性之上，简直是雪上加霜——被 $A^{-1}$ 放大的不只是模型误差，还有随机噪声。

**面对这两层困难，贝叶斯框架给了一记漂亮的组合拳：**

$$p(x|y) \propto p(y|x) \cdot p(x)$$

左边 $p(x|y)$ 是**后验**（白话：给定观测后，$x$ 的概率分布——这也是我们最终的答案），右边 $p(y|x)$ 是**似然**（白话：数据告诉我们什么，用来应对噪声），乘上 $p(x)$ 是**先验**（白话：我们额外知道什么，用来应对不适定性）。这三样合起来，逆问题求解就不再是"找一个孤零零的数"，而是"刻画一整个分布"。

> 这条"后验 = 似然 × 先验"的主线，正是上面那张"MLE → MAP → 贝叶斯 → 扩散"演进链的数学引擎。本书后面所有章节（先验设计、MAP 优化、MCMC 采样、得分函数、扩散模型）都是从这一个式子长出来的枝干。

## 本章路线：顺着逻辑链往下走

这一章我们就沿着上面这条逻辑链，一节一节展开，每一节都是上一节自然推出来的下一站：

- **定义逆问题（1.1）**——先从"效果反推原因"这种日常直觉说起，看清"逆"字到底难在哪
- **建立正向模型（1.2）**——既然要反推，得先懂"观测是怎么生成的"，于是把它写成数学式子 $y = Ax$
- **揭示第一层困难（1.3）**——因为正向模型会丢失信息，直接求逆就会失败，于是我们分析"不适定性"
- **揭示第二层困难（1.4）**——因为真实观测还被噪声污染，于是我们建模噪声、引出"似然函数"
- **贝叶斯统一收束（1.5）**——既然两层困难同根（信息不足），就用"后验 = 似然 × 先验"一并解决，并看清它与 MAP、扩散模型同属一家

这一章立下的理论基石——**后验 = 似然 × 先验**——后面整本书都会反复用到。记住这条主线，1.1章节中我们就从一个你每天都在做的动作开始。

```
定义问题(1.1) → 正向模型(1.2) → 第一层困难：不适定性(1.3) → 第二层困难：噪声(1.4) → 贝叶斯统一解法(1.5)
```

> **为什么这一章值得慢读**：它是全书的地基。地基没打牢，后面讲先验、讲扩散，都会变成悬空的符号游戏。所以别急着赶路——把"两层困难"和"一个框架"嚼碎，后面会轻松很多。
