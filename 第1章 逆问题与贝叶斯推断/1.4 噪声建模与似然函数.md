# 1.4 噪声建模与似然函数

## 一、从"直接求逆不行"到"观测还不精确"

1.3 节揭示了逆问题的第一层困难——不适定性：即使观测数据 $\mathbf{y}$ 精确满足 $\mathbf{y} = Ax$，直接求逆也可能不可靠。现实的情形还要更严峻。我们拿到的从来不是干净利落的 $\mathbf{y} = Ax$，而是

$$\mathbf{y} = Ax + \varepsilon$$

其中 $\varepsilon$ 是**噪声**——由探测器电子涨落、光子计数随机性、传输错误等物理过程引入的随机扰动。

**为什么这一层困难与上一层相互叠加？** 因为 1.3 节我们看到，伪逆 $A^\dagger$ 会把噪声分量 $\langle \mathbf{u}_i, \varepsilon\rangle$ 除以小奇异值 $\sigma_i$ 急剧放大；现在，噪声为这些小奇异值方向提供了真实的非零分量，放大效应从"潜在威胁"变成"必然结果"。

本节核心任务：**怎么用概率论的语言精确描述噪声？** 这会引出似然函数——连接噪声模型与数据拟合项的数学纽带，也是 1.5 节贝叶斯框架的第一根支柱。

从更深层次看，噪声建模的意义不止于"刻画误差"：它决定了重建算法应当以何种形式度量数据保真度。"物理机制决定统计模型、统计模型决定算法目标"这一因果链，是本节贯穿始终的主线。

---

## 二、统一推导框架

不同成像系统噪声机制不同，但推导似然的流程是统一的：

```
噪声物理机制 → 噪声分布 p(ε) → 似然函数 p(y|x) → 负对数似然 -ln p(y|x) → 数据项 D(y, Ax)
```

背后的逻辑是：
1. **噪声物理机制**决定 $\varepsilon$ 服从什么分布
2. 由 $\mathbf{y} = Ax + \varepsilon$，得 $\varepsilon = \mathbf{y} - Ax$ 的分布，直接给出**似然函数** $p(\mathbf{y}|\mathbf{x})$——给定 $\mathbf{x}$ 时观测到 $\mathbf{y}$ 的概率密度
3. 取负对数，乘积变求和、指数消失（指数族概率分布），得到简洁**数据项** $D(\mathbf{y}, Ax)$

需要说明的是，上述流程是按加性噪声 $\mathbf{y} = Ax + \varepsilon$ 书写的；对 Poisson 这类信号依赖噪声，噪声的统计描述直接以 $\mathbf{y}$ 关于 $\mathbf{x}$ 的条件分布给出，第 2 步相应简化，但最终归宿相同——都是似然函数。

**数据项的形式不是人为选的，而是由物理噪声机制唯一决定的。** 选 L2、L1 还是 KL 散度，不是因为哪个"更好"，而取决于噪声是高斯、Laplace（脉冲）还是 Poisson 的。

## 三、高斯噪声 → L² 数据项

### 物理来源：为什么几乎都用高斯？

这里先回答一个你可能一直想问的问题：**为什么图像处理中高斯噪声如此普遍？** 答案藏在**中心极限定理（Central Limit Theorem, CLT）** 里。

中心极限定理说：大量相互独立的随机小扰动叠加在一起，其总和的分布会趋近高斯分布——不管单个扰动原本是什么分布。探测器里的电子热噪声、散粒噪声，本质都是海量独立微观事件（电子跃迁、光子到达）的叠加。所以按 CLT，它们的总和天然接近高斯。这就是"为什么几乎都用高斯"的根本原因：**高斯不是人为设定的假设，而是大量独立小扰动叠加的数学必然。**

### 噪声模型

设 $\varepsilon \sim \mathcal{N}(0, \sigma^2 I)$，即各像素独立同分布零均值高斯噪声：

$$p(\varepsilon_i) = \frac{1}{\sqrt{2\pi}\sigma} \exp\!\Big(-\frac{\varepsilon_i^2}{2\sigma^2}\Big)$$

其中 $\sigma$ 为噪声标准差，由探测器特性与采集条件共同决定。

### 似然函数推导

**因为**我们要从噪声分布得到"已知 $\mathbf{x}$ 时看到 $\mathbf{y}$"的概率，所以由 $\mathbf{y} = Ax + \varepsilon$，给定 $\mathbf{x}$ 时 $\mathbf{y} \sim \mathcal{N}(Ax, \sigma^2 I)$，似然：

$$p(\mathbf{y}|\mathbf{x}) = \prod_{i=1}^{m} \frac{1}{\sqrt{2\pi}\sigma} \exp\!\Big(-\frac{(y_i - (Ax)_i)^2}{2\sigma^2}\Big) = \frac{1}{(2\pi\sigma^2)^{m/2}} \exp\!\Big(-\frac{\|\mathbf{y} - Ax\|_2^2}{2\sigma^2}\Big)$$

式中每个因子都有明确的现实含义：$(Ax)_i$ 是正向模型对第 $i$ 个像素的预测值，$y_i - (Ax)_i$ 是观测与预测之间的残差，$\sigma^2$ 是噪声方差。注意似然是固定观测 $\mathbf{y}$ 之后关于 $\mathbf{x}$ 的函数——它越大，说明 $\mathbf{x}$ 与观测越一致。

### 负对数似然 → 数据项

取负对数（忽略与 $\mathbf{x}$ 无关的常数）：

$$-\ln p(\mathbf{y}|\mathbf{x}) = \frac{1}{2\sigma^2} \|\mathbf{y} - Ax\|_2^2 + \text{const}$$

**高斯噪声 → L² 数据项（最小二乘）**。几何含义是最小化观测与预测间的欧氏距离。这一转变意味着，经典的最小二乘不再是一条"约定俗成的公理"，而是从高斯噪声假设出发可以严格推导出的定理。

### 特点与局限

- **优点**：数学性质好（凸、可微），有闭式解（正规方程）
- **局限**：假设各像素噪声独立且同方差。当存在离群值（outlier）时，L² 对大残差过于敏感——一个异常大偏差被平方放大，主导整个目标函数

## 四、Poisson 噪声 → KL 散度数据项

### 物理来源

Poisson 噪声源于**光子的离散性**：光子到探测器是随机计数过程，每像素记录的光子数服从 Poisson 分布。这是**信号依赖的噪声**——噪声方差等于信号均值。

典型场景：低剂量 CT（光子少，Poisson 噪声显著）、天文成像（天体光子极少）、荧光显微镜（弱荧光计数统计）。

### 噪声模型

设第 $i$ 像素真实光子数为 $(Ax)_i$，观测 $y_i$ 服从 Poisson：

$$y_i | \mathbf{x} \sim \mathrm{Poisson}\big((Ax)_i\big)$$

PMF：

$$p(y_i | (Ax)_i) = \frac{(Ax)_i^{y_i}}{y_i!} e^{-(Ax)_i}$$

关键特性：**均值 = 方差**。$(Ax)_i$ 大时信噪比 $\mathrm{SNR} = \sqrt{(Ax)_i}$ 高；$(Ax)_i$ 小时信噪比急剧下降。低剂量 CT 图像劣化，不是噪声绝对量变大了，而是信噪比恶化了。

值得强调的是，Poisson 噪声并不进入 $\mathbf{y} = Ax + \varepsilon$ 的加性框架——噪声的强度本身就依赖于 $\mathbf{x}$。因此其似然由上面的条件分布直接给出，这正是"物理机制决定统计模型"的体现。

### 似然函数推导

**因为**各像素独立，所以似然：

$$p(\mathbf{y}|\mathbf{x}) = \prod_{i=1}^{m} \frac{(Ax)_i^{y_i}}{y_i!} e^{-(Ax)_i}$$

### 负对数似然 → 数据项

取负对数：

$$-\ln p(\mathbf{y}|\mathbf{x}) = \sum_{i=1}^{m} \Big[(Ax)_i - y_i \ln(Ax)_i + \ln(y_i!)\Big]$$

忽略与 $\mathbf{x}$ 无关项，得 **KL 散度数据项**：

$$D_{\text{KL}}(\mathbf{y}, Ax) = \sum_{i=1}^{m} \Big[(Ax)_i - y_i \ln(Ax)_i\Big]$$

名称来自信息论。严格地说，两（未归一化）计数分布 $\mathbf{y}$ 与 $Ax$ 之间的 KL 散度为 $\sum_i \big[y_i \ln \tfrac{y_i}{(Ax)_i} - y_i + (Ax)_i\big]$，与上式仅相差只依赖 $\mathbf{y}$ 的项（负对数似然中的 $\ln(y_i!)$ 项经 Stirling 近似后恰对应 $y_i \ln y_i - y_i$）。因此 Poisson 的负对数似然在相差常数的意义下，正是观测与预测之间的**广义 KL 散度**——把 $\mathbf{y}$ 和 $Ax$ 视为两个未归一化分布，数据项度量的是两者的偏离程度。

### 为何不能用 L²？

能否把 Poisson 近似成高斯、直接上 L²？近似条件：当 $(Ax)_i$ 足够大，$\mathrm{Poisson}((Ax)_i) \approx \mathcal{N}((Ax)_i, (Ax)_i)$，L² 变加权最小二乘 $\sum_i (y_i - (Ax)_i)^2 / (Ax)_i$。但低计数区（$(Ax)_i$ 近零）失效：Poisson 高度偏斜不再近似高斯，且分母趋零数值不稳。因此**低剂量成像必须用 KL 散度**。

## 五、脉冲噪声 → L¹ 数据项

### 物理来源

脉冲噪声（impulse noise），也叫椒盐噪声（salt-and-pepper），源于：
- **传输错误**：个别像素被错替换为最大值（盐）或最小值（胡椒）
- **探测器故障**：个别单元失效，输出饱和或零
- **恶劣光照**：长曝光偶发强干扰

与高斯不同，脉冲噪声**只影响少数像素**，但受影响像素偏差极大。

### 噪声模型

以概率 $p$ 像素被随机替换为极值，否则不变。更一般地，用 **Laplace 分布**建模含脉冲噪声的残差：

$$\varepsilon_i \sim \mathrm{Laplace}(0, b)$$

PDF：

$$p(\varepsilon_i) = \frac{1}{2b} \exp\!\Big(-\frac{|\varepsilon_i|}{b}\Big)$$

其中尺度参数 $b$ 控制残差的典型幅度。与高斯关键区别：Laplace 尾部更"厚"——大偏差出现概率远高于高斯，正是脉冲噪声"偶尔巨大偏差"的特征。

### 似然函数推导

**因为**由 $\mathbf{y} = Ax + \varepsilon$ 且 $\varepsilon \sim \mathrm{Laplace}(0, bI)$，所以：

$$p(\mathbf{y}|\mathbf{x}) = \prod_{i=1}^{m} \frac{1}{2b} \exp\!\Big(-\frac{|y_i - (Ax)_i|}{b}\Big) = \frac{1}{(2b)^m} \exp\!\Big(-\frac{\|\mathbf{y} - Ax\|_1}{b}\Big)$$

### 负对数似然 → 数据项

$$-\ln p(\mathbf{y}|\mathbf{x}) = \frac{1}{b} \|\mathbf{y} - Ax\|_1 + \text{const}$$

**脉冲/Laplace 噪声 → L¹ 数据项**。

### L¹ vs L²：鲁棒性直觉

为何 L¹ 对离群值更鲁棒？看去噪问题（设$A = I$）：
- **L² 目标**：$\min_x \|\mathbf{y} - \mathbf{x}\|_2^2 = \sum_i (y_i - x_i)^2$。单个大残差被平方放大，迫使 $x_k$ 向 $y_k$ 靠拢——解被离群值裹挟。
- **L¹ 目标**：$\min_x \|\mathbf{y} - \mathbf{x}\|_1 = \sum_i |y_i - x_i|$。大残差只线性增长，不主导总误差——算法可"忽略"少数离群值。

所以**脉冲噪声场景必须用 L¹**：L² 会让少数被污染像素主导重建，L¹ 对它们不敏感。

## 六、三种噪声→三种数据项：统一视角

汇总三种噪声模型推导：

**1. 高斯噪声**
- 分布：$\varepsilon \sim \mathcal{N}(0, \sigma^2 I)$
- 似然：$p(\mathbf{y}|\mathbf{x}) \propto \exp\big(-\frac{\|\mathbf{y}-Ax\|_2^2}{2\sigma^2}\big)$
- 数据项：$\frac{1}{2\sigma^2}\|\mathbf{y}-Ax\|_2^2$
- 场景：电子学噪声、读出噪声

**2. Poisson 噪声**
- 分布：$y_i \sim \mathrm{Poisson}((Ax)_i)$
- 似然：$p(\mathbf{y}|\mathbf{x}) \propto \prod (Ax)_i^{y_i} e^{-(Ax)_i}$
- 数据项：$\sum\big[(Ax)_i - y_i\ln(Ax)_i\big]$（KL 散度）
- 场景：低剂量CT、天文成像

**3. 脉冲噪声**
- 分布：$\varepsilon \sim \mathrm{Laplace}(0, bI)$
- 似然：$p(\mathbf{y}|\mathbf{x}) \propto \exp\big(-\frac{\|\mathbf{y}-Ax\|_1}{b}\big)$
- 数据项：$\frac{1}{b}\|\mathbf{y}-Ax\|_1$
- 场景：传输错误、探测器故障

三种数据项来自三种物理噪声机制，流程完全统一。**数据项选择不是任意的，由成像系统物理特性决定。** 用错数据项（如 Poisson 用 L²），重建质量会显著下降——不是算法不好，是噪声模型不对。

### 深层统一：指数族视角

三种噪声模型（观测数据的概率分布）同属**指数族（exponential family）**，其负对数似然都可以统一写成"对观测与预测之偏差的凸惩罚"：

$$p(\mathbf{y}|\mathbf{x}) \propto \exp\big(-\phi(\mathbf{y}, Ax)\big)$$

$\phi$ 为某凸函数：
- 高斯：$\phi = \sum_i (y_i - (Ax)_i)^2 / (2\sigma^2)$（残差的二次惩罚）
- Laplace：$\phi = \sum_i |y_i - (Ax)_i| / b$（残差的绝对值惩罚）
- Poisson：$\phi = \sum_i \big[(Ax)_i - y_i \ln (Ax)_i\big]$（作用于预测均值的广义 KL 惩罚——注意它并非加性残差的函数，这正是信号依赖噪声的体现）

统一性意味着：无论噪声如何，负对数似然总归是某凸函数作用于"观测与预测的偏差"——**数据项本质是对偏差的某种"惩罚"，惩罚形状由噪声统计决定**。

## 七、实验 1.4-1：三种噪声模型的直观对比

实验`1.4-1.py`在同一幅 Shepp-Logan 幻影上分别加三种典型噪声（高斯、Poisson、脉冲），直观对比视觉特征、统计特性和信号依赖性。

### 实验场景

用 $256 \times 256$ Shepp-Logan 幻影，分别施加三种噪声并调参使 PSNR 量级相近（约 $20\!-\!24$ dB）：
- **高斯噪声**（$\sigma = 0.1$）：信号无关，各像素 iid
- **Poisson 噪声**（增益 $= 0.08$）：信号依赖，方差 $\propto$ 信号强度
- **脉冲噪声**（椒盐，$p = 0.01$）：仅影响极少数像素但偏差极大

对每种噪声算 PSNR 和 SSIM（均基于**未截断**的原始含噪数据，`np.clip` 只用于 `imshow` 显示），绘含噪图、残差图和直方图，并用"渐变图 + 多次噪声实现"的分桶统计验证 Poisson 信号依赖（$\sigma \propto \sqrt{\text{signal}}$）和高斯信号无关性。

> PSNR 和 SSIM 在附录 1A 详述。此处仅作工具，核心是对比三种噪声视觉与统计差异。

### 实验输入

| 参数 | 数值 |
|------|------|
| 图像 | $256 \times 256$ Shepp-Logan 幻影，归一化至 $[0, 1]$ |
| 高斯噪声 | $\sigma = 0.1$，加性白噪声 |
| Poisson 噪声 | gain = 0.08，采样后 ×gain |
| 脉冲噪声 | 椒盐，$p = 0.01$ |
| 分桶数 | 20（用 $0\to1$ 水平渐变图，20 桶全部非空、**不剔桶**；每个像素独立重复 50 次噪声实现后按桶汇总，共 $65536\times50$ 个残差样本） |

### 实际效果

![实验1.4-1 三种噪声对比](<./第一章 配套实验/实验1.4-1/实验1_4_1_噪声建模.png>)

三种噪声在 PSNR 量级相近（约 $20\!-\!24$ dB）的前提下，视觉与统计差异依然鲜明：
- **高斯**（PSNR 19.98 dB，SSIM 0.1979）：噪声均匀覆盖全图，SSIM 最低。幻影约 58% 的像素位于平坦背景，$\sigma=0.1$ 的高斯噪声在这些区域的局部方差完全由噪声贡献，实测**背景区（$x<0.01$）SSIM 均值仅 0.1204**，从而拉低全图得分——"均匀噪点破坏结构维度"在平坦图像上会被放大
- **Poisson**（PSNR 20.02 dB，SSIM 0.6567）：同等 PSNR 下它比高斯"看起来更干净"，因为其方差 $\propto$ 信号强度，在 $\mathbf{x}\approx 0$ 的暗背景处噪声几乎为零，58% 的像素基本完好（**背景区 SSIM 均值 0.9879**），而亮区噪声反而更强——这是信号依赖噪声的特征
- **脉冲**（PSNR 23.59 dB，SSIM 0.7858）：仅约 1% 像素被替换为极值（实际改变像素约 0.69%，因落在原值 0/1 上的替换不改变像素），却偏差极大；SSIM 最高，因为绝大多数像素完好、仅极少数遭破坏，整体结构保真优于前两者

> 注意：三者的 PSNR 相近但 SSIM 差异悬殊（0.20 / 0.66 / 0.79），恰恰说明 PSNR 不足以刻画噪声质量——这正是本节要传达的核心：噪声类型不同，即使"平均误差"相当，对图像的破坏方式也截然不同。
>
> 可复现性注记：高斯与 Poisson 噪声由 numpy 全局种子（seed=42）直接生成，逐位可复现；脉冲噪声经 `skimage.util.random_noise` 生成，skimage $\ge 0.20$ 起该函数不再读取全局 `np.random.seed`（默认改用操作系统熵初始化的 PCG64），代码已显式传入 `rng=42` 修复。固定种子保证同版本内逐位复现，但 s&p 的内部抽样实现随 skimage 版本而异，跨版本脉冲噪声指标可能有约 $0.5$ dB 漂移。

残差图对应三种数据项：高斯残差各处置均匀（L² 均匀惩罚）、Poisson 亮区波动更大（KL 加权惩罚）、脉冲残差稀疏位置有极大值（L¹ 稀疏大偏差容忍）。

![实验1.4-1 信号依赖性验证](<./第一章 配套实验/实验1.4-1/实验1_4_1_噪声信号依赖性.png>)

左图验证 Poisson 标准差随信号强度增大：$\sigma \propto \sqrt{x}$。在 $0\to1$ 渐变图的 20 个桶上（每像素 50 次独立实现，无截断），实测 $\sigma$ 从信号 $0.0235$ 处的 $0.0435$ 单调升到 $0.9765$ 处的 $0.2789$，与理论 $\sqrt{\text{信号}\cdot\text{gain}}=\sqrt{0.08x}$（对应 $0.0434$ 与 $0.2795$）在**全亮度范围**吻合；幻影的 6 个灰度级给出同样结果（灰度 $0.098/0.2/0.298/0.4/1.0$ 处实测 $0.089/0.1266/0.155/0.1812/0.2833$，理论 $0.0885/0.1265/0.1545/0.179/0.283$），纯黑背景（$x=0$）处 $\sigma$ 恒为 0——这正是"信号依赖、暗部无损"的定量含义。右图对比高斯：20 个桶的实测 $\sigma$ 全部落在 $0.0996\sim0.1002$ 的窄带内（幻影 6 个灰度级为 $0.1000\sim0.1009$），与理论常数 $0.1$ 一致，**不随亮度变化**——体现信号无关性。这对应本节核心结论：**噪声类型不同，统计特性截然不同，正因如此不同物理噪声对应不同数据项。**

## 八、似然的局限与先验的必要性

1.3 节结论：不适定性意味着仅靠数据 $\mathbf{y}$ 和算子 $A$ 无法可靠恢复 $\mathbf{x}$，需额外信息。1.4 节给出数据信息的精确表达——似然函数 $p(\mathbf{y}|\mathbf{x})$。

但似然只告诉我们"数据说什么"，解决不了不适定性——它无法区分那些与数据同样兼容但视觉无意义的解。我们需要另一条信息约束被 $A$ 抹去的自由度，这就是**先验** $p(\mathbf{x})$，编码对图像的先验知识（平滑性、稀疏性、非负性等）。

## 九、实验 1.4-2：似然的局限——数据拟合好 ≠ 图像有意义

实验`1.4-2.py`通过一个极端案例展示似然根本局限：**似然只衡量数据拟合程度，无法区分"有意义的图像"和"无意义的噪声"**。

### 实验场景

考虑病态模糊问题：给 $32 \times 32$ Shepp-Logan 合成幻影（缩放到 $32\times32$ 后归一化到 $[0,1]$）$x_{\text{true}}$，经病态平滑算子 $A$ 得观测 $\mathbf{y} = Ax_{\text{true}} + \varepsilon$（$\varepsilon$ 为 8-bit 量化噪声，$\|\varepsilon\|_2=0.0358$）。算子完全由程序构造（$A = U\,\mathrm{diag}(s)\,V^\top$，$U,V$ 为固定种子的随机正交阵，谱 $s$ 前 1000 个从 $1$ 衰减到 $10^{-2}$、末尾 24 个继续降到 $1/4.8\times10^4$），故实验自包含、无外部图片依赖。$\kappa(A) = 4.8 \times 10^4$ 只算**轻度病态**——1024 个奇异值中仅 24 个衰减到 $1\%\cdot\sigma_{\max}$ 以下。问：在似然意义下，哪个 $\mathbf{x}$ 最"合理"？

直觉：当然是真实图！但只要 $A$ 存在近零方向，"真值 + 近零空间扰动"这一族解就与真值在数据拟合上几乎不可分辨——似然对它们一视同仁，选不出"有意义"的那一个。

### 实验输入

| 参数 | 数值 |
|------|------|
| 图像 | $32 \times 32$ Shepp-Logan 合成幻影，归一化至 $[0, 1]$ |
| 变换矩阵 $A$ | $1024 \times 1024$，由 $A=U\,\mathrm{diag}(s)\,V^\top$ 程序构造（稠密、含负元素，非严格卷积核），$\sigma_{\max}=1$、$\sigma_{\min}=2.08\times10^{-5}$ |
| 观测 $\mathbf{y}$ | $\mathbf{y} = \mathrm{round}(Ax_{\text{true}}\cdot255)/255$，8-bit 量化，$\|\varepsilon\|_2=0.0358$ |
| 对比图像 | 对照图像 $x_{\text{random}} = x_{\text{true}} + d$：$d$ 完全落在 24 维近零空间内（像素级 RMS $=0.15$），按构造生成而非独立随机抽样 |

### 实际效果

![实验1.4-2 似然的局限](<./第一章 配套实验/实验1.4-2/实验1_4_2_似然的局限.png>)

运行结果（固定种子 seed=2024/2026，数值确定、可逐位复现）：

```
σ_max: 1.0000e+00, σ_min: 2.0833e-05, κ(A) = 4.8000e+04（轻度病态）
σ < 1%·σ_max 的方向数: 24

数据拟合误差 ||Ax - y||_2:
  真实图像 x_true:      0.0358
  对照图像 x_random:    0.0380   （与真值几乎相当）

诊断一：500 张全新 uniform[0,1] 随机噪声图（seed=2026）
  误差中位数 4.79，5–95 分位 [4.54, 5.08]
  误差小于真实图像的比例: 0.0%（0/500）

诊断二：差值 d = x_random - x_true
  ||d|| = 4.80，但 ||Ad|| = 0.0130（相差约 369 倍）
  100% 的能量集中在 σ < 1%·σ_max 的 24 个近零方向

诊断三：最小二乘解 x_ls
  ||A x_ls - y|| ≈ 6.3e-14（完美拟合），但 ||x_ls - x_true|| = 136.4
  （达 ||x_true|| = 8.65 的 1577%）
```

### 正确归因：是"构造"，不是"运气"

必须澄清一点：$x_{\text{random}}$ **不是"碰巧拟合好"的随机噪声**。实验代码内置三项诊断给出答案：

1. **全新随机噪声从不获胜**：500 张重抽的随机噪声图拟合误差中位数约 4.79，比真图的 0.0358 差约 134 倍，无一能战胜真图。因此旧版"随机噪声恰好运气好""具体数值因随机噪声而异"的说法不成立——真去重抽随机噪声，现象只会反转。
2. **对照样本是构造的**：$d = x_{\text{random}} - x_{\text{true}}$ 的能量 100% 落在 $A$ 的 24 个近零奇异方向上（$\|d\| = 4.80$ 而 $\|Ad\| = 0.0130$，相差约 369 倍）。它像素级"像噪声"，但这些成分经 $A$ 后几乎全部湮灭，故拟合误差与真值几乎相当（0.0380 vs 0.0358）。

这不但没有削弱实验结论，反而把它讲得更准：**似然局限的根源正是 $A$ 的近零空间（不适定性）**——只要这些方向存在，就存在无穷多个"像素级像噪声、数据上却与真值同样好"的解，仅靠似然永远选不出真解。能"造出"这样一个解，本身就是数据拟合不充分的证明。

更直接的证据来自诊断三：最小二乘解 $x_{\text{ls}}$ 完美拟合数据（残差 $\sim 6.3\times 10^{-14}$），却与真图相差 $\|x_{\text{ls}} - x_{\text{true}}\| = 136.4$——数据端的微小误差经 $A^{-1}$ 放大为解端的巨大偏差，这才是条件数 $\kappa(A)$ 的真正含义（对应 1.3 节"病态性导致不稳定性"）。

**解决方案：引入先验**——先验编码"什么样的图像更合理"：真实图像通常平滑、稀疏、非负；近零空间噪声违反这些性质，先验赋极低概率。

将似然与先验结合，同时考虑数据拟合和图像合理性，便得贝叶斯核心等式 $p(\mathbf{x}|\mathbf{y}) \propto p(\mathbf{y}|\mathbf{x}) \cdot p(\mathbf{x})$——下一节正式建立此框架，揭示"后验能量 = 数据项 + 正则项"，及贝叶斯如何同时应对噪声与不适定性。
