# 第1章 逆问题与贝叶斯推断 — 提纲

> **章节定位**：全书起点与问题定义章。从"什么是逆问题"出发，逐步揭示逆问题的两层困难——不适定性（算子本身的问题）与噪声（观测的不精确），最终以贝叶斯框架统一应对。本章确立全书的理论基石（后验=似然×先验），为后续先验选择（第2章）、优化求解（第3章）、后验采样（第4章）打开全部接口。

> **叙事主线**：定义逆问题(1.1) → 建立正向模型(1.2) → 第一层困难：不适定性(1.3) → 第二层困难：噪声与似然(1.4) → 贝叶斯框架统一解决(1.5)——困难逐层叠加，贝叶斯一揽子应对

## 1.1 什么是逆问题？从观察到因果的推理

**核心观点**：正向推理是从因到果（已知x，预测y），逆问题是从果到因（观测y，推断x）。图像逆问题无处不在：去模糊、超分辨、CT重建……

- 逆问题的直观引入：日常生活中的例子（影子还原物体形状、残缺拼图还原全貌）
- 形式化定义：给定y，求解x使得 y=Ax（或 y≈Ax）
- 正问题 vs 逆问题的对比表

**来源**：Pereyra L1 P1-5; Benning L1 P1-30

---

## 1.2 正向模型：线性算子 y=Ax

**核心观点**：正向模型 A 是逆问题的起点——只有理解了"观测如何生成"，才能讨论"如何反推"。

- **卷积模糊**：A = 循环卷积矩阵，模拟散焦/运动模糊
  - DFT对角化性质：卷积在频域变为逐元素乘法
- **下采样**：A = 选取子集行，模拟低分辨率成像
- **Radon变换**：A = 沿不同角度的线积分，CT成像的核心
- **Beer-Lambert定律**（CT正向模型实例）
  - X射线衰减 I = I₀ exp(-∫μ(s)ds) → 线积分模型 y = Ax
  - 从物理定律到线性算子的完整推导

**来源**：Calatroni P1-13; Siltanen D2 P28-70; MiniProject_DefiningOperator; Siltanen D2 P55-70

---

## 1.3 不适定性：为什么逆问题难？

**核心观点**：即使没有噪声，直接求逆 x=A⁻¹y 也往往不可行——这是算子A本身的性质，而非观测的缺陷。

- **Hadamard适定性三条件**：
  - 存在性：解是否存在？
  - 唯一性：解是否唯一？
  - 稳定性：解是否连续依赖于数据？
  - 三个条件各自违反的图像逆问题实例
- **病态性**：A⁻¹放大误差的直观解释
  - SVD视角：奇异值衰减 → 小奇异值对应的分量被急剧放大
  - 图示：一个小的观测扰动导致完全不同的重建结果
- **即便无噪声，求逆已不可靠**——不适定性是第一层困难
- 📌 **侧栏：Inverse Crime**
  - 定义：用与生成数据相同的离散化和算子做重建
  - 为何危险：掩盖了模型误差的影响，给出虚假的良好重建
  - 正确做法：正向模型与重建模型使用不同离散化
  - **来源**：Siltanen D2 (XR02代码) 🟡 代码有，理论解释需补充

**来源**：Benning L1 P1-30; Pereyra L1 P5

> **过渡**：不适定性意味着我们需要额外信息来"补全"被A抹去的部分。但在此之前，还有第二层困难——我们的观测y本身也不精确。

## 1.4 噪声建模与似然函数

**核心观点**：实际观测不是y=Ax，而是y=Ax+噪声（或更一般的随机扰动）。噪声模型决定了似然函数，似然函数决定了数据拟合项的形式——三者一脉相承。

- **观测模型**：y = Ax + 噪声（在不适定性之上雪上加霜）

- **统一推导框架**（每种噪声模型走同一套流程）：
  ```
  噪声分布 p(噪声) → 似然函数 p(y|x) → 负对数似然 -ln p(y|x) → 数据项
  ```

- **高斯噪声 → L²数据项**
  - p(y|Ax) = N(Ax, σ²I)
  - -ln p(y|x) ∝ ‖Ax - y‖² （L²数据项/最小二乘）
  - 几何含义：最小化观测与预测的欧氏距离
  - **来源**：Calatroni P14-17; Pereyra L1 P8

- **Poisson噪声 → KL散度数据项**
  - 光子计数场景（CT、天文成像）
  - p(y|Ax) = Poisson(Ax)
  - -ln p(y|x) → KL散度数据项 ∑(Ax)ᵢ - yᵢ ln(Ax)ᵢ
  - 为何不能用L²：Poisson噪声方差=均值，信噪比随亮度变化
  - **来源**：Calatroni P36-37

- **脉冲/Laplace噪声 → L¹数据项**
  - 椒盐噪声、重尾分布场景
  - p(y|Ax) = Laplace(Ax, bI)
  - -ln p(y|x) ∝ ‖Ax - y‖₁ （L¹数据项）
  - L¹ vs L²：L¹对离群值鲁棒的直观解释
  - **来源**：Calatroni P37-38

- **似然函数的统一视角**：
  - 三种噪声→三种数据项，背后是同一个推导逻辑
  - 数据项选择不是任意的，而是由物理噪声机制决定的
  - **来源**：Pereyra L1 P8; Calatroni P26-28

> **过渡**：似然函数告诉我们"数据说什么"，但不能解决不适定性。我们需要另一条信息——先验。

## 1.5 贝叶斯框架：从似然到后验

**核心观点**：贝叶斯定理将数据信息（似然）和先验知识（先验）融合为后验分布，同时解决了噪声建模和不适定性两个困难——这是全书的理论基石。

- **贝叶斯定理**：
  $$p(x|y) = \frac{p(y|x) \, p(x)}{p(y)} \propto p(y|x) \, p(x)$$

- **三项解读**：
  - 似然 p(y|x)：数据说什么（来自1.4节，已知噪声模型）
  - 先验 p(x)：我们额外知道什么（回应1.3节的不适定性——需要额外信息）
  - 后验 p(x|y)：融合后的完整推断

- **后验 = 似然 × 先验：信息融合的数学表达**
  - 负对数形式：-ln p(x|y) = -ln p(y|x) - ln p(x) + const
  - 即：**后验能量 = 数据项 + 正则项**（预告第2章先验→正则项的对应）
  - 贝叶斯框架天然解释了为什么正则化能解决不适定性

- **从"点估计"到"后验分布"的视角跃迁**：
  - 经典方法：找一个x̂（MAP，第3章展开）
  - 贝叶斯方法：刻画整个后验分布（采样，第4章展开）
  - 不确定性量化：后验的方差/置信区间比单点估计更有信息量

- **全书的起点**：
  - 先验 p(x) 的选择 → 第2章
  - 从后验求点估计 → 第3章（MAP/优化）
  - 从后验求分布 → 第4章（MCMC/ULA采样）
  - 从采样到得分函数 → 第5章
  - 从得分到扩散 → 第7章

**来源**：Pereyra L1 P7-10; Calatroni P26-28
