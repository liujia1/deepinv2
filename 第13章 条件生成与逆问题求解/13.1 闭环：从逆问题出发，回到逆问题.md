# 13.1 闭环：从逆问题出发，回到逆问题

> 想象你是个画家，被人蒙上眼睛，只递给你一张从钥匙孔里瞄到的、模模糊糊还带噪点的画。你没法凭空照着"想象中好看的画"去画——你得被那张残破的观测 `y` 拽着走，画出"既好看、又和钥匙孔里看到的对得上"的画。这就是本章要做的事：**我们不是凭空画图，而是被观测数据"拽"着走。** 第1章我们写下 `y = Ax + ε`，说"逆问题 = 求后验"。第3章我们补刀：只求 MAP 点不够，得采样。可那时我们既没好先验、也不会采样。现在，十二章之后，预训练扩散模型就摆在手边当先验。剩下的唯一问题就是：怎么把这个先验和观测 `y` 捏到一起，真正去采后验？本章立起那个核心等式——**条件扩散采样 = 逆问题求解**，并让整本书的故事在这里划上一个圆。

---

## 本章 roadmap

读完这一节，你应该能讲清楚四件事：

- 逆问题的贝叶斯解 `p(x|y)` 怎么从"一个点"变成"一片分布"；
- 为什么 MAP 点估计把不确定性丢了，从而逼出"后验采样"；
- 预训练扩散模型凭什么能当"现成先验"，但还差临门一脚（它只会采无条件 `p(x)`）；
- **后验得分分解**如何把"无条件扩散"变成"条件扩散"，并用一个等式收口全书。

---

## 回顾全书推理链

### 起点：逆问题与贝叶斯解

第1章给图像逆问题写下的数学样子，你一定还记得：

$$y = Ax + \epsilon$$

白话翻译一下：`x` 是你想找回的干净原图（一个长长的向量），`A` 是**正向算子**（forward operator，把原图变成观测的那套操作——模糊、下采样、CT的Radon变换都算），`ε` 是观测噪声，`y` 是到手的、被搞脏搞糊的观测。逆问题的目标就是从 `y` 反推 `x`。

第1章第5节给了贝叶斯框架的统一解法：

$$p(x|y) \propto p(y|x) \cdot p(x)$$

这里两个角色你一定要认识（先给白话注解）：

- **似然 `p(y|x)`**（likelihood，一句话："如果真是 `x`，会观测到 `y` 的概率"）——它说"数据告诉我什么"；
- **先验 `p(x)`**（prior，一句话："抛开数据，我本来就认为 `x` 大概长啥样"）——它说"我额外知道什么"；
- 两者相乘得到**后验 `p(x|y)`**（posterior，一句话："看完数据后，我对 `x` 的新信念"）——这是关于 `x` 的**完整概率描述**。

从这一刻起，逆问题求解就不再是"找一个数"，而是"刻画一个分布"。从更深的层次看，这个贝叶斯公式本身就是本章全部工作的种子：**"先验 + 似然 = 后验"是逆问题最凝练的表述，而本节的整个推理链，最终都是为了把这句话兑现成可运行的采样过程。**

> **类比**：先验像你买彩票前对"今天会不会中奖"的直觉（比如"中不中全凭运气"），似然像开奖后你手里的那张票，后验则是你核对完票之后更新出的信念。**逆问题要的不是"你猜的中奖号码"，而是"所有可能号码各自还合不合理的完整账本"。**

### 分叉：MAP 把不确定性丢了

第3章第7节戳破了 MAP（最大后验）估计的根本局限。MAP 给你后验众数：

$$\hat{x}_\text{MAP} = \arg\max_x p(x|y) = \arg\min_x \left[-\log p(y|x) - \log p(x)\right]$$

但**众数不等于典型样本**。在高维空间里，概率密度最高的那一点几乎不可能被采样到；如果后验是多峰的（逆问题常有多个解），众数只代表其中一个峰。更要命的是：**点估计把后验分布的全部"形状"信息都扔了**——不确定性（方差多大）、多峰性（有几种可能）、相关结构。优化过程把它们全丢了。

所以第3章成了全书的分叉点：要处理复杂的逆问题，得从"求点"跃迁到"求分布"——也就是**后验采样**。两条路径从不同方向逼近这个目标。

### 采样路径：从 ULA 到扩散 SDE

采样路径（第4到7章）从"逆问题要采后验"这个需求出发，逐步搭起高效的采样工具：

- **第4章**：MCMC 能从后验里采样，但传统 Metropolis-Hastings 在高维慢得离谱。ULA（Unadjusted Langevin Algorithm）用得分函数 `∇log p(x)` 加速，但要求得分函数已知。
- **第5章**：得分函数 `∇log p(x)` 本身算不出（归一化常数 `Z` 算不出），但 **Tweedie 等式**搭了桥——一个最优去噪器 `D_σ^*(x)` 能直接给出得分的闭式估计。
- **第6章**：得分匹配（DSM）能从数据里学得分——训练去噪器等价于学得分，不用知道 `Z`。
- **第7章**：多尺度得分匹配走向扩散 SDE——连续时间的加噪过程和去噪过程，得分函数 `∇log p_t(x_t)` 驱动逆向 SDE 完成采样。

这条路径的终点是关键能力：**从噪声出发，靠得分函数驱动的随机微分方程，采出高质量的图像样本**。

### 变分路径：从 ELBO 到 VLB

变分路径（第8到11章）从生成建模的"最大似然"需求出发，也走到了扩散模型：

- **第8章**：生成模型要最大化似然 `log p(x)`，但似然算不出→ELBO（证据下界）给了一个可优化的下界；
- **第9章**：VAE 用编码器-解码器实现 ELBO 最大化，重参数化技巧让梯度能回传；
- **第10章**：层级 VAE 加层次，无限层极限指向扩散；
- **第11章**：VLB 分解→均值匹配→ε预测参数化→简化目标 `L_simple`，得到 DDPM 训练算法。

### 统一：DSM ≡ VLB

第12章证明了两条路径的训练目标在数学上等价：

$$\text{DSM损失} \equiv \text{变分下界（VLB）}$$

两条路从不同的出发点（后验采样需求 vs. 最大似然需求），训出了**完全相同的模型**——同一个去噪网络 `ε_θ(x_t, t)`、同一套加噪过程、同一套采样过程。等价性告诉我们：学好得分函数（梯度信息）等价于学好对数似然（标量信息），因为 `∇log p(x)` 与 `log p(x)` 是同一个分布的不同数学表示。

### 此刻：用扩散模型当先验，解决逆问题

12章给我们一件利器——预训练扩散模型。它的核心能力是：

1. **提供先验得分**：去噪网络 `ε_θ(x_t, t)` 通过 Tweedie 等式给出 `∇log p_t(x_t)`；
2. **高效采样**：逆向 SDE / 概率流 ODE 能从噪声生成符合先验 `p(x)` 的样本；
3. **隐式编码先验**：训练时从海量数据里隐式学了图像的统计规律——比任何手工先验（TV、小波稀疏）都强。

但到目前为止，它采样的是**无条件分布** `p(x)`——能画出"像真图"的样本，却保证不了样本和观测 `y` 一致。逆问题的核心需求始终是**条件分布** `p(x|y)`——给定 `y`，采样与之兼容的 `x`。

于是问题变成：**怎么把预训练扩散模型从无条件采样 `p(x)` 扩到条件采样 `p(x|y)`？** 这一步，就是本章要解决的全部。

## 关键等式：条件扩散采样 = 逆问题求解

### 贝叶斯定理在得分函数层面的表达

后验得分分解是本章的数学发动机。推导短得惊人：由贝叶斯定理 `p(x|y) = p(y|x)p(x)/p(y)`，两边取对数再对 `x` 求梯度（`p(y)` 与 `x` 无关，梯度为零），立刻得到：

$$\boxed{\nabla_x \log p(x|y) = \nabla_x \log p(y|x) + \nabla_x \log p(x)}$$

这就是**后验得分分解**：后验得分 = 似然得分 + 先验得分。注意顺序已经预设了本章的叙事：右边第一项是本章要花大半篇幅攻坚的对象（似然得分），第二项是我们早已拥有的资产（先验得分）。

> **一个温暖的呼应**：这个等式在第5章 5.5 节 PnP-ULA 里其实已经出现过——`s(x|y) = ∇log p(y|x) + ∇log p(x)`，跟这里一字不差。区别在于：PnP-ULA 用**单一噪声水平**的去噪器给先验得分，是条件采样的"单步版"；而条件扩散用**多尺度**得分 `∇log p_t(x_t)` 驱动逆向 SDE，是 PnP-ULA 的"多步升级版"。**PnP-ULA 是条件扩散的单噪声尺度特例。** 这一认识把第5章到第13章的线连上了——第5章埋下的种子，正是本章收获的果实的雏形。

把这个分解代回第7章的逆向 SDE：

$$dx = \left[f(x,t) - g^2(t)\nabla_x\log p_t(x)\right]dt + g(t)d\bar{w}$$

把无条件得分换成条件得分：

$$dx = \left[f(x,t) - g^2(t)\left(\nabla_x\log p_t(x_t) + \nabla_x\log p(y|x_t)\right)\right]dt + g(t)d\bar{w}$$

**条件逆向 SDE 只比无条件的多了一项**——似然得分 `∇log p(y|x_t)`。这一项把观测 `y` 的约束融进采样，让轨迹从"画任意图"变成"画与 `y` 一致的图"。

### 两种视角的对照

后验得分分解把"逆问题求解"和"条件扩散采样"统一成同一个数学对象 `p(x|y)`。但从不同角度看，意味完全不同：

| 维度 | 逆问题视角 | 条件扩散视角 |
|---|---|---|
| 核心问题 | 已知 `y = Ax + ε`，求 `x` | 已知观测 `y`，从 `p(x\|y)` 采样 |
| 数学框架 | 贝叶斯推断：`p(x\|y) ∝ p(y\|x)p(x)` | 条件生成：`p(x\|y) = p(y\|x)p(x)/p(y)` |
| 先验来源 | 手工设计（TV、小波）或学习 | 预训练扩散模型给 `∇log p(x_t)` |
| 似然来源 | 正向模型 `A` + 噪声 `ε` | 同左——`∇log p(y\|x_t)` |
| 求解方式 | 优化（MAP）或采样（MCMC） | 条件逆向 SDE 采样 |
| 输出 | 单点（MAP）或样本集（MCMC） | 后验样本集 |
| 不确定性 | 优化给不了；MCMC 能给但慢 | 天然给——每个样本都是后验一次实现 |

两种视角的等价是深刻的：逆问题的贝叶斯框架要求从 `p(x|y)` 采样，条件扩散模型恰好提供了高效的 `p(x|y)` 采样方法。**条件扩散采样 = 逆问题求解，这不是比喻，是等号。**

### 等式成立的条件

"条件扩散采样 = 逆问题求解"依赖三个前提：

1. **先验得分要准**：预训练扩散模型得准确估计 `∇log p_t(x_t)`。第12章的等价性 `DSM ≡ VLB` 保证这一点——训好的模型同时最优化了得分和似然下界。
2. **似然得分要能近似**：`∇log p(y|x_t)` 算不出（涉及对 `x_0` 的不可解积分），需要近似——这是 13.2~13.3 节的核心。
3. **得分分解要精确**：后验得分分解直接来自贝叶斯定理，是精确的；误差只来自似然得分那一项。

### 扩散模型解逆问题的三重优势

传统逆问题方法有三个老毛病：(1) 手工先验表达能力有限；(2) 归一化常数算不出；(3) 不同逆问题要设计不同算法。扩散模型正好一一破解——无需显式先验（得分函数隐式编码全部先验信息）、无需归一化常数（得分天然与 `Z` 无关）、零样本迁移（同一个预训练模型换 `A` 和 `y` 就能解不同问题）。三根支柱的共同根源是：**得分函数 `∇log p(x)` 是概率分布的充分统计量**。13.6 节会在闭环总结里完整展开这四点（含不确定性量化）。

> **一个反直觉的小数字（先猜猜看）**：如果让你用同一个训练好的模型，去解"去噪""去模糊""非线性退化"三种完全不同的逆问题，你猜需要重训几次模型？直觉上，每种问题该各训一个网络吧？——**答案：零次。** 后验得分分解把"通用先验"和"问题特异的观测约束"解耦了，换 `A` 和 `y` 就行，模型一次都不用重训。这正是 13.6 节要亲手验证的"零样本迁移"机制。

## 本节小结

本节立起了本章核心等式：

$$\boxed{\text{条件扩散采样 } p(x|y) \;=\; \text{逆问题求解}}$$

数学基础是后验得分分解：

$$\nabla\log p(x_t|y) = \nabla\log p(x_t) + \nabla\log p(y|x_t)$$

第一项由预训练扩散模型给，第二项编码观测约束。扩散解逆问题有三重结构优势（无需显式先验、无需归一化常数、零样本迁移），13.6 节完整展开。

但一个关键问题还没回答：**似然得分 `∇log p(y|x_t)` 怎么算？** 它拿不到，因为 `p(y|x_t)` 涉及对 `x_0` 的不可解积分。后验得分分解把问题拆成两个子问题，先验得分已有解，似然得分是剩下的硬骨头。

后验得分分解把条件扩散采样的实现归结为似然得分 `∇log p(y|x_t)` 的计算。深入分析这个分解，能看清似然得分为什么算不出，以及 Tweedie 等式怎么在条件化里当关键枢纽——从第5章的"去噪器→得分函数"闭环，到第13章的"去噪器→似然得分"闭环。

## 收尾：为什么这一节重要

这一节做了一件看似简单、实则关键的事：**把"逆问题求解"和"条件生成"用等号焊在了一起。** 从此以后，你再看到一张模糊的图，心里想的不再是"我该怎么设计一个新算法去还原它"，而是"我该怎么把观测 `y` 当成条件，拽着已经会画图的扩散模型走"。

这个视角的转换，就是全书十二章理论旅程的终点——绕了这么一大圈，我们并没有发明一个"异于"逆问题的新工具，而是发现自己手里最强的生成工具，本质上正是逆问题的求解器。从更深层次看，这正是"贝叶斯 = 先验 + 似然"这一全书主线在最后关头的又一次显形：无条件扩散学的先验、观测提供的似然，在采样轨迹上合成了后验。下一节，我们把那个"拽"的动作——后验得分分解——拆开来，看看为什么第二项（似然得分）偏偏算不出，以及 Tweedie 等式怎么来救场。

## 实验 13.1-1：1D逆问题原理——条件扩散采样 = 逆问题求解

实验 `13.1-1.py` 演示**1D高斯混合先验下，无条件采样 `p(x)` 与条件采样 `p(x|y)` 的对比**，直观验证13.1节的核心等式：条件扩散采样等价于逆问题求解。

### 实验场景

实验考虑1D去噪问题：观测模型 `y = x + n`，其中 `n ∼ N(0, σ_obs²)` 为加性高斯噪声。先验分布为1D高斯混合 `p(x) = 0.3·N(-2, 1) + 0.7·N(1, 1)`，使用VP-SDE框架进行扩散采样。

对比两种采样方式：

**无条件采样**：仅使用先验得分 `∇log p_t(x_t)` 驱动逆向SDE，采样结果服从先验分布 `p(x)`。

**条件采样（后验采样）**：使用后验得分 `∇log p_t(x_t|y) = ∇log p_t(x_t) + ∇log p(y|x_t)` 驱动逆向SDE，其中似然梯度通过DPS近似计算：`∇log p(y|x_t) ≈ (m_t/σ_obs²)(y - x̂_{0|t})`，采样结果服从后验分布 `p(x|y)`。

### 实验目的

1. **直观验证"条件扩散采样 = 逆问题求解"**：条件采样的样本与观测 `y` 一致，而非遍历整个先验空间
2. **展示似然项的约束效果**：似然梯度 `∇log p(y|x_t)` 将采样轨迹从先验区域"拉"向观测一致区域
3. **对比后验与先验的统计特性**：后验分布更集中（方差更小），均值更接近观测值
4. **揭示扩散后验采样与MAP的本质区别**：后验采样保持多样性（不坍缩到单点），同时受观测约束

### 实验输入

| 参数 | 设置 |
|------|------|
| 先验分布 | 1D高斯混合：`0.3·N(-2, 1) + 0.7·N(1, 1)` |
| 噪声调度 | VP-SDE，`β_min=0.1`，`β_max=20.0` |
| 逆问题类型 | 1D去噪：`y = x + n`，`σ_obs = 0.5` |
| 采样粒子数 | 5000 |
| 逆向SDE步数 | 300 |
| 似然权重 | `ζ = 1.0`（简化设置） |

### 预期结果

- 无条件采样的分布接近先验 `p(x)`：双峰结构，均值接近先验均值，方差大
- 条件采样的分布更集中于观测 `y` 附近：均值接近 `y`，方差显著小于无条件采样
- 后验采样的 `|x - y|` 均值和 `|x - x_0^*|` 均值均显著小于无条件采样
- 似然项起"软约束"作用：把粒子从整个先验空间拉向 `y` 附近，同时先验项保持多样性

### 实验结果

- **无条件采样**的均值（0.051）接近先验均值 `0.3×(-2) + 0.7×1 = 0.1`，方差（2.946）接近先验方差，分布呈现双峰结构——这正是先验 `p(x)` 的形状
- **条件采样**的均值（0.078）接近观测值 `y = 0.048`，方差（0.144）远小于无条件采样（缩小约20倍）——似然项将分布从整个先验空间压缩到观测附近
- 后验采样的集中性验证了核心等式：**条件扩散采样确实在求解逆问题**——给定观测 `y`，采样结果与 `y` 一致

#### 核心知识点

本实验在1D情形下直观验证了13.1节的核心等式"条件扩散采样 = 逆问题求解"：

1. **后验得分分解的物理含义**：`∇log p(x_t|y) = ∇log p(x_t) + ∇log p(y|x_t)`，第一项（先验得分）维持先验结构，第二项（似然得分）引入观测约束
2. **似然项的角色**：似然梯度 `∇log p(y|x_t)` 是"软约束"——它不像MAP那样把解强制拉到某个点，而是引导采样轨迹向观测一致区域偏移，同时保留后验的多样性
3. **与MAP的本质区别**：MAP给出后验众数（单点），后验采样给出后验分布（样本集）。后验采样既受观测约束（均值接近 `y`），又保持不确定性（非零方差），这是优化方法无法提供的信息
