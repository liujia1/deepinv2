# 13.1 闭环：从逆问题出发，回到逆问题

> **核心观点**：第1章定义了逆问题 $y = Ax + \epsilon$，第3章指出需要从后验 $p(x|y)$ 采样而非仅做MAP估计。经过12章的理论发展，我们已拥有了预训练的扩散模型作为先验 $p(x)$。现在的问题是：如何将这个先验与观测 $y$ 结合，实现后验采样？答案是后验得分分解——$\nabla\log p(x_t|y) = \nabla\log p(x_t) + \nabla\log p(y|x_t)$，第一项由扩散模型提供，第二项通过近似方法融入。由此，条件扩散采样与逆问题求解等价，全书叙事闭环。

## 回顾全书推理链

### 起点：逆问题与贝叶斯解

第1章定义了图像逆问题的数学形式：

$$y = Ax + \epsilon$$

其中 $x \in \mathbb{R}^n$ 是未知的原始图像，$A \in \mathbb{R}^{m \times n}$ 是正向算子（模糊核、下采样矩阵、Radon变换等），$\epsilon$ 是观测噪声，$y \in \mathbb{R}^m$ 是观测数据。逆问题的目标是从 $y$ 推断 $x$。

第1章5节给出了贝叶斯框架的统一解法：

$$p(x|y) \propto p(y|x) \cdot p(x)$$

似然 $p(y|x)$ 刻画了"数据告诉我们什么"，先验 $p(x)$ 编码了"我们额外知道什么"，两者相乘得到后验 $p(x|y)$——关于 $x$ 的完整概率描述。从此，逆问题求解不再只是"找一个数"，而是"刻画一个分布"。

### 分叉：MAP丢弃了不确定性

第3章7节揭示了MAP估计的根本局限。MAP给出后验众数：

$$\hat{x}_\text{MAP} = \arg\max_x p(x|y) = \arg\min_x \left[-\log p(y|x) - \log p(x)\right]$$

但众数不等于典型。高维空间中，概率密度最高的点几乎不可能被采样到；多峰后验中，众数只代表一个峰。更根本的是，**点估计丢弃了后验分布的全部形状信息**——不确定性（方差）、多峰性（多解）、后验相关结构——这些在优化过程中被完全丢弃。

第3章7节因此成为全书的分叉点：要处理复杂后验，需要从"求点"跃迁到"求分布"——即后验采样。两条路径从不同角度逼近这一目标。

### 采样路径：从ULA到扩散SDE

采样路径（第4-7章）从逆问题的后验采样需求出发，逐步建立了高效的概率采样工具：

- **第4章**：MCMC方法可以从后验中采样，但传统Metropolis-Hastings在高维中效率低。ULA（Unadjusted Langevin Algorithm）利用得分函数 $\nabla\log p(x)$ 加速采样，但需要得分函数已知
- **第5章**：得分函数 $\nabla\log p(x)$ 不可直接计算（归一化常数 $Z$ 不可求），但Tweedie等式提供了桥梁——MMSE去噪器 $D_\sigma^*(x)$ 可以给出得分函数的闭式估计
- **第6章**：得分匹配（DSM）可以从数据中学习得分函数——训练一个去噪器等价于学习得分函数，无需知道归一化常数
- **第7章**：多尺度得分匹配走向扩散SDE——连续时间的正向加噪过程与逆向去噪过程，得分函数 $\nabla\log p_t(x_t)$ 驱动逆向SDE完成采样

这条路径的终点是一个关键能力：**从噪声出发，通过得分函数驱动的随机微分方程，采样出高质量的图像样本**。

### 变分路径：从ELBO到VLB

变分路径（第8-11章）从生成建模的最大似然需求出发，也走向了扩散模型：

- **第8章**：生成模型需要最大化似然 $\log p(x)$，但似然不可计算→ELBO提供可优化的下界
- **第9章**：VAE用编码器-解码器架构实现ELBO最大化，重参数化技巧使梯度可传播
- **第10章**：层级VAE增加潜变量层次提升表达能力，无限层极限指向扩散模型
- **第11章**：VLB分解→均值匹配→ε预测参数化→简化训练目标 $L_\text{simple}$，得到DDPM训练算法

### 统一：DSM ≡ VLB

第12章证明了采样路径与变分路径的训练目标在数学上等价：

$$\text{DSM损失} \equiv \text{变分下界（VLB）}$$

两条路径从不同的出发点（后验采样需求 vs. 最大似然需求），训练出了完全相同的模型——同样的去噪器网络 $\epsilon_\theta(x_t, t)$，同样的加噪过程，同样的采样过程。等价性告诉我们：学好得分函数（梯度信息）等价于学好对数似然（标量信息），因为 $\nabla\log p(x)$ 与 $\log p(x)$ 是同一个概率分布的不同数学表示。

### 此刻：用扩散模型作为先验，解决逆问题

12章的理论发展赋予了我们一个强大的工具——预训练的扩散模型。这个模型的核心能力是：

1. **提供先验得分**：去噪器网络 $\epsilon_\theta(x_t, t)$ 通过Tweedie等式给出 $\nabla\log p_t(x_t)$，即先验分布的梯度信息
2. **高效采样**：逆向SDE/概率流ODE可以从噪声出发，生成符合先验 $p(x)$ 的高质量样本
3. **隐式编码先验**：训练过程中，模型从大量数据中隐式学习了图像的统计规律——比任何手工设计的先验（TV、小波稀疏性等）都更强大

但到目前为止，这个模型采样的是**无条件分布** $p(x)$——它可以生成"看起来像真实图像"的样本，但无法保证样本与观测 $y$ 一致。逆问题的核心需求始终是**条件分布** $p(x|y)$——给定观测 $y$，采样与之兼容的图像 $x$。

于是问题变为：**如何将预训练的扩散模型从无条件采样 $p(x)$ 扩展到条件采样 $p(x|y)$？**

## 关键等式：条件扩散采样 = 逆问题求解

### 贝叶斯定理在得分函数层面的表达

后验得分分解是本章的核心数学工具，其推导简洁而深刻。由贝叶斯定理 $p(x|y) = p(y|x)p(x)/p(y)$，两边取对数后对 $x$ 求梯度（注意 $p(y)$ 与 $x$ 无关），即得：

$\boxed{\nabla_x \log p(x|y) = \nabla_x \log p(y|x) + \nabla_x \log p(x)}$

这就是**后验得分分解**——后验得分 = 似然得分 + 先验得分。

> **回顾**：这个分解在第5章5.5节已经出现过——PnP-ULA的得分分解 $s(x|y) = \nabla\log p(y|x) + \nabla\log p(x)$ 与此处完全相同。区别在于：PnP-ULA使用**单一噪声水平**的去噪器提供先验得分，是条件采样的"单步版本"；而条件扩散使用**多尺度**的得分函数 $\nabla\log p_t(x_t)$ 驱动逆向SDE，是PnP-ULA的"多步推广"。换言之，**PnP-ULA是条件扩散采样的单噪声尺度特例**——它在固定噪声水平上使用同一得分分解，而条件扩散在多尺度上递归使用。这一认识揭示了从Ch5到Ch13的连贯叙事线。

将这个分解代入第7章的逆向SDE：

$$dx = \left[f(x,t) - g^2(t)\nabla_x\log p_t(x)\right]dt + g(t)d\bar{w}$$

用条件得分替换无条件得分：

$$dx = \left[f(x,t) - g^2(t)\left(\nabla_x\log p_t(x_t) + \nabla_x\log p(y|x_t)\right)\right]dt + g(t)d\bar{w}$$

**条件逆向SDE只比无条件逆向SDE多了一项**——似然得分 $\nabla_x\log p(y|x_t)$。这一项将观测 $y$ 的约束信息融入采样过程，使采样轨迹从"生成任意图像"变为"生成与观测一致的图像"。

### 两种视角的对照

后验得分分解将逆问题求解与条件扩散采样统一为同一数学对象——$p(x|y)$。但从不同视角看，它们的意义截然不同：

| 维度 | 逆问题视角 | 条件扩散视角 |
|---|---|---|
| 核心问题 | 已知 $y = Ax + \epsilon$，求 $x$ | 已知观测 $y$，从 $p(x\|y)$ 采样 |
| 数学框架 | 贝叶斯推断：$p(x\|y) \propto p(y\|x)p(x)$ | 条件生成：$p(x\|y) = p(y\|x)p(x)/p(y)$ |
| 先验来源 | 手工设计（TV、小波稀疏性）或学习 | 预训练扩散模型提供 $\nabla\log p(x_t)$ |
| 似然来源 | 正向模型 $A$ + 噪声模型 $\epsilon$ | 同左——$\nabla\log p(y\|x_t)$ |
| 求解方式 | 优化（MAP）或采样（MCMC） | 条件逆向SDE采样 |
| 输出 | 单点估计（MAP）或样本集（MCMC） | 后验样本集 |
| 不确定性 | 优化无法提供；MCMC可提供但效率低 | 天然提供——每个样本都是后验的一个实现 |

两种视角的等价性是深刻的：逆问题的贝叶斯框架要求从 $p(x|y)$ 采样，条件扩散模型恰好提供了一种高效的 $p(x|y)$ 采样方法。**条件扩散采样 = 逆问题求解**，这不是类比，而是数学上的等式。

### 等式成立的条件

需要强调的是，"条件扩散采样 = 逆问题求解"的等价性依赖于以下前提：

1. **先验得分的准确性**：预训练的扩散模型必须准确估计 $\nabla\log p_t(x_t)$。如果先验得分不准确，条件采样的结果将偏离真实后验
2. **似然得分的可近似性**：$\nabla\log p(y|x_t)$ 无法精确计算（涉及对 $x_0$ 的不可解积分），需要近似方法——这是第13.2-13.3节的核心内容
3. **得分分解的精确性**：后验得分分解 $\nabla\log p(x_t|y) = \nabla\log p(x_t) + \nabla\log p(y|x_t)$ 是精确的（直接来自贝叶斯定理），但近似误差在似然得分项引入

前提1由第12章的等价性保证——DSM ≡ VLB意味着训练的模型同时最优化了得分估计和似然下界。前提2和3是接下来的核心问题。

### 扩散模型求解逆问题的结构性优势

传统逆问题方法面临三个核心困难：(1) 手工先验表达能力有限，(2) 归一化常数不可计算，(3) 不同逆问题需设计不同算法。扩散模型恰好克服了这三个困难——无需显式先验（得分函数隐式编码先验的全部信息）、无需归一化常数（得分函数天然与$Z$无关）、零样本迁移（同一预训练模型更换$A$和$y$即可解不同问题）。三重优势的统一根源是：**得分函数$\nabla\log p(x)$是概率分布的充分统计量**。13.6节将在闭环总结中详细展开这四点优势（含不确定性量化）。

## 本节小结

本节建立了本章的核心等式：

$\boxed{\text{条件扩散采样 } p(x|y) \;=\; \text{逆问题求解}}$

这个等式的数学基础是后验得分分解：

$\nabla\log p(x_t|y) = \nabla\log p(x_t) + \nabla\log p(y|x_t)$

第一项由预训练扩散模型提供，第二项编码观测约束。扩散模型求解逆问题具有结构性优势（无需显式先验、无需归一化常数、零样本迁移），13.6节将完整展开。

但一个关键问题尚未回答：似然得分 $\nabla\log p(y|x_t)$ 如何计算？它不能直接获得，因为 $p(y|x_t)$ 涉及对 $x_0$ 的不可解积分。后验得分分解将问题拆解为两个子问题，先验得分已有解决方案，似然得分是剩下的核心挑战。

后验得分分解将条件扩散采样的实现归结为似然得分 $\nabla\log p(y|x_t)$ 的计算。深入分析这个分解的数学推导，可以揭示似然得分不可直接计算的原因，以及Tweedie等式如何在条件化中扮演关键角色——从第5章的"去噪器→得分函数"闭环，到本章的"去噪器→似然得分"闭环。
