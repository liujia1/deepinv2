# 13.6 闭环：回到第1章的逆问题

> **核心观点**：从第1章的逆问题 $y = Ax + \epsilon$ 出发，经过12章的理论旅程——贝叶斯框架、先验设计、后验采样、得分匹配、扩散模型、变分推断、统一理论——我们回到逆问题求解，但已拥有了远比传统方法更强大的工具：条件扩散采样。扩散模型之所以能超越传统方法，根本原因在于它隐式学习了任意复杂的先验分布，并能通过后验得分分解灵活融入观测约束。后验得分分解 $\nabla\log p(x_t|y) = \nabla\log p(x_t) + \nabla\log p(y|x_t)$ 正是贝叶斯定理"先验 + 似然 = 后验"在得分函数空间的数学体现——全书核心论点的最终验证。

## 从贝叶斯框架到条件扩散的完整路径

第1章提出了逆问题 $y = Ax + \epsilon$，给出了贝叶斯解 $p(x|y) \propto p(y|x)p(x)$。12章之后，我们终于走通了从贝叶斯框架到条件扩散采样的完整路径。回顾这条路径的全貌：

```
第1章  逆问题 y=Ax+ε
       └── 贝叶斯解：p(x|y) ∝ p(y|x)p(x) —— "答案是一个分布"
              │
第2章  先验 p(x)
       └── 正则化的概率诠释 —— "先验是概率化的正则化"
              │
第3章  MAP → 后验
       └── 分叉点：众数≠典型 —— "点估计丢弃不确定性，需要后验采样"
              │
       ┌──────┴──────┐
       │              │
  采样路径          变分路径
  (逆问题驱动)      (生成建模驱动)
       │              │
第4章  MCMC/ULA     第8章  ELBO
       │              │
第5章  Langevin      第9章  VAE
       │ + 得分函数   │
       │ + Tweedie    │
       │              │
第6章  得分匹配      第10章 层级VAE
       │ (DSM)        │
       │              │
第7章  扩散SDE       第11章 VLB + ε预测
       │              │
       └──────┬──────┘
              │
第12章  DSM ≡ VLB —— "殊途同归：训练的是同一个去噪器"
              │
第13章  条件扩散采样 = 逆问题求解 —— "闭环！"
       └── 后验得分分解：∇log p(x_t|y) = ∇log p(x_t) + ∇log p(y|x_t)
           └── 先验得分（预训练扩散模型）+ 似然得分（测量模型）= 后验采样
```

这条路径上的每一个环节都不可或缺：

- **第1章**：定义了问题和目标——从 $y$ 推断 $x$，贝叶斯解要求刻画后验 $p(x|y)$
- **第2章**：指出先验 $p(x)$ 的设计是核心挑战——手工先验的表达能力有限
- **第3章**：揭示了点估计的根本局限——后验采样才是正确的目标
- **第4-7章**：从MCMC到扩散SDE，建立了高效的概率采样工具——但采样的是 $p(x)$ 而非 $p(x|y)$
- **第8-12章**：从ELBO到DSM≡VLB，理解了扩散模型训练的统一本质——同一个去噪器，两条路径殊途同归
- **第13章**：将 $p(x)$ 采样扩展为 $p(x|y)$ 采样——后验得分分解将先验知识与观测约束优雅地解耦

**闭环的含义**：从逆问题出发，经过12章的理论旅程，回到逆问题求解——但此刻已拥有了远比第1章更强大的工具。第1章的逆问题需要手工先验和MCMC采样，第13章的逆问题用预训练扩散模型做先验、用条件扩散做采样。起点与终点是同一个问题，但解决方案已发生质的飞跃。

## 扩散模型为何能超越传统方法

从第2章的手工先验到第13章的扩散先验，逆问题求解能力发生了质的飞跃。扩散模型超越传统方法的根本原因可以归结为四点。

### 任意复杂先验

传统方法需要手工设计先验——TV正则化假设图像分段光滑，小波稀疏性假设图像在小波域稀疏，BM3D假设图像具有非局部自相似性。这些先验是对图像统计规律的简化假设，其表达能力受限于人的先验知识。

扩散模型**隐式编码了任意复杂的先验**。训练过程中，模型从大量数据中学习了图像的全部统计规律——纹理、结构、语义、全局一致性——这些规律远比任何手工先验都更丰富。先验知识不是以显式公式 $R(x)$ 的形式给出，而是编码在去噪器网络的参数 $\theta$ 中：

$$\nabla\log p_t(x_t) = \frac{\sqrt{\bar\alpha_t}\,\hat{x}_\theta(x_t, t) - x_t}{1 - \bar\alpha_t}$$

当数据分布足够复杂时（如人脸、自然场景），任何参数化先验族 $p(x; \phi)$ 都无法精确刻画，但扩散模型的得分函数 $\nabla\log p_t(x_t)$ 可以——因为它通过通用近似器（神经网络）隐式学习了先验分布的全部信息。

### 不确定性量化

传统逆问题方法给出点估计——MAP、正则化解——丢失了后验分布的全部形状信息。第3章指出，点估计无法回答"这个重建有多可靠？""是否存在其他合理的重建？""不同区域的置信度如何？"这些关键问题。

扩散模型通过**后验采样提供完整的不确定性量化**。每一次条件扩散采样生成后验 $p(x|y)$ 的一个样本，多次采样得到样本集 $\{x^{(i)}\}_{i=1}^N$，从中可以估计：

- **点估计**：$\bar{x} = \frac{1}{N}\sum_i x^{(i)}$（后验均值，比MAP更稳健）
- **不确定性**：$\text{Var}[x|y] \approx \frac{1}{N}\sum_i (x^{(i)} - \bar{x})^2$（逐像素方差图）
- **多峰性**：不同的样本可能聚类为多个模态——揭示了逆问题的多解性
- **后验相关**：样本集保留了后验分布的空间相关结构

这种不确定性量化能力是传统点估计方法根本无法提供的信息。

## 实验 13.6-2：DPS去模糊与Inpainting——图像级零样本迁移

实验 `13.6-2.py` 演示**在MNIST上训练的扩散模型，使用DPS算法分别求解去模糊和Inpainting两种逆问题**，验证图像级别的零样本迁移能力。

### 实验场景

实验在MNIST上训练UNet DDPM，然后使用DPS算法解决两种不同的图像逆问题：

- **去模糊**：$y = k * x + n$，模糊核 $k$ 为高斯模糊，观测 $y$ 为模糊含噪图像
- **Inpainting**：$y = M \odot x + n$，$M$ 为二值掩膜（随机遮挡50%像素），观测 $y$ 为部分遮挡图像

两种任务使用**同一个预训练扩散模型**，仅需更换前向算子 $A$ 和观测 $y$——零样本迁移。

### 实验目的

1. **验证图像级零样本迁移**：同一MNIST模型应用于去模糊和Inpainting两种任务
2. **对比不同逆问题的重建效果**：去模糊（信息全局扩散）vs Inpainting（局部信息缺失）
3. **展示DPS对任意正向算子的通用性**：仅需实现 $A$ 和 $A^\top$（或通过自动微分计算梯度）

### 实验输入

| 参数 | 设置 |
|------|------|
| 数据集 | MNIST，$28 \times 28$ 灰度图 |
| 扩散模型 | SmallUNet，$\epsilon$-prediction |
| 去模糊 | 高斯模糊核，$\zeta = 0.5$ |
| Inpainting | 随机50%像素遮挡，$\zeta = 0.5$ |

### 预期结果

- 去模糊和Inpainting均能有效恢复图像，无需重新训练模型
- 去模糊恢复整体结构，Inpainting在遮挡区域生成合理内容
- 两种任务的重建质量受 $\zeta$ 影响：$\zeta$ 过小→偏离观测，$\zeta$ 过大→过拟合

## 实验 13.6-1：条件采样与零样本迁移

实验 `13.6-1.py` 演示**1D高斯混合先验下，同一训练好的扩散模型应用于三种不同逆问题**（去噪、去模糊、非线性退化），验证零样本迁移能力和不确定性量化。

### 实验场景

实验训练一个1D高斯混合先验下的VP-SDE扩散模型（仅学习先验），然后将同一模型应用到三种不同逆问题：

1. **去噪**（$A = I$）：$y = x + n$，最简单的逆问题
2. **去模糊**（$A = 0.7x$）：$y = 0.7x + n$，线性退化（下采样比例0.7）
3. **非线性退化**（$A = \tanh(2x)$）：$y = \tanh(2x) + n$，非线性正向模型

三种任务共用同一个预训练扩散模型，仅需更换算子 $A$ 及其导数 $A'$ 和观测 $y$——无需任何额外训练。

### 实验目的

1. **验证零样本迁移**：同一模型解决三种不同逆问题，展示后验得分分解的解耦优势
2. **对比不同退化算子的后验特性**：线性vs非线性算子对后验均值和方差的影响
3. **展示不确定性量化**：多次后验采样给出样本集，可计算均值、方差和置信区间

### 实验输入

| 参数 | 设置 |
|------|------|
| 先验分布 | 1D高斯混合：$0.3\,\mathcal{N}(-2, 1) + 0.7\,\mathcal{N}(1, 1)$ |
| 噪声调度 | VP-SDE，$\beta_\text{min}=0.1$，$\beta_\text{max}=20.0$ |
| 去噪 | $A = I$，$\sigma_y = 0.5$，$\zeta = 0.5$ |
| 去模糊 | $A = 0.7x$，$\sigma_y = 0.5$，$\zeta = 0.5$ |
| 非线性退化 | $A = \tanh(2x)$，$\sigma_y = 0.5$，$\zeta = 0.5$ |
| 不确定性量化 | 5次独立后验采样 |

### 预期结果

- 三种任务均成功恢复信号，无需重新训练模型
- 去噪（$A = I$）：后验最集中，标准差最小
- 去模糊（$A = 0.7x$）：$A' = 0.7 < 1$ 使似然约束减弱，标准差增大
- 非线性退化（$A = \tanh(2x)$）：饱和区 $A' \to 0$，似然梯度自动衰减，不确定性最大
- 多次采样的均值稳定，标准差反映后验的内在不确定性

#### 核心知识点

本实验验证了13.6节的两大优势：

1. **零样本迁移**：后验得分分解 $\nabla\log p(x_t|y) = \nabla\log p(x_t) + \nabla\log p(y|x_t)$ 将先验（通用）与似然（问题特异）解耦——更换 $A$ 和 $y$ 即可解不同问题
2. **不确定性量化**：后验采样的方差图逐像素给出重建置信度，多峰采样揭示逆问题的多解性——这是传统MAP方法根本无法提供的信息

### 无需归一化常数

贝叶斯推断的核心计算困难是归一化常数 $p(y) = \int p(y|x)p(x)dx$ 在高维空间中不可计算。得分函数天然绕过了这一困难：

$$\nabla\log p(x) = \nabla\log\frac{\tilde{p}(x)}{Z} = \nabla\log\tilde{p}(x) - \underbrace{\nabla\log Z}_{=0}$$

训练时，DSM损失不需要 $Z$；采样时，逆向SDE只需要 $\nabla\log p_t(x_t)$，不需要 $p_t(x_t)$ 本身；条件化时，似然得分 $\nabla\log p(y|x_t)$ 也与归一化常数无关。得分函数天然规避了贝叶斯推断中归一化常数的计算困难——这不仅是技术上的便利，更是得分匹配框架的深刻优势。

## 全书核心论点的最终验证

### 核心论点

本书的核心论点是：**扩散模型是逆问题方法演化的自然终点**。

这条论点不是事后归纳，而是从逆问题的核心需求出发，逐步推导的必然结论：

1. **逆问题需要后验采样**（第3章）：MAP估计丢弃不确定性，后验采样才是正确目标
2. **后验采样需要得分函数**（第5章）：Langevin动力学用 $\nabla\log p(x)$ 驱动采样，但得分函数不可直接计算
3. **得分函数可以从去噪器中提取**（第5章Tweedie等式）：$\nabla\log p_\sigma(x) = (D_\sigma^*(x) - x)/\sigma^2$，去噪器即得分函数
4. **去噪器可通过得分匹配训练**（第6章）：DSM从数据中学习去噪器，无需知道归一化常数

> **桥接：这条"去噪器 = 得分函数"的主线其实无需配对数据——并通向第17章**
> 上面的 $D_\sigma^*(x)$ 是**最优 MMSE 去噪器**，而一个常被忽视的事实是：它**可以完全不依赖配对数据 $(x,y)$ 地训练**——这正是第17章自监督逆问题求解的起点。Stein 无偏风险估计（SURE, Stein 1981）给出风险 $\mathbb{E}_y\|\hat x(y)-x\|^2$ 的无偏形式，其关于网络参数的梯度可直接反向传播，无需真实 $x$；更关键的是，SURE 的解析解恰好就是
> $$\hat x_{\text{SURE}}(y)=y+\sigma^2\nabla\log p_\sigma(y)=D_\sigma^*(y)$$
> 即它**与第5章 Tweedie 等式是同一个公式**。换言之：**SURE 自监督训练 ↔ Tweedie/得分匹配 ↔ 扩散模型的去噪得分** 三者共享同一条数学主线（Tachella 讲座 2025 明确把这一公式标为"扩散模型背后的关键公式"）。第17章的等变成像（Equivariant Imaging）进一步把这种"无配对数据"的能力从去噪（$A=I$）推广到不完整测量（$A\neq I$，如 MRI/CT 加速成像）——用数据分布的对称性先验去约束算子零空间里观测不到的方向。本书因此把"对称性先验"（第17章）与"生成式扩散先验"（本章及第16.5节）并列为逆问题求解的两大类互补先验。
5. **多步得分驱动采样即扩散模型**（第7章）：从单步去噪到多尺度得分驱动采样，扩散SDE自然出现
6. **条件扩散采样即逆问题求解**（第13章）：后验得分分解将先验知识与观测约束解耦，条件扩散采样 = 后验采样 = 逆问题求解

每一步都是上一步需求的自然延伸——**逆问题的需求驱动了方法的演化**，而方法演化的终点恰好是扩散模型。

### 后验得分分解：贝叶斯定理在得分空间的体现

后验得分分解

$$\nabla\log p(x_t|y) = \nabla\log p(x_t) + \nabla\log p(y|x_t)$$

是全书核心论点的数学体现。将它与贝叶斯定理对照：

$$\log p(x|y) = \log p(x) + \log p(y|x) - \log p(y)$$

两边对 $x$ 求梯度，归一化常数项消失：

$$\nabla\log p(x|y) = \nabla\log p(x) + \nabla\log p(y|x)$$

**贝叶斯定理中的"先验 + 似然 = 后验"在得分空间中体现为"先验得分 + 似然得分 = 后验得分"**。这一对应不是巧合——它是概率论基本定律在梯度空间的自然表达。

更深层地，这个对应揭示了一个关键事实：**得分函数空间是概率空间的对偶空间**。在概率空间中，归一化常数 $p(y)$ 是不可回避的计算障碍；在得分空间中，归一化常数自动消失（$\nabla\log p(y) = 0$）。后验得分分解之所以比后验概率分解更"好用"，正是因为得分空间天然规避了归一化常数——这是扩散模型求解逆问题的数学根源。

### "从逆问题出发，回到逆问题"的闭环

全书叙事的闭环可以用一个简洁的公式概括：

$$\text{逆问题} \xrightarrow{\text{贝叶斯}} \text{后验采样} \xrightarrow{\text{得分匹配}} \text{扩散模型} \xrightarrow{\text{条件采样}} \text{逆问题求解}$$

- **起点**（第1章）：逆问题 $y = Ax + \epsilon$，需要求解
- **中间**（第2-12章）：理论旅程——先验、采样、得分、扩散、变分、统一
- **终点**（第13章）：条件扩散采样 $p(x|y)$ = 逆问题求解

起点与终点是同一个问题，但解决方案已发生质的飞跃。第1章的逆问题需要手工先验和MCMC采样——计算代价高、表达能力弱、无法量化不确定性。第13章的逆问题用预训练扩散模型做先验、用后验得分分解做条件化、用逆向SDE做采样——零样本、高精度、天然量化不确定性。

**"从逆问题出发，回到逆问题"——这不是循环，而是螺旋上升。**

## 展望

第13章完成了"条件扩散采样 = 逆问题求解"的理论闭环，但远非终点。扩散模型与逆问题求解的故事仍在快速发展：

**流匹配（Flow Matching）**：扩散模型的连续归一化流替代方案，以更简单的训练目标和更灵活的路径设计受到广泛关注。第14章将详细讨论流匹配的理论基础及其与扩散模型的关系。

**实践应用**：第15-18章将把本章建立的理论框架应用到具体的逆问题场景——计算成像（CT、MRI）、图像修复与增强、盲逆问题（算子未知）等。理论框架的优雅最终需要在实践中验证和打磨。

**方法论前沿**：更精确的似然近似（超越DPS的delta函数假设）、更高效的控制策略（超越DOC的全局优化代价）、更鲁棒的条件训练（CFG在逆问题中的深入应用）——这些方向正在推动条件扩散采样从"能用"走向"好用"。

---

从第1章到第13章，我们走了一条漫长但逻辑严密的理论旅程。起点是一个古老的数学问题——如何从间接观测中恢复原始信号？这个问题的贝叶斯回答将我们引向后验分布，后验分布的采样需求将我们引向得分函数，得分函数的学习将我们引向扩散模型，而扩散模型的条件化最终将我们带回逆问题求解。

每一步都不是随意的跳跃，而是由上一步的核心困难所驱动的必然选择。如果逆问题不需要不确定性量化，我们不会走向后验采样；如果后验采样不需要得分函数，我们不会走向扩散模型；如果扩散模型不能条件化，我们不会回到逆问题求解。

**正是逆问题自身的内在逻辑，将我们一步步引向了扩散模型——而扩散模型，最终回馈给逆问题以最强大的求解工具。**

这，就是全书的核心故事。

## 实验 13.6-3：img2img闭环对比——Diffusers管线视角

实验 `13.6-3.py` 演示**使用Diffusers的 `StableDiffusionImg2ImgPipeline` 进行图像到图像生成**，建立img2img与逆问题求解的联系。

### 实验场景

Stable Diffusion的img2img管线本质上是条件扩散采样的一种实现：给定初始图像，通过部分加噪（由 `strength` 参数控制）再去噪生成新图像。这与DPS的逆问题求解有形式上的相似性，但存在关键区别：

- **img2img**：条件信号来自初始图像的编码（VAE latent），通过strength控制条件强度
- **DPS**：条件信号来自测量模型 $y = Ax + n$，通过 $\zeta$ 控制似然权重

### 实验目的

1. **演示img2img管线的基本使用**：理解strength参数的物理含义
2. **建立img2img与逆问题求解的联系**：img2img是条件扩散采样在"初始图像一致性"约束下的特例
3. **类比strength与 $\zeta$**：strength小→保留原图（类似 $\zeta$ 大），strength大→重新生成（类似 $\zeta$ 小）

### 实验输入

| 参数 | 设置 |
|------|------|
| 模型 | Stable Diffusion v1.5 |
| 管线 | `StableDiffusionImg2ImgPipeline` |
| prompt | "a beautiful sunset over mountains, oil painting style" |
| strength | $\{0.1, 0.3, 0.5, 0.75, 0.95\}$ |
| guidance_scale | 7.5 |

> **运行说明**：本实验需要GPU和diffusers库。

### 预期结果

- strength=0.1：几乎保留原图，多样性极低
- strength=0.5：平衡点，保留结构同时融入prompt风格
- strength=0.95：几乎重新生成，多样性高但与原图相似度低

## 实验 13.6-4：自定义img2img Pipeline——CFG显式实现

实验 `13.6-4.py` 演示**自定义Stable Diffusion img2img管线，显式实现CFG的uncond/cond拼接与权重混合**，拆解img2img流程的每一步。

### 实验场景

本实验手动组装Stable Diffusion的各组件（VAE、CLIP Text Encoder、UNet、DDIM Scheduler），构建 `CustomImg2ImgPipeline`，显式展示CFG的实现细节：

1. **CLIP编码**：prompt → text embeddings
2. **CFG准备**：构造 $[\epsilon_\text{uncond}, \epsilon_\text{cond}]$ 拼接（uncond用空字符串）
3. **VAE编码**：初始图像 → latent $z_0$
4. **确定起始步**：$t_\text{start} = N - \lfloor N \times \text{strength}\rfloor$
5. **加噪**：$z_t = \text{Scheduler.add\_noise}(z_0, \epsilon, t_\text{start})$
6. **逆向采样**：每步UNet前向 → CFG混合 → Scheduler步进

### 实验目的

1. **显式理解CFG的实现**：uncond/cond拼接、权重混合 $\hat{\epsilon} = \epsilon_\text{uncond} + s(\epsilon_\text{cond} - \epsilon_\text{uncond})$
2. **拆解img2img流程**：理解strength如何控制加噪程度，进而控制条件强度
3. **建立工程直觉**：从黑盒管线到白盒组件，理解每个模块的角色

### 实验输入

| 参数 | 设置 |

| 自定义管线 | `CustomImg2ImgPipeline`（手动组装VAE/CLIP/UNet/Scheduler） |
| strength | 0.8 |
| guidance_scale | 7.5 |
| 初始图像 | 渐变背景（程序生成） |

> **运行说明**：本实验需要GPU和diffusers/transformers库。

### 预期结果

- 自定义管线成功生成img2img结果，与官方管线效果一致
- 显式展示CFG的uncond/cond拼接过程
- 理解strength参数如何映射到扩散过程的起始时间步

## 实验 13.6-5：strength参数效应——与 $\zeta$ 和 guidance_scale 的三方类比

实验 `13.6-5.py` 演示**img2img strength参数的系统性效应**，并建立与DPS $\zeta$ 和CFG guidance_scale的三方类比。

### 实验场景

在同一初始图像和prompt下，系统扫描strength参数 $\{0.1, 0.3, 0.5, 0.75, 0.95\}$，展示strength对生成结果的连续影响。

三方参数的类比关系（13.6节统一视角）：

| 参数 | 控制维度 | 大值效果 | 小值效果 |
|------|---------|---------|---------|
| strength | 初始图像一致性 | 重新生成（多样性高） | 保留原图（一致性高） |
| $\zeta$（DPS） | 观测图像一致性 | 强约束（多样性低） | 弱约束（多样性高） |
| guidance_scale（CFG） | 文本语义一致性 | 贴合prompt（一致性高） | 接近无条件（多样性高） |

关键区别：strength和 $\zeta$ 控制图像层面的观测一致性，而guidance_scale控制文本语义一致性——两者是独立的维度。

### 实验目的

1. **系统展示strength参数效应**：从0.1到0.95的连续变化
2. **建立三方类比**：strength（初始图像）、$\zeta$（观测图像）、guidance_scale（文本语义）
3. **强调维度独立性**：图像一致性与文本一致性是两个独立的控制旋钮

### 实验输入

| 参数 | 设置 |
|------|------|
| 模型 | Stable Diffusion v1.5 |
| 管线 | `StableDiffusionImg2ImgPipeline` |
| strength | $\{0.1, 0.3, 0.5, 0.75, 0.95\}$ |
| guidance_scale | 7.5（固定） |
| 随机种子 | seed=42 |

> **运行说明**：本实验需要GPU和diffusers库。

### 预期结果

- strength从0.1到0.95：生成结果从"几乎保留原图"到"几乎重新生成"的连续过渡
- 对应DPS的 $t_\text{start} = \lfloor \text{strength} \times T \rfloor$：strength大→起始噪声大→多样性高

#### 核心知识点（实验13.6-3/4/5汇总）

这三个实验从Diffusers管线的实践视角验证了13.6节的统一框架论点：

1. **img2img是条件扩散采样的特例**：给定初始图像作为条件，strength控制条件强度——与DPS的 $\zeta$ 扮演类似角色
2. **CFG的显式实现**：uncond/cond拼接 + 权重混合 $\hat{\epsilon} = \epsilon_\text{uncond} + s(\epsilon_\text{cond} - \epsilon_\text{uncond})$，是Classifier-Free Guidance的工程实现
3. **三方参数的统一视角**：DPS（$\zeta$，观测图像一致性）、CFG（$s$，文本语义一致性）、img2img（strength，初始图像一致性）——三者都是"先验强度 vs 条件强度"的权衡，但控制的是不同的一致性维度
