## 从贝叶斯框架到条件扩散的完整路径

第1章提出逆问题 $y = Ax + \varepsilon$，给贝叶斯解 $p(x\mid y) \propto p(y\mid x)p(x)$。12章之后，我们终于走通了从贝叶斯框架到条件扩散采样的完整路径。回看全貌：

```
第1章  逆问题 y=Ax+ε
       └── 贝叶斯解：p(x|y) ∝ p(y|x)p(x) —— "答案是一个分布"
              │
第2章  先验 p(x)
       └── 正则化的概率诠释 —— "先验是概率化的正则化"
              │
第3章  MAP → 后验
       └── 分叉点：众数≠典型 —— "点估计丢弃不确定性，需要后验采样"
              │
       ┌──────┴──────┐
       │              │
  采样路径          变分路径
  (逆问题驱动)      (生成建模驱动)
       │              │
第4章  MCMC/ULA     第8章  ELBO
       │              │
第5章  Langevin      第9章  VAE
       │ + 得分函数   │
       │ + Tweedie    │
       │              │
第6章  得分匹配      第10章 层级VAE
       │ (DSM)        │
       │              │
第7章  扩散SDE       第11章 VLB + ε预测
       │              │
       └──────┬──────┘
              │
第12章  DSM ≡ VLB —— "殊途同归：训的是同一个去噪器"
              │
第13章  条件扩散采样 = 逆问题求解 —— "闭环！"
       └── 后验得分分解：∇log p(x_t|y) = ∇log p(x_t) + ∇log p(y|x_t)
           └── 先验得分（预训练扩散模型）+ 似然得分（测量模型）= 后验采样
```

路径上每环节都不可或缺：
- **第1章**：定义问题和目标——从 $y$ 推断 $x$，贝叶斯解要求刻画后验 $p(x\mid y)$
- **第2章**：指出先验 $p(x)$ 设计是核心挑战——手工先验表达能力有限
- **第3章**：揭示点估计根本局限——后验采样才正确目标
- **第4~7章**：从MCMC到扩散SDE，建高效采样工具——但采的是 $p(x)$ 非 $p(x\mid y)$
- **第8~12章**：从ELBO到DSM≡VLB，理解扩散训练统一本质——同去噪器，两路殊途同归
- **第13章**：把 $p(x)$ 采样扩到 $p(x\mid y)$ 采样——后验得分分解把先验知识与观测约束优雅解耦

**闭环含义**：从逆问题出发，经12章理论旅程，回到逆问题求解——但此刻已拥有远比第1章强工具。第1章逆问题需手工先验和MCMC采样，第13章逆问题用预训练扩散模型做先验、条件扩散做采样。起点终点同一问题，解决方案已质飞跃。从更深层次看，这段旅程其实是在反复打磨同一样东西——我们把"逆问题"这块石头，一路打磨成"条件扩散采样"这把刀，而刀锋上最关键的一处，就是把逆问题的解写成了后验 $p(x\mid y)$，再按贝叶斯把它拆成先验与似然两半。

> **一个值得先猜再揭晓的数字**：实验 13.6-1 里，我们用同一个训好的 1D 扩散模型（以解析 score 等价替代网络训练，无需训练，见实验说明），去解"去噪""线性缩放观测""非线性退化"三种完全不同的逆问题——你猜为了这三种任务，我们重训了几次模型？直觉上每种问题该各训一个网络吧？——**答案是零次。** 模型一次都不用重训，只是把正向算子 $A$ 和观测 $y$ 换一下就行。这个"零样本迁移"的魔法，正是后验得分分解把"通用先验"和"问题特异的观测约束"彻底解耦的结果。下面四小节，我们一条条拆开看扩散模型到底强在哪。

## 扩散模型为何能超越传统方法

从第2章手工先验到第13章扩散先验，逆问题求解能力质飞跃。扩散模型超越传统方法根本原因可归四点：其中**任意复杂先验、零样本迁移、无需归一化常数**三点就是 13.1 节讲的"三重优势"（那里按传统方法的三个老毛病逐条对应），**不确定性量化**是本节增补的第四点——它对应的不是某个"老毛病"，而是传统点估计方法整体丢失的后验分布信息。

### 任意复杂先验

传统方法需手工设计先验——TV正则化假设图像分段光滑，小波稀疏性假设图像在小波域稀疏，BM3D假设图像有非局部自相似性。这些先验是对图像统计规律的简化假设，表达能力受限于人的先验知识。

扩散模型**隐式编码任意复杂先验**。训练时模型从大量数据学了图像全部统计规律——纹理、结构、语义、全局一致性——远比任何手工先验丰富。先验知识不以显式公式 $R(x)$ 形式给，而编码在去噪网络参数 $\theta$ 中：

$$\nabla\log p_t(\mathbf{x}_t) = \frac{\sqrt{\bar{\alpha}_t}\,\hat{x}_\theta(\mathbf{x}_t, t) - \mathbf{x}_t}{1 - \bar{\alpha}_t}$$

当数据分布足够复杂（人脸、自然场景），任何参数化先验族 $p(x; \phi)$ 都无法精确刻画，但扩散模型得分函数 $\nabla \log p_t(x_t)$ 可以——因它通过通用近似器（神经网络）隐式学了先验分布全部信息。

### 不确定性量化

传统逆问题方法给点估计——MAP、正则化解——丢了后验分布全部形状信息。第3章指出，点估计无法答"这重建多可靠？""是否存在其他合理重建？""不同区域置信度如何？"这些关键问题。

扩散模型通过**后验采样提供完整不确定性量化**。每次条件扩散采样生成后验 $p(x\mid y)$ 一个样本，多次采样得样本集 $\lbrace x^{(i)}\rbrace_{i=1}^{N}$，可估：
- **点估计**：$\bar{x} = (1/N)\sum_i x^{(i)}$（后验均值，比MAP更稳健）
- **不确定性**：$\operatorname{Var}[x\mid y] \approx (1/N)\sum_i (x^{(i)} - \bar{x})^{2}$（逐像素方差图）
- **多峰性**：不同样本可能聚多模态——揭示逆问题多解性
- **后验相关**：样本集保留后验分布空间相关结构

这种不确定性量化能力是传统点估计方法根本无法提供的信息。这一转变意味着，"解逆问题"不再只是给一张图，而是给出"可能的图 + 这张图可信多少"——后者恰恰是医学、科学决策真正需要的。

### 零样本迁移

第13.1节详论此优势：同一预训练扩散模型，换算子 $A$ 和观测 $y$ 即可解不同逆问题——无需任何额外训练或微调。

零样本迁移数学根源是后验得分分解：先验得分 $\nabla \log p(x_t)$ 与具体逆问题无关（同预训练模型给），似然得分 $\nabla \log p(y\mid x_t)$ 通过算子 $A$ 和观测 $y$ 引入问题特异性。先验知识通用，观测约束问题——两者通过得分分解优雅解耦。

### 无需归一化常数

贝叶斯推断核心计算困难是归一化常数 $p(y) = \int p(y\mid x)p(x)dx$ 在高维不可算。得分函数天然绕过这困难：

$$∇\log p(\mathbf{x}) = ∇\log\frac{\tilde{p}(\mathbf{x})}{Z} = ∇\log\tilde{p}(\mathbf{x}) - \underbrace{∇\log Z}_{=0}$$

训练时 DSM 损失不需 $Z$；采样时逆向 SDE 只需 $\nabla \log p_t(x_t)$，不需 $p_t(x_t)$ 本身；条件化时似然得分 $\nabla \log p(y\mid x_t)$ 也与归一化常数无关。得分函数天然规避贝叶斯推断归一化常数计算困难——不仅是技术便利，更是得分匹配框架深刻优势。

> **为什么这四点加起来才"质变"**：任意复杂先验让模型"看得懂图"，不确定性量化让它能"说出自己有多不确定"，零样本迁移让它能"换个问题立刻上"，无需归一化常数让它在高维里"算得动"。传统方法在这四件事上每样都至少瘸一条腿；扩散模型四样全占——所以同样是"解逆问题"，它和手工先验 + MCMC 不是一个量级的工具。

## 实验 13.6-2：DPS去模糊与Inpainting——图像级零样本迁移

实验 `13.6-2.py` 演示**在MNIST上训练的扩散模型，使用DPS算法分别求解去模糊和Inpainting两种逆问题**，验证图像级零样本迁移能力。

### 实验场景

实验在MNIST上训UNet DDPM，然后用DPS解两种不同图像逆问题：
- **去模糊**：$y = k \cdot x + n$，模糊核 $k$ 为高斯模糊，观测 $y$ 为模糊含噪图
- **Inpainting**：$y = M \odot (x + n)$，$M$ 为二值掩膜（随机遮挡30%像素），观测 $y$ 为部分遮挡图；噪声只落在已知像素上，被遮挡区域不产生观测（避免把噪声当成测量）

两种任务用**同一预训练扩散模型**，仅需换正向算子 $A$ 和观测 $y$——零样本迁移。

### 实验目的

1. **验证图像级零样本迁移**：同一MNIST模型应用于去模糊和Inpainting两种任务
2. **对比不同逆问题重建效果**：去模糊（信息全局扩散）vs Inpainting（局部信息缺失）
3. **展示DPS对任意正向算子通用性**：仅需实现 $A$ 和 $A^\top$（或自动微分算梯度）

### 实验输入

| 参数 | 设置 |
|------|------|
| 数据集 | MNIST，$28 \times 28$ 灰度图，归一化到 $[-1,1]$ |
| 扩散模型 | SmallUNet，$\varepsilon$-prediction，$T = 200$，线性调度 $\beta \in [1e-4, 0.02]$，100 epochs |
| 引导权重 | $\zeta \in \lbrace 1.0, 10.0, 20.0, 50.0, 100.0\rbrace$（单位归一化梯度参数化，见 13.4-3） |
| 去模糊 | 高斯模糊核 $7\times 7$（$\sigma_k = 2.0$），观测噪声 $\sigma_y = 0.02$ |
| Inpainting | 随机 30% 像素遮挡，观测噪声 $\sigma_y = 0.01$ |

### 预期结果

- 去模糊和Inpainting均能有效恢复图像，无需重训模型（零样本迁移）
- 去模糊恢复整体结构，Inpainting在遮挡区域生成合理内容
- 重建质量显著受 $\zeta$ 影响。本实现为“单位归一化梯度”参数化，需**较大 $\zeta$ 才见效**（与 13.4-3 一致：归一化实现最优 $\zeta \approx 10$，$\zeta \le 1$ 跑不赢含噪观测）：
  - $\zeta = 1.0$：引导不足、先验主导，采样偏离观测（高多样性，PSNR 甚至**低于观测参照线**）
  - $\zeta = 10.0/20.0$：数据一致性主导，两任务均显著超越观测（高一致性）
  - $\zeta = 50.0/100.0$：继续小幅提升；本实验观测噪声很低（$\sigma_y=0.02/0.01$），$\zeta =100$ 时两任务仍在小幅提升（去模糊 26.31→26.65 dB，Inpainting 28.42→28.63 dB），未出现 13.4-3（$\sigma_y=0.3$）中 $\zeta =100$ 回落约 4.3 dB 的现象——回落阈值与观测噪声尺度相关

| 去模糊 | 15.18 dB | 8.21±0.25 | 17.99±1.29 | 25.08±0.46 | 26.31±0.43 | 26.65±0.40 |
| Inpainting | 11.52 dB | 8.26±0.27 | 24.58±0.68 | 27.83±0.33 | 28.42±0.34 | 28.63±0.41 |

观察与结论：

- **零样本迁移成立**：同一无条件 DDPM 仅换正向算子 $A$，去模糊与 Inpainting 均能求解；$\zeta =10/20$ 时两任务都显著超过观测参照（去模糊 25.1 dB > 观测 15.2 dB；Inpainting 27.8 dB > 观测 11.5 dB），数字 7/2/1/0 全部正确重建。

- **$\zeta$ 尺度的重要提醒**：本实现用“单位归一化梯度”，引导量级与残差解耦，故起效所需 $\zeta$ 远大于“真 DPS/原版尺度”（$\zeta'\approx 0.1-1$）——与实验 13.4-3 结论一致：离开步长参数化谈 $\zeta$ 的“标准强度”毫无意义。本实验观测噪声低（$\sigma_y=0.02/0.01$），$\zeta$ 升到 100 仍在升（Inpainting 从 28.42 升到 28.63），与 13.4-3（$\sigma_y=0.3$，$\zeta =100$ 回落约 4.3 dB）形成对照：过拟合回落的阈值由观测噪声尺度决定。

读这张表有三个要点：

- **多样性与一致性同步单调收缩**：去模糊的样本间 MSE 从 $\zeta =1$ 的 0.580 降到 $\zeta =50$ 的 0.0078（约 74 倍），Inpainting 从 0.568 降到 0.0036（约 158 倍）；数据一致性残差同步从 0.21/0.24 降到 0.016/0.009。这是 13.4.3 节 $\zeta$ 双重作用的图像级证据——$\zeta$ 不是“只提质量”，而是**用多样性换一致性**。
- **$\zeta =1$ 的高多样性是“错得各不相干”**：去模糊 4 条轨迹的 PSNR 分别是 8.94 / 7.82 / 10.01 / 9.30 dB，彼此相差 2 dB 以上，且都远低于观测参照 15.18 dB——多样性高，但采的都是错的。多样性本身不是好处，它得和一致性一起读。
- **$\zeta =50$ 时 4 条轨迹已高度一致**：去模糊四条 PSNR 落在 24.83–27.90 dB、Inpainting 落在 28.88–30.96 dB，逐像素 std 收到 0.01–0.02。此时“再多采几次”不会再带来新解，DPS 在该噪声水平下已把后验压成近似单峰——这也从侧面解释了 13.6-4 里 img2img 单样本现象的成因。

一处口径提醒：本对照只扫到 $\zeta =50$（未含 $\zeta =100$），因为它要说明的是“收缩趋势”而非“最优值”；最优 $\zeta$ 仍由上面的 3 种子 PSNR 表给出。

#### 核心知识点

本实验在图像级验证13.6节零样本迁移优势：同一模型、不同算子、无需重训——后验得分分解将通用先验与问题特异似然优雅解耦。

## 实验 13.6-1：条件采样与零样本迁移

实验 `13.6-1.py` 演示**1D高斯混合先验下，同一训练好扩散模型应用于三种不同逆问题**（去噪、线性缩放观测、非线性退化），验证零样本迁移能力和不确定性量化。

### 实验场景

实验场景中，先验为1D高斯混合 $0.3\cdot \mathcal{N}(-2,1)+0.7\cdot \mathcal{N}(1,1)$。由于高斯混合经 VP-SDE 任意时刻的边缘分布仍是高斯混合、score 存在解析解，实验**直接用解析 score 等价替代"训练好的去噪网络"**（二者数学上参数化同一个先验，无需训练，CPU 即可精确演示）；需强调这是1D教学沙盒，图像任务中的神经网络先验不具备此处的精确可解条件。将同一先验应用到三种不同逆问题：
1. **去噪**（$A = I$）：$y = x + n$，最简单逆问题
2. **线性缩放观测**（$A = 0.7x$）：$y = 0.7x + n$，信号衰减算子 $A = 0.7I$（不是卷积模糊，也不是下采样）
3. **非线性退化**（$A = \tanh(2x)$）：$y = \tanh(2x) + n$，非线性正向模型

三种任务共用同一预训练扩散模型，仅需换算子 $A$ 及其导数 $A'$ 和观测 $y$——无需任何额外训练。

### 实验目的

1. **验证零样本迁移**：同一模型解三种不同逆问题，展示后验得分分解解耦优势
2. **对比不同退化算子后验特性**：线性vs非线性算子对后验均值和方差影响
3. **展示不确定性量化**：多次后验采样给样本集，可算均值、方差和置信区间

### 实验输入

| 参数 | 设置 |
|------|------|
| 先验分布 | 1D高斯混合：$0.3\cdot \mathcal{N}(-2, 1) + 0.7\cdot \mathcal{N}(1, 1)$ |
| 噪声调度 | VP-SDE，$\beta_{\min}=0.1$，$\beta_{\max}=20.0$ |
| 去噪 | $A = I$，$\sigma_y = 0.3$，$\zeta = 0.5$ |
| 缩放观测 | $A = 0.7x$，$\sigma_y = 0.3$，$\zeta = 0.5$ |
| 非线性退化 | $A = \tanh(2x)$，$\sigma_y = 0.3$，$\zeta = 0.5$ |
| 不确定性量化 | 5次独立后验采样 |

### 预期结果

- 三种任务均能在后验意义下约束信号（均值与尾概率定量校准；非线性任务的后验宽度略偏大，见下方"δ-似然近似残留偏差"小节），无需重训模型
- 去噪（$A = I$）：后验最集中，标准差最小
- 缩放观测（$A = 0.7x$）：$A' = 0.7 < 1$ 使似然约束减弱，标准差增大
- 非线性退化（$A = \tanh(2x)$）：饱和区 $A' \to 0$，似然梯度自动衰减，不确定性最大
- 多次采样均值稳定，标准差反映后验内在不确定性

结果分析：
- **零样本迁移成功**：三种任务共用同一模型，无需重训。正是13.1节"条件扩散采样=逆问题求解"直接验证
- **$A'$ 影响后验集中度**：$A'=1$（去噪）→最集中；$A'=0.7$（缩放观测）→约束减弱；$A'\to 0$（tanh饱和区）→约束几乎消失——似然梯度强度与 $A'$ 成正比
- **不确定性量化**：均值标准误（0.0022）远小于平均标准差（0.307），区分"估计误差"与"后验内在不确定性"

#### δ-似然近似的残留偏差：后验宽度（重点）

非线性任务上，精确后验是均值 0.952、std 0.772、$P(x\ge 1)=0.380$ 的**严重右偏宽分布**（tanh 在 $x\gtrsim 1$ 饱和，似然形成平坦高原，"哪个 x 能解释 y=0.5"变模糊，先验右峰 $\mathcal{N}(1,1)$ 把质量铺到右尾）。修正雅可比缩放后，vanilla DPS(ζ=0.5) 给出 0.947/0.856/0.400：均值偏差 0.005、尾概率偏差 0.02，**但标准差偏宽约 11%**。

- **此前的"右尾排空"是错误缩放的假象**：早期实现把 $\hat{x}_{0}$ 对 $x_t$ 的雅可比写成 $1/\operatorname{mean}_t$（正确为 $\operatorname{mean}_t$）。$t\to T$ 时 $\operatorname{mean}_t\approx 0.006$、$1/\operatorname{mean}_t\approx 150$，梯度全程撞上裁剪上限 10，退化为"常数强度引导"，把非线性任务的右尾粒子强行拉回窄区，得到 0.66/0.59/0.22——看上去像"DPS 严重低估不确定性"，实为雅可比方向写反。实验 13.4-2 已用有限差分证实 $d\hat{x}_{0}/dx_t\approx \operatorname{mean}_t$。
- **残留偏差是 δ-似然本身的代价**：$p(y\mid x_t) \approx \mathcal{N}(y; A(\hat{x}_{0}), \sigma_y^{2})$ 把 x₀ 钉在 Tweedie 点估计上，忽略 $p(x_{0}\mid x_t)$ 的弥散。三个任务的标准差分别偏宽 6%/12%/11%，均值和尾概率基本无偏——偏差从"整体位移+尾部排空"缩小为"宽度略大"。
- **ζ 仍有影响**：ζ=0.25 时 std=1.155（过宽 50%）、均值 0.822（偏低）；ζ=0.5 在本设置下更接近精确后验。不存在"任意任务通用"的 ζ 标定。
- **结构性可修**：改用边际化似然 $L(x_t)=\int \mathcal{N}(y;A(x_{0}),\sigma_y^{2})p(x_{0}\mid x_t)dx_{0}$（GMM 下为两分量高斯混合，Gauss-Hermite 求积即可），引导样本给出 0.959/0.762/0.383，标准差从 0.856 收紧到 0.762，与精确后验的 0.772 吻合；去噪/缩放观测任务同样吻合（0.539/0.284、0.568/0.395）。
- **结论**：修正雅可比后，vanilla DPS 已接近精确后验；δ-似然的残留偏差主要落在**后验宽度**上，可在同一后验得分分解框架内通过边际化 $x_{0}\mid x_t$ 闭合。高维图像无法精确积分：线性算子可用 ΠGDM（各向同性高斯近似，闭式预条件），一般情形用 Moment Matching 等数值近似——即 13.2/13.3 节的精度递进链（delta→ΠGDM→完整协方差→精确积分）与本节展望所述"更精确似然近似（超越DPS的delta假设）"。线性观测下的同类精确得分对照已在实验 13.4-2 给出，本实验把这一对照推进到非线性 A。

#### 核心知识点

本实验验证13.6节两大优势：
1. **零样本迁移**：后验得分分解 $\nabla \log p(x_t\mid y) = \nabla \log p(x_t) + \nabla \log p(y\mid x_t)$ 将先验（通用）与似然（问题特异）解耦——换 $A$ 和 $y$ 即可解不同问题
2. **不确定性量化**：后验采样方差图逐像素给重建置信度，多峰采样揭示逆问题多解性——传统MAP方法根本无法提供

## 全书核心论点的最终验证

### 核心论点

本书核心论点：**扩散模型是逆问题方法演化的自然终点**。

这条论点不是事后归纳，而是从逆问题核心需求出发逐步推导的必然结论：
1. **逆问题需要后验采样**（第3章）：MAP丢弃不确定性，后验采样才正确目标
2. **后验采样需要得分函数**（第5章）：Langevin动力学用 $\nabla \log p(x)$ 驱动采样，但得分函数不可直接算
3. **得分函数可从去噪器提取**（第5章Tweedie）：$\nabla \log p_\sigma(x) = (D_\sigma^{*}(x) - x)/\sigma^{2}$，去噪器即得分函数
4. **去噪器可通过得分匹配训练**（第6章）：DSM从数据学去噪器，不需知归一化常数

> **桥接：这条"去噪器 = 得分函数"主线其实无需配对数据——并通向第17章**
> 上面 $D_\sigma^{*}(x)$ 是**最优 MMSE 去噪器**，常被忽视的事实是：它可以完全不依赖配对数据 $(x, y)$ 训练——这正是第17章自监督逆问题求解起点。Stein 无偏风险估计（SURE, Stein 1981）给风险 $\mathbb{E}_y\Vert \hat{x}(y)-x\Vert^{2}$ 无偏形式，其关于网络参数梯度可直接反向传播，不需真 $x$；更关键，SURE 解析解恰是
> $$\hat x_{\text{SURE}}(\mathbf{y})=\mathbf{y}+\sigma^2\nabla\log p_\sigma(\mathbf{y})=D_\sigma^*(\mathbf{y})$$
> 即它**与第5章 Tweedie 等式是同一公式**。换言之：**SURE 自监督训练 ↔ Tweedie/得分匹配 ↔ 扩散模型去噪得分** 三者共享同一条数学主线（Tachella 讲座 2025 明确把此公式标为"扩散模型背后关键公式"）。第17章等变成像（Equivariant Imaging）进一步把"无配对数据"能力从去噪（$A=I$）推广到不完整测量（$A\ne I$，如 MRI/CT 加速成像）——用数据分布对称性先验约束算子零空间观测不到的方向。本书因此把"对称性先验"（第17章）与"生成式扩散先验"（本章及第16.5节）并列为逆问题求解两大类互补先验。

5. **多步得分驱动采样即扩散模型**（第7章）：从单步去噪到多尺度得分驱动采样，扩散SDE自然出现
6. **条件扩散采样即逆问题求解**（第13章）：后验得分分解把先验知识与观测约束解耦，条件扩散采样 = 后验采样 = 逆问题求解

每一步都是上一步需求自然延伸——**逆问题需求驱动方法演化**，方法演化终点恰是扩散模型。

### 后验得分分解：贝叶斯定理在得分空间的体现

后验得分分解

$$\nabla\log p(\mathbf{x}_t|\mathbf{y}) = \nabla\log p(\mathbf{x}_t) + \nabla\log p(\mathbf{y}|\mathbf{x}_t)$$

是全书核心论点数学体现。把它与贝叶斯定理对照：

$$\log p(\mathbf{x}|\mathbf{y}) = \log p(\mathbf{x}) + \log p(\mathbf{y}|\mathbf{x}) - \log p(\mathbf{y})$$

两边对 $x$ 求梯度，归一化常数项消失：

$$\nabla\log p(\mathbf{x}|\mathbf{y}) = \nabla\log p(\mathbf{x}) + \nabla\log p(\mathbf{y}|\mathbf{x})$$

**贝叶斯定理"先验 + 似然 = 后验"在得分空间体现为"先验得分 + 似然得分 = 后验得分"**。这对应不是巧合——它是概率论基本定律在梯度空间自然表达。

更深层，这对应揭示关键事实：**得分函数空间是概率空间的对偶空间**。概率空间里归一化常数 $p(y)$ 是不可回避计算障碍；得分空间里归一化常数自动消失（$\nabla \log p(y)=0$）。后验得分分解比后验概率分解更"好用"，正因得分空间天然规避归一化常数——这是扩散模型解逆问题数学根源。

### "从逆问题出发，回到逆问题"的闭环

全书叙事闭环可用一简洁公式概括：

$$\text{逆问题} \xrightarrow{\text{贝叶斯}} \text{后验采样} \xrightarrow{\text{得分匹配}} \text{扩散模型} \xrightarrow{\text{条件采样}} \text{逆问题求解}$$

- **起点**（第1章）：逆问题 $y = Ax + \varepsilon$，需求解
- **中间**（第2~12章）：理论旅程——先验、采样、得分、扩散、变分、统一
- **终点**（第13章）：条件扩散采样 $p(x\mid y)$ = 逆问题求解

起点终点同一问题，解决方案已质飞跃。第1章逆问题需手工先验和MCMC采样——计算贵、表达弱、无法量化不确定性。第13章逆问题用预训练扩散模型做先验、后验得分分解做条件化、逆向SDE做采样——零样本、高精度、天然量化不确定性。

把这条链合起来读，条件扩散采样之所以等于逆问题求解，是因为它在**每一步去噪里**同时做了两件事：无条件去噪网络负责把轨迹拉回数据分布（先验），测量模型负责把轨迹拉回与 $y$ 一致（似然）——一次一步地，先验与似然被"掰开揉碎地融合"进采样过程。这一转变意味着，贝叶斯主干并没有在扩散模型这里消失，而是被重新组织：整本书反复强调的"先验 × 似然 = 后验"，在条件扩散里以"每步叠加先验得分与似然得分"的形式逐点兑现。

**"从逆问题出发，回到逆问题"——这不是循环，是螺旋上升。**

## 统一视角总结：先验—条件强度的三类旋钮

到这里，"回到第1章的逆问题"这条闭环已经讲完。下面补三个从**生成侧**出发的实验（13.6-3/4/5）作为收束——它们**不新增逆问题求解方法**，而是把第13章散落各节的"先验强度 vs 条件强度"权衡，统一到同一框架下看：

- **$\zeta$（13.3 DPS）**：控制"观测一致性"——大则强约束、多样性低，小则弱约束、多样性高；
- **`guidance_scale`（13.4 CFG）**：控制"文本语义一致性"——大则贴合 prompt、小则接近无条件；
- **`strength`（img2img）**：控制"初始图一致性"——它不是逆问题特例，而是"从初始图出发、保留多少"的插值参数，大则重新生成、小则保留原图。

三者都是"先验强度 vs 条件强度"的权衡，只是**控制的"一致性维度"不同**。下面三个实验用 Stable Diffusion 的 img2img 管线，把这条主线从逆问题侧（$\zeta$）拓展到条件生成侧（strength/CFG），作为第13章条件控制维度的统一视角收束。

## 实验 13.6-3：img2img闭环对比——Diffusers管线视角

实验 `13.6-3.py` 演示**使用Diffusers的 `StableDiffusionImg2ImgPipeline` 进行图像到图像生成**，建立img2img与逆问题求解联系。

### 实验场景

Stable Diffusion的img2img管线本质是条件扩散采样一种实现：给定初始图，通过部分加噪（由 `strength` 参数控制）再去噪生成新图。这与DPS逆问题求解有形式相似性，但有关键区别：
- **img2img**：条件信号来自初始图编码（VAE latent），通过strength控条件强度
- **DPS**：条件信号来自测量模型 $y = Ax + n$，通过 $\zeta$ 控似然权重

### 实验目的

1. **演示img2img管线基本使用**：同一初始图、固定 `strength=0.75`，仅改变文本prompt，观察文本条件与初始图条件各自的作用位置
2. **建立img2img与逆问题求解联系**：二者共享同一预训练先验框架，但img2img**不是**逆问题的特例——初始图完整已知、无信息损失，也没有似然项；它用 `strength` 在"忠于原图"与"服从文本"之间插值（脚本对此有明确说明）
3. **理解双重约束的分工**：初始图（经strength控制）决定构图骨架，prompt决定风格纹理——strength参数的系统性效应扫描由实验13.6-5专门展示

### 实验输入

| 参数 | 设置 |
|------|------|
| 模型 | Stable Diffusion v1.5 |
| 管线 | `StableDiffusionImg2ImgPipeline` |
| 初始图 | CompVis官方示例 `sketch-mountains-input.jpg`（彩色粉笔山景素描，resize到512×512） |
| prompt | 三组：油画风景 / 写实照片 / 铅笔素描（见代码） |
| strength | 主对比 0.75；另做 0.6/0.75/0.9 扫描（同 prompt） |
| guidance_scale | 7.5 |
| 随机种子 | seed=42（当前代码已固定；存档配图生成于固定种子之前，重跑细节会不同） |

> **运行说明**：本实验需要GPU和diffusers库（SD v1.5 fp16约需4–6GB显存；CPU上50步采样单图即需数十分钟至小时级，不现实）。若 `runwayml/stable-diffusion-v1-5` 仓库不可用，可替换为镜像仓库 `stable-diffusion-v1-5/stable-diffusion-v1-5`。

### 预期结果

- 三幅图共享初始图的构图骨架（山体/河流的大致布局与色块位置），因为strength=0.75只允许后半段采样，初始latent的结构信息大部分保留；
- 风格随prompt变化：油画笔触、纹理细节、铅笔排线各自可辨；
- "photorealistic"面板在 strength=0.75 下仍保留平涂插画感——但**不能据此断言这是 img2img 的固有上界**：保真度由 strength 控制，0.75 意味着初始图约束仍强。代码另做同 prompt 的 strength 扫描（0.6/0.75/0.9），用于区分"参数权衡"与"机制上界"。

### 实验结果

运行 `13.6-3.py` 后（需要GPU），生成img2img闭环对比图与 strength 扫描图。实际结果：三幅图构图同源、风格随prompt分化；"photorealistic"面板在 strength=0.75 下仍偏平涂插画风。

**strength 扫描**（同一 prompt `a photorealistic photo of mountains, sunny day`，seed=42）：

- `strength=0.6`（30步，t_start=20）：平涂卡通/插画风，初始图的蓝河道、亮绿山丘、桃色岸带、尖顶山几乎全部保留，构图忠实度最高；`sunny day` 只体现在天空淡蓝色调，无太阳；
- `strength=0.75`（37步，t_start=13）：几何化平涂插画，出现黄色卡通太阳与放射光线；河道退化为红粉色带、山体几何化，构图仅部分保留；
- `strength=0.9`（45步，t_start=5）：**明显照片化**——写实山体纹理与光影、真实天空与强烈镜头光晕，前景为写实起伏的暖色沙丘；初始图的河道/亮绿山丘等具体构图元素全部消失，仅保留"山脉+晴天"的语义。

因此，0.75 处未照片化是 **strength 参数选择导致的"保真-自由"权衡**，而不是 img2img 机制或 SD1.5 的固有上界：照片化程度随 strength 单调增强，对初始图的构图忠实度单调下降。这正好对应本章主线——条件强度（这里是 strength）决定"先验自由 vs 条件约束"的平衡点（与 DPS 的 $\zeta$、CFG 的 $s$ 同类）。（图 13.24、图 13.25）

## 实验 13.6-4：自定义img2img Pipeline——CFG显式实现

实验 `13.6-4.py` 演示**自定义Stable Diffusion img2img管线，显式实现CFG的uncond/cond拼接与权重混合**，拆解img2img流程每步。

### 实验场景

本实验手动组装Stable Diffusion各组件（VAE、CLIP Text Encoder、UNet、DDIM Scheduler），构建 `CustomImg2ImgPipeline`，显式展示CFG实现细节：
1. **CLIP编码**：prompt → text embeddings
2. **CFG准备**：构造 $[\varepsilon_{\mathrm{uncond}}, \varepsilon_{\mathrm{cond}}]$ 拼接（uncond用空字符串）
3. **VAE编码**：初始图 → latent $z_0$
4. **确定起始步**：`t_start = N - ⌊N × strength⌋`
5. **加噪**：`z_t = Scheduler.add_noise(z_0, ε, t_start)`
6. **逆向采样**：每步UNet前向 → CFG混合 → Scheduler步进

### 实验目的

1. **显式理解CFG实现**：uncond/cond拼接、权重混合 $\hat{\varepsilon} = \varepsilon_{\mathrm{uncond}} + s(\varepsilon_{\mathrm{cond}} - \varepsilon_{\mathrm{uncond}})$
2. **拆解img2img流程**：理解strength如何控加噪程度，进而控条件强度
3. **建立工程直觉**：从黑盒管线到白盒组件，理解每模块角色

### 实验输入

| 参数 | 设置 |
|------|------|
| 模型 | CompVis/stable-diffusion-v1-4 |
| 自定义管线 | `CustomImg2ImgPipeline`（手动组装VAE/CLIP/UNet/Scheduler） |
| strength | 0.8 |
| guidance_scale | 7.5 |
| 初始图像 | 渐变背景（程序生成） |

> **运行说明**：本实验需要GPU和diffusers/transformers库。

### 预期结果

- 自定义管线成功生成img2img结果，与官方管线**数值等价**（MAE≈0.5/255、相关系数 1.0）
- 显式展示CFG的uncond/cond拼接过程
- 理解strength参数如何映射到扩散过程起始时间步

### 实验结果

运行 `13.6-4.py` 后（需要GPU），生成主对比图、种子扫描图与官方管线对照图三张。（图 13.26）

## 实验 13.6-5：strength参数效应——与 $\zeta$ 和 guidance_scale 的三方类比

实验 `13.6-5.py` 演示**img2img strength参数系统性效应**，并建立与DPS $\zeta$ 和CFG guidance_scale三方类比。

### 实验场景

同一初始图和prompt下，系统扫描strength参数 $\lbrace 0.1, 0.3, 0.5, 0.75, 0.95\rbrace$，展示strength对生成结果连续影响。

三方参数类比关系（13.6节统一视角）：

| 参数 | 控制维度 | 大值效果 | 小值效果 |
|------|---------|---------|---------|
| strength | 初始图一致性 | 重新生成（多样性高） | 保留原图（一致性高） |
| $\zeta$（DPS） | 观测图一致性 | 强约束（多样性低） | 弱约束（多样性高） |
| guidance_scale（CFG） | 文本语义一致性 | 贴合prompt（一致性高） | 接近无条件（多样性高） |

关键区别：strength和 $\zeta$ 控图像层观测一致性，guidance_scale控文本语义一致性——两者独立维度。

### 实验目的

1. **系统展示strength参数效应**：从0.1到0.95连续变化
2. **建立三方类比**：strength（初始图）、$\zeta$（观测图）、guidance_scale（文本语义）
3. **强调维度独立性**：图像一致性与文本一致性是两个独立控制旋钮

### 实验输入

| 参数 | 设置 |
|------|------|
| 模型 | Stable Diffusion v1.5 |
| 管线 | `StableDiffusionImg2ImgPipeline` |
| 初始图 | CompVis官方示例 `init_image.jpg`（sketch-mountains，原始 1024×512；等比缩放后中心裁剪到 512×512） |
| prompt | "a beautiful sunset over mountains, oil painting style" |
| strength | $\lbrace 0.1, 0.3, 0.5, 0.75, 0.95\rbrace$ |
| guidance_scale | 7.5（固定） |
| 随机种子 | seed=42 |

> **运行说明**：本实验需要GPU和diffusers库（SD v1.5 fp16约需4–6GB显存，CPU上单图50步采样需数十分钟至小时级）。若 `runwayml/stable-diffusion-v1-5` 仓库不可用，可替换为镜像仓库 `stable-diffusion-v1-5/stable-diffusion-v1-5`。

### 预期结果

- strength从0.1到0.95：生成结果从"几乎保留原图"到"几乎重新生成"连续过渡
- img2img自身的加噪起点 `t_start ≈ ⌊strength × T⌋`（正向过程加噪到的噪声水平，注意这是img2img机制、与DPS无关——DPS从纯噪声起步靠似然梯度引导）：strength大→起始噪声大→多样性高、与初始图一致性低
- prompt中的"sunset"元素应只在strength足够大时才出现：小strength下初始图约束压制文本约束

### 实验结果

运行 `13.6-5.py` 后（需要GPU），生成strength参数效应图。实际结果（2026-10-05 存档图逐面板核对）：

- 0.1：与原图几乎不可区分（蓝河、两岸、铅笔线条与天空散点全保留）；
- 0.3：仅轻微油画化，构图与元素完整保留；
- 0.5：构图骨架（河道/两岸/右侧高山）保留，天空出现紫色笔触感重绘；
- 0.75：大幅油画化，河道与同源构图仍可辨认、远山出现，但**本样本天空为灰紫色、未见太阳**；
- 0.95：完全换景的落日油画（暖色天空与水面倒影、蓝色远山），初始图构图基本消失。

量化上，输出与初始图的像素距离随 strength 严格单调上升：MSE 从 137（0.1）→ 262（0.3）→ 625（0.5）→ 1665（0.75）→ 4178（0.95），MAE 从 6.3 → 8.8 → 14.1 → 30.5 → 50.8。核心趋势（初始图一致性单调下降、重绘自由度单调上升）与理论预期一致。

> **单样本提醒**：每档仅 1 个样本（seed=42）。“sunset 在何档出现”不应被当作普适阈值：旧存档（预处理口径不同）中 0.75 曾出现太阳，本次同 seed 下 0.95 才充分显现——阈值受输入预处理与推理版本影响，属单样本波动，不影响单调趋势结论。另外，本实验只量化了“与初始图的像素距离”（MSE/MAE），**未测跨种子多样性**；上表及类比中“多样性高/低”是机制层面的预期，不是本实验的实测指标。

#### 核心知识点（实验13.6-3/4/5汇总）

这三实验从Diffusers管线实践视角验证13.6节统一框架论点：
1. **img2img与逆问题求解共享框架，但不是特例**：初始图是完整已知的采样起点（无信息损失、无似然项），`strength` 只在"忠于原图"与"服从文本"之间插值；它与 DPS 的 $\zeta$ 同属"条件强度"旋钮，但机制不同——img2img 靠初始化位置，DPS 靠似然梯度
2. **CFG显式实现**：uncond/cond拼接 + 权重混合 $\hat{\varepsilon} = \varepsilon_{\mathrm{uncond}} + s(\varepsilon_{\mathrm{cond}} - \varepsilon_{\mathrm{uncond}})$，是Classifier-Free Guidance工程实现
3. **三方参数统一视角**：DPS（$\zeta$，观测图一致性）、CFG（$s$，文本语义一致性）、img2img（strength，初始图一致性）——三者都是"先验强度 vs 条件强度"权衡，但控不同一致性维度

## 展望

第13章完成"条件扩散采样 = 逆问题求解"理论闭环，但远非终点。扩散模型与逆问题求解故事仍在快速发展：

**流匹配（Flow Matching）**：扩散模型连续归一化流替代方案，以更简单训练目标和更灵活路径设计受广泛关注。第14章将详论流匹配理论基础及其与扩散模型关系。

**实践应用**：第15~18章把本章理论框架应用到具体逆问题场景——计算成像（CT、MRI）、图像修复与增强、盲逆问题（算子未知）等。理论框架优雅最终需在实践中验证打磨。

**方法论前沿**：更精确似然近似（超越DPS的delta假设）、更高效控制策略（超越DOC全局优化代价）、更鲁棒条件训练（CFG在逆问题深入应用）——这些方向正推动条件扩散采样从"能用"走向"好用"。

---

从第1章到第13章，我们走了漫长但逻辑严密的理论旅程。起点是个古老数学问题——怎么从间接观测恢复原始信号？这问题贝叶斯回答引向后验分布，后验分布采样需求引向得分函数，得分函数学习引向扩散模型，扩散模型条件化最终引回逆问题求解。

每一步都不是随意跳跃，而是由前一步核心困难驱动的必然选择。若逆问题不需不确定性量化，我们不会走向后验采样；若后验采样不需得分函数，我们不会走向扩散模型；若扩散模型不能条件化，我们不会回到逆问题求解。

**正是逆问题自身内在逻辑，把我们一步步引向扩散模型——而扩散模型，最终回馈逆问题以最强大求解工具。**

这，就是全书核心故事。
