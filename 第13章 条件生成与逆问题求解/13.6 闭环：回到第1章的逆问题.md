## 从贝叶斯框架到条件扩散的完整路径

第1章提出逆问题 `y = Ax + ε`，给贝叶斯解 `p(x|y) ∝ p(y|x)p(x)`。12章之后，我们终于走通了从贝叶斯框架到条件扩散采样的完整路径。回看全貌：

```
第1章  逆问题 y=Ax+ε
       └── 贝叶斯解：p(x|y) ∝ p(y|x)p(x) —— "答案是一个分布"
              │
第2章  先验 p(x)
       └── 正则化的概率诠释 —— "先验是概率化的正则化"
              │
第3章  MAP → 后验
       └── 分叉点：众数≠典型 —— "点估计丢弃不确定性，需要后验采样"
              │
       ┌──────┴──────┐
       │              │
  采样路径          变分路径
  (逆问题驱动)      (生成建模驱动)
       │              │
第4章  MCMC/ULA     第8章  ELBO
       │              │
第5章  Langevin      第9章  VAE
       │ + 得分函数   │
       │ + Tweedie    │
       │              │
第6章  得分匹配      第10章 层级VAE
       │ (DSM)        │
       │              │
第7章  扩散SDE       第11章 VLB + ε预测
       │              │
       └──────┬──────┘
              │
第12章  DSM ≡ VLB —— "殊途同归：训的是同一个去噪器"
              │
第13章  条件扩散采样 = 逆问题求解 —— "闭环！"
       └── 后验得分分解：∇log p(x_t|y) = ∇log p(x_t) + ∇log p(y|x_t)
           └── 先验得分（预训练扩散模型）+ 似然得分（测量模型）= 后验采样
```

路径上每环节都不可或缺：
- **第1章**：定义问题和目标——从 `y` 推断 `x`，贝叶斯解要求刻画后验 `p(x|y)`
- **第2章**：指出先验 `p(x)` 设计是核心挑战——手工先验表达能力有限
- **第3章**：揭示点估计根本局限——后验采样才正确目标
- **第4~7章**：从MCMC到扩散SDE，建高效采样工具——但采的是 `p(x)` 非 `p(x|y)`
- **第8~12章**：从ELBO到DSM≡VLB，理解扩散训练统一本质——同去噪器，两路殊途同归
- **第13章**：把 `p(x)` 采样扩到 `p(x|y)` 采样——后验得分分解把先验知识与观测约束优雅解耦

**闭环含义**：从逆问题出发，经12章理论旅程，回到逆问题求解——但此刻已拥有远比第1章强工具。第1章逆问题需手工先验和MCMC采样，第13章逆问题用预训练扩散模型做先验、条件扩散做采样。起点终点同一问题，解决方案已质飞跃。

> **一个值得先猜再揭晓的数字**：实验 13.6-1 里，我们用同一个训好的 1D 扩散模型，去解"去噪""去模糊""非线性退化"三种完全不同的逆问题——你猜为了这三种任务，我们重训了几次模型？直觉上每种问题该各训一个网络吧？——**答案是零次。** 模型一次都不用重训，只是把前向算子 `A` 和观测 `y` 换一下就行。这个"零样本迁移"的魔法，正是后验得分分解把"通用先验"和"问题特异的观测约束"彻底解耦的结果。下面四小节，我们一条条拆开看扩散模型到底强在哪。

## 扩散模型为何能超越传统方法

从第2章手工先验到第13章扩散先验，逆问题求解能力质飞跃。扩散模型超越传统方法根本原因可归四点。

### 任意复杂先验

传统方法需手工设计先验——TV正则化假设图像分段光滑，小波稀疏性假设图像在小波域稀疏，BM3D假设图像有非局部自相似性。这些先验是对图像统计规律的简化假设，表达能力受限于人的先验知识。

扩散模型**隐式编码任意复杂先验**。训练时模型从大量数据学了图像全部统计规律——纹理、结构、语义、全局一致性——远比任何手工先验丰富。先验知识不以显式公式 `R(x)` 形式给，而编码在去噪网络参数 `θ` 中：

$$\nabla\log p_t(x_t) = \frac{\sqrt{\bar\alpha_t}\,\hat{x}_\theta(x_t, t) - x_t}{1 - \bar\alpha_t}$$

当数据分布足够复杂（人脸、自然场景），任何参数化先验族 `p(x; φ)` 都无法精确刻画，但扩散模型得分函数 `∇log p_t(x_t)` 可以——因它通过通用近似器（神经网络）隐式学了先验分布全部信息。

### 不确定性量化

传统逆问题方法给点估计——MAP、正则化解——丢了后验分布全部形状信息。第3章指出，点估计无法答"这重建多可靠？""是否存在其他合理重建？""不同区域置信度如何？"这些关键问题。

扩散模型通过**后验采样提供完整不确定性量化**。每次条件扩散采样生成后验 `p(x|y)` 一个样本，多次采样得样本集 `{x^(i)}_{i=1}^N`，可估：
- **点估计**：`x̄ = (1/N)Σ_i x^(i)`（后验均值，比MAP更稳健）
- **不确定性**：`Var[x|y] ≈ (1/N)Σ_i (x^(i) - x̄)²`（逐像素方差图）
- **多峰性**：不同样本可能聚多模态——揭示逆问题多解性
- **后验相关**：样本集保留后验分布空间相关结构

这种不确定性量化能力是传统点估计方法根本无法提供的信息。

## 实验 13.6-2：DPS去模糊与Inpainting——图像级零样本迁移

实验 `13.6-2.py` 演示**在MNIST上训练的扩散模型，使用DPS算法分别求解去模糊和Inpainting两种逆问题**，验证图像级零样本迁移能力。

### 实验场景

实验在MNIST上训UNet DDPM，然后用DPS解两种不同图像逆问题：
- **去模糊**：`y = k * x + n`，模糊核 `k` 为高斯模糊，观测 `y` 为模糊含噪图
- **Inpainting**：`y = M ⊙ x + n`，`M` 为二值掩膜（随机遮挡50%像素），观测 `y` 为部分遮挡图

两种任务用**同一预训练扩散模型**，仅需换前向算子 `A` 和观测 `y`——零样本迁移。

### 实验目的

1. **验证图像级零样本迁移**：同一MNIST模型应用于去模糊和Inpainting两种任务
2. **对比不同逆问题重建效果**：去模糊（信息全局扩散）vs Inpainting（局部信息缺失）
3. **展示DPS对任意正向算子通用性**：仅需实现 `A` 和 `A^⊤`（或自动微分算梯度）

### 实验输入

| 参数 | 设置 |
|------|------|
| 数据集 | MNIST，`28 × 28` 灰度图 |
| 扩散模型 | SmallUNet，`ε`-prediction |
| 去模糊 | 高斯模糊核，`ζ = 0.5` |
| Inpainting | 随机50%像素遮挡，`ζ = 0.5` |

### 预期结果

- 去模糊和Inpainting均能有效恢复图像，无需重训模型
- 去模糊恢复整体结构，Inpainting在遮挡区域生成合理内容
- 两种任务重建质量受 `ζ` 影响：`ζ` 过小→偏离观测，`ζ` 过大→过拟合

### 零样本迁移

第13.1节详论此优势：同一预训练扩散模型，换算子 `A` 和观测 `y` 即可解不同逆问题——无需任何额外训练或微调。

零样本迁移数学根源是后验得分分解：先验得分 `∇log p(x_t)` 与具体逆问题无关（同预训练模型给），似然得分 `∇log p(y|x_t)` 通过算子 `A` 和观测 `y` 引入问题特异性。先验知识通用，观测约束问题——两者通过得分分解优雅解耦。

## 实验 13.6-1：条件采样与零样本迁移

实验 `13.6-1.py` 演示**1D高斯混合先验下，同一训练好扩散模型应用于三种不同逆问题**（去噪、去模糊、非线性退化），验证零样本迁移能力和不确定性量化。

### 实验场景

实验训一个1D高斯混合先验下VP-SDE扩散模型（仅学先验），将同模型应用到三种不同逆问题：
1. **去噪**（`A = I`）：`y = x + n`，最简单逆问题
2. **去模糊**（`A = 0.7x`）：`y = 0.7x + n`，线性退化（下采样比例0.7）
3. **非线性退化**（`A = tanh(2x)`）：`y = tanh(2x) + n`，非线性正向模型

三种任务共用同一预训练扩散模型，仅需换算子 `A` 及其导数 `A'` 和观测 `y`——无需任何额外训练。

### 实验目的

1. **验证零样本迁移**：同一模型解三种不同逆问题，展示后验得分分解解耦优势
2. **对比不同退化算子后验特性**：线性vs非线性算子对后验均值和方差影响
3. **展示不确定性量化**：多次后验采样给样本集，可算均值、方差和置信区间

### 实验输入

| 参数 | 设置 |
|------|------|
| 先验分布 | 1D高斯混合：`0.3·N(-2, 1) + 0.7·N(1, 1)` |
| 噪声调度 | VP-SDE，`β_min=0.1`，`β_max=20.0` |
| 去噪 | `A = I`，`σ_y = 0.5`，`ζ = 0.5` |
| 去模糊 | `A = 0.7x`，`σ_y = 0.5`，`ζ = 0.5` |
| 非线性退化 | `A = tanh(2x)`，`σ_y = 0.5`，`ζ = 0.5` |
| 不确定性量化 | 5次独立后验采样 |

### 预期结果

- 三种任务均成功恢复信号，无需重训模型
- 去噪（`A = I`）：后验最集中，标准差最小
- 去模糊（`A = 0.7x`）：`A' = 0.7 < 1` 使似然约束减弱，标准差增大
- 非线性退化（`A = tanh(2x)`）：饱和区 `A' → 0`，似然梯度自动衰减，不确定性最大
- 多次采样均值稳定，标准差反映后验内在不确定性

#### 核心知识点

本实验验证13.6节两大优势：
1. **零样本迁移**：后验得分分解 `∇log p(x_t|y) = ∇log p(x_t) + ∇log p(y|x_t)` 将先验（通用）与似然（问题特异）解耦——换 `A` 和 `y` 即可解不同问题
2. **不确定性量化**：后验采样方差图逐像素给重建置信度，多峰采样揭示逆问题多解性——传统MAP方法根本无法提供

### 无需归一化常数

贝叶斯推断核心计算困难是归一化常数 `p(y) = ∫ p(y|x)p(x)dx` 在高维不可算。得分函数天然绕过这困难：

$$\nabla\log p(x) = \nabla\log\frac{\tilde{p}(x)}{Z} = \nabla\log\tilde{p}(x) - \underbrace{\nabla\log Z}_{=0}$$

训练时 DSM 损失不需 `Z`；采样时逆向 SDE 只需 `∇log p_t(x_t)`，不需 `p_t(x_t)` 本身；条件化时似然得分 `∇log p(y|x_t)` 也与归一化常数无关。得分函数天然规避贝叶斯推断归一化常数计算困难——不仅是技术便利，更是得分匹配框架深刻优势。

> **为什么这四点加起来才"质变"**：任意复杂先验让模型"看得懂图"，不确定性量化让它能"说出自己有多不确定"，零样本迁移让它能"换个问题立刻上"，无需归一化常数让它在高维里"算得动"。传统方法在这四件事上每样都至少瘸一条腿；扩散模型四样全占——所以同样是"解逆问题"，它和手工先验 + MCMC 不是一个量级的工具。

## 全书核心论点的最终验证

### 核心论点

本书核心论点：**扩散模型是逆问题方法演化的自然终点**。

这条论点不是事后归纳，而是从逆问题核心需求出发逐步推导的必然结论：
1. **逆问题需要后验采样**（第3章）：MAP丢弃不确定性，后验采样才正确目标
2. **后验采样需要得分函数**（第5章）：Langevin动力学用 `∇log p(x)` 驱动采样，但得分函数不可直接算
3. **得分函数可从去噪器提取**（第5章Tweedie）：`∇log p_σ(x) = (D_σ^*(x) - x)/σ²`，去噪器即得分函数
4. **去噪器可通过得分匹配训练**（第6章）：DSM从数据学去噪器，不需知归一化常数

> **桥接：这条"去噪器 = 得分函数"主线其实无需配对数据——并通向第17章**
> 上面 `D_σ^*(x)` 是**最优 MMSE 去噪器**，常被忽视的事实是：它可以完全不依赖配对数据 `(x, y)` 训练——这正是第17章自监督逆问题求解起点。Stein 无偏风险估计（SURE, Stein 1981）给风险 `E_y‖x̂(y)-x‖²` 无偏形式，其关于网络参数梯度可直接反向传播，不需真 `x`；更关键，SURE 解析解恰是
> $$\hat x_{\text{SURE}}(y)=y+\sigma^2\nabla\log p_\sigma(y)=D_\sigma^*(y)$$
> 即它**与第5章 Tweedie 等式是同一公式**。换言之：**SURE 自监督训练 ↔ Tweedie/得分匹配 ↔ 扩散模型去噪得分** 三者共享同一条数学主线（Tachella 讲座 2025 明确把此公式标为"扩散模型背后关键公式"）。第17章等变成像（Equivariant Imaging）进一步把"无配对数据"能力从去噪（`A=I`）推广到不完整测量（`A≠I`，如 MRI/CT 加速成像）——用数据分布对称性先验约束算子零空间观测不到的方向。本书因此把"对称性先验"（第17章）与"生成式扩散先验"（本章及第16.5节）并列为逆问题求解两大类互补先验。

5. **多步得分驱动采样即扩散模型**（第7章）：从单步去噪到多尺度得分驱动采样，扩散SDE自然出现
6. **条件扩散采样即逆问题求解**（第13章）：后验得分分解把先验知识与观测约束解耦，条件扩散采样 = 后验采样 = 逆问题求解

每一步都是上一步需求自然延伸——**逆问题需求驱动方法演化**，方法演化终点恰是扩散模型。

### 后验得分分解：贝叶斯定理在得分空间的体现

后验得分分解

$$\nabla\log p(x_t|y) = \nabla\log p(x_t) + \nabla\log p(y|x_t)$$

是全书核心论点数学体现。把它与贝叶斯定理对照：

$$\log p(x|y) = \log p(x) + \log p(y|x) - \log p(y)$$

两边对 `x` 求梯度，归一化常数项消失：

$$\nabla\log p(x|y) = \nabla\log p(x) + \nabla\log p(y|x)$$

**贝叶斯定理"先验 + 似然 = 后验"在得分空间体现为"先验得分 + 似然得分 = 后验得分"**。这对应不是巧合——它是概率论基本定律在梯度空间自然表达。

更深层，这对应揭示关键事实：**得分函数空间是概率空间的对偶空间**。概率空间里归一化常数 `p(y)` 是不可回避计算障碍；得分空间里归一化常数自动消失（`∇log p(y)=0`）。后验得分分解比后验概率分解更"好用"，正因得分空间天然规避归一化常数——这是扩散模型解逆问题数学根源。

### "从逆问题出发，回到逆问题"的闭环

全书叙事闭环可用一简洁公式概括：

$$\text{逆问题} \xrightarrow{\text{贝叶斯}} \text{后验采样} \xrightarrow{\text{得分匹配}} \text{扩散模型} \xrightarrow{\text{条件采样}} \text{逆问题求解}$$

- **起点**（第1章）：逆问题 `y = Ax + ε`，需求解
- **中间**（第2~12章）：理论旅程——先验、采样、得分、扩散、变分、统一
- **终点**（第13章）：条件扩散采样 `p(x|y)` = 逆问题求解

起点终点同一问题，解决方案已质飞跃。第1章逆问题需手工先验和MCMC采样——计算贵、表达弱、无法量化不确定性。第13章逆问题用预训练扩散模型做先验、后验得分分解做条件化、逆向SDE做采样——零样本、高精度、天然量化不确定性。

**"从逆问题出发，回到逆问题"——这不是循环，是螺旋上升。**

---

## 统一视角总结：先验—条件强度的三类旋钮

到这里，"回到第1章的逆问题"这条闭环已经讲完。下面补三个从**生成侧**出发的实验（13.6-3/4/5）作为收束——它们**不新增逆问题求解方法**，而是把第13章散落各节的"先验强度 vs 条件强度"权衡，统一到同一框架下看：

- **`ζ`（13.3 DPS）**：控制"观测一致性"——大则强约束、多样性低，小则弱约束、多样性高；
- **`guidance_scale`（13.4 CFG）**：控制"文本语义一致性"——大则贴合 prompt、小则接近无条件；
- **`strength`（img2img）**：控制"初始图一致性"——作为条件扩散采样的特例，大则重新生成、小则保留原图。

三者都是"先验强度 vs 条件强度"的权衡，只是**控制的"一致性维度"不同**。下面三个实验用 Stable Diffusion 的 img2img 管线，把这条主线从逆问题侧（`ζ`）拓展到条件生成侧（strength/CFG），作为第13章条件控制维度的统一视角收束。

## 实验 13.6-3：img2img闭环对比——Diffusers管线视角

实验 `13.6-3.py` 演示**使用Diffusers的 `StableDiffusionImg2ImgPipeline` 进行图像到图像生成**，建立img2img与逆问题求解联系。

### 实验场景

- **img2img**：条件信号来自初始图编码（VAE latent），通过strength控条件强度
- **DPS**：条件信号来自测量模型 `y = Ax + n`，通过 `ζ` 控似然权重

### 实验目的

1. **演示img2img管线基本使用**：理解strength参数物理含义
2. **建立img2img与逆问题求解联系**：img2img是条件扩散采样在"初始图一致性"约束下特例
3. **类比strength与 `ζ`**：strength小→保留原图（类似 `ζ` 大），strength大→重新生成（类似 `ζ` 小）

## 实验 13.6-4：自定义img2img Pipeline——CFG显式实现

本实验手动组装Stable Diffusion各组件（VAE、CLIP Text Encoder、UNet、DDIM Scheduler），构建 `CustomImg2ImgPipeline`，显式展示CFG实现细节：
1. **CLIP编码**：prompt → text embeddings
2. **CFG准备**：构造 `[ε_uncond, ε_cond]` 拼接（uncond用空字符串）

## 实验 13.6-5：strength参数效应——与 `ζ` 和 guidance_scale 的三方类比

实验 `13.6-5.py` 演示**img2img strength参数系统性效应**，并建立与DPS `ζ` 和CFG guidance_scale三方类比。

1. **系统展示strength参数效应**：从0.1到0.95连续变化
2. **建立三方类比**：strength（初始图）、`ζ`（观测图）、guidance_scale（文本语义）

## 展望

第13章完成"条件扩散采样 = 逆问题求解"理论闭环，但远非终点。扩散模型与逆问题求解故事仍在快速发展：

**流匹配（Flow Matching）**：扩散模型连续归一化流替代方案，以更简单训练目标和更灵活路径设计受广泛关注。第14章将详论流匹配理论基础及其与扩散模型关系。

**实践应用**：第15~18章把本章理论框架应用到具体逆问题场景——计算成像（CT、MRI）、图像修复与增强、盲逆问题（算子未知）等。理论框架优雅最终需在实践中验证打磨。

**方法论前沿**：更精确似然近似（超越DPS的delta假设）、更高效控制策略（超越DOC全局优化代价）、更鲁棒条件训练（CFG在逆问题深入应用）——这些方向正推动条件扩散采样从"能用"走向"好用"。

---

从第1章到第13章，我们走了漫长但逻辑严密的理论旅程。起点是个古老数学问题——怎么从间接观测恢复原始信号？这问题贝叶斯回答引向后验分布，后验分布采样需求引向得分函数，得分函数学习引向扩散模型，扩散模型条件化最终引回逆问题求解。

每一步都不是随意跳跃，而是由前一步核心困难驱动的必然选择。若逆问题不需不确定性量化，我们不会走向后验采样；若后验采样不需得分函数，我们不会走向扩散模型；若扩散模型不能条件化，我们不会回到逆问题求解。

**正是逆问题自身内在逻辑，把我们一步步引向扩散模型——而扩散模型，最终回馈逆问题以最强大求解工具。**

这，就是全书核心故事。
