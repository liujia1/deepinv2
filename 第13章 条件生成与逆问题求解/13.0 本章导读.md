# 13.0 本章导读：梦境成真——"复原 = 要后验"，现在真的能采样后验了

> "第1章我们说过，逆问题真正的答案不是一个点，而是一个**后验分布** `p(x|y)`。当时那句话更像一句愿望——我们既不会采样，也没有好的先验。Twelve 章之后，这个愿望变成了可以运行的代码。"

还记得第1章那个让你有点不安的结论吗？我们说：给你一张糊的、有噪声的、被欠采样的图 `y`，你想找回干净原图 `x`，但"正确"的答案不是某一个 `x̂`，而是**一整片可能的 `x`**，它们各有一定的概率——这就是后验 `p(x|y)`。那时我们无奈地摊手：后验算不出来，采样更别想。MAP（最大后验点估计）成了退而求其次的妥协。

好消息是，从第1章到第12章，我们其实一直在为这一刻铺路。到第12章结束时，我们手里已经有了一件利器：**预训练的扩散模型**。它本质上就是一个"学出来的先验"——它知道真实图像长什么样，而且能高效地从噪声里采样出像样的图。

那么问题来了：这个只会"无中生有"画图的模型，能不能反过来帮我们**复原**图像？能不能把观测 `y` 塞进去，让它只画出"既像真图、又和 `y` 一致"的图？

**本章要告诉你的核心答案就是：能，而且这正是逆问题求解本身。**

我们把"用预训练扩散模型当先验 + 把观测 `y` 融进采样过程"这套操作，叫做**条件扩散采样**（conditional diffusion sampling）。本章要证明一件听起来像魔法、其实是等式的事：

$$\boxed{\text{条件扩散采样 } p(x|y) \;=\; \text{逆问题求解}}$$

不是类比，是等号。第1章说的"复原 = 要后验"，此刻真的能用扩散采样后验了。这就是我们说的"梦境成真"。

## 本章目标（读完你该能做到）

- 把任意逆问题 `y = Ax + ε` 写成贝叶斯后验 `p(x|y)`，并看懂它怎么变成一条扩散采样方程；
- 说出**后验得分分解**这个全场最关键的等式，并解释它的两项分别由谁提供；
- 区分逆问题求解的两种用法：**MAP 点估计** vs **后验采样**（分布），知道什么时候该用哪个；
- 讲清楚 **DPS** 是怎么在反向采样里加一个"数据保真梯度"把样本拉向观测的；
- 理解 **DDRM** 怎么用前向算子的 SVD 分解，在频谱域里做精确的条件采样；
- 看明白"无条件扩散怎么变成条件扩散"这一转换，为下一章 Flow Matching 埋好伏笔。

## 全书推理链的完整闭环

把镜头拉远，从第1章到第12章我们走了一条很长的路。此刻站在第13章门口，先回顾这一整条链长什么样：

```
第1章  逆问题 y=Ax+ε ─── 起点：贝叶斯告诉我们  p(x|y) ∝ p(y|x)·p(x)
  │
第2章  先验 p(x) ─── 正则化=概率化："额外知道什么"写成一个分布
  │
第3章  MAP → 后验 ─── 分叉点：众数≠典型样本，光求点不够，要采样
  │
  ├──→ 采样路径（主线·逆问题驱动）
  │    第4章  MCMC/ULA ─── 能采样但太慢
  │    第5章  Langevin + 得分函数 ─── 用梯度 ∇log p(x) 加速
  │          ↕ Tweedie等式：去噪器 ⟺ 得分函数
  │    第6章  得分匹配（DSM）─── 从去噪里学得分
  │    第7章  扩散SDE ─── 多步得分驱动采样
  │
  ├──→ 变分路径（副线·生成建模驱动）
  │    第8章  ELBO ─── 似然算不出→变分下界
  │    第9章  VAE ─── 编码器-解码器+重参数化
  │    第10章 层级VAE ─── 加层次
  │    第11章 VLB + ε预测 ─── 扩散的变分视角
  │
  └──→ 第12章 DSM ≡ VLB ─── 殊途同归，训练的是同一个去噪器
       │
第13章  条件扩散采样 = 逆问题求解 ─── 闭环！
```

这条链上最关键的转折发生在**第3章末尾**：MAP 只给你后验的"众数"（概率最高的那一个点），却把不确定性全丢了。从那以后全书的核心问题就变成——**怎么从后验分布 `p(x|y)` 里采样？**

第4到12章回答了前半截：怎么高效地从分布里采样（不管有没有条件）。我们拿到了扩散模型——一个强大的、可训练的概率采样器。但它采样的是**无条件分布** `p(x)`（"画一张像样的图"），不是我们真正需要的**条件分布** `p(x|y)`（"画一张既像样又和 `y` 一致的图"）。

第13章回答后半截：**怎么把无条件扩散变成条件扩散，让它采 `p(x|y)` 而不是 `p(x)`？**

> **为什么这个问题配得上"梦境成真"四个字？** 因为前12章我们苦练的所有功夫——贝叶斯、采样、得分、Tweedie、扩散——缺了任何一环，都接不上"用观测拽着画图"这件看似简单的事。现在它们终于攒成一把能用的钥匙。

## 后验得分分解：一句话点破天机

答案藏在一个朴素得近乎无聊的等式里——**后验得分分解**（posterior score decomposition）：

$$\nabla_x \log p(x|y) = \underbrace{\nabla_x \log p(x)}_{\text{先验得分}} + \underbrace{\nabla_x \log p(y|x)}_{\text{似然得分}}$$

它直接来自贝叶斯定理：对 `p(x|y) ∝ p(y|x)p(x)` 两边取对数，再对 `x` 求梯度（注意 `p(y)` 跟 `x` 无关，求完梯度就消失）。但它告诉我们的事一点都不朴素：

- **第一项** `∇log p(x)`——我们**已经有了**！第4到12章建的扩散模型，就是个先验得分估计器。去噪网络 `ε_θ(x_t, t)` 通过 Tweedie 等式直接给出 `∇log p_t(x_t)`。
- **第二项** `∇log p(y|x)`——需要**额外算**。它编码了观测 `y` 的约束，取决于具体的逆问题（前向算子 `A` 和噪声模型）。

于是"条件扩散采样"被干净地拆成两个能分开处理的子问题：先用预训练扩散模型提供先验知识，再用近似方法把观测约束融进来。**同一个预训练模型，不用重训，换个 `A` 和 `y` 就能解不同的逆问题**——这正是扩散模型解逆问题最爽的地方。

## 为什么这一章重要

第13章是全书的**叙事闭环**。它回答了一个贯穿全书的问题：

**为什么逆问题的研究最终走向了扩散模型？**

前12章的回答是：因为逆问题要后验采样，后验采样要得分函数，得分函数能从去噪器里抽出来（Tweedie），去噪器能用得分匹配训练，多步得分驱动采样就是扩散模型——**是逆问题的需求把方法一步步推到了扩散模型**。

第13章的回答更进一步：因为扩散模型不只是一个生成模型，它更是逆问题的天然求解器——预训练的扩散模型给先验得分，观测约束通过后验得分分解融进采样，条件扩散采样就是逆问题求解——**扩散模型反过来serves了逆问题**。

从逆问题出发，绕了12章，回到逆问题求解——但手里已不是第1章那套手工先验加 MCMC 的简陋工具。闭环长这样：

$$\text{逆问题} \xrightarrow{\text{贝叶斯}} \text{后验采样} \xrightarrow{\text{得分匹配}} \text{扩散模型} \xrightarrow{\text{条件采样}} \text{逆问题求解}$$

我们从第1章的起点——那句"复原 = 要后验"——开始，看看这12章怎么一步步把我们带到条件扩散采样的门前。
