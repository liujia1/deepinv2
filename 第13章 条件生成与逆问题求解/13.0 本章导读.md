# 13.0 本章导读：从等价性到条件生成——闭环时刻

> **核心观点**：第12章证明了DSM ≡ VLB，建立了无条件扩散模型的统一理论——无论从采样路径还是变分路径出发，训练的都是同一个去噪器、优化的都是同一个目标。但逆问题的核心需求始终是条件生成——给定观测 $y$，从后验 $p(x|y)$ 中采样，而非从无条件分布 $p(x)$ 中采样。本章将无条件扩散扩展到条件扩散，证明**条件扩散采样 = 逆问题求解**，完成全书"从逆问题出发，回到逆问题"的叙事闭环。

## 全书推理链的完整闭环

从第1章到第12章，我们走了漫长的理论旅程。此刻站在第13章的起点，回顾这条推理链的全貌：

```
第1章  逆问题 y=Ax+ε ─── 起点：贝叶斯解 p(x|y) ∝ p(y|x)p(x)
  │
第2章  先验 p(x) ─── 正则化的概率诠释
  │
第3章  MAP → 后验 ─── 分叉点：众数≠典型，需要后验采样
  │
  ├──→ 采样路径（主线·逆问题驱动）
  │    第4章  MCMC/ULA ─── 可采样但效率低
  │    第5章  Langevin + 得分函数 ─── 梯度加速采样
  │          ↕ Tweedie等式：去噪器 ⟺ 得分函数
  │    第6章  得分匹配（DSM）─── 从去噪中学习得分
  │    第7章  扩散SDE ─── 多步得分驱动采样
  │
  ├──→ 变分路径（副线·生成建模驱动）
  │    第8章  ELBO ─── 似然不可计算→变分下界
  │    第9章  VAE ─── 重参数化+推断网络

  └──→ 第12章 DSM ≡ VLB ─── 殊途同归，统一理论
       │
第13章  条件扩散采样 = 逆问题求解 ─── 闭环！
```

这条推理链的关键转折发生在第3章末尾：MAP估计只给出后验众数，丢弃了不确定性信息。从那时起，全书的核心问题就是——**如何从后验分布 $p(x|y)$ 中采样？**

第4-12章回答了前半截问题：如何高效地从概率分布中采样（无论是有条件还是无条件的）。我们得到了扩散模型——一个强大的、可训练的概率采样器。但它采样的是无条件分布 $p(x)$，而非我们真正需要的条件分布 $p(x|y)$。

第13章回答后半截问题：**如何将无条件扩散变成条件扩散，使其采样 $p(x|y)$ 而非 $p(x)$？**

## 后验得分分解：关键洞察

这个问题的答案藏在一个看似简单的等式中——**后验得分分解**：

$$\nabla_x \log p(x|y) = \underbrace{\nabla_x \log p(x)}_{\text{先验得分}} + \underbrace{\nabla_x \log p(y|x)}_{\text{似然得分}}$$

这个等式直接来自贝叶斯定理：$p(x|y) \propto p(y|x)p(x)$，两边取对数再求梯度。但它揭示了一个深刻的事实：

- **第一项** $\nabla\log p(x)$——我们**已经有了**！第4-12章建立的扩散模型就是一个先验得分估计器，去噪器网络 $\epsilon_\theta(x_t, t)$ 通过Tweedie等式提供 $\nabla\log p_t(x_t)$
- **第二项** $\nabla\log p(y|x)$——需要**额外计算**！它编码了观测 $y$ 提供的约束信息，依赖于具体的逆问题（算子 $A$ 和噪声模型）

于是，条件扩散采样被拆解为两个可独立处理的子问题：先用预训练的扩散模型提供先验知识，再通过近似方法融入观测约束。**无需重新训练，同一个预训练模型就能解决不同的逆问题**——这正是扩散模型求解逆问题的核心优势。

## 为什么这一章重要

第13章是全书的叙事闭环。它回答了一个贯穿全书的核心问题：

**为什么逆问题的研究最终走向了扩散模型？**

前12章的回答是：因为逆问题需要后验采样，后验采样需要得分函数，得分函数可以从去噪器中提取（Tweedie），去噪器可通过得分匹配训练，多步得分驱动采样即扩散模型——**逆问题的需求驱动了方法演化**。

第13章的回答更进一步：因为扩散模型不仅是一个生成模型，更是逆问题的天然求解器——预训练的扩散模型提供先验得分，观测约束通过后验得分分解融入采样过程，条件扩散采样即逆问题求解——**扩散模型反过来服务于逆问题**。

从逆问题出发，经过12章的理论旅程，回到逆问题求解——但此刻已拥有了远比传统方法更强大的工具。这就是全书的叙事闭环：

$$\text{逆问题} \xrightarrow{\text{贝叶斯}} \text{后验采样} \xrightarrow{\text{得分匹配}} \text{扩散模型} \xrightarrow{\text{条件采样}} \text{逆问题求解}$$
