# 附录13B DDRM 算法的 SVD 推导

> 13.3.1 节我们提过 DDRM 走了一条和 DPS 完全不同的路：它不靠"单点近似"，而是借着线性算子的 SVD 分解，把问题搬进频谱域，在每个频谱分量上精确做条件化。这一节把这套推导完整摊开。你会看到，SVD 怎么把一个"向量逆问题"拆成一堆"标量逆问题"——这正是 DDRM 在线性问题上能精确、而 DPS 只能近似的根本原因。

本附录给出 DDRM（Denoising Diffusion Restoration Models）算法基于 SVD 分解的严格推导。DDRM 利用线性算子 SVD 结构，把向量值逆问题解耦为标量逆问题，在频谱域实现精确条件化。

---

## 1 线性算子 A 的 SVD 分解

### 1.1 SVD 分解

设线性算子 `A ∈ R^{m×n}`，其奇异值分解（SVD）：

$$A = U\Sigma V^\top$$

其中：
- `U ∈ R^{m×m}` 是左奇异向量矩阵，满足 `U^⊤U = UU^⊤ = I_m`
- `V ∈ R^{n×n}` 是右奇异向量矩阵，满足 `V^⊤V = VV^⊤ = I_n`
- `Σ ∈ R^{m×n}` 是对角矩阵，对角元素为奇异值 `{s_i}_{i=1}^{min(m,n)}`，满足 `s_1 ≥ s_2 ≥ … ≥ s_r > 0 = s_{r+1} = …`，`r = rank(A)`

> **类比**：SVD 就像给一个复杂的线性变换 `A` 做一次"换坐标系"——在输入空间用 `V` 摆好一组正交基，在输出空间用 `U` 摆好另一组正交基，于是 `A` 在这两套基下变成一条对角线上排着几个数 `s_i` 的矩阵。每个 `s_i` 就是"这个方向上的拉伸倍数"。拉伸大的方向（`s_i` 大）观测得清清楚楚，拉伸为零的方向（`s_i = 0`，零空间）观测完全看不见。DDRM 的全部智慧，就是按这个"看得清不清"的尺度来决策每个方向该听先验还是听测量。

### 1.2 变换到频谱域

定义频谱域变量：

$$\bar{y} = U^\top y \in \mathbb{R}^m, \quad \bar{x} = V^\top x \in \mathbb{R}^n, \quad \bar{\epsilon} = U^\top \epsilon \in \mathbb{R}^m$$

因 `U` 和 `V` 是正交矩阵，上述变换保距（isometry）：`‖ȳ‖ = ‖y‖`，`‖x̄‖ = ‖x‖`。

频谱域下，线性测量模型 `y = Ax + ε_y`（`ε_y ~ N(0, σ_y²I)`）变：

$$\bar{y} = U^\top(Ax + \epsilon_y) = U^\top U\Sigma V^\top x + U^\top\epsilon_y = \Sigma\bar{x} + \bar{\epsilon}$$

因 `U` 正交且 `ε_y ~ N(0, σ_y²I)`，有 `ε̄ = U^⊤ε_y ~ N(0, σ_y²I)`——噪声在频谱域仍是独立同分布高斯噪声。

### 1.3 解耦为标量问题

频谱域方程逐分量写：

$$\bar{y}_i = s_i\bar{x}_i + \sigma_y\bar{\epsilon}_i, \quad i = 1, \ldots, \min(m, n)$$

对 `i > r`（即 `s_i = 0`），方程退化为 `ȳ_i = σ_y ε̄_i`——观测不含关于 `x̄_i` 任何信息，这些分量完全由先验决定。

**关键洞察**：SVD 把向量值逆问题 `y = Ax + ε_y` **解耦为 `n` 个独立标量逆问题**——每个频谱分量 `x̄_i` 可独立据 `ȳ_i` 和 `s_i` 推断。这是 DDRM 精确条件化数学基础。

## 2 频谱域上的条件化

### 2.1 条件分布的因子化

因频谱域解耦，后验分布因子化：

$$p(\bar{x}|y) = p(\bar{x}|\bar{y}) \propto p(\bar{y}|\bar{x})\,p(\bar{x})$$

独立高斯噪声假设下，似然因子化：

$$p(\bar{y}|\bar{x}) = \prod_{i=1}^{m} p(\bar{y}_i|\bar{x}_i) = \prod_{i=1}^{m} \mathcal{N}(\bar{y}_i; s_i\bar{x}_i, \sigma_y^2)$$

但先验 `p(x̄)` 一般**不能**因子化——因图像频谱分量间有复杂相关性（正是自然图像先验复杂之处）。这意味着我们不能简单对每个 `x̄_i` 独立采样再组合。

### 2.2 DDRM 策略：在扩散采样中注入频谱域条件

DDRM 策略不是直接对因子化后验采样，而是在扩散逆向采样每步，对频谱域每个分量独立施加条件约束。具体而言，DDRM 把逆向采样步产生的含噪状态 `x_t` 变换到频谱域 `x̄_t = V^⊤x_t`，对每个频谱分量 `x̄_t^i` 独立施加条件化，再变换回原始域。

这策略可行性依赖关键事实：**扩散过程噪声各向同性**——VP-SDE 和 VE-SDE 加的噪声是 `σ_tε`，`ε ~ N(0, I)`。各向同性噪声在正交变换下不变，故频谱域扩散过程与原始域扩散过程同结构。这使我们可以安全在频谱域做条件化操作。

## 3 DDRM 的逐分量条件化公式

### 3.1 条件化准则的推导

DDRM 核心：在逆向采样每步 `t → t-1`，对每个频谱分量 `x̄_t^i`，根据该分量信噪比选不同条件化策略。

考虑时刻 `t` 含噪状态 `x_t`。VP-SDE 下与干净图 `x_0` 关系 `x_t = √ᾱ_t x_0 + √(1-ᾱ_t)ε`。变换到频谱域：

$$\bar{x}_t^i = \sqrt{\bar\alpha_t}\,\bar{x}_0^i + \sqrt{1-\bar\alpha_t}\,\bar{\epsilon}_t^i$$

`ε̄_t^i ~ N(0, 1)`。频谱域中测量方程 `ȳ_i = s_i x̄_0^i + σ_y ε̄_i`。

DDRM 关键判断：对每个频谱分量，**当前扩散噪声水平与测量噪声水平相对大小**决定该信任先验还是测量。

### 3.2 三种情况的条件化

定义扩散噪声方差 `σ_t² = 1 - ᾱ_t`（VP-SDE 下），测量噪声在频谱域有效方差 `σ_y²/s_i²`（注意 `s_i x̄_0^i` 测量噪声为 `σ_y ε̄_i`，归一化到 `x̄_0^i` 后有效方差 `σ_y²/s_i²`）。

**情况一：`s_i = 0`（零空间分量）**

`s_i = 0` 时观测 `ȳ_i` 不含关于 `x̄_0^i` 任何信息——这分量完全处于算子 `A` 零空间。此时只能依赖先验：

$$p(\bar{x}_{t-1}^i | x_t, y) = \mathcal{N}(\bar{x}_{t-1}^i;\, \hat{\bar{x}}_{0|t}^i,\, \sigma_{t-1}^2)$$

`x̂̄_{0|t}^i` 是先验后验均值（Tweedie 估计给），`σ_{t-1}²` 是下一步扩散噪声方差。

**情况二：`σ_t < σ_y/s_i`（测量噪声主导）**

`σ_t < σ_y/s_i` 时当前扩散噪声水平低于测量噪声有效水平——意味扩散过程已去除大部分噪声，图像在该频谱分量估计精度**高于**测量能提供精度。此时信任测量反而引入更多噪声，故仍依赖先验：

$$p(\bar{x}_{t-1}^i | x_t, y) = \mathcal{N}(\bar{x}_{t-1}^i;\, \hat{\bar{x}}_{0|t}^i,\, \sigma_{t-1}^2)$$

与情况一同先验驱动采样。

**情况三：`σ_t ≥ σ_y/s_i`（扩散噪声主导）**

`σ_t ≥ σ_y/s_i` 时当前扩散噪声水平不低于测量噪声有效水平——意味测量提供信息比当前含噪状态估计更可靠。此时应信任测量，用测量信息条件化：

$$p(\bar{x}_{t-1}^i | x_t, y) = \mathcal{N}\!\left(\bar{x}_{t-1}^i;\, \frac{\bar{y}_i}{s_i},\, \frac{\sigma_y^2}{s_i^2} - \sigma_t^2\right)$$

**推导**：这条件分布可严格推导。频谱域中 `x̄_0^i` 后验分布：

$$p(\bar{x}_0^i | \bar{y}_i) \propto p(\bar{y}_i | \bar{x}_0^i)\,p(\bar{x}_0^i)$$

忽略先验 `p(x̄_0^i)` 影响（扩散噪声主导时似然信息量更大），仅考虑似然 `p(ȳ_i | x̄_0^i) = N(ȳ_i; s_i x̄_0^i, σ_y²)`，对 `x̄_0^i` 最大似然估计为 `ȳ_i/s_i`。

时刻 `t-1`，含噪状态 `x̄_{t-1}^i` 分布为 `N(√ᾱ_{t-1} x̄_0^i, σ_{t-1}²)`（先验驱动），或条件化后为关于 `ȳ_i/s_i` 的高斯。两种信息源结合（先验扩散步 + 测量条件化）给方差 `σ_y²/s_i² - σ_t²`——这是测量信息中扣除已被扩散过程解释部分后的剩余方差。

### 3.3 物理解释：从"信任先验"到"信任测量"的过渡

DDRM 三种情况揭示优美物理图像：**随逆向采样从高噪声到低噪声推进，每个频谱分量经历从"信任先验"到"信任测量"过渡**。

固定频谱分量 `i`（固定 `s_i`），随 `t` 从 `T` 减到 `0`：
1. **高噪声阶段**（`t` 大，`σ_t` 大）：`σ_t ≥ σ_y/s_i`，扩散噪声主导→信任测量，用 `ȳ_i/s_i` 作条件均值
2. **低噪声阶段**（`t` 小，`σ_t` 小）：`σ_t < σ_y/s_i`，测量噪声主导→信任先验，用 Tweedie 估计

过渡时间点 `t_i^*` 满足 `σ_{t_i^*} = σ_y/s_i`，即：

$$t_i^* = \arg\min_t \{t : \sigma_t \geq \sigma_y/s_i\}$$

**奇异值 `s_i` 越大分量过渡越早**——因大奇异值意味该分量在测量中被更好保留，测量信息更早变可靠。这解释 DDRM 能自然处理不同频谱分量信噪比差异——条件化策略自动适应每分量信息量。

**奇异值 `s_i = 0` 分量（零空间），始终信任先验**——因测量不提供任何该分量信息，只能依赖先验知识推断。

## 4 DDRM with `η` parameter

### 4.1 随机性控制参数 `η`

DDRM 引入随机性控制参数 `η ∈ (0, 1]`，角色类似 DDIM（第7章 7.4）中 `η`——控制逆向采样过程随机性。

DDRM 逐分量条件化中，`η` 控制条件分布方差：
- `η = 1`：用完整条件方差（上述三种情况方差），实现完全随机采样——后验多样性完整保留
- `η → 0`：条件分布方差趋零，采样过程趋确定——每次运行产生相同结果

### 4.2 `η` 的数学表达

DDRM 带 `η` 条件化公式：

**情况三**（`σ_t ≥ σ_y/s_i`）：

$$p(\bar{x}_{t-1}^i | x_t, y) = \mathcal{N}\!\left(\bar{x}_{t-1}^i;\, \frac{\bar{y}_i}{s_i},\, \eta^2\left(\frac{\sigma_y^2}{s_i^2} - \sigma_t^2\right)\right)$$

**情况一和二**（先验驱动）：

$$p(\bar{x}_{t-1}^i | x_t, y) = \mathcal{N}\!\left(\bar{x}_{t-1}^i;\, \hat{\bar{x}}_{0|t}^i,\, \eta^2\sigma_{t-1}^2\right)$$

### 4.3 `η` 与采样质量关系

`η` 选择影响采样结果多样性和鲁棒性：
- **`η = 1`**：完全随机采样，后验多峰都能探索。适不确定性量化，但单次采样重建质量可能不够好
- **`η ∈ [0.5, 0.85]`**：实践常用范围，多样性和重建质量平衡。与 DDIM 中 `η = 0.5` 或 `0.75` 经验一致
- **`η → 0`**：确定性采样，类似条件 ODE 求解。单次采样重建质量最高，但丧失不确定性量化能力——每次运行产生相同结果

## 5 DDRM vs DPS 在线性问题下对比

### 5.1 数学结构对比

| 维度 | DDRM | DPS |
|---|---|---|
| 条件化方式 | 频谱域逐分量精确条件化 | 原始域全局近似条件化 |
| 似然得分计算 | SVD解耦后直接算 `ȳ_i/s_i` | Tweedie估计 + `A^⊤(y - A(x̂_0))/σ_y²` |
| 近似来源 | 无（线性问题下精确） | delta近似 + Jacobian省略 |
| 对 `A` 要求 | 必须能算SVD | 任意（只需前向 `A` 和反传 `A^⊤`） |
| 零空间处理 | 自然分离（`s_i=0` 分量纯先验） | 隐式（通过先验得分驱动） |
| 计算代价 | SVD预计算 + 频谱域条件化 | 每步一次额外前向/反传 |

### 5.2 精度对比

**线性问题下**，DDRM 条件化精确——频谱域解耦后每个标量子问题条件分布可直接算，无需任何近似。相比 DPS 引入 delta 近似和 Jacobian 省略，理论上不如 DDRM 精确。

实验上，线性逆问题（高斯去模糊、超分辨、inpainting）上 DDRM 通常获比 DPS 更高 PSNR 和更稳定重建——特别测量噪声低场景，DDRM 精确条件化优势更明显。

### 5.3 适用范围对比

**DPS 适用范围更广**：DPS 不要求算子 `A` 有 SVD 分解——只需能算 `A(x̂_{0|t})`（前向）和 `A^⊤(y - A(x̂_{0|t}))`（反传）。这使 DPS 可处理非线性算子 `A`（相位恢复、非线性散射等），而 DDRM 仅适用线性算子。

**DDRM 精度更高**：线性问题下 DDRM 用 SVD 实现频谱域精确条件化，避免 DPS 近似误差。且 DDRM 条件化策略自动适应每频谱分量信噪比——大奇异值分量更早被测量约束，小奇异值分量更依赖先验——这种自适应机制理论上更合理。

### 5.4 计算代价对比

**DDRM 预计算代价**：需算 `A` 的 SVD，对大尺寸算子（`A ∈ R^{m×n}`，`n` 图像像素数）SVD 复杂度 `O(min(m,n)² max(m,n))`。特定算子（模糊算子循环卷积结构）可利用 FFT 加速 SVD。但一般 SVD 计算代价限制 DDRM 在大规模问题应用。

**DPS 逐步代价**：每步需一次 `A` 前向传播和一次 `A^⊤` 反传。具快速算法算子（CT 的 Radon 变换、模糊的 FFT 卷积）这些操作计算量远小于 SVD。

**总结**：DDRM 适中等规模、线性算子有快速 SVD 场景；DPS 适大规模或非线性算子场景。两者在线性问题互补，选取决于算子结构和问题规模。

### 5.5 统一视角

从后验得分分解角度，DDRM 和 DPS 差异可统一理解：

$$\nabla_{x_t}\log p(x_t|y) = \underbrace{\nabla_{x_t}\log p(x_t)}_{\text{先验得分（两者相同）}} + \underbrace{\nabla_{x_t}\log p(y|x_t)}_{\text{似然得分（近似策略不同）}}$$

- **DDRM**：通过 SVD 在频谱域精确算 `∇_{x_t}log p(y|x_t)`，但仅限线性 `A`
- **DPS**：通过 Tweedie 近似算 `∇_{x_t}log p(y|x_t)`，但适用任意 `A`

两者先验得分完全相同（同预训练扩散模型），差异只在似然得分计算方式——精确但受限 vs 近似但通用。这对比再次印证 13.3.6 节核心论点：**所有条件扩散采样方法本质都在近似 `∇log p(y|x_t)`，差异在近似策略与精度-效率权衡**。

## 附录小结

DDRM 算法 SVD 推导揭示线性逆问题中条件扩散采样特殊结构：**SVD 把向量值问题解耦为标量问题，使精确条件化成为可能**。

DDRM 核心公式总结：

| 条件 | 条件均值 | 条件方差 | 物理含义 |
|---|---|---|---|
| `s_i = 0` | `x̂̄_{0\|t}^i`（Tweedie估计） | `η²σ_{t-1}²` | 零空间：纯先验 |
| `σ_t < σ_y/s_i` | `x̂̄_{0\|t}^i`（Tweedie估计） | `η²σ_{t-1}²` | 测量噪声主导：信任先验 |
| `σ_t ≥ σ_y/s_i` | `ȳ_i/s_i` | `η²(σ_y²/s_i² - σ_t²)` | 扩散噪声主导：信任测量 |

DDRM 局限与 DPS 互补构成第13章方法选择重要维度：算子线性且 SVD 可得时 DDRM 提供更精确条件化；算子非线性或 SVD 不可得时 DPS 提供更灵活近似方案。
