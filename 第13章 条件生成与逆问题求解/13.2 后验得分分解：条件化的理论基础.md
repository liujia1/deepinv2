# 13.2 后验得分分解：条件化的理论基础

> 上一节我们把等式立起来了：**条件扩散采样 = 逆问题求解**。但"等式成立"和"怎么算"是两回事。这一节我们干两件事：第一，证明条件采样其实就是把无条件采样的得分函数换一项；第二，直面那个尴尬的事实——换进来的那一项（似然得分）恰恰算不出来。然后你会发现，第5章的 Tweedie 等式又一次来救场。

---

## 本节 roadmap

- 看清"条件逆向 SDE"和无条件版本长得一模一样，差别只在那一个得分替换；
- 跟着三行推导拿下**后验得分分解定理**，并理解它把逆问题拆成"先验"+"似然"两个子问题；
- 弄明白**似然得分为什么算不出**（一个对 `x₀` 的不可解积分）；
- 看 Tweedie 等式如何当"桥梁"，把"得分 → 去噪估计 → 一致性梯度 → 修正得分"串成一条闭环。

## 13.2.1 条件逆向 SDE 的推导

### 回顾：无条件正向 SDE 与逆向 SDE

第7章搭了扩散模型的 SDE 框架。正向 SDE 描述从数据到噪声的连续过程：

$$dx = f(x,t)\,dt + g(t)\,dw$$

`f(x,t)` 是漂移函数，`g(t)` 是扩散系数，`w` 是标准布朗运动。选不同的 `f`、`g`，就覆盖 VE-SDE（`f=0`，`g(t)=√(d[σ(t)²]/dt)`）和 VP-SDE（`f(x,t)=-β(t)/2·x`，`g(t)=√β(t)`）两种经典设定。

Anderson (1982) 的逆向时间 SDE 定理（第7章 7.3）给出从噪声回数据的方程——**无条件逆向 SDE**：

$$\boxed{dx = \left[f(x,t) - g(t)^2\,\nabla_x\log p_t(x)\right]\,dt + g(t)\,d\bar{w}}$$

`p̄w` 是逆向时间的布朗运动，`p_t(x)` 是正向过程在时刻 `t` 的边际分布。这个方程里，**得分函数 `∇log p_t(x)` 是唯一需要从数据里学的量**——第6章 DSM 和第11~12章 VLB 训的都是它。

无条件逆向 SDE 的采样：从纯噪声 `x_T ~ p_T(x)` 出发，逐步解回 `t=0`，拿到数据分布 `p_0(x)=p_data(x)` 的样本。这样生成的图"像训练数据"，但没法保证满足特定条件约束。

### 引入条件：条件逆向 SDE

现在的核心问题：给定观测 `y`（比如 `y = A(x) + n`），怎么从**条件分布** `p(x|y)` 而不是无条件分布 `p(x)` 里采样？

答案出人意料地简洁：**条件逆向 SDE 的形式和无条件的一模一样，只需把无条件得分换成条件得分**。

$$\boxed{dx = \left[f(x,t) - g(t)^2\,\nabla_x\log p_t(x|y)\right]\,dt + g(t)\,d\bar{w}_y}$$

`d\bar{w}_y` 表示以观测 `y` 为条件的逆向时间布朗运动。

这个替换的推导是直接的。Anderson 的逆向 SDE 定理本身不要求正向 SDE 的边际分布是 `p_t(x)`——它对任意由正向 SDE 产生的边际分布都成立。当我们把采样目标从 `p(x)` 换成 `p(x|y)`，只需把边际分布的得分从 `∇log p_t(x)` 换成 `∇log p_t(x|y)`，SDE 的数学结构完全不变。

**关键洞察**：SDE 的形式不变——漂移项 `f(x,t)` 和扩散系数 `g(t)` 完全由正向过程决定，跟条件化无关。条件化的全部效果都浓缩在那一次得分函数的替换里。换言之，**条件得分 `∇log p_t(x|y)` 是我们唯一需要新算的量**。

### 物理直觉

无条件采样 vs 条件采样，区别可以这样感受：

- **无条件采样**：画"像训练数据的图"——轨迹被得分 `∇log p_t(x)` 拉向数据分布的高密度区；
- **条件采样**：画"像训练数据**且**和 `y` 一致的图"——轨迹被条件得分 `∇log p_t(x|y)` 同时拉向两个方向：数据分布高密度区（先验知识）+ 与观测一致的区域（测量约束）。

这个直觉正好坐实了"从 `p(x|y)` 采样 = 解逆问题"：第1章说逆问题的贝叶斯解是 `p(x|y) ∝ p(y|x)p(x)`，而条件逆向 SDE 恰好给出了从 `p(x|y)` 采样的算法——把逆问题求解变成扩散采样里的一次得分替换。

但关键问题来了：条件得分 `∇log p_t(x|y)` 怎么算？无条件得分 `∇log p_t(x)` 已经从预训练扩散模型拿到，条件得分还没有。后验得分分解定理给出答案。

## 13.2.2 后验得分分解定理

### 定理陈述

**后验得分分解定理**：条件得分 `∇_{x_t}log p(x_t|y)` 可拆成先验得分 + 似然得分：

$$\boxed{\nabla_{x_t}\log p(x_t|y) = \nabla_{x_t}\log p(x_t) + \nabla_{x_t}\log p(y|x_t)}$$

这正是 Chung et al. (2023) 公式(3) 的核心，也是条件扩散采样解逆问题的**理论基石**。

### 第一项：先验得分 `∇_{x_t}log p(x_t)`

先验得分编码"数据长什么样"——它指向数据分布 `p(x)` 的高密度区。在扩散模型里，先验得分正是第6~7章训的目标：

$$s_\theta(x_t, t) \approx \nabla_{x_t}\log p_t(x_t)$$

这个近似来自去噪得分匹配（DSM）或等价的变分下界（VLB）训练。**预训练扩散模型已经给了先验得分——不用任何额外训练。**

它的物理角色是"先验知识的驱动力"：把采样轨迹拉向"像真图"的区域，防止漂移到数据分布的低密度区。这和第5章 PnP-ULA 里先验梯度 `∇log p(x)` 的角色完全一致——区别只是扩散模型用多尺度得分给了更精确的先验。

### 第二项：似然得分 `∇_{x_t}log p(y|x_t)`

似然得分编码"和观测 `y` 的一致性"——它指向让观测 `y` 更可能出现的方向。在逆问题 `y = A(x) + n` 语境下，它把轨迹拉回"和测量数据一致"的区域。

**似然得分算不出来**——这是本节后面要细扒的核心困难，也是 13.3 节所有近似方法要解决的终极问题。所有方法的差异，本质上都在于怎么近似 `∇_{x_t}log p(y|x_t)`。

它的物理角色是"数据一致性的驱动力"：每步采样都加一个修正力，让生成的图不仅"像真图"，而且"和观测一致"。这个力的大小和方向决定条件信息的强度和精度。

### 证明（可跳过）

证明是贝叶斯定理在得分函数层面的直接应用，三行就完事：

**第一步**：由贝叶斯定理写条件分布

$$p(x_t|y) = \frac{p(y|x_t)\,p(x_t)}{p(y)}$$

**第二步**：两边取对数

$$\log p(x_t|y) = \log p(y|x_t) + \log p(x_t) - \log p(y)$$

**第三步**：对 `x_t` 求梯度。由于 `p(y)` 不依赖 `x_t`，`∇_{x_t}log p(y) = 0`：

$$\nabla_{x_t}\log p(x_t|y) = \nabla_{x_t}\log p(y|x_t) + \nabla_{x_t}\log p(x_t)$$

证明的简洁令人惊叹——三行推导就把条件得分拆成两个独立项。但这简洁背后有深意：`∇log p(y)=0` 能成立，是因为边际似然 `p(y)` 相对 `x_t` 是常数。正是这个"常数无关性"，让得分函数天然绕过了贝叶斯公式里归一化常数的计算困难——和第5~6章得分匹配绕过配分函数的逻辑一模一样。

### 核心洞察：逆问题被拆成两个子问题

后验得分分解把逆问题求解拆成两个能分开处理的子问题：

| 子问题 | 对应项 | 状态 | 来源 |
|---|---|---|---|
| "数据长什么样？" | `∇log p(x_t)` | **已解决** | 预训练扩散模型（第6~7章） |
| "和观测 `y` 是否一致？" | `∇log p(y\|x_t)` | **未解决** | 需要近似（13.3节） |

这个拆解的意义：**我们不用为每个逆问题重训一个扩散模型**。预训练模型给的先验得分是通用的——同一个先验得分能配不同的似然得分，解不同的逆问题。这正是扩散解逆问题"零样本"优势（13.1节）的数学基础。

同时它也点明了本章核心技术挑战：**怎么近似算似然得分 `∇log p(y|x_t)`**。所有条件扩散采样方法（DPS、ΠGDM、DDRM、DiffPIR…）的差异，本质上都来自对这个不可解量的不同近似策略。要理解似然得分为啥算不出，是看懂所有近似方法的前提。

## 实验 13.2-1：后验得分分解定理验证

实验 `13.2-1.py` 演示**1D高斯混合先验下，后验得分分解定理的数值验证**，通过三个独立计算的量验证 `∇log p(x_t|y) = ∇log p(x_t) + ∇log p(y|x_t)` 的精确性。

### 实验场景

实验考虑1D去噪问题：`y = x + n`，`σ_y = 0.5`，观测值 `y = 0.5`。先验分布为1D高斯混合 `p(x) = 0.3·N(-2, 1) + 0.7·N(1, 1)`，使用VP-SDE框架。

验证方法采用**三个独立计算的量**进行双边验证：

1. **先验得分** `∇log p(x_t)`：由VP-SDE边际分布的解析解直接计算
2. **似然得分** `∇log p(y|x_t)`：对归一化的 `p(y|x_t)` 做中心有限差分，其中 `p(y|x_t) = ∫ p(y|x_0)p(x_0|x_t)dx_0` 通过数值积分计算
3. **后验得分** `∇log p(x_t|y)`：独立对联合概率 `p(x_t, y) = p(x_t)·p(y|x_t)` 做有限差分（`∇log p(y)` 不依赖 `x_t`，故 `∇log p(x_t|y) = ∇log p(x_t, y)`）

验证在中心区域 `|x_t| < 3` 内进行，排除尾部 `p(x_t) → 0` 处的数值噪声。

### 实验目的

1. **数值验证后验得分分解定理**：确认 `∇log p(x_t|y) = ∇log p(x_t) + ∇log p(y|x_t)` 在多个噪声水平 `t` 下精确成立
2. **揭示归一化常数 `p(y)` 的梯度为零**：这是得分函数天然绕过配分函数的核心机制
3. **验证三个独立计算路径的一致性**：先验得分（解析解）、似然得分（有限差分）、后验得分（独立有限差分）三路独立计算，确保验证的可靠性

### 实验输入

|------|------|
| 先验分布 | 1D高斯混合：`0.3·N(-2, 1) + 0.7·N(1, 1)` |
| 噪声调度 | VP-SDE，`β_min=0.1`，`β_max=20.0` |
| 逆问题 | 去噪：`y = x + n`，`σ_y = 0.5`，`y_obs = 0.5` |

## 13.2.3 似然得分 `∇log p(y|x_t)` 的计算挑战

### 不可直接计算的原因

似然得分看起来只是个梯度——为啥算不出？因为 `p(y|x_t)` 本身就是个不可解的积分。

由全概率公式，`p(y|x_t)` 可以展开：

$$p(y|x_t) = \int p(y|x_0)\,p(x_0|x_t)\,dx_0 = \mathbb{E}_{x_0 \sim p(x_0|x_t)}[p(y|x_0)]$$

这个展开暴露了不可解性的两个来源：

**来源一**：`p(x_0|x_t)` 没有闭式表达。后验 `p(x_0|x_t)` 是"给定含噪状态 `x_t` 时干净数据 `x_0` 的条件分布"。虽然正向转移核 `p(x_t|x_0)` 是简单高斯（SDE 结构保证），但逆向核 `p(x_0|x_t)` 依赖数据分布 `p(x_0)` 的结构，一般没有闭式。

**来源二**：即便 `p(y|x_0)` 很简单，积分仍不可解。最常见的线性高斯测量 `y = Ax + n`，`n ~ N(0, σ_y²I)` 下，似然 `p(y|x_0) = N(y; Ax_0, σ_y²I)` 是个简单高斯。但被复杂的后验 `p(x_0|x_t)` 加权积分后，结果还是不可解——因为 `p(x_0|x_t)` 的复杂性让积分化不开。

**根本原因**：`x_t` 到 `y` 的关系不是直接的——`x_t` 得先"去噪"到 `x_0`，再经正向模型 `A` 映射到测量空间。这条"去噪→映射"的两步链让 `p(y|x_t)` 没法直接算，必须通过对 `x_0` 的积分 `p(x_0|x_t)` 来搭桥。

> **类比**：你只知道"某个被严重打码的人"和"这个人是公安局档案里的人"。想知道"打码图 `x_t` 和证据 `y` 有多一致"，你得先脑补出"打码图对应哪个清晰人脸 `x_0`"，再把清晰脸拿去比对证据。可"脑补"本身是个概率分布（同一个打码图可能对应好几个清晰脸），所以你得对**所有可能的清晰脸**求平均——这就是那个化不开的积分 `∫ p(y|x_0)p(x_0|x_t)dx_0`。

### Tweedie 等式的关键角色

虽然 `p(x_0|x_t)` 没闭式，但第5章的 **Tweedie 等式**给了它后验均值的闭式表达。这个后验均值是所有近似方法的共同起点。

**Tweedie 等式**（第5章 5.3，Chung et al. Theorem 1）：在高斯扰动核 `p(x_t|x_0) = N(x_t; s_t x_0, σ_t²I)` 下，后验均值为：

$$\mathbb{E}[x_0|x_t] = \frac{1}{s_t}\left(x_t + \sigma_t^2\,\nabla_{x_t}\log p_t(x_t)\right)$$

VP-SDE 下 `s_t = √ᾱ_t`，`σ_t² = 1 - ᾱ_t`，所以：

$$\mathbb{E}[x_0|x_t] = \frac{x_t + (1-\bar\alpha_t)\,\nabla_{x_t}\log p_t(x_t)}{\sqrt{\bar\alpha_t}}$$

用 ε 预测参数化 `∇_{x_t}log p_t(x_t) = -ε_θ(x_t, t)/√(1-ᾱ_t)`（第11章 11.3），后验均值等价写成：

$$\hat{x}_{0|t} = \mathbb{E}[x_0|x_t] = \frac{x_t - \sqrt{1-\bar\alpha_t}\,\epsilon_\theta(x_t, t)}{\sqrt{\bar\alpha_t}}$$

这个估计 `x̂_{0|t}` 是从含噪状态 `x_t` 出发，对干净数据 `x_0` 的 MMSE（最小均方误差）估计——是扩散模型在时刻 `t` 对"原图长啥样"的最佳猜测。

### Tweedie 闭环：从得分到去噪再到修正得分

Tweedie 等式在似然得分近似里扮演枢纽角色，它搭起一条闭环计算链：

$$\underbrace{\nabla\log p_t(x_t)}_{\text{得分函数}} \xrightarrow{\text{Tweedie}} \underbrace{\hat{x}_{0|t} = \mathbb{E}[x_0|x_t]}_{\text{去噪估计}} \xrightarrow{\text{正向模型}} \underbrace{\nabla_{\hat{x}_{0|t}}\ell(\hat{x}_{0|t})}_{\text{一致性梯度}} \xrightarrow{\text{链式法则}} \underbrace{\nabla_{x_t}\log p(y|x_t)}_{\text{似然得分近似}}$$

闭环怎么转：

**第一步：得分函数 → 去噪估计。** 由 Tweedie 等式，预训练得分 `s_θ(x_t, t) ≈ ∇log p_t(x_t)` 直接变成去噪估计 `x̂_{0|t}`。这是先验得分的"副产品"——本来就有得分，Tweedie 免费给出去噪估计。

**第二步：去噪估计 → 一致性梯度。** 有了 `x̂_{0|t}`，经正向模型算测量预测 `A(x̂_{0|t})`，再算数据一致性损失 `ℓ(x̂_{0|t}) = ‖y - A(x̂_{0|t})‖²/(2σ_y²)` 及其梯度 `∇_{x̂_{0|t}}ℓ(x̂_{0|t})`。

**第三步：一致性梯度 → 似然得分近似。** 链式法则把关于 `x̂_{0|t}` 的梯度回传到 `x_t`，得到似然得分 `∇_{x_t}log p(y|x_t)` 的近似。

**第四步：似然得分近似 → 修正得分。** 近似后的似然得分加回先验得分，得到修正后的条件得分 `∇log p(x_t|y) ≈ ∇log p(x_t) + ∇log p(y|x_t)`，驱动条件逆向 SDE 的下一步。

**第五步：回到第一步。** 新采样步产生新 `x_t`，重算得分和去噪估计，循环。

这条闭环和第5章遥相呼应——第5章 Tweedie 连接去噪器和得分函数，实现"去噪→得分→采样"；条件扩散里 Tweedie 进一步连接去噪估计和似然得分，实现"得分→去噪→一致性→修正得分"。这正是 DPS 及其衍生算法的核心机制——13.3 节细展开。

### 去噪估计 `x̂_{0|t}` 的双重角色

`x̂_{0|t}` 在这条闭环里身兼两职：

1. **先验信息的载体**：它编码了扩散模型对"原图长啥样"的最佳估计，是先验知识的集中体现；
2. **似然得分的计算桥梁**：它把不可解积分 `p(y|x_t) = ∫ p(y|x_0)p(x_0|x_t)dx_0` 变成可算的近似 `p(y|x̂_{0|t})`——用单点估计代替了整个积分。

所有近似方法——DPS 的 delta 函数近似 `p(x_0|x_t) ≈ δ(x_0 - x̂_{0|t})`、ΠGDM 的各向同性高斯近似 `p(x_0|x_t) ≈ N(x̂_{0|t}, r_t²I)`、Moment Matching 的完整协方差近似 `p(x_0|x_t) ≈ N(x̂_{0|t}, Var[x_0|x_t])`——都以 `x̂_{0|t}` 为起点。差别只在对 `p(x_0|x_t)` 分布形状的近似精度。

从 delta 函数到各向同性高斯再到完整协方差，近似精度逐步提升，计算代价也逐步增加。这种精度-效率权衡，构成了 13.3 节方法分类的核心维度。

后验得分分解把条件扩散采样的核心挑战定位为似然得分 `∇log p(y|x_t)` 的近似计算，而 Tweedie 等式把这一挑战转化为对 `p(x_0|x_t)` 的近似问题——所有方法都以去噪估计 `x̂_{0|t}` 为共同起点。系统梳理四类近似方法，从最简单的 DPS 到渐近精确的 MCMC 方法，能揭示它们在近似策略和精度-效率权衡上的差异。

## 实验 13.2-2：DPS的Tweedie闭环验证

实验 `13.2-2.py` 演示**DPS近似似然得分与精确似然得分的对比**，验证Tweedie闭环中delta函数近似的精度，以及含/忽略Jacobian项两种DPS变体的误差特征。

### 实验场景

实验考虑1D去噪问题：`y = x + n`，`σ_y = 0.5`，`y = 0.5`。先验为1D高斯混合，使用VP-SDE框架。

DPS的核心近似是将不可解的积分 `p(y|x_t) = ∫ p(y|x_0)p(x_0|x_t)dx_0` 用delta函数近似 `p(x_0|x_t) ≈ δ(x_0 - x̂_{0|t})` 坍缩为单点求值：

$$p(y|x_t) \approx p(y|\hat{x}_{0|t})$$

其中 `x̂_{0|t}` 由Tweedie等式给出。由此得到两种DPS似然得分近似：

- **含Jacobian项**：`∇_{x_t}log p(y|x_t) ≈ (∂x̂_{0|t}/∂x_t) · ∇_{x̂_{0|t}}log p(y|x̂_{0|t})`
- **忽略Jacobian项**：`∇_{x_t}log p(y|x_t) ≈ ∇_{x̂_{0|t}}log p(y|x̂_{0|t})`（简化版，实践中更常用）

### 实验目的

1. **验证Tweedie闭环的精度**：对比DPS近似似然得分与精确似然得分，揭示delta函数近似的误差特征
2. **比较含/忽略Jacobian项的误差**：量化Jacobian项对近似精度的贡献
3. **揭示误差随噪声水平 `t` 的变化规律**：高噪声时Tweedie估计不可靠，DPS近似误差增大

### 实验输入

| 参数 | 设置 |
|------|------|
| 先验分布 | 1D高斯混合：`0.3·N(-2, 1) + 0.7·N(1, 1)` |
| 噪声调度 | VP-SDE，`β_min=0.1`，`β_max=20.0` |
| 逆问题 | 去噪：`y = x + n`，`σ_y = 0.5`，`y_obs = 0.5` |
| 验证时刻 | `t = 0.3`（似然得分对比），`t ∈ [0.05, 0.95]`（误差扫描） |
| 精确似然得分 | 对 `p(y\|x_t)` 数值积分 + 有限差分 |

### 预期结果

- DPS近似的似然得分方向正确（正负号一致），但幅度存在偏差
- 含Jacobian项的DPS近似精度优于忽略Jacobian项的简化版
- 高噪声时（`t` 大），Tweedie估计 `x̂_{0|t}` 不可靠，DPS近似误差增大——这解释了DPS在高噪声步需要更小引导权重 `ζ` 的实践策略

#### 核心知识点

本实验验证了13.2.3节Tweedie闭环的近似精度，揭示了DPS的核心局限：

1. **delta函数近似的精度-效率权衡**：DPS用单点 `x̂_{0|t}` 替代整个积分 `p(x_0|x_t)`，计算高效但引入幅度偏差。更精确的近似（ΠGDM的各向同性高斯、Moment Matching的完整协方差）以更高计算代价换取更高精度
2. **Tweedie估计的双重角色**：`x̂_{0|t}` 既是先验信息的载体（"图像长什么样"），也是似然得分的计算桥梁（"与观测是否一致"）。当Tweedie估计不可靠时（高噪声），两个角色的精度同时下降
