# 10.0 本章导读：从一步编码到逐步加噪

> **路线定位**：这是变分路径（variational path，从"优化后验近似"出发的路线）的第三步，也是最关键的一跃。第9章的 VAE（变分自编码器，用一个编码器把数据压成潜变量、再用解码器还原的模型）相当于采样路径里第6章的得分匹配。而本章要做的，相当于第6章把"单尺度得分"扩展成"多尺度得分"——两条路都在往"从单步到多步"这个方向走。真正戏剧性的转折在章末：当层级VAE的编码器被固定成"高斯加噪"时，它和扩散模型的正向过程一模一样——变分路径第一次和采样路径的终点（第7章的扩散 SDE）握手了。

---

## 先讲一个反直觉的事

你大概率听过扩散模型（diffusion model，一类靠"加噪声—去噪声"来生成图片的模型）：先给一张清晰的猫图一步步加噪声，直到变成一团高斯白噪；再训练一个网络从噪声里把猫一步步"洗"出来。听着像个独立的黑魔法。

而第9章我们讲的 VAE，是另一回事：一个编码器把图片压成一个潜变量（latent variable，藏在数据背后、看不见的随机变量），一个解码器再把它还原。

**这两样东西，其实是同一家人的两个名字。**

先别急着反驳。我让你猜个数：把 VAE 的"单层潜变量"改成"无穷多层潜变量"，并且让每一层的编码动作退化成"往上一层结果里加一点点高斯噪声"——你猜这个无穷层级的 VAE，极限下会变成什么？

（先想两秒。）

答案是：**它就是扩散模型。** 编码器那无数个"加一点噪"的小动作，连起来正好是扩散的正向过程（forward process，逐步加噪的链路）；解码器那无数个"去一点噪"的小动作，连起来正好是扩散的逆向过程（reverse process，逐步去噪的链路）。"单层 VAE"和"扩散模型"之间，差的只是"把一步拆成无穷小步"这件事。

本章要带你亲眼看见这个"殊途同归"。这不只是猎奇——它意味着扩散训练根本不是凭空冒出来的技巧，而是变分推断（variational inference，用简单分布去近似难算后验的一类方法）在"层级 + 高斯"假设下的自然极限。

---

## 本章你要带走的四样东西

读完这一章，你应该能：

- **说清为什么单层 VAE 不够用**：为什么"一步把数据压成潜变量"会撞上表达能力的天花板。
- **写出层级 ELBO**（evidence lower bound，证据下界，对数似然的一个可计算的低估）：它是由单层 ELBO 自然推广来的，每一层多一个 KL 散度项。
- **看懂"高斯编码器 = 加噪过程"这个机关**：当编码器的每一步变成固定高斯转移时，层级 VAE 怎么就变成了扩散模型，以及 VLB（variational lower bound，变分下界，扩散版的 ELBO）怎么拆成三项。
- **理解 L→∞ 的连续极限**：层级数趋于无穷时，离散的马尔可夫链（Markov chain，每一步只依赖上一步的随机过程）是怎么变成连续 SDE（stochastic differential equation，随机微分方程，用漂移项和布朗运动描述连续随机演化的方程）的。

## 我们的路线图（因果链）

我们顺着一条"因为…所以…"的线走，绝不在半路丢下你：

1. **从 VAE 到层级 VAE（10.1）**：单层潜变量有表达瓶颈 → 把潜变量拆成多层 $z_1,\ldots,z_L$，构成一条马尔可夫链 → 推导层级 ELBO，它是单层 ELBO 每多一层就多一个 KL 项。
2. **扩散过程的变分下界推导（10.2）**：编码器的每一步若取成高斯转移 $q(x_t|x_{t-1})=\mathcal{N}(\sqrt{\alpha_t}\,x_{t-1},(1-\alpha_t)I)$ → 编码就成了逐步加噪 → 把层级 ELBO 翻译成扩散的 VLB，并给出前向过程后验的闭式解。
3. **从 VLB 到去噪训练（10.3）**：VLB 的核心项可化简成"均值匹配" → 等价于从带噪图预测干净图（去噪）→ 三种等价参数化与简化目标 $L_{\text{simple}}$。
4. **层级 VAE → 扩散的极限（10.4）**：当层级数 $L\to\infty$ → 离散链变成连续 SDE → 编码 ↔ 加噪、解码 ↔ 去噪，两条视角彻底统一。

```
VAE 单层局限(10.1) → 层级 ELBO 推导(10.1) → 高斯编码器=加噪(10.2)
      → VLB 概念框架(10.2) → 均值匹配与参数化预告(10.3) → L→∞→扩散 SDE(10.4)
```

## 一个贯穿全章的信念更新视角

贝叶斯（Bayes，用"先验 + 证据"不断更新信念的框架）的核心是**信念随证据而变**。本章我们也会用到这个视角，只是主角换成了"潜变量"：

- **先验**（prior，编码前你对潜变量的默认信念，通常取标准高斯 $\mathcal{N}(0,I)$）：在没有看到数据时，你认为潜变量长什么样。
- **似然**（likelihood，看到数据后，数据在给定潜变量下出现的概率 $p(x|z)$）：数据对潜变量的"投票"。
- **后验**（posterior，把先验和似然结合后，你对潜变量的修正信念 $p(z|x)$）：看见图之后，你判断它最可能对应哪个潜变量。
- **证据**（evidence，数据本身的边际概率 $p(x)$，也叫配分常数）：它只是个归一化因子，让所有后验概率加起来等于 1。

单层 VAE 想用一个高斯去近似后验，但真实后验往往是多模态的（同一个图可以对应好几种合理的编码）——单高斯兜不住，这就是第9章埋下的坑。本章的办法是：**别逼一步到位，让每一层只修正一小点信念**，于是"信念更新"被分散到一条长长的链上，每一步都轻松了。这也是为什么层级结构能缓解"KL 塌陷"（KL collapse，KL 项归零、潜变量失去信息）等老问题。

## 一句话先记在心里

**扩散模型不是天降神兵，而是 VAE 在"层级结构 + 高斯转移 + 无穷层"假设下的自然极限。** VAE 编码器每一步加噪，就是扩散的正向过程；解码器每一步去噪，就是扩散的逆向过程——两者是同一数学对象的不同说法。本章搭好这座桥的概念骨架，下一章（第11章）再把 VLB 落成完整的训练算法。而这座桥，正是第12章"Score ≡ ELBO"（得分匹配等价于变分下界）统一论的变分侧基石：采样路径从得分匹配走到扩散，变分路径从 ELBO 走到扩散，两条线即将汇合。
