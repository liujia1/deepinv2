# 10.4 层级 VAE → 扩散的极限

> **核心观点**：当层级数 $L\to\infty$，每步变换量 $\to 0$，离散的层级 VAE 就趋于连续的扩散过程。编码链变成正向 SDE（stochastic differential equation，随机微分方程，用漂移项 + 布朗运动描述连续随机演化），解码链变成逆向 SDE。这是变分路径的终点——从优化后验近似出发，经层级 VAE，自然抵达与第7章 SDE 视角相同的扩散模型。

---

## Hook：把"一步"切得足够细，VAE 就熔化成了扩散

还记得 10.1 我们说：单层 VAE 的毛病是"一步跨太大"。层级 VAE 把它切成 $L$ 步。那如果**把 $L$ 切到无穷多步、每步无穷小**呢？

直觉上，一串"无穷小的高斯小步"连起来，就不再是一串离散跳跃，而是一条**连续滑动的轨迹**。数学上，这条轨迹恰好就是第7章的正向 SDE（加噪）和它的逆向 SDE（去噪）。也就是说：层级 VAE 不是"近似像"扩散，而是在极限意义下**就是**扩散。下面把这条极限走一遍。

---

## 从离散步到连续过程

之前我们一直在离散时间步 $t=1,2,\ldots,T$ 下讨论。现在让 $T\to\infty$。

### 连续时间变量

把离散步 $t=0,1,\ldots,T$ 换成连续时间 $t\in[0,1]$（或 $[0,T]$），离散变量 $x_t$ 变成连续随机过程 $x(t)$。

### 噪声调度的连续化

离散噪声调度 $\beta_1,\ldots,\beta_T$ 对应连续函数 $\beta(t)$。每步加噪量：

$$\beta_t = \beta(t)\cdot\Delta t, \quad \Delta t = 1/T$$

当 $T\to\infty$，$\Delta t\to 0$，每步只加微量噪声 $\beta(t)\Delta t$。对应地：

$$\alpha_t = 1-\beta_t \approx 1-\beta(t)\Delta t$$

$$\bar{\alpha}_t = \prod_{s=1}^{t}\alpha_s \approx \exp\left(-\int_0^t \beta(s)\,ds\right)$$

这里用了 $\log\bar{\alpha}_t=\sum_s\log\alpha_s\approx\sum_s(-\beta_s)\approx-\int_0^t\beta(s)\,ds$。

### 从递推到微分方程

离散递推：

$$\mathbf{x}_t = \sqrt{1-\beta_t}\,\mathbf{x}_{t-1} + \sqrt{\beta_t}\,\boldsymbol{\varepsilon}_{t-1}$$

当 $\beta_t=\beta(t)\Delta t$ 很小，做泰勒展开 $\sqrt{1-\beta_t}\approx 1-\frac{\beta(t)}{2}\Delta t$、$\sqrt{\beta_t}\approx\sqrt{\beta(t)\Delta t}$，代入得：

$$\mathbf{x}(t+\Delta t) = \mathbf{x}(t) - \frac{\beta(t)}{2}\mathbf{x}(t)\Delta t + \sqrt{\beta(t)\Delta t}\,\boldsymbol{\varepsilon}_t$$

当 $\Delta t\to 0$，$\sqrt{\Delta t}\,\varepsilon_t\to d\mathbf{W}(t)$（布朗运动，Brownian motion，连续时间的随机游走增量），得到连续极限：

$$\boxed{d\mathbf{x} = -\frac{\beta(t)}{2}\mathbf{x}\,dt + \sqrt{\beta(t)}\,d\mathbf{W}}$$

这正是第7章 7.2 节的正向 SDE——**方差保持 SDE（VP-SDE）**。这一转变意味着，之前"加噪"这个离散动作，在极限下被重新表达为一条由漂移项与随机扩散项组成的连续演化律——同一物理过程，由求和变成了积分。

---

## 正向 SDE：编码链的连续极限

### VP-SDE 回顾

$$d\mathbf{x} = -\frac{\beta(t)}{2}\mathbf{x}\,dt + \sqrt{\beta(t)}\,d\mathbf{W}$$

- **漂移项** $-\frac{\beta(t)}{2}\mathbf{x}$：信号指数衰减，方向指向原点（把图"拉淡"）；
- **扩散项** $\sqrt{\beta(t)}\,d\mathbf{W}$：不断注入噪声。

它的边际分布恰好是已知的：

$$q(\mathbf{x}_t|\mathbf{x}_0) = \mathcal{N}(\mathbf{x}_t; \sqrt{\bar{\alpha}_t}\mathbf{x}_0, (1-\bar{\alpha}_t)\mathbf{I}),\quad \bar{\alpha}(t)=\exp\left(-\int_0^t\beta(s)\,ds\right)$$

### 编码器的连续化解读

- **离散层级 VAE**：编码器是一步步高斯转移 $q(x_t|x_{t-1})$，每步缩放并加噪；
- **连续扩散**：编码器变成 SDE 的演化，每时刻 $dt$ 做微量缩放 + 微量加噪。

连续化没改变编码的本质——还是"逐步加噪"，只是步长从有限变成无穷小。$\bar{\alpha}(t)$ 从离散累积乘积变成连续指数衰减，更精确刻画信号消退。从更深层次看，这一过程可以读作连续的"信念稀释"：信号随时间被噪声一层层冲淡，直到极限处几乎不剩结构。

---

## 逆向 SDE：解码链的连续极限

### 逆向 SDE 的形式

第7章 7.3 节用 Anderson 逆向时间 SDE 定理，从正向 SDE 推出逆向 SDE：

$$d\mathbf{x} = \left[-\frac{\beta(t)}{2}\mathbf{x} - \beta(t)\nabla_{\mathbf{x}}\log q_t(\mathbf{x})\right]dt + \sqrt{\beta(t)}\,d\bar{\mathbf{W}}$$

其中 $d\bar{\mathbf{W}}$ 是逆向时间的布朗运动增量，$\nabla_{\mathbf{x}}\log q_t(\mathbf{x})$ 是边际分布的**得分函数**（score function，$\nabla\log q_t$，对数密度对输入的梯度，指向数据密集方向）。

### 变分视角下的逆向 SDE

- **离散层级 VAE**：解码器 $p_\theta(x_{t-1}|x_t)$，每步按当前状态 + 学到的去噪器预测上一步；
- **连续扩散**：解码器变成逆向 SDE 的演化，方向由得分函数引导。

逆向 SDE 里的得分函数，正好对应离散框架里我们学的去噪器——10.3 节用 $\varepsilon$ 预测学的就是它。换句话说，逆向 SDE 是在连续时间上一步步"重建信念"，把被噪声冲淡的过程倒着走一遍。

### VLB 的连续极限

离散 VLB：$L = L_T + \sum_{t=2}^{T} L_{t-1} + L_0$。当 $T\to\infty$，求和变积分：

$$L_{\text{cont}} = L_T + \int_0^T \ell(t)\,dt + L_0$$

$\ell(t)$ 是连续时间下去噪损失的密度。Kingma et al. (2021) 的 VDM 论文详细推导了连续时间 VLB，形式和离散 VLB 高度一致——核心仍是匹配前向后验与逆向过程的均值。

## 统一视角：编码/解码 ↔ 加噪/去噪

走过"层级扩展 → 高斯特化 → 去噪参数化 → 连续极限"四步，对应关系完全清晰了。

### VAE 与扩散模型的对应总表

| VAE 概念 | 扩散模型概念 | 数学对应 |
|---|---|---|
| 编码器 $q_\phi(z\|x)$ | 正向过程 $q(x_t\|x_{t-1})$ | 逐步高斯转移 |
| 解码器 $p_\theta(x\|z)$ | 逆向过程 $p_\theta(x_{t-1}\|x_t)$ | 逐步去噪转移 |
| 潜变量 $z$ | 中间状态 $x_t$ | 含噪数据 |
| 先验 $p(z)=\mathcal{N}(0,I)$ | 终态分布 $p(x_T)=\mathcal{N}(0,I)$ | 标准高斯 |
| ELBO | VLB | 对数似然下界 |
| 重建项 $\mathbb{E}_q[\log p(x\|z)]$ | $L_0$：终端重建 | 从最低噪声恢复数据 |
| KL 项 $D_{\text{KL}}(q\|p)$ | $L_{t-1}$：一致性项 | 匹配前向后验与逆向过程 |
| 重参数化 $z=\mu+\sigma\varepsilon$ | 直接采样 $x_t=\sqrt{\bar{\alpha}_t}x_0+\sqrt{1-\bar{\alpha}_t}\varepsilon$ | 噪声注入 |

![图 10.2 编码/解码 ↔ 加噪/去噪 对照图：层级 VAE 与扩散模型的统一视角](./编码解码对照加噪去噪.png)

*图 10.2：左栏层级 VAE（编码 $q(z_l|z_{l-1})$ 自底向上、解码 $p(z_l|z_{l+1})$ 自顶向下），右栏扩散（正向 $q(x_t|x_{t-1})$ 加噪、逆向 $p_\theta(x_{t-1}|x_t)$ 去噪）。中间桥接表明：在高斯转移 + 编码器固定 + 层数 $T\to\infty$ 下，左栏的编码/解码正是右栏的正向/逆向——同一数学对象的不同表述。*

### 关键差异（别忽视）

结构对应完美，但扩散和 VAE 有三点根本不同：

1. **编码器不学**：VAE 编码器是参数化网络；扩散正向过程由固定调度定义。简化了训练，也限制了前向灵活性。
2. **层数巨大**：VAE 通常 1–3 层；扩散动辄 1000 步。层数的差异是质变的——层数够多才能保证终态近似标准高斯。
3. **每步很简单**：VAE 的编/解码网络可以很复杂；扩散每步只是简单高斯变换。这是"简单变换重复多次" vs "复杂变换一次完成"的哲学差异。

### 变分路径的完整链路

$$\text{ELBO} \xrightarrow{\text{第8章}} \text{VAE} \xrightarrow{\text{第9章}} \text{层级VAE} \xrightarrow{\text{本章}} \text{扩散模型（VLB）}$$

每一步都是自然推广：
- ELBO → VAE：引入变分分布近似后验；
- VAE → 层级 VAE：单层潜变量 → 多层马尔可夫链；
- 层级 VAE → 扩散：高斯转移 + 编码器固定 + 层数巨大 → 连续极限。

### 与采样路径的对照

采样路径（Part II）：
$$\text{MCMC} \xrightarrow{\text{第4章}} \text{Langevin} \xrightarrow{\text{第5章}} \text{Score} \xrightarrow{\text{第6章}} \text{Diffusion (SDE)} \xrightarrow{\text{第7章}}$$

两条路都抵达了扩散，但视角不同：
- **采样路径**从"怎么从后验采样"出发，经得分函数利用，到多步扩散采样；
- **变分路径**从"怎么近似后验"出发，经 ELBO 优化和层级扩展，到变分训练目标。

两者的核心等价——**DSM 损失 ≡ VLB**——将在第12章严格证明。这不仅形式上等价，更揭示一个深刻统一：**得分匹配和变分推断是同一枚硬币的两面**。

## 实验 10.4-1：层级 VAE → 扩散的连续极限

实验 `10.4-1.py` 验证**离散层级过程到连续扩散过程的极限**，展示 VP-SDE 边际分布，以及"编码器固定 → 不用训推断网络"的特性。

### 实验场景

- **离散→连续极限**：当 $L\to\infty$，离散乘积 $\prod_{i=1}^L(1-\beta/L)$ 收敛到连续指数 $\exp(-\beta t)$。
- **VP-SDE 形式**：前向 $d\mathbf{x}=-\frac{\beta(t)}{2}\mathbf{x}dt+\sqrt{\beta(t)}d\mathbf{W}$，边际 $\bar{\alpha}(t)=\exp(-\int_0^t\beta(s)ds)$。
- **边际分布演化**：离散层级 → VP-SDE 连续极限，编码器固定无需训练。

### 实验目的

1. 验证离散→连续极限（$L$ 增大，离散乘积逼近连续指数）；
2. 展示 VP-SDE 边际分布公式的解析性；
3. 验证边际分布演化的连续极限（KL 积分随 $L$ 收敛）；
4. 展示"层级 VAE → 扩散 → VP-SDE"的统一框架（编码器固定，只优化解码器）。

### 实验输入

| 参数 | 设置 |
|------|------|
| 噪声调度 | 线性，$\beta_{\min}=10^{-4}$，$\beta_{\max}=0.02$ |
| 层级数验证 | $L\in\{5,10,50,100,500,1000\}$ |
| 总噪声强度 | $\beta_\text{total}=1.0$ |
| 数据分布 | 2 维高斯混合 |

### 预期结果

- $L$ 增大，离散 $\bar{\alpha}_L$ 逼近连续 $\exp(-\beta t)$，相对误差递减；
- VP-SDE 边际公式解析可算；
- KL 积分随 $L$ 增大收敛到约 0.42；
- 扩散 = 固定编码器的层级 VAE 连续极限，编码器无需训练。

#### 步骤2：VP-SDE 形式推导

- **前向 SDE**：$d\mathbf{x}=-\frac{\beta(t)}{2}\mathbf{x}dt+\sqrt{\beta(t)}d\mathbf{W}$
- **边际分布**：$q(x_t|x_0)=\mathcal{N}(\sqrt{\bar{\alpha}(t)}x_0,(1-\bar{\alpha}(t))I)$，$\bar{\alpha}(t)=\exp(-\int_0^t\beta(s)ds)$
- **逆向 SDE**：由得分函数驱动 $d\mathbf{x}=[-\frac{\beta(t)}{2}x-\beta(t)s_\theta(x,t)]dt+\sqrt{\beta(t)}d\bar{\mathbf{W}}$；或由 $\varepsilon$ 预测驱动 $d\mathbf{x}=[-\frac{\beta(t)}{2}x+\frac{\beta(t)}{\sqrt{1-\bar{\alpha}(t)}}\hat{\varepsilon}_\theta(x,t)]dt+\sqrt{\beta(t)}d\bar{\mathbf{W}}$
- **概率流 ODE**（Probability Flow ODE，去掉随机项得确定性 ODE）：$d\mathbf{x}=[-\frac{\beta(t)}{2}x-\frac{\beta(t)}{2}s_\theta(x,t)]dt$，用于确定性采样和似然计算。

#### 步骤3：边际分布演化与连续极限

**层级 VAE → 扩散 → VP-SDE 对应表**：

| 层级 VAE 概念 | → | 扩散模型概念 |
|-----------|---|-----------|
| 编码器 $q(z_l\|z_{l-1})$ | → | 前向加噪 $q(x_t\|x_{t-1})$ |
| 解码器 $p(z_{l-1}\|z_l)$ | → | 反向去噪 $p_\theta(x_{t-1}\|x_t)$ |
| 隐变量 $z_l$ | → | 噪声状态 $x_t$ |
| 先验 $p(z_L)$ | → | 先验 $p(x_T)=\mathcal{N}(0,I)$ |
| 重参数化 | → | 直接采样 $x_t=\sqrt{\bar{\alpha}_t}x_0+\sqrt{1-\bar{\alpha}_t}\varepsilon$ |
| ELBO | → | VLB |

**关键差异**：层级 VAE 的编码器被学习；扩散的编码器被固定（仅 $\beta_t$ 是超参）；扩散的"推断"无需训练，VLB 只优化解码器（去噪网络）。

**KL 积分随 $L$ 收敛**：

| $L$ | KL 积分估计 | 每步 $\beta$ |
|-----|-----------|------------|
| 5 | 0.3376 | 0.2 |
| 10 | 0.3784 | 0.1 |
| 50 | 0.4112 | 0.02 |
| 100 | 0.4153 | 0.01 |

$L$ 增大 → 积分收敛到约 0.42，体现离散求和 → 连续积分的数值稳定性。

#### 核心知识点总结

1. **离散→连续极限**：当 $L\to\infty$，$\prod_{i=1}^L(1-\beta/L)\to\exp(-\beta t)$，是 VP-SDE 基础。
2. **VP-SDE 形式**：前向 SDE、边际 $\bar{\alpha}(t)$、逆向 SDE（得分或 $\varepsilon$ 驱动）。
3. **边际分布演化**：扩散 = 固定编码器的层级 VAE 连续极限，只优化解码器。
4. **三者统一**：层级 VAE（通用、编码器可学）/ 扩散（固定编码器、离散 $T$ 步）/ VP-SDE（$L\to\infty$ 连续极限）。

## 实验 10.4-2：层级 VAE 的前向与逆向过程

实验 `10.4-2.py` 验证**"编码/解码 ↔ 加噪/去噪"的对应机理**，展示层级 VAE 的编码器如何逐层加噪、解码器如何逐层去噪，以及为什么理想解码器可以精确反演、而真实解码器（拿不到 $x_0$）必须借助学到的去噪网络。

### 实验场景

- **编码器=加噪**：$q(x_t|x_{t-1})=\mathcal{N}(\sqrt{1-\beta_t}\,x_{t-1},\beta_t)$，每步乘 $\sqrt{\alpha}$ 缩放 + 加 $\sqrt{\beta}$ 噪声。
- **解码器=去噪**：$p(x_{t-1}|x_t)$ 的目标是正向后验均值 $\tilde\mu_t$，逐层把信号洗回来。
- **理想 vs 不完美**：Oracle 已知 $x_0$，往返精确可逆；不完美解码器需从 $x_t$ 估计 $x_0$，往返出现误差。

### 实验目的

1. 直观展示前向链把干净信号逐步埋进噪声、末态趋于标准高斯；
2. 验证理想解码器（后验均值）与编码链严格可逆，误差≈0 且与 $L$ 无关；
3. 对比不完美解码器（只用 $x_L$ 估计 $x_0$）的往返误差，说明训练去噪网络（10.3 节）的必要性。

### 实验输入

| 参数 | 设置 |
|------|------|
| 数据 | 一维标量 $x_0=1.5$（结论对高维逐分量成立） |
| 总噪声强度 | $\beta_\text{total}=1.0$ |
| 前向演示层级数 | $L\in\{5,50,500\}$ |
| 往返统计层级数 | $L\in\{5,20,100\}$ |
| 解码器类型 | 理想（Oracle 已知 $x_0$） / 不完美（仅用 $x_L$） |
| 采样量 | 每种 $L$ 做 5000 次随机往返 |

### 预期结果

- 前向链逐层加噪，末态接近标准高斯先验；
- 理想解码器往返误差≈0，与 $L$ 无关；
- 不完美解码器往返误差显著非零，且远大于 Oracle——"难点不在层数，而在解码器不知道 $x_0$"。

| 100 | ≈0 |

若解码器知道真 $x_0$，逐层用后验均值 $\tilde\mu_t$ 去噪即严格反演编码链，误差≈机器精度、与 $L$ 无关。这说明编解码理想情形下可逆，难点在于解码器现实中拿不到 $x_0$。

#### 步骤3：不完美解码器（只用 $x_L$ 估计 $x_0$）

朴素估计 $\hat{x}_0=x_L/\sqrt{\bar\alpha_L}$（极大似然解，忽略噪声）本身带标准差 $\sqrt{(1-\bar\alpha)/\bar\alpha}\approx\sqrt{e-1}\approx1.31$ 的噪声，会沿逆向链传导：

| $L$ | Oracle 平均往返误差 | 朴素估计平均往返误差 |
|-----|--------------------|--------------------|
| 5 | ≈0 | 1.144 |
| 20 | ≈0 | 1.062 |
| 100 | ≈0 | 1.056 |

不完美解码器的误差远大于 Oracle，必须用更好的去噪器（10.3 节的 $\varepsilon$/$x_0$ 预测网络）去逼近理想后验均值 $\tilde\mu_t$。这一步把"瓶颈"从结构问题转回成"学习问题"：缺口不在于层级够不够多，而在于解码器只能看到带噪状态、必须自己造出那份缺失的干净信息。

#### 核心知识点总结

1. **编码器=逐层加噪**：$x_t=\sqrt{\alpha}\,x_{t-1}+\sqrt{\beta}\,\varepsilon$，末态趋于标准高斯先验。
2. **理想解码器=后验均值**：已知 $x_0$ 时往返精确可逆，误差≈0 与 $L$ 无关。
3. **解码需估计 $x_0$**：真实解码器不知 $x_0$，朴素估计引入误差——引出训练去噪网络（10.3 节）。
4. **与扩散的对应**：前向加噪=编码、逆向去噪=解码（本实验见机理；$L\to\infty$ 连续极限见实验 10.4-1）。

## 本章总结与展望

### 关键步骤回顾

1. **层级扩展**（10.1）：单层 → 多层马尔可夫链，层级 ELBO = 重建项 + ∑KL 项；
2. **高斯编码器**（10.2）：编码器取高斯转移 = 逐步加噪，编码器不学；前向后验闭式解；
3. **去噪参数化**（10.3）：VLB 化简成均值匹配 → $x_0$ 或 $\varepsilon$ 预测 → 简化目标 $L_\text{simple}$；
4. **连续极限**（10.4）：$T\to\infty$ → 离散层级趋连续 SDE，编码/解码 ↔ 加噪/去噪。

### 核心认知

**扩散模型 = 层级 VAE 在"高斯转移 + 无穷层级"下的极限。** 意义有三层：

- **实践上**：扩散训练不是黑魔法，而是变分推断的自然推论——训练去噪器就是在优化变分下界；
- **理论上**：两条独立路径（采样路径、变分路径）都指向同一模型，不是巧合，而是贝叶斯框架内在统一的体现；
- **历史上**：VAE(2014) → 层级 VAE(2016) → DDPM(2020) 是平滑演化，不是断裂。

## 收尾：为什么这件事重要

把整章压缩成一句话：**别把扩散模型当成天降神兵——它不过是 VAE 把"一步编码"耐心拆成"无穷步加噪"后的自然极限。** 当你意识到"编码器每步加噪 = 正向过程、解码器每步去噪 = 逆向过程"，变分路径和采样路径就不再是两个故事，而是同一座桥的两头。这一认识还有更深的一层：所谓生成，不过是一条"先稀释、再重建"的完整信念周期——正向把结构冲淡成噪声，逆向再把结构从噪声里一寸寸找回来。下一章我们把桥面铺平成可运行的训练算法；第12章，两条路正式合龙。
