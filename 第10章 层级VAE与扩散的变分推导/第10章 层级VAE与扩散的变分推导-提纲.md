# 第10章 层级VAE与扩散的变分推导 — 提纲

> **章节定位**：变分路径（Part III 副线）的关键桥梁章。上一章（第9章）建立了VAE的基本框架——编码器-解码器结构、ELBO训练、重参数化技巧。本章将VAE从单层推广到多层（层级VAE），并证明：当层数L→∞、编码器取高斯转移时，层级VAE退化为扩散模型。这是变分路径"VAE → 层级VAE → 扩散"的核心推导链。

> **逆问题动机**：变分路径与采样路径殊途同归——采样路径从逆问题的后验采样需求出发，经由Langevin→Score→Diffusion；变分路径从优化角度近似后验出发，经由ELBO→VAE→层级VAE→Diffusion。本章是变分路径抵达扩散模型的最后一跳，为第12章"Score ≡ ELBO"的统一提供变分侧的基础。

> **叙事主线**：单层VAE局限 → 层级潜变量结构 → 层级ELBO推导 → 高斯编码器=加噪 → VLB→去噪目标 → L→∞极限→扩散

> **与前章衔接**：第9章建立了VAE框架（编码器q_φ(z|x)、解码器p_θ(x|z)、ELBO=重建项+KL项、重参数化技巧）。本章从VAE出发，将单层z扩展为层级z_1,...,z_L。

> **与后章衔接**：本章建立了扩散模型的变分推导框架。第11章将在此基础上深入VLB分解（L_T + L_{t-1} + L_0）、三种参数化的详细比较、简化VLB与DDPM训练目标的关系。

## 10.0 本章导读：从一步编码到逐步加噪

第9章我们建立了VAE：一个编码器将数据映射到潜空间，一个解码器从潜空间重建数据。但VAE的"一步到位"编码方式在面对复杂数据分布时力不从心——单层潜变量难以捕捉数据的层次结构。

如果我们将编码过程分解为多个小步骤呢？每一步只做一点点变换，逐步将数据推向简单分布。这就是层级VAE的核心思想。而当我们让每一步的变换都是高斯的——加一点噪声——层级VAE就变成了扩散模型。

本章从这个问题出发，走一条"VAE局限→层级扩展→变分推导→高斯特化→连续极限"的路径：

- **从VAE到层级VAE**（10.1）：引入层级潜变量，建立马尔可夫推断链，推导层级ELBO
- **扩散过程的变分下界推导**（10.2）：当编码器取高斯转移分布时，推导完整的VLB，得到前向过程后验的闭式解
- **从变分下界到去噪目标**（10.3）：将VLB转化为可训练的去噪损失，建立x₀预测与ε预测两种参数化
- **层级VAE→扩散的极限**（10.4）：L→∞时离散层级趋于连续扩散过程，统一编码/解码与加噪/去噪的视角

```
VAE单层局限(10.1) → 层级ELBO推导(10.1) → 高斯编码器=加噪(10.2)
      → 前向后验闭式解(10.2) → VLB→去噪损失(10.3) → L→∞→扩散(10.4)
```

本章结束时，读者将理解：扩散模型不是一个从天而降的新架构，而是VAE在层级结构和高斯转移假设下的自然极限。**VAE编码器的每一步加噪，就是扩散的正向过程；解码器的每一步去噪，就是扩散的逆向过程——两者是同一数学对象的不同表述。**

## 10.1 从VAE到层级VAE

> **核心观点**：单层VAE的编码器需要一步完成"数据→潜变量"的映射，表达能力受限。层级VAE引入多层潜变量z_1,...,z_L，将编码/解码分解为马尔可夫链上的逐步变换，大幅增强模型的表达能力。层级ELBO是单层ELBO的自然推广——每一层引入一个KL散度项。

### 10.1.1 单层VAE的局限

- 回顾VAE结构：编码器q_φ(z|x)，解码器p_θ(x|z)
- 单层潜变量的表达瓶颈：z需要同时编码所有层次的特征
- 信息瓶颈问题：单个高斯分布难以表示多模态后验
- 重建质量与KL正则化的矛盾：强KL约束→潜空间过于简单→重建模糊；弱KL约束→隐空间不规则→采样无意义

### 10.1.2 层级潜变量的引入

- 从z到z_1,...,z_L：多层潜变量的生成模型
- 生成过程（自顶向下）：p(z_L) → p(z_{L-1}|z_L) → ... → p(x|z_1)
- 推断过程（自底向上）：q(z_1|x) → q(z_2|z_1) → ... → q(z_L|z_{L-1})
- 马尔可夫性假设：每一步只依赖相邻层
- 直观理解：不同层编码不同抽象级别的特征（底层=纹理，中层=结构，顶层=语义）

### 10.1.3 马尔可夫推断链

- 推断链的马尔可夫结构：q(z_{1:L}|x) = ∏_{l=1}^{L} q(z_l|z_{l-1})，其中z_0≡x
- 生成链的马尔可夫结构：p(z_{1:L}) = p(z_L)∏_{l=1}^{L-1} p(z_l|z_{l+1})
- 马尔可夫性的好处：分解推断，降低每一步的复杂度
- 与非马尔可夫层级模型的对比

### 10.1.4 层级ELBO推导

- 从单层ELBO出发：log p(x) ≥ E_q[log p(x|z)] - KL(q(z|x)||p(z))
- 推广到层级：log p(x) ≥ E_q[log p(x|z_{1:L})] - KL(q(z_{1:L}|x)||p(z_{1:L}))
- 利用马尔可夫性分解KL项：KL = ∑_l KL(q(z_l|z_{l-1})||p(z_l|z_{l+1}))
- 层级ELBO的直觉：每一层都在"匹配"推断分布和生成分布
- 关键观察：层级ELBO = 重建项 + ∑_l KL项

**来源**：Tutorial on Diffusion Models Sec 1-2; Kingma & Welling (2014); Rezende et al. (2014); Sønderby et al. (2016) LVAE

层级VAE提供了更灵活的生成框架，但如何选择每一步的转移分布q(z_l|z_{l-1})和p(z_l|z_{l+1})？当这些转移取为特定的高斯分布时，一个惊人的对应关系浮现：编码器的每一步就是加噪，解码器的每一步就是去噪。

## 10.2 扩散过程的变分下界推导

> **核心观点**：当层级VAE的编码器取为高斯转移q(x_t|x_{t-1}) = N(√α_t x_{t-1}, (1-α_t)I)时，编码过程就是逐步加噪，解码过程就是逐步去噪。此时层级ELBO化为扩散模型的变分下界（VLB），其中前向过程后验q(x_{t-1}|x_t, x_0)有闭式高斯解——这是扩散训练可行的关键。

### 10.2.1 高斯编码器=加噪过程

- 将z_1,...,z_L重标记为x_1,...,x_T（时间步），z_0≡x_0≡x（数据）
- 编码器转移：q(x_t|x_{t-1}) = N(x_t; √(1-β_t) x_{t-1}, β_t I)
- 等价形式：q(x_t|x_{t-1}) = N(x_t; √α_t x_{t-1}, (1-α_t)I)，其中α_t = 1-β_t
- 关键性质：编码器无需学习——参数β_t（噪声调度）是固定的
- 这与标准VAE的根本区别：VAE编码器是学习的神经网络，扩散编码器是预定义的高斯链

### 10.2.2 噪声调度与直接采样

- 递推关系：x_t = √α_t x_{t-1} + √(1-α_t) ε_{t-1}
- 直接采样：x_t = √ᾱ_t x_0 + √(1-ᾱ_t) ε，其中ᾱ_t = ∏_{s=1}^{t} α_s
- ᾱ_t的物理含义：信噪比的衰减因子
- 噪声调度选择：线性调度、余弦调度等

### 10.2.3 变分下界的KL分解

- 层级ELBO应用于扩散结构
- 三项分解：
  - L_T = KL(q(x_T|x_0) || p(x_T))：先验匹配项（终极噪声应近似标准高斯）
  - L_{t-1} = KL(q(x_{t-1}|x_t, x_0) || p_θ(x_{t-1}|x_t))：一致性项（核心训练信号）
  - L_0 = -log p_θ(x_0|x_1)：重建项
- 总目标：-log p(x_0) ≥ L_T + ∑_{t=2}^{T} L_{t-1} + L_0

### 10.2.4 前向过程后验的闭式解

- 关键推导：利用马尔可夫性和贝叶斯定理
- q(x_{t-1}|x_t, x_0) = q(x_t|x_{t-1}, x_0) · q(x_{t-1}|x_0) / q(x_t|x_0)
- 由于马尔可夫性：q(x_t|x_{t-1}, x_0) = q(x_t|x_{t-1})
- 结果：q(x_{t-1}|x_t, x_0) = N(x_{t-1}; μ̃_t(x_t, x_0), β̃_t I)
- 后验均值：μ̃_t = (√α_t (1-ᾱ_{t-1}) / (1-ᾱ_t)) x_t + (√ᾱ_{t-1} (1-α_t) / (1-ᾱ_t)) x_0
- 后验方差：β̃_t = (1-ᾱ_{t-1})/(1-ᾱ_t) · β_t
- 关键意义：后验仅依赖x_t和x_0，且方差固定（无需学习）

**来源**：Tutorial on Diffusion Models Sec 2.2-2.3; DDPM (Ho et al. 2020); 2209.14687v1 Sec 2.2; Kingma et al. (2021) VDM

至此，本节建立了扩散过程的变分框架：VLB三项分解、前向后验闭式解、均值匹配的化简方向。进一步的问题是，当层级数 $T \to \infty$ 时，离散的层级结构会发生什么？

## 10.3 从变分下界到去噪目标

> **核心观点**：VLB中的KL散度项L_{t-1}可化简为两个高斯分布之间的KL，它只依赖于均值的差异。通过参数化逆向过程p_θ(x_{t-1}|x_t)的均值，VLB等价于一个加权去噪损失——这就是扩散训练的变分基础。

### 10.3.1 KL散度项的化简

- L_{t-1} = KL(N(μ̃_t, β̃_t I) || N(μ_θ(x_t, t), β̃_t I))
- 两个同方差高斯的KL散度 → 均值差的二次型
- 结果：L_{t-1} = (1/(2β̃_t)) ||μ̃_t - μ_θ(x_t, t)||²
- 关键简化：方差项消失，只需匹配均值

### 10.3.2 逆向过程的参数化

- 逆向过程：p_θ(x_{t-1}|x_t) = N(x_{t-1}; μ_θ(x_t, t), Σ_θ(x_t, t))
- 方差选择：Σ_θ = β̃_t I（固定方差，与后验方差相同）
- 均值参数化的两种选择：
  - **x₀预测**：直接预测x̂₀，通过μ̃_t的公式反推μ_θ
  - **ε预测**：预测噪声ε̂，利用x₀ = (x_t - √(1-ᾱ_t) ε̂) / √ᾱ_t代入

### 10.3.3 x₀预测参数化

- 令去噪网络输出x̂₀ = f_θ(x_t, t)
- 代入μ̃_t公式：μ_θ = (√α_t (1-ᾱ_{t-1}) / (1-ᾱ_t)) x_t + (√ᾱ_{t-1} (1-α_t) / (1-ᾱ_t)) x̂₀
- L_{t-1}化为关于x̂₀的损失

### 10.3.4 ε预测参数化

- 令去噪网络输出ε̂_θ = f_θ(x_t, t)
- 利用x₀ = (x_t - √(1-ᾱ_t) ε̂) / √ᾱ_t
- 代入均值匹配目标，化简得：L_{t-1} ∝ (α_t/(2β̃_t(1-ᾱ_t))) ||ε - ε̂_θ(x_t, t)||²
- 简化训练目标：L_simple = E_t[||ε - ε̂_θ(x_t, t)||²]（DDPM的训练目标）
- 时间加权因子的作用与简化VLB的权衡（→第11章深入讨论）

### 10.3.5 变分视角与得分视角的初步对应

- ε预测参数化下的VLB ↔ 第6章的去噪得分匹配（DSM）
- 预告第12章：DSM损失 ≡ VLB，两条路径即将汇合

**来源**：Tutorial on Diffusion Models Sec 2.4-2.5; DDPM (Ho et al. 2020); 2406.08929v2 Sec 5; 2209.14687v1 Sec 2.2

从变分下界出发，我们看到了扩散训练的概念框架：均值匹配、三种参数化、简化目标，以及与得分视角的初步对应。但这一切仍然在离散时间步 $T$ 的框架下，当 $T$ 趋近无穷时，离散的层级结构会发生什么？

## 10.4 层级VAE→扩散的极限

> **核心观点**：当层级数L→∞，每一步的变换量→0，离散的层级VAE趋于连续的扩散过程。编码链变成正向SDE（加噪），解码链变成逆向SDE（去噪）。这是变分路径的终点——从优化后验近似出发，经由层级VAE，自然抵达与第7章SDE视角相同的扩散模型。

### 10.4.1 从离散步到连续过程

- 离散时间步t=1,...,T → 连续时间t∈[0,1]
- β_t → β(t)dt：每一步的噪声量趋于零
- ᾱ_T → 0：足够多步后信号完全被噪声淹没
- 递推关系x_t = √α_t x_{t-1} + √(1-α_t) ε → 连续极限dx = f(x,t)dt + g(t)dW

### 10.4.2 正向SDE：编码链的连续极限

- VP-SDE（方差保持）：dx = -½β(t)x dt + √β(t) dW
- 与第7章正向SDE的对应关系
- 编码器的连续化：每一步加微量噪声 → 信号渐进消退

### 10.4.3 逆向SDE：解码链的连续极限

- 逆向SDE：dx = [f(x,t) - g(t)²∇log p_t(x)]dt + g(t)dW̄
- 解码器的连续化：每一步去微量噪声 → 从纯噪声恢复信号
- 变分视角下的逆向SDE：连续极限的VLB等价于第7章的得分驱动采样

### 10.4.4 统一视角：编码/解码与加噪/去噪

- 对应关系总表：

| VAE概念 | 扩散概念 |
|---|---|
| 编码器 q_φ(z\|x) | 正向过程 q(x_t\|x_{t-1}) |
| 解码器 p_θ(x\|z) | 逆向过程 p_θ(x_{t-1}\|x_t) |
| 潜变量 z | 中间状态 x_t |
| 先验 p(z) | 终态分布 p(x_T) ≈ N(0,I) |
| ELBO | VLB |
| 重参数化 | 噪声调度 + 重新参数化 |

- 变分路径的完整链路：ELBO → VAE → 层级VAE → 扩散（VLB）→ 连续SDE
- 与采样路径的对照：Score Matching → 退火Langevin → 扩散SDE
- 预告第12章：两条路径即将在"DSM ≡ VLB"处汇合

### 10.4.5 本章总结与展望

- 本章的核心贡献：从变分推断的角度严格推导了扩散模型
- 关键步骤回顾：(1) 层级扩展 (2) 高斯编码器 (3) VLB推导 (4) 去噪参数化 (5) 连续极限
- 下一站（第11章）：深入VLB的分解与简化，理解DDPM训练目标的变分本质

**来源**：Kingma et al. (2021) VDM; Song et al. (2021) Score-SDE; 2406.08929v2 Sec 5; Tutorial on Diffusion Models Sec 4
