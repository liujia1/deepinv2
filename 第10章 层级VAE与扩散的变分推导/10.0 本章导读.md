# 10.0 本章导读：从一步编码到逐步加噪

> **路线定位**：变分路径第三步。第9章的VAE是变分路径的第一个里程碑，相当于采样路径中第6章得分匹配的地位。本章将VAE扩展为层级VAE，正如第6章将单尺度得分扩展为多尺度NCSN——两条路径都在"从单步到多步"的相同方向上推进。关键转折在本章末尾出现：当层级VAE的编码器取高斯加噪时，它与扩散的正向过程完全一致——变分路径开始与采样路径的终点（第7章扩散SDE）靠拢。

第9章建立了VAE的完整框架：一个编码器将数据映射到潜空间，一个解码器从潜空间重建数据，训练目标是最小化ELBO——重建项让解码器忠实还原数据，KL项让编码器靠近先验分布。但VAE有一个根本性的局限：**编码器必须一步完成"数据→潜变量"的映射**。这意味着单个高斯分布的编码器需要同时捕捉数据的所有层次特征，表达能力的天花板很低。

如果我们将这个"一步到位"的编码过程分解为多个小步骤呢？每一步只做一点点变换，逐步将数据推向简单分布。这就是**层级VAE**的核心思想——用一条马尔可夫链替代单步映射，每一层潜变量只需编码一个"微小变化"。

而当我们进一步要求每一步的变换都是高斯的——给数据加一点噪声——一个惊人的对应关系浮现：**编码器的每一步加噪就是扩散的正向过程，解码器的每一步去噪就是扩散的逆向过程**。层级VAE，在层级数趋于无穷时，自然退化为扩散模型。

本章从这个问题出发，走一条"VAE局限→层级扩展→高斯特化→概念框架→连续极限"的路径：

- **从VAE到层级VAE**（10.1）：引入层级潜变量 $z_1, \ldots, z_L$，建立马尔可夫推断链，推导层级ELBO——单层ELBO的自然推广，每一层引入一个KL散度项。

- **扩散过程的变分下界推导**（10.2）：当编码器取高斯转移分布 $q(x_t|x_{t-1}) = \mathcal{N}(\sqrt{\alpha_t} x_{t-1}, (1-\alpha_t)\mathbf{I})$ 时，编码过程变成逐步加噪。建立VLB三项分解的概念框架，给出前向过程后验 $q(x_{t-1}|x_t, x_0)$ 的闭式高斯解，指出核心训练项可化简为均值匹配。详细的推导与训练算法设计将留待第11章完成。

- **从VLB到去噪训练：概念与预告**（10.3）：概述均值匹配与去噪的等价性、三种参数化的概念结论、简化训练目标 $L_\text{simple}$，以及变分视角与得分视角的初步对应。本节聚焦概念和直觉，为第11章的详细推导提供路线图。

- **层级VAE→扩散的极限**（10.4）：当层级数 $L \to \infty$，离散的层级结构趋于连续的扩散过程。编码链变为正向SDE，解码链变为逆向SDE。变分路径的终点，与第7章SDE视角殊途同归。

```
VAE单层局限(10.1) → 层级ELBO推导(10.1) → 高斯编码器=加噪(10.2)
      → VLB概念框架(10.2) → 均值匹配与参数化预告(10.3) → L→∞→扩散SDE(10.4)
```

本章结束时，读者将理解：扩散模型不是一个从天而降的新架构，而是VAE在层级结构和高斯转移假设下的自然极限。**VAE编码器的每一步加噪，就是扩散的正向过程；解码器的每一步去噪，就是扩散的逆向过程——两者是同一数学对象的不同表述。** 本章建立了这一对应的概念框架，下一章将把VLB化为完整的训练算法。这一认知也为第12章"Score ≡ ELBO"的统一提供变分侧的基石：采样路径从得分匹配抵达扩散，变分路径从ELBO抵达扩散，两条路径即将汇合。
