# 12.1 采样路径回顾：从 Tweedie 到 DSM 损失

> 核心观点：采样路径的链条是「去噪器 → 得分函数 → 采样」。Tweedie 等式把"去噪器"和"得分函数"焊在一起，得分匹配把"训练去噪器"和"学得分"画等号，多尺度得分匹配再把单一噪声铺成噪声调度，最终走向扩散 SDE。本节把这条链上的关键结果重新擦亮，统一记号，为 12.3–12.4 的等价性证明铺路。
>
> **回顾定位**：本节是对第 5–7 章的**串联回顾**。Tweedie 等式源出第 5 章 5.3（证明见附录 5B），得分匹配见第 6 章，扩散 SDE 见第 7 章。这里不再重推，只用统一记号把它们串成一条因果链。

先别急着看公式。我们先问一个最朴素的问题：**采样路径到底想解决什么？** 答案在第5章就已经埋下——Langevin 采样（Langevin 采样：一种"朝高概率方向走一步 + 随机抖一下"的采样方法）需要数据的得分函数 $\nabla\log p(x)$，可真实图像分布 $p(x)$ 的归一化常数 $Z = \int \exp(-R(x))\,dx$ 根本算不出来。于是路径的核心难题变成：

> **怎么在一个连归一化常数都求不出的分布上，学会它的"概率往哪涨"？**

Tweedie 等式和得分匹配，就是这道难题的两个答案。本节依次讲它们。

---

## 一、得分函数与 Tweedie 等式：去噪器就是得分函数

### 得分函数：概率分布的"指路牌"

第5章给了定义。对概率密度 $p(x)$，得分函数是

$$s(x) = \nabla_x \log p(x) = \frac{\nabla_x p(x)}{p(x)}$$

把它想成"概率密度增长最快的方向"——在概率山上，它是指向山顶的坡向。Langevin 采样正是靠它把样本往高概率区推：

$$X_{k+1} = X_k + \delta\,\nabla\log p(X_k) + \sqrt{2\delta}\,Z_{k+1}$$

（最后那项 $\sqrt{2\delta}\,Z_{k+1}$ 是随机抖动，保证我们能逛遍整座山，而不只是卡在山顶。）

### Tweedie 等式：一个绕开归一化常数的桥

问题来了：上式里的 $\nabla\log p(x)$ 算不出，因为 $Z$ 算不出。第5章的 Tweedie 等式（Tweedie 等式：一个把"去噪器"和"含噪分布的得分"直接画等号的恒等式）给了漂亮的桥。对噪声扰动后的分布 $p_\sigma(x) = (p * \mathcal{N}(0,\sigma^2 I))(x)$（就是把数据掺了方差为 $\sigma^2$ 的高斯噪声后的分布），有：

$$\boxed{\nabla_x \log p_\sigma(x) = \frac{D_\sigma^*(x) - x}{\sigma^2}}$$

这里 $D_\sigma^*(x) = \mathbb{E}[x_0 | x]$ 是 MMSE 去噪器（MMSE 去噪器：给定含噪图，输出"最可能的干净图"，即后验均值），$\sigma^2$ 是噪声方差。

这个等式干成了三件事，每件事都值得停下来品一品：

1. **绕开了归一化常数**：右边 $(D_\sigma^*(x) - x)/\sigma^2$ 完全不碰 $Z$；
2. **去噪 = 学得分**：只要能训练一个去噪器，就等于学到了含噪分布的得分；
3. **数据驱动地拿到了先验梯度**：去噪器从数据里隐式学到了先验（先验：我们在看到观测之前，对信号的"本来应该长啥样"的信念），Tweedie 把它变成显式的梯度。

> **直觉先行**：含噪图 $x$ 减去去噪结果 $D_\sigma^*(x)$，剩下的就是"被噪声带偏了多少"；除以 $\sigma^2$ 把它缩放回梯度量纲。原来"去掉噪声的方向"和"概率上涨的方向"是同一个方向——这会是本章反复出现的主题。

### 不同噪声注入下的 Tweedie 等式

两种主流加噪方式，Tweedie 长得略有不同：

**加性噪声（VE-SDE / NCSN）**：$\tilde{x} = x_0 + \sigma\epsilon$，$\epsilon \sim \mathcal{N}(0, I)$

$$\nabla_{\tilde{x}}\log p_\sigma(\tilde{x}) = \frac{D_\sigma^*(\tilde{x}) - \tilde{x}}{\sigma^2}$$

**缩放加性噪声（VP-SDE / DDPM）**：$x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$

$$\nabla_{x_t}\log p_t(x_t) = \frac{\sqrt{\bar\alpha_t}\,D_t^*(x_t) - x_t}{1 - \bar\alpha_t}$$

区别只在于加噪时有没有把原信号缩放一下。这点小差异，在 12.3 节的对比里很关键——先记住它。

## 二、DSM 目标：从"知道得分"到"学会得分"

### 从 ESM 到 DSM：为什么需要绕这一圈

第6章把得分匹配的方法演化讲清楚了，这里用因果链串一遍，因为这正是采样路径的骨架：

- **ESM（显式得分匹配）**：直接逼模型得分靠近真实得分
  $$\mathcal{J}_\text{ESM}(\theta) = \frac{1}{2}\mathbb{E}_{p(x)}\left[\|s_\theta(x) - \nabla\log p(x)\|^2\right]$$
  **卡点**：它需要真实得分 $\nabla\log p(x)$ 当监督，而这恰恰算不出。
- **ISM（隐式得分匹配）**：用分部积分把 $\nabla\log p(x)$ 消掉
  $$\mathcal{J}_\text{ISM}(\theta) = \frac{1}{2}\mathbb{E}_{p(x)}\left[\|s_\theta(x)\|^2 + 2\,\text{tr}(\nabla_x s_\theta(x))\right] + C$$
  **卡点**：要算 Jacobian 的迹，复杂度 $O(d^2)$，图像这种高维直接爆掉。
- **DSM（去噪得分匹配）**：引入噪声扰动，让条件得分有闭式解
  $$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2}\mathbb{E}_{p(x)}\mathbb{E}_{\epsilon}\left[\left\|s_\theta(x + \sigma\epsilon) - \left(-\frac{\epsilon}{\sigma}\right)\right\|^2\right]$$
  **突破**：条件得分 $-\epsilon/\sigma$ 是已知的（因为噪声是我们自己加的），不再需要 Jacobian 迹，完全可计算。

**因为 ESM 要真实得分、ISM 要算迹，两者都走不通，所以我们才落到 DSM**——这就是采样路径"为什么难、怎么解"的标准剧本。

### Vincent (2011) 等价性：DSM 就是 ESM 的替身

Vincent 证明了一个关键等式：

$$\mathcal{J}_\text{DSM}(\theta) = \mathcal{J}_\text{ESM}^{(\sigma)}(\theta) + C(\sigma)$$

左边定义在含噪分布 $p_\sigma$ 上，右边是同样的 ESM 目标，$C(\sigma)$ 与参数 $\theta$ 无关。翻译一下：**DSM 的最优解，同时就是含噪分布上 ESM 的最优解**。也就是说，我们不需要真实得分，只要在噪声扰动后用 DSM 学，Tweedie 保证学到的得分是货真价实的（完整证明见第 6 章附录 6A，这里只在回顾层面引用其结论）。

> **这是采样路径的命门**：绕过不可算的归一化常数，用"加噪—去噪"的游戏把得分函数学出来。

## 三、ε 预测参数化：把"得分"翻译成"噪声"

### 为什么需要这个转换

第6章 6.6 节讲了三种参数化（参数化：决定网络到底输出什么量）。最关键的是"得分预测"和"噪声预测"之间的转换——它正是连接采样路径和变分路径的桥。

对加性噪声 $\tilde{x} = x_0 + \sigma\epsilon$，由 Tweedie：

$$s_\sigma(\tilde{x}) = \nabla\log p_\sigma(\tilde{x}) = \frac{D_\sigma(\tilde{x}) - \tilde{x}}{\sigma^2}$$

而 $\tilde{x} - D_\sigma(\tilde{x})$ 就是去噪器认为"被加进去的那份噪声"。于是我们定义一个噪声预测网络 $\epsilon_\theta(\tilde{x}, \sigma)$，令：

$$s_\theta(\tilde{x}, \sigma) = -\frac{\epsilon_\theta(\tilde{x}, \sigma)}{\sigma}$$

**直觉**：得分函数指向"概率上涨的方向"（即远离噪声、奔向干净信号的方向），而 $-\epsilon/\sigma$ 正是"消除噪声的方向"（从含噪观测指向原信号），两者方向一致，只是换了件衣服。

### DSM 的 ε 预测形式：目标变成"猜噪声"

把 $s_\theta = -\epsilon_\theta/\sigma$ 代入 DSM：

$$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2}\mathbb{E}_{p(x)}\mathbb{E}_\epsilon\left[\left\|-\frac{\epsilon_\theta(x+\sigma\epsilon, \sigma)}{\sigma} + \frac{\epsilon}{\sigma}\right\|^2\right]
:= \frac{1}{2\sigma^2}\mathbb{E}_{p(x)}\mathbb{E}_\epsilon\left[\|\epsilon - \epsilon_\theta(x+\sigma\epsilon, \sigma)\|^2\right]$$

**看啊——DSM 目标变成了"预测加进去的噪声 ε"的均方误差（MSE）！** 这恰恰就是去噪器本来的训练目标。这一步转换是本章的枢纽：它让采样路径和变分路径开始说同一种语言。

对 VP-SDE 加噪 $x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon$，同理得到：

$$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2(1-\bar\alpha_t)}\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

## 四、多尺度得分匹配与噪声调度：从"一个噪声"到"一串噪声"

### 为什么单一噪声不够

第6章 6.5 节指出单一噪声水平的 DSM 有个毛病：在概率密度很低的区域（比如两张脸之间的"空隙"），得分估计不准。解决思路很自然——在**多个噪声水平** $\{\sigma_i\}_{i=1}^L$ 上分别学得分，再用退火 Langevin 动力学（退火：从大噪声逐步降到小噪声，像慢慢降温让样本落进细节）采样。

多尺度 DSM：

$$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2}\sum_{i=1}^L \lambda(\sigma_i)\,\mathbb{E}_{x_0,\epsilon}\left[\left\|s_\theta(x_0+\sigma_i\epsilon, \sigma_i) + \frac{\epsilon}{\sigma_i}\right\|^2\right]$$

其中 $\lambda(\sigma_i)$ 是权重函数。换成 ε 预测参数化：

$$\boxed{\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2}\sum_{i=1}^L \frac{\lambda(\sigma_i)}{\sigma_i^2}\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_0+\sigma_i\epsilon, \sigma_i)\|^2\right]}$$

（有的文献用 $\frac{1}{L}\sum$ 归一化，只差一个缩放，不影响最优解。这里保留 $\frac{1}{2}\sum$ 以和 ESM 定义一致。）

### 权重函数 $\lambda$ 是唯一的旋钮

权重 $\lambda(\sigma_i)/\sigma_i^2$ 怎么选，直接影响训练：

- **$\lambda(\sigma) = \sigma^2$（NCSN 默认）**：权重退化为 1，得到均匀加权的"猜噪声"MSE；
- **$\lambda(\sigma) = 1$**：权重为 $1/\sigma^2$，更强调低噪声水平的得分；
- **$\lambda(\sigma) = \sigma^2 \cdot w_t$（VLB 权重）**：权重去匹配变分下界——这正是 12.4 节要证明的。

### 从 NCSN 到扩散 SDE：连续化

第7章把离散的噪声调度推广成连续的随机微分方程（SDE，随机微分方程：用"漂移 + 随机扰动"描述含噪图随时间的演化）：

- VE-SDE（NCSN 的连续极限）：$dx = \sqrt{d[\sigma^2(t)]/dt}\,dw$
- VP-SDE（DDPM 的连续极限）：$dx = -\frac{\beta(t)}{2}x\,dt + \sqrt{\beta(t)}\,dw$

逆向 SDE 由 Anderson (1982) 定理给出：

$$dx = [f(x,t) - g^2(t)\nabla_x\log p_t(x)]\,dt + g(t)\,d\bar{w}$$

得分函数 $\nabla\log p_t(x)$ 是逆向 SDE 的核心驱动力——而它由上面那个 DSM 训练的噪声条件网络 $\epsilon_\theta(x_t, t)$ 提供。

## 五、采样路径的终点（and 这就是 12.4 要对比的"答案 A"）

把整条链收个口：

$$\boxed{\text{训练去噪器} \xrightarrow{\text{Tweedie}} \text{学习得分函数} \xrightarrow{\text{逆向 SDE}} \text{扩散采样}}$$

去噪器的训练目标，就是 DSM 损失——一个"预测噪声"的 MSE：

$$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{L}\sum_{i=1}^L \frac{\lambda(\sigma_i)}{\sigma_i^2}\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_0+\sigma_i\epsilon, \sigma_i)\|^2\right]$$

**这是采样路径的"最终答案"。** 记下它，因为 12.4 节会把它和变分路径的"最终答案"放在一起，证明两者等价。

采样路径停在"预测噪声的 MSE"上。那变分路径的终点又是什么？它从最大似然出发，绕了一大圈，最后会不会也停在同一个 MSE 上？带着这个悬念，我们进入下一节。
