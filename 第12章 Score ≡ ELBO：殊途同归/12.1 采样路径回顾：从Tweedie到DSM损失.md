# 12.1 采样路径回顾：从Tweedie到DSM损失

> **核心观点**：采样路径的核心链条是"去噪器→得分函数→采样"——Tweedie等式将去噪器与得分函数桥接，DSM将去噪器训练与得分匹配等价，多尺度得分匹配将单一噪声扩展为噪声调度，最终走向扩散SDE。本节回顾这条路径的关键数学结果，统一记号，为12.3-12.4的等价性证明做准备。

## 得分函数与Tweedie等式

### 得分函数：概率分布的梯度

第5章5.2节引入了得分函数的定义：对于概率密度 $p(x)$，得分函数为

$$s(x) = \nabla_x \log p(x) = \frac{\nabla_x p(x)}{p(x)}$$

得分函数指向概率密度增长最快的方向——它是概率分布的"梯度信息"。在Langevin采样中，得分函数驱动采样过程向高概率区域移动：

$$X_{k+1} = X_k + \delta\,\nabla\log p(X_k) + \sqrt{2\delta}\,Z_{k+1}$$

问题在于：对于真实的图像分布 $p(x)$，得分函数 $\nabla\log p(x)$ 不可直接计算——归一化常数 $Z = \int\exp(-R(x))\,dx$ 不可求解。

### Tweedie等式：去噪器即得分函数

第5章5.3节的Tweedie等式提供了绕过归一化常数的桥梁。对噪声扰动分布 $p_\sigma(x) = (p * \mathcal{N}(0, \sigma^2 I))(x)$，Tweedie等式给出：

$$\boxed{\nabla_x \log p_\sigma(x) = \frac{D_\sigma^*(x) - x}{\sigma^2}}$$

其中 $D_\sigma^*(x) = \mathbb{E}[x_0 | x]$ 是MMSE去噪器（后验均值），$\sigma^2$ 是噪声方差。

**Tweedie等式的关键含义**：

1. **绕过归一化常数**：右边 $(D_\sigma^*(x) - x)/\sigma^2$ 完全不需要 $Z$
2. **去噪 = 得分估计**：训练一个去噪器等价于学习得分函数
3. **数据驱动的先验梯度**：去噪器从数据中隐式学习先验，Tweedie将其转化为显式梯度

### 不同噪声注入方式下的Tweedie等式

Tweedie等式对不同的噪声注入方式有不同的具体形式。考虑两种主要的加噪方式：

**加性噪声（VE-SDE/NCSN）**：$\tilde{x} = x_0 + \sigma\epsilon$，$\epsilon \sim \mathcal{N}(0, I)$

$$\nabla_{\tilde{x}}\log p_\sigma(\tilde{x}) = \frac{D_\sigma^*(\tilde{x}) - \tilde{x}}{\sigma^2}$$

**缩放加性噪声（VP-SDE/DDPM）**：$x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$，$\epsilon \sim \mathcal{N}(0, I)$

$$\nabla_{x_t}\log p_t(x_t) = \frac{\sqrt{\bar\alpha_t}\,D_t^*(x_t) - x_t}{1 - \bar\alpha_t}$$

两种形式的区别在于噪声注入时是否对原始信号进行缩放。这个区别在12.3节的对比中很重要。

## DSM目标函数

### 从ESM到DSM的演化

第6章详细推导了得分匹配方法的演化链：

**ESM（显式得分匹配）**：直接最小化模型得分与真实得分的距离

$$\mathcal{J}_\text{ESM}(\theta) = \frac{1}{2}\mathbb{E}_{p(x)}\left[\|s_\theta(x) - \nabla\log p(x)\|^2\right]$$

ESM不可行——需要知道 $\nabla\log p(x)$ 作为监督信号。

**ISM（隐式得分匹配）**：利用分部积分消除 $\nabla\log p(x)$

$$\mathcal{J}_\text{ISM}(\theta) = \frac{1}{2}\mathbb{E}_{p(x)}\left[\|s_\theta(x)\|^2 + 2\,\text{tr}(\nabla_x s_\theta(x))\right] + C$$

ISM有Jacobian迹的计算瓶颈——$O(d^2)$ 复杂度，在高维（图像）中不可行。

**DSM（去噪得分匹配）**：引入噪声扰动，条件得分有闭式解

$$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2}\mathbb{E}_{p(x)}\mathbb{E}_{\epsilon}\left[\left\|s_\theta(x + \sigma\epsilon) - \left(-\frac{\epsilon}{\sigma}\right)\right\|^2\right]$$

DSM完全可计算——条件得分 $-\epsilon/\sigma$ 已知，无需Jacobian迹。

### Vincent (2011) 等价性

Vincent (2011) 证明了DSM与ESM在噪声扰动分布上的等价性：

$$\mathcal{J}_\text{DSM}(\theta) = \mathcal{J}_\text{ESM}^{(\sigma)}(\theta) + C(\sigma)$$

其中 $\mathcal{J}_\text{ESM}^{(\sigma)}$ 是定义在噪声扰动分布 $p_\sigma$ 上的ESM目标，$C(\sigma)$ 与 $\theta$ 无关。因此，DSM的最优解同时也是 $p_\sigma$ 上ESM的最优解。

**这个等价性是采样路径的核心**：我们不需要知道真实得分 $\nabla\log p(x)$，只需在噪声扰动分布上用DSM学习得分，而Tweedie等式保证了学到的得分可以通过去噪器获得。

## ε预测参数化

### 得分预测与噪声预测的转换

第6章6.6节讨论了三种参数化方式。其中最关键的是得分预测与噪声预测之间的转换——这也是连接采样路径与变分路径的桥梁。

对于加性噪声模型 $\tilde{x} = x_0 + \sigma\epsilon$，由Tweedie等式：

$$s_\sigma(\tilde{x}) = \nabla\log p_\sigma(\tilde{x}) = \frac{D_\sigma(\tilde{x}) - \tilde{x}}{\sigma^2}$$

而 $\tilde{x} - D_\sigma(\tilde{x})$ 是去噪器认为的"噪声部分"。定义噪声预测网络 $\epsilon_\theta(\tilde{x}, \sigma)$，使得：

$$s_\theta(\tilde{x}, \sigma) = -\frac{\epsilon_\theta(\tilde{x}, \sigma)}{\sigma}$$

这个转换的直觉是：得分函数指向"概率增长方向"（即远离噪声的方向），而 $-\epsilon/\sigma$ 正是"去除噪声的方向"（从含噪观测指向原始信号），两者方向一致。

### DSM的ε预测形式

将 $s_\theta = -\epsilon_\theta/\sigma$ 代入DSM目标：

$$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2}\mathbb{E}_{p(x)}\mathbb{E}_\epsilon\left[\left\|-\frac{\epsilon_\theta(x+\sigma\epsilon, \sigma)}{\sigma} + \frac{\epsilon}{\sigma}\right\|^2\right]$$

$$= \frac{1}{2\sigma^2}\mathbb{E}_{p(x)}\mathbb{E}_\epsilon\left[\|\epsilon - \epsilon_\theta(x+\sigma\epsilon, \sigma)\|^2\right]$$

**DSM目标变成了"预测添加的噪声"的MSE损失**——这正是去噪器的训练目标！

对于VP-SDE的加噪方式 $x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon$，类似推导给出：

$$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2(1-\bar\alpha_t)}\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

## 多尺度得分匹配与噪声调度

### 从单一σ到噪声调度

第6章6.5节讨论了单一噪声水平的DSM的局限性：在低密度区域，得分估计不准确。解决方案是使用多个噪声水平 $\{\sigma_i\}_{i=1}^L$，在每个噪声水平上分别学习得分函数，然后用退火Langevin动力学进行采样。

多尺度DSM目标：

$$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2}\sum_{i=1}^L \lambda(\sigma_i)\,\mathbb{E}_{x_0,\epsilon}\left[\left\|s_\theta(x_0+\sigma_i\epsilon, \sigma_i) + \frac{\epsilon}{\sigma_i}\right\|^2\right]$$

其中 $\lambda(\sigma_i)$ 是权重函数，$1/2$ 来自ESM的定义 $\frac{1}{2}\mathbb{E}[\|s_\theta - s\|^2]$。转换为ε预测参数化：

$$\boxed{\mathcal{J}_\text{DSM}(\theta) = \frac{1}{2}\sum_{i=1}^L \frac{\lambda(\sigma_i)}{\sigma_i^2}\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_0+\sigma_i\epsilon, \sigma_i)\|^2\right]}$$

（有些文献使用 $\frac{1}{L}\sum$ 的归一化形式，两者仅差缩放因子，不影响最优解。这里统一使用 $\frac{1}{2}\sum$ 以与ESM定义保持一致。）

### 权重函数的选择

权重 $\lambda(\sigma_i)/\sigma_i^2$ 的选择对训练效果有重要影响：

- **$\lambda(\sigma) = \sigma^2$（NCSN默认）**：权重退化为1，得到均匀加权的噪声预测MSE
- **$\lambda(\sigma) = 1$**：权重为 $1/\sigma^2$，强调低噪声水平的得分估计
- **$\lambda(\sigma) = \sigma^2 \cdot w_t$（VLB权重）**：权重匹配变分下界——这将在12.4节证明

### 从NCSN到扩散SDE

第7章将离散的噪声调度推广为连续的SDE：

- VE-SDE（NCSN的连续极限）：$dx = \sqrt{d[\sigma^2(t)]/dt}\,dw$
- VP-SDE（DDPM的连续极限）：$dx = -\frac{\beta(t)}{2}x\,dt + \sqrt{\beta(t)}\,dw$

逆向SDE由Anderson (1982) 定理给出：

$$dx = [f(x,t) - g^2(t)\nabla_x\log p_t(x)]\,dt + g(t)\,d\bar{w}$$

得分函数 $\nabla\log p_t(x)$ 是逆向SDE的核心驱动力——通过DSM训练的噪声条件网络 $\epsilon_\theta(x_t, t)$ 提供得分估计。

### 采样路径的终点

综合以上结果，采样路径的核心结论是：

$$\boxed{\text{训练去噪器} \xrightarrow{\text{Tweedie}} \text{学习得分函数} \xrightarrow{\text{逆向SDE}} \text{扩散采样}}$$

去噪器的训练目标是**DSM损失**，即预测添加噪声的MSE：

$$\mathcal{J}_\text{DSM}(\theta) = \frac{1}{L}\sum_{i=1}^L \frac{\lambda(\sigma_i)}{\sigma_i^2}\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_0+\sigma_i\epsilon, \sigma_i)\|^2\right]$$

这是采样路径的"最终答案"——12.4节将证明它与变分路径的"最终答案"等价。
