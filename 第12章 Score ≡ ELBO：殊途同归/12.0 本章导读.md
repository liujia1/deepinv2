# 12.0 本章导读：两条路径的交汇时刻

> **核心观点**：从第1章到第11章，我们走了两条路。采样路径（第4-7章）从逆问题的后验采样需求出发，经由Langevin动力学、得分函数、Tweedie等式、得分匹配，走向了扩散模型。变分路径（第8-11章）从生成建模的最大似然需求出发，经由ELBO、VAE、层级VAE，也走向了扩散模型。两条路径各自独立发展，却训练出了几乎一样的模型——同样的去噪器网络、同样的加噪过程、同样的采样过程。这不是巧合。本章将证明：两条路径的训练目标在数学上等价，**DSM损失 ≡ 变分下界（VLB）**。

## 两条路，一个终点

让我们回顾全书的理论架构。在第3章的末尾，我们站在了一个分叉点上：MAP估计只给出点估计，丢弃了后验的不确定性信息。要处理复杂后验，有两条路可走——

**采样路径**（第4-7章，主线）：

```
逆问题需要后验采样 → MCMC效率低 → Langevin利用梯度 →
得分函数需要学习 → 得分匹配(DSM) → 多步扩散采样
```

这条路径的直接驱动力是逆问题的后验采样需求：我们想知道"给定观测，信号可能是什么样的"，而不仅仅是"最可能的信号是什么"。从ULA到Langevin SDE，从得分函数到Tweedie等式，从DSM到扩散SDE，每一步都是前一步局限性的自然回应。

**变分路径**（第8-11章，副线）：

```
生成模型需要最大似然 → 似然不可计算 → ELBO下界 →
VAE编码-解码 → 层级VAE增加深度 → 扩散模型=无限层VAE
```

这条路径的驱动力是生成建模的基本需求：我们想让模型对真实数据赋予高概率。从ELBO到VAE，从单层到层级，从有限层到无限层极限，每一步都是对表达能力的提升。

**惊人的事实**：两条路径的终点——扩散模型——在工程实现上几乎完全一致：

| 组件 | 采样路径 | 变分路径 |
|---|---|---|
| 加噪过程 | $x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon$ | 完全相同 |
| 去噪器网络 | $\epsilon_\theta(x_t, t)$ | 完全相同 |
| 训练数据对 | $(x_t, \epsilon)$ | 完全相同 |
| 采样过程 | 逆向SDE / DDPM | 完全相同 |

如果两个理论推导出了完全相同的算法，它们在数学上一定是等价的。本章的任务就是严格证明这一点。

本章的叙事遵循"回顾→对比→证明→统一→实践→汇合"的弧线：

## 为什么这一章重要

DSM ≡ VLB的等价性不仅仅是数学上的一个漂亮结论。它回答了全书最根本的问题：

**为什么逆问题的研究最终走向了扩散模型？**

等价性告诉我们：从逆问题的后验采样需求出发（采样路径），和从生成模型的最大似然需求出发（变分路径），最终到达了同一个地方。这不是偶然——得分函数 $\nabla\log p(x)$ 是概率分布的"梯度信息"，而 $\log p(x)$ 是"概率值信息"。梯度与函数值是同一数学对象的不同表示，学好梯度等价于学好函数值。两条路径殊途同归，是贝叶斯框架内在逻辑的必然结果。

让我们从采样路径的回顾开始，重新审视这条路径上的关键数学结果——它们将在等价性证明中扮演核心角色。
