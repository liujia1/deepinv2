# 12.0 本章导读：两条路径的交汇时刻

> 「第12章是全书必经之地——只有走到这，前十一章两条分叉的河流才真正汇成一股。这一章是全书的高潮，值得你慢读。」

先讲一个可能让你意外的事实：前十一章里，我们其实一直开着两辆车、走两条完全不相交的路，却在路的尽头发现——停的是同一个站牌。

一条路叫**采样路径**（第4–7章）。它从逆问题出发：我们想知道"给定一张模糊的 CT 图，真实的解可能长什么样"，而不是只要一个最可能的猜测。为了从后验（后验：给定观测后，我们对未知信号应该相信什么样的概率分布）里采样，我们一路走到 Langevin 动力学、得分函数、Tweedie 等式、得分匹配（得分匹配：一种不依赖真实分布就能学会"概率往哪涨"的训练技巧），最后抵达扩散模型。

另一条路叫**变分路径**（第8–11章）。它从生成建模出发：我们想让模型学会"真实数据看起来有多合理"，于是用证据下界 ELBO（ELBO：证据下界，一个永远不超过真实对数似然的可优化目标）绕过算不出的似然，经过 VAE、层级 VAE，也抵达了扩散模型。

**两条路各自的数学山头完全不同**，翻的坡、用的工具、出发的动机没有一处重叠。可是——你猜怎么着？两条路造出来的东西几乎一模一样：同样的去噪网络、同样的加噪过程、同样的采样循环。这不是巧合。本章要干的事，就是严格证明一个等式：

**DSM 损失 ≡ 变分下界（VLB）**（DSM：去噪得分匹配，一种"预测加进去了什么噪声"的训练损失；VLB：变分下界，把 ELBO 套到扩散模型上得到的具体形式）。

也就是说：采样路径在优化"概率梯度的准确度"，变分路径在优化"概率值的大小"，而这两者其实是同一个数学对象的两种写法。两条路，一个终点。

## 两条路，一个终点

回想一下：第3章末尾我们站在了分叉口。MAP 估计（MAP：最大后验，只给你一个点估计，也就是"最可能的那一个解"）丢掉了后验的全部不确定性。要真正处理复杂的后验，有两条路可走——

**采样路径**（第4–7章，主线），驱动力是逆问题的后验采样需求：

```
逆问题需要后验采样 → MCMC 太慢 → 用 Langevin 借梯度加速
→ 得分函数 ∇log p 算不出 → Tweedie 等式用去噪器取而代之
→ 得分匹配(DSM) 学会它 → 多步扩散采样
```

每一步都是前一步"卡住了"的自然回应。我们从来没想过要建生成模型，只是想给逆问题找一个能用的采样器。

**变分路径**（第8–11章，副线），驱动力是生成建模的最大似然需求：

```
生成模型要最大似然 → 似然算不出 → ELBO 给个下界
→ VAE 用编码-解码 + 重参数化 → 层级 VAE 加深潜变量
→ 无限层极限 → 扩散模型 = 无限层 VAE
```

每一步都在提升表达能力。我们从来没想过逆问题，只是想让模型给真实数据打高分。

**惊人的事实**：两条路的终点——扩散模型——在工程上几乎完全一致。把组件摆在一起对比：

| 组件 | 采样路径 | 变分路径 |
|---|---|---|
| 加噪过程 | $x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$ | 完全相同 |
| 去噪器网络 | $\epsilon_\theta(x_t, t)$ | 完全相同 |
| 训练数据对 | $(x_t, \epsilon)$ | 完全相同 |
| 采样过程 | 逆向 SDE / DDPM | 完全相同 |

> **如果两套完全不同的理论，推导出了逐行一样的算法，那它们在数学上一定等价。** 本章就是要亲手把这个"一定"坐实。

## 为什么这一章重要（请你带着这个问题读）

本章要回答全书最根本的一个追问：**为什么逆问题的研究，最后会走向扩散模型？**

等价性告诉我们：从逆问题的后验采样需求出发（采样路径），和从生成模型的最大似然需求出发（变分路径），最终到了同一个地方。这不是偶然——得分函数 $\nabla\log p(x)$ 是概率分布的"梯度信息"，而 $\log p(x)$ 是"概率值信息"。梯度与函数值，是同一数学对象的不同表示；学好梯度，就等于学好函数值。两条路径殊途同归，是贝叶斯框架（贝叶斯框架：用概率分布统一描述"已知"和"未知"，用后验描述"看到证据后该信什么"）内在逻辑的必然结果。
