# 12.6 实践意义与训练目标选择

> 核心观点：DSM ≡ VLB 的等价性不只是理论上的漂亮结论，它直接指导实践——同一个扩散模型可以从两种视角理解和训练，而训练目标的选择（简化 VLB vs 完整 VLB vs 自定义权重）是影响生成质量和似然性能的关键工程决策。

读完证明，你手里攥着一个 powerful 的事实：**无论你从"学得分函数"还是"最大化似然下界"出发，训练算法完全相同。** 但工程上仍有一个真问题没解决：

> **既然算法一样，我到底该用哪个"视角"、哪个"权重"去训？**

这一节就回答它。先给一个会让你会心一笑的观察：等价性意味着，下面这段不到 10 行的训练循环，既是 DSM 训练，又是 VLB 训练——取决于你怎么"解读"它。

## 一、同一扩散模型的两种训练视角

### 两种视角，一个算法

等价性告诉我们：无论从"学习得分函数"（采样路径）还是"最大化似然下界"（变分路径）出发，最终训练算法完全相同：

```
算法：扩散模型训练
1. 从训练集采样 x_0
2. 采样时间步 t ~ Uniform{1, ..., T}
3. 采样噪声 ε ~ N(0, I)
4. 计算含噪输入 x_t = √ᾱ_t · x_0 + √(1-ᾱ_t) · ε
5. 计算损失 L = ‖ε - ε_θ(x_t, t)‖²
6. 更新参数 θ ← θ - η · ∇_θ L
```

这个算法同时是：

- **DSM 训练**：步骤 5 是最小化 DSM 损失（$\lambda=\sigma^2$ 时）
- **VLB 训练**：步骤 5 是最小化简化 VLB（均匀权重时）

**两套理论，推导出了同一段不到 10 行的代码。** 这就是等价性最朴素的样子。

### 理解视角影响调试策略

算法虽同，但"你把它想成什么"会影响怎么 debug：

**采样视角的调试思路**：
- "得分函数估计不准" → 调整噪声调度，让中等噪声水平的训练更充分
- "采样不收敛" → 调采样步数或数值求解器
- "低密度区域得分差" → 用退火或重要性采样

**变分视角的调试思路**：
- "似然下界不够高" → 检查 VLB 各项贡献，找瓶颈
- "重建质量差" → 加模型容量或训练数据
- "KL 正则太强" → 调噪声调度的总噪声量

两种视角是互补的诊断工具——这也是等价性的实践价值之一。

## 实验 12.6-1：实践意义与训练目标选择

实验 `12.6-1.py` 通过训练两个架构相同、目标相同但随机种子不同的模型（分别标记为"采样路径"和"变分路径"），对比训练曲线、采样结果，并从同一网络输出中同时提取得分函数、逆向均值和 $x_0$ 估计，直观展示等价性的实践含义。

### 实验场景

实验在 MNIST 数据集上训练两个 SmallUNet 去噪网络（通道数 [16, 32, 64]，时间嵌入维度 64），使用 DDPM 线性噪声调度（$T=200$，$\beta_{\min}=10^{-4}$，$\beta_{\max}=0.02$），数据归一化到 $[-1, 1]$：

**模型 A（采样路径，种子 42）**：从 DSM 视角理解，训练目标为 $\|\epsilon - \hat\epsilon_\theta\|^2$

**模型 B（变分路径，种子 123）**：从 VLB 视角理解，训练目标为 $\|\epsilon - \hat\epsilon_\theta\|^2$

两个模型用完全相同的网络架构、相同的损失函数、相同的训练流程，仅随机种子不同。训练 50 轮后，各采样 8 张图像对比，并从模型 A 的输出 $\hat\epsilon_\theta$ 中同时提取三种信息。

### 实验目的

1. **验证训练目标等价**：两条路径训练曲线总体收敛趋势相近，差异仅来自随机初始化
2. **验证采样结果一致**：两条路径训练出的模型，采样质量相当
3. **双向验证**：从同一个网络输出 $\hat\epsilon_\theta$ 同时提取得分函数 $s_\theta$、逆向均值 $\mu_\theta$、$x_0$ 估计 $\hat x_0$，验证一个网络输出承载三种信息
4. **展示实践意义**：选哪种路径解释不影响训练和采样——代码完全相同

### 实验输入

| 参数 | 设置 |
|------|------|
| 数据集 | MNIST，60000 训练样本，归一化到 $[-1, 1]$ |
| 网络架构 | SmallUNet，通道数 [1, 16, 32, 64]，时间嵌入维度 64 |
| 噪声调度 | DDPM 线性，$T=200$，$\beta_{\min}=10^{-4}$，$\beta_{\max}=0.02$ |
| 训练配置 | Adam 优化器，学习率 $2\times 10^{-4}$，batch size 128，50 轮 |
| 模型 A 种子 | 42（采样路径/DSM） |
| 模型 B 种子 | 123（变分路径/VLB） |
| 采样数量 | 每个模型各采样 8 张 $28\times 28$ 图像 |
| 双向验证 | 从模型 A 在 $t=50$ 时的输出 $\hat\epsilon_\theta$ 提取 $s_\theta$、$\mu_\theta$、$\hat x_0$ |

### 预期结果

- 训练曲线：两条路径损失曲线总体收敛趋势相近，最终损失接近（细节差异来自不同随机初始化）
- 采样结果：两个模型各采样 8 张图像，均能生成可辨认的 MNIST 数字，质量相当
- 双向验证：从同一 $\hat\epsilon_\theta$ 提取的 $s_\theta$、$\mu_\theta$、$\hat x_0$ 范数不同但均有意义，验证"一个网络输出，三种解读，三种用途"
- 因模型容量较小（SmallUNet）且训练轮数有限（50 轮），采样结果可能略模糊，但两条路径的一致性仍清晰可见

#### 步骤 3：双向验证

从模型 A（采样路径）在 $t=50$ 时的网络输出 $\hat\epsilon_\theta$ 中，同时提取三种信息：

| 提取量 | 公式 | 范数 | 路径 |
|--------|------|------|------|
| $\hat\epsilon_\theta$ | 网络直接输出 | 56.77 | 公共语言 |
| $s_\theta = -\hat\epsilon_\theta/\sqrt{1-\bar\alpha_t}$ | 得分函数 | 160.98 | 采样路径 |
| $\mu_\theta = \frac{1}{\sqrt{\alpha_t}}(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\hat\epsilon_\theta)$ | 逆向均值 | 27.23 | 变分路径 |
| $\hat x_0 = (x_t - \sqrt{1-\bar\alpha_t}\hat\epsilon_\theta)/\sqrt{\bar\alpha_t}$ | x₀ 估计 | 18.71 | Tweedie 等式 |

**→ 一个网络输出，三种解读，三种用途。**

- **采样路径视角**：$s_\theta$ 是得分函数，驱动 Langevin/SDE 采样
- **变分路径视角**：$\mu_\theta$ 是逆向均值，构建 DDPM 逆向过程 $p_\theta(x_{t-1}|x_t)$
- **Tweedie 等式**：$\hat x_0$ 是去噪估计，可直接用于重建

三种提取方式共享同一个 $\hat\epsilon_\theta$，仅通过不同解析变换得到不同用途的量。这正是 DSM≡VLB 等价性的实践体现——网络只需学一种参数化（ε-prediction），其余信息可解析转换。

## 二、ε 预测：两条路径的公共语言

三种参数化里，ε 预测最常用，原因很实在：

1. **等价性的直接体现**：ε 预测是 DSM 与 VLB 的共同目标——$\|\epsilon - \epsilon_\theta\|^2$
2. **训练稳定**：ε 预测目标（猜噪声）在不同时步的尺度相对均匀，而 $x_0$ 预测和得分预测的尺度随时步剧烈变化
3. **物理直觉清晰**："猜加进去了什么噪声"比"猜原始信号"或"猜概率梯度"更直白
4. **工程便利**：噪声 $\epsilon$ 的分布是标准高斯，与时步无关，简化了损失计算和归一化

### ε 预测的局限

也有短板：在极小时间步（低噪声），ε 预测目标几乎退化成恒等映射（$\epsilon_\theta(x_t, t) \approx \epsilon$），导致梯度消失。这也解释了为什么简化 VLB（均匀权重）在实践中优于完整 VLB——均匀权重自动降低了小时间步的过度权重。

## 三、训练目标选择指南

基于等价性，扩散模型的训练目标可统一写成：

$$L(\theta) = \sum_{t=1}^T c(t)\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

$c(t)$ 是时间步权重。三种主要选择：

### 选项 1：简化 VLB / 简化 DSM（$c(t) = 1$）

$$L_\text{simple} = \mathbb{E}_{t,x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

**优点**：实现最简单；训练稳定（权重均匀，无极端梯度）；生成质量最好（FID/IS 最优，Ho et al. 2020 验证）；自动降低小 $t$ 项的过度影响。
**缺点**：不是严格最大似然——codelength 次优；不同噪声水平训练信号不均衡。
**适用**：追求生成质量（图像生成、艺术创作）。

### 选项 2：完整 VLB / 加权 DSM（$c(t) = w_t$）

$$L_\text{VLB} = \sum_{t=1}^T w_t\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

**优点**：严格最大似然下界；codelength 最优（数据压缩场景）；理论上最优权重。
**缺点**：权重 $w_t$ 在小 $t$ 时极大（$\propto 1/\beta_t$），训练不稳定；生成质量通常不如简化目标；需精心设计学习率和梯度裁剪。
**适用**：追求似然性能（数据压缩、密度估计）。

### 选项 3：重要性采样加权（$c(t) = \text{IS}_t$）

$$L_\text{IS} = \sum_{t=1}^T \text{IS}_t\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

$\text{IS}_t$ 是基于损失方差的重要性采样权重。

**优点**：在完整 VLB 和简化 VLB 间取得平衡；降低高方差时间步影响，提高训练效率；兼顾质量和似然。
**缺点**：实现更复杂（需维护损失方差估计）；需额外超参数调优。
**适用**：需兼顾质量和似然的高端应用。

### 选择决策树

```
你的主要目标是什么？
├── 生成质量（FID/IS）→ 简化 VLB（选项1）
├── 似然/压缩（codelength）→ 完整 VLB（选项2）
└── 两者兼顾 → 重要性采样（选项3）
    └── 实现复杂度可接受？→ 是 → 选项3
                                  └── 否 → 选项1（通常质量更关键）
```

## 四、噪声调度与时间加权的实践影响

### 噪声调度的选择影响权重分布

不同噪声调度 $\{\beta_t\}$ 对应不同 VLB 权重 $\{w_t\}$ 分布：

- **线性调度**（$\beta_t$ 从 $\beta_1$ 线性增长到 $\beta_T$）：$w_t$ 在小 $t$ 时非常大，强调低噪声去噪
- **余弦调度**（Nichol & Dhariwal 2021）：$\bar\alpha_t$ 按余弦衰减，权重分布更均匀
- **SNR 感知调度**：直接控制信噪比 $\text{SNR}(t) = \bar\alpha_t/(1-\bar\alpha_t)$ 的衰减方式

选"好的"噪声调度，本质上是在选"好的"权重函数——和 DSM 的 $\lambda(\sigma)$ 选择是同一件事。

### 时间步采样策略

训练时如何采时间步 $t$ 也是重要选择：

- **均匀采样**：$t \sim \mathcal{U}\{1, T\}$（最常用，对应简化 VLB）
- **重要性采样**：按损失方差比例采样 $t$（降低高方差步的采样频率）
- **分箱采样**：把时间步分区间，每区间等量采样（确保各噪声水平被充分训练）

### Improved DDPM 的启示

Nichol & Dhariwal (2021) 的 Improved DDPM 提供重要实践启示：

1. **学习方差**：把逆向过程方差从固定值改成可学习参数，让模型在"保留细节"（小方差）和"添加随机性"（大方差）间自适应选择
2. **VLB 微调**：先用简化 VLB 训练，再用完整 VLB 微调——结合两者优点
3. **余弦调度**：比线性调度更平滑的噪声增长，改善小 $t$ 的训练

这些改进都能通过等价性框架理解：它们本质是在优化权重函数 $\lambda(\sigma)$ 的选择，以获得更好训练效果。
