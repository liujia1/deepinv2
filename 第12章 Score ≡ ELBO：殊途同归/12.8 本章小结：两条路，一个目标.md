# 12.8 本章小结：两条路，一个目标

> 核心观点：本章把一个"看着像巧合"的现象升级成了一条定理——采样路径优化的 $\|\varepsilon-\varepsilon_\theta(\mathbf{x}_t,t)\|^2$ 与变分路径优化的 VLB，在时间权重取 $w_t$ 时逐项相等。于是"得分是梯度化的对数似然"不再只是直觉，而是可以写进训练循环的等式；扩散模型的两套语言，从此合成一套。

## 一、本章走过了什么

```
12.1 采样路径回顾：Tweedie 等式 → DSM 损失 → ε 预测 → 多尺度权重 λ(t)
  │
12.2 变分路径回顾：ELBO → 层级 VAE → VLB 三分解 → ε 预测 VLB
  │
12.3 结构对比：预测目标相同、含噪输入相同、只差时间权重
  │
12.4 形式化证明：权重匹配 λ_t = 2σ_t² w_t ⇒ DSM ≡ VLB（含简化版与三种参数化）
  │
12.5 连续时间：SDE 与 VDM 的连续极限重合，概率流 ODE 成第三种交汇
  │
12.6 实践意义：c(t)=1、c(t)=w_t、c(t)=IS_t 三种加权各适合什么目标
  │
12.7 全书叙事：扩散模型不是逆问题的旁支，而是它逻辑推演的终点
```

- **12.1**：把采样路径的工具箱重新摆出来——Tweedie 等式让去噪器顶替得分，得分匹配把"学得分"变成"猜噪声"，多尺度噪声调度则把单点结论拼成一条时间轴。
- **12.2**：把变分路径的工具箱摆出来——ELBO 绕过算不出的似然，层级 VAE 加深潜变量，VLB 三分解后同样落到"猜噪声"，只是每一步带着自己的权重。
- **12.3**：两条路的损失并排放在一起，预测目标、输入、网络结构三项一致，差别只剩一个时间权重函数——这是"同归"的结构证据，也是 12.4 要处理的对象。
- **12.4**：把结构证据变成定理。若取 $\lambda_t = 2\sigma_t^2 w_t$，加权 DSM 与完整 VLB 逐项相等；权重全取 1 时，简化 DSM 与简化 VLB 也只差一个常数。三种参数化（$\varepsilon$、$\mathbf{x}_0$、得分）在这条等式下彼此一致。
- **12.5**：离散结论在连续时间下同样成立——score-SDE 的训练目标与 VDM 的连续下界重合，概率流 ODE 从第三条路走到同一处，三方框架收成一个。
- **12.6**：等价性的实践含义不是"随便选"，而是"选权重等于选代价"。要生成质量就均匀加权，要似然与压缩就上完整权重，要两者兼顾就用重要性采样。
- **12.7**：回到全书主线——等价性证明了逆问题研究走进扩散模型不是巧合，而是贝叶斯框架推到底的必然。

## 二、两条路径的对应关系

| 环节 | 采样路径（第 4–7 章） | 变分路径（第 8–11 章） |
|---|---|---|
| 出发点 | 逆问题要探索后验，不能只要一个点 | 生成模型要最大化似然 |
| 卡住的地方 | 得分函数算不出来 | 似然函数算不出来 |
| 绕过去的工具 | Tweedie 等式 + 得分匹配 | ELBO + 层级 VAE |
| 最终落到的动作 | 回归噪声 $\|\varepsilon-\varepsilon_\theta\|^2$ | 回归噪声 $\|\varepsilon-\varepsilon_\theta\|^2$ |
| 两者的差别 | 时间权重 $\lambda_t$ | 时间权重 $2\sigma_t^2 w_t$ |
| 连续极限 | score-SDE | VDM |
| 采样器 | 逆向 SDE / 概率流 ODE | 同一条 ODE |

这张表右侧一列与左侧一列并不是"类比关系"，而是同一个对象在两种记法下的写法——这正是 12.4 定理的内容，也是本章与前面各章回顾性叙述的区别所在。

## 三、等价性交还给读者的三件事

1. **调试视角可以互换**。训练不收敛时，既可以从"得分估计是否准"入手，也可以从"下界是否被抬高"入手；两种诊断指向同一个故障点。
2. **训练目标的选择就是权重的选择**。$c(t)$ 定了，目标就定了；剩下的不是理论问题，而是明确代价后的工程取舍。
3. **连续化不带来新理论**。从离散到连续，公式变长、常数变多，但没有出现新的数学对象；认识到这一点，读论文时就不必把 SDE 与 VDM 当成两套独立体系。

## 四、与前后章的呼应

- **承接第 11 章**：11.5 留下的那句"ε 预测 VLB 与 DSM 只差时间权重"，在 12.3 被坐实、在 12.4 被证明。
- **回收第 6 章**：当时学得分匹配，只知道它是"绕开归一化常数"的训练技巧；现在知道它同时是最大似然的一个下界，技巧变成了原理。
- **开放给第 13 章**：本章的统一是"无条件"的——没有观测、没有算子、没有噪声模型。第 13 章把条件接上去，让这套等价关系去解真正的逆问题，全书闭环。

## 五、一句话总结

把整章压成一句：**两条出发点相反、工具不重叠的路，在同一个回归问题前停下；而证明它们停在同一处，靠的不是比喻，是一次权重匹配。**
