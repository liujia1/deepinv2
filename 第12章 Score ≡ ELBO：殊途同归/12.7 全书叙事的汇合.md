## 二、核心论点的验证

### 全书核心论点

第1章提出：**扩散模型是逆问题自然发展的产物**。更具体地说：

> 逆问题需要后验采样 → 采样需要得分函数 → 得分函数可从去噪器提取（Tweedie）→ 去噪器可通过得分匹配训练 → 多步得分驱动采样即扩散模型。

这条链有明确因果逻辑：逆问题的需求驱动了每一步方法演化。

### 等价性如何验证论点

DSM ≡ VLB 从另一个角度验证这个论点：

1. **逆问题驱动论**：采样路径每步都是逆问题局限性的自然回应——论点的直接证据；
2. **殊途同归论**：变分路径从完全不同的出发点（最大似然）也走向扩散模型——论点的间接证据；
3. **等价性论**：两条路径训练目标在数学上等价——意味着"逆问题的需求"与"生成建模的需求"在深层是一致的。

综合三点，等价性不仅验证核心论点，还揭示更深层事实：**逆问题的需求与生成建模的需求不是两件事，而是同一数学结构的不同侧面**。

### "殊途同归"的深层原因

为什么两条独立发展的路径必然殊途同归？根本在贝叶斯框架的内在结构：

$$\log p(x) \quad\text{与}\quad \nabla\log p(x)$$

是同一概率分布 $p(x)$ 的两种等价数学表示：

- $\log p(x)$ 是概率分布的"标量场"——描述每个点的概率值；
- $\nabla\log p(x)$ 是概率分布的"向量场"——描述概率变化的速率和方向。

标量场和向量场由梯度和积分互相关联，信息量等价。因此：

- VLB 优化 $\log p(x)$ 的下界——学概率的标量信息；
- DSM 优化 $\nabla\log p(x)$ 的估计精度——学概率的向量信息。

学好向量信息 → 积分得标量信息（差常数）；学好标量信息 → 微分得向量信息。两者必然等价。

> **从更深层次看**，这个"标量场/向量场"的对照正是贝叶斯框架的统一性体现：无论你是想"算出后验的值"还是"走向后验的高处"，你需要的其实都是同一份关于后验的知识，只是用值还是用梯度去表达它。这一转变意味着，本书反复强调的"先验→后验→采样"思想路径，在数学上可以归结为"同一分布的知识用两种等价形式传递"。

### 更一般的数学原理

等价性反映了一个更一般的数学原理：

**原理**：对光滑函数 $f: \mathbb{R}^d \to \mathbb{R}$，以下两个优化目标在适当条件下等价：

1. 最小化 $\|g - \nabla f\|^2$（逼近梯度）
2. 最大化 $f$ 的下界（逼近函数值）

当 $g = \nabla h$（$h$ 是 $f$ 的近似），两者等价，因为费舍信息（梯度的二阶统计量）控制了函数值之间的 KL 散度。

这个原理不仅适用于扩散模型，也适用于其他场景——例如，对比学习（学表示的"方向"）与生成模型（学表示的"值"）之间的等价性。

## 三、从等价性到条件生成（展望第13章）

### 等价性建立了无条件扩散的统一理论

第12章建立了无条件扩散模型（$p(x)$）的统一理论：DSM ≡ VLB，两条路径等价。

### 第13章的展望

第13章把等价性扩展到条件扩散模型 $p(x|y)$，$y$ 是观测。核心等式是后验得分分解：

$$\nabla\log p(x|y) = \nabla\log p(x) + \nabla\log p(y|x)$$

- 第一项 $\nabla\log p(x)$ 由无条件扩散模型提供（已学到的先验得分）；
- 第二项 $\nabla\log p(y|x)$ 根据具体逆问题设计。

条件扩散采样 $p(x|y)$ 就是逆问题求解——从观测 $y$ 出发，采样后验分布 $p(x|y)$。这把全书带回第1章起点，完成闭环：

$$\text{逆问题} \xrightarrow{\text{贝叶斯}} \text{后验采样} \xrightarrow{\text{得分匹配}} \text{扩散模型} \xrightarrow{\text{条件采样}} \text{逆问题求解}$$

## 四、逆问题求解中的"又一重"殊途同归

第13章在建立"条件扩散采样 = 逆问题求解"时，实际上复现了与本章同构的"双路径"结构——构成全书核心论点的**第二重闭环**：

- **得分路径（后验得分分解）**：Chung et al. (2025) 把条件采样拆为
  $$\nabla\log p(x|y) = \nabla\log p(x) + \nabla\log p(y|x)$$
  第一项是无条件先验得分（本章已学），第二项由具体正向算子 $A$ 提供。DPS、DDRM 等显式近似方法都走这条路。Chung et al. 还给出与之平行的"变分视角"（从联合分布 $p(x,y)$ 出发推导），与本书第8–11章的变分路径遥相呼应。
- **控制路径（最优控制）**：Li & Pereira (NeurIPS 2024) 把同一步采样重述为一个离散最优控制问题——把数据一致性当作控制代价，把去噪得分当作动力学。其优雅结论是：**所需的条件得分函数直接等于价值函数 $V(x_t,t)$ 对其状态 $x_t$ 的雅可比** $\nabla_{x_t}V$。

两条路径处理同一件事（从 $y$ 采样 $p(x|y)$），却分别用"得分的加法分解"与"价值函数的梯度"两种语言描述，最终数学上等价。这恰是 $\log p$ 与 $\nabla\log p$ 等价（本章核心原理）在**条件生成**上的重演：标量场（价值/对数似然）与向量场（得分/价值梯度）本是一体两面。

> 因此，"殊途同归"不仅发生在无条件扩散的 DSM ≡ VLB，也发生在条件扩散的逆问题求解中。这进一步印证第1章核心论点：扩散模型是逆问题自然发展的产物，而这一产物的理论结构，在不同层面上反复自洽地"收网"。

> **这一转变意味着**：第12章的正等价与条件情况下的第二重等价交叠在一起，构成一个不自洽就站不住的双保险——无论从无条件生成的"得分 vs 变分"，还是从逆问题求解的"得分分解 vs 最优控制"，殊途同归都在反复重现。这正是"统一理论"与"几个凑巧相似的公式"最本质的区别。

## 六、动手感受一下：同一网络、两种损失，梯度方向几乎一致（可运行代码）

先猜个数字：如果你用同一个网络、同一批数据，分别用 DSM 损失和 VLB 来更新参数——你猜这两个"该往哪更新"的信号，方向会差多远？是乱七八糟、毫无关系？还是指向同一个方向？

> **揭晓**：它们指向**几乎完全相同的方向**，余弦相似度接近 1，只差一个正的常数倍。下面这段重度注释的 numpy 代码，用一个**一维双峰高斯混合**做最简示例，让你亲眼看到这件事。不需要任何深度学习框架，纯 numpy 就能跑。

```python
# -*- coding: utf-8 -*-
# 第12章 章末复现：DSM 损失 ≡ VLB（一维数值验证）
# 目标：用最朴素的一维例子，亲眼看到"同一个网络、两种损失、梯度方向一致"
# 需要：numpy（可选 matplotlib 画图）

import numpy as np

# ---------- 0. 设定：一维双峰先验 p(x0) = 0.5 N(-3,1) + 0.5 N(3,1) ----------
# 这是我们要"学会"的真实数据分布。我们假装不知道它的参数，
# 只通过"加噪-去噪"的游戏让一个小网络去近似它。

rng = np.random.default_rng(0)

def sample_x0(n=2000):
    """从双峰先验里采样 n 个干净样本 x0。"""
    comp = rng.integers(0, 2, size=n)          # 随机选左峰还是右峰
    mean = np.where(comp == 0, -3.0, 3.0)
    return mean + rng.normal(0.0, 1.0, size=n)  # 加一点高斯抖动

# ---------- 1. 退化成一个"单参数网络"：epsilon_theta(x_t, t) = a * x_t + b ----------
# 真实一维 VP-SDE 下，理想去噪器是线性的，所以我们用一个最简单的线性网络
# epsilon_theta = a * x_t + b，参数 theta = [a, b]。
# 注意：这里 a, b 就是我们要训练的全部参数——够小，方便手算梯度。

# VP-SDE 的离散噪声调度（极简版，T=5 步）
betas = np.linspace(0.1, 0.3, 5)               # β_1..β_5
alphas = 1.0 - betas
bar_alphas = np.cumprod(alphas)                # ᾱ_t
one_minus_bar = 1.0 - bar_alphas               # 1 - ᾱ_t

# VLB 权重 w_t（来自 12.4 节公式）：w_t = β_t^2 / (2 * β̃_t * α_t * (1-ᾱ_t))
# 其中 β̃_t = (1-ᾱ_{t-1}) β_t / (1-ᾱ_t)
bar_alphas_prev = np.concatenate([[1.0], bar_alphas[:-1]])  # ᾱ_{t-1}，t=1 时取 1
beta_tilde = (1.0 - bar_alphas_prev) * betas / (1.0 - bar_alphas)
w_t = betas**2 / (2.0 * beta_tilde * alphas * (1.0 - bar_alphas))

# 让 DSM 权重匹配 VLB 权重所需的 λ(t)（来自 12.4 核心定理）：
#   λ(t) / [2 (1-ᾱ_t)] = w_t   →   λ(t) = 2 * w_t * (1-ᾱ_t)
lambda_t = 2.0 * w_t * (1.0 - bar_alphas)

# DSM 在 VP-SDE 下的单步权重（来自 12.4 第三步）：λ(t) / [2 (1-ᾱ_t)]
dsm_weight_t = lambda_t / (2.0 * (1.0 - bar_alphas))   # 理论上应等于 w_t
print("权重匹配检查  w_t :", np.round(w_t, 4))
print("权重匹配检查  dsm :", np.round(dsm_weight_t, 4))
print("两者比值(应≈1):", np.round(dsm_weight_t / w_t, 6))

# ---------- 2. 前向加噪：x_t = sqrt(ᾱ_t) x0 + sqrt(1-ᾱ_t) ε ----------
def forward(x0, t, n=None):
    """给定 x0 和时间步 t(0-indexed)，返回含噪样本 x_t 和所用噪声 ε。"""
    sq = np.sqrt(bar_alphas[t])
    sq1m = np.sqrt(1.0 - bar_alphas[t])
    if n is None:
        n = x0.shape[0]
    eps = rng.normal(0.0, 1.0, size=n)
    xt = sq * x0 + sq1m * eps
    return xt, eps

# ---------- 3. 两种损失的"梯度"（对参数 theta=[a,b]）----------
# 损失核心都是 ‖ε - epsilon_theta(x_t,t)‖^2，只是权重不同。
# epsilon_theta = a * x_t + b，所以残差 r = ε - (a x_t + b)。
# 对 a 的梯度 = -2 * 权重 * E[r * x_t]，对 b 的梯度 = -2 * 权重 * E[r]。

def grad_loss(theta, weight_per_t, n=4000):
    """返回两种损失（VLB 与 DSM）对 theta 的梯度，权重逐 t 累加。"""
    a, b = theta
    g_vlb = np.zeros(2)
    g_dsm = np.zeros(2)
    x0 = sample_x0(n)
    for t in range(len(betas)):
        xt, eps = forward(x0, t, n)
        pred = a * xt + b               # epsilon_theta
        r = eps - pred                  # 残差
        # 期望用蒙特卡洛平均近似
        g_vlb[0] += -2.0 * w_t[t]      * np.mean(r * xt)   # d/da
        g_vlb[1] += -2.0 * w_t[t]      * np.mean(r)        # d/db
        g_dsm[0] += -2.0 * dsm_weight_t[t] * np.mean(r * xt)
        g_dsm[1] += -2.0 * dsm_weight_t[t] * np.mean(r)
    return g_vlb, g_dsm

# ---------- 4. 在几个不同 theta 上检查：两梯度方向是否一致 ----------
thetas = [[0.0, 0.0], [0.3, -0.2], [-0.5, 0.4], [1.2, 1.0]]
print("\ntheta\t\tVLB梯度\t\t\tDSM梯度\t\t\tcos相似度")
for th in thetas:
    gv, gd = grad_loss(np.array(th))
    # 余弦相似度：两向量方向一致时≈1（允许差一个正标量倍）
    cos = np.dot(gv, gd) / (np.linalg.norm(gv) * np.linalg.norm(gd) + 1e-12)
    print(f"{th}\t{gv.round(4)}\t{gd.round(4)}\t{cos:.6f}")

# ---------- 5. 结论 ----------
# 你会发现：对每个 theta，VLB 梯度与 DSM 梯度方向几乎完全一致（cos≈1），
# 且两者数值上满足 g_dsm ≈ (dsm_weight/w_t 的常数) * g_vlb —— 即仅差常数倍，
# 这正是 "DSM ≡ VLB（仅差常数）" 在一维玩具问题上的数值体现。
# 换句话说：同一个网络、同一批数据，从"得分匹配"和"变分下界"两条路出发，
# 收到的"该往哪更新参数"的信号，指向同一个方向。
```

**怎么读这段代码**：第 1 段按 12.4 节公式算出 VLB 权重 $w_t$ 和匹配用的 $\lambda(t)$，并打印"两者比值≈1"——先亲手确认权重确实能对上。第 4 段在几个不同的网络参数 $\theta$ 上，分别算出 VLB 梯度（采样路径视角）和 DSM 梯度（变分路径视角），算它们的余弦相似度。你会看到 cosine 接近 1：**两个视角给的更新方向一致，只差一个正的标量倍**——这正是"DSM ≡ VLB（仅差常数）"这句话在一维玩具上的数值化身。

## 七、收尾：为什么这件事重要

把整本书压缩成一句话：

> **得分（Score）= 梯度化的 ELBO。概率的"梯度"和"数值"本是一体两面；所以无论你从逆问题的后验采样出发，还是从生成模型的最大似然出发，最后都殊途同归到同一个扩散模型——两条路，一个终点。**

这就是为什么第1章埋下的种子，会在第12章开花：逆问题的研究不是"碰巧"走进了扩散模型，而是贝叶斯框架的逻辑必然把它领到了这。**从更深层次看**，那枚种子从一开始就包含着这次汇合——贝叶斯推断要"先验与证据融合"，先验给出结构、采样给出对后验的探索，而扩散模型正是在无穷层变分假设下把这一思想推到极限的产物。下一章，我们把这个统一理论接上"条件"，让它真正去解逆问题——全书闭环。
