# 12.6 实践意义与训练目标选择

> **核心观点**：DSM ≡ VLB的等价性不仅是理论上的优美结论，更有直接的实践意义。它意味着同一个扩散模型可以从两种视角理解和训练，而训练目标的选择（简化VLB vs 完整VLB vs 自定义权重）是影响模型生成质量和似然性能的关键工程决策。

## 同一扩散模型的两种训练视角

### 两种视角，一个算法

等价性告诉我们：无论你从"学习得分函数"（采样路径）出发，还是从"最大化似然下界"（变分路径）出发，最终得到的训练算法是完全相同的：

```
算法：扩散模型训练
1. 从训练集采样 x_0
2. 采样时间步 t ~ Uniform{1, ..., T}
3. 采样噪声 ε ~ N(0, I)
4. 计算含噪输入 x_t = √ᾱ_t · x_0 + √(1-ᾱ_t) · ε
5. 计算损失 L = ‖ε - ε_θ(x_t, t)‖²
6. 更新参数 θ ← θ - η · ∇_θ L
```

这个算法同时是：
- **DSM训练**：步骤5是最小化DSM损失（$\lambda=\sigma^2$时）
- **VLB训练**：步骤5是最小化简化VLB（均匀权重时）

两种理论推导出了完全相同的5行代码。

### 理解视角影响调试策略

虽然训练算法相同，但理解视角影响我们如何调试和改进模型：

**采样视角的调试思路**：
- "得分函数估计不准"→ 调整噪声调度，使得在中等噪声水平的训练更充分
- "采样过程不收敛"→ 调整采样步数或数值求解器
- "低密度区域得分差"→ 使用退火或重要性采样

**变分视角的调试思路**：
- "似然下界不够高"→ 检查VLB各项的贡献，找到瓶颈
- "重建质量差"→ 增加模型容量或训练数据
- "KL正则化太强"→ 调整噪声调度的总噪声量

两种视角提供互补的诊断工具——这也是等价性的实践价值之一。

## 实验 12.6-1：实践意义与训练目标选择

实验 `12.6-1.py` 通过训练两个架构相同、目标相同但随机种子不同的模型（分别标记为"采样路径"和"变分路径"），对比其训练曲线、采样结果，并从同一网络输出中同时提取得分函数、逆向均值和 x₀ 估计，直观展示等价性的实践含义。

### 实验场景

实验在 MNIST 数据集上训练两个 SmallUNet 去噪网络（通道数 [16, 32, 64]，时间嵌入维度 64），使用 DDPM 线性噪声调度（$T=200$，$\beta_{\min}=10^{-4}$，$\beta_{\max}=0.02$），数据归一化到 $[-1, 1]$：

**模型 A（采样路径，种子 42）**：从 DSM 视角理解，训练目标为 $\|\epsilon - \hat\epsilon_\theta\|^2$

**模型 B（变分路径，种子 123）**：从 VLB 视角理解，训练目标为 $\|\epsilon - \hat\epsilon_\theta\|^2$

两个模型使用完全相同的网络架构、相同的损失函数、相同的训练流程，仅随机种子不同。训练 50 轮后，各采样 8 张图像进行对比，并从模型 A 的输出 $\hat\epsilon_\theta$ 中同时提取三种信息。

### 实验目的

1. **验证训练目标等价**：两条路径的训练曲线总体收敛趋势相近，差异仅来自随机初始化
2. **验证采样结果一致**：两条路径训练出的模型，采样质量相当
3. **双向验证**：从同一个网络输出 $\hat\epsilon_\theta$ 同时提取得分函数 $s_\theta$、逆向均值 $\mu_\theta$、x₀ 估计 $\hat x_0$，验证一个网络输出承载三种信息
4. **展示实践意义**：选择哪种路径解释不影响训练和采样——代码完全相同

> **实验目的与章节匹配性检查**：实验目的完全对应 12.6 节"同一扩散模型的两种训练视角"小节的核心观点——"两种视角，一个算法"。步骤 1-2 验证训练动态和采样结果的一致性；步骤 3 验证"ε预测作为两条路径的公共语言"；步骤 4 验证双向提取能力。所有目的均服务于 12.6 节"选择哪种路径解释不影响训练和采样"的实践结论。

### 实验输入

| 参数 | 设置 |
|------|------|
| 数据集 | MNIST，60000 训练样本，归一化到 $[-1, 1]$ |
| 网络架构 | SmallUNet，通道数 [1, 16, 32, 64]，时间嵌入维度 64 |
| 噪声调度 | DDPM 线性，$T=200$，$\beta_{\min}=10^{-4}$，$\beta_{\max}=0.02$ |
| 训练配置 | Adam 优化器，学习率 $2\times 10^{-4}$，batch size 128，50 轮 |
| 模型 A 种子 | 42（采样路径/DSM） |
| 模型 B 种子 | 123（变分路径/VLB） |
| 采样数量 | 每个模型各采样 8 张 $28\times 28$ 图像 |
| 双向验证 | 从模型 A 在 $t=50$ 时的输出 $\hat\epsilon_\theta$ 提取 $s_\theta$、$\mu_\theta$、$\hat x_0$ |

### 预期结果

- 训练曲线：两条路径的损失曲线总体收敛趋势相近，最终损失接近（细节差异来自不同随机初始化）
- 采样结果：两个模型各采样 8 张图像，均能生成可辨认的 MNIST 数字，质量相当
- 双向验证：从同一 $\hat\epsilon_\theta$ 提取的 $s_\theta$、$\mu_\theta$、$\hat x_0$ 范数不同但均有意义，验证"一个网络输出，三种解读，三种用途"
- 由于模型容量较小（SmallUNet）且训练轮数有限（50 轮），采样结果可能略显模糊，但两条路径的一致性仍然清晰可见

> **预期结果与章节匹配性检查**：预期结果与 12.6 节"两种视角，一个算法"的核心观点完全对应。训练曲线相近验证"训练算法完全相同"；采样质量相当验证"选择哪种路径解释不影响采样"；双向验证验证"ε预测作为两条路径的公共语言"。采样结果模糊是因为实验设计侧重展示等价性而非追求生成质量（SmallUNet + 50 轮），这不影响核心结论的验证。

#### 步骤 3：双向验证

从模型 A（采样路径）在 $t=50$ 时的网络输出 $\hat\epsilon_\theta$ 中，同时提取三种信息：

| 提取量 | 公式 | 范数 | 路径 |
|--------|------|------|------|
| $\hat\epsilon_\theta$ | 网络直接输出 | 56.77 | 公共语言 |
| $s_\theta = -\hat\epsilon_\theta/\sqrt{1-\bar\alpha_t}$ | 得分函数 | 160.98 | 采样路径 |
| $\mu_\theta = \frac{1}{\sqrt{\alpha_t}}(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\hat\epsilon_\theta)$ | 逆向均值 | 27.23 | 变分路径 |
| $\hat x_0 = (x_t - \sqrt{1-\bar\alpha_t}\hat\epsilon_\theta)/\sqrt{\bar\alpha_t}$ | x₀ 估计 | 18.71 | Tweedie 等式 |

**→ 一个网络输出，三种解读，三种用途。**

- **采样路径视角**：$s_\theta$ 是得分函数，驱动 Langevin/SDE 采样
- **变分路径视角**：$\mu_\theta$ 是逆向均值，构建 DDPM 逆向过程 $p_\theta(x_{t-1}|x_t)$
- **Tweedie 等式**：$\hat x_0$ 是去噪估计，可直接用于重建

三种提取方式共享同一个 $\hat\epsilon_\theta$，仅通过不同的解析变换得到不同用途的量。这正是 12.4 节 DSM≡VLB 等价性的实践体现——网络只需学习一种参数化（ε-prediction），其余信息可解析转换。

## ε预测：两条路径的公共语言

### 为什么ε预测是最常用的参数化

在三种参数化中，ε预测在实践中最常用，原因包括：

1. **等价性的直接体现**：ε预测是DSM与VLB的共同目标——$\|\epsilon - \epsilon_\theta\|^2$
2. **训练稳定性**：ε预测的目标（预测噪声）在不同时间步的尺度相对均匀，而$x_0$预测和得分预测的尺度随时间步剧烈变化
3. **物理直觉清晰**："预测添加了什么噪声"比"预测原始信号"或"预测概率梯度"更直观
4. **工程便利**：噪声 $\epsilon$ 的分布是标准高斯，与时间步无关，简化了损失的计算和归一化

### ε预测的局限

ε预测也有局限：在非常小的时间步（低噪声），ε预测目标几乎退化为恒等映射（$\epsilon_\theta(x_t, t) \approx \epsilon$），导致梯度消失。这也是为什么简化VLB（均匀权重）在实践中优于完整VLB——均匀权重自动降低了小时间步的过度权重。

## 训练目标选择指南

### 三种主要训练目标

基于等价性，扩散模型的训练目标可以统一为：

$$L(\theta) = \sum_{t=1}^T c(t)\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

其中 $c(t)$ 是时间步权重。三种主要选择：

#### 选项1：简化VLB / 简化DSM（$c(t) = 1$）

$$L_\text{simple} = \mathbb{E}_{t,x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

**优点**：
- 实现最简单
- 训练稳定（权重均匀，无极端梯度）
- 生成质量最好（FID/IS最优）——Ho et al. (2020) 的实验验证
- 自动降低小 $t$ 项的过度影响

**缺点**：
- 不是严格的最大似然——codelength次优
- 不同噪声水平的训练信号不均衡

**适用场景**：追求生成质量（如图像生成、艺术创作）

#### 选项2：完整VLB / 加权DSM（$c(t) = w_t$）

$$L_\text{VLB} = \sum_{t=1}^T w_t\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

**优点**：
- 严格的最大似然下界
- codelength最优（数据压缩场景）
- 理论上最优的权重

**缺点**：
- 权重 $w_t$ 在小 $t$ 时极大（$\propto 1/\beta_t$），训练不稳定
- 生成质量通常不如简化目标
- 需要精心设计学习率和梯度裁剪

**适用场景**：追求似然性能（如数据压缩、密度估计）

#### 选项3：重要性采样加权（$c(t) = \text{IS}_t$）

$$L_\text{IS} = \sum_{t=1}^T \text{IS}_t\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

其中 $\text{IS}_t$ 是基于损失方差的重要性采样权重。

**优点**：
- 在完整VLB和简化VLB之间取得平衡
- 降低高方差时间步的影响，提高训练效率
- 兼顾质量和似然

**缺点**：
- 实现更复杂（需要维护损失方差的估计）
- 需要额外的超参数调优

**适用场景**：需要兼顾质量和似然的高端应用

### 选择决策树

```
你的主要目标是什么？
├── 生成质量（FID/IS）→ 简化VLB（选项1）
├── 似然/压缩（codelength）→ 完整VLB（选项2）
└── 两者兼顾 → 重要性采样（选项3）
    └── 实现复杂度可接受？→ 是 → 选项3
                                  └── 否 → 选项1（通常质量更关键）
```

## 噪声调度与时间加权的实践影响

### 噪声调度的选择影响权重分布

不同的噪声调度 $\{\beta_t\}$ 对应不同的VLB权重 $\{w_t\}$ 分布：

- **线性调度**（$\beta_t$ 从 $\beta_1$ 线性增长到 $\beta_T$）：$w_t$ 在小 $t$ 时非常大，强调低噪声去噪
- **余弦调度**（Nichol & Dhariwal 2021）：$\bar\alpha_t$ 按余弦函数衰减，权重分布更均匀
- **SNR感知调度**：直接控制信噪比 $\text{SNR}(t) = \bar\alpha_t/(1-\bar\alpha_t)$ 的衰减方式

噪声调度影响权重分布，进而影响训练行为。选择"好的"噪声调度本质上是在选择"好的"权重函数——这与DSM的 $\lambda(\sigma)$ 选择是同一问题。

### 时间步采样策略

训练过程中，如何采样时间步 $t$ 也是重要的实践选择：

- **均匀采样**：$t \sim \mathcal{U}\{1, T\}$（最常用，对应简化VLB）
- **重要性采样**：按损失方差的比例采样 $t$（降低高方差步的采样频率）
- **分箱采样**：将时间步分为几个区间，每个区间等量采样（确保各噪声水平被充分训练）

### Improved DDPM的启示

Nichol & Dhariwal (2021) 的Improved DDPM提供了重要的实践启示：

1. **学习方差**：将逆向过程的方差从固定值改为可学习参数，允许模型在"保留细节"（小方差）和"添加随机性"（大方差）之间自适应选择
2. **VLB微调**：先用简化VLB训练，再用完整VLB微调——结合两者的优点
3. **余弦调度**：比线性调度更平滑的噪声增长，改善小 $t$ 的训练

这些改进都可以通过等价性框架理解：它们本质上是在优化权重函数 $\lambda(\sigma)$ 的选择，以获得更好的训练效果。

等价性的实践意义在于统一了两种训练视角，明确了训练目标选择的关键性。现在，让我们回到全书的叙事主线，总结等价性对全书核心论点的验证。
