# 附录12A 连续时间得分匹配与变分下界的等价性推导

## A.1 连续时间 ELBO

### 连续时间扩散过程

把离散时间步推广成连续时间 $t \in [0, 1]$（从数据 $t=0$ 到噪声 $t=1$）。正向 SDE 为：

$$dx = f(\mathbf{x},t)\,dt + g(t)\,dw$$

边际分布 $q(\mathbf{x}_t|\mathbf{x}_0)$ 在 VP-SDE 设定下为：

$$q(\mathbf{x}_t|\mathbf{x}_0) = \mathcal{N}(\mathbf{x}_t | \sqrt{\bar{\alpha}(t)}\,\mathbf{x}_0,\, (1-\bar{\alpha}(t))I)$$

其中 $\bar{\alpha}(t)$ 是连续时间版本的累积乘积。它的直观含义与离散版一致：$\sqrt{\bar{\alpha}(t)}$ 度量"到时刻 $t$ 还保留了多少信号"，而 $(1-\bar{\alpha}(t))$ 度量"到时刻 $t$ 已经掺入了多少噪声"。

### 连续时间 ELBO 的推导

由 Jensen 不等式和离散→连续的极限，连续时间 ELBO 为：

$$\log p(\mathbf{x}_0) \geq \underbrace{\mathbb{E}_q\left[\log\frac{p(\mathbf{x}_0|x_\varepsilon)}{q(x_\varepsilon|\mathbf{x}_0)}\right]}_{\text{端点项}} + \underbrace{\int_0^1 \mathbb{E}_q\left[\frac{1}{2}\left\|\frac{\mu_\theta(\mathbf{x}_t,t) - \tilde{\mu}_t(\mathbf{x}_t,\mathbf{x}_0)}{\sigma(t)}\right\|^2\right]dt}_{\text{连续一致性积分}}$$

结构上它仍是"端点项 + 一致性积分"，与离散 VLB 的"重建项 + 一致性项和"一一对应——只是把求和换成了积分。

### ε 预测参数化下的连续一致性积分

在 ε 预测参数化下，连续一致性积分变为：

$$\int_0^1 w(t)\,\mathbb{E}_{\mathbf{x}_0,\varepsilon}\left[\|\varepsilon - \varepsilon_\theta(\mathbf{x}_t, t)\|^2\right]dt$$

$w(t)$ 是连续时间权重函数。

对 VP-SDE，$w(t)$ 的具体形式为：

$$w(t) = -\frac{1}{2}\frac{d[\bar{\alpha}(t)]/dt}{\bar{\alpha}(t)\,[1-\bar{\alpha}(t)]\,\alpha(t)}$$

这是离散权重 $w_t=\beta_t/[2(1-\bar{\alpha}_{t-1})\alpha_t]$ 在连续时间下的自然推广：代入 $\beta(t)\approx-(d\bar{\alpha}/dt)/\bar{\alpha}(t)$（连续时间下 $\bar{\alpha}$ 以速率 $\beta$ 指数衰减）即可得到它。负号不可省——$d\bar{\alpha}/dt<0$，而权重必须为正；$1/\bar{\alpha}$ 因子也不可省，它来自 $\beta(t)$ 与 $d\bar{\alpha}/dt$ 的换算。检验方式：$w(t)\Delta t$ 应当重现离散的 $w_t$（见 12.5 节代码）。

## A.2 连续时间 DSM 目标

### 连续时间得分匹配

连续时间 DSM 目标为：

$$\mathcal{J}_\text{DSM}^\text{cont}(\theta) = \frac{1}{2}\int_0^1 \lambda(t)\,\mathbb{E}_{\mathbf{x}_0,\varepsilon}\left[\left\|s_\theta(\mathbf{x}_t, t) + \frac{\varepsilon}{\sqrt{1-\bar{\alpha}(t)}}\right\|^2\right]dt$$

注意这里的条件得分目标分母是 $\sqrt{1-\bar{\alpha}(t)}$（VP-SDE 下的扰动噪声标准差），与 12.4 中的 VP-SDE 记法保持一致。在 ε 预测参数化 $s_\theta = -\varepsilon_\theta/\sqrt{1-\bar{\alpha}(t)}$ 下：

$$\mathcal{J}_\text{DSM}^\text{cont}(\theta) = \frac{1}{2}\int_0^1 \frac{\lambda(t)}{1-\bar{\alpha}(t)}\,\mathbb{E}_{\mathbf{x}_0,\varepsilon}\left[\|\varepsilon - \varepsilon_\theta(\mathbf{x}_t, t)\|^2\right]dt$$

## A.3 连续时间等价性

### 权重匹配

比较连续时间 VLB 和 DSM：

- VLB 权重：$w(t) = -\frac{1}{2}\frac{d[\bar{\alpha}]/dt}{\bar{\alpha}(1-\bar{\alpha})\alpha}$
- DSM 权重：$\frac{\lambda(t)}{2(1-\bar{\alpha}(t))}$

令两者相等：

$$\frac{\lambda(t)}{2(1-\bar{\alpha}(t))} = -\frac{1}{2}\frac{d[\bar{\alpha}]/dt}{\bar{\alpha}(1-\bar{\alpha})\alpha}$$

$$\lambda(t) = -\frac{d[\bar{\alpha}]/dt}{\bar{\alpha}(t)\,\alpha(t)} = \frac{\beta(t)}{\alpha(t)}$$

### 连续时间的"干净"等价性

在连续时间下，等价性比离散时间更"干净"：

1. **三种参数化共享同一权重**：@kingma2021vdm 证明，连续时间下 ε 预测、$\mathbf{x}_0$ 预测、得分预测导出同一个 $w(t)$；离散版本其实也精确成立（代数恒等），连续形式的价值是把三种写法压缩成一个函数
2. **权重由 SDE 参数唯一确定**：$f,g$ 一经给定，$w(t)$ 就没有自由度；离散版本则需逐时间步求后验方差，形式上更繁琐
3. **精确似然计算**：通过 PF-ODE 的瞬时变量变换，可精确计算 $\log p(\mathbf{x}_0)$（而非下界）

> **从更深层次看**，第 1、2 点说明的是“表示更紧凑”，而非“离散有误差、连续无误差”。12.4 的等价性在离散层就是精确的代数恒等式；取连续极限的意义在于把 $T$ 个逐步系数替换成一个由 $f,g$ 决定的函数 $w(t)$，从而看清等价性的来源是动力学而不是网格。

### 连续时间等价性定理

**定理**：在连续时间 VP-SDE 设定下，选 $\lambda(t) = -\dfrac{d[\bar{\alpha}(t)]/dt}{\bar{\alpha}(t)\alpha(t)} = \dfrac{\beta(t)}{\alpha(t)}$，则

$$\mathcal{J}_\text{DSM}^\text{cont}(\theta) = L_\text{VLB}^\text{cont}(\theta) + \text{const}$$

**证明**：与离散版本完全类似——两个积分的权重函数在 $\lambda(t)$ 的上述选择下逐点相等，故积分结果仅差常数。 $\square$
