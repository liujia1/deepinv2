# 12.3 结构对比：殊途为何同归？

> 核心观点：把 12.1 和 12.2 的终点并排，你会看到一个令人头皮发麻的事实——DSM 损失和 ε 预测 VLB 的核心结构**完全一致**，都是"预测加进去的噪声 ε"的 MSE，差异只在含噪输入的形式和时间权重。这种一致不是巧合，它说明两种推导正在趋同。权重选得当时，两者精确等价。

先玩一个**"猜猜看"**的小游戏。

假如我告诉你：学界有两组人，一组从"逆问题后验采样"出发，另一组从"生成模型最大似然"出发，用了完全不同的数学工具，翻了不同的山头。现在我问你——

> **他们各自训练出来的扩散模型，训练目标（损失函数）会是什么样子？**

你很可能会猜：既然出发点、工具、哲学全都不一样，**训练目标应该长得天差地别吧**？一组在优化"概率梯度"，另一组在优化"概率值"，怎么可能相同？

但答案会让你一愣：**两者的核心结构一模一样，都是"预测加进去的噪声 ε"的均方误差，只差一个时间权重。** 这不是近似，是在结构上逐字对应。下面我们把两张"答案纸"摊开看。

---

## 一、两个损失函数的并排对比

把 DSM 损失（采样路径终点）和 ε 预测 VLB（变分路径终点）放进同一张表：

| 维度 | DSM 损失（采样路径） | ε 预测 VLB（变分路径） |
|---|---|---|
| **噪声变量** | $\sigma$（噪声水平） | $t$（时间步，对应 $\sqrt{1-\bar\alpha_t}$） |
| **含噪输入** | $x_0 + \sigma\epsilon$ | $\sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon$ |
| **预测目标** | $\epsilon$（添加的噪声） | $\epsilon$（添加的噪声） |
| **核心结构** | $\|\epsilon - \epsilon_\theta(\cdot)\|^2$ | $\|\epsilon - \epsilon_\theta(\cdot)\|^2$ |
| **时间权重** | $\lambda(\sigma)/\sigma^2$ | $w_t = \frac{\beta_t^2}{2\tilde\beta_t\alpha_t(1-\bar\alpha_t)}$ |
| **噪声/时间采样** | $\sigma \sim p(\sigma)$（噪声调度） | $t \sim \mathcal{U}\{1,T\}$（均匀） |
| **推导起点** | 得分函数 $\nabla\log p$ | 对数似然 $\log p$ |
| **理论框架** | Tweedie 等式 + 得分匹配 | ELBO + 变分推断 |

### 观察 1：预测目标完全相同

两张"答案纸"的核心都是 $\|\epsilon - \epsilon_\theta(\text{含噪输入}, \text{条件})\|^2$——都在猜加进去的那份噪声 $\epsilon$。

为什么是同一个目标？因为 Tweedie 等式告诉我们：得分函数、去噪器残差、噪声预测，是同一信息的三种编码：

$$\underbrace{\nabla\log p_\sigma(x)}_{\text{边际得分函数}} = \underbrace{\frac{D_\sigma(x) - x}{\sigma^2}}_{\text{去噪器残差（Tweedie）}} \quad\longleftrightarrow\quad \underbrace{-\frac{\epsilon}{\sigma}}_{\text{条件得分（DSM 目标）}}$$

左边两项是边际分布 $p_\sigma$ 的得分（由 Tweedie 等式成立），右边是 DSM 训练用的条件得分目标。三者靠 Tweedie 等式和 Vincent (2011) 的 DSM 等价性串在一起。

**所以你看到的现象是**：采样路径从得分函数出发，变分路径从 ELBO 出发，兜了一大圈，却都发现了"预测噪声"这个共同语言。

### 观察 2：含噪输入的形式可以统一

DSM 用 $x_0 + \sigma\epsilon$（加性噪声，VE-SDE），VLB 用 $\sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon$（缩放加性噪声，VP-SDE）。两种写法可以塞进 Karras et al. (2022) 的统一参数化：

$$x_t = s(t)\,x_0 + s(t)\,\sigma(t)\,\epsilon$$

- VE-SDE：$s(t) = 1$，$\sigma(t) = \sigma_t$
- VP-SDE：$s(t) = \sqrt{\bar\alpha_t}$，$\sigma(t) = \sqrt{(1-\bar\alpha_t)/\bar\alpha_t}$

统一之后，含噪输入的差异只是参数化的选择，不影响等价性本身。

### 观察 3：差异仅在于时间权重

两个损失唯一的实质差别，就是时间权重：

- DSM：$\lambda(\sigma)/\sigma^2$（由权重函数 $\lambda$ 决定）
- VLB：$w_t = \frac{\beta_t^2}{2\tilde\beta_t\alpha_t(1-\bar\alpha_t)}$（由噪声调度决定）

**当权重匹配时，两个目标精确等价。** 这引出下面的等价性条件。

---

## 二、权重匹配与等价性条件

### 情况 1：简化 VLB ≡ 简化 DSM

当 $\lambda(\sigma) = \sigma^2$（NCSN 的默认选择），DSM 权重退化：

$$\frac{\lambda(\sigma)}{\sigma^2} = \frac{\sigma^2}{\sigma^2} = 1$$

此时 DSM 目标就是均匀加权的"猜噪声"MSE，和简化 VLB $L_\text{simple} = \mathbb{E}[\|\epsilon - \epsilon_\theta\|^2]$ **完全一致**。

**注意**：这正是 Ho et al. (2020) 在 DDPM 论文里点破的——"某个参数化揭示，扩散模型的训练等价于多噪声水平的去噪得分匹配"。DDPM 的简化训练目标，就是 NCSN 的去噪得分匹配目标。这不再只是"结构相似"，而是**同一个目标**。

### 情况 2：加权 DSM ≡ 完整 VLB

选 $\lambda(t)$ 让 DSM 权重去匹配 VLB 权重：

$$\frac{\lambda(t)}{2(1-\bar\alpha_t)} = w_t = \frac{\beta_t^2}{2\tilde\beta_t\alpha_t(1-\bar\alpha_t)}$$

解得 $\lambda(t) = \frac{\beta_t^2}{\tilde\beta_t\alpha_t} = \frac{\beta_t(1-\bar\alpha_t)}{(1-\bar\alpha_{t-1})\alpha_t}$，此时

$$\mathcal{J}_\text{DSM}(\theta) = L_\text{VLB}(\theta) + \text{const}$$

两个目标的最优解完全相同——**DSM ≡ VLB**。

### 等价性的本质

权重匹配暴露了真相：DSM 和 VLB 优化的是**同一个目标函数**——预测噪声的 MSE——只是从不同的理论路径推出来，所以对时间步的加权方式不同。加权方式一旦对齐，两个目标在数学上就不可区分了。

## 实验 12.3-1：DSM 与 VLB 结构对比——殊途为何同归（数值验证）

实验 `12.3-1.py` 演示**采样路径（DSM）与变分路径（VLB）损失结构的并排对比**，通过 VP-SDE 噪声调度表、Karras 统一参数化数值对照、以及权重匹配曲线的可视化，数值验证本节三个关键观察。

### 实验场景

实验使用 DDPM 线性噪声调度（$T=1000$，$\beta_{\min}=10^{-4}$，$\beta_{\max}=0.02$），在 VP-SDE 设定下对比两条路径的损失结构：

**DSM 损失**（采样路径）：$\mathcal{J}_\text{DSM}(\theta) = \sum_i \frac{\lambda(\sigma_i)}{\sigma_i^2} \cdot \mathbb{E}[\|\epsilon - \hat\epsilon_\theta(x_0+\sigma_i\epsilon, \sigma_i)\|^2]$

**VLB 损失**（变分路径）：$L_\text{VLB}(\theta) = \sum_t w_t \cdot \mathbb{E}[\|\epsilon - \hat\epsilon_\theta(x_t, t)\|^2]$，其中 $w_t = \frac{\beta_t^2}{2\tilde\beta_t\alpha_t(1-\bar\alpha_t)}$

两条路径的核心结构均为 $\|\epsilon - \hat\epsilon_\theta(\text{含噪输入}, \text{条件})\|^2$，差异仅在于含噪输入的形式和时间权重。

### 实验目的

1. **验证本节三个关键观察**：预测目标相同、含噪输入可统一、差异仅在权重
2. **展示 Karras 统一参数化消除含噪输入的形式差异**：VE-SDE 和 VP-SDE 只是 $(s, \sigma)$ 的不同取值
3. **数值验证权重匹配条件**：当 $\lambda(t) = \frac{\beta_t(1-\bar\alpha_t)}{(1-\bar\alpha_{t-1})\alpha_t}$ 时，DSM 权重与 VLB 权重重合
4. **展示 VLB 权重的量级特征**：跨越约 2 个数量级，与简化目标的均匀权重形成对比

### 实验输入

| 参数 | 设置 |
|------|------|
| 噪声调度 | DDPM 线性，$T=1000$，$\beta_{\min}=10^{-4}$，$\beta_{\max}=0.02$ |
| 展示时间步 | $t \in \{1, 10, 50, 100, 250, 500, 750, 999\}$ |
| 权重匹配条件 | $\lambda(t) = \beta_t(1-\bar\alpha_t) / [(1-\bar\alpha_{t-1})\alpha_t]$ |
| 对比目标 | DSM 权重 $\lambda(t)/\sigma_t^2$ vs VLB 权重 $w_t$ vs 简化目标权重 $=1$ |

### 预期结果

- VP-SDE 噪声调度表展示 $\bar\alpha_t$、$\sigma_t = \sqrt{1-\bar\alpha_t}$、$\text{SNR}_t$ 随时间步的演化
- Karras 参数化数值对照表展示 VE-SDE 和 VP-SDE 在相同时间步下的 $(s, \sigma)$ 取值
- 权重匹配验证：DSM 权重与 VLB 权重在缩放后完全重合（比值恒为 2.0，偏差在浮点误差范围内）
- VLB 权重跨越约 2 个数量级，简化目标为均匀权重 1

## 三、直觉解释：等价性为何必然？

结构对比让我们"看见"了等价。但**为什么**两条完全不同的路会给出同一个目标？答案藏在得分函数和对数似然的根本关系里。

### 梯度与函数值的信息等价性

$$\nabla\log p(x) = \text{概率分布的"梯度信息"}$$
$$\log p(x) = \text{概率分布的"函数值信息"}$$

对一个光滑函数，**梯度信息和函数值信息是等价的**：

- 知道梯度 $\nabla\log p(x)$（处处），积分就能得函数值 $\log p(x)$（差一个常数）；
- 知道函数值 $\log p(x)$（处处），微分就能得梯度 $\nabla\log p(x)$。

DSM 优化的是梯度信息——逼模型准确估计 $\nabla\log p_t(x)$；VLB 优化的是函数值信息——逼模型给数据高 $\log p(x_0)$。既然两者是同一分布的两种表示，优化一个就等于优化另一个。

### 一个一维小类比（先猜后揭）

考虑一维函数 $f(x)$。两个目标：

1. **目标 A**：找 $g(x)$ 使 $g(x) \approx f'(x)$（逼近导数）
2. **目标 B**：找 $h(x)$ 使 $h(x) \approx f(x)$（逼近函数值）

如果 $g(x) = h'(x)$，那么：

- 逼近导数好 → 积分得函数值也接近（差常数）
- 逼近函数值好 → 微分得导数也接近

**这就是 DSM ≡ VLB 的本质**：得分函数是概率分布的"导数"，ELBO 是概率分布的"函数值"。你之前猜"梯度目标和值目标应该天差地别"——现在揭晓：它们是同一座山的两种地图。

### 从 Tweedie 等式看等价性的根源

Tweedie 等式是等价性的核心枢纽：

$$\nabla\log p_\sigma(x) = \frac{D_\sigma(x) - x}{\sigma^2}$$

- **采样路径**：Tweedie 把去噪器 $D_\sigma$ 转成得分函数 $\nabla\log p_\sigma$，用来驱动 Langevin / 扩散采样；
- **变分路径**：同一个去噪器 $D_\sigma$（经 ε 预测参数化）用来构造逆向过程 $p_\theta(x_{t-1}|x_t)$，最大化 ELBO。

两条路径**交汇于去噪器**——它同时扛着得分信息（采样路径）和似然信息（变分路径）。Tweedie 等式保证这两种信息其实是同一数学对象的不同表示。

### 信息论视角：费舍信息串起得分与似然

从信息论看：

- $\log p(x)$ 衡量"模型给数据 $x$ 赋予了多少信息量"（负自信息）；
- $\nabla\log p(x)$ 衡量"信息量随位置变化的速率和方向"。

准确估计信息量的变化率（得分匹配）≈ 准确估计信息量本身（似然最大化）——这背后是费舍信息与 KL 散度的关系。费舍信息矩阵（费舍信息：衡量"数据能多大程度区分模型参数"的量）正是得分函数的外积期望：

$$\mathcal{I}(\theta) = \mathbb{E}_{p_\theta}\left[\nabla\log p_\theta(x)\,\nabla\log p_\theta(x)^\top\right]$$

而 KL 散度可用费舍信息局部近似：

$$D_\text{KL}(p_\theta\|p_{\theta+\delta\theta}) \approx \frac{1}{2}\delta\theta^\top \mathcal{I}(\theta)\,\delta\theta$$

**因果链串起来**：学好得分 → 费舍信息准确 → KL 散度控制好 → 似然高。所以两条路径必然等价。

直觉已经站得住脚了。下一节，我们把这份直觉升级成严格的数学证明——DSM 损失 ≡ 变分下界。
