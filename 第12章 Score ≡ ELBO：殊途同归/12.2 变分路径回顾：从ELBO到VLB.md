# 12.2 变分路径回顾：从ELBO到VLB

> **核心观点**：变分路径的核心链条是"ELBO→VAE→层级VAE→VLB"——ELBO将似然最大化转化为变分下界最大化，VAE引入重参数化技巧和推断网络，层级VAE增加潜变量层次提升表达能力，扩散模型是无限层层级VAE的极限。本节回顾这条路径的关键数学结果，聚焦于ε预测VLB的形式，为12.3-12.4的等价性证明做准备。

## ELBO与变分推断

### 对数似然的下界

第8章8.2节推导了证据下界（ELBO）。对于观测数据 $x$，潜变量 $z$，生成模型 $p(x,z) = p(x|z)p(z)$，推断模型 $q(z|x)$：

$$\log p(x) = \log\int p(x|z)p(z)\,dz \geq \text{ELBO}$$

ELBO有两种等价形式：

**形式一（Jensen不等式推导）**：

$$\text{ELBO} = \mathbb{E}_{q(z|x)}\left[\log\frac{p(x,z)}{q(z|x)}\right]$$

**形式二（KL分解）**：

$$\text{ELBO} = \underbrace{\mathbb{E}_{q(z|x)}[\log p(x|z)]}_{\text{重建项}} - \underbrace{D_\text{KL}(q(z|x)\|p(z))}_{\text{正则化项}}$$

对数似然与ELBO的差距为变分间隙：

$$\log p(x) = \text{ELBO} + D_\text{KL}(q(z|x)\|p(z|x))$$

当 $q(z|x) = p(z|x)$ 时，变分间隙为零，ELBO = $\log p(x)$。

### ELBO最大化 = KL最小化

最大化ELBO等价于最小化 $q(z|x)$ 与真实后验 $p(z|x)$ 之间的KL散度——这正是变分推断的目标。ELBO将不可计算的后验推断问题转化为可优化的变分问题。

## 从VAE到层级VAE

### VAE：单层变分自编码器

第9章讨论了VAE。VAE的核心设计：

- **推断网络**（编码器）：$q_\phi(z|x)$ 将观测映射到潜变量分布
- **生成网络**（解码器）：$p_\theta(x|z)$ 将潜变量映射回观测
- **重参数化技巧**：$z = \mu_\phi(x) + \sigma_\phi(x)\odot\epsilon$，$\epsilon\sim\mathcal{N}(0,I)$

VAE的训练目标：

$$\max_{\theta,\phi}\,\text{ELBO}(\theta,\phi) = \mathbb{E}_{q_\phi(z|x)}[\log p_\theta(x|z)] - D_\text{KL}(q_\phi(z|x)\|p(z))$$

### 层级VAE：多层潜变量

第10章讨论了层级VAE。引入多层潜变量 $z_1, z_2, \ldots, z_T$，每一层都有自己的编码器和解码器：

$$q_\phi(z_{1:T}|x) = \prod_{t=1}^T q_\phi(z_t|z_{t-1}, x), \quad p_\theta(x, z_{1:T}) = p(z_T)\prod_{t=1}^T p_\theta(z_{t-1}|z_t) \cdot p_\theta(x|z_1)$$

其中 $z_0 \equiv x$。层级VAE的ELBO分解为：

$$\text{ELBO} = \mathbb{E}_{q(z_1|x)}[\log p_\theta(x|z_1)] - D_\text{KL}(q(z_T|z_{T-1})\|p(z_T)) - \sum_{t=2}^T \mathbb{E}_q[D_\text{KL}(q(z_{t-1}|z_t, x)\|p_\theta(z_{t-1}|z_t))]$$

### 从层级VAE到扩散模型

当层级VAE的层数 $T\to\infty$，且编码器固定为简单的加噪过程（而非学习的推断网络），层级VAE退化为扩散模型：

- **编码器固定**：$q(z_t|z_{t-1}) = \mathcal{N}(z_t | \sqrt{\alpha_t}z_{t-1}, \beta_t I)$（加噪过程）
- **解码器学习**：$p_\theta(z_{t-1}|z_t)$（去噪过程）
- **记号替换**：$z_t \to x_t$，$z_0 \to x_0$

这就是第10章的结论：扩散模型是层级VAE在"固定编码器+无穷层次"极限下的特例。

## VLB分解与ε预测形式

### VLB的三分解

第11章11.1节推导了扩散模型的变分下界（VLB）。将ELBO应用于扩散模型的结构：

$$\log p(x_0) \geq -L_\text{VLB}$$

其中：

$$L_\text{VLB} = \underbrace{D_\text{KL}(q(x_T|x_0)\|p(x_T))}_{L_T\text{（先验匹配）}} + \sum_{t=2}^T \underbrace{\mathbb{E}_q[D_\text{KL}(q(x_{t-1}|x_t, x_0)\|p_\theta(x_{t-1}|x_t))]}_{L_{t-1}\text{（一致性项）}} - \underbrace{\mathbb{E}_q[\log p_\theta(x_0|x_1)]}_{L_0\text{（重建项）}}$$

三项的含义：

- **$L_T$（先验匹配）**：最终的含噪潜变量 $x_T$ 应接近先验 $\mathcal{N}(0,I)$。由于前向过程是固定的，此项不含可训练参数，为常数。
- **$L_{t-1}$（一致性项）**：前向过程的后验 $q(x_{t-1}|x_t, x_0)$ 应与逆向过程的转移 $p_\theta(x_{t-1}|x_t)$ 一致。这是**核心训练项**。
- **$L_0$（重建项）**：从最低噪声水平 $x_1$ 重建原始数据 $x_0$。

### 正向过程后验的闭式解

由于前向过程是高斯马尔可夫链，利用贝叶斯定理可以得到 $q(x_{t-1}|x_t, x_0)$ 的闭式解：

$$q(x_{t-1}|x_t, x_0) = \mathcal{N}(x_{t-1}|\tilde\mu_t(x_t, x_0),\, \tilde\beta_t I)$$

其中后验均值为：

$$\tilde\mu_t(x_t, x_0) = \frac{\sqrt{\bar\alpha_{t-1}}\beta_t}{1-\bar\alpha_t}x_0 + \frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}x_t$$

后验方差为：

$$\tilde\beta_t = \frac{(1-\bar\alpha_{t-1})\beta_t}{1-\bar\alpha_t}$$

（有些文献用 $\sigma_t^2$ 表示此量，但为了避免与VP-SDE的有效噪声水平混淆，我们采用 $\tilde\beta_t$ 记号。）

这里 $\alpha_t = 1-\beta_t$，$\bar\alpha_t = \prod_{s=1}^t\alpha_s$。

后验均值 $\tilde\mu_t$ 是 $x_0$ 和 $x_t$ 的线性组合——它位于连接 $x_t$ 和 $x_0$ 的直线上，位置由噪声调度决定。

### 一致性项的化简

由于 $q(x_{t-1}|x_t, x_0)$ 和 $p_\theta(x_{t-1}|x_t)$ 都是高斯分布且方差相同（$\tilde\beta_t I$），KL散度退化为均值之间的欧氏距离：

$$L_{t-1} = \mathbb{E}_q\left[\frac{1}{2\tilde\beta_t}\|\tilde\mu_t(x_t, x_0) - \mu_\theta(x_t, t)\|^2\right] + C_t$$

这是第11章11.2节的核心结果——一致性项从KL散度化简为**均值匹配**问题。

### ε预测VLB

第11章11.3节将均值匹配转化为噪声预测。关键步骤是利用重参数化 $x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon$，将后验均值表示为：

$$\tilde\mu_t(x_t, x_0) = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\epsilon\right)$$

设计逆向过程均值具有相同结构：

$$\mu_\theta(x_t, t) = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta(x_t, t)\right)$$

代入均值匹配目标，化简得到：

$$L_{t-1} = \frac{\beta_t^2}{2\tilde\beta_t\alpha_t(1-\bar\alpha_t)}\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right] + C_t$$

定义权重 $w_t = \frac{\beta_t^2}{2\tilde\beta_t\alpha_t(1-\bar\alpha_t)}$，合并所有时间步：

$$\boxed{L_\text{VLB} = \sum_{t=1}^T w_t\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right] + \text{const}}$$

其中 $x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon$。

**这就是变分路径的"最终答案"**——VLB是预测添加噪声的加权MSE损失，权重 $w_t$ 由噪声调度决定。

## 简化VLB

### DDPM的简化训练目标

第11章11.4节讨论了Ho et al. (2020) 的关键发现：丢弃VLB权重 $w_t$，使用简化目标

$$L_\text{simple}(\theta) = \mathbb{E}_{t \sim \mathcal{U}\{1,T\}}\,\mathbb{E}_{x_0}\,\mathbb{E}_\epsilon\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

简化VLB在实践中有更好的生成质量（FID更低），因为：

1. **完整的VLB权重** $w_t$ 在小 $t$（低噪声）时值很大——训练过度关注"几乎无噪声"的去噪，而这些任务相对简单
2. **简化VLB**的均匀权重使得训练更关注中等噪声水平的去噪——这些是更有信息量的任务
3. 简化VLB的采样方式（均匀采 $t$）天然实现了重要性采样

不过，完整的VLB在数据压缩（codelength）方面更优，因为它严格最大化对数似然下界。

### 简化VLB的等价性暗示

简化VLB的形式 $L_\text{simple} = \mathbb{E}[\|\epsilon - \epsilon_\theta\|^2]$ 与DSM在 $\lambda(\sigma) = \sigma^2$ 时的形式完全一致——都是均匀加权的噪声预测MSE。这是12.3节结构对比的关键观察之一。

## 变分路径的终点

综合以上结果，变分路径的核心结论是：

$$\boxed{\text{训练去噪器} = \text{最大化ELBO} = \text{最大化数据似然下界}}$$

去噪器的训练目标是**ε预测VLB**：

$$L_\text{VLB} = \sum_{t=1}^T w_t\,\mathbb{E}_{x_0,\epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right] + \text{const}$$

简化版本 $L_\text{simple} = \mathbb{E}[\|\epsilon - \epsilon_\theta\|^2]$ 是实践中最常用的训练目标。

**现在，将12.1节和12.2节的结果并排放在一起**：

- 采样路径的终点：$\mathcal{J}_\text{DSM} = \sum_i \frac{\lambda(\sigma_i)}{\sigma_i^2}\,\mathbb{E}[\|\epsilon - \epsilon_\theta\|^2]$
- 变分路径的终点：$L_\text{VLB} = \sum_t w_t\,\mathbb{E}[\|\epsilon - \epsilon_\theta\|^2]$

两者都是"预测噪声ε"的加权MSE——差异仅在于权重。这暗示了深层的数学等价性。

> **过渡**：两条路径的"最终答案"在结构上高度相似——都是 $\|\epsilon - \epsilon_\theta\|^2$ 的加权求和。下一节将仔细对比两者，发现关键的结构一致性，并给出等价性的直觉解释。
