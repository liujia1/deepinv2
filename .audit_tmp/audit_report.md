## 二、P0 问题（必须修）

### P0-1　13.5-1：DOC 控制退化为“末步把 x₀ 设成 y/A”，全局优化没有实际作用

**证据**

- 脚本 `13.5-1.py` 受控 rollout：
  ```python
  posterior_mean = (x_t + beta_t * score_tensor) / torch.sqrt(alpha_t)
  u_t = control_sequence[t_idx]
  x_t = posterior_mean + u_t + posterior_noise
  ```
  `u_t` 以**系数 1**直接加到后验均值上。
- 调度 `beta_bars = linspace(0, 4.6, 20)`，`alpha_bars = exp(-beta_bars)`，因此 `t_idx=0` 时 `alpha_0=1`、`beta_0=0`、`beta_tilde_0=0`。于是末步
  \[
  x_0 = x_{t=1} + u_0
  \]
  控制 `u_0` 可以**一步完全补偿**终端误差。
- 终端代价权重 \(0.5/\sigma^2 = 0.5/0.01 = 50\)（对平方残差），控制正则仅 `0.1·Σu²`；最优解显然让 `x_0 ≈ y/A`。
- JSON 直接佐证：
  - `DOC_平均误差 = 0.036344`
  - `参考_yA数据一致点_平均误差 = 0.036345`
  - 两者在 \(10^{-6}\) 内相等；`参考_精确后验均值_平均误差 = 0.036423` 也几乎相同。
- 对比 DPS：`u_t = ζβ_t∇log p(y|x_t)`，`t_idx=0` 时 `β_0=0`，**末步引导自动消失**；DOC 的 `u_0` 不受 `β` 缩放。两者结构性不对称。

**影响**

- “DOC 相对改进 14.71%、DOC 胜 31/50”实际是 **“y/A 点估计 vs DPS 后验样本”** 的差异，不是“全局轨迹优化优于贪心引导”。
- 实验无法区分“DOC 全局控制”与“末步数据一致性投影”，13.5 节的核心论点（全局优化有独立价值）在本实验中未被验证。
- md 仍引用旧运行（DPS 0.0743、DOC 0.1250），与当前 v2 JSON 完全相反，见 P0-2。

**修正建议**

1. 控制项改为 `beta_t * u_t`（或 `sqrt(beta_t) * u_t`），与 score 引导同尺度；末步 `β=0` 时控制也应消失，或显式禁止末步控制。
2. 若保留“终端可直接投影”的设计，则 DOC 应与**后验均值**（同为点估计）比较，而不是与后验样本比较；并在正文明确“DOC 在本实验退化为数据一致点估计”。
3. 重跑后更新 md 的表格、图注、`x_0≈-2.61/-2.46`、控制曲线 `-0.16/-0.40` 等全部旧图注。

### P0-3　13.6-1：似然梯度前因子写成 `1/mean_t`，方向与 13.4-2 的结论相反

**证据**

- `13.6-1.py` line 184：
  ```python
  likelihood_grad_raw = A_prime * (y_obs - Ax0_hat) / (sigma_y**2 * mean_t)
  ```
- line 181 注释：“原bug1: mean_t * (...) 方向反了，应该是除以 mean_t”——这个诊断本身是反的。
- 13.4-2 的 docstring/推导明确：对单位方差高斯先验，
  \[
  \frac{\partial \hat{x}_{0|t}}{\partial x_t} = \text{mean}_t
  \]
  正确似然得分应为
  \[
  \nabla_{x_t}\log p(y|x_t)\approx \text{mean}_t\cdot \frac{A'(y-A\hat{x}_0)}{\sigma_y^2}.
  \]
  `t=0.9` 时 `mean_t≈0.017`，`1/mean_t≈58.8`，相差约 \(1/\text{mean}_t^2\approx 3.5\times10^3\)。
- `GRAD_CLIP_MAX=10` 把爆炸截断，掩盖了错误；md line 248 还把“经 `1/mean_t` 放大”写成 δ-似然偏差的机理。

**影响**

- 13.6-1 的 vanilla DPS 不是标准 DPS，任务 1/2/3 的均值/标准差、`ζ=0.25` 对照、“δ-似然近似边界”的定量结论全部被污染。
- 与 13.4-2（mean_t 正确）形成同一章内互相矛盾的两种实现。

**修正建议**

1. 改为 `mean_t * A_prime * (y - Ax0_hat) / sigma_y**2`，或直接用 autograd 精确 Jacobian。
2. 去掉固定 `clip=10`，改用自适应裁剪/分位数裁剪；或先归一化再乘 `mean_t`。
3. 重跑任务 1/2/3、`ζ=0.25` 对照与边际化对照；重新评估“δ-近似边界”是否仍成立。
4. 修正 md line 248 的“1/mean_t 放大”表述，并与 13.4-2 统一记号。

### P1-2　13.4.3 偏差-方差/多样性写反

- md line 322：“`ζ` 大 → 偏差低，**方差高（不同采样轨迹高度相似、缺多样性）**”——“轨迹相似”对应**方差低**，不是高。

### P1-3　13.3.2 伪代码步骤2注释符号错误

- line 268：`# 线性情形：= -2 · ∇_{x_t}x̂₀ · Aᵀ(Ax̂₀ - y) / σ²`
- 正确：\(\nabla_{x_t}\|y-A\hat{x}_0\|^2 = -2(\partial\hat{x}_0/\partial x_t)^\top A^\top(y-A\hat{x}_0)\)。
- 当前注释等价于 \(+2\nabla\hat{x}_0 A^\top(y-A\hat{x}_0)/\sigma^2\)，**符号相反**，且多出无来源的 `/σ²`（σ² 属于 log 似然的 \(1/(2\sigma^2)\) 因子，不在 \(\|\cdot\|^2\) 里）。
- 建议改为 `-2 (∂x̂₀/∂x_t)ᵀ Aᵀ (y - Ax̂₀)`，并让步骤3的 `-ζ·∇_likelihood` 与该定义一致。

### P1-4　13.3-1：冗余前向、单样本“多样性”、print 与数据矛盾

- 模型前向两次（`no_grad` 一次 + 需梯度一次），数值等价但多一倍算力，与 docstring“单次前向”不符。建议删除 `no_grad` 那次，保留 `requires_grad` 前向。
- 每个 ζ 仅单次采样，却宣称“质量-多样性权衡”；print“单调权衡”与自身数据（ζ=3 的 26.64 > ζ=5 的 26.34）及 md 峰值矛盾。建议每档跑多种子，或把结论降级为“单样本趋势”。

### P1-5　13.3-3：DPS 基线不是完整采样链，调度也不自洽

- DPS 基线是单步梯度 `x_hat_0 + A.T@(y-A@x_hat_0)/S[0]**2`，不是完整 DPS 采样链；与 DDRM 的完整逆向过程对比不公平。建议要么实现完整链，要么在正文明确“DPS 仅作单步数据一致性基线”。
- `T=200、β_max=0.02` → \(\bar\alpha_T\approx0.13\)，并非纯噪声；md 称 t=199“最后一步/高噪声”不准确。建议增大 β_max 或改称“中等噪声起点”。
- line 320–325 的 `x0_star/y_obs` 是死代码，建议删除。
- DDRM 用逐分量独立 1D GM + `v_prior=mean(var)`，与“频谱域条件化精确”的叙事有张力；建议在实验节说明这是“高斯近似下的精确”，并给出近似误差来源。

### P1-6　13.2-2：“忽略 Jacobian”同时丢掉了 `mean_t` 因子，夸大两变体差异

- `dps_approx_simple = dps_residual = (y - A*x0_hat)/σ²`。
- 标准 DPS 至少应保留 \(\partial\hat{x}_0/\partial x_t = \text{mean}_t\)；当前“简单版”把 Jacobian **和** Tweedie 缩放都丢了，因此不是“仅忽略 Jacobian”。
- 后果：含 J 误差 0.1306→8.5536，忽略 J 误差 0.1410→**309.27**，差异被显著放大。
- 建议：简单版改为 `mean_t*(y - A*x0_hat)/σ²`，或明确标注“同时忽略 Jacobian 与 Tweedie 缩放”；重算误差曲线。
- 另：“99.5% 采样点”不在 JSON 中，属脚本外统计，建议移入 JSON 或删除。

### P1-9　13.6-5 单样本无法测量“多样性”

- 每个 strength 仅 1 个样本（seed=42），只测了“与初始图的像素距离”，没有测多样性。
- JSON 的“样本数说明”已诚实注明；但 md 标题/结论仍用“质量-多样性权衡”。
- 建议：标题/结论降级为“重绘幅度-保真度趋势”；若要谈多样性，每档跑 5–10 个种子，统计方差/LPIPS 分布。

### P1-10　13.6-1 把“5 个均值的标准差”称为“标准误”

- md line 242：“多次采样标准误（0.004）”。
- 脚本用 `np.std(all_means)=0.0042`，这是 **5 个运行均值的标准差**；标准误应为 \(0.0042/\sqrt{5}\approx0.0019\)。
- 建议改为“5 次运行均值的标准差 0.0042（标准误约 0.0019）”，或直接报告 95% 区间。

### P1-11　13.7 的 DPS 公式与正文/附录记号不一致

- line 34：\(\nabla\log p(y|x_t)\approx -\frac{1}{\sigma^2}\nabla_{x_t}\|y-A\hat{x}_{0|t}\|^2\)。
- 正确应为 \(-\frac{1}{2\sigma^2}\nabla\|\cdot\|^2\)（若 ∇ 是对 \(x_t\) 的全梯度）；13.3 的式 (13.33) 有 1/2，13.7 丢了。
- 建议补上 1/2，或写成“吸收进 ζ 后的等价形式”，并与 13.3/附录13A 统一符号约定。
